# [辩论内容概述]
[一段话交代：辩题、正反双方立场（各一句话概括）、辩论整体走向（交锋的核心议题；**转折或占优只在原文明示时写**——评委/主持人点评、辩手自陈，不自判）；**不展开具体论据与交锋细节（那是 [核心论点] / [环节交锋] 的事）**；**提到某一方立场时只写原文明确归属该方的表述**（分不清就写「一方」或只写议题）；一段写完，约 250–400 字]

# [核心论点]
[正文交代辩题、正反方立场与整体格局（一两句即可）；正反方的立论框架、核心论点与支撑论据**只写进下表**——**按原文出现顺序排列（同一环节内正反交替），不要把一方的论点归堆写完再写另一方**；**行数＝论点数**（原文有几个论点就写几行，每方通常 2–4 行，**不要一方一行、也不要求两方行数对称**）；一个论点下的多个论据用 `；` 分隔列全；**支撑论据列只写具体论据（数据、类比、案例、原话），不得重复另外两列的文字，某格确实没有就写 `—`**；**阵营归属以原文的开场自我介绍、主持人报幕和队名为准；凭论点内容判不出阵营时写「一方」，不得猜**；正文不复述表内内容]

# [争议焦点]
[按**议题**归纳双方真正的分歧（不是按环节复述交锋）：最顶层级按数字序号（1. 2. 3. ...）一行一项（`1. **焦点**：争的是什么；正方：…；反方：…`，亦兼容每条一个焦点，`- **焦点**：争的是什么；正方：…；反方：…`；一方没有对应主张时只写有的那侧）；**3–5 条，原文出现过的焦点都要有**——论点表里每对相反的主张就是一个焦点，**看完通篇回头归纳**，不要与 [核心论点] 的表述逐字重复；**只归纳双方的立场与依据，不做输赢、高下或"谁更有道理"的判断**（原文明示占优才写，且写在 [结辩与评委点评]）；原文没有形成观点对立的就写「未提及」]

# [环节交锋]
[按原文实际出现的环节分组（环节名取原文的说法）：每个环节一行 `## 环节名`，交锋采用对决微卡片结构，写清谁攻谁守（即一方质疑/立论、对方反驳/回应）：每个交锋点一行加粗提炼议题 `**【交锋焦点】**`，紧接双引用卡片行：第一行 `> **质疑方（或攻方/阵营）**：发问或立论要点`，第二行 `> **回应方（或守方/阵营）**：“原话引用或反驳”`（亦兼容数字序号 1. 2. 3. ... 一行一项；先写一方进攻、紧接写对方回应）；**禁止在阵营后重复加括号（如出现「正方质询（正方）」等同义反复）；严禁凭论点内容主观推断正反方——只有原文明示队名/辩手时才标注阵营，未明示正反方时统一按客观攻防动作使用「质疑方/回应方」或「立论方/反驳方」，完全判不准就写「一方」与「另一方」**；**每个环节 2–5 个交锋点**（**标题下必须至少一条正文，不得只有标题；写不出内容的不立标题**）（原文有几个写几个，不要把一轮交锋压成一条）；原文没有环节线索就直接按交锋顺序分条，不要硬分组；**每个交锋点尽量带 1 句原文引用**（`> ` 逐字不改写），归不到人时只引原话、不署名]

# [结辩与评委点评]
[**分三条写**，最顶层级按数字序号：`1. **正方结辩**：…`、`2. **反方结辩**：…`、`3. **评委点评**：…`（亦兼容 `- **正方结辩**：…`、`- **反方结辩**：…`、`- **评委点评**：…`；原文没有的条不写）；每条写清核心升华点与关键判断（数字、环节、名次照原文），**每条 60–150 字**；**原文明示获胜方时才标注**（评委宣布、赛制规则或双方确认），未明示不写；评委的总结性判断或点题句用 *具体内容* 突出；**只写该环节原文出现的原话与判断**——不得把其它环节的论点搬进结辩或点评，也不得替评委补结论]
