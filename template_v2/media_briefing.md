# [发布会概况]  
[以一段话简明概括发布会主题、发布单位、核心信息及整体基调，确保涵盖所有关键要素，避免遗漏重要背景信息，语言精炼、逻辑清晰，突出发布会的核心目的与主要传达信息]

# [核心信息]  
[提炼官方发布的关键事实、核心数据及重要政策/举措，确保信息完整、重点突出，避免无关细节；关键数据**加粗**，文件名、政策名、日期、机构名可用 `具体内容` 标注；数据需注明来源或背景，确保信息准确、可追溯]

# [官方表态]  
[记录发言人对热点问题的核心表态与官方口径，逐项还原，不得改写措辞；需保留的官方原话可用 > 引用；确保回应内容与问题一一对应，避免重复或无关内容混杂；若同一问题有多个回应，应分别列出并清晰区分，避免信息混淆]

# [Q&A环节]  
[梳理媒体提问的核心问题及官方回应，用「问 → 答」形式呈现；确保覆盖原文中所有重要提问场景，避免遗漏或比例失调；问题与回应应紧扣发布会主题，剔除与主题关联较弱的内容；若多个问题内容相似，应整合归纳，避免重复，保持信息密度与可读性]
