# [研讨背景与议题]
[上半段一段话交代研讨背景：主题、参与方（人数/机构/方向照原文；**原文没说参与方就不写**）、为什么开这场研讨；下半段最顶层级按数字序号（1. 2. 3. ...）一行一项逐条列出（`1. **议题名**：要解决的核心痛点 / 待解问题 / 为什么重要`，亦兼容 `- **议题名**：要解决的核心痛点 / 待解问题 / 为什么重要`），议题名取原文说法，一条一个议题，宁多不漏；人员与数字照原文]

# [核心观点]
[按议题维度梳理（每个主要议题一行 `### 议题名` 展开，亦兼容按数字序号集中列出）：最顶层级按数字序号（1. 2. 3. ...）一行一项列出不同视角的观点、提出的创新思路、数据或案例支撑（格式：`1. **观点提炼短语**：具体主张与论据（提出方/发言者照原文）`，亦兼容 `- **观点提炼短语**：…`；**每条以该观点的核心关键词/论题加粗起头，禁止机械使用「倾向性认识」「核心观点」等套话作前缀**）；对立观点分别标注提出方]

# [达成共识与解决方案]
[有共识就写共识：谁与谁一致、依据是什么；**未形成统一结论时直写「未形成统一结论」，再分条提炼本场研讨形成的倾向性认识与主流意见**（每条以具体的共识/结论主题词加粗开头：`1. **结论主题**：具体认识与依据…` 或 `- **结论主题**：…`；**严禁机械重复「倾向性认识」「主流意见」等空洞套话作为加粗前缀**，不要用无倾向的观点散漫罗列充当共识）；解决方案最顶层级按数字序号（1. 2. 3. ...）一行一项写成可落地条目：对象 + 做法 + 依据/前提，原文没有就写「未提及」（不写说明句）；关键结论用**加粗**]

# [未决分歧与后续探索]
[最顶层级按数字序号（1. 2. 3. ...）一行一项列出，每条写清：分歧点是什么 + 双方各自主张（标注提出方）+ 需要验证什么 / 谁跟进（原文有才写）；**只写原文说出具体事项与责任方或跟进人的内容**；整条确实无信息就**不写该条**（不要逐条标「未明确」）；整栏都没有内容时才用一次「未明确」]
