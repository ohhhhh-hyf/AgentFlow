面向使用者 · 不讲代码

从一句需求，到可交付成果

这份教程教你使用 AgentFlow 完成会议纪要、待办提取、风险分析、资料入库、OCR 图片识别、 知识目录、复习清单、自测题和知识图谱。按步骤操作即可，不需要理解系统内部实现。

开始使用 查看示例指令
2 个入口 静态前端工作台用于完整交互；Gradio 测试台用于快速验证单个任务。
2 个领域 会议域处理会议材料；笔记域处理学习资料、知识库和复习任务。
推荐路径

先输入用户 ID，再用自然语言说目标。系统会在右侧生成任务计划，你只需补学科、项目、上传文件，然后点击执行。

快速上手

第一次使用时，照着这 6 步走最稳。

打开服务页面

静态前端通常访问 http://127.0.0.1:8000。如果使用 Gradio 测试台，访问 http://127.0.0.1:7860。

填写用户 ID

左下角输入用户 ID，例如 user_001。知识库、历史会话、产物云盘都会按用户隔离；不填用户 ID 时，前端会提示先填写。

在中间聊天框说出目标

例如“把这些物理资料入库，并生成复习清单”。系统会把你的话转成右侧的任务计划。

检查右侧任务计划

右侧会显示“流水线编排”。如果缺文件、学科、项目等信息，会在当前任务卡片里提示你补充。

上传文件或补充参数

根据任务上传会议文本、课件、讲义、笔记图片等。笔记域通常还要填写“所属学科”；会议域可选填“所属项目”。

点击执行并查看成果

执行后切到“执行监控”看进度。完成后系统会自动切到“产物中心”，可在线预览或下载生成的 HTML、Markdown、图片等成果。

界面认识

静态前端是三栏布局：左侧资产，中间对话，右侧任务和产物。

左侧栏

会话中心、知识库资产、产物云盘

  • 顶部“+”可以开启新会话。
  • “知识库资产”展示当前用户已有学科。
  • “产物云盘”展示历史生成文件，可点击预览。
  • 头像可配置职业视角和个人偏好。
中间栏

自然语言入口

  • 输入一句需求即可规划任务。
  • 系统会识别学科、项目、职业视角等参数建议。
  • 如果不是任务型需求，会转为知识库问答。
  • 历史会话会按用户 ID 保存。
右侧栏

任务计划、执行监控、产物中心

  • “任务计划”用于补参数、传文件、执行阶段。
  • “执行监控”用于查看实时日志和进度。
  • “产物中心”用于预览、下载最终成果。
最重要的使用习惯： 不要一开始就到处找按钮。先在中间聊天框说出目标，再跟着右侧任务卡片补材料。

用户头像：职业视角与偏好设置

左下角头像不只是装饰，它决定系统用什么“身份”和表达习惯来理解你的需求。

先填写用户 ID

头像设置绑定当前用户 ID。左下角没有用户 ID 时，点击头像会提示先填写。建议每个人、每个测试账号都使用固定 ID，例如 user_001、teacher_li。

点击左下角头像

头像旁带有设置标记。点击后会打开“用户画像与偏好设置”弹窗，里面可以查看当前用户 ID、选择职业视角、填写个性化偏好。

选择职业视角

默认是“客观 · 客观全员”。你也可以切到开发人员、产品经理、项目经理、测试工程师、算法工程师、客户经理等职业视角。

填写偏好并保存

可填写“做事风格”“沟通偏好”“性格特质”。保存后，聊天框上方会显示当前职业标签；之后生成纪要、分析风险、总结待办时会参考这些偏好。

职业视角 适合场景 输出倾向
客观全员 默认纪要、课堂记录、资料整理 尽量中立、完整、面向所有人可读。
开发人员 技术评审、研发周会、缺陷复盘 更关注实现细节、技术依赖、接口、上线风险。
产品经理 需求讨论、版本规划、用户反馈会 更关注需求边界、验收标准、优先级、用户价值。
项目经理 项目例会、里程碑检查、资源协调 更关注时间节点、负责人、阻塞项、交付风险。
测试工程师 测试评审、质量复盘、发布前检查 更关注验收用例、缺陷风险、覆盖范围、回归点。
算法工程师 模型评审、实验讨论、算力和指标分析 更关注数据、指标、模型效果、训练和部署条件。
客户经理 客户沟通、商务交付、项目汇报 更关注客户诉求、承诺事项、商务风险、交付口径。
偏好示例

可以这样填写

  • 做事风格：结论先行，重视可执行步骤。
  • 沟通偏好：少套话，多列清单，保留关键责任人。
  • 性格特质：严谨，关注风险和遗漏。
使用建议

什么时候要改职业视角

如果你希望同一份会议记录产出不同关注点，可以先改头像职业视角，再重新生成。例如先用“客观全员”出正式纪要，再切“项目经理”出交付跟进版。

任务计划页怎么填写

右侧“任务计划”是正式执行前的确认区，所有缺失项都会在这里补齐。

流水线编排

看阶段，不看代码

顶部会显示“阶段 1、阶段 2...”这样的流程。当前阶段的任务卡片会展开，其它阶段暂时隐藏。执行完当前阶段后，会自动切到下一阶段。

待补全项

按钮灰了先看提示

如果“执行”按钮不可点，底部会提示缺什么，例如缺附件、缺所属学科。补齐后按钮会恢复可点。

输入依赖自动供给

不要重复上传上游产物

如果任务卡片显示“由上游自动供给”，说明上一步的 OCR、入库或纪要产物会自动传给下一步，不需要手动下载再上传。

你看到的字段 什么时候出现 应该怎么填
所属学科 资料入库、知识目录、复习清单、知识图谱、OCR 等笔记域任务 填课程或学科名，例如“物理”“数学”“高等数学”。后续任务要保持同一个名字。
所属项目 会议域任务，尤其是会议纪要 可填“晨会”“AgentFlow”“版本评审”等，用于区分会议项目。
文件上传区 任务缺文件或缺图片时 按任务卡片提示上传。资料入库可多选；OCR 支持多图；普通会议任务通常上传一份文本。
老师划重点 知识目录、复习清单任务 可粘贴文本，也可上传重点文件。它是补充材料，不是必须项。
无需新增知识 已有该学科知识库，且当前阶段需要资料但你不想再上传 点击后跳过新增入库，直接进入后续目录、清单等任务。

左侧资产区：知识库资产、产物云盘、历史会话

左侧栏负责“找回东西”和“复用已有资料”。这是长期使用 AgentFlow 时最重要的区域之一。

知识库资产

查看当前用户已有学科

点击“知识库资产”可以展开当前用户的学科列表。每个学科后面会显示已有资料切块数量，例如“物理（128条）”。

  • 点击刷新按钮，可以重新扫描当前用户知识库。
  • 点击某个学科标签，会自动填入右侧“所属学科”。
  • 如果列表为空，说明当前用户还没有入库资料，或用户 ID 填错了。
产物云盘

找回历史生成文件

点击“产物云盘”会展开历史交付物列表，包括 HTML、Markdown、JSON、图片等。

  • 点击刷新按钮，可以重新加载历史产物。
  • 点击文件条目，会切到右侧“产物中心”并打开预览。
  • 适合找回之前生成的会议纪要、复习清单、知识图谱和导图。
历史会话

回到之前的对话

左侧“历史会话”按用户 ID 展示曾经的聊天记录。点击某条会话即可恢复中间聊天记录。

  • 会话标题通常来自第一句用户问题。
  • 点击删除按钮可以移除某条会话。
  • 点击左上“+”可以开启全新会话。
你想做什么 去哪里点 结果是什么
看看当前用户有哪些知识库学科 左侧“知识库资产” 展开学科标签列表，并显示每个学科已有资料数量。
把已有学科填入新任务 展开“知识库资产”，点击学科标签 右侧“所属学科”会自动填入该学科。
找之前生成的报告 左侧“产物云盘” 展开历史文件列表，可点开预览或下载。
继续之前的聊天 左侧“历史会话” 中间对话区恢复该会话内容。
开始一个全新任务 左侧顶部“+” 新建会话，清空当前工作台，保留用户资产。
知识库资产和用户 ID 强绑定。 如果你换了用户 ID，左侧看到的学科也会变。找不到之前的学科时，先确认左下角用户 ID 是否和入库时一致。
产物云盘是“历史成果入口”。 当前任务完成后可以在右侧产物中心看；过一段时间想找回来，就到左侧产物云盘里找。

输出模板与纪要场景选择

模板用于控制最终成果的版式。会议纪要、风险、待办、思维导图、知识图谱等任务会显示“输出模板（选填）”。

方式一

内置模板选择

点击“输出模板”里的“内置模板选择”，打开下拉菜单。左侧按场景分类，右侧展示对应模板。选中后会显示“已定制模板”。

方式二

上传模板文件

选择“上传模板文件”，上传 .md 或 .txt。系统会读取模板内容，你可以在预览框里继续编辑。

方式三

自然语言描述生成

选择“自然语言描述生成”，直接写你的版式要求，例如“第一部分写结论，第二部分用表格列待办，第三部分列风险”。

内置场景 模板名称 适合什么材料
会议 团队例会、项目进度会、决策评审会、工作研讨会、总结复盘会、沟通交流会 团队同步、项目推进、评审决策、复盘总结等正式会议。
学习 课堂记录、专题讲座、小组讨论、知识笔记、辩论会 课堂转写、讲座整理、学习讨论、知识归纳。
访谈 调研访谈、采访记录 用户访谈、调研访谈、采访逐字稿整理。
面试 面试报告、面试复盘 招聘面试、候选人评价、面试过程复盘。
医疗 就医咨询、心理咨询 咨询记录整理。注意最终判断仍需专业人士确认。
法律 法律咨询、庭审记录、合同审核 法律咨询和合同讨论记录。正式用途应再由专业人士审阅。
发布 新闻发布、产品发布、政府报告、媒体问答 发布会、媒体沟通、公开问答、正式公告整理。
日常 通用纪要、个人备忘、对话记录、参观游览、家校沟通 不确定类型时可选通用纪要；个人记录和日常沟通也适用。
查看模板内容

选模板前可以先看

在内置模板模式中，选择具体模板后可点击“查看模板内容”。如果不选模板，系统使用默认输出格式。

自然语言模板示例
请生成项目进度会纪要： 1. 顶部写会议主题、时间、参会人 2. 正文先给一段 200 字以内总结 3. 用表格列出待办事项、负责人、截止时间 4. 最后列出风险和需要协调的资源

常用任务怎么做

下面按最常见场景列出输入、操作和产物。

会议纪要 输入用户 ID，发送“帮我生成一份会议纪要”，上传会议记录文本。可选填项目 ID；可在头像里选择职业视角。完成后查看纪要 HTML/Markdown。
待办事项 发送“帮我提取这次会议的待办事项”，上传会议记录。系统会生成行动项、负责人、截止时间等内容。
风险分析 发送“帮我识别这次会议里的风险点”，上传会议记录。适合项目复盘、评审会和周会之后使用。
会议思维导图 发送“把这份会议内容生成思维导图”，上传会议记录。成果通常是可交互 HTML，也可能包含图片导出。
资料入库 输入用户 ID 和学科，发送“把这些资料入库到数学”。上传课件、讲义、Word、PDF、Excel、Markdown 或文本。完成后知识库资产会出现对应学科。
图片 OCR 发送“识别这些笔记图片”，上传 PNG/JPG/JPEG 图片。成果是整理后的 Markdown，可继续用于资料入库、审校或出题。
图片入库再复习 发送“把这些图片识别后入库到物理，并生成复习清单”。上传图片，填写学科。系统会先识别，再入库，再生成清单。
知识目录 已有知识库后，发送“基于物理知识库生成知识目录”。可选上传或粘贴老师划重点文本；不需要重复上传已入库课件。
复习清单 已有知识库和目录后，发送“生成物理考点复习清单”。可选补充老师本次划重点；不补也能基于知识库生成。
自测题 发送“根据这份笔记出几道自测题”，上传笔记文本或 OCR 后的 Markdown。可选择难度和题型。
知识图谱 发送“为数学生成知识图谱”。需要用户 ID 和学科，适合在资料已经入库之后查看知识结构。
知识库问答 直接问“我物理知识库里关于动量守恒有哪些重点？”如果没有识别成任务，会进入问答模式并给出参考来源。

完整案例流程

下面按真实使用顺序写，适合照着操作。

案例一

生成一份项目进度会纪要，并套用模板

  1. 左下角填写用户 ID，例如 pm_001。
  2. 如果你希望偏项目管理，点击头像，把职业视角改为“项目经理”。
  3. 在聊天框输入：帮我生成一份项目进度会纪要。
  4. 右侧出现“会议纪要生成”任务后，填写“所属项目”，例如 AgentFlow。
  5. 上传会议记录文本。
  6. 展开“输出模板”，选择“内置模板选择”。
  7. 在场景里选择“会议场景”，再选“项目进度会”。
  8. 可点击“查看模板内容”确认格式。
  9. 点击“执行”，完成后到“产物中心”查看 HTML/Markdown。
案例二

把一批课件入库，并生成复习清单

  1. 左下角填写用户 ID，例如 student_001。
  2. 聊天框输入：把这些资料入库到物理，并生成复习清单。
  3. 如果系统识别到学科建议，点击“学科：物理”；也可以在右侧手动填“物理”。
  4. 在“资料入库”阶段上传 PDF、PPTX、DOCX、TXT、MD 等资料，可多选。
  5. 点击执行。入库完成后，下一阶段会继续生成目录或清单。
  6. 如果“复习清单”阶段出现老师划重点输入框，可选填本次重点；不填也可以执行。
  7. 完成后查看复习清单 HTML，左侧知识库资产里也会出现“物理”。
案例三

把手写图片识别后再入库

  1. 聊天框输入：把这些笔记图片识别后入库到数学。
  2. 右侧会出现 OCR 和资料入库相关阶段。
  3. 在 OCR 阶段上传多张 PNG/JPG/JPEG 图片。
  4. 填写所属学科“数学”。
  5. 点击执行。OCR 完成后，识别出的 Markdown 会自动供给入库任务。
  6. 不需要手动下载 OCR 结果再上传。
  7. 完成后可到产物中心查看 OCR Markdown，也可到知识库资产确认学科。
案例四

基于已有知识库生成目录和清单

  1. 确认左下角用户 ID 是之前入库时用的 ID。
  2. 展开左侧“知识库资产”，点击已有学科，例如“物理”。
  3. 聊天框输入：基于已有物理知识库生成知识目录和复习清单。
  4. 如果右侧出现上传资料阶段，但你不想新增资料，可以点击“无需新增知识”。
  5. 目录阶段可选填老师划重点。
  6. 清单阶段可选填考前重点或老师强调内容。
  7. 完成后在产物中心查看目录说明、复习清单和相关 HTML 文件。
案例五

生成自测题并控制难度

  1. 聊天框输入：根据这份笔记生成自测题，难度适中。
  2. 上传笔记文本或 OCR 后的 Markdown。
  3. 如果页面出现难度和题型选项，选择“适中”“单选题/多选题/解答题”等。
  4. 点击执行。
  5. 完成后打开自测题 HTML，通常答案和解析会折叠展示，适合先做题再核对。
案例六

从产物云盘找回历史成果

  1. 确认左下角用户 ID 是生成该成果时的用户 ID。
  2. 点击左侧“产物云盘”。
  3. 点击刷新按钮，等待历史交付物列表出现。
  4. 找到目标文件，例如 result_*.html、result_*.md。
  5. 点击文件条目，右侧会切到产物中心并加载预览。
  6. 需要保存时，在文件列表中点击下载。

上传文件规范

文件传对，后面的结果会顺很多。

任务 建议上传 注意事项
会议类任务 会议记录、转写文本、Markdown 通常一份文本即可。内容越完整，纪要、待办、风险越准确。
资料入库 TXT、MD、PDF、DOCX、PPTX、XLSX，也支持图片 可多选。建议同一批资料属于同一用户和同一学科。
OCR 图片识别 PNG、JPG、JPEG 图片尽量清晰、正向、无遮挡。多页笔记可以一次上传多张。
知识目录 / 复习清单 可选上传老师划重点文本 课件和笔记不用重复上传，系统会读取已入库知识库。
自测题 / 笔记审查 笔记文本、Markdown、OCR 结果 如果原始材料是图片，建议先 OCR，再基于 OCR 结果出题或审查。
学科一定要一致。 例如入库时写“物理”，后续生成复习清单也写“物理”。同一个用户 ID + 学科会定位到同一个知识库。
已有知识库时可以跳过新增资料。 如果你只是想基于已有知识库生成目录或清单，选择已有学科并继续执行即可。

选择领域和任务

顶部选择“会议”或“笔记”，再选择具体任务，例如纪要、资料入库、复习清单、OCR识别。

填写配置

笔记域的资料入库、目录、清单和 OCR 通常需要用户 ID 与学科；会议纪要可选视角、用户 ID 和项目 ID。

上传或粘贴输入

按页面提示上传文本、资料或图片。资料入库可多文件；OCR 只需要图片；目录和清单可选填老师划重点。

运行并下载

点击“运行”，右侧会显示日志、预览和下载文件。OCR 会显示计时；部分任务会生成 HTML、Markdown、图片等多个文件。

常见问题

遇到卡住时，先看这一组。

为什么一直提示输入用户 ID？

当前前端要求先填写用户 ID，用于隔离你的知识库、历史会话和产物。左下角填一个固定 ID 即可，例如 user_001。

为什么复习清单提示缺学科？

复习清单需要知道读取哪个学科的知识库。请在右侧“所属学科”里填写和入库时一致的学科名。

已有资料入库，还要重复上传吗？

不需要。生成目录、复习清单、知识图谱时，选择已有学科即可。老师划重点是可选补充，不是必填资料。

图片识别结果不理想怎么办？

尽量上传清晰、正向、光照均匀的图片。多页笔记建议按页上传，不要把很多页拼在一张图里。

产物中心没有看到想要的文件？

先确认任务是否完成，再切到“产物中心”。也可以打开左侧“产物云盘”刷新历史文件。

一句话识别成了问答，不是任务？

把动作说得更明确，例如“生成”“入库”“识别”“提取”“生成复习清单”。如果只是提问，系统会进入知识库问答。

运行前检查清单

提交前快速扫一遍，能避免多数失败。

已经填写用户 ID，且后续都用同一个用户 ID。
笔记域任务已经填写学科，且学科名和入库时一致。
上传文件类型符合任务要求：会议传文本，OCR 传图片，入库可多文件。
如果只是基于已有知识库生成目录或清单，没有重复上传旧课件。
任务完成后，已在产物中心或产物云盘查看并下载成果。
一句话记住 AgentFlow 的用法

先填用户 ID，再说目标；右侧补参数和材料；执行后到产物中心查看结果。
