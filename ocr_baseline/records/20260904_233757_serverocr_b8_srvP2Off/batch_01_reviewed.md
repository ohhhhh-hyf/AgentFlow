## 气体的基本统计规律

### 气体的微观模型

$$PV = \nu RT = \frac{m}{M}RT = \frac{N}{N_A}RT$$

$$P = \frac{N}{V}kT = nkT$$

其中 $n$ 为单位体积内的粒子数。

标准状态下的气体分子数密度 $n_0 = 2.69 \times 10^{25} \text{ m}^{-3}$，表示每 $\text{m}^3$ 理想气体中的微观粒子数。

分子线度为 $d$，则 $d^3 \sim \frac{V}{N} = \frac{M}{\rho N_A}$，即 $d \sim \left(\frac{M}{\rho N_A}\right)^{1/3}$，即可不计分子本身的大小。

**理想气体的微观模型：**
① 可不计分子本身的大小；
② 除碰撞外，气体分子间及气体分子同器壁间的相互作用可忽略；
③ 分子在两次碰撞间做匀速直线运动。

**压强的微观模型：**
① 宏观上认为器壁受连续作用力；
② 热平衡时，假设分子和器壁的碰撞是弹性碰撞；
③ 分子混沌性假设：平衡态时，气体分子的热运动速度无择优方向。

第 $i$ 个分子与 $A_1$ 面碰撞，$y$、$z$ 分量不变，$x$ 方向速度分量由 $v_{xi} \to -v_{xi}$。

第 $i$ 个分子单位时间与 $A_1$ 面碰撞次数为 $\frac{v_{xi}}{2a}$，单位时间单位面积冲量即压强。

$$P = \frac{2mv_{xi}^2}{bc} \cdot \frac{1}{2a} = \frac{mv_{xi}^2}{abc} = \frac{m}{V}\sum_i v_{xi}^2$$

$$\overline{v_x^2} = \frac{1}{3}\overline{v^2}，则 p = \frac{1}{3}nm\overline{v^2} = \frac{2}{3}n\overline{\varepsilon_k}$$

$$\varepsilon_k = \frac{1}{2}m\overline{v^2} \text{ 为粒子的平均动能}，\quad p = \frac{2}{3}n\overline{\varepsilon_k} = nkT \Rightarrow \overline{\varepsilon_k} = \frac{3}{2}kT$$

### 分子的平均动能与理想气体系统的内能

只考虑分子平动动能，$U = \sum \varepsilon_{ki} = N\overline{\varepsilon_k} = \frac{3}{2}NkT = \frac{3}{2}\nu RT$。

定体热容 $C_V = \left(\frac{\partial U}{\partial T}\right)_V = \frac{3}{2}\nu R$，$C_{V,m} = \frac{3}{2}R$。

## 近独立粒子系的麦克斯韦-玻尔兹曼分布能量分布律

### 微观粒子基本运动状态的经典描述（能量、坐标、动量）

#### ① 自由平动粒子

在三维空间中运动时，粒子的自由度为 3，位置由 $x, y, z$ 标定，与之共轭的动量为 $P_x = m\dot{x}$，$P_y = m\dot{y}$，$P_z = m\dot{z}$，$\dot{x}$ 表示 $x$ 对时间的导数。

无外力作用时，$E = \frac{1}{2m}(P_x^2 + P_y^2 + P_z^2)$。粒子状态可由 $x, y, z, P_x, P_y, P_z$ 确定。

#### ② 线性谐振子

质量为 $m$ 的粒子在弹性力 $F = -Ax$ 作用下在平衡点附近作简谐运动，振动圆频率 $\omega = \sqrt{\frac{A}{m}}$。

$$E = \frac{P^2}{2m} + \frac{1}{2}Ax^2 = \frac{P^2}{2m} + \frac{1}{2}m\omega^2 x^2 = \frac{P^2}{2m} + \frac{1}{2}m\omega^2 x^2$$

以 $x, p$ 为直角坐标可构成二维 $\mu$ 空间，若 $E$ 给定，则代表点的轨迹是椭圆，椭圆面积 $= \pi \sqrt{\frac{2mE}{A}} = \pi \sqrt{\frac{2mE}{m\omega^2}}$，即 $S = \frac{2\pi E}{\omega}$。

$$T_{\text{转}} = \frac{1}{2}\mu r^2(\dot{\theta}^2 + \sin^2\theta\dot{\varphi}^2) = \frac{1}{2}I(\dot{\theta}^2 + \sin^2\theta\dot{\varphi}^2) = \frac{P_\theta^2}{2I} + \frac{P_\varphi^2}{2I\sin^2\theta}$$

$$T_{\text{总}} = \frac{1}{2}\mu r^2\dot{\theta}^2 + \frac{1}{2}\mu r^2\sin^2\theta\dot{\varphi}^2 = \frac{1}{2I}\left(P_\theta^2 + \frac{P_\varphi^2}{\sin^2\theta}\right)$$

# 宏观分布、组态、微观态

## M空间分割（宏观）

把 $\mu$ 空间分成许多小体元 $\Delta \omega_j$（$j=1,2,\dots,l$），大小适当，足够小到可近似认为代表点落在 $\Delta \omega_j$ 内的粒子运动状态相同，但也不是无穷小，要满足 $\Delta \omega_j \ge 10$（统计需要）。

## 宏观分布与宏观态（与 $\mu$ 空间的分布 $\{a_j\}$ 对应）

宏观状态参量是相应微观物理量的统计平均值。

知道了 $\Delta \omega_j$（$j=1,2,\dots,l$）体元内代表点的数目 $a_j$（$j=1,2,\dots,l$），即可确定系统的内能等宏观量的平均值，从而系统的宏观态也就确定了。

## 宏观分布的组态（配容）（哪些粒子的代表点在 $\Delta \omega_j$ 内）

经典力学中，粒子是可分辨的，交换两粒子的状态会改变系统的状态（微观）。

一个宏观分布 $\{a_j\}$ 对应的组态数 $W = \dfrac{N!}{\prod_j a_j!}$，即将 $N$ 个粒子按 $\{a_j\}$ 分布给 $l$ 个状态的可能数。

## 经典力学中一个组态的微观数（相字 $\Delta \omega_j$ → 相格 $h_0^r$，过渡到微观）

粒子的状态是连续的，粒子和系统的微观运动状态不可数 → 人为划出最小的"格子"。

将 $p_i, q_i$ 分为等间隔区域，$\delta p_i \delta q_i = h_0 \Rightarrow (\delta q_1 \delta p_1)\dots(\delta q_r \delta p_r) = h_0^r$，相格 $h_0^r$ 代表一个粒子态。

子相字空间小体元 $\Delta \omega_j$（$j=1,2,\dots,l$）中粒子运动状态数为 $\Delta \omega_j = \dfrac{\Delta \omega_j}{h_0^r}$，$a_j$ 个粒子在 $\Delta \omega_j$ 个运动状态上分布的可能微观状态数为 $\binom{\Delta \omega_j + a_j - 1}{a_j}$，多个粒子可以处于同一相格内。

## 一个分布的微观分布数

$$W = \prod_j \binom{\Delta \omega_j + a_j - 1}{a_j} = \prod_j \frac{(\Delta \omega_j + a_j - 1)!}{a_j!(\Delta \omega_j - 1)!}$$

# 等概率原理和最概然统计

若系统的各微观态无更多限制，就假定一切符合所有约束条件的微观态出现的概率相等。

**最概然统计**：认为出现概率最大（即微观态数最多）的那个宏观态分布对应于系统的平衡态。

## 最概然分布求算

一个宏观态分布 $\{a_i\}$ 出现的微观态数为 $\Omega$，则 $\Omega$ 最大也即 $\ln\Omega$ 最大，$\delta(\ln\Omega)=0$（即 $d(\ln\Omega)=0$）。

$$\Omega = \frac{N!}{\prod_i a_i!} \prod_i (\omega_i)^{a_i}, \quad \ln\Omega = \ln N! - \sum_i \ln a_i! + \sum_i a_i \ln(\omega_i)$$

$$\delta(\ln\Omega) = \delta(\ln N!) - \sum_i \delta(\ln a_i!) + \sum_i \ln(\omega_i) \delta a_i = \sum_i [-\ln a_i + \ln(\omega_i)] \delta a_i = 0$$

由斯特林公式，$N$ 足够大时，有 $\ln N! \approx N\ln N - N$。

则

$$\delta(\ln\Omega) = \sum_i (\ln a_i \delta a_i + \delta a_i - \delta a_i) - \sum_i \ln(\omega_i) \delta a_i = \sum_i (\ln a_i - \ln \omega_i) \delta a_i = 0$$

又有粒子数和能量守恒条件（孤立系），则 $\sum_i \delta a_i = 0$，$\sum_i \varepsilon_i \delta a_i = 0$。

令

$$f(a_1, a_2, \dots, a_c, \alpha, \beta) = \sum_i a_i(\ln a_i - 1) - \sum_i \ln(\omega_i) a_i + \alpha\left(\sum_i a_i - N\right) + \beta\left(\sum_i \varepsilon_i a_i - E\right)$$

则 $f$ 取极值时，$\frac{\partial f}{\partial a_i} = 0$，$\frac{\partial f}{\partial \alpha} = \frac{\partial f}{\partial \beta} = 0$。

$$\ln a_i + \alpha + \beta \varepsilon_i = 0$$

$$a_i = \omega_i e^{-\alpha - \beta \varepsilon_i}$$

且此时 $f$ 取极大值。

$\beta = -\frac{1}{kT}$，是一个普遍量，$a_i = \omega_i e^{-\alpha - \beta \varepsilon_i}$。

由 $\sum_i a_i = N$，则 $e^{-\alpha} \sum_i \omega_i e^{-\beta \varepsilon_i} = N$。引入配分函数 $Z = \sum_i \omega_i e^{-\beta \varepsilon_i}$，则 $e^{-\alpha} = \frac{N}{Z}$。

# 狄拉克符号

**右矢与左矢**：$|4\rangle$：右矢；$\langle 4|$：左矢，称 $|4\rangle$ 或 $\langle 4|$ 为态矢，$4$ 是一个标签，用于区分不同的量子态。

$\langle 4| = (|4\rangle)^\dagger$，左矢与右矢是一种共轭转置关系。$\langle a\psi| = a^*\langle \psi|$（$a$ 为复数）。

**内积**：$(\phi, \psi) = \langle \phi|\psi\rangle$，坐标表象下 $\langle \phi|\psi\rangle = \int \phi^*(\mathbf{r}) \psi(\mathbf{r}) \, dt$，$dt = dxdydz$ 为微体积元，$\psi(\mathbf{r}) = \psi(x,y,z)$。

$\langle \phi|\psi\rangle^* = \langle \psi|\phi\rangle$，用定积分理解是共轭，用矩阵理解是转置后取共轭。

**正交**：$\langle \phi|\psi\rangle = 0$ 代表 $\phi$ 和 $\psi$ 是正交的；**归一**：$\langle \psi|\psi\rangle = 1$ 代表 $\psi$ 是归一化的。

**平均值**：力学量 $A$ 在归一化量子态 $\psi$ 下的平均值 $\bar{A} = \langle \psi|A|\psi\rangle$。

$|\psi\rangle$ 与 $\langle \psi|$ 是量子态 $\psi$ 在右矢、左矢空间的不同表示。

## 左、右矢空间的算符运算

设 $A$ 和 $B$ 是两个算符，$|\phi\rangle$ 和 $|\psi\rangle$，若 $\langle \phi|A|\psi\rangle = \langle \phi|B|\psi\rangle$，则称 $B$ 为 $A$ 的转置算符。

$B = A^T$，在右矢空间中，$|\psi'\rangle = A|\psi\rangle = |A\psi\rangle$，默认 $A$ 向右作用；在左矢空间中，$\langle \psi'| = \langle \psi|A^\dagger$，算符 $A^\dagger$（$A^*$）向左作用。$\langle \psi|A^T = \langle A\psi| = \langle \psi|$。若 $A$ 为厄米算符，则 $\langle \psi'| = \langle \psi|A$。

→ **厄米算符在左、右矢空间中的运算具有形式不变性**。

算符在左矢和右矢之间的转换本质上是对偶空间的伴随映射。

- 关于 $(\langle \phi|A|\psi\rangle)^* = \langle \psi|A^\dagger|\phi\rangle$：$A = \langle \phi|A|\psi\rangle$，$A^\dagger = \langle \psi|A^\dagger|\phi\rangle$，$A^* = \langle \phi|A|\psi\rangle^* = \langle A\phi|\psi\rangle \Rightarrow \langle A\phi| = \langle \phi|A^\dagger$。
- $\langle \phi|AB|\psi\rangle = \langle \phi|B^\dagger A^\dagger|\psi\rangle$（先将 $B|\psi\rangle$ 视为一体，再作变换）。

## 角动量的对易式

设角动量算符 $\hat{L} = \hat{r} \times \hat{p}$，即：

$$\hat{L}_x = y\hat{p}_z - z\hat{p}_y,\quad \hat{L}_y = z\hat{p}_x - x\hat{p}_z,\quad \hat{L}_z = x\hat{p}_y - y\hat{p}_x$$

### 角动量分量之间的对易关系

$$\left[\hat{L}_x, \hat{L}_y\right] = \left[y\hat{p}_z - z\hat{p}_y,\ y\hat{p}_z - z\hat{p}_y\right] = -\left[z\hat{p}_y,\ y\hat{p}_z\right] = i\hbar \hat{L}_z$$

$$\left[\hat{L}_y, \hat{L}_z\right] = \left[z\hat{p}_x - x\hat{p}_z,\ z\hat{p}_x - x\hat{p}_z\right] = \left[y\hat{p}_z,\ z\hat{p}_x\right] = i\hbar \hat{L}_x$$

$$\left[\hat{L}_z, \hat{L}_x\right] = \left[x\hat{p}_y - y\hat{p}_x,\ x\hat{p}_y - y\hat{p}_x\right] = \left[y\hat{p}_x,\ x\hat{p}_y\right] = i\hbar \hat{L}_y$$

**注意：** 上述结果满足右手螺旋关系（循环对称性）。

### 角动量与坐标的对易关系

$$\left[\hat{L}_x, x\right] = \left[y\hat{p}_z - z\hat{p}_y,\ x\right] = 0,\quad \left[\hat{L}_\alpha, x_\beta\right] = 0 \quad (\alpha = x, y, z)$$

$$\left[\hat{L}_x, y\right] = \left[y\hat{p}_z - z\hat{p}_y,\ y\right] = -\left[z\hat{p}_y,\ y\right] = i\hbar z$$

$$\left[\hat{L}_x, z\right] = \left[y\hat{p}_z - z\hat{p}_y,\ z\right] = \left[y\hat{p}_z,\ z\right] = -i\hbar y$$

同理有：

$$\left[\hat{L}_y, x\right] = -i\hbar z,\quad \left[\hat{L}_y, z\right] = i\hbar x,\quad \left[\hat{L}_z, x\right] = i\hbar y,\quad \left[\hat{L}_z, y\right] = -i\hbar x$$

### 角动量与动量的对易关系

$$\left[\hat{L}_x, \hat{p}_x\right] = \left[y\hat{p}_z - z\hat{p}_y,\ \hat{p}_x\right] = 0,\quad \left[\hat{L}_\alpha, \hat{p}_\beta\right] = 0 \quad (\alpha = x, y, z)$$

$$\left[\hat{L}_x, \hat{p}_y\right] = \left[y\hat{p}_z - z\hat{p}_y,\ \hat{p}_y\right] = \left[y\hat{p}_z,\ \hat{p}_y\right] = i\hbar \hat{p}_z$$

$$\left[\hat{L}_x, \hat{p}_z\right] = \left[y\hat{p}_z - z\hat{p}_y,\ \hat{p}_z\right] = -\left[z\hat{p}_y,\ \hat{p}_z\right] = -i\hbar \hat{p}_y$$

同理有：

$$\left[\hat{L}_y, \hat{p}_x\right] = -i\hbar \hat{p}_z,\quad \left[\hat{L}_y, \hat{p}_z\right] = i\hbar \hat{p}_x,\quad \left[\hat{L}_z, \hat{p}_x\right] = i\hbar \hat{p}_y,\quad \left[\hat{L}_z, \hat{p}_y\right] = -i\hbar \hat{p}_x$$

### 角动量平方算符的性质

$$\left[\hat{L}_x, \hat{L}_x\right] = 0,\quad \left[\hat{L}_\alpha, \hat{L}_\alpha\right] = 0 \quad (\alpha = x, y, z)$$

$$\left[\hat{L}_x, \hat{L}_y\right] = \left[y\hat{p}_z - z\hat{p}_y,\ z\hat{p}_x - x\hat{p}_z\right] = \left[y\hat{p}_z,\ z\hat{p}_x\right] - \left[y\hat{p}_z,\ x\hat{p}_z\right] - \left[z\hat{p}_y,\ z\hat{p}_x\right] + \left[z\hat{p}_y,\ x\hat{p}_z\right]$$

$$= \left[y\hat{p}_z,\ z\hat{p}_x\right] + \left[z\hat{p}_y,\ x\hat{p}_z\right] = y\left[\hat{p}_z,\ z\right]\hat{p}_x + x\left[z,\ \hat{p}_z\right]\hat{p}_y = -i\hbar (y\hat{p}_x) - x(-i\hbar \hat{p}_y) = i\hbar \hat{L}_z$$

同理，$\left[\hat{L}_y, \hat{L}_z\right] = i\hbar \hat{L}_x$，$\left[\hat{L}_z, \hat{L}_x\right] = i\hbar \hat{L}_y$。

令 $\hat{L}^2 = \hat{L}_x^2 + \hat{L}_y^2 + \hat{L}_z^2$，则：

$$\hat{L}^2 = (y^2 + z^2)\hat{p}_x^2 + (z^2 + x^2)\hat{p}_y^2 + (x^2 + y^2)\hat{p}_z^2 - (yz\hat{p}_y\hat{p}_z - i\hbar y\hat{p}_z) - (yz\hat{p}_z\hat{p}_y - i\hbar z\hat{p}_y) - (zx\hat{p}_z\hat{p}_x - i\hbar x\hat{p}_z)$$

$$- (zx\hat{p}_x\hat{p}_z - i\hbar z\hat{p}_x) - (xy\hat{p}_x\hat{p}_y - i\hbar x\hat{p}_y) - (xy\hat{p}_y\hat{p}_x - i\hbar y\hat{p}_x)$$

### 对易恒等式

$$\left[A, BC\right] = ABC - BCA = A(BC - CB) + ACB - BCA = A\left[B, C\right] + \left[A, C\right]B + CAB - BCA = A\left[B, C\right] + \left[A, C\right]B$$

**注意：** B 左移变边缘，可提公因式。

$$\left[A, BC\right] = (AB - BA)C + B(AC - CA) = \left[A, B\right]C + B\left[A, C\right]$$

$$\left[A, BC\right] = \left[A, B\right]C + B\left[A, C\right],\quad \left[AB, C\right] = A\left[B, C\right] + \left[A, C\right]B$$

### 角动量平方与分量的对易

$$\left[\hat{L}^2, \hat{L}_x\right] = \left[\hat{L}_y^2, \hat{L}_x\right] + \left[\hat{L}_z^2, \hat{L}_x\right] = \hat{L}_y\left[\hat{L}_y, \hat{L}_x\right] + \left[\hat{L}_y, \hat{L}_x\right]\hat{L}_y + \hat{L}_z\left[\hat{L}_z, \hat{L}_x\right] + \left[\hat{L}_z, \hat{L}_x\right]\hat{L}_z$$
