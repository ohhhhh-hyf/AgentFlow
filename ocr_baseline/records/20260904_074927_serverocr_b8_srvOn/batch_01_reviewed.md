## 气体的基本统计规律

### 气体的微观模型

$$PV = \nu RT = \frac{m}{M}RT = \frac{N}{N_A}RT$$

$$P = \frac{N}{V}kT = nkT$$

其中 $n$ 为单位体积内的粒子数。

标准状态下的气体分子数密度 $n_0 = 2.21 \times 10^{25} \text{ m}^{-3}$，表示每 $\text{m}^3$ 理想气体中的微观粒子数。

分子线度为 $d$，则 $d^3 \sim \frac{V}{N} = \frac{M}{\rho N_A}$，即 $d \sim \left(\frac{M}{\rho N_A}\right)^{1/3}$，即可不计分子本身的大小。

**理想气体的微观模型：**
① 可不计分子本身的大小；
② 除碰撞外，气体分子间及气体分子同器壁间的相互作用可忽略；
③ 分子在两次碰撞间做匀速直线运动。

**压强的微观模型：**
① 宏观上认为器壁受连续作用力；
② 热平衡时，假设分子和器壁的碰撞是弹性碰撞；
③ 分子混沌性假设：平衡态时，气体分子的热运动速度无择优方向。

第 $i$ 个分子与 $A_1$ 面碰撞，$y$、$z$ 分量不变，$x$ 方向速度分量由 $v_{xi} \to -v_{xi}$。

第 $i$ 个分子单位时间与 $A_1$ 面碰撞次数为 $\frac{v_{xi}}{2a}$，单位时间单位面积冲量即压强。

$$P = \frac{2mv_{xi}^2}{bc} \cdot \frac{1}{2a} = \frac{m v_{xi}^2}{abc} = \frac{m}{V}\sum_i v_{xi}^2$$

$$\overline{v_x^2} = \frac{1}{3}\overline{v^2}，\quad 则 \quad p = \frac{1}{3}nm\overline{v^2} = \frac{2}{3}n\overline{\varepsilon_k}$$

$$\overline{\varepsilon_k} = \frac{1}{2}m\overline{v^2} \text{ 为粒子的平均动能}，\quad p = \frac{2}{3}n\overline{\varepsilon_k} = nkT \Rightarrow \overline{\varepsilon_k} = \frac{3}{2}kT$$

### 分子的平均动能与理想气体系统的内能

只考虑分子平动动能，$U = \sum \overline{\varepsilon_k} = N\overline{\varepsilon_k} = \frac{3}{2}NkT = \frac{3}{2}\nu RT$。

定体热容 $C_V = \left(\frac{\partial U}{\partial T}\right)_V = \frac{3}{2}\nu R$，$C_{V,m} = \frac{3}{2}R$。

## 近独立粒子系的麦克斯韦-玻尔兹曼分布能量分布律

### 微观粒子基本运动状态的经典描述（能量、坐标、动量）

#### ① 自由平动粒子

在三维空间中运动时，粒子的自由度为 3，位置由 $x, y, z$ 标定，与之共轭的动量为 $P_x = m\dot{x}$，$P_y = m\dot{y}$，$P_z = m\dot{z}$，$\dot{x}$ 表示 $x$ 对时间的导数。

无外力作用时，$E = \frac{1}{2m}(P_x^2 + P_y^2 + P_z^2)$。粒子状态可由 $x, y, z, P_x, P_y, P_z$ 确定。

#### ② 线性谐振子

质量为 $m$ 的粒子在弹性力 $F = -Ax$ 作用下在平衡点附近作简谐运动，振动圆频率 $\omega = \sqrt{\frac{A}{m}}$。

$$E = \frac{P^2}{2m} + \frac{1}{2}Ax^2 = \frac{P^2}{2m} + \frac{1}{2}m\omega^2 x^2 = \text{常数}$$

以 $x, p$ 为直角坐标可构成二维 $\mu$ 空间，若 $E$ 给定，则代表点的轨迹是椭圆，椭圆面积 $= \pi \sqrt{\frac{2mE}{A}} = \frac{\pi}{\omega}\sqrt{\frac{2E}{m}}$，即 $S = \frac{E}{\nu}$（其中 $\nu = \frac{\omega}{2\pi}$）。

#### ③ 转子（双原子分子整体刚性转动）

考虑质量为 $m$ 的质点 $A$ 被具有一定长度的轻杆系于原点时所做运动（$r$ 一定）：

$$E = \frac{1}{2}m(\dot{x}^2 + \dot{y}^2 + \dot{z}^2)$$

其中 $x = r\sin\theta\cos\varphi$，$y = r\sin\theta\sin\varphi$，$z = r\cos\theta$。

$$E = \frac{1}{2}m(r^2\dot{\theta}^2 + r^2\sin^2\theta\dot{\varphi}^2) = \frac{1}{2}mr^2(\dot{\theta}^2 + \sin^2\theta\dot{\varphi}^2)$$

对于双原子分子，两质点绕系统质心转动可约化为质量 $M_\mu$ 的单体转动问题。$M_\mu = \frac{m_1 m_2}{m_1 + m_2}$。取质心为坐标原点，$m_1$ 原子距原点 $r_1$，$m_2$ 原子距原点 $r_2$：

$$r_1 = \frac{m_2}{m_1 + m_2}r, \quad r_2 = \frac{m_1}{m_1 + m_2}r$$

$$I_{\text{总}} = m_1 r_1^2 + m_2 r_2^2 = M_\mu r^2$$

系统转动能量：

$$T_{\text{转}} = \frac{1}{2}m_1 r_1^2(\dot{\theta}^2 + \sin^2\theta\dot{\varphi}^2) + \frac{1}{2}m_2 r_2^2(\dot{\theta}^2 + \sin^2\theta\dot{\varphi}^2)$$

即：

$$T_{\text{转}} = \frac{1}{2}M_\mu r^2(\dot{\theta}^2 + \sin^2\theta\dot{\varphi}^2) = \frac{1}{2}I(\dot{\theta}^2 + \sin^2\theta\dot{\varphi}^2) = \frac{P_\theta^2}{2I} + \frac{P_\varphi^2}{2I\sin^2\theta}$$

其中 $P_\theta = M_\mu r^2\dot{\theta} = P_{\theta_1} + P_{\theta_2}$，$P_\varphi = M_\mu r^2\sin^2\theta\dot{\varphi}$（与 $\theta$、$\varphi$ 共轭的动量）。

$$T_{\text{总}} = \frac{1}{2}M_\mu r^2\dot{\theta}^2 + \frac{1}{2}M_\mu r^2\sin^2\theta\dot{\varphi}^2 = \frac{1}{2I}\left(P_\theta^2 + \frac{P_\varphi^2}{\sin^2\theta}\right)$$

# 宏观分布、组态、微观态

## M空间分割（宏观）

把 $\mu$ 空间分成许多小体元 $\Delta \mu_j (j=1,2,\dots,l)$，大小适当，足够小到可近似认为代表点落在 $\Delta \mu_j$ 内的粒子运动状态相同，但也不是无穷小，要满足 $Q_j \ge 10$（统计需要）。

## 宏观分布与宏观态（与M空间的分布 $\{a_j\}$ 对应）

宏观状态参量是相应微观物理量的统计平均值。

知道了 $\Delta \mu_j (j=1,2,\dots,l)$ 体元内代表点的数目 $Q_j (j=1,2,\dots,l)$，即可确定系统的内能等宏观量的平均值，从而系统的宏观态也就确定了。

## 宏观分布的组态（配容）（哪些粒子的代表点在 $\Delta \mu_i$ 内）

经典力学中，粒子是可分辨的，交换两粒子的状态会改变系统的状态（微观）。

一个宏观分布 $\{a_j\}$ 对应的组态数 $W = \dfrac{N!}{\prod_j a_j!}$，即将 $N$ 个粒子按 $\{Q_j\}$ 分布给 $l$ 个状态的可能数。

## 经典力学中一个组态的微观数（相字 $\Delta \mu_j$ → 相格 $h_0^r$，过渡到微观）

粒子的状态是连续的，粒子和系统的微观运动状态不可数 → 人为划出最小的"格子"。

将 $p_i, q_i$ 分为等间隔区域，$\delta p_i \delta q_i = h_0 \Rightarrow (\delta q_1 \delta p_1)\dots(\delta q_r \delta p_r) = h_0^r$，相格 $h_0^r$ 代表一个粒子态。

子相字空间小体元 $\Delta \mu_j (j=1,2,\dots,l)$ 中粒子运动状态数为 $\Delta \omega_j = \dfrac{\Delta \mu_j}{h_0^r}$，$a_j$ 个粒子在 $\Delta \omega_j$ 个运动状态上分布的可能微观状态数为 $\binom{\Delta \omega_j + a_j - 1}{a_j}$，多个粒子可以处于同一相格内。

## 一个分布的微观分布数

$$W = \prod_j \binom{\Delta \omega_j + a_j - 1}{a_j} = \prod_j \frac{(\Delta \omega_j + a_j - 1)!}{a_j! (\Delta \omega_j - 1)!}$$

# 等概率原理和最概然统计

若系统的各微观态无更多限制，就假定一切符合所有约束条件的微观态出现的概率相等。

**最概然统计**：认为出现概率最大（即微观态数最多）的那个宏观态分布对应于系统的平衡态。

## 最概然分布求算

一个宏观态分布 $\{a_{ij}\}$ 出现的微观态数为 $\Omega$，则 $\Omega$ 最大也即 $\ln\Omega$ 最大，$\delta(\ln\Omega)=0$（即 $d(\ln\Omega)=0$）。

$$\Omega = \frac{N!}{\prod_j a_j!} \prod_j (\omega_j)^{a_j}, \quad \ln\Omega = \ln N! - \sum_j \ln a_j! + \sum_j a_j \ln(\omega_j)$$

$$\delta(\ln\Omega) = \delta\left[\ln N! - \sum_j \ln(a_j!) + \sum_j \ln(\omega_j) \cdot a_j\right] = \sum_j \left[-\delta\ln(a_j!) + \ln(\omega_j)\,\delta a_j\right] = 0$$

由斯特林公式，$N$ 足够大时，有 $\ln N! \approx N\ln N - N$。

则

$$\delta(\ln\Omega) = -\sum_j (\ln a_j + 1 - 1)\,\delta a_j + \sum_j \ln(\omega_j)\,\delta a_j = \sum_j (\ln a_j - \ln\omega_j)\,\delta a_j = 0$$

又有粒子数和能量守恒条件（孤立系），则 $\sum_j \delta a_j = 0$，$\sum_j \varepsilon_j \delta a_j = 0$。

令

$$f(a_1, a_2, \dots, a_c, \alpha, \beta) = -\sum_j a_j(\ln a_j - 1) - \sum_j \ln(\omega_j) a_j + \alpha\left(\sum_j a_j - N\right) + \beta\left(\sum_j \varepsilon_j a_j - E\right)$$

则 $f$ 取极值时，$\frac{\partial f}{\partial a_j} = 0$，$\frac{\partial f}{\partial \alpha} = \frac{\partial f}{\partial \beta} = 0$。即

$$-\ln a_j + \ln\omega_j + \alpha + \beta\varepsilon_j = 0$$

$$a_j = \omega_j e^{\alpha + \beta\varepsilon_j}$$

且此时 $f$ 取极大值。

$\beta = -\frac{1}{kT}$，是一个普遍量，$a_j = \omega_j e^{\alpha - \varepsilon_j/(kT)}$。

由 $\sum_j a_j = N$，则 $e^{\alpha}\sum_j \omega_j e^{-\varepsilon_j/(kT)} = N$。引入配分函数 $Z = \sum_j \omega_j e^{-\varepsilon_j/(kT)}$，则 $e^{\alpha} = \frac{N}{Z}$。

# 华中科技大学

## 算符

### 狄拉克符号

- $|4\rangle$：右矢；$\langle 4|$：左矢，称 $|4\rangle$ 或 $\langle 4|$ 为态矢，$4$ 是一个标签，用于区分不同的量子态
- $\langle 4| = (|4\rangle)^\dagger$，左矢与右矢是一种共轭转置关系。$\langle a\psi| = a^*\langle \psi|$（$a$ 为复数）
- 内积：$(\varphi, \psi) = \langle \varphi|\psi\rangle$，坐标表象 $\langle \varphi|\psi\rangle = \int \varphi^*(\mathbf{r}) \psi(\mathbf{r}) \, dt$，$dt = dxdydz$ 为微体积元，$\varphi(\mathbf{r}) = \varphi(x,y,z)$
- $\langle \varphi|\psi\rangle^* = \langle \psi|\varphi\rangle$，用定积分理解是共轭，用矩阵理解是转置后取共轭
- **正交**：$\langle \varphi|\psi\rangle = 0$ 代表 $\varphi$ 和 $\psi$ 是正交的；**归一**：$\langle \varphi|\varphi\rangle = 1$ 代表 $\varphi$ 是归一化的
- **平均值**：力学量 $A$ 在归一化量子态 $\psi$ 下的平均值 $\bar{A} = \langle \psi|A|\psi\rangle$
- $|\psi\rangle$ 与 $\langle \psi|$ 是量子态 $\psi$ 在右矢、左矢空间的不同表示

### 左、右矢空间的算符运算

设 $A$ 和 $B$ 是两个算符，$|\varphi\rangle$ 和 $|\psi\rangle$，若 $\langle \varphi|A|\psi\rangle = \langle \varphi|B|\psi\rangle$，则称 $B$ 为 $A$ 的转置算符。

- $B = A^T$，在右矢空间中，$|\psi'\rangle = A|\psi\rangle = |A\psi\rangle$，默认 $A$ 向右作用；在左矢空间中，$\langle \psi'| = \langle \psi|A^\dagger$，算符 $A^\dagger$（$A^*$）向左作用。$\langle \psi|A^T = \langle A\psi| = \langle \psi|$。若 $A$ 为厄米算符，则 $\langle \psi'| = \langle \psi|A$
- → **厄米算符在左、右矢空间中的运算具有形式不变性**
- 算符在左矢和右矢之间的转换本质上是对偶空间的伴随映射
- 关于 $(A|\psi\rangle)^\dagger = \langle \psi|A^\dagger$：$A = \langle \psi|A|\psi\rangle$，$A^\dagger = \langle \psi|A^\dagger|\psi\rangle$，$A = \langle \psi|A|\psi\rangle^* = \langle A\psi|\psi\rangle \Rightarrow \langle A\psi| = \langle \psi|A^\dagger$
- $\langle AB\psi| = \langle \psi|B^\dagger A^\dagger$（先将 $B\psi$ 视为一体，再作变换）

### 基矢与本征方程

- $F|\psi\rangle = \lambda|\psi\rangle$，称 $|\psi\rangle$ 为算符 $F$ 的本征态，$\lambda$ 为本征值
- **能量本征方程**：$H|k\rangle = E_k|k\rangle$，将 $|\psi_k\rangle$ 简记为 $|k\rangle$（为基矢），量子数 $k$ 标记系统所有量子数

### 角动量的对易式

设角动量算符 $\hat{L} = \hat{r} \times \hat{p}$，即：

$$
\hat{L}_x = y\hat{p}_z - z\hat{p}_y,\quad
\hat{L}_y = z\hat{p}_x - x\hat{p}_z,\quad
\hat{L}_z = x\hat{p}_y - y\hat{p}_x
$$

**基本对易关系**（$x$ 与 $p$ 的正则对易关系 $[x, p_x] = i\hbar$，不同分量对易为零）：

$$
[\hat{L}_\alpha, \hat{x}_\beta] = i\hbar \varepsilon_{\alpha\beta\gamma} \hat{x}_\gamma,\quad
[\hat{L}_\alpha, \hat{p}_\beta] = i\hbar \varepsilon_{\alpha\beta\gamma} \hat{p}_\gamma
$$

具体展开：

- $[\hat{L}_x, \hat{x}] = [y\hat{p}_z - z\hat{p}_y, x] = 0$，同理 $[\hat{L}_\alpha, x] = 0$（$\alpha = x, y, z$）
- $[\hat{L}_x, \hat{y}] = [y\hat{p}_z, \hat{y}] - [z\hat{p}_y, \hat{y}] = -[z\hat{p}_y, \hat{y}] = i\hbar z$
- $[\hat{L}_x, \hat{z}] = [y\hat{p}_z, \hat{z}] - [z\hat{p}_y, \hat{z}] = [y\hat{p}_z, \hat{z}] = -i\hbar y$（或写为 $i\hbar(-y)$）

同理可得：

$$
[\hat{L}_y, \hat{x}] = -i\hbar z,\quad [\hat{L}_y, \hat{z}] = i\hbar x,\quad [\hat{L}_z, \hat{x}] = i\hbar y,\quad [\hat{L}_z, \hat{y}] = -i\hbar x
$$

**与动量分量的对易关系**：

- $[\hat{L}_x, \hat{p}_x] = [y\hat{p}_z - z\hat{p}_y, \hat{p}_x] = 0$，同理 $[\hat{L}_\alpha, \hat{p}_\alpha] = 0$（$\alpha = x, y, z$）
- $[\hat{L}_x, \hat{p}_y] = [y\hat{p}_z - z\hat{p}_y, \hat{p}_y] = [y\hat{p}_z, \hat{p}_y] = [y, \hat{p}_y]\hat{p}_z = i\hbar \hat{p}_z$
- $[\hat{L}_x, \hat{p}_z] = [y\hat{p}_z - z\hat{p}_y, \hat{p}_z] = -[z\hat{p}_y, \hat{p}_z] = -[z, \hat{p}_z]\hat{p}_y = -i\hbar \hat{p}_y$

同理可得：

$$
[\hat{L}_y, \hat{p}_x] = -i\hbar \hat{p}_z,\quad [\hat{L}_y, \hat{p}_z] = i\hbar \hat{p}_x,\quad [\hat{L}_z, \hat{p}_x] = i\hbar \hat{p}_y,\quad [\hat{L}_z, \hat{p}_y] = -i\hbar \hat{p}_x
$$

**角动量分量之间的对易关系**：

$$
[\hat{L}_x, \hat{L}_x] = 0,\quad [\hat{L}_\alpha, \hat{L}_\alpha] = 0 \quad (\alpha = x, y, z)
$$

计算 $[\hat{L}_x, \hat{L}_y]$：

$$
[\hat{L}_x, \hat{L}_y] = [y\hat{p}_z - z\hat{p}_y,\ z\hat{p}_x - x\hat{p}_z]
$$

展开：

$$
= [y\hat{p}_z, z\hat{p}_x] - [y\hat{p}_z, x\hat{p}_z] - [z\hat{p}_y, z\hat{p}_x] + [z\hat{p}_y, x\hat{p}_z]
$$
