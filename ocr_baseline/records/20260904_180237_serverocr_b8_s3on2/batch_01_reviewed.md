# 气体的基本统计规律

## 气体的微观模型

理想气体状态方程：$PV = \nu RT = \frac{m}{M}RT = NkT$，其中 $n$ 为单位体积内的粒子数。

标准状态下的气体分子数密度 $n_0 = 2.2 \times 10^{25} \, \text{m}^{-3}$，表示每 $\text{m}^3$ 理想气体中的微观粒子数。

分子线度为 $d$，则 $d^3 \cdot \frac{P}{kT} = \frac{M}{\rho N_A}$，即可不计分子本身的大小。

**理想气体的微观模型**：
1. 可不计分子本身的大小
2. 除碰撞外，气体分子间及气体分子同器壁间的相互作用可忽略
3. 分子在两次碰撞间做匀速直线运动

**压强的微观模型**：
1. 宏观上认为器壁受连续作用力
2. 热平衡时，假设分子和器壁的碰撞是弹性碰撞
3. 分子混沌性假设：平衡态时，气体分子的热运动速度无择优方向

第 $i$ 个分子与 $A_1$ 碰撞，$y$、$z$ 分量不变，$x$ 方向速度分量由 $v_{xi} \to -v_{xi}$。第 $i$ 个分子单位时间与 $A_1$ 碰撞次数为 $\frac{v_{xi}}{2a}$，单位时间单位面积冲量即压强：

$$P = \frac{2mv_{xi}^2}{bc} = \frac{m}{abc}\sum v_{xi}^2 = \frac{1}{3}nm\overline{v^2} = \frac{2}{3}n\overline{\varepsilon_k}$$

其中 $\overline{\varepsilon_k} = \frac{1}{2}m\overline{v^2}$ 为粒子的平均平动动能。

$$p = \frac{2}{3}n\overline{\varepsilon_k} = nkT \Rightarrow \overline{\varepsilon_k} = \frac{3}{2}kT$$

## 分子的平均动能与理想气体系统的内能

只考虑分子平动动能：

$$U = \sum \overline{\varepsilon_{ki}} = N\overline{\varepsilon_k} = \frac{3}{2}NkT = \frac{3}{2}\nu RT$$

定体热容：

$$C_V = \left(\frac{\partial U}{\partial T}\right)_V = \frac{3}{2}\nu R, \quad C_{V,m} = \frac{3}{2}R$$

## 宏观分布、组、态、微观态

### M空间分割（宏观）

把 $\mu$ 空间分成许多小体元 $\Delta \omega_j (j=1,2,\dots,l)$，大小适当，足够小到可近似认为代表点落在 $\Delta \omega_j$ 内的粒子运动状态相同，但也不是无穷小，要满足 $\omega_j \ge 10$（统计需要）。

### 宏观分布与宏观态

（与 $\mu$ 空间的分布 $\{a_j\}$ 对应）宏观状态参量是相应微观物理量的统计平均值。知道了 $\Delta \omega_j (j=1,2,\dots,l)$ 体元内代表点的数目 $a_j (j=1,2,\dots,l)$，即可确定系统的内能等宏观量的平均值，从而系统的宏观态也就确定了。

### 宏观分布的组态（配容）

（哪些粒子的代表点在 $\Delta \omega_j$ 内）经典力学中，粒子是可分辨的，交换两粒子的状态会改变系统的状态（微观）。一个宏观分布 $\{a_j\}$ 对应的组态数 $W = \dfrac{N!}{\prod_j a_j!}$，即将 $N$ 个粒子按 $\{a_j\}$ 分布给 $l$ 个状态的可能数。

### 经典力学中一个组态的微观数

（相字 $\Delta \omega_j \to$ 相格 $h_0^r$，过渡到微观）粒子的状态是连续的，粒子和系统的微观运动状态不可数 $\Rightarrow$ 人为划出最小的"格子"。将 $p_i, q_i$ 分为等间隔区域，$\delta p_i \delta q_i = h_0 \Rightarrow (\delta q_1 \delta p_1)\dots(\delta q_r \delta p_r) = h_0^r$，相格 $h_0^r$ 代表一个粒子态。子相字空间小体元 $\Delta \omega_j (j=1,2,\dots,l)$ 中粒子运动状态数为 $\Delta \omega_j = \dfrac{\Delta \omega_j}{h_0^r}$，$a_j$ 个粒子在 $\Delta \omega_j$ 个运动状态上分布的可能微观状态数为 $\binom{\Delta \omega_j + a_j - 1}{a_j}$，多个粒子可以处于同一相格内。

### 一个分布的微观分布数

$$W = \prod_j \binom{\Delta \omega_j + a_j - 1}{a_j} = \prod_j \frac{(\Delta \omega_j + a_j - 1)!}{a_j! (\Delta \omega_j - 1)!} \tag{7}$$

## 等概率原理和最概然统计

若系统的各微观态无更多限制，就假定一切符合所有约束条件的微观态出现的概率相等。**最概然统计**：认为出现概率最大（即微观态数最多）的那个宏观态分布对应于系统的平衡态。

## 最概然分布求算

一个宏观态分布 $\{a_i\}$ 出现的微观态数为 $\Omega$，则 $\Omega$ 最大也即 $\ln\Omega$ 最大，$\delta(\ln\Omega)=0$（即 $d(\ln\Omega)=0$）。

$$\Omega = \frac{N!}{\prod_i a_i!}\prod_i \omega_i^{a_i}$$

$$\ln\Omega = \ln N! - \sum_i \ln a_i! + \sum_i a_i \ln(\omega_i)$$

$$\delta(\ln\Omega) = \delta\left[\ln N! - \sum_i \ln a_i! + \sum_i a_i \ln(\omega_i)\right] = \sum_i \left[\ln\left(\frac{\omega_i}{a_i}\right)\right]\delta a_i = 0$$

由斯特林公式，$N$ 足够大时，有 $\ln M! \approx M\ln M - M$。

则

$$\sum_i \delta(a_i\ln a_i - a_i) - \sum_i \ln(\omega_i)\delta a_i = \sum_i (\ln a_i\,\delta a_i + \delta a_i - \delta a_i) - \sum_i \ln(\omega_i)\delta a_i = \sum_i (\ln a_i - \ln\omega_i)\delta a_i = 0$$

又有粒子数和能量守恒条件（孤立系），则 $\sum_i \delta a_i = 0$，$\sum_i \varepsilon_i \delta a_i = 0$。

令

$$f(a_1, a_2, \dots, a_c, \alpha, \beta) = -\sum_i a_i(\ln a_i - 1) - \sum_i \ln(\omega_i/a_i)a_i + \alpha\left(\sum_i a_i - N\right) + \beta\left(\sum_i \varepsilon_i a_i - E\right)$$

则 $f$ 取极值时，$\frac{\partial f}{\partial a_i} = 0$，$\frac{\partial f}{\partial \alpha} = \frac{\partial f}{\partial \beta} = 0$。

$$\ln a_i + \alpha + \beta\varepsilon_i = 0 \Rightarrow a_i = \omega_i e^{-\alpha - \beta\varepsilon_i}$$

且此时 $f$ 取极大值。$\beta = -\frac{1}{kT}$，是一个普遍量，$a_i = \omega_i e^{-\alpha - \beta\varepsilon_i}$。

由 $\sum_i a_i = N$，则 $e^{-\alpha}\sum_i \omega_i e^{-\beta\varepsilon_i} = N$。引入配分函数 $Z = \sum_i \omega_i e^{-\beta\varepsilon_i}$，则 $e^{-\alpha} = \frac{N}{Z}$。

## MB分布的物理意义

**MB分布是出现概率最大的一种分布**，别的分布出现的概率可忽略。MB分布给出了系统处于平衡态时同一时刻系统内粒子取某一能量值的概率。

## 角动量的对易式

设 $L = x \times p$，即 $L_x = y p_z - z p_y$，$L_y = z p_x - x p_z$，$L_z = x p_y - y p_x$。

计算各分量间的对易关系：

$$L_x = y p_z - z p_y$$

$$L_y = z p_x - x p_z$$

$$L_z = x p_y - y p_x$$

**基本对易关系：**

$$[L_x, x] = [y p_z - z p_y, x] = 0$$

$$[L_\alpha, x] = 0 \quad (\alpha = x, y, z)$$

$$[L_x, y] = [y p_z, y] - [z p_y, y] = -[z p_y, y] = i\hbar z$$

**x 右手螺旋关系：**

$$[L_x, z] = [y p_z - z p_y, z] = [y p_z, z] = -i\hbar y$$

同理有：

$$[L_y, x] = -i\hbar z, \quad [L_y, z] = i\hbar x$$

$$[L_z, x] = i\hbar y, \quad [L_z, y] = -i\hbar x$$

**与动量分量的对易关系：**

$$[L_x, p_x] = [y p_z - z p_y, p_x] = 0$$

$$[L_\alpha, p_\alpha] = 0 \quad (\alpha = x, y, z)$$

$$[L_x, p_y] = [y p_z - z p_y, p_y] = [y p_z, p_y] = i\hbar p_z$$

$$[L_x, p_z] = [y p_z - z p_y, p_z] = -[z p_y, p_z] = -i\hbar p_y$$

同理有：

$$[L_y, p_z] = i\hbar p_x, \quad [L_y, p_x] = -i\hbar p_z$$

$$[L_z, p_x] = i\hbar p_y, \quad [L_z, p_y] = -i\hbar p_x$$

**角动量分量之间的对易式：**

$$[L_x, L_x] = 0, \quad [L_\alpha, L_\alpha] = 0 \quad (\alpha = x, y, z)$$

$$[L_x, L_y] = [y p_z - z p_y, z p_x - x p_z]$$

$$= [y p_z, z p_x] - [y p_z, x p_z] - [z p_y, z p_x] + [z p_y, x p_z]$$

$$= [y p_z, z p_x] + [z p_y, x p_z]$$

$$= y[p_z, z]p_x + x[z, p_z]p_y$$

$$= -i\hbar y p_x + i\hbar x p_y = i\hbar L_z$$

同理可得：

$$[L_y, L_z] = i\hbar L_x, \quad [L_z, L_x] = i\hbar L_y$$

**角动量平方算符：**

令 $L^2 = L_x^2 + L_y^2 + L_z^2$，则：

$$L^2 = (y p_z - z p_y)^2 + (z p_x - x p_z)^2 + (x p_y - y p_x)^2$$

**恒等式：**

$$[A, BC] = ABC - BCA = A(BC - CB) + ACB - BCA = A[B, C] + [A, C]B$$

**B 左移变边缘，可提公因式：**

$$[A, BC] = (AB - BA)C + B(AC - CA) = [A, B]C + B[A, C]$$

$$[AB, C] = A[B, C] + [A, C]B$$

**角动量平方与分量的对易：**

$$[L^2, L_z] = [L_x^2 + L_y^2 + L_z^2, L_z] = [L_x^2, L_z] + [L_y^2, L_z]$$

$$= L_x[L_x, L_z] + [L_x, L_z]L_x + L_y[L_y, L_z] + [L_y, L_z]L_y$$

$$= L_x(-i\hbar L_y) + (-i\hbar L_y)L_x + L_y(i\hbar L_x) + (i\hbar L_x)L_y = 0$$

同理可得：

$$[L^2, L_x] = [L^2, L_y] = 0$$
