# calendar：企业级待办截止时间（DDL）智能转换引擎

针对会议与待办场景打造的**企业级、高精度、毫秒级响应**的自然语言截止时间转换器。

基于 **LangGraph 工业级混合双通道架构**：

```text
                    ┌─── [L1 极速规则引擎] (覆盖 85%+ 高频表达，0 网络耗时，<1ms) ──┐
输入待办 ──> 路由决策 ──┤                                                           ├──> [确定性日历工具] ──> 标准化输出
                    └─── [L2 DeepSeek LLM] (复杂长句/意向推理/消歧走大模型) ───────┘
```

---

## 核心设计特性

1. **工业级双通道加速（Hybrid Fast-Path）**：
   - **L1 极速规则引擎**：对“明天”、“下周三”、“本周末”、“3个工作日后”、“本月底”、“Q3末”、“今年年底”、“会后1小时”等 85%+ 常见表达实现本地纯内存解析，**耗时 < 1ms，0 Token 成本，完全离线可用**。
   - **L2 LLM 深度语义通道**：当遇到规则未覆盖的复杂长句、模糊多意向（如“这周五或者最迟下周一”）、指代消解或事件依赖时，精准分流至 DeepSeek 模型。
2. **全周期业务节点深度支持**：
   - **周末**（本周末、下周末）自动识别对齐至周日；
   - **季度**（Q1~Q4末、本季度末、下季度末/初）自动计算季度天数；已过去的季度自动智能顺延至下一年；
   - **年度**（今年年底、明年末、明年初）自动锚定 12/31 与 01/01 并支持跨年；
   - **工作日**（3个工作日内/后）自动跳过周末。
3. **时段语义解耦（拒绝伪精准）**：
   - 模糊时段（如“明天下午”）输出纯公历日期 `"2026/10/30"` 并附带标准中文时段标签 `"time_slot": "下午"`，不凭空捏造虚假的 `15:00`；
   - 钟点任务（如“下午3点半”）精确输出 `"2026/10/30 15:30"`（kind 为 datetime）。
4. **异常强隔离**：
   - 批处理中单条解析失败转为结构化 `error` 并输出 `deadline: null`，绝不崩溃整批处理。

## 1. 配置 API Key（可选）

如果全部输入均由 Fast-Path 规则命中，**无需配置 Key 即可离线运行**。若需使用 LLM 处理复杂非标语义，请在 `calendar/config.py` 填写：

```python
DEEPSEEK_API_KEY = "sk-..."
```

或使用环境变量覆盖：
```bash
export DEEPSEEK_API_KEY=sk-...
```

## 2. 运行与使用

```bash
python calendar/cli.py \
  --meeting-time "2026-10-29 14:30:45" \
  --input calendar/examples/input.json
```

支持管道输入：
```bash
cat calendar/examples/input.json | python calendar/cli.py \
  --meeting-time "2026-10-29 14:30:45" \
  --input -
```

## 3. 标准时段输出列表 (time_slot)

| time_slot 输出 | 对应输入口语 | 业务说明 |
| :--- | :--- | :--- |
| **`"上午"`** | 早上、上午、明早、一早 | 纯日期任务，附带上午标签 |
| **`"中午"`** | 中午、午休前 | 纯日期任务，附带中午标签 |
| **`"下午"`** | 下午、下半天 | 纯日期任务，附带下午标签 |
| **`"晚上"`** | 晚上、今晚、明晚 | 纯日期任务，附带晚上标签 |
| **`"下班前"`** | 下班前、下班时、傍晚、EOD | 纯日期任务，附带下班前标签 |
| **`null`** | 明天、10月1号、或 15:30 具体钟点 | 无时段偏好或已有精确时间点 |

## 4. 全周期时间规则支持

| 规则大类 | 典型口语表述 | 计算逻辑 |
| :--- | :--- | :--- |
| **周末识别** | 本周末 / 下周末 / 这周末下班前 | 统一锚定至周日（`target_weekday=7`） |
| **年度节点** | 年底 / 今年年底 / 明年末 / 明年初 | 自动锚定为 `12/31` 或 `01/01`，支持自动跨年 |
| **季度节点** | Q1~Q4末 / 二季度末 / 本季度末 / 下季度初 | 自动识别目标季度月末（3/31, 6/30, 9/30, 12/31），已过季度自动顺延下一年 |
| **工作日计算** | 3个工作日后 / 2个工作日内 | **自动跳过周六周日** |
| **基础自然日** | 明天 / 后天 / 大后天 / 昨天 / 5天后 | 相对 `meeting_start_time` 绝对天数加减 |
| **周历对齐** | 下周三 / 本周五 / 周五 / 大下周一 | 基于基准时间所在周进行锚定对齐 |
| **整周 / 整月** | 两周后 / 三周前 / 3个月后 | 绝对周/月偏移，自动处理月份月末边界 |
| **月初 / 月底** | 本月底 / 下月底 / 下月初 / 本月初 | 自动计算 28/29/30/31 天及大小月 |
| **固定公历** | 10月1号 / 15号 | 自动匹配当年或下一次出现（闰年2/29自动顺延） |
| **会前会后** | 会后1小时 / 会前15分钟 / 会后半小时 | 以会议具体时间点为基准进行分钟级加减 |
| **午夜跨日** | 晚上12点 / 24点 / 零点 | **自动进位至次日 00:00** |
| **无时间表达** | 尽快 / 待定 / 暂无 / 没提时间 | 识别为 `none`，输出 `null`，严禁猜测脑补 |
