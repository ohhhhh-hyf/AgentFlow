高等数学期末划重点（最后一课课堂录音整理）

同学们，最后这节课我把期末考试的范围和重点跟大家交代清楚，大家对照自己的笔记好好复习。

先说说整体结构。咱们第一章极限是考试的重中之重，占到大约三成左右的分数，而且后面的导数、积分都要用它，所以这一章必须吃透。其他章节虽然也有分，但极限要是没学好，后面全是空中楼阁。

一、必考内容（一定出大题，务必掌握）

第一个必考的是两个重要极限，这个每届必出，而且是拉开分差的地方。第一个重要极限就是那个 sin x 比 x，当 x 趋近于零的时候极限等于一。考的时候一般不会直接给你 sin x 比 x，而是给你变形，比如 sin 3x 比 x，或者 sin 5x 比 sin 3x 这种，大家要会凑形。第二个重要极限是那个一加 n 分之一的 n 次方趋近于 e，这个也必考，要会凑"一加无穷小、指数取倒数"这个结构，比如一加 x 分之二的三 x 次方这种，答案都是 e 的多少次方。

第二个必考的是等价无穷小替换求极限。这一块我给九个常用的等价无穷小，大家必须背下来：sin x 等价于 x，tan x 等价于 x，一减 cos x 等价于二分之 x 平方，ln 一加 x 等价于 x，e 的 x 次方减一等价于 x，这些一定要滚瓜烂熟。注意我强调过的，替换只能在乘除里面用，加减法里面不能乱换，那个 tan x 减 sin x 比 x 三次方的题，很多同学直接换就错了，一定要先提公因子。

第三个必考的是极限计算的一般方法，0 比 0 型、无穷比无穷型都会出计算题。0 比 0 型的套路是约因子、有理化、等价替换；无穷比无穷型就是抓大头，分子分母同除以最高次项。这个没什么技巧，就是多练。

第四个必考的是间断点的分类。给你一个分段函数，让你判断在分段点处是第几类间断点，是可去还是跳跃，这种题几乎年年有。大家记住判断流程：先看左右极限，都存在就是第一类，相等是可去、不相等是跳跃；有一个不存在就是第二类。

二、重点内容（考到的概率很大）

重点一个是夹逼准则和单调有界准则，这个一般出在数列极限的题里。夹逼要注意放缩，两边极限要一致；单调有界要按三步走，先证有界再证单调最后设极限解方程。递推数列的题会用到，比如那个 x 一等于根号二，x 加一等于根号下二加 x 的题，大家一定要会。

重点二是连续性的概念和闭区间上连续函数的性质，特别是零点定理。证明方程在某个区间内有根，就用零点定理，先构造函数，再找两个端点函数值异号，直接下结论。如果要证唯一，再加一步单调性。这个证明题是每年必考的一个类型，大家一定要掌握书写规范。

重点三是无穷小与无穷大的概念辨析，特别是"无界"和"无穷大"的区别，那个 x 乘 sin x 的反例要记住，这个在选择题里出现过。

三、了解内容（有印象即可）

数列极限和函数极限的定义证明，就是那个 ε 语言和 ε-δ 语言，大家了解书写规范就行，一般不会让你现场证一个大题，但概念要清楚。海涅定理了解一下它的思想。连续函数的运算性质了解即可。

四、考法提示与复习建议

计算题一般五到六道，全是极限；选择填空里会有概念辨析，比如收敛和有界的关系、等价替换的适用范围；证明题就是零点定理和单调有界。大家复习的时候，把我说的必考四块每块做十道题，重点两块每块做五道，基本就稳了。错题一定要整理，考前把错题本过一遍，比盲目刷题效果好得多。

还有两天时间，大家把两个重要极限和九个等价无穷小默写一遍，保证拿分。好，就这些，下课。


—— 以下补充第二章·导数与微分的划重点（第二次整理，供两章一起复习）——

同学们，极限那章我跟大家交代完了，这一节把第二章导数与微分的重点也过一遍。这章在卷面上占两成多，而且导数本身就是极限的应用，前面极限学扎实了，这章主要就是套公式、练法则，是最好拿分的一章。

一、必考内容（一定出大题，务必掌握）

第一个必考的是复合函数求导，就是链式法则。外层求导再乘内层导数，复合几层乘几个因子。这个每届必考，而且丢分最多的就是"漏乘内层导数"——求完外层就停笔。大家记住检查办法：数一数复合了几层，就必须有几个因子。像 sin 3x 是 3 倍 cos 3x，sin 平方 3x 是 2 sin 3x cos 3x 再乘 3，这个变形一定要熟练。

第二个必考的是隐函数求导。给一个方程比如 x 平方加 y 平方等于 1，让你求 dy 比 dx，两边同时对 x 求导，遇到含 y 的项求完导数后面必须补乘一个 y 撇，然后解出 y 撇。这一步"补乘 y 撇"是每年必扣分的点，大家一定要盯住。参数方程求导也是这个考法，dy 比 dx 等于两个导数相除，注意别和 dy 比 dt 混了。

第三个必考的是导数的几何意义和切线方程。给你一个曲线和上面一个点，求切线方程，就是 y 减 y 零等于 f 撇 x 零乘 x 减 x 零，这个公式直接套。但要注意，题目如果只说"过某点的切线"，点不一定在曲线上，要先设切点解方程，这个坑很多人踩。

第四个必考的是利用导数研究函数：单调性、极值和最值。单调看导数正负，极值看驻点和不可导点，最值还要加区间端点。这个大题每年都有，一般结合求导法则一起考，比如求个带参数的函数最值。书写规范要完整：求导、列表、下结论三步不能少。

二、重点内容（考到的概率很大）

重点一个是微分及其近似计算。d y 等于 f 撇 x 乘 d x，这个定义要清楚；近似公式 f(x0 加 Δx) 约等于 f(x0) 加 f 撇 x0 乘 Δx，常用来求根号、指数、对数的近似值，比如根号 9.1 这种。这个在小题里出现概率很高，套路固定，选好基准点就能做。

重点二是高阶导数，特别是莱布尼茨公式。求两个函数乘积的高阶导，比如 x 平方乘 e 的 x 次方的 n 阶导，用莱布尼茨公式展开，组合数别漏。这个属于"会了就是送分题"的类型。

重点三是对数求导法，专门对付幂指函数，像 x 的 x 次方这种，底数和指数都在变，既不能用幂公式也不能用指数公式，必须先取对数再求导。这个在填空或选择里出现，识别题型是关键。

三、了解内容（有印象即可）

导数的定义证明，就是那个用定义求导的差商极限，了解书写规范就行；微分形式不变性知道一阶形式不变即可，不太会单独出大题。可导与连续的关系要记牢：可导必连续，连续不一定可导，y 等于 x 的绝对值在零处是经典反例，这个在判断题里出现过。

四、考法提示与复习建议

试卷结构上，第二章一般这样分布：切线方程一道（小题或大题第一问），求导计算两到三道（复合、隐函数、参数方程各一），单调性极值最值一道大题，微分近似一道小题，高阶导数可能夹在综合题里。复习的时候，把链式法则、隐函数、对数求导每类练五道题，导数应用大题做三道并对照标准书写格式，基本就稳了。

大家把基本求导公式表（幂、三角、指数、对数、反三角）默写一遍，再把易错点过一遍——漏乘内层导、隐函数漏 y 撇、商法则分子写反、dy 与 Δy 分不清，这四处盯住了，第二章的分就到手了。好，就这些。
