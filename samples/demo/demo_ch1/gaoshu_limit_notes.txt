高等数学·第一章 函数与极限·学习笔记（期末完整版）

本笔记系统覆盖极限一章全部核心内容：数列极限、函数极限、无穷小与无穷大、极限运算法则、极限存在准则、两个重要极限、无穷小阶的比较、函数连续性与间断点、闭区间上连续函数的性质，以及综合例题与易错点。每一节都按"概念定义 → 直观理解 → 性质定理 → 计算方法 → 例题详解 → 易错提醒"的顺序展开，力求自学可懂、复习可用。

一、数列极限

1.1 数列的基本概念
数列是按照自然数顺序排列的一列数，记作 x₁, x₂, x₃, …, xₙ, …，简记为 {xₙ}，其中第 n 项 xₙ 称为数列的通项。例如 xₙ = 1/n 对应数列 1, 1/2, 1/3, …, 而 xₙ = (−1)ⁿ 对应 −1, 1, −1, 1, …。数列本质上是定义域为正整数集的函数 xₙ = f(n)，因此研究数列与研究函数的方法可以互相借鉴。从直观上看，数列就是"一列排好队的数"，我们的任务是搞清楚这一列数"最终走向哪里"——这正是极限要回答的问题。

1.2 数列极限的直观定义与 ε-N 语言
直观定义：设 {xₙ} 是一个数列，a 是一个常数。如果当 n 无限增大时，xₙ 无限趋近于 a，就称数列 {xₙ} 以 a 为极限（或收敛于 a），记作 lim(n→∞) xₙ = a。例如数列 1, 1/2, 1/3, … 无限趋近 0，故 lim(n→∞) 1/n = 0。而数列 (−1)ⁿ 在 −1 与 1 之间来回跳动，不趋近任何数，故发散。

"无限趋近"是口语化的说法，数学上需要精确刻画，于是有了 ε-N 定义：如果存在常数 a，使得对任意给定的正数 ε，都存在正整数 N，当 n > N 时恒有 |xₙ − a| < ε，则称 a 是数列 {xₙ} 的极限。这里的 ε 代表"允许的误差"，无论 ε 给得多小（比如 10⁻¹⁰），我们总能找到一项 N，使得第 N 项以后的所有项都落在 a 的 ε 邻域 (a−ε, a+ε) 内。直观地说：数列尾巴上的所有点都被"挤进"了 a 附近任意小的区间。这个定义的关键是"任意 ε"和"存在 N"，顺序不能颠倒——先给误差，再找 N。

1.3 收敛数列的性质
唯一性：收敛数列的极限唯一。证明思路：若同时收敛于 a 和 b 且 a ≠ b，取 ε = |a−b|/2，则当 n 充分大时同时有 |xₙ−a| < ε 和 |xₙ−b| < ε，由三角不等式得 |a−b| ≤ |xₙ−a| + |xₙ−b| < 2ε = |a−b|，矛盾。
有界性：收敛数列必有界。证明思路：取 ε = 1，则存在 N 使 n > N 时 |xₙ| < |a| + 1，前面的有限项又显然有界，合并即得整体有界。注意有界是收敛的必要条件而非充分条件（(−1)ⁿ 有界但发散）。
保号性：若 lim xₙ = a > 0，则存在 N，当 n > N 时 xₙ > 0。这保证了极限符号与数列项的符号在"尾部"一致，是处理不等式问题的重要工具。
子列收敛性：若数列收敛于 a，则它的任何子列都收敛于 a。这个性质的逆否命题常用来证明数列发散：只要找到两个收敛于不同极限的子列，原数列必发散。例如 xₙ = (−1)ⁿ，奇子列收敛于 −1，偶子列收敛于 1，故发散。

1.4 数列极限的四则运算与两个准则
设 lim xₙ = a，lim yₙ = b，则：
（1）lim(xₙ ± yₙ) = a ± b；
（2）lim(xₙ·yₙ) = a·b；
（3）当 b ≠ 0 时，lim(xₙ/yₙ) = a/b。
注意运算法则要求"各自的极限都存在"，缺一不可。0/0、∞/∞、0·∞ 等形式不能直接套用，需要先变形。
夹逼准则：若从某项起 yₙ ≤ xₙ ≤ zₙ，且 lim yₙ = lim zₙ = a，则 lim xₙ = a。应用时关键是"放缩"——把要研究的数列夹在两个已知极限的数列之间。
单调有界准则：单调递增且有上界的数列必收敛；单调递减且有下界的数列必收敛。这个准则不告诉你极限是多少，但保证了收敛性，常用于递推数列：先证单调，再证有界，然后设极限为 A 代入递推式解方程。

1.5 常用数列极限与例题
常用结论：lim(1/n) = 0；lim qⁿ = 0（|q| < 1）；lim n^(1/n) = 1；lim (1 + 1/n)ⁿ = e。
例1 求 lim(n→∞) (3n² + 2n)/(2n² − 1)。解：分子分母同除以 n²，得 lim(3 + 2/n)/(2 − 1/n²) = 3/2。
例2 求 lim(n→∞) (√(n+1) − √n)。解：有理化得 1/(√(n+1) + √n)，分母趋于无穷大，故极限为 0。
例3 设 x₁ = 2，xₙ₊₁ = 1 + √(xₙ − 1)，证明 {xₙ} 收敛并求极限。解：先证有界（1 ≤ xₙ ≤ 2）与单调，收敛后设 lim xₙ = A，代入递推式得 A = 1 + √(A−1)，解得 A = 2。
例4 利用夹逼求 lim(n→∞) (1 + 2 + … + n)/n²。解：该式 = n(n+1)/(2n²) = (1 + 1/n)/2 → 1/2；也可以夹逼：n²/(2n²) ≤ 原式 ≤ (n+1)²/(2n²) 两侧均趋于 1/2。

二、函数极限

2.1 自变量趋于无穷大时的极限
设 f(x) 在 |x| 大于某正数时有定义。若 x 的绝对值无限增大时 f(x) 无限趋近 A，则记 lim(x→∞) f(x) = A。例如 lim(x→∞) 1/x = 0，lim(x→∞) arctan x = π/2。需要区分 x→+∞ 与 x→−∞ 两个方向：lim(x→∞) f(x) = A 当且仅当两个单侧无穷极限都等于 A。典型例子是 arctan x：x→+∞ 时趋于 π/2，x→−∞ 时趋于 −π/2，两者不等，故 lim(x→∞) arctan x 不存在。类似地，eˣ 在 x→+∞ 时趋于 +∞，在 x→−∞ 时趋于 0，所以 lim(x→∞) eˣ 不存在。

2.2 自变量趋于有限值时的极限
设 f(x) 在 x₀ 的某去心邻域内有定义。若 x 无限趋近 x₀（x ≠ x₀）时 f(x) 无限趋近 A，则记 lim(x→x₀) f(x) = A。注意"去心"二字：极限只看 x₀ 附近的变化趋势，与 f(x₀) 是否有定义、等于多少完全无关。这是函数极限与函数值最本质的区别，也是最常见的理解误区。
ε-δ 语言：对任意 ε > 0，存在 δ > 0，当 0 < |x − x₀| < δ 时，恒有 |f(x) − A| < ε，则称 A 是 f(x) 在 x₀ 处的极限。直观理解：只要 x 离 x₀ 足够近（距离小于 δ），f(x) 就离 A 足够近（误差小于 ε）。δ 一般依赖于 ε，ε 越小通常 δ 也越小。

2.3 左极限、右极限与极限存在的充要条件
若 x 从 x₀ 左侧（x < x₀）趋近时 f(x) 趋于 A，称 A 为左极限，记 lim(x→x₀⁻) f(x)；从右侧趋近记 lim(x→x₀⁺)。函数在 x₀ 处极限存在当且仅当左右极限都存在且相等。这个充要条件在处理分段函数、含绝对值、含符号函数的情形时是必经之路。
例1 讨论 f(x) = |x|/x 在 x = 0 处的极限。解：x→0⁻ 时 |x|/x = −1，x→0⁺ 时 = 1，左右极限不等，故 lim(x→0) |x|/x 不存在。
例2 讨论 f(x) = x·sin(1/x) 在 x = 0 处的极限。解：|x·sin(1/x)| ≤ |x| → 0，由夹逼（或有界×无穷小）知极限为 0。这里 f(0) 无定义，但极限存在且为 0，说明"极限存在"与"函数在该点有定义"是两回事。

2.4 函数极限的性质与海涅定理
函数极限有与数列平行的性质：唯一性、局部有界性、局部保号性、四则运算、夹逼准则。此外还有海涅定理（归结原则）：lim(x→x₀) f(x) = A 当且仅当对任意趋于 x₀ 的数列 {xₙ}（xₙ ≠ x₀），都有 lim f(xₙ) = A。海涅定理把函数极限与数列极限联系起来，常用来证明某个函数极限不存在：只要构造两个不同的趋于 x₀ 的数列，使 f(xₙ) 趋于不同值即可。例如证明 lim(x→0) sin(1/x) 不存在：取 xₙ = 1/(nπ) 得 sin(nπ) = 0，取 xₙ' = 1/(π/2 + 2nπ) 得 sin = 1，两个子列极限不同。

三、无穷小与无穷大

3.1 无穷小的定义与性质
如果函数 f(x) 在自变量的某一变化过程中以零为极限，就称 f(x) 是该过程中的无穷小。例如 x→0 时 x、sin x、1 − cos x 都是无穷小；x→∞ 时 1/x 是无穷小。
无穷小的三条性质必须熟练掌握：（1）有限个无穷小的代数和仍是无穷小；（2）有限个无穷小的乘积仍是无穷小；（3）有界函数与无穷小的乘积仍是无穷小。第三条用途极广，例如 lim(x→0) x²·sin(1/x) = 0，因为 x² → 0 而 sin(1/x) 有界。注意"有限个"的限制：无限个无穷小的和不一定无穷小（如 n 个 1/n 相加等于 1）。

3.2 无穷大的定义
若在自变量的某一变化过程中 |f(x)| 无限增大，则称 f(x) 为无穷大，记 lim f(x) = ∞。若 f(x) 只取正值（或负值）无限增大，记 +∞（或 −∞）。例如 x→0 时 1/x² → +∞；x→∞ 时 x³ → +∞。
无穷大与无界是两个不同的概念：无穷大必然无界，但无界不一定无穷大。经典反例是 f(x) = x·sin x 在 x→∞ 时：取 xₙ = 2nπ + π/2 得 f = 2nπ + π/2 → ∞，但取 xₙ = nπ 得 f = 0，说明它并非无限增大而是来回振荡，所以无界但不趋于无穷大。

3.3 无穷大与无穷小的关系
在同一变化过程中：若 f(x) 是无穷大，则 1/f(x) 是无穷小；若 f(x) 是无穷小且 f(x) ≠ 0，则 1/f(x) 是无穷大。这条关系把"无穷大"的计算转化为"无穷小"的计算，例如求 lim(x→1) 1/(x−1)²：x→1 时 x−1 是无穷小，平方后仍为无穷小，故 1/(x−1)² 是无穷大（+∞）。

四、极限运算法则

4.1 四则运算法则
如果 lim f(x) = A，lim g(x) = B，则：lim[f(x) ± g(x)] = A ± B；lim[f(x)·g(x)] = A·B；当 B ≠ 0 时 lim[f(x)/g(x)] = A/B。运算法则的前提是"两个极限都存在且分母极限非零"，违背前提直接套用会出错。
不能直接套用的"未定型"：0/0、∞/∞、0·∞、∞−∞、0⁰、∞⁰、1^∞。这些形式必须经过变形后才能用运算法则。处理原则：0/0 型约零因子或等价替换；∞/∞ 型抓大头；0·∞ 型转化为 0/0 或 ∞/∞；∞−∞ 型通分或有理化；1^∞ 型用第二个重要极限。

4.2 复合函数的极限（换元法）
设 u = φ(x)，若 lim(x→x₀) φ(x) = u₀ 且 lim(u→u₀) f(u) = A，在满足条件时 lim(x→x₀) f[φ(x)] = A。这个定理的实用价值在于：当内层函数的极限容易求时，先求出内层极限再代入外层。两个重要极限的许多变形都依赖此法。例如 lim(x→0) sin(x²)/x²：令 u = x²，则 u→0，原式 = lim(u→0) sin u/u = 1。

4.3 极限计算的常用技巧
（1）约去零因子：lim(x→1) (x²−1)/(x−1) = lim(x→1)(x+1) = 2。
（2）有理化：lim(x→0) (√(1+x) − 1)/x = lim(x→0) x/[x(√(1+x)+1)] = 1/2。
（3）抓大头（∞/∞ 型）：lim(x→∞) (3x³ + x)/(2x³ − 5) = 3/2。分子分母同除以最高次项。
（4）无穷小替换（0/0 型）：见第七节。
（5）分段点处理：先分左右，再合并判断。

五、极限存在准则

5.1 夹逼准则
函数形式：若在 x₀ 的某去心邻域内 g(x) ≤ f(x) ≤ h(x)，且 lim g(x) = lim h(x) = A，则 lim f(x) = A。数列形式同理。
夹逼准则的适用场景：被研究的量"卡"在两个容易求极限的量之间。典型例子：
例1 lim(x→0) x·sin(1/x) = 0：由 −|x| ≤ x·sin(1/x) ≤ |x| 夹逼。
例2 lim(n→∞) (1/√(n²+1) + 1/√(n²+2) + … + 1/√(n²+n))：分母换成 n²+1 和 n²+n 分别放缩，两侧极限都为 1。
放缩的原则：目标极限要一致；放缩不能太松（否则两边极限不同，夹不出结果）。

5.2 单调有界准则
单调递增有上界（或单调递减有下界）的数列必收敛。这是证明递推数列收敛的标准工具。完整步骤：① 证明单调性（常用数学归纳法或作差/作商）；② 证明有界性；③ 设极限为 A，对递推式两边取极限解出 A。注意第③步依赖连续函数，递推式中的表达式须连续。
例：x₁ = √2，xₙ₊₁ = √(2 + xₙ)。由归纳法知 0 < xₙ < 2，且 xₙ₊₁ − xₙ 同号可证递增，故收敛。设极限为 A，A = √(2 + A)，解得 A = 2。

六、两个重要极限

6.1 第一个重要极限：lim(x→0) sin x / x = 1
几何证明（单位圆）：在单位圆中，x 为圆心角（弧度），则 sin x < x < tan x（面积比较），除以 sin x 得 1 < x/sin x < 1/cos x，令 x→0 由夹逼得 x/sin x → 1，即 sin x/x → 1。
使用要点：分子分母是"同一个量"（都趋于零）。变形技巧：lim(x→0) sin kx / x = k；lim(x→0) sin kx / sin mx = k/m；lim(x→0) tan x / x = 1。
易错：lim(x→∞) sin x / x = 0（有界×无穷小），绝不能套用重要极限。判别方法：看趋于零的"量"是否同时出现在 sin 内和分母上。

6.2 第二个重要极限：lim(x→∞) (1 + 1/x)ˣ = e，或 lim(x→0) (1 + x)^(1/x) = e
e 是无理数，e ≈ 2.71828…。该极限刻画了"复利"、"连续增长"等自然现象。
使用要点：底数形如"1 + 无穷小量"，指数是"该无穷小量的倒数"。凑形方法：
例1 lim(x→∞) (1 + 2/x)ˣ = lim(x→∞) [(1 + 2/x)^(x/2)]² = e²。
例2 lim(x→∞) (1 − 1/x)ˣ = lim(x→∞) [(1 + 1/(−x))^(−x)]⁻¹ = e⁻¹。
例3 lim(x→0) (1 + sin x)^(1/x) = lim(x→0) [(1 + sin x)^(1/sin x)]^(sin x/x) = e¹ = e。
注意与 1^∞ 型未定式的关系：第二个重要极限就是 1^∞ 型的标准处理手段。

七、无穷小阶的比较与等价无穷小

7.1 阶的概念
设 α、β 是同一过程中的无穷小。若 lim β/α = 0，则 β 是比 α 高阶的无穷小（β 趋于 0 更快）；若 lim β/α = c ≠ 0，则 β 与 α 同阶；若 c = 1，则等价（记 α ~ β）；若 lim β/α = ∞，则 β 是比 α 低阶的无穷小。
意义：比较无穷小"趋于零的快慢"，用于判断主导项、简化计算。例如 x² 比 x 高阶，因为 x²/x = x → 0。

7.2 常用等价无穷小（x→0 时）
sin x ~ x；tan x ~ x；arcsin x ~ x；arctan x ~ x；1 − cos x ~ x²/2；ln(1+x) ~ x；eˣ − 1 ~ x；(1+x)^a − 1 ~ ax；aˣ − 1 ~ x·ln a。
记忆方法：它们都是"基本初等函数在 0 附近的主部"。例如 eˣ 在 0 处展开为 1 + x + …，故 eˣ − 1 ~ x。

7.3 等价无穷小替换的规则与禁忌
核心规则：**在乘除运算中，无穷小因子可用等价无穷小替换**，极限不变。理由：等价无穷小之比趋于 1，乘除中替换不改变极限。
禁忌：**加减法一般不能直接替换**，除非能证明替换后不出现"同阶抵消"。反例：lim(x→0) (tan x − sin x)/x³，若把 tan x 和 sin x 都换成 x，得 0/0 且分子为 0，得出错误结论 0；正确做法是 tan x − sin x = tan x(1 − cos x) ~ x·(x²/2) = x³/2，故极限为 1/2。这个例子是期末最经典的"陷阱题"，务必牢记"加减慎换"。

八、函数的连续性与间断点

8.1 连续的定义与等价条件
设 f(x) 在 x₀ 的某邻域内有定义，若 lim(x→x₀) f(x) = f(x₀)，则称 f 在 x₀ 处连续。等价定义：lim(Δx→0) [f(x₀+Δx) − f(x₀)] = 0，即自变量的微小变化引起函数值的微小变化。
连续的三条件（缺一不可）：① f(x₀) 有定义；② lim(x→x₀) f(x) 存在；③ 极限值等于函数值。分段函数分段点处的连续性判断必须同时验证这三条。若函数在区间内每一点都连续，则称在区间上连续。

8.2 左连续与右连续
f 在 x₀ 处连续 ⇔ f 在 x₀ 处既左连续又右连续。分段函数在分段点 x₀ 处：先分别求左、右极限，若都存在且都等于 f(x₀)，则连续。

8.3 间断点及其分类
第一类间断点：左右极限都存在。
可去间断点：左右极限存在且相等，但不等于 f(x₀)（或 f(x₀) 无定义）。例如 f(x) = sin x/x 在 x = 0 处无定义但左右极限都是 1，是可去间断点；可"补齐定义"使其连续。
跳跃间断点：左右极限存在但不相等。例如 f(x) = |x|/x 在 x = 0 处，左 −1 右 +1。
第二类间断点：左右极限至少有一个不存在。
无穷间断点：极限为无穷大，如 1/x 在 x = 0。
振荡间断点：如 sin(1/x) 在 x = 0 处左右极限不存在且函数值在 [−1,1] 间振荡。
判断流程：先看 f(x₀) 有无定义 → 求左右极限 → 按左右极限存在与否及是否相等分类。

九、连续函数的运算与闭区间性质

9.1 连续函数的四则与复合
连续函数的和、差、积、商（分母非零）连续；连续函数的复合连续；单调连续函数的反函数连续。据此，一切初等函数在其定义区间内连续——这是"代入法求极限"的理论依据：lim(x→x₀) f(x) = f(x₀)（f 为初等函数且在 x₀ 的定义区间内）。

9.2 闭区间上连续函数的三大定理
最值定理：f 在 [a,b] 连续 ⇒ f 在 [a,b] 上有最大值与最小值。
有界性定理：f 在 [a,b] 连续 ⇒ f 在 [a,b] 上有界。
介值定理：f 在 [a,b] 连续，且 f(a) ≠ f(b)，则对介于 f(a) 与 f(b) 之间的任何数 C，存在 ξ ∈ (a,b) 使 f(ξ) = C。
零点定理：f 在 [a,b] 连续且 f(a)·f(b) < 0 ⇒ 存在 ξ ∈ (a,b) 使 f(ξ) = 0。
零点定理的典型应用：
例 证明方程 x⁵ − 3x + 1 = 0 在 (0,1) 内至少有一个实根。解：令 f(x) = x⁵ − 3x + 1，f(0) = 1 > 0，f(1) = −1 < 0，f 在 [0,1] 连续，由零点定理存在 ξ ∈ (0,1) 使 f(ξ) = 0。
推广：要证方程在某区间有根，关键在于找到区间端点函数值异号；若端点同号，可考虑找区间内部两点异号，或利用连续函数的最大最小值。

十、综合例题、易错点与复习建议

10.1 综合例题
例1 求 lim(x→0) (1 − cos 2x)/(x sin x)。解：1 − cos 2x ~ (2x)²/2 = 2x²，sin x ~ x，原式 = lim 2x²/x² = 2。
例2 求 lim(x→∞) (√(x² + x) − x)。解：有理化得 x/(√(x²+x) + x)，分子分母同除 x 得 1/(√(1+1/x) + 1) = 1/2。
例3 求 lim(x→0) (e^x − 1)/x。解：e^x − 1 ~ x，故极限为 1。
例4 讨论 f(x) = (x² − 1)/(x − 1) 在 x = 1 处的连续性。解：x = 1 处无定义，但 lim(x→1) f(x) = 2，故是可去间断点。
例5 设 f(x) = { x·sin(1/x), x ≠ 0；0, x = 0 }，讨论 f 在 x = 0 处的连续性。解：lim(x→0) x·sin(1/x) = 0 = f(0)，故连续。
例6 证明 lim(x→0) (a^x − 1)/x = ln a（a > 0）。解：a^x − 1 ~ x·ln a，直接得证；也可令 t = a^x − 1 换元。

10.2 高频易错点清单（期末必背）
（1）极限与函数值无关：lim(x→x₀) f(x) 是否存在不依赖 f(x₀)。判断连续时才需要比较极限与函数值。
（2）等价无穷小替换只在乘除中安全使用；加减中除非能证明不同阶，否则慎换（tan x − sin x 陷阱题）。
（3）lim(x→∞) sin x/x = 0 不是 1；重要极限要求"趋于零的量"同时出现在 sin 内与分母。
（4）0/0 型：先约因子、有理化或等价替换；∞/∞ 型：抓大头；∞−∞ 型：通分或有理化。
（5）分段函数分段点：必须先分左右极限，相等才存在。
（6）"无界" ≠ "无穷大"：x·sin x 是经典反例。
（7）连续三条件缺一不可；第二类间断点与第一类间断点的区分看左右极限是否存在。
（8）闭区间上连续才有最值/介值/零点定理；开区间或区间内有间断点时不保证。
（9）零点定理只能保证"至少一个根"，不能保证唯一；证唯一需额外证单调。
（10）1^∞ 型极限要用第二个重要极限凑形，不能直接写成 1。

10.3 复习路径建议
第一步（理解）：把"数列极限 → 函数极限 → 连续性"这条主线串起来，理解极限是"趋势"而非"到达"。
第二步（计算）：集中刷"未定型极限"计算题，做到看到 0/0、∞/∞、1^∞ 立刻反应出对应套路。
第三步（证明）：掌握用定义证明极限（ε-N 与 ε-δ 的书写规范）、用单调有界/夹逼证收敛、用零点定理证根的存在性。
第四步（综合）：把极限与后续章节衔接——导数本质是差商极限，定积分是和的极限，级数是部分和数列的极限，理解了极限就理解了整个微积分的根基。
建议每类题型做三道变式，错题记录"错因"（概念混淆/计算失误/方法误用），考前重做一遍错题本。

补充讲义·各章节深入讲解与拓展（配合主笔记使用）

一、数列极限的深入补充

1.1 ε-N 语言的标准书写与证明技巧
用定义证明极限是初学者第一道坎，关键在于"给定 ε 后如何找 N"。标准做法：从 |xₙ − a| < ε 出发，通过放缩把它化成一个"只含 n 的不等式"，解出 n > 某表达式，再取 N 为该表达式的上取整。例如证明 lim(1/n) = 0：对任意 ε > 0，令 N = [1/ε]（取整），则当 n > N 时 1/n < 1/N ≤ ε，满足定义。这里的技巧是"先放缩再取 N"——只要找到一个比 |xₙ − a| 大的、便于解 n 的上界即可。另一个常见例子是证明 lim(n²/(n²+1)) = 1：|n²/(n²+1) − 1| = 1/(n²+1) < 1/n，令 N = [1/ε] 即可。放缩时要注意方向：必须把原式放缩得"更靠近 ε 一边"，即放大后仍要小于 ε。

1.2 收敛数列性质的证明与应用拓展
有界性证明的完整思路：由 ε = 1 得到尾部有界 |xₙ| < |a| + 1（n > N），前 N 项取最大值 M₁，令 M = max(|a|+1, M₁) 即得整体有界。这个"分段处理"的思想在后面许多证明中都会用到。保号性的用处：已知极限正负可推出数列尾项符号，这在判断数列是否恒正、处理不等式约束时很有用。关于子列：收敛数列任何子列收敛到同一极限，逆命题不成立（有收敛子列不一定收敛），但"存在两个收敛到不同极限的子列 ⇒ 原数列发散"是可靠的判定法。

1.3 夹逼准则的放缩技巧
夹逼的关键是"两边放缩后极限相同"。常用放缩方向：分母换大（整体变小）与分母换小（整体变大）。例：求 lim(n→∞) (sin1/√n + sin2/√n + … + sinn/√n)/n。注意到每一项 sin(k/√n) ≤ 1，且 sin 在正小量附近可放大缩小。更常见的例子是：lim(n→∞) (1/√(n²+1) + 1/√(n²+2) + … + 1/√(n²+n))。放缩：分母统一换成 n²+1 得下界 n/√(n²+n)，分母换成 n²+n 得上界 n/√(n²+1)，两边极限都是 1，故原极限为 1。放缩时"松紧"要适中：太松则两边极限不同，夹逼失效。

1.4 单调有界准则的完整解题流程
以 x₁ = √2，xₙ₊₁ = √(2 + xₙ) 为例：第一步证有界，用归纳法假设 0 < xₙ < 2，则 xₙ₊₁ = √(2 + xₙ) < √4 = 2，有界成立；第二步证单调，xₙ₊₁ − xₙ 与 xₙ − xₙ₋₁ 同号（因为函数 √(2+x) 单调增），由归纳法从 x₂ > x₁ 出发可得递增；第三步设极限为 A，对递推式两边取极限 A = √(2 + A)，解得 A = 2（负根舍去，因各项为正）。这个三步流程适用于绝大多数递推数列收敛题。

二、函数极限的深入补充

2.1 ε-δ 语言的证明示例
证明 lim(x→2) (3x − 1) = 5。对任意 ε > 0，要 |(3x−1) − 5| = 3|x − 2| < ε，只需 |x − 2| < ε/3，取 δ = ε/3 即证。证明含多项式的极限多用"提取公因子"；证明含分式的极限需先对分母做有界性估计。例如证明 lim(x→1) 1/x = 1：|1/x − 1| = |x−1|/|x|，先限定 |x−1| < 1/2 使 1/|x| < 2，再令 |x−1| < ε/2，取 δ = min(1/2, ε/2)。这里的 min 取法是关键——既要保证分母不为零，又要保证误差小于 ε。

2.2 左右极限的实战意义
含绝对值的函数在绝对值零点处、分段函数在分段点处、含符号函数处，都必须用左右极限。例：lim(x→0) (1 − |x|)/(1 + x) 的左右极限不同（左：x<0 时 |x|=−x，代入得 (1+x)/(1+x)=1；右：x>0 时 |x|=x，得 (1−x)/(1+x)=1——此处两者恰巧相等）。真正会出差异的例子：lim(x→0) e^(1/x)：x→0⁻ 时 1/x→−∞，e^(1/x)→0；x→0⁺ 时 1/x→+∞，e^(1/x)→+∞，左右极限不同故不存在。这类"指数型"函数的极限，左右方向必须分开判断。

2.3 海涅定理（归结原则）的灵活运用
海涅定理把函数极限化为数列极限，常用于：① 证明极限不存在——构造两个数列使 f(xₙ) 趋于不同值；② 把函数极限计算转化为数列极限（有时数列更好算）。例：证明 lim(x→0) cos(1/x) 不存在：取 xₙ = 1/(2nπ) 得 cos = 1，取 xₙ' = 1/((2n+1)π) 得 cos = −1，两个子列极限不同。

三、无穷小的深入补充

3.1 无穷小运算性质的证明与注意
"有限个无穷小的和是无穷小"的证明依赖 ε/n 技巧：设 α₁,…,αₖ 都是无穷小，对任意 ε > 0，每个 αᵢ 存在 δᵢ 使 |αᵢ| < ε/k，取 δ = min δᵢ，则和的绝对值 < k·(ε/k) = ε。这个"除以个数"的技巧值得记住。"有界×无穷小 = 无穷小"最常用：x·sin(1/x)、x·arctan(1/x)、√x·cos x 等在 x→0⁺ 时都是 0。注意"无穷小不能相除得结论"：0/0 型必须用其他方法。

3.2 无穷大的比较与未定型
x→∞ 时，幂函数、指数函数、对数函数、阶乘的增长速度排序：n! 增长最快，其次 aˣ（a>1），其次 xᵃ（a>0），最慢 ln x。这个排序在判断 ∞/∞ 型、∞−∞ 型极限时给出直观预期：如 lim(x→∞) ln x/x = 0（对数比幂函数慢），lim(x→∞) x/eˣ = 0（幂比指数慢）。"抓大头"的本质就是保留增长最快的主导项。

四、极限运算法则的深入补充

4.1 未定型转化技巧大全
0/0 型：因式分解约因子、有理化、等价替换、洛必达（后续章节）。∞/∞ 型：分子分母同除最高次项；含根号的用"同除 x 的最高次"并注意 √x² = |x|。0·∞ 型：把其中一个因子"翻下去"变 0/0 或 ∞/∞。∞−∞ 型：通分（分式）、有理化（根式）、提取公因子。1^∞ 型：凑第二个重要极限或取对数。例：lim(x→∞) (√(x²+x+1) − x)：有理化后分子为 x+1，分母为 √(x²+x+1)+x，同除 x 得 1/2。

4.2 复合函数极限的注意事项
换元法的前提是"内层极限存在"且"外层在该点极限存在"，并且当外层在 u₀ 处连续时条件最宽松。常见错误：未验证内层是否趋于目标值就换元。例：lim(x→0) sin(1/x)·x 不能直接令 t = 1/x 换元（因为 t→∞ 不是有限值），需用有界×无穷小处理。

五、极限存在准则的深入补充

5.1 夹逼准则的"两边设计"
夹逼的难点在于如何构造上界与下界。常用手段：① 单调性放缩（如 1/(n²+k) 随 k 增大而减小）；② 三角不等式放缩；③ 有界性放缩（|sin x| ≤ 1）。例：lim(x→0⁺) x·[1/x]（[·]为取整）：由 x−1 < x·[1/x] ≤ x 与 x → 0 夹逼，或用 x−1 < [1/x] ≤ 1/x 得 1 − x < x·[1/x] ≤ 1，夹逼得极限 1。

5.2 单调有界准则与不动点
递推数列 xₙ₊₁ = f(xₙ) 收敛时，极限 A 满足 A = f(A)，即 A 是 f 的不动点。解方程 A = f(A) 可能有多解，需结合有界范围取舍。若 f 在区间上单调递增且 x₁ 在区间内，通常可证单调性；若 f 单调递减，数列可能分成两个单调子列（奇偶分别收敛），此时要分别讨论。

六、两个重要极限的深入补充

6.1 第一个重要极限的变形全集
lim(x→0) sin(kx)/x = k；lim(x→0) sin(kx)/sin(mx) = k/m；lim(x→0) tan x/x = 1；lim(x→0) arcsin x/x = 1；lim(x→0) (1 − cos x)/x = 0（因 1 − cos x ~ x²/2）；lim(x→0) sin(x²)/x² = 1。核心判别：找"趋于零的量 u"，验证 lim sin u/u 结构。例：lim(x→0) sin(5x)/tan(3x) = 5/3（分别替换 sin 5x ~ 5x，tan 3x ~ 3x）。

6.2 第二个重要极限的凑形方法
lim(x→∞) (1 + a/x)^(bx) = e^(ab)；lim(x→0) (1 + ax)^(b/x) = e^(ab)。通用步骤：① 把底数写成 1 + (某无穷小)；② 指数写成"该无穷小的倒数 × 常数"；③ 整体 = e^常数。例：lim(x→∞) ((x+3)/(x−2))ˣ：底 = 1 + 5/(x−2)，指数 x = (x−2)/5 · 5x/(x−2)，故极限 = e^5。例：lim(x→0) (1 + tan x)^(1/sin x)：底 1 + tan x（tan x → 0），指数 1/sin x = (1/tan x)·(tan x/sin x)，故极限 = e^1 = e。

七、等价无穷小的深入补充

7.1 等价无穷小的来源（泰勒展开视角）
理解等价无穷小最快的方式是泰勒展开：sin x = x − x³/6 + …，取一阶得 sin x ~ x；1 − cos x = x²/2 − x⁴/24 + …，故 ~ x²/2；ln(1+x) = x − x²/2 + …，故 ~ x；eˣ = 1 + x + x²/2 + …，故 eˣ − 1 ~ x；(1+x)^a = 1 + ax + a(a−1)x²/2 + …，故 (1+x)^a − 1 ~ ax。掌握泰勒视角后，遇到新函数可以自行判断主部。

7.2 乘除替换的严谨依据
为什么乘除可替换？因为等价无穷小 α ~ β 意味着 lim α/β = 1，在乘除结构中 lim(f·α)/(g·β) = lim(f/g)·lim(α/β) = lim(f/g)，替换不影响极限。而加减中 lim(α − γ)/(β − γ) 一般不等于 lim(α−γ)/(α−γ)，因为"抵消项"可能同阶，导致分子分母的主导阶数改变。这就是"加减慎换"的数学本质。

7.3 替换的实战组合
0/0 型极限最强大的工具是"等价替换 + 有理化 + 因式分解"组合。例：lim(x→0) (√(1+x) − 1)/sin x = lim (x/2)/x = 1/2（√(1+x) − 1 ~ x/2）。例：lim(x→0) (e^(2x) − 1)/ln(1+3x) = lim 2x/(3x) = 2/3。例：lim(x→0) (1 − cos x)/x² = 1/2。这些题都可以直接套等价替换秒解。

八、连续性的深入补充

8.1 间断点分类的完整判断流程
步骤：① 检查 f(x₀) 是否有定义；② 求左极限 L⁻ 与右极限 L⁺；③ 若 L⁻ 与 L⁺ 均存在：相等 → 可去（再对比 f(x₀)，相等则连续，不等则可去）；不等 → 跳跃；④ 若至少一个不存在：极限为 ∞ → 无穷间断；振荡 → 振荡间断。例：f(x) = sin x/x 在 x = 0 是可去间断点（左右极限 1，无定义）；f(x) = 1/(x−1) 在 x = 1 是无穷间断点；f(x) = e^(1/x) 在 x = 0 是第二类（左 0 右 ∞）。

8.2 连续性与极限计算的结合
若 f 在 x₀ 连续，则 lim(x→x₀) f(x) = f(x₀)，这就是"代入法"。许多题先判断连续性再求极限：例设 f(x) = { (e^x − 1)/x, x ≠ 0；a, x = 0 } 在 x = 0 连续，求 a。解：lim(x→0)(e^x−1)/x = 1，连续要求 a = 1。

九、闭区间连续函数性质的深入补充

9.1 零点定理的证明题套路
证明 f 在 (a,b) 内有零点：① 构造连续函数（把方程移项）；② 找两点异号。若 f(a) 与 f(b) 同号，可尝试取中点或其他点。例：证明方程 x = cos x 在 (0, π/2) 内有解。令 f(x) = x − cos x，f(0) = −1 < 0，f(π/2) = π/2 > 0，由零点定理存在 ξ ∈ (0, π/2) 使 f(ξ) = 0。
9.2 如何证明"恰有一个根"
在零点定理基础上加单调性：若 f 在区间上严格单调（如 f'(x) > 0），则至多一个零点，结合零点存在即"恰有一个"。例：证明 x³ + x − 1 = 0 恰有一个实根：f(0) = −1，f(1) = 1，存在性成立；f'(x) = 3x² + 1 > 0 恒成立，f 严格递增，唯一性成立。
9.3 介值定理的应用
介值定理用于证明"函数能取到某个中间值"。例：证明连续函数 f 在 [0,1] 上若 f(0) = f(1)，则存在 ξ 使 f(ξ) = f(ξ + 1/2)。构造辅助函数 g(x) = f(x) − f(x+1/2)，g(0) = f(0) − f(1/2)，g(1/2) = f(1/2) − f(1) = f(1/2) − f(0) = −g(0)，若 g(0) = 0 则已得证，否则 g(0) 与 g(1/2) 异号，由零点定理得证。这类"构造辅助函数"的题是期末提升题，关键是凑出端点异号。

十、复习速查与题型对照

10.1 公式速查表
极限基础：lim 1/n = 0；lim qⁿ = 0（|q|<1）；lim n^(1/n) = 1。
两个重要极限：lim sin x/x = 1（x→0）；lim (1+1/x)ˣ = e（x→∞）。
等价无穷小（x→0）：sin x~x；tan x~x；arcsin x~x；arctan x~x；1−cos x~x²/2；ln(1+x)~x；eˣ−1~x；(1+x)^a−1~ax；aˣ−1~x·ln a。
连续条件：f(x₀) 有定义、lim 存在、lim = f(x₀)。
闭区间性质：最值、有界、介值、零点。
10.2 题型-方法对照
| 题型 | 首选方法 |
| 0/0 型 | 约因子 / 有理化 / 等价替换 |

例题精讲·20 道典型极限与连续题详解

题1 求 lim(n→∞) (2n² + 3n − 1)/(3n² − n + 2)。
解：分子分母都是二次多项式，属 ∞/∞ 型，分子分母同除以 n²，得 (2 + 3/n − 1/n²)/(3 − 1/n + 2/n²)，当 n→∞ 时含 1/n、1/n² 的项都趋于 0，故极限 = 2/3。小结：∞/∞ 型"抓大头"，看最高次项系数之比。

题2 求 lim(n→∞) (√(n² + 3n) − n)。
解：这是 ∞−∞ 型，有理化：分子分母同乘 (√(n²+3n) + n)，得 (n² + 3n − n²)/(√(n²+3n) + n) = 3n/(√(n²+3n) + n)。分子分母同除以 n（注意 √(n²+3n) 除以 n 得 √(1 + 3/n)），得 3/(√(1+3/n) + 1) → 3/2。

题3 求 lim(n→∞) n·(√(n+1) − √n)。
解：n·(√(n+1) − √n) = n·1/(√(n+1) + √n) = n/(√(n+1) + √n)，分子分母同除以 √n 得 √n/(√(1+1/n) + 1) → +∞。即该极限不存在（为无穷大）。

题4 求 lim(x→0) (x² + 2x)/sin x。
解：0/0 型。x² + 2x = x(x + 2)，sin x ~ x，故原式 = lim x(x+2)/x = lim(x+2) = 2。也可直接：lim(x²+2x)/sin x = lim x(x+2)/x = 2。

题5 求 lim(x→0) (1 − cos x)/(x sin x)。
解：1 − cos x ~ x²/2，sin x ~ x，故原式 = lim (x²/2)/(x·x) = 1/2。

题6 求 lim(x→0) (tan x − sin x)/x³。
解：这是"加减慎换"的经典题。tan x − sin x = tan x(1 − cos x)，tan x ~ x，1 − cos x ~ x²/2，故原式 = lim x·(x²/2)/x³ = 1/2。若直接把 tan x 和 sin x 都换成 x，会得到 0 的错误答案——因为分子两项同阶抵消。

题7 求 lim(x→0) (√(1+x) − 1)/x。
解：有理化：分子分母同乘 (√(1+x) + 1)，得 x/[x(√(1+x)+1)] = 1/(√(1+x)+1) → 1/2。等价替换更直接：√(1+x) − 1 ~ x/2。

题8 求 lim(x→0) (e^(3x) − 1)/ln(1 + 2x)。
解：e^(3x) − 1 ~ 3x，ln(1+2x) ~ 2x，原式 = lim 3x/2x = 3/2。

题9 求 lim(x→∞) (1 + 2/x)^(3x)。
解：第二个重要极限的凑形。底 = 1 + 2/x（2/x 是无穷小），指数 3x = (x/2)·6，故原式 = [lim (1 + 2/x)^(x/2)]⁶ = e⁶。

题10 求 lim(x→∞) ((x+1)/(x−1))ˣ。
解：底 = 1 + 2/(x−1)，指数 x = (x−1)/2 · 2x/(x−1)，故原式 = e^(lim 2x/(x−1)) = e²。

题11 求 lim(x→0) (1 + 3x)^(2/x)。
解：底 = 1 + 3x（3x 是无穷小），指数 2/x = (1/(3x))·6，故原式 = e⁶。

题12 求 lim(x→0) x·sin(1/x)。
解：x → 0 是无穷小，sin(1/x) 有界（|sin| ≤ 1），有界×无穷小 = 无穷小，故极限为 0。不能用等价替换（sin(1/x) 不趋于 0）。

题13 求 lim(x→0) sin(5x)/sin(3x)。
解：sin 5x ~ 5x，sin 3x ~ 3x，原式 = lim 5x/3x = 5/3。也可用第一个重要极限变形：lim (sin5x/5x)·(3x/sin3x)·(5/3) = 5/3。

题14 讨论 f(x) = { x·sin(1/x), x ≠ 0；1, x = 0 } 在 x = 0 处的连续性。
解：lim(x→0) x·sin(1/x) = 0（题12），但 f(0) = 1 ≠ 0，极限存在但极限值不等于函数值，故 x = 0 是第一类（可去）间断点。这题强调"极限与函数值无关"。

题15 求 a 使 f(x) = { (e^x − 1)/x, x ≠ 0；a, x = 0 } 在 x = 0 处连续。
解：lim(x→0)(e^x − 1)/x = 1（等价替换），连续要求 f(0) = lim，故 a = 1。

题16 讨论 f(x) = |x−1|/(x−1) 在 x = 1 处的间断类型。
解：x→1⁻ 时 |x−1| = 1−x，f = −1；x→1⁺ 时 f = 1。左右极限分别为 −1 与 1，存在但不相等，故 x = 1 是第一类跳跃间断点。

题17 证明方程 x³ − 3x + 1 = 0 在 (0,1) 内至少有一个根。
解：令 f(x) = x³ − 3x + 1，f 在 [0,1] 连续。f(0) = 1 > 0，f(1) = −1 < 0，f(0)·f(1) < 0，由零点定理存在 ξ ∈ (0,1) 使 f(ξ) = 0。

题18 证明方程 2ˣ = x² + 1 在 (0,1) 内有解。
解：令 f(x) = 2ˣ − x² − 1，f 连续。f(0) = 1 − 0 − 1 = 0——恰好在 0 处为零，不能直接说明 (0,1) 内有根。改看 f(1/2) 与 f(1)：f(1) = 2 − 1 − 1 = 0 也不理想。计算 f(0.5) = √2 − 0.25 − 1 ≈ 1.414 − 1.25 = 0.164 > 0；f(0.9) ≈ 1.866 − 0.81 − 1 = 0.056 > 0——都不易找异号点。换个思路：把方程改写为 2ˣ − x² − 1 = 0，在 (1,2) 内：f(1) = 0 仍不好。此题更稳妥的做法是考虑 g(x) = 2ˣ − x² − 1 在 [0,2] 上：g(0) = 0，g(1) = 0，g(2) = 4 − 4 − 1 = −1 < 0，由 g(1)·g(2) < 0 知存在 ξ ∈ (1,2) 使 g(ξ) = 0。小结：找异号端点要多试几个点，端点本身为零不算数。

题19 证明：若 f 在 [a,b] 上连续，且对任意 x ∈ [a,b] 有 f(x) > 0，则 1/f 在 [a,b] 上有界。
解：f 在闭区间连续 ⇒ f 有最小值 m > 0（最值定理），故 1/f ≤ 1/m 有上界；又 1/f 连续（连续函数之商），由有界性定理直接有界。该题综合了最值定理与连续函数运算性质。

题20 求 lim(x→0⁺) x·ln x（提示，为后续章节做铺垫）。
解：这是 0·∞ 型。令 x = e^(−t)，则 x→0⁺ 对应 t→+∞，x·ln x = −t·e^(−t) = −t/e^t。由指数函数增长速度远快于幂函数，lim(t→∞) t/e^t = 0，故原极限为 0。这个极限在后面求导、积分中频繁出现，先记住结论：x·ln x → 0（x→0⁺）。

解题心得：极限题的"三步法"——先判断型（0/0、∞/∞、0·∞、∞−∞、1^∞、非未定型），再选方法（等价替换/有理化/抓大头/重要极限/夹逼），最后验证（左右极限是否一致、是否满足使用前提）。连续题则紧扣"三条件"与"间断点分类"，证明题靠"零点定理+构造辅助函数"。把这些题吃透，极限一章的计算与证明就基本过关了。

概念辨析·极限与连续 20 问

问1 数列收敛、有界、单调三者的关系是什么？
答：收敛 ⇒ 有界（必要非充分）；单调 + 有界 ⇒ 收敛（充分非必要，因为收敛数列未必单调，如 xₙ = (−1)ⁿ/n 收敛于 0 但不单调）；有界且收敛的数列不要求单调。三者关系常考判断题，务必分清"谁推谁"。

问2 "极限不存在"有哪几种情形？
答：① 左右极限不相等（如 |x|/x 在 0 处）；② 极限为无穷大（如 1/x 在 0 处，记为"极限不存在但为无穷大"或"极限为 ∞"）；③ 振荡不收敛（如 sin(1/x) 在 0 处）；④ 数列在两个值之间跳动（如 (−1)ⁿ）。

问3 无穷小是"很小的数"吗？
答：不是。无穷小是"以零为极限的函数"，描述的是变化趋势，不是绝对值大小。唯一的例外是常数零，它可以在任何过程中作为无穷小。例如 10⁻¹⁰ 虽然很小，但不是无穷小（它的极限是它自己）。

问4 为什么 lim(x→0) sin x/x = 1，而 lim(x→0) x·sin(1/x) = 0？
答：前者是"同阶无穷小之比"（sin x ~ x，比值为 1），后者是"无穷小 × 有界函数"（x → 0，sin(1/x) 有界，乘积为无穷小）。区分标志：sin 内是"趋于零的量"还是"趋于无穷的量"。

问5 等价无穷小替换在加减法中一定错吗？
答：不一定错，但危险。安全的判据：若替换后"加减结果的阶"不因替换而改变，则可换；若出现同阶项抵消（如 tan x − sin x），替换会得出错误结果。考试中最稳妥的策略：加减法尽量别用等价替换，改用泰勒展开或提取公因子。

问6 无界函数一定是无穷大吗？
答：不一定。无穷大要求 |f(x)| 最终"单调地或总体地"趋于无穷，而无界只要求存在点列使 |f(xₙ)| 趋于无穷。x·sin x 在 x→∞ 时无界但不趋于无穷大（它还会经常回到 0）。

问7 函数在某点无定义，该点的极限一定不存在吗？
答：不一定。极限只看去心邻域内的趋势，与函数值无关。例如 sin x/x 在 x = 0 无定义，但极限存在且为 1。反过来，函数在某点有定义，也不保证该点极限存在（如 |x|/x 在 0 处有定义但极限不存在）。

问8 连续与可导、可积的关系（预习向）？
答：可导 ⇒ 连续 ⇒ 可积（在闭区间上）；反过来都不成立：连续不一定可导（如 |x| 在 0 处），可积不一定连续（有有限个间断点的有界函数可积）。这些关系后续章节会系统学习。

问9 第一类间断点与第二类间断点的本质区别？
答：第一类：左右极限都存在（可去：相等；跳跃：不等）。第二类：至少一个左右极限不存在（无穷/振荡）。判断口诀："左右极限都在，是一类；否则是二类"。

问10 闭区间上连续函数必有什么性质？为什么开区间不保证？
答：闭区间连续 ⇒ 有界、有最值、满足介值/零点定理。开区间不保证：如 f(x) = 1/x 在 (0,1) 上连续但无界、无最大值。原因是闭区间把"端点"包含进来，函数值不会在端点处"跑掉"。

问11 零点定理能说明"只有一个根"吗？
答：不能。零点定理只保证"至少有一个"。要证唯一，必须附加单调性（或导函数不变号）。考试题常组合考查："先证存在（零点定理），再证唯一（单调）"。

问12 抓大头（∞/∞ 型）的本质是什么？
答：分子分母同时除以最高次项，使除最高次以外的项都趋于 0。本质是比较"增长速度"：同次多项式极限为系数比；分子次数高则趋于 ∞；分母次数高则趋于 0。

问13 有理化的目的是什么？
答：把含根号的分式化为不含根号（或根号移到分子/分母一侧），从而消去"零因子"或约去公因子。常用于 √(x²+x) − x 型（∞−∞）和 (√(1+x) − 1)/x 型（0/0）。

问14 两个重要极限的"几何直觉"是什么？
答：第一个：单位圆中 sin x 与弧长 x 几乎相等（x 很小时），故 sin x/x ≈ 1。第二个：复利问题中连续复利本利和为 e 倍本金；或理解为"1 加上一个无穷小，再以该无穷小的倒数次方"趋向 e。

问15 数列极限与函数极限的关系（海涅定理）？
答：函数在 x₀ 的极限存在 ⇔ 任意趋于 x₀ 的数列（去心）其函数值极限都存在且相等。海涅定理是桥梁：它把"函数极限不存在"的证明化为"找两个子列"，也把复杂函数极限化为数列极限处理。

问16 为什么要求分段函数在分段点"分左右"？
答：因为分段函数在分段点左右两侧的表达式不同，极限可能由不同的式子决定。只有左右极限都存在且相等，整体极限才存在。跳跃间断点的本质就是"左右各走各的"。

问17 等价无穷小与同阶无穷小有什么区别？
答：等价（α ~ β）要求比值极限为 1，是同阶（比值极限为非零常数）的特例。同阶说明"趋于零速度相同"，等价进一步要求"主导项相同"。比较阶时用"比值"判断，比值趋向 0/常数/∞ 分别对应高阶/同阶/低阶。

问18 求极限时可以先代值再判断吗？
答：只有函数在该点连续时才可以"直接代入"（lim f(x) = f(x₀)）。初等函数在定义区间内的点都连续，故可代入；但分段点、无定义点、∞ 处必须先判断未定型再处理。盲目代值会把 0/0 误写成 0。

问19 无穷大与"没有极限"如何区分？
答：习惯上"极限为 ∞"也是一种描述，表示函数值最终无限增大，此时说"极限不存在（发散到无穷）"。判定中若极限为 ∞，通常记为 lim f(x) = ∞，并注明是无穷间断点或发散。与"振荡无极限"区分：∞ 是有明确趋势的，振荡没有。

问20 学完极限，为什么说它是整个微积分的基石？
答：导数是"差商（Δy/Δx）的极限"，定积分是"和式（黎曼和）的极限"，级数是"部分和数列的极限"，连续本身就是"极限等于函数值"。没有极限的语言，就无法精确刻画"瞬时变化率""曲线下面积"这些概念。所以极限不只是第一章的内容，而是贯穿整个高等数学的思想工具。

期末高频考点·极限章节冲刺总结

一、必背公式（考试直接使用）
极限：lim(1/n)=0；lim qⁿ=0（|q|<1）；lim n^(1/n)=1。
重要极限：lim(x→0) sin x/x = 1；lim(x→∞)(1+1/x)ˣ = e。
等价无穷小（x→0）：sin x~x、tan x~x、arcsin x~x、arctan x~x、1−cos x~x²/2、ln(1+x)~x、eˣ−1~x、(1+x)^a−1~ax、aˣ−1~x·ln a。
连续性：lim(x→x₀) f(x) = f(x₀)；闭区间连续 ⇒ 有界/最值/介值/零点。

二、必会题型（按出现频率排序）
1. 0/0 型极限计算：等价替换 + 约因子 + 有理化，3 步内解决。
2. ∞/∞ 型：抓大头，同除最高次项，注意带根号时同除 x 并处理 |x|。
3. 1^∞ 型：凑第二个重要极限，答案形如 e^(常数)。
4. 数列极限：先化简通项，再夹逼或单调有界；递推数列三步法（有界→单调→解 A）。
5. 间断点分类：分段点分左右，按左右极限存在与否及是否相等分类。
6. 零点定理证明：构造连续函数，找端点异号；证唯一加单调性。
7. 已知极限/连续求参数：利用"极限值 = 函数值"或"左右极限相等"列方程。

三、必防陷阱（历年失分点）
陷阱1：lim(x→∞) sin x/x 误用重要极限——答案 0 不是 1。
陷阱2：加减中乱用等价替换——tan x − sin x 必须提公因子。
陷阱3：把"无界"当"无穷大"——x·sin x 是反例。
陷阱4：忽略分段点左右极限——|x|/x 在 0 处极限不存在。
陷阱5：零点定理只证存在，答"唯一"被扣分——必须补单调。
陷阱6：未定型直接套四则运算——0/0、∞/∞ 必须先变形。
陷阱7：开区间用闭区间性质——最值定理要求闭区间。
陷阱8：1^∞ 型直接写 1——必须凑形得 e 的幂。
