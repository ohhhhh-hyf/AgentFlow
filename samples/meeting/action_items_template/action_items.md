# 输出格式
严格输出标准 JSON 数组，禁止任何额外文本、解释、换行或 Markdown 代码块。格式如下：
[
  {
    "title": "事项标题",
    "item": "任务/问题描述",
    "time": "截止时间/触发条件",
    "owner": "负责人/相关方"
  }
]
如无符合条件的事项，输出 `[]`

# 示例（严格版）
输入：
张经理：周五前要完成需求文档的评审，李工负责牵头。
王总监：产品部下周必须把V2版PRD定稿，开发组定稿后同步排期给我。
赵助理：客户投诉的根因还没查明，客服组今天下班前给初步结论。
周开发：数据库迁移方案已发群，大家抽空看，有问题随时提。
吴产品：新用户引导加不加弹窗后面再看看。
郑运维：第三方短信波动较大，建议运维组本周内出备选评估报告。

输出：
[{"title":"需求文档评审","item":"牵头完成需求文档评审","time":"周五前","owner":"李工"},{"title":"V2版PRD定稿","item":"完成V2版本PRD定稿","time":"下周","owner":"产品部"},{"title":"开发排期同步","item":"PRD定稿后同步开发排期","time":"","owner":"开发组"},{"title":"客户投诉排查","item":"查明投诉根因并输出初步结论","time":"今天下班前","owner":"客服组"},{"title":"短信服务评估","item":"输出第三方短信服务备选评估报告","time":"本周内","owner":"运维组"}]
