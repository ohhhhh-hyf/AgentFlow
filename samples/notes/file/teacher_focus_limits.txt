期末最后一课·划重点（高等数学·极限与连续）

同学们，还有两天就考试了，这最后一节课我把重点给大家划一下，你们照着复习。

先说总的情况：这次考试计算题有 5 到 6 道，几乎全是极限，分值占得很大，大家一定要把极限的计算练熟。选择填空里会有概念辨析，比如极限定义、无穷小、连续和间断点这些，都是送分题，别丢。证明题会出 1 道，就在闭区间上连续函数的性质里，我课上讲过的那两个定理，你们把证明模板记住。

第一章极限是重中之重，每一届都必考。第一个重要极限，sin x 比 x，当 x 趋于 0 的时候极限是 1，这个必考，变形要会凑：sin3x 比 x、sin5x 比 sin3x 这种，把形式凑出来再算。第二个重要极限，(1 + 1/x) 的 x 次方趋近于 e，也是必考，要会凑"1 加无穷小、指数取倒数"的形式，复利背景了解一下就行。这两个重要极限你们必须会推导证明，还要会算，年年都有大题。

等价无穷小替换是重点，九个常用的等价无穷小要默写出来：x 趋于 0 时 sin x、tan x、arcsin x、arctan x 都等价于 x，ln(1+x) 等价于 x，e 的 x 次方减 1 等价于 x，1 减 cos x 等价于二分之一 x 平方，等等。替换的时候乘除可以直接换，加减要慎用，这个经常考，每年都有人在这里丢分。考试里那种 tan x 减 sin x 比 x 立方的题，先提公因子再换，答案二分之一。

数列极限这部分，ε-N 定义是重点，要会背，还要能用定义证明简单的数列极限，比如证明 1/n 趋近于 0，步骤要写全。单调有界准则考得少一点，但 x 的 n 加 1 等于根号下 2 加 x 的 n 这种递推数列求极限，还是可能会出，你们要会先证有界再证单调，最后两边取极限。

函数连续性和间断点分类是重点。连续的定义要会，间断点要会分第一类（可去、跳跃）和第二类（无穷、振荡），这个选择填空基本必考，我 PPT 里那张分类表你们要记住。闭区间上连续函数的性质，最大值最小值定理、零点定理、介值定理，证明题就从这里出，零点定理的证明步骤背下来，考场上直接写。

海涅定理（归结原则）了解一下就行，有个印象，知道函数极限和数列极限的关系，选择题可能出一个选项，不会单独出大题。

求极限的一般方法你们要总结一遍：能代入就代入，0 比 0 型先等价无穷小替换再洛必达，无穷大比无穷大提最高次项，1 的无穷大次方凑第二个重要极限。我把这些方法都写在黑板上了，你们抄下来。

最后，复习安排我建议：今天把第一章必考的极限计算练熟，明天上午把概念辨析过一遍，下午做一套往年题。错题本一定要看，考前把错题过一遍比刷新题有用。考试记得先易后难，概念题别纠结太久。

好，就这些，大家回去好好复习，有问题来办公室问我。
