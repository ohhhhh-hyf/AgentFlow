# 讨论议题与背景
本次会议围绕三国赤壁之战、合肥之战、火烧连营等战役，从兵法和战法角度讨论其影响及人物评价。参会成员包括发言人1、发言人2、发言人3，核心探讨问题包括赤壁之战中曹军因缺乏水军而战败、孙权多次北伐合肥未果、刘备在夷陵之战中因扎营失误被陆逊火攻，以及关羽、张飞、黄忠、五子良将等武将的战斗力比较。

# 发言要点
发言人1认为赤壁之战曹军失败主要因虎豹骑擅长陆战而缺乏水军，并非实力不济；东吴水军擅长水战但陆战弱，在合肥之战中失利。发言人1详细叙述215年合肥之战，张辽率800死士大破孙权十万大军，孙权差点被俘，后人戏称“孙十万”。发言人2表示小时候认为孙权厉害，长大后看法反转，认为其打仗能力不佳。发言人3补充孙权在孙策刚死时也曾被刘表（或刘琦）等打得惨败，几万人被几千人追着打。关于火烧连营，发言人1指出刘备因体恤士兵在密林扎营，被陆逊抓住秋季干燥时机火攻，连营七百里被烧，刘备逃回白帝城。发言人2质疑陆逊与孙家有仇，发言人1确认陆逊为江东四杰之一，并提及孙策被刺杀。关于武将能力，发言人1认为关羽阵中斩将能力突出，是历史第一人；发言人3提到关羽水淹七军，并认为刘备汉中之战打得还行。发言人1还讨论诸葛亮第一次北伐若用魏延守街亭可能成功，但魏延想法不符合蜀汉实际，发言人3认为蜀汉地盘太小。

# 共识形成
会议最终达成共识：赤壁之战失败主要因曹军不擅水战，而非实力不济；孙权一生未能攻克合肥，合肥之战成为其军事生涯的污点；火烧连营是刘备冒进和陆逊抓住时机的结果；**关羽阵中斩将能力突出，被认为是历史第一人**；**诸葛亮第一次北伐若用魏延守街亭可能成功，但魏延想法不符合蜀汉实际，因蜀汉地盘小，难以支撑其战略**。
