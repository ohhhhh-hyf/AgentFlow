# 项目概况
本次会议为原占比二玉米面加工厂项目中期验收会议，由验收组代表王总主持并汇报。验收组于18、19号提前介入，20号召开首次会议，对卢萨卡、蒙泽两点开展内业与外业检查。卢萨卡点已完成除带料调试以外的所有验收工作，蒙泽点利用现场资源顺带完成全部验收（含带料调试），姆皮卡点现场验收尚未开展，其内业资料已提前送至卢萨卡。内业检查分管理组和技术组，按合同及规范执行，项目执行团队人员基本在岗，内业资料基本满足标准要求，但分类整理和签字规范性需完善；竣工文件基本达到组卷成册要求，但资料分散，需汇总至卢萨卡。外业检查分建筑、安装、设备三部分：建筑部分原材料集中采购、质量良好，但局部有损伤和排水需检查；安装部分钢结构合格，但监控管线接头有脱落；设备部分运行正常，产能符合设计指标；蒙泽厂区混凝土路面有少量开裂。财务检查符合规范，中基公司无挪用资金情况。验收组提出整改要求，管理组田组长和技术组龚总承诺会后落实，合作局领导金昌柱要求出报告前完成整改并复核。项目有动用不可预见费情况，需完善证据资料，后续专项对接。

# 后续计划
- **会后整改**：管理组田组长承诺会后与技术组一起细化验收组提出的问题，制定方案并落实整改；技术组龚总承诺在验收完成后第一时间将三个厂区资料（含竣工图）汇总至卢萨卡，分类组卷及编码，并针对现场实体整改按方案逐一落实。
- **混凝土路面开裂整改**：合作局领导金昌柱要求管理组和总包单位共同分析开裂原因，制定科学合理的整改方案，*在出报告前完成整改*，验收组需进行复核。
- **资料汇总**：技术组需在验收完成后第一时间将三个厂区资料汇总至卢萨卡，分类组卷及编码。
- **不可预见费**：验收组将利用后续时间对不可预见费使用情况做专项对接，完善依据证据和数据，确保充分无误。
- **姆皮卡点验收**：会后将及时安排姆皮卡点现场验收工作，*该点路途遥远、交通状况不佳，需注意交通安全和疫情防控*。
- **成品保护**：在移交外方前继续做好成品保护，对破损部位及时修补。
