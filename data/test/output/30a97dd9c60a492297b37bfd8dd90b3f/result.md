# 全文摘要
会议围绕生活中约定俗成规则（必须结婚、买房、工作）的合理性展开讨论，并延伸至理想工作状态、AI与机器人承担苦活累活、机器人拥有思想意识后的风险等话题。讨论以观点分享为主，未形成明确结论；最后简短提及语音分离标注测试。

# 要点梳理
## 约定俗成规则的合理性
- **必须结婚**：发言人1认为不合理，经济不好时更不可行；发言人2补充必须买房、必须结婚生子，并强调取决于遇到的人和自身经济能力。
- **必须工作**：发言人3认为合理；发言人1认为工作合理但应干自己想做的，不跟钱挂钩；发言人2提出工作后还需进修学习。

## 理想工作状态
- **按兴趣干活**：发言人1希望每天起来想干啥就干，参考兴趣干活；发言人4提出不干活更好。
- **职业举例**：发言人3举例宠物博主发宠物视频剪视频赚钱，发言人2补充游戏高手。
- **脏活累活**：发言人1指出总有脏活累活没人承担，发言人3建议让AI去做苦活累活，不应让AI搞创作艺术。

## AI与机器人的未来影响
- **机器人干苦活**：发言人2提到蔡明小品中机器人脑袋被敲后煮牛皮制品，发言人1认为机器人负责生产、人负责享受挺好，但规则能否实现不确定。
- **阶级问题**：发言人1认为上层人不想让平民过太好，存在阶级。
- **机器人反抗风险**：发言人2提出机器人有思想后可能罢工反抗奴役人类（终结者剧情），并提到成为犯罪代理人、职业杀手、超级战士等风险；发言人3提到斯皮尔伯格人工智能电影结局。
- **思想必要性**：发言人5认为机器人只需执行命令不必有思想，发言人3认为智能和思想没法分开，发言人5担心思想带来不好影响。
- **军事应用**：发言人2提到单兵装甲外骨骼、智能枪械等半机械人状态，发言人3提到排雷机械狗和机械车。
- **影视形象**：发言人2提到重返德军总部超级战士、数码宝贝守卫兽和安多路兽、机械邪龙兽等。
