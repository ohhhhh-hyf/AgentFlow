# 参观概况
本次讲解沿故宫中轴线及东西六宫展开，从午门检票处讲起，依次介绍太和门、太和殿、中和殿、保和殿、乾清门、乾清宫、交泰殿、坤宁宫、储秀宫、慈宁宫、寿康宫、断虹桥、武英殿、文华殿、箭亭、钟表馆、珍宝馆、东筒子夹道、延禧宫、景仁宫、御花园及北门神武门等景点，并标注多处免费盖章点。讲解最后总结三条游览路线：第一条走完视频内所有景点，适合待一整天，一天走了3万步；第二条约半天；第三条预计2小时左右。

# 核心看点与讲解
## 中轴线
- 午门：排队检票处，明朝皇帝在此杖打犯错大臣，清朝在此颁朔；明三暗五，正门仅皇帝可走，皇后大婚进一次、状元榜眼探花出一次，旁门走皇亲国戚和文武百官。
- 太和门广场：五座金水桥，皇帝走中间，皇亲国戚走挨着中间两座，文武百官走最边上。
- 太和门：明朝皇帝御门听政处，门口铜狮为故宫六对铜狮中最大一对，建议不要站在底下合影。
- 太和殿：即金銮殿，皇帝登基、皇后册封等大典场所，文武百官文东武西朝拜；西边弘义阁为皇帝银库，东边体仁阁为缎库。
- 中和殿：大典时皇帝休息室。
- 保和殿：自乾隆五十四年起为科举殿试考场；东北角汉字馆有4枚免费印章，可购买紫禁城100并现场盖章，每家店印章不同，买了之后不能去其他店铺盖章，汉字馆印章数量据说最多，可邮寄或自背。
- 乾清门：皇帝上早朝处，东边九卿直房供等级高的大臣等待召见，西边为军机处，门口狮子耳朵耷拉、眉毛遮眼以警示后宫。
- 乾清宫：皇帝睡觉处，据说有27张龙床防刺客，正大光明匾后藏立储诏书，门口铜鹤铜龟旁有紫禁城最小宫殿江山金殿。
- 交泰殿：放25块传国玉玺。
- 坤宁宫：住皇后，明朝所有皇后都住此；东北角文创店有5枚免费印章。

## 西线
- 储秀宫：慈禧住了20多年，现为慈禧五十大寿原状陈列，其子在此出生，旁边文创店有3枚免费印章。
- 翊坤宫、永寿宫及太极殿：太极殿是东西六宫唯一称殿的。
- 慈宁宫：康熙为孝庄皇太后修建的养老院；旁边寿康宫是甄嬛居住地。
- 冰窖书吧：3枚免费印章，作者在此买了冰嬉图。
- 断虹桥：网红打卡地，最有名的是武当狮。
- 武英殿：后改陶瓷馆，目前关闭只能在门口看。
- 文华殿：作者去时未开，据说现在有展览。

## 东线
- 箭亭：清朝皇帝及子孙练习骑马射箭处，旁边商店可买文创雪糕。
- 钟表馆：展示各年代钟表。
- 珍宝馆：门口为我国现存三座古代九龙壁之一，左边数第三条白龙下有一块木头刷白漆以假乱真；珍宝馆即宁寿全宫，乾隆给自己修建的养老院，皇极殿据说1:1复刻乾清宫，宁寿宫对标坤宁宫，乐寿堂是故宫唯一能进去参观的皇家寝室，有二龙仙楼设计，再往后是珍妃井，出口右手边商店有3枚免费印章。
- 东筒子夹道：拍照出片地。
- 延禧宫：网红打卡地；旁边景仁宫是甄嬛被封熹妃时住处，珍妃也住过。
- 御花园：钦安殿供奉真武大帝。
- 神武门：故宫北门，出门左手边角楼咖啡2枚、故宫文创2枚免费印章。

# 互动与体验
讲解中设置多处互动提问：九龙壁白龙下用木头以假乱真的小细节，当时皇上究竟有没有发现；皇上家的御花园和和珅家的后花园更喜欢哪个；文创雪糕上的人物是谁，欢迎在评论区分享。作者在汉字馆购买紫禁城100并现场盖章，在冰窖书吧购买冰嬉图，并体验了多处免费盖章，称盖章时有批折子的感觉。作者建议不要站在太和门铜狮底下合影，单独拍照即可；提醒珍宝馆游客太多，看凤冠没点技术挤不进去；建议游览中适当休息和补充水分。

# 收获与建议
通过讲解可了解午门明三暗五与正门使用规则、太和殿大典功能与文东武西、保和殿自乾隆五十四年起为殿试考场、乾清宫27张龙床与正大光明匾藏立储诏书、交泰殿25块传国玉玺、坤宁宫为皇后居所、储秀宫慈禧居住20多年、慈宁宫为康熙为孝庄修建的养老院、珍宝馆即宁寿全宫及九龙壁白龙下木头以假乱真等知识。建议：早起排队一进门沿中轴线往后走可错开旅游团；打算待一整天可选第一条路线，一天约3万步，注意休息补水；时间有限可选第三条路线，预计2小时左右；喜欢盖章者可截图保存视频标注的七个免费盖章位置，并注意每家店印章不同、买了紫禁城100后不能去其他店铺盖章。
