# 参观概况
本次参观为故宫游览攻略讲解，围绕午门、太和门、太和殿、中和殿、保和殿、乾清门、乾清宫、交泰殿、坤宁宫、储秀宫、慈宁宫、断虹桥、武英殿、文华殿、箭亭、钟表馆、珍宝馆、御花园等景点展开，穿插历史典故与参观建议。讲解汇总了七个免费盖章点，并推荐三条游览路线，供不同时间与体力需求的游客选择。

# 核心看点与讲解
- **午门**：明三暗五结构，正门仅供皇帝行走，皇后大婚时可进一次，殿试前三名可出一次；明朝皇帝在此杖打犯错大臣，清朝皇帝在此颁发历书。
- **太和门**：明朝御门听政的上朝场所，门口铜狮子为故宫六对铜狮中最大的一对，脚踩寰宇象征权力。
- **太和殿**：举行盛大典礼的场所，如皇帝登基、皇后册封；文武百官在广场上站位为文东武西。
- **中和殿**：举行盛大典礼时皇帝的休息室，文武百官站好后皇帝再前往太和殿。
- **保和殿**：自乾隆五十四年起作为殿试考场；东北角汉字馆有4枚免费印章，可购买《紫禁城100》现场盖章。
- **乾清门**：皇帝上早朝的地方，东边九卿直房、西边军机处；门口铜狮耳朵耷拉、眉毛遮眼，警示后宫不该看的不看、不该听的不听。
- **乾清宫**：皇帝寝宫，有27张龙床防刺客；牌匾“正大光明”后藏立储诏书，皇帝驾崩后与另一份对比验证。
- **交泰殿**：存放25块传国玉玺。
- **坤宁宫**：皇后居所，明朝所有皇后都住于此；东北角文创店有5枚免费印章。
- **储秀宫**：慈禧居住20多年，现为慈禧五十大寿时期原状陈列，因其子在此出生；旁边文创店有3枚免费印章。
- **慈宁宫**：康熙为奶奶孝庄皇太后修建的养老院，旁边寿康宫为甄嬛居住地。
- **断虹桥**：网红打卡地，石狮子形态各异，最有名的为“武当狮”。
- **武英殿**：西边，后改陶瓷馆，目前关闭。
- **文华殿**：东边，我去时未开，据说现有展览。
- **箭亭**：清朝皇帝及子孙练习骑马射箭处，旁边商店可买文创雪糕。
- **钟表馆**：展示各种造型的钟表。
- **珍宝馆**：宁寿全宫，乾隆养老院，皇极殿1:1复刻乾清宫，乐寿堂为故宫唯一可进入参观的皇家寝室，有珍妃井。
- **御花园**：有钦安殿供奉真武大帝，北边景山酷似闭目盘坐人像。

# 互动与体验
讲解中穿插互动提问，如询问文创雪糕形象、御花园与和珅后花园对比等，引导观众参与。个人感受包括：珍宝馆游客太多，看凤冠需挤进去；盖章有批折子感觉；钟表馆造型令人开眼；东筒子夹道拍照出片。

# 收获与建议
- **择时/排队**：建议早起排队，一进门就冲，可错开旅游团人群。
- **路线选择**：三条路线可选，第一条走完所有景点适合一整天，约3万步；第二条约半天；第三条约2小时最省力。
- **盖章点**：七个免费盖章点，包括汉字馆4枚、坤宁宫文创店5枚、储秀宫文创店3枚、冰窖书吧3枚、珍宝馆出口商店3枚、角楼咖啡2枚、故宫文创2枚。
- **注意事项**：故宫多处可买《紫禁城100》，但印章不同且不能跨店盖章；珍宝馆虽叫馆但不是单独展厅，需逛院子周围屋子。
- **饮食与休息**：一天走3万步，需适当休息和补充水分。
