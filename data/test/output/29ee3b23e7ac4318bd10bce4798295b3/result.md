# 参观概况
本次参观为故宫博物院游览，讲解围绕午门、太和殿、乾清宫等主要景点展开，核心主题为故宫历史建筑与游览攻略。讲解从午门开始，沿中轴线依次介绍太和门、太和殿、中和殿、保和殿、乾清门、乾清宫、交泰殿、坤宁宫、储秀宫、慈宁宫、断虹桥、武英殿、文华殿、箭亭、钟表馆、珍宝馆、延禧宫、御花园至神武门，全程覆盖前朝与后宫区域。讲解内容涵盖各建筑的历史功能、建筑特色、相关典故及游览注意事项，并标注了七处免费盖章点与三条推荐游览路线。

# 核心看点与讲解
- **午门**：讲解“明三暗五”结构，三个门洞进门后变五个；中间正门仅供皇帝行走，皇后大婚时可进一次，殿试前三名（状元、榜眼、探花）可出一次，两侧门走皇亲国戚和文武百官。明朝皇帝在此杖打犯错大臣，清朝皇帝在此颁发次年历书（颁朔之礼）。
- **太和门广场**：有五座金水桥，皇帝走中间，黄金国器走挨着中间两座，文武百官走最边上。太和门为明朝御门听政（上朝）之处，门口铜狮子是故宫六对铜狮中最大的一对，脚踩寰宇象征权力，建议单独拍照而非站在其下合影。
- **太和殿**：即金銮殿，是举行盛大典礼的地方，如皇帝登基、皇后册封，文武百官在太和殿广场高呼“吾皇万岁万岁万万岁”，站位遵循“文东武西”原则。西边红衣阁为皇帝银库，东边体仁阁为缎库。
- **中和殿**：举行盛大典礼时皇帝的休息室，文武百官站好后皇帝再前往太和殿。
- **保和殿**：自乾隆五十四年起为殿试考场；东北角汉字馆有4枚免费印章，可购买《紫禁城100》现场盖章，每家店印章不同，购买后不能去其他店铺盖章，汉字馆印章数量最多，可邮寄到家或自行携带。
- **乾清门**：过此门即后宫（皇帝与妃嫔生活区域），皇帝在此上早朝；东边九卿直房为等级高的大臣等待召见处，西边为军机处。门口铜狮耳朵耷拉、眉毛遮眼，警示后宫之人“不该看的别看，不该听的别听”。
- **乾清宫**：皇帝寝宫，内有27张龙床，据说是为防止刺客找到皇帝位置；牌匾“正大光明”后藏立储诏书，皇帝写两份诏书，驾崩后对比验证是否被动过手脚。门口有铜鹤、铜龟及紫禁城最小宫殿“社稷江山金殿”，提醒皇帝将江山社稷放在第一位。
- **交泰殿**：存放25块传国玉玺。
- **坤宁宫**：皇后居所，明朝所有皇后均住于此；东北角文创店有5枚免费印章。
- **储秀宫**：慈禧住了20多年的地方，现为慈禧五十大寿时期原状陈列，因其子在此出生而受喜爱；旁边文创店有3枚免费印章。
- **翊坤宫、永寿宫、太极殿**：永寿宫西边为东西六宫中唯一被称为“殿”的太极殿。
- **慈宁宫、寿康宫**：慈宁宫为康熙给奶奶孝庄皇太后修建的养老院，寿康宫为甄嬛居住地。
- **冰窖书吧**：有3枚免费印章，印章造型有批折子的感觉，可购买冰溪图。
- **断虹桥**：网红打卡地，石狮子形态各异，最有名的为“武当狮”。
- **武英殿**：后改为陶瓷馆，目前关闭状态，只能在门口观看。
- **文华殿**：与武英殿对应“文东武西”，参观时未开放，据说有展览。
- **箭亭**：清朝皇帝及子孙练习骑马射箭之处，旁边商店可购买文创雪糕。
- **钟表馆**：展示古代钟表造型。
- **珍宝馆（宁寿全宫）**：门口为我国现存三座古代九龙壁之一，左边数第三条白龙下方有一块木头，据说是烧制琉璃砖瓦弄坏后工匠用木头刷白漆以假乱真。珍宝馆并非单独展厅，院子周围屋子均为展区；此处为乾隆给自己修建的养老院，退休后未放权仍照常上朝办公。皇极殿1:1复刻乾清宫，宁寿宫对标坤宁宫，乐寿堂为故宫唯一能进去参观的皇家寝室，有二龙仙楼设计；珍妃井为当年慈禧将珍妃丢入之处，现井口石非珍妃进入的入口。出口商店有3枚免费印章。
- **东筒子夹道**：拍照出片的长夹道。
- **延禧宫、景仁宫**：延禧宫为网红打卡地，景仁宫为甄嬛被封熹妃时所住，珍妃也曾居住。
- **御花园**：钦安殿供奉真武大帝，紫禁城靠山景山从天上酷似闭目盘坐人像，有人说该造型即真武大帝。
- **神武门**：故宫北门，出门左手边有两个盖章点——角楼咖啡2枚免费印章、故宫文创2枚免费印章。

# 互动与体验
- **盖章互动**：讲解中标注了七处免费盖章点，包括保和殿东北角汉字馆4枚、坤宁宫东北角文创店5枚、储秀宫旁文创店3枚、冰窖书吧3枚、珍宝馆出口商店3枚、神武门外角楼咖啡2枚及故宫文创2枚免费印章。
  - **汉字馆**：可购买《紫禁城100》并现场盖章，工作人员现场操作，印章数量为各店最多；购买后不能去其他店铺盖章，需有所取舍。
  - **冰窖书吧**：印章造型独特，盖章时有“批折子”的感觉；讲解者在此购买了冰溪图。
- **文创雪糕**：箭亭旁商店可购买文创雪糕，讲解者以提问方式引导观众猜测雪糕造型人物，并邀请在评论区分享。
- **拍照打卡**：太和门铜狮子造型威武，讲解者建议单独拍张照即可，不建议站在狮子底下合影；东筒子夹道拍照非常出片，是很多游客喜欢来的打卡地。
- **个人感受**：钟表馆展品造型令人“开了眼”；珍宝馆内宝贝惊艳，但游客太多，尤其是看凤冠的区域“没点技术还真挤不进去”；珍宝馆是故宫唯一能进去参观皇家寝室（乐寿堂）的地方。

# 收获与建议
- **择时与排队**：建议早起排队，一进门就沿中轴线往里冲，可错开大批旅游团人群；等大部队到达时，已能在人少时逛完最重要的几个景点。讲解者实测进门一小时后游客明显增多。
- **路线选择**：提供三条游览路线，按时间与体力自行选择。
  - **全天路线**：走完视频内所有景点，适合打算在故宫待上一整天的游客，全程约3万步。
  - **半天路线**：沿中轴线至坤宁宫后，参观景仁宫、延禧宫、钟表馆、珍宝馆，再至御花园，从神武门出，约半天时间。
  - **省力路线**：沿中轴线至坤宁宫后去储秀宫，再至御花园，从神武门出，约2小时，适合时间有限、不想走太多路的游客。
- **盖章点汇总**：讲解共标注**7处**免费盖章位置，各点印章数量与特色不同。
  - **保和殿东北角汉字馆**：4枚免费印章，可购买《紫禁城100》现场盖章，据称印章数量最多。
  - **坤宁宫东北角文创店**：5枚免费印章。
  - **储秀宫旁文创店**：3枚免费印章。
  - **冰窖书吧**：3枚免费印章，盖章时有批折子的感觉。
  - **珍宝馆出口商店**：3枚免费印章。
  - **神武门外角楼咖啡**：2枚免费印章。
  - **神武门外故宫文创店**：2枚免费印章。
- **盖章注意事项**：故宫内不止一处可购买《紫禁城100》，但每家店印章不同，购买后不能去其他店铺盖章，需提前做好取舍。
- **饮食与休息提醒**：全天路线一天走3万步，游览过程中需适当休息和补充水分。
- **拍照建议**：太和门门口铜狮子造型威武，但站在其底下时爪子正好盖在头顶，建议单独给狮子拍照即可，不必合影。
- **珍宝馆参观提示**：珍宝馆并非单独展厅，院子周围各屋均需入内参观；游客较多，尤其看凤冠处拥挤，需有耐心挤进去。
- **其他提示**：陶瓷馆（武英殿）目前关闭，只能在门口看看；文华殿讲解者到访时未开放，据称现有一个展览可关注。
