# 参观概况
本次参观以故宫为对象，围绕保姆级游览攻略展开，由主讲人沿中轴线及东西两路依次讲解午门、太和门、太和殿、中和殿、保和殿、乾清门、乾清宫、交泰殿、坤宁宫、储秀宫、慈宁宫、断虹桥、武英殿、文华殿、箭亭、钟表馆、珍宝馆、御花园等主要景点，穿插历史典故与建筑特色。午门呈明三暗五的门洞结构，中间正门仅供皇帝行走，皇后大婚时可进一次，殿试前三名可出一次；太和殿是举行登基、册封等盛大典礼的场所，并非上朝之地；保和殿自乾隆五十四年起作为殿试考场；乾清宫为皇帝寝宫，内有27张龙床，牌匾后藏立储诏书；坤宁宫为皇后住所，明朝所有皇后均居于此；储秀宫为慈禧居住20多年的地方，现为慈禧五十大寿原状陈列。讲解同时介绍了故宫内多个免费盖章点及紫禁城100的购买与盖章规则，并总结三条游览路线，分别适合全天、半天和短时游览，建议早起排队错开旅游团人群。

# 核心看点与讲解
- **午门**：排队检票处即午门，明朝皇帝在此杖打犯错大臣，清朝皇帝在此举行颁朔之礼颁发次年历书。午门正面三个门洞，进门后可见五个门洞，即“明三暗五”。中间正门仅供皇帝行走，皇后大婚时可进一次，殿试前三名（状元、榜眼、探花）可出一次；两侧门洞走皇亲国戚和文武百官。
- **太和门广场**：进入后为太和门广场，眼前有五座金水桥，皇帝走中间，黄金国器走挨着中间的两座桥，文武百官走最边上。
- **太和门**：明朝皇帝在此御门听政，即上朝之处。门口铜狮子为故宫六对铜狮中最大的一对，脚踩寰宇象征权力，不建议站在其下合影，单独拍照即可。
- **太和殿**：即金銮殿，但并非上朝之地，而是举行盛大典礼的场所，如皇帝登基、皇后册封，文武百官在太和殿广场向皇帝高呼“吾皇万岁万岁万万岁”。百官站位遵循“文东武西”，文官站东边，武官站西边。西边弘义阁为皇帝银库，东边体仁阁为缎库。
- **中和殿**：位于太和殿后，是举行盛大典礼时皇帝的休息室，文武百官站好后皇帝再前往太和殿。
- **保和殿**：自乾隆五十四年起为科举考试殿试考场。东北角有汉字馆，内有4枚免费印章，可购买《紫禁城100》并现场盖章；故宫不止一处可购买此书，每家店印章不同，购买后不能去其他店铺盖章，汉字馆印章数量据称最多，盖完后可邮寄到家或自行带走。
- **乾清门**：过此门即后宫区域。过去皇帝在此上早朝，东边九卿直房为等级高的大臣等待皇帝召见之处，西边为军机处。门口两尊狮子耳朵耷拉、眉毛遮眼，意在警示后宫之人“不该看的别看，不该听的别听”。
- **乾清宫**：皇帝平时睡觉之处，内有27张龙床，据说是为防止刺客找到皇帝位置。殿内“正大光明”牌匾后藏皇帝立储诏书，皇帝写两份诏书，一份藏于牌匾后，驾崩后取出对比，若名字不一致则说明诏书被动过手脚。门口有铜鹤与铜龟，旁边有社稷江山金殿，为紫禁城最小宫殿，寓意将江山社稷、百姓民生放在首位。
- **交泰殿**：内放25块传国玉玺。
- **坤宁宫**：皇后住所，明朝所有皇后均居于此。东北角文创店有5枚免费印章。
- **储秀宫**：慈禧居住20多年的地方，现为慈禧五十大寿时期原状陈列，慈禧因儿子在此出生而偏爱此处。旁边文创店有3枚免费印章。
- **翊坤宫与永寿宫**：往南即翊坤宫和永寿宫，永寿宫西边为太极殿，是东西六宫中唯一被称为“殿”的宫殿。
- **慈宁宫与寿康宫**：慈宁宫为康熙为奶奶孝庄皇太后修建的养老院，旁边寿康宫为甄嬛（剧中人物）居住之处。
- **冰窖书吧**：内有3枚免费印章，印章造型有批折子的感觉，可购买冰嬉图。
- **断虹桥**：网红打卡地，桥上有形态各异的石狮子，最有名的为“捂裆狮”。
- **武英殿**：往西即武英殿，后改为陶瓷馆，目前关闭状态，只能在门口观看。
- **文华殿**：往东穿过太和门广场即文华殿，与武英殿对应“文东武西”格局，参观时未开放，据说现有展览。
- **箭亭**：清朝皇帝及子孙练习骑马射箭之处，旁边商店可购买文创雪糕。
- **钟表馆**：展示清代钟表造型，令人开眼界。
- **珍宝馆**：强烈建议参观，实为宁寿全宫，是乾隆为自己修建的养老院，乾隆退休后未放权，仍每日上朝办公。馆内并非单独展厅，院子周围屋子均需参观，展品惊艳但游客众多，尤其看凤冠需挤入。馆内皇极殿据称1:1复刻乾清宫，宁寿宫对标坤宁宫，养性殿后为乐寿堂，是故宫内唯一能进入参观的皇家寝室，有二龙戏珠设计。再往后为珍妃井，当年慈禧将珍妃丢入此处，现井口石非珍妃坠入之处。珍宝馆门口有我国现存三座古代九龙壁之一，左边数第三条白龙下方有一块木头，据说是当年烧制琉璃时弄坏一块，工匠为保命用木头刷白漆以假乱真。
- **东筒子夹道**：从珍宝馆出口出来可见，拍照出片，出口右手边商店有3枚免费印章。
- **延禧宫与景仁宫**：沿东筒子夹道往南即网红打卡地延禧宫，旁边景仁宫为甄嬛被封熹妃时所住，珍妃也曾居住。
- **御花园**：内有钦安殿，供奉真武大帝；紫禁城靠山景山从天上看酷似闭目盘坐人像，有人说此造型即真武大帝。
- **神武门**：故宫北门，游览终点。出门左手边有两个盖章点：角楼咖啡有2枚免费印章，故宫文创有2枚免费印章。

# 互动与体验
- **免费盖章**：保和殿东北角汉字馆有4枚免费印章，可购买《紫禁城100》并现场盖章；坤宁宫东北角文创店有5枚免费印章；储秀宫边文创店有3枚免费印章；冰窖书吧有3枚免费印章；珍宝馆出口商店有3枚免费印章；神武门出门左手边角楼咖啡有2枚免费印章，故宫文创有2枚免费印章。
- **盖章规则**：故宫不止一处可购买《紫禁城100》，每家店印章不同，购买后不能去其他店铺盖章，需有所取舍；据称汉字馆印章数量最多，盖完后可选择邮寄到家或自行携带。
- **文创雪糕**：箭亭旁商店可购买文创雪糕，主讲人提问雪糕造型人物身份，邀请观众在评论区分享。
- **拍照建议**：太和门门口铜狮子为故宫六对铜狮中最大的一对，不建议站在狮子下方合影，因其大爪子正好盖在头顶，建议单独给狮子拍照。
- **网红打卡**：断虹桥为网红打卡地，桥上有形态各异的石狮子，其中最有名的是“武当狮”，可寻找其位置；东筒子夹道拍照非常出片，受许多游客喜爱；延禧宫为网红打卡地。
- **影视联动**：寿康宫为甄嬛居住地，喜欢《甄嬛传》的游客可前往打卡；乐寿堂为故宫内唯一能进去参观的皇家寝室，内有二龙戏珠设计，令人联想到恭王府和珅的卧室。
- **个人体验**：主讲人在冰窖书吧购买了一本冰溪图，因已购买《紫禁城100》；珍宝馆游客非常多，尤其是看凤冠的区域，没点技术很难挤进去；一天走完所有景点约3万步，游览过程中需适当休息和补充水分。

# 收获与建议
- **择时与排队**：建议早起排队，一进门就沿中轴线往里冲，可错开大批旅游团人群；等大部队到达时，已在人少时逛完最重要的几个景点。
- **路线选择**：主讲人总结三条游览路线，可按自身情况选择。
  - **全天路线**：走完视频内提到的所有景点，适合打算在故宫待上一整天的游客，一天约走3万步。
  - **半天路线**：进门沿中轴线往后走，看完坤宁宫后去景仁宫和延禧宫，接着逛钟表馆和珍宝馆，出来直奔御花园，从神武门出，约半天时间。
  - **省力路线**：进门沿中轴线往后走，看完坤宁宫后去储秀宫，出来去御花园，从神武门出，约2小时，最省力，适合时间有限、不想走太多路的游客。
- **盖章点汇总**：故宫内共有七个可免费盖章的位置。
  - **保和殿东北角汉字馆**：4枚免费印章，可购买《紫禁城100》并现场盖章，据称此处印章数量最多。
  - **坤宁宫东北角文创店**：5枚免费印章。
  - **储秀宫边文创店**：3枚免费印章。
  - **冰窖书吧**：3枚免费印章，盖章时有批折子的感觉。
  - **珍宝馆出口商店**：3枚免费印章。
  - **神武门出门左手边角楼咖啡**：2枚免费印章。
  - **神武门出门左手边故宫文创**：2枚免费印章。
- **盖章注意事项**：故宫不止一处可买到《紫禁城100》，每家店印章不同；购买后不能去其他店铺盖章，需有所取舍；盖完后可选择邮寄到家或自行携带。
- **饮食与休息提醒**：游览过程中需适当休息和补充水分；冰窖书吧可作休息点，兼有盖章功能。
- **拍照建议**：太和门门口铜狮子虽造型威武，但站在其下拍照时大爪子会盖在头顶，建议单独给狮子拍照即可。
