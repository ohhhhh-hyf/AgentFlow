# 复盘目标与结果概况
本次年会复盘2023年公司经营与团队表现。预期目标为总结发展状况、公布数据、评价员工并发放年终奖。实际结果：年终奖转账总额**226,000元**，全年实际支出（含人员工资、外援配音字幕、租机器）**390万元**，利润率约**24%或27%**，成本控制较差；最高工资（含年终奖）两三人到手达**20万元**，平均工资到手**1万多元**；年终奖总额比去年多**13万多元**，去年干满一年仅四五人，今年达**12人**；公司总量提升但结余到账往下跑，还有**百来万**未收回；老板每人比去年少拿约**10万元**，承担风险亏损**100万元**。会议对全员逐一进行肯定性评价，颁发**最佳新人奖**（红叶子、张扬）、**最佳进步奖**（欧阳小元）、**后期独当一面奖**（刘腾宇）、**最佳员工奖**（游腾宇）、**特别贡献奖**（李海腾），并抽奖。

# 亮点事项
- **账号增长**：郭东辉负责的短视频账号从**6月20日**第一条外出拍摄视频起色，视频号粉丝从**7万**涨至**8万**，小红书从**2000+**涨至**6.4万**，抖音从**2000+**涨至**5.7万**，B站从**3.1万**涨至**7.6万**；变现课程达**7.5分**（满分10分），直播**4-5场**平均在线**5000+**。成功原因：**坚持**（潘老师多次提醒放弃仍坚持）、**破釜沉舟说服外出拍摄**、**数据支撑决策**（每晚8-9点刷竞品直播间）。
- **人才引进**：张扬为公司邀请人才，职业态度和工作能力有目共睹，老板称**2023年最有价值的事就是把他招进来**。
- **员工表现**：刘腾宇获**评价最高**，职业性、专业性、纪律性最好，能完美胜任后期各种类型；红叶子获政委**非常高的评价**，既懂技术又懂英语；张文倩综合能力强，宁波项目完成超预期；宋俊逸编导效率高，首次安排活即获认可。
- **复用经验**：**坚持与破局**（郭东辉在项目低谷时坚持并说服外出拍摄）、**数据驱动**（所有内容决策有数据支撑）、**仪式感建设**（认真准备证书、奖项，增强团队凝聚力）。

# 不足事项
- **成本控制差**：全年实际支出**390万元**，利润率仅**24%或27%**，非常不可观；老板自评**最大问题是老板对关心或关注不够、不够雷厉风行、问题未及时解决**。
- **结余缩水**：公司总量提升但结余到账往下跑，还有**百来万**未收回；老板每人比去年少拿约**10万元**，承担风险亏损**100万元**。
- **账号变现未完成**：重点项目**账号变现**未完成，直播无课程无法变现；郭东辉称重点项目**没有完成**。
- **后期加班多**：后期人员劳累程度高，后半年基本都在加班，晚上、周末均被侵占；老板承认**人不够是最大因素**，是**判断失误**。
- **拍摄参与不足**：钱德峰提出请外援成本高，公司内部凑不出人按机位，很多人以没空、很忙、不想去推脱。
- **商务支持少**：张启表现高于预期，但老板给的支持比较少，几乎没什么项目，靠老板帮忙聊或打理。
