# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷一案，国开行不服云南省高级人民法院2018云民初88号民事判决，向最高人民法院提起上诉。本案由审判员李少平担任审判长，与审判员魏文超、黄年、王海峰、葛洪涛组成合议庭，法官助理张瑞，依法公开开庭审理。庭审中，各方当事人出庭人员身份经核对均符合法律规定，东源煤电、东源煤业、曲靖电力三方合并发表意见。庭审围绕三个争议焦点展开法庭调查与辩论，合议庭休庭评议后提出调解方案，各方当事人均无异议，自愿达成调解协议，法院予以确认并出具调解书。

# 举证与法庭调查
**证据与质证意见**
- 国开行提交2018年9月对曲靖电力公司的融资租赁查询证书：招银租赁质证认为该查询证书不符合要求，依据2014年93号中国人民银行关于融资租赁登记系统的规定，国开行应在抵押时点（2015年12月）进行查询。
- 国开行提交证据第54页、58页东源煤电公司、曲靖电力公司对设备的权属证明材料和股东会决议：国开行主张据此已对设备所有权尽到审慎义务，核查义务仅限于曲靖电力公司。
- 国开行提交证据第108页融资租赁登记信息核查表：国开行主张已按法律法规和行业规范履行核查义务，构成善意取得。
- 招银租赁提交回租设备清单（证据第7页）：国开行质证认为该清单仅载明设备名称和生产厂家，未提及型号，且记载出厂日期为2012年3月1日，与国开行现场调查核实的抵押设备铭牌生产日期（2013年11月、12月、2014年3月）不符，看不出是同一设备。
- 招银租赁提交2013年和2015年审计报告（证据第82页、95页）：国开行质证认为虽为合并报表，但明确载明曲靖电力公司注册资本4亿元且已实缴，招银租赁应当知道设备出资情况。
- 东源方提交2015年12月2日邮件及东源公司融资情况统计表：国开行质证认为该邮件系贷后审查材料，统计表中招银租赁一栏记载抵押类型为不动产抵押，与融资租赁是两个法律概念，看不出东源方履行了告知义务。

**法官询问要点**
- 审判长询问各方如何理解中国人民银行征信中心融资租赁登记的性质及法律后果：国开行认为是行业强制性规范，目的是防范金融风险；东源方认为是行业指导性规范，不当然产生物权后果；招银租赁认为不是法定物权登记，但强化动产权利外观，可能产生对抗效力。
- 合议庭询问融资租赁登记系统的查询方式：国开行称仅能按单位查询；招银租赁称可按公司名称或设备查询，但案涉5套设备因无唯一识别码未登记。
- 合议庭询问案涉5套设备登记时是否登记唯一标识码：招银租赁称唯一标识码不是必填项，设备铭牌上只有型号和参数，无唯一识别码。
- 合议庭询问国开行贷款前审查时内部是否有规定必须查询融资租赁系统并保留未查询到结果的单子：国开行称按央行规定查询了系统，因无记录未保留筛查记录，内部无此规定。
- 合议庭询问各方对融资租赁司法解释第9条第2款举证责任分担的理解：国开行主张按谁主张谁举证原则；招银租赁认为第1、2、4项由出租人举证，第3项由第三人（国开行）举证。
- 合议庭询问若银行通过其他途径知晓设备属融资租赁物，是否仍需查询登记系统：国开行认为查询是基本义务必须做；招银租赁认为仍需通过央行系统查询，因其他方式无法证明。

**双方辩论的争议焦点**
- 争议焦点一：国开行是否尽到审查义务、是否构成善意取得。国开行主张已按央行规定查询融资租赁登记系统，审查义务仅限于抵押人曲靖电力公司，不扩大至关联企业；东源方主张2015年12月2日邮件已告知设备存在融资租赁且用红色标注，国开行应尽注意义务；招银租赁主张国开行未在抵押时点查询登记系统，不构成善意取得。
- 争议焦点二：一审判决对案涉借款罚息复息的计算及起算日期是否认定错误。国开行主张利息自2017年12月21日计算至2018年6月12日，罚息自2018年6月13日计算至2019年2月19日，复利自2018年3月21日计算至2019年2月19日；东源方主张国开行发函要求立即偿还未给合理期限，且罚息不应作为复利计算基数。
- 争议焦点三：东源煤电、东源煤业是否应当连带给付违约金。国开行主张依据借款合同第24条第3项，被上诉人违约应支付千分之一违约金；东源方主张国开行未举证证明违约行为，且未按合同约定先限期纠正，故无权主张违约金。

# 庭审结果
本案争议焦点有三：一是国开行是否尽到审查义务、是否构成善意取得；二是一审判决对案涉借款罚息复息的计算及起算日期是否认定错误；三是东源煤电、东源煤业是否应当连带给付违约金。经合议庭休庭评议，提出调解方案，各方当事人均无异议，自愿达成调解协议，法院予以确认并出具调解书。调解方案主要内容：国开行对东源煤电的债权扣除破产中已清偿本金外，利息、罚息、复利合计6474.4513万元；确定招银租赁对涉案6项设备享有所有权，对应债权数额1377.4137万元，国开行对93项设备有抵押权；招银租赁和国开行对案涉全部发电设备整体盘活处置，变现价款双方各得50%，费用各担50%；若司法变现不能，双方放弃对案涉设备权益，由东源曲靖电力自主生产经营；东源曲靖电力承担设备管理费用并无条件配合司法处置。各方对一审判决第2项、第4项无争议，按判项内容在调解书中确认。一审诉讼费用中对于国开行诉请部分按一审判决执行，对于招银租赁诉请部分由二审法院按规定计算后由国开行承担；二审诉讼费用由法院依法确定后，由国开行和东源煤电各承担50%。本协议签订后，各方之间就本案涉及的问题不再存在任何争议。
