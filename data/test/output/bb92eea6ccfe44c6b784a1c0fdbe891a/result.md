# 就诊概况
患者张春和，男，48岁，因上腹反复烧灼痛4年、近3个月加重伴两次黑便及呕吐，就诊于消化内科。严医生接诊，初步判断需排查消化道出血及胃部病变，已安排留大便检查并预约后天胃镜，将向上级张医生汇报后商定治疗方案。

# 诊断与检查结果
医生初步判断为上腹烧灼痛可能与胃部疾病相关，需进一步检查明确。关键异常：近3个月两次黑便（一次一年前、一次三个月前），每次持续约一个月，大便干、形状正常仅颜色改变，两次均住院后大便转黄，提示可能存在消化道出血；近两个月呕吐酸水样物，含早晨或中午所食，偶有隔夜食物，呕吐物无红色或黑色。既往16岁患甲肝（三医院住院一个月，已愈），磺胺药过敏史。检查安排：留大便查潜血，预约后天胃镜。

# 治疗方案与医嘱
- **检查安排**：留大便做检查，排查出血；预约后天做胃镜（因患者爱人后天可请假陪同）。
- **用药**：近期服用斯达舒（初每天两次每次一颗有效，现加至每天四五次效果不佳）、奥美拉唑（武汉药厂产，国产）、阿莫西林及医务室自配胃炎合剂，服药好转后停药又复发；具体明细见下表。
- **生活方式**：建议戒烟限酒，避免劳累熬夜，因工作紧张、常熬夜可能诱发或加重病情。
- **复诊与陪同**：后天做胃镜，需爱人陪同；医生将总结病情向上级张医生汇报后，再商定下一步处理意见。
