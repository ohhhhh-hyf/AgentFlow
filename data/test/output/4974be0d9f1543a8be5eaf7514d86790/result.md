# 发布会概况
王毅在慕尼黑安全会议上发表演讲，阐述中国推动平等有序世界多极化的主张，提出四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。他强调中国是现行国际秩序的受益者和维护者，反对双重标准，支持联合国核心作用，并愿推动高质量共建“一带一路”与欧盟全球门户战略对接。在回应主持人提问时，王毅表示中国将继续维护联合国权威，遵守联合国宪章宗旨和原则，推动国际秩序更加公正合理；在乌克兰危机上，中国主张通过对话政治解决争端，反对武力和制裁，已提出劝和促谈并同巴西等发起“和平之友”，乐见包括美俄达成的共识在内的一切和平努力，并认为欧洲应发挥重要作用。关于中美关系，王毅表示中国对美政策保持连续性和稳定性，遵循相互尊重、和平共处、合作共赢三原则，愿构建稳定健康可持续的双边关系；但若美方打压遏制，中方将奉陪到底，坚决维护国家主权和正当发展权利。

# 核心信息
王毅在慕尼黑安全会议上发表演讲，指出世界走向多极化是历史必然，中国主张推动平等有序的世界多极化。他提出四点看法：一是倡导平等相待，坚持权利平等、机会平等、规则平等，主张大小国家一律平等，提升发展中国家在国际体系中的代表性和发言权；二是尊重国际法治，维护联合国宪章宗旨和原则，中国加入了几乎所有普遍性的政府间国际组织和600多项国际公约；三是践行多边主义，中国承担超过20%的联合国会费，建成世界上最大的清洁发电体系，提出并落实全球发展倡议、全球安全倡议、全球文明倡议；四是坚持开放共赢，去年中国GDP增长5%，对世界经济增长的贡献率接近30%，愿推动高质量共建“一带一路”与欧盟全球门户战略对接。

# 官方表态
关于国际秩序与规则：王毅回应称，中国是现行国际秩序的受益者，主张维护以联合国为核心的国际体系，遵守以联合国宪章宗旨和原则为基础的国际关系基本准则，这是国际社会的最大公约数。关于乌克兰危机：王毅表示，中俄是正常国家交往，中国不会停止购买俄罗斯油气，因为其他国家无法提供如此巨量的油气满足中国民众需求；中国主张通过对话政治解决争端，反对武力和制裁，已提出劝和促谈，并同巴西等南方国家发起“和平之友”，乐见包括美俄达成的共识在内的一切和平努力，认为欧洲应发挥重要作用。关于中美关系：王毅表示，中国对美政策保持连续性和稳定性，遵循相互尊重、和平共处、合作共赢三原则，愿构建稳定健康可持续的双边关系；若美方打压遏制，中方将奉陪到底，坚决维护国家主权和正当发展权利。
