# 参观概况
本次参观为故宫博物院游览讲解，主讲人于视频中依次介绍午门、太和门、太和殿、中和殿、保和殿、乾清门、乾清宫、交泰殿、坤宁宫、储秀宫、慈宁宫、断虹桥、武英殿、文华殿、箭亭、钟表馆、珍宝馆、御花园等主要景点，涵盖各建筑的历史功能、典故与建筑细节，并穿插明三暗五、文东武西、正大光明牌匾立储等知识。讲解同时总结三条游览路线，分别适合全天、半天与约2小时的行程，并标注故宫内七个免费盖章点及各店印章差异。整体过程以中轴线为主干、东西两路为辅，兼顾历史讲解、文创体验与路线规划，形成一套完整的故宫保姆级游览攻略。

# 核心看点与讲解
- **午门**：排队检票处，明朝皇帝在此杖打犯错大臣，清朝皇帝在此举行颁朔之礼。门洞呈明三暗五格局，中间正门仅供皇帝行走，皇后大婚时可进一次，殿试前三名可出一次，两侧门走皇亲国戚和文武百官。
- **太和门广场**：眼前有五座金水桥，皇帝走中间，黄金国器走挨着中间两座桥，文武百官走最边上。太和门是明朝皇帝御门听政的上朝之处，门口铜狮子为故宫六对铜狮中最大的一对，脚踩寰宇象征权力。
- **太和殿**：即金銮殿，是举行盛大典礼的地方，如皇帝登基、皇后册封，文武百官在太和殿广场高呼万岁。百官站位遵循文东武西，西边弘义阁为皇帝银库，东边体仁阁为缎库。
- **中和殿**：举行盛大典礼时皇帝的休息室，文武百官站好后皇帝再前往太和殿。
- **保和殿**：从乾隆五十四年开始作为科举殿试考场。东北角汉字馆有4枚免费印章，可购买《紫禁城100》现场盖章，各店印章不同，购买后不能跨店盖章。
- **乾清门**：过了此门即后宫生活区域，皇帝在此上早朝。东边九卿直房为大臣等待召见处，西边为军机处。门口狮子耳朵耷拉、眉毛遮眼，警示后宫之人不该看的别看、不该听的别听。
- **乾清宫**：皇帝睡觉之处，据说有27张龙床以防刺客。牌匾「正大光明」后藏立储诏书，皇帝写两份诏书，驾崩后对比验证是否被动过手脚。门口有铜鹤铜龟及紫禁城最小宫殿社稷江山金殿，提醒皇帝把江山社稷放在第一位。
- **交泰殿**：殿内放有25块传国玉玺。
- **坤宁宫**：皇后住所，明朝所有皇后都住于此。东北角文创店有5枚免费印章。
- **储秀宫**：慈禧住了20多年的地方，现为慈禧五十大寿时期原状陈列，慈禧因其子在此出生而偏爱此处。旁边文创店有3枚免费印章。
- **翊坤宫与永寿宫**：翊坤宫和永寿宫位于储秀宫以南，永寿宫西边为东西六宫中唯一被称为殿的太极殿。
- **慈宁宫与寿康宫**：慈宁宫为康熙给奶奶孝庄皇太后修建的养老院，旁边寿康宫为甄嬛居住之处。附近冰窖书吧有3枚免费印章，印章造型有批折子之感。
- **断虹桥**：网红打卡地，桥上有形态各异的石狮子，最有名的为武当狮。往西为武英殿，后改陶瓷馆，目前关闭状态。
- **文华殿**：位于东边，与西边武英殿对应文东武西。主讲人去时未开放，据说现有一个展览。
- **箭亭**：清朝皇帝及子孙练习骑马射箭之处，旁边商店可购买文创雪糕。
- **钟表馆**：展示那个年代的钟表造型，令人开眼界。
- **珍宝馆**：即宁寿全宫，乾隆给自己修建的养老院，退休后未放权仍照常上朝。皇极殿据说是1:1复刻乾清宫，宁寿宫对标坤宁宫。馆内宝贝惊艳但游客众多，尤其凤冠展区拥挤。门口为我国现存三座古代九龙壁之一，左边数第三条白龙下有一块木头，据说是当年烧制琉璃损坏后工匠为保命用木头刷白漆以假乱真。
- **养性殿与乐寿堂**：养性殿后为乐寿堂，是故宫内唯一能进去参观的皇家寝室，有二龙仙楼设计。再往后为珍妃井，现上头为井口石，珍妃并非从那个小眼进去。珍宝馆出口商店有3枚免费印章。
- **东筒子夹道**：长长的夹道，拍照非常出片，沿路往南拐弯即到延禧宫。
- **延禧宫与景仁宫**：延禧宫为网红打卡地，旁边景仁宫为甄嬛被封熹妃时所住，珍妃也住过。
- **御花园**：内有钦安殿供奉真武大帝，紫禁城靠山景山从天上看酷似闭目盘坐人像，有人说造型即真武大帝。
- **神武门**：故宫北门，游览终点。出门左手边角楼咖啡有2枚免费印章，故宫文创也有2枚免费印章。

# 互动与体验
- **盖章体验**：保和殿东北角汉字馆有4枚免费印章，可现场购买《紫禁城100》并由工作人员盖章，据说此处印章数量最多；故宫内不止一处可买到《紫禁城100》，每家店印章不同，购买后不能去其他店铺盖章，需有所取舍；盖完后可选择邮寄到家或自行携带。
- **盖章体验**：坤宁宫东北角文创店有5枚免费印章；储秀宫边文创店有3枚免费印章；冰窖书吧有3枚免费印章，盖章时有批折子的感觉；珍宝馆出口商店有3枚免费印章；神武门出口左手边角楼咖啡有2枚免费印章，故宫文创也有2枚免费印章。
- **打卡体验**：断虹桥是网红打卡地，桥上有形态各异的石狮子，其中最有名的是「武当狮」，可自行寻找；东筒子夹道拍照非常出片，是很多游客喜欢来的地方；慈宁宫旁寿康宫是甄嬛居住地，喜欢《甄嬛传》的游客可到此打卡。
- **文创体验**：箭亭旁商店可购买文创雪糕，主讲人邀请观众在评论区分享雪糕造型对应的历史人物；冰窖书吧购买了冰溪图。
- **参观感受**：珍宝馆虽名为馆，但并非单独展厅，院子周围屋子均可参观，每件展品都令人惊叹；馆内游客非常多，尤其看凤冠需挤进去；乐寿堂是故宫内唯一能进去参观的皇家寝室，内有二龙戏珠设计，令人联想到恭王府和珅的卧室。
- **参观感受**：武英殿陶瓷馆目前关闭，只能在门口看看；文华殿当时未开放，据说现有一个展览可参观。

# 收获与建议
## 游览路线与时间安排

- **第一条路线（全天深度游）**：走完视频内提到的所有景点，早起排队一进门就沿中轴线往后走，适合打算在故宫待上一整天的游客；主讲人实测一天走3万步，提醒游览过程中适当休息和补充水分。
- **第二条路线（半天游）**：进门沿中轴线往后走，看完坤宁宫后去景仁宫和延禧宫，紧接着逛钟表馆和珍宝馆，出来直奔御花园，从神武门出，约半天时间逛完。
- **第三条路线（省力速览）**：进门沿中轴线往后走，看完坤宁宫后去储秀宫，出来去御花园，然后从神武门出，预计2小时左右逛完，是最省力的路线。
- **错峰建议**：建议早到排队，进门后先冲中轴线，可错开大批旅游团人群，等大批游客到达时已在人少时逛完最重要的景点。

## 知识增量与实用信息

- **午门功能**：明朝皇帝在此杖打犯错大臣，清朝皇帝在此颁发第二年历书（颁朔之礼）；午门三个门洞进门后变五个，即「明三暗五」；中间正门仅供皇帝行走，皇后大婚时可进一次，殿试前三名（状元、榜眼、探花）可出一次，旁边两门走皇亲国戚和文武百官。
- **太和门与太和殿**：太和门是明朝皇帝御门听政（上朝）的地方，门口铜狮为故宫六对铜狮中最大一对，脚踩寰宇象征权力；太和殿是举行盛大典礼（皇帝登基、皇后册封）的场所，并非上朝之地，文武百官在太和殿广场朝拜，站位为「文东武西」。
- **中和殿与保和殿**：中和殿是盛大典礼时皇帝的休息室；保和殿从乾隆五十四年起为殿试考场。
- **乾清门与乾清宫**：乾清门是皇帝上早朝的地方，东边九卿直房为等级高的大臣等待召见处，西边为军机处；门口铜狮耳朵耷拉、眉毛遮眼，警示后宫之人「不该看的别看，不该听的别听」；乾清宫为皇帝寝宫，据说有27张龙床以防刺客，「正大光明」牌匾后藏立储诏书，皇帝驾崩后与另一份诏书比对以防篡改。
- **坤宁宫与交泰殿**：坤宁宫为皇后住所，明朝所有皇后都住于此；交泰殿内放有25块传国玉玺。
- **储秀宫与慈宁宫区域**：储秀宫为慈禧住了20多年的地方，现为慈禧五十大寿原状陈列，慈禧因儿子在此出生而偏爱此处；慈宁宫是康熙为奶奶孝庄皇太后修建的养老院，寿康宫为甄嬛（剧中人物）居住地。
- **珍宝馆与宁寿全宫**：珍宝馆实为宁寿全宫，是乾隆给自己修建的养老院，乾隆退休后未放权仍照常上朝办公；皇极殿据称1:1复刻乾清宫，宁寿宫对标坤宁宫；乐寿堂是故宫内唯一能进去参观的皇家寝室，有二龙仙楼设计；珍妃井现放井口石，珍妃并非从该小眼进入。
- **九龙壁细节**：珍宝馆门口为我国现存三座古代九龙壁之一，左边数第三条白龙下方有一块木头，据传因当年烧制琉璃砖瓦时弄坏一块，工匠为保命用木头刷白漆以假乱真。
- **其他景点知识**：断虹桥石狮子中「武当狮」最有名；武英殿改为陶瓷馆但目前关闭；文华殿据称有展览；箭亭为清朝皇帝及子孙练习骑马射箭处；御花园钦安殿供奉真武大帝，与景山酷似闭目盘坐人像的造型相呼应；东筒子夹道拍照出片，延禧宫为网红打卡地，景仁宫为甄嬛被封熹妃时所住、珍妃也曾居住。
- **文创推荐**：箭亭旁商店可购买文创雪糕；冰窖书吧可购买冰溪图。
