# 就诊概况
48岁男性患者张春和，在成都轻工研究所从事科研工作，于消化内科门诊就诊。主诉上腹烧灼痛4年、近3个月加重，伴两次黑便及近期反酸呕吐。医生初步判断需排查消化道出血及幽门梗阻可能，建议留大便查潜血并预约胃镜。

# 病史与背景
- **现病史**：上腹心窝处烧灼感疼痛4年，每年春季多发，近3个月加重；进食冷、硬、辛辣食物或工作紧张劳累时诱发，白天发作，无夜间痛醒，疼痛可忍受，有完全不痛的时候。
- **黑便史**：一年前及三个月前各出现一次黑便，每次持续约一个月，均住院数日好转；近3个月大便正常，无黑便。
- **反酸呕吐**：近2个月出现数次呕吐，呕吐物为酸水，含早晨或中午食物，有时含隔夜食物，呕吐后舒适。
- **既往史**：16岁患甲肝，在三医院住院一个月，出院及此后体检肝功能均正常；小时候因扁桃体炎在儿童医院就诊。
- **过敏史**：小时候因扁桃体炎服用磺胺药后左手起红疹，持续半个月，诊断为药物过敏，此后禁用磺胺药。
- **家族史**：父亲76岁有低血压，母亲75岁有冠心病，弟弟身体健康；婶婶（叔叔的爱人）患胃癌，患者担心自己是否也会得胃癌。
- **个人史**：吸烟，以前每天一包，现限制在10支以内，计划逐步戒烟；偶尔饮酒，平时不喝，应酬时少量；每天喝两杯淡茶；双眼近视400度，偶尔口腔溃疡。
- **近期用药**：近期服用斯达舒，最初一天两次每次一颗有效，后效果不佳，现加至每天四五次仍效果不好；还服用过奥美拉唑（武汉药厂产，国产）和阿莫西林，以及医务室自配的胃炎合剂，服药好转后停药则症状反复。

# 诊断与检查结果
医生初步判断患者上腹烧灼痛与饮食及劳累相关，结合两次黑便史需排查消化道出血，反酸呕吐物含隔夜食物提示可能存在幽门梗阻。尚未进行胃镜及大便潜血检查，待检查后由上级张医生（指导教授）进一步判断。

# 治疗方案与医嘱
- **检查安排**：留大便做潜血检查，以排查出血；预约胃镜，因患者爱人后天可请假陪同，改至后天进行。
- **生活方式**：建议戒烟、尽量少喝酒，因吸烟饮酒对胃肠道疾病有影响；注意休息，避免熬夜劳累。
- **复诊与陪同**：胃镜后天进行，由爱人陪同；医生将向上级张医生汇报病情后，再商定下一步处理意见。
