# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷二审。合议庭由审判长及审判员组成，公开开庭审理。庭审围绕抵押权与融资租赁所有权冲突、罚息复利计算、违约金连带给付三个争议焦点展开调查与辩论，各方充分发表意见后，合议庭提出调解方案，各方均无异议，合议庭确认调解协议并出具调解书。

# 举证与法庭调查
## 举证与质证
- **2015年12月2日邮件及融资情况统计表（东源公司）**：东源公司主张该邮件已告知国开行抵押设备存在融资租赁，设备名称完全相同且用红色标注，国开行应尽注意义务；国开行代理人辩称该邮件系常规贷后审查，正文及附表均无融资租赁字样，统计表中招银租赁一栏记载的抵押类型为不动产抵押，与融资租赁概念不同，无法得出已告知的结论。
- **回租设备清单（招银租赁一审提交）**：国开行代理人指出该清单仅载明设备名称和生产厂家，未提及设备型号，且清单提示2012年3月1日，而抵押设备铭牌生产日期均在2013年以后，无法认定为同一设备。
- **2018年核查表（国开行）**：国开行主张2018年再次核查时曲靖电力公司名下仍无融资租赁登记，已尽审慎义务；招银租赁代理人认为该查询证书不符合2014年93号文规定，国开行在抵押时点未进行相应查询。
- **审计报告（招银租赁一审提交）**：国开行代理人指出招银租赁提交的2013年和2015年审计报告（证据82页、95页）载明曲靖电力公司注册资本4亿元且已实缴，证明设备出资事项已载明，招银租赁知道或应当知道设备出资情况。
- **上海中院一审判决（招银租赁）**：国开行代理人认为该判决仅限东源公司对设备的返还义务，未确认所有权归招银租赁，与本案抵押权审理不冲突。

## 证人、鉴定与其他来源陈述
- **评估报告**：国开行代理人引述评估报告内容，称报告明确曲靖电力公司拥有的在建工程价值5.7亿元、机械设备价值5.1亿元，虽未纳入资产负债表，但不影响资产归属。

## 法官询问
1. **【融资租赁登记查询方式】**：审判员询问国开行和招银租赁，央行融资租赁登记系统的查询方式能否保证查询到登记结果。国开行代理人称目前只能按单位名称查询；招银租赁代理人称可通过公司名称或设备情况两种方式查询，但设备查询涉及种类物区分问题。
2. **【贷款审查内部规定】**：审判员询问国开行，贷款前审查是否有内部规定要求必须查询融资租赁登记，未查到结果时是否需将未查到单子作为风控材料。国开行代理人称按央行规定需做筛查，但因无查询结果未保留筛查记录，且至今系统仍无登记。
3. **【设备唯一标识码必填性】**：审判员询问招银租赁，融资租赁登记系统中设备唯一标识码是否必填项。招银租赁代理人称不是必填项，因设备不像汽车有发动机号，铭牌上只有型号和参数。
4. **【查询通知性质及违反后果】**：审判员询问国开行和招银租赁，查询通知规定银行办理抵押前应查询，违反该规范会导致何种后果。国开行代理人认为这是基本查询义务，依据最高院融资租赁司法解释第九条第三款，金融机构取得善意权利应查询；招银租赁代理人认为这是对银行业的严格要求，未查询即违反行业规范。
5. **【融资租赁司法解释第九条举证责任】**：审判员询问各方对融资租赁司法解释第九条的理解。招银租赁代理人认为应依谁主张谁举证原则，第一、二、四款由出租人举证，第三款由第三人（国开行）证明办理抵押时已查询。
6. **【不同登记机构产生登记瑕疵的看法】**：审判长询问各方对因不同登记机构产生登记瑕疵的看法及建议。国开行代理人认为系统信息不完整是整体问题，动产抵押登记与融资租赁登记缺乏联通，可能形成恶性循环；东源公司代理人表示非专业机构，提供不了建议；招银租赁代理人建议从立法层面统一规范，发挥行业协会作用，技术上实现登记平台统一。

## 争议焦点与辩论
- **争议焦点一：抵押权与融资租赁所有权冲突**。国开行主张其审查义务仅限于抵押人曲靖电力公司，已尽审慎义务，构成善意取得；东源公司称2015年12月2日邮件已告知抵押设备存在融资租赁，国开行未予注意；招银租赁称2012年即取得设备所有权，国开行2015年抵押登记在后且未查询融资租赁登记，不构成善意。各方对央行融资租赁登记性质存在分歧：国开行认为属行业强制性规范，招银租赁认为非强制，东源公司认为属行业指导性规范。
- **争议焦点二：罚息、复息计算**。国开行主张利息计算至2018年6月12日合计2179万5727.08元，罚息自2018年6月13日计算至2019年2月19日为4105万零579.57元，复利自2018年3月21日计算至2019年2月19日为191.8206万元；东源公司认为合同约定限期偿还，不应要求立即偿还，且罚息不应计收复利，并引用《人民币利率管理规定》第21条及最高院判例。
- **争议焦点三：违约金连带给付**。国开行主张依据借款合同第24条第三项，东源煤电违约应支付千分之一违约金；东源公司称国开行未举证东源煤电违反柜台协议，且未发出限期纠正通知；招银租赁表示非合同当事人，尊重合议庭审查结果。

# 庭审结果
1. **调解协议确认**：经本院主持调解，各方当事人自愿达成的调解协议不违反法律规定，本院予以确认，并依据《中华人民共和国民事诉讼法》第97条出具调解书。
2. **债权债务确定**：国开行对东源公司债权扣除破产中已清偿本金后，利息、罚息、复利合计6474.4513万元。
3. **设备权属确认**：招银租赁对涉案六项设备享有所有权，对应债权数额1377.4137万元；国开行对93项设备有抵押权。
4. **设备处置安排**：招银租赁和国开行对案涉全部发电设备整体盘活处置，从变现款中实现各自债权；本案生效后20日内由国开行向一审法院提出执行申请，启动司法变现；变现价格双方各50%，实现费用双方各担50%。
5. **变现不足处理**：变现款不足以清偿债务或变现不能时，招银租赁未实现债权在执行法院裁定后按破产重整计划预留方案清偿，由东源煤电按此前有担保清偿方案予以清偿。
6. **权益放弃条款**：司法变现不能时，国开行和招银租赁放弃对案涉设备权益，由东源曲靖电力自主生产经营。
7. **无争议判项确认**：各方对一审判决第二项、第四项无争议，按判项内容在调解书中确认。
8. **诉讼费负担**：一审诉讼费中国开行诉请部分按一审判决执行，招银租赁诉请部分由二审法院按规定确定，二审诉讼费由本院依法确定。
9. **争议终结**：调解书签订后，各方之间就本案涉及的问题不再存在任何争议。
10. **司法建议**：合议庭将依据《最高人民法院关于加强司法建议工作的意见》向有关部门提出司法建议，推动建立统一动产登记制度。
