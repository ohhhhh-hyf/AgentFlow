# 杭州医学院医学技术专业硕士点招生宣讲会

## 沟通背景与目的
杭州医学院检验医学院、生物工程学院党委书记、副院长宋宝峰副教授做客专场直播，面向考生及家长介绍该校医学技术专业硕士点的招生情况。沟通旨在帮助考生全面了解该学位点的学科建设、研究方向、师资力量、培养模式与就业去向，并解答报考相关疑问。整体基调为招生宣介与答疑，宋宝峰系统介绍了学位点概况与2026年招考安排，并回应了考生关切，整体氛围积极。

## 核心信息与数据
### 学位点基本情况
1. **学位点获批**：医学技术专业硕士点于2024年获批，为新增学位授权点。
2. **共建学院**：由5个学院共同承担培养工作，其中检验医学院、生物工程学院合署办公，另有医学影像学院、康复学院、信息工程学院共建。
3. **专业方向**：聚焦检验技术、医学影像技术、康复治疗、智能医学工程四个方向，其中检验技术细分为医检和卫检两个方向。

### 2025年招生情况
1. **录取人数**：2025年录取64位考生，其中检验方向38人、医学影像方向11人、康复方向13人、智能医学工程方向2人。

### 学科建设情况
1. **学科层次**：医学技术学科2023年获批浙江省一流学科B类。
2. **科研项目**：近五年获国家级基金项目19项、省鉴定领先项目1项。
3. **科研经费**：纵向科研经费1300万元，横向合作课题经费2200多万元。
4. **科技奖励**：获省科技进步一等奖2项、二等奖1项、三等奖2项。
5. **课程与专业**：建成国家级一流本科课程2门、国家级一流本科专业建设点2个。
6. **科研平台**：建有省生物标志物与器官诊断转化重点实验室、检验诊断关键技术质量研究室、康复模块和机器人国际联合实验室、省实验室和安全培训基地、数字化康复装备质量研究中心、脑认知与疾病数字医疗器械质量工程研究中心、浙江省神经系统疾病数字化装备研发重点实验室等省级平台。

### 学科优势
1. **体外诊断领域**：疫情期间与企业联合开发新冠病毒核酸检测、抗原检测、抗体检测三个产品，获NMPA注册；系中华医学会检验医学分会教育学组组长单位、卫生高新技术公司实体开发基地。
2. **医学影像技术**：为国家临床药物验证机构、国家卫健委外周血管介入诊疗培训基地。
3. **康复治疗方向**：依托省人民医院康复医学科，为省内综合医院中建科最早、人才最齐、技术最先进、设备最先进、社会效益最佳的康复医学科之一。
4. **智能医学工程方向**：聚焦阿尔茨海默病智能预警数字生物标志物，居国际领跑水平；系浙江省中医药重点学科、老年助浴疾病数字医疗器械浙江省中心、智能医学前沿交叉学院。

### 主要研究方向
1. **医学检验技术**（负责人吕建新教授）：聚焦重大疾病新型生物标志物筛选及其机制、新发突发传染病新型生物标志物筛选及致病机制、重大疾病体外诊断检测技术、新型药物系统体内治疗易复发难治愈疾病等方向。
2. **卫生检验检疫**（负责人金大志教授）：聚焦新发突发传染病病原体检测检验新技术方法开发，特别是艰难梭菌致病机制、耐药机制、基因组进化及小分子药物开发，以及卫生检验技术研究。
3. **医学影像技术**（负责人徐秀芳教授）：研究方向包括多参数MRI有效指标、肿瘤分子影像学、神经导航引导的脑肿瘤穿刺技术、脑肿瘤术前功能区定位。
4. **康复治疗**（负责人叶祥明教授）：围绕人工智能康复、神经修复、运动技术创新等方向。
5. **智能医学工程**（负责人李凯教授）：聚焦脑认知与脑疾病智能诊疗、健康大数据、脑机接口、中医先进医疗器械、重大疾病智能诊断等。

### 师资队伍与领军人物
1. **总体规模**：专任教师90人，高级职称53人（占30%以上），博士55人；硕导69人，正高35人，博士46人。
2. **吕建新教授**：国家百千万人才工程人选，教育部医学技术类专业教学指导委员会委员，国家自然科学基金医学技术检验学科专家组组长，中华医学会检验学会教育学组组长；主持国家自然科学基金重点项目、科技部重点研发、863计划重点项目、省科技重点研发应急公关项目等十余项，发表高水平论文200多篇，获省科技一等奖3项、优秀教学成果奖2项。
3. **徐秀芳教授**：浙江省151人才第三层次人才，省高校中青年学科带头人，研究生院院长兼医学影像学院院长，国家一流本科专业建设点医学影像技术专业负责人，教育部教指委相关医学分会委员，中华医学会影像技术分会影像技术专委会委员。
4. **叶祥明教授**：省人民医院主任医师、二级教授，博导、博士后导师，省卫生领军人才，国家区域医疗中心浙江省重点培育专科康复医学学科带头人，数字化康复装备省部研究中心常务副主任；主持国家级课题3项、省重大课题2项，发表SCI论文98篇。
5. **金大志研究员**：博士、硕导，美国华盛顿大学博士后、美国MSCC访问学者，省卫生创新人才、省首届优秀医疗机器人才，检验医学院学术院长，省生物标志物体外诊断转化重点实验室主任，中国医师协会临床微生物分会常务委员。
6. **李凯教授**：复旦大学公共卫生学院博士，早稻田大学访问学者，智能医学前沿交叉学科研究院执行院长，智能医学学科负责人，浙江省中医药大学学科带头人；参与国家省级项目，研制全生命周期中医治疗及康复医疗体系设备3台（套）。

### 硕士培养与毕业去向
1. **培养目标**：面向健康中国发展需要，紧密服务区域行业产业发展，围绕国际学术前沿、国际重大需求，培养具有良好创新实践能力的高层次应用型人才。
2. **培养方式**：采用教学、专业实践与学位论文相结合的方式。
3. **学制**：全日制专业学位学制三年，最长不超过五年。
4. **课程学分**：课程学习包括公共学位课、专业学位课和专业选修课；毕业前学业课程不少于24学分，其中专业必修课不少于12学分，专业选修课不少于5-6学分。
5. **就业方向**：可进入医院检验科、输血科、病理科、放射科、超声科、康复医学科等科室，疾控中心，医药企业，医疗器械公司（从事研发、销售、技术支持、质量管理体系建立维护、产品法规统筹合规管理），保险公司（医疗保险核保理赔、健康险产品开发），药监局、卫健委、海关（医疗器械监管、卫生政策制定、口岸卫生检疫），高校研究所继续深造（读博或从事研究工作）。

### 2026年招考计划
1. **计划招生**：2026年计划招生34人，实际以教育部正式下达人数为准。
2. **初试科目**：共三门，包括思想政治理论、英语和一门专业综合（按方向分为检验综合、医学影像技术综合、康复治疗综合、智能医学工程综合）。
3. **专业综合考试**：分值300分，时长180分钟；检验综合中分子生物学检验占40%、生物化学检验占30%、微生物学检验占30%。
4. **复试方式**：采用线上线下结合方式，目前以线下为主；初试成绩占60%、复试成绩占40%。
5. **复试内容**：英语能力测试占20%、专业能力测试占40%、综合能力测试占40%。
6. **参考信息渠道**：考试科目与内容详见学校研究生招生网及杭州医学院研究生教育微信公众号。

## 各方立场与诉求
1. **宋宝峰（杭州医学院检验医学院、生物工程学院党委书记、副院长）**：作为主讲嘉宾，系统介绍医学技术专业硕士点的学位点概况、学科优势、研究方向、师资队伍、培养模式、就业方向及2026年招考计划，并回应考生关切，鼓励报考。
2. **主持人**：引导直播流程，代考生提出就业前景、初试科目、英语难度、跨专业报考资格等具体问题，请宋宝峰逐一解答。
3. **考生及家长（通过主持人代问）**：重点关注就业去向（医院、疾控、企业、监管机构等）、初试科目与参考书、英语考试难度、非本专业能否跨考、校区位置与交通便利性、学科竞赛参与机会等；宋宝峰均予以正面回应，明确允许跨专业报考、英语难度介于四级与六级之间、主校区位于黄龙校区交通便利。

## 达成共识
1. **学位点建设口径已确认**：医学技术专业硕士点于2024年获批，由检验医学院、生物工程学院合署办公，医学影像学院、康复学院、信息工程学院共建，聚焦检验技术（细分为医检、卫检）、医学影像技术、康复治疗、智能医学工程四个方向。

2. **学科实力定位已明确**：医学技术学科2023年获批省一流学科B类，近五年获国家级基金项目19项，纵向科研经费1300万元、横向合作课题经费2200多万元，获省科技进步一等奖2项、二等奖1项、三等奖2项，建成国家级一流本科课程2门、国家级一流本科专业建设点2个。

3. **师资队伍规模与结构已确认**：专任教师90人，高级职称53人（占30%以上），博士55人；硕导69人，正高35人，博士46人。学科领军人物包括吕建新教授、徐秀芳教授、叶祥明教授、金大志研究员、李凯教授。

4. **培养方案口径已确认**：全日制专业学位学制三年，最长不超过五年；培养方式为教学、专业实践与学位论文相结合；毕业前要求学业课程不少于24学分，其中专业必修课不少于12学分、专业选修课不少于5-6学分。

5. **2026年招生计划为参考口径**：计划招生34人，**实际招生人数以教育部正式下达为准**。宋宝峰明确表示：
> “这个招生人数啊仅供这个参考啊，我们要以教育部的2026年这个正式下达的这个人数为准”
> —— **宋宝峰** ｜ 杭州医学院检验医学院生物工程学院党委书记、副院长

6. **初试科目与考试内容已确认**：初试共三门——思想政治理论、英语、专业综合（按方向分为检验综合、医学影像技术综合、康复治疗综合、智能医学工程综合）；专业综合分值300分、时长180分钟；检验综合中分子生物学检验占40%、生物化学检验占30%、微生物学检验占30%。

7. **复试方式与成绩占比已确认**：复试采用线上线下结合方式，目前以线下为主；初试占60%、复试占40%；复试内容为英语能力测试20%、专业能力测试40%、综合能力测试40%。

8. **跨专业报考政策已确认**：允许非本专业考生跨专业报考医学技术专业。
