# 发布会概况
王毅在慕尼黑安全会议上发表演讲，借用今年慕安会报告主题指出世界正走向多极化，并阐述中国主张推动平等有序的世界多极化，这是习近平主席提出的重大主张。王毅提出四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。中国已加入几乎所有普遍性政府间国际组织和600多项国际公约，承担超过20%的联合国会费，建成世界上最大的清洁发电体系，并提出落实全球发展倡议、全球安全倡议、全球文明倡议。去年中国GDP增长5%，对世界经济增长贡献率接近30%。今年是中欧建交50周年，中方愿推动高质量共建'一带一路'与欧盟全球门户战略对接。

# 核心信息
- **多极化主张**：中国主张推动平等有序的世界多极化，这是习近平主席提出的重大主张；中国必将是多极体系中的确定性因素，坚定做变革世界中的建设性力量。
- **四点看法**：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。
- **国际法治**：中国加入几乎所有普遍性的政府间国际组织和**600多项**国际公约，从不搞例外主义，更不搞合则用、不合则弃。
- **多边主义**：中国承担超过**20%**的联合国会费，切实履行巴黎协定，建成世界上最大的清洁发电体系。
- **全球倡议**：提出并落实全球发展倡议、全球安全倡议、全球文明倡议，为完善全球治理提供公共产品。
- **开放共赢**：去年中国GDP增长**5%**，对世界经济增长贡献率接近**30%**，担当全球经济增长的重要引擎。
- **中欧合作**：今年是中欧建交**50周年**，中方愿推动高质量共建'一带一路'与欧盟全球门户战略相互对接。

# 官方表态
- **多极化主张**：王毅表示，多极化的世界既是历史的必然，也正在成为现实；中国给出的答案是推动平等有序的世界多极化，这是习近平主席提出的又一个重大主张。
- **平等相待**：王毅指出，坚持权利平等、机会平等、规则平等，应当成为建设多极世界的基本原则；中国主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权。
- **国际法治**：王毅强调，联合国宪章宗旨和原则是国际关系的根本遵循，也是建设多极世界的重要基石；国家不论大小强弱，都是国际法治的利益攸关方。
- **多边主义**：王毅表示，联合国是践行多边主义、推进全球治理的核心平台，已经为各国遮风挡雨80年；未来的多极世界更加需要联合国，对于这座大厦应该固本强基，而不是拆梁毁柱。
- **开放共赢**：王毅指出，发展是破解各种难题的钥匙，多极世界应该是各国共同发展的世界；保护主义不是出路，滥加关税没有赢家，脱钩断链断的是机遇，小院高墙封的是自己。
- **中欧关系**：王毅表示，中方始终认为欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手。

# Q&A环节
**问**：主持人周琦提问，中国被指控违反海洋法或世界人权宣言，王毅是否仍相信联合国和联合国宪章，是否推动联合国改革？
**答**：王毅表示，中国是现行国际秩序的受益者，要推动秩序朝着更加公正合理的方向发展；主张共同维护以联合国为核心的国际体系，遵守以联合国宪章宗旨和原则为基础的国际关系基本准则，这是最大的公约数。

**问**：主持人引用王毅此前关于尊重乌克兰主权和领土完整的表态，询问中国是否可减少从俄罗斯购买油气或停止双用物品以施压俄罗斯？
**答**：王毅表示，中国从俄罗斯购买油气是正常国与国交往，反问哪个国家能提供如此巨量油气满足中国民众需求；中国在乌克兰问题上主张通过对话寻求政治解决，危机爆发第2天即2022年2月25日中方即提出对话协商解决，习近平主席提出4点主张，中国派特使斡旋，同巴西等南方国家发起和平之友，乐见一切致力于和平的努力，包括美俄达成的共识，并强调所有当事方包括利益攸关方应适时参与和谈，欧洲更有必要发挥重要作用。

**问**：主持人请王毅预告中美关系将如何发展。
**答**：王毅表示，中国对美政策保持连续性和稳定性，对美政策是习近平主席提出的三原则：相互尊重、和平共处、合作共赢；中方已准备好按三原则同美方构建稳定健康可持续的双边关系，若美方仍打压遏制，中方必将奉陪到底，坚决回击单边霸凌行径。
