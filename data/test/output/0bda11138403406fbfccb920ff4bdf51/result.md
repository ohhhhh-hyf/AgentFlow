# 讲座概况
本次讲座由基金经理肖楠主讲，面向机构投资者汇报其过去一年的研究布局、投资框架反思与认知升级，并回答投资者提问。肖楠首先指出投资者普遍关心的“What happen next”类问题因知识鸿沟而用处有限，并基于自身研究框架将问题分为重要不重要、可研究及难以研究四类，强调真正关心的是标的基本面变化、投资逻辑更新、认知深入及投资框架修正。他明确反对市场上“抱团”与“均值回归”两个流行观点，认为抱团定义不本质，均值回归仅是局部正确，长期看收益率呈幂律分布，投资核心在于寻找长线超级大牛股。随后他介绍过去一年在互联网、财富管理、新消费和高端制造四个方向的研究布局，并分享五点投资框架反思，包括商业模式分类的不完备性、从商增角度理解商业模式、长期变量对收益率的影响、深度价值可能长期无效（存疑）以及小企业X factor的重要性。最后，肖楠就投资者关于终局判断、伟大公司标准、全市场基金选股逻辑、血制品行业、农林牧渔行业、商增商减分析、增长曲线、财富管理行业及企业家精神等问题逐一作答。

# 核心观点与论证
讲座围绕“知识与信息的鸿沟”展开，肖楠指出投资者获得的仅是信息而非知识，知识更新会迅速改变判断，因此“What happen next”类答案对投资者用处不大。他基于自身研究框架将问题分为重要不重要、可研究及难以研究四类，强调关心标的基本面变化、投资逻辑更新、认知深入及投资框架修正。

肖楠明确反对“抱团”与“均值回归”两个流行观点。关于抱团，他认为该定义不本质，基金经理之间是竞争关系，主观上不可能抱团；同一公司买同一板块是研究员推荐被广泛认可的结果，而非合谋。关于均值回归，他指出其仅是局部正确，长期看收益率呈幂律分布，并以美国股市200年增量由4%公司贡献为例，强调投资核心是找到长线超级大牛股。

他介绍过去一年在互联网、财富管理、新消费和高端制造四个方向的研究布局。互联网产业是富矿，中国和美国能诞生巨大公司；财富管理行业空间巨大，因中国收入中位数提升将带来巨额剩余财富；新消费公司从CEO到组织架构完全不同于传统企业；高端制造中国在众多细分领域已占据主导地位，未来空间可见。

肖楠分享五点投资框架反思：第一，商业模式分类不完备，没有一劳永逸的坐地收钱生意，长期看所有企业都会死去；第二，从商增角度理解商业模式更本质，企业成长过程中需吸收熵增，商增过快会导致失败；第三，长期变量如国运、文化背景影响收益率，需保持谦卑但大胆思考；第四，深度价值可能长期无效（打问号），因深度价值只是结果，若导致原因不变，最好结果也只是不输；第五，小企业的X factor，即驱动企业增长且不被线性描述的因子，无法定价但必须承认存在，否则会陷入估值与基本面的两难。

# 金句总结
“知识和信息之间有着巨大的鸿沟。”——肖楠以此说明投资者获得的“看好某板块”等信息对其决策用处有限，因为知识更新会迅速改变判断。

“务实还是务虚，其实没有高下之分的。做好的都是大师，做不好都是东施效颦。”——他强调投资理念无好坏，关键在于执行。

“均值回归这个事情，90%的时间都正确，那10%的错误依然让你代价惨重。”——他以商学院老师在海螺水泥上做波段、最终错过两年五六倍涨幅为例，说明均值回归的局限性。

“收益率是幂律分布的，不是正态分布的。”——他以此强调投资核心是找到长线超级大牛股，美国股市200年增量由4%公司贡献。

“我们一定要对市场保持谦卑。”——他提醒投资者注意长期变量对收益率的影响，避免过度归因于个人能力。

“驱动企业增长且不被线性描述的因子，我们即使是没有办法去有效定价，我们也一定要承认它的存在。”——他以此引出X factor概念，强调超额认知的来源。

# Q&A 环节
问：您刚刚讲到在重视终局结果的过程中，也更加关注格局演进的阶段性特征和中期投资机会，能否再详细描述一下？
答：这个想法源于我们过去错过了一些特别大的机会，我们判断这些行业的终局可能不大行，但明明判断对了，却在两三年的时间里错过了十几倍的涨幅。复盘发现，这些企业虽然某一代产品被追上，但做出了第二增长曲线，且壁垒更深。所以我们开始承认终局可能没那么强，但依然能做出好的投资，希望未来不再错过类似机会。

问：您在年报中讲到坚定持有优秀乃至伟大的公司，请问判断标准是否有具体财务指标？
答：伟大公司在财务指标里看不出来。我举例两家公司，A和B都在自己领域把成本做到行业最低，市场份额稳固提升。但B公司不怎么做研发，靠精细化管理；A公司每年高额研发，关键技术指标快速迭代，且从董事长到技术骨干都有强烈的产业报国精神，从跟着日本人、德国人学到超越对手，堪称伟大企业。

问：全市场基金的选股逻辑是什么？消费以外的行业选股基于什么逻辑？
答：我们很难分消费内消费外，选股逻辑都一样，都是基于不可能三角、企业三阶段、三种商业模式等。消费行业只许买消费，所以只能在消费里选，两者逻辑完全一样。

问：您怎么看血制品行业的竞争壁垒？
答：我们初步研究过，觉得壁垒不是特别强，不是我们想要的那种强壁垒，所以没有深入，我们买了另外一些强壁垒的公司。

问：农林牧渔行业持仓有所提升，您对这个行业怎么看？
答：农林牧渔行业提升是因为牧原股份，就那一只股票。不是先看好行业再选牧原，而是牧原比例提高了，就这么简单。

问：能否具体讲一下生意模式里商增和商减的分析？
答：用直白的话讲，企业从小到大，部门越来越多，传达效率变低，内部腐败出现，为解决这些问题又增设部门，导致效率进一步下降。有些生意收入从10亿到100亿，机构没多几个部门；有些企业则被商增拖死。我建议大家读党史，看组织如何保持活力，很多国家和企业都是被商增拖死的。

问：您讲到伟大企业的增长曲线，能否再具体讲一下？
答：有些企业每年看是线性增长，但拉长到10年，会在关键节点突然甩开竞争对手。比如疫情时只有顺丰能送，一下子拉开差距；家电领域美的做渠道扁平化，疫情时占有率突然超过格力。这些企业平时直线发展，但在特殊时刻拐上去，就像下雨时有人带了伞。

问：您讲到财富管理行业，能否具体展开投资逻辑和机会？
答：财富管理行业话题很大，且分层，顶级富豪、中产阶级、中低收入者的财富管理方式不同，商业模式也不同。我们最早研究保险时发现，不同保险公司业务员单均保费差距巨大，背后是结构设置、激励机制、文化的差异。财富分布极不均匀，头部公司可能拿走行业增量的绝大部分，这种偏激分布可能诞生特别大的企业。但受监管和法律限制，我们有些产品暂时不能投类似标的，未来合同设置更清晰时可能会有所体现。

问：您讲到第二第三增长曲线需要卓越的企业家精神，请问观察这个指标有什么心得？
答：第一，评判时要特别小心谨慎，不要乱归因，把所有能归因到客观指标的都归因完，再谨慎评价虚的因素。第二，不要轻易给这些因素定价，绝对不要说因为企业家在，公司就值多少。我们一致同意它不可被定价。这些虚的因素在客观归因穷尽后再考虑，且只能在两两比较中比较企业家水平，不要跨行业比较。要谨慎使用“企业家精神”“伟大企业”等词，避免错误归因。
