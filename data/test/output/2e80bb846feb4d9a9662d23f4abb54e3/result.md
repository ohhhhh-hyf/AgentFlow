# 知识主题与概述
本栏围绕调和级数发散性的证明展开，核心议题是评析Stack Exchange上网友给出的多种证明方法。皮卡首先从高中数学出发，定义了级数收敛与发散的基本判据，随后逐一评析了分组估计、柯西凝聚判别法、积分估计、差分法及Stolz定理等证明路径。整体逻辑框架为：以调和级数发散性为锚点，比较不同证明方法的思路与自然程度，并指出部分技巧性证明存在“先射箭后画靶”的刻意构造痕迹。关键概念与结论的细节留给后续各栏展开。

# 核心概念
## 调和级数与收敛发散定义
- **级数收敛**：对正向级数，若存在固定实数 `a` 作为上界，使得所有前 `n` 项和 `sn` 均小于 `a`（无论 `n` 取多大），则称该级数**收敛**。
- **级数发散**：若存在一个单调递增且无上界的序列 `bn`，使得 `sn` 大于 `bn`，即对任意大的数 `b`，总能通过增大 `n` 使 `bn` 超过 `b`，则称该级数**发散**。
- **调和级数**：形如 `1 + 1/2 + 1/3 + … + 1/n` 的级数，其部分和记为 `hn`（或 `sn`），英文为 `harmonic`，是调和序列的部分和。
- **调和级数发散**：`hn` 无上界，因此调和级数发散；这是高等数学中的经典结论。

## 分组求和与柯西凝聚判别法
- **分组估计法**：将调和级数各项分组，如 `{1}`、`{1/2, 1/3}`、`{1/4, 1/5, 1/6, 1/7}`、`{1/8, …, 1/15}` 等，每组和均大于 `1/2`，因组数无限，故级数发散。
- **柯西凝聚判别法**：其证明思路与分组估计法完全一致——对非负不增序列分组并做上下界估计，从而将原级数的收敛发散性转化为凝聚后序列的收敛发散性。
- **凝聚判别法应用**：对 `∑1/n` 应用该判别法，等价于判断 `∑(2^k × 1/2^k) = ∑1` 的收敛性，而无穷个 `1` 相加显然无上界，故发散。
- **分组求和思想**：高斯幼年计算 `1+2+3+…+100` 时，采用 `1+100=101`、`2+99=101` 的分组配对法，只需数出有多少个 `101` 即可；在求和或估计问题中，若能发现具有良好性质（如和恒定、满足估计要求）的组，问题即可简化。

## 积分估计法
- **积分近似思想**：`hn` 从几何上可视为一系列高为 `1/n`、底为 `1` 的矩形面积之和，这些矩形始终大于对应曲边梯形（即 `1/x` 曲线下的面积），故 `hn` 大于积分 `∫₁ⁿ⁺¹ 1/x dx = log(n+1)`。
- **发散结论**：`log(n+1)` 无上界，因此 `hn` 也无上界，级数发散；该方法属于**和的积分估计**流派。

## 差分法与指数放缩
- **指数放缩法**：利用 `e^(1/k) > 1 + 1/k`（即 `e^x > 1+x`），对 `e^(hn)` 做放缩，将和转化为连乘积。
- **连乘积化简**：`∏(1 + 1/k) = ∏((k+1)/k)`，相邻项相消后等于 `n+1`，从而证明 `hn > log(n+1)`。
- **对数差分关系**：该方法与对数不等式 `log(k+1) - log(k) < 1/k` 的差分求和本质相同——两边取对数后即为上述指数放缩法，两种表述完全等价。

## Stolz定理证明的批评
- **Stolz定理**（中文亦称 `stolz` 定理）：当分子分母均为无穷大时，可通过比较差分 `(aₙ₊₁ - aₙ)/(bₙ₊₁ - bₙ)` 的极限来求 `aₙ/bₙ` 的极限。
- **应用方式**：证明 `hn/log n` 的极限为 `1`，其差分分别为 `1/(n+1)` 和 `log(1 + 1/n)`，两者比值极限为 `1`，故 `hn` 与 `log n` 同增长级别，`log n` 无上界，所以 `hn` 发散。
- **不自然之处**：该方法需预先知道 `hn` 与 `log n` 同阶这一结论才能构造差分，属于**先射箭后画靶**；若不知道结果，没有理由选择 `log n` 而非 `log log n` 的平方或 `√n` 作为比较对象。
- **调和级数基本估计**：`log(n+1) < hn < log n + 1`，两边除以 `log n` 后取极限即得 `hn/log n → 1`；但证明该不等式仍需回到积分估计等方法，并非独立的新方法。

# 核心结论
## 核心结论

- **调和级数发散**：级数 ∑1/n（即 1+1/2+1/3+…+1/n+…）是发散的，不存在一个固定实数上界能控制其所有部分和。
- **收敛与发散的定义**：对正项级数，若所有部分和 sn 都小于某个固定实数 a（无论 n 取多大），则收敛；若部分和大于某个单调递增且无上界的 bn，则发散。
- **第一个网友的证明**：将调和级数分组（1 单独一组、1/2+1/3 一组、1/4+1/5+1/6+1/7 一组、1/8～1/15 一组……），每组和都大于 1/2，而组数无限，故部分和无上界，级数发散。
- **柯西凝聚判别法**：对非负不增序列，其级数收敛发散性质等价于加速后的序列 ∑2^k·a(2^k)；用于调和级数时，等价于 ∑2^k·(1/2^k)=∑1，即无穷个 1 相加，显然发散。
- **第二个网友的证明**：证明 hn > log(n+1)，因 log(n+1) 无上界，故 hn 也无上界，级数发散。
- **积分估计法**：用积分曲线面积近似 hn，矩形面积始终大于下方曲边梯形面积，可推出 hn > log(n+1) 的下界。
- **差分法**：利用 e^(1/k) > 1+1/k，将 e^hn 放缩为连乘积 ∏(1+1/k)，相邻项相消后等于 n+1，从而证明 hn 发散。
- **Stolz 定理证明**：通过 hn/log n 的差分（分子差分为 1/(n+1)，分母差分为 log(1+1/n)）求极限为 1，从而证明 hn 与 log n 同增长级别，log n 无上界故 hn 发散。

## 易混点与适用边界

- **收敛与发散判断的适用前提**：上述简化判断仅适用于正项级数（原文明确「因为是正向技术，所以我们只需要考虑两个判断」）。
- **柯西凝聚判别法的适用条件**：仅适用于非负不增序列；其证明思路与分组求和完全一致，本质是分组后对每组做上下界估计。
- **积分估计法的几何边界**：矩形面积始终大于曲边梯形面积，故 hn 大于积分值；该放缩方向是单向的（只给出下界）。
- **差分法对微积分的依赖**：e^(1/k) > 1+1/k 本身需用微积分证明，而微积分建立在极限之上；原文指出也可用不等式 (1+1/k)^k < e 在不用微积分的情况下操作，但用微积分更简单。
- **Stolz 定理的适用前提**：适用于分子分母均为无穷大的情形，通过比较差分极限来求原极限；但原文强调该证明「不自然」，因为需要预先知道 hn 与 log n 同阶这一结果才能构造差分，属于「先射箭后画靶」。
- **log 记号的地区差异**：原文指出 log 是美国写法，ln 是欧洲写法（经苏联传入中国），两者指同一函数。
- **常见误区**：皮卡批评某些证明「故弄玄虚」——用障眼法包装简单本质，妨碍理解但让人感觉 magic；差分法看似巧妙，实际与对数差分不等式两边求和是同一回事。
