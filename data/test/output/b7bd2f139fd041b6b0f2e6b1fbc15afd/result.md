# 18岁前记忆分享与游戏文化讨论

## 讨论议题与背景
本次会议为6位发言人（编号1至6）围绕“18岁以前的深刻印象和记忆”展开的漫谈式分享，由发言人1发起话题，引导大家回忆逃课、网吧游戏、追星、乐队等经历。讨论以个人回忆为线索自然发散，先后涉及多个议题：18岁前的深刻记忆分享（含逃课、网吧游戏、追星、小说漫画）、电脑游戏与单机游戏讨论（含摩尔庄园、穿越火线、魔兽争霸及游戏鄙视链）、第一人称射击游戏与暴力内容讨论（含求生之路、Steam年龄限制）、恐怖游戏与电影讨论（含生化危机、惊变48小时）、变形金刚起源讨论，以及塔防游戏与使命召唤讨论。整体以分享观点为主，未形成统一结论。讨论中提及的关键锚点包括：发言人1初中走读时每周一下午4点放学后去游戏厅网吧、求生之路第二部因血腥暴力要求18岁以上才能注册Steam账号、2020年新冠疫情后该游戏重新火爆。讨论按话题逐块推进，各发言人穿插补充个人经历与看法，气氛轻松。

## 发言要点
### 18岁前记忆分享与游戏文化讨论

1. **发言人1**：初中走读，每周一下午4点放学后去游戏厅网吧，流行穿越火线（CF）、反恐精英online（CS online）、使命召唤、战地、魔兽等游戏；高中因高考压力不敢逃课，转而追星和搞乐队，偏好朋克金属音乐。
2. **发言人5**：喜欢郭敬明的小说，提到《梦里花落知多少》；还提到当时流行看杂志。
3. **发言人4**：班级流行看柯南和老夫子漫画。
4. **发言人2**：大学前没逃过课；流行看意林、读者、故事会等杂志。

### 电脑游戏与单机游戏讨论

1. **发言人4**：小学初中流行摩尔庄园、赛尔号。
2. **发言人2**：初中玩穿越火线、地下城与勇士；玩过魔兽争霸，区分魔兽争霸（单机）和魔兽世界（网游）。
3. **发言人5**：玩过仙剑四，也玩过仙剑一或古剑四（记不清具体版本）。
4. **发言人1**：单机最流行求生之路，联机局域网玩；初中流行CS online。
5. **发言人5**：英雄联盟、DOTA、王者荣耀存在鄙视链，王者荣耀被认为最低端。

### 第一人称射击游戏与暴力内容讨论

1. **发言人1**：因在贴吧和QQ空间写文章骂穿越火线被平台封禁，后成为CS反恐精英铁杆粉丝，喜欢僵尸模式；曾被说跳舞姿势像舞体僵尸。
2. **发言人5**：质疑求生之路等游戏暴力内容无年龄限制，认为同龄人很少玩这类游戏。
3. **发言人1**：解释求生之路第二部血腥暴力，未成年人不能注册Steam账号，需18岁以上；认为制作团队精准预测美国政府面对大灾难的表现，2020年新冠疫情后游戏重新火爆。
  - 详细描述剧情：美国政府默不作声导致失控，军队暴力清理，主角团自救，最终去荒岛开辟新住处。
4. **发言人2**：欧美玩家热衷打僵尸类游戏，模式一上线欧洲年轻人疯狂在线。

### 恐怖游戏与电影讨论

1. **发言人2**：生化危机恐怖不敢玩。
2. **发言人1**：生化危机三用核武器夷平城市，剧情涉及病毒泄露和政府不作为；提到惊变48小时、死亡鬼屋等作品，求生之路结合这些作品。
3. **发言人5**：过年与表姐表弟看恐怖片，大家都跑了。
4. **发言人6**：表哥每年过年放恐怖片。
5. **发言人2**：生化危机先有游戏后有电影；**发言人1**：求生之路先有电影后有游戏。

### 变形金刚起源讨论

1. **发言人4**：提问变形金刚先有玩具还是电影。
2. **发言人1**：先有玩具，后来有MV和电影，提到绿日（Green Day）的MV。
3. **发言人2**：确认变形金刚玩具可变形。

### 塔防游戏与使命召唤讨论

1. **发言人3**：喜欢玩塔防游戏如植物大战僵尸和Kindle Rush。
2. **发言人2**：植物大战僵尸有变态版，后期满屏子弹导致电脑卡顿。
3. **发言人2**：使命召唤等游戏太男性化。
4. **发言人1**：使命召唤黑色行动涉及冷战时期美苏秘密行动；现代战争虚构较多，认为高估俄罗斯。

## 共识形成
1. **达成共识**：本场为分享型漫谈，未形成正式决议或行动安排，但围绕“18岁前的深刻记忆”达成若干一致认识：
   - **游戏记忆是共同主线**：多位成员确认初中阶段流行**穿越火线（CF）、反恐精英online（CS online）、地下城与勇士**等游戏；小学初中阶段流行**摩尔庄园、赛尔号**；单机游戏以**求生之路**为最流行（联机局域网玩）。
   - **阅读记忆有共同交集**：成员一致提到当年流行看**意林、读者、故事会**等杂志，以及**名侦探柯南、老夫子**漫画；发言人5提到喜欢郭敬明小说。
   - **游戏与电影先后关系**：就生化危机、求生之路、变形金刚的起源顺序，成员经讨论形成一致判断——**生化危机先有游戏后有电影**；**求生之路先有电影后有游戏**（在惊变48小时、生化危机基础上）；**变形金刚先有玩具，后有MV和电影**（绿日乐队MV）。
   - **求生之路的剧情预测性**：发言人1提出该游戏制作团队精准预测美国政府面对大灾难的表现，2020年新冠疫情后游戏重新火爆，与会成员未提出异议。

2. **核心分歧与倾向**：
   - **游戏鄙视链**：发言人5提出英雄联盟、DOTA、王者荣耀之间存在鄙视链，发言人2补充认为**王者荣耀处于鄙视链最低端**，此判断获在场默认，无反对意见。
   - **穿越火线评价**：发言人1明确认为穿越火线“抄袭”，并因在贴吧和QQ空间写文章批评该游戏被平台封禁，此后成为CS反恐精英铁杆粉丝；发言人2认为穿越火线现在看起来像像素游戏，未有人为穿越火线辩护。
   - **游戏暴力与年龄限制**：发言人5质疑此类暴力游戏无年龄限制、同龄人很少玩；发言人1解释求生之路第二部血腥暴力，**未成年人不能注册Steam账号，需18岁以上**才能游玩，并指出该游戏08年国服开服时较为血腥。
   - **使命召唤剧情评价**：发言人2认为使命召唤等游戏“太男性化”；发言人1认为黑色行动贴合冷战历史，而现代战争系列虚构较多，**结合当前俄军在乌克兰的表现，认为游戏高估了俄罗斯**。
