# 就诊概况
患者张学恒，男，48岁，因上腹反复疼痛4年、近3个月加重，于消化专科门诊就诊。疼痛位于心窝处，呈烧灼感，与进食冷、硬、辛辣食物及工作紧张劳累相关，白天发作，夜间无痛醒。近4年出现两次黑便，近两个月呕吐数次。初步判断需排除消化道出血及恶性病变可能，已安排大便潜血及胃镜检查。

# 诊断与检查结果
本次门诊未进行胃镜及大便潜血检查，医生根据病史初步判断需排除消化道出血及恶性病变可能。患者近4年出现两次黑便，均查大便示出血，**一年前**一次持续约一个月并住院10天，**三个月前**一次住院两三天。近三个月无黑便，大便黄色正常，小便正常。既往16岁患甲肝，在三医院住院一个月，出院及后续体检肝功能均正常；对磺胺药过敏（左手起红疹，持续约半个月）。

# 治疗方案与医嘱
治疗计划：待大便潜血及胃镜检查结果明确后，再判断是否需要手术；若药物可控制病情则无需手术。生活注意事项：医生建议患者尽量少抽或不抽烟、少喝酒，因吸烟饮酒对胃部疾病不利；注意避免工作紧张、劳累及加班熬夜，因可能加重病情。用药说明：患者近期服用达喜、奥美拉唑、阿莫西林及胃炎合剂，均停药后复发，具体用药方案见下表。
