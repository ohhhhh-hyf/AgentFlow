# 项目概况
本次会议为原占比二玉米面加工厂项目中期验收会议，验收组于18号19号提前介入前期摸排，20号召开首次会议，分内业检查和外业检查，按建筑工程、安装工程、机电设备专业方向开展。截止今天已完成卢萨卡点除弹料加工调试以外的所有验收工作，蒙泽点已完成全部验收工作，姆皮卡点现场验收工作尚未开展；因带料调试厂家工作人员在现场，验收组与技术组顺带把整个流程试生产、外方人员操作、产品生产过程过了一道。内业方面，管理组技术组基本能按项目合同组建项目执行团队并按流程程序开展工作，受疫情及项目特殊情况影响主要人员基本能保证在前方岗位，验收组查阅内业资料、现场抽检及问询交流，基本评价为满足项目有关标准和规范要求，但分类整理及少量质检和管理机构验收签字的规范性还需进一步规范和完善。外业建筑部分，原材料除国内采购出口建筑材料外，主要主材包括预制构件、年广场地砖从卢萨卡大规模成建制有质量管控体系的供货单位集中预制采购、从200多公里以外拉过去，内在品质通过查验资料、外在表观通过现场抽检和检测达到很好标准，因资料完整整理结果没出来今天不下最后结论。外业安装部分，钢结构所有材料从国内定制发货到现场，满足规范和标准要求；设备由技术组执行单位与国内中粮西安设计院及相关厂家签订专项供货合同，参照中国标准，按输出产品分三类标准专门定制编制设备并生产三套成套设备，厂家高峰期派十几名工作人员到现场指导安装，验收组对工艺设备逐台复核并投料试运行，工艺设备运行正常、工艺流程满足生产要求、产能符合设计指标，机电设备安装达到国家质量检验有关标准。财务验收方面，本项目财务从账户设置、资金往来、银行开户等过程完全符合财务处理有关规范和标准。验收组提出人员履约、内业资料、现场实体整改及不可预见费使用等整改要求，合作局领导建议尽快补充资料、做好沟通对接，蒙泽厂区混凝土路面开裂需管理组和总包单位共同研究制定整改方案，争取在末次会之前、最迟出报告之前完成整改并形成闭环，交给外方之前继续做好成品保护。

# 风险预警
整体健康度：🟡低风险。风险点如下：

- **人员履约与合同履约资料不闭合**：个别同志进出场时间以及护照还需施工部和管理组进一步完善和提高，以期验收报告时达到闭合条件；个别岗位人员因各种原因有申请更换流程；人员统计数量尤其是技术组对厂家服务人员可能没有计算进去；个别特种人员证件在有效期上，可能出国后国内延期或更新没有及时到位。等级：中；责任人：施工部、管理组、技术组；应对计划：请执行单位跟国内人力资源对接，完善相关资料闭合。
- **内业资料分类整理及签字规范性不足**：分类整理以及少量质检和管理机构验收签字的规范性还需进一步规范和完善。等级：中；责任人：技术组、管理组；应对计划：按项目执行有关标准和规范及国家有关规范及时把资料汇总到卢萨卡、分类成册、按竣工文件归档要求及时组卷。
- **竣工文件分散**：全部集中到卢萨卡点过程中有一个点因太远还在分散。等级：中；责任人：技术组；应对计划：验收完成第一时间将三个厂区的资料全部汇总于卢萨卡，包括竣工图进行分类汇总、分类组卷及编码。
- **蒙泽厂区混凝土路面开裂**：非主要通道范围内混凝土路面有少量开裂现象，可能与基础碾压和混凝土扬升过程有关，当地工人处理裂纹效果不好。等级：高；责任人：管理组、总包单位；应对计划：分析原因，结合赞比亚当地气候特点制定切实可行整改方案，管理组和总包单位共同研究会同制定科学合理整改方案，研究出技术方案后尽快整改，争取在末次会之前、最迟出报告之前完成整改，报告里形成闭环，出报告之前完成整改后验收组还要复核。
- **监控管线接头脱落**：局部监控管线因设备启动震动、加工设备转子通过转速采集数据的管线接头处有脱落，可能引起机械故障。等级：中；责任人：施工组；应对计划：伴随设备调试全面检查，保证有效性和安全性。
- **罗萨卡点加工提升桶位置雨水倒灌**：赞比亚雨量大风大、雨水有可能倒灌。等级：中；责任人：施工组；应对计划：检查，即便按原设计施工若不足以解决水的问题要考虑增加覆盖面积或通过技术措施解决。
- **卢萨卡点廊墙端头竖条不足**：廊墙最端头横向分布只有三个竖条，视觉上感觉不够安全。等级：低；责任人：施工组；应对计划：建议中间再加两个竖条，为巡检和维护工作人员提供安全保障，后面再做一次检查和完善。
- **成品保护疏忽**：工程实体完工时间较长、带料调试一直没法进行导致验收推后，成品保护可能有疏忽。等级：中；责任人：管理组、总包单位；应对计划：交给外方之前继续做好成品保护，有破损的地方及时修补。
- **赴姆皮卡交通安全**：赞比亚雨季路况不好、去姆皮卡路途遥远。等级：高；责任人：验收组；应对计划：注意交通安全，争取安安全全平平安安回来。
- **新冠疫情防疫**：等级：中；责任人：验收组；应对计划：注意新冠防疫。
- **不可预见费依据证据**：有关依据证据和数据需充分无误。等级：中；责任人：验收组、施工单位；应对计划：后续时间做专门对接，放在末次汇报再进行沟通。
