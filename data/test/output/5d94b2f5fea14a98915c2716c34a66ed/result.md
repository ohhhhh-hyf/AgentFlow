# 报告概况
国务院总理李强代表国务院向第十四届全国人民代表大会第三次会议作政府工作报告，请代表审议并请全国政协委员提出意见。报告回顾2024年工作，指出过去一年我国发展历程很不平凡，党的二十届三中全会对进一步全面深化改革、推进中国式现代化作出部署，我们隆重庆祝中华人民共和国成立75周年；面对外部压力加大、内部困难增多的复杂严峻形势，经济运行总体平稳、稳中有进，全年经济社会发展主要目标任务顺利完成，高质量发展扎实推进，新质生产力稳步发展。报告同时指出面临的困难与挑战，明确2025年经济社会发展总体要求和政策取向，并部署2025年政府工作任务。报告强调，今年是十四五规划收官之年，要高质量完成十四五规划目标任务，为实现十四五良好开局打牢基础，并开展十五规划编制工作。

# 核心政策
2025年主要预期目标：国内生产总值增长**5%左右**；城镇调查失业率**5.5%左右**，城镇新增就业**1200万人以上**；居民消费价格涨幅**2%左右**；居民收入增长和经济增长同步；国际收支保持基本平衡；粮食产量**1.4万亿斤左右**；单位国内生产总值能耗降低**3%左右**，生态环境质量持续改善。财政政策方面，实施更加积极的财政政策，今年赤字率拟按**4%左右**安排，赤字规模**5.66万亿元**；发行超长期特别国债**1.3万亿元**；发行特别国债**5000亿元**，支持国有大型商业银行补充资本；安排地方政府专项债券**4.4万亿元**；今年合计新增政府债务总规模**11.86万亿元**，比上一年增加**2.9万亿元**。货币政策方面，实施适度宽松的货币政策，适时降准降息，保持流动性充裕，使社会融资规模、货币供应量增长同经济增长、价格总水平预期目标相匹配。政策取向强调强化宏观政策民生导向，经济政策着力点更多转向惠民生、促消费，推动更多资金资源投资于人、服务于民生；打好政策组合拳，健全和用好宏观政策取向一致性评估工作机制。

# 重点工作
经济领域：大力提振消费、提高投资效益，全方位扩大国内需求，实施提振消费专项行动，安排超长期特别国债**3000亿元**支持消费品以旧换新，今年中央预算内投资已安排**7350亿元**；因地制宜发展新质生产力，加快建设现代化产业体系，培育生物制造、量子科技、具身智能、6G等未来产业，持续推进人工智能加行动；推动标志性改革举措加快落地，高质量完成国有企业改革深化提升行动，纵深推进全国统一大市场建设，综合整治内卷式竞争；扩大高水平对外开放，稳外贸、稳外资，扩大电信、医疗、教育等领域开放试点，推动高质量共建一带一路走深走实。民生领域：更大力度稳定和扩大就业，实施重点领域、重点行业、城乡基层和中小微企业就业支持计划；强化基本医疗卫生服务，深化以公益性为导向的公立医院改革，优化药品集采政策；完善社会保障和服务政策，城乡居民基本养老金最低标准再提高**20元**，适当提高退休人员基本养老金，制定促进生育政策、发放育儿补贴；加强精神文明建设，推进群众身边运动场地设施建设。科教领域：深入实施科教兴国战略，制定实施教育强国建设三年行动计划，扩大高中阶段教育学位供给，逐步推行免费学前教育，扎实推进优质本科、加快双一流建设；推进高水平科技自立自强，加快组织实施和超前布局重大科技项目，加强企业主导的产学研深度融合。三农与区域领域：着力抓好三农工作，稳定粮食播种面积，严守耕地红线，有序推进第二轮土地承包到期后再延长30年试点、扩大整省试点范围；推进新型城镇化和区域协调发展，科学有序推进农业转移人口市民化，支持经济大省挑大梁。环保领域：协同推进降碳、减污、扩绿、增长，持续深入推进蓝天碧水净土保卫战，建立一批零碳园区、零碳工厂，加快建设沙戈荒新能源基地。风险防范领域：有效防范化解重点领域风险，持续用力推动房地产市场止跌回稳，稳妥化解地方政府债务风险，积极防范金融领域风险。> 报告强调，确保十四五规划圆满收官，为以中国式现代化全面推进强国建设、民族复兴伟业不懈奋斗。
