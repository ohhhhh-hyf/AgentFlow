# 讲座概况
本期视频由主讲人李正（正直讲史）讲述康熙朝文渊阁大学士陈廷敬的一生，按母亲张氏开蒙、康熙讲师、至公无私落幕三个阶段展开。陈廷敬本名陈敬，字子端，号午亭，1638年生于山西泽州府阳城县，书香门第，六代读书人。其母张氏自幼读书，亲自为陈廷敬开蒙，陈廷敬6岁前已背完论语、孟子、大学、中庸及诗经。陈廷敬14岁中秀才，20岁中举人，21岁中进士，入翰林院任庶吉士，因与直隶陈敬重名主动上书改名，顺治赐名廷敬。顺治18年顺治驾崩，母亲病倒，陈廷敬请假归乡三年。回朝后，陈廷敬历任国子监司业、日讲起居注官、经筵讲官、翰林院掌院学士，整顿国子监送礼风气，其母去世时康熙打破满汉界限派大臣祭奠并追封其母。康熙23年任左都御史，针对捐纳买官者提出追加考试，获康熙支持；此后历任工部、户部、吏部尚书。康熙26年湖广巡抚张谦贪污案牵连陈廷敬，陈廷敬否认受贿，康熙下令只处理张谦不扩大株连，陈廷敬主动辞官但留京修书，康熙29年复出再任左都御史。康熙42年升文渊阁大学士并总理南书房，康熙46年起多次申请退休均被拒，直至康熙49年第四次申请才获准，康熙赐匾额和楹联并称自此不再给人写字。陈廷敬一生清廉，康熙对其信任有加，最终在康熙49年准其退休。

# 核心观点与论证
讲座按三个阶段展开：第一阶段“妈妈张氏的开蒙”，主讲人指出陈廷敬的童年教育由母亲张氏负责，张氏自幼随父张弘毅读书，精通儒家经典，陈廷敬6岁前已背完《论语》《孟子》《大学》《中庸》及《诗经》，9岁作《咏牡丹》获母亲称赞。陈廷敬14岁以全省第一中秀才，20岁中举人，21岁中进士入翰林院任庶吉士，因与直隶陈敬重名主动上书改名，顺治赐名廷敬。顺治18年顺治驾崩，母亲病倒，陈廷敬请假归乡三年。第二阶段“圣祖康熙的讲师”，陈廷敬回朝后康熙六年考察一等，两年后升国子监司业，整顿国子监送礼风气；康熙11年充日讲起居注官，康熙15年充经筵讲官，康熙16年任翰林院掌院学士。其母去世时，康熙打破满汉界限派大臣祭奠并追封其母。第三阶段“至公无私的落幕”，康熙23年任左都御史，针对捐纳买官者提出追加考试，吏部反对但康熙支持；此后历任工部、户部、吏部尚书。康熙26年湖广巡抚张谦贪污案牵连陈廷敬，张谦称曾贿赂陈廷敬，陈廷敬否认，康熙下令只处理张谦不扩大株连，陈廷敬主动辞官但留京修书，康熙29年复出再任左都御史。康熙42年升文渊阁大学士并总理南书房，康熙46年起多次申请退休均被拒，直至康熙49年第四次申请才获准，康熙赐匾额和楹联并称自此不再给人写字。主讲人强调陈廷敬一生清廉，康熙对其信任有加，最终在康熙49年准其退休。

# 金句总结
主讲人引用康熙原话：“朕日望大学士病体速愈，在佐朕料理机务几年。若事出意外，大臣中学问人品如大学士可代理内廷事务者为谁？”体现康熙对陈廷敬的倚重。陈廷敬自述：“臣自念无他才能报塞万一，唯早夜静静私自淬砺，不寻亲党，不阿友朋，上恐负圣主之殊恩，下欲全微臣之孝节。”表明其清廉自守。主讲人总结：“清者自清，浊者自浊，有时也并非一句空话。”并引用《论语》“苟正其身矣，于从政乎何有？”强调品行端正对治理的重要性。
