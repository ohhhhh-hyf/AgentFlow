# 电力系统基本概念与发展史授课

## 课程概况
本课为电气工程基础课程的入门课，由发言者1主讲，面向刚进入专业课学习的学生。课程教学目的有二：一是掌握电力系统发电、输电、配电、用电四个典型环节的构成、工作原理及与电力系统整体的关系，建立电力系统的整体概念；二是掌握电力系统在分析、设计、运行、管理方面的最基础理论、技术与计算方法。前修课程要求电路理论和电机学知识，特别是变压器和同步电机；后续课程包括电力系统分析、电力系统机电保护、电力系统自动化和高电压技术。本次课程重点讲授第1章电力系统基本概念，内容涵盖电力系统、电力网、动力系统、变电站等基本概念，电力系统的特点及要求，电能质量指标（国家标准规定范围），常用接地方式（中心点接地方式），并梳理了电力发展简史（从直流输电起源、交直流之争到交流输电电压等级提升与直流输电复兴）、三相交流输电优势、电力系统的形成过程与定义，以及地方电力网、区域电力网、超高压远距离输送网络的分类。

## 核心知识点梳理
### 课程目标与学习要求
- **课程定位**：电气工程基础是进入专业课后的第1门课，属专业入门课，对今后工作非常重要。
- **教学目标一**：掌握电力系统发电、输电、配电、用电4个典型环节的构成、工作原理及与电力系统整体的关系，建立电力系统整体概念。
- **教学目标二**：掌握电力系统在分析、设计、运行、管理方面的最基础理论、基本技术及基本计算方法。
- **前修课程**：要求了解电路理论和电机学知识，特别是变压器和同步电机的相关知识，本课要求较高；有欠缺的同学需自行补充相关内容。
- **后续课程**：最重要的4门为电力系统分析、电力系统机电保护、电力系统自动化和高电压技术。

### 第1章学习内容与难点
- **学习内容一**：掌握电力系统、电力网、动力系统和变电站等若干基本概念。
- **学习内容二**：理解电力系统的特点，以及由特点引起的电力系统设计、运行等方面的最基础理论。
- **学习内容三**：理解对电力系统所提出的要求，涉及运行、设计和维护各个方面。
- **学习内容四**：掌握电力系统的电能质量指标，包括国家标准对各项指标规定的范围。
- **学习内容五**：了解电力系统常用接地方式，特别是工作接地（中心点接地方式）的不同特点。
- **难点一**：由电力系统特点引出的基本原理——电能不能大量储存决定了有功功率和无功功率的动态平衡问题，是进行运行调整和设计的基础。
- **难点二**：电力系统额定电压的规定繁杂，需把规定搞清楚。
- **难点三**：各种中心点接地方式直接影响后续多个章节内容，学习较困难。
- **学习方法**：基本概念注意内涵和外延并适当记忆；从电力系统特点和要求出发、从最基础原理推导，不记结论；寻找额定电压规定之间的基本规律；比较不同中心点接地方式的特点。

### 直流输电早期发展
- **直流输电起源**：电力发展从直流开始而非交流；福泰勒用2000米导线连接瓦斯发电机，拖动一台直流电动机和一台带水泵的电动机，证明直流远距离输电可行。
- **1874年**：俄国工程师在彼得堡建成4.5公里直流输电线路，传输功率4.5千瓦，后用于有轨电车的原始工业试验。
- **1882年**：法国德普勒架设首条57公里直流试验线路，采用电报线传输，首端电压343伏、末端850伏，输送功率200瓦，损耗78%，将水电站直流发电机电力送至博览会。
- **1883年**：德普勒从法国南部进行14公里输电试验，输送功率1.1千瓦，损耗55%。
- **1882年10月**：英国科学家发明直流输电三线制系统，外线与中线间电压110伏、两外线间220伏，后扩展至5根线形成直流无限制系统。
- **直流输电限制**：电压等级低时损耗大、电压降落快；制造大容量高压直流发电机非常困难，限制远距离大容量输电。
- **19世纪末**：法国方剑在送端串联多台直流发电机以提高电压，将75千瓦电力输送75千米。
- **20世纪初**：瑞典科学家在串联直流发电机上装短路器，使任意发电机投切不停电；此后20多年建成15条直流输电线路。
- **1906年**：规模最大的线路投运，从法国慕尼黑水电厂到里昂，180公里、57千伏、4700千瓦；1927年改建为260公里、125千伏、19000千瓦，接入两座水电站。
- **直流输电制约**：设备复杂、运行方式复杂、造价高、可靠性差。

### 交流输电发展与交直流之争
- **变压器前身**：英国法拉第的电磁感应原理；美国亨利用多匝线圈作原边、少匝线圈作副边，使高电压感应出低电压。
- **1876年**：俄国科学家发明单相变压器，主要用于照明。
- **1883年**：美国特斯拉制造出感应电机，为标志性成果。
- **1885年**：匈牙利科学家共同设计多台变压器并联运行方式，使并联运行成为可能。
- **1886年**：威斯汀豪斯在美国麻省进行1.2千米、30千伏交流输电示范；又在意大利建成17英里高压输电线路。
- **1886年**：俄国科学家发明三相交流电、三相交流输电和三相异步电动机。
- **交直流之争**：爱迪生和凯尔文主张直流电，理由为直流电效率高、交流电有危险性——他们购买威斯汀豪斯公司的交流发电机卖给监狱给死刑犯执行死刑，以此证明交流电危险。
- **交流电主张**：威斯汀豪斯和特斯拉积极主张交流电，理由是交流电易利用变压器升压降压，可在电压提高状态下减少电能损失；交流发电机制造业发展也为交流输电做了准备。
- **交流输电标志性事件**：从法国到德国的交流输电线路（常被认为是第1条交流输电线路），水电厂安装三相发电机和升压变压器升压后送至德国，在法兰克福建两座降压变电站，一座供展览会照明，另一座供100马力三相异步电动机（用于人工瀑布离心泵）。

### 交流输电电压等级提升
- **1898年**：发明瓷绝缘子，美国加利福尼亚输电电压等级提高到33千伏。
- **1906年**：发明悬式绝缘子，建成110千伏高压输电。
- **1912年**：发现电晕临界电压与导线直径成比例增加，铝线和钢芯铝绞线开始应用，美国建成154千伏高压输电线路。
- **1923年**：均压阀技术应用，成功建设220千伏输电线路。
- **1936年**：美国287千伏线路投运。
- **1952年**：瑞典建成380千伏线路，首次采用分裂导线。
- **1956年**：苏联400千伏双回线路投入运行（平行双回线）。
- **1965年**：加拿大建成735千伏输电系统。
- **1969年**：美国765千伏线路并入电网。
- **1985年**：苏联1150千伏特高压线路投运，后降压至500千伏运行。
- **中国交流输电**：220千伏于1941年投运，330千伏于1972年投运，500千伏于1981年投运，1000千伏于2009年投运（交流特高压标志性首次投运成果）。

### 直流输电复兴与中国直流工程
- **1954年**：瑞典本土与哥特兰岛之间建成世界首个工业采用海底电缆的直流工程，电压100千伏、96公里，采用汞弧阀。
- **1970年**：瑞典本土与哥特兰岛之间扩建50千伏、1万千瓦晶闸管换流阀试验工程。
- **1972年**：世界首个晶闸管换流阀背靠背直流工程在加拿大投运。
- **中国首个直流输电工程**：将舟山群岛与浙江定海电网连接起来。
- **1989年**：葛上直流（葛洲坝电厂到上海）投运，±500千伏。
- **云广直流**：±800千伏特高压直流工程，今年6月投运，为标志性工程。
- **发展简史阅读建议**：作为电气专业学生应了解电力发展基本史，推荐三本书供课后阅读。

### 三相交流输电优势
- **三相交流系统优点一**：易于产生旋转磁场，三相电动机容易做驱动。
- **三相交流系统优点二**：瞬时功率恒定，不随时间变化。
- **三相交流系统优点三**：输电线路所用导线量（金属消耗量）最少。
- **应用范围**：除室内配电等小功率供电采用单相交流外，其他场合基本采用三相交流；国内电力系统大多数高压、超高压、特高压输电采用三相交流，联网时才采用直流。
- **三相三线制效率**：在直流传输方式和其他交流传输方式中，三相三线制传输效率最高。
- **金属消耗量比较**：在同等功率和功率因数下，三相三线制金属消耗量最小（全截面为一根导线截面乘以3）。
- **结论**：由于效率和金属消耗量两个原因，三相三线制在交流输电领域得到广泛应用，目前仍采用这种输电方式。

### 电力系统的形成过程
- **初始形态**：最早用一台发电机向附近负荷供电（如展览会照明、大楼照明），各自孤立供电；类似前几年街边停电后用小型柴油发电机向商铺供电。
- **可靠性问题**：单机供电时发电机出问题负荷即停电，供电可靠性差。
- **互联方案**：将两台发电机并联，一台出问题时另一台可带起重要负荷，不重要的地方可停掉；发电机相互连接越来越多，可靠性提高。
- **输电线路参数**：导线有电阻和电抗两个重要参数，传输功率（线路流通电流）时产生电压损耗和功率损耗；阻抗越大、电流越大，损耗越大。
- **距离限制**：输电线路不能太长，因电阻和电抗都与距离有关；距离长则电压降得太低、效率变低。
- **升压解决**：传输有功功率一定时，电压升高则电流减小，线路有功损耗`I²R`和电压降落`IZ`减小，输电距离可变长。
- **升压手段**：交流升压采用变压器，一侧升压、另一侧降压，中间电压升高后距离损耗、电压损耗和功率损耗均降低。
- **系统雏形**：近距离（几十到几百米）两台发电机可直接相连，远距离则升压传输，构成电力系统雏形。
- **多机供电好处**：发电机数目足够多时，单台停机不影响供电；可装大机组向大片区域供电，供电范围扩大，带来直接经济效益。

### 电力系统、电力网与动力系统定义
- **电力系统定义**：由发电机、变压器、输电线路和用电设备构成的整体，完成电能生产、输送、分配、消耗4个职能，由发电、输电、配电、用电4个环节组成。
- **电力网定义**：电力系统中去除发电机和用电设备的部分，即变压器和输电线路构成的网络。
- **动力系统定义**：电力系统加上发电厂动力部分——火电厂包括锅炉、汽机及煤炭输送处理系统，水电厂包括水轮机、水坝、水库等。
- **概念使用**：行业中说「电网」指电力网，「系统」指电力系统；动力系统概念现在很少说，说得最多的是电力网和电力系统。
- **现代电力系统特征**：发电机发电后经升压变压器升压，通过输电线路传输到负荷中心，再降压后供给用电设备；输电距离很长时（如湖北送电华东、云贵送电两广），中间可装设变电站降压向当地供电，并可引接部分负荷。

### 电网分类
- **地方电力网**：向固定地方供给电能的网络，电压等级一般在110千伏及以下（早期定义为35千伏及以下），供电半径20~50公里。
- **区域电力网**：电压等级为110、220千伏和少量500千伏，供电半径超过50公里，联系较多发电厂和负荷中心的网络。
- **超高压远距离输送网络**：电压等级为500千伏或1000千伏（东北有330千伏），主要任务是把发电厂电能送到负荷中心，距离很远，构成跨省跨地区的大型电力系统。
- **实例一**：武汉电网属地方电力网，主要供电电压110千伏和35千伏，少数地方已出现220千伏，供电半径一般在50公里以内。
- **实例二**：华中电网是典型区域电网，华中几省紧密联系，供电半径较大。
- **实例三**：葛上直流、三峡到上海的输电线路属超高压远距离输电网络，连接华中与华东。
- **特高压实例**：山西晋东南到湖北荆门的特高压系统跨三个省，连接华北电网和华中电网，属超高压远距离输送网络。
- **动态变化**：随着电网发展和电压等级提高，各级电网所用电压等级会发生变化，一般越朝后发展电压等级越高。

### 变电站分类
- **按最高电压等级分类**：以站内最高电压命名——华工变电站为10千伏变电站（10千伏变到380伏），关山变电站为220千伏变电站，凤凰山变电站为500千伏变电站。
- **按主要功率流向分类**：分为升压变电站和降压变电站——大部分功率从高压侧流向低压侧的为降压变电站；发电厂内大部分功率从发电机低压侧升到高压侧的为升压变电站。

## 课堂互动与答疑
### Q1. 为什么我国电力系统主要采用交流三相三线制输电？

- **学生**：为什么我国电力系统主要采用交流三相三线制输电？

> **教师**：三相交流系统有三个优点：易于产生旋转磁场，便于三相电动机制作驱动；瞬时功率恒定不随时间变化；同等功率和功率因数下输电线路金属消耗量最少。三相三线制传输效率最高，金属消耗量最小，因此除室内配电等小功率供电采用单相交流外，其他场合基本采用三相交流。国内大多数高压、超高压、特高压输电均采用三相交流，仅在联网时才采用直流。

### Q2. 直流输电早期发展受到哪些限制？

- **学生**：直流输电早期发展受到哪些限制？

> **教师**：直流输电早期主要受三个因素限制：电压等级低时线路损耗大、电压降落快；制造大容量高压直流发电机非常困难；设备复杂、运行方式复杂、造价高且可靠性差。这些限制阻碍了直流进行远距离大容量输电的可能性，直到20世纪中期晶闸管换流阀技术出现后，直流输电才重新用于电网间连接。

## 课后任务与学习建议
### 复习重点
- [ ] **电力系统四个典型环节**：掌握发电、输电、配电、用电四个环节的构成、工作原理及与电力系统整体的关系，建立电力系统整体概念。
- [ ] **电力系统、电力网、动力系统定义**：电力系统由发电机、变压器、输电线路和用电设备构成，完成电能生产、输送、分配、消耗四个职能；电力网为去除发电机和用电设备后的变压器与输电线路网络；动力系统为电力系统加上发电厂动力部分（火电锅炉汽机煤炭系统、水电水轮机水坝水库等）。
- [ ] **电力系统特点引出的基本原理**：电能不能大量储存，决定电力系统有功功率和无功功率的动态平衡问题，是运行调整和设计的基础。
- [ ] **电能质量指标**：掌握国家标准对电能质量指标的各种规定范围。
- [ ] **额定电压规定**：电力系统额定电压规定繁杂，注意寻找规定之间的基本规律。
- [ ] **中心点接地方式**：掌握工作接地（中心点接地方式）的不同特点，该内容直接影响后续多个章节的学习。
- [ ] **三相交流输电优势**：三相交流系统易于产生旋转磁场、瞬时功率恒定、输电线路金属消耗量最少；三相三线制传输效率最高，金属消耗量在同等功率和功率因数下最小。
- [ ] **电网分类**：地方电力网（110千伏及以下，供电半径20~50公里）、区域电力网（110、220千伏和少量500千伏，供电半径超50公里）、超高压远距离输送网络（500千伏或1000千伏，东北有330千伏，跨省跨地区）。
- [ ] **变电站分类**：按最高电压等级分类（10千伏、220千伏、500千伏变电站）；按主要功率流向分为升压变电站和降压变电站。

### 学习建议
- [ ] **补充前修知识**：对电路理论和电机学知识有欠缺的同学，应补充相关内容，特别是变压器和同步电机的相关知识，本课程要求较高。
- [ ] **掌握概念方法**：对基本概念注意其内涵和外延，并适当结合实际；思考时从电力系统特点和要求出发，从最基础原理推导，不要死记结论——结论在使用条件变化时会失效。
- [ ] **寻找规律与比较**：注意寻找额定电压规定之间的基本规律；比较不同中心点接地方式之间的特点。
- [ ] **阅读电力发展史**：作为电气专业学生应了解电力发展的基本发展史，教师推荐三本书供课后阅读。
- [ ] **课后体会学习方法**：学完章节后仔细体会教师所讲的辅导性学习方法，再结合章节内容深入理解。
