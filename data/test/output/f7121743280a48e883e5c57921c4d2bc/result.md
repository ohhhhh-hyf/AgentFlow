# 上腹疼痛患者病史采集与检查安排

## 就诊概况
患者张学恒，男，48岁，在成都轻工研究所从事科研工作。本次于消化专科就诊，由严医生接诊，为初诊。患者主诉上腹反复疼痛4年，近3个月持续发作，疼痛位于心窝处，有烧灼感，进食冷硬、辛辣刺激食物或工作紧张劳累时诱发，白天为主，无夜间痛醒，暖和、工作轻松时缓解。近4年每年春季多发。伴随症状包括：一年前及三个月前各出现一次黑便，每次持续约一个月，每天最多两次，大便形状基本正常，两次均就医查大便提示出血并住院（分别约10天及数天），住院后大便转黄；近两个月呕吐数次，吐出酸味黄水样物，为早午餐食物，晚上腹胀时呕吐后缓解。近期服用奥美拉唑（武汉药厂产）和阿莫西林效果不佳。初步考虑消化系统疾病，需进一步检查明确，本次就诊拟通过留大便查出血及胃镜检查以明确诊断，并待向上级张医生汇报后商定处理意见。

## 病史与背景
1. **现病史**：上腹反复疼痛4年，每年春季多发，近3个月持续发作。疼痛位于心窝处，呈烧灼感，进食冷硬食物、辛辣刺激或工作紧张劳累时诱发，与油腻食物关系不大；疼痛可忍受，白天为主，无夜间痛醒，暖和、工作轻松时无痛。一年前和三个月前各出现一次黑便，每次持续约一个月，每天最多两次，大便形状基本正常，两次均就医查大便提示出血，各住院约10天和两三天，住院后大便转黄。最近两个月呕吐数次，吐出酸味黄水样物，为早午餐食物，晚上腹胀时呕吐后缓解。近期服用奥美拉唑（武汉药厂产）和阿莫西林，效果不佳，现每天服4-5次。
2. **既往史**：16岁时患甲肝，在三医院住院一个月，出院时肝功能正常，此后体检肝功均正常；无手术史；按计划预防接种，近两年单位统一接种上海产乙肝疫苗三针，无不良反应。
3. **过敏史**：小时候因扁桃体炎在成都市儿童医院就诊，服用磺胺药后左手起红疹，持续约半个月，确诊磺胺药过敏。
4. **系统回顾**：双眼近视400度，平时不常戴眼镜；偶尔口腔溃疡，用贴片治疗；偶有腹泻，多因饮食不洁，急性自愈。
5. **个人史**：出生于成都，一直在成都生活，在成都轻工研究所从事科研工作，工作紧张，常加班熬夜；吸烟史，以前每天一包，现限制在10支以内，计划逐步戒烟；偶尔饮酒，平时不喝；每天泡两次茶；26岁结婚，育有一子，爱人及孩子身体健康；居住为三口人两房一厅，有专门卫生间，父母及岳父母均单独居住于成都。
6. **家族史**：父亲76岁，有低血压；母亲75岁，有冠心病，药物控制良好；弟弟身体健康；一位婶婶（叔叔的爱人）患胃癌，患者担心自己是否也会得此病，严医生解释婶婶无血缘关系，不必担心遗传问题。

## 诊断与检查结果
1. **初步印象**：考虑上腹疼痛原因待查，需进一步检查明确。患者因上腹反复疼痛4年、近3个月持续发作就诊，伴两次黑便史及近期呕吐，目前尚未确诊。
2. **关键检查结果**：
   - 大便检查：一年前及三个月前两次黑便期间，医院查大便均提示出血，两次住院后大便转黄。
   - 胃镜：尚未进行，已预约后天（患者要求，因爱人可请假陪同）。
   - 大便留检：医生要求患者留大便做检查，以明确有无出血。
3. **医生对结果的说明**：
   - 严医生解释，患者婶婶（叔叔的爱人）患胃癌，但与其无血缘关系，不必担心遗传问题。
   - 关于手术问题，严医生表示需等检查资料更全面后再判断是否需要手术，目前临床上有很多药物对消化系统疾病有良好治疗效果，能药物控制则无需手术。
4. **患者疑问与顾虑**：
   - 患者担心反复疼痛与婶婶胃癌有关，怀疑自己是否也患此病。
   - 患者担心是否需要手术，因工作繁忙且所里领导拟安排其出国进修，希望如需手术能尽早安排。

## 治疗方案与医嘱
1. **检查安排**：需留大便做出血检查，以明确有无消化道出血；预约**后天**行胃镜检查（患者因爱人可请假陪同而要求安排在后天，严医生同意并预约），胃镜活检后正好张大夫查房。
2. **用药说明**：近期服用奥美拉唑（武汉药厂产）和阿莫西林，效果不佳，现每天服4-5次；另服用所里医务室自配胃炎合剂，均未规律坚持，停药后症状反复。具体用药明细见下表。
3. **生活方式与饮食**：建议戒烟（吸烟对疾病不利，已从每日一包限至10支以内，计划逐步戒烟）；**饮酒对胃部疾病影响较大，需注意**；避免进食冷、硬、辛辣等刺激性食物，避免工作紧张劳累。

- **黑便情况**：患者曾两次出现黑便（一年前、三个月前），每次持续约一个月，需留意大便颜色变化，如有再次出现应及时告知医生。
