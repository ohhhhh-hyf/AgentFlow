# 具身智能关键技术圆桌论坛

## 研讨背景与议题
本次圆桌论坛围绕具身智能关键技术展开，由发言者2主持，邀请多模态大模型与具身智能融合、强化学习、数据收集与柔性物体操作、具身世界模型等方向的嘉宾与博士生参与研讨。论坛旨在就具身智能形态收敛、世界模型定义与构建、强化学习与模仿学习路线选择、数据采集与仿真数据等核心议题进行跨领域观点碰撞与经验交流，未形成明确决策。

1. **具身智能的形态收敛**：探讨具身智能最终形态会收敛为人形机器人还是特种机器人，以及模型架构与硬件迭代之间的关系。
2. **世界模型的定义与构建**：围绕强化学习领域与CV领域对世界模型的不同理解展开，涉及可交互性、三维表征、inductive bias等关键问题。
3. **强化学习与模仿学习的路线选择**：讨论监督学习、强化学习与模仿学习在具身智能任务中的适用场景与组合方式。
4. **数据采集与仿真数据**：探讨遥操、reward采集、可穿戴设备、仿真数据与真机数据结合等不同数据获取路线的可行性与成本。

## 核心观点
### 具身智能的形态收敛

1. **形态收敛方向未定，人形与特种机器人并存**：发言者6认为人形机器人和特种机器人将来都会存在，人形机器人因现实环境为人设计而占一定比例；发言者7从产业角度预测具身智能将经历多波技术变革，每波带来形态改变，最终形态无法预测。
2. **模型不应完全端到端，需分层设计**：发言者5认为大模型不应从上到下完全端到端，至少应分上下层；以人手受伤为例，大脑仍能指挥剩余肢体完成泡咖啡等任务，说明小脑应自适应肢体变化，而非更换大脑。
3. **硬件与模型需协同优化**：发言者2提出具身智能一定是软硬件协同优化的范式，以松龄产品为例，第二代本体在遥操和策略部署上明显优于第一代；发言者4指出现有工业机械臂并非为具身智能实验设计，模型预测失误撞桌几次即损坏，难以可靠scale up，需要个人柔顺的硬件结构支撑大规模真机评估。

### 世界模型的定义与构建

1. **强化学习视角强调可交互性**：发言者8指出世界模型概念可追溯至1990-91年强化学习之父Sutton的Dyna-Q文章，其定义为黑盒模型，输出下一时刻观测，核心是可交互；2018年Schmidhuber教授和图灵奖得主杨乐坤（Yann LeCun）的定义包含表征与转移表征两个组件，将视觉等模态输入压缩到隐空间。
2. **CV视角强调三维重建与数据规模决定归纳偏置**：发言者7认为CV界追求重建物理世界，可作为RL世界模型的工具，但当前三维表征（如voxel、光照纹理材质）在RL领域不受重视；数据规模决定是否需要inductive bias，数据多则不需要。
3. **世界模型可能无法统一**：发言者5认为世界模型因存在歧义问题可能无法统一，而policy可能统一。
4. **反对意见：CV世界模型对强化任务不必要**：发言者9认为CV世界模型对强化任务不必要，强化世界模型应针对任务本身；发言者7回应称Dreamer等论文不带三维表征，仅做生成。

### 强化学习与模仿学习的路线选择

1. **业界采用模型强化加机理融合**：发言者10表示公司采用模型强化加机理融合方式，因监督学习数据分布远不足以覆盖高维动作空间；纯强化学习强依赖仿真环境，sim-to-real迁移困难，需将决策规模和任务设定限制得很好。
2. **复杂任务应先模仿后强化**：发言者9认为单独模仿或强化均不可行，复杂任务应先模仿后强化。
3. **反馈可作为强化学习reward**：发言者5认为PID系统必有反馈，可作强化学习的reward。
4. **模仿学习与强化学习不冲突**：发言者11认为两者并无本质冲突，可先通过强化学习（如DeepMind的Motion Matching）获取运动先验，再以模仿学习（BC）形式实现；有现成数据可从模仿学习角度做，没有则先用强化学习获取数据再建模latent。

### 数据采集与仿真数据

1. **数据采集视角与标定影响模型性能**：发言者11强调数据采集时视角和标定对模型性能影响大，Open X等数据集视角不固定。
2. **reward采集是低成本方案**：发言者4主张all in reward采集路线，认为现实世界是最好的仿真器；终极数据采集形态可能是脑机接口或机电方式，实现无感、多模态（触觉、力觉、视觉、听觉）内生采集；现阶段可穿戴设备是较能scale的方案；互联网视频数据与机器人所需数据差异很大，专门研究过发现人们网上发布的内容与机器人数据需求不一致。
3. **仿真数据加少量真机数据可显著提升成功率**：发言者2指出仿真数据包含物体随机位置、orientation、任意初始状态，配以几十条真机数据可训练出较好policy，如300条仿真数据加20条真机数据。
4. **2025年应推广无标注数据利用**：发言者7认为应基于成本case by case判断真实数据与仿真数据的使用，自动驾驶场景真机数据收集成本高、corner case危险；2025年应迈向同时使用真实和仿真的有标注数据基础上，大规模利用无标注数据（如Segment Anything、Depth Anything），并提及国产仿真系统可能面临卡脖子风险，宋应等公司赌国产替代。

## 达成共识与解决方案
**未形成统一结论**。本场圆桌论坛围绕具身智能形态收敛、世界模型构建、学习路线选择与数据采集四个议题展开讨论，各议题均呈现多元观点碰撞，未形成明确决策或统一结论。以下为本场讨论中呈现的倾向性认识与主流意见：

### 具身智能形态收敛

1. **人形与特种机器人并存**：发言者6认为人形机器人和特种机器人将来都会存在，人形机器人因现实环境为人设计而占一定比例；特种机器人在工业生产制造中大量存在，两者并行发展。
2. **模型分层优于完全端到端**：发言者5主张大模型不应从上到下完全端到端，至少应分上下两层——大脑层保持稳定，小脑层自适应肢体变化；以人手受伤为例，构型改变后大脑仍能正常工作，说明控制层应独立于硬件形态。
3. **形态收敛不可预测**：发言者7从产业角度预测具身智能将经历多波技术变革，每波带来形态改变，最终形态无法预测。

### 世界模型定义与构建

1. **世界模型概念溯源**：发言者8指出强化学习领域世界模型概念可追溯至1990-91年Dyna-Q文章，核心是可交互性——输入观测、输出下一时刻观测；后续Schmidhuber教授与杨立昆（Yann LeCun）定义的世界模型包含表征与转移两个组件。
2. **CV与RL世界模型定位差异**：发言者7认为CV界追求重建物理世界，可作为RL世界模型的工具，但当前三维表征（voxel、光照纹理材质）在RL领域不受重视；数据规模决定是否需要inductive bias，数据多则不需要。
3. **世界模型统一性存疑**：发言者5认为世界模型可能无法统一，因存在歧义问题，而policy可能统一；发言者9持反对意见，认为CV世界模型对强化任务不必要，强化世界模型应针对具体任务构建。

### 强化学习与模仿学习路线

1. **模型强化加机理融合**：发言者10表示公司当前采用模型强化加机理融合方式，因监督学习数据分布不足以覆盖高维动作空间，纯强化学习强依赖仿真环境、sim-to-real迁移困难；实物强化学习需严格限制决策规模与任务设定。
2. **先模仿后强化**：发言者9认为复杂任务应先模仿后强化，单独模仿或强化均不可行。
3. **模仿与强化不冲突**：发言者11认为两者并无本质冲突——模仿学习可获取运动先验，数据缺失时可用强化学习（如DeepMind的mimic）先生成数据再以BC形式建模latent。

### 数据采集与仿真数据

1. **数据质量关键因素**：发言者11强调数据采集时视角和标定对模型性能影响大，Open X等数据集视角不固定，影响训练效果。
2. **reward采集路线**：发言者4主张reward采集是低成本方案，现实世界是最好的仿真器；终极数据采集形态可能是脑机接口或可穿戴设备，现阶段可穿戴设备是较可scale的方案；互联网视频数据与机器人所需数据差异大，直接利用价值有限。
3. **仿真加真机数据结合**：发言者2指出仿真数据加少量真机数据可显著提升成功率——海量仿真数据（随机位置、orientation、初始状态）配几十条真机数据可训练出较好policy。
4. **无标注数据利用**：发言者7认为2025年应迈向大规模利用无标注真实数据（如segment anything、depth anything），不再局限于有标注真实数据与仿真数据的比例讨论（1:9、2:8、5:5等观点）。

### 解决方案

1. **硬件可靠性提升**：发言者4提出具身智能实验需硬件具备高寿命与高可靠性，现有工业机械臂非为此设计，需个人柔顺硬件结构支撑大规模真机evaluation——依据：模型预测撞桌等事故易致设备损坏，影响scale up。
2. **软硬件协同优化**：发言者2提出具身智能应走软硬件协同优化范式，以松龄产品两代迭代为例，第二代在遥操与策略部署上显著优于第一代。
3. **国产仿真系统布局**：发言者7提及国产仿真系统产业问题，宋应等公司赌卡脖子风险、做国产替代，属business层面的布局，技术上将趋于统一。

## 未决分歧与后续探索
1. **具身智能最终形态**：人形机器人还是特种机器人，尚未达成一致。发言者6认为人形机器人与特种机器人将并存，人形机器人因现实环境为人设计而占一定比例；发言者7从产业角度预测具身智能将经历多波技术变革，每波带来形态改变，最终形态无法预测；发言者3提出机械智能视角，认为硬件可通过软手等结构实现顺应性，不一定需要人形。

2. **世界模型是否需要三维表征**：强化学习与CV领域观点不同。发言者7认为CV界追求重建物理世界，可作为RL世界模型的工具，但当前三维表征在RL领域不受重视，并主张数据规模决定是否需要inductive bias，数据多则不需要；发言者9持反对意见，认为CV世界模型对强化任务不必要，强化世界模型应针对任务；发言者5认为世界模型可能无法统一，因存在歧义问题，而policy可能统一。

3. **强化学习与模仿学习的最终路线**：是先模仿后强化还是其他方式，未达成共识。发言者9认为复杂任务应先模仿后强化，单独模仿或强化均不可行；发言者10表示公司采用模型强化加机理融合方式，因监督学习数据分布不足以覆盖高维动作空间，纯强化学习强依赖仿真环境、sim-to-real迁移困难；发言者11认为模仿学习和强化学习不冲突，可获取运动先验；发言者5认为PID系统必有反馈，可作强化学习的reward。

4. **数据采集方式**：遥操、仿真还是可穿戴设备，尚未确定。发言者4主张reward采集路线，认为现实世界是最好的仿真器，终极数据采集形态可能是脑机接口或可穿戴设备；发言者2指出仿真数据加少量真机数据可显著提升成功率，如300条仿真数据加20条真机数据；发言者7认为应推广无标注数据利用，如segment anything，并认为真实数据还是仿真数据应case by case看成本。
