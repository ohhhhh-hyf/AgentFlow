# 锵锵三人行：从《大奥》到明史的文化对谈

## 访谈概述
本期《锵锵三人行》邀请《明朝那些事儿》作者当年明月（发言者2）与嘉宾马先生（发言者3）、发言者4，围绕刚播完的日剧《大奥》与明史展开文化对谈。访谈先由《大奥》切入日本文化中的极端精神与忠诚文化，再转入明史魅力、朱元璋评价、明朝兴亡经验及明式家具审美，最后以历史认知的局限性作结。受访者核心观点：一是日本文化精神是“极端精神”，所有事情做到尽头，与中国“中庸”文化形成对比，日本战后用30年成为世界第二经济强国（绝对量、唯一没有资源的强国）；二是明史资料最多但一个事件可能有7个不同说法，如罗生门，明朝260多年历史跌宕起伏，多次濒临灭亡（土木堡之变、夺门之变）；三是历史经验教训难以直接套用，“我们从历史中得到的唯一教训就是我们从来没有从历史中得到过教训”。访谈看点在于当年明月以“照片与录像”比喻史书与真实生活的差距，并指出明武宗正德皇帝被嘉靖命杨廷和编实录时写坏，其从江南回来先在通州停留半天派人打探京城，说明此人并非史料所写那么蠢。

## 访谈详细记录
### 日剧《大奥》与日本文化

1. **《大奥》背景与反响**：发言者3认为《大奥》是《大长今》以后最有影响的外国电视剧，发言者2表示赞同。该剧共三部，前两部对应中国晚明到清初时段，第三部在明治维新之前，是一部有跨越性的历史剧。
2. **大奥的含义**：发言者3解释“大奥”即中文的“后宫”，日语“奥”指屋子最深处，如“堂奥”“深奥”保留此意；发言者2补充另一层意思是“一般人不准进去”。
3. **日本权力结构与天皇处境**：发言者2指出日本天皇一直是摆设，实际权力掌握在幕府将军手中，德川家康开创德川幕府后权力集于一人。他举例称天皇曾想举办活动但没钱，找将军要钱被拒，活动未办成，天皇后来以退位抗议。
4. **日本文化的极端精神**：发言者2认为日本文化核心是“极端精神”，所有事情要做到尽头，与中国“中庸”文化形成对比。发言者3补充日本战后用30年成为世界第二经济强国（绝对量而非人均量），是唯一没有资源的强国，这不是偶然而是必然。
5. **日本人的专业精神**：发言者2称看《大奥》吸引他的是严谨精神——回头看《三国演义》会看到群众演员笑，但日本剧看不到；发言者3提到第一集片头将军出场时所有人呈45度鞠躬、依次行礼，场面华丽，一看就不一样。
6. **岛国生存环境与民族性格**：发言者2认为日本作为岛国资源匮乏、多灾多难，人必须融入团体按规则行事才能生存，这是日本文化特性的根源。

### 明朝历史与《明朝那些事儿》

1. **明史为何吸引人**：发言者2称自己写《明朝那些事儿》是因为明史资料最多，但一个事件可能有7个不同说法，如罗生门；发言者3补充明朝260多年历史本身跌宕起伏，几次要死没死了，如土木堡之变、夺门之变，皇上被瓦剌军抓了又扶弟弟起来，构成现代版电视剧般的情节。
2. **对朱元璋的推崇**：发言者2认为朱元璋是了不起的人才，从乞丐到皇帝，定下明朝规章制度基本无大改动；发言者3认为人的因素最大，改变时势的一定是出现一个人，发言者1称这是英雄史观。
3. **历史经验教训**：发言者2称“我们从历史中得到的唯一教训就是我们从来没有从历史中得到过教训”，强调历史事件发生时有背景，不能简单套用——“你不比前人聪明，甚至可能比前人笨，当那种情况出现的时候你也得那么办”。他以照片比喻史书记载，称史书只留下“咔嚓”一张照片，而古人的生活是录像，你不知道那一幕之前和之后是什么。
4. **明朝灭亡的蹊跷**：发言者2提到1644年明朝首都北京闹瘟疫（疙瘩瘟，即天花），李自成军攻入时无人抵抗；他曾与老师王佩奇交流，认为明朝亡得蹊跷，什么坏事衰事都赶上了。发言者3称中国历史上跨过300年大限的只有宋朝（南北宋接上，延续319年），明朝未跨过。
5. **明末市民生活**：发言者2称明末市民生活轻松，江南工商业兴起，出现三言二拍等娱乐产品。
6. **明式家具与审美**：发言者3认为宋明是汉人文人政权，审美素雅；满族异族政权审美表象化，导致今天大红大紫的审美。发言者2提到马先生家具店有一块特别硬的木头上面刻着云彩，印象很深。

### 明朝皇帝趣事与历史认知

1. **正德皇帝被写坏**：发言者2认为明武宗正德皇帝被写坏，因嘉靖非其亲生（是堂兄弟），命杨廷和等人编《明武宗实录》时贬低他。他举例正德从江南回来先在通州停半天，派人打探京城有无埋伏圈套，说明其有城府——“这个人绝不是史料上所写的那么蠢”。
2. **正德皇帝的荒淫与无嗣**：发言者3称正德是明朝最荒淫的皇帝，但没少找女人却不留种，没有生育能力；发言者4称没有正宗传下来。发言者3还提到正德对宫廷外女人有兴趣，因宫廷内女人禁忌太多、太保守。
3. **豹房真相**：发言者2称豹房其实是玩的地方，有动物园、养了豹子，女人肯定有，但后宫也是女人，不影响其他问题；发言者1调侃险些把“豹房”听成“炮房”。
4. **天启皇帝当木匠**：发言者3称天启皇帝爱当木匠，做完家具让大臣去卖，卖得好很有成就感。
5. **历史研究的傲慢与偏见**：发言者1批评很多专家研究历史有傲慢与偏见，不设身处地，老觉得自己聪明，判断前人昏庸无能；发言者2认为嘉靖为给自己父亲争名分搞大礼仪事件，为此死了很多人，历史“非常玄幻”，有些事你以为这么回事，实际上不是这么回事。
