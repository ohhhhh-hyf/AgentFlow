# 知识主题与概述
本期视频是皮卡新系列「评论」的试水之作，核心是带领观众浏览 Stack Exchange 上关于调和级数 ∑1/n 收敛性的经典问题，并给出个人主观评论。皮卡首先从高中数学角度解释了级数收敛与发散的定义：若前 n 项和 sn 存在固定上界则收敛，若其下界无界则发散。随后逐一评论了网友的多种证明方法，包括分组求和估计、柯西凝聚判别法、积分估计法、差分法等，并批评了某些证明的故弄玄虚。皮卡认为调和级数发散是明确的，但强调证明方法的自然性与可理解性。

# 核心概念
## 级数收敛与发散
- **收敛**：对任意正整数 n，前 n 项和 sn 都小于某个固定实数 a（如 100 或 1000 万），即存在上界，则称级数收敛。
- **发散**：若能证明 sn 大于某个单向递增且永无止境的 bn，即对任意大的数 b，总可通过增大 n 使 bn 超过 b，则称级数发散。

## 分组求和估计
- 将调和级数分组：第 1 组为 1，第 2 组为 1/2+1/3，第 3 组为 1/4+1/5+1/6+1/7，第 4 组为 1/8 到 1/15，依此类推。
- 每组和均大于 1/2（如 1/2+1/3 > 1/4+1/4 = 1/2，4 个 1/8 之和 = 1/2），而组数无限，故总和无上界，级数发散。

## 柯西凝聚判别法
- 证明过程与分组求和完全一致，即分组后对每组取上界或下界进行估计，从而得到对整个部分和的估计。
- 对非负不增序列，其收敛发散性质等价于加速后的序列 ∑2^k·a_{2^k}；对调和级数，等价于 ∑2^k·(1/2^k) = ∑1，即无穷个 1 相加，显然发散。

## 积分估计法
- 用积分曲线面积近似 hn（调和级数前 n 项和），矩形面积（高为 1/n，底为 1）始终大于曲边梯形面积，故 hn > ∫₁ⁿ⁺¹ (1/x) dx = log(n+1)。
- 因 log(n+1) 无上界，故 hn 无上界，级数发散。

## 差分法（Stolz 定理）
- 利用 Stolz 定理（中文常称施托尔茨定理），当分子分母均为无穷大时，可比较差分极限：分子差分 hn+1 - hn = 1/(n+1)，分母差分 log(n+1) - log n = log(1+1/n)，两者极限均为 1，故 hn 与 log n 同阶，log n 无上界，故 hn 发散。
- 皮卡认为此法不自然，有先射箭后画靶之嫌，因为需预先知道 hn 与 log n 同阶。

## 取对数放缩法
- 对 e^{hn} 取对数，利用 e^{a+b} = e^a·e^b 将和转化为连乘积，再用不等式 e^{1/k} > 1+1/k 放缩，连乘积相邻项相消，最终得到 e^{hn} > n+1，从而 hn > log(n+1)。
- 皮卡批评此法为「故弄玄虚」「装逼」，本质是已知结果后反向凑证明，妨碍理解。

# 核心结论
## 核心结论
- 调和级数 ∑1/n 是发散的，这是明确结论。
- 柯西凝聚判别法的证明过程与分组求和完全一致，可推广到非负不增序列。
- 积分估计法通过比较矩形面积与曲边梯形面积，得到 hn > log(n+1) 的下界。
- 差分法利用 Stolz 定理，通过比较差分极限证明 hn 与 log n 同阶，从而发散。

## 易混点与适用边界
- 收敛与发散的定义：收敛需存在固定上界，发散需下界无界，两者是互斥的。
- 柯西凝聚判别法仅适用于非负不增序列，对一般级数不适用。
- 积分估计法需预先知道积分 ∫(1/x) dx = log x，且矩形面积始终大于曲边梯形面积。
- 差分法需预先知道 hn 与 log n 同阶，否则难以想到用 log n 作比较。
- 取对数放缩法需用不等式 e^{1/k} > 1+1/k，该不等式本身需微积分或极限知识，但也可用中学不等式证明。
