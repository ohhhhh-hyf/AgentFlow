# 讲座概况
会议围绕电影《南京照相馆》展开讨论，成员分享了观影印象：有人看过抖音切片，有人觉得深刻好看，有人因题材沉重未看，有人提到地下室场景。主持人介绍了1937年八一三淞沪抗战、日军进攻南京及南京大屠杀的历史背景，并说明日军军纪失控、松井石根被替换、朝香宫鸠彦发布不留俘虏命令等细节。主持人辨析了电影虚构与真实：主要人物虚构，但照片拍摄真实，实际由美国传教士拍摄，中国冲洗人员偷拷证据，战后递交国民政府军事法庭作为审判日本战犯的证据；电影中中华门战斗、挹江门惨案、战犯审判等为真实历史。成员还分享了参观伪满洲国博物馆、唐山大地震纪念馆、上海抗战纪念馆等经历，提到南京大屠杀纪念馆预约难。

# 核心观点与论证
主持人首先介绍历史背景：1937年8月13日八一三淞沪抗战，国军从上海撤退后日军追击至南京；自九一八事变以来日军未遭成规模抵抗，八一三淞沪抗战是首次迎头痛击，日军伤亡惨重、军纪失控，攻破南京后发生南京大屠杀。其次辨析电影虚构与真实：主要人物虚构，但照片拍摄真实，实际由两名美国传教士拍摄日军暴行，中国冲洗人员偷偷拷贝并藏起，战后递交国民政府军事法庭作为审判日本战犯的证据；电影中中华门城墙战斗、挹江门撤退惨案、战犯审判（谷寿夫等被枪决）均为真实历史。再次分析日军暴行原因：日军未遭像样抵抗、遭受前所未有的侮辱与应激创伤，结合日本屠城传统、高压武士道精神，以及松井石根因病被替换为朝香宫鸠彦亲王，后者发布不留俘虏命令，导致军纪失控。

# 金句总结
主持人指出：“从他们当时那样的心态来说，觉得遭受了一种前所未有的侮辱，以及在战场上的一种应激创伤反应。”此句关联日军在南京暴行的心理动因。另一处：“攻破了敌方的城镇，都要以屠城来进行自己那种狂欢与麻痹。”此句解释日军屠城的历史传统。
