# 就诊概况
48岁男性患者张学恒，因上腹心窝处烧灼样疼痛4年、近3个月反复发作，于消化专科就诊。疼痛与进食冷、硬、辛辣食物及工作紧张劳累相关，可忍受，无夜间痛醒。近4年出现两次黑便，分别于一年前和三个月前，每次持续约一个月，两次均住院治疗后好转。近两个月呕吐数次，吐出黄水样酸味物。既往有甲肝病史及磺胺过敏史。医生初步判断需进一步检查以明确诊断，已安排胃镜检查。

# 诊断与检查结果
本次就诊为初步问诊，尚未得出明确诊断结论。医生建议留大便做检查以明确有无出血，并预约后天行胃镜检查及活检。患者既往16岁患甲肝，在三医院住院一个月，出院时肝功能正常，此后体检肝功均正常；对磺胺药过敏，曾服磺胺药后左手起红疹伴瘙痒，持续半个月。

# 治疗方案与医嘱
治疗计划：医生将总结患者病情向上级张医生汇报，再讨论下一步治疗方案。生活注意事项：医生建议患者尽量少抽或不抽烟，尽量少喝酒，因吸烟饮酒对胃部疾病有不良影响；注意避免工作紧张、劳累及加班熬夜，因这些因素可诱发或加重症状。
