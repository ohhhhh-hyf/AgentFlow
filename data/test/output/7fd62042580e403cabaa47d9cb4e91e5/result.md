# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司（东源煤电）、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷上诉案，不服云南省高级人民法院（2018）云民初88号民事判决，向最高人民法院提起上诉。二审公开开庭审理，合议庭由审判长李少平与审判员魏文超、黄年、王海峰、葛洪涛组成，法官助理张瑞。各方围绕三个争议焦点展开辩论：国开行抵押权是否构成善意取得、罚息复利计算及起算日期、东源煤电及东源煤业是否应连带给付违约金。经合议庭评议提出调解方案，各方均无异议，合议庭予以确认，庭后出具调解书。

# 举证与法庭调查
**证据与质证意见**
- **东源方2015年12月2日邮件及融资情况统计表**：东源方主张该邮件显示招银租赁抵押物已登记、国开行抵押物正在办理，设备名称完全相同且用红色标注，国开行应尽注意义务；国开行反驳称邮件正文及附表均无告知融资租赁的文字，统计表仅并列描述，不能得出已告知的结论。
- **国开行2018年9月融资租赁查询证书**：国开行用以证明查询无记录；招银租赁质证认为该查询不符合要求，依据2014年93号文，国开行应在抵押时点（2015年12月）查询人行征信中心。
- **招银租赁回租设备清单（证据第7页）**：招银租赁用以证明设备特定化；国开行质证称清单仅载明设备名称和生产厂家，无型号，且出厂日期为2012年3月1日，与国开行现场调查的铭牌生产日期（2013年11月、12月、2014年3月）不符，不能认定为同一设备。
- **国开行证据第54、58页权属证明及股东会决议**：国开行用以证明抵押设备所有权属曲靖电力公司；招银租赁未否认，但主张东源煤电出资系无权处分。
- **国开行证据第108页融资租赁登记核查表**：国开行用以证明已对曲靖电力公司进行核查；招银租赁主张应扩大至东源煤电。
- **招银租赁2013年、2015年审计报告（证据第82、95页）**：招银租赁用以证明曲靖电力公司注册资本4亿元已实缴；国开行用以证明设备出资事项已载明。

**法官询问要点**
- **融资租赁登记性质及法律后果**：审判长询问各方对中国人民银行征信中心融资租赁登记性质及法律后果的理解。国开行认为是行业强制性规范，旨在防范金融风险；东源方认为是行业指导性规范，不当然产生物权后果；招银租赁认为是权利公示，产生对抗效力，不影响所有权设立转移。
- **查询方式**：王海峰法官询问融资租赁登记系统有几种查询方式。国开行称仅能按查询单位查询；招银租赁称可按公司名称或设备查询，但设备查询涉及种类物区分问题。
- **案涉设备识别码登记情况**：王海峰法官询问案涉5套设备识别码是否登记清楚。招银租赁称设备为种类物，无唯一识别码，未登记。
- **内部风控规定**：葛洪涛法官询问国开行贷款前审查是否有内部规定要求保留未查询到结果的单证。国开行称无此规定，因未查询到结果故未保留。
- **查询义务程度**：葛洪涛法官询问违反查询规范达到何种程度才导致融资租赁司法解释第9条第2款后果，是基本查询义务还是全面审慎义务。国开行认为是基本义务，招银租赁认为是严格义务，未查询即不构成善意。
- **举证责任分担**：葛洪涛法官询问各方对融资租赁司法解释第9条第2款举证责任分担的理解。国开行主张谁主张谁举证；招银租赁主张第1、2、4项由出租人举证，第3项由第三人（国开行）举证。

**双方辩论的争议焦点**
- **国开行抵押权是否构成善意取得**：国开行主张抵押设备为通用设备、无唯一标识码，审查义务仅限于抵押人曲靖电力公司，查询无记录即构成善意；东源方主张邮件已告知融资租赁情况，国开行未尽注意义务；招银租赁主张国开行未在抵押时点查询，不构成善意。
- **融资租赁登记查询义务范围**：国开行主张仅限于抵押人曲靖电力公司；招银租赁主张因东源煤电系借款人及全资控股母公司，应扩大至东源煤电。
- **东源煤电出资行为性质**：招银租赁主张系无权处分，因2012年已取得设备所有权；国开行主张设备已实缴出资，所有权属曲靖电力公司。
- **上海中院判决与本案关系**：国开行主张上海中院判决仅确认返还义务，未确认所有权归属，与本案担保物权审理不冲突；招银租赁未明确回应。

# 庭审结果
本案争议焦点归纳为三项：一是国开行抵押权是否构成善意取得；二是一审判决对案涉借款罚息、复息计算及起算日期是否认定错误；三是东源煤电、东源煤业是否应连带给付违约金。经合议庭休庭评议，提出调解方案，各方均无异议，合议庭予以确认，庭后出具调解书。调解方案主要内容：国开行对东源煤电债权扣除破产已清偿本金外，利息、罚息、复利合计6474.4513万元；招银租赁对涉案6项设备享有所有权，对应债权数额1377.4137万元；国开行对93项设备有抵押权，招银租赁对6项设备有所有权；招银租赁和国开行对案涉全部发电设备整体盘活处置，变现价款双方各得50%，实现费用各担50%；调解书生效后20日内由国开行向一审法院提出执行申请，启动司法处置程序；未实现债权待执行法院出具体本裁定后按破产重整计划预留方案实现，若破产管理人不纳入预留方案，由东源煤电按有担保清偿方案清偿；若司法变现不能，国开行和招银租赁放弃案涉设备权益，由东源曲靖电力自主生产经营；案涉设备管理费用由东源曲靖电力承担，东源曲靖电力无条件配合司法处置；一审判决第2项、第4项无争议按判项内容确认；一审诉讼费中国开行诉请部分按一审判决执行，招银租赁诉请部分由二审法院按规定计算后由国开行承担；二审诉讼费由国开行和东源煤电各承担50%；协议签订后各方就本案涉及问题不再存在任何争议。审判长指出，本案涉及的动产抵押权与融资租赁物所有权冲突是司法实践中的普遍性难题，根本原因在于国家尚未建立统一的动产登记制度，现有动产融资租赁登记系统和动产抵押登记系统缺乏有效衔接，合议庭将根据最高人民法院关于加强司法建议工作的意见向有关部门提出司法建议。
