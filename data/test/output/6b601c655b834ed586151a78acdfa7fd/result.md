# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷二审案件，国开行不服云南省高级人民法院2018云民初88号民事判决提起上诉。本案由审判员李少平担任审判长，与审判员魏文超、黄年、王海峰、葛洪涛组成合议庭，法官助理张瑞，依法公开开庭审理。庭审中，各方当事人核对身份无异议，东源煤电、东源煤业、曲靖电力合并发表意见。法庭围绕三个争议焦点展开调查与辩论：国开行对案涉设备是否享有抵押权（善意取得）、一审判决对借款罚息复息的计算及起算日期是否认定错误、东源煤电及东源煤业是否应连带给付违约金。合议庭休庭评议后提出调解方案，各方均无异议，合议庭予以确认，庭后出具调解书。

# 原告诉称与被告辩称
上诉人国开行上诉请求：撤销一审判决相关判项，改判确认其对案涉设备享有抵押权，并支持其利息、罚息、复利及违约金主张。事实与理由：国开行已按央行规定查询融资租赁登记系统，未显示曲靖电力公司设备有融资租赁登记；设备为通用设备无唯一标识码，无法按设备查询；抵押人仅为曲靖电力公司，审查义务仅限于抵押人，已履行审慎义务，构成善意取得。被上诉人东源煤电、东源煤业、曲靖电力答辩称：国开行未举证证明东源煤电违反柜台前移和账户管理约定，且按合同约定应先限期纠正，国开行从未发出书面纠正函；罚息不应作为复利计算基数，复利再计算复利无合同依据。被上诉人招银租赁答辩称：国开行未在抵押时点（2015年12月）查询融资租赁登记系统，仅提供2018年9月查询证书，不符合规定；审查义务应扩大到东源煤电（借款人与抵押人全资控股关系）；东源煤电出资行为系无权处分，招银租赁2012年已取得设备所有权。

# 举证与法庭调查
**证据与质证意见**
- 国开行提交2018年9月对曲靖电力公司的融资租赁查询证书，招银租赁质证认为不符合要求，依据2014年93号中国人民银行规定，国开行应在抵押时点（2015年12月）查询人行征信中心。
- 招银租赁提交回租设备清单（证据第7页），仅载明设备名称和生产厂家，未载明型号；国开行质证称清单记载出厂日期为2012年3月1日，而现场调查核实抵押设备铭牌生产日期均在2013年以后，看不出是同一设备。
- 国开行提交证据第54页、58页，显示东源煤电公司、曲靖电力公司对设备权属的证明材料及股东会决议，证明设备所有权属曲靖电力公司。
- 国开行提交融资租赁登记信息核查表（证据第108页），显示曲靖电力公司名下无融资租赁登记，招银租赁质证称该核查表系2018年9月查询，非抵押时点查询。
- 招银租赁提交2013年和2015年审计报告（证据第82页、95页），载明曲靖电力公司注册资本4亿元且已实缴，国开行据此主张招银租赁知道或应当知道设备出资情况。

**法官询问要点**
- 合议庭询问各方对中国人民银行征信中心融资租赁登记性质及法律后果的理解：国开行认为系行业强制性规范，用于防范金融风险；东源方认为系行业指导性规范，不产生物权后果；招银租赁认为系行业性强制性规范，不构成法律效力约束。
- 合议庭询问融资租赁登记系统查询方式：国开行称仅能按单位查询；招银租赁称可按公司名称或设备查询，但设备查询需特定化。
- 合议庭询问案涉5套设备是否登记唯一识别码：招银租赁称设备无唯一识别码，非必填项，未登记。
- 合议庭询问国开行内部是否有规定要求保留未查询到结果的记录：国开行称无此规定，因未查询到结果故未保留记录。
- 合议庭询问查询义务程度：国开行认为系基本义务，仅需查询抵押人名下登记；招银租赁认为系严格义务，未查询即不构成善意。
- 合议庭询问融资租赁司法解释第9条第2款举证责任分担：国开行主张谁主张谁举证；招银租赁主张第1、2、4项由出租人举证，第3项由第三人（国开行）举证。

**双方辩论的争议焦点**
- 争议焦点一：国开行对案涉设备是否享有抵押权（善意取得）。国开行主张已履行审慎义务构成善意取得；东源方主张2015年12月2日邮件已告知融资租赁情况，设备名称相同且用红色标注，国开行应尽注意义务；招银租赁主张国开行未在抵押时点查询系统，审查义务应扩大到东源煤电，东源煤电出资行为系无权处分。
- 争议焦点二：一审判决对案涉借款罚息复息的计算及起算日期是否认定错误。国开行主张利息自2017年12月21日计算至2018年6月12日合计21,795,727.68元，罚息自2018年6月13日计算至2019年2月19日合计41,050,579.57元，复利自2018年3月21日计算至2019年2月19日合计1,918,206.23元；东源方主张国开行当天发函要求当天偿还未给合理期限，罚息不应作为复利计算基数，复利再计算复利无合同依据。
- 争议焦点三：东源煤电、东源煤业是否应当连带给付违约金。国开行主张借款合同第24条第3项约定违约金为千分之一，东源煤电未配合办理账户管理及柜台前移手续构成违约；东源方主张国开行未举证证明违约，且按合同约定应先限期纠正，国开行从未发出书面纠正函。

# 庭审结果
本案三个争议焦点：一是国开行对案涉设备是否享有抵押权（善意取得）；二是一审判决对案涉借款罚息复息的计算及起算日期是否认定错误；三是东源煤电、东源煤业是否应当连带给付违约金。合议庭休庭评议后提出调解方案，各方当事人均无异议，合议庭予以确认，庭后出具调解书。调解方案主要内容：国开行对东源煤电的债权扣除破产中已清偿本金外，利息、罚息、复利合计6474.4513万元；招银租赁对涉案6项设备享有所有权，对应债权数额1377.4137万元，国开行对93项设备有抵押权；案涉全部发电设备整体盘活处置，变现价款双方各得50%，实现费用双方各担50%；调解书生效后20日内由国开行向一审法院提出执行申请；未实现债权按破产重整计划预留方案实现，若司法变现不能，双方放弃设备权益，由东源曲靖电力自主生产经营。各方对一审判决第2项、第4项无争议，按判项内容在调解书中确认。
