# 杭州医学院医学技术硕士点招生宣讲会

## 沟通背景与目的
杭州医学院检验医学院、生物工程学院党委书记、副院长宋宝峰副教授做客招生宣讲直播间，面向考生及家长介绍该校医学技术专业硕士点的招生情况。沟通旨在帮助考生全面了解该学位点的学科建设、研究方向、师资力量、培养方式、就业前景及2026年招考安排，解答报考疑问。整场宣讲以介绍与答疑为主，宋宝峰系统展示了学位点的办学实力与培养特色，并回应了考生关切的就业、复试、跨考等问题，整体基调积极，鼓励考生报考。

## 核心信息与数据
### 学位点基本情况
1. **学位点获批**：医学技术专业硕士点于2024年获批，为新增学位点。
2. **学院构成**：由5个学院共同承担培养工作，其中检验学院、生物工程学院合署办公，共建学院为医学影像学院、康复学院和信息工程学院。
3. **专业方向**：聚焦四个主要专业方向，即检验技术、医学影像技术、康复治疗和智能医学工程；其中检验技术细分为医检和卫检两个方向。

### 2025年招生情况
1. **录取人数**：2025年共录取64位考生，其中检验方向38人、经济方向11人、康复方向13人、职业方向2人。

### 学科建设与科研平台
1. **学科层次**：医学技术学科于2023年获批省医学技术一流学科B类。
2. **科研项目与经费**：近五年获国家级基金项目19项、省鉴定领先项目1项；纵向科研经费1300万元，横向合作课题经费2200多万元。
3. **科研奖项**：获省科技进步一等奖2项、二等奖1项、三等奖2项。
4. **课程与专业建设**：建成国家级一流本科课程2门、国家级一流本科专业建设点2个。
5. **省级科研平台**：建有省生物标志物与器官诊断转化重点实验室、检验诊断关键技术质量研究室、康复模块和机器人国际联合实验室、省实验室和安全培训基地、数字化康复装备质量研究中心、脑认知与疾病数字医疗器械质量工程研究中心、浙江省神经系统疾病数字化装备研发重点实验室等省级平台。

### 学科优势
1. **体外诊断领域**：优势显著，疫情期间与企业联合开发新冠病毒核酸检测、抗原检测、抗体检测三个产品，获NMPA注册。
2. **医学影像技术方向**：为国家临床药物验证机构、国家卫健委外周血管介入诊疗培训基地。
3. **康复治疗方向**：依托省人民医院康复医学科，为省内综合医院中建科最早、人才最齐、技术最先进、设备最先进、社会效益最佳的康复医学科之一。
4. **智能医学工程方向**：聚焦阿尔茨海默病智能预警生物标志物（数字生物标志物），居国际领跑水平；为浙江省中医药重点学科、老人助浴疾病数字器械医疗器械浙江省中心、智能医学前沿交叉学院。

### 主要研究方向
1. **医学检验技术**：负责人为吕建新教授，聚焦重大疾病新型生物标志物筛选及其机制、新发突发传染病新型生物标志物筛选及致病机制、重大疾病体外诊断检测技术、新型药物系统体内治疗易复发难以治愈疾病等方向。
2. **卫生检验检疫**：负责人为金大志教授，聚焦新发突发传染病病原体检测检验新技术方法开发，特别是艰难梭菌致病机制、耐药机制、基因组进化及小分子药物开发，以及卫生检验技术研究。
3. **医学影像技术**：负责人为徐秀芳教授，研究方向包括多参数MRI有效指标、肿瘤分子影像学、神经导航引导脑肿瘤穿刺技术、脑肿瘤术前功能区定位。
4. **康复治疗**：负责人为叶祥明教授，研究方向包括人工智能康复、神经修复、运动技术创新。
5. **智能医学工程**：聚焦阿尔茨海默病智能预警生物标志物、脑认知与脑疾病智能诊疗、健康大数据、脑机接口、中医先进医疗器械、重大疾病智能诊断等。

### 师资队伍与领军人物
1. **师资总体情况**：专任教师90人，高级职称53人（占30%以上），博士55人；硕导69人，正高35人，博士46人。
2. **人才称号**：教育部医学技术类专业教学指导委员会委员、省万人创新人才2人次、浙江省151人才5人、省杰青1人、省高层次创新人才2人、省领军团队1个。
3. **吕建新教授**：学位点负责人，国家百千万人才工程人选，主持国家自然科学基金重点项目、科技部重点研发、863计划重点项目及省科技重点研发、应急攻关项目等十余项，发表高水平论文200多篇，获省科技一等奖3项、优秀教学成果奖2项。
4. **徐秀芳教授**：浙江省151人才第三层次，省高校中青年学科带头人，研究生院院长兼医学影像学院院长，国家一流本科专业建设点医学影像技术专业负责人，教育部教指委相关医学分会委员、中华医学会影像技术分会影像技术专委会委员。
5. **叶祥明教授**：省人民医院主任医师、二级教授，博导、博士后导师，主持国家级课题3项、省重大课题2项，发表SCI论文98篇。
6. **金大志研究员**：博士、硕导，美国华盛顿大学博士后、美国MSCC访问学者，省创新人才、卫生创新人才、首届优秀医疗机器人才，检验医学院学术院长、省生物标志物与器官诊断转化重点实验室主任、中国医师协会临床微生物分会常务委员。
7. **李凯教授**：信息工程学院院长，复旦大学公共卫生学院博士、早稻田大学访问学者，智能医学前沿交叉学科研究院执行院长、智能医学工程学科负责人、浙江省中医药大学学科带头人，研制全生命周期中医治疗及康复医疗体系设备3台/套。

### 硕士培养与毕业去向
1. **培养目标**：面向健康中国发展需要，紧密服务区域行业产业发展，围绕国际学术前沿、国际重大需求和转化研究，培养熟练掌握医学技术领域专业知识技能、具有良好创新实践能力的高层次应用型人才。
2. **培养方式**：采用教学、专业实践与学位论文相结合的方式。
3. **学制**：全日制专业学位学制三年，最长不超过五年。
4. **学分要求**：毕业前学业课程不少于24学分，其中专业必修课分方向取得学分大于等于12学分。
5. **就业方向**：可进入医院检验科、输血科、病理科、放射科、超声科、康复医学科等科室，以及疾控中心、医药企业、医疗器械公司（从事研发、销售、技术支持、质量管理体系建立与维护、产品法规统筹与合规管理）、保险公司（医疗保险核保理赔、健康险产品开发）、药监局、卫健委、海关（医疗器械监管、卫生政策制定、口岸卫生检疫）等部门。

### 2026年招考计划
1. **招生计划**：2026年计划招生34人，实际以教育部正式下达人数为准。
2. **初试科目**：思想政治理论、英语（统考），专业课按方向自主命题，包括检验综合、医学影像技术综合、康复治疗综合、智能医学工程综合；专业课分值300分、时长180分钟。
3. **检验综合构成**：分子生物学检验占40%、生物化学检验占30%、微生物学检验占30%。
4. **复试方式**：采用线上线下结合，目前以线下为主；初试占60%、复试占40%。
5. **复试内容**：英语能力测试20%、专业能力测试40%、综合能力测试40%。

## 各方立场与诉求
1. **宋宝峰（杭州医学院检验医学院、生物工程学院党委书记、副院长）**：作为主讲嘉宾，系统介绍医学技术专业硕士点的学位点概况、学科优势、研究方向、师资队伍、培养方式、就业方向及2026年招考计划，并回应考生关切，鼓励报考。
2. **主持人**：代表屏幕前考生及家长提出关注点，包括就业前景、复试环节、初试科目、英语难度、跨专业报考资格、校区位置及学科竞赛情况，引导宋宝峰逐一解答。
3. **考生及家长（通过主持人代问）**：关注点集中在毕业去向（医院科室、疾控、企业、监管机构等）、复试构成与占比、初试专业课内容、英语考试难度、跨专业报考是否可行、校区交通便利性及研究生竞赛表现；宋宝峰均予以正面回应，明确允许跨专业报考并鼓励非本专业考生报考。

## 达成共识
1. **学位点建设口径已确认**：医学技术专业硕士点于2024年获批，由检验学院、生物工程学院合署办公，医学影像学院、康复学院、信息工程学院共建，聚焦检验技术（医检、卫检）、医学影像技术、康复治疗、智能医学工程四个方向。
2. **2025年招生数据已确认**：共录取64名考生，其中检验方向38人、经济方向11人、康复方向13人、职业方向2人。
3. **学科建设成果已确认**：2023年获批省医学技术一流学科B类；近五年获国家级基金项目19项、省鉴定领先项目1项，纵向科研经费1300万元、横向课题经费2200多万元，获省科技进步一等奖2项、二等奖1项、三等奖2项；建成国家级一流本科课程2门、国家级一流本科专业建设点2个。
4. **培养方案已确认**：培养目标为面向健康中国发展需要，培养掌握医学技术领域专业知识技能、具有创新实践能力的高层次应用型人才；培养方式为教学、专业实践与学位论文相结合；学制为全日制专业学位三年，最长不超过五年；学业课程不少于24学分，专业必修课不少于12学分。
5. **2026年招考口径已确认**：计划招生34人，实际以教育部正式下达人数为准；初试科目为思想政治理论、英语（统考）及按方向自主命题的专业课（检验综合、医学影像技术综合、康复治疗综合、智能医学工程综合），专业课分值300分、时长180分钟；复试采用线上线下结合，目前以线下为主，初试占60%、复试占40%，复试内容为英语能力测试20%、专业能力测试40%、综合能力测试40%。
6. **跨专业报考口径已确认**：允许跨专业报考，鼓励非本专业考生报考。
