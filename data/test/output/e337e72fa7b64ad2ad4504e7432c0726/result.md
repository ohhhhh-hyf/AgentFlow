# 复盘目标与结果概况
本次年会复盘2023年公司经营状况与员工表现。预期目标为通过总结数据、发放年终奖与奖项增强团队凝聚力；实际结果为公司总量提升，年终奖转账总额226,000元，但成本控制差，全年支出390万元，利润率约24%或27%，老板个人比去年少拿约10万元并承担亏损100万元。会议公布了年终奖发放标准，对短视频、执行、商务三部门及个人逐一评价，颁发最佳新人、最佳进步、后期独当一面、最佳员工、特别贡献五项奖，并抽奖。

# 亮点事项
- 短视频账号各平台粉丝大幅增长：视频号从3月1日70019人增至8万，小红书从2000+增至6.4万，抖音从2000+增至5.7万，B站从3.1万增至7.6万，成功原因是6月20日第一条外出拍摄视频起色，郭东辉坚持并说服潘老师改变拍摄方式。
- 直播在视频号直播4-5场，平均在线人数50分钟以上，每场平均5000人以上，为后续变现打下基础。
- 商务部门实打实项目约300万元，基本达到期待，张启表现高于预期，主动联系客户。
- 后期整体进步明显，分级模糊、效率接近，硬着头皮安排没做过的人也能完成，体现团队能力提升。
- 最具复用价值的经验：**郭东辉破釜沉舟说服潘老师外出拍摄**，以及**坚持用数据支撑内容决策**（晚上8-9点刷直播间研究同行），值得推广。

# 不足事项
- 成本控制非常差，全年支出390万元（含人员工资、外援配音、字幕、租机器），利润率仅约24%或27%，根因是老板对成本关注不够、不够雷厉风行，问题未及时解决。
- 公司结余到账往下跑，还有百来万没收回来，老板承担风险亏了100万元。
- 账号变现重点项目未完成，课程变现仅达7.5分（满分10分），直播无课程可售。
- 后期人员劳累程度高，后半年基本都在加班，高强度工作有怨言但仍坚持，根因是**老板未及时招合适人数**，属判断失误。
- 拍摄外援成本高，公司内部凑不出人按机位，钱德峰建议内部人员尝试拍摄以降低成本。

# 改进计划
- 明年开会再讨论成本控制问题，责任人无，时间无。
- 明年开会再讨论年终奖额度问题，责任人无，时间无。
- 老板明年将反思对员工的支持、管理或关心不够的问题，并投入更大精力推动短视频账号变现。
- 老板期待明年更多进行组织协调，提高效率，减少侵占员工休息时间。
- 老板表示明年会往拍摄方向靠，希望大家都能参与拍摄，提升个人市场价值。
- 老板承诺给商务部门张启更多支持和帮助，责任人无，时间无。
