# 发布会概况
王毅在慕尼黑安全会议发表讲话并回答提问，围绕多极化世界阐述中方立场。王毅表示，多极化是历史必然并正在成为现实，中国主张推动平等有序的世界多极化，中国必将是多极体系中的确定性因素，坚定做变革世界中的建设性力量。他提出四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。王毅还就中欧关系表示，欧洲是多极世界的重要一极，中欧是伙伴而不是对手，今年是中欧建交50周年。在答问环节，王毅就乌克兰问题、中美关系等阐明中方立场。

# 核心信息
王毅提出四点主张：一是倡导平等相待，坚持权利平等、机会平等、规则平等，主张大小国家一律平等，提升发展中国家在国际体系中的代表性和发言权；二是尊重国际法治，联合国宪章宗旨和原则是国际关系根本遵循，国家不论大小强弱都是国际法治利益攸关方，大国要带头讲诚信讲法治，摒弃言行不一、零和博弈，遵守国际法不能搞双重标准，应支持中国实现完全统一；三是践行多边主义，联合国是推进全球治理的核心平台，应固本强基而非拆梁毁柱，中国承担超过**20%**的联合国会费，切实履行`巴黎协定`，建成世界上最大的清洁发电体系，提出并落实全球发展倡议、全球安全倡议、全球文明倡议；四是坚持开放共赢，保护主义不是出路，滥加关税没有赢家，脱钩断链断的是机遇，小院高墙封的是自己，去年中国GDP增长**5%**，对世界经济增长的贡献率接近**30%**，愿推动高质量共建`一带一路`同欧盟`全球门户`战略相互对接。中欧关系方面，今年是中欧建交**50周年**，中方愿同欧方用好这一契机深化战略沟通和互利合作。

# 官方表态
关于国际秩序与规则：中国是在现行国际秩序中发展起来的，是这个秩序的受益者，要做的就是按照大多数国家的愿望，推动这个秩序朝着更加公正合理的方向去发展；需要共同维护以联合国为核心的国际体系，共同遵守以联合国宪章宗旨和原则为基础的国际关系基本准则。关于乌克兰问题：中国同俄罗斯是两大邻国，建立了不结盟、不对抗、不针对第三方的睦邻友好关系，进而建立全面战略伙伴关系；中国同俄罗斯之间的交往是正常的国与国之间的交往；> 如果中国不从俄罗斯买，哪个国家能够提供如此巨量的油气来满足中国民众的需求呢？那是不可能的，也是不保险的。中方历来主张一切争端和冲突都应该通过对话寻求政治解决，从这场危机爆发的第2天开始，就是2022年2月25号，中方就提出了对话协商解决；习近平主席提出的4点主张是中国立场的最权威的阐释，即各国的主权领土完整应该得到尊重，联合国的宪章应该得到遵守，各国的合理安全关切应该得到重视，一切致力于和平的努力都应该得到支持；中方派出的特使去各国斡旋，同巴西等南方国家发起了和平之友；中方乐见一切致力于和平的努力，包括这两天美国同俄罗斯达成的共识；所有当事方包括利益攸关方，都应该适时参与到和谈进程当中，欧洲更有必要为此发挥重要作用。关于中美关系：中国的对美政策保持着连续性和稳定性，不会轻易翻烙饼；对美政策就是习近平主席提出的三原则，相互尊重、和平共处、合作共赢；中美制度不一样是各自人民做出的选择，如果想改造或者颠覆对方是不切实际的；中美两个大国总不能冲突起来，因为那将殃及整个世界；中方已经准备好了，愿意按照三原则同美方构建稳定健康可持续的双边关系；如果美方仍然还要对中国打压和遏制，那我们也别无选择，我们必将奉陪到底，必将坚定维护中国的主权、国家的尊严和我们的正当发展权利，必将坚决回击美方的单边和霸凌行径。

# Q&A环节
问：你是否继续相信联合国？是否相信联合国宪章？是否会为联合国及其宪章改革而努力？这在你优先事项中排多高？ → 答：王毅表示，提问涉及秩序和规则两个关键词；真正要挑战秩序、毁约退群的国家出现了，而中国是在现行国际秩序中发展起来的，是受益者，要做的就是按照大多数国家的愿望推动这个秩序朝着更加公正合理的方向发展；需要共同维护以联合国为核心的国际体系，共同遵守以联合国宪章宗旨和原则为基础的国际关系基本准则，这是最大的公约数。
问：中国是否有可能对俄施压，如削减俄对华供气、降低价格或停止部分两用物资，以推动结束战争？ → 答：王毅表示，中国同俄罗斯是两大邻国，两国关系过去经历过曲折，之后双方吸取教训，建立了不结盟、不对抗、不针对第三方的睦邻友好关系，进而建立全面战略伙伴关系；中国同俄罗斯之间的交往是正常的国与国之间的交往；如果中国不从俄罗斯买，哪个国家能够提供如此巨量的油气来满足中国民众的需求，那是不可能的，也是不保险的；中方不会允许把经贸问题政治化、当做打压中国的工具，要为人民负责任；中方历来主张一切争端和冲突都应该通过对话寻求政治解决，乌克兰问题上同样如此，从2022年2月25号起中方就提出了对话协商解决，习近平主席提出的4点主张是中国立场的最权威阐释，中方不断推进劝和促谈，派出特使去各国斡旋，同巴西等南方国家发起了和平之友；中方乐见一切致力于和平的努力，包括这两天美国同俄罗斯达成的共识，认为所有当事方包括利益攸关方都应适时参与和谈进程，欧洲更有必要发挥重要作用。
问：请简要预览一下中美关系将如何发展？ → 答：王毅表示，中国的对美政策保持着连续性和稳定性，不会轻易翻烙饼，这体现了作为大国的战略定力和国际信誉；对美政策就是习近平主席提出的三原则，相互尊重、和平共处、合作共赢；中美制度不一样是各自人民做出的选择，如果想改造或者颠覆对方是不切实际的，正确的态度就是相互尊重；中美两个大国总不能冲突起来，因为那将殃及整个世界，所以还是要开展对话、加强交往、增进了解、建立信任；合作共赢是因为国际社会期待中美开展合作，全球性挑战也需要中美携手应对；中方已经准备好了，愿意按照三原则同美方构建稳定健康可持续的双边关系，找到两个大国在这个星球上的正确相处之道；如果美方仍然还要对中国打压和遏制，那我们也别无选择，我们必将奉陪到底，必将坚定维护中国的主权、国家的尊严和我们的正当发展权利，必将坚决回击美方的单边和霸凌行径。
