# 锵锵三人行：从《大奥》到明史的文化对谈

## 访谈概述
本期锵锵三人行由主持人发言者1与嘉宾发言者2（《明朝那些事儿》作者）、发言者3、发言者4围绕日剧《大奥》与明朝历史展开对谈。上半场以刚播完的日剧《大奥》为引，讨论日本文化的极端精神、忠诚文化与中日文化差异；下半场转向明朝历史，探讨明史魅力、朱元璋评价、明朝兴亡经验教训及历史记载的偏见。核心观点包括：发言者2认为日本文化从头到尾未变，体现为极端精神，所有事情做到尽头；发言者3补充日本战后用30年成为世界第二经济强国（绝对量），是唯一没有资源的国家；发言者2总结“我们从历史中得到的唯一教训就是我们从来没有从历史中得到过教训”，并指出明武宗正德皇帝被嘉靖朝编的实录写坏，实际有城府。访谈看点在于发言者2以《明朝那些事儿》作者身份，结合史料细节（如1644年北京闹疙瘩瘟致李自成军攻入无人抵抗、正德皇帝从江南回来在通州停留打探）提出与流俗看法不同的历史解读，发言者1则批评专家研究历史有傲慢与偏见。

## 访谈详细记录
### 日剧《大奥》与日本文化

- **访谈员**：刚播完的日剧《大奥》引起很大反响，它反映的是日本哪个阶段？
- **受访嘉宾**：《大奥》三部曲，前两部大概相当于中国的晚明到清初，第三部在明治维新之前，是一部有跨越性的历史剧。

1. 发言者3认为《大奥》是《大长今》以后最有影响的外国电视剧，发言者2表示赞同，称其确实是一部非常好的剧。
2. 发言者2被《大奥》吸引的原因是「严谨的精神」——他对比说，回头看《三国演义》会看到群众演员在笑，但日本剧里看不到笑，每个人都特别认真、有专业精神。
3. 发言者3回忆自己看《大奥》第一集片头就被震住了：将军出场时所有人呈45度依次鞠躬，场面之华丽、色彩之讲究，「一看就不一样」。
4. 发言者1对《大奥》最表面的印象是欣赏日本人的礼仪——穿和服走小碎步、尊贵人物一来两旁伏地行礼；发言者3补充说大奥即中文的「后宫」，日语「奥」指很深的地方、屋子最里处，引申为「深奥」，且一般人不准进去。
5. 发言者2认为从《大奥》可以看出日本文化从头到尾没有变，体现为一种「极端精神」——所有事情要做到尽头；发言者3强调这是发自内心的，与中国人不同。

### 日本极端精神与中日文化差异

1. 发言者3指出日本战后用30年时间成为世界第二经济强国（绝对量而非人均量），且是强国中唯一没有资源的国家，他认为这不是偶然而是必然，源于全民族的极端精神。
2. 发言者2对比中日文化精神：中国是「中庸」，他举例在马先生家具店看到一块特别硬的木头刻着云彩，马先生说「这么硬的一个东西能做成这么柔软的形状」，他当时想这就是中庸；而日本坚持一个原则，是极端精神。
3. 发言者3提到日本跳槽率最低，西方经济学家不能理解终身雇佣制为何不导致效率低下——日本终身雇佣下人们积极性仍然很高。
4. 发言者3举例日本豆腐厂规定当天做当天卖：夜里11:45所有人坐好不动手、看着表，12点整准时站起来开始工作，到四点多干完上市，期间没人瞎聊胡侃，「一丝不苟」。
5. 发言者3认为日本投机取巧者没有生存环境，社会文化鄙视使其不能生存；发言者2补充说日本岛国资源匮乏、灾害多，人必须融入团体按规则行事才能生存。

### 明朝历史与《明朝那些事儿》

1. 发言者2解释很多人对明史感兴趣的原因：明史资料最多，但一个事件可能有7个不同说法，像罗生门；发言者3补充说明朝260多年过程跌宕起伏，多次濒临灭亡。
2. 发言者2推崇朱元璋，认为他从乞丐到皇帝、定下明朝规章制度，是了不起的人才；发言者3认为「人的因素最大，改变时势一定是出现一个人」，发言者1称这是英雄史观。
3. 发言者2以《亮剑》中李云龙为例说明天赋：没上过军事院校但能打仗，因为「一个人到战场上死生多少年没死，最后积累下来经验，我一上战场就知道敌人会往哪走」。
4. 发言者2称明末市民生活轻松，江南工商业兴起，三言二拍等娱乐产品出现；发言者3提到明末工艺精细，文征明、唐寅、董其昌等艺术家活跃。
5. 发言者2总结历史经验教训：「我们从历史中得到的唯一教训就是我们从来没有从历史中得到过教训」，并强调历史事件发生时有背景，你不比前人聪明，那种情况出现时你也得那么办。
6. 发言者2提到1644年明朝首都北京闹瘟疫（疙瘩瘟，可能为天花），导致李自成军攻入时无人抵抗；发言者3补充说中国历史王朝逼近300年就完了，「跟人一到八九十岁大限快到了一样」。

### 明朝皇帝与历史记载的偏见

1. 发言者2指出明武宗正德皇帝被记载为荒淫，但实际很有城府——他从江南回来没进京城，先在通州停了半天或一天，派人打探京城里有没有人想搞埋伏搞圈套，这是史料记载的。
2. 发言者2解释正德被写坏的原因：明武宗实录是嘉靖时期编的，具体是嘉靖指派杨廷和等人编的，而嘉靖不是正德亲生儿子、是堂兄弟，所以不能把正德写得太好。
3. 发言者3称正德是明朝最荒淫的皇帝，但没少找女人却不留种、没有生育能力；发言者4补充说正德对宫廷内的女人没兴趣，因为「禁忌太多」，而民女不知他是谁，「抡圆了干」。
4. 发言者2称明神宗几十年不上朝但不出去；发言者3提到嘉靖为给自己父亲争名分搞大礼仪事件，为此死了很多人。
5. 发言者1批评很多专家研究历史有「傲慢与偏见」——没有设身处地，老觉得自己聪明、判断前人昏庸无能；发言者2回应说历史「非常玄幻」，有些事你看到以为这么回事，实际上不是这么回事。
