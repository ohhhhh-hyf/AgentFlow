# 沟通概况
班主任林瑞在372班家长会上，面向全体家长介绍了班级基本情况、教师团队、班级存在问题及解决思路、管理计划与措施，并给出家庭教育建议。班级共60人，男生25人、女生35人，整体班风纪律良好，但存在少数学生周末玩手机游戏、自习课效率低、书写欠佳等问题；教师团队以老教师和优秀教师为主，班主任林瑞任教地理学科。会议还涉及成立家长委员会、保险购买、电子学生证办理、资助政策说明等事项，家长代表张宇波（校长代表）分享了家庭教育经验，强调关注孩子身心健康、尊重孩子、多倾听多交流。会议基调为加强家校协同，共同促进学生成长。

# 沟通内容
## 学习表现

- **亮点**：班级整体时间观念和执行能力有所加强，班风班貌纪律良好，教室地面干净整洁，卫生状况好。
- **亮点**：学生遇到问题会主动向老师请教，班主任林瑞提到上课时会给学生提问机会，学生能积极上来问问题。
- **亮点**：班级学生整体书写不错，可从学生手册和抽屉里的架构书看出学习情况。
- **需关注**：个别学生书写不好，班主任已与家长沟通过，建议家长给孩子买字帖练字；有学生写班级计划时把“372班”写成“172班”，字迹潦草影响辨识。
- **需关注**：自习课效率较低，班主任在场时学生表现安静，不在场时教室乱哄哄；计划加强班委培训，给学生10分钟讨论时间，不懂的可离开座位去问。
- **需关注**：少数同学思考能力较差，尤其在自习课上表现明显。
- **需关注**：下次月考在11月初，学生已在学生手册中定下月考目标，建议家长了解孩子的兴趣爱好和目标想法。

## 行为表现

- **亮点**：班级整体纪律良好，班风班貌好。
- **需关注**：少数同学（约两三个）周末沉迷玩手机游戏，玩累了导致懒散，精神状态不佳。
- **需关注**：有少数男生有网瘾，星期六晚上往游戏里充值，有学生充了400元；班主任发现有男生晚上看直播、接触不健康内容。
- **需关注**：有学生带手机到校，班主任要求手机统一上交至手机存放箱，每个箱子贴好学生名字；要求家长处理家中多余手机，不要留多部手机给孩子。
- **需关注**：班主任建议家长在周一到周五不定时打电话检查孩子手机是否上交——电话能打通说明手机还在孩子手里，打不通或无人接说明已上交。
- **需关注**：班主任在抽屉里发现学生带镜子，约10人左右，要求全部收掉，请家长也检查孩子书包。
- **需关注**：有学生看小说，班主任建议家长管控孩子阅读内容，两个店（书店）让孩子看，有目标后再叫出去看。

## 社交与心理表现

- **需关注**：班主任提醒家长关注学生早恋问题，建议家长加孩子QQ、关注其空间朋友圈、抖音、快手等社交账号，留意是否有多个账号、是否屏蔽家长。
- **需关注**：学生处于初中阶段生理和心理持续变化的时期，是人生中不稳定的时期，需要培养应对风险的能力。
- **需关注**：班主任强调学生心理健康是重点关注点，家长发现孩子状态不对应及时进行心理辅导。
- **需关注**：有学生周末外出过生日，喝酒回来一身酒气还抽烟；周六选择住校的学生须遵守住宿纪律要求。
- **需关注**：班主任提到有学生谎称没钱多次向家里要钱，实际把钱花在别处；提醒家长关注孩子消费情况，建议生活费每天21–24元、每周不超过150元，避免给过多零花钱。
- **需关注**：班主任在班级调查“知道父母生日”时举手人数很少，提醒家长加强感恩教育，引导孩子用零花钱给父母买小礼物。

# 家长反馈
- **家长代表分享**：张宇波（校长代表、372班语文老师）以家长身份分享家庭教育经验，强调关注孩子身体健康和心理健康，做人教育是必修技能，先做人再成才；家长要有平常心，帮助孩子面对挫折和失败；尊重孩子，给孩子自由空间，不轻易下消极评价；多倾听多交流，给予关爱与理解；配合学校制度，尊重老师。
  > “要想让孩子离开，就要让他们学会怎么样做人，千万不能让他们带上不良的风气。”
  > “无论怎样，那你都是爸爸妈妈心里最优秀的儿子，你先批评他，还是不当，这样的话他会更加的深刻。”
  - 孩子面临的学习压力很大，需要家长帮助重新定位，放下眼前、向往更远风景。
  - 孩子心理上追求尊重与要求，家长应真正做到陪伴。
  - 孩子犯错时先安慰再批评，效果更深刻。
  - 家长应多抽时间了解孩子在校表现，经常给孩子制定容易达到的小目标，激发潜能。
  - 家长应避免过分关注、放任不管、期望过高等教育误区。
  - 家长应关注孩子心理健康，发现异常及时进行心理辅导。
  - 家长应提醒孩子注意交通安全（未满16周岁骑电动车危险）、运动安全、饮食安全、防诈骗、防溺水。
  - 家长应关注孩子防校园欺凌，遇到问题第一时间联系班主任。
  - 家长应多鼓励少批评，给孩子适当压力，但期望不能过高或过低。
  - 家长应给孩子创造和睦、祥和、稳定的家庭气氛，不在家里聚众打麻将、点外卖，不当着孩子面长时间玩手机。
  - 家长应关注孩子生活费使用情况，建议每天21-24元、每周不超过150元，防止孩子将钱用于非正常消费。
  - 家长应关注孩子手机使用情况，管理好手机，防止接触不良内容；可不定时打电话检查手机是否上交。
  - 家长应关注孩子QQ、抖音、快手等社交账号，关注早恋问题。
  - 家长应关注孩子书包，检查是否携带镜子等与学习无关的物品。

# 共识与配合事项
## 费用与收费

- [ ] **家长**：确认水费险收费标准（每两周2元/人，按月收取），卫生不达标或饮水超量时另行补收
- [ ] **家长**：确认书费预交11000元（已购5本书），待结算后退还未购书箱同学的相应费用
- [ ] **家长**：关注少数同学约100元、70元、120元、123元等不同额度的费用明细，班主任会逐一公布
- [ ] **家长**：所有费用由学生交给生活委员，不在微信群内转账缴费
- [ ] **家长**：警惕冒充班主任头像在群内收费的诈骗行为，一律不信不转

## 保险

- [ ] **家长**：自愿为学生购买保险，费用约310多元，可在学校、菜市场或阿里巴巴等渠道自行购买
- [ ] **班主任**：统计全班学生保险购买情况，确认是否已参保

## 电子学生证

- [ ] **家长**：自愿办理电子学生证，移动套餐满78元/月可办理，方便与孩子联系及请假沟通
- [ ] **家长**：班级现有老年机部分已停机（因诈骗电话多被误判），有可用号码的请及时更新
- [ ] **班主任**：将新的号码发到家长群，供家长重新登记补充
- [ ] **班主任**：说明现有坐席到期情况（上届遗留3个坐席，今年9月20几号到期，6月20号已停用）

## 资助政策

- [ ] **家长**：查阅家长群内已发布的资助政策，注意高中补助与初中不同——所有补助打在医保卡上（非营养餐和生活补助直接上卡）
- [ ] **家长**：每次补助到账后与孩子确认资金用途（生活费或交回家里），防止用于买手机、过生日、喝酒、抽烟等非正常消费
- [ ] **班主任**：每次打款后提醒家长核对到账金额

## 手机管理

- [ ] **家长**：配合学校手机管理制度，学生手机统一上交存放（手机箱内每人贴名字）
- [ ] **家长**：家中多余的手机（含坏手机）及时处理或收走，不留多部手机给孩子
- [ ] **家长**：周一到周五不定时拨打孩子电话，若打通无人接或关机，说明手机未上交，需及时处理
- [ ] **家长**：关注孩子手机使用内容，防止接触直播、不健康内容及网瘾问题
- [ ] **家长**：关注孩子QQ、抖音、快手等社交账号，留意是否被屏蔽、是否有早恋迹象

## 住校纪律与安全

- [ ] **家长**：提醒住校学生周六住校期间遵守寝室纪律要求（2:10回寝室休息），不饮酒、不抽烟
- [ ] **家长**：提醒孩子注意交通安全——未满16周岁不得骑电动车，确需骑行只能一人骑，不得载人
- [ ] **家长**：提醒孩子注意运动安全、饮食安全、防诈骗、防溺水（不私下结伴游泳）
- [ ] **家长**：关注防校园欺凌，孩子遇到问题第一时间联系班主任处理
- [ ] **班主任**：学生生活小事再小也要管好教育好，第一时间处理学生矛盾（如曾深夜12点至2点处理学生纠纷）

## 班级管理与学习

- [ ] **班主任**：继续加强思想教育，每天进行
- [ ] **班主任**：执行详细班规——该扣分扣分、该写检讨写检讨、该罚站罚站，严格请假制度
- [ ] **班主任**：加强班委培训，提升自习课效率（自习课给10分钟讨论时间，不懂可离座请教）
- [ ] **班主任**：定期与科任老师沟通，了解学生课堂及各方面表现
- [ ] **家长**：查看学生手册/记录手册，了解孩子兴趣爱好、月考目标及书写情况
- [ ] **家长**：书写不好的学生，到文具店购买字帖练习写字
- [ ] **家长**：关注下次月考时间（11月初），与孩子一起制定合理目标

## 家长教育配合

- [ ] **家长**：避免教育误区——不过分关注、不放任不管、不期望过高、不给过多零花钱
- [ ] **家长**：控制生活费标准——每天21-24元（早餐3-4元、午餐8元、晚餐8元），每周不超过150元
- [ ] **家长**：关注孩子心理健康，发现异常及时进行心理辅导
- [ ] **家长**：多鼓励少批评，给孩子适当压力，期望要适当
- [ ] **家长**：为孩子创造和睦、祥和、稳定的家庭氛围，不在孩子面前长时间玩手机
- [ ] **家长**：不在家里聚众打牌、点外卖或麻将，避免过多唠叨
- [ ] **家长**：经常给孩子制定容易达到的小目标（如年级排名120名到30名范围内），激发潜能
- [ ] **家长**：多抽时间了解孩子在校表现，与孩子多沟通交流

## 家委会

- [ ] **家长**：自愿报名参加家长委员会，至少需要三人
- [ ] **班主任**：家委会重大事项经班主任与家长探讨，通过后正式成立

## 其他事项

- [ ] **家长**：培训时间3:20开始，下午3点半可办理相关业务（有一节课时间）
- [ ] **家长**：培训期间禁止拍照，不得发朋友圈或社交媒体（因教官着装不允许拍照）
- [ ] **家长**：关注校园系统（请假系统）短信通知，了解孩子出入校情况
