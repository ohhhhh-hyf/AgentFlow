# 访谈概况
本次访谈围绕农村与城市留守老人养老问题展开，受访者包括农村老人、村干部、民政局干部、城市社区社工等。访谈目的是了解留守老人养老现状、政策落实情况及改善建议。整体反馈基调为担忧与期待并存：农村老人反映独居寂寞、就医困难、经济拮据；村干部指出财政困难导致养老设施运营难以为继；社工则强调志愿者制度与社工行业困境。根据2021社区居家养老现状与未来趋势报告，65.5%的老人子女长期不在身边，26.8%与子女同住；2021年公安数据显示当地73万多老人，老龄化程度约17.8%且会持续加重。

# 核心反馈
## 农村老人
- 独居寂寞，渴望陪伴：黑龙江绥滨一位独居老奶奶因太寂寞报警，只为找人聊天；有老人表示“没得人亲好”，子女外出打工后无人照料。
- 就医困难：一位视障老人反映就医存在障碍；村干部提到子女不在身边，一旦生病住院比较麻烦。
- 经济困难：农村老人每月养老金仅118元，五保户分散供养每月475元生活费加护理补贴，低保分160、270、380三档，生活拮据。
- 娱乐方式少：老人只能坐在一起聊天、打牌。

## 村干部/民政局干部
- 养老设施运营经费无着落：曾探索农村养老公共设施，但地方财政困难，后续运营经费无支持。
- 老人无人陪伴、经济困难、子女不在身边是主要问题；老龄化程度会越来越严重，2021年数据为73万多老人、17.8%左右。
- 建议：请专业施工人陪伴、倡导子女多联系、丰富文化生活、老年协会专项建养老设施并保障持续运营经费。

## 城市社区社工
- 城市留守老人社交机会更少，更易孤独抑郁；有老人心理问题严重，抗拒上门帮助，觉得“周围的人都是陌生的，没有关心他的人”。
- 志愿者制度有效：一对一帮扶、积分兑换礼品、小手拉大手等活动，但志愿者队伍需扩充中年力量。
- 社工行业困境：工资低、就业率低，很多社工做不超过一年；服务领域多、专注力不集中；项目资金拨不下来，服务成效不明显。

# 关键洞察与建议
原文事实：65.5%的老人子女长期不在身边，独居老人存在无人照料、就医困难等问题；农村养老设施因财政困难运营难以为继；城市社区通过志愿者制度、养老服务中心提供帮扶。
支持的判断：留守老人养老问题普遍且严峻，经济与陪伴是两大核心痛点；农村养老设施重建设轻运营，缺乏可持续资金；城市志愿者制度可复制，但需解决社工专业性与资金问题。
受访者建议：村干部建议请专业施工人陪伴、倡导子女多联系、丰富文化生活、老年协会专项建养老设施并保障运营经费；社工建议发掘中年志愿者、开展小手拉大手活动、23年目标由家长自组织活动、社区协助。
