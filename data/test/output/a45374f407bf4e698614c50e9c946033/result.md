# 知识主题与概述
本笔记围绕调和级数收敛性这一经典数学问题展开，以皮卡在Stack Exchange上评论网友证明方法为背景，系统梳理了级数收敛与发散的定义、分组求和证明、柯西凝聚判别法、积分估计、对数差分及Stolz定理等多种证明思路。皮卡指出，分组求和与柯西凝聚判别法本质一致，是自然且普遍的想法；而对数差分等证明则因事先知道结果而显得故弄玄虚，妨碍理解。笔记整体逻辑框架从定义出发，逐一点评各证明流派，并强调数学证明应追求自然与本质，而非表面技巧。

# 核心概念
### 级数收敛与发散的定义
- **收敛**：对于正向级数，若存在固定实数 a，使得所有部分和 s_n 均小于 a，则称级数收敛。
- **发散**：若部分和 s_n 大于某个无界递增的下界 b_n，即无论给定多大的数，总能通过增大 n 使 b_n 超过它，则级数发散。

### 分组求和证明
- 将调和级数分组：1 单独一组，1/2+1/3 一组，1/4+1/5+1/6+1/7 一组，依此类推。
- 每组和均大于 1/2，因此任意多组相加无上界，故级数发散。
- 皮卡认为该思路与高斯求 1+2+…+100 时分组配对的想法类似，是普遍且自然的求和估计方法。

### 柯西凝聚判别法
- 证明过程与分组求和完全一致，通过分组估计部分和。
- 对非负不增序列，其收敛性与 `∑2^k a_{2^k}` 相同。
- 应用于调和级数时，等价于判断 `∑1` 的收敛性，显然发散。
- 皮卡推测柯西当年正是基于此想法推广到一般非负不增序列。

### 积分估计法
- 利用 `∫1/x dx = log x` 近似部分和 H_n，矩形面积始终大于曲边梯形面积，从而得到下界 `H_n > log(n+1)`。
- 皮卡认为这是正规流派。

### 对数差分法
- 通过 `e^{1/k} > 1+1/k` 放缩，连乘积化简为 n+1，证明发散。
- 皮卡批评此法本质是已知结果后反推，属于故弄玄虚，妨碍理解。

### Stolz定理法
- 比较 H_n 与 log n 的增长级别，利用差分 `(H_{n+1}-H_n)/(log(n+1)-log n)` 求极限为 1。
- 皮卡认为此法不自然，因事先知道答案才选择 log n 作为比较对象。

# 核心结论
### 核心结论
- 调和级数发散，可通过分组求和、柯西凝聚判别法、积分估计、对数差分、Stolz定理等多种方法证明。
- 分组求和与柯西凝聚判别法本质一致，是自然且普遍的想法。
- 对数差分与Stolz定理法因事先知道结果而显得不自然，属于故弄玄虚。

### 易混淆点
- **收敛与发散的定义**：收敛要求所有部分和小于固定上界；发散则要求部分和无界递增。
- **柯西凝聚判别法**：适用于非负不增序列，其收敛性与 `∑2^k a_{2^k}` 相同。
- **对数差分法**：看似巧妙，但本质是已知结果后反推，并非独立新方法。
