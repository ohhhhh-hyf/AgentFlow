# 访谈概况
本次访谈对象包括农村留守老人、村政府和民政局干部、城市社区养老社工等，访谈目的是了解农村留守老人养老现状、政策困境及城市社区养老服务经验。核心议题涵盖独居老人无人照料、就医困难、意外风险，农村养老政策实施情况，以及城市社区志愿者制度、养老服务中心和社工服务。整体反馈基调呈现农村养老资源不足、政策覆盖有限，城市社区服务相对完善但社工供给不足，受访者普遍表达对改善养老服务的期待。

# 核心反馈
农村留守老人核心痛点：**无人照料**，65.5%的老人子女长期不在身边，独居老人存在无人照料、就医困难、意外风险等问题；**精神孤独**，黑龙江绥滨独居老人因寂寞报警，杭州67岁独居老人去世多日才被发现；**经济困难**，农村养老金118元/月，与工人养老金差距大，五保户分散供养生活费475元/月，残疾人低保分160、270、380元三档；**就医不便**，视障老人反映就医障碍。城市社区老人痛点：**社交机会少**，更易产生孤独、抑郁情绪；**心理问题**，社工帮助过一位与邻里关系不和谐、抗拒外界关心的老人。对现有解决方案的不满：农村养老公共设施运营经费缺乏后续支持，地方财政困难；社工工资低、转行率高，专业能力欠缺，项目资金不稳定，服务成效难以持续。

# 关键洞察与建议
核心洞察：农村养老问题受多重因素叠加影响，包括子女外出务工、老人适应能力降低、城市对农村老人存在无形歧视；农村养老政策覆盖有限，五保户和残疾人保障标准较低，养老设施运营经费不足。建议：请专业施工人员进行陪伴，倡导在外务工子女多与老人联系，丰富老人文化生活，建立老年协会专项执行养老设施并保障持续运营经费；城市社区志愿者制度、一对一帮扶、积分兑换礼品、送春联、做月饼、百家宴等活动可借鉴，养老服务中心提供理疗、按摩、老年大学、心理咨询等服务；社工制度需解决供给不足、工资低、专业欠缺问题，政府应加大资金支持，保障项目持续性。受访者倾向性表达：老人需要关爱和陪伴，社区应成为大家庭，志愿者制度需长期坚持并发展新志愿者。
