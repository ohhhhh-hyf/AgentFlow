# 庭审概况
本案为国家开发银行（以下简称国开行）与云南东源电力股份有限公司（以下简称东源煤电）、云南东源曲靖电力有限公司（以下简称曲靖电力）、招银金融租赁有限公司（以下简称招银租赁）金融借款合同纠纷上诉案，由云南省高级人民法院一审（2018云民初88号）判决后，国开行不服，向最高人民法院提起上诉。二审由审判员李少平担任审判长，与审判员魏文超、黄年、王海峰、葛洪涛组成合议庭，法官助理张瑞，于公开开庭审理。庭审围绕三个争议焦点展开：动产抵押与融资租赁登记冲突及善意取得、罚息复息计算、违约金连带责任。经评议，合议庭提出调解方案，各方无异议，达成调解协议。

# 举证与法庭调查
**证据与质证意见**
- 国开行提交2018年9月对曲靖电力公司的融资租赁查询证书，招银租赁质证认为该查询不符合要求，应提供2015年12月抵押时点的人行征信中心查询结果。
- 国开行提交证据第54页、58页，显示东源煤电公司、曲靖电力公司对案涉设备的权属证明材料和股东会决议，证明设备所有权属曲靖电力公司。
- 招银租赁提交一审证据第7页回租设备清单，载明设备名称、生产厂家，但未载明型号；国开行质证认为清单记载出厂日期为2012年3月1日，而现场调查设备铭牌生产日期均在2013年以后，不能认定为同一设备。
- 招银租赁提交2013年、2015年审计报告（证据82页、95页），载明曲靖电力公司注册资本4亿元且已实缴，国开行据此主张招银租赁应当知道设备出资情况。
- 国开行提交证据108页融资租赁登记核查表，显示未查询到曲靖电力公司融资租赁登记信息。

**法官询问要点**
- 合议庭询问各方对中国人民银行征信中心融资租赁登记性质及法律后果的理解。
- 询问融资租赁登记系统有几种查询方式，能否保证查询到登记结果。
- 询问案涉5套设备登记时是否登记唯一识别码。
- 询问国开行内部风控规定是否要求保留未查询到结果的记录。
- 询问融资租赁登记系统设备唯一标识码是否必填项。
- 询问违反查询规范达到何种程度才导致融资租赁司法解释第9条第2款的法律后果，是基本查询义务还是全面审慎义务。
- 询问通过其他途径知晓融资租赁情况是否仍需查询登记系统。
- 询问融资租赁司法解释第9条第2款举证责任如何分担。
- 询问因不同登记机构产生的登记信息冲突有何意见建议。

**双方辩论的争议焦点**
- 国开行是否尽到融资租赁登记查询义务，是否构成善意取得。
- 东源煤电2015年12月2日邮件是否构成对国开行的告知。
- 国开行审查义务是否应扩展至东源煤电。
- 东源煤电出资行为是否系无权处分。
- 融资租赁登记查询义务是基本义务还是全面审慎义务。
- 罚息是否应作为复利计算基数。
- 国开行宣布贷款提前到期是否应给予合理期限。

# 庭审结果
本案争议焦点有三：一是动产抵押与融资租赁登记冲突及善意取得问题；二是一审判决对案涉借款罚息复息的计算及起算日期是否认定错误；三是东源煤电、东源煤业是否应当连带给付违约金。经合议庭评议，提出调解方案，各方当事人均无异议，达成调解协议。调解方案主要内容：国开行对东源煤电债权扣除破产已清偿本金外，利息、罚息、复利三项共计6474.4513万元；招银租赁对涉案6项设备享有所有权，对应债权数额1377.4137万元；国开行对93项设备有抵押权，招银租赁对6项设备有所有权，双方对案涉全部发电设备整体盘活处置，变现款双方各得50%，费用各担50%；调解书生效后20日内由国开行向一审法院提出执行申请，启动司法处置程序；未实现债权待执行法院出具体本裁定后按破产重整计划预留方案实现，若破产管理人不予纳入，由东源煤电按有担保清偿方案清偿；若司法变现不能，双方放弃对案涉设备权益，由东源曲靖电力自主生产经营；案涉设备管理费用由东源曲靖电力承担，东源曲靖电力无条件配合司法处置。各方对一审判决第2项、第4项无争议，按判项内容确认。一审诉讼费用中国开行诉请部分按一审判决执行，招银租赁诉请部分由二审法院按规定计算后由国开行承担；二审诉讼费用由国开行和东源煤电各承担50%。协议签订后各方就本案问题不再存在任何争议。合议庭确认调解协议合法有效，将出具调解书。
