# 讲座概况
会议围绕电影《南京照相馆》展开讨论，由发言人1主导介绍历史背景。发言人3看过抖音切片，发言人4看过电影，印象是灾难电影，老弱妇孺存活，地下室场景；发言人2觉得深刻好看；发言人5因题材不习惯未看。发言人1介绍1937年8月13日八一三淞沪抗战后，国军从上海撤退，日军追击至南京，因缺乏军纪约束导致南京大屠杀。电影主要人物虚构，但照片拍摄真实，实际由美国传教士拍摄，中国冲洗人员偷拷并提交军事法庭作为证据；电影中中华门战斗、挹江门惨案、战犯审判为真实历史。发言人2提到沈阳伪满洲国博物馆、唐山大地震纪念馆参观人多需预约；发言人3提到上海抗战纪念馆人多，南京大屠杀纪念馆难抢；发言人4多年前去过。

# 核心观点与论证
发言人1首先介绍历史背景：1937年8月13日八一三淞沪抗战，国军与日军在上海激战，因实力原因撤退，日军追击至南京。更深层原因是自1931年九一八事变以来，日军占领东北、华北均未遭遇成规模抵抗，八一三淞沪抗战是日军首次遭受迎头痛击，伤亡惨重，加上长达四个月战斗，日军缺乏军纪约束，攻破南京后导致南京大屠杀。电影中主要人物虚构，但照片拍摄真实，实际由两名美国传教士拍摄日军暴行，同时期中国冲洗照片人员无意发现后偷偷拷贝，抗战后提交国民政府军事法庭作为审判日本战犯证据。电影中中华门城墙战斗、挹江门撤退惨案、战犯审判（谷寿夫、第六师团师团长等被枪决）均为真实历史。发言人1还分析日军暴行原因：日军遭受前所未有的侮辱及战场应激创伤，结合日本屠城传统、高压武士道精神，以及指挥官更换——松井石根因病被替换，朝香宫鸠彦亲王上任后发布不留俘虏命令，导致军纪失控。

# 金句总结
发言人1指出：“从他们当时那样的心态来说，觉得遭受了一种前所未有的侮辱，以及在战场上的一种应激创伤反应。”此句关联日军在南京暴行的心理动因。另一金句：“攻破了敌方的城镇，都要以屠城来进行自己那种狂欢与麻痹。”此句解释日军屠城的历史传统。

# Q&A 环节
问：电影里面虚构的，它里面有一个日本的军方关系叫什么？就是主角一度好像和他建立一次友谊吧，不知道这个是虚构的，有没有这个日本军官是不是真实？答：电影里的主要人物是虚构，但照片的拍摄是真实的，但不是以电影里所描述的方式进行的。真实历史是当时两个美国传教士拍摄日军暴行，同时期中国负责冲洗照片的人无意发现后偷偷拷贝，抗战后提交国民政府军事法庭作为审判证据。
