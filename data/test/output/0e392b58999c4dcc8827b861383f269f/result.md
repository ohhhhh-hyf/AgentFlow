# 沟通概况
班主任林瑞在372班家长会上，围绕班级基本情况、教师团队、存在问题及解决思路、计划与措施、给家长的建议等板块与家长沟通。班级共60人（男生25人、女生35人），整体班风纪律良好，但存在少数学生周末玩手机、自习课效率低、个别书写不良等问题。林瑞提出加强手机管理（上交手机、家长不定时电话检查）、制定详细班规、严格请假制度等举措，并建议家长关注学生心理健康与社交账号，注意交通、防溺水等安全教育。家长代表张宇波分享家庭教育经验，强调先做人再学习、尊重孩子、多倾听交流。会议还议定成立家长委员会（至少三人自愿参加）、家长为孩子购买保险（约310多元）、办理电子学生证（套餐78元）等事项。

# 共识与配合事项
## 手机与网络管理

- [ ] **家长**：配合学校手机管理制度，督促孩子每周一至周五按时上交手机，周末在家也需控制使用时间
- [ ] **家长**：不定时拨打孩子手机检查是否处于开机状态，若电话能打通但无人接听，说明孩子可能未按要求上交手机
- [ ] **家长**：清理家中多余手机，只保留一部供孩子使用，避免孩子藏匿多部手机
- [ ] **家长**：检查孩子手机中的社交账号（`QQ`、`抖音`、`快手`等），关注是否存在网瘾、观看不健康内容或早恋迹象
- [ ] **班主任**：在班级设置手机存放箱，每个学生姓名贴好标签，统一管理上交手机
- [ ] **班主任**：对发现的上课玩手机行为按规定处理，发现即收缴

## 学习与纪律管理

- [ ] **班主任**：继续每天加强思想教育工作
- [ ] **班主任**：执行详细班规，该扣分扣分、该写检讨写检讨、该罚站罚站
- [ ] **班主任**：严格请假制度，稳定学习秩序
- [ ] **班主任**：加强班委培训，提升自习课管理效率，自习课允许学生讨论、可离座请教问题
- [ ] **班主任**：定期与科任老师沟通，了解学生课堂表现和学习情况
- [ ] **家长**：关注孩子书写质量，根据学生手册中作业情况判断是否需要购买字帖练习书写
- [ ] **家长**：帮助孩子制定合理的学习目标，参照学生手册中记录的月考目标，下次月考在11月初

## 安全教育与心理健康

- [ ] **家长**：提醒孩子注意交通安全，未满16周岁不得骑电动车，尤其禁止载人
- [ ] **家长**：提醒孩子注意运动安全、饮食安全、防诈骗、防溺水
- [ ] **家长**：关注孩子心理健康，发现异常及时联系班主任进行心理辅导
- [ ] **家长**：关注孩子生活费使用情况，合理控制零花钱，避免过度消费
- [ ] **班主任**：发现校园欺凌等问题第一时间处理，家长遇到孩子异常情况可随时联系

## 家校沟通与家庭环境

- [ ] **家长**：创造和睦、祥和、稳定的家庭气氛，多鼓励少批评，不给孩子过多压力
- [ ] **家长**：避免教育误区——不过分关注、不放任不管、不期望过高、不给过多零花钱
- [ ] **家长**：多抽时间了解孩子在校表现，经常与孩子沟通，了解心理动态
- [ ] **家长**：不在孩子面前长时间玩手机，不聚众打麻将，为孩子创造良好学习环境
- [ ] **家长**：配合学校制度，尊重老师工作，有教育问题及时与班主任沟通

## 保险、电子学生证与资助

- [ ] **家长**：为孩子购买保险，费用约310多元，可在学校购买或自行在`阿里巴巴`等平台购买，购买后需统计上报
- [ ] **家长**：办理电子学生证，套餐78元（移动套餐），方便与孩子联系及请假管理
- [ ] **班主任**：统计保险购买情况，汇总未购买名单
- [ ] **班主任**：将新的电子学生证号码发到家长群，更新联系方式
- [ ] **家长**：关注高中资助政策，高中补助打在医保卡上，需与孩子确认资金用途，防止乱消费

## 家委会成立

- [ ] **家长**：自愿报名参加家长委员会，至少需要三人
- [ ] **班主任**：组织家委会成立事宜，重大事项经班主任与家长探讨后决定
