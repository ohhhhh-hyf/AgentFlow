# 沟通背景与目的
电子科技大学电子科学与工程学院举办招生宣讲会，面向考生和家长介绍学院整体情况、学科方向、师资科研、人才培养及学生体验，以吸引优秀生源。段院介绍学院历史沿革、学科布局、师资规模与科研平台；柳教授介绍电子信息材料与元器件方向；张教授介绍电磁场与微波技术和电路与系统方向；李天明教授介绍物理电子学方向；在读博士田雨桐从学生视角分享选择电子学院的8个理由。宣讲会达成的主要结果是向考生和家长全面展示了学院实力与特色，并解答了夏令营相关问题：学院计划今年举办夏令营，时间待定，相关信息将通过QQ群（978499108）发布。

# 信息同步
**段院（学院整体情况）**
- 学院历史：1956年建校时成立无线电系、电真空器件系、无线电零件系，经1979、1992、2001、2018年四次院系调整成立电子科学与工程学院，2023年成立电子科学与工程学院与集成电路学院。
- 学科布局：一级学科电子科学与技术为国家重点一级学科，下设电磁场与微波技术、电路与系统、微电子学与固体电子学、物理电子学、电磁信息功能材料与机构5个二级学科方向，另有3个国防特色学科。
- 人才培养：本科生1545人，招生专业为工科试验班（电子工程类），含电子科学与技术（国家特色专业、国家级一流本科专业建设点）和电磁场与无线技术两个专业方向；研究生1975人，学硕/博士专业为电子科学与技术、材料科学与工程，专硕/博士为电子信息、材料工程。
- 师资与科研：教师302人（教研系列139人、科研系列95人、教学系列14人、实验系列21人、机关33人），两院院士2人、领军人才19人、青年人才28人；近5年科研经费到账稳定在3-4亿元，牵头获国家科技奖励11项，发表高水平论文2000余篇，专利申请1600余件、授权1300余件。
- 平台与交流：拥有2个国家级平台（国家电磁辐射控制材料工程技术研究中心、微波电子器件国家级重点实验室）、4个国际合作平台、7个省部级科研平台；共建国际姊妹院系2个（香港大学电机工程电子系、香港城市大学电子工程系），主办高水平国际会议13场，学生长短期交流项目20多个。

**柳教授（电子信息材料与元器件方向）**
- 方向内涵：以电子在物质中的输运特性（电磁声光热力、化学生物）为基础，以材料为基础、器件为核心、应用为目标导向；2021年中国集成电路电子产品进口额度达2.8万亿元，约为原油进口量的1.7倍，先进电子材料、元器件、电路系统是我国最紧迫的卡脖子问题之一。
- 研究团队：国家级人才10余人；邓龙江院士的电磁辐射控制材料与技术团队（研究人员19人，年均到账经费3000多万元，获国家科技进步/技术发明二等奖共3项）；张怀武教授的磁电薄膜与微型器件团队（研究人员17人，年均到账经费2000余万元，获科技进步二等奖3项）。
- 平台与条件：依托国家电磁辐射控制材料工程技术研究中心和电磁薄膜与集成器件全国重点实验室，科研面积2万余平米（超净间3000平），建设两条国家重大任务试验生产线，大型设备/系统500余台套。
- 成果与去向：获国家技术发明等奖项共7项；毕业生去向包括英特尔、中芯国际、华为、德州仪器等企业及高校科研院所。

**张教授（电磁场与微波技术、电路与系统方向）**
- 学科方向：电磁场与微波技术含微波毫米波电路、电波传播与电磁兼容、计算电磁学与工程电子学、天线理论与技术4个细分方向；电路与系统含非线性电路与复杂电子系统、射频微波电路与系统、集成电路与系统3个方向。
- 学科历史：始于1956年建校时期，由林为干先生和谢处方先生创建，所属一级学科电子科学与技术入选双一流A类学科。
- 团队与平台：电磁场与微波技术有6个团队，硬件平台含中国高校最先进的微波暗室群体；电路与系统学科1981年开始招收研究生，1988年成立首批博士后流动站，拥有国家级人才4人、教授10人、副教授22人。
- 代表性成果：杨世文教授团队四维天线阵列技术应用于中电14所某大型机载相控阵雷达；樊勇教授团队研制0.22THz、0.34THz、0.42THz雷达成像系统（分辨率小于1厘米），太赫兹通信成果在2023年成都大运会田径项目示范应用；李恩教授团队在生物医学电磁学及成像方向发表大量高水平论文，有20余项国家发明专利。

**李天明教授（物理电子学方向）**
- 学科定义：物理电子学是物理学与电子科学与技术的交叉学科，将物理学最新研究成果应用于电子学产生新电子器件，如微波电子学（微波电真空器件）、光电子学（光电器件）。
- 历史沿革：1956年建校时在前苏联专家帮助下成立电真空器件专业，1979年刘盛纲院士带领成立高能电子学研究所，2001年物理系、应用所、高能所成立物理电子学，2018年成立电子科学与工程学院。
- 发展方向：纵向发展（上游仿真设计、下游系统应用，拥有自主知识产权商用软件MMST和切皮克，引入人工智能）与横向发展（频段从微波上移到毫米波、太赫兹，与医学交叉利用太赫兹成像提高诊断准确性）并重。
- 科研与地位：每年到校科研经费接近2亿元，在学院中最多；为世界上最大的真空器件研究中心，2023年成功举办行业顶级会议，物理电子学方向共9个团队。

**田雨桐（学生视角）**
- 城市与产业：成都是四川省会、国家中心城市、新一线城市，电子信息产业发达，英特尔、华为、京东方等巨头汇聚，提供实践平台和就业资源。
- 学校与专业：电子科技大学是我国电子信息人才培育的代名词，构建了最完整的电子信息学科群；电子科学与技术学科在第4轮学科评估中获A+稳居全国第一。
- 团队与培养：其所在毫米波技术与系统应用团队在樊勇老师带领下围绕五大方向开展研究，团队硕博毕业生实现100%就业率，就业单位有民营企业、大型央国企和头部科研院所。
- 奖助与建议：学院构建全覆盖、高额度、长周期的奖助体系，包括国家奖学金、学业奖学金、专项奖学金、新生奖学金、校园地国家助学贷款和生源地助学贷款；择校建议为先选择研究团队再选择导师，可通过学院网站、文献检索网站（如IEEE、中国知网）了解导师论文和指导研究生情况。
