# 沟通背景与目的
杭州医学院医学技术专业硕士点招生宣讲直播于2026年举行，由检验医学院、生物工程学院党委书记、副院长宋宝峰副教授主讲，面向考生及家长介绍学位点基本情况、学科优势、研究方向、师资队伍、培养与就业及2026年招考计划。学位点于2024年获批，由检验医学院、生物工程学院合署办公，共建学院包括医学影像学院、康复学院和信息工程学院，聚焦检验技术（细分为医检和卫检）、医学影像技术、康复治疗、智能医学工程四个方向，2025年录取64人，其中检验方向38人、影像方向11人、康复方向13人、智能医学工程方向2人。学科建设方面，医学技术学科2023年获批省一流学科B类，近五年获国家级基金项目19项、省鉴定领先项目1项，纵向科研经费1300万，横向合作课题经费2200多万，获省科技进步一等奖2项、二等奖1项、三等奖2项，建有国家级一流本科课程2门、国家级一流本科专业建设点2个及多个省级科研平台。师资队伍有专任教师90人，高级职称53人（占30%以上），博士55人，硕导69人，正高35人，博士占比46人。2026年计划招生34人（仅供参考，以教育部正式下达人数为准），初试科目为思想政治理论、英语（统考）及按方向自主命题的专业课综合，实践分值300分、考试时长180分钟，复试初试占60%、复试占40%，复试内容为英语能力测试20%、专业能力测试40%、综合能力测试40%，复试形式目前以线下为主。

# 信息同步
一、学位点基本情况：医学技术专业硕士点于2024年获批，由检验医学院、生物工程学院合署办公，共建学院包括医学影像学院、康复学院和信息工程学院，聚焦检验技术（细分为医检和卫检）、医学影像技术、康复治疗、智能医学工程四个方向。2025年录取64人，其中检验方向38人、影像方向11人、康复方向13人、智能医学工程方向2人。
二、学科建设与优势：医学技术学科2023年获批省一流学科B类，近五年获国家级基金项目19项、省鉴定领先项目1项，纵向科研经费1300万，横向合作课题经费2200多万，获省科技进步一等奖2项、二等奖1项、三等奖2项，建有国家级一流本科课程2门、国家级一流本科专业建设点2个。省级平台包括省生物标志物与器官诊断转化重点实验室、检验诊断关键技术研究室、康复模块和机器人国际联合实验室、省实验室和安全培训基地、数字化康复装备质量研究中心、脑认知与疾病数字医疗器械质量工程研究中心、浙江省神经系统疾病数字化装备研发重点实验室。学科优势：体外诊断领域显著，疫情期间联合开发新冠核酸检测、抗原检测、抗体检测产品，获NMPA注册；医学影像技术方向在多参数MRI、肿瘤分子影像学、医学图像处理等方面形成优势；康复治疗方向依托省人民医院康复医学科，综合实力强；智能医学工程方向聚焦阿尔茨海默病智能预警生物标志物，居国际领跑水平。
三、研究方向与师资队伍：主要研究方向包括医学检验技术（负责人吕建新教授，聚焦重大疾病新型生物标志物筛选、新发突发传染病标志物、体外诊断技术、新型药物系统、神经免疫与再生等）、卫生检验检疫（负责人金大志研究员，聚焦新发突发传染病病原体检测、艰难梭菌致病机制等）、医学影像技术（负责人徐秀芳教授，聚焦多参数MRI、肿瘤分子影像学、神经导航引导脑肿瘤穿刺、术前功能区定位）、康复治疗（负责人倪祥明教授，聚焦技术研发、神经损伤修复、运动康复、意识障碍促醒、中西医结合）、智能医学工程（负责人李凯教授，聚焦脑认知与脑疾病智能诊疗、健康大数据、脑机接口、中医器械、重大疾病智能诊断）。师资队伍：专任教师90人，高级职称53人（占30%以上），博士55人，硕导69人，正高35人，博士占比46人。人才称号：教育部医学技术类专业技能教授委员会委员、省万人创新人才2人次、浙江省151人才5人、省杰青1人、省高层次创新人才2人、省派义乌市校创新领军团队1个。学科领军人物：吕建新教授（国家百千万人才工程、教育部医学技术类专业教学指导委员会委员、国家自然基金会医学技术检验学科专家组长、中华医学会检验学会教育学组组长等），徐秀芳教授（浙江省151人才第三层次、省高校中青年学科带头人、研究生院院长、医学影像学院院长），叶祥明教授（省人民医院主任医师、二级教授、博导、康复学院院长、省卫生领军人才），金大志研究员（美国华盛顿大学博士后、省创新人才、检验医学院学术院长、省生物标志物与器官诊断转化重点实验室主任），李凯教授（复旦大学公共卫生学院博士、早稻田大学访问学者、信息工程学院院长、智能医学前沿交叉学科研究院执行院长）。
四、硕士培养与就业：培养目标为面向健康中国发展需要，培养熟练掌握医学技术领域专业知识技能、具有创新实践能力的高层次应用型人才。培养方式为教学、专业实践与学位论文相结合，学制三年，最长不超过五年。课程学分：学业课程不少于24学分，专业必修课分方向不少于12学分，专业选修课不少于5-6学分。培养环节：第二学期开题，第三、四学期过程性考核，研二完成，研一第二学期论文答辩。就业方向包括医院科室（检验科、输血科、病理科、放射科、超声科、康复医学科、骨科、神经科、运动医学科等）、疾控中心（CDC）、医药企业与生物技术公司、医疗器械公司、保险公司、药监局、卫健委、海关、高校、研究所等。目前尚无毕业生，但就业前景广阔。
五、2026年招考计划：计划招生34人（仅供参考，以教育部正式下达人数为准）。初试科目：思想政治理论、英语（统考），专业课按方向自主命题：检验综合（分子生物学检验、生物化学检验、微生物学检验）、医学影像技术综合、康复治疗综合、智能医学工程综合。考试大纲包括考试内容、形式、试卷结构、知识点、参考书目。实践分值300分，考试时长180分钟。检验综合占比：卫生生物学检验40%、生物化学检验30%、微生物学检验30%。复试：初试占60%，复试占40%。复试内容：英语能力测试20%、专业能力测试40%、综合能力测试40%。复试形式目前以线下为主。
六、考生问答：就业前景方面，就业面广，可深造读博、进入三甲医院、疾控中心、企业等，研究生学历有核心竞争力。备考建议：暑期是关键时期，英语难度介于四级和六级之间，建议做真题；关注杭州医学院研究生招生网和研究生教育微信公众号获取考试大纲和参考书。跨专业报考：允许非本专业考生跨专业报考，如从事检验的可以报考检验方向。竞赛：学校重视竞赛，研究生在竞赛中取得好成绩，有资源提升改善、专门讲座和培训。交通：学校有三个校区，主校区在市中心黄龙校区，交通便利。
