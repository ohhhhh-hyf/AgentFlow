# 消化专科门诊：患者上腹疼痛病史采集与检查安排

## 就诊概况
本次门诊由消化专科严医生接诊48岁男性患者张学恒，围绕其上腹反复疼痛4年的主诉进行病史采集与检查安排。患者疼痛位于心窝处，有烧灼感，近3个月持续发作，每年春季多发，进食冷硬或刺激性食物、工作紧张劳累时诱发，白天为主，夜间无痛醒；近两个月呕吐数次，吐出酸味黄水样物，呕吐后腹胀缓解。患者一年前与三个月前各出现一次黑便，每次持续约一个月，每日最多两次，大便形状基本正常，两次均住院检查诊断为大便出血，住院两三天后大便转黄；最近三个月未再出现黑便。患者近期服用奥美拉唑和阿莫西林效果不佳，自行加量至每日四五次。严医生要求患者留大便标本以检查有无出血，并预约后天行胃镜检查（因患者爱人后天可请假陪同），胃镜活检后恰逢张大夫查房，便于进一步讨论。初步判断需进一步检查明确，严医生将总结病情后向上级张医生汇报，再商定治疗方案。

## 病史与背景
1. **现病史**：上腹反复疼痛4年，每年春季多发，近3个月持续发作。
  - 疼痛位于心窝处，有烧灼感，进食冷硬食物、刺激性食物（如太辣）或工作紧张劳累时诱发，与油腻食物关系不大。
  - 近3个月疼痛可忍受，白天为主，夜间无痛醒；天气暖和、工作轻松时有不痛的时候。
  - 一年前和三个月前各出现一次黑便，每次持续约一个月，每日最多两次，大便形状基本正常，仅颜色改变（如柏油样）；两次均因工作忙、加班熬夜未及时就医，后经查大便诊断为大便出血，各住院约10天，住院两三天后大便转黄。
  - 近两个月呕吐数次，吐出酸味黄水样物，为早午餐食物，晚上腹胀时呕吐后缓解。
  - 最近三个月未再出现黑便，大便黄色正常，小便正常。
2. **既往史**：16岁时患甲肝，在三医院住院一个月，出院时肝功能正常，此后体检肝功均正常；双眼近视400度，偶尔口腔溃疡。
3. **过敏史**：小时候因扁桃体炎在成都市儿童医院就诊，服用磺胺药后左手起红疹，持续半个月，确诊磺胺药过敏。
4. **用药史**：近期服用奥美拉唑和阿莫西林，效果不佳，自行加量至每日四五次；还服用医务室自配的胃炎合剂，刚开始吃有些效果，停药后疼痛反复。
5. **个人史**：吸烟史，以前每天一包，现限制在10支以内；偶尔饮酒（应酬时喝一点，平时不喝）；长期加班熬夜；喝茶，上班时一天泡两次。
6. **家族史**：父亲76岁，有低血压；母亲75岁，有冠心病，平时吃药控制得比较好；弟弟身体健康；婶婶（叔叔的爱人）患胃癌，患者担心自己是否也会得此病，医生解释婶婶无血缘关系，不必过早担心。

## 诊断与检查结果
1. **初步印象**：上腹反复疼痛4年、近3个月持续发作，伴两次黑便史，**考虑消化系统疾病可能，需进一步检查明确**；医生明确表示目前不必过早担心胃癌问题，需待检查资料更全面后再判断。
  - 患者自述疼痛位于心窝处，有烧灼感，进食冷硬或刺激性食物、工作紧张劳累时诱发，白天为主，夜间无痛醒。
  - 患者因婶婶（叔叔的爱人）患胃癌而担心自己是否患此病，医生解释婶婶无血缘关系，不必过早担心。
2. **既往检查结果**：两次黑便发作时均住院检查，诊断为大便出血，住院两三天后大便转黄；最近三个月未再出现黑便，大便黄色正常。
  - 一年前黑便持续约一个月，每日最多两次，大便形状基本正常，仅颜色改变。
  - 三个月前黑便发作后很快就医，同样查出大便出血并住院。
3. **本次检查安排**：尚未完成相关检查，医生要求留大便标本以检查有无出血，并预约后天行胃镜检查（含活检）。
4. **患者顾虑**：担心是否需要手术，因工作繁忙且领导拟安排出国进修，希望如需手术能尽早安排；医生回应待检查资料全面后再判断，若能药物控制则可不手术。

## 治疗方案与医嘱
1. **检查安排**：
  - 留取大便标本，用于检查有无消化道出血（因患者曾两次出现黑便）。
  - 胃镜预约在后天进行，因患者爱人后天可请假陪同；胃镜活检后恰逢张大夫查房，便于进一步讨论。

2. **用药说明**：
  - 患者近期自行服用奥美拉唑和阿莫西林，效果不佳，且自行加量至每日四五次；医生未在本次就诊中调整用药方案，待检查结果明确后商定。
  - 患者曾服用医务室自配的胃炎合剂，效果亦不持久，停药后疼痛反复。

3. **生活方式与饮食**：
  - **戒烟**：医生明确建议戒烟，认为对疾病恢复有好处。
  - **限酒**：医生提醒酒对胃部疾病影响较大，患者平时不喝酒、偶尔应酬少量饮酒，以后需注意。
  - 避免进食冷、硬及刺激性（过辣）食物，因可诱发上腹疼痛。

4. **复诊安排**：
  - 严医生将总结病情后向上级张医生（指导教授）汇报，再与患者商量下一步处理意见；关于是否需要手术，需等检查资料更全面后再判断。
