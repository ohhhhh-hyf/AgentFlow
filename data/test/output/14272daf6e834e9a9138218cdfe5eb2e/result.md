# 就诊概况
消化内科严医生于门诊接诊48岁男性患者张春和，患者为成都轻工研究所科研人员。本次就诊核心主诉为上腹烧灼感反复发作4年、近3个月加重，伴两次黑便史及近期呕吐。初步判断为上消化道疾病，需进一步检查明确病因。

# 病史与背景
- **现病史**：上腹烧灼感反复发作4年，每年春季多发；近3个月加重，疼痛以白天为主、可忍受，无夜间痛醒。
- **诱因**：进食冷、硬、辛辣食物及工作紧张劳累可诱发或加重。
- **伴随症状**：近4年出现两次黑便（一次在一年前、一次在三个月前），第一次持续约一个月并住院约10天，第二次住院两三天后好转；黑便期间大便每日最多两次、干便、形状基本正常。
- **近期症状**：近两个月出现呕吐，呕吐物为酸水样，含当日或隔日食物，呕吐后舒适；近3个月无黑便，大便黄色正常，小便正常。
- **既往史**：16岁时患甲肝，在三医院住院一个月，出院时肝功能正常，此后体检肝功均正常；无手术史。
- **过敏史**：小时候因扁桃体炎在儿童医院就诊，服用磺胺药后左手起红疹伴瘙痒，持续约半个月，医生诊断为药物过敏，此后不能服用磺胺药。
- **家族史**：父亲76岁有低血压（患者自述血压90/60），母亲75岁有冠心病（服药控制良好），有一个弟弟身体健康；有一个婶婶（叔叔的爱人）患胃癌，患者担心自己是否也患胃癌。
- **个人史**：出生于成都并一直在成都生活，未到过传染病疫区；在成都轻工研究所从事科研工作，工作紧张、经常加班熬夜；有吸烟史（以前每天一包，现限制在10支以内，考虑戒烟），偶尔饮酒，每天喝两次淡茶；26岁结婚，有一小孩，爱人及小孩身体健康。
- **近期用药**：曾服用斯达舒，初有效后效果不佳，剂量从每日两次每次一颗增至每日四五次；近期服用奥美拉唑（武汉药厂产，国产）和阿莫西林，以及医务室自配胃炎合剂，停药后症状反复。

# 诊断与检查结果
医生初步判断为上消化道疾病，需进一步检查明确病因。已安排大便检查以排查出血，并预约后天胃镜。患者有两次黑便史，提示可能存在消化道出血风险；有胃癌家族史（婶婶，无血缘关系），医生解释无需过度担心，但需检查排除。

# 治疗方案与医嘱
- **检查安排**：留大便做检查，以排查出血；胃镜预约在后天进行，因患者爱人可请假陪同。
- **生活方式**：建议戒烟、少喝酒，因吸烟、饮酒对胃肠道疾病影响较大；注意避免熬夜，因工作紧张、经常加班熬夜可能影响疾病恢复。
- **复诊与陪同**：后天做胃镜，需爱人陪同；胃镜后张大夫查房，时间安排较好。
- **用药说明**：近期服用斯达舒、奥美拉唑、阿莫西林及胃炎合剂，停药后症状反复，具体用药调整待检查后由上级医生商定。
