# 沟通概况
班主任林瑞在372班家长会上，面向全体家长介绍了班级基本情况、教师团队、学生存在问题及解决思路，并围绕手机管理、安全教育、家校配合等提出具体要求。班级共60人，男生25人、女生35人；教师团队多为有3年以上经验的老教师和优秀教师，班主任林瑞任教地理学科。会议还说明了保险购买、电子学生证办理、资助政策等事项，并提议成立家长委员会；家长代表张宇波（372班语文老师）分享了家庭教育经验，强调关注孩子身心健康、尊重孩子、多倾听交流。会议基调为加强家校协同，共同促进学生成长。

# 沟通内容
## 学习表现

- **亮点**：班级整体时间观念与执行力较强，班风班貌纪律良好，教室地面干净、卫生状况好。
- **亮点**：学生遇到问题会积极向老师请教，班主任林瑞提到上课时会主动给学生提问机会，学生能主动上来问。
- **亮点**：班级学生普遍关注老师反馈，会主动向老师汇报情况。
- **需关注**：个别学生书写较差，班主任已与家长沟通，建议家长给孩子买字帖练字；班主任展示学生作业时发现班号写错（把372班写成172班）的情况。
- **需关注**：少数学生思考能力较差，尤其在自习课上表现明显。
- **需关注**：下次月考安排在11月初，学生已在学生手册中记录月考目标，家长可查看孩子的目标设定情况。

## 行为表现

- **亮点**：班级纪律整体良好，班风班貌得到班主任肯定。
- **需关注**：少数同学周末沉迷玩手机游戏，玩累后上课表现懒散，约有两三个学生存在此类情况。
- **需关注**：自习课纪律问题突出——班主任在场时学生表现安静，班主任不在时教室乱哄哄，需加强班委培训和管理。
- **需关注**：发现少数男生有网瘾，曾发现学生在周六晚上往游戏充值（有充400元的情况），班主任提醒家长管理好手机并检查学生手机内容。
- **需关注**：有学生观看不健康直播内容，班主任在检查中发现班级男生观看涉及暴力、不健康内容的直播。
- **需关注**：发现学生携带镜子等物品，约10人左右，班主任要求全部收掉。
- **需关注**：存在学生早恋现象，班主任建议家长关注孩子的QQ、抖音、快手等社交账号，注意是否被孩子屏蔽。

## 社交与心理表现

- **需关注**：学生处于初中阶段生理心理持续变化的不稳定时期，需要家长和老师共同引导。
- **需关注**：班主任提醒家长关注学生心理健康，发现异常应及时进行心理辅导。
- **需关注**：有学生周末外出过生日时喝酒、抽烟，违反住校纪律要求，班主任提醒住校生周六也须遵守纪律。
- **需关注**：班主任在班级调查中发现，知道父母生日的学生很少，建议家长加强感恩教育，引导学生体谅父母。

## 手机管理专项

- **需关注**：班主任要求手机统一上交，专门设置手机存放箱，每个学生名字贴好，每人对应存放。
- **需关注**：有学生交一个手机、私留另一个，班主任提醒家长检查家中是否有多个手机，多余的要处理掉，不要留多部手机给孩子。
- **需关注**：班主任建议家长在周一到周五不定时打电话检查，如果电话能打通但没人接，说明学生可能未交手机；如果打过去关机或停机，说明手机已上交。
- **需关注**：班主任提醒家长关注学生手机中的社交应用（QQ空间、朋友圈、抖音、快手等），注意学生是否发布不当内容或存在早恋迹象。

# 家长反馈
- **家长代表身份**：家长代表为372班语文老师，同时也是学生家长，在发言中感谢学校及班主任老师的信任与付出。
- **家庭教育理念**：强调家庭教育要关注孩子身体健康和心理健康，高中阶段仍是孩子长身体的关键时期，家长要给予营养支持，让孩子健康成长。
- **做人教育**：认为做人是必修技能，要让孩子学会做人，不能沾染不良风气，经常对孩子说“先做人”。
- **平常心对待**：孩子面临学习压力很大，家长要有平常心，帮助孩子正确面对挫折和失败，重新定位自己，放下眼前，向往更远的风景。
- **尊重孩子**：孩子从小得到大人尊重，长大后也会尊重别人；要给孩子自由空间，不轻易下消极评价，不以夸耀孩子为自豪。
- **多倾听多交流**：要多与孩子沟通，了解他们的烦恼和事件，给予更多关爱与理解。
- **鼓励而非批评**：分享与儿子的对话，儿子问“妈妈你怎么批评我有钱”，家长回应“无论怎样，那你都是爸爸妈妈心里最优秀的儿子”，认为先批评不当，这样孩子印象更深刻。
- **配合学校**：要遵守学校制度，配合老师工作，做一个有质量的家长。

> “无论怎样，那你都是爸爸妈妈心里最优秀的儿子”

> “先做人”

> “要给孩子一个自由空间，不要轻易给孩子下消极的评价”

- **关注孩子身心健康**：家长代表提出要控制孩子的身体健康和心理健康，高中阶段仍是长身体关键时期。
- **尊重孩子个性**：每个孩子都有自己的个性特点，没有适合所有人的教育方法，家长要尊重孩子的个性差异。
- **多倾听多交流**：建议家长多倾听、多交流，了解孩子的烦恼和真实想法，给予更多关爱与理解。
- **配合学校工作**：要遵守学校制度，配合老师工作，家校协同促进孩子成长。

# 共识与配合事项
## 费用与收费

- [ ] **家长**：确认水费险收费标准（每两周2元/人），如饮用水不够再另行沟通
- [ ] **家长**：确认书费预交11000元尚未结算，待后续结算通知
- [ ] **家长**：未购买书箱的同学，班主任将退还相应费用
- [ ] **家长**：少数同学相关费用约100元左右，无无效费用约70元，具体明细班主任会另行通知
- [ ] **家长**：班主任不会在微信群收取任何费用，需交费用由学生交给生活委员，不在微信转账
- [ ] **家长**：警惕冒充班主任头像在群内收费的诈骗行为，不轻信群内收费消息

## 保险事项

- [ ] **家长**：确认学生保险费用约310元，自愿购买
- [ ] **家长**：可选择在校购买、自行购买或通过手机平台（如阿里巴巴）购买
- [ ] **家长**：购买后配合班主任统计购买情况
- [ ] **班主任**：统计班级学生保险购买情况

## 电子学生证

- [ ] **家长**：自愿办理电子学生证，套餐78元（移动套餐），方便联系学生
- [ ] **家长**：班级目前有老年机且部分停机，能办理的尽量办理
- [ ] **班主任**：将新号码发到家长群，家长需重新补充登记
- [ ] **家长**：原坐席号码9月20几号到期，过期后无法使用

## 资助政策

- [ ] **家长**：查看家长群内发布的资助政策文件
- [ ] **家长**：高中资助与初中不同，所有补助打在学生医保卡上，需关注到账情况
- [ ] **家长**：每次打款后与孩子确认钱款用途（生活费或带回），防止用于不当消费

## 手机管理

- [ ] **家长**：配合学校手机管理制度，学生手机统一上交存放箱，每人名字贴好
- [ ] **家长**：家中多余的手机处理掉，不留多部手机，防止学生藏匿
- [ ] **家长**：周一到周五不定时打电话检查学生手机是否上交（能打通说明未交）
- [ ] **家长**：关注学生手机使用情况，防止网瘾、观看不健康直播等行为
- [ ] **家长**：关注学生QQ、抖音、快手等社交账号，了解是否有早恋迹象

## 住校纪律与安全

- [ ] **家长**：提醒住校学生周六住校也须遵守寝室纪律要求
- [ ] **家长**：提醒学生注意交通安全，未满16周岁不得骑电动车，尤其不得载人
- [ ] **家长**：提醒学生注意运动安全、饮食安全
- [ ] **家长**：提醒学生防诈骗、防溺水，不私下和陌生人外出
- [ ] **家长**：关注防校园欺凌，学生遇到问题第一时间联系班主任处理
- [ ] **班主任**：学生生活小事再小也要管好教育好，及时处理学生矛盾

## 学习与行为管理

- [ ] **家长**：查看学生手册，关注书写情况，个别书写差的学生需购买字帖练字
- [ ] **班主任**：加强班委培训，提升自习课管理效率
- [ ] **班主任**：制定详细班规，严格扣分、检讨、罚站等管理措施
- [ ] **班主任**：严格请假制度，稳定学习秩序
- [ ] **班主任**：定期与科任老师沟通，了解学生课堂表现
- [ ] **家长**：关注学生月考目标（下次月考在11月初），查看学生手册中的目标设定
- [ ] **家长**：收掉学生携带的镜子等违禁物品

## 家校配合

- [ ] **家长**：自愿报名参加家长委员会（至少三人，已有家长自愿报名）
- [ ] **班主任**：组织家委会事项探讨，经班主任和家长探讨通过后成立
- [ ] **家长**：避免教育误区——不过分关注孩子、不放任不管、不期望过高、不给过多零花钱
- [ ] **家长**：多与孩子沟通，多鼓励少批评，适当给压力，关注心理健康
- [ ] **家长**：创造和睦祥和的家庭氛围，不在孩子面前长时间玩手机
- [ ] **家长**：给孩子制定容易达到的小目标，激发潜能
- [ ] **家长**：提醒孩子合理安排饮食，注意补充营养
- [ ] **家长**：关注孩子生活费使用情况，建议每周生活费不超过150元（早餐3-4元、午餐8元、晚餐8元）
- [ ] **班主任**：每天进行思想教育工作
- [ ] **班主任**：及时与家长沟通学生问题
