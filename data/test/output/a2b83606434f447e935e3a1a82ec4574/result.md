# 参观概况
本次参观为故宫博物院全程游览讲解，由导游按中轴线及东西两路动线依次介绍午门、太和门、太和殿、中和殿、保和殿、乾清门、乾清宫、交泰殿、坤宁宫、储秀宫、慈宁宫、断虹桥、武英殿、文华殿、箭亭、钟表馆、珍宝馆、御花园等主要景点，并穿插历史典故与建筑特色讲解。核心主题为提供故宫保姆级游览攻略，帮助游客高效规划路线并了解景点历史。讲解覆盖午门明三暗五门洞及通行规制、太和殿盛大典礼与文东武西站位、乾清宫立储诏书、交泰殿25块传国玉玺、坤宁宫皇后住所等知识，同时介绍故宫内七个免费盖章点及三条按时间与体力划分的游览路线，并推荐珍宝馆为必去之处。

# 核心看点与讲解
- **午门**：排队检票处，明朝皇帝在此杖打犯错大臣，清朝皇帝在此颁发次年历书（颁朔之礼）。门洞呈“明三暗五”格局，中间正门仅供皇帝通行，例外是皇后大婚时可进一次、殿试前三名（状元、榜眼、探花）可出一次，两侧门洞走皇亲国戚和文武百官。
- **太和门广场**：眼前有五座金水桥，皇帝走中间，皇亲国戚走挨着中间的两座，文武百官走最边上的。
- **太和门**：明朝皇帝在此御门听政（上朝）。门口铜狮子是故宫六对铜狮中最大的一对，脚踩寰宇象征权力，建议单独拍照即可，不宜站在其下合影。
- **太和殿**：即金銮殿，是举行盛大典礼的地方，如皇帝登基、皇后册封，文武百官在太和殿广场高呼“吾皇万岁万岁万万岁”，站位遵循“文东武西”——文官站东边，武官站西边。
- **体仁阁与弘义阁**：西边弘义阁（原文如此）是皇帝的银库，东边体仁阁是缎库。
- **中和殿**：举行盛大典礼时皇帝的休息室，文武百官站好后皇帝再前往太和殿。
- **保和殿**：从乾隆五十四年开始作为殿试考场。东北角有汉字馆，内有4枚免费印章，可购买《紫禁城100》现场盖章，且可邮寄到家或自行带走。
- **乾清门**：过此门即后宫（皇帝和妃嫔生活区域），皇帝过去在此上早朝。东边九卿直房是等级高的大臣等待召见之处，西边是军机处。门口铜狮子耳朵耷拉、眉毛遮眼，意在警示后宫之人“不该看的别看，不该听的别听”。
- **乾清宫**：皇帝平时睡觉的地方，据说有27张龙床以防刺客找到皇帝位置。殿内“正大光明”牌匾后藏皇帝立储诏书，皇帝驾崩后与另一份诏书比对以防篡改。门口有铜鹤与铜龟，旁边有社稷江山金殿（原文如此），是紫禁城里最小的宫殿，提醒皇帝把江山社稷、百姓民生放在第一位。
- **交泰殿**：存放25块传国玉玺。
- **坤宁宫**：皇后住所，明朝所有皇后都住这里。东北角有文创店，内有5枚免费印章。
- **储秀宫**：慈禧住了20多年，现为慈禧五十大寿时期原状陈列，慈禧因其子在此出生而偏爱此处。旁边文创店有3枚免费印章。
- **翊坤宫与永寿宫**：翊坤宫、永寿宫为东西六宫中的宫殿，永寿宫西边是东西六宫中唯一被称为“殿”的太极殿。
- **慈宁宫与寿康宫**：慈宁宫是康熙为奶奶孝庄皇太后修建的养老院，旁边寿康宫是甄嬛居住之处（《甄嬛传》打卡点）。
- **冰窖书吧**：内有3枚免费印章，印章造型有批折子的感觉。
- **断虹桥**：桥上有形态各异的石狮子，最有名的是“武当狮”（原文如此），可寻找其位置。
- **武英殿**：后改为陶瓷馆，目前关闭状态，只能在门口看看。
- **文华殿**：与武英殿对应“文东武西”，参观时未开放，据说现有一个展览。
- **箭亭**：清朝皇帝及子孙练习骑马射箭的地方，旁边商店可购买文创雪糕。
- **钟表馆**：展示那个年代的钟表造型。
- **珍宝馆（宁寿全宫）**：强烈建议参观，虽称“馆”但不是单独展厅，院子周围屋子都值得进去。此处是乾隆给自己修建的养老院，乾隆退休后未放权，仍照常上朝办公。皇极殿据说是1:1复刻乾清宫，宁寿宫对标坤宁宫，养性殿后为乐寿堂——故宫里唯一能进去参观的皇家寝室，内有二龙戏珠（原文如此）设计。再往后是珍妃井，当年慈禧把珍妃丢进去，现井口石非珍妃坠入之处。出口右手边商店有3枚免费印章。
- **九龙壁**：珍宝馆门口，是我国现存三座古代九龙壁之一。左边数第三条白龙下方有一块明显不同的琉璃，实为木头——据说是当年烧制时弄坏一块，工匠为保命用刷白漆的木头以假乱真。
- **东筒子夹道**：长长的夹道，拍照非常出片。
- **延禧宫与景仁宫**：延禧宫是网红打卡地，旁边景仁宫是甄嬛被封熹妃时所住，珍妃也住过。
- **御花园**：内有钦安殿，供奉真武大帝；紫禁城靠山景山从天上看酷似闭目盘坐人像，有人说该造型就是真武大帝。
- **神武门**：故宫北门，游览终点。出门左手边有两个盖章点：角楼咖啡有2枚免费印章，故宫文创也有2枚免费印章。

# 互动与体验
- **盖章体验**：保和殿东北角汉字馆有4枚免费印章，可购买《紫禁城100》并现场盖章，导游形容盖章感觉「盖了帽了」，并调侃乾隆喜欢盖章。
- **盖章规则**：故宫内不止一处可购买《紫禁城100》，每家店印章不同，且购买后不能去其他店铺盖章，导游提示「注定得有所取舍」；据称汉字馆印章数量最多，盖完后可选择邮寄到家或随身带走。
- **储秀宫盖章**：储秀宫旁文创店有3枚免费印章，可在此盖章。
- **冰窖书吧盖章**：冰窖书吧有3枚免费印章，导游称印章造型好，盖章时有「批折子的感觉」；导游在此购买了冰溪图。
- **珍宝馆出口盖章**：珍宝馆出口商店有3枚免费印章，导游提醒喜欢收集印章的游客别漏掉。
- **神武门出口盖章**：神武门出口左手边有两个盖章点，角楼咖啡有2枚免费印章，故宫文创也有2枚免费印章。
- **文创雪糕**：箭亭旁商店可购买文创雪糕，导游以提问方式互动，邀请观众在评论区分享雪糕形象是谁。
- **珍宝馆参观体验**：珍宝馆并非单独展厅，院子周围屋子均可参观；馆内游客众多，尤其看凤冠需「没点技术还真挤不进去」。
- **乐寿堂体验**：乐寿堂是故宫内唯一能进去参观的皇家寝室，可见二龙戏珠设计，导游提示会联想到恭王府和珅的卧室。
- **东筒子夹道拍照**：东筒子夹道是很多游客喜欢拍照的地方，导游称「拍照非常出片」。
- **断虹桥打卡**：断虹桥是网红打卡地，桥上有形态各异的石狮子，其中最有名的是「武当狮」，导游邀请游客找一找它在哪。
- **寿康宫打卡**：寿康宫是甄嬛居住地，导游建议喜欢看《甄嬛传》的游客到此打卡。
- **九龙壁细节互动**：珍宝馆门口九龙壁左边数第三条白龙下方有一块明显不同的琉璃，实为木头刷白漆以假乱真，导游以「皇上究竟有没有发现」设问与观众互动。

# 收获与建议
## 历史知识与典故收获
- **午门规制**：午门有“明三暗五”的门洞设计，从正面看三个门洞，进门后可见五个；中间正门仅供皇帝通行，例外是皇帝大婚时皇后可进一次、殿试前三名（状元、榜眼、探花）可出一次，旁边两门走皇亲国戚和文武百官。
- **午门功能**：明朝皇帝在此杖打犯错大臣，清朝皇帝在此颁发第二年历书，称“颁朔之礼”；午门并非斩首之处。
- **太和门与铜狮**：太和门是明朝皇帝御门听政（上朝）的地方；门口铜狮是故宫六对铜狮中最大的一对，脚踩寰宇象征权力，建议单独拍照而非站在其下合影。
- **太和殿用途**：太和殿是举行盛大典礼的场所（皇帝登基、皇后册封），并非上朝之处；文武百官在太和殿广场站列，遵循“文东武西”——文官站东边，武官站西边。
- **体仁阁与弘义阁**：西边弘义阁是皇帝的银库（讲解中称“内裤”，并说明非裤衩子），东边体仁阁是缎库。
- **中和殿与保和殿**：中和殿是盛大典礼时皇帝的休息室；保和殿从乾隆五十四年起成为殿试考场。
- **乾清门与军机处**：乾清门是皇帝上早朝的地方，东边九卿直房是等级高的大臣等待召见之处，西边是军机处；门口狮子耳朵耷拉、眉毛遮眼，意在警示后宫之人“不该看的别看，不该听的别听”。
- **乾清宫与立储**：乾清宫是皇帝寝宫，内有27张龙床，据说是为防止刺客找到皇帝位置；“正大光明”牌匾后藏皇帝立储诏书，皇帝写两份，驾崩后对比，名字不一致则说明诏书被动过手脚。
- **社稷江山金殿**：乾清宫门口有精致小房子“社稷江山金殿”，是紫禁城最小的宫殿，寓意将江山社稷（百姓吃饭、民生问题）放在第一位。
- **交泰殿与坤宁宫**：交泰殿存放25块传国玉玺；坤宁宫住皇后，明朝所有皇后都住于此，与乾清宫对应“乾坤”之意。
- **储秀宫与慈禧**：储秀宫是慈禧住了20多年的地方，现为慈禧五十大寿时期原状陈列；慈禧喜欢此处因其子在此出生。
- **慈宁宫与寿康宫**：慈宁宫是康熙为奶奶孝庄皇太后修建的养老院；寿康宫是甄嬛（影视人物）居住之处。
- **断虹桥与武英殿**：断虹桥是网红打卡地，桥上有形态各异的石狮子，最有名的是“捂裆狮”；武英殿后改为陶瓷馆，目前关闭。
- **文华殿与箭亭**：文华殿在东边，与西边武英殿对应“文东武西”；箭亭是清朝皇帝及子孙练习骑马射箭的地方。
- **九龙壁与珍宝馆**：珍宝馆门口有我国现存三座古代九龙壁之一，左边数第三条白龙下方有一块木头——据说是当年烧制琉璃时弄坏一块，工匠为保命用木头刷白漆以假乱真；珍宝馆实为宁寿全宫，是乾隆给自己修建的养老院，乾隆退休后未放权仍每天上朝办公。
- **皇极殿与乐寿堂**：皇极殿据说是1:1复刻乾清宫，宁寿宫对标坤宁宫；乐寿堂是故宫里唯一能进去参观的皇家寝室，有二龙戏珠（原文“二龙仙楼”）设计。
- **珍妃井**：珍妃井是当年慈禧把珍妃丢进去的地方，井口石为后放，珍妃并非从那个小眼进去的。
- **御花园与钦安殿**：御花园内钦安殿供奉真武大帝；紫禁城靠山景山从天上看酷似闭目盘坐的人像，有人说该造型就是真武大帝。
- **东筒子夹道与延禧宫**：东筒子夹道拍照出片；延禧宫是网红打卡地，景仁宫是甄嬛被封熹妃时所住、珍妃也住过。

## 盖章与文创建议
- **汉字馆**：保和殿东北角，有4枚免费印章，可购买《紫禁城100》并现场盖章，据称印章数量最多。
- **坤宁宫文创店**：坤宁宫东北角，有5枚免费印章。
- **储秀宫文创店**：储秀宫旁，有3枚免费印章。
- **冰窖书吧**：有3枚免费印章，盖章时有“批折子”的感觉。
- **珍宝馆出口商店**：右手边往里走，有3枚免费印章。
- **神武门出口盖章点**：出门左手边角楼咖啡有2枚免费印章，故宫文创也有2枚免费印章。
- **《紫禁城100》购买规则**：故宫内不止一处可购买，每家店印章不同，购买后不能去其他店铺盖章，需有所取舍；可邮寄到家或自行带走。

## 游览路线与时间建议
- **第一条路线（全天）**：走完视频内所有景点，适合打算待一整天的游客；建议早起排队，一进门沿中轴线往后走，可错开大批旅游团，等大部队来时已逛完最重要景点；一天约走3万步，需注意休息和补水。
- **第二条路线（半天）**：进门沿中轴线往后走，看完坤宁宫后去景仁宫、延禧宫，再逛钟表馆和珍宝馆，出来直奔御花园，从神武门出，约半天时间。
- **第三条路线（约2小时）**：进门沿中轴线，看完坤宁宫后去储秀宫，出来去御花园，从神武门出，最省力，适合时间有限、不想走太多路的游客。
- **错峰建议**：早来可错开旅游团人群，在人少时逛完重要景点。
- **钟表馆与珍宝馆**：钟表馆可看那个年代钟表的造型；珍宝馆强烈建议参观，虽名为“馆”但不是单独展厅，院子周围屋子都值得进去看，凤冠展品游客极多、需挤进去看。
