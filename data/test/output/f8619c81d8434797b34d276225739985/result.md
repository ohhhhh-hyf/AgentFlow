# 消化内科门诊病史采集与诊疗安排

## 就诊概况
48岁男性患者张春和，在成都轻工研究所从事科研工作，因上腹烧灼感4年、近3个月加重，于消化内科门诊初诊。患者主诉心窝处反复烧灼感，每年春季多发，近3个月疼痛加重，白天发作、无夜间痛醒，与进食冷、硬、辛辣食物及工作紧张劳累相关，与油腻食物关系不大；近2个月出现数次呕吐，呕吐物为酸水样，含当日或隔日食物，呕吐后缓解；近3个月无黑便，大便正常黄色，饮食量无明显下降，体重在发病时稍下降但很快恢复。既往有两次黑便史（一年前及三个月前各一次），曾因黑便两次住院。医生初步考虑上消化道疾病可能，需进一步检查明确，本次就诊拟安排大便潜血检查及胃镜检查。

## 病史与背景
1. **现病史**：上腹烧灼感4年，每年春季多发，近3个月加重；疼痛位于心窝处，白天发作、无夜间痛醒，疼痛可忍受，有完全不痛的时候；诱因为进食冷、硬、辛辣食物及工作紧张劳累，与油腻食物关系不大。
2. **黑便史**：一年前及三个月前各出现一次黑便，每次持续约一个月，大便呈黑色、质干、形状基本正常，每天最多两次；两次均住院，住院后大便转黄，第一次住院约10天，第二次住院两三天。
3. **呕吐**：近2个月出现数次呕吐，呕吐物为酸水样，含当日或隔日食物，晚上呕吐后缓解。
4. **既往史**：16岁时患甲肝，在三医院住院一个月，出院时肝功能正常，此后体检肝功均正常；小时候因扁桃体炎在儿童医院服用磺胺药后左手起红疹，持续半个月，医生诊断为药物过敏，此后不能服用磺胺药。
5. **个人史**：双眼近视400度，平时不常戴眼镜；偶尔出现口腔溃疡；吸烟史，以前一天一包，现限制在10支以内，计划逐步戒烟；偶尔饮酒，平时不喝；喝淡茶，一天泡两次。
6. **家族史**：父亲76岁有低血压，母亲75岁有冠心病，弟弟身体健康；婶婶（叔叔的爱人）有胃癌，患者担心自己是否也会得胃癌。

## 诊断与检查结果
1. **初步印象**：考虑上消化道疾病可能，需进一步检查明确，尚未确诊。
2. **检查安排**：建议留大便做潜血检查，以明确有无出血；建议做胃镜，患者要求安排在后天，因爱人可请假陪同，医生同意预约在后天。
3. **医生说明**：关于婶婶胃癌的担忧，医生解释婶婶是叔叔的爱人，与患者无血缘关系，不必担心遗传问题；关于手术问题，医生表示待检查资料全面后再判断是否需要手术，若能药物控制则无需手术。
4. **患者顾虑**：患者担心自己是否得了胃癌，担心是否需要手术，因工作忙且所里领导安排出国进修，希望如需手术能尽早安排。

## 治疗方案与医嘱
1. **检查安排**：留大便做潜血检查，以明确有无出血；预约后天做胃镜。
2. **生活方式与饮食**：建议戒烟，因吸烟对身体不好，患者已限制在10支以内并计划逐步戒烟；建议少喝酒，因酒对胃肠道疾病影响大；注意休息，避免经常加班熬夜。
3. **复诊安排**：医生计划将病情总结后向上级张医生汇报，再商定下一步处理意见。
