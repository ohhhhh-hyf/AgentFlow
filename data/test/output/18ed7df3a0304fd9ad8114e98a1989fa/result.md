# 就诊概况
48岁男性患者张学恒，因上腹心窝处反复烧灼样疼痛4年、近3个月加重，于消化专科门诊就诊。疼痛每年春季多发，与进食冷硬、辛辣食物及工作紧张劳累相关，与油腻关系不大；疼痛可忍受，无夜间痛醒，暖和、轻松时缓解，近3个月无完全无痛期。患者曾两次黑便（一年前一次持续约一个月，住院10天；三个月前一次，住院两三天后转黄），近两个月呕吐数次，吐出酸味黄水样物，为当日早中餐食物，晚间腹胀时吐出后缓解，无隔夜食物及红色/黑色呕吐物。近3个月大便黄色正常，小便正常，体重无明显下降，近3个月未做过相关检查。既往16岁患甲肝（已愈），对磺胺药过敏。医生初步判断需进一步检查以明确诊断，已预约后天胃镜，并要求留大便标本排查出血。

# 诊断与检查结果
本次为门诊问诊，尚未给出明确诊断结论。医生初步判断患者上腹疼痛与进食冷硬、辛辣食物及工作紧张劳累相关，需进一步检查明确。已安排**大便检查**以排查出血（因患者曾两次黑便），并预约**胃镜**（后天进行，活检后由张大夫查房）。患者近3个月未做过相关检查。

# 治疗方案与医嘱
治疗计划：待检查资料（大便检查、胃镜及活检）全面后，由上级张医生判断是否需要手术；若药物可控制病情则无需手术。生活注意事项：医生建议患者尽量少抽或不抽烟、少喝酒，因吸烟和饮酒对胃部疾病有不良影响；注意避免进食冷、硬、辛辣等刺激性食物，避免工作过度紧张劳累和熬夜。用药说明：患者自述近期服用药物效果逐渐变差，自行加量后仍不佳，具体用药调整待检查结果明确后由医生决定。
