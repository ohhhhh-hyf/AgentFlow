# 讨论议题与背景
本次会议为一场围绕“18岁以前深刻印象和记忆”的分享型讨论，共6位发言人参与，以编号相称。由发言人1发起话题，引导大家回忆逃课、网吧游戏、追星、阅读等经历。讨论议题范围涵盖：18岁前的逃课与游戏经历、阅读与漫画、电脑游戏与单机游戏回忆、第一人称射击游戏与暴力内容、求生之路与生化危机等游戏讨论、游戏与电影的关系、塔防游戏与使命召唤。整体以分享个人经历和观点为主，未形成统一结论。讨论按议题逐块推进，从逃课经历切入，依次展开游戏、阅读、漫画等话题，并穿插对游戏内容与现实事件关联的探讨。会议提及的关键锚点包括：发言人1初中走读时每周一下午4点放学后去游戏厅、网吧；穿越火线（CF）为2008年国服开启的游戏；求生之路第二部因血腥暴力要求18岁以上才能注册Steam账号。

# 发言要点
## 18岁前的逃课与游戏经历

1. **发言人1**：初中走读，每周一下午4点放学后去游戏厅、网吧，当时流行穿越火线（CF）、反恐精英online（CS online）、使命召唤、战地、魔兽等游戏；高中因高考压力不敢逃课，转而追星、搞乐队，喜欢朋克金属音乐。
2. **发言人2**：18岁前未逃过课，大学后逃过一次；发言人3认为逃课是正常现象，发言人4补充上大学后不算。

## 18岁前的阅读与漫画

1. **发言人5**：喜欢郭敬明的小说，还提到当时的一些杂志。
2. **发言人2**：认为郭敬明的小说让人难受，提到《梦里花落知多少》；自己喜欢看漫画，还提到意林、读者、故事会等杂志。
3. **发言人4**：班上流行看柯南。
4. **发言人1**：流行看柯南和老夫子，老夫子是香港漫画；发言人5提到萌化三国。

## 电脑游戏与单机游戏回忆

1. **发言人4**：提到摩尔庄园、赛尔号。
2. **发言人2**：提到穿越火线、地下城与勇士；初中玩魔兽争霸（非魔兽世界）。
3. **发言人1**：初中流行CS online，高中时单机最流行求生之路，联机局域网玩。
4. **发言人5**：玩过仙剑四，还提到英雄联盟、DOTA，并讨论鄙视链。
5. **发言人2**：认为撸啊撸和DOTA有鄙视链，王者荣耀在鄙视链最底端。

## 第一人称射击游戏与暴力内容

1. **发言人1**：玩过CS1.5、1.6，因在贴吧和QQ空间写文章骂穿越火线被平台封禁，成为CS铁杆粉；最喜欢僵尸模式，曾被舞蹈队说跳舞姿势像舞体僵尸。
2. **发言人5**：质疑游戏暴力且无年龄限制，认为同龄人里没怎么玩过穿越火线。
3. **发言人1**：解释求生之路第二部血腥暴力，可用东洋刀、电锯和砍刀砍丧尸，能把脑袋和四肢砍飞、血喷一脸，因此未成年人不能注册Steam账号，需18岁以上。

## 求生之路与生化危机等游戏讨论

1. **发言人1**：认为求生之路制作团队精准预测了美国政府在新冠疫情中的表现——政府默不作声、病毒失控、军队暴力清理、主角团自救；2020年疫情后游戏重新火爆。
2. **发言人2**：提到欧美玩家喜欢打僵尸游戏，模式一上线欧洲玩家就疯狂在线。
3. **发言人1**：提到生化危机也是病毒泄露、政府不作为，生化三用核武器把整个城市夷平。
4. **发言人2**：认为生化危机挺恐怖，不敢玩；发言人4认为挺抓人，发言人1补充剧情和背景音乐设计诡异。

## 游戏与电影的关系

1. **发言人2**：询问游戏与电影先后。
2. **发言人1**：生化危机先有游戏后有电影；求生之路在惊变48小时、生化危机基础上，先有电影后有游戏。
3. **发言人4**：提到变形金刚，询问先有的什么。
4. **发言人1**：变形金刚先有玩具，后有MV和电影，提到绿日（Green Day）乐队出过介绍变形金刚的MV。

## 塔防游戏与使命召唤

1. **发言人3**：小时候经常玩塔防游戏，现在也还在玩植物大战僵尸、Kindle rush。
2. **发言人2**：提到植物大战僵尸有特别变态的版，后期满屏子弹导致电脑卡顿。
3. **发言人2**：认为使命召唤太男性化。
4. **发言人1**：介绍使命召唤黑色行动背景为冷战时期美国和苏联的明争暗斗；现代战争第一部涉及车臣战争、伊拉克战争、海湾战争，但后来美国挑衅俄罗斯、俄罗斯反杀到美国本土的情节结合俄军在乌克兰表现，有点高估俄罗斯。

# 共识形成
- **一致意见**：与会者普遍认同18岁前逃课、网吧游戏、追星、看漫画小说等是共同的时代记忆；对穿越火线（CF）、反恐精英（CS）、求生之路、生化危机等游戏均有接触，并认可这些游戏在当时学生群体中流行。
- **倾向性认识**：发言人1认为求生之路制作团队精准预测了美国政府在新冠疫情中的表现，2020年疫情后该游戏重新火爆；发言人2补充欧美玩家热衷打僵尸类游戏，此观点未遭反驳。
  - **游戏与电影先后**：发言人1认为生化危机先有游戏后有电影、求生之路先有电影后有游戏；发言人4询问变形金刚先后，发言人1主张先有玩具后有MV和电影，发言未形成统一结论。
  - **游戏暴力与年龄限制**：发言人5质疑求生之路等游戏暴力且无年龄限制；发言人1解释求生之路第二部血腥暴力，未成年人不能注册Steam账号、需18岁以上，双方未就限制合理性达成一致。
  - **游戏鄙视链**：发言人5提出英雄联盟、DOTA、王者荣耀间存在鄙视链，发言人2回应王者荣耀处于鄙视链底端，未深入展开。
