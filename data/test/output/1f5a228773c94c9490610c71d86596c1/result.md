# 研讨背景与议题
本次圆桌论坛由一位主持人（代表多模态大模型与具身智能融合方向）组织发起，邀请多位老师与博士生围绕具身智能领域的关键技术路线与产业前景展开研讨。参与方包括穆老师（机械与传感器方向）、王岳老师（强化学习方向）、赵昊老师（计算机视觉方向）、杨立新老师（真机数据采集）、李欣老师、静波老师、业界嘉宾，以及雄辉、薛寒、志龙等博士生，分别来自强化学习、柔性物体操作、具身世界模型等方向。研讨旨在碰撞不同流派观点，探讨具身智能从技术路线到产业落地的核心问题。讨论覆盖大模型架构与硬件形态、世界模型定义与构建、强化学习与模仿学习路线之争、数据采集与仿真数据、国产仿真系统等五个议题，确认了软硬件协同、混合策略学习等观点，并遗留了世界模型统一性、国产仿真系统等未决问题。

- **具身智能大模型架构与硬件形态**：探讨大模型应采用端到端还是分层架构，以及具身智能的最终形态是人形还是特种机器人，涉及软硬件协同优化与产业前景判断。
- **世界模型的定义与构建**：讨论强化学习与计算机视觉两个领域对世界模型的不同理解，核心分歧在于是否需要3D表征与物理规律建模，以及世界模型能否统一。
- **强化学习与模仿学习的路线之争**：分析两大策略学习流派各自的局限，探讨先模仿后强化、混合策略等可行路线，以及真机场景下reward的获取问题。
- **数据采集与仿真数据**：比较真机遥操数据、仿真生成数据与互联网视频数据三种数据来源的质量与成本，讨论如何规模化采集高质量数据。
- **国产仿真系统**：讨论中国是否强依赖英伟达生态，以及国产仿真系统能否出现并支撑具身智能发展。

# 核心观点
- **大模型架构与硬件形态**：主持人提出端到端模型与分层模型之争，以派灵收集6000多小时数据训练端到端模型为例；穆老师从机械角度反问具身形态收敛方向，举例星际穿越中的变形机器人；王岳老师认为大模型不应完全端到端，至少应分两层，大脑不变、小脑自适应肢体，以手断后大脑仍能工作为例；赵昊老师从产业角度分析，认为具身智能是手机和汽车之后的第三个万亿级市场，融资将经历四波，分别对应自动驾驶、大模型、互联网的规模，并提到马斯克公司花一半精力做灵巧手，实现22自由度，车厂和微电子制造厂已有97%以上自动化使用机械臂。结论是人形机器人和特种机器人将来都会存在。
- **世界模型定义与构建**：志龙从强化学习角度阐述世界模型的可交互性，可追溯到1990-1991年Sutton的Dyna-Q文章，2018年Schmidhuber和LeCun定义包含表征和转移两个组件；赵昊老师从CV角度强调三维重建，认为CV界追求重建物理世界可作为RL世界模型的工具，并提到UniSim需要3D inductive bias，梦想写一篇data bias trade off的paper；王岳老师举例刺客信条游戏与真实世界跳楼的不同结局，认为世界模型无法同时建模两个dynamics，可能做不到统一，但policy有可能统一；薛寒博士提出不同物理结构可以有统一表征，王岳老师认为需要加condition，工程难度高。结论是世界模型在RL和CV界关注点不同，是否需要3D inductive bias由数据决定。
- **强化学习与模仿学习路线之争**：业界嘉宾分享公司采用模型强化加机理融合的方式，认为监督学习数据分布不足以覆盖高维动作空间，纯强化学习强依赖仿真环境，sim-to-real迁移困难，其强化PC工作考虑任务分层，上层强化学习，底层用MPC或DWA等传统方法；薛寒博士认为复杂任务应先模仿后强化，单独模仿或单独强化都不行，举例AlphaStar和GPT都是先模仿后强化；王岳老师认为PID有反馈，可作为强化学习的reward；李欣老师认为模仿学习和强化学习并不冲突，只是获取运动先验的不同方式。结论是当前阶段应采用混合方式，先模仿后强化是实际可行的路线。
- **数据采集与仿真数据**：杨立新老师提到Open X数据集相机视角不固定，影响模型表现，强调标定重要，手眼标定问题至今未完全解决，Open X数据集缺少物体运动信息，orkin从采集时记录物体运动；薛寒博士提到柔性体操作如叠衣服、系鞋带等任务仿真困难，UCLA蒋正凡老师做过高性能仿真技术，认为reward数据是低成本方案，现实生活是最好的仿真器，派灵收集1万小时数据但离GPT-3级别还远，终极数据采集形态是脑机接口或机电方式，互联网视频数据与机器人所需数据不同，例如叠衣服视频都是平铺状态；主持人提到自己洗ego4d数据集洗了三个月，仿真数据加少量真机数据可显著提升成功率，例如300条仿真数据加20条真机数据；赵昊老师认为真实数据还是仿真数据要看成本，case by case。结论是仿真数据与真实数据结合是有效方案，未来应重视无标注数据。
- **国产仿真系统**：主持人提到Isaac Sim/Isaac Lab开放了柔性物体仿真接口，是目前最好用的；赵昊老师提到朋友宋应赌国产替代，认为会被卡脖子，技术上会统一，但business上复杂。

# 达成共识与解决方案
- **软硬件协同优化**：主持人（多模态大模型与具身智能融合方向）与王岳老师一致认为，具身智能是软硬件协同进化的范式，依据是松灵机器人两代产品在遥操与策略部署上的代际提升，以及加凝胶夹爪在触觉反馈与摩擦力上的改进。**结论：具身智能必须走软硬件协同优化路线**。
- **大模型分层架构**：王岳老师提出大模型不应从上到下完全端到端，至少应分两层——大脑不变、小脑自适应肢体，依据是手断后大脑仍能工作、底层控制需适配新动力学的类比；主持人对此表示认可。**结论：端到端模型与分层模型并非互斥，分层架构更利于硬件迭代**。
- **人形与特种机器人并存**：穆老师提出具身形态收敛问题后，赵昊老师从产业角度分析，认为人形机器人（如马斯克公司投入一半精力研发的22自由度灵巧手）与特种机器人（如车厂、微电子制造厂中已实现97%以上自动化的机械臂）将来都会存在。**结论：人形机器人和特种机器人将长期并存**。
- **世界模型定义差异**：志龙（强化学习方向）与赵昊老师（计算机视觉方向）就世界模型定义达成部分共识——CV界追求重建物理世界，可作为RL中世界模型的工具；分歧在于RL更强调可交互性，CV更强调三维表征，这一现状由学术发展阶段导致。**结论：世界模型在RL和CV界关注点不同，是否需要3D inductive bias由数据决定**。
- **混合策略学习路线**：业界嘉宾、薛寒博士、王岳老师、李欣老师一致认为，当前阶段应采用混合方式，先模仿后强化是实际可行的路线。业界嘉宾分享公司采用模型强化加机理融合的方式，上层强化学习做决策、底层用MPC或DWA等传统方法执行；薛寒博士举例AlphaStar和GPT都是先模仿后强化，单独模仿或单独强化都不行；王岳老师认为PID有反馈，可作为强化学习的reward。**结论：复杂任务应先模仿后强化，当前阶段监督学习与强化学习各有局限，需融合使用**。
- **仿真数据与真机数据结合**：主持人分享实验数据，300条仿真数据加20条真机数据可显著提升策略成功率，而纯仿真数据（300条）直接迁移真机成功率很低；薛寒博士认为reward数据是低成本方案，现实生活是最好的仿真器。**结论：仿真数据与真实数据结合是有效方案，仿真数据可覆盖物体随机位置与初始状态，少量真机数据用于微调**。
- **数据质量把控**：杨立新老师与主持人就数据质量达成一致——视角固定与标定是影响模型表现的关键因素，Open X等数据集因相机视角不固定、缺少物体运动信息而质量受限；杨立新老师强调orkin从采集时记录物体运动，主持人提到自己洗ego4d数据集洗了三个月。**结论：数据采集需控制视角与标定，并记录物体运动信息**。
- **无标注数据方向**：赵昊老师提出2025年应迈向大规模利用无标注真实数据，类比segment anything和depth anything的成功，认为不应再局限于讨论真实数据与仿真数据的比例（1:9、2:8、5:5等）。**结论：未来应重视无标注数据，作为有标注数据之外的第三个数据域**。
- **国产仿真系统**：主持人提出中国是否强依赖英伟达生态的问题，赵昊老师回应称宋应团队在做国产替代生意，赌的是被卡脖子；赵昊老师认为技术上会统一，但business上复杂。**结论：国产仿真系统有市场需求，但产业问题复杂，技术标准化后问题不大**。

# 未决分歧与后续探索
- **具身智能最终形态**：穆老师从机械领域提出，具身形态会收敛为人形机器人还是如《星际穿越》中可变形的大方块等特种形态，并指出机械领域有通过软手等硬件实现高顺应性抓取的「机械智能」路线；赵昊老师认为人形机器人和特种机器人将来都会存在，人形因现实环境为人设计而占很大比例，特种机器人已在车厂、微电子制造厂实现97%以上自动化。需验证的是人形与特种形态各自的应用边界与占比，暂无明确跟进方。
- **大模型架构是否应完全端到端**：主持人提出是采用一个端到端模型，还是前段固定、后段接Action refiner的分层方案；王岳老师主张不应从上到下完全端到端，至少应分两层——大脑不变、小脑自适应肢体，并以人手断后大脑仍能工作、底层控制需适配新构型为例；赵昊老师认为若大模型直通最底层会消除硬件迭代可能性，新硬件出现时前段模型需完全重新训练。需验证分层架构在硬件更换时的重训成本与泛化能力，暂无明确跟进方。
- **世界模型是否需要3D inductive bias**：赵昊老师认为CV界追求重建物理世界，UniSim等工作需要3D inductive bias，但数据规模扩大后可能不再需要，并梦想写一篇「data bias trade off」论文；志龙从强化学习角度认为世界模型第一要义是可交互，3D信息只是可引入的补充模态。赵昊老师提出由数据量决定，需验证数据规模与inductive bias需求之间的权衡关系，暂无明确跟进方。
- **世界模型能否统一**：王岳老师以刺客信条游戏与真实世界跳楼结局不同为例，认为一个世界模型无法同时建模两个dynamics，世界模型可能做不到统一，但policy有可能统一；薛寒博士提出不同物理结构最后可有相同统一表征，王岳老师回应需加condition，工程难度高，M个独立模型比一个高维可控模型更简单。需验证统一世界模型在工程上的可实现性与复杂度，暂无明确跟进方。
- **强化学习与模仿学习的最终路线**：业界嘉宾认为当前阶段监督学习数据量不足、仿真环境不够好，应采用模型强化加机理融合的混合方式；薛寒博士认为复杂任务应先模仿后强化，单独模仿或单独强化都不行，并以AlphaStar和GPT为例；李欣老师认为两者并不冲突，只是获取运动先验的不同方式。需验证先模仿后强化在工程上能否解决学术界宣称的「先模仿再强化会不好」的问题，暂无明确跟进方。
- **真机reward获取方式**：主持人提出若以RL作为最后环节，真机复杂任务的reward如何获取，因仿真有上帝视角而真机传感器有偏差；王岳老师认为PID能做的系统必然有反馈，可完全拿该反馈作为强化学习的reward。需验证该反馈作为reward在复杂任务中的有效性，暂无明确跟进方。
- **中国是否强依赖英伟达生态**：主持人提出Isaac Sim/Isaac Lab是目前最好用的柔性物体仿真接口，询问未来中国是否强依赖英伟达生态，还是能有国产产品支持仿真；赵昊老师回应朋友宋应赌国产替代、认为会被卡脖子，技术上会统一但business上复杂。需验证国产仿真系统的可行性与产业路径，暂无明确跟进方。
- **数据采集路线**：薛寒博士主张all in reward采集，认为现实生活是最好的仿真器，终极形态是脑机接口或机电等可穿戴设备实现无感多模态采集；主持人认为仿真数据可提供海量随机初始状态，配合少量真机数据（如300条仿真加20条真机）可显著提升成功率；赵昊老师认为真实数据还是仿真数据要看成本，case by case，并主张2025年应推广无标注真实数据的大规模利用。需验证可穿戴设备采集的精度能否覆盖遥操数据的gap，以及无标注数据在具身智能中的有效性，暂无明确跟进方。
