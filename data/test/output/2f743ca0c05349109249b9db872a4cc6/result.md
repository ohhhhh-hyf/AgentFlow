# 发布会概况
本次会议由中金公司策略组刘刚凯文主持，为每周一度的中金宏观策略周会，围绕大美丽法案、关税谈判、港股流动性、光伏反内卷、人形机器人和游戏板块展开。刘刚凯文解读大美丽法案三大块：提高债务上限约5万亿美元、延长2017年减税（新增支出3.4万亿、一年3400亿）、取消899条款，认为对信用周期中长期有利，但7-9月有约1万亿发债抽水效应，美债利率或上行，波动提供再配置机会。关税方面提出四点信息：一定会做以支撑收入、需维持10-12%有效税率（可收3000-4000亿）、不能太高、市场逐渐脱敏，关注8月1日和8月12日中美谈判及转口限制。港股7-9月美元流动性边际收紧，港币在7.84-7.85，金管局会收流动性但可小幅收，三季度流动性不如二季度，港股在23000-24000区间震荡。刘佳妮介绍光伏反内卷，郭文秀分析人形机器人三季度三条主线，张雪琴更新游戏板块政策与产品周期。整体基调为在合适位置配置长期正确板块，不悲观。

# 核心信息
大美丽法案三大块：提高债务上限约**5万亿美元**；延长2017年减税，新增支出**3.4万亿**、一年**3400亿**，同时减少新能源补贴**1.4万**；取消899条款。7-9月发债抽水效应约**1万亿**，2023年三季度曾发1万亿债推高美债利率从**3.8%至5%**，美股跌约**4-5%**。关税有效税率约**10-12%**，可收**3000-4000亿**，最极端回到**18%**；通胀年底约**3.3-3.4%**。港股港币在**7.84-7.85**，指数区间**23000-24000**。光伏2025年全球需求**650-700GW**，产能过剩：电池**1.5倍**、硅片组件**2倍**、硅料**2.5倍**，价格下跌**70-90%**；多晶硅期货反弹至**40元/公斤**，硅片报价涨**10%**；光伏玻璃7月计划降产**30%**。人形机器人二季度A股板块跌约**9%**、跑输机械**12个百分点**，宇树科技年收入破**10亿**，智元与宇树中标中国移动**1.2亿**订单。游戏6月版号单月**158个**创新高，1-5月游戏市场规模同比增长**17%**超**1400亿**，手游增长**20%**，TTM PE约**30倍**、2025年静态PE约**20倍**。

# 官方表态
刘刚凯文：大美丽法案中长期对信用周期有利，但三季度有流动性波折，美股美债波动提供再配置机会，不悲观。> 「波动提供再配置的机会，我们重申我们这个观点并不悲观。」关税大概率是谈判技巧，有效税率约10-12%，通胀压力有但不会太大。港股三季度流动性边际收紧，建议低迷时介入、亢奋时锁定利润。刘佳妮：反内卷政策有望夯实行业底部，硅料整合最迫切，头部一体化组件企业和财务健康企业穿越周期能力较强。郭文秀：三季度是二季度迷茫期到商业兑现的过渡阶段，建议关注华为云生态接入、头部企业出货量跨越年化500台或1000台、电机硬件优化三类信号。张雪琴：游戏板块在消费政策和新品周期三重利好下，有望在调整后再次实现戴维斯双击，当前是好的配置时间点。

# Q&A环节
问：关税威胁是否只是谈判技巧，还是可能真正实施？ → 答：刘刚凯文提出四点信息，关税一定会做以支撑收入，需维持10-12%有效税率，不能太高，市场逐渐脱敏；姑且认作谈判技巧。问：加拿大、墨西哥、欧盟的关税谈判能否谈妥？ → 答：这三个贸易占比太高，一定要和他们谈妥，其他国家对有效税率影响很小。问：8月12日中美谈判进展及转口限制如何？ → 答：需密切关注8月12日中美谈判进一步进展，尤其是一些转口的限制，越南转口限制是40%，我们比这个税率还要低。问：光伏反内卷具体干预措施尚未披露，政策最终如何落地？ → 答：目前细节来看并没有看到一个干预措施的具体披露，但随着反内卷力度不断强化升级，价格的恶性竞争有望告一段落。问：组件价格能否跟涨，下游电站能否接受产业链价格上涨传导？ → 答：组件价格也有跟涨意愿，但下游电站受136号文影响，电价不确定性大幅增加，能否接受传导还需观望未来一段时间招标情况。问：特斯拉Optimus硬件问题何时解决，供应商筛选结果如何？ → 答：特斯拉在变更方案，供应商层面还在筛选，硬件瓶颈是行业共性瓶颈，关注电机过热、灵巧手负载不足、续航问题及轻量化方向。
