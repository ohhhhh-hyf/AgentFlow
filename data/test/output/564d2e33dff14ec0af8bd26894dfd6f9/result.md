# 讨论议题与背景
本次讨论由发言人1、发言人2、发言人3、发言人4共同参与，以《白夜行》为引，漫谈日本、法国、英国、俄国、美国等国文学特点及《西游记》狮驼岭章节。发言人1从《白夜行》悬疑叙事手法谈起，认为其结局阴暗；发言人2提及《菊与刀》对日本人性格的描绘，并引导比较各国文学。讨论涉及法国文学描绘底层与浪漫理想主义、英国文学写贵族生活与底层鸿沟、俄国文学揭露人性丑恶、美国文学历史较短多表现现代社会，以及台湾电影《假如我是真的》与知青上山下乡、《西游记》狮驼岭对佛教的批判。会议为自由漫谈，未形成明确决议或分工。

# 发言要点
发言人1：认为《白夜行》叙事手法隐藏、结局阴暗；法国文学有抗争精神，英国狄更斯作品讲贵族与穷人鸿沟、宗教虚无，国内底层小说因政策原因受限；提及《一九四二》讲大饥荒与战乱。发言人2：以《菊与刀》描绘日本人性格，引导各国文学比较；认为法国文学有浪漫理想主义，俄国文学更讽刺、揭露人性丑恶，提及《古拉格群岛》《钦差大臣》、格罗斯曼《命运与生活》、高尔基《海燕》；讲述台湾电影《假如我是真的》结合文革真实事件与果戈里《钦差大臣》；详述《西游记》狮驼岭青狮、白象、大鹏作妖吃人，距灵山约500公里，批判佛教虚伪并联系旧社会西藏。发言人3：参与提问与话题引导，提及哈利波特、俄国文学等。发言人4：认为法国小说描绘底层民众多于英国贵族生活，俄国戏剧性更明显，只读过《简爱》。分歧点：对法国与俄国文学描绘底层谁更生动存在不同看法，发言人4认为俄国更曲折、戏剧性更明显。
