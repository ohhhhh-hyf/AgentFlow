# 参观概况
本次参观为故宫游览攻略讲解，围绕午门、太和殿、乾清宫、珍宝馆等主要景点展开，介绍历史典故、盖章点及三条游览路线。讲解从午门检票进入，沿中轴线依次参观太和门、太和殿、中和殿、保和殿、乾清门、乾清宫、交泰殿、坤宁宫、储秀宫、慈宁宫、断虹桥、武英殿、文华殿、箭亭、钟表馆、珍宝馆、东筒子夹道、延禧宫、景仁宫、御花园，最后从神武门出。全程约一天，讲解者实际走了3万步。

# 核心看点与讲解
- **午门**：三个门洞，进门后变五个，即明三暗五；中间正门仅供皇帝、皇后大婚、殿试前三名通行，两侧门走皇亲国戚和文武百官。
- **太和门广场**：有五座金水桥，中间桥供皇帝，两侧桥供皇亲国戚和文武百官。
- **太和门**：明朝御门听政之地，门口铜狮子是故宫六对铜狮中最大的一对，脚踩寰宇象征权力。
- **太和殿**：举行盛大典礼之地，如皇帝登基、皇后册封；文武百官在太和殿广场站列，文东武西。
- **中和殿**：举行盛大典礼时皇帝的休息室。
- **保和殿**：从乾隆五十四年开始作为殿试考场。
- **乾清门**：后宫入口，东边九卿直房，西边军机处；门口狮子耳朵耷拉、眉毛遮眼，警示后宫不该看的不看。
- **乾清宫**：皇帝睡觉的地方，有27张龙床，牌匾“正大光明”后藏立储诏书。
- **交泰殿**：放25块传国玉玺。
- **坤宁宫**：住皇后，明朝所有皇后都住这。
- **储秀宫**：慈禧住过20多年，五十大寿原状陈列，其子在此出生。
- **慈宁宫**：康熙为孝庄皇太后修建的养老院；寿康宫是甄嬛居住地。
- **断虹桥**：石狮子形态各异，最有名的是武当狮。
- **武英殿**：改为陶瓷馆，目前关闭。
- **文华殿**：有展览，但未开放。
- **箭亭**：清朝皇帝练习骑马射箭之地，旁边商店有文创雪糕。
- **钟表馆**：展示各种钟表。
- **珍宝馆**：宁寿全宫，乾隆养老院；皇极殿1:1复刻乾清宫，乐寿堂是唯一能进去参观的皇家寝室，有珍妃井。
- **东筒子夹道**：拍照出片；延禧宫是网红打卡地，景仁宫是甄嬛封熹妃时住处。
- **御花园**：有钦安殿，供奉真武大帝；北边景山酷似真武大帝。
- **神武门**：北门，出门左手边有角楼咖啡和故宫文创两个盖章点。

# 互动与体验
- **盖章互动**：保和殿东北角汉字馆有4枚免费印章，可购买紫禁城100并现场盖章，每家店印章不同，购买后不能去其他店铺盖章，汉字馆印章数量最多。
- **盖章互动**：坤宁宫东北角文创店有5枚免费印章；储秀宫边文创店有3枚免费印章；冰窖书吧有3枚免费印章，印章造型好，购买了冰溪图。
- **盖章互动**：珍宝馆出口右手边商店有3枚免费印章；神武门出门左手边角楼咖啡有2枚免费印章，故宫文创有2枚免费印章。
- **盖章互动**：共标注七个免费盖章位置，可截图保存。
- **文创雪糕**：箭亭旁边商店可购买文创雪糕，讲解者提问雪糕形象是谁，欢迎评论区分享。
- **拍照体验**：东筒子夹道拍照非常出片，是很多小姐姐喜欢来的地方。
- **个人感受**：钟表馆的钟表造型令人开眼；珍宝馆宝贝惊艳，但游客太多，尤其是看凤冠的挤不进去。
