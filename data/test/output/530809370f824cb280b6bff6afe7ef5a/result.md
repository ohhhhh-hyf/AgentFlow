# 报告概况
《政府工作报告》由国务院总理李强在第十四届全国人民代表大会第三次会议上代表国务院作报告，报告期间为2024年全年及2025年工作部署。报告回顾2024年工作，指出经济运行总体平稳、稳中有进，国内生产总值达134.9万亿元、增长5%，城镇新增就业1256万人，居民消费价格上涨0.2%，粮食产量1.4万亿斤，新能源汽车产量突破1300万辆，嫦娥六号实现月球背面采样返回；同时指出外部环境复杂严峻，内需不振、预期偏弱等问题。报告提出2025年经济社会发展总体要求，坚持稳中求进工作总基调，实施更加积极有为的宏观政策，推动经济持续回升向好，高质量完成“十四五”规划目标任务。整体基调务实进取，既正视困难挑战，又坚定发展信心。

# 核心政策
2025年主要预期目标：**国内生产总值增长5%左右**，**城镇调查失业率5.5%左右**，**城镇新增就业1200万人以上**，**居民消费价格涨幅2%左右**，居民收入增长和经济增长同步，国际收支保持基本平衡，**粮食产量1.4万亿斤左右**，**单位国内生产总值能耗降低3%左右**，生态环境质量持续改善。财政政策：**赤字率拟按4%左右安排**，**赤字规模5.66万亿元**，拟发行**超长期特别国债1.3万亿元**，拟发行**特别国债5000亿元**支持国有大型商业银行补充资本，安排**地方政府专项债券4.4万亿元**，合计新增政府债务总规模**11.86万亿元**。货币政策：实施适度宽松的货币政策，适时降准降息，保持流动性充裕。

# 重点工作
**一、经济领域**：大力提振消费、提高投资效益，全方位扩大国内需求，实施提振消费专项行动，安排超长期特别国债3000亿元支持消费品以旧换新；因地制宜发展新质生产力，培育壮大新兴产业、未来产业，推动传统产业改造升级，激发数字经济创新活力；扩大高水平对外开放，稳定对外贸易发展，大力鼓励外商投资，推动高质量共建“一带一路”走深走实。**二、民生领域**：更大力度稳定和扩大就业，实施重点领域、重点行业、城乡基层和中小微企业就业支持计划；强化基本医疗卫生服务，深化以公益性为导向的公立医院改革；完善社会保障和服务政策，城乡居民基础养老金最低标准再提高20元，适当提高退休人员基本养老金，制定促进生育政策、发放育儿补贴；着力抓好“三农”工作，持续增强粮食等重要农产品稳产保供能力，巩固拓展脱贫攻坚成果。**三、生态环保领域**：协同推进降碳、减污、扩绿、增长，加强污染防治和生态建设，积极稳妥推进碳达峰碳中和，建立零碳园区、零碳工厂，开展煤电低碳化改造试点示范。**四、改革与风险防范**：推动标志性改革举措加快落地，高质量完成国有企业改革深化提升行动，纵深推进全国统一大市场建设；有效防范化解重点领域风险，持续用力推动房地产市场止跌回稳，稳妥化解地方政府债务风险，积极防范金融领域风险。
