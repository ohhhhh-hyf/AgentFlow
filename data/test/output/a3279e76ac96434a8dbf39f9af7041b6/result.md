# 发布会概况
本次采访/对话中，中方代表王毅在慕尼黑安全会议上发表演讲并回应主持人提问，围绕世界多极化阐述中方主张。王毅指出世界走向多极化是历史必然，中国主张推动平等有序的世界多极化，并提出四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。他强调中国是多极体系中的确定性因素，坚定做变革世界中的建设性力量。整体基调理性务实，既阐明中方立场，也回应了国际社会对国际秩序、乌克兰危机及中美关系的关切。

# 核心信息
王毅在慕尼黑安全会议上阐述中方主张，核心信息包括：世界多极化是历史必然，中国主张推动平等有序的世界多极化；提出四点看法，即倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。关键数据：联合国成立时仅有51个会员国，如今有193个国家；中国承担超过20%的联合国会费；去年中国GDP增长5%，对世界经济增长贡献率接近30%；中国加入了几乎所有普遍性政府间国际组织和600多项国际公约。政策举措：中国坚持大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权；坚定维护联合国权威和地位，切实履行巴黎协定，建成世界上最大的清洁发电体系；提出并落实全球发展倡议、全球安全倡议、全球文明倡议；推动高质量共建“一带一路”，并与欧盟“全球门户”战略相互对接。

# 官方表态
关于国际秩序与规则：王毅回应称，中国是现行国际秩序的受益者，要推动秩序朝着更加公正合理的方向发展；应共同维护以联合国为核心的国际体系，遵守以联合国宪章宗旨和原则为基础的国际关系基本准则；反对双重标准，尊重各国主权和领土完整，支持中国实现完全统一。关于乌克兰危机：王毅表示，中俄是正常国家交往，中国从俄罗斯购买油气是满足民众需求，不可能不买；中国主张通过对话政治解决争端，从2022年2月25日起就提出对话协商解决；习近平主席提出四点主张，即各国主权领土完整应得到尊重、联合国宪章应得到遵守、各国合理安全关切应得到重视、一切致力于和平的努力都应得到支持；中国推进劝和促谈，派特使斡旋，同巴西等南方国家发起“和平之友”；所有当事方和利益攸关方应适时参与和谈，欧洲应发挥重要作用，探讨欧洲长治久安的安全框架。关于中美关系：王毅表示，中国对美政策保持连续性和稳定性，遵循习近平主席提出的相互尊重、和平共处、合作共赢三原则；中方愿意按照三原则构建稳定健康可持续的双边关系，希望美方相向而行；如果美方打压遏制，中方将奉陪到底，坚决维护国家主权、尊严和正当发展权利。
