# 复盘目标与结果概况
本次年终总结会旨在复盘2023年度经营状况并表彰员工。实际结果：年终奖总额226,000元，全年实打实支出390万元，利润率约24%或27%，成本控制非常差；最高工资（含年终奖）约20万元，平均到手工资1万多元；2023年公司总量提升、员工拿到钱提升，但成本上升、结余到账往下跑，尚有百来万未收回，老板个人比去年少拿约10万元并承担了100万元亏损风险。会议主要内容包括公布经营数据与年终奖发放标准、逐一点评员工、颁发奖项、部门总结展望及抽奖。

# 亮点事项
超出预期的成果主要体现在短视频账号的显著增长与员工个人表现的突出。郭东辉负责的多个平台粉丝数大幅增长：视频号从700多增至8万，小红书从2000+增至6.4万，抖音从2000+增至5.7万，B站从3.1万增至7.6万，账号变现程度约7.5分（满分10分），直播平均每场5000人以上。促成成功的关键动作包括：6月20日第一条外出拍摄视频成为转折点，郭东辉在潘老师多次提醒放弃的情况下坚持并说服其外出拍摄，同时有外部公司挖角带来的破釜沉舟心态，以及新同事加入带来的支持。最具复用价值的经验是**坚持与破局**：面对困境不轻言放弃，找准一个点突破（如外出拍摄），并持续用数据支撑决策。此外，张扬的加入被老板称为2023年最有价值的事，其工作态度与能力基本达到期待。

# 不足事项
未达预期的环节及根因分析：
- 成本控制非常差，利润率仅24%或27%，全年支出390万元，结余到账往下跑，尚有百来万未收回。现象 → 根因：老板对成本关心或关注不够，不够雷厉风行，出现问题未及时解决，根源在于老板的管理问题。
- 加班多，后半年几乎都在加班，侵占员工休息时间。现象 → 根因：人不够，未及时招聘合适人数，属于老板的判断失误。
- 账号变现重点项目未完成，直播虽已开展但尚无课程可变现。现象 → 根因：变现路径尚未打通，需继续推进。
- 老板个人比去年少拿约10万元，并承担100万元亏损风险。现象 → 根因：公司结余缩水，成本上升。
