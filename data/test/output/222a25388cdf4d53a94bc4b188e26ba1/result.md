# 沟通背景与目的
电子科技大学电子科学与工程学院面向考生及家长举办招生宣讲会，由学院段院、柳教授、张教授、李天明教授及在读博士生田雨桐分别介绍学院整体情况与各学科方向，旨在帮助考生和家长了解学院学科实力、师资科研与人才培养情况，吸引优秀生源报考。整体宣讲以学院历史沿革、学科方向、科研平台、师资队伍及学生发展为主线，辅以在校生视角的择校建议，并现场解答了关于夏令营安排等招生咨询问题，整体基调为积极推介与开放答疑。

# 核心信息与数据
## 学院整体情况

- **历史沿革**：1956年建校时成立无线电系、电真空器件系、无线电零件系，经1979年、1992年、2001年、2018年4次院系调整，成立电子科学与工程学院（科普示范性微电子学院）；2023年响应国家号召，成立电子科学与工程学院与基层电路学院（原文如此）。
- **学科设置**：电子科学与技术为国家重点一级学科，下设5个二级学科方向——电磁场与微波技术、电路与系统、微电子学与固体电子学、物理电子学、电磁信息功能材料与机构（原文如此）。
- **国防特色学科**：电磁场与微波军用关键材料、电子元器件（原文如此）。
- **党建荣誉**：学校党委入选教育部首批全国党建工作标杆院系学院，学院荣获全国教育系统先进集体。
- **本科生规模**：现有本科生1545人，招生专业为工科试验班（电子工程类），含电子科学技术（国家特色专业、国家级一流本科专业建设点）与电磁场与无线技术两个专业方向。
- **研究生规模**：现有硕士和博士研究生1975人，招生专业为学术型博士/硕士电子科学与技术、材料科学与工程，专业学位博士/硕士电子信息、材料工程。
- **师资构成**：现有教师302人，其中教研系139人、科研系95人、教学系14人、实验系21人，教师总数269人，机关33人。
- **高层次人才**：两院院士2人、领军人才19人、青年人才28人、其他类型人才12人、后继61人（原文如此）。
- **教师团队**：融合两个全国高校黄大年式教师团队，2022年融合4个国家自然科学基金创新群体。
- **科研经费**：近5年科研经费到账稳定在3—4亿元之间，项目构成以纵向项目为主、横向项目为辅。
- **科研成果**：牵头获得国家科技奖励11项；近5年发表高水平学术论文2000余篇；专利申请1600余件、授权1300余件。
- **科研团队**：共20个科研团队，年度经费过千万元的团队15个，其中过亿元团队1个。
- **科研平台**：拥有国家电子辐射控制材料工程技术研究中心、微波电子工器件国家级重点实验室（原文如此）两个国家级平台，4个国际合作平台，7个省部级科研平台。
- **国际交流**：共建国际姊妹院系两个——香港大学电机工程电子系、香港城市大学电子工程系；主办高水平国际会议13场；学生长短期交流项目20多个。

## 电子信息材料与元器件方向

- **方向内涵**：以材料为基础、器件为核心、应用为目标导向，涉及电子材料与电子器件的设计、研制、生产与应用，涵盖电磁、声、光、热、力及化学生物等特性。
- **产业背景**：2021年中国集成电路电子产品进口额度达2.8万亿元，约为原有进口量的1.7倍；先进电子材料元器件电路系统等电子产品是我国目前最为紧迫的卡脖子问题之一。
- **应用领域**：在6G通讯、量子技术、智慧城市、光电技术、新能源、智能电子等领域起重要作用，已广泛应用于物联网、移动设备、网络基础设施、无人驾驶、航空航天、医疗健康和可穿戴设备，达到万亿美元量级。
- **发展趋势**：电子产品向小型化、多功能、低功耗、智能化方向发展，元器件朝微型化、片式化、集成化、薄膜化和智能化发展，强调材料和器件一体化；集成技术将摩尔定律制程缩小与超摩尔定律功能多样化相结合。
- **邓龙江院士团队**：电磁辐射控制材料与技术团队，现有研究人员19人（正高13人、副高15人），近年发表包括《自然》在内的论文300余篇，承担国家省部级及国际合作课题130余项，年均到账经费3000多万元，授权发明专利100余项，获国家科技进步或技术发明二等奖共计3项。
- **张怀武教授团队**：磁电薄膜与微型器件团队，现有研究人员17人（正高15人、副高2人），开展LTCC材料及集成技术、微波毫米波晶圆及器件、自旋电子与磁量子器件、传感器芯片等研究，承担国家重点研发计划、自然基金重点重大科学仪器项目等100余项，发表SCI论文400余篇，年均到账经费2000余万元，获科技进步二等奖共计3项。
- **国家电磁辐射控制材料工程技术研究中心**：历史可追溯至1990年校级材料与技术研究中心，经2008年、2013年两次升级形成国家级平台，开展多频谱涂层、电磁材料与结构、智能材料与结构研究，拥有成都嘉驰电子科技等成果转化基地。
- **电磁薄膜与集成器件全国重点实验室**：2006年依托新型传感器、功率半导体技术、电子信息材料三个部级重点实验室筹建，围绕电子信息系统微小型化和单片集成的重大需求开展研究，形成电子聚合物与阵列传感器、功率半导体与集成技术三个重点方向。
- **研究条件**：科研面积2万余平米（超精尖3000平），建设两条国家重大任务试验生产线，拥有大型设备或系统500余台套；材料制备设备约50台套，微纳加工设备30台套，微观表征设备10余台套，性能测试设备50余台套。
- **方向成果**：已获国家科技技术发明等奖项共计7项，在《自然》及子刊每年有多篇重要文章发表。
- **毕业生去向**：遍布产业界与学术界，包括英特尔、中芯国际、华为、德州仪器及高校科研院所。
- **学生代表成果**：在读学生杨伟豪以第一作者在《自然·电子》《自然·通讯》各发表一篇论文；5G滤波器芯片学生团队获挑战杯创新创业大赛四川省金奖；黄飞获2018年四川省优秀毕业生并获斯坦福大学攻读博士全额奖学金；李凤霞读博期间发表论文16篇（一作6篇）；严巍获21届王大珩光学奖，以优秀青年学者身份加入苏州大学；毕业生万位现任河北美泰电子科技公司副总，带领团队采用MEMS工艺研制出SIW环形器隔离器，突破卡脖子器件核心技术。

## 电磁场与微波技术和电路与系统方向

- **电磁场与微波技术细分方向**：包含微波毫米波电路、电波传播与电磁兼容、计算电磁学与工程电子学、天线理论与技术4个细分方向。
- **电路与系统细分方向**：包含非线性电路与复杂电子系统、射频微波电路与系统、集成电路与系统3个方向。
- **学科历史**：电磁场与微波技术学科始于1956年建校时期，由林卫干先生和谢楚芳先生共同创建，形成电磁场与无线技术国家特色专业和电波传播与天线国防紧缺特色专业；所属一级学科电子科学与技术入选双一流A类学科。
- **研究团队**：电磁场与微波技术学科由6个团队组成——电磁辐射与散射团队、毫米波技术与系统应用团队、微波毫米波集成电路与系统团队、电磁兼容技术团队、微波测试与成像技术团队、无线技术与集成系统团队。
- **学科平台**：包含国家自然基金委创新群体、国家高等学校学科创新引智基地、国家工程技术研究中心及国家级重点实验室；硬件方面拥有中国高校最为先进的微波暗室群体及微波毫米波太赫兹仿真测试平台。
- **天线方向成果**：杨世文教授团队研究四维天线阵列技术，为天线阵列设计提供新自由度，实现低成本高性能；强耦合超宽带相控阵成果应用于中电14所某大型机载相控阵雷达；樊勇教授团队研究毫米波平面集成天线，可应用于毫米波通信雷达系统。
- **测量与电磁兼容成果**：李恩教授团队微波毫米波测量技术突破众多技术封锁，有60多年技术积累；杨世文教授团队电磁测井仪器获国家科技进步二等奖1项，成果在中海油推广应用。
- **微波毫米波电路成果**：延波教授团队（原文如此）引领微波毫米波太赫兹芯片研究，获国家科技重大专项及军科委项目支持，应用于新一代高速通信系统；在固态合成功率源、天线阵列、扩电网络（原文如此）等电路与通信雷达系统及三毫米导引头前端、毫米波引信前端、8毫米宽带收发前端等微系统技术方面取得进展。
- **计算电磁学与太赫兹成果**：杨世文教授团队计算电磁学相关算法被评为20世纪十大算法之一；樊勇教授团队成功研制0.22THz、0.34THz、0.42THz雷达成像系统，实验平台分辨率小于1厘米；太赫兹通信成果在2023年成都大运会田径项目成功示范应用。
- **电磁波应用成果**：李恩教授团队面向5G通信、高性能系统、生物医学、新能源等方向开展电磁波与物质互作用机理及测评系统研究；生物医学电磁学及成像方向发表大量高水平论文，有20余项国家发明专利。
- **电路与系统学科沿革**：1981年开始招收研究生和博士研究生，1988年成立首批博士后流动站；学科包含教育部国际合作联合实验室及国家高等学校学科创新引智基地，拥有国家级人才4人、新世纪人才2人、教授10人、副教授22人。
- **电路与系统研究成果**：樊勇教授和李廷军教授团队从事高速磁浮交通38GHz车地通信系统研制；樊勇教授和张静直（即张教授本人）团队从事毫米波通信雷达CMOS芯片研究；康凯教授团队在毫米波CMOS芯片方向取得超宽带模块级芯片及5G通信系统、雷达系统研制成果。
- **人才培养成果**：连续三年获全国大学生集成电路创新创业大赛奖项，荣获华为优秀合作项目奖、研究生优秀导学团队提名奖；学生获互联网+奖项、国际HPV（原文如此）各类奖项及优秀论文、创新创业大赛奖项。
- **就业方向**：就业领域分布广泛，包括华为、中兴等行业领军企业及各大研究所、高校，毕业生在海外留学方面也取得突破。

## 物理电子学方向

- **学科定义**：物理电子学是物理学与电子科学技术的交叉学科，将物理学最新研究成果应用于电子学中产生新电子器件；典型应用包括微波电子学（微波电真空器件）和光电子学（光电器件）。
- **学科特点**：内容不断充实（如量子电子学内容逐渐增加）；学科边界不一定清晰，如光电子学既可属物理电子学也可属光学工程一级学科；具有基础性与前沿性，是支撑现代信息技术的关键技术学科。
- **学校发展历程**：起源于1956年建校时在前苏联专家帮助下成立的电子控器件专业（原文如此），归属电子器件系；1979年在刘成刚院士（原文如此）带领下成立高能电子学研究所；2001年物理系、应用所、高能所成立物理电子学；2018年物理电子学院、电工学院和微工学院部分成立现在的电子科学与工程学院。
- **纵向发展**：上游为仿真设计（拥有自主知识产权商用软件MMST和切皮克，原文如此），并引入人工智能方向到器件设计和电子学应用；下游为系统应用，包括用回旋行波管研制毫米波雷达、用行波管做无线输能系统、用磁控管做微波能干燥系统。
- **横向发展**：频段从微波上移至毫米波到太赫兹；与医学交叉，利用太赫兹分辨率高、透视效果好的特点做太赫兹成像用于医学诊断，利用太赫兹宽频带特点做保密通信和高速通信。
- **科研平台与经费**：有三个四川省工程中心或重点实验室，参与成立一系列行业协会；每年到校科研经费接近2亿元，在学院中最多；2023年成功举办行业顶级会议；物理电子学方向共有9个团队。
- **国际地位**：是国际上最大的真空器件研究中心（原文如此），在国际上名气越来越大。
- **学生出口**：李天明教授团队学生约1/3硕博连读、1/3去企业、1/3去研究所或其他（公务员等）；李天明教授个人每年约两个硕士毕业、一个博士毕业。

## 学生视角分享

- **城市优势**：成都是四川省会、国家中心城市、新一线城市、国家历史文化名城、古蜀文明发祥地、中国十大古都之一；电子信息产业发达，英特尔、华为、京东方等巨头汇聚，提供实践平台和就业资源。
- **学校优势**：电子科技大学是我国电子信息人才培育的代名词，拥有电子信息博物馆，记录我国第一台晶体管收音机的诞生；从电子科学与技术、信息与通信工程到集成电路科学与技术，构建了最完整的电子信息学科群。
- **学科实力**：电子科学与技术学科在第4轮学科评估中斩获A+，稳居全国第一；学院拥有四大学科和19个科研团队。
- **团队情况**：田雨桐所在毫米波技术与系统应用团队在樊勇老师带领下，围绕微波毫米波理论与技术、天线理论与技术、元器件与电路、通信技术与系统、雷达成像技术与系统五大方向开展研究，覆盖从芯片、封装、天线、电路、模块到系统的全面知识。
- **就业情况**：团队硕博毕业生实现100%就业率，就业单位有各类民营企业、大型央国企和头部科研院所。
- **奖助体系**：学院构建全覆盖、高额度、长周期的奖助体系，包括国家奖学金、学业奖学金、专项奖学金、新生奖学金及校园地国家助学贷款和生源地助学贷款。
- **择校建议**：先根据研究方向选择研究团队，再选择合适导师；可通过学院网站进入团队网页找导师，也可借助IEEE和中国知网等文献检索网站检索导师论文和指导研究生毕业情况。
