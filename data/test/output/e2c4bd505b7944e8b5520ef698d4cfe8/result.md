# 沟通背景与目的
杭州医学院检验医学院、生物工程学院专场直播中，宋宝峰书记（检验医学院、生物工程学院党委书记、副院长）向考生及家长介绍医学技术专业硕士点情况。该学位点2024年获批，由5个学院共同承担培养，聚焦检验技术、医学影像技术、康复治疗、智能医学工程四个方向，2025年已录取64名考生，2026年计划招生34人（以教育部正式下达为准）。直播还解答了就业前景、初试科目、跨专业报考等问题，并鼓励考生报考。

# 信息同步
**宋宝峰书记（杭州医学院检验医学院、生物工程学院党委书记、副院长）**：
- **学位点基本情况**：医学技术专业硕士点2024年获批，由检验学院、生物工程学院（合署办公）为组建学院，医学影像学院、康复学院、信息工程学院为共建学院；聚焦检验技术（细分为医检、卫检）、医学影像技术、康复治疗、智能医学工程四个方向。
- **2025年招生情况**：录取64名考生，其中检验方向38人、影像方向11人、康复方向13人、智能医学工程方向2人。
- **学科建设**：2023年获批省医学技术一流学科B类；近五年获国家级基金项目19项、省鉴定领先项目1项、纵向科研经费1300万、横向课题经费2200多万；获省科技进步一等奖2项、二等奖1项、三等奖2项；建有国家级一流本科课程2门、国家级一流本科专业建设点2个。
- **学科优势**：体外诊断领域优势显著，疫情期间联合开发新冠核酸检测、抗原检测、抗体检测三个产品并获NMPA注册；医学影像技术方向在多参数MRI、肿瘤分子影像学、医学图像处理等方面形成优质方向；康复治疗方向依托省人民医院康复医学科（省内综合医院中建科最早、人才最齐、技术最先进、设备最先进、社会效益最佳的康复医学科之一）；智能医学工程方向聚焦阿尔茨海默病数字生物标志物，居国际领跑水平。
- **主要研究方向**：医学检验技术方向负责人吕建新教授，聚焦重大疾病新型生物标志物筛选及机制、新发突发传染病新型生物标志物筛选及致病机制、重大疾病体外诊断检测技术、新型药物系统体内治疗易复发难治愈疾病、长神经免疫与再生；卫生检验检疫方向负责人金大志教授，聚焦新发突发传染病病原体检测检验新技术方法开发（艰难梭菌致病机制、耐药机制、基因组进化、小分子药物开发）及卫生检验技术研究；医学影像技术方向负责人徐秀芳教授，聚焦多参数MRI、肿瘤分子影像学、神经导航引导的脑肿瘤穿刺技术、脑肿瘤术前功能区定位；康复治疗方向负责人倪湘明教授，聚焦技术研发、神经损伤修复与再生、运动康复机制与技术创新、意识障碍促醒机制、中西医康复治疗神经系统疾病机制及临床研究；智能医学工程方向负责人李海教授，聚焦脑认知与脑疾病智能诊疗及康复、健康大数据分析与智慧医疗、脑机接口高端数字医疗器械、中医先进医疗器械研发、脑部及精神系统重大疾病智能诊断及数字方向。
- **师资队伍**：专任教师90人，高级职称53人（占30%以上），博士55人；硕导69人，正高35人，博士46人；人才称号包括教育部医学技术类专业技能教授委员会委员、省万人创新人才2人次、浙江省151人才5人、省杰青1人、省高层次创新人才2人、省派义乌市校创新领军团队1个。
- **培养与就业**：培养目标为面向健康中国发展需要，培养熟练掌握医学技术领域专业知识技能、具有良好创新实践能力的高层次应用型人才；培养方式为教学专业实践与学位论文相结合；学制三年（最长不超过五年）；实行学分制，毕业前学业课程不少于24学分（专业必修课≥12学分、专业选修课5-6学分以上）；就业方向涵盖医院相关科室（检验科、输血科、病理科、放射科、超声科、康复医学科、骨科、神经科、运动医学科）、疾控中心、医药企业与生物技术公司、医疗器械公司、保险公司、药监局、卫健委、海关、高校、研究所等；目前尚无毕业生（2025年开始招生），但就业前景乐观。
- **2026年招考计划**：计划招生34人（仅供参考，以教育部正式下达为准）；初试科目为思想政治理论、英语（统考）加一门自主命题专业课（按方向考检验综合、医学影像技术综合、康复治疗综合、智能医学工程综合）；检验综合占比为卫生生物学检验40%、生物化学检验30%、微生物学检验30%；专业综合课程为指定性考试大纲，实践分值300分、时长180分钟；复试方式目前以线下为主，初试60%、复试40%，复试内容为英语能力测试20%、专业能力测试40%、综合能力测试40%，导师采取双选制。
- **考生问答**：就业前景方面，就业优先，专业就业面广，可继续深造（读博）或进入三甲医院、疾控中心、医药企业、医疗器械公司、保险公司、药监局、卫健委、海关、高校、研究所等；杭州有高水平三甲医院和企业，研究生及以上学位具有核心竞争力；初试科目共三门，英语难度介于四级和六级之间；备考建议为暑期是关键时期，英语达到四级水平，关注研究生招生网和研究生教育微信公众号；跨专业报考方面，允许非本专业考生跨专业报考医学技术学位点，被录取概率会大大提高。
- **其他问题**：学校有三个校区（滨江校区、市中心黄路校区等），主校区在市中心黄路校区，交通便利；学校重视竞赛，有资源提升改善、专门讲座和培训，研究生在竞赛中取得好成绩，以赛促学、以赛促教、以赛促改。
