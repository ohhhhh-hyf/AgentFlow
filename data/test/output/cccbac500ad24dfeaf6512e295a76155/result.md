# 庭审概况
本案为上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷二审，由最高人民法院组成合议庭公开开庭审理，审判长主持庭审。案件围绕国开行抵押权与招银租赁所有权冲突、罚息复利计算、违约金连带责任三个争议焦点展开辩论，各方充分发表意见后，合议庭提出调解方案，各方无异议并签字确认，法院出具调解书。

# 举证与法庭调查
## 举证与质证
- **国开行提交**：2018年9月融资租赁查询证书，证明已尽查询义务。招银租赁质证认为该查询证书不符合要求，依据2014年93号文，国开行在抵押时点未进行相应查询。
- **国开行提交**：工商部门出资证明、东源煤电及曲靖电力权属证明、人民银行查询情况，证明已尽审慎义务。东源方质证认为统计表显示两家公司抵押设备名称完全相同，且邮件中抵押设备部分用红色标注，国开行应尽注意义务。
- **招银租赁提交**：回租设备清单（证据7页），载明设备名称和生产厂家，但未提及型号。国开行质证认为无法据此识别设备唯一性。
- **招银租赁提交**：2013年和2015年审计报告（证据82页、95页），载明曲靖电力注册资本4亿元且已实缴。国开行质证认为该报告已载明设备出资事项。
- **国开行提交**：2018年核查表（证据108页），证明曲靖电力名下无融资租赁登记。招银租赁质证认为该核查表不符合要求。

## 法官询问
- **审判员询问国开行**：贷款前审查是否有内部规定必须查询融资租赁登记，未查到结果是否需保留单证作为风控材料。国开行代理人答复：按央行规定需查询系统，但未查到结果故未保留筛查记录。
- **审判员询问招银租赁**：融资租赁登记系统中设备唯一标识码是否为必填项。招银租赁代理人答复：不是必填项，本案设备无唯一标识码，故未登记。
- **审判员询问国开行和招银租赁**：央行融资租赁登记查询方式能否保证查询到登记结果。国开行答复：只能按单位名称查询；招银租赁答复：可按公司名称或设备查询，但设备查询涉及种类物区分问题。
- **审判员询问**：查询通知规定银行办理抵押前必须查询，违反规范会导致何种后果。国开行答复：查询是基本义务，依据融资租赁司法解释第九条第三款，未查询不能取得善意权利。

## 争议焦点与辩论
### 争议焦点一：国开行抵押权与招银租赁所有权冲突
- **国开行主张**：办理抵押登记时已尽审慎义务，构成善意取得；抵押登记针对曲靖电力公司设备，核查义务仅限于曲靖电力公司，不能任意扩大到东源煤电公司。
- **招银租赁主张**：国开行未按央行规定查询融资租赁登记，不构成善意；东源煤电出资行为系无权处分，因招银租赁2012年已取得设备所有权。
- **东源方主张**：2015年12月2日邮件已告知设备融资租赁情况，国开行应尽注意义务；统计表显示两家公司抵押设备名称完全相同，且用红色标注，国开行应进行核查。
- **国开行反驳**：邮件为贷后审查材料，未明确告知融资租赁；统计表显示招银租赁抵押类型为不动产抵押，与融资租赁概念不同。

### 争议焦点二：罚息、复利计算
- **国开行主张**：利息计算至2017年12月20日，罚息自2018年6月13日起算，复利自2018年3月21日起算，有合同第六条第四款依据。
- **东源方主张**：罚息不应作为复利基数，依据《人民币利率管理规定》第21条；国开行宣布贷款提前到期未给合理期限，不符合合同约定。
- **招银租赁表示**：非合同当事人，尊重合议庭审查结果。

### 争议焦点三：违约金连带责任
- **国开行主张**：依据借款合同第24条第三项，东源煤电应支付千分之一违约金，因其未配合办理账户管理及柜台签约手续。
- **东源方主张**：国开行未举证东源煤电违约，且未发出限期纠正通知，不符合合同约定。
- **招银租赁表示**：非合同当事人，尊重合议庭审查结果。

# 庭审结果
## 调解方案
- **债权确认**：国开行对东源公司债权扣除破产清偿本金后，利息、罚息、复利合计6474.4513万元；招银租赁对6项设备所有权对应债权1377.4137万元。
- **权利确认**：国开行对93项设备有抵押权，招银租赁对6项设备有所有权。
- **设备处置**：招银租赁和国开行对案涉全部发电设备整体盘活处置，从变现款中实现各自债权；变现价格双方各50%，实现费用各担50%。
- **变现不足处理**：若变现款不足以清偿债务，招银租赁未实现债权按破产重整计划预留方案实现，由东源煤电按有担保清偿方案予以清偿。
- **权益放弃**：若司法变现不能，国开行和招银租赁权益通过前述方法实现后，均放弃对案涉设备权益，由东源曲靖电力自主生产经营。
- **无争议事项**：各方对一审判决第二项、第四项无争议，按判项内容在调解书中确认。
- **诉讼费用**：一审诉讼费中，国开行诉请部分按一审判决执行，招银租赁诉请部分由二审法院按规定确定；二审诉讼费由本院依法确定。
- **争议终结**：各方就本案涉及问题不再存在任何争议。

## 调解结果
- 各方对调解方案均无异议，诉讼代理人依次在调解协议正式文本上签字。
- 法院确认调解协议不违反法律规定，依据《民事诉讼法》第97条出具调解书。
- 审判长指出，调解是高质量审判，各方在分清是非基础上合作共赢，东源煤业破产重组得以圆满成功，企业重生并良性发展，金融债权得到充分保护。
- 审判长表示，本案反映动产抵押权与融资租赁所有权冲突是司法实践普遍性难题，根本原因在于国家未建立统一动产登记制度，现有融资租赁登记系统和动产抵押登记系统缺乏有效衔接，将依据最高人民法院关于加强司法建议工作的意见，向有关部门提出司法建议，共同推进国家治理现代化。
