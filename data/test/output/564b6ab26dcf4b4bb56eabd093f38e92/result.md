# 讲座概况
会议围绕电影《南京照相馆》展开讨论，成员分享观影印象：有人看过抖音切片，有人觉得深刻好看，有人因题材沉重未看，有人记得地下室场景。主持人介绍历史背景，包括1937年八一三淞沪抗战、日军进攻南京、南京大屠杀的起因，以及日军军纪失控、松井石根被替换、朝香宫鸠彦发布不留俘虏命令等细节。主持人辨析电影虚构与真实：电影主要人物虚构，但照片拍摄真实，实际由美国传教士拍摄，中国冲洗人员拷贝并提交军事法庭作为证据，方式与电影描述不同。主持人还指出中华门城墙战斗、挹江门撤退惨案、战后审判枪决战犯等真实历史细节。成员提到日本有人不承认历史，并分享参观伪满洲国博物馆、唐山大地震纪念馆、上海抗战纪念馆等经历，提到南京大屠杀纪念馆预约难。

# 核心观点与论证
主持人首先介绍历史背景：1937年8月13日，国民党军队在上海与日军激战（八一三淞沪抗战），因实力原因撤退后，日军追击至南京。更深层原因是自1931年九一八事变以来，日军占领东北、华北均未遭遇成规模抵抗，八一三淞沪抗战是日军首次遭受迎头痛击，伤亡惨重，加之长达四个月的战斗，日军缺乏军纪约束，人性泯灭，攻破南京后导致南京大屠杀。主持人辨析电影虚构与真实：电影主要人物虚构，但照片拍摄真实，实际由两名美国传教士拍摄日军暴行，同时期中国负责冲洗照片的人员无意发现后偷偷拷贝，抗战后提交国民政府军事法庭作为审判日本战犯的证据，而非电影中人物拍摄。主持人指出真实历史细节：中华门城墙战斗、挹江门撤退时宪兵未让平民撤出、守军未收到撤退命令导致惨案、战后审判枪决谷寿夫（第六师团师团长）等主犯。主持人分析日军暴行原因：日军自九一八事变以来未遭大规模抵抗，感到前所未有的侮辱和应激创伤，结合日本屠城传统、高压武士道精神，以及松井石根因生病被替换为朝香宫鸠彦亲王，后者发布不留俘虏命令，导致军纪失控。

# 金句总结
主持人指出："从他们当时那样的心态来说，觉得遭受了一种前所未有的侮辱，以及在战场上的一种应激创伤反应。" 此句关联日军在南京暴行的心理动因。主持人还提到："攻破了敌方的城镇，都要以屠城来进行自己那种狂欢与麻痹。" 说明日军暴行与历史传统的关系。
