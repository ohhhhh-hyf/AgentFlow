# 初中光学复习课：直线传播与反射

## 课程概况
本节课为初中光学复习课，围绕几何光学展开，覆盖光的直线传播、光的反射定律、镜面反射与漫反射、平面镜成像及球面镜应用五大板块。主讲人首先界定光源（自然光源如太阳，人造光源如火把、电灯）与光线（物理模型，非真实存在），强调光在均匀介质中沿直线传播，并以三点一线、激光准直、小孔成像、日食月食、影子形成等实例佐证；其中小孔成像成倒立实像，日食时月球居中、月食时地球居中。光速部分给出真空中3×10⁸米/秒、水中约为其3/4、玻璃中约为2/3等关键数据。随后系统讲解光的反射定律（三线共面、分居两侧、反射角等于入射角），区分镜面反射与漫反射，并借助实验梳理平面镜成像特点（正立、等大、虚像）及玻璃板代替平面镜的缘由。最后介绍凸面镜（发散、成缩小正立虚像）与凹面镜（会聚）的应用，如汽车后视镜、太阳灶等。全程以例题讲练结合，强调作图规范与实验操作细节。

## 核心知识点梳理
### 光的直线传播
- **光源定义**：自身能够发光的物体，分为自然光源（如太阳、萤火虫）和人造光源（如火把、蜡烛、煤油灯、电灯）。
- **光线概念**：用带箭头的直线表示，是**物理模型**，并非真实存在；按来源分为点光源与平行光源，按形状可画成点或平行光束。
- **光沿直线传播条件**：在**均匀介质**中沿直线传播；大气层不均匀时会发生偏折，如日出时太阳位置、星星“眨眼睛”等现象。
- **实例——三点一线**：步枪瞄准时眼睛、准心尖、标尺缺口三者重合，依据光在均匀介质中沿直线传播；队列排齐、木工闭眼检查直尺同理。
- **实例——小孔成像**：光沿直线传播，成**倒立实像**，放大缩小不一定，与孔形状无关；墨经中有记载，常考。
- **实例——日食与月食**：日食时太阳、月球、地球在同一直线，月球在中间，分日全食（1号区）、日偏食（2、3号区）、日环食（4号区）；月食时地球在中间，月球部分在1号区、部分在2或3号区时才出现月偏食，完全在1号区为月全食。
- **实例——影子形成**：光沿直线传播，光线被物体挡住形成阴影，如唐朝皮影戏利用此原理。
- **光速**：真空中传播速度为 `3×10^8 米/秒`（`3×10^5 千米/秒`），约每秒绕地球赤道7圈半；空气中略慢（约 `2.99×10^8 米/秒`），水中约为真空中的 `3/4`，玻璃中约为 `2/3`。
- **光速计算例题**：激光从地球射到月球表面用时 `1.25 秒`，地月距离 `s = v×t = 3×10^8 × 1.25 = 3.75×10^8 米`。
- **声光对比**：发生雷电时先看到闪电后听到雷声，因为光速大于声速（15℃时声速 `340 米/秒`）；百米赛跑计时员若按听到枪声计时会产生误差。

### 光的反射定律
- **基本概念**：入射光线 `AO`、反射光线 `OB`、入射点 `O`、法线 `OP`（垂直于镜面，画虚线，非真实存在）；入射角为入射光线与法线的夹角，反射角为反射光线与法线的夹角。
- **定律内容**：① 反射光线、入射光线、法线在同一平面内（共面）；② 反射光线和入射光线分居法线两侧；③ 反射角等于入射角。
- **垂直入射易错点**：光垂直射到镜面上时，入射角和反射角均为 **0度**，不是90度。
- **作图步骤**：① 先画法线（虚线，留作图痕迹）；② 根据反射角等于入射角，利用对称法（如尺子刻度对准法线，两侧找等距点）确定入射或反射光线；③ 补全箭头。
- **例题**：反射光线与平面镜夹角 `40度`，入射角为 `50度`；入射光线与法线夹角 `60度`，反射角 `60度`；反射光线与入射光线夹角 `80度`，反射角 `40度`。

### 镜面反射与漫反射
- **镜面反射**：平行光射到光滑表面（如平面镜、平静水面、光滑金属表面），反射光平行；若人眼不在反射光方向上则看不到，易造成反光问题（如商场玻璃隔断撞人）。
- **漫反射**：平行光射到凹凸不平表面，每个小面看作小平面镜，反射光线射向各个方向；**生活中大多数反射是漫反射**（如黑板、电影银幕、人本身）。
- **共同点**：镜面反射和漫反射**都遵守光的反射定律**。
- **黑板反光**：教室某些位置看黑板只见光亮看不清粉笔字，是黑板发生**镜面反射**；电影放映机射到银幕上的光发生**漫反射**。
- **雨后水潭判断**：迎着月光走，发亮处是水潭（镜面反射）；背着月光走，暗处是水潭。
- **光路可逆**：若小明能看到小刚在平面镜中的像，则小刚也一定能看到小明在平面镜中的像。

### 平面镜成像
- **成像原理**：根据光的反射定律，反射光线反向延长线的交点即为像点 `S'`；像与物连线与镜面垂直，像到镜面距离等于物到镜面距离。
- **成像特点**：成**正立、等大、虚像**；像与物关于镜面对称。
- **实验器材与作用**：用玻璃板代替平面镜（便于确定像的位置）；刻度尺用于比较像与物到镜面的距离；两段完全相同的蜡烛用于比较像与物的大小。
- **虚像验证**：光屏（如白塑料片、白墙）不能接收到烛焰的像，因为实际光线没有到达镜后。
- **像的大小**：物体靠近玻璃板，像的大小**不变**。
- **实验误差原因**：① 玻璃板与水平面不垂直（或与预先画好的镜面位置不重合）；② 玻璃板有厚度，两个面发生反射成像，看到同一个蜡烛的两个像。
- **例题——视力表**：视力表距镜子 `3.5 米`，像距镜子 `3.5 米`，人距镜子 `1.5 米` 时看虚像距离为 `5 米`；若视力表距镜 `3 米`，人距镜 `2 米` 即可。
- **例题——人与像距离**：人站在平面镜前 `1 米` 处，人与像距离 `2 米`；远离平面镜，像的大小不变。
- **易混点**：人在河边看到岸边的树在水中的“倒影”属于光的反射（平静水面充当平面镜），成的是正立等大的虚像，文学上称“倒影”易与折射混淆。

### 球面镜及其应用
- **凸面镜**：对光线起**发散作用**，成**正立、缩小的虚像**；应用于汽车后视镜、丁字路口拐弯处反光镜。
- **凹面镜**：对光线起**会聚作用**，平行光反射后汇聚于焦点 `F`；应用于手电筒电珠（小灯泡置于焦点）、汽车前大灯、探照灯、耳鼻喉科检查镜、太阳灶。
- **作图方法**：以直代曲，将曲面看作多个小平面镜，逐面画法线与反射光线。
- **光污染案例**：玻璃幕墙形成凹面会聚光线，可能烧死树木（如校园枣树被烧死）、引燃电线造成自燃；凹面反射声音导致楼间噪音增大。

## 课堂互动与答疑
### Q1. 光源的分类依据

- **学生**：光源除了按来源分，还能怎么分？
> **教师**：还可以按形状分。点光源画成一个点，如蜡烛从无限远处看；平行光源画一束平行光，如太阳光从无限远处来，画法不同。

### Q2. 光沿直线传播的条件

- **学生**：光沿直线传播是不是在任何情况下都成立？
> **教师**：只在均匀介质中成立。大气层不均匀时，光线会发生偏折，所以看到太阳越出地平线、星星眨眼，都是大气层不均匀造成的。

### Q3. 小孔成像的像的性质

- **学生**：小孔成像成的像一定是倒立的吗？放大缩小怎么判断？
> **教师**：一定是倒立的实像，因为光线实际到达光屏。放大缩小不一定，取决于物距和像距的关系；像的形状与孔的形状无关，如树荫下的光斑是太阳的缩小的像。

### Q4. 日食与月食的区分

- **学生**：日食和月食都是月球在中间吗？月偏食怎么形成的？
> **教师**：日食是月球在太阳和地球之间，月球挡住太阳光；月食是地球在太阳和月球之间，地球挡住太阳光。月偏食是月球部分进入地球本影（1号区域）、部分在半影（2、3号区域）时形成的，不是整个月球都在半影里。

### Q5. 光速在不同介质中的差异

- **学生**：光速在不同介质中一样吗？
> **教师**：不一样。真空中最快，为3×10⁸米/秒；空气中略慢，约为2.99×10⁸米/秒；水中约为真空中的3/4；玻璃中约为真空中的2/3。

### Q6. 垂直入射时入射角的大小

- **学生**：光垂直射到镜面上，入射角是多少度？
> **教师**：入射角和反射角都是0度，不是90度。因为入射角是入射光线与法线的夹角，垂直入射时二者重合，夹角为0度。

### Q7. 反射作图的方法

- **学生**：画反射光线时，一定要用量角器量角度吗？
> **教师**：不需要。先画法线（虚线，留作图痕迹），再根据反射角等于入射角，用尺子在法线两侧找对称点，连接入射点即可，不必精确量角。

### Q8. 镜面反射与漫反射的区别

- **学生**：镜面反射和漫反射都遵守反射定律吗？生活中哪种更多？
> **教师**：都遵守光的反射定律。镜面反射是平行光射到光滑表面，反射光平行，可能造成反光；漫反射是射到凹凸不平表面，反射光射向各个方向，是生活中大多数反射的类型，如黑板反光是镜面反射，电影银幕是漫反射。

### Q9. 雨后夜晚判断水潭位置

- **学生**：雨后夜晚，怎么判断哪里是水潭？
> **教师**：迎着月光走，亮处是水潭，因为水面发生镜面反射，反射光进入人眼；背着月光走，暗处是水潭，反射光射向其他方向，地面发生漫反射反而更亮。

### Q10. 光路可逆的应用

- **学生**：小明能看到小刚在平面镜中的像，小刚一定能看到小明吗？
> **教师**：一定能，这是光路可逆原理。光从小明射向镜面反射到小刚眼中，反向传播时，小刚也能看到小明的像。

### Q11. 平面镜成像实验用玻璃板的原因

- **学生**：为什么用玻璃板代替平面镜做实验？
> **教师**：玻璃板既能反射成像，又能透过光看到后面的蜡烛，便于移动未点燃的蜡烛确定像的位置；平面镜不透明，无法做到这一点。

### Q12. 平面镜成像实验误差原因

- **学生**：实验中像与物到镜面距离不相等，可能是什么原因？
> **教师**：一是玻璃板与水平面不垂直，导致像的位置偏移；二是玻璃板有厚度，两个面都能反射成像，造成重影，所以应选薄玻璃板。

### Q13. 平面镜成虚像的判断

- **学生**：为什么光屏接收不到平面镜成的像？
> **教师**：因为平面镜成的是虚像，实际光线没有到达像的位置，只是反射光线的反向延长线会聚形成的，所以光屏接收不到。

### Q14. 平面镜成像的大小变化

- **学生**：人远离平面镜，镜中的像会变小吗？
> **教师**：不会，像的大小不变，始终与物体等大。人远离时，只是视角变小，像本身大小不变。

### Q15. 凸面镜和凹面镜的作用

- **学生**：凸面镜和凹面镜对光线分别起什么作用？用在哪些地方？
> **教师**：凸面镜对光线起发散作用，成正立缩小的虚像，用于汽车后视镜、丁字路口反光镜；凹面镜对光线起会聚作用，用于手电筒、汽车前大灯、太阳灶、耳鼻喉科检查镜。

- [ ] **练习6（光的直线传播）**：多选选ABC，D项错在未强调均匀介质，光传播路线需在均匀介质中才为直线。

- [ ] **练习10（反射角变化）**：入射光线与镜面夹角增大时，入射角减小，反射角也减小，传播速度不变，选C。
- [ ] **练习11（反射角计算）**：入射光线与法线夹角60°时，反射角为60°。
- [ ] **练习12（反射角计算）**：反射光线与入射光线夹角80°时，反射角为40°（角平分线）。
- [ ] **练习13（雨后水潭判断）**：迎着月光走，发亮处是水潭（镜面反射）；背着月光走，发暗处是水潭。选对应项。
- [ ] **练习14（光路可逆）**：A错（垂直入射反射角0°）；B对（光路可逆）；C错（漫反射也遵守反射定律）；D错（不同介质光速不同）。
- [ ] **练习15（电影银幕）**：白色银幕对光产生漫反射，选B。
- [ ] **练习16（黑板反光）**：黑板反光看不清粉笔字是镜面反射；电影银幕反射是漫反射；两种反射都遵守光的反射定律。
- [ ] **练习17（电影院屏幕）**：白色屏幕粗糙是为了使光发生漫反射。
- [ ] **练习18（光的反射判断）**：选D（人在河边看到岸边的树在水中的倒影，属光的反射）；A、B为直线传播，C为折射。
- [ ] **练习19（平面镜成像实验误差）**：①蜡烛到玻璃板距离与像到玻璃板距离不相等，原因是玻璃板与水平面不垂直（或未与预先画好的镜面位置重合）；②看到同一蜡烛两个像，原因是玻璃板有厚度，两个面发生反射成像。
- [ ] **练习20（平面镜成像实验）**：①用玻璃板代替平面镜是为了便于确定像的位置；②刻度尺用于比较像与物到镜面的距离；③两段相同蜡烛用于比较像与物大小；④光屏不能接收到烛焰的像，因为成的是虚像；⑤物体靠近玻璃板，像的大小不变。
- [ ] **练习21（视力表）**：视力表距镜子3.5米，像距镜子3.5米，人距镜子1.5米时看虚像距离为5米，填1.5米。
- [ ] **练习22（视力表）**：视力表到镜距离改为3米，像到镜距离3米，人距镜子2米即可，选B。
- [ ] **练习23（平面镜距离）**：人站在平面镜前1米处，人与像之间距离为2米。
- [ ] **练习24（平面镜成像大小）**：人向远离平面镜方向移动，像的大小不变，选C。

### 复习重点
- [ ] **光源与光线**：光源是自身能够发光的物体，分自然光源（太阳、萤火虫）和人造光源（火把、蜡烛、煤油灯、电灯）；光线是用带箭头的直线表示的物理模型，并非真实存在。
- [ ] **光沿直线传播**：光在均匀介质中沿直线传播；实例包括三点一线、激光准直、小孔成像、日食月食、影子形成；大气层不均匀时太阳光发生偏折，故日出时太阳实际位置低于所见位置。
- [ ] **小孔成像**：成倒立实像，放大缩小不一定，与孔形状无关；树荫下光斑是太阳通过树叶缝隙形成的小孔成像，为缩小的实像。
- [ ] **日食与月食**：日食时太阳、月球、地球在同一直线，月球在中间，分日全食（1号区）、日偏食（2、3号区）、日环食（4号区）；月食时地球在中间，月全食是月球完全进入地球阴影（1号区），月偏食是月球部分在1号区、部分在2或3号区。
- [ ] **光速**：真空中光速为3×10⁸米/秒（约每秒30万公里，一秒钟绕地球赤道7圈半）；空气中略慢（约2.99×10⁸米/秒）；水中约为真空中的3/4；玻璃中约为2/3；光速大于声速（15℃时声速340米/秒），故先看到闪电后听到雷声。
- [ ] **光的反射定律**：反射光线、入射光线和法线在同一平面内（共面）；反射光线和入射光线分居法线两侧；反射角等于入射角；垂直射到镜面上时入射角和反射角均为0°。
- [ ] **镜面反射与漫反射**：镜面反射是平行光射到光滑表面，反射光平行，可能造成反光问题（如黑板反光）；漫反射是平行光射到凹凸不平表面，反射光射向各个方向，是生活中大多数反射的类型（如电影银幕、白纸）；两者都遵守光的反射定律。
- [ ] **光路可逆**：若小明能看到小刚在平面镜中的像，则小刚也一定能看到小明在平面镜中的像。
- [ ] **平面镜成像特点**：成正立、等大的虚像；像与物到镜面距离相等；像与物连线与镜面垂直；光屏不能接收到虚像（实际光线未到达）。
- [ ] **球面镜**：凸面镜对光线起发散作用，成正立缩小的虚像，用于汽车后视镜、丁字路口反光镜；凹面镜对光线起会聚作用，用于手电筒、汽车前大灯、太阳灶、耳鼻喉科检查镜。

### 学习建议
- [ ] **自制小孔成像实验**：用纸杯（或易拉罐）底部用针扎一个小孔（不要用钉子扎大孔），杯口蒙上塑料布，点燃蜡烛放在小孔前方，可在塑料布上看到倒立的火苗像；体会像与孔形状无关。
- [ ] **自制反射定律探究装置**：用硬纸壳中间贴透明胶带使其可前后转动，画上均匀刻度，放一面小平面镜，用激光笔照射，验证三线共面、反射角等于入射角。
- [ ] **自制平面镜成像实验**：白纸上竖一块透明玻璃板，用两个相同蜡烛（或跳棋子），一个点燃放玻璃板前，移动另一个找像的位置，记录位置后可验证像与物到镜面距离相等、连线与镜面垂直。
- [ ] **验证镜面反射与漫反射**：白纸上放一面小镜子，用手电筒垂直照射，斜着看时镜子是黑的、周围白纸是亮的，说明镜面反射光返回、漫反射光射向各方向。
- [ ] **观察生活中的光学现象**：夏天观察大杨树下的光斑（小孔成像）；雨后夜晚判断水潭位置（迎着月光亮处是水潭，背着月光暗处是水潭）；观察汽车后视镜和丁字路口反光镜（凸面镜成正立缩小虚像）。
- [ ] **作图规范提醒**：画反射光路图时先画法线（虚线，保留作图痕迹），再根据反射角等于入射角画光线，补全箭头；法线画两三段断开即可，不必画得过密。
- [ ] **保护视力提醒**：主讲人强调长时间用眼、教室拉窗帘、写字姿势不良等都会导致近视，建议多到户外活动，减少盯屏幕时间。
