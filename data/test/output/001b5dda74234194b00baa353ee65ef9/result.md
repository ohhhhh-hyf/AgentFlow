# 故宫保姆级游览攻略：路线、看点与盖章点全解析

## 参观概况

本次参访为故宫博物院游览攻略讲解，主讲人沿中轴线及东西两路，系统介绍了故宫核心景点、历史典故、建筑特色与文创盖章信息。行程自午门启程，经太和门广场、太和殿、中和殿、保和殿，进入乾清门后宫区域，依次参观乾清宫、交泰殿、坤宁宫，随后转至西六宫储秀宫、慈宁宫、寿康宫，再经断虹桥、武英殿、文华殿，抵达箭亭、钟表馆与珍宝馆，最后经东筒子夹道、延禧宫、御花园，至神武门结束。讲解纠正了太和殿为上朝场所的常见误解，明确其为举行盛大典礼之地；文武百官站位遵循文东武西原则。午门采用明三暗五结构，中间正门仅供皇帝、大婚皇后及殿试前三名通行。太和门为明朝御门听政之所，门口铜狮子为故宫六对铜狮中最大的一对。讲解全程穿插历史典故与建筑细节，并标注了七个免费盖章位置，最后总结三条游览路线供不同时长游客选择。

## 核心看点

| 景点/展点 | 相关知识 |
| --- | --- |
| 午门 | 采用明三暗五结构，三个门洞进门后变为五个；中间正门仅供皇帝行走，皇后大婚时可进一次，殿试前三名（状元、榜眼、探花）可出一次 |
| 太和门广场 | 有五座金水桥，中间桥供皇帝走，两侧桥供皇亲国戚和文武百官走 |
| 太和门 | 明朝御门听政的地方，门口铜狮子是故宫六对铜狮中最大的一对 |
| 太和殿 | 举行盛大典礼的地方，如皇帝登基、皇后册封；文武百官站位遵循文东武西原则 |
| 中和殿 | 举行盛大典礼时皇帝的休息室 |
| 保和殿 | 从乾隆五十四年开始作为殿试考场；东北角有汉字馆，内有4枚免费印章，可购买紫禁城100并现场盖章 |
| 乾清门 | 后宫入口，东边是九卿直房，西边是军机处；门口狮子耳朵耷拉、眉毛遮眼，警示后宫人员不该看的不看、不该听的不听 |
| 乾清宫 | 皇帝睡觉的地方，内有27张龙床以防刺客；正大光明牌匾后藏有立储诏书，皇帝写两份，驾崩后对比验证 |
| 交泰殿 | 内放有25块传国玉玺 |
| 坤宁宫 | 皇后住所，明朝所有皇后都住这里；东北角文创店有5枚免费印章 |
| 储秀宫 | 慈禧住了20多年的地方，现为慈禧五十大寿时期的原状陈列；边上文创店有3枚免费印章 |
| 慈宁宫 | 康熙为孝庄皇太后修建的养老院 |
| 寿康宫 | 甄嬛居住的地方 |
| 断虹桥 | 上有形态各异的石狮子，最有名的是武当狮 |
| 武英殿 | 后来改为陶瓷馆，目前关闭状态 |
| 文华殿 | 当时未开放，据说有展览 |
| 箭亭 | 清朝皇帝及其子孙练习骑马射箭的地方，旁边商店可购买文创雪糕 |
| 钟表馆 | 展示了各种造型的钟表 |
| 珍宝馆 | 门口有我国现存三座古代九龙壁之一，左边数第三条白龙下有一块木头，因烧制时弄坏，工匠用木头刷白漆以假乱真；实为宁寿全宫，乾隆给自己修建的养老院，但退休后未放权仍每天上朝；皇极殿据说是1:1复刻乾清宫；乐寿堂是故宫唯一能进去参观的皇家寝室，有二龙仙楼设计；珍妃井是慈禧把珍妃丢进去的地方，现井口石非原物；出口右手边商店有3枚免费印章 |
| 东筒子夹道 | 网红拍照地 |
| 延禧宫 | 网红打卡地 |
| 景仁宫 | 甄嬛被封熹妃时住的，珍妃也住过 |
| 御花园 | 内有钦安殿，供奉真武大帝，紫禁城靠山景山从天上酷似真武大帝造型 |
| 神武门 | 故宫北门，出门左手边有两个盖章点：角楼咖啡有2枚免费印章，故宫文创有2枚免费印章 |

## 互动体验

- **文创盖章**：讲解标注了七个免费盖章位置，包括汉字馆4枚、坤宁宫文创店5枚、储秀宫文创店3枚、冰窖书吧3枚、珍宝馆出口商店3枚、角楼咖啡2枚、故宫文创2枚；故宫内多处可购买紫禁城100，但每家店印章不同，且不能跨店盖章
- **文创雪糕**：箭亭旁边商店可购买文创雪糕，为游览途中补充体力的选择
- **拍照打卡**：东筒子夹道为网红拍照地，延禧宫为网红打卡地，适合游客拍照留念

## 心得收获

- **游览路线规划**：第一条路线走完所有景点，适合全天，约3万步；第二条半天路线，涵盖坤宁宫、景仁宫、延禧宫、钟表馆、珍宝馆、御花园；第三条最省力，约2小时，涵盖坤宁宫、储秀宫、御花园
- **错峰建议**：建议游客早来排队，一进门就沿中轴线往后走，以错开旅游团人群
- **重点推荐**：珍宝馆为强烈建议参观的景点，涵盖九龙壁、皇极殿、乐寿堂、珍妃井等核心看点
- **体力管理**：建议游客在游览过程中适当休息和补充水分
