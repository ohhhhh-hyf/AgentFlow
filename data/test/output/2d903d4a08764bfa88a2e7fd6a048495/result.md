# 就诊概况
48岁男性患者张春和，职业为成都轻工研究所科研人员，因上腹反复不适4年、近3个月加重，于消化内科门诊初诊。患者自述心窝处烧灼样疼痛，进食冷、硬、辛辣食物或工作紧张劳累时诱发，近3个月白天发作、无夜间痛醒；曾两次黑便（一年前、三个月前各一次），近两月呕吐酸水样物，含当日或隔夜食物。近期服用斯达舒、奥美拉唑、阿莫西林及胃炎合剂，效果不佳。初步考虑上消化道疾病可能，需进一步检查明确，本次就诊拟行大便潜血检查及胃镜检查。

# 病史与背景
- **现病史**：上腹烧灼样疼痛4年，每年春季多发，近3个月持续；疼痛位于心窝处，进食冷、硬、辛辣食物或工作紧张劳累时诱发，白天发作、无夜间痛醒，疼痛可忍受，工作轻松时有完全不痛的时候。
- **黑便史**：两次黑便，一次在一年前、一次在三个月前，每次持续约一个月，每日最多两次，大便干、形状正常；两次均住院两三天后大便转黄。
- **呕吐史**：近两个月出现呕吐，吐出酸水样物，含早晨或中午所食食物，晚上吐出后舒适，偶有隔夜食物吐出。
- **既往史**：16岁患甲肝，在三医院住院一个月治愈，出院时各项指标正常，此后体检肝功均正常；无手术史。
- **过敏史**：小时候因扁桃体炎在儿童医院服用磺胺药后左手起红疹，持续半个月，医生诊断为药物过敏，此后不能服用磺胺药。
- **个人史**：出生于成都，一直在成都生活，在成都轻工研究所从事科研工作，工作紧张、常加班熬夜；吸烟由一天一包减至10支以内，计划逐步戒烟；平时不饮酒，应酬时少量；每天泡两次淡茶；26岁结婚，爱人及孩子身体健康，三口人住两房一厅。
- **家族史**：父亲76岁有低血压，母亲75岁有冠心病（服药控制良好），弟弟身体健康；婶婶（叔叔的爱人）有胃癌，患者担心与此有关。

# 诊断与检查结果
初步考虑上消化道疾病可能，需进一步检查明确。患者有两次黑便史，需排查消化道出血；有胃癌家族史（婶婶，无血缘关系），患者本人担忧，严医生解释婶婶无血缘关系，不必担心遗传问题。患者担心是否需要手术，严医生表示待检查资料全面后再判断，若能药物控制则不需手术。
