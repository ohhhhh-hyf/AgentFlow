# 杭州医学院医学技术硕士点招生宣讲会

## 沟通背景与目的
杭州医学院检验医学院、生物工程学院党委书记宋宝峰副教授做客招生宣讲直播，面向屏幕前的考生及家长介绍医学技术专业硕士点的总体情况。沟通旨在帮助广大考生全面了解2026年研究生招生情况，围绕学位点基本情况、学科建设与优势、主要研究方向、师资队伍、硕士培养与毕业去向及招考计划等主题展开介绍，并解答考生关于就业前景、复试环节、初试科目及跨专业报考等疑问。整体基调为招生宣传推介，宋宝峰系统展示了学位点的学科实力与培养特色，鼓励考生关注并报考。

## 核心信息与数据
### 学位点基本情况
1. **学位点获批**：医学技术专业硕士点于2024年获批，为新增学位点。
2. **培养单位构成**：由5个学院共同承担培养工作，其中检验医学院、生物工程学院合署办公，共建学院为医学影像学院、康复学院和信息工程学院。
3. **专业方向设置**：聚焦四个主要专业方向，分别为检验技术、医学影像技术、康复治疗和智能医学工程；其中检验技术细分为医检和卫检两个方向。

### 2025年招生情况
1. **录取总人数**：2025年共录取64位考生。
2. **分方向录取人数**：心理方向38人，经济方向11人，康复方向13人，职业方向2人。

### 学科建设与科研平台
1. **学科层次**：医学技术于2023年获批浙江省一流学科B类。
2. **科研项目与经费**：近五年获国家级基金项目19项、省鉴定领先项目1项；纵向科研经费1300万元，横向合作课题经费2200多万元。
3. **科研成果奖项**：获省科技进步一等奖2项、二等奖1项、三等奖2项。
4. **课程与专业建设**：建成国家级一流本科课程2门、国家级一流本科专业建设点2个。
5. **省级科研平台**：建有省生物标志物与器官诊断转化重点实验室（2024年获批）、检验诊断关键技术研究室（2022年）、康复模块和机器人国际联合实验室（2023年）、省实验室和安全培训基地、数字化康复装备质量研究中心、脑认知与疾病数字医疗器械质量工程研究中心、浙江省神经系统疾病数字化装备研发重点实验室（2024年）等。

### 学科优势
1. **体外诊断领域**：优势显著，疫情期间与企业联合开发新冠病毒核酸检测、抗原检测、抗体检测三个产品，获NMPA注册；为中华医学会检验医学分会教育学组组长单位、卫生高新技术公司实体开发基地。
2. **医学影像技术方向**：为国家临床药物验证机构、国家卫健委外周血管介入诊疗培训基地。
3. **康复治疗方向**：依托省人民医院康复医学科，为省内综合医院中建科最早、人才最齐、技术最先进、设备最先进、社会效益最佳的康复医学科之一。
4. **智能医学工程方向**：聚焦阿尔茨海默病智能预警数字生物标志物，居国际领跑水平；为浙江省中医药重点学科、老年疾病数字医疗器械浙江省中心、智能医学前沿交叉学院。

### 主要研究方向
1. **医学检验技术方向**（负责人吕建新教授）：聚焦重大疾病新型生物标志物的筛选及机制研究、新发突发传染病新型生物标志物的筛选及致病机制研究、重大疾病的体外诊断检测技术研究、新型药物系统体内治疗易复发难以治愈疾病的研究等五大方向。
2. **卫生检验检疫方向**（负责人金大志教授）：聚焦新发突发传染病病原体的检测检验新技术方法开发，特别是艰难梭菌致病机制、耐药机制、基因组进化及小分子药物开发，以及卫生检验技术研究。
3. **医学影像技术方向**（负责人徐秀芳教授）：研究方向包括多参数MRI有效指标、肿瘤分子影像学、神经导航引导的脑肿瘤穿刺技术、脑肿瘤术前功能区定位研究。
4. **康复治疗方向**（负责人叶祥明教授）：围绕人工智能康复、神经修复、运动技术创新等方向。
5. **智能医学工程方向**（负责人李凯教授）：聚焦脑认知与脑疾病智能诊疗及康复、健康大数据分析、脑机接口等。

### 硕士培养与毕业去向
1. **培养目标**：面向健康中国发展需要，紧密服务区域行业产业发展，围绕国际学术前沿、国际重大需求和转化研究，为健康产业培养熟练掌握医学技术领域专业知识技能、具有良好创新实践能力的高层次应用型人才。
2. **培养方式与学制**：采用教学、专业实践与学位论文相结合的方式；全日制专业学位学制三年，最长不超过五年。
3. **学分要求**：毕业前学业课程不少于24学分，其中专业必修课分方向修读、不少于12学分，专业选修课（如智慧医疗、中医康复治疗学、生物信息学等）不少于5-6学分。
4. **就业方向**：可进入医院相关科室——检验方向对应检验科、输血科、病理科，影像技术方向对应放射科、超声科；还可进入疾控中心、医药企业（产品推广、质量管理体系建立维护、产品法规统筹）、医疗器械公司（研发、销售、技术支持）、保险公司（医疗保险核保理赔、健康险产品开发）、药监局、卫健委、海关（医疗器械监管、卫生政策制定、口岸卫生检疫）及高校研究所等。

### 2026年招考计划
1. **招生计划**：2026年计划招生34人，实际人数以教育部正式下达为准。
2. **初试科目**：思想政治理论、英语为统考科目；专业课按方向自主命题，分别为检验综合、医学影像技术综合、康复治疗综合、智能医学工程综合。
3. **专业课考试**：分值300分，时长180分钟；检验综合中分子生物学检验占40%、生物化学检验占30%、微生物学检验占30%。
4. **复试安排**：采用线上线下结合方式，目前以线下为主；初试占60%、复试占40%。
5. **复试内容**：英语能力测试占20%、专业能力测试占40%、综合能力测试占40%；导师与考生之间采取双选制。

## 各方立场与诉求
1. **宋宝峰（杭州医学院检验医学院、生物工程学院党委书记、副院长）**：作为主讲嘉宾，系统介绍医学技术专业硕士点的学位点概况、学科建设、师资队伍、培养方式与就业方向，并逐一解答考生关于就业前景、复试环节、初试科目、英语难度及跨专业报考等具体问题，核心诉求是吸引考生报考本学位点。
   - 针对考生关注的就业问题，回应称就业面宽广，毕业生可进入三甲医院、疾控中心、医药企业、医疗器械公司、保险公司、药监局、卫健委、海关及高校研究所等，研究生学历具有核心竞争力。
   - 针对复试环节的疑问，明确复试分为专业能力测试（40%）、综合能力测试（40%）、英语能力测试（20%）三个环节，初试占60%、复试占40%。
   - 针对初试科目，说明思想政治理论、英语为统考，专业课按方向自主命题（检验综合、医学影像技术综合、康复治疗综合、智能医学工程综合），并说明英语考试难度介于四级和六级之间。
   - 针对跨专业报考问题，明确允许非本专业考生跨专业报考（如从事检验的可报考检验方向），并称跨专业报考被录取概率会大大提高。

2. **主持人（发言人1）**：代表屏幕前考生及家长提出关注点，引导宋宝峰就学位点基本情况、学科优势、研究方向、师资队伍、培养与就业、2026年招考计划等逐一展开介绍，并在问答环节代考生提出就业前景、复试环节、初试科目、跨专业报考等具体疑问，推动信息充分披露。

## 达成共识
1. **2026年招生计划已明确**：计划招生34人，实际人数以教育部正式下达为准；初试科目为思想政治理论、英语（统考）加专业课（按方向自主命题），专业课分值300分、时长180分钟。
2. **复试方案已确认**：采用线上线下结合方式（目前以线下为主），初试占60%、复试占40%；复试内容为英语能力测试20%、专业能力测试40%、综合能力测试40%。
3. **跨专业报考口径已明确**：允许非本专业考生跨专业报考，如从事检验工作的可报考检验方向，被录取概率会大大提高。
4. **英语考试难度已确认**：介于四级和六级之间。
5. **就业前景口径已确认**：就业面宽广，可进入三甲医院、疾控中心、医药企业、医疗器械公司、保险公司、药监局、卫健委、海关、高校研究所等，研究生学历具有核心竞争力。
