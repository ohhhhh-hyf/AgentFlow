# 沟通背景与目的
本次直播由电子科技大学电子科学与工程学院主办，面向考生和家长介绍学院整体情况、学科方向与人才培养成果。学院历史可追溯至1956年建校时的无线电系等，经4次院系调整，2023年成立电子科学与工程学院与基层电路学院；一级学科电子科学与技术为国家重点一级学科，含5个二级学科方向（电磁场与微波技术、电路与系统、微电子学与固体电子学、物理电子学、电磁信息功能材料与机构）和3个国防特色学科。学院现有本科生1545人、研究生1975人，教师302人（含两院院士2人、领军人才19人、青年人才28人），近5年科研经费到账稳定在3-4亿元，牵头获国家科技奖励11项，发表高水平论文2000余篇，专利1600余件（授权1300余件），拥有两个国家级平台、4个国际合作平台和7个省部级平台。电子信息材料与元器件方向以材料为基础、器件为核心、应用为目标导向，2021年中国集成电路电子产品进口额达2.8万亿元，约为原油进口量的1.7倍，属卡脖子问题之一。电磁场与微波技术学科始于1956年，由林卫干先生和谢楚芳先生创建，含4个细分方向，所属一级学科入选双一流A类；电路与系统学科1981年开始招收研究生，1988年成立首批博士后流动站。物理电子学是物理学与电子科学与技术的交叉学科，起源于1956年建校时的电子控器件专业，1979年刘成刚院士成立高能电子学研究所，2018年成立电子科学与工程学院。学生代表田雨桐（2023级电子科学与技术专业博士）从学生视角分享选择电子学院的8个理由，包括城市、学校、专业、团队、培养、就业、校园生活、奖助体系。直播最后解答了夏令营问题：今年计划举办，时间待定，相关信息通过QQ群978499108发布。

# 信息同步
段院（电子科学与工程学院）：介绍学院历史，1956年建校成立无线电系、电真空器件系、无线电零件系，经1979年、1992年、2001年、2018年4次院系调整，2023年成立电子科学与工程学院与基层电路学院。一级学科电子科学与技术为国家重点一级学科，含5个二级学科方向（电磁场与微波技术、电路与系统、微电子学与固体电子学、物理电子学、电磁信息功能材料与机构）和3个国防特色学科（电磁场与微波军用关键材料、电子元器件）。党建获教育部首批全国党建工作标杆院系、全国教育系统先进集体。本科生1545人，招生专业为工科试验班（电子工程类），含电子科学技术（国家特色专业、国家级一流本科专业建设点）和电磁场与无线技术两个专业方向。研究生1975人，招生专业含学硕/博士电子科学与技术、硕士材料科学与工程、专业学位博士电子信息、硕士电子信息/材料工程。教师302人（教研系139人、科研系95人、教学系14人、实验系21人、机关33人），两院院士2人、领军人才19人、青年人才28人、其他类型人才12人、博士后61人。融合两个全国高校黄大年式教师团队。近5年科研经费到账稳定在3-4亿元，项目以纵向为主、横向为辅，牵头获国家科技奖励11项，发表高水平论文2000余篇，专利申请1600余件（授权1300余件）。20个科研团队，年度经费过千万的15个、过亿的1个。拥有两个国家级平台（国家电子辐射控制材料工程技术研究中心、微波电子工器件国家级重点实验室）、4个国际合作平台、7个省部级科研平台。国际姊妹院系2个（香港大学电机工程电子系、香港城市大学电子工程系），主办高水平国际会议13场，学生长短期交流项目20多个。

# 达成共识
柳教授（电子信息材料与元器件方向）：该方向以材料为基础、器件为核心、应用为目标导向，涉及电子材料与电子器件，在IT领域以物质基础与先导推动电路系统与电子装备研发。2021年中国集成电路电子产品进口额达2.8万亿元，约为原油进口量的1.7倍，是卡脖子问题之一。应用领域包括6G通讯、量子技术、智慧城市、光电技术、新能源、智能电子等，市场规模达万亿美元量级。发展趋势为小型化、多功能、低功耗、智能化，元器件向微型化、片式化、集成化、薄膜化、智能化发展，强调材料和器件一体化。研究队伍含国家级人才10余人，两个团队：邓龙江院士团队（电磁辐射控制材料与技术，19人，正高13人、副高15人，发表论文300余篇，承担课题130余项，年均到账经费3000多万元，授权发明专利100余项，获国家科技进步/技术发明二等奖3项）；张怀武教授团队（磁电薄膜与微型器件，17人，正高15人、副高2人，承担项目100余项，获科技进步二等奖3项，发表SCI论文400余篇，年均到账经费2000余万元）。依托两个国家级平台：国家电磁辐射控制材料工程技术研究中心（1990年校级中心，2008年、2013年两次升级）和电磁薄膜与集成器件全国重点实验室（2006年筹建）。科研面积2万余平米（超精尖3000平），两条国家重大任务试验生产线，大型设备500余台套，材料制备设备50余台套、微纳加工设备30台套、表征设备10余台套、测试设备50余台套。获国家技术发明等奖项共7项。毕业生去向包括英特尔、中芯国际、华为、德州仪器等。学生案例：杨伟豪在自然电子、自然通讯各发一篇一作；5G滤波器芯片学生团队获挑战杯四川省金奖；黄飞获斯坦福全奖；李凤霞读博期间发表论文16篇（一作6篇）；严巍获王大珩光学奖并加入苏州大学；万位任河北美泰电子科技副总，采用MEMS工艺研制出SIW环形器隔离器。

# 待协调事项
张教授（电磁场与微波技术和电路与系统方向）：电磁场与微波技术含4个细分方向（微波毫米波电路、电波传播与电磁兼容、计算电磁学与工程电子学、天线理论与技术），电路与系统含3个方向（非线性电路与复杂电子系统、射频微波电路与系统、集成电路与系统）。电磁场与微波技术学科始于1956年，由林卫干先生和谢楚芳先生创建，形成电磁场与无线技术国家特色专业和电波传播与天线国防紧缺特色专业，所属一级学科入选双一流A类。学科有6个团队（电磁辐射与散射、毫米波技术与系统应用、微波毫米波集成电路与系统、电磁兼容技术、微波测试与成像技术、无线技术与集成系统），平台含国家自然基金委创新群体、国家高等学校学科创新引智基地、国家工程技术研究中心、国家级重点实验室，硬件包括中国高校最先进的微波暗室群体和微波毫米波太赫兹仿真测试平台。主要成果：杨世文教授团队四维天线阵列技术、强耦合超宽带相控阵（应用于中电14所某大型机载相控阵雷达）；樊勇教授团队毫米波平面集成天线；李恩教授团队微波毫米波测量技术（60多年积累）、电磁测井仪器获国家科技进步二等奖并在中海油应用；延波教授团队微波毫米波太赫兹芯片、固态合成功率源、三毫米导引头前端、毫米波引信前端、8毫米宽带收发前端；杨世文教授团队计算电磁学算法被评为20世纪十大算法之一；樊勇教授团队太赫兹雷达成像系统（0.22THz、0.34THz、0.42THz，分辨率小于1厘米），2023年成都大运会田径项目示范应用；李恩教授团队生物医学电磁学及成像方向发表大量论文和20余项发明专利。电路与系统学科1981年开始招收研究生，1988年成立首批博士后流动站，含教育部国际合作联合实验室、国家高等学校学科创新引智基地，国家级人才4人、新世纪人才2人、教授10人、副教授22人。樊勇教授和李廷军教授团队从事高速磁浮交通38GHz车地通信系统；樊勇教授和张静（本人）团队从事毫米波通信雷达CMOS芯片；康凯教授团队毫米波CMOS芯片（超宽带模块级芯片、5G通信和雷达系统）。人才培养连续三年获全国大学生集成电路创新创业大赛奖项、华为优秀合作项目奖、研究生优秀导学团队提名奖，就业领域包括华为、中兴等。
