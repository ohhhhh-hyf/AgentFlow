# 报告概况
国务院总理李强代表国务院向第十四届全国人民代表大会第三次会议作政府工作报告，请代表审议并请全国政协委员提出意见。报告期间为2024年工作回顾与2025年经济社会发展总体要求、政策取向和政府工作任务。报告指出，过去一年面对外部压力加大、内部困难增多的复杂严峻形势，经济运行总体平稳、稳中有进，全年经济社会发展主要目标任务顺利完成，中国式现代化迈出新的坚实步伐。报告同时指出外部环境更复杂严峻、国内有效需求不足等困难挑战，并强调我国经济长期向好的基本趋势没有改变。

# 核心政策
2025年主要预期目标：国内生产总值增长**5%左右**，城镇调查失业率**5.5%左右**，城镇新增就业**1200万人以上**，居民消费价格涨幅**2%左右**，居民收入增长和经济增长同步，国际收支保持基本平衡，粮食产量**1.4万亿斤左右**，单位国内生产总值能耗降低**3%左右**，生态环境质量持续改善。财政政策方面，今年赤字率拟按**4%左右**安排，赤字规模**5.66万亿元**；发行超长期特别国债**1.3万亿元**；发行特别国债**5000亿元**支持国有大型商业银行补充资本；安排地方政府专项债券**4.4万亿元**；今年合计新增政府债务总规模**11.86万亿元**，比上一年增加**2.9万亿元**。货币政策方面，实施适度宽松的货币政策，适时降准降息，保持流动性充裕。政策取向包括：坚持稳中求进工作总基调，完整准确全面贯彻新发展理念，加快构建新发展格局，扎实推动高质量发展，进一步全面深化改革，扩大高水平对外开放，建设现代化产业体系，更好统筹发展和安全，实施更加积极有为的宏观政策，扩大需求，推动科技创新和产业创新融合发展，稳住楼市股市，防范化解重点领域风险和外部冲击，稳定预期、激发活力，推动经济持续回升向好。

# 重点工作
经济领域：大力提振消费、提高投资效益，全方位扩大国内需求，实施提振消费专项行动，安排超长期特别国债**3000亿元**支持消费品以旧换新，今年中央预算内投资已安排**7350亿元**；因地制宜发展新质生产力，加快建设现代化产业体系，培育生物制造、量子科技、具身智能、6G等未来产业，持续推进人工智能+行动；推动标志性改革举措加快落地，高质量完成国有企业改革深化提升行动，纵深推进全国统一大市场建设，综合整治内卷式竞争；扩大高水平对外开放，稳外贸稳外资，扩大电信、医疗、教育等领域开放试点，推动高质量共建一带一路走深走实。民生领域：更大力度稳定和扩大就业，实施重点领域、重点行业、城乡基层和中小微企业就业支持计划；强化基本医疗卫生服务，深化以公益性为导向的公立医院改革，优化药品集采政策；完善社会保障和服务政策，城乡居民基本养老金最低标准再提高**20元**，适当提高退休人员基本养老金，制定促进生育政策、发放育儿补贴；加快建设高质量教育体系，制定实施教育强国建设三年行动计划，逐步推行免费学前教育。环保领域：协同推进降碳、减污、扩绿、增长，持续深入推进蓝天碧水净土保卫战，加快发展绿色低碳经济，积极稳妥推进碳达峰碳中和，建立一批零碳园区、零碳工厂。风险防范领域：有效防范化解重点领域风险，持续用力推动房地产市场止跌回稳，稳妥化解地方政府债务风险，积极防范金融领域风险。三农领域：持续增强粮食等重要农产品稳产保供能力，稳定粮食播种面积，严守耕地红线，有序推进第二轮土地承包到期后再延长30年试点。此外，今年将开展十五规划编制工作。> 报告强调，信心凝聚力量，实干谱写华章，要努力完成全年经济社会发展目标任务，确保十四五规划圆满收官。
