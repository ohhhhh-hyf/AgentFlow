# 消化内科病史采集与胃镜诊疗安排

## 就诊概况
48岁男性患者张春和（成都轻工研究所科研人员）因上腹烧灼感4年、近3个月加重，于消化内科初诊。疼痛位于心窝处，与进食冷、硬、辛辣食物及工作紧张劳累相关，白天发作、无夜间痛醒；近3个月无黑便，大便黄色正常。一年前与三个月前各出现一次黑便，每次持续约一个月，大便干、形状正常，仅颜色改变，两次均住院两三天后转黄；近两个月出现呕吐，吐出酸水样物及当日或隔日食物。近期服用斯达舒（加量至每日四五次效果不佳）、奥美拉唑（武汉产）、阿莫西林及单位医务室胃炎合剂，停药后症状反复。既往有甲肝史、磺胺药过敏史，婶婶（叔叔爱人）有胃癌史。初步考虑消化系统疾病，需进一步检查明确诊断。

## 病史与背景
1. **现病史**：上腹烧灼感4年，每年春季多发，近3个月加重；疼痛位于心窝处，与进食冷、硬、辛辣食物及工作紧张劳累相关，与油腻食物关系不大；白天发作，无夜间痛醒，疼痛可忍受，有完全不痛的时候。
2. **黑便史**：一年前和三个月前各出现一次黑便，每次持续约一个月，大便干、形状正常，仅颜色改变；两次均住院两三天后转黄。
3. **呕吐史**：最近两个月出现呕吐，吐出酸水样物，含早晨或中午吃的食物，晚上吐出后舒服，偶有隔夜食物吐出。
4. **既往史**：16岁患甲肝，在三医院住院一个月，出院时肝功能正常，此后体检肝功均正常；小时候因扁桃体炎在儿童医院服用磺胺药后左手起红疹，瘙痒，持续半个月，医生告知过敏，此后不能服用磺胺药。
5. **个人史**：双眼近视400度，偶尔口腔溃疡；吸烟（以前一天一包，现限制在10支以内，考虑戒烟），偶尔饮酒，每天喝两次淡茶；在成都轻工研究所从事科研工作，工作紧张，经常加班熬夜；26岁结婚，爱人及孩子身体健康，居住两房一厅，父母及岳父母均单独居住。
6. **家族史**：父亲76岁有低血压，母亲75岁有冠心病（服药控制良好），弟弟身体健康；婶婶（叔叔爱人）有胃癌，患者担心自己是否也患胃癌。

## 诊断与检查结果
1. **初步印象**：考虑消化系统疾病，需进一步检查明确诊断。
2. **检查安排**：建议留大便查潜血（因曾有两次黑便），预约胃镜。
3. **医生说明**：关于婶婶胃癌史，医生解释其与患者无血缘关系，不必过度担心；关于手术问题，医生表示需等检查资料全面后再判断，药物控制可能避免手术。
4. **患者顾虑**：担心是否需要手术，因工作忙且所里安排出国进修，希望尽早安排；对医疗费用无顾虑（夫妻双方工作且有社保）。

## 治疗方案与医嘱
1. **检查安排**：留大便查潜血；胃镜预约在后天进行（患者要求，爱人可请假陪同）。
2. **生活方式与饮食**：建议戒烟，尽量少喝酒，注意休息，避免熬夜。
3. **复诊安排**：待检查结果后由张医生决定下一步治疗方案。
