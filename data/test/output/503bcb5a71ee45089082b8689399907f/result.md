# 沟通背景与目的
杭州医学院检验医学院、生物工程学院党委书记、副院长宋宝峰副教授做客直播间，面向考生及家长介绍医学技术专业硕士点情况。该硕士点于2024年获批，由检验医学院、生物工程学院（合署办公）作为组建学院，医学影像学院、康复学院、信息工程学院作为共建学院共同承担培养工作，聚焦检验技术（细分为医检和卫检）、医学影像技术、康复治疗、智能医学工程四个方向。2025年录取64位考生，其中检验方向38人、影像方向11人、康复方向13人、智能医学工程方向2人。学科于2023年获批省一流学科B类，近五年获国家级基金项目19项，纵向科研经费1300万、横向合作课题经费2200多万，获省科技进步一等奖2项、二等奖1项、三等奖2项。师资方面专任教师90人，高级职称53人，博士55人，硕导69人。2026年计划招生34人（以教育部正式下达人数为准），初试科目为思想政治理论、英语加一门自主命题专业课，复试成绩占比初试60%、复试40%。直播中宋宝峰还解答了就业前景、初试科目、跨专业报考等问题，并明确允许非本专业考生跨专业报考。

# 信息同步
**宋宝峰（杭州医学院检验医学院、生物工程学院党委书记、副院长）**：
- **学位点基本情况**：医学技术专业硕士点于2024年获批，由5个学院共同承担培养工作，组建学院为检验医学院、生物工程学院（合署办公），共建学院为医学影像学院、康复学院、信息工程学院；聚焦检验技术（细分为医检和卫检）、医学影像技术、康复治疗、智能医学工程四个方向。
- **2025年招生情况**：录取64位考生，其中检验方向38人、影像方向11人、康复方向13人、智能医学工程方向2人。
- **学科建设**：医学技术于2023年获批省一流学科B类；近五年获国家级基金项目19项、省鉴定领先项目1项，纵向科研经费1300万、横向合作课题经费2200多万；获省科技进步一等奖2项、二等奖1项、三等奖2项；建成国家级一流本科课程2门、国家级一流本科专业建设点2个。
- **省级科研平台**：建有省生物标志物与器官诊断转化重点实验室（2024年）、检验诊断关键技术研究室（2022年）、康复模块和机器人国际联合实验室（2023年）、省实验室和安全培训基地、数字化康复装备质量研究中心、脑认知与疾病数字医疗器械质量工程研究中心、浙江省神经系统疾病数字化装备研发重点实验室（2024年）。
- **学科优势**：体外诊断领域优势显著，疫情期间与企业联合开发新冠病毒核酸检测、抗原检测、抗体检测三个产品并获NMPA注册；医学影像技术方向在多参数MRI、肿瘤分子影像学、医学图像处理等方面形成优势；康复治疗方向依托省人民医院康复医学科，为省内综合医院中建科最早、人才最齐、技术最先进、设备最先进、社会效益最佳的康复医学科之一；智能医学工程方向聚焦阿尔茨海默病智能预警数字生物标志物，居国际领跑水平。
- **研究方向**：医学检验技术方向负责人为吕建新教授，聚焦重大疾病新型生物标志物筛选及机制研究、新发突发传染病新型生物标志物筛选及致病机制研究、重大疾病体外诊断检测技术研究、新型药物系统体内治疗易复发难治愈疾病研究、神经免疫与再生研究；卫生检验检疫方向负责人为金大志教授，聚焦新发突发传染病病原体检测检验新技术方法开发（艰难梭菌致病机制、耐药机制、基因组进化、小分子药物开发）及卫生检验技术研究；医学影像技术方向负责人为徐秀芳教授，聚焦多参数MRI、肿瘤分子影像学、神经导航引导的脑肿瘤穿刺技术、脑肿瘤术前功能区定位；康复治疗方向负责人为附属人民医院倪湘明教授，聚焦技术研发、神经损伤修复与再生、运动康复机制与技术创新、意识障碍促醒机制、中西医康复治疗神经系统疾病机制及临床研究；智能医学工程方向负责人为李凯教授，聚焦脑认知与脑疾病智能诊疗及康复、健康大数据分析与智慧医疗、脑机接口高端数字医疗器械、中医先进医疗器械研发、脑部及精神系统重大疾病（阿尔茨海默病、帕金森病、抑郁症、自闭症）智能诊断及数字方向。
- **师资队伍**：专任教师90人，高级职称53人（占30%以上），博士55人；硕导69人，正高35人，博士46人；人才称号包括教育部医学技术类专业教学指导委员会委员、省万人创新人才2人次、浙江省151人才5人、省杰青1人、省高层次创新人才2人、省派义乌市校创新领军团队1个。
- **培养与就业**：全日制专业学位学制三年（最长不超过五年），毕业前学业课程不少于24学分（专业必修课≥12学分，专业选修课5-6学分以上），第二学期开题、研二过程性考核、研一第二学期学位论文答辩；就业方向涵盖医院相关科室（检验科、输血科、病理科、放射科、超声科、康复医学科、骨科、神经科、运动医学科等）、疾控中心、医药企业与生物技术公司、医疗器械公司、保险公司、药监局、卫健委、海关、高校、研究所等；目前尚无毕业生（2025年开始招生），但就业前景被看好。
- **2026年招考计划**：计划招生34人（以教育部正式下达人数为准）；初试科目为思想政治理论、英语（统考）加一门自主命题专业课（按方向设置检验综合、医学影像技术综合、康复治疗综合、智能医学工程综合）；检验综合中分子生物学检验占40%、生物化学检验占30%、微生物学检验占30%；复试方式目前以线下为主，复试成绩占比初试60%、复试40%，复试内容英语能力测试20%、专业能力测试40%、综合能力测试40%；导师制采取双选制，一志愿报考优势明显。
- **考生问答**：就业前景方面，就业面广，研究生学历具有核心竞争力；初试科目三门，两门统考（思想政治理论、英语），一门专业课按方向选择；英语难度介于四级和六级之间；备考建议暑期是关键时期，英语需达到四级水平，专业课聚焦学校研究生招生网和微信公众号公布的大纲；允许非本专业考生跨专业报考；学校有三个校区（滨江校区、主城区黄路校区等），交通便利；学校重视竞赛，研究生在竞赛中取得好成绩，有资源提升改善、专门讲座和培训。

# 达成共识
**达成的共识**：
- **2026年计划招生34人**，但以教育部正式下达人数为准。
- **复试方式目前以线下为主**。
- **复试成绩占比：初试60%，复试40%**。
