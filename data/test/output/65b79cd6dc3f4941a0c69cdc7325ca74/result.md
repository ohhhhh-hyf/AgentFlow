# 发布会概况
本次中金宏观策略周会由中金公司策略组主办，策略分析师刘刚凯文主持，围绕大美丽法案、关税更新、港股流动性、光伏反内卷、人形机器人及游戏板块等热点议题展开。会议核心信息包括：大美丽法案提高债务上限5万亿美元、延长减税并取消899条款，对美股美债中长期有利但三季度存在流动性波折；关税大概率作为谈判技巧，有效税率维持10-12%水平；港股流动性边际收紧但基本面可盖过影响；光伏反内卷政策升级，硅料整合最迫切；人形机器人三季度关注华为云生态、本土企业技术闭环及特斯拉硬件替代三条主线；游戏板块在政策、消费、新品周期三重利好下有望实现戴维斯双击。整体基调偏积极，建议投资者在合适位置布局长期正确板块。

# 核心信息
大美丽法案三大块：提高债务上限5万亿美元，延长2017年减税法案（新增支出3.4万亿美元，年3400亿），取消899条款。财政赤字率维持5-6%，关税收入可覆盖支出。三季度7-9月美债供给约1万亿美元，可能推高利率但幅度或不及2023年。关税有效税率测算10-12%，极端18%，通胀年底3.3-3.4%，关注8月1日和其他市场谈判、8月12日中美谈判及转口限制（越南40%）。港股流动性三季度不如二季度，港币7.85，IPO融资多。光伏行业2020-2024年装机CAGR 42%，2025-26年增速回落至10%左右，产能过剩：电池1.5倍、硅片组件2倍、硅料2.5倍，价格下跌70-90%。反内卷政策：6月29日人民日报发声、7月1日中财委会议、7月3日工信部座谈会。多晶硅期货价格反弹至40元/公斤，硅片涨10%，电池涨2分。人形机器人二季度板块跌9%，跑输机械12个百分点，特斯拉标签股回调30-40%，智元收购上市、宇树年收入破10亿、两家中标中国移动1.2亿订单。游戏板块6月版号单月158个创新高，1-5月市场规模同比增长17%，手游增长20%，吉比特仗剑传说首月流水2亿多，巨人网络超自然行动组年化20亿流水，估值TTM PE 30倍、2025年静态PE 20倍。

# 官方表态
刘刚凯文对大美丽法案表态：提高债务上限消除违约风险，延长减税避免大幅加税，取消899条款维护美元体系根基，认为信用周期改善，财政赤字率不会大幅增加，三季度流动性有波折但波动提供再配置机会，对美股美债不悲观。对关税表态：关税一定会做，需维持一定税率（10-12%有效税率），不能太高，市场逐渐脱敏，大概率是谈判技巧，对通胀影响有限，美联储仍可降息。对港股流动性表态：三季度不如二季度，但基本面强可盖过影响，建议在合适位置拿长期正确板块。刘佳妮对光伏反内卷表态：政策力度升级，价格恶性竞争有望告一段落，行业底部夯实，硅料整合最迫切，头部一体化组件企业穿越周期能力强。郭文秀对人形机器人表态：三季度是迷茫期到商业兑现的过渡阶段，关注华为云生态接入、头部企业出货量跨越500/1000台、电机硬件优化三类信号。张雪琴对游戏板块表态：在消费、政策、新品周期三重利好下，调整后有望实现戴维斯双击，当前是配置时间点。

# Q&A环节
问：大美丽法案对美股美债和美元流动性有何影响？答：刘刚凯文指出，法案提高债务上限、延长减税、取消899条款，对中长期信用周期有利，但三季度7-9月有流动性抽水效应，美债供给约1万亿美元，可能推高利率但幅度或不及2023年，波动提供再配置机会，四季度美元可能小幅走强。问：关税升级市场为何反应冷静？答：刘刚凯文表示，关税大概率作为谈判技巧，有效税率维持10-12%水平，对通胀影响有限，市场逐渐脱敏，关注8月1日和其他市场谈判、8月12日中美谈判及转口限制。问：港股流动性前景如何？答：刘刚凯文指出，三季度流动性不如二季度，美元流动性供给压力、港币未完全回来、IPO融资多，但基本面强可盖过影响，建议在合适位置布局长期正确板块。问：光伏反内卷政策对行业有何影响？答：刘佳妮表示，政策升级强化，价格恶性竞争有望告一段落，行业底部夯实，硅料整合最迫切，组件价格跟涨需观望招标情况。问：人形机器人三季度有哪些投资主线？答：郭文秀指出，关注华为云生态开放、本土企业技术闭环、特斯拉延期带来的硬件替代窗口三条主线，建议关注物流场景、电机优化、轻量化方向。问：游戏板块调整后是否值得配置？答：张雪琴表示，在消费、政策、新品周期三重利好下，调整后有望实现戴维斯双击，当前是配置时间点。
