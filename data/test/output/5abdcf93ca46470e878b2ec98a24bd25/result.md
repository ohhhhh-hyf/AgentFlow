# 发布会概况
王毅于慕尼黑安全会议上发表演讲并接受现场提问，围绕中国对多极化世界的立场与政策主张展开。演讲以慕安会报告主题“走向多极化”为切入点，提出推动平等有序的世界多极化，并阐述四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。随后，王毅就国际秩序与规则、乌克兰危机、中美关系等议题回应主持人提问。整场活动基调明确：中国将坚定做多极体系中的确定性因素，做变革世界中的建设性力量。

# 核心信息
## 多极化主张与全球治理

- **多极化定位**：当前世界处于更加变乱交织的状态，多极化既是历史必然、也正在成为现实；中国主张推动**平等有序的世界多极化**，这是习近平主席提出的重大主张，中国将坚定做多极体系中的确定性因素、变革世界中的建设性力量。
- **联合国会员国规模**：联合国成立时（1945年）有51个会员国，至今已增至**193个国家**。
- **平等相待原则**：主张坚持权利平等、机会平等、规则平等，作为建设多极世界的基本原则；中国主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权。
- **国际法治立场**：`联合国宪章`宗旨和原则是国际关系的根本遵循、建设多极世界的重要基石；中国加入了几乎所有普遍性的政府间国际组织和**600多项国际公约**，从不搞例外主义，更不搞合则用、不合则弃。
- **多边主义实践**：中国坚定维护联合国权威和地位，承担**超过20%的联合国会费**；切实履行`巴黎协定`，建成**世界上最大的清洁发电体系**。
- **全球倡议落实**：提出并落实`全球发展倡议`、`全球安全倡议`、`全球文明倡议`，为完善全球治理提供公共产品。
- **开放共赢主张**：发展是破解各种难题的钥匙，多极世界应是各国共同发展的世界；保护主义不是出路，滥加关税没有赢家，脱钩断链断的是机遇，小院高墙封的是自己。
- **经济增长数据**：去年中国GDP增长**5%**，对世界经济增长的贡献率接近**30%**，担当全球经济增长的重要引擎，向世界释放超大规模市场红利。
- **一带一路对接**：中国愿推动高质量共建`一带一路`，同欧盟`全球门户`战略相互对接，赋能彼此也赋能世界。
- **中欧关系定位**：欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手；**2025年**是中欧建交**50周年**，中方愿同欧方用好这一契机，深化战略沟通和互利合作。

## 国际秩序与规则回应

- **秩序立场**：中国是在现行国际秩序中发展起来的、是受益者，要做的就是按照大多数国家的愿望推动秩序朝着更加公正合理的方向发展；真正挑战秩序、毁约退群的国家已经出现。
- **规则共识**：应共同维护以联合国为核心的国际体系，共同遵守以`联合国宪章`宗旨和原则为基础的国际关系基本准则，这是最大公约数；只要认同这一点，双重标准就不会有存在空间。

## 乌克兰危机立场

- **中俄关系性质**：中国同俄罗斯是两大邻国，建立了**不结盟、不对抗、不针对第三方**的睦邻友好关系，进而建立全面战略伙伴关系；中俄交往是正常的国与国之间交往。
- **油气采购回应**：中国从俄罗斯购买油气是出于满足国内民众需求的考虑，没有其他国家能够提供如此巨量的油气；中国不会允许经贸问题被政治化、当作打压中国的工具。
- **危机解决时间线**：从乌克兰危机爆发第2天（**2022年2月25日**）起，中方就提出对话协商解决；习近平主席提出4点主张——各国主权领土完整应得到尊重、`联合国宪章`应得到遵守、各国合理安全关切应得到重视、一切致力于和平的努力应得到支持。
- **劝和促谈行动**：中国以此为依据持续推进劝和促谈，派出特使赴各国斡旋，同巴西等南方国家发起`和平之友`。
- **和谈进程立场**：中方乐见一切致力于和平的努力，包括美国同俄罗斯达成的共识；所有当事方包括利益攸关方都应适时参与和谈进程，欧洲有必要为此发挥重要作用，共同探讨欧洲长治久安、找到均衡有效可持续的欧洲安全框架。

## 中美关系政策

- **政策稳定性**：中国对美政策保持连续性和稳定性，不会轻易翻烙饼，体现大国的战略定力和国际信誉。
- **对美三原则**：对美政策是习近平主席提出的三原则——**相互尊重、和平共处、合作共赢**；相互尊重是中美交往的前提，和平共处是理所当然，合作共赢是国际社会期待。
- **关系构建意愿**：中方已准备好按照三原则同美方构建**稳定、健康、可持续**的双边关系，找到两个大国在这个星球上的正确相处之道，希望美方相向而行。
- **应对底线**：如果美方仍对中国打压遏制，中方别无选择、必将奉陪到底，坚定维护中国的主权、国家尊严和正当发展权利，坚决回击美方的单边霸凌行径。

# 官方表态
**中国外交部（王毅）**：在慕尼黑安全会议上，王毅就多极化世界阐述中国立场，提出推动平等有序的世界多极化，并表达四点看法。

## 平等相待
- **主张**：坚持权利平等、机会平等、规则平等，作为建设多极世界的基本原则。
- **针对**：列强争霸曾给人类带来灾难，不平等的秩序注定土崩瓦解。
- **承诺**：中国主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权；这不会导致西方的缺失，而将促进世界的正和。
- **边界**：每一个国家的声音都应该得到倾听，每一个国家都可以在多极格局中找到自身的位置。

## 尊重国际法治
- **主张**：联合国宪章宗旨和原则是处理国际关系的根本遵循，也是建设多极世界的重要基石。
- **针对**：当今世界乱象频出，重要原因是有些国家迷信实力至上，打开了丛林法则的潘多拉盒子。
- **承诺**：中国坚定维护国际法治权威，积极履行国际责任和义务，加入了几乎所有普遍性的政府间国际组织和600多项国际公约；从不搞例外主义，更不搞合则用、不合则弃。
- **条件**：在遵守国际法上不能搞双重标准；要尊重各国的主权和领土完整，就应该支持中国实现完全统一。

## 践行多边主义
- **主张**：联合国是践行多边主义、推进全球治理的核心平台，对于这座大厦应该固本强基，而不是拆梁毁柱。
- **针对**：面对层出不穷的全球性挑战，没有哪一个国家能够独善其身，搞本国优先只会造成各方的多输。
- **承诺**：中国坚持真正的多边主义，倡导共商共建共享的全球治理观，坚定维护联合国的权威和地位，承担超过20%的联合国会费；切实履行巴黎协定，建成了世界上最大的清洁发电体系；提出并落实全球发展倡议、全球安全倡议、全球文明倡议，为完善全球治理提供公共产品。

## 坚持开放共赢
- **主张**：发展是破解各种难题的钥匙，多极世界应该是各国共同发展的世界；应当坚持开放合作，以普惠包容的经济全球化来支撑平等有序的世界多极化。
- **针对**：保护主义不是出路，滥加关税没有赢家；脱钩断链断的是机遇，小院高墙封的是自己。
- **承诺**：中国坚定同各国共享发展机遇，愿推动高质量共建"一带一路"，同欧盟"全球门户"战略相互对接，赋能彼此也赋能世界。
- **依据**：去年中国GDP增长5%，对世界经济增长的贡献率接近30%，担当全球经济增长的重要引擎。

## 中欧关系
- **主张**：中方始终认为欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手。
- **承诺**：今年是中欧建交50周年，中方愿意同欧方用好这一契机，深化战略沟通和互利合作，推动世界走向和平、安全、繁荣、进步的光明前景。

# Q&A环节
**1. 主持人**：您提到国际秩序，我开场也强调要尊重联合国宪章，但现在看到很多质疑——俄罗斯入侵乌克兰、美国总统威胁对格陵兰和巴拿马动武、巴勒斯坦人流离失所，中国也被指责违反海洋法和《世界人权宣言》。您即将前往纽约参加安理会会议，您还相信联合国和联合国宪章吗？是否推动联合国改革？这有多优先？

**王毅**：你的提问涉及秩序和规则两个关键词。关于秩序，这几年有人说中国要改变秩序、另起炉灶，但现在说这种话的人可能不多了，因为真正挑战秩序、毁约退群的国家出现了。中国是在现行国际秩序中发展起来的，是受益者，我们要做的是按照大多数国家愿望推动秩序朝更加公正合理方向发展。关于规则，我们起码应有共同认知：共同维护以联合国为核心的国际体系，共同遵守以联合国宪章宗旨和原则为基础的国际关系基本准则，这是最大公约数。只要认同这一点，双重标准就没有存在空间。习近平主席提出全球发展倡议、全球安全倡议、全球文明倡议，希望国际社会携手解决发展赤字、安全赤字、治理赤字，共同构建人类命运共同体，这已得到越来越多国家理解认同和支持。

**2. 主持人**：2022年慕安会前几天您曾说任何国家的主权、独立和领土完整都应得到尊重和维护，乌克兰也不例外。如今俄罗斯已成为中国有军队的加油站，您对乌克兰有很大影响力。现在有更多压力要求结束这场战争，您能否从你们这边切断俄罗斯向中国供气的可能、压低价格或停止部分军民两用物资，从而对俄施压？

**王毅**：中国同俄罗斯是两大邻国，有着漫长边界，两国关系经历过曲折后吸取教训，建立了不结盟、不对抗、不针对第三方的睦邻友好关系，进而建立全面战略伙伴关系。中国同俄罗斯的交往是正常的国与国交往。关于是否不从俄罗斯买油气，我想问：如果中国不从俄罗斯买，哪个国家能提供如此巨量油气满足中国民众需求？那是不可能的，也是不保险的，因为常有国家把经贸问题政治化、当作打压中国的工具，我们不会允许这种情况，要为人民负责。中国在地区热点问题上有自己的立场，历来主张一切争端和冲突应通过对话寻求政治解决，武力和制裁不可能真正彻底解决问题。乌克兰危机爆发第二天即2022年2月25日，中方就提出对话协商解决。习近平主席提出四点主张：各国主权领土完整应得到尊重、联合国宪章应得到遵守、各国合理安全关切应得到重视、一切致力于和平的努力都应得到支持。我们以此推进劝和促谈，派特使斡旋，同巴西等南方国家发起"和平之友"。中方乐见一切致力于和平的努力，包括美俄达成的共识，同时认为所有当事方包括利益攸关方都应适时参与和谈。战事发生在欧洲大地，欧洲更有必要发挥作用，共同探讨欧洲长治久安，找到均衡、有效、可持续的欧洲安全框架。

**3. 主持人**：时间快到了，能否简短预告您认为美中关系将如何发展？

**王毅**：中国的对美政策保持连续性和稳定性，不会轻易翻烙饼，这体现大国的战略定力和国际信誉。对美政策就是习近平主席提出的三原则：相互尊重、和平共处、合作共赢。中美制度不同是各自人民的选择，想改造或颠覆对方不切实际，正确态度是相互尊重，这是中美交往的前提；和平共处理所当然，两个大国总不能冲突起来，那将殃及整个世界；合作共赢是因为国际社会期待中美合作，全球性挑战需要中美携手应对。中方已准备好按三原则同美方构建稳定健康可持续的双边关系。我们希望美方相向而行，但如果美方仍对中国打压遏制，我们别无选择，必将奉陪到底，坚定维护中国主权、国家尊严和正当发展权利，坚决回击美方单边霸凌行径。中国人从来不信邪、不怕鬼，我们对世界前途和中美关系未来都充满信心，中美共同努力的方向就是相互尊重、和平共处、合作共赢。
