# 杭州医学院医学技术硕士点2026年招生宣讲

## 沟通背景与目的
杭州医学院检验医学院、生物工程学院党委书记、副院长宋宝峰副教授做客招生宣讲直播间，面向考生及家长介绍该校医学技术专业硕士点的总体情况。沟通旨在帮助考生全面了解2026年研究生招生政策与培养条件，围绕学位点基本情况、学科优势、研究方向、师资队伍、培养方式、就业方向及招考安排等展开宣介，并现场解答考生关切。整体基调为积极推介，突出学位点学科竞争力与报考性价比，鼓励考生关注并报考。

## 核心信息与数据
### 学位点基本情况
1. **学位点获批**：医学技术专业硕士点于2024年获批，为新增学位点。
2. **培养单位构成**：由5个学院共同承担培养工作，其中检验医学院、生物工程学院合署办公，共建学院为医学影像学院、康复学院、信息工程学院。
3. **专业方向设置**：聚焦检验技术、医学影像技术、康复治疗、智能医学工程四个方向，其中检验技术细分为医检和卫检两个方向。

### 2025年招生情况
1. **录取总人数**：2025年录取考生64人。
2. **各方向人数**：检验方向38人，影像方向11人，康复方向13人，智能医学工程方向2人。

### 学科建设与科研平台
1. **学科层次**：医学技术于2023年获批浙江省医学技术省一流学科B类。
2. **科研项目与经费**：近五年获国家级基金项目19项，省鉴定领先项目1项；纵向科研经费1300万，横向合作课题经费2200多万。
3. **科研成果**：获省科技进步一等奖2项、二等奖1项、三等奖2项。
4. **教学建设**：建成国家级一流本科课程2门，国家级一流本科专业建设点2个。
5. **省级科研平台**：建有省生物标志物与器官诊断转化重点实验室、检验诊断关键技术质量研究室、康复模块和机器人国际联合实验室、省实验室和安全培训基地、数字化康复装备质量研究中心、脑认知与疾病数字医疗器械质量工程研究中心、浙江省神经系统疾病数字化装备研发重点实验室等。

### 学科优势
1. **体外诊断领域**：优势显著，疫情期间与企业联合开发新冠病毒核酸检测、抗原检测、抗体检测三个产品，获NMPA注册；为中华医学会检验医学分会教育学组组长单位、卫生高新技术公司实体开发基地。
2. **医学影像技术方向**：在多参数MRI、肿瘤分子影像学、医学图像处理等方面形成优势方向；拥有国家级本科专业建设点、省医学重点学科、医学创新学科、省临床放射质控中心、国家临床药物验证机构、国家卫健委外周血管介入诊疗培训基地等平台。
3. **康复治疗方向**：依托省人民医院康复医学科，为省内综合医院中建科最早、人才最齐、技术最先进、设备最先进、社会效益最佳的康复医学科之一。
4. **智能医学工程方向**：聚焦阿尔茨海默病智能预警生物标志物（数字生物标志物），居国际领跑水平；为浙江省中医药重点学科、老年助浴疾病数字器械医疗器械浙江省中心、智能医学前沿交叉学院。

### 主要研究方向
1. **医学检验技术方向**（负责人吕建新教授）：聚焦重大疾病新型生物标志物筛选及其机制研究、新发突发传染病新型生物标志物筛选及致病机制研究、重大疾病体外诊断检测技术研究、新型药物系统体内治疗易复发难治愈疾病研究等。
2. **卫生检验检疫方向**（负责人金大志教授）：聚焦新发突发传染病病原体检测检验新技术方法开发，特别是艰难梭菌致病机制、耐药机制、基因组进化及小分子药物开发，以及卫生检验技术研究。
3. **医学影像技术方向**（负责人徐秀芳教授）：研究多参数MRI有效指标、肿瘤分子影像学、神经导航引导脑肿瘤穿刺技术、脑肿瘤术前功能区定位；获国家自然科学基金3项、省部级项目20多项，获全国优秀教材二等奖1项。
4. **康复治疗方向**（负责人叶祥明教授）：围绕人工智能康复、神经修复、运动技术创新开展研究。
5. **智能医学工程方向**：聚焦阿尔茨海默病智能预警生物标志物研究。

### 师资队伍与领军人物
1. **师资总体情况**：专任教师90人，高级职称53人（占30%以上），博士55人；硕导69人，其中正高35人、博士46人。
2. **人才称号**：教育部医学技术类专业教学指导委员会委员1人，省万人创新人才2人次，浙江省151人才5人，省杰青1人，省高层次创新人才2人，省领军型创新创业团队1个。
3. **学科领军人物**：学位点负责人吕建新教授（博士，国家百千万人才工程人选、国家行业企业专家、省万人计划领军人才，教育部医学技术类专业教学指导委员会委员、国家自然科学基金医学技术检验学科专家组组长、中华医学会检验学会教育学组组长）；研究生院院长徐秀芳教授（兼医学影像学院院长，国家一流本科专业建设点医学影像技术专业负责人，教育部教指委相关医学分会委员、中华医学会影像技术分会影像技术专委会委员）；叶祥明教授（省人民医院主任医师、二级教授、博导、博士后导师）；金大志研究员（学术院长）；李凯教授（信息工程学院院长）。

### 硕士培养与毕业去向
1. **培养目标**：面向健康中国发展需要，紧密服务区域行业产业发展，围绕国际学术前沿、国际重大需求和转化研究，培养熟练掌握医学技术领域专业知识技能、具有良好创新实践能力的高层次应用型人才。
2. **培养方式与学制**：采用教学、专业实践及学位论文相结合方式；全日制专业学位学制三年，最长不超过五年。
3. **学分要求**：实行学分制，毕业前学业课程不少于24学分，其中专业必修课分方向、学分大于等于12学分。
4. **就业方向**：医院相关科室（检验方向可进入检验科、输血科、病理科，影像技术方向可进入放射科、超声科）；疾控中心；医药企业（产品研发、推广，质量管理体系建立与维护、产品法规统筹与合规管理）；医疗器械公司（研发、销售、技术支持）；保险公司（医疗保险核保理赔、健康险产品开发）；药监局、卫健委、海关（医疗器械监管、卫生政策制定、口岸卫生检疫）；高校研究所等。

### 2026年招考计划
1. **招生计划**：2026年计划招生34人，实际以教育部正式下达人数为准。
2. **初试科目**：思想政治理论、英语（统考），专业课按方向自主命题（检验综合、医学影像技术综合、康复治疗综合、智能医学工程综合）；专业课分值300分、时长180分钟。
3. **检验综合构成**：分子生物学检验占40%、生物化学检验占30%、微生物学检验占30%。
4. **考试大纲**：包括考试内容、考试形式、试卷结构、具体知识点及参考书目，各方向专业综合课程均有指定考试大纲。
5. **复试方式与占比**：目前以线下为主，初试占60%、复试占40%；复试内容为英语能力测试20%、专业能力测试40%、综合能力测试40%。
6. **英语难度**：介于四级和六级之间。
7. **跨专业报考**：允许非本专业考生跨专业报考医学技术专业。

## 各方立场与诉求
1. **宋宝峰（杭州医学院检验医学院、生物工程学院党委书记、副院长）**：作为主讲嘉宾，系统介绍医学技术专业硕士点的基本情况、学科优势、研究方向、师资队伍、培养方式、就业方向及2026年招考计划，并回应考生关切，鼓励报考。
2. **主持人**：代表考生及家长提出关注点，引导宋宝峰就就业前景、复试环节、初试科目、跨专业报考等问题进行解答；宋宝峰逐一回应，双方形成问答互动。
