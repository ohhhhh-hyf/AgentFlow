# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷一案，因不服云南省高级人民法院云民初88号民事判决，向本院提起上诉。本院依法组成合议庭，公开开庭审理。庭审围绕三个争议焦点展开：抵押权与融资租赁所有权冲突、罚息复利计算、违约金。经法庭调查与辩论，合议庭在查明事实、分清是非基础上提出调解方案，各方当事人均无异议，自愿达成调解协议，法院予以确认并出具调解书。

# 原告诉称与被告辩称
庭审中，国开行主张其已尽审查义务，构成善意取得抵押权；招银租赁认为国开行未查询融资租赁登记系统，不构成善意。国开行主张罚息自2018年6月13日起算且复利有合同依据；东源公司认为罚息不应计收复利，且宣布提前到期未给合理期限。国开行主张东源煤电违约应支付违约金；东源公司认为国开行未举证违约事实，且未履行限期纠正程序。

# 举证与法庭调查
**举证与质证**
- 国开行提交证据：2018年6月13日向东源煤电、东源煤业发送的偿还贷款本金函件；2018年9月对曲靖电力公司的融资租赁查询证书；设备权属证明、工商出资证明、人民银行征信查询结果等。
- 招银租赁提交证据：回租设备清单（载明设备名称、生产厂家，未载明型号）；2013年、2015年审计报告（载明曲靖电力公司注册资本4亿元且已实缴）；2018年核查表（显示曲靖电力公司名下无融资租赁登记）。
- 东源公司提交证据：2015年12月2日发送的邮件及附表（载明抵押设备情况，设备名称与招银租赁设备一致，并以红色标注）。

**质证意见**
- 国开行认为：东源公司邮件未明确告知融资租赁情况，统计表仅显示招银租赁抵押物已登记，不能得出已告知的结论；设备为通用设备，无唯一标识，无法逐一核查；已按人民银行规定完成查询，未发现登记，构成善意取得。
- 招银租赁认为：国开行2018年查询证书不符合要求，未在抵押时点查询；东源煤电出资行为系无权处分；招银租赁2012年已取得设备所有权，国开行抵押权在后且未尽审查义务，不构成善意。
- 东源公司认为：邮件发送时间（2015年12月2日）早于抵押合同签订（2015年12月20日），且设备名称一致并以红色标注，国开行应尽注意义务进行核查。

**法官询问要点**
- 询问各方对人民银行征信中心融资租赁登记性质及法律后果的理解。
- 询问国开行贷款前审查是否内部规定必须查询融资租赁系统，未查到结果是否需保留单据作为风控材料。
- 询问招银租赁在融资租赁登记系统中设备唯一标识码是否为必填项。
- 询问国开行与招银租赁查询方式能否保证查询到登记结果。
- 询问各方对融资租赁司法解释第九条举证责任分配的意见。
- 询问各方对因不同登记机构产生登记瑕疵的意见和建议。

**争议焦点辩论**
- 争议焦点一：抵押权与融资租赁所有权冲突。国开行主张已尽审查义务构成善意取得；招银租赁认为国开行未查询系统不构成善意；东源公司认为国开行未尽注意义务。
- 争议焦点二：罚息、复利计算。国开行主张罚息自2018年6月13日起算，复利有合同依据；东源公司认为罚息不应计收复利，且宣布提前到期未给合理期限。
- 争议焦点三：违约金。国开行主张东源煤电违约应支付违约金；东源公司认为国开行未举证违约事实，且未履行限期纠正程序。

# 庭审结果
本案争议焦点为：一、国开行对案涉设备是否享有抵押权，是否构成善意取得；二、罚息、复利的计算方式；三、东源煤电、东源煤业是否应连带给付违约金。经合议庭评议，各方当事人自愿达成调解协议，法院予以确认并出具调解书。调解方案主要内容：确定国开行对93项设备有抵押权，招银租赁对六项设备有所有权；双方对案涉全部发电设备整体盘活处置，从变现款中实现各自债权；司法变现价格双方各50%，费用各担50%；变现款不足或变现不能时，招银租赁未实现债权按破产重整计划预留方案清偿；司法变现不能时，双方均放弃设备权益，由东源曲靖电力自主生产经营。各方对一审判决第二项、第四项无争议，按判项内容在调解书中确认。一审诉讼费中国开行诉请部分按一审判决执行，招银租赁诉请部分由二审法院按规定确定，二审诉讼费由本院依法确定。各方之间就本案涉及的问题不再存在任何争议。
