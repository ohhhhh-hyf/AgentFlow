# 课程概况
本次课程为历史小论文写作专题指导课，由老师主讲、学生参与互动。课程围绕小论文写作的核心要求展开，强调观点必须明确亮出、不能仅作事实陈述，论证部分建议写2至3条以支撑论点，整体结构遵循“先背景、再观点、后论证、最后总结升华”的框架，且总结需升华观点而非简单重复。课程重点讲解了自命题类、观点提示类和图表信息类三类题型的解题方法：自命题类需按审题、读材料、罗列事实、控制篇幅的步骤推进，审题时注意题目要求（如是否限定用世界史知识），写作前先列提纲避免直接写在答题卡上；观点提示类需先判断材料中的观点、选择核心观点并明确表述自身立场，结合具体史实评析后得出结论，不能照抄材料；图表信息类需快速提取题头、横向纵向等关键信息，分析信息间关系与变化，再提取有效信息进行分析。课程通过武汉长江大桥、梁启超观点、图表题等例题进行实践指导，并明确了“先写对内改革，再写对外开放”的写作顺序。

# 核心知识点梳理
## 小论文写作基本要求
- **观点明确**：小论文必须亮出明确观点，不能只做「几个方面加个名词」的简单陈述，观点需有凝聚力。
- **论证条数**：论证部分建议写 **2–3 条**，太少无法支撑论点，太多则显冗长。
- **写作结构**：先写背景（可先打开一个学术报告作背景），再亮观点，随后展开论证，最后总结升华。
- **总结升华**：结尾不能简单重复观点，要升华观点，说明写作目的。
- **逻辑呈现**：可用序号或直接分条列出，但逻辑必须清晰；可按时间脉络（如 700 时期、明清时期）、国内外、内政外交等维度罗列，让阅卷者清楚看到层次。

## 自命题类题型解题方法
- **审题**：先慢审题，看清要求，注意是否限定用世界史知识、是否限定范围，以及「小红帽」要求与评分标准。
- **读材料**：先大概浏览抓主要信息，再细看材料之间的关系。
- **列事实**：先写好题目，再罗列与材料相关的事实，避免乱列，不要直接写在答题卡上。
- **控制篇幅**：写作时注意控制篇幅，先列提纲再动笔。
- **武汉长江大桥例题**：学生分析时提到「一五计划」与新中国成立背景，老师指出写作顺序应**先写对内改革，再写对外开放**，按时间顺序排列。
- **易错点**：审题时未看清要求（如是否限定用世界史知识）、选材未体现重大国家利益、背景与措施混写。

## 观点提示类题型解题方法
- **判断观点**：先看材料中有哪些观点，判断其正误，选择一个核心观点并清晰表述自己的立场。
- **明确表述**：不能照抄材料观点，要形成自己的观点，如「我认为某某的观点是如何如何的」。
- **评析结合史实**：评析材料观点时需结合具体史实，如中华文化的优越性可举丝绸之路、四大发明对欧洲的贡献等。
- **结论判断**：结论需基于材料观点做出具体判断，不能重复材料观点。
- **梁启超观点例题**：材料含四个观点——国民应略知本国历史、了解本国历史可维护国家利益、有历史知识不会偏激理解、国家发展需国民具备历史素养；学生选择第二条评析，老师肯定其写法，并指出应补充「为什么在 1940 年抗战时期写此书」的时代背景。
- **易错点**：只评析材料观点而未提出自己的看法，或照抄材料观点。

## 图表信息类题型解题方法
- **提取关键信息**：快速看图表题头、横向纵向信息，抓住关键信息。
- **分析关系变化**：注意信息之间的关系与变化，提取有效信息后再进行分析。
- **图表题例题**：涉及历代民德等级变化，学生可写春秋、东汉、宋明等时期，结合儒家思想、社会状态分析变化原因；官方答案引用梁启超「人人独善其身，人人相善其群」，并联系唐朝国力强盛但民德评价不高，探讨国家强盛、民德高尚与制度改善的关系。
- **易错点**：只描述图表现象而未分析原因，或未结合时代背景（如思想、政治、经济因素）进行论证。

# 课堂互动与答疑
**学生**：观点提示类题型和自命题类题型有什么区别？
**教师**：自命题类需要自己提出观点并论证；观点提示类则先判断材料中的观点，选择核心观点后明确表述自己的立场，不能照抄材料，评析时需结合具体史实得出结论。

**学生**：图表信息类题型怎么提取信息？
**教师**：先快速看图表题头、横向纵向信息，抓关键信息，再分析信息之间的关系和变化，提取有效信息后进行分析，注意图表中隐含的时间、地域等要素。

**学生**：写小论文时论证部分写几条合适？
**教师**：论证部分建议写2-3条，太少无法支撑论点，太多则显得冗长，每条论证需逻辑清晰、与材料相关。

**学生**：总结部分怎么写？
**教师**：总结要升华观点，不能简单重复观点，需结合论述内容进行提升，体现对观点的深化理解。

**学生**：审题时要注意什么？
**教师**：审题要慢，注意题目要求，如是否限定用世界史知识或特定范围，还要关注题目中的"小红帽"要求及评分标准，避免答非所问。

**学生**：写作前需要列提纲吗？
**教师**：建议先列提纲，罗列要写的事实，避免直接写在答题卡上导致出错或混乱，罗列的事实要与材料相关，不能乱列。

# 课后任务与学习建议
## 课堂练习
- **武汉长江大桥自命题练习**：审题后先写背景（新中国成立或改革开放以来），再列对内改革、对外开放等事实，注意按时间顺序先写对内改革再写对外开放，最后总结升华。
- **梁启超观点评析练习**：材料给出四个观点（国民应略知本国历史、了解本国利益、敬畏本国历史、不偏激不局限），任选两个结合史实评析，结论需自己判断、不能重复材料观点。
- **历代民德变化图表题**：根据图表提取春秋、东汉、宋明等时期民德等级变化，结合儒家思想、社会状态等分析原因，可拟题如「学术发展影响民德」或「民德与制度改善的关系」。
- **建筑与政治关系图表题**：从建筑角度分析其与政治的关系，提取图中有效信息，结合材料与实践关系进行论述。

## 复习重点
- **小论文写作结构**：先背景、再观点、后论证、最后总结升华；总结不能简单重复观点，需升华。
- **论证条数**：建议写2-3条，太少无法支撑论点，太多则难以控制篇幅。
- **观点表述**：必须亮出明确观点，不能只是几个方面加名词的简单陈述。
- **逻辑呈现**：可用序号或直接列出，但逻辑要清晰，可按时间脉络（如先秦、明清）、国内外、内政外交等维度罗列。
- **自命题类解题步骤**：先审题（注意要求，如是否限定用世界史知识）、再读材料（抓主要信息、分析材料间关系）、罗列与材料相关的事实、控制篇幅。
- **观点提示类解题步骤**：先判断材料中观点，选择核心观点，明确表述自己立场（不能照抄），结合史实评析，最后得出结论。
- **图表信息类解题步骤**：快速看题头、横向纵向信息，注意信息间关系与变化，提取有效信息后分析。

## 学习建议
- **写作前列提纲**：先在草稿上写好题目、罗列要写的事实，不要直接写在答题卡上，避免写错又乱。
- **审题要慢**：仔细看题目要求，注意「小红帽」等关键限定条件及评分标准。
- **结合时代背景**：写历史小论文时思考「为什么在这个时期写这个内容」，如梁启超1940年抗战时期写本国历史认知问题，有其现实针对性。
- **多角度选材**：可写政治、科技、文化、经济等多方面史实，如丝绸之路、四大发明对欧洲的贡献等，支撑观点。
