# 复盘目标与结果概况
老板主持2023年度年终总结会，面向短视频、执行（拍摄/后期）、商务等部门的全体员工，围绕全年经营数据、年终奖发放标准、员工个人评价、部门评价、颁奖与抽奖等环节展开。会议公布年终奖总额226,000元，成本支出390万元（含人员工资、外援配音、字幕、租机器），利润率约24%或27%；公司总量提升，但成本控制差，结余到账往下跑，还有百来万没收回来，老板个人比去年少拿约10万，公司亏损100万。会议基调以肯定与鼓励为主，老板逐一点评员工并颁发5项奖项，最后组织抽奖，整体氛围积极。

# 全年结果与表彰
## 经营数据与口径
- **年终奖总额**：226,000元，为转账部分总额。
- **成本支出**：390万元，包括人员工资、外援配音、字幕、租机器。
- **利润率**：约24%或27%，老板认为非常不可观。
- **最高工资**：含年终奖，有两三人拿到手达到20万以上。
- **平均工资**：到手1万多。
- **人工支出**：2023年平均人工支出相对提高，平时工资到手提高约25万。
- **年终奖对比**：比去年多1312万多；去年干满一年的员工四五人，今年12人。
- **公司结余**：总量提升，但结余到账往下跑，还有百来万没收回来。
- **老板收入**：个人比去年少拿约10万，公司亏损100万。

## 制度与标准
- **年终奖发放标准**：刚入职两三个月或半年以内的发红包，去年600、800元，今年约1000元；干满一年的以一个月基本工资为基准，表现好会更高；超过一年主要考虑当年表现，不再过多考虑年限；干得久且满意的员工有高预算，实际拿到两三万，预算可到大几万。
- **评选标准**：奖项评选为2选1或3选1，有竞争性；未获奖不代表能力不行，但证明不突出。
- **奖金侧重**：年终奖和奖项侧重后期，后期比前期少一截，老板唯一愿意解释。

## 奖项与表彰
- **最佳新人奖**：颁给红叶子（10月入职，11月转正，政委评价高，懂技术懂英语，有把事情做好的精神）和张扬（公司邀请的人才，来了半年，职业态度和工作能力达到期待）。
- **最佳进步奖**：颁给欧阳小元（刚满一年，有学习能力，技术进步明显）。
- **后期独挡一面奖**：颁给李国宇（能完美胜任后期各种类型，拍摄水平高，后期有灵性）。
- **最佳员工奖**：颁给刘腾宇（评价最高，职业性、专业性、纪律性最好，含金量最高）。
- **特别贡献奖**：颁给林海腾（奖金最多，运营层面重要，上传下达，后期安排繁重）。

## 环节与福利
- **证书**：皮质，40块钱一本，加上设计费，字体认真对过。
- **抽奖**：15个奖品，包括充电宝（价值79元）、观影券（价值30元）、洗头膏（价值七八十）、100元红包；抽奖方式为纸条放袋子里。
- **报销政策**：今天看电影或吃饭在一定额度内可报销，仅限今天。
- **红包**：林海腾发200元红包在群里，老板转给他。

# 亮点事项
- **账号运营突破**：郭东辉负责的账号在6月20日第一条外出拍摄视频后起色，视频号粉丝从700涨到8万，小红书从2000涨到6.4万，抖音从2000涨到5.7万，B站从3.1万涨到7.6万；成功原因包括**破釜沉舟说服潘老师外出拍摄**、坚持不放弃、有数据支撑的决策。
- **员工表现超预期**：张文倩完成宁波项目出乎意料，本以为干不了但完成了；宋俊逸第一次安排活就效率高、段位高；张扬的加入带来改变，老板认为2023年最有价值的事是招他进来。
- **后期整体进步**：林海腾指出后期人员分级模糊，效率整体提升，制作能力进步，高强度工作下仍保证质量。
- **商务结果达标**：商务部门实打实项目约300万左右，基本达到预期。

# 不足事项
- **成本控制差**：成本支出390万元，利润率仅约24%或27%，非常不可观；根因是老板对成本关心或关注不够，不够雷厉风行，问题未及时解决。
- **公司结余缩水**：总量提升但结余到账往下跑，还有百来万没收回来；老板个人比去年少拿约10万，公司亏损100万。
- **加班多、人不够**：后半年基本都在加班，根因是老板判断失误，没有及时招合适人数的人员，商务活断断续续造成错觉。
- **外援成本高**：部分外援因忙不过来，部分因技术水平达不到；钱德峰指出有些活公司内部就能搞定，但凑不出人。
- **账号未变现**：账号虽有发展但未变现，变现程度满分十分只达到7.05分，重点项目未完成。

# 改进计划
- **针对成本控制差**：老板表示明年开会再讨论成本控制的具体措施。
- **针对账号未变现**：老板期待明年账号开始变现，将投入更大精力，给予足够重视。
- **针对加班多、人不够**：老板承认判断失误，本质是没有及时招合适人数的人员，明年将反思并改进。
- **针对外援成本高**：钱德峰建议尝试让公司内部人员参与拍摄，提升收入并体验；老板表示明年靠这个方向靠，希望大家都能参与。
- **针对商务支持不足**：老板表示明年将给予商务部门更多支持和帮助。
- **针对员工沟通能力**：老板对欧阳、李国宇等提出沟通能力需提升的期待。
