# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司（东源煤电）、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷二审案件，由最高人民法院审判员李少平担任审判长，与审判员魏文超、黄年、王海峰、葛洪涛组成合议庭，法官助理张瑞，于二审公开开庭审理。庭审程序包括宣布法庭纪律、核对当事人身份、确认诉讼权利义务、法庭调查、法庭辩论及调解。各方对出庭人员身份均无异议，东源煤电、东源煤业、曲靖电力三方同意合并发表意见。合议庭归纳三个争议焦点：国开行是否尽到审查义务并构成善意取得、一审判决对罚息复息计算及起算日期是否认定错误、东源煤电与东源煤业是否应连带给付违约金。经法庭调查与辩论，合议庭休庭评议后提出调解方案，各方均无异议，合议庭予以确认，将出具调解书。

# 举证与法庭调查
**证据与质证**：
- **融资情况统计表**：东源方主张2015年12月2日邮件所附《东源公司融资情况统计表》已告知设备存在融资租赁，且抵押设备部分用红色标注；国开行反驳称邮件正文及附表均无文字载明告知融资租赁情形，且招银租赁栏记载的抵押类型为不动产抵押，与本案融资租赁系不同法律概念。
- **回租设备清单**：国开行指出招银租赁一审提交的证据第7页回租设备清单仅载明设备名称和生产厂家，未载明型号，出厂日期为2012年3月1日，而国开行现场调查核实抵押设备铭牌生产日期均在2013年以后，无法认定同一设备。
- **权属证明材料**：国开行提交证据第54页、58页显示东源煤电公司、曲靖电力公司对抵押设备的权属证明及股东会决议，证明设备所有权属曲靖电力公司，国开行已尽审慎义务。
- **融资租赁查询证书**：招银租赁主张国开行提供的2018年9月查询证书不符合要求，依据2014年93号文，国开行应在抵押时点（2015年12月）查询人行征信中心融资租赁登记系统。
- **审计报告**：招银租赁一审提交2013年、2015年审计报告（证据第82页、95页）载明曲靖电力公司注册资本4亿元且已实缴，国开行据此主张招银租赁应当知道设备出资情况。

**法官询问要点**：
- **融资租赁登记性质**：合议庭询问各方对央行征信中心融资租赁登记性质及法律后果的理解，国开行认为是行业强制性规范，东源方认为是行业指导性规范，招银租赁认为是行业性强制性规范但不影响物权效力。
- **查询方式**：法官询问融资租赁登记系统查询方式，国开行称仅能按单位查询，招银租赁称可按公司名称或设备查询，但案涉5套设备因无唯一识别码未登记。
- **查询义务程度**：法官询问违反查询规范导致的法律后果，国开行主张为基本查询义务，招银租赁主张为严格义务，未查询即不构成善意。
- **举证责任**：法官询问融资租赁司法解释第9条第2款举证责任分担，国开行主张按谁主张谁举证原则，招银租赁主张第1、2、4项由出租人举证，第3项由第三人（国开行）举证。

**争议焦点辩论**：
- **审查义务范围**：国开行主张审查义务仅限于抵押人曲靖电力公司，不能扩大到关联企业；招银租赁主张因东源煤电系借款人且为曲靖电力全资控股母公司，国开行应扩展调查东源煤电。
- **善意取得**：国开行主张已按央行规定查询系统且无登记记录，构成善意取得；招银租赁主张国开行未在抵押时点查询，不构成善意。
- **设备所有权**：招银租赁主张2012年设备交付时即取得所有权，东源煤电出资行为系无权处分；国开行主张设备系通用设备无唯一标识码，已对抵押人尽审查义务。

# 庭审结果
本案争议焦点为：一、国开行是否尽到审查义务、是否构成善意取得；二、一审判决对案涉借款罚息复息的计算及起算日期是否认定错误；三、东源煤电、东源煤业是否应当连带给付违约金。经合议庭评议，各方当事人对调解方案均无异议，合议庭予以确认，将出具调解书。调解方案主要内容：国开行对东源煤电的债权扣除破产清偿本金外，利息、罚息、复利合计6474.4513万元；招银租赁对6项设备享有所有权，对应债权1377.4137万元，国开行对93项设备有抵押权；案涉全部发电设备整体盘活处置，变现价款双方各得50%，费用各担50%；调解书生效后20日内，国开行向一审法院提出执行申请；若司法变现不能，双方放弃设备权益，由东源曲靖电力自主生产经营。
