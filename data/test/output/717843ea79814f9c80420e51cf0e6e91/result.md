# 报告概况
十四届全国人大三次会议于2025年开幕，出席代表2880人，缺席49人，符合法定人数。会议共有四项议程，第一项为审议政府工作报告，由国务院总理李强代表国务院作报告。报告回顾2024年工作，指出经济运行总体平稳，国内生产总值达134.9万亿元，增长5%；城镇新增就业1256万人，居民消费价格上涨0.2%；粮食产量首次跃上1.4万亿斤新台阶，新能源汽车年产量突破1300万辆；嫦娥六号实现人类首次月球背面采样返回。同时指出外部环境复杂严峻，内需不振、预期偏弱等问题交织叠加。报告提出2025年经济社会发展总体要求，部署十大工作任务，整体基调为稳中求进、迎难而上，高质量完成十四五规划目标任务。

# 核心政策
2025年主要预期目标：**国内生产总值增长5%左右**，**城镇调查失业率5.5%左右**，**城镇新增就业1200万人以上**，**居民消费价格涨幅2%左右**，居民收入增长和经济增长同步，国际收支保持基本平衡，**粮食产量1.4万亿斤左右**，**单位国内生产总值能耗降低3%左右**。实施更加积极的财政政策，**赤字率拟按4%左右安排**，**赤字规模5.66万亿元**，发行超长期特别国债1.3万亿元，拟发行特别国债5000亿元支持国有大型商业银行补充资本，安排地方政府专项债券4.4万亿元，合计新增政府债务总规模11.86万亿元。实施适度宽松的货币政策，适时降准降息。安排超长期特别国债3000亿元支持消费品以旧换新，中央预算内投资安排7350亿元。

# 重点工作
**经济领域**：大力提振消费、提高投资效益，全方位扩大国内需求，实施提振消费专项行动，安排超长期特别国债3000亿元支持消费品以旧换新，扩大健康、养老、托幼、家政等多元化服务供给，加快数字、绿色、智能等新型消费发展；因地制宜发展新质生产力，培育壮大新兴产业、未来产业，培育生物制造、量子科技、具身智能、6G等未来产业，推动传统产业改造升级，激发数字经济创新活力；扩大高水平对外开放，稳定对外贸易发展，促进跨境电商发展，大力鼓励外商投资，推动高质量共建一带一路走深走实。

**民生领域**：更大力度稳定和扩大就业，实施重点领域、重点行业、城乡基层和中小微企业就业支持计划；强化基本医疗卫生服务，深化以公益性为导向的公立医院改革，优化药品集采政策；完善社会保障和服务政策，**城乡居民基本养老金最低标准再提高20元**，适当提高退休人员基本养老金，制定促进生育政策并发放育儿补贴，大力发展托幼一体服务；深入实施科教兴国战略，制定实施教育强国建设三年行动计划，逐步推行免费学前教育，推进高水平科技自立自强。

**环保领域**：协同推进降碳、减污、扩绿、增长，持续深入推进蓝天碧水净土保卫战，全面推进以国家公园为主体的自然保护地体系建设，加快发展绿色低碳经济，积极稳妥推进碳达峰碳中和，建立零碳园区、零碳工厂，开展煤电低碳化改造试点示范。

**改革与风险防范**：推动标志性改革举措加快落地，高质量完成国有企业改革深化提升行动，开展规范涉企执法专项行动，纵深推进全国统一大市场建设；有效防范化解重点领域风险，持续用力推动房地产市场止跌回稳，稳妥化解地方政府债务风险，积极防范金融领域风险。

**三农与城镇化**：着力抓好三农工作，稳定粮食播种面积，严守耕地红线，高质量推进高标准农田建设，巩固拓展脱贫攻坚成果；推进新型城镇化和区域协调发展，科学有序推进农业转移人口市民化，持续推进城市更新和城镇老旧小区改造。
