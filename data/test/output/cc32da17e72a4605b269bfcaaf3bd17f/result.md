# 就诊概况
48岁男性患者张学恒，因上腹心窝处烧灼样疼痛反复发作4年、近3个月持续加重，于消化专科门诊就诊。疼痛与进食冷硬、辛辣食物及工作紧张劳累相关，可忍受，无夜间痛醒。近一年内两次出现黑便，近两个月有呕吐。初步判断为上消化道疾病，需进一步检查明确诊断。

# 诊断与检查结果
医生初步诊断为上消化道疾病，具体性质待检查明确。患者近一年内两次黑便，大便潜血阳性（原文为医生告知大便出血），提示上消化道出血可能。近3个月大便颜色正常，无黑便。胃镜检查预约在后天进行，以明确诊断。

# 治疗方案与医嘱
治疗计划：待胃镜及大便检查结果明确后，由上级张医生确定具体治疗方案。生活注意事项：建议戒烟、少饮酒，因吸烟饮酒对胃部疾病有不良影响；注意休息，避免过度劳累和熬夜，因工作紧张劳累可诱发症状。重点禁忌：**磺胺类药物过敏**，禁用磺胺药。
