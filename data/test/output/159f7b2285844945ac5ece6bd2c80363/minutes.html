白母山村芦塘支部换届选举党员大会

全文摘要

中共巢湖市银屏镇白母山村芦塘支部召开党员大会改选支部委员会，支部共有正式党员8名，因病请假1名，实到7名，符合法定人数；银屏镇党委组织委员钱小丽到会指导。大会围绕换届选举展开，依次完成上届支部委员会工作报告审议、选举办法草案表决、支委候选人名单及监票人建议名单通过、候选人竞职演说、新一届支部委员及书记选举等议程。经无记名投票，卢燕娇、辛东升、杜军强当选新一届支部委员会委员，卢燕娇当选支部书记，辛东升负责组织宣传工作、杜军强负责纪检工作，选举结果报镇党委批准。上届工作报告显示，三年来支部新发展党员1名，收缴党费2640元上交上级党组织。

分段速览

00:00:13-00:02:41 会议开场与领导讲话

会议开始，主持人宣布应到有选举权党员8名，因病请假1名，实到7名，符合法定人数。镇党委组织委员钱小丽到会，代表镇党委就换届选举提出三点意见：充分认识大会重要意义、正确行使选举权严格把握选举要求、服从大局遵守选举纪律。

00:02:41-00:05:26 上届支部委员会工作报告

上届支部委员会作三年工作报告，总结思想政治建设、支部建设、主题教育活动、党务公开、党风党纪教育五方面工作，指出存在问题：党建工作制度不够完善、党员主体意识需提高、党支部对党员教育管理监督不够深入。党员对报告表示满意，鼓掌通过。

00:05:55-00:10:43 通过选举办法、候选人名单及工作人员名单

杜军晓宣读选举办法草案，明确选举委员3名、候选人4名，差额不少于应选名额20%，采用无记名投票，先差额选委员再等额选书记，经举手表决一致通过。宣读镇党委批复，候选人名单为卢燕娇、辛东升、杜军强、秦磊，书记候选人预备人选卢燕娇，鼓掌通过。贾淑玲任监票人，黄婷丽、刘彩云任计票人，一致通过。

00:10:43-00:14:45 候选人竞职演说

四位候选人依次发表竞职演说。卢燕娇承诺加强支部建设、推动村集体经济发展、抓好民生工程；杜军强表示可更好担当桥梁纽带作用；辛东升承诺群众有困难随叫随到、严格要求自己、完成上级任务；秦磊表示有责任心、思想觉悟高、不计较个人得失。

00:14:45-00:21:17 选举新一届支部委员会委员

清点人数确认实到7名，达到应到会人数4/5，可以进行选举。发出并收回选票7张，选举有效。计票结果：卢燕娇6票、杜军强6票、秦磊2票。卢燕娇、辛东升、杜军强当选为新一届支部委员会委员。

00:21:17-00:28:42 选举支部书记及委员分工

召开第一次支委会，通过书记候选人建议名单卢燕娇，辛东升任监票人和计票人。发出并收回选票3张，卢燕娇得3票，当选为新一届党支部书记。分工为辛东升负责组织宣传工作，杜军强负责纪检工作。选举结果将报镇党委批准。

00:28:42-00:29:56 新当选支委代表发言与大会闭幕

新当选支委代表卢燕娇发言，表示将抓好支部学习工作、制度建设和基层党组织建设，争创学习型、制度型、服务型支部。主持人宣布换届选举大会圆满结束，全体起立奏国际歌。

要点梳理

会议开幕与镇党委指导

  1. 中共巢湖市银屏镇白母山村芦塘支部召开党员大会，改选支部委员会；支部共有正式党员8名，因病请假1名，实到有选举权党员7名，符合法定人数。
  2. 银屏镇党委组织委员钱小丽到会指导，就换届选举工作提出三点意见：充分认识大会重要意义、正确行使选举权严格把握选举要求、服从大局严格遵守选举纪律。
  3. 钱小丽希望新一届班子加强学习、提高素质、发挥战斗堡垒作用，带领全村党员和群众将白母山村建设得更加美好。

上届支部委员会工作报告

  1. 上届支部委员会作三年工作报告，总结工作包括：加强思想政治建设和理论学习、抓好党支部建设增强凝聚力、开展主题教育活动、推进党务公开、抓好党风党纪教育。
  2. 三年间新发展党员1名，按规定收缴党费2640元上交上级党组织。
  3. 上届支部指出存在问题：党建工作制度不够完善、党员主体意识尚需提高、个别党员干部顶推中心服务大局意识不强、党支部对党员教育管理监督不够深入。
  4. 党员对工作报告表示满意，鼓掌通过。

通过选举办法

  1. 杜军晓宣读党员大会选举办法草案，规定选举中共芦塘支部委员会委员3名，候选人4名，差额不少于应选名额20%。
  2. 选举采用无记名投票方式，先差额选举支部委员会委员，再从当选委员中等额选举书记，两次选举分别投票、计票和宣布结果。
  3. 参加会议有选举权的正式党员必须超过应到会党员的4/5方可进行选举；收回选票等于或少于发出选票选举有效，多于发出选票选举无效。
  4. 候选人得到赞成票超过应到会选举人数半数方可当选；得票超过半数候选人多于应选名额时以得票多少为序取足应选名额。
  5. 选举办法草案经举手表决一致通过。

通过候选人名单

  1. 杜军晓宣读银屏镇党委批复（2019年10月12日），同意新一届支部委员会委员候选人预备人选4名：卢燕娇、辛东升、杜军强、秦磊；委员实行差额选举，差额1人。
  2. 书记候选人预备人选为卢燕娇，实行等额选举；选举结果报镇党委批准。
  3. 候选人名单经鼓掌通过。

通过选举工作人员名单

  1. 提议贾淑玲担任监票人，经举手表决一致通过。
  2. 宣布计票人员为黄婷丽、刘彩云。

候选人竞职演说

  1. 卢燕娇（1993年9月出生，2014年4月入党）承诺：加强支部建设，落实三会一课、组织生活会和民主评议党员等制度；推动村集体经济发展，发挥党组织和党员在产业培育、农民增收、脱贫攻坚方面的示范引领作用；抓好民生工程落实，把群众满意度作为衡量工作标准。
  2. 杜军强（从事村委会工作）表示：农村党支部是基层党组织与党员群众之间的桥梁纽带，如当选可更好担当主导角色，为党员和群众服务。
  3. 辛东升承诺：群众有困难随叫随到；严格要求自己，不该吃的饭不吃、不该拿的钱不拿、不该做的事不做；圆满完成上级党组织分配的各项任务。
  4. 秦磊表示：有较强责任心，能认真参加支部理论学习、不折不扣完成组织任务；有较高思想觉悟，积极向群众宣传并带头遵守；配合上级工作，不计较个人得失。

选举新一届支部委员会委员

  1. 清点人数：应到会有选举权党员8名，因病请假1名，实到7名，达到应到会人数的4/5，可以进行选举。
  2. 发出选票7张，收回选票7张，选举有效。
  3. 计票结果：卢燕娇6票、杜军强6票、秦磊2票。
  4. 根据大会选举办法，卢燕娇、辛东升、杜军强当选为新一届中共巢湖市银屏镇白母山村芦塘支部委员会委员。

选举新一届支部书记及委员分工

  1. 召开第一次支部委员会全体会议，宣读选举办法草案，规定选举产生支部书记1人，采用无记名投票、等额选举方式。
  2. 书记候选人建议名单为卢燕娇，经鼓掌通过；辛东升担任监票人和计票人，经举手表决通过。
  3. 发出选票3张，收回选票3张，卢燕娇得3票，当选为新一届党支部书记。
  4. 委员分工：辛东升负责组织宣传工作，杜军强负责纪检工作。
  5. 新当选支委代表表态：抓好支部学习工作，认真开展不忘初心、牢记使命主题教育；抓好制度建设工作，增强党支部凝聚力战斗力；完善基层党组织建设，争创服务型支部，发挥战斗堡垒和党员先锋模范作用。

结论与决定

  1. 通过上届支部委员会工作报告。
  2. 通过党员大会选举办法草案。
  3. 通过支委候选人名单：卢燕娇、辛东升、杜军强、秦磊。
  4. 通过监票人建议名单：贾淑玲担任监票人，黄婷丽、刘彩云任计票人。
  5. 卢燕娇、辛东升、杜军强当选为新一届支部委员会委员。
  6. 卢燕娇当选为新一届党支部书记，选举结果以报镇党委批准为准。
  7. 辛东升负责组织宣传工作，杜军强负责纪检工作。
