# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷一案，国家开发银行不服云南省高级人民法院（2018）云民初88号民事判决，向本院提起上诉。本院依法组成合议庭，依据《中华人民共和国民事诉讼法》第一百三十四条第一款、第一百六十九条的规定公开开庭审理。审判长核对各方出庭人员身份：上诉人国家开发银行委托北京德恒昆明律师事务所邓劲松、刘双俊律师，代理权限为特别授权代理；被上诉人东源煤电委托云南勤业律师事务所吴学成律师，东源煤业委托员工李新海及吴学成律师，东源曲靖电力出庭人员与东源煤电一致，代理权限均为特别授权代理；被上诉人招银租赁委托员工万海龙及上海盈泰律师事务所陈志超律师出庭。各方对出庭人员身份均无异议，审判长确认身份符合法律规定。鉴于东源煤电、东源煤业、曲靖电力委托有共同诉讼代理人，三方同意合并发表意见。庭审围绕三个争议焦点进行审理：国开行是否尽到审查义务并善意取得抵押权、一审对罚息复息的计算及起算日期是否认定错误、东源煤电及东源煤业是否应连带给付违约金。各方充分辩论后，合议庭休庭评议提出调解方案，各方均无异议并签署调解协议，法院将出具调解书。

# 举证与法庭调查
## 举证与质证

1. **融资租赁登记查询证书（招银租赁质证）**：招银租赁指出国开行提交的查询证书不符合要求。依据2014年93号《中国人民银行关于融资租赁登记系统的规定》，国开行应当在抵押时点进行融资租赁登记查询，即应提供2015年12月操作抵押时查询人行征信中心的查询结果。
  - 证明目的：国开行主张其已按央行规定查询融资租赁登记系统，未发现相关登记，构成善意取得抵押权。
  - 对方质证意见：招银租赁认为该查询证书系2018年9月出具，非抵押时点查询结果，不能证明国开行在设定抵押权时已尽查询义务。

2. **2015年12月2日邮件中的融资情况统计表（东源方质证）**：东源方主张该统计表显示招银租赁的抵押物已登记，且设备名称与国开行抵押设备完全一致并已红色标注，国开行应尽注意义务。
  - 证明目的：东源方认为国开行在办理抵押时已知悉或应当知悉案涉设备上存在招银租赁的融资租赁登记。
  - 对方质证意见：国开行主张其审查义务仅限于抵押人曲靖电力公司，不能扩大到东源煤电公司；且融资租赁登记为行业性规范，非法定物权登记。

3. **借款合同第24条第2款第2项（东源方引用）**：东源方主张合同约定国开行宣布贷款提前到期时应向借款人发出通知并要求限期偿还，限期偿还与立刻偿还是完全不同的两个概念。
  - 证明目的：东源方认为国开行2018年6月13日发函要求当天偿还全部贷款，未给合理期限，不符合合同约定。
  - 对方质证意见：国开行主张其于2018年6月13日向东源煤电、东源煤业发送两份关于偿还云南恩洪矿区煤矸石综合利用电厂上大压小项目贷款本金的函，明确要求当日归还借款，贷款已提前到期。

4. **借款合同第6条第4款（国开行引用）**：国开行主张合同明确约定贷款人对借款人不能按期支付的利息计收复利，其中包含对不能按期支付的逾期借款利息按罚息利率计收复利。
  - 证明目的：国开行主张罚息应作为复利计算基数，有合同依据。
  - 对方质证意见：东源方认为合同表述的是对逾期借款的「利息」计收复利，均未提到罚息；依据《人民币利率管理规定》第21条，计收复利仅针对贷款期内不能按期支付的利息，而非贷款逾期后的罚息。

5. **借款合同第24条第3项（国开行引用）**：国开行主张合同明确约定被上诉人发生违约时应承担违约责任，按千分之一支付违约金。
  - 证明目的：国开行主张东源煤电、东源煤业构成违约，应连带给付违约金。
  - 对方质证意见：东源方认为国开行未举证证明东源煤电存在违反柜台前移和账户管理约定的行为；且按合同约定，国开行必须先对违约行为进行限期纠正，不予纠正的才有权主张违约金，国开行自提起诉讼之日始终未发出任何书面纠正函件或告知。

## 争议焦点与辩论

1. **争议焦点一：国开行是否尽到审查义务、是否构成善意取得抵押权**
  - 国开行主张：其审查义务仅限于抵押人曲靖电力公司，不能扩大到东源煤电公司；已按央行规定查询融资租赁登记系统，未发现登记，构成善意取得。
  - 东源方主张：2015年12月2日邮件中融资情况统计表显示招银租赁抵押物已登记，设备名称与国开行抵押设备完全一致并已红色标注，国开行应尽注意义务；国开行作为贷款人，其借款人东源煤电与抵押人曲靖电力构成100%全资控股关系，东源煤电具有借款人及抵押人全资控股母公司的双重身份，国开行对东源煤电的审查义务应当具备。
  - 招银租赁主张：国开行应在抵押时点（2015年12月）查询融资租赁登记系统，而非提供2018年9月的查询证书；案涉5套设备为通用设备，无唯一识别码，招银租赁未在登记系统中登记识别码；查询是银行业严格义务，未查询则不构成善意。
  - 关于融资租赁登记性质：国开行主张为行业性规范，非法定物权登记；招银租赁认为系行业性规范但非法定物权登记。
  - 关于举证责任：招银租赁主张司法解释第9条第1、2、4项由出租人举证，第3项由第三人（国开行）举证。

2. **争议焦点二：一审判决对案涉借款罚息、复息的计算及起算日期是否认定错误**
  - 国开行主张：东源煤电利息支付时间截止到2017年12月20日，利息应从2017年12月21日计算至2018年6月12日，合计21,795,727.68元；罚息自2018年6月13日计算至东源煤电、东源煤业向人民法院申请破产受理之日即2019年2月19日，合计41,050,579.57元；复利自2018年3月21日计算至2019年2月19日，合计1,918,206.23元。
  - 东源方主张：国开行2018年6月13日发函要求当天偿还全部贷款，不符合合同第24条第2款第2项关于限期偿还的约定，未给合理期限；本案本金将近8.37亿元，当天发通知要求当天全额偿还未给合理时间；依据《人民币利率管理规定》第21条，计收复利仅针对贷款期内不能按期支付的利息，而非贷款逾期后的罚息；合同第6条第4款表述的也是利息，均未提到罚息，罚息不应作为复利计算基数。

3. **争议焦点三：东源煤电、东源煤业是否应当连带给付违约金**
  - 国开行主张：依据借款合同第24条第3项，被上诉人发生违约时应按千分之一支付违约金，属双方意思自治，对双方均具有法律约束力。
  - 东源方主张：国开行未举证证明东源煤电存在违反柜台前移和账户管理约定的行为，举证不能的后果应由其自行承担；按合同约定，国开行必须先对违约行为进行限期纠正，不予纠正的才有权主张违约金，国开行自提起诉讼之日始终未向东源煤电发出任何书面纠正函件或告知。
  - 招银租赁主张：招银租赁不是该合同签订时的参与方，尊重合议庭的审查结果。

# 庭审结果
1. **调解协议达成**：经合议庭休庭评议，在查明事实、分清是非基础上提出调解方案，征求各方意见后，各方当事人均无异议，同意签署调解协议。合议庭当庭确认调解协议不违反法律规定，予以确认，并宣布庭后依据《中华人民共和国民事诉讼法》第97条出具调解书。

2. **债权数额确认**：国开行对东源煤电的债权，扣除破产程序中已清偿的本金外，利息、罚息、复利合计6474.4513万元。
  - 利息：2017年12月21日至2018年6月12日期间，合计2179.5727万元
  - 罚息：2018年6月13日至2019年2月19日期间，合计4105.0579万元
  - 复利：2018年3月21日至2019年2月19日期间，合计191.8206万元

3. **设备权属确认**：在东源煤电、东源煤业破产重整程序中，已确定招银租赁对涉案6项设备享有所有权，对应债权数额1377.4137万元；确定国开行对93项设备享有抵押权。

4. **整体盘活处置安排**：招银租赁和国开行对案涉全部发电设备整体盘活处置，并从变现款中实现各自债权。
  - 变现价款双方各得50%，实现费用双方各担50%
  - 调解书生效后20日内，由国开行向一审法院提出执行申请，启动司法处置程序
  - 国开行、招银租赁未实现的债权，待执行法院出具终本裁定后，按照破产重整计划中的预留方案实现债权
  - 若破产管理人对招银租赁的债权不予纳入预留方案，由东源煤电按照此前招银租赁在东源煤电破产重整程序中有担保清偿方案予以清偿
  - 若司法变现不能，国开行和招银租赁的权益通过前述方法实现后，均放弃对案涉设备的权益，由东源曲靖电力自主生产经营

5. **设备管理与配合义务**：案涉设备上的管理费用由东源曲靖电力承担，东源曲靖电力无条件配合司法处置。

6. **一审判决确认事项**：各方对一审判决第2项、第4项无争议，按照其判项内容在调解书中确认。

7. **诉讼费用分担**：
  - 一审诉讼费用中，对于国开行诉请部分按照一审判决执行
  - 对于招银租赁诉请部分的诉讼费用，由二审法院按照规定，根据争议财产对应的债权数额计算后，由国开行承担
  - 二审诉讼费用由法院依法确定后，由国开行和东源煤电各承担50%

8. **争议终结**：本协议签订后，各方之间就本案涉及的问题不再存在任何争议。

9. **程序安排**：各方诉讼代理人依次在调解协议正式文本上签字；合议庭宣布庭审结束，告知阅看庭审笔录并签名，如有遗漏和差错可以申请补正，随后闭庭。
