# 就诊概况
消化内科严医生接诊48岁男性患者张春和（成都轻工研究所科研人员），本次为初诊。患者主诉上腹烧灼感4年，每年春季多发，近3个月加重，疼痛位于心窝处，与进食冷、硬、辛辣食物及工作紧张劳累相关，与油腻食物关系不大；近3个月疼痛为白天发作，无夜间痛醒，有完全不痛的时候。近4年出现两次黑便（一次一年前、一次三个月前），每次持续约一个月，大便干、形状正常，仅颜色改变，两次均住院治疗，住院两三天后大便转黄。最近两个月出现呕吐，吐出酸水样物，含早晨或中午吃的食物，晚上呕吐后舒适，偶有隔夜食物吐出。初步考虑上消化道疾病可能，需进一步检查明确。

# 病史与背景
1. **现病史**：上腹烧灼感4年，每年春季多发，近3个月加重；疼痛位于心窝处，与进食冷、硬、辛辣食物及工作紧张劳累相关，与油腻食物关系不大；近3个月疼痛为白天发作，无夜间痛醒，有完全不痛的时候。
2. **黑便史**：近4年出现两次黑便，一次在一年前，一次在三个月前，每次持续约一个月，大便干、形状正常，仅颜色改变；两次均住院治疗，住院两三天后大便转黄。
3. **呕吐史**：最近两个月出现呕吐，吐出酸水样物，含早晨或中午吃的食物，晚上呕吐后舒适，偶有隔夜食物吐出。
4. **既往史**：16岁时患甲肝，在三医院住院一个月，出院时肝功能正常，此后体检肝功均正常；小时候因扁桃体炎在儿童医院服用磺胺药后左手起红疹，持续半个月，医生诊断为药物过敏，此后不能服用磺胺药。
5. **个人史**：双眼近视400度，平时不常戴眼镜；偶尔出现口腔溃疡，贴小紫药片可好转；偶有腹泻，多因饮食不洁，急性发作后很快好转。
6. **生活史**：吸烟史以前每天一包，现限制在10支以内，考虑逐步戒烟；偶尔应酬时少量饮酒，平时不喝；每天泡两次淡茶；26岁结婚，有一小孩，爱人及孩子身体健康。
7. **家族史**：父亲76岁有低血压，母亲75岁诊断冠心病、服药控制良好，患者本人有低血压（血压90/60），有一个弟弟身体健康；婶婶（叔叔的爱人）患胃癌，患者担心自己反复腹痛与此有关。

# 诊断与检查结果
1. **初步印象**：考虑上消化道疾病可能，需进一步检查明确。
2. **检查安排**：建议留大便做潜血检查，以明确有无出血；建议做胃镜，患者要求安排在后天，因爱人可请假陪同，严医生同意，并提到后天张医生查房，可结合胃镜结果讨论。
3. **医生说明**：严医生解释婶婶无血缘关系，不必担心遗传问题；表示需等检查资料全面后再判断是否手术，若药物能控制则不需手术。
4. **患者顾虑**：患者担心自己是否得了胃癌，担心是否需要手术，因工作繁忙且所里可能安排出国进修，希望如需手术能尽早安排；患者表示医疗费用问题不大，因夫妻双方均有收入且有社保。

# 治疗方案与医嘱
1. **检查安排**：留大便做潜血检查；胃镜预约在后天进行，因患者爱人可请假陪同。
