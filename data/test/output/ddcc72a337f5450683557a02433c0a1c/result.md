# 电子科技大学电子科学与工程学院研究生招生宣讲会

## 沟通背景

电子科技大学电子科学与工程学院举办研究生招生宣讲会，由学院领导段院、柳教授、张教授、李天明教授及在读博士田雨桐面向考生和家长，系统介绍学院历史沿革、学科布局、师资力量、科研平台、人才培养成果及招生政策。学院源于1956年建校时设立的无线电系、电真空器件系、无线电零件系，历经四次院系调整，于2023年成立电子科学与工程学院与集成电路学院，拥有电子科学与技术国家重点一级学科及3个国防特色学科。宣讲会依次介绍学院整体情况、电子信息材料与元器件、电磁场与微波技术、电路与系统、物理电子学等方向，并由在读博士分享择校经验。整体沟通基调为全面展示学科实力与科研条件，吸引优秀生源报考。会议最后解答了考生关于夏令营时间的关切，明确夏令营计划今年举办、具体时间待定，相关信息将通过QQ群发布，并进行了抽奖互动。

## 核心信息

### 1. 学院整体情况

- **历史沿革**：学院源于1956年建校时设立的无线电系、电真空器件系、无线电零件系，历经1979、1992、2001、2018年四次院系调整，2023年成立电子科学与工程学院与集成电路学院。
- **学科布局**：电子科学与技术为国家重点一级学科，下设电磁场与微波技术、电路与系统、微电子学与固体电子学、物理电子学、电磁信息功能材料与机构5个二级学科方向，另有3个国防特色学科。
- **学生规模**：本科生现有1545人，招生专业为工科试验班（电子工程类）；研究生现有硕士和博士研究生1975人。
- **师资队伍**：教师总数302人，含两院院士2人、领军人才19人、青年人才28人、其他类型人才12人、后备61人；拥有2个全国高校黄大年式教师团队，2022年获批4个国家自然科学基金创新群体。
- **科研经费与成果**：近5年科研经费到账稳定在3~4亿元，以纵向项目为主；牵头获得国家科技奖励11项，近5年发表高水平学术论文2000余篇，申请专利1600余件、授权1300余件。
- **科研平台**：拥有2个国家级平台、4个国际合作平台、7个省部级科研平台；科研团队20个，年度经费过千万元的团队15个，其中过亿元团队1个。

### 2. 电子信息材料与元器件方向

- **方向定位**：以电子在物质中的输运特性为基础，以材料为基础、器件为核心、应用为目标导向；2021年中国集成电路电子产品进口额度达2.8万亿元，约为原油进口量的1.7倍，属最紧迫的卡脖子问题之一。
- **邓龙江院士团队**：现有研究人员19人，近年发表包括Nature在内的论文300余篇，承担课题130余项，年均到账经费3000多万元，获国家科技进步/技术发明二等奖共3项。
- **张怀武教授团队**：现有研究人员17人，开展LTCC材料及集成技术、微波毫米波晶圆及器件等研究，承担项目100余项，发表SCI论文400余篇，年均到账经费2000余万元。
- **平台条件**：依托2个国家级平台，科研面积2万余平米，建设两条国家重大任务试验生产线，拥有大型设备/系统500余台套；已获国家技术发明等奖项共计7项。
- **人才培养**：毕业生去向包括英特尔、中芯国际、华为、德州仪器等企业；在读学生杨伟豪以第一作者在Nature Electronics、Nature Communications各发表一篇论文，5G滤波器芯片学生团队获挑战杯四川省金奖。

### 3. 电磁场与微波技术、电路与系统方向

- **学科概况**：电磁场与微波技术含4个细分方向，始于1956年建校时期，所属一级学科入选双一流A类学科；电路与系统学科1981年开始招收研究生，1988年成立首批博士后流动站。
- **团队与成果**：电磁场与微波技术有6个团队；杨世文教授团队强耦合超宽带相控阵成果应用于中电14所某大型机载相控阵雷达，计算电磁学算法被评为20世纪十大算法之一。
- **标志性成果**：樊勇教授团队成功研制0.22THz、0.34THz、0.42THz雷达成像系统，分辨率小于1厘米；太赫兹通信成果在2023年成都大运会田径项目示范应用。
- **平台条件**：拥有国家自然基金委创新群体、国家高等学校学科创新引智基地、国家工程技术研究中心、国家级重点实验室；硬件平台拥有中国高校最先进的微波暗室群体。
- **人才培养**：连续三年获全国大学生集成电路创新创业大赛奖项；就业领域包括华为、中兴等领军企业及各大研究所、高校。

### 4. 物理电子学方向

- **学科定位**：物理学与电子科学与技术的交叉学科，将物理学最新研究成果应用于电子学，产生新型电子器件；典型应用包括微波电子学（微波电真空器件）与光电子学（光电器件）。
- **发展历程**：起源于1956年建校时成立的电子器件专业，1979年成立高能电子学研究所，2018年合并成立电子科学与工程学院；经过近70年发展，拥有自主知识产权商用软件MMST和切皮克。
- **科研实力**：每年到校科研经费接近2亿元，为学院最多；是国际上最大的真空器件研究中心；拥有3个四川省工程中心或重点实验室，2023年成功举办行业顶级会议。
- **研究方向**：系统应用包括回旋行波管毫米波雷达、行波管无线输能系统、磁控管微波能干燥系统；横向拓展至毫米波、太赫兹频段及医学交叉领域。
- **学生出口**：物理电子学方向共有9个团队，团队学生约1/3硕博连读、1/3去企业、1/3去研究所或其他。

### 5. 学生视角分享与招生咨询

- **择校理由**：成都为国家中心城市、新一线城市，电子信息产业发达；电子科学与技术学科在第4轮学科评估中获A+，稳居全国第一；学院拥有四大学科和19个科研团队。
- **团队情况**：田雨桐所在毫米波技术与系统应用团队负责人为樊勇老师，围绕微波毫米波理论与技术等五大方向开展研究，硕博毕业生实现100%就业率。
- **奖助体系**：包括国家奖学金、学业奖学金、专项奖学金、新生奖学金、校园地国家助学贷款和生源地助学贷款等。
- **择导师建议**：先选研究团队再选导师，可通过学院网站、IEEE Xplore和中国知网等检索导师论文和指导研究生情况。

## 各方诉求

- **学院领导段院**：全面展示学院历史沿革、学科实力与科研平台，明确学院2023年响应国家号召成立电子科学与工程学院与集成电路学院，突出国家重点一级学科与国防特色学科布局，吸引优秀生源报考。
- **柳教授**：强调电子信息材料与元器件方向在解决国家卡脖子问题中的关键作用，以2021年集成电路电子产品进口额度2.8万亿元、约为原油进口量1.7倍的数据说明紧迫性，展示两大团队科研经费与成果实力。
- **张教授**：突出电磁场与微波技术、电路与系统两个方向的学科历史积淀与应用成果，以双一流A类学科、20世纪十大算法、太赫兹雷达成像系统等标志性成果彰显学科竞争力。
- **李天明教授**：强调物理电子学方向的基础性与前沿性，以每年近2亿元科研经费、国际最大真空器件研究中心、自主知识产权商用软件等展示方向实力，说明学生出口约1/3硕博连读、1/3去企业、1/3去研究所。
- **田雨桐（在读博士）**：从学生视角分享选择电子学院的8个理由，包括成都产业优势、学科A+评级、团队100%就业率及完善奖助体系，建议考生先选研究团队再选导师。
- **考生及家长**：关注夏令营举办时间，希望明确具体安排以便规划报考。
