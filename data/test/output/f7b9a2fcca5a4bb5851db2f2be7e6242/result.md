# 芦塘支部党员大会换届选举

## 全文摘要
中共巢湖市银屏镇白母山村芦塘支部召开党员大会改选支部委员会，支部共有正式党员8名，因病请假1名，实到会7名，符合法定人数；银屏镇党委组织委员钱小丽应邀到会指导。会议依次完成上届支部委员会工作报告审议、党员大会选举办法表决、支委候选人名单及监票人计票人名单通过、候选人竞职演说、支部委员选举、支部书记选举及委员分工等议程。上届支部报告总结三年工作，指出党建工作制度不够完善、党员主体意识需提高、党员教育管理监督不够深入等问题。经无记名投票，卢燕娇、辛东升、杜军强当选新一届支部委员，卢燕娇当选支部书记，辛东升负责组织宣传、杜军强负责纪检，选举结果报镇党委批准。

## 分段速览
### 00:00:13-00:05:26 大会开幕与上届工作报告
会议开场清点人数：支部共有正式党员8名，因病请假1名，实到会有选举权党员7名，符合法定人数。镇党委组织委员钱小丽到会讲话，就换届选举提出三点意见：充分认识大会重要意义、正确行使选举权严格把握选举要求、服从大局遵守选举纪律。上届支部委员会作工作报告，总结三年工作成效并指出存在问题，党员对报告表示满意，鼓掌通过。

### 00:05:55-00:10:43 通过选举办法、候选人名单与工作人员名单
杜军晓宣读党员大会选举办法草案，明确选举委员3名、候选人4名（差额不少于应选名额20%），采用无记名投票，先差额选委员再等额选书记，实到会有选举权党员须超过应到会4/5方可选举，候选人得赞成票超过应到会选举人数半数方可当选。办法经举手表决一致通过。随后宣读镇党委批复，公布委员候选人预备人选4名及书记候选人预备人选，经鼓掌通过。监票人贾淑玲经表决通过，计票人员为黄婷丽、刘彩云。

### 00:10:43-00:14:45 候选人竞职演说
四位候选人依次发表竞职演说。卢燕娇介绍个人基本情况，承诺加强支部建设、推动村集体经济发展、抓好民生工程落实；杜军强结合村委会工作经历，表示愿担当桥梁纽带作用；辛东升承诺群众有困难随叫随到、严格要求自己、完成上级任务；秦磊阐述自身责任心和思想觉悟方面的有利条件，表示服从大局、不计较个人得失。

### 00:14:45-00:21:17 选举新一届支部委员会委员
清点人数确认实到会7名，达到应到会选举权党员人数的4/5，可以进行选举。监票人员检查并封好票箱，分发选票并说明填写方法。投票后清点：发出选票7张、收回选票7张，选举有效。计票结果为卢燕娇6票、杜军强6票、秦磊2票。根据选举办法，卢燕娇、辛东升、杜军强当选为新一届支部委员会委员。

### 00:21:17-00:28:42 选举支部书记并明确委员分工
召开第一次支部委员会全体会议，宣读选举办法草案，明确书记等额选举产生。卢燕娇作为书记候选人建议人选经鼓掌通过，辛东升担任监票人和计票人。发出选票3张、收回3张，卢燕娇得3票当选为新一届党支部书记。随后进行委员分工：辛东升负责组织宣传工作，杜军强负责纪检工作。选举结果以报镇党委批准为准。

### 00:28:42-00:29:56 新当选支委代表发言与大会闭幕
新当选支委代表发言，表示将抓好支部学习工作争创学习型支部、抓好制度建设工作争创制度型支部、完善基层党组织建设争创服务型支部，并恳请党员提出建议和意见。大会完成各项任务后宣布换届选举大会圆满结束，全体起立奏国际歌。

## 要点梳理
### 上届支部委员会工作报告
1. 上届支部委员会作三年工作报告：在上级党组织领导下，认真落实党建工作要求，发挥党支部战斗堡垒作用和党员模范带头作用。
2. 三年工作成效：新发展党员1名，按规定收缴党费2640元上交上级党组织；严格实行支部议事决策制度、民主生活会制度、民主评议党员制度、党员联系服务群众制度。
3. 开展主题教育活动：认真开展“两学一做”学习教育常态化、制度化和“讲严立”专题警示教育活动；通过党内会议、公开栏等形式公开年度工作计划、党风廉政建设、党费收缴等内容。
4. 上届支部指出存在问题：一是党建工作制度不够完善，二是党员主体意识尚需进一步提高，个别党员干部服务中心大局意识不强，三是党支部对党员教育管理监督不够深入。
5. 党员对工作报告表示满意，鼓掌通过。

### 通过党员大会选举办法
1. 杜军晓宣读选举办法草案，依据《中国共产党章程》和《中国共产党基层组织选举工作暂行条例》制定。
2. 选举中共芦塘支部委员会委员3名，候选人4名，差额不少于应选名额20%；候选人按姓氏笔画为序排列，采用无记名投票方式。
3. 选举分两步进行：先差额选举支部委员会委员，再从当选委员中等额选举书记，两次选举分别投票、计票和宣布结果。
4. 参加会议有选举权的正式党员必须超过应到会党员的4/5方可进行选举；收回选票等于或少于发出选票选举有效，多于发出选票选举无效。
5. 候选人得到赞成票超过应到会选举人数半数方可当选；得票超过半数候选人多于应选名额时以得票多少为序取足；最后几名得票相等时重新投票；超过半数候选人少于应选名额时，不足名额在未过半数候选人中重新选举，接近应选名额可减少名额不再选举。
6. 选举设监票人1名，经大会表决通过；设选举工作人员2名，由会议主持人指定；提名作为支部委员候选人的不能担任监票人和工作人员。
7. 党员对选举办法无不同意见，举手表决一致通过。

### 通过支委候选人名单
1. 杜军晓宣读镇党委批复：同意新一届支部委员会委员和书记候选人预备人选名单，委员实行差额选举（差额1人），书记实行等额选举，批复日期为2019年10月12日。
2. 委员候选人预备人选4名：卢燕娇、辛东升、杜军强、秦磊；书记候选人预备人选为卢燕娇。
3. 党员对候选人名单无不同意见，鼓掌通过。

### 通过选举工作人员名单
1. 提议贾淑玲担任监票人，党员无意见，举手表决一致通过。
2. 宣布计票人员为黄婷丽、刘彩云。

### 候选人竞职演说
1. 卢燕娇（1993年9月出生，2014年4月入党）承诺：进一步加强支部建设，落实“三会一课”、组织生活会和民主评议党员等基本制度，结合“两学一做”学习教育常态化制度化开展“不忘初心、牢记使命”主题教育；推动村集体经济发展，发挥党组织和党员在产业培育、农民增收、脱贫攻坚方面的示范引领和帮扶帮带作用；抓好各项民生工程落实，把群众利益作为首要职责、群众满意度作为衡量工作标准。
2. 杜军强（从事村委会工作）表示：农村党支部是基层党组织与党员群众之间的桥梁纽带，如当选可更好担当纽带角色，为党员和群众服务。
3. 辛东升承诺：群众有困难随叫随到；严格要求自己做合格党员干部，不该吃的饭不吃、不该拿的钱不拿、不该做的事不做；圆满完成上级党组织分配的各项任务。
4. 秦磊表示竞选有利条件：有较强责任心，能认真参加支部理论学习，不折不扣完成组织交给的任务；有较高思想觉悟，积极参加学习，热情为群众办实事，配合上级工作，不计较个人得失。

### 选举新一届支部委员会委员
1. 清点人数：应到会有选举权党员8名，因病请假1名，实到会7名，达到应到会党员人数的4/5，可以进行选举。
2. 监票人员检查并封好票箱，分发选票；填写选票一律用钢笔，所选人数等于或少于应选人数为有效票，多于应选人数为无效票。
3. 投票顺序：监票人员、计票人员先投票，然后全体党员依次投票。
4. 清点票数：实到会有选举权党员7名，发出选票7张，收回选票7张，选举有效。
5. 计票结果：卢燕娇6票，杜军强6票，秦磊2票。
6. 根据大会选举办法规定，卢燕娇、辛东升、杜军强当选为新一届支部委员会委员。

### 选举新一届支部书记及委员分工
1. 召开第一次支部委员会全体会议，宣读选举办法草案：选举产生支部书记1人，采用无记名投票、等额选举方式；实到会委员必须超过应到会委员的4/5方可选举；候选人得赞成票超过实到会委员半数当选。
2. 介绍书记候选人建议名单：卢燕娇工作认真负责，上届支委会在其带领下各项工作取得较好成绩，建议继续由其担任支部书记，党员鼓掌通过。
3. 通过选举工作人员名单：辛东升担任监票人和计票人，举手表决一致通过。
4. 选举结果：发出选票3张，收回选票3张，卢燕娇得3票，当选为新一届党支部书记。
5. 委员分工：辛东升负责组织宣传工作，杜军强负责纪检工作。
6. 新当选支委代表表态：抓好支部学习工作，争创学习型支部，组织开展“不忘初心、牢记使命”主题教育；抓好支部制度建设工作，争创制度型支部，增强党支部凝聚力、战斗力；完善基层党组织建设，争创服务型支部，严格按照《中国共产党支部工作条例（试行）》加强支部建设，发挥战斗堡垒和党员先锋模范作用。

### 结论与决定
1. 通过上届支部委员会工作报告。
2. 通过党员大会选举办法。
3. 通过支委候选人名单：卢燕娇、辛东升、杜军强、秦磊。
4. 通过监票人贾淑玲，计票人员黄婷丽、刘彩云。
5. 卢燕娇、辛东升、杜军强当选为新一届支部委员会委员。
6. 卢燕娇当选为新一届党支部书记，选举结果报镇党委批准。
7. 辛东升负责组织宣传工作，杜军强负责纪检工作。
