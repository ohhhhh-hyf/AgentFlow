# 复盘目标与结果概况
本次会议为2023年度总结与年终奖颁发会，核心目标是总结公司全年经营状况、公布年终奖数据、评价各部门及个人表现并颁发奖项。实际结果：年终奖转账总额为226,000元，全年实际支出（含人员工资、外援配音字幕、租机器）达390万元，利润率约24%或27%，成本控制较差；最高工资（含年终奖）有两三人到手达20万元，平均工资到手1万多元；年终奖总额比去年多出约13万元，去年干满一年的仅四五人，今年达12人；公司总量在提升，但结余到账往下跑，还有百来万未收回；老板每人比去年少拿约10万元，承担风险亏损100万元。会议对红叶子、郭东辉、刘腾宇、欧阳、徐艺玲、张文倩、市井、钱德峰、徐武安、宋俊逸、张扬、林海腾、李国宇、张启等逐一进行肯定性评价，并颁发最佳新人、最佳进步、后期独当一面、最佳员工、特别贡献五项奖，最后进行抽奖。

# 亮点事项
- **账号粉丝大幅增长**：郭东辉负责的账号从6月20日第一条外出拍摄视频起有起色，视频号粉丝从70019人增至8万，小红书从2000+增至6.4万，抖音从2000+增至5.7万，B站从3.1万增至7.6万；成功原因在于**坚持破釜沉舟说服潘老师外出拍摄**，并引入forty加入团队。
- **账号变现初显成效**：课程变现评分达7.5分（满分10分），直播平均在线人数5000人以上，前100人平均在线时长超50分钟；成功原因在于**所有内容决策均有数据支撑**，如每晚8-9点刷英语老师直播间研究内容与互动。
- **后期整体技术提升**：林海腾指出今年后期人员分级模糊、效率整体接近，制作能力提升，高强度加班下仍保证质量，体现职业操守。
- **新员工表现超预期**：张扬作为公司邀请的人才，职业态度和工作能力有目共睹，老板称“2023年干到最有价值的一件事就把他招进来”；宋俊逸首次安排活即展现高效，监狱、财经项目无问题。
- **最具复用价值的经验**：**坚持与破局**——郭东辉在项目濒临放弃时坚持，通过“敲鸡蛋”找到突破点，最终说服潘老师外出拍摄，带动全平台涨粉；**数据驱动决策**——所有内容与直播策划均基于观看竞品直播的数据分析。

# 不足事项
- **成本控制非常差**：全年实际支出390万元，利润率仅24%或27%，非常不可观；根因是**老板对成本关心或关注不够、不够雷厉风行，出现问题未及时解决**。
- **公司结余缩水**：总量在提升但结余到账往下跑，还有百来万未收回，老板承担风险亏损100万元；根因是成本上升且回款未到位。
- **账号变现重点项目未完成**：课程变现评分7.5分，重点项目未完成；直播虽平均在线5000人以上，但**没有课程，无法变现**。
- **后期人员加班严重**：后半年基本都在加班，劳累程度高，可能影响质量；根因是**老板未及时招合适人数的人员**，商务活断断续续导致误判不需招人，属判断失误。
- **拍摄参与度不足**：钱德峰指出请外援成本高，公司内部凑不出人按机位，喊人拍摄时很多人以“没空、很忙”推脱；根因是后期活多且安排不开。
- **商务支持不足**：张启作为商务，老板给的支持较少，项目几乎靠老板帮忙聊；商务部门实打实项目约300万元，可能不止，但不确定。

# 改进计划
- **成本控制**：明年开会时再讨论具体措施，老板自认今年给予的支持、管理或关心不够，明年会反思。
- **账号变现**：期待明年账号开始变现，老板将投入更大精力并给予足够重视，政委已尽力解决部分问题。
- **拍摄参与**：明年鼓励大家都能参与拍摄，至少能应付基本机位，提升个人市场价值；老板强调被领导问到时应解释手头工作或勉为其难安排，不能直接说“没空”。
- **组织协调**：老板明年将更多进行组织协调，提高效率，减少侵占员工休息时间。
- **商务支持**：老板后续会考虑给商务部门更多支持和帮助，协助项目洽谈。
