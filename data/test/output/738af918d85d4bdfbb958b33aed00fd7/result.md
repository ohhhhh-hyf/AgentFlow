# 陈廷敬生平事迹讲述会

## 讲座概况
本期视频由主讲人李正讲述康熙朝文渊阁大学士陈廷敬的一生，分为母亲张氏开蒙、圣祖康熙的讲师、至公无私的落幕三个阶段。陈廷敬本名陈敬，字子端，号午亭，1638年（崇祯11年）出生于山西泽州府阳城县，家族书香门第，往上数六代皆为读书人。其母张氏自幼随父读书，亲自为陈廷敬开蒙，陈廷敬6岁前已背完《论语》《孟子》《大学》《中庸》及《诗经》。陈廷敬14岁以全省第一考中秀才，20岁中举人，21岁中进士并入翰林院任庶吉士，22岁因与直隶通州陈敬同名，主动上书顺治请求改名，据李光地记载“廷”字为顺治所赐。陈廷敬仕途早期以教学为主，康熙六年（1667年）考察一等称职，康熙八年（1669年）32岁升任国子监司业，任上拒绝学生送礼，规定不送礼才愿意见。康熙十一年（1672年）充日讲起居注官，康熙十五年（1676年）充经筵讲官，康熙十六年（1677年）任翰林院掌院学士，同年母亲张氏去世，终年59岁。康熙为表彰其母，破例按学士品级由官方派人祭奠。康熙二十三年（1684年），47岁的陈廷敬升任左都御史，上奏要求捐纳者上岗前追加考试，获康熙支持，并令各地督抚详查已任命官员，文化不过关者罢免。此后陈廷敬连续出任工部、户部、吏部尚书，所到之处整顿积弊。康熙二十六年（1687年），湖广巡抚张谦因贪污被抓，供称曾贿赂陈廷敬、徐乾学、高士奇，陈廷敬否认。康熙传旨主审官马齐，张谦案只处理张谦，不得蔓延，其他人事后密查。康熙二十七年（1688年），51岁的陈廷敬主动上书辞官，康熙准许其辞官但留京修书。康熙二十九年（1690年），53岁的陈廷敬被重新启用，再次出任左都御史，康熙以此宣告其清白。康熙四十二年（1703年），66岁的陈廷敬升任文渊阁大学士，总理南书房事务。康熙四十六年（1707年）起，陈廷敬连续三年申请退休均被康熙拒绝。康熙四十九年（1710年），73岁的陈廷敬第四次申请退休获准，康熙赐匾额“午亭山村”和楹联“春归乔木浓阴茂，秋到黄花晚节香”，并表示自此不再给人写字。两年后陈廷敬病逝，终年75岁，谥号文贞。康熙包办治丧费用，命各部院满汉大臣往吊。

## 核心观点与论证
### 母亲张氏开蒙奠定根基
1. 陈廷敬本名陈敬，字子端，号午亭，1638年（崇祯11年）出生于山西泽州府阳城县，家族书香门第，往上数六代皆为读书人，父亲陈长七曾入选顺治朝国子监。
2. 母亲张氏自幼随父读书，亲自为陈廷敬开蒙，陈廷敬6岁前已背完《论语》《孟子》《大学》《中庸》及《诗经》，其学习天赋大概率遗传自母亲。
3. 科举成绩突出：顺治八年（1651年）14岁以全省第一考中秀才，20岁中举人，21岁中进士，同年入选翰林院任庶吉士；对比天才李光地21岁尚未考中秀才。
4. 因与直隶通州陈敬同名，且对方满文考试不及格，陈廷敬22岁时主动上书顺治请求改名，据李光地记载“廷”字为顺治所赐。

### 康熙讲师与仕途升迁
1. 康熙十一年（1672年）十月，以翰林院侍讲学士充日讲起居注官，与康熙朝夕相处4年；康熙十五年（1676年）九月，39岁充经筵讲官，教学风格外放，讲评经史“对就骂错就骂，从不含糊其辞”。
2. 康熙十六年（1677年）任翰林院掌院学士，同年母亲张氏去世，终年59岁；康熙破例按学士品级由官方派人祭奠。
3. 康熙六年（1667年）考察一等称职，康熙八年（1669年）32岁升任正六品国子监司业，任上废除学生拜见须带见面礼的不成文规定，规定不送礼才愿意见。
4. 康熙二十三年（1684年），47岁升任左都御史，上奏要求捐纳者上岗前追加考试，获康熙支持，并令各地督抚详查已任命官员，文化不过关者罢免。

### 张谦案牵连与清白昭雪
1. 康熙二十六年（1687年），湖广巡抚张谦因贪污被抓，供称曾贿赂陈廷敬、徐乾学、高士奇，并拿出三人劝其好好当官的信件作为“索贿暗示”证据。
2. 陈廷敬否认受贿，表示因张谦是亲戚而尤其注意避嫌，原话称“积疑成恨，羽射连染”；康熙传旨主审官马齐，张谦案只处理张谦，不得蔓延，其他人事后密查。
3. 康熙二十七年（1688年），51岁的陈廷敬主动上书辞官，康熙准许其辞官但留京修书；同案徐乾学、高士奇均因贪污被罢官，唯独陈廷敬仅辞官一年即被重新启用。
4. 康熙二十九年（1690年），53岁的陈廷敬复出再次出任左都御史，康熙以此向流言宣告其清白——若无十足把握，不会让其回任全国最高监察长官。

### 至公无私的晚年落幕
1. 康熙四十二年（1703年），66岁升任文渊阁大学士，总理南书房事务；康熙四十六年（1707年）起连续三年申请退休均被拒绝。
2. 康熙四十九年（1710年），73岁第四次申请退休获准，康熙赐匾额“午亭山村”和楹联“春归乔木浓阴茂，秋到黄花晚节香”，并表示自此不再给人写字。
3. 两年后陈廷敬病逝，终年75岁，谥号文贞；康熙包办治丧费用，命各部院满汉大臣往吊，临终前仍询问大臣中是否有学问人品如陈廷敬者可代理内廷事务。
