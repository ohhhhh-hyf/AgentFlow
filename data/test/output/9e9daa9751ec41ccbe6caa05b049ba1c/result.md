# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司（东源煤电）、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷二审案件，由最高人民法院依法组成合议庭公开开庭审理，针对云南省高级人民法院（2018）云民初88号民事判决提起上诉。庭审核对各方出庭人员身份后，围绕三个争议焦点进行审理：国开行是否尽到审查义务并善意取得抵押权、一审判决对案涉借款罚息复息的计算及起算日期是否认定错误、东源煤电及东源煤业是否应连带给付违约金。各方充分发表辩论意见后，合议庭休庭评议并提出调解方案，各方均无异议，同意签署调解协议，法院将依法出具调解书。

# 举证与法庭调查
## 举证与质证

1. **融资租赁登记查询证书（招银租赁质证）**：招银租赁认为国开行提交的查询证书不符合要求。根据2014年93号中国人民银行关于融资租赁登记系统的规定，国家开发银行应当在抵押的时点进行融资租赁登记查询，即应提供2015年12月操作抵押时查询人行征信中心的查询结果，而非事后取得的查询证书。
  - **证明目的**：国开行主张其已按央行规定查询融资租赁登记系统，未发现招银租赁的融资租赁登记，构成善意取得抵押权。
  - **对方质证意见**：招银租赁认为该查询证书不符合规定时点要求，不能证明国开行在抵押时点已尽查询义务；东源方认为2015年12月2日邮件中融资情况统计表已显示招银租赁抵押物已登记，国开行应尽注意义务。

2. **2015年12月2日邮件及融资情况统计表（东源方提交）**：东源方主张该邮件显示招银租赁的抵押物已登记，国开行在办理抵押时应知悉相关情况。
  - **证明目的**：证明国开行对东源煤电的审查义务应当具备——借款人为东源煤电，抵押人曲靖电力公司系东源煤电100%全资控股子公司，东源煤电同时是贷款案件的借款人，国开行对其审查义务不应仅限于抵押人曲靖电力公司。
  - **对方质证意见**：国开行主张其审查义务仅限于抵押人曲靖电力公司，不能扩大到东源煤电公司。

3. **借款合同第24条第2款第2项（东源方引用）**：东源方主张合同约定国开行宣布贷款提前到期时应向借款人发通知并要求限期偿还，限期偿还与立刻偿还是完全不同的两个概念。
  - **证明目的**：证明国开行2018年6月13日发函要求当天偿还全部借款不符合合同约定，未给借款人合理期限。
  - **对方质证意见**：国开行主张其于2018年6月13日向东源煤电、东源煤业发送两份关于偿还云南恩洪矿区煤矸石综合利用电厂上大压小项目贷款本金的函，明确要求当日归还借款，贷款已提前到期。

4. **借款合同第6条第4款（国开行引用）**：国开行主张合同明确约定贷款人对借款人不能按期支付的利息计收复利，其中包含对不能按期支付的逾期借款利息按罚息利率计收复利。
  - **证明目的**：证明对逾期借款利息按罚息利率计收复利有合同依据。
  - **对方质证意见**：东源方认为《人民币利率管理规定》第21条明确针对的是贷款期内不能按期支付的利息按合同利率按季计收复利，而非贷款逾期以后不能按期支付的罚息；合同第6条第4款表述的也是利息，均未提到罚息，故罚息不应作为复利计算基数。

5. **借款合同第24条第3项（国开行引用）**：国开行主张合同明确约定被上诉人发生违约时应承担违约责任，按约定应向上诉人支付千分之一的违约金。
  - **证明目的**：证明东源煤电、东源煤业构成违约，应连带给付违约金。
  - **对方质证意见**：东源方认为国开行未举证证明东源煤电存在违反柜台前移和账户管理的违约行为，举证不能的后果应由其自行承担；且按合同约定国开行须先对违约行为进行限期纠正，不予纠正的才有权主张违约金，但国开行自提起诉讼之日始终未向东源煤电发出任何书面纠正函件或进行任何告知。

## 证人、鉴定与其他来源陈述

- **中国人民银行2014年93号文件（关于融资租赁登记系统的规定）**：招银租赁引用该规定，主张国家开发银行应当在抵押的时点（2015年12月）进行融资租赁登记查询，而非提供2018年9月的查询证书。
- **《人民币利率管理规定》第21条（东源方引用）**：东源方引用该规定主张对贷款期内不能按期支付的利息按合同利率按季计收复利，贷款逾期后改按罚息利率计收复利，该规定仅针对贷款期内不能按期支付的利息，而非贷款逾期以后不能按期支付的罚息。
- **《中华人民共和国物权法》及《动产抵押登记管理办法》（国开行代理人引用）**：国开行主张动产抵押登记是法定的物权登记，对外具有排他性；融资租赁登记更多是行业性质的登记，不是法定意义上的物权登记。
- **最高人民法院关于人民法院民事调解工作若干问题的规定第8条（审判长引用）**：当事人可以自行提出调解方案，组织调解的人员也可以提出调解方案供当事人协商参考。
- **《中华人民共和国民事诉讼法》第93条（审判长引用）**：人民法院审理民事案件在事实清楚的基础上，分清是非，进行调解。

## 法官询问

1. **各方当事人出庭人员身份及代理权限核对**：审判长逐一核对上诉人国家开发银行（委托代理人邓劲松、刘双俊，均为北京德恒昆明律师事务所律师，特别授权代理）、被上诉人东源煤电（委托代理人吴学成，云南勤业律师事务所律师，特别授权代理）、被上诉人东源煤业（委托代理人李新海，云南东源煤业集团有限公司员工，特别授权代理；另有共同代理人吴学成）、被上诉人东源曲靖电力（出庭人员与东源煤电一致）、被上诉人招银租赁（委托代理人万海龙，招银租赁员工；陈志超，上海盈泰律师事务所律师，代理权限均为一般代理）。各方对其他方出庭人员身份均无异议。审判长询问东源煤电、东源煤业、曲靖电力三方是否合并发表意见，东源方答复合并发表意见。

2. **融资租赁登记查询时点问题**：审判长就国开行提交的融资租赁登记查询证书是否符合要求进行询问，招银租赁主张国开行应提供2015年12月抵押操作时点的查询结果，而非2018年9月的查询证书。

3. **融资租赁登记性质问题**：审判长询问各方对融资租赁登记性质的看法。国开行代理人认为动产抵押登记是法定物权登记，融资租赁登记是行业性质的登记，非法定意义上的物权登记；东源方认为融资租赁登记只是行业指导性规范意见，非强制性规范，不当然产生物权后果；招银租赁补充发表意见。

4. **调解意愿征询**：审判长询问各方是否同意调解。国开行表示愿意在法庭明确基本事实和双方责任后进行调解，并希望法庭提出合理的调解方案；东源方在发表调解意见前请求占用合议庭时间介绍东源公司情况，获审判长准许。

## 争议焦点与辩论

1. **争议焦点一：国开行是否尽到审查义务、是否构成善意取得抵押权**
  - **国开行主张**：已按中国人民银行2014年93号文件规定查询融资租赁登记系统，未发现招银租赁的融资租赁登记；审查义务仅限于抵押人曲靖电力公司，不能扩大到东源煤电公司；融资租赁登记是行业性规范，非法定物权登记，不当然产生物权后果。
  - **东源方主张**：2015年12月2日邮件中融资情况统计表已显示招银租赁抵押物已登记，国开行应尽注意义务；东源煤电不仅是抵押人曲靖电力公司的全资控股母公司，同时是贷款案件的借款人，国开行对东源煤电的审查义务应当具备。
  - **招银租赁主张**：国开行应在抵押时点（2015年12月）查询融资租赁登记系统，而非提供2018年9月的查询证书；案涉5套设备为通用设备，无唯一识别码，招银租赁未在登记系统中登记识别码；查询是银行业严格义务，未查询则不构成善意；关于举证责任，司法解释第9条第1、2、4项由出租人举证，第3项由第三人（国开行）举证。

2. **争议焦点二：一审判决对案涉借款的罚息、复息的计算以及起算日期是否认定错误**
  - **国开行主张**：东源煤电利息支付时间截止到2017年12月20日，利息应从2017年12月21日计算至2018年6月12日，合计21,795,727.68元；2018年6月13日国开行向东源煤电、东源煤业发送两份关于偿还云南恩洪矿区煤矸石综合利用电厂上大压小项目贷款本金的函，明确要求当日归还借款，罚息应自2018年6月13日计算至东源煤电、东源煤业向人民法院申请破产受理之日即2019年2月19日，罚息为41,050,579.57元；复利自2018年3月21日计算至2019年2月19日，复利为1,918,206.23元；合同第6条第4款明确约定对逾期借款利息按罚息利率计收复利，有合同依据。
  - **东源方主张**：借款合同第24条第2款第2项约定国开行宣布贷款提前到期时应发通知并要求限期偿还，限期偿还与立刻偿还是完全不同的概念，国开行当天发函要求当天全额偿还近8.37亿元本金，未给合理期限，不符合合同约定；《人民币利率管理规定》第21条仅针对贷款期内不能按期支付的利息按合同利率按季计收复利，而非贷款逾期后的罚息；合同第6条第4款表述的也是利息，均未提到罚息，罚息不应作为复利计算基数。

3. **争议焦点三：东源煤电、东源煤业是否应当连带给付违约金**
  - **国开行主张**：借款合同第24条第3项明确约定被上诉人发生违约时应承担违约责任，属双方意思自治，对双方均具有法律约束力；被上诉人出现违约事项时，理应向上诉人支付千分之一的违约金。
  - **东源方主张**：国开行未举证证明东源煤电存在违反柜台前移和账户管理的违约行为，在一审庭审、二审庭前会议及本次庭审中始终未向人民法院举证，举证不能的后果应由其自行承担；按合同约定国开行须先对东源煤电的行为进行限期纠正，不予纠正的才有权主张违约金，但国开行自提起诉讼之日始终未向东源煤电发出任何书面纠正函件或进行任何告知。

# 庭审结果
1. **调解协议达成**：经合议庭休庭评议，结合我国动产担保及融资租赁登记不完善的现实背景，合议庭提出调解方案，并在休庭时征求各方当事人意见。各方对调解方案均无异议，同意签署调解协议，法院当庭予以确认，将根据《中华人民共和国民事诉讼法》第97条出具调解书。

2. **债权数额确认**：
  - 国开行对东源煤电的债权，扣除破产中已清偿的本金外，利息、罚息、复利合计**6474.4513万元**，其中利息（2017年12月21日至2018年6月12日）**2179.5727万元**，罚息（2018年6月13日至2019年2月19日）**4105.0579万元**，复利（2018年3月21日至2019年2月19日）**191.8206万元**。
  - 在东源煤电、东源煤业破产重整程序中，已确定招银租赁对涉案6项设备享有所有权，对应债权数额**1377.4137万元**。

3. **担保权利确认**：确定国开行对**93项设备**享有抵押权，招银租赁对**6项设备**享有所有权。

4. **设备整体盘活处置安排**：招银租赁和国开行对案涉全部发电设备整体盘活处置，并从变现款中实现各自债权。调解书生效后**20日内**，由国开行向一审法院提出执行申请，启动司法处置程序。变现价款双方各得**50%**，实现费用双方各担**50%**。

5. **未实现债权处理**：国开行、招银租赁未实现的债权，待执行法院出具终本裁定后，按照破产重整计划中的预留方案实现债权；若破产管理人对招银租赁的债权不予纳入预留方案，由东源煤电按照此前招银租赁在东源煤电破产重整程序中有担保清偿方案予以清偿。

6. **司法变现不能的兜底安排**：若司法变现不能，国开行和招银租赁的权益通过前述方法实现后，均放弃对上述案涉设备的权益，由东源曲靖电力自主生产经营。

7. **设备管理与配合义务**：案涉设备上的管理费用由东源曲靖电力承担，东源曲靖电力无条件配合司法处置。

8. **一审判决确认事项**：各方对一审判决第2项、第4项无争议，按照其判项内容在调解书中确认。

9. **诉讼费用分担**：
  - 一审诉讼费用中，国开行诉请部分按照一审判决执行；招银租赁诉请部分的诉讼费用，由二审法院按照规定，根据争议财产对应的债权数额计算后，由国开行承担。
  - 二审诉讼费用由法院依法确定后，由国开行和东源煤电各承担**50%**。

10. **争议终结**：本协议签订后，各方之间就本案涉及的问题不再存在任何争议。
