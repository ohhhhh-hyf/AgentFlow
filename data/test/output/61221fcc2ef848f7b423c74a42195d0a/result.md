# 参观概况
本次参观为故宫博物院一日深度游览，由导游全程讲解，围绕中轴线及东西两路展开，覆盖午门、太和门、太和殿、中和殿、保和殿、乾清门、乾清宫、交泰殿、坤宁宫、储秀宫、慈宁宫、断虹桥、武英殿、文华殿、箭亭、钟表馆、珍宝馆、御花园等主要景点，全程穿插历史典故与建筑特色讲解。游览以午门检票入场为起点，导游依次介绍各殿功能与规制，如午门“明三暗五”结构、太和殿大典用途、乾清宫立储诏书秘密、珍宝馆乾隆养老院布局等；同时沿途标注七处免费盖章点及文创购买规则，并推荐三条不同时长的游览路线。整体过程从早间排队错峰开始，至神武门出宫结束，形成一条完整的故宫保姆级游览攻略。

# 核心看点与讲解
- **午门**：排队检票处，明朝皇帝在此杖打犯错大臣，清朝皇帝在此举行颁朔之礼。门洞呈“明三暗五”结构，正门仅供皇帝行走，皇后大婚时可进一次，殿试前三名（状元、榜眼、探花）可出一次；两侧门走皇亲国戚和文武百官。
- **太和门广场**：眼前有五座金水桥，中间桥供皇帝行走，挨着中间的两座桥供黄金国器行走，文武百官走最边上的桥。
- **太和门**：明朝皇帝在此御门听政（上朝的地方），门口铜狮子是故宫六对铜狮中最大的一对，脚踩寰宇象征权力，不建议站在狮子底下合影。
- **太和殿**：即金銮殿，但并非上朝之地，而是举行盛大典礼的地方，如皇帝登基、皇后册封；文武百官在太和殿广场向皇帝喊“吾皇万岁万岁万万岁”，站位遵循“文东武西”——文官站东边，武官站西边。西边弘义阁是皇帝的银库，东边体仁阁是缎库。
- **中和殿**：举行盛大典礼时皇帝的休息室，文武百官站好后皇帝再前往太和殿。
- **保和殿**：从乾隆五十四年开始作为科举考试殿试的考场；东北角有汉字馆，内有4枚免费印章，可购买《紫禁城100》并现场盖章，购买后不能去其他店铺盖章，据说汉字馆印章数量最多。
- **乾清门**：过了此门即后宫区域，皇帝在此上早朝；东边九卿直房是等级高的大臣等待皇帝召见之处，西边是军机处。门口两尊狮子耳朵耷拉、眉毛遮眼，警示后宫之人不该看的别看、不该听的别听。
- **乾清宫**：皇帝平时睡觉的地方，内有27张龙床，据说是为防止刺客找到皇帝位置；牌匾“正大光明”后藏皇帝立储诏书，皇帝写两份诏书，驾崩后取出对比以防被动手脚。门口有铜鹤与铜龟，旁边有社稷江山金殿，是紫禁城里最小的宫殿，提醒皇帝把江山社稷放在第一位。
- **交泰殿**：内放25块传国玉玺。
- **坤宁宫**：皇后住所，明朝所有皇后都住于此；东北角文创店有5枚免费印章。
- **储秀宫**：慈禧住了20多年的地方，现为慈禧五十大寿时期原状陈列，慈禧儿子在此出生；旁边文创店有3枚免费印章。
- **翊坤宫与永寿宫**：翊坤宫和永寿宫位于储秀宫以南，永寿宫西边是东西六宫中唯一被称为殿的太极殿。
- **慈宁宫与寿康宫**：慈宁宫是康熙给奶奶孝庄皇太后修建的养老院，旁边寿康宫是甄嬛居住之处。
- **冰窖书吧**：内有3枚免费印章，印章造型有批折子的感觉。
- **断虹桥**：网红打卡地，桥上有形态各异的石狮子，最有名的是“武当狮”。
- **武英殿**：后改为陶瓷馆，目前关闭状态，只能在门口看看。
- **文华殿**：位于东边，与西边武英殿对应“文东武西”，参观时未开放，据说现有一个展览。
- **箭亭**：清朝皇帝及其子孙练习骑马射箭的地方，旁边商店可购买文创雪糕。
- **钟表馆**：展示那个年代的钟表造型。
- **珍宝馆**：强烈建议参观，门口有我国现存三座古代九龙壁之一，左边数第三条白龙下方有一块木头，据说是当年烧制琉璃砖瓦弄坏后工匠为保命用木头刷白漆以假乱真。珍宝馆并非单独展厅，院子周围屋子都可参观，游客多，尤其看凤冠需挤进去。此处即宁寿全宫，是乾隆给自己修建的养老院，乾隆退休后未放权仍每天上朝办公；皇极殿1:1复刻乾清宫，宁寿宫对标坤宁宫，养性殿后为乐寿堂，是故宫里唯一能进去参观的皇家寝室，有二龙戏珠设计；再往后是当年慈禧把珍妃丢进去的珍妃井，井口石并非珍妃被丢入之处。珍宝馆出口右手边商店有3枚免费印章。
- **东筒子夹道**：长长的夹道，拍照非常出片。
- **延禧宫与景仁宫**：延禧宫为网红打卡地，旁边景仁宫是当年甄嬛被封为熹妃时住的，珍妃也住过。
- **御花园**：内有钦安殿，供奉真武大帝；紫禁城靠山景山从天上看酷似闭目盘坐的人像，有人说该造型就是钦安殿供奉的真武大帝。
- **神武门**：故宫紫禁城北门，游览终点；出门左手边有两个盖章点——角楼咖啡有2枚免费印章，故宫文创有2枚免费印章。

# 互动与体验
- **排队检票**：导游建议早点过来排队，排队检票处即午门，可借此观察午门外观。
- **午门门洞观察**：从正面看午门有三个门洞，进门后可见变成五个门洞，即“明三暗五”结构；导游提示中间正门仅供皇帝行走，皇后大婚时可进一次，殿试前三名可出一次。
- **太和门铜狮子合影提醒**：门口铜狮子为故宫六对铜狮中最大的一对，造型威武、脚踩寰宇，导游建议不要站在狮子底下合影，因大爪子正好盖在头顶，单独给狮子拍照即可。
- **中和殿与保和殿参观**：中和殿为盛大典礼时皇帝的休息室；保和殿自乾隆五十四年起为殿试考场，导游以“弹幕走一波前途无量”互动祝福观众。
- **汉字馆盖章体验**：保和殿东北角汉字馆有4枚免费印章，可购买《紫禁城100》由工作人员现场盖章；导游形容盖章“真是盖了帽了”，并提及故宫不止一处可买此书，但每家店印章不同，购买后不能去其他店铺盖章，需有所取舍；据说汉字馆印章数量最多，盖完后可选择邮寄到家或自行带走。
- **乾清宫参观提示**：可往殿内看“正大光明”牌匾，牌匾后藏皇帝立储诏书；门口有铜鹤与铜龟，旁边还有紫禁城里最小的宫殿——社稷江山金殿。
- **坤宁宫文创店盖章**：坤宁宫东北角文创店有5枚免费印章，导游提醒别错过。
- **储秀宫参观与盖章**：储秀宫为慈禧居住20多年的地方，现为慈禧五十大寿时期原状陈列；其子在此出生；旁边文创店有3枚免费印章。
- **慈宁宫与寿康宫打卡**：慈宁宫为康熙给奶奶孝庄皇太后修建的养老院，旁边寿康宫为甄嬛居住地，导游提醒喜欢看《甄嬛传》的游客可到此打卡。
- **冰窖书吧盖章**：冰窖书吧内有3枚免费印章，导游称印章造型好，盖章时有批折子的感觉；其本人因已买《紫禁城100》，在此购买了冰嬉图。
- **断虹桥找狮子**：断虹桥上有形态各异的石狮子，最有名的是“捂裆狮”，导游邀请游客找一找它在哪。
- **武英殿与文华殿现状**：武英殿改为陶瓷馆但目前关闭，只能在门口看看；文华殿导游去时未开，据说现有一个展览，感兴趣可去看。
- **箭亭文创雪糕**：箭亭为清朝皇帝及子孙练习骑马射箭之处，旁边商店可买到文创雪糕，导游提问雪糕造型是谁，欢迎在评论区分享。
- **钟表馆参观**：导游带看钟表馆，感叹“不来不知道钟表竟然还有这种造型，真是开了眼了”。
- **九龙壁找木头龙**：珍宝馆门口为我国现存三座古代九龙壁之一，左边数第三条白色龙下边有一块明显不同的琉璃，实为木头刷白漆，导游讲述工匠烧坏琉璃后以假乱真的典故，并提问“当时皇上究竟有没有发现这个小细节”。
- **珍宝馆参观体验**：珍宝馆并非单独展厅，院子周围屋子都值得进去看；导游称每样宝贝都能让人说出感叹词，但游客太多，尤其是看凤冠的“没点技术还真挤不进去”。
- **乐寿堂参观**：乐寿堂为故宫里唯一能进去参观的皇家寝室，可看到二龙戏珠设计，导游提示会联想到恭王府和珅的卧室。
- **珍妃井说明**：珍妃井为当年慈禧丢珍妃之处，导游澄清井口上方现为井口石，珍妃并非从那个小眼进去的。
- **珍宝馆出口商店盖章**：珍宝馆出口右手边商店有3枚免费印章，导游提醒收集印章者别漏了。
- **东筒子夹道拍照**：东筒子夹道拍照非常出片，是很多小姐姐喜欢来的地方。
- **延禧宫与景仁宫打卡**：延禧宫为网红打卡地，旁边景仁宫为甄嬛被封熹妃时所住，珍妃也住过。
- **御花园与钦安殿**：御花园内有钦安殿，供奉真武大帝；导游提及紫禁城靠山景山从天上看酷似闭目盘坐人像，有人说造型就是真武大帝。
- **神武门出口盖章**：神武门出口左手边有两个盖章点，角楼咖啡有2枚免费印章，故宫文创也有2枚免费印章。
- **三条游览路线选择**：导游总结三条路线供游客按自身情况选择——第一条走完视频内所有景点，适合打算待一整天的游客，建议早起排队、进门往里冲以错开旅游团，导游本人一天走了3万步；第二条沿中轴线看完坤宁宫后去景仁宫、延禧宫，再逛钟表馆和珍宝馆，出来直奔御花园，从神武门出，约半天；第三条沿中轴线看完坤宁宫后去储秀宫，出来去御花园，从神武门出，约2小时，最省力。
- **盖章点汇总**：导游标注了七个可免费盖章的位置，供有需要的游客截图保存。

# 收获与建议
## 择时与排队

- **早起错峰**：建议早起排队，一进门就沿中轴线往里冲，可错开大批旅游团人群；等大部队到达时，已在人少时逛完最重要的几个景点。
- **全天体力预期**：走完所有景点的路线一天约走3万步，游览过程中需适当休息和补充水分。

## 路线选择

- **第一条路线（全天）**：走完视频内提到的所有景点，适合打算在故宫待上一整天的游客；进门后沿中轴线往后走，一天约3万步。
- **第二条路线（半天）**：进门沿中轴线往后走，看完坤宁宫后去景仁宫和延禧宫，接着逛钟表馆和珍宝馆，出来直奔御花园，从神武门出，约半天逛完。
- **第三条路线（约2小时）**：进门沿中轴线往后走，看完坤宁宫后去储秀宫，出来去御花园，从神武门出；最省力，适合时间有限、不想走太多路的游客。

## 注意事项

- **午门正门通行规则**：中间正门仅供皇帝行走；皇后大婚时可进一次，殿试前三名（状元、榜眼、探花）可出一次，旁边两门走皇亲国戚和文武百官。
- **金水桥通行规则**：想体验皇帝待遇走中间桥，皇亲国戚走挨着中间的两座桥，文武百官走最边上的桥。
- **太和门铜狮子**：不建议站在铜狮子下合影，其大爪子正好盖在头顶，建议单独给狮子拍照。
- **太和殿非上朝处**：太和殿是举行盛大典礼的地方（皇帝登基、皇后册封），上朝在太和门（明朝御门听政）和乾清门。
- **珍宝馆参观**：珍宝馆不是单独展厅，院子周围屋子都要进去看；游客多，尤其看凤冠需挤进去。
- **珍妃井**：井口上方现放的是井口石，珍妃并非从那个小眼进去的。
- **陶瓷馆状态**：武英殿改为陶瓷馆，目前关闭，只能在门口看看。
- **文华殿展览**：导游去时未开，据称现有一个展览，感兴趣可前往。
- **断虹桥打卡**：桥上石狮子形态各异，最有名的是“捂裆狮”，可自行寻找。
- **文创雪糕**：箭亭旁商店可买到文创雪糕。
- **东筒子夹道**：拍照非常出片，适合打卡。
- **御花园对比**：有游客认为御花园比不过和珅家的后花园。
