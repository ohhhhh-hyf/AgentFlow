投资框架反思与年度研究布局汇报

讲座概况

肖楠（主讲人，基金经理）向机构投资者作年度汇报，主题为过去一年的研究布局与投资框架反思。讲座面向关注其产品运作的基金投资者，旨在让投资者了解其研究积累、看问题角度及投资理念的更新。汇报围绕四个板块展开：反对“抱团”与“均值回归”两种流行观点、四大研究布局方向（互联网、财富管理、新消费、高端制造）、投资框架的五点反思与更新、以及投资者问答。核心主张包括：知识与信息之间存在巨大鸿沟，投资者得到的只是信息而非知识；收益率呈幂律分布而非正态分布，投资核心是寻找长线超级大牛股；存在长期变量（如国运、文化背景）影响收益率，需保持谦卑。关键锚点：美国股市200年价值增量由4%的公司贡献；互联网产业在中国已迭代三代企业；深度价值可能长期无效（打了问号）。对听众的意义在于理解基金经理的决策依据与框架演进，而非获取具体买卖建议。

核心观点与论证

知识与信息的鸿沟

  1. 投资者关心的“what happen next”问题用处不大：肖楠认为，他看好某板块是基于相关知识（knowledge），而投资者得到的仅是一条“肖楠看好某某”的信息（information），知识与信息之间存在巨大鸿沟。
  2. 观点会随知识更新而改变：他今天的观点明天可能就变，因为新知识会修正判断，而投资者可能需等一年甚至更长时间才知道观点已变。
  3. 研究框架四分类：肖楠将问题分为重要不重要、可研究及难以研究四类，只关心可研究且重要的问题，如标的基本面是否变化、投资逻辑有无更新、认知是否更深入领先、投资框架有无值得修正之处。
  4. 框架仅针对个人：该表只针对他本人，例如基于宏观变量做资产配置的人，可能认为美联储利率变化对市场的影响是既重要又可研究的问题。

反对“抱团”与“均值回归”

  1. 反对“抱团”定义：肖楠认为“抱团”定义不本质，如同给一叫太阳就出来的动物取名“光明使者”，不说明因果关系。基金经理之间是竞争关系，主观上不可能抱团，同一家基金公司因研究员推荐而买同一股票也不应叫抱团。
  2. 抱团是截面数据：在某个时间点看到很多基金买类似股票，忽略了时间维度变化；拉长时间看，A股与海外股市都有类似现象（如当年的五朵金花、眉飞色舞、长牛的医药消费）。
  3. 反对“均值回归”：均值回归是“跌多了要涨、涨多了要跌”的局部正确，90%时间正确，但10%的错误代价惨重。举例：某商学院老师在$海螺水泥$上做波段十年赚两三倍，2016或2017年卖出后等回调，结果两年涨了五六倍，再也没买回来。
  4. 收益率呈幂律分布：美国股市200年价值增量由4%的公司贡献，把那4%公司挖掉，200年来美国股市没有涨。投资核心是找到摆脱“涨多跌多”局部规律的长线超级大牛股。

四大研究布局方向

  1. 互联网：全球能把互联网做成巨大产业、诞生巨大公司的只有中国和美国。中国在十几年内已迭代三代企业——第一代基于流量（门户网站、搜索引擎）、第二代基于运营管理（阿里、淘宝）、第三代基于算法（字节、拼多多）。开了港股通后，可投资以前在A股未上市的互联网公司，不能容忍错失机会。
  2. 财富管理：中国从一穷二白进入小康，人均收入中位数向前挪5%或10%，因巨大基数效应和收入分布密度效应会有巨额剩余财富，有待专业机构管理，行业潜在空间远超想象。
  3. 新消费：从匮乏年代走出的第一代、第二代消费品公司，与富裕年代诞生的新消费公司完全不同——从CEO理念、组织架构、经营理念到生产方式、营销方式都截然不同，不是产品够新，而是整个公司构造不一样。
  4. 高端制造：中国几乎是全球唯一拥有全产业链的国家，在众多制造业细分领域已不是被卡脖子，而是客气地讲“占据主导地位”。已诞生一批非常厉害的企业，欧美日企业手中的市场份额从中国视角看已是“碗里的肉”，未来空间非常可见。

投资框架的五点反思

  1. 商业模式分类不完备：肖楠过去将生意分为坐地收钱、苦尽甘来、燃烧自己照亮别人三类，至今仍相信这一理解，但承认框架有不完备性——世界上没有一劳永逸的坐地收钱生意，连爱马仕也会因设计师好坏影响未来五到十年销售，长期看所有企业都要死去，单一维度出发会错失机会。
  2. 商增视角更本质：从商增角度理解商业模式可能更本质。有些企业从诞生到收入和利润涨100倍，结构没有特别大区别，商没有怎么增加；另一些企业扩张过程中商增剧烈，增到一定程度后科斯定理表明企业已无存在必要。过去大量讨论企业成长靠什么吸收熵增。
  3. 长期变量影响收益率：与张坤争论企业家精神值不值得定价。西方世界无人预料到中国和平稳定高速发展30多年、40年，这是一个隐藏的巨大变量。买茅台赚钱的人列出的逻辑（便宜、产品好、商业模式好）加在一起，也解释不了过去十年二十年茅台如此巨大的涨幅，可能有更大的变量（宏观经济背景、文化背景、品牌背景）在起作用。
  4. 深度价值可能长期无效：深度价值只是一个结果，导致深度价值的原因不变，最好的结果也就是不输。过去投了一些认为是深度价值的标的，结果非常差，对深度价值是否长期无效打了问号。
  5. X factor：经典投资模型（DCF、DDM）都是线性假设，但企业10年视角下发展是曲线，经典模型没有一个变量隐含对企业发展曲率的估计。驱动企业增长且不被线性描述的因子（X factor）即使无法有效定价，也一定要承认其存在，否则会陷入“企业挺好但估值贵、企业便宜但基本面烂”的困境。超额认知就来自这些方面。

错过机会的反思

  1. 错过十几倍涨幅的机会：因判断某些行业终局可能不大行而放弃中期投资机会，最打脸的是明明判断对了，却在两三年的时间里深深错过十几倍的涨幅。复盘发现，这类企业某一代产品领先被追上后，做出了第二增长曲线，且第二增长曲线的壁垒比第一增长曲线更深更厚。
  2. 应对思路：在坚持对终局重要性判断的基础上，争取研究格局演进的阶段性特征来把握投资机会。可通过紧密跟踪认知快速迭代、识别里程碑式事件来提高胜率，在中期时间内获得好的投资回报率。

Q&A 环节

Q1. 中期投资机会与终局判断

  • 听众：您刚刚有讲到是在对于终局结果的重视的过程中，也更加去关注格局演进的过程中阶段性的特征，中期投资机会，请问您能对这一点再详细描述一下吗？
肖楠：这个想法最早来自我们过去错过了一些特别大的机会，导致非常懊恼。我们之所以错过，是因为判断这些行业的终局可能不大行，而最打脸的是我们明明判断对了，却在两三年的时间里深深错过了十几倍的涨幅。复盘发现，这类企业某一代产品领先被追上后，做出了第二增长曲线，且第二增长曲线壁垒比第一增长曲线更深更厚。所以后来我们渐渐开始承认终局可能没有那么强，但在这种前提下依然能做出好的投资，希望未来不要再错过类似机会。具体标的不便详述，确实有一两个标的带来极大刺激。

Q2. 伟大公司的判断标准

  • 听众：您在年报中也讲到过，坚定持有优秀乃至伟大的公司。请问您对于优秀乃至伟大公司的判断标准，是否有具体的财务指标？
肖楠：伟大公司是在财务指标里面看不出来的。举例说明：两家公司同属一个大行业、不同细分子行业，都是把成本做到行业最低、市场份额稳固且不断提高的优秀公司。区别在于B公司不怎么做研发，靠管理精益求精形成壁垒；A公司每年有非常高额的研发支出，关键技术指标以非常强的速度迭代，且很多研发项目是特别前沿的方向，目前这些方向的技术掌握在德国人、日本人手里。A公司发展初期被德国人、日本人狠狠坑过，从董事长到总经理到技术骨干都有强烈的产业报国、技术报国理想，从跟着学、越做越强、超越对手、对手跑来学，到做全产业链布局，这种企业堪称伟大。两家其实都是国企，打破国企效率低的刻板印象。

Q3. 全市场基金的选股逻辑

  • 听众：我们是全市场基金，能否介绍一下这个产品的投资逻辑？对于消费以外的行业的选股，主要是基于什么逻辑呢？
肖楠：很难分消费内消费外，选股逻辑都是一样的，都是以前讲过的“不可能三角”、企业的三阶段、三种商业模式。只不过消费行业只许买消费，所以只能在消费行业里选，两者的选股逻辑完全一样，没有什么区别。

Q4. 血制品行业的竞争壁垒

  • 听众：您是怎么看待血制品行业的竞争壁垒呢？
肖楠：血制品行业我们初步研究过，觉得壁垒不是特别强，不是我们想要的那种强壁垒，这个就不展开。因为我们的研究不是特别深入，我们也找了一堆强壁垒的公司，相比之下买了另外的一些。

Q5. 血制品行业再探讨

  • 听众：在管理行业能否再具体讲一下呢？
肖楠：我们只就血制品这个行业，研究得不是特别多。因为我们还有一些基金经理买了血制品行业，我觉得可以请教他们，我们不希望有一些特别冲突的观点。

Q6. 农林牧渔行业的观点

  • 听众：农林牧渔行业是有所提升，请问您对这个行业的观点能够给我们讲一下吗？
肖楠：这行业太大了。农林牧渔行业的提升是因为牧原股份，就那一只股票。我们不应该在公开场合讲具体股票的投资逻辑。不是因为我先看好农林牧渔行业，然后再去选牧原股份，就是牧原股份的比例提高了，就这么简单。

Q7. 商增与商减的分析

  • 听众：您能够再具体讲一下生意模式里边商增和商减的这个分析吗？
肖楠：用直白的理论讲，你们都是企业里的打工人，能深切感受到：企业从小到大，部门越来越多，以前三五个部门现在十几个，中层干部一大堆，传达效率变低，内部腐败开始出现。企业为解决问题又设巡视检查部门，部门里的人要加工资、提级别。企业扩张往下游或上游做，又多一个副总裁、多个部门。有些生意收入10亿和100亿时没多几个部门，有些企业不需要设那么多高管就把生意做成了。从商增角度讲，有些企业是商增把自己拖死的。举例：某行业剩两家互联网大厂，一家效率特别高，另一家山头林立、互相推诿、腐败丛生，因为后者从一开始就没考虑好企业大了以后商增怎么处理。前者基本是高度中央集权，CEO有非常强大的情报部门，知道每件重要事情细入基层是怎么回事。建议大家读党史，看这个组织从国民革命时期、抗战时期一直走到现在，怎么保持活力。有些国家也是被商增拖死的，一条铁路修几十年这种事在很多国家都会发生。

Q8. 伟大企业的增长曲线

  • 听众：您讲到伟大的企业的增长曲线，能否对于这个曲线的情况再具体跟大家讲一下呢？
肖楠：过去几年每年看，企业今年增长20%、明年15%、后年17.5%，都是线性的。但站10年周期看，这个企业跟竞争对手之间拉开极大差距。举例：快递行业，疫情时只有顺丰能送，没疫情时看不出来，一下子顺丰的估值和业绩把竞争对手甩出一大截。家电领域，过去格力一直是老大，美的做渠道扁平化、T加三一直没看到成果，突然疫情来了，美的占有率哗一下就上去了，超过格力。当一些企业在埋头做事还没体现到报表时，我们往往忽略这些事未来可能产生的重大影响。这些伟大企业都是在一些特别特殊的时候拐上去的——平时走在路上大家都好好的，突然来一场雨，发现有一个人带伞了，别人都淋成落汤鸡，就他家有伞。

Q9. 财富管理行业的投资逻辑

  • 听众：您刚刚讲到财富管理行业，能否对这个行业具体展开，讲一下投资逻辑和投资机会呢？
肖楠：财富管理行业这个话题特别大，而且是分层的——顶级富豪、普通中产阶级、中低收入人员的财富管理怎么做，都有不同的公司和商业模式。我们最早是研究保险时发现有意思的现象：某些保险公司一个保险员一单能签七八千的首年保费，有些公司平均一个业务员只有两三千，差距巨大。调研后发现，同样是卖保险，背后的逻辑、机制差异超级大，源于公司的结构设置、机构设置、激励机制、文化等巨大差异。去年发基金时也发现，有些渠道经理过来调研问的问题超级专业，另一些永远问下半年是涨是跌、明年是牛市还是熊市。财富管理行业最大的逻辑在于财富分布超级不均匀，头部公司可能一口气拿掉行业增量的绝大部分，第二名只能拿到剩下的20%的80%。在这种特别偏激的行业里，有可能诞生特别大的企业。遗憾的是，有些产品因监管和法律规则原因反而不能投类似标的，未来合同设置更清晰时，可能会在这方面有所体现。

Q10. 企业家精神的观察心得

  • 听众：您刚刚讲到曲线的方面，第二第三增长曲线需要卓越的企业家精神，企业家精神应该是投资中比较艺术的部分，请问您在观察这个指标方面会有什么心得和把握呢？
肖楠：第一个心得是评判这个因素时要特别小心谨慎，不要乱归因。不要因为一个企业经营成功就说这个企业家特别厉害，就像不要因为一个基金经理过去业绩好就说他特别厉害。一定要把所有能归因到数据里客观指标的因素全部归因完，再特别谨慎地评价一些比较虚的因素。第二个是不要轻易给这些因素定价，绝对不要说因为这个企业家在，所以这个公司就能值多少。我始终强调的是避免错误的归因，避免因为对企业家认可而犯投资错误，一定要把底线风险搞好。这些比较虚的因素（技术进步、企业家精神）什么时候考虑？在所有客观归因尽量穷尽以后再说。确确实实只能在有限范围内做两两比较——两个公司做同样生意、同样产品时，可以比较两个企业家水平高低、理念先后，去找你认可的那一家，不要跨行业、跨业务、跨产品比较。不要什么事情都归结到企业家身上，要谨慎使用“企业家精神”“伟大企业”这些词，在一些特别极端的时候，它可能是某些信仰上的支持，但尽量不要去用。
