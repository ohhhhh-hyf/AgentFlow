# 产品概况

海尔叠黛H2洗干集成机是海尔为中国家庭打造的原创之作，定位为洗干集成新物种。发布会背景源于中国80%用户将洗烘套装叠放阳台带来的操作不便，产品专为客阳一体空间设计，以一体集成机身解决洗烘套叠放带来的震动等安全隐患。产品高度167厘米，超薄机身可嵌入60厘米标准橱柜，采用同向开门与无水盒设计。核心目标是为向往整洁有序新阳台的用户提供一体化洗护体验，让用户享受家的整洁有序。

# 市场定位与目标用户

目标人群覆盖多类中国家庭：一是追求客阳一体家居风格的年轻用户，他们在阳台休闲娱乐、健身、社交，悬挂晾衣既不美观又占空间；二是养宠家庭，居家环境漂浮的毛屑多来自衣物家纺；三是有宝宝的家庭，需要洗衣无残留、干衣无毛絮的健康守护。产品针对中国80%用户将洗烘套装叠放阳台的痛点，对比欧洲家庭独立洗衣房并排摆放洗烘套装的使用习惯，以一体集成设计解决屏幕过高、开门方向相反、水盒太高太沉等不便，形成差异化竞争力。

# 核心卖点与技术参数

**一体集成设计**：专为客阳一体空间设计，一体集成机身解决洗烘套叠放带来的震动等安全隐患，高度167厘米，超薄机身嵌入60厘米标准橱柜，纯平不突出，同向开门，采用无水盒设计无需手动倒水。

**智慧互联**：搭载全新升级的智慧大脑，利用中枢神经式智能网络让上下桶默契配合；独有的灵犀洗烘联动实现数据共享，洗涤结束前上桶提前15分钟主动预热，缩短烘干时长。

**烘干技术**：搭载原创双擎热泵技术，大件烘干不缠绕；首次引入行业领先黑科技3D透视烘干，羽绒服、水洗被均可一次烘透，免去二次晾晒。

**洗护功能**：升级精华洗2.0，39分钟洗净一周衣物；新鲜净水漂洗减少洗衣液残留，对残留泡沫敏感人群友好。

**健康与静音**：搭载空净过滤系统，去除衣物线屑和毛絮；搭载三台变频电机，洗涤、甩干、烘干全过程噪音低。
