# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷二审，由最高人民法院组成合议庭公开开庭审理，审判长李少平，审判员魏文超、黄年、王海峰、葛洪涛，法官助理张瑞。各方围绕三个争议焦点展开辩论：国开行是否尽到审查义务并善意取得抵押权；一审判决对案涉借款罚息、复息的计算及起算日期是否认定错误；东源煤电、东源煤业是否应连带给付违约金。庭审中，国开行主张其审查义务仅限于抵押人曲靖电力公司，且已按央行规定查询融资租赁登记系统未发现登记；东源方及招银租赁则认为国开行未在抵押时点（2015年12月）查询，且设备名称相同、邮件中已用红色标注，应尽注意义务，不构成善意。各方均承认动产抵押登记与融资租赁登记系统信息不互通，存在系统性风险。合议庭休庭评议后提出调解方案，各方均无异议，同意签署调解协议。

# 举证与法庭调查
## 举证与质证
- **东源公司融资情况统计表（东源方提交）**：2015年12月2日邮件所附，载明招银租赁抵押物为恩洪电厂设备资产、抵押手续已登记，国开行抵押物为恩洪电厂设备在建工程、正在办理；东源方主张该表已引起国开行注意义务，国开行质证认为该表并列描述不能得出已告知的结论。
- **回租设备清单（招银租赁一审提交）**：证据第7页，仅载明设备名称和生产厂家，未提及型号；国开行质证认为清单记载出厂日期为2012年3月1日，与现场调查核实到的铭牌生产日期（2013年11月、12月、2014年3月）不符，看不出是同一设备。
- **权属证明材料及股东会决议（国开行提交）**：证据第54页、58页，显示案涉抵押设备所有权属曲靖电力公司；国开行主张据此已尽审慎义务，融资租赁登记核查义务仅限于曲靖电力公司。
- **融资租赁登记查询证书（国开行提交）**：2018年9月对曲靖电力公司的查询结果；招银租赁质证认为不符合要求，依据2014年93号文，国开行应在抵押时点（2015年12月）查询。
- **审计报告（招银租赁一审提交）**：2013年和2015年合并报表，证据第82页、95页，载明曲靖电力公司注册资本4亿元且已实缴；国开行主张招银租赁据此应知道或应当知道设备出资情况。
- **融资租赁登记系统查询截图（国开行提交）**：显示曲靖电力公司名下无融资租赁登记；国开行主张已履行查询义务，招银租赁质证认为查询时点不符合规定。

## 证人、鉴定与其他来源陈述
- **审计报告（招银租赁一审提交）**：2013年和2015年合并报表，证据第82页、95页，载明曲靖电力公司注册资本4亿元且已实缴，设备出资事项已载明。
- **评估报告（国开行引用）**：在建工程价值5.7亿元，机器设备价值5.1亿元，明确上述资产存在，虽未纳入资产负债表但不等于不拥有。

## 法官询问
- **【融资租赁登记性质】**：审判长询问各方如何理解央行征信中心融资租赁登记的性质及法律后果；国开行认为是行业强制性规范，旨在防范金融风险；东源方认为是行业指导性规范，不产生物权后果；招银租赁认为不是法定物权登记，但具有对抗效力。
- **【查询方式】**：审判员询问国开行和招银租赁融资租赁登记系统的查询方式；国开行称仅有一种查询方式（查询单位）；招银租赁称可通过公司名称或设备情况两种方式查询，但设备查询涉及种类物区分问题。
- **【案涉设备识别码登记】**：审判员询问招银租赁案涉5套设备识别码是否登记清楚；招银租赁称设备交付时无唯一识别码，属种类物，故未登记。
- **【内部风控规定】**：审判员询问国开行贷款前审查是否有内部规定要求必须查询并保留未查询到结果的单子；国开行称按央行规定查询系统，因无记录故未保留筛查记录，内部无此规定。
- **【查询免责逻辑】**：审判员要求国开行说明查询曲靖电力登记信息未查到结果而免责的逻辑；国开行称查询是手段之一，系统无记载且至今无记载，行为无过失。
- **【设备唯一标识码必填性】**：审判员询问招银租赁融资租赁登记系统中设备唯一标识码是否必填；招银租赁称不是必填项，案涉设备无唯一识别码，故未填写。
- **【设备铭牌标识】**：审判员询问设备安装后发电机上是否有唯一标识码；招银租赁称铭牌上只有型号和参数，同型号设备铭牌相同。
- **【查询义务程度】**：审判员询问国开行和招银租赁违反查询规范在多大程度上导致司法解释第9条第2款后果，是基本查询义务还是全面审慎义务；国开行认为是基本义务，审查对象限于抵押人；招银租赁认为是对银行业的严格要求，未查询即不构成善意。
- **【其他途径知晓是否免查询】**：审判员询问若银行通过其他途径知晓动产属融资租赁物，是否相当于已了解风控情况；国开行称基本义务必须履行，查询动作完成即可；招银租赁认为仍需通过央行系统查询，因其他方式无法证明。
- **【举证责任分担】**：审判员询问各方对融资租赁司法解释第9条第2款举证责任的理解；国开行主张按谁主张谁举证原则；招银租赁主张第1、2、4项由出租人举证，第3项由第三人（国开行）举证。
- **【登记信息冲突建议】**：审判长询问各方对因不同登记机构产生登记信息冲突的意见和建议；国开行认为系系统信息不完整、条块化分割所致，建议整合互联互通；东源方称非专业机构提不出成熟建议；招银租赁建议从立法、行业协会、操作技术三个层面改进。

## 争议焦点与辩论
- **争议焦点一：国开行是否尽到审查义务、是否构成善意取得抵押权**
  - **国开行主张**：审查义务仅限于抵押人曲靖电力公司，不能扩大到东源煤电公司；案涉设备为通用设备，无唯一标识码，无法按设备查询；已按央行规定查询融资租赁登记系统，未发现登记，已尽审慎义务，构成善意取得。
  - **东源方主张**：2015年12月2日邮件中融资情况统计表显示招银租赁抵押物已登记，且设备名称完全相同、用红色标注，国开行应尽注意义务并做区分核查。
  - **招银租赁主张**：国开行应在抵押时点（2015年12月）查询融资租赁登记系统，而非提供2018年9月的查询证书；国开行未在抵押时点查询，不构成善意；东源煤电出资行为系无权处分，电力公司未取得设备所有权。
- **争议焦点二：一审判决对案涉借款罚息、复息的计算及起算日期是否认定错误**
  - **国开行主张**：利息自2017年12月21日计算至2018年6月12日，合计21,795,727.68元；罚息自2018年6月13日计算至2019年2月19日，为41,050,579.57元；复利自2018年3月21日计算至2019年2月19日，为1,918,206.23元；合同第6条第4款明确约定对逾期借款利息按罚息利率计收复利。
  - **东源方主张**：国开行2018年6月13日发函要求立即偿还，未给合理期限，不符合合同约定的“限期偿还”；罚息不应作为复利计算基数，依据《人民币利率管理规定》第21条及最高院判例；复利再计算复利无合同依据。
- **争议焦点三：东源煤电、东源煤业是否应当连带给付违约金**
  - **国开行主张**：依据借款合同第24条第3项，被上诉人违约应支付千分之一违约金；东源煤电未按合同第13条、第14条配合办理账户管理及柜台前移手续，举证责任在被上诉人。
  - **东源方主张**：国开行未举证证明东源煤电违反柜台前移和账户管理约定；国开行未按合同约定先发出限期纠正函件，无权主张违约金。

# 庭审结果
- **调解协议达成**：各方对调解方案均无异议，同意签署调解协议，法院将出具调解书。
- **债权数额确认**：国开行对东源煤电的债权扣除破产已清偿本金外，利息、罚息、复利合计6474.4513万元。
- **设备权属确认**：招银租赁对涉案6项设备享有所有权，对应债权数额1377.4137万元；国开行对93项设备有抵押权。
- **设备处置安排**：招银租赁和国开行对案涉全部发电设备整体盘活处置，变现价款各得50%，实现费用各担50%。
- **执行申请期限**：调解书生效后20日内，由国开行向一审法院提出执行申请，启动司法处置程序。
- **未实现债权处理**：国开行、招银租赁未实现的债权待执行法院出具体本裁定后，按破产重整计划中的预留方案实现；若破产管理人不予纳入预留方案，由东源煤电按此前有担保清偿方案予以清偿。
- **司法变现不能的后果**：若司法变现不能，国开行和招银租赁放弃对案涉设备的权益，由东源曲靖电力自主生产经营。
- **管理费用承担**：案涉设备上的管理费用由东源曲靖电力承担，东源曲靖电力无条件配合司法处置。
- **诉讼费用分担**：一审诉讼费用中，国开行诉请部分按一审判决执行，招银租赁诉请部分由国开行承担；二审诉讼费用由国开行和东源煤电各承担50%。
- **争议终结**：本协议签订后，各方之间就本案涉及的问题不再存在任何争议。
