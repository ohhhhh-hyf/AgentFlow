# 发布会概况
本次会议由中金公司策略组刘刚凯文主持，为每周一度的中金宏观策略周会，围绕大美丽法案、关税谈判、港股流动性三大宏观议题展开，并邀请公用事业首席分析师刘佳妮、机械军工分析师郭文秀、传媒首席分析师张雪琴分别更新光伏反内卷、人形机器人和游戏板块。会议核心信息包括：大美丽法案三大块为提高债务上限约5万亿美元、延长2017年减税（新增支出3.4万亿、一年3400亿）、取消899条款；关税收入每年3000~4000亿可对冲支出，赤字率基本维持5~6%；7~9月发债约1万亿带来流动性抽水，美债利率可能上行但幅度或小于2023年（3.8~5%）。整体基调为：对美股美债不悲观，三季度有流动性波折但波动提供再配置机会，四季度美元可能小幅走强、美股可能反弹跑赢；光伏反内卷有望夯实行业底部；人形机器人三季度是从迷茫期到商业兑现的过渡阶段；游戏板块旗帜鲜明看好，认为调整后更健康可上车。

# 核心信息
大美丽法案三大块：一是提高债务上限约**5万亿美元**，违约风险消除；二是延长2017年减税，新增支出**3.4万亿**（一年**3400亿**），同时减掉其他支出**1.4万亿**；三是取消899条款。关税收入每年**3000~4000亿**可对冲支出，赤字率基本维持**5~6%**。7~9月发债约**1万亿**带来流动性抽水，美债利率可能上行但幅度或小于2023年（**3.8~5%**），期限溢价已处**2013年以来高点**。关税有效税率约**10~12%**，极端回到**18%**，通胀年底抬升至**3.3~3.4%**但不改变路径。港股指数在**23000~24000**区间震荡。光伏主产业链四环节产能严重过剩：电池为需求**1.5倍**、硅片组件**2倍**、硅料**2.5倍**；2022年以来价格下跌**70~90%**；硅料现金成本**38元/公斤**，头部颗粒硅**28元**、尾部**45元**；多晶硅期货反弹至**40元/公斤**，硅片报价涨**10%**，电池涨**2分**。人形机器人二季度A股板块跌约**9%**、跑输机械**12个百分点**，特斯拉供应商标签股回调**30~40%**；宇树科技年收入破**10亿**，两家同时中标中国移动近**1.2亿**订单。游戏6月单月版号发放**158个**（国产**147**、进口**11**），为**2018年以来最高**；1~5月市场规模同比增长**17%以上**、手游增长**20%**；估值TTM PE约**30倍**、2025年静态PE约**20倍**。

# 官方表态
刘刚凯文：> 我们并不是完全的认同，去美元化这个观点的。现在成了一个高度趋同的共识。市场两个最大的误区：把美元弱当成去美元化；把美元弱和美股弱直接划等号。> 波动提供再配置的机会，我们重申我们这个观点并不悲观。> 在合适的位置拿长期正确的板块。刘佳妮：> 随着反内卷的力度不断的强化升级，我们相信就是价格的恶性竞争有望告一段落。> 对于硅料的整合其实是最为迫切的。郭文秀：> 三季度将是一个二季度的迷茫期到商业兑现过度的这样的一个小阶段。> 技术创新产业需求和工厂替代，往往这三重周期共振的时候，其实是孕育着比较不错的一个投资机会的。张雪琴：> 我们的态度旗帜鲜明是后者（回调一下更健康可以上车）。> 在消费政策和新品周期三重利好下面，游戏行业有望在调整后再次实现戴维斯双击。

# Q&A环节
问：关税威胁是否只是谈判技巧，还是真的会大幅提高？→ 答：刘刚凯文表示，关税四点信息：一定会做以支撑收入、需维持一定税率（10~12%有效税率即可收3000~4000亿）、不能太高否则通胀受不了、市场逐渐脱敏；姑且把它认作还是一个所谓的谈判技巧。问：加拿大墨西哥欧盟能否谈妥稳住？→ 答：刘刚凯文表示，加拿大墨西哥欧盟贸易占比太高，一定要和他们谈妥稳住，其他的这些国家即便增加一倍都不影响它的有效税率。问：8月12日中美谈判及转口限制进展如何？→ 答：刘刚凯文表示，需要关注8月12号中美谈判进一步的进展，尤其是一些转口的限制；越南的转口限制是40%，我们比这个税率还要低。问：光伏反内卷具体干预措施尚未披露，细节待明确？→ 答：刘佳妮表示，目前我们并没有看到一个干预措施的一个具体的披露，政府近期对于这个光伏行业的接连的发生，说明了光伏产业对于作为一个国家重要的名片的一个重要性。问：组件价格能否跟涨传导，下游电站能否接受产业链价格上涨？→ 答：刘佳妮表示，组件价格也有跟涨的一个意愿，但下游电站受136号文新能源全面入市政策影响，电价未来不确定性大幅增加，能否接受产业链价格上涨的传导还需观望未来一段时间的招标情况。问：特斯拉Optimus硬件问题何时解决，供应商筛选结果如何？→ 答：郭文秀表示，特斯拉由于存在非常多的硬件问题，包括电机的过热、灵巧手的负载不足、还有一些续航问题，目前整体特斯拉是在变更他的方案，包括他的目前的供应商从供应商的一个层面上还是在去进行筛选。
