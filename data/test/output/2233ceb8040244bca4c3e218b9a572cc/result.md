# 就诊概况
48岁男性患者张学恒，因上腹心窝处反复烧灼样疼痛4年、近3个月加重，于消化专科门诊就诊。疼痛与进食冷、硬、辛辣食物及工作紧张劳累相关，白天发作、夜间无痛醒；近3个月内两次黑便（一年前一次持续约一个月并住院10天，三个月前一次住院两三天后转黄），近两个月呕吐数次，吐出当日早、午餐食物，吐后舒适。近期服用达喜、奥美拉唑、阿莫西林及医务室自配胃炎合剂，均停药后复发。既往有甲肝史、磺胺过敏史，婶婶有胃癌史。医生初步判断症状符合消化性溃疡或胃炎表现，需进一步检查明确。

# 诊断与检查结果
医生初步判断患者症状符合消化性溃疡或胃炎表现，需进一步检查明确。关键检查安排：留大便做潜血检查以排查出血；后天行胃镜及活检。既往检查：一年前及三个月前两次大便检查均提示大便出血。异常指标：**两次黑便**（提示消化道出血可能）。

# 治疗方案与医嘱
- **检查安排**：留大便做潜血检查，排查出血；后天行胃镜及活检，届时张大夫查房。
- **用药说明**：近期服用达喜（初始一天两次每次一颗有效，后加至每天4-5次效果不佳）、奥美拉唑（武汉药厂国产）、阿莫西林及医务室自配胃炎合剂，均停药后复发，具体用药明细见下表。
- **生活方式**：建议戒烟、少喝酒，因长期加班熬夜、吸烟、饮酒可能加重胃部疾病；注意饮食，避免冷、硬、辛辣食物。
- **复诊与陪同**：后天做胃镜，需爱人请假陪同。
- **高风险提醒**：**磺胺药过敏**，禁用磺胺类药物。
