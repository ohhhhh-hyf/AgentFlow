# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷一案，国开行不服云南省高级人民法院2018云民初88号民事判决，向最高人民法院提起上诉。本案由审判员李少平担任审判长，与审判员魏文超、黄年、王海峰、葛洪涛组成合议庭，法官助理张瑞，依法公开开庭审理。庭审中，各方当事人对出庭人员身份均无异议，东源煤电、东源煤业、曲靖电力三方合并发表意见。庭审围绕三个争议焦点展开法庭调查与辩论：国开行是否尽到融资租赁登记查询义务并构成善意取得抵押权；一审对罚息复息的计算及起算日期是否认定错误；东源煤电、东源煤业是否应连带给付违约金。合议庭在查明事实基础上提出调解方案，各方均无异议，合议庭予以确认，庭后出具调解书。

# 原告诉称与被告辩称
本案系二审上诉案件，无原告、被告之分，各方立场如下：
- **上诉人（国开行）**：请求改判支持其关于罚息、复利计算及违约金的主张，认为一审认定有误。事实与理由：已按央行规定查询融资租赁登记系统，审查义务仅限于抵押人曲靖电力公司，抵押设备所有权经核查属曲靖电力公司，构成善意取得；利息应自2017年12月21日计算至2018年6月12日，罚息自2018年6月13日计算至2019年2月19日，复利自2018年3月21日计算至2019年2月19日；借款合同第24条第3项约定违约金为千分之一，东源煤电未配合办理账户管理及柜台前移手续构成违约。
- **被上诉人（东源煤电、东源煤业、曲靖电力）**：请求驳回上诉，维持原判。事实与理由：2015年12月2日邮件已用红色标注告知抵押设备存在融资租赁，国开行应尽注意义务；国开行2018年6月13日发函要求立即偿还不符合合同约定的限期偿还要求；罚息不应作为复利计算基数，复利再计算复利无合同依据；国开行未举证证明违约行为，且未按合同约定先限期纠正。
- **被上诉人（招银租赁）**：请求驳回上诉，维持原判。事实与理由：国开行未在抵押时点（2015年12月）进行融资租赁登记查询，仅提供2018年9月查询证书，不符合规定；国开行审查义务应扩展到全资控股母公司东源煤电；东源煤电出资行为系无权处分，电力公司未取得所有权；招银租赁2012年已取得设备所有权。

# 举证与法庭调查
**证据与质证意见**
- **东源方证据（2015年12月2日邮件及融资情况统计表）**：东源方主张该邮件已告知国开行抵押设备存在融资租赁，设备名称完全相同且用红色标注；国开行质证认为该邮件系贷后审查材料，非针对抵押物的告知，统计表中招银租赁一栏记载的抵押类型为不动产抵押，与融资租赁是两个法律概念，不能得出已告知的结论。
- **国开行证据（融资租赁登记查询证书，证据第5组第1项）**：国开行主张已按央行规定查询融资租赁登记系统，未发现曲靖电力公司设备有融资租赁登记；招银租赁质证认为该查询证书系2018年9月出具，不符合2014年93号文关于应在抵押时点（2015年12月）查询的规定。
- **招银租赁证据（回租设备清单，证据第7页）**：招银租赁主张清单已载明设备名称、数量、原值、净值、出厂时间、生产厂商及存放地点，足以特定化；国开行质证认为清单仅载明设备名称和生产厂家，未提及型号，且记载的出厂日期为2012年3月1日，与国开行现场调查核实的铭牌生产日期（2013年11月、12月、2014年3月）不符，看不出是同一设备。
- **国开行证据（权属证明材料，证据第54页、58页）**：国开行主张东源煤电、曲靖电力出具的权属证明及股东会决议显示设备所有权属曲靖电力公司；招银租赁质证认为东源煤电出资系无权处分，电力公司未取得所有权。
- **国开行证据（融资租赁登记核查表，证据第108页）**：国开行主张已对曲靖电力公司名下融资租赁登记信息进行核查，未发现登记；招银租赁质证认为核查范围应扩展到东源煤电。
- **招银租赁证据（2013年、2015年审计报告，证据第82页、95页）**：招银租赁主张报告载明曲靖电力公司注册资本4亿元已实缴，设备出资事项已载明；国开行质证认为报告虽为合并报表，但已明确载明设备出资情况，招银租赁有理由知道或应当知道设备出资情况。

**法官询问要点**
- 合议庭询问各方对中国人民银行征信中心融资租赁登记性质的理解及法律后果：国开行认为是行业强制性规范，用于防范金融风险；东源方认为是行业指导性规范，不产生物权后果；招银租赁认为非法定物权登记，但具有对抗效力。
- 合议庭询问融资租赁登记系统的查询方式：国开行称只能按单位查询；招银租赁称可按公司名称或设备查询，但设备查询需特定化。
- 合议庭询问案涉5套设备是否登记唯一识别码：招银租赁称设备为种类物，无唯一识别码，未登记；国开行称设备铭牌上无唯一标识码。
- 合议庭询问国开行内部是否有规定要求保留未查询到结果的记录：国开行称无此规定。
- 合议庭询问查询义务是基本义务还是全面审慎义务：国开行认为是基本义务，招银租赁认为是严格义务。
- 合议庭询问融资租赁司法解释第9条第2款的举证责任分担：国开行主张谁主张谁举证；招银租赁认为第1、2、4项由出租人举证，第3项由第三人（国开行）举证。
- 合议庭询问若通过其他途径知晓融资租赁情况是否仍需查询登记系统：国开行认为仍需查询，招银租赁认为必须通过央行系统查询以确定标准。

**双方辩论的争议焦点**
- **争议焦点一**：国开行是否尽到融资租赁登记查询义务、是否构成善意取得抵押权。国开行主张已按央行规定查询，审查义务仅限于抵押人曲靖电力公司，构成善意取得；东源方主张邮件已告知且用红色标注，国开行应尽注意义务；招银租赁主张国开行未在抵押时点查询，审查义务应扩展到东源煤电，东源煤电出资系无权处分。
- **争议焦点二**：一审对罚息复息的计算及起算日期是否认定错误。国开行主张利息、罚息、复利应分别自2017年12月21日、2018年6月13日、2018年3月21日起算；东源方主张国开行发函要求立即偿还不符合限期偿还约定，罚息不应作为复利计算基数，复利再计算复利无合同依据。
- **争议焦点三**：东源煤电、东源煤业是否应连带给付违约金。国开行主张合同约定违约金为千分之一，东源煤电未配合办理账户管理及柜台前移手续构成违约；东源方主张国开行未举证证明违约行为，且未按合同约定先限期纠正。

# 庭审结果
本案争议焦点有三：一是国开行是否尽到融资租赁登记查询义务、是否构成善意取得抵押权；二是一审对罚息复息的计算及起算日期是否认定错误；三是东源煤电、东源煤业是否应连带给付违约金。庭审中，合议庭在查明事实基础上提出调解方案，各方当事人均表示无异议，合议庭予以确认，庭后出具调解书。调解方案主要内容：国开行对东源煤电的债权扣除破产清偿本金外，利息、罚息、复利合计6474.4513万元；招银租赁对6项设备享有所有权，债权数额1377.4137万元；国开行对93项设备有抵押权；双方对案涉全部发电设备整体盘活处置，变现价款各得50%，费用各担50%；调解书生效后20日内国开行向一审法院申请执行；未实现债权按破产重整计划预留方案实现；若司法变现不能，双方放弃设备权益，由东源曲靖电力自主生产经营；设备管理费用由东源曲靖电力承担；一审判决第2项、第4项无争议；诉讼费用按规定分担。未决事项：国开行是否尽到查询义务、审查义务范围、罚息是否作为复利基数、东源煤电是否构成违约等争议焦点，因调解达成而未在判决中认定。
