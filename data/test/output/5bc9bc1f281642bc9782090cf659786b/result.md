# 项目概况
本次会议为原占比二玉米面加工厂项目中期验收会议，验收组于18、19号提前介入项目摸排，20号召开首次会议，分内业、外业两方面对卢萨卡、蒙泽两点开展检查。卢萨卡点已完成除弹料加工调试以外的所有验收工作，蒙泽点已完成全部验收并顺带完成带料调试和试生产；姆皮卡点现场验收尚未开展，内业资料已提前拿到卢萨卡。内业资料基本满足项目标准和规范要求，但竣工文件分类整理和签字规范性需完善；外业检查中建筑、安装、设备三部分总体质量良好，蒙泽点工艺设备运行正常，产能符合设计指标。财务账户设置、资金往来、银行开户等符合财务处理规范和标准。验收组提出人员履约、内业资料、现场整改等要求，管理组和技术组承诺会后细化并落实；合作局领导要求分析混凝土路面开裂原因、出报告前完成整改，公司领导强调按合同仔细验收并注意交通安全和疫情防控。

# 后续计划
- **人员履约整改**：管理组和技术组会后细化验收组提出的问题，技术组正在收集所有参与项目现场人员的护照证书，完善人员统计（含厂家服务人员）及个别人员进出场时间、护照等资料，确保验收报告闭合。
- **内业资料汇总**：技术组承诺在验收完成第一时间将三个厂区资料（含竣工图）汇总于卢萨卡，按援外项目执行手册管理办法进行分类组卷及编码，验收组可配合补充完善。
- **现场实体整改**：技术组编制整改方案，对装饰装修损伤、卫生、排水、混凝土路面开裂、监控管线接头脱落、廊桥加固等问题逐一整改落实。
- **路面开裂专项分析**：管理组和总包单位共同分析混凝土路面开裂原因（结合赞比亚气候特点），制定科学合理的整改方案，最迟在出报告前完成整改，验收组进行复核。
- **成品保护与修补**：在移交外方前继续做好成品保护，对破损部位及时修补，雨季前检查厂区及办公区排水系统。
- **姆皮卡点验收**：验收组会后安排前往姆皮卡点开展现场验收，注意交通安全和疫情防控，内业资料已提前拿到卢萨卡。
- **不可预见费资料完善**：验收组与施工单位对接，完善不可预见费使用的依据证据和数据，确保充分无误，后续专门沟通。
