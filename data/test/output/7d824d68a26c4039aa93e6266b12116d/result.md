# 就诊概况
患者张春和，男，48岁，因上腹反复烧灼痛4年、近3个月加重伴两次黑便及呕吐，就诊于消化内科，由严医生接诊。患者上腹心窝处烧灼感持续3个月，4年来每年春季多发，诱因为吃冷、硬、刺激性食物及工作紧张、劳累、加班熬夜；疼痛可忍受，白天发生，无夜间痛醒。近3个月有两次黑便（一次一年前、一次三个月前），每次持续约一个月，大便干、形状正常仅颜色改变，两次均住院（第一次约10天、第二次两三天）后大便转黄。近两个月出现呕吐，吐出酸水样物，含早晨或中午所食，晚上吐出后舒服，偶有隔夜食物吐出，呕吐物无红色或黑色。近3个月无黑便，大便黄色正常，小便正常，睡眠可，饮食量无明显下降，体重在发病时稍降但很快恢复。初步判断需排查消化道出血及胃部病变，已安排留大便检查并预约后天胃镜。

# 诊断与检查结果
本次就诊尚未完成胃镜及大便检查，暂无明确诊断结论。患者有两次黑便史，可能存在消化道出血，需通过大便检查排查。患者有胃癌家族史（婶婶患胃癌，虽无血缘关系），但患者担心，需进一步检查排除。既往史：16岁时患甲肝，在三医院住院一个月，出院时肝功能正常，此后体检肝功正常；小时候因扁桃体炎在儿童医院就诊，服用磺胺药后左手起红疹、痒，持续半个月，医生诊断为药物过敏，此后不能服用磺胺药；无手术史。系统回顾：偶有头昏（与休息有关），双眼近视400度，偶发口腔溃疡，无皮肤瘀斑、牙龈出血，无咳嗽咳痰，无心慌心累，偶有急性腹泻（与不洁饮食有关），小便正常，关节肌肉无疼痛，记忆力正常。

- **用药**：近期服药包括斯达舒（初每天两次每次一颗有效，现加至每天四五次效果不佳）、奥美拉唑（武汉药厂产，国产）、阿莫西林及医务室自配胃炎合剂，服药好转后停药又复发；具体明细见下表。
