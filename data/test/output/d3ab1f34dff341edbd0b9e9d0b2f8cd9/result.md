# 庭审概况
本案系上诉人国家开发银行（国开行）与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司（招银租赁）金融借款合同纠纷二审案件，由最高人民法院依法组成合议庭公开开庭审理。庭审围绕三个争议焦点展开辩论：一是国开行对抵押设备是否尽到审查义务、是否构成善意取得，以及融资租赁登记的性质与效力；二是案涉借款的罚息、复利计算方式；三是东源煤电是否应连带给付违约金。合议庭在查明事实、分清是非的基础上提出调解方案，各方当事人均无异议，当庭达成调解协议。

# 举证与法庭调查
**证据与质证意见**
- 国开行提交2018年9月对曲靖电力公司的融资租赁查询证书，招银租赁认为不符合2014年93号文要求，国开行在抵押时点未进行相应查询。
- 国开行提交工商部门出资证明及权属证明，主张已对设备所有权尽到审慎审查义务；招银租赁认为工商登记公示的是出资行为而非动产所有权，东源煤电出资系无权处分。
- 招银租赁提交回租设备清单（一审证据7页），仅载明设备名称和生产厂家，未提及型号；国开行主张无法据此识别设备唯一性。
- 招银租赁提交2013年、2015年审计报告（证据82页、95页），载明曲靖电力公司注册资本4亿元且已实缴；国开行主张该报告已载明设备出资事项。
- 国开行提交2018年核查表（证据108页），显示曲靖电力公司名下无融资租赁登记；招银租赁认为该核查不符合要求。

**法官询问要点**
- 合议庭询问各方对中国人民银行征信中心融资租赁登记性质及法律后果的理解。
- 询问国开行贷款前审查是否有内部规定要求查询融资租赁登记，未查到结果时是否保留筛查记录。
- 询问招银租赁在融资租赁登记系统中是否登记设备唯一标识码，该标识码是否为必填项。
- 询问国开行和招银租赁关于查询通知规定的性质及违反后果。
- 询问各方对因不同登记机构产生登记瑕疵的看法及建议。

**双方辩论的争议焦点**
- 国开行是否尽到审查义务、是否构成善意取得：国开行主张审查义务仅限于抵押人曲靖电力公司，已按人民银行规定查询系统，未发现登记信息；招银租赁认为国开行未在抵押时查询，不构成善意。
- 融资租赁登记的性质与效力：国开行认为是行业强制性规范，招银租赁及东源方认为是行业指导性规范，不产生物权效力。
- 设备唯一标识码与查询方式：招银租赁称暗设五套设备无唯一识别码，未登记；国开行称查询曲靖电力公司无融资租赁登记，但未保留查询记录。

# 庭审结果
本案争议焦点为：一是国开行对抵押设备是否尽到审查义务、是否构成善意取得，以及融资租赁登记的性质与效力；二是案涉借款的罚息、复利计算方式；三是东源煤电是否应连带给付违约金。合议庭休庭评议后宣读调解方案，各方均无异议并签字确认。调解方案主要内容包括：确认国开行对东源公司债权扣除破产清偿本金外，利息、罚息、复利合计6474.4513万元；确认招银租赁对涉案六项设备享有所有权，对应债权1377.4137万元；确认国开行对93项设备有抵押权；招银租赁和国开行对案涉全部发电设备整体盘活处置，变现价格及实现费用双方各担50%；变现款不足清偿时按破产重整计划预留方案实现；若司法变现不能，双方权益实现后均放弃对案涉设备权益，由东源曲靖电力自主生产经营。一审判决第二项、第四项无争议，按判项内容在调解书中确认；诉讼费按规定确定。合议庭指出，动产抵押权与融资租赁物所有权冲突是司法实践中的普遍性难题，根本原因在于国家尚未建立统一的动产登记制度，现有融资租赁登记系统和动产抵押登记系统缺乏有效衔接，将向有关部门提出司法建议。
