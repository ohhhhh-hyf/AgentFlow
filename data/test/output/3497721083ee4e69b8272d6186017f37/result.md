# 沟通概况
2025年秋季学期，372班班主任林瑞（地理教师）主持召开家长会，与全班60名学生家长沟通班级管理与学生成长事宜。会议围绕班级基本情况、教师团队、存在问题及解决思路、费用说明、保险与电子学生证办理、家庭教育建议等议题展开。班主任指出班级整体班风纪律良好，但少数学生存在周末玩手机游戏、自习课效率低、个别学生书写不佳等问题，并提出加强手机管理、制定班规、加强班委培训等措施。会议明确费用由学生交给生活委员、不在微信群收取，建议家长关注学生社交账号与心理健康，并成立家委会（至少三人）。张宇波校长作为家长代表分享家庭教育经验，强调尊重孩子、多倾听多交流。

# 沟通内容
**班级亮点**：
- **班风纪律**：372班共60人（男生25人、女生35人），整体时间观念、执行力强，班风班貌纪律良好，卫生干净。
- **教师团队**：多为老教师、优秀教师，师范院校毕业，有3年以上教学经验，部分教师有6年以上经验；班主任林瑞教地理学科。

**需关注之处**：
- **手机管理**：少数同学周末玩手机游戏，有网瘾，充生活费400元用于游戏；发现学生看直播、不健康内容，需家长关注。
- **自习效率**：自习课效率低，思考能力差，班主任不在时纪律松散，需加强班委培训。
- **书写习惯**：个别学生书写不好，已与家长沟通，建议买字帖练字。
- **行为规范**：发现学生带镜子，要求全部收掉；有学生谈恋爱，需家长关注QQ、抖音、快手等社交账号。

# 家长反馈
张宇波校长作为家长代表分享家庭教育经验，强调关注孩子身体健康和心理健康，尊重孩子，多倾听多交流，配合学校制度。班主任林瑞转述家长反馈：个别学生书写问题已与家长沟通；有家长反映孩子生活费使用不当，建议控制零花钱。班主任提醒家长注意孩子社交账号动态，防止早恋和不良内容影响。

# 共识与配合事项
**家校共识**：
- 费用由学生交给生活委员，不在微信群收取，防止诈骗。
- 要求收掉镜子，加强手机管理，家长配合处理多余手机。
- 成立家委会，至少三人，有家长自愿报名。

**后续配合事项**：
- [ ] 家长：周一到周五不定时打电话检查孩子手机是否开机。
- [ ] 家长：处理孩子多余手机，不留多部。
- [ ] 家长：关注孩子QQ、抖音、快手等社交账号，防止早恋和不良内容。
- [ ] 家长：督促孩子练字，购买字帖。
- [ ] 班主任：制定详细班规，严格扣分、写检讨、罚站。
- [ ] 班主任：加强班委培训，提高自习课效率。
- [ ] 班主任：定期与科任老师沟通，了解学生表现。
- [ ] 家长：关注孩子心理健康，发现异常及时心理辅导。
- [ ] 家长：提醒孩子注意交通安全，未满16周岁不骑电动车。
- [ ] 家长：配合学校防溺水、防诈骗、防校园欺凌教育。
