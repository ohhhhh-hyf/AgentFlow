# 参观概况
本次参观为故宫博物院一日深度游览，由主讲人按中轴线及东西延伸路线进行全程讲解，覆盖午门、太和门、太和殿、中和殿、保和殿、乾清门、乾清宫、交泰殿、坤宁宫、储秀宫、慈宁宫、断虹桥、武英殿、文华殿、箭亭、钟表馆、珍宝馆、御花园等主要景点，穿插历史典故与建筑功能说明。讲解以午门“明三暗五”结构及门洞通行规制开篇，依次介绍太和门御门听政、太和殿盛大典礼、保和殿殿试考场、乾清宫立储诏书等核心内容，并延伸至慈禧储秀宫原状陈列、珍宝馆宁寿全宫及九龙壁等专题。全程同时梳理故宫内七处免费盖章点及文创购买规则，并在结尾总结三条适用不同时长与体力的游览路线，整体构成一份涵盖景点、历史、盖章与路线规划的保姆级游览攻略。

# 核心看点与讲解
- **午门**：检票入口，明朝皇帝在此杖打犯错大臣，清朝皇帝在此举行颁朔之礼颁发历书。门洞为“明三暗五”结构，中间正门仅供皇帝行走，皇后大婚时可进一次，殿试前三名（状元、榜眼、探花）可出一次，旁门走皇亲国戚和文武百官。
- **太和门广场**：眼前有五座金水桥，中间桥供皇帝行走，挨着中间的两座桥供皇亲国戚行走，文武百官走最边上的桥。
- **太和门**：明朝皇帝在此御门听政（上朝），门口铜狮子是故宫六对铜狮中最大的一对，脚踩寰宇象征权力，不建议站在狮子底下合影。
- **太和殿**：即金銮殿，但并非上朝之处，而是举行盛大典礼的地方，如皇帝登基、皇后册封，文武百官在太和殿广场向皇帝喊“吾皇万岁万岁万万岁”，站位遵循“文东武西”。西边弘义阁是皇帝银库，东边体仁阁是缎库。
- **中和殿**：举行盛大典礼时皇帝的休息室，文武百官站好后皇帝再前往太和殿。
- **保和殿**：从乾隆五十四年开始作为科举考试殿试考场。东北角有汉字馆，内有4枚免费印章，可购买《紫禁城100》现场盖章，购买后不能去其他店铺盖章，汉字馆印章数量据说是最多的。
- **乾清门**：过此门即后宫生活区域，皇帝在此上早朝。东边九卿直房是等级高的大臣等待皇帝召见之处，西边是军机处。门口狮子耳朵耷拉、眉毛遮眼，警示后宫之人不该看的别看、不该听的别听。
- **乾清宫**：皇帝平时睡觉的地方，内有27张龙床，据说是为防止刺客找到皇帝位置。“正大光明”牌匾后藏皇帝立储诏书，皇帝写两份诏书，驾崩后对比验证是否被动过手脚。门口有铜鹤与铜龟，旁边有社稷江山金殿，是紫禁城里最小的宫殿，提醒皇帝把江山社稷放在第一位。
- **交泰殿**：内放25块传国玉玺。
- **坤宁宫**：皇后住所，明朝所有皇后都住这里。东北角文创店有5枚免费印章。
- **储秀宫**：慈禧住了20多年的地方，现为慈禧五十大寿时期原状陈列，慈禧喜欢此处因其子在此出生。旁边文创店有3枚免费印章。
- **翊坤宫、永寿宫、太极殿**：翊坤宫和永寿宫位于储秀宫南边，永寿宫西边是太极殿，为东西六宫中唯一被称为殿的宫殿。
- **慈宁宫、寿康宫**：慈宁宫是康熙为奶奶孝庄皇太后修建的养老院，旁边寿康宫是甄嬛（剧中人物）居住之处。附近有冰窖书吧，内有3枚免费印章，盖章时有批折子的感觉。
- **断虹桥**：网红打卡地，桥上有形态各异的石狮子，最有名的是“捂裆狮”。
- **武英殿**：后改为陶瓷馆，目前关闭状态，只能在门口看看。
- **文华殿**：位于东边，与西边武英殿对应“文东武西”，参观时未开放，据说现有一个展览。
- **箭亭**：清朝皇帝及子孙练习骑马射箭的地方，旁边商店可购买文创雪糕。
- **钟表馆**：展示那个年代的钟表造型。
- **珍宝馆**：即宁寿全宫，是乾隆给自己修建的养老院，退休后未放权仍每天上朝办公。门口有我国现存三座古代九龙壁之一，左边数第三条白龙下方有一块木头，据说是当年烧制琉璃时弄坏一块，工匠为保命用木头刷白漆以假乱真。皇极殿据说是1:1复刻乾清宫，宁寿宫对标坤宁宫，养性殿后为乐寿堂，是故宫里唯一能进去参观的皇家寝室，有二龙戏珠设计。再往后是珍妃井，当年慈禧把珍妃丢进去之处，现井口石非珍妃进入的入口。珍宝馆并非单独展厅，院子周围屋子都需参观，游客多，尤其看凤冠处拥挤。出口右手边商店有3枚免费印章。
- **东筒子夹道**：长长的夹道，拍照非常出片。
- **延禧宫、景仁宫**：延禧宫为网红打卡地，旁边景仁宫是甄嬛被封熹妃时住的宫殿，珍妃也住过。
- **御花园**：内有钦安殿，供奉真武大帝，紫禁城靠山景山从天上看酷似闭目盘坐的人像，有人说该造型就是真武大帝。
- **神武门**：故宫北门，出门左手边有两个盖章点，角楼咖啡有2枚免费印章，故宫文创有2枚免费印章。

# 互动与体验
- **排队检票**：主讲人建议早点过来排队，排队检票处即午门，可借此观察午门外观。
- **午门门洞观察**：从正面看午门有三个门洞，进门后变为五个门洞，即“明三暗五”结构。
- **铜狮子合影提醒**：太和门门口铜狮子为故宫六对铜狮中最大的一对，造型威武、脚踩寰宇，象征权力；主讲人建议不要站在狮子底下合影，因大爪子正好盖在头顶上，单独给狮子拍照即可。
- **汉字馆盖章**：保和殿东北角汉字馆有4枚免费印章，可购买《紫禁城100》由工作人员现场盖章；故宫内不止一处可买到《紫禁城100》，每家店印章不同，购买后不能去其他店铺盖章，需有所取舍；据称汉字馆印章数量最多，盖完后可选择邮寄到家或自行携带。
- **坤宁宫文创店盖章**：坤宁宫东北角文创店有5枚免费印章，主讲人提醒别错过。
- **储秀宫文创店盖章**：储秀宫边上有文创店，可免费盖章，共3枚免费印章。
- **冰窖书吧盖章**：冰窖书吧内有3枚免费印章，印章造型好，盖章时有批折子的感觉；主讲人已买了一本《紫禁城100》，在此又买了一个冰溪图。
- **断虹桥找狮子**：断虹桥上有形态各异的石狮子，其中最有名的是“武当狮”，游客可自行寻找其位置。
- **箭亭文创雪糕**：箭亭旁商店可买到文创雪糕，主讲人询问雪糕造型人物是谁，邀请观众在评论区分享。
- **珍宝馆参观体验**：珍宝馆虽名为“馆”但不是单独展厅，院子周围屋子均可进入参观；馆内宝贝令人惊艳，但游客非常多，尤其是看凤冠的区域，没点技术挤不进去。
- **乐寿堂参观**：乐寿堂是故宫里唯一能进去参观的皇家寝室，可看到二龙仙楼的设计，让人联想到恭王府和珅的卧室。
- **珍宝馆出口商店盖章**：珍宝馆出口右手边往里走有商店，可免费盖章，共3枚免费印章。
- **东筒子夹道拍照**：东筒子夹道是很多游客喜欢来拍照的地方，拍照非常出片。
- **神武门外盖章点**：神武门出门左手边有两个盖章点，角楼咖啡有2枚免费印章，故宫文创内同样有2枚免费印章。
- **三条游览路线选择**：主讲人总结三条游览路线供游客按自身情况选择——第一条走完视频内所有景点，适合打算待一整天的游客，建议早起排队、进门后沿中轴线往后走以错开旅游团，一天约走3万步，需注意适当休息和补充水分；第二条沿中轴线至坤宁宫后看景仁宫和延禧宫，再逛钟表馆和珍宝馆，出御花园后从神武门出，约半天逛完；第三条沿中轴线至坤宁宫后去储秀宫，再逛御花园，从神武门出，约2小时，最省力。
- **盖章点汇总提示**：主讲人标注了七个可免费盖章的位置，供喜欢盖章的游客截图保存。

# 收获与建议
## 收获与建议

- **择时与排队**：建议早起排队，一进门就沿中轴线往里走，可错开大批旅游团人群，等大部队到达时已把最重要景点逛完。
- **路线选择（全天线）**：走完视频内所有景点，适合打算在故宫待上一整天的游客，一天约走3万步。
- **路线选择（半天线）**：进门沿中轴线至坤宁宫，看景仁宫、延禧宫，逛钟表馆、珍宝馆，出御花园后从神武门出，约半天逛完。
- **路线选择（省力线）**：进门沿中轴线至坤宁宫，去储秀宫，出御花园后从神武门出，约2小时，最省力，适合时间有限、不想走太多路的游客。
- **盖章点（汉字馆）**：保和殿东北角，有4枚免费印章，可购买《紫禁城100》现场盖章。
- **盖章点（坤宁宫文创店）**：坤宁宫东北角，有5枚免费印章。
- **盖章点（储秀宫文创店）**：储秀宫边上，有3枚免费印章。
- **盖章点（冰窖书吧）**：有3枚免费印章，印章造型好，盖章时有批折子的感觉。
- **盖章点（珍宝馆出口商店）**：珍宝馆出口右手边往里走，有3枚免费印章。
- **盖章点（神武门外）**：出门左手边角楼咖啡有2枚免费印章，故宫文创有2枚免费印章。
- **盖章注意事项**：故宫内不止一处可买到《紫禁城100》，每家店印章不同，购买后不能去其他店铺盖章，需有所取舍；据称汉字馆印章数量最多。
- **饮食与休息**：游览过程中别忘了适当休息和补充水分。
- **拍照建议**：太和门门口铜狮子虽造型威武，但站在其下大爪子正好盖在头上，不建议合影，单独给狮子拍照即可。
- **珍宝馆参观提醒**：珍宝馆并非单独展厅，院子周围屋子都值得进去看；游客多，尤其看凤冠需挤进去。
- **陶瓷馆状态**：武英殿改成的陶瓷馆目前关闭，只能在门口看看；文华殿主讲人去时未开，据说现有一个展览，感兴趣可前往。
