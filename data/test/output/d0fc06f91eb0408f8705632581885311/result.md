# 复盘目标与结果概况
本次年会复盘2023年公司经营与团队表现。预期目标为总结发展状况、公布数据、评价员工并发放年终奖与奖项。实际结果：年终奖转账总额226,000元，全年支出390万元，利润率约24%或27%，成本控制差；最高工资（含年终奖）两三人到手20万元，平均工资1万多元；年终奖总额比去年多1312万余元，干满一年人数从四五人增至12人；公司总量提升但结余到账下滑，还有百来万未收回，老板承担亏损100万元。会上公布年终奖标准，逐人评价，颁发最佳新人、最佳进步、后期独当一面、最佳员工、特别贡献五项奖，并抽奖。

# 亮点事项
- 短视频账号运营取得显著增长：视频号粉丝从2023年3月1日70019人增至8万，小红书从2000+增至6.4万，抖音从2000+增至5.7万，B站从3.1万增至7.6万，涨粉自6月20日第一条外出拍摄视频起有起色。成功原因：郭东辉在潘老师多次提醒放弃的情况下坚持，并破釜沉舟说服外出拍摄，加上forty加入，最终突破。
- 账号变现课程拍摄达十分满分7.5分，直播每场平均在线5000人以上，虽重点项目未完成，但为软实力提升提供帮助。
- 后期团队整体技术提升：林海腾指出今年后期人员分级模糊、效率接近，整体技术有进步，硬着头皮安排没做过的人也能完成好。
- 张扬作为公司邀请人才，职业态度与工作能力基本达到期待，老板称2023年最有价值的事就是把他招进来。
- 刘腾宇获最高评价，职业性、专业性、纪律性最好，迟到几乎没有，请假严格按规定，工作安排提前告知，成为团队标杆。

# 不足事项
- 成本控制非常差：全年实打实支出390万元（含人员工资、外援配音字幕、租机器），利润率仅约24%或27%，非常不可观。根因：老板对成本关心或关注不够、不够雷厉风行，问题未及时解决。
- 公司结余到账往下跑，还有百来万未收回，老板每人比去年少拿约10万元，承担亏损100万元。
- 账号变现重点项目未完成，直播暂无课程可变现。
- 后期人员劳累程度高，今年尤其是后半年基本都在加班，很少正常休息。根因：老板未及时招合适人数，判断失误，人不够是最大因素。
- 外援成本高：钱德峰指出请外援价格与内部拍摄差很多，但公司凑不出人按机位、让机器不关机，内部人员多以没空、很忙、不想去推脱。

# 改进计划
- 成本控制问题明年开会再议，具体改进措施未明确，责任人无，时间无。
- 短视频部门：期待明年账号能开始变现，老板将投入更大精力并给予足够重视，责任人无，时间无。
- 执行部门：期待老板明年更多进行组织协调，提高效率，减少侵占休息时间，责任人无，时间无。
- 商务部门：老板承认今年给予的支持、管理或关心不够，明年会反思，并考虑给张启更多支持和帮助，责任人无，时间无。
- 拍摄参与：老板期待大家都能参与拍摄，明年往这个方向靠，提升个人市场价值，责任人无，时间无。
- 加班补贴：年终奖中考虑加班因素，补贴一两千元，已实施。
