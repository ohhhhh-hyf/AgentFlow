# 电子科技大学电子科学与工程学院招生宣讲会

## 沟通背景与目的
本次沟通为电子科技大学电子科学与工程学院面向考生及家长的招生宣讲直播，由学院多位教师及学生代表参与。沟通旨在介绍学院整体情况、学科方向与人才培养成果，解答考生和家长关心的报考问题，吸引优秀生源报考。整体基调为积极推介，各方向负责人依次介绍学科特色与科研实力，学生代表分享就读体验，并预告了夏令营安排与咨询渠道。

## 核心信息与数据
### 学院整体情况
1. **历史沿革**：1956年建校之初成立无线电系、电真空器件系、无线电零件系，经1979年、1992年、2001年、2018年4次院系调整成立电子科学与工程学院（示范性微电子学院），2023年响应国家号召成立电子科学与工程学院与集成电路学院。
2. **学科设置**：电子科学与技术为国家重点一级学科，下设电磁场与微波技术、电路与系统、微电子学与固体电子学、物理电子学、电磁信息功能材料与机构5个二级学科方向，另有电磁场与微波、军用关键材料、电子元器件3个国防特色学科。
3. **学生规模**：本科生现有1545人，招生专业为工科试验班（电子工程类），含电子科学与技术（国家特色专业、国家级一流本科专业建设点）和电磁场与无线技术两个专业方向；硕士和博士研究生1975人。
4. **师资队伍**：现有教师302人，其中教研系列139人、科研系列95人、教学系列14人、实验系列21人，教师总数269人，机关33人；两院院士2人、领军人才19人、青年人才28人、其他类型人才12人、博士后61人。
5. **科研经费与成果**：近5年科研经费到账稳定在3—4亿元之间，以纵向项目为主、横向项目为辅；牵头获国家科技奖励11项，发表高水平学术论文2000余篇，专利申请1600余件、授权1300余件。
6. **科研团队与平台**：共20个科研团队，年度经费过千万元团队15个、过亿元团队1个；拥有国家电子辐射控制材料工程技术研究中心、微波电子器件国家级重点实验室2个国家级平台，4个国际合作平台，7个省部级科研平台。
7. **国际交流**：共建国际姊妹院系2个（香港大学电机工程电子系、香港城市大学电子工程系），主办高水平国际会议13场，学生长短期交流项目20多个。
8. **党建荣誉**：学院党委入选教育部首批全国党建工作标杆院系，学院荣获全国教育系统先进集体；融合2个全国高校黄大年式教师团队，2022年获批4个国家自然科学基金创新群体。

### 电子信息材料与元器件方向
1. **方向定位**：以材料为基础、器件为核心、应用为目标导向，涉及电子材料与电子器件的设计、研制、生产和应用，涵盖电磁、声、光、热、力及化学生物等特性。
2. **国家需求背景**：2021年中国集成电路电子产品进口额度达2.8万亿元，约为原有进口量的1.7倍；先进电子材料、元器件、电路系统等电子产品属我国目前最为紧迫的卡脖子问题之一，在6G通讯、量子技术、智慧城市、光电技术、新能源、智能电子等领域起重要作用。
3. **邓龙江院士团队**：电磁辐射控制材料与技术团队，现有研究人员19人（正高13人、副高15人「原文如此」），发表包括Nature在内的论文300余篇，承担国家、省部级及国际合作课题130余项，年均到账经费3000多万元，授权发明专利100余项，获国家科技进步或技术发明二等奖共计3项。
4. **张怀武教授团队**：磁电薄膜与微型器件团队，现有研究人员17人（正高15人、副高2人），重点开展LTCC材料及集成技术、微波毫米波晶圆及器件、自旋电子与磁量子器件、传感器芯片等研究，承担国家重点研发计划、自然基金重点重大科学仪器项目、国际合作等项目100余项，发表SCI论文400余篇，获科技进步二等奖共计3项。
5. **研究条件**：科研面积2万余平米（其中超精尖3000平），建设2条国家重大任务试验生产线，拥有大型设备或系统500余台套；材料制备设备约50台套，微纳加工设备30台套，构建了材料—器件—电路—系统全链条研究平台。
6. **毕业生去向**：遍布产业界与学术界，包括英特尔、中芯国际、华为、德州仪器及高校科研院所；在读学生杨伟豪以第一作者在Nature Electronics、Nature Communications各发表论文1篇，5G滤波器芯片学生团队获挑战杯创新创业大赛四川省金奖。

### 电磁场与微波技术、电路与系统方向
1. **专业构成**：电磁场与微波技术包含微波毫米波电路、电波传播与电磁兼容、计算电磁学与工程电子学、天线理论与技术4个细分方向；电路与系统包含非线性电路与复杂电子系统、射频微波电路与系统、集成电路与系统3个方向。
2. **历史沿革**：电磁场与微波技术学科始于1956年建校时期，由林卫干先生和谢楚芳先生创建，形成电磁场与无线技术国家特色专业及电波传播与天线国防紧缺特色专业，所属一级学科电子科学与技术入选双一流A类学科。
3. **研究团队**：电磁场与微波技术有6个团队——电磁辐射与散射团队、毫米波技术与系统应用团队、微波毫米波集成电路与系统团队、电磁兼容技术团队、微波测试与成像技术团队、无线技术与集成系统团队。
4. **天线方向成果**：杨世文教授团队研究四维天线阵列技术，实现低成本高性能并提升系统整体性能，成果应用于中电14所某大型机载相控阵雷达；该团队在强耦合超宽带相控阵方面取得系列进展，在电磁测井仪器方面获国家科技进步二等奖1项并在中海油推广应用。
5. **毫米波与太赫兹成果**：樊勇教授团队研制出0.22THz、0.34THz、0.42THz雷达成像系统，分辨率小于1厘米；太赫兹通信成果于2023年成都大运会田径项目成功示范应用；延波教授团队引领微波毫米波太赫兹芯片研究，获国家科技重大专项及军科委项目支持。
6. **计算电磁学与测量**：杨世文教授团队计算电磁学相关算法被评为20世纪十大算法之一；李恩教授团队微波毫米波测量技术有60多年技术积累，在生物医学电磁学及成像方向发表大量高水平论文并有20余项国家发明专利。
7. **电路与系统学科**：1981年开始招收研究生和博士研究生，1988年成立首批博士后流动站；拥有教育部国际合作联合实验室、国家高等学校学科创新引智基地，国家级人才4人、新世纪人才2人、教授10人、副教授22人。
8. **人才培养**：连续三年获全国大学生集成电路创新创业大赛奖项，荣获华为优秀合作项目奖、研究生优秀导学团队提名奖；就业领域包括华为、中兴等行业领军企业及各研究所、高校。

### 物理电子学方向
1. **学科定义**：物理电子学是物理学与电子科学技术的交叉学科，将物理学最新研究成果应用于电子学，产生新型电子器件；学科边界不十分清晰，如光电子学既可属物理电子学也可属光学工程一级学科。
2. **学科特点**：具有基础性与前沿性，数理基础要求高，所生成的电子器件是信息科技产业的重要支撑，是支撑现代信息技术的关键技术学科。
3. **研究拓展**：纵向发展覆盖上游仿真设计（数字、模拟材料）到下游系统应用；横向发展包括频段上移至太赫兹及与医学交叉；拥有自主知识产权商用软件MMST和切皮克，并将人工智能引入器件设计和电子学应用。
4. **系统应用**：利用功率器件研制毫米波雷达（回旋行波管），用行波管做无线输能系统，用磁控管做微波能干燥系统。
5. **科研经费**：每年科研经费接近2亿元，为学院最多；2023年成功举办行业顶级会议。
6. **学生出口**：团队学生约1/3硕博连读、1/3去企业、1/3去研究所或其他单位。

### 学生视角分享
1. **选择理由**：成都为四川省会、国家中心城市、新一线城市，电子信息产业发达；电子科技大学电子科学与技术学科在第4轮学科评估中获A+，稳居全国第一。
2. **团队情况**：学院拥有四大学科和19个科研团队；田雨桐所在毫米波技术与系统应用团队负责人为樊勇老师，团队硕博毕业生就业率100%。
3. **奖助体系**：学院奖助体系全覆盖、高额度、长周期，包括国家奖学金、学业奖学金等；另有生源地直营助学贷款。
4. **选导师建议**：根据研究方向先选研究团队再选导师，可通过学院网站及Web of Science、中国知网等文献检索网站查询导师论文和指导研究生毕业情况，提前沟通交流。
