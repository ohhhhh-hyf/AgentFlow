# 核心概念
## **GitHub 资源库定位**
GitHub 不只是全球最大的同性交友平台，更是每个人都可以用的巨大宝藏资源库，几乎想找的资源、教程、工具都能找到。正经资源包括麻省理工、斯坦福等名校公开课，字节、阿里、腾讯等大厂的面试题和面试经验，Google、阿里等大公司最新的开源大模型，用 AI 搞副业赚钱的教程，AI 学习资料等；不正经资源包括国内这些年全网火爆的表情包大合集、活到 150 岁养生指南、国内 996 最严重的大厂黑名单等。

## **实用热门项目**
- **B 班值不值得上**：评估工作性价比，输入年薪、工作地区、年假、通勤时长、学历、工作年限及领导同事是否 SB 等因素，综合给出工作性价比分数和评级。
- **表情包博物馆**：国内过去这些年全网爆火的表情包大合集，包含甄嬛传、罗翔老师、特朗普、马保国等表情包。
- **活到 150 岁指南**：分享经过科学研究证实的健康知识，如间歇性进食对身体有好处，会促进胆汁代谢、炎症自愈；吃天然发酵类食品可以改善肠道菌群生态等。
- **一键做证件照**：上传一张大头照即可一键抠图换背景，生成不同标准的证件照和各种规格的打印模板。
- **丐版健身教练**：可选择自重、哑铃、弹力带、长凳等，选择要练习的肌肉群后给出用身体自重练习的参考动画。
- **PDF 教材合集**：收集国内所有小学、初中、高中一部分大学的 PDF 教材，全部免费用。
- **全自动视频生成项目** `Morning Printer Turbo`。
- **声音克隆模型** `ChatTTS`：零样本语言克隆，情感控制非常到位，克隆的声音就像真人说话一样。
- **AI 学习资源库**：涵盖大语言模型、RAG、AI Agents、MSI 等最新 AI 技术，教程内容整理成一份 500 多页的 PDF 文档，含大量示意图。
- **awesome AI apps**：收录大模型最新的 agent 应用，如医学影像数据分析的 agent、AI 投资的 agent、竞争对手情报分析 agent 等。

## **GitHub 访问加速方法**
- **Watt Toolkit 加速软件**：进入网站选择适合电脑的版本下载安装，打开后找到网络加速勾选 GitHub 加速，即可流畅上 GitHub。
- **GitHub 镜像站**：如 `gh proxy`，浏览器点开就直接上 GitHub，默认是镜像的项目地址，搜其他项目也没问题。
- **魔法**：个人最推荐的方法。

## **GitHub 页面汉化**
给浏览器装翻译插件，推荐谷歌 `Translate` 或 `沉浸式翻译`，装好后可直接把网页翻译成中文；动手能力强的还可给浏览器安装汉化插件。

## **GitHub 搜索技巧**
- **原生搜索**：按搜索词精准匹配，搜 `screen record` 和 `screen recording` 按星标排序结果不一样。
- **AI 搜索**：推荐用 ChatGPT 等工具，用中文指令如“在 github 上帮我找好用的录屏软件”，能搜全热门录屏工具并总结成表格。

## **项目主页功能与热门项目跟踪**
- **项目主页功能**：`star` 相当于收藏和点赞，`watch` 是关注项目，`fork` 是复制项目，`about` 是项目简介，`release` 是软件安装包，`readme` 是项目说明书，`commit` 日期可理解为最近更新时间。
- **跟踪热门项目**：点开左侧 `explore`，在 `trending` 里能看到全站当天、本周、本月最热门的项目；也可用 ChatGPT 找 `github daily`。

# 核心结论
GitHub 是每个人都可以用的巨大宝藏资源库，几乎想找的资源、教程、工具都能找到。国内访问 GitHub 卡顿难，可用 Watt Toolkit 加速软件、gh proxy 等镜像站或魔法解决，其中 Watt Toolkit 更流畅，镜像站速度稳定性较差，个人最推荐魔法。页面满屏英文可装谷歌 Translate 或沉浸式翻译插件汉化。原生搜索按精准匹配，搜 `screen record` 与 `screen recording` 结果不一致，推荐用 ChatGPT 等 AI 工具以中文指令搜索。项目主页的 `star`、`watch`、`fork`、`about`、`release`、`readme`、`commit` 日期等功能需了解；跟踪热门项目可看 `explore` 的 `trending`，或用 ChatGPT 找 `github daily`。所有开源项目、教程及视频未提到的项目都整理在文档里，需要的可以三连关注免费领取。
