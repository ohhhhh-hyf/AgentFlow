# 沟通概况
班主任林瑞在372班家长会上与家长沟通，班级共60人，男生25人、女生35人，学生处于青春期不稳定时期。老师反馈班级亮点为时间观念执行力强、班风良好，需关注之处为少数同学周末玩手机、自习课效率低、个别学生书写不良、有学生带镜子及谈恋爱等问题。会议明确费用由学生交给生活委员、不在微信群转账，并提醒防诈骗；要求手机统一上交并贴名字，家长配合检查。后续将加强思想教育、制定详细班规、严格请假制度，并建议家长多关注学生心理健康、注意安全、创造良好家庭环境。家长代表张宇波分享家庭教育经验，强调关注孩子身心健康、尊重孩子、多倾听交流、配合学校工作。班主任建议成立家委会，至少三人，家长自愿报名，有家长响应。另说明保险可自行购买，电子学生证套餐78元（移动套餐满78元可办理），高中资助补助打在医保卡上，提醒家长注意孩子使用。

# 沟通内容
**亮点**：班级时间观念执行力强，班风班貌纪律良好，地面干净、卫生好；多数学生能主动向老师请教问题。**需关注之处**：少数同学周末玩手机、有网瘾，自习课效率低、老师不在时纪律差；个别学生书写不良需练字；有学生带镜子、看小说、谈恋爱；个别学生生活费使用不当，存在乱花钱现象。

# 家长反馈
家长代表张宇波（372班语文老师）分享家庭教育经验，强调关注孩子身体健康和心理健康，认为高中阶段仍是长身体关键时期；主张先做人再成才，家长要有平常心，尊重孩子、给孩子自由空间，多倾听多交流，配合学校制度与老师工作。她提到自己对孩子说：'无论怎样，你都是爸爸妈妈心里最优秀的儿子'，认为先肯定再批评效果更深刻。
