# 就诊概况
48岁男性患者张学恒，职业为科研工作（成都轻工研究所），因上腹反复疼痛4年、近3个月加重就诊于消化专科，为初诊。患者主诉心窝部烧灼样疼痛，进食冷硬食物或工作紧张时诱发，近3个月疼痛可忍受，无夜间痛醒；近4年出现两次黑便（1年前、3个月前），每次持续约1个月，两次均住院诊断为大便出血；近2个月呕吐数次，吐出黄水样酸味物。既往有甲肝病史（已愈）、磺胺药过敏史；近期服用奥美拉唑（武汉药厂产）和阿莫西林，效果不佳。初步考虑消化系统疾病，需进一步检查明确，已预约胃镜。

# 病史与背景
- **现病史**：上腹疼痛4年，每年春季多发，近3个月持续；疼痛位于心窝部，有烧灼感，进食冷硬食物或工作紧张时诱发，暖和、工作轻松时无痛；近3个月疼痛可忍受，无夜间痛醒。
- **黑便史**：近4年出现两次黑便，分别于1年前和3个月前，每次持续约1个月，每日最多2次，大便性状正常仅颜色改变；两次均住院检查诊断为大便出血，住院2-3天后大便转黄。
- **呕吐**：近2个月呕吐数次，吐出黄水样酸味物，含早中餐食物，晚间腹胀时呕吐后缓解。
- **既往史**：16岁时患甲肝，在三医院住院1个月，出院后肝功能正常；小时候因扁桃体炎在成都市儿童医院就诊，服用磺胺药后左手出现红疹，持续半个月，确诊磺胺过敏。
- **个人史**：双眼近视400度，偶有口腔溃疡；吸烟史，以前每天1包，现限制在10支以内；饮酒少量，平时不喝；工作紧张，经常加班熬夜。
- **家族史**：父亲76岁有低血压，母亲75岁有冠心病，弟弟身体健康；婶婶（无血缘关系）患胃癌。
- **近期用药**：近期服用奥美拉唑（武汉药厂产）和阿莫西林，效果不佳，现每日4-5次；有时服用医务室自配胃炎合剂。

# 诊断与检查结果
尚未确诊，需进一步检查明确。患者有两次黑便史，需排查消化道出血；医生建议留大便检查，并预约胃镜。患者担心是否患胃癌，医生解释婶婶（无血缘关系）的胃癌与患者无直接关联，但需进一步检查。
