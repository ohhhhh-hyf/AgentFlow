# 沟通概况
班主任林瑞在372班家长会上，围绕班级基本情况、教师团队、存在问题及解决思路、给家长的建议、家长代表分享、家委会成立及保险、电子学生证、资助等事项，与家长进行了沟通。班级共60人，男生25人、女生35人；班主任林瑞任教地理学科，教师团队多为有3年以上经验的老教师、优秀教师。会议重点讨论了手机管理、自习纪律、书写、网瘾、早恋等问题，提出加强班规管理、家长配合检查手机等解决思路；同时提醒家长避免教育误区，关注心理健康与安全教育。家长代表张宇波分享了家庭教育经验，强调先做人再成才、尊重孩子、多倾听多交流。会议还提议成立至少三人的家长委员会（已有家长自愿报名），并说明保险（约310元，可自行购买）、电子学生证（移动套餐78元）及高中补助发放至医保卡等事项。

# 沟通内容
## 亮点

- **时间观念与执行力**：整体来看，班级时间观念和执行力度较强。
- **班风班貌**：班风、班貌、纪律良好，教室地面干净，卫生状况好。
- **学习主动性**：学生遇到问题会积极上来问老师，班主任提到“他们遇到问题了，他们会积极的上来问”。
- **尊师表现**：学生非常关注老师，都会主动问老师，会给老师汇报情况。
- **书写表现**：部分学生写字不错，可从学生手册和架构书中看到。

## 需关注之处

### 学习方面

- **书写问题**：个别学生书写差，班主任已与家长沟通，建议家长给孩子买字帖练字；有学生把“372班”写成“172班”，字迹难以辨认。
- **自习课效率低**：自习课效率较低，班主任在时学生表现乖，不在时乱哄哄；需加强班委培训和管理，计划给学生10分钟讨论时间，有不懂的可离开座位去问。
- **思考能力**：少数学生思考能力较差，尤其在自习课上表现明显。
- **成绩比较**：班主任提醒家长不要拿孩子成绩与其他人比较，要帮助孩子分析成绩下滑或进步的原因。

### 手机与网络管理

- **周末玩手机游戏**：少数同学周末玩手机游戏，玩累了导致懒散，约有两三个学生手机依赖严重。
- **网瘾问题**：有少数男生有网瘾，曾发现学生星期六晚上充值游戏，有充400元的，还有更多。
- **观看不健康内容**：发现有男生观看不健康直播内容，班主任提醒家长检查手机里装的东西。
- **手机上交管理**：要求手机上交，专门设置手机存放箱，每人名字贴好；家长可不定时打电话检查手机是否开机，若打通没人接说明手机未交。
- **多部手机问题**：有学生有两部手机，家长家里可能还有五部手机，班主任要求家长处理多余手机，不要留多部，防止学生拿旧手机上交、留好手机使用。

### 行为与社交

- **早恋现象**：存在早恋现象，班主任建议家长关注孩子的QQ、抖音、快手等社交账号，查看是否有异常，注意孩子可能屏蔽家长。
- **携带违禁物品**：班主任在抽屉里发现有同学带镜子，要求全部收掉，涉及约10人。
- **生活费使用不当**：少数学生生活费不是用于学习和就餐，而是用于非正常消费；有学生一周多次向家里要钱，实际用于其他用途。
- **住校纪律**：有男生周六住校期间外出过生日，喝酒回来一身酒气还抽烟、玩手机；住校生周六也需遵守纪律要求。

### 安全与健康

- **交通安全**：未满16周岁骑电动车非常危险，有学生载两三个同学，班主任提醒家长注意。
- **心理健康**：学生处于生理心理持续变化阶段，是人生中不稳定时期，需关注心理动态，发现异常及时进行心理辅导。
- **防溺水与防诈骗**：提醒注意防溺水，不能私下结伴游泳；注意防诈骗，班主任强调不会在群里收取任何费用，提醒家长和学生防范电信诈骗。

# 家长反馈
- **家长代表分享**：家长代表张宇波（兼1372班语文老师）分享家庭教育经验，强调关注孩子身体健康和心理健康，教育孩子先做人再成才，家长要有平常心，尊重孩子、给孩子自由空间，多倾听多交流，配合学校制度、尊重老师。
- **家长诉求**：家长代表张宇波提出希望孩子在学校不断进步成长，并坦言自己"没有主动参与"孩子教育，感到不安，希望与各位家长交流经验、抛砖引玉。
> "我觉得做妈妈真是难，觉得应该再走一步，一直想，但让我感到不安的是，我本身没有主动参与，很多很多的话，也不是在在座的家长教育里面都有。"
> "要想让孩子离开，就要让他们学会怎么样做人，千万不能让他们带上不良的风气。"
> "无论怎样，那你都是爸爸妈妈心里最优秀的儿子，你先批评他，还是不当，这样的话他会更加的深刻。"
  - 孩子面临的学习压力很大，面对挫折和失败时家长应帮助孩子重新定位，放下眼前、向往更远风景
  - 家长应尊重孩子，给孩子自由空间，不要轻易给孩子下消极评价
  - 要多倾听、多交流，给予孩子更多关爱与理解
  - 家长应配合学校制度、尊重老师工作

# 共识与配合事项
## 费用与收费

- [ ] **家长**：水费按每两周2元/人标准收取，若实际用水超出预算再另行通知补收
- [ ] **家长**：书费已预交11000元，目前购买5本书尚未结算，待结算后多退少补
- [ ] **家长**：未购买书箱的同学，相关费用将退还
- [ ] **家长**：少数同学存在无效费用约100元，其中约70元可退；另有约120–123元费用待班主任核算后统一公布明细
- [ ] **家长**：所有费用由学生直接交给生活委员，不在微信群内转账缴费
- [ ] **家长**：警惕冒充班主任头像在群内收费的诈骗行为，任何群内收费消息均不可信

## 保险

- [ ] **家长**：建议为学生购买保险，费用约310元，可自行选择购买渠道（学校宣传单、校外、阿里巴巴平台等）
- [ ] **班主任**：会后统计各班学生保险购买情况，未购买者需确认原因

## 电子学生证

- [ ] **家长**：可办理移动电子学生证套餐，月费78元，方便请假联系及日常沟通
- [ ] **家长**：班级现有3个座机号码中，2个已停机（1个因诈骗电话多被停机、1个用班主任身份证办理未处理），1个将于今年9月20几号到期，能办理的尽量办理
- [ ] **班主任**：将把新的号码发到家长群，供家长重新登记补充

## 资助政策

- [ ] **家长**：高中阶段所有补助直接打入学生医保卡账户，与初中（营养餐和生活补助直接上卡）不同
- [ ] **家长**：每次补助到账后，与孩子确认资金用途（生活费或交回家长），防止用于买手机、过生日请客、喝酒抽烟等非学习消费
- [ ] **家长**：相关资助政策文件已发至家长群，请自行查阅了解

## 手机管理

- [ ] **家长**：要求学生上交手机，每人手机贴好名字放入手机存放箱
- [ ] **家长**：家中多余的手机（如家里有5个手机的情况）处理掉或收好，只留一部可用手机，避免学生拿旧手机顶替上交
- [ ] **家长**：周一到周五不定时拨打学生电话，若电话能打通但无人接听，说明学生未按时上交手机
- [ ] **家长**：关注学生书包、抽屉等是否藏有手机
- [ ] **家长**：关注学生QQ、抖音、快手等社交账号（可能有多个账号），留意是否被屏蔽、是否发布异常内容
- [ ] **家长**：关注学生是否观看不健康直播、是否有网瘾（有男生曾观看不健康直播，有学生生活费充值400元用于游戏）
- [ ] **班主任**：加强手机管理，发现未交手机的学生按规定处理

## 住校纪律与安全

- [ ] **家长**：提醒住校学生周六住校也须遵守就寝纪律要求（有男生过生日喝酒、抽烟、玩手机被查）
- [ ] **家长**：提醒学生注意交通安全，未满16周岁不得骑电动车，尤其不得载人（载2–3人非常危险）；如实在要骑只能一人骑
- [ ] **家长**：提醒学生注意运动安全、饮食安全、防诈骗、防溺水
- [ ] **家长**：关注防校园欺凌，学生遇到问题第一时间联系班主任处理
- [ ] **班主任**：学生无小事，再小的事班主任都会管好、教育好

## 学习与行为习惯

- [ ] **家长**：查看学生手册中作业书写情况，书写差的同学到文具店买字帖练字
- [ ] **家长**：关注学生自习课效率，配合班主任加强管理
- [ ] **家长**：提醒学生上课不懂就问，主动请教老师
- [ ] **家长**：不要拿孩子成绩与他人比较，要帮助分析成绩下滑或进步的原因，正确引导
- [ ] **班主任**：加强班委培训，提升自习课纪律管理
- [ ] **班主任**：继续加强思想教育，制定详细班规（该扣分扣分、该写检讨写检讨、该罚站罚站），严格请假制度，稳定学习秩序
- [ ] **班主任**：定期与家长沟通学生在校表现，及时反馈问题

## 家庭教育配合

- [ ] **家长**：避免教育误区——不过分关注孩子、不放任不管、不期望过高、不给过多零花钱（有学生生活费过高，一周400元，用于买手机或游戏）
- [ ] **家长**：多与孩子沟通，多鼓励少批评，关注心理健康，发现异常及时进行心理辅导
- [ ] **家长**：合理安排孩子饮食，注意补充营养
- [ ] **家长**：为孩子创造和睦、祥和、稳定的家庭氛围，不在孩子面前争吵
- [ ] **家长**：不在家里聚众打麻将、点外卖，不常备客人，避免影响学习环境
- [ ] **家长**：不当着孩子面长时间玩手机
- [ ] **家长**：给孩子制定容易达到的小目标（如年级排名120名到30名范围内），激发潜能
- [ ] **家长**：控制孩子生活费在合理范围（早餐约3–4元、午餐8元、晚餐8元，一周5天不超过150元），避免孩子买面包、牛奶等非必要消费
- [ ] **家长**：教育孩子感恩父母，可用零花钱给父母买小礼物（袜子、手套等）
