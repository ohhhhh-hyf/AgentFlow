# 研讨背景与议题
本次圆桌论坛由发言者2（主持人）主持，邀请多位学术界与产业界嘉宾参与，围绕具身智能领域的关键技术问题与发展趋势展开讨论。与会者来自机械、计算机视觉、强化学习、产业投资等不同方向，包括发言者3（机械领域）、发言者4（薛寒，柔性体操作）、发言者5（王岳，强化学习）、发言者6（赵昊，世界模型）、发言者7（赵昊，产业视角）、发言者8（志龙，强化学习）、发言者9（薛寒，强化学习）、发言者10（业界嘉宾）、发言者11（静波/杨立新，数据采集）等。讨论覆盖具身智能形态与硬件期待、融资与产业前景、世界模型、强化学习与模仿学习路线、数据采集与仿真等议题，观点碰撞激烈，未形成统一决策。

- **具身智能的形态与硬件期待**：探讨具身智能最终收敛形态，以及硬件寿命、可靠性、软硬件协同等核心痛点。
- **融资与产业前景**：分析具身智能作为万亿级市场的融资规模与多波增长预测。
- **世界模型**：讨论世界模型的定义、是否需要3D inductive bias，以及CV与RL视角的差异。
- **强化学习与模仿学习路线**：探讨两种策略学习主流的优劣与融合方案。
- **数据采集与仿真**：讨论真机数据与仿真数据的成本、质量与规模化方案。

# 核心观点
**具身智能形态与硬件**
- **发言者3**：提出形态收敛问题，类比星际穿越中的变形机器人，并分享机械智能观点，认为软手可通过摩擦和顺应性在误差较大时仍抓得牢。
- **发言者4（薛寒）**：强调硬件需寿命长、可靠性高，现有工业机械臂不适合大规模真机评估，需个人柔顺硬件结构支持scale up。
- **发言者2**：认为具身是软硬件协同优化范式，松灵第二代产品在遥操和策略部署上优于第一代，凝胶夹爪可反馈触觉且更稳。
- **发言者5（王岳）**：认为大模型直通硬件会消除硬件迭代可能性，应分层，大脑不变、小脑adaptive到肢体。
- **发言者6（赵昊）**：认为人形机器人和特种机器人将并存，提及马斯克公司花一半精力做22自由度灵巧手，车厂和微电子制造厂机械臂自动化率超97%。

**融资与产业前景**
- **发言者7（赵昊）**：认为具身智能是手机和汽车之后的第三个万亿级市场，当前10亿融资相比自动驾驶、大模型、互联网仍很小，预测过年后融资将进入低谷，随后经历与自动驾驶、大模型、互联网规模相当的多波增长，技术突破决定变革到来时间。

**世界模型**
- **发言者8（志龙）**：追溯世界模型概念至1990-91年Sutton的dyna Q文章，提及2018年Schmidhuber和LeCun定义的表征与转移两个组件，强调可交互是强化学习世界模型的第一要义。
- **发言者7（赵昊）**：认为CV界追求重建物理世界，可作为RL中world models的工具，RL领域不太关注三维表征是学术发展阶段导致的现状；讨论inductive bias与数据量的权衡，梦想写一篇data bias trade off论文。
- **发言者5（王岳）**：提出世界模型可能无法同时建模游戏和物理世界的dynamics，因为输入相同但输出不同，但policy可能统一，因为人可以在游戏中跳楼但在现实中避免。
- **发言者9（薛寒）**：认为CV世界模型不必要，强化学习的世界模型只需帮助学策略，并讨论不同物理结构可能有统一表征。

**强化学习与模仿学习路线**
- **发言者2**：提到派零团队收集近万小时数据后仍看到模仿学习瓶颈，语言模型最后有RLHF环节，o1引入思维链和MCTS。
- **发言者10（业界嘉宾）**：公司采用模型强化加机理融合方式，认为监督学习数据分布不足以覆盖高维动作空间，纯强化学习不能很好sim-to-real迁移，其强化PC工作上层用强化学习做决策，底层用MPC或DWA等传统方法。
- **发言者9（薛寒）**：认为复杂任务应先模仿后强化，单独模仿或单独强化都不行，提及AlphaStar和GPT都是先模仿后强化。
- **发言者5（王岳）**：认为PID有反馈，可作为强化学习的reward。
- **发言者11（静波）**：认为模仿学习和强化学习不冲突，只是想要运动先验，有数据可用模仿学习，无数据可用强化学习生成。

**数据采集与仿真**
- **发言者2**：提到Open X和Joy数据集数据质量较差，自己受ego4d数据集毒害，洗数据洗了三个月，数据金字塔中互联网数据在最底层。
- **发言者11（杨立新）**：认为视角影响模型policy表现，标定非常重要，Open X数据集不关注物体，缺少物体运动信息，其ORKIN数据集记录物体运动，但设备有限只能采集刚体和关节体。
- **发言者4（薛寒）**：all in reward采集路线，提到柔性体操作任务如叠衣服，现有仿真需要IPC等先进技术，算力要求高，UCLA蒋正凡老师做高性能仿真技术，认为reward数据是低成本方案，大自然是最好的仿真器，可穿戴式设备是能scale的方案，终极形态可能是脑机接口，互联网视频数据与机器人所需数据不同。
- **发言者2**：分享仿真数据与真机数据结合的经验，300条仿真数据加20条真机数据可显著提升成功率。
- **发言者7（赵昊）**：认为真实数据与仿真数据的选择应看成本，并提议加入无标注真实数据作为第三个domain，认为2025年应推广大规模利用无标注数据。

# 达成共识与解决方案
**未形成统一结论**。本场倾向性认识包括：
- **软硬件协同优化**：发言者2、发言者5等认为具身智能需软硬件协同，大模型不应直通硬件，应分层（大脑不变、小脑adaptive）。
- **混合策略学习路线**：发言者9、发言者10等认为复杂任务应先模仿后强化，单独模仿或单独强化都不行，业界采用模型强化加机理融合方式。
- **数据采集多元化**：发言者4、发言者7等认为真机数据与仿真数据应结合，并考虑无标注真实数据作为补充。
- **解决方案**：发言者10公司采用模型强化加机理融合，上层强化学习做决策，底层用MPC或DWA等传统方法；发言者2提到300条仿真数据加20条真机数据可显著提升成功率。

# 未决分歧与后续探索
- **具身智能形态**：发言者3提出形态收敛问题，发言者6认为人形和特种机器人将并存，发言者5认为大模型不应直通硬件，需验证最终形态与硬件迭代的关系。
- **世界模型是否需要3D inductive bias**：发言者7认为数据多时需要的inductive bias少，数据少时需要的多，发言者9认为CV世界模型不必要，需验证数据规模与inductive bias的权衡。
- **世界模型能否统一**：发言者5认为世界模型可能无法同时建模游戏和物理世界的dynamics，发言者9提出不同物理结构可能有统一表征，需验证M个独立模型与统一模型的复杂度。
- **强化学习与模仿学习最终路线**：发言者9认为应先模仿后强化，发言者10认为需混合多种方式，发言者11认为两者不冲突，需验证单独模仿或单独强化是否可行。
- **中国仿真系统是否强依赖英伟达生态**：发言者2提出此问题，发言者7提到宋应等做国产替代，需验证国产仿真系统的可行性。
- **如何保证数据采集的高质量**：发言者11强调视角和标定，发言者4提出可穿戴式设备，需验证规模化数据采集方案。
