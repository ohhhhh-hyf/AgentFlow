# 课程概况
本次课程为历史小论文写作指导课，围绕观点明确、论证充分、结构清晰等要求展开。教师强调小论文必须亮明观点，观点需有凝聚力，不能只是简单陈述形式或几个方面加名词；论证部分一般写两到三条，不宜过多或过少。写作顺序为先写背景学术报告，再写自己的观点，最后进行论述升华；论述时逻辑要清晰，可用序号或按时间脉络（如700时期、明清时期）、国内外、内衣外衣等维度罗列，最后总结升华观点，不能简单重复观点。课程讲解了自命题类、观点提示类、图表信息类三类题目的解题步骤与方法，并点评学生习作，指出常见问题。

# 核心知识点梳理
## 小论文写作基本要求
- **观点明确**：必须亮出观点，不能只是简单陈述形式或几个方面加名词，观点要有凝聚力。
- **论证条数**：一般写**两到三条**，不宜过多或过少，否则无法支撑论点。
- **写作顺序**：先写背景学术报告，再写自己的观点，最后进行论述升华。
- **逻辑清晰**：可用序号或按时间脉络（如700时期、明清时期）、国内外、内衣外衣等维度罗列，让老师看清条理。
- **论述升华**：最后论述要升华观点，不能简单抄一遍观点。

## 自命题类题目解题步骤
- **审题**：先阅读题目，注意要求中的“小红帽”和形成标准，如要求用世界史知识或限定范围。
- **读材料**：认真读材料，抓主要信息，细看材料间关系。
- **列事实**：先写题目，再罗列事实，事实要与材料相关，不能乱罗列。
- **行文**：控制篇幅，先写题目，再罗列事实，最后进行论述。
- **案例**：武汉长江大桥例题中，学生未充分审题，背景与措施混淆；对内改革与对外开放应按时间顺序，先写对内改革，再写对外开放。

## 观点提示类题目解析
- **选择观点**：先看观点，选择核心观点，明确表述自己的判断，不能照抄材料。
- **例题背景**：1940年抗战时期某书，包含四个观点，学生选择第二条进行评析。
- **论证内容**：涉及政治、科技、文化，如丝绸之路、四大发明对欧洲的影响。
- **关键点**：不能重复材料观点，需有自己的理解。

## 图表信息类题目解析
- **看图表**：快速看图表关键信息，如题头、横向纵向信息。
- **分析关系**：注意信息间关系变化，提取有效信息进行分析。
- **案例**：民德与制度关系，如唐朝国力强盛但民德不高，宋朝民德繁盛。
- **官方答案**：引用梁启超观点，强调“人人独善其身，人人相善其群”。

# 课堂互动与答疑
**问**：武汉长江大桥例题中，学生如何理解材料？
**答**：学生认为材料通过一个计划和一个减少，体现新中国成立对澳门的重要作用，但教师指出其审题不细，背景与措施混淆。
延伸思考：审题时需明确题目要求，区分背景与措施。

**问**：观点提示类题目中，如何论证本国历史了解的重要性？
**答**：学生选择第二条观点，论证涉及政治、科技、文化，如丝绸之路、四大发明对欧洲的影响。
延伸思考：论证需结合具体史实，不能空泛。

**问**：图表信息类题目中，如何解读民德与制度关系？
**答**：学生解读材料，讨论图表反映的历史现象，如唐朝国力强盛但民德不高，宋朝民德繁盛。
延伸思考：需注意图表信息间的关系变化。

> 教师提醒：写小论文时，观点要明确，论证要清晰，最后要升华观点，不能简单重复。

# 课后任务与学习建议
**任务**：完成小论文写作，注意观点明确、论证充分、结构清晰，论证部分写两到三条。
**建议**：审题时注意要求中的“小红帽”和形成标准；读材料抓主要信息，细看材料间关系；先写题目，再罗列事实，最后行文。
**建议**：观点提示类题目需选择核心观点，明确判断，不能照抄材料；图表信息类题目需快速看图表关键信息，分析关系变化。
