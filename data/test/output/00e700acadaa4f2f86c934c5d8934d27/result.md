# 沟通内容
**亮点**：整体来看，第一个月时间观念执行力加强，班风关系全部良好，班风纪律非常好，地面干净，卫生良好；写字还是不错的，学生手册可查看；老师多数是老教师、优秀教师、师范院校毕业，有3年以上经验，部分6年以上，各科老师认真备课、用心上课、关爱每一位学生。**需关注之处**：少数同学周末玩游戏、懒散，思考能力比较差，自习课纪律差，班主任在时较乖、不在时乱哄哄；个别学生行动时间方面有问题，书写需练字，建议家长买字帖；自习课效率比较低；存在玩手机、看小说、镜子、微信、网瘾、打游戏充值400元、直播、不健康内容、谈恋爱、QQ、抖音、快手等情况；手机管理要求每个手机贴名字，家长处理掉多余手机，周一到周五不定时打电话检查手机是否开机；班主任将加强人员管理和班委培训，自习时给10分钟讨论，继续加强思想教育，制定详细班规，严格请假制度，定期沟通。

# 家长反馈
家长代表张宇波校长分享家庭教育经验：要控制孩子的身体健康和心理健康，高中阶段仍是长身体的关键时期；先做人，让孩子学会做人，千万不能带上不良风气；家长对待孩子要有平常心，孩子面临的学习压力很大，对挫折和失败要帮助孩子重新定位；要尊重孩子，给孩子自由空间，不轻易下消极评价；多倾听、多交流，把更多关爱与理解给孩子；遵守学校制度，配合老师工作。张宇波校长原话：> 无论怎样，那你都是爸爸妈妈心里最优秀的儿子。班主任林瑞反馈家长需配合支持占30%，建议避免过分关注孩子、认为孩子不需要学习、过分期望、放任不管、给过多钱等误区，关注心理健康、交通安全（未满16周岁骑电动车非常危险，可能载两三个）、运动安全、饮食安全、防诈骗、防溺水、防校园欺凌，学习上不懂就问、不与他人比较，创造良好环境、和睦家庭气氛、制定小目标、多鼓励少指责。
