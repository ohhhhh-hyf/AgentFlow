# 访谈概述
本期《锵锵三人行》围绕日剧《大奥》与《明朝那些事儿》展开，主持人窦文涛与嘉宾马先生、当年明月（石悦）共同探讨中日文化差异及明朝历史。节目先讨论《大奥》的历史背景，认为该剧反映日本从晚明至清初再到明治维新前的历史，并指出日本文化具有极端精神，强调做事做到极致，忠诚文化体现在具体行为中，如剧中阿福40年不出于私心、完全公心。随后话题转向明朝历史，当年明月解释自己写明史是因为明史资料最多，但同一事件常有多个不同说法，如同罗生门；他推崇朱元璋，认为其从乞丐到皇帝是人才决定论的体现，并强调历史经验教训难以直接套用，因为后人并不比前人聪明。嘉宾还讨论了明朝兴亡的经验，认为明末江南市民生活富足，艺术与工艺精细，但李自成起义源于陕西灾荒；同时指出明朝历史跌宕起伏，皇帝行为多样，如正德皇帝被后世评价偏低，可能因嘉靖朝修史存在偏颇。

# 访谈详细记录
议题一：日剧《大奥》与日本文化
- 马先生认为《大奥》是继《大长今》之后最有影响的外国电视剧，拍摄极好，反映日本从晚明到清初，再到明治维新前的历史，是一部有跨越性的历史剧。
- 当年明月表示被该剧吸引是因为其严谨精神，指出日本历史剧中群众演员不会笑，而中国历史剧如《三国演义》中群众演员会笑。
- 马先生描述《大奥》第一集片头将军出场时，所有人呈45度鞠躬，场面华丽，色彩鲜明，令人震撼。
- 窦文涛欣赏日本人的礼仪，如穿和服走小碎步、尊贵人物到来时两旁的人伏地行礼。
- 马先生解释“大奥”即后宫，日语中“奥”指很深的地方，即屋子最里处，中文中“堂奥”“深奥”保留此意，且一般人不得进入。
- 当年明月指出日本天皇一直是摆设，实际权力掌握在幕府将军手中，德川家康开创德川幕府后，权力集中于一人，将军想干什么就干什么。
- 当年明月举例说明天皇不受尊重：德川家掌权后，天皇想举办活动但没钱，找将军要钱被拒，活动未办成，天皇为抗议甚至退位。
- 马先生认为日本文化具有极端精神，所有事情要做到尽头，且是发自内心的，这与中国的“中庸”文化不同。
- 当年明月对比中日文化：中国文化精神是中庸，讲究融合，走最适合的路；日本精神则坚持一个原则，如“鞠一刀”，炮手开炮时忘记一切只记得开炮，即达到最高境界。
- 马先生指出日本战后用30年成为世界第二经济强国（绝对量），是必然结果，源于全民族的极端精神，且日本是唯一没有资源的强国。
- 马先生提到日本跳槽率最低，终身雇佣制虽违背经济学原理，但日本人积极性仍高。
- 窦文涛讲述《大奥》剧情：一女子本有情人，情人发誓救她，但将军死后情人放火来救，女子却拒绝跟走，因将军曾告诉她即使掉到井里也能有自己的天空，她选择留下甚至出家。马先生认为这是日本忠诚文化的具体体现，靠具体事例而非说教。
- 马先生举例：阿福25岁进大奥当奶妈，65岁去世，40年完全出于公心，不出于私心，即使被伤害，对方也认为她出于公心，最终成为楷模。
- 当年明月总结：所有人按自己角色做事，最节省成本，形成合力，效率极高。
- 马先生讲述参观日本豆腐厂：豆腐当天做当天卖，夜里11:45所有人坐好等钟，12点整准时开始工作，到四点多干完上市，无人闲聊。
- 当年明月分析原因：日本是岛国，无资源，常火山地震，生存条件恶劣，人必须融入团体按规则行事才能生存，因此对世界悲观，必须努力求生。
- 马先生指出日本投机取巧者没有生存环境，社会文化鄙视使其无法生存；举例日本做绳子的人，几年不赚钱铺市场，最后通过加价2%获得巨大利润。
- 当年明月表示不愿做日本人，因其有盲从和寻死的潜在欲望，如看樱花只看落的那天，对死亡不惧怕甚至向往。
- 马先生认为日本民族不是藐视生命，而是重视死亡，如经济危机时身家万贯的人剖腹自杀。

议题二：明朝历史与《明朝那些事儿》
- 窦文涛提到很多人对明史感兴趣，包括金庸晚年研究明史。
- 当年明月解释自己写明史是因为明史资料最多，历史研究有两个难点：一是先秦春秋，史料少，如孙武事迹多靠编；二是明清，史料多但同一事件有多个不同说法，如同罗生门。
- 马先生补充明朝260多年过程跌宕起伏，几次要死没死，如土木堡之变、夺门之变，皇上被瓦剌军抓走，又扶弟弟上位，情节堪比现代电视剧。
- 当年明月推崇朱元璋，认为其从乞丐到皇帝，历史上独此一份，刘邦好歹是亭长，朱元璋要过饭，知道每一层的猫腻，疑心重，但太不容易，且明朝规章制度由他定下，基本无大改动。
- 马先生认为人的因素最大，改变时势一定出现一个人，持英雄史观。
- 当年明月以《亮剑》李云龙为例，说明会打仗的人靠天赋和经验，而非兵书。
- 窦文涛提到朱元璋参加起义军是逼上梁山：好友汤和写信让他参加，信被泄露，他怕被杀头才去。当年明月强调历史最重要的是弄明白事情是真的，朱元璋当时参加起义是掉脑袋的风险。
- 马先生认为历史经验能体现，如明朝仁宣盛世，晚明虽政治黑暗，但老百姓生活很好，如《金瓶梅》中西门庆代表一个阶层。
- 当年明月指出明末很多真相被掩盖，市民生活轻松舒服，江浙工商业兴起，雇工活得很滋润，娱乐产品如“三言二拍”出现说明有养活自己的资本；李自成起义源于陕西大规模灾荒。
- 马先生提到明末工艺精细，日本派大量工匠来中国交流，江南富足，文征明、唐寅、董其昌等艺术家生活好才能画出小桥流水，而八大山人画翻白眼是因对社会愤愤不平。
- 当年明月引用名言：“我们从历史中得到的唯一教训就是我们从来没有从历史中得到过教训。”并解释历史事件发生时有背景，后人并不比前人聪明，史书只是照片，而生活是录像，不能套用经验。
- 当年明月指出明代有趣在于什么事都有：宦官专政（魏忠贤、刘瑾）、文官专政（张居正）、皇帝专政（朱元璋、朱棣），皇帝出去还能回来做皇帝。
- 当年明月提到吴三桂与满清合作入关，原因之一是崇祯皇帝死了，吴三桂忠诚于崇祯，入关是为崇祯复仇；1644年明朝灭亡时北京闹瘟疫（疙瘩瘟，即天花），李自成军打到京城无人抵抗。
- 马先生指出中国王朝300年大限，只有宋朝（南北宋接上）延续319年，汉朝中间隔断14年，唐朝、明朝、清朝都没跨过300年。
- 马先生对比宋明与清朝审美：宋明是汉人文人政权，审美高，对美的判断不是表象；满族是异族，对美的判断是表象的，如故宫大红大紫是满族趣味，而晚清民国初年收藏讲究素雅。
- 当年明月举例明朝皇帝受限制：明武宗要去江南，大臣跪在金水桥前抗议，皇帝打死十几人仍不让去。
- 窦文涛提到明朝史官冒死进谏以青史留名，马先生认为这是文化的力量。
- 当年明月为明武宗正德翻案：正德从江南回来在通州停半天，先派人打探京城情况，说明有城府；明武宗实录是嘉靖朝编的，嘉靖因大礼仪事件为父亲争名分，可能修史有偏颇。
- 马先生提到正德皇帝是明朝最荒淫的皇帝，但没留种，对宫廷内女人没兴趣，因禁忌太多，喜欢乔装改扮找民女。
- 窦文涛总结研究历史要有设身处地的态度，不能有傲慢与偏见。
