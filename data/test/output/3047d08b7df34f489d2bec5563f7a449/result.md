# 沟通概况
本次为372班家长会，由班主任林瑞主持，家长代表张宇波校长及全体家长参与，围绕班级基本情况、教师团队、存在问题与解决思路、给家长的建议、家长代表分享及家委会与相关事项展开。班级共60人，男生25人、女生35人；林瑞教地理，各科老师多为老教师、优秀教师、师范院校毕业且有3年以上经验，其电话将发在群里。费用方面，书费预交11000元尚未结算，书箱未购买部分将退费，相关费用约100元或70元、4000元购买、700/120/123元左右；明确不在微信群收取家长任何费用，由学生交给生活委员，并提醒家长和学生注意反诈。家委会建议至少三人、自愿报名；保险约310多元可自行购买并统计购买情况；电子学生证套餐78元，移动可能办不了，目前三个坐席，第三个9月二十几号到期，6月20号停机；学校资助高中补助打在医保卡上；生活费建议每天约21-24元，不超过150元/周。

# 沟通内容
**亮点**：整体来看，第一个月时间观念执行力加强，班风关系全部良好，周边环境地面干干净净，卫生、班风班貌、班风纪律非常好。**需关注之处**：少数同学周末玩游戏、懒散，自习课效率低、思考能力差，老师在时较乖、不在时乱哄哄；个别学生行动时间方面存在问题；书写需练字，建议买字帖；手机问题突出，有学生带手机、玩手机、有网瘾，甚至充值400元，要求手机放箱贴名字、家长处理多余手机、周一到周五可打电话检查；另有学生拿镜子、看小说等小问题；学生可能谈恋爱，需关注QQ、朋友圈、抖音、快手。

# 家长反馈
家长代表张宇波校长分享家庭教育经验：要控制孩子的身体健康和心理健康，高中阶段仍是长身体的关键时期；先做人，让孩子学会做人，千万不能让他们带上不良风气；家长对待孩子要有平常心，孩子面临的学习压力很大，对于挫折和失败要帮助孩子重新给自己定位；要尊重孩子，给孩子自由空间，不要轻易给孩子下消极评价；多倾听、多交流，把更多关爱与理解给孩子；要遵守学校制度、配合老师工作。张宇波校长原话：> 无论怎样，那你都是爸爸妈妈心里最优秀的儿子。
