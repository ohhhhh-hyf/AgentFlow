# 课程概况
本次课程为《电气工程基础》导论，属于电气工程专业入门课。课程旨在使学生掌握电力系统发电、输电、配电、用电四个典型环节的构成、工作原理及整体关系，并掌握分析、设计、运行、管理的基础理论、技术与计算方法。前修课程要求电路理论和电机学知识，特别是变压器和同步电机；后续课程包括电力系统分析、电力系统机电保护、电力系统自动化和高电压技术。第一章为概念最多且最重要的章节，要求掌握电力系统、电力网、动力系统、变电站等基本概念，理解电力系统特点及要求，掌握电能质量指标国家标准，了解中心点接地方式。课程还梳理了电力发展简史，从早期直流输电到交流输电占主导，再到直流输电在联网中重新受关注，并介绍了电力系统的形成过程与电网分类。

# 核心知识点梳理
**课程目标**：掌握电力系统发电、输电、配电、用电四个典型环节的构成、工作原理及整体关系；掌握分析、设计、运行、管理的基础理论、技术与计算方法。

**第一章重点**：
- 基本概念：`电力系统`、`电力网`、`动力系统`、`变电站`。
- 电力系统特点及要求，电能质量指标国家标准，中心点接地方式。

⭐ **难点**：
1. 由电力系统特点引出的基本原理，如电能不能大量储存决定的有功功率和无功功率动态平衡问题。
2. 电力系统额定电压的规定繁杂，需理清规律。
3. 各种中心点接地方式的特点及其对后续章节的影响。

**电力发展简史**：
- 直流输电早期试验：1874年俄国彼得堡4.5公里直流线路；1882年法国德普勒57公里试验线路（首端电压343伏，末端850伏，输送功率200瓦，损耗78%）；1883年14公里试验（输送功率1.1千瓦，损耗55%）。
- 直流输电受电压提升困难限制，19世纪末法国方剑串联直流发电机送75千瓦电力75千米；20世纪初瑞典科学家加装短路器，20多年建15条直流线路，最大为1906年法国慕尼黑水电厂到里昂180公里、57千伏、4700千瓦。
- 交流输电发展：1876年俄国发明单相变压器；1883年特斯拉制造感应电机；1885年匈牙利科学家设计变压器并联运行；1886年威斯汀豪斯在美国麻省示范1.2千米30千伏交流输电，又在意大利建成17英里高压线路；1886年俄国发明三相交流电。
- 交直流电力战争：爱迪生与凯尔文主张直流电，威斯汀豪斯与特斯拉主张交流电；交流电因变压器升压优势胜出。
- 电压等级提升：1898年发明瓷绝缘子，美国33千伏；1906年悬式绝缘子，110千伏；1912年发现电晕临界电压与导线直径成比例，美国154千伏；1923年均压阀技术，220千伏；1936年美国287千伏；1952年瑞典380千伏（首次采用分裂导线）；1956年苏联400千伏双回线路；1965年加拿大735千伏；1969年美国765千伏；1985年苏联1150千伏特高压（后降压至500千伏运行）。
- 中国：1941年220千伏投运；1972年330千伏；1981年500千伏；2009年1000千伏交流特高压投运。
- 直流输电在联网中重新受关注：1954年瑞典本土与哥特兰岛世界首个工业海底电缆工程（100千伏、96公里，汞弧阀）；1970年扩建50千伏1万千瓦晶闸管换流阀试验工程；1972年加拿大世界首个晶闸管换流阀背靠背直流工程；中国首个直流输电工程连接舟山群岛与浙江定海；1989年葛上直流（葛洲坝电厂到上海）±500千伏；今年6月云广直流±800千伏特高压直流工程投运。

**三相交流优势**：
- 三相交流系统三个优点：①易于产生旋转磁场，三相电动机易做驱动；②瞬时功率恒定；③输电线路导线金属消耗量最少。
- 三相三线制传输效率最高、金属消耗量最小，因此在交流输电中占主导地位。

**电力系统的形成**：
- 从单机向负荷供电，通过并联发电机提高可靠性；但输电线路电阻电抗导致电压损耗和功率损耗，需升压传输。
- 电力系统由发电机、变压器、输电线路、用电设备组成，完成生产、输送、分配、消耗职能。
- `电力网`：去除发电机和用电设备的部分；`动力系统`：电力系统加上发电厂动力部分（如锅炉、汽机、水轮机等）。
- 电网按规模分类：`地方电力网`（110千伏及以下，供电半径20-50公里）、`区域电力网`（110-500千伏，供电半径超50公里）、`超高压远距离输送网络`（500千伏及以上，跨省跨地区）。
- 变电站分类：按最高电压等级（如10千伏、220千伏、500千伏变电站）；按功率流向分为升压变电站和降压变电站。

# 课堂互动与答疑
课堂中教师提到，多年以来很多同学上课时问到“我们国家为什么采用交流？为什么采用交流三相三线制？”教师通过讲解三相交流系统的三个优点（易于产生旋转磁场、瞬时功率恒定、导线金属消耗量最少）及三相三线制传输效率最高、金属消耗量最小来解答。教师还提醒，对于基本概念要注意其内涵和外延，并适当记忆；思考方法要从电力系统的特点要求出发，从最基础的原理去推导，不要只记结论，因为结论在使用条件变化时可能失效。

# 课后任务与学习建议
教师推荐三本书供学生课后阅读，以了解电力发展的基本历史。教师强调，作为电气专业学生应了解电力发展的基本发展史。第一章为本章重点内容，学生应掌握基本概念、电力系统特点及要求、电能质量指标国家标准、中心点接地方式等。学习方法建议：①对基本概念注意内涵和外延，适当记忆；②从电力系统特点要求出发，从最基础原理推导，不记结论；③寻找额定电压规定之间的基本规律；④比较不同中心点接地方式的特点。对电路理论和电机学知识（特别是变压器和同步电机）有欠缺的同学，应下去补充相关内容。
