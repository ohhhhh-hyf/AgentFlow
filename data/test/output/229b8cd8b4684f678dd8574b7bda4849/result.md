# 电气工程基础第1章：电力系统基本概念与电网分类

## 课程概况
本课为电气工程基础课程第1章，是电气工程专业的入门课。课程提出两个教学目标：一是掌握电力系统发电、输电、配电、用电四个典型环节的构成、工作原理及与电力系统的整体关系；二是掌握电力系统在分析、设计、运行、管理方面的基础理论、基本技术与计算方法。前修课程要求具备电路理论和电机学知识，特别是变压器和同步电机的相关内容；后续重要课程包括电力系统分析、电力系统机电保护、电力系统自动化和高电压技术。第1章为概念最多、最重要的章节，要求掌握电力系统、电力网、动力系统、变电站等基本概念，理解电力系统特点及其对设计运行的影响，掌握电能质量指标及国家标准规定范围，了解常用接地方式特别是中性点接地方式。三个学习难点为：电能不能大量储存决定有功无功动态平衡、额定电压规定繁杂、中性点接地方式影响后续章节。主讲人还简要梳理了电力发展史，从直流输电起源到交流输电兴起及交直流之争，并讲解了电力系统的形成过程、三相交流输电优势、电力系统与电力网及动力系统的定义，以及电网按规模分为地方、区域、超高压远距离输送三类和变电站的分类方法。

## 核心知识点梳理
### 课程定位与学习目标

- **课程性质**：电气工程基础是进入专业课后的第一门课，属于专业入门课。
- **教学目标一**：掌握电力系统发电、输电、配电、用电四个典型环节的构成、工作原理及与电力系统整体之间的关系，建立电力系统整体概念。
- **教学目标二**：掌握电力系统在分析、设计、运行、管理方面的基础理论、基本技术及基本计算方法。
- **前修课程要求**：需具备电路理论和电机学知识，特别是变压器和同步电机的相关知识要求较高；有欠缺的同学应课后补充相关内容。
- **后续重要课程**：电力系统分析、电力系统机电保护、电力系统自动化、高电压技术。

### 第1章学习内容与难点

- **基本概念**：掌握电力系统、电力网、动力系统和变电站等相关概念。
- **电力系统特点**：理解电力系统的特点，以及由特点引起的电力系统设计、运行等方面的基础理论。
- **对电力系统的要求**：理解对电力系统提出的要求，涉及运行、设计和维护各方面。
- **电能质量指标**：掌握电能质量指标及国家标准规定的范围。
- **接地方式**：了解电力系统常用接地方式，特别是工作接地（中性点接地方式）的不同特点。
- **难点一【难点】**：由电力系统特点引出的基本原理——电能不能大量储存，决定了电力系统有功功率和无功功率的动态平衡问题，是运行调整和设计的基础。
- **难点二【难点】**：电力系统额定电压的规定繁杂，需注意把额定电压规定搞清楚。
- **难点三【难点】**：各种中性点接地方式直接影响后续多个章节内容，学习难度较大。
- **学习方法**：对基本概念注意内涵和外延并适当记忆；从电力系统特点和要求出发、从基础原理推导，不记结论；寻找额定电压规定之间的基本规律；比较不同中性点接地方式的特点。

### 电力发展简史

- **直流输电起源**：电力发展从直流开始，福泰勒用2000米导线连接瓦斯发电机，拖动直流发电机、电动机和带水泵的电动机，证明直流远距离（两公里）输电可行。
- **1874年**：俄国工程师在彼得堡建成4.5公里直流输电线路，传输功率4.5千瓦，后用于有轨电车的原始工业试验。
- **1882年**：法国德普勒架设首条57公里直流试验线路，采用电报线传输，首端电压343伏、末端850伏，输送功率200瓦，损耗78%，将水电站直流发电机电力送至博览会。
- **1883年**：德普勒从法国南部进行14公里输电试验，输送功率1.1千瓦，从瓦利尔书店到巴黎56公里，损耗55%。
- **1882年10月**：英国科学家发明直流输电三线制系统，外线与中线间电压110伏，两外线间电压220伏，后扩展到5根线形成直流无限制系统。
- **直流输电限制**：电压等级低时损耗大、电压降落快；提高电压困难——制造大容量高压直流发电机困难，限制远距离大容量输电。
- **19世纪末**：法国方剑在送端串联多台直流发电机以提高电压，将75千瓦电力输送75千米。
- **20世纪初**：瑞典科学家在串联直流发电机上装短路器，使任意发电机投切不停电；此后20多年建成15条直流输电线路。
- **1906年**：规模最大的直流线路投运，从法国慕尼黑水电厂到里昂，180公里、57千伏、4700千瓦。
- **1927年**：改建为260公里、125千伏、19000千瓦，接入两座水电站。
- **直流输电制约**：设备复杂、运行方式复杂、造价高、可靠性差。
- **交流输电早期发展**：英国法拉第电磁感应原理；美国亨利用多匝线圈做原边、少匝线圈做副边，使高电压感应出低电压，为变压器前身。
- **1876年**：俄国科学家发明单相变压器，主要用于照明。
- **变压器串联问题**：法国和英国科学家联合将多台变压器串联到输电线路中，负荷变化时输电电压受干扰。
- **1883年**：美国特斯拉制造感应电机，为标志性成果。
- **1885年**：匈牙利科学家设计多台变压器并联运行连接方式，使并联运行成为可能。
- **交直流之争**：爱迪生与凯尔文主张直流电，理由为直流电效率高、交流电有危险性——购买威斯汀豪斯公司交流发电机卖给监狱给死刑犯执行死刑以证明危险性。
- **交流电主张**：威斯汀豪斯和特斯拉主张交流电，因交流电易用变压器升压降压，可在高电压下减少电能损失；交流发电机制造业发展为交流输电做了准备。
- **1886年**：威斯汀豪斯在美国麻省进行1.2千米、30千伏交流输电示范；同年又在意大利建成17英里高压输电线路。
- **1886年**：俄国科学家发明三相交流电、三相交流输电和三相异步电动机。
- **交直流之争标志**：法国到德国的交流输电线路，从水电厂安装三相发电机和升压变压器，升压后送到德国，在法兰克福建两座降压变电站——一座供展览会照明，另一座供100马力三相异步电动机（用于人工瀑布离心泵）。
- **交流输电进展**：1898年发明针式绝缘子，美国加利福尼亚输电电压提高到33千伏；1906年发明悬式绝缘子，建成110千伏高压输电。
- **1912年**：发现电晕临界电压与导线直径成比例增加，铝线和钢芯铝绞线开始应用，美国建成154千伏高压输电线路。
- **1923年**：均压阀技术应用，建成220千伏输电线路。
- **1936年**：美国287千伏线路投运。
- **1952年**：瑞典建成380千伏线路，首次采用分裂导线。
- **1956年**：苏联400千伏双回线路（平行双回线）投入运行。
- **1965年**：加拿大建成735千伏输电系统。
- **1969年**：美国765千伏线路并入电网。
- **1985年**：苏联特高压线路1150千伏投运，后降压至500千伏运行。
- **国内交流输电**：220千伏于1941年投运，330千伏于1972年投运，500千伏于1981年投运，1000千伏于2009年投运（交流特高压首次投运）。
- **直流联网复兴**：交流大电网稳定问题突出后，直流在联网中的优势显现，用于电网与电网之间的连接。
- **1954年**：瑞典本土与哥特兰岛间建成世界首个工业采用海底电缆的直流工程，电压100千伏、96公里，采用汞弧阀技术。
- **1970年**：瑞典本土与哥特兰岛间扩建50千伏、1万千瓦晶闸管换流阀试验工程。
- **1972年**：世界首个晶闸管换流阀背靠背直流工程在加拿大投运。
- **中国直流工程**：首个直流输电工程为舟山群岛与浙江定海电网连接；第二个为1989年葛上直流（葛洲坝电厂到上海），±500千伏；今年6月投运云广直流±800千伏特高压直流工程。
- **推荐阅读**：主讲人推荐三本书供课后阅读，了解电力发展基本史。

### 三相交流输电优势

- **三相交流定义**：交流指ABC三相对称系统。
- **优点一**：易于产生旋转磁场，三相电动机容易做驱动。
- **优点二**：瞬时功率恒定，不随时间变化。
- **优点三**：输电线路导线量（金属消耗量）最少。
- **应用范围**：除室内配电等小功率供电采用单相交流外，其他场合基本采用三相交流；国内高压、超高压、特高压输电大多采用三相交流，联网时采用直流。
- **效率比较**：三相三线制传输效率最高，优于直流传输方式和其他交流传输方式。
- **金属消耗量比较**：同等功率和功率因数下，三相三线制金属消耗量最小——全截面为一根导线截面乘以3，与单相三线制和对称n相n线制比较后得出。

### 电力系统的形成与定义

- **早期供电方式**：一台发电机向附近负荷供电（如展览会照明、大楼照明），各发电机孤立供电；发电机故障即停电，供电可靠性差。
- **提高可靠性方法**：将两台发电机并联，一台故障时另一台带重要负荷，连接越来越多。
- **输电线路参数问题**：导线有电阻和电抗两个重要参数，传输功率时产生电压损耗和功率损耗；阻抗越大、电流越大，损耗越大，输电线路不能太长。
- **升压解决思路**：电压升高后，传输相同功率时电流减小，有功功率损耗`I²R`减小，电压降落`IZ`减小，输电距离可变长。
- **交流升压手段**：加变压器——一侧升压、另一侧降压，中间电压升高后距离损耗、电压损耗和功率损耗均降低。
- **电力系统形成**：近距离（几十到几百米）发电机直接相连，远距离升压传输，构成电力系统雏形；多台发电机共同供电，单台停机影响不大。
- **大机组效益**：可装大机组向大范围供电，供电范围越来越大，带来直接经济效益。
- **远距离输电问题**：距离很长时（如湖北送电华东、云贵送电两广），中间负荷可在输电线路中间装设变电站、装降压变压器供电；稳定问题可在变电站装设备调整。
- **电力系统定义**：发电机、变压器、输电线路和用电设备构成的整体，完成电能生产、输送、分配、消耗四个职能，由发电厂（发电机）、变压器、输电线路、用电设备四个环节组成。
- **电力网定义**：变压器和输电线路构成的网络，即电力系统中去除发电机和用电设备的部分。
- **动力系统定义**：在电力系统基础上加上发电厂动力部分——火电厂的锅炉、汽机及煤炭输送处理系统，水电厂的水轮机、水坝、水库等。
- **概念辨析**：行业中最常用的是电力网和电力系统两个概念，动力系统概念现在很少使用。

### 电网分类与变电站分类

- **地方电力网**：向固定地方供给电能的网络，电压等级110千伏及以下（早期定义35千伏及以下，现常用110千伏及以下），供电半径20~50公里。
- **区域电力网**：电压等级110、220千伏及少量500千伏，供电半径超过50公里，联系较多发电厂和负荷中心的网络。
- **超高压远距离输送网络**：电压等级500千伏或1000千伏（东北有330千伏），主要任务是把发电厂电能送到负荷中心，距离很远，构成跨省跨地区大型电力系统。
- **实例一**：武汉电网属于地方电力网，主要供电电压110千伏和35千伏，少数地方出现220千伏，供电半径一般在50公里以内。
- **实例二**：华中电网是典型区域网，华中几省紧密联系。
- **实例三**：山西晋东南到湖北荆门的特高压系统，跨三个省，连接华北电网和华中电网，属于超高压远距离输送网络。
- **实例四**：三峡到上海的输电线路连接华中与华东，属于超高压远距离输电网络。
- **电压等级变化**：随着电网发展，各级电网使用的电压等级会提高，变电站地位也随之变化。
- **按电压等级分类**：按变电站最高电压等级分类——华工变电站为10千伏变电站（10千伏变380伏），关山变电站为220千伏变电站，凤凰山变电站为500千伏变电站。
- **按功率流向分类**：按主要功率流通方向分为升压变电站和降压变电站——大部分功率从高压侧流向低压侧为降压变电站；发电厂内大部分功率从低压侧升到高压侧为升压变电站。

## 课堂互动与答疑
### Q1. 为什么我国电力系统采用交流三相三线制输电？

- **学生**：我们国家为什么采用交流，而且采用三相三线制？
> **教师**：三相交流系统具有三个优点：易于产生旋转磁场，便于三相电动机驱动；瞬时功率恒定，不随时间变化；同等功率和功率因数下，输电线路导线金属消耗量最少。三相三线制在各类传输方式中传输效率最高，因此除室内配电等小功率供电采用单相交流外，其他场合基本采用三相交流。国内高压、超高压、特高压输电大多采用三相交流，仅在联网时采用直流。

### 学习建议
- [ ] **补充前修知识**：对电路理论和电机学知识有欠缺的同学，应补充变压器和同步电机的相关知识，本课程对此有较高要求。
- [ ] **概念学习方法**：注意基本概念的内涵和外延，适当结合实际；从电力系统的特点要求出发，从最基础原理推导，不要记结论（结论在使用条件变化时会失效）。
- [ ] **规律归纳**：注意寻找额定电压规定之间的基本规律；比较各种不同中性点接地方式之间的特点。
- [ ] **课后阅读电力发展史**：作为电气专业学生应了解电力发展基本史，主讲人推荐三本书供课后阅读，建议进一步阅读交直流输电发展相关内容。
- [ ] **结合实例理解电网分类**：通过武汉电网（地方电网）、华中电网（区域电网）、三峡至上海输电线路（超高压远距离输送网络）等实际例子对比，理解电网规模分类标准。
