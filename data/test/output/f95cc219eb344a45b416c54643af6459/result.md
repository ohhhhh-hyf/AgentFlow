# 课程概况
本次课程为《电气工程基础》导论，是电气专业入门课。课程教学目的有二：一是掌握电力系统发电、输电、配电、用电四个典型环节的构成、工作原理及与系统整体的关系，建立整体概念；二是掌握电力系统分析、设计、运行、管理的最基础理论、技术与计算方法。前修课程为电路理论、电机学，尤其对变压器和同步电机知识要求较高；后续课程包括电力系统分析、电力系统继电保护、电力系统自动化、高电压技术。第一章是概念最多、最重要的章节，涵盖电力系统、电力网、动力系统、变电站等基本概念，电力系统特点及要求、电能质量指标、中性点接地方式等内容，并梳理了交直流输电发展简史、三相交流输电优势、电力系统形成过程与定义、电网分类及变电站分类。

# 核心知识点梳理
## 课程定位与教学目标
- **课程性质**：电气工程基础是进入专业课的第一门课，属专业入门课。
- **教学目标一**：掌握电力系统**发电、输电、配电、用电**四个典型环节的构成、工作原理及与系统整体的关系，建立整体概念。
- **教学目标二**：掌握电力系统分析、设计、运行、管理的最基础理论、技术与计算方法。
- **前修课程**：电路理论、电机学，特别是**变压器和同步电机**知识要求较高，有欠缺的同学需自行补充。
- **后续课程**：电力系统分析、电力系统继电保护、电力系统自动化、高电压技术。

## 第一章学习内容与难点
- **学习内容**：电力系统、电力网、动力系统、变电站等基本概念；电力系统特点及引起的基础理论；对电力系统的要求；电能质量指标及国家标准规定范围；常用接地方式，特别是**中性点接地方式**。
- **难点一** ⭐：电能不能大量储存，决定电力系统**有功功率和无功功率的动态平衡**问题。
- **难点二** ⭐：电力系统**额定电压的规定**繁杂，需注意搞清。
- **难点三** ⭐：各种**中性点接地方式**直接影响后续多个章节内容，学习较困难。
- **学习方法**：注意概念的内涵和外延；从电力系统特点要求出发、从最基础原理推导，*不要只记结论*；寻找额定电压规定之间的基本规律；比较不同中性点接地方式的特点。

## 电力发展简史
- **直流输电起步**：福泰勒用**2000米**导线连接瓦斯发电机，拖动直流电动机和水泵，证明直流远距离输电可行。
- **1874年**：俄国工程师在彼得堡建成**4.5公里**直流输电线路，传输功率**4.5千瓦**。
- **1882年**：法国德普勒架设**57公里**直流试验线路，首端电压**343伏**、末端**850伏**，输送功率**200瓦**，损耗**78%**。
- **1883年**：德普勒从法国南部进行**14公里**输电试验，输送功率**1.1千瓦**，从瓦利尔书店到巴黎**56公里**损耗**55%**。
- **1882年10月**：英国科学家发明直流**三线制系统**，外线与中线电压**110伏**、外线间**220伏**，后扩展至5线。
- **19世纪末**：法国方剑串联多台直流发电机，将**75千瓦**电力送**75千米**。
- **20世纪初**：瑞典科学家装短路器，20多年建**15条**直流线路；最大为**1906年**法国慕尼黑水电厂到里昂**180公里**、**57千伏**、**4700千瓦**；**1927年**改建**260公里**、**125千伏**、**19000千瓦**。
- **交流输电基础**：法拉第电磁感应原理；美国亨利用多线圈做变压器前身；**1876年**俄国科学家发明单相变压器；**1883年**特斯拉制造感应电机；**1885年**匈牙利科学家设计多台变压器并联运行。
- **1886年**：威斯汀豪斯在美国麻省进行**1.2千米**、**30千伏**交流输电示范，又在意大利建成**17英里**、**2千伏**线路；同年俄国科学家发明三相交流电和三相异步电动机。
- **交直流电力战争**：爱迪生与凯尔文主张直流电，称其效率高、交流电有危险性，曾购买威斯汀豪斯交流发电机卖给监狱执行死刑；威斯汀豪斯与特斯拉主张交流电，因易用变压器升压降压、减少电能损失。
- **标志性线路**：从法国到德国的交流输电线路，水电厂装三相发电机和升压变压器，法兰克福建两座降压变，一座供展览照明，一座供**100马力**三相异步电动机带动离心泵做人工瀑布。
- **高压输电发展**：**1898年**针式绝缘子，美国加利福尼亚**33千伏**；**1906年**悬式绝缘子，建成**110千伏**；**1912年**发现电晕临界电压与导线直径成比例，铝线和钢芯铝绞线应用，美国建成**154千伏**；**1923年**均压阀技术，建成**220千伏**；**1936年**美国**287千伏**投运；**1952年**瑞典**380千伏**首次采用分裂导线；**1956年**苏联**400千伏**双回线路；**1965年**加拿大**735千伏**；**1969年**美国**765千伏**；**1985年**苏联**1150千伏**特高压投运后降压至**500千伏**。
- **国内发展**：**220千伏**1941年投运，**330千伏**1972年，**500千伏**1981年，**1000千伏**2009年投运（交流特高压标志性成果）。
- **直流输电复兴**：**1954年**瑞典本土与哥特兰岛建成世界第一个工业海底电缆，**100千伏**、**96公里**，汞弧阀；**1970年**扩建**50千伏**、**1万千瓦**晶闸管换流阀试验工程；**1972年**世界第一个晶闸管换流阀背靠背直流工程在加拿大投运。
- **中国直流工程**：第一个直流输电工程连接舟山群岛与浙江定海；**1989年**葛上直流（葛洲坝到上海）**±500千伏**；今年**6月**云广直流**±800**特高压直流投运。
- **推荐阅读**：教师推荐三本书供学生进一步阅读，作为电气专业学生应了解电力发展基本史。

## 三相交流输电优势
- **三相优点一**：易于产生旋转磁场，三相电动机容易做驱动。
- **三相优点二**：瞬时功率恒定，不随时间变化。
- **三相优点三**：输电线路导线金属消耗量最少。
- **应用现状**：除室内配电等小功率供电采用单相交流外，其他场合基本采用三相交流；国内大多数高压、超高压、特高压输电采用三相交流，联网才用直流。
- **三相三线制**：传输效率最高，同等功率和功率因数下金属消耗量最小，目前仍采用这种输电方式。

## 电力系统的形成与定义
- **形成过程**：从单机向附近负荷供电，到多机并联提高可靠性，再到升压输电扩大距离。
- **输电线路参数**：导线有电阻和电抗，传输功率时产生电压损耗和功率损耗，距离不能太长。
- **升压原理**：传输有功功率一定时，电压升高则电流减小，线路有功损耗和电压降落减小，距离可变长；交流采用变压器升压。
- **电力系统定义**：发电机、变压器、输电线路和用电设备构成的整体，完成电能**生产、输送、分配、消耗**四个职能。
- **电力网定义**：电力系统中去除发电机和用电设备的部分，即变压器和输电线路构成的网络。
- **动力系统定义**：电力系统加上发电厂动力部分（火电锅炉汽机煤炭系统，水电水轮机水坝水库）。
- **行业常用**：电力网和电力系统两个概念，动力系统很少说。

## 电网分类与变电站分类
- **地方电力网**：向固定地方供电，电压等级**110千伏及以下**（早期定义35千伏及以下），供电半径**20-50公里**。
- **区域电力网**：电压等级**110、220千伏**和少量**500千伏**，供电半径超过**50公里**，联系较多发电厂和负荷中心。
- **超高压远距离输送网络**：电压等级**500千伏或1000千伏**（东北有330千伏），任务是把发电厂电能送到负荷中心，构成跨省跨地区大型电力系统。
- **实例**：武汉电网属地方电力网，主要供电电压110和35千伏，少数220；华中网是典型区域网；葛上直流、三峡到上海输电线路属超高压远距离输送网络；特高压系统从山西晋东南到湖北荆门，跨三省，连接华北和华中电网。
- **按电压等级分类**：华工变电站**10千伏**，关山变电站**220千伏**，凤凰山变电站**500千伏**。
- **按功率流向分类**：大部分功率从高压侧流向低压侧为**降压变电站**；发电厂内从低压侧升压到高压侧为**升压变电站**。
