# 沟通概况
2024年秋季学期，372班召开家长会，班主任林瑞（地理教师）主持，张宇波校长作为家长代表分享家庭教育经验。会议围绕班级基本情况、教师团队、存在问题及解决思路、费用说明、保险与电子学生证办理、资助政策、家委会成立等议题展开。班级共60人，男生25人、女生35人，学生处于生理和心理持续变化的不稳定时期。班主任指出班级优点为时间观念、执行力强，班风班貌纪律良好；缺点是少数同学周末玩手机游戏、懒散，自习课效率低。会议明确费用由学生交给生活委员、不在微信群收取，要求收掉镜子，并成立至少三人的家委会。

# 沟通内容
**亮点**：
- **班风纪律**：时间观念、执行力强，班风班貌纪律良好，地面干净、卫生好。
- **教师团队**：多为老教师、优秀教师，师范院校毕业，有3年以上教学经验，部分教师有6年以上经验。

**需关注之处**：
- **手机管理**：少数同学周末玩手机游戏，有网瘾，充生活费400元用于游戏；发现学生看直播、不健康内容。
- **自习纪律**：自习课效率低，老师不在时乱哄哄，思考能力差。
- **书写问题**：个别学生书写不好，已与家长沟通，建议买字帖练字。
- **行为规范**：发现学生带镜子，要求全部收掉；有学生谈恋爱，需家长关注QQ、抖音、快手等社交账号。

# 家长反馈
张宇波校长作为家长代表分享家庭教育经验，强调关注孩子身体健康和心理健康，尊重孩子，多倾听多交流，配合学校制度。
- 家长关注孩子学习压力大，面对挫折和失败需要积极互动和帮助。
- 家长提出要给孩子自由空间，不要轻易下消极评价。
- 家长强调多倾听、多交流，给予孩子更多关爱与理解。
> 无论怎样，那你都是爸爸妈妈心里最优秀的儿子。
> 先做人，这的话也是我经常对我家儿子说的。

# 共识与配合事项
- [ ] **班主任**：继续加强思想教育工作，每天进行。
- [ ] **班主任**：制定详细班规，严格扣分、写检讨、罚站，严格请假制度。
- [ ] **班主任**：定期与科任老师沟通，了解学生表现。
- [ ] **班主任**：下次月考在11月初，提醒学生定目标。
- [ ] **家长**：处理多余手机，不留多部，周一到周五不定时打电话检查手机是否开机。
- [ ] **家长**：关注孩子QQ、抖音、快手等社交账号，防止谈恋爱、看不健康内容。
- [ ] **家长**：费用由学生交给生活委员，不在微信群收取；水费险每人每月2元，书费预交11000元待结算。
- [ ] **家长**：购买保险约310元，可自行购买，最后统计购买情况。
- [ ] **家长**：办理电子学生证套餐78元（移动），方便联系。
- [ ] **家长**：关注高中补助打在医保卡上，每次打钱会通知，提醒孩子合理使用。
- [ ] **家长**：提醒孩子注意交通安全（未满16周岁不骑电动车）、运动安全、饮食安全、防诈骗、防溺水、防校园欺凌。
- [ ] **家长**：创建良好家庭环境，避免唠叨，不聚众打麻将，不在家常备客人，不看手机。
- [ ] **家长**：制定小目标，如年级120名到30名，多鼓励少批评。
- [ ] **班主任**：成立家委会，至少三人，有家长自愿报名。
