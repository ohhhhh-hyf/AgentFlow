# 电子科技大学电子科学与工程学院招生宣讲直播

## 沟通背景与目的
本次沟通为电子科技大学电子科学与工程学院面向考生及家长的招生宣讲直播，由学院段院、柳教授、张教授、李天明教授及在读博士生田雨桐参与，主持人负责串场。沟通旨在介绍学院整体情况、各学科方向与人才培养成果，解答考生和家长关心的报考问题，吸引优秀生源。整体基调为积极推介，各方向介绍详实，并设有互动答疑与抽奖环节；夏令营具体安排尚未确定，相关信息将通过学院QQ群发布。

## 核心信息与数据
### 学院整体情况
1. **历史沿革**：学院源于1956年建校时成立的无线电系、电真空器件系、无线电零件系，经1979年、1992年、2001年、2018年4次院系调整成立电子科学与工程学院（示范性微电子学院），2023年响应国家号召成立电子科学与工程学院与基层电路学院（原文如此）。
2. **学科设置**：电子科学与技术为国家重点一级学科，下设5个二级学科方向——电磁场与微波技术、电路与系统、微电子学与固体电子学、物理电子学、电磁信息功能材料与机构；另有3个国防特色学科。
3. **人才培养规模**：本科生现有1545人，招生专业为工科试验班（电子工程类），含电子科学技术（国家特色专业、国家级一流本科专业建设点）与电磁场与无线技术两个专业方向；硕士和博士研究生1975人。
4. **研究生招生专业**：学术学位博士、硕士为电子科学与技术、材料科学与工程；专业学位博士、硕士为电子信息、材料工程。
5. **师资构成**：现有教师302人，其中教研系139人、科研系95人、教学系14人、实验系21人，教师总数269人，机关33人。
6. **高层次人才**：两院院士2人、领军人才19人、青年人才28人、其他类型人才12人、博士后61人；融合2个全国高校黄大年式教师团队，2022年获批4个国家自然科学基金创新群体。
7. **科研经费与成果**：近5年科研经费到账稳定在3–4亿元之间，以纵向项目为主、横向项目为辅；牵头获国家科技奖励11项，发表高水平学术论文2000余篇，申请专利1600余件、授权1300余件。
8. **科研团队与平台**：共20个科研团队，年度经费过千万元的团队15个、过亿元团队1个；拥有2个国家级平台（国家电子辐射控制材料工程技术研究中心、微波电子工器件国家级重点实验室〔原文如此〕）、4个国际合作平台、7个省部级科研平台。
9. **国际交流**：共建国际姊妹院系2个（香港大学电机工程电子系、香港城市大学电子工程系），主办高水平国际会议13场，学生长短期交流项目20多个。

### 电子信息材料与元器件方向
1. **方向定位**：以材料为基础、器件为核心、应用为目标导向，涉及电子材料、器件、电路的设计研制生产应用；以电子在物质中的输运特性（电磁声光热力及化学生物特性）为基础。
2. **产业背景**：2021年中国集成电路电子产品进口额达2.8万亿元，约为原油进口量的1.7倍；先进电子材料元器件电路系统等电子产品是我国目前最为紧迫的卡脖子问题之一。
3. **应用领域**：在6G通讯、量子技术、智慧城市、光电技术、新能源、智能电子等领域起重要作用，广泛用于物联网、移动设备、网络基础设施、无人驾驶、航空航天、医疗健康和可穿戴设备。
4. **邓龙江院士团队**：电磁辐射控制材料与技术团队，现有研究人员19人（正高13人、副高15人〔原文如此〕），近年发表包括《自然》在内的论文300余篇，承担国家省部级及国际合作课题130余项，年均到账经费3000多万元，授权发明专利100余项，获国家科技进步或技术发明二等奖共计3项。
5. **张怀武教授团队**：磁电薄膜与微型器件团队，现有研究人员17人（正高15人、副高2人），开展LTCC材料及集成技术、微波毫米波晶圆及器件、自旋电子与磁量子器件、传感器芯片等研究，承担国家重点研发计划、自然基金重点重大科学仪器项目等100余项，发表SCI论文400余篇，年均到账经费2000余万元，获科技进步二等奖共计3项。
6. **国家级平台**：国家电磁辐射控制材料工程技术研究中心（历史可追溯至1990年校级材料与技术研究中心，经2008年、2013年两次升级），开展多频谱涂层、电磁材料与结构、智能材料与结构研究；电磁薄膜与集成器件全国重点实验室，形成电子聚合物与阵列传感器、功率半导体与集成技术三个重点方向。
7. **研究条件**：科研面积2万余平米（超精尖3000平），建设两条国家重大任务试验生产线，大型设备或系统500余台套；材料制备设备约50余台套，微纳加工设备30台套。
8. **毕业生去向**：遍布产业界与学术界，包括英特尔、中芯国际、华为、德州仪器及高校科研院所；在读学生杨伟豪以第一作者在《自然·电子》《自然·通讯》各发表一篇论文；5G滤波器芯片学生团队获挑战杯创新创业大赛四川省金奖。

### 电磁场与微波技术、电路与系统方向
1. **电磁场与微波技术细分方向**：包含微波毫米波电路、电波传播与电磁兼容、计算电磁学与工程电子学、天线理论与技术4个细分方向，涵盖射频微波整套系统的全部研发方向。
2. **电路与系统细分方向**：包含非线性电路与复杂电子系统、射频微波电路与系统、集成电路与系统3个专业方向。
3. **学科历史**：电磁场与微波技术学科始于1956年建校时期，由林卫干先生和谢楚芳先生创建，形成电磁场与无线技术国家特色专业及电波传播与天线国防紧缺特色专业，所属一级学科电子科学与技术入选双一流A类学科。
4. **研究团队**：电磁场与微波技术方向由6个团队组成——电磁辐射与散射团队、毫米波技术与系统应用团队、微波毫米波集成电路与系统团队、电磁兼容技术团队、微波测试与成像技术团队、无线技术与集成系统团队。
5. **学科平台**：含国家自然基金委创新群体、国家高等学校学科创新引智基地、国家工程技术研究中心及国家级重点实验室；硬件方面拥有中国高校最为先进的微波暗室群体及微波毫米波太赫兹仿真测试平台。
6. **天线与雷达成果**：杨世文教授团队研究四维天线阵列技术，为天线阵列设计提供新自由度，实现低成本高性能，成果应用于中电14所某大型机载相控阵雷达；樊勇教授团队研制出0.22THz、0.34THz、0.42THz雷达成像系统，分辨率小于1厘米，成果在2023年成都大运会田径项目成功示范应用。
7. **测量与计算电磁学**：李恩教授团队微波毫米波测量技术有60多年技术积累和传承，突破众多技术封锁；杨世文教授团队计算电磁学相关算法被评为20世纪十大算法之一。
8. **电路与系统学科**：1981年开始招收研究生和博士研究生，1988年成立首批博士后流动站；拥有国家级人才4人、新世纪人才2人、教授10人、副教授22人。
9. **人才培养成果**：连续三年获全国大学生集成电路创新创业大赛奖项，荣获华为优秀合作项目奖、研究生优秀导学团队提名奖；就业领域包括华为、中兴等领军企业及各大研究所、高校。

### 物理电子学方向
1. **学科定义**：物理电子学是物理学与电子科学技术的交叉学科，将物理学最新研究成果应用于电子学，产生新的电子器件；学科边界不一定清晰，如光电子学既可属物理电子学也可属光学工程一级学科。
2. **学科特点**：基础性与前沿性，数理基础要求高，所生成的电子器件是信息科技产业的重要支撑，是支撑现代信息技术的关键技术学科。
3. **发展历程**：起源于1956年建校时的电真空器件专业（归宿于电子器件系）；1979年在刘成刚院士带领下成立高能电子学研究所；2001年物理系、应用所、高能所成立物理电子学；2018年物理电子学院、电工学院和微工学院部分成立现电子科学与工程学院。
4. **纵向发展**：上游为仿真设计、数字模拟材料，下游为系统应用——利用功率器件研制毫米波雷达（回旋行波管）、无线输能系统（行波管）、微波能干燥系统（磁控管）。
5. **横向拓展**：频段从微波上移至毫米波、太赫兹；与医学交叉，利用太赫兹分辨率高、透视效果好的特点做太赫兹成像，利用宽频带特点做保密通信、高速通信。

2. **学科实力**：电子科学与技术学科在第4轮学科评估中获A+，稳居全国第一。
3. **选团队建议**：学院拥有四大学科和19个科研团队，建议先选团队再选导师；可通过学院网站、IEEE Xplore、中国知网等检索导师论文和指导研究生情况。
