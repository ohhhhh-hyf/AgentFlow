# 讲座概况
本次研讨会围绕1979年至1989年苏联入侵阿富汗的苏阿战争展开，主讲人系统介绍了阿富汗的地理位置、历史背景、苏联出兵原因、战争过程及各方援助情况。阿富汗地处亚洲中部，东接中国，北邻塔吉克斯坦，南接巴基斯坦、伊朗，被称为亚洲的中间走廊地带，是兵家必争之地；其国土百分之九十为高原山地，易守难攻，历史上多次获得“帝国坟场”称号。主讲人详细讲述了苏联出兵的过程：1979年12月24日平安夜，苏联以兵变政变形式，借口阿富汗请求救援，从东部、中部、西部（塔吉克斯坦、土库曼斯坦方向）分路推进，一夜之间控制喀布尔，处决阿明一家，扶植代理人卡尔迈勒上台，将阿富汗纳入苏联阵营。此举招致阿拉伯国家、中国及西方盟国共同不满，各方合力援助阿富汗抵抗组织，阿富汗和穆斯林国家出动兵源，中国和西方盟国提供武器与情报资源，支持阿富汗进行长达十年的游击战争，最终苏联于1989年撤军。问答环节中，主讲人解答了听众关于阿富汗战略价值、石油资源、圣战者含义及帝国坟场原因等问题。

# 核心观点与论证
主讲人首先阐述阿富汗的地理位置与战略价值：地处亚洲中部，东接中国，北邻塔吉克斯坦，南接巴基斯坦、伊朗，被称为“亚洲的中间走廊地带”，是兵家必争之地；其国土百分之九十为高原山地，易守难攻，历史上多次获得“帝国坟场”称号。接着介绍战前背景：20世纪50年代，阿富汗同时与苏联及西方国家保持友好，实行君主立宪制，精英阶层奉行亲英与亲苏两头政策，文化上师从英国，国家建设与工业方面向苏联看齐；基辛格评价当时的国王阿明“用苏联的火柴点美国的香烟”，两边要好处。苏联因阿明不满其干涉内政、过度导向美国，担心阿富汗脱离掌控影响中亚地区，遂决定武力介入。1979年12月24日平安夜，苏联以兵变政变形式，借口阿富汗请求救援，从东部、中部、西部（塔吉克斯坦、土库曼斯坦方向）分路推进，一夜控制喀布尔，处决阿明一家，扶植代理人卡尔迈勒上台。此举招致阿拉伯国家、中国及西方盟国共同不满，各方合力援助阿富汗抵抗组织：阿富汗和穆斯林国家出动兵源，中国和西方盟国提供武器与情报资源，支持阿富汗进行长达十年的游击战争。主讲人分析阿富汗难打的原因：百分之九十的高原山地地形适合游击战，乡村由部落长老控制，政府无法有效统治；中国曾教授地道战、地雷战等战法，美国援助了毒刺导弹等单兵武器，有效压制苏联武装直升机；苏联基层官兵普遍厌战，士气低落，最终于1989年撤军。

# 金句总结
“谁控制了阿富汗，谁就控制住了亚洲的咽喉。”——主讲人回答听众关于阿富汗战略价值的问题时指出，地理位置是列强争夺阿富汗的根本原因。
“它是用的苏联的火柴在点的美国的香烟。”——主讲人引用基辛格对阿富汗国王阿明的评价，说明阿富汗在苏联与西方之间两头要好处、左右逢源的“墙头草”状态。
“苏联的军事实力看似庞大，但实际上它的武器发挥不了任何的作用。”——主讲人总结苏联在阿富汗的困境，指出其重装部队在高原山地无法形成有效战斗力。

# Q&A 环节
问：阿富汗到底有啥好呀？为啥都想打它？
答：地理位置的原因，因为谁控制了阿富汗，谁就控制住了亚洲的咽喉。
问：是不是阿富汗有石油啊？
答：它这个国家相对来说是个贫油国，但它周边的国家都是富油国，比如说是西边的伊朗，北边的土库曼斯坦和塔吉克斯坦。
问：之前看阿富汗那边把那个部队叫什么圣战者，这个是什么意思？
答：就是狂烈的激进的伊斯兰圣战思想，以及从上到下那种宗教式洗脑，导致其阿富汗圣战者具备像二战时期日本军国主义荼毒之下的日本军民那样，不顾一切地抱着同归于尽的思想进行圣战。
问：为什么阿富汗这个位置这么难打？
答：因为这个国家百分之九十都是处于高原山地地带，就是一个天然的游击战地区。除了喀布尔和坎大哈那几个主要城市以外，剩下大部分百分之九十的地区都是乡村部落长老制，政府没有任何控制力，各个村落与部落各自为政，导致任何列强以及阿富汗的城市政府都无法对广大高原山地地区形成有力控制。
