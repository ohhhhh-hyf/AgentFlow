# 讨论议题与背景
本次讨论以闲聊方式围绕多国文学及《西游记》相关话题展开，参与发言的有发言人1、发言人2、发言人3、发言人4。核心探讨问题包括：日本文学（东野圭吾《白夜行》）的叙事手法与阴暗结局、法国文学（雨果《悲惨世界》）的抗争精神与浪漫理想主义、俄国文学（契诃夫、列夫·托尔斯泰、格罗斯曼、《古拉格群岛》《命运与生活》）对人性丑恶的揭露与批判、英国文学（狄更斯《圣诞欢歌》《雾都孤儿》《简爱》）对底层民众的描写、美国文学（马克·吐温、海明威、《了不起的盖茨比》）的现代叙事风格，以及中国文学与影视（《平凡的世界》、台湾电影《假如我是真的》）和《西游记》狮驼岭章节的讨论。讨论未形成明确结论，最后转入练习环节。

# 发言要点
发言人1提到《白夜行》是悬疑小说，叙事手法隐藏、每个人都有嫌疑，结局非常阴暗；认为法国文学有抗争精神，法国革命多，英国小说多写贵族生活；提到国内《平凡的世界》写底层也深刻，但受政策原因很多作品不让看；认为英国狄更斯的《圣诞欢歌》《雾都孤儿》讲底层人，贵族与穷人之间有鸿沟，穷人把希望寄托宗教或虚无；提到美国历史短、美洲大陆相对幸福，并提及《了不起的盖茨比》；提到《一九四二》讲大饥荒和战乱；提到《西游记》狮驼岭章节吓人，认为黑神话悟空没有设计那一章，因太血腥不好过审。发言人2提到《菊与刀》描绘日本人性格特点，认为《白夜行》符合日本形象；提到雨果《悲惨世界》体现浪漫的理想主义精神；提到契诃夫、列夫·托尔斯泰、格罗斯曼，认为俄国文学戏剧性更明显、更多揭露批判人性丑恶，《古拉格群岛》最早为法语版、俄语版在苏联解体后发行；提到台湾电影《假如我是真的》改编自俄国小说并结合文革真实事件，涉及知青上山下乡；提到英国土地承载不了人口膨胀，很多人移民美国；提到美国农业资源广阔、从不缺粮食、从未发生大饥荒；提到高尔基《海燕》体现被压迫后的反抗；详细讲述《西游记》狮驼岭章节，青狮、白象、大鹏三魔头吃掉全城人、尸骸遍地、人皮做地毯、头骨做装饰，距灵山约500公里，与普度众生大相径庭，认为大鹏精是唯一能遛猴子的反派。发言人3提到哈利波特、俄国文学，询问《假如我是真的》讲什么，最后提议停止讨论转入练习。发言人4提到法国只读过《悲惨世界》，英国只看了《简爱》，认为法国小说描绘底层民众多一些、英国都是贵族生活，认为俄国文学更曲折、戏剧性更明显，询问狮驼岭是什么、是否没有拍到电视剧。观点交锋点主要在于法国与俄国文学对底层民众描写的生动性比较，以及各国文学主题特点的差异。
