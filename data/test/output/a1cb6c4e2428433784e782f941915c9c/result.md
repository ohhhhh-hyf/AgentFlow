# 发布会概况
本次中金宏观策略争论周会由策略组刘刚凯文主持，围绕大美丽法案、关税、港股流动性三大宏观议题展开，并邀请公用事业首席分析师刘佳妮、机械军工分析师郭文秀、传媒首席分析师张雪琴分别解读光伏反内卷、人形机器人、游戏板块的投资机会。整体基调为：对美股美债不悲观，波动提供再配置机会；关税大概率是谈判技巧，市场逐渐脱敏；港股流动性三季度边际收紧但基本面可盖过；光伏反内卷政策力度升级、行业底部夯实；人形机器人三季度围绕华为链、本土企业技术闭环、特斯拉硬件替代三条主线；游戏板块在消费、政策和新品周期三重利好下有望戴维斯双击。

# 核心信息
- 大美丽法案三大块：提高债务上限约**5万亿美元**，延长2017年减税法案（新增支出**3.4万亿**、每年**3400亿**，减新能源补贴**1.4万亿**），取消`899条款`。
- 信用周期框架：政府、AI产业投资、传统私人部门需求三部分；美国如篝火自然修复，中国如煮水需持续添柴；上半年美国遭遇`DeepSeek`、财政收缩、`4月2日对等关税`三盆冷水，纳斯达克从底部反弹**35%**。
- 7-9月美债供给约**1万亿美元**，参考2023年三季度推高美债利率从3.8%到5%、美股小幅下跌4-5%；当前期限溢价已是**2013年以来高点**，预计利率抬升幅度可能不及2023年；四季度美元可能小幅走强，美股可能反弹跑赢。
- 关税四点信息：一定要做以支撑收入；需维持一定税率（当前豁免**10%**水平）以收**3000-4000亿**；不能太高以免通胀；市场逐渐脱敏。新变化：时间拖后（原`7月9日`），大部分税率相比`4月2日对等关税`回落，除巴西；加拿大、墨西哥、欧盟单拎出因贸易占比高。有效税率当前**10-12%**，若`8月1日`全回去可能10-15%，最极端**18%**；通胀压力缓慢抬升，年底约**3.3-3.4%**。对中国关税约**40-50%**，越南转口限制**40%**，需关注`8月12日`中美谈判及转口限制。
- 港股流动性：`7-9月`美债利率走高、美元流动性供给压力，四季度美元可能小幅走强，边际上对港股略偏负面；港股5月后微观流动性释放，`HIBOR`大幅下降，金管局投放大量资金，港币触及**7.85**，金管局会收流动性但可小幅收（如收90亿放1000多亿），流动性边际变紧，`IPO`融资较多形成约束。指数在**23000-24000**区间震荡，类似3月底；风格上长期两头分红，银行股溢价低于**20%**短期透支，**125%**是隐形底；成长端新消费拥挤，创新药稍降，科技硬件AI应用降幅大，可提前埋伏。
- 光伏反内卷：需求端全球新增装机从2020年**130GW**增至2024年**530GW**（CAGR **42%**），2025-26年增速回落至**10%**左右；供给端2023年产能从**600GW**增至**1000GW**，电池产能是需求**1.5倍**、硅片组件**2倍**、硅料**2.5倍**；2022年以来产业链价格下跌**70%-90%**，硅片电池2023Q4亏损，硅料组件2024Q2亏损。反内卷政策力度升级（`2024年5月17日`光伏行业高质量发展座谈会、`2025年2月`国常会、`6月29日`人民日报发声、`7月1日`中财委第6次会议、`7月3日`工信部座谈会），价格恶性竞争有望告一段落，行业底部夯实。硅料环节最易整合（集中度高、成本曲线陡峭、供需比超**200%**），电池环节供需最好（`PERC`退出、`TOPCon`占**90%**、`BC`渗透率**5-6%**）；光伏玻璃`2024年9月`第一轮产能出清降幅**6%**，第二轮计划7月降产**30%**，需出清约**2万吨**，龙头企业成本**1元/平米**。市场反馈：多晶硅期货价格触及**40元/公斤**，现货从35元上涨，硅片涨**10%**，电池涨**2分**，硅料和玻璃股价涨**20-30%**，组件涨**10%**。穿越周期企业：头部一体化组件企业议价能力强，低杠杆强现金企业财务健康，技术创新（颗粒硅使用比例从10-20%提升到**50%**，铜替代银2025-26年导入）。
- 人形机器人：二季度A股机器人板块按流通市值加权跌约**9%**，跑输机械设备约**12个百分点**，特斯拉核心供应商股价从3月高点回调**30%-40%**，回调原因系特斯拉4月后量产时间线延后叠加中美关税。三季度三条主线：华为云生态开放（6月底发布`盘古世界模型`和`CloudRobot平台`，具备多模态生成、规划大模型、执行大模型毫米级精度，华为明确不造机器人，以`RTC`方式开放，探索`AI agent`或`license`收费）、本土人形机器人企业技术闭环（智元机器人拟收购材料厂商在A股上市，宇树科技年收入突破**10亿**、下半年加速上市，两家同时中标中国移动近**1.2亿**人形机器人采购订单）、特斯拉延期带来的硬件替代窗口（`Optimus`存在电机过热、灵巧手负载不足、续航问题，正在变更方案和筛选供应商）。物流端是投资回报率明确的场景，2025年降低单件运输成本是刚需；国内至少**100家以上**人形机器人本体厂商；港股机器人板块二季度估值溢价明显，下半年有确定性扩容。关注三类信号：华为云生态接入厂商新增、头部企业出货量跨越年化**500台**或**1000台**、电机硬件优化窗口。
- 游戏板块：上涨接近两三个月，上周初开始调整，观点仍看好。政策端今年1月和3月国务院层面发布游戏行业支持政策，广东、浙江、北京、上海等地有专门政策支持包；版号发放今年6月单月发放**158个**（国产**147个**，进口**11个**），**2018年以来单月最高**；市场数据2024年8月以来单月持续正增长，今年1-5月游戏市场规模同比增长**17%**（**1400多亿**），手游同比增长**20%**。新品周期：市场预期今年缺乏大作，但中型厂商新品成为核心催化，如吉比特`《仗剑传说》`首月流水**2亿多**，巨人网络`《超自然行动组》`6月流水过亿，年化乐观**20亿**，利润提升**50%以上**。估值：`TTM PE`约**30倍**（2023年AI行情到过**45倍**），2025年静态`PE`约**20倍**。游戏板块逆周期性，政策友好，新品周期延续，但利润有滞后性，今年新品利润明年兑现；建议关注新品市场表现、用户获取下载榜排名等领先指标。

# 官方表态
- 关于去美元化：刘刚凯文表示，我们并不是完全认同去美元化这个观点，这个现在成了一个高度趋同的共识，而且都是基于宏大叙事，5~10年之后的事即便认可这个逻辑的人也没法拍胸脯说一定兑现。
- 关于市场误区：刘刚凯文指出，现在市场两个最大的误区，一个是把美元弱当成去美元化，另一个是把美元弱和美股弱直接划等号；美元弱在大部分时间，只要不是抛售美国资产的弱，实际是对美股有利的。
- 关于美股美债：刘刚凯文重申，我们对美股也不悲观，波动提供再配置的机会，背后的原因是信用周期的再度转好，只不过三季度有一个流动性的波折。
- 关于关税：刘刚凯文判断，关税大概率要做，需要维持一定税率才能收上钱，也不能太高以免通胀受不了，所以市场逐渐脱敏，静观其变。
- 关于港股流动性：刘刚凯文强调，美元美债利率并不是绝对主导港股市场的唯一变量，很多时候自己的基本面强完全可以盖过它的影响。
- 关于光伏反内卷：刘佳妮表示，随着反内卷力度不断强化升级，价格恶性竞争有望告一段落，至少对行业来讲夯实了它的底部。
- 关于人形机器人：郭文秀认为，三季度将是从二季度的迷茫期到商业兑现过渡的小阶段，建议关注华为云生态接入、头部企业出货量跨越年化500台或1000台、电机硬件优化三类信号。
- 关于游戏板块：张雪琴重申，在消费、政策和新品周期三重利好下，游戏行业有望在调整后再次实现戴维斯双击。

# Q&A环节
**问**：大美丽法案对美股、美债、美元流动性有什么影响？
**答**：刘刚凯文表示，大美丽法案三大块（提高债务上限约5万亿美元、延长2017年减税法案、取消899条款）对信用周期中长期有利，但短期7-9月有流动性抽水效应，美债供给约1万亿美元，参考2023年三季度推高美债利率从3.8%到5%、美股小幅下跌4-5%；当前期限溢价已是2013年以来高点，预计利率抬升幅度可能不及2023年，波动提供再配置机会，对美股美债不悲观。

**问**：关税是否在升级？对通胀和美联储降息有什么影响？
**答**：刘刚凯文表示，关税大概率要做以支撑收入，需维持一定税率（当前豁免10%水平）以收3000-4000亿，不能太高以免通胀；新变化是时间拖后（原7月9日），大部分税率相比4月2日对等关税回落，除巴西；有效税率当前10-12%，若8月1日全回去可能10-15%，最极端18%；通胀压力缓慢抬升，年底约3.3-3.4%，不大幅改变通胀路径，美联储7-9月仍可降息。

**问**：对中国关税和转口限制有什么影响？
**答**：刘刚凯文提示，对中国关税约40-50%，越南转口限制40%，我们比这个税率还要低，需关注8月12日中美谈判进展及转口限制。

**问**：港股流动性三季度会怎样？
**答**：刘刚凯文表示，7-9月美债利率走高、美元流动性供给压力，四季度美元可能小幅走强，边际上对港股略偏负面；港股5月后微观流动性释放，HIBOR大幅下降，金管局投放大量资金，港币触及7.85，金管局会收流动性但可小幅收（如收90亿放1000多亿），流动性边际变紧，IPO融资较多形成约束；指数在23000-24000区间震荡，类似3月底。

**问**：光伏反内卷政策对行业有什么影响？哪些环节最受益？
**答**：刘佳妮表示，反内卷政策力度升级（2024年5月17日光伏行业高质量发展座谈会、2025年2月国常会、6月29日人民日报发声、7月1日中财委第6次会议、7月3日工信部座谈会），价格恶性竞争有望告一段落，行业底部夯实；硅料环节最易整合（集中度高、成本曲线陡峭、供需比超200%），电池环节供需最好（PERC退出、TOPCon占90%、BC渗透率5-6%）；光伏玻璃第二轮产能出清计划7月降产30%，需出清约2万吨。

**问**：光伏产业链价格和股价有什么反应？
**答**：刘佳妮表示，多晶硅期货价格触及40元/公斤，现货从35元上涨，硅片涨10%，电池涨2分，硅料和玻璃股价涨20-30%，组件涨10%；组件价格能否跟涨取决于下游电站能否接受产业链价格上涨传导，需观望招标情况。

**问**：人形机器人三季度有哪些催化剂和投资主线？
**答**：郭文秀表示，三季度围绕三条主线：华为云生态开放（6月底发布盘古世界模型和CloudRobot平台，华为明确不造机器人，以RTC方式开放）、本土人形机器人企业技术闭环（智元机器人拟收购材料厂商在A股上市，宇树科技年收入突破10亿、下半年加速上市，两家同时中标中国移动近1.2亿人形机器人采购订单）、特斯拉延期带来的硬件替代窗口（Optimus存在电机过热、灵巧手负载不足、续航问题，正在变更方案和筛选供应商）；建议关注三类信号：华为云生态接入厂商新增、头部企业出货量跨越年化500台或1000台、电机硬件优化窗口。

**问**：游戏板块上涨后调整，是结束还是回调后更健康？
**答**：张雪琴表示，观点旗帜鲜明是后者；估值上TTM PE约30倍（2023年AI行情到过45倍），2025年静态PE约20倍，游戏板块逆周期性，政策友好，新品周期延续，但利润有滞后性，今年新品利润明年兑现；在消费、政策和新品周期三重利好下，游戏行业有望在调整后再次实现戴维斯双击。
