# 沟通背景与目的
本次直播由电子科技大学电子科学与工程学院面向考生和家长举办，段院、柳教授、张教授、李天明教授及博士生田雨桐分别介绍学院整体情况、电子信息材料与元器件、电磁场与微波技术与电路与系统、物理电子学等学科方向，并分享学生视角的择校建议。学院历史可追溯至1956年建校时的无线电系、电真空器件系、无线电零件系，经四次院系调整成立，电子科学与技术为国家重点一级学科，下设5个二级学科方向。本科生1545人，研究生1975人，教师总数302人，近5年科研经费到账稳定在3~4亿元。直播最后解答夏令营问题，计划今年举办但时间待定，相关信息将通过QQ群发布。

# 信息同步
**段院（学院领导）**：介绍学院历史沿革，1956年建校时成立无线电系、电真空器件系、无线电零件系，经1979、1992、2001、2018年四次院系调整成立电子科学与工程学院，2023年成立电子科学与工程学院与基层电路学院。电子科学与技术为国家重点一级学科，下设电磁场与微波技术、电路与系统、微电子学与固体电子学、物理电子学、电磁信息功能材料与机构5个二级学科方向，另有3个国防特色学科。本科生现有1545人，招生专业为工科试验班（电子工程类），含电子科学技术（国家特色专业、国家级一流本科专业建设点）和电磁场与无线技术两个专业方向；研究生现有硕士和博士研究生1975人，招生专业涵盖电子科学与技术、材料科学与工程、电子信息、材料工程等。教师总数302人，其中教研系列139人、科研系列95人、教学系列14人、实验系列21人，另有机关33人；师资含两院院士2人、领军人才19人、青年人才28人、其他类型人才12人、博士后61人。拥有2个全国高校黄大年式教师团队，2022年获批4个国家自然科学基金创新群体。近5年科研经费到账稳定在3~4亿元，以纵向项目为主、横向项目为辅；牵头获国家科技奖励11项，发表高水平论文2000余篇，专利申请1600余件、授权1300余件。现有20个科研团队，年度经费过千万元的团队15个，其中过亿元团队1个。拥有国家电子辐射控制材料工程技术研究中心和微波电子工器件国家级重点实验室两个国家级平台，4个国际合作平台，7个省部级科研平台，共建国际姊妹院系2个（香港大学电机工程电子系、香港城市大学电子工程系），主办高水平国际会议13场，学生长短期交流项目20多个。

**柳教授（电子信息材料与元器件方向）**：该方向以电子在物质中的输运特性（电磁声光热力、化学生物）为基础，设计研究和生产电子器件，以材料为基础、器件为核心、应用为目标导向。2021年中国集成电路电子产品进口额度达2.8万亿元，约为原有进口量的1.7倍，先进电子材料、元器件、电路系统等是我国目前最为紧迫的卡脖子问题之一。电子产品在6G通讯、量子技术、智慧城市、光电技术、新能源、智能电子等领域起重要作用，广泛应用于物联网、移动设备、网络基础设施、无人驾驶、航空航天、医疗健康和可穿戴设备，达到万亿美元量级。电子产品向小型化、多功能、低功耗、智能化方向发展，元器件向微型化、片式化、集成化、薄膜化、智能化发展，强调材料和器件一体化。研究队伍含国家级人才10余人，主要有两个团队：邓龙江院士所在的电磁辐射控制材料与技术团队（研究人员19人，正高13人、副高15人，发表包括Nature在内论文300余篇，承担课题130余项，年均到账经费3000多万元，授权发明专利100余项，获国家科技进步或技术发明二等奖共3项）；张怀武教授领导的磁电薄膜与微型器件团队（研究人员17人，正高15人、副高2人，承担项目100余项，获科技进步二等奖共3项，发表SCI论文400余篇，年均到账经费2000余万元）。依托国家电磁辐射控制材料工程技术研究中心（历史可追溯至1990年校级材料与技术研究中心，经2008年、2013年两次升级形成，开展多频谱涂层、电磁材料与结构、智能材料与结构研究，拥有成都嘉驰电子科技等成果转化基地）和电磁薄膜与集成器件全国重点实验室（2006年依托新型传感器、功率半导体技术、电子信息材料三个部级重点实验室筹建，形成电子聚合物与阵列传感器、功率半导体与集成技术三个重点方向）两个国家级平台。科研面积2万余平米，其中超精尖3000平，建设两条国家重大任务试验生产线，拥有大型设备或系统500余台套；材料制备设备约50余台套，微纳加工设备30台套，材料微观表征设备约10余台套，材料性能测试设备50余台套。已获包括国家技术发明奖在内的奖项共计7项。毕业生去向包括英特尔、中芯国际、华为、德州仪器等企业及高校科研院所；在读学生杨伟豪以第一作者在自然电子、自然通讯各发表一篇学术论文，5G滤波器芯片学生团队获挑战杯创新创业大赛四川省金奖，黄飞为2018年四川省优秀毕业生并获斯坦福攻读博士全额奖学金，李凤霞读博期间发表学术论文16篇（一作6篇），严巍获华为光产线优秀合作项目奖和王大珞光学奖后以优秀青年学者身份加入苏州大学，万位为河北美泰电子科技公司副总，率先采用MEMS工艺研制出SIW环形器隔离器，突破卡脖子器件核心技术。

**张教授（电磁场与微波技术、电路与系统方向）**：电磁场与微波技术包含4个细分方向：微波毫米波电路、电波传播与电磁兼容、计算电磁学与工程电子学、天线理论与技术；电路与系统专业包含非线性电路与复杂电子系统、射频微波电路与系统、集成电路与系统三个方向。电磁场与微波技术学科始于1956年，由林卫干先生和谢楚芳先生共同创建，形成电磁场与无线技术国家特色专业和电波传播与天线国防紧缺特色专业，所属一级学科电子科学与技术入选双一流A类学科。该学科有6个团队：电磁辐射与散射团队、毫米波技术与系统应用团队、微波毫米波集成电路与系统团队、电磁兼容技术团队、微波测试与成像技术团队、无线技术与集成系统团队。学科平台含国家自然基金委创新群体、国家高等学校学科创新引智基地、国家工程技术研究中心、国家级重点实验室，硬件平台拥有中国高校最为先进的微波暗室群体及微波毫米波太赫兹仿真测试平台。主要成果：杨世文教授团队的四维天线阵列技术应用于中电14所某大型机载相控阵雷达，在强耦合超宽带相控阵方面取得进展，计算电磁学算法被评为20世纪十大算法之一，电磁测井仪器获国家科技进步二等奖并在中海油推广应用；樊勇教授团队研制出0.22太赫兹、0.34太赫兹、0.42太赫兹雷达成像系统（分辨率小于1厘米），太赫兹通信成果在2023年成都大运会田径项目示范应用；李恩教授团队引领微波毫米波测量技术，有60多年技术积累，在生物医学电磁学及成像方向发表大量高水平论文及20余项国家发明专利；延波教授团队引领微波毫米波太赫兹芯片研究，获国家科技重大专项及军科委支持，应用于新一代高速通信系统，在微系统技术方面包括三毫米导引头前端、毫米波引信前端、8毫米宽带收发前端。电路与系统专业1981年开始招收研究生，1988年成立首批博士后流动站，拥有教育部国际合作联合实验室及国家高等学校学科创新引智基地，国家级人才4人、新世纪人才2人、教授10人、副教授22人。人才培养方面连续三年获全国大学生集成电路创新创业大赛奖项，荣获华为优秀合作项目奖和研究生优秀导学团队提名奖，就业领域包括华为、中兴等领军企业及各大研究所和高校。

**李天明教授（物理电子学方向）**：物理电子学是物理学与电子科学技术的交叉学科，将物理学最新研究成果应用于电子学产生新电子器件，典型如微波电子学（微波电真空器件）、光电子学（光电器件）。学科特点：内容不断充实（如量子电子学内容增加），学科边界不一定清晰（如光电子学也可属于光学工程一级学科），具有基础性与前沿性，是支撑现代信息技术的关键技术学科。学校物理电子学起源于1956年建校时在前苏联专家帮助下成立的电子控器件专业，归属电子器件系；1979年在刘成刚院士带领下成立高能电子学研究所；2001年物理系、应用所、高能所成立物理电子学；2018年物理电子学院、电工学院和微工学院部分成立现在的电子科学与工程学院。纵向发展涵盖上游仿真设计、数字模拟材料到下游系统应用，拥有自主知识产权的商用软件MMST和切皮克，并引入人工智能到器件设计和电子学应用；系统应用方面用回旋行波管研制毫米波雷达、用行波管做无线输能系统、用磁控管做微波能干燥系统。横向发展从微波上移到毫米波到太赫兹，与医学交叉利用太赫兹成像提高诊断准确性，利用太赫兹宽频带做保密通信、高速通信。拥有3个四川省工程中心或重点实验室，每年到校科研经费接近2亿元，是学院中最多的；是国际上最大的真空器件研究中心，2023年成功举办行业顶级会议。物理电子学方向有9个团队，学生出口约1/3硕博连读、1/3去企业、1/3去研究所或其他（如公务员）；李天明教授个人每年约两个研究生毕业、一个博士毕业。

**田雨桐（博士生）**：从学生视角分享选择电子学院的8个理由：城市（成都为四川省会、国家中心城市、新一线城市、国家历史文化名城、古蜀文明发祥地、中国十大古都之一）；电子信息产业前景广阔，英特尔、华为、京东方等巨头汇聚；电子科技大学是我国电子信息人才培育的代名词，拥有电子信息博物馆记录我国第一台晶体管收音机的诞生；学院电子科学与技术学科在第4轮学科评估中斩获A+，稳居全国第一；学院拥有四大学科和19个科研团队。田雨桐所在团队为毫米波技术与系统应用团队，负责人为樊勇老师，围绕微波毫米波理论与技术、天线理论与技术、元器件与电路、通信技术与系统、雷达成像技术与系统五大研究方向，团队硕博毕业生实现百分百就业率，就业单位包括民营企业、大型央国企和头部科研院所。2021年跨年学校在主楼前用300架无人机拼出电子科大英文简称UESTC字样。奖助体系包括国家奖学金、学业奖学金、专项奖学金、新生奖学金、校园地国家助学贷款和生源地助学贷款。择校建议：先选择研究团队再选择导师，可从学院网站按兴趣选择团队，再进入团队网页找导师；可用IEEE和中国知网等文献检索网站检索导师论文和指导研究生毕业情况。
