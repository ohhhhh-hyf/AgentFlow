# 发布会概况
王毅在慕尼黑安全会议上围绕多极化世界走向阐述中方立场并回答提问。王毅表示，多极化既是历史必然也正在成为现实，中国主张推动平等有序的世界多极化，中国必将是多极体系中的确定性因素，将坚定做变革世界中的建设性力量。他提出四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。王毅还就联合国与国际秩序规则、乌克兰危机、中美关系等问题回答提问，表示欧洲是多极世界的重要一极，中欧是伙伴而不是对手，今年是中欧建交50周年。

# 核心信息
王毅在慕尼黑安全会议上提出四点主张：一是倡导平等相待，坚持权利平等、机会平等、规则平等，主张大小国家一律平等，提升发展中国家在国际体系中的代表性和发言权；二是尊重国际法治，强调联合国宪章宗旨和原则是国际关系根本遵循，国家不论大小强弱都是国际法治利益攸关方，大国要带头讲诚信讲法治，摒弃言行不一、零和博弈，遵守国际法不能搞双重标准，应支持中国实现完全统一；三是践行多边主义，称联合国是推进全球治理的核心平台，应固本强基而非拆梁毁柱，中国承担超过**20%**的联合国会费，履行`巴黎协定`，建成世界上最大的清洁发电体系，提出并落实全球发展倡议、全球安全倡议、全球文明倡议；四是坚持开放共赢，指出保护主义不是出路、滥加关税没有赢家、脱钩断链断的是机遇、小院高墙封的是自己，去年中国GDP增长**5%**，对世界经济增长的贡献率接近**30%**，愿推动高质量共建`一带一路`同欧盟`全球门户`战略相互对接。王毅表示，今年是中欧建交**50周年**，中方愿同欧方用好这一契机深化战略沟通和互利合作。

# 官方表态
关于联合国与国际秩序规则，王毅表示，中国是现行国际秩序受益者，要做的就是按照大多数国家的愿望，推动这个秩序朝着更加公正合理的方向去发展；需要共同维护以联合国为核心的国际体系，共同遵守以联合国宪章宗旨和原则为基础的国际关系基本准则。关于乌克兰危机，王毅表示，中国同俄罗斯是两大邻国，建立了不结盟、不对抗、不针对第三方的睦邻友好关系，进而建立全面战略伙伴关系，中俄交往是正常的国与国之间的交往；中方自2022年2月25日起就提出对话协商解决，习近平主席提出的四点主张是中国立场的最权威阐释，中方派特使去各国斡旋，同巴西等南方国家发起和平之友，乐见一切致力于和平的努力，包括这两天美国同俄罗斯达成的共识，认为所有当事方包括利益攸关方都应适时参与和谈进程，欧洲更有必要发挥重要作用。关于中美关系，王毅表示，中国对美政策保持着连续性和稳定性，遵循习近平主席提出的相互尊重、和平共处、合作共赢三原则；中美制度不同是各自人民做出的选择，改造或颠覆对方不切实际；中方已准备好按三原则同美方构建稳定健康可持续的双边关系，希望美方相向而行，若美方仍对中国打压和遏制，中方必将奉陪到底，坚定维护中国的主权、国家的尊严和正当发展权利，坚决回击美方单边和霸凌行径。
