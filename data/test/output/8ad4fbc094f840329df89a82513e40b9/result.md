# 庭审概况
本案系国家开发银行因与云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷一案，不服云南省高级人民法院云民初88号民事判决，向本院提起上诉。本院依法组成合议庭，对本案公开开庭审理，各方当事人均已到庭，法庭准备工作就绪。庭审围绕三个争议焦点展开调查辩论：一是抵押权与融资租赁所有权冲突及善意取得，二是罚息、复利计算，三是东源煤电、东源煤业是否应连带给付违约金。合议庭休庭评议后提出调解方案，各方当事人对调解方案均无异议，依次在调解协议正式文本上签字，本院予以确认，并在庭后根据民事诉讼法第97条规定出具调解书。

# 举证与法庭调查
## 一、举证与质证

### （一）国开行举证
1. 2018年9月对曲靖电力公司租赁情况的查询证书（第五组证据第一项），用以证明已对融资租赁登记信息进行核查。招银租赁质证认为该查询证书不符合要求，根据201493号中国人民银行关于融资租赁登记系统规定，国开行在操作抵押时点未查询人行征信中心结果，无论以设备名义还是以电力公司名义查询，均未进行相应查询。
2. 证据四冶合成58亿，含东源煤电公司、曲靖电力公司对案涉设备的权属证明，用以证明设备所有权确属曲靖电力公司。
3. 2018年核查表（证据108页），用以证明2018年再次核查曲靖电力公司名下仍无融资租赁登记信息。
4. 2015年12月2日邮件及统计表，东源方用以证明已告知设备融资租赁情况。国开行质证认为该邮件正文及附表均无设备存在融资租赁的文字，统计表中招银租赁一栏记载的融资额度及抵押类型为不动产抵押，看不出东源方履行过告知义务。

### （二）东源方举证
1. 2015年12月2日邮件及融资情况表，主张邮件发送时间与2015年12月20日签订抵押合同时间吻合，统计表中两家公司抵押设备名称完全相同且用红色标注，国开行作为专业金融机构应尽注意义务。
2. 东源公司经营困难情况说明：以煤炭开采为主营业务，2015年下半年出现资金链断裂，2019年2月19日人民法院受理破产重整时点负债高达76.2亿元，2016年响应去产能政策安置职工1万3000多人，最困难时近半年未发工资、社会保险严重拖欠。

### （三）招银租赁举证
1. 一审提交证据7页回租设备清单，载明设备名称和生产厂家，未提及设备型号。国开行质证认为即便提交该清单，开行角度亦无法对设备进行同一性测试；清单提示2012年3月1日，而抵押设备铭牌记载生产日期均在2013年以后，部分为2013年11月、2013年12月、2014年3月，看不出是同一设备。
2. 2013年和2015年审计报告（证据82页、95页），载明曲靖电力公司注册资本4个亿且已实缴。国开行认为招银租赁有理由知道或应当知道设备出资情况。
3. 融资租赁登记系统初始登记附件清单，含设备名称、数量、进场时间、生产厂商及存放地点，显示存放地点为登封矿区梅干石电厂，该电厂只有汽轮机两台、发电机两台、锅炉两台。

## 二、法官询问要点
1. 合议庭询问各方如何理解中国人民银行征信中心融资租赁登记的性质及法律后果。国开行认为系行业强制性规范，目的是防范动产设备多处抵押或融资冲突；招银租赁认为系行业性质、非物权法定登记，仅强化动产权利外观、可能产生对抗效力，不影响所有权设立转移；东源方认为系行业指导性规范文件，非强制性，不当然产生物权后果。
2. 合议庭询问央行金融租赁查询方式能否保证查询到登记结果。国开行称能使用的查询方式就是查询单位；招银租赁称可通过公司名称或设备两种方式查询，以设备查询涉及种类物区分问题。
3. 合议庭询问设备唯一标识码是否为必填项。招银租赁称不是必填项，发电机组铭牌只有型号和参数，无发动机号类唯一标识；暗设五套设备当时刚交付、无唯一识别码，故未登记。
4. 合议庭询问国开行内部风控是否规定必须查询、未查到是否需将未查到单据作为风控材料。国开行称办理动产抵押时需调查该系统并筛查，因无表现故未保留筛查记录，内部无此规定。
5. 合议庭询问国开行认为未查到登记结果即可免责的逻辑。国开行称按央行规定查询融资租赁系统，抵押人为曲靖电力公司，查询后系统无记载，2018年6月截图亦无显示，至今无结果，说明行为无过失。
6. 合议庭询问若通过其他渠道知道抵押设备存在租赁是否仍需查询。招银租赁称仍需通过央行系统查询，央行规定出台背景是实践中大量存在此类案例，只有确定标准才能衡量双方是否善意。
7. 合议庭询问各方如何看待因不同登记机构产生登记瑕疵。国开行认为涉及人民银行融资租赁登记系统与动产抵押登记的冲突，系统信息不完整、体系相互隔离、信息不流畅，未形成相互联通，可能带来交易风险；东源方称非专业机构，提供不了相关建议；招银租赁认为规范不统一、登记机构不统一、信息不对称，建议从立法层面统一对金融主体和市场主体要求，发挥行业协会作用，从操作和技能方面推动登记平台统一化。

## 三、双方辩论的争议焦点
1. 抵押权与融资租赁所有权冲突及善意取得：国开行主张已尽合理审慎义务、构成善意取得；东源方主张邮件已告知且设备名称相同并用红色标注、国开行应尽注意义务；招银租赁主张2012年即取得设备所有权、国开行2015年办理抵押时未查询登记、不构成善意。
2. 罚息、复利计算：国开行主张利息自2017年12月21日至2018年6月12日合计2179万5727.08元、罚息自2018年6月13日至2019年2月19日合计4105万零579.57元、复利自2018年3月21日至2019年2月19日合计191万8206元；东源方主张2018年6月13日宣布贷款提前到期不符合合同约定、未给合理期限、罚息不应作为复利计算基数、复利再计算复利无合同依据。
3. 违约金连带责任：国开行主张依借款合同第24条第三项约定应支付千分之一违约金、东源煤电未按第13条、第14条约定配合办理账户管理及柜台前手续构成违约；东源方主张国开行未举证证明东源煤电违反柜台协议且未按合同约定限期纠正即主张违约金、应予驳回。

# 庭审结果
本案争议焦点为三项：一是抵押权与融资租赁所有权冲突及善意取得；二是罚息、复利计算；三是东源煤电、东源煤业是否应连带给付违约金。合议庭休庭评议后提出调解方案，各方当事人对调解方案均无异议，依次在调解协议正式文本上签字。经本院主持调解，各方当事人自愿达成调解协议，本院予以确认，并在庭后根据民事诉讼法第97条规定出具调解书。调解方案主要内容：确定国开行对东源公司债权扣除破产中已清偿本金外，利息2017年12月21日至2018年6月12日合计2179万5727.08元、罚息2018年6月13日至2019年2月19日合计4105万零579.57元、复利2018年3月21日至2019年2月19日合计191万8206元，三项共计6474万4513元；确定招银租赁对涉案六项设备享有所有权、对应债权数额1377万4137万元，确定国开行对93项设备有抵押权，双方对案涉全部发电设备整体盘活处置并从变现款中实现各自债权，生效20日内由国开行向一审法院提出执行申请启动司法变现，变现价格双方各50%、实现费用双方各担50%；变现款不足清偿债务或变现后招银租赁未实现债权，在执行法院处具体本裁定后按破产重整计划中预留方案实现债权，破产管理人对招银租赁债权予以纳入预留方案，由东源煤电按此前招银租赁在东源煤电破产重组程序中有担保清偿方案予以清偿；如司法变现不能实现国开行和招银租赁权益，通过前述方法实现后均放弃对案涉设备权益，由东源曲靖电力自主生产经营；各方对一审判决第二项、第四项无争议，按判项内容在调解书中确认；一审诉讼费用中对于国开行诉请部分按一审判决执行，对于招银租赁诉请部分诉讼费由二审法院按规定根据证据确定，二审诉讼费由本院依法确定。合议庭指出本案涉及生产设备的动产抵押权与融资租赁物所有权冲突是司法实践中普遍性难题，金融风险防控还有较大空间，根本原因在于国家还未建立统一的动产登记制度，现有动产融资租赁登记系统和动产抵押登记系统缺乏有效衔接，将根据最高人民法院关于加强司法建议工作的意见向有关部门提出司法建议，共同推进国家治理现代化。
