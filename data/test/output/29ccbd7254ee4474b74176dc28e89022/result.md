# 沟通背景与目的
电子科技大学电子科学与工程学院举办招生宣讲会，面向考生和家长介绍学院整体情况、学科方向、师资科研与人才培养。段院介绍学院源于1956年建校时的无线电系、电真空器件系、无线电零件系，经四次院系调整成立，一级学科电子科学与技术为国家重点一级学科，现有本科生1545人、研究生1975人，教师302人，近5年科研到账经费稳定在3-4亿元/年，牵头获国家科技奖励11项。柳教授介绍电子信息材料与元器件方向，指出2021年中国集成电路电子产品进口额达2.8万亿元，属最紧迫的卡脖子问题之一，拥有邓龙江院士团队和张怀武教授团队，依托两个国家级平台。张教授介绍电磁场与微波技术、电路与系统方向，学科始于1956年，拥有6个团队，代表性成果包括四维天线阵列技术、太赫兹雷达成像系统等。李天明教授介绍物理电子学方向，每年到校科研经费接近2亿元，是国际上最大的真空器件研究中心。在读博士田雨桐分享选择电子学院的8个理由，包括成都产业优势、学科A+、团队培养与100%就业率等。关于夏令营，段院表示计划今年举办，时间待定，相关信息将通过QQ群（978499108）发布。

# 信息同步
**段院（学院整体情况）**
- 学院历史：1956年建校时成立无线电系、电真空器件系、无线电零件系，经1979、1992、2001、2018年四次院系调整成立电子科学与工程学院，2023年成立电子科学与工程学院与集成电路学院。
- 学科设置：一级学科电子科学与技术为国家重点一级学科，下设5个二级学科方向（电磁场与微波技术、电路与系统、微电子学与固体电子学、物理电子学、电磁信息功能材料与机构）及3个国防特色学科（电磁场与微波、军用关键材料、电子元器件）。
- 人才培养：本科生1545人，招生专业为工科试验班（电子工程类），含电子科学与技术（国家特色专业、国家级一流本科专业建设点）和电磁场与无线技术两个专业方向；研究生1975人，学硕/博士专业为电子科学与技术、材料科学与工程，专硕/博士为电子信息、材料工程。
- 师资队伍：教师302人（教研系列139人、科研系列95人、教学系列14人、实验系列21人、教师总数269人、机关33人），两院院士2人、领军人才19人、青年人才28人、其他类型人才12人、博士后61人。
- 科研实力：近5年到账经费稳定在3-4亿元/年，以纵向项目为主；牵头获国家科技奖励11项，发表高水平论文2000余篇，专利申请1600余件、授权1300余件；20个科研团队中年度经费过千万元的15个、过亿元1个。
- 平台与交流：2个国家级平台（国家电磁辐射控制材料工程技术研究中心、微波电子器件国家级重点实验室）、4个国际合作平台、7个省部级科研平台；共建国际姊妹院系2个（香港大学电机工程电子系、香港城市大学电子工程系），主办高水平国际会议13场，学生长短期交流项目20多个。

**柳教授（电子信息材料与元器件方向）**
- 方向内涵：以电子在物质中的输运特性（电磁声光热力、化学生物）为基础，设计、研究和生产电子器件，以材料为基础、器件为核心、应用为目标导向。
- 行业背景：2021年中国集成电路电子产品进口额度达2.8万亿元，约为原油进口量的1.7倍，先进电子材料元器件电路系统等是我国最紧迫的卡脖子问题之一。
- 应用领域：6G通讯、量子技术、智慧城市、光电技术、新能源、智能电子等，广泛用于物联网、移动设备、网络基础设施、无人驾驶、航空航天、医疗健康、可穿戴设备，市场规模达万亿美元量级。
- 发展趋势：电子产品向小型化、多功能、低功耗、智能化发展，元器件向微型化、片式化、集成化、薄膜化、智能化发展，强调材料和器件一体化，集成技术结合摩尔定律与超摩尔定律。
- 研究队伍：国家级人才10余人，两个团队。邓龙江院士团队（电磁辐射控制材料与技术）研究人员19人（正高13人、副高15人），发表含Nature在内论文300余篇，承担课题130余项，年均到账经费3000多万元，授权发明专利100余项，获国家科技进步奖或技术发明奖二等奖共3项；张怀武教授团队（磁电薄膜与微型器件）研究人员17人（正高15人、副高2人），研究LTCC材料及集成技术、微波毫米波晶圆及器件、自旋电子与磁量子器件、传感器芯片等，承担项目100余项，获科技进步二等奖3项，发表SCI论文400余篇，年均到账经费2000余万元。
- 平台条件：国家电磁辐射控制材料工程技术研究中心（1990年校级中心，2008、2013年两次升级）开展多频谱涂层、电磁材料与结构、智能材料与结构研究，有成都嘉驰电子科技等成果转化基地；电磁薄膜与集成器件全国重点实验室（2006年依托三个部级重点实验室筹建）三个重点方向为电子聚合物与阵列传感器、功率半导体与集成技术。科研面积2万余平米（超精尖3000平），两条国家重大任务试验生产线，大型设备/系统500余台套。
- 成果与去向：获国家技术发明奖等共7项，每年在Nature及子刊发表多篇重要文章；毕业生去向包括英特尔、中芯国际、华为、德州仪器等企业及高校科研院所。

**张教授（电磁场与微波技术、电路与系统方向）**
- 专业构成：电磁场与微波技术含4个细分方向（微波毫米波电路、电波传播与电磁兼容、计算电磁学与工程电子学、天线理论与技术），电路与系统含3个方向（非线性电路与复杂电子系统、射频微波电路与系统、集成电路与系统）。
- 学科沿革：电磁场与微波技术学科始于1956年建校时期，由林为干先生和谢处方先生创建，形成电磁场与无线技术国家特色专业和电波传播与天线国防紧缺特色专业，所属一级学科电子科学与技术入选双一流A类学科。
- 团队与平台：6个团队（电磁辐射与散射、毫米波技术与系统应用、微波毫米波集成电路与系统、电磁兼容技术、微波测试与成像技术、无线技术与集成系统）；学科平台含国家自然基金委创新群体、国家高等学校学科创新引智基地、国家工程技术研究中心、国家级重点实验室；硬件平台含中国高校最先进的微波暗室群体、先进的微波毫米波太赫兹仿真测试平台。
- 研究成果：杨世文教授团队四维天线阵列技术应用于中电14所某大型机载相控阵雷达，电磁测井仪器获国家科技进步二等奖并在中海油推广应用，计算电磁学算法被评为20世纪十大算法之一；樊勇教授团队研制0.22THz、0.34THz、0.42THz雷达成像系统（分辨率小于1厘米），太赫兹通信成果在2023年成都大运会田径项目示范应用；延波教授团队引领微波毫米波太赫兹芯片研究，获国家科技重大专项及军科委支持，研制三毫米导引头前端、毫米波引信前端、8毫米宽带收发前端；李恩教授团队引领微波毫米波测量技术（60多年积累），在生物医学电磁学及成像方向发表大量高水平论文及20余项国家发明专利。
- 电路与系统学科：1981年开始招收研究生，1988年成立首批博士后流动站，含教育部国际合作联合实验室、国家高等学校学科创新引智基地，国家级人才4人、新世纪人才2人、教授10人、副教授22人；樊勇教授和李廷军教授团队从事高速磁浮交通38GHz车地通信系统研制，樊勇教授和张静（本人）团队研究毫米波通信雷达CMOS芯片，康凯教授团队研究毫米波CMOS芯片（超宽带模块级芯片、5G通信系统和雷达系统）。
- 人才培养：连续三年获全国大学生集成电路创新创业大赛奖项，获华为优秀合作项目奖、研究生优秀导学团队提名奖，学生获互联网+奖项、国际HPV奖项等；就业面向华为、中兴等领军企业、研究所、高校，毕业生海外留学有突破。

**李天明教授（物理电子学方向）**
- 学科定义：物理电子学是物理学与电子科学与技术的交叉学科，将物理学最新研究成果应用于电子学产生新电子器件，如微波电子学（微波电真空器件）、光电子学（光电器件）；学科内容不断充实（如量子电子学），边界不清晰（光电子学也可属光学工程），具有基础性与前沿性，是支撑现代信息技术的关键技术学科。
- 历史沿革：1956年建校时在前苏联专家帮助下成立电真空器件专业，归属电子器件系；1979年刘盛纲院士带领成立高能电子学研究所；2001年物理系、应用所、高能所成立物理电子学；2018年物理电子学院、电工学院、微固学院部分成立电子科学与工程学院。
- 发展方向：纵向发展（上游仿真设计、数字模拟材料，下游系统应用），拥有自主知识产权商用软件MMST和切皮克，引入人工智能到器件设计和电子学应用；系统应用包括毫米波雷达（回旋行波管）、无线输能系统（行波管）、微波能干燥系统（磁控管）。横向发展：频段从微波上移至毫米波、太赫兹，与医学交叉做太赫兹成像提高诊断准确性，利用太赫兹宽频带做保密通信、高速通信。
- 平台与成果：3个四川省工程中心或重点实验室，参与成立行业协会；每年到校科研经费接近2亿元（为学院最多），是国际上最大的真空器件研究中心，2023年成功举办行业顶级会议；物理电子学方向共9个团队。
- 学生出口：团队学生约1/3硕博连读、1/3去企业、1/3去研究所或其他（公务员等）；个人每年约2个硕士毕业、1个博士毕业。

**田雨桐（在读博士，学生视角）**
- 城市因素：成都是四川省会、国家中心城市、新一线城市、国家历史文化名城、古蜀文明发祥地、中国十大古都之一，宣传标语“成都都成”指梦想都成；电子信息是朝阳行业，成都站在国内电子信息产业发展前端，英特尔、华为、京东方等巨头汇聚，提供实践平台和就业资源。
- 学校与专业：电子科技大学是我国电子信息人才培育的代名词，有电子信息博物馆记录我国第一台晶体管收音机诞生，构建了最完整的电子信息学科群；电子科学与技术学科在第4轮学科评估中获A+，稳居全国第一，拥有五大国防特色学科。
- 团队与培养：选择导师时考虑研究方向契合和志同道合，作者所在毫米波技术与系统应用团队在樊勇老师带领下，围绕微波毫米波理论与技术、天线理论与技术、元器件与电路、通信技术与系统、雷达成像技术与系统五大方向开展研究；学生可学到从芯片、封装、天线、电路、模块到系统的全面知识，作者从事毫米波雷达通信信号处理研究，可自主做雷达或无线通信系统。
- 就业与生活：团队硕博毕业生实现100%就业率，就业单位有民营企业、大型央国企和头部科研院所；2021年跨年学校主楼前300架无人机灯光秀拼出UESTC字样。
- 奖助体系：学院构建全覆盖、高额度、长周期的奖助体系，包括国家奖学金、学业奖学金、专项奖学金、新生奖学金、校园地国家助学贷款和生源地助学贷款。
- 择校建议：先选研究团队再选导师，学院有四大学科和19个科研团队，可从学院网站选择团队，再进入团队网页找导师；可用IEEE Xplore和中国知网检索导师论文和指导研究生毕业情况。
