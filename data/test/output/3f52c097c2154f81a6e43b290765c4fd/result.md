# 复盘目标与结果概况
本次复盘会为年终总结与表彰大会，预期目标为总结2023年度经营状况、公布年终奖与奖项、进行部门评价与展望。实际结果：年终奖总额226,000元，个人数额不一一公布；全年实打实支出390万元，利润率约24%或27%，成本控制较差；最高到手工资约20万元（两三人），平均到手工资1万多元；2023年公司总量提升、员工到手收入提升，但成本上升、结余缩水，尚有百来万未收回。老板自评对员工关心关注不够、管理不够雷厉风行，成本控制问题明年开会再议。会议逐一点评员工并颁发奖项，各部门总结展望，最后抽奖结束。

# 亮点事项
超出预期的成果包括：短视频账号粉丝大幅增长，视频号从719人增至8万，小红书从2000+增至6.4万，抖音从2000+增至5.7万，B站从3.1万增至7.6万，且账号变现课程评分约7.5分（满分10分），直播平均在线5000人以上；商务部门实打实项目约300万元；员工整体表现获认可，如刘腾宇获最佳员工奖、李海腾获特别贡献奖。促成成功的关键动作：郭东辉在6月20日说服老板到外面拍摄，破釜沉舟推动转型，并坚持不放弃；老板对员工认真评价、准备证书与红包，增强仪式感；对后期部门侧重奖励，激励员工。最具复用价值的经验：**坚持突破舒适区，用数据支撑决策，主动说服上级并持续投入**。

# 不足事项
未达预期的环节包括：成本控制非常差，利润率低，公司结余缩水，有百来万未收回；老板对员工关心不够，管理不够雷厉风行；加班多，人员不足，判断失误；外援成本高，内部人员参与拍摄不足。现象 → 根因：成本高企 → 老板对成本关注不够，未及时解决问题；加班多 → 人员不足，老板判断失误，未及时招合适人数；外援成本高 → 内部人员技术水平不足或参与意愿低。关键根因：**老板管理不够雷厉风行，对问题未及时解决**；**人员配置不足，判断失误**。

# 改进计划
后续改进计划：明年开会讨论成本控制问题；短视频账号明年开始变现，老板投入更大精力；执行部门老板更多组织协调，减少侵占休息时间；商务部门老板给予更多支持和帮助；鼓励全员参与拍摄，提升内部人员拍摄能力以减少外援成本；对后期部门在年终奖和奖项上有所侧重。责任人：老板（成本控制、组织协调、支持商务）、郭东辉（账号变现）、林海腾（后期安排）。时间：明年（具体时间无）。
