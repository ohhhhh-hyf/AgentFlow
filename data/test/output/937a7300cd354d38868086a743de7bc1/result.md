# 全文摘要
本次会议为景城苑小区物业招标答疑及评标会，由业委会组织，两家物业公司（富家物业、资平物业）分别就业主关心的改造计划、承接查验、停车管理、安防监控、杂物堆放等问题进行解答。富家物业承诺一年内完成主要改造，提出分析乱停原因、增加停车位、增设隔离墩、建设外围停车场、增设电动车停车场等措施；资平物业计划进场一个月内集中整改环境绿化，半年内处理设备设施，八个月内完成主要改造，一年内达到有序状态，并提出收集业主车辆信息、制定停车管理方案、升级道闸系统等措施。评标委员会打分后公布结果：第一名中标候选人为深圳市资平物业发展有限公司，第二名长沙富佳物业管理有限公司72.91分，第三名湖南恒基居业物业管理有限公司60.73分，第四名重庆新东源物业管理有限公司54.48分。打分环节全程保密，暂停网络直播，录像材料不予公开，总评委打分去掉一个最高分和最低分。

# 要点梳理
## 富家物业答疑

1. **改造计划与时间**：富家物业预计在一年内完成全部改造项目，具体12大改造点详见标书第117页。
2. **停车管理问题**：先分析乱停原因（停车位不够、距离远或业主不自觉），停车位不足则增加停车位；业主不自觉则派保安和客服现场说服、劝阻、纠正。
3. **停车管理具体措施**：大门口增设人行门禁系统（支持手机微信、刷卡、密码进出）；升级大堂报到系统，业主车辆信息统一录入管理，临时车辆由安保登记后放行；地面增设隔离墩，禁止公共场所停车，保障消防通道和人行通道畅通；建设外围停车场并安装停车管理系统；增设电动车停车场（考察发现电动车乱停与停车位不足有直接关系）。
4. **承接查验与交接**：提前两周项目负责人入场摸底；提前一周服务人员安排到位并培训；交接不畅时先与原物业私下沟通了解诉求，公司间无法解决则请业委会或街道社区组织协调会；仍无法解决时，在获得业委会、业主大会及街道社区许可下采取强制措施。
5. **安防监控问题**：通过增设门禁系统、升级报到系统、增设隔离墩、建设外围停车场、增设电动车停车场五方面改善。
6. **业主满意度与收费率**：采取「用心倾听、如实记录、马上处理、及时反馈」四句话方法处理业主投诉，处理完成后及时向业主反馈完成时间，业主可联系确认。

## 资平物业公司介绍

1. **公司概况**：资平管理成立于2004年，总部在深圳，为全市场化物业公司（无开发背景），全国367个项目，其中127个为业委会项目；公司创始人陈志平先生原为万科物业创始人，曾协同建立中国第一个业委会；公司为中国物业管理协会副会长单位、全国百强企业。
2. **管理理念**：打造「让一线权利归还业主」，确保财务透明（包干制每季度公示物业管理费、停车费等财务信息）和管理透明（业委会授权事项及外包标准让业主代表参与）。
3. **团队配置**：景城苑项目编制16人，薪酬福利保证高于同类及周边项目；所有一线人员直招不外包（长沙项目有外包影响服务品质的经验教训）。

## 资平物业改造计划

1. **四步举措**：第一步「洗理静音」——进场第一个月调动湖南战队其他项目人员资源，对小区环境、绿化、清洁、杂物进行全面清扫，保证感官上干净整洁有序；第二步「疏金活选」——调动集团设备公司水电、给排水、电梯、消防工程师，对小区所有设备设施全面排查诊断，在投资范围内集中改造；第三步「疑难杂症」——涉及消防、渗水等重大问题，全面检查后提供意见，经业委会授权或业主大会招投标解决；第四步「有效提升」——将总部管理标准和前沿管理经验延续到项目。
2. **改造时间表**：进场一个月内完成环境绿化集中整改；半年内处理设备设施问题；八个月内完成主要改造；一年内保证小区达到有序状态。
3. **特色管理系统**：全面导入顾客管理系统，业主投诉、咨询、报事集中到系统，通过专线电话保证有人处理、有人回访、有人跟进；根据月度投诉报事数据形成大数据库，指导下月工作重点。
4. **社区文化活动**：针对小区老龄群体开展活动（如教老年人发抖音）；按不同团体（跳舞、打篮球等）打造社区社团；公司硬性标准为每两个月开展一次社区文化活动。

## 资平物业答疑

1. **改造措施**：进场第一个月对环境绿化全面整改（补种绿化、清理楼道杂物、清除牛皮癣）；利用集团工程师资源全面排查设备设施，投资款内快速整改，需动用维修资金的与业主沟通或启动业主大会授权；针对业主和业委会关注的问题优先整改。
2. **包干制经验**：公司在湖南有11个项目（长沙11个），其中10个为包干制、1个为酬金制；包干制下同样保证财务透明和业主知情权；团队30%管理干部从现有人员选拔，60%左右为现有物业优秀员工或重新招聘。
3. **公益服务**：长沙所有项目提供居家上门服务，员工免费，材料费由业主自付或公司购买；提供家政服务及24小时业主护送服务，有偿与无偿业务均有开展。
4. **承接查验**：前期与社区街道和派出所沟通；与现有物业和业委会明确设备设施、债务债权；按专业线分专业组查验，调动集团工程师协助查出问题；承接查验期间在16人团队基础上增派150%人员；已有成熟的承接查验小组和标准流程。
5. **安防与停车管理**：关键岗位（门岗、门勤岗、车务）用老员工，保证责任心和担当意识，对来访人员和车辆进行管控、登记、核实后放行；收集业主车辆信息，制定小区整体停车管理方案（含禁区停放）；升级道闸系统识别外来人员和业主亲戚来访；通过设备公司和技术手段加强关键部位监控。
6. **楼层杂物与晾晒问题**：宣传引导为主，通过上门宣传、海报、法律知识宣传让业主明白堆放杂物的风险和法律后果；联合社区应急管理部门采取行动；与业主充分沟通，给予处理杂物的时间段；可设置临时堆放区供业主短期存放（贴纸条注明临时存放、限期解决）；以疏导而非强制方式处理，避免激发矛盾；计划设置集中晾晒区满足业主晾晒需求，可提供免费上门晾晒增值服务（业主预约后早上拉出、晚上收回）。

## 结论与决定

1. 评标确定深圳市资平物业发展有限公司为中标候选人。
2. 第二名长沙富佳物业管理有限公司72.91分，第三名湖南恒基居业物业管理有限公司60.73分，第四名重庆新东源物业管理有限公司54.48分。
3. 打分环节全程保密，暂停网络直播，录像材料不予公开。
4. 总评委打分去掉一个最高分和最低分。

## 待确认与风险

1. 小区存在监控门禁失效，导致人员车辆随意进出。
2. 小区停车管理混乱，存在车辆乱停、电动车乱停现象。
3. 楼层顶层存在堆放杂物和乱搭乱晒问题，可能引发矛盾。
