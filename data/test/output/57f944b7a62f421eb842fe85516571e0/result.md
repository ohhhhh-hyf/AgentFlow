# 参观概况
本次讲解为故宫保姆级游览攻略，覆盖午门、太和殿、乾清宫、珍宝馆等主要景点，介绍历史背景与建筑特色。午门为明三暗五结构，中间正门仅供皇帝、皇后大婚及殿试前三名通行；太和殿为举行盛大典礼的金銮殿，文武百官文东武西站立；乾清宫为皇帝寝宫，正大光明牌匾后藏立储诏书；珍宝馆为乾隆养老院，皇极殿1:1复刻乾清宫，乐寿堂是唯一可进入参观的皇家寝室。讲解标注了七个免费盖章位置，并推荐三条游览路线，供游客按时间选择。

# 核心看点与讲解
**午门**：三个门洞，进门后变五个，即明三暗五；中间正门仅供皇帝、皇后大婚、殿试前三名通行，两侧门走皇亲国戚和文武百官。
**太和门广场**：五座金水桥，中间桥供皇帝，两侧桥供皇亲国戚和文武百官；太和门为明朝御门听政处，门口铜狮子为故宫六对铜狮中最大一对。
**太和殿**：金銮殿，举行皇帝登基、皇后册封等盛大典礼，文武百官文东武西站立；中和殿为皇帝休息室。
**保和殿**：乾隆五十四年起为殿试考场，东北角汉字馆有4枚免费印章，可购买紫禁城100并现场盖章。
**乾清门**：皇帝上早朝处，东侧九卿直房，西侧军机处，门口狮子耳朵耷拉、眉毛遮眼警示后宫。
**乾清宫**：皇帝寝宫，27张龙床，正大光明牌匾后藏立储诏书；交泰殿放25块传国玉玺；坤宁宫为皇后住所，东北角文创店有5枚免费印章。
**储秀宫**：慈禧住20多年，五十大寿原状陈列，旁边文创店有3枚免费印章；翊坤宫、永寿宫、太极殿为东西六宫，太极殿是唯一称殿的。
**慈宁宫**：康熙为孝庄皇太后修建，旁边寿康宫为甄嬛居住；冰窖书吧有3枚免费印章。
**断虹桥**：网红打卡地，石狮子形态各异，最有名武当狮；武英殿改陶瓷馆，目前关闭；文华殿我去时未开，据说有展览。
**箭亭**：清朝皇帝练习骑马射箭，旁边商店有文创雪糕；钟表馆展示各种钟表。
**珍宝馆**：宁寿全宫，乾隆养老院，皇极殿1:1复刻乾清宫，乐寿堂是唯一能进去参观的皇家寝室，珍妃井在出口附近。
**东筒子夹道**：拍照出片；延禧宫、景仁宫为网红打卡地，甄嬛、珍妃曾住。
**御花园**：钦安殿供奉真武大帝，景山酷似真武大帝；神武门为故宫北门，出门左手边角楼咖啡和故宫文创各有2枚免费印章。

# 互动与体验
**盖章互动**：讲解标注七个免费盖章位置，包括保和殿东北角汉字馆4枚、坤宁宫东北角文创店5枚、储秀宫旁文创店3枚、冰窖书吧3枚、珍宝馆出口右手边商店3枚、神武门出门左手边角楼咖啡2枚、故宫文创2枚。
**文创体验**：在汉字馆可购买紫禁城100并现场盖章，每家店印章不同，购买后不能去其他店铺盖章；在冰窖书吧购买了冰溪图，盖章时有批折子的感觉。
**拍照打卡**：太和门铜狮子造型威武，建议单独拍照；东筒子夹道拍照出片；断虹桥武当狮可寻找。
**个人感受**：钟表馆的钟表造型令人开眼；珍宝馆宝贝惊艳，但游客太多，看凤冠需挤进去；一天走3万步，需适当休息和补充水分。

# 收获与建议
**知识增量**：午门明三暗五结构及通行规则；太和殿为典礼场所而非上朝处；乾清宫正大光明牌匾后藏立储诏书；珍宝馆为乾隆养老院，乐寿堂是唯一可进入参观的皇家寝室。
**游览建议**：建议早起排队一进门沿中轴线往后走，可错开旅游团；三条路线按时间选择，第一条适合一整天，第二条约半天，第三条约2小时最省力。
**盖章建议**：标注七个免费盖章位置，供章友截图保存；汉字馆印章数量最多，购买紫禁城100后不能去其他店铺盖章。
