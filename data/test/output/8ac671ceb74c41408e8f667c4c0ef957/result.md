# 就诊概况

患者为结肠癌术后转移患者，本次由家属陪同就诊，讨论后续治疗方案。患者于2023年9月因腹痛（疼了一晚上）确诊结肠癌，行结肠癌切除手术，术后完成8期化疗；复查发现肝转移，从老家来北京做PET-CT，去年9月行肝消融和乳腺结节切除，当时存在腹膜转移，肠切除可能不干净。消融和结节切除后行紫杉醇化疗，但仅第一次检查，后续因肝功能不行停用靶向药；3月底复查发现肝、肺、腹膜再次转移，4月份检查显示广泛转移。医生初步判断当前核心是全身系统治疗，建议进行基因检测与免疫评估，而非局部介入。

# 病史与背景

- **现病史**：2023年9月因腹痛（疼了一晚上）确诊结肠癌，行结肠癌切除手术，术后完成8期化疗。
- **既往史**：多年来吃东西易中毒，如吃海鲜会上吐下泻，一直被认为肠胃比较弱。
- **手术史**：结肠癌切除手术；去年9月行肝消融和乳腺结节切除；肠切除时可能切得不是特别干净，当时存在腹膜转移。
- **转移情况**：术后复查发现肝转移，从老家来北京做PET-CT；3月底复查发现肝、肺、腹膜再次转移；4月份检查显示广泛转移，肝上、肺上、腹膜均有。
- **近期用药**：消融和乳腺结节切除后行紫杉醇化疗，但仅第一次检查，后续因肝功能不行停用靶向药，中间停药3个月。

# 诊断与检查结果

- **诊断结论**：患者为结肠癌术后转移，当前存在肝、肺、腹膜广泛转移。
- **检查结果**：PET-CT显示肝转移；4月份检查显示广泛转移；上个月肠镜显示没事，但PET显示有问题，医生认为可能是肠镜做得不好。
- **基因检测**：医生建议做基因检测，特别是针对转移灶的二次检测，以提高检出率；检测可通过血液、尿液、唾液等进行。
- **免疫评估**：医生强调免疫细胞状态重要，数量不足需提升质量；建议做免疫评估，但方案由患者决定。

# 治疗方案与医嘱

- **全身系统治疗**：医生强调当前核心是全身系统治疗，包括化疗、靶向、免疫，局部介入（如肝消融）不是当前主要问题；若肿瘤增长至10公分或危及生命，才考虑局部处理。

- **免疫评估**：建议做免疫评估，但方案由患者决定。
- **生活方式**：建议患者提升免疫力，调整好状态。
- **复诊与陪同**：患者今早查了血。
