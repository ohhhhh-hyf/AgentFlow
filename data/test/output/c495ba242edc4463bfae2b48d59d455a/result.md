# 讲座概况
本期视频由主讲人李正（正直讲史）讲述康熙朝文渊阁大学士陈廷敬的一生，分为母亲张氏开蒙、圣祖康熙的讲师、至公无私的落幕三个阶段。陈廷敬本名陈敬，字子端，号午亭，1638年生于山西泽州府阳城县，书香门第，六代读书人。影视剧中支持撤藩、招抚台湾、征剿噶尔丹等功绩均非史实，但康熙临终前仍询问是否有类似陈廷敬的大臣。陈廷敬童年由母亲张氏开蒙，6岁前已背诵《论语》《孟子》《大学》《中庸》《诗经》，14岁以全省第一考中秀才，20岁中举，21岁中进士入翰林。入翰林后因与直隶通州陈敬重名，主动上书改名，顺治赐“廷”字。重返官场后，康熙六年考察一等，升国子监司业，整顿收礼陋习；康熙11年充日讲起居注官，康熙15年充经筵讲官，教学风格外放。康熙16年任翰林院掌院学士，同年母亲去世，康熙破例派大臣祭奠并追封学士品级。康熙23年任左都御史，上奏捐纳者需考试，获康熙支持并扩大至已任官员。康熙26年亲家张谦贪污案牵连陈廷敬，康熙令密查不蔓延，陈廷敬主动辞官，一年后复任左都御史。康熙42年任文渊阁大学士，总理南书房，70岁起四次申请退休，康熙49年准奏并赐匾联。75岁病逝，谥号文贞。

# 核心观点与论证
讲座按时间顺序分三阶段展开。第一阶段“妈妈张氏的开蒙”：陈廷敬母亲张氏自幼随父张弘毅读书，精通儒家经典，婚后勤学不辍，亲自教授陈廷敬，6岁前已背诵《论语》《孟子》《大学》《中庸》《诗经》，9岁作诗《咏牡丹》获母亲称赞。14岁以全省第一考中秀才，20岁中举，21岁中进士入翰林。入翰林后因与直隶通州陈敬重名，主动上书改名，顺治赐“廷”字，顺治18年庶吉士毕业考试获第一，授秘书院检讨。第二阶段“圣祖康熙的讲师”：康熙六年考察一等，两年后升国子监司业，整顿收礼陋习；康熙11年充日讲起居注官，康熙15年充经筵讲官，教学风格外放，曾痛骂孙权背刺关羽；康熙16年任翰林院掌院学士，同年母亲去世，康熙破例派大臣祭奠，礼部反对后坚持追封学士品级。第三阶段“至公无私的落幕”：康熙23年任左都御史，上奏捐纳者需考试，获康熙支持并扩大至已任官员；后历任工部、户部、吏部尚书，整顿各领域；康熙26年亲家张谦贪污案牵连陈廷敬，康熙令密查不蔓延，陈廷敬主动辞官，一年后复任左都御史；康熙42年任文渊阁大学士，总理南书房，70岁起四次申请退休，康熙49年准奏并赐匾联“午亭山村”和楹联“春归乔木浓阴茂，秋到黄花晚节香”；75岁病逝，谥号文贞。核心概念如“捐纳”“日讲起居注官”“经筵讲官”等均基于原文。

# 金句总结
“朕日望大学士病体速愈，在佐朕料理机务几年。若事出意外，大臣中学问人品如大学士可代理内廷事务者为谁？”——康熙在陈廷敬临终前询问是否有类似大臣，体现对其学问人品的极高信任。“自古未有不晓文艺之人可以为民父母者也”——陈廷敬主张捐纳者需考试，强调父母官必须有文化。“我贤与虽折且怨，庸何伤”——陈廷敬表示只要人是对的、事是好的，即便遭受挫折和埋怨也无所谓。“苟正其身矣，于从政乎何有？”——引用《论语》，强调自身品行端正则治理政事不难，呼应陈廷敬一生清廉。
