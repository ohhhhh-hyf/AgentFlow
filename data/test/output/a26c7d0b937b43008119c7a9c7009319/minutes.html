372班家长会：家校协同促成长

沟通概况

班主任林瑞在372班家长会上向家长介绍班级情况与家校协同事项。班级共60人，男生25人、女生35人，学生处于生理心理持续变化的初中阶段；整体时间观念与执行力强、班风班貌纪律良好，但少数同学存在周末玩手机游戏、思考能力差、自习课纪律差等问题。教师团队多为老教师、优秀教师，班主任林瑞任教地理学科。针对班级问题，林瑞提出解决思路：个别学生书写差已与家长沟通并建议练字；自习课效率低需加强班委培训；手机管理要求上交并请家长不定时电话检查；关注网瘾、不健康直播及谈恋爱现象。班级管理计划包括每日思想教育、制定严格班规、严格请假制度、定期家校沟通，下次月考在11月初。林瑞指出家长常见误区并给出建议，家长代表张宇波分享家庭教育经验。会议还涉及成立家长委员会（至少三人自愿）、保险购买（约310元）、电子学生证办理（套餐78元）及资助政策说明。

沟通内容

亮点

  • 时间观念与执行力：整体来看第一个月，学生时间观念、执行力加强，班风班貌纪律良好，周边环境地面干干净净，卫生状况良好。
  • 主动请教意识：学生遇到问题会积极上来问老师，会主动向老师汇报，非常关注学习。

需关注之处

  • 周末玩手机游戏：少数同学主要在周末了解和爽一玩游戏，玩累了、玩过了，显得懒散，有两三个学生手机使用过度（原文如此）。
  • 自习课纪律差：思考能力比较差，班主任在的时候学生很乖，班主任不在就乱哄哄的；需加强人员管理和班委培训。
  • 书写问题：个别学生书写差，已与家长说了，建议家长看学生手册后买字帖练字；有学生把班计划372班写成172班（原文如此）。
  • 手机管理：目前玩手机现象未发现（原文如此），要求手机上交，专门放手机箱，每个名字贴好；有学生有两个手机，家长家里可能有五个手机，家长要处理掉多余的，不要留多的。
  • 网瘾问题：发现少数男生有网瘾，星期六晚上有学生充生活费充了400元（原文如此），有学生观看不健康直播内容。
  • 谈恋爱现象：需多关注学生谈恋爱，尤其是QQ、空间朋友圈、抖音、快手等社交账号，有学生可能把家长屏蔽了。
  • 阅读不良小说：家里有的小说要管理，两个店让他看（原文如此），知道目标后把他叫出去看了（原文如此）。
  • 零花钱使用不当：少数学生生活费不是用于学习和就业，而是用于非正常消费；有男生出去过生日，喝了酒回来一身酒气还抽烟、玩手机。
  • 安全意识：未满16周岁骑电动车非常危险，有学生会载两个载三个；需注意交通安全、运动安全、饮食安全、防诈骗、防溺水、防校园欺凌。

家长反馈

家长关注的问题与诉求

  • 手机管理：班主任要求家长配合检查学生手机是否上交，可不定时打电话验证手机是否开机或有人接听，发现未交需处理；家长需清理家中多余手机，避免学生藏匿备用机。
  • 班主任建议家长周一到周五不定时打电话检查，若电话能打通但无人接听，说明手机可能未上交。
  • 班主任提醒家长关注学生手机中的内容，曾发现学生观看不健康直播，建议家长检查手机应用、QQ空间、朋友圈、抖音、快手等账号。
  • 生活费与消费：班主任提醒家长控制零花钱额度，建议每周生活费不超过150元（按每天21–24元标准计算），避免学生将钱用于买手机、玩游戏、过生日聚会等非正常消费。
  • 班主任举例：有学生一周内多次以买学习用品为由向家里要钱，实际用于其他用途；有男生外出过生日喝酒、抽烟，违反住校纪律。
  • 学生安全：班主任提醒未满16周岁骑电动车非常危险，尤其载两三个同学；要求家长提醒孩子注意交通安全、运动安全、饮食安全、防诈骗、防溺水，发现异常第一时间联系班主任。
  • 心理健康与情感：班主任建议家长关注学生心理动态，多沟通、多鼓励、少批评；关注学生是否谈恋爱，建议家长查看学生QQ、抖音、快手等社交账号是否有异常。
  • 学习习惯：班主任指出个别学生书写差，已与家长沟通，建议家长购买字帖让孩子练字；自习课效率低，需加强管理。
  • 电子学生证办理：班主任说明班级目前仅有两个老年机可用、一个已停机，建议家长办理电子学生证（移动套餐78元），方便联系学生；能办的就办，不能办的说明情况。
  • 保险购买：班主任说明保险费用约310元，家长可自行购买（校内、校外、阿里巴巴平台均可），需统计购买情况，为学生提供保障。
  • 资助政策：班主任提醒高中阶段补助打在学生医保卡上，家长需关注到账金额及用途，避免学生将补助用于不当消费。

家长原话

“无论怎样，那你都是爸爸妈妈心里最优秀的儿子，你先批评他，还是不当，这样的话他会更加的深刻，这样的话更加的深刻。”
  • 背景：家长代表张宇波在家长会上分享家庭教育经验时，讲述自己如何安慰考试失利的孩子，强调先肯定孩子再指出问题。
“要想让孩子离开，就要让他们学会怎么样做人，千万不能让他们带上不良的风气。”
  • 背景：家长代表张宇波在家长会上分享教育理念，强调教育孩子先做人、再学习。

共识与配合事项

手机与网络管理

  • [ ] 家长：配合执行手机上交制度，学生到校后手机放入贴有姓名的手机存放箱，发现未交需处理
  • [ ] 家长：周一到周五不定时拨打学生电话检查，若电话能打通但无人接听，说明手机未上交，需及时处理
  • [ ] 家长：家中多余手机（含备用机、旧机）处理掉或收好，避免学生拿旧手机应付上交、留好手机自用
  • [ ] 家长：检查学生手机内容，关注是否安装游戏、观看不健康直播或浏览不良内容
  • [ ] 家长：关注学生QQ、抖音、快手等社交账号，留意是否有谈恋爱迹象或异常动态（如被屏蔽需注意）
  • [ ] 班主任：继续加强手机管理，发现学生玩手机及时处理
  • [ ] 班主任：对少数有网瘾的男生加强关注与引导

学习与行为习惯

  • [ ] 家长：查看学生手册及作业书写情况，书写差的学生到文具店购买字帖练字
  • [ ] 班主任：加强自习课管理，加强对班委的培训，提升自习课效率
  • [ ] 班主任：继续加强思想教育工作，每天进行
  • [ ] 班主任：制定详细班规，严格执行扣分、写检讨、罚站等纪律要求
  • [ ] 班主任：严格请假制度，稳定学习秩序
  • [ ] 班主任：定期与家长沟通，了解学生各方面表现
  • [ ] 班主任：关注学生心理健康，发现异常及时进行心理辅导
  • [ ] 家长：关注学生心理动态，多沟通、多鼓励、少批评，适当给予压力但期望不宜过高或过低
  • [ ] 家长：避免教育误区——不过分关注、不放任不管、不期望过高、不给过多零花钱
  • [ ] 家长：给孩子制定容易达到的小目标（如年级排名120–190名范围），激发潜能
  • [ ] 家长：创造和睦、祥和、稳定的家庭气氛，不在孩子面前长时间玩手机，不聚众打麻将、点外卖，不在家里常备零食
  • [ ] 家长：多抽时间了解孩子在校表现，孩子犯错时引导而非指责

安全教育

  • [ ] 家长：提醒孩子注意交通安全，未满16周岁骑电动车非常危险（尤其载人），如实在要骑须单人骑行
  • [ ] 家长：提醒孩子注意运动安全、饮食安全、防诈骗、防溺水
  • [ ] 家长：关注防校园欺凌，孩子遇到问题第一时间联系班主任处理
  • [ ] 班主任：对学生安全问题进行教育提醒

费用与保险

  • [ ] 家长：保险自愿购买（费用约310元），可在学校购买或自行在菜市场、阿里巴巴等渠道购买，购买后需统计
  • [ ] 班主任：统计学生保险购买情况
  • [ ] 家长：建议办理电子学生证（移动套餐78元），方便联系；班级目前仅有两个老年机可用，其中一个已停机，另一个用班主任身份证办理尚未处理
  • [ ] 班主任：将新的电子学生证号码发到家长群，家长需重新补充登记
  • [ ] 家长：关注资助政策（已发家长群），高中阶段所有补助打在医保卡上，注意孩子收到补助后的使用情况
  • [ ] 班主任：每次补助发放时提醒家长注意金额及用途

家委会与后续安排

  • [ ] 家长：自愿报名参加家长委员会，至少需要三人
  • [ ] 班主任：家委会事项需经班主任与家长共同探讨后确定
  • [ ] 家长：下次月考在11月初，关注学生月考目标（已记录在学生手册中）
  • [ ] 家长：会后如需办理电子学生证等业务，可在3:20–3:30期间前往办理
