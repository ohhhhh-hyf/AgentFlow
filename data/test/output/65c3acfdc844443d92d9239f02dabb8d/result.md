# 参观概况
本次参观为故宫博物院一日深度游览，核心主题是故宫主要景点讲解与游览攻略分享。游览沿中轴线依次经过午门、太和门、太和殿、中和殿、保和殿、乾清门、乾清宫、交泰殿、坤宁宫，再向西至储秀宫、慈宁宫、寿康宫，随后经断虹桥、武英殿、文华殿、箭亭，参观钟表馆与珍宝馆，最后经东筒子夹道、延禧宫、景仁宫抵达御花园，从神武门结束。讲解穿插历史典故与建筑功能，如午门“明三暗五”结构、太和殿典礼功能、乾清宫立储诏书秘密等，并介绍了故宫内七个免费盖章点及三条不同时长的游览路线。

# 核心看点与讲解
- **午门**：排队检票处，明朝皇帝在此杖打犯错大臣，清朝皇帝在此颁发次年历书（颁朔之礼）。门洞呈明三暗五结构，中间正门仅供皇帝行走，皇后大婚时可进一次，殿试前三名可出一次，旁门走皇亲国戚和文武百官。
- **太和门广场**：眼前有五座金水桥，皇帝走中间，皇亲国戚走挨着中间的两座，文武百官走最边上。
- **太和门**：明朝皇帝在此御门听政，即上朝的地方。门口铜狮子为故宫六对铜狮中最大的一对，脚踩寰宇象征权力，建议单独拍照，不要站在其底下合影。
- **太和殿**：即金銮殿，是举行盛大典礼的地方，如皇帝登基、皇后册封。文武百官在太和殿广场向皇帝高呼万岁，站位遵循文东武西——文官站东边，武官站西边。
- **体仁阁与弘义阁**：东边体仁阁为缎库，西边弘义阁为银库，是皇帝的「内库」（原文如此，主讲人表述为「皇上的内库」）。
- **中和殿**：举行盛大典礼时皇帝的休息室，文武百官站好后皇帝再前往太和殿。
- **保和殿**：从乾隆五十四年开始作为科举殿试考场。东北角有汉字馆，内有4枚免费印章，可购买《紫禁城100》现场盖章，且可邮寄到家或自行带走。
- **乾清门**：过此门即后宫生活区域。东边九卿直房为等级高的大臣等待召见处，西边为军机处。门口铜狮子耳朵耷拉、眉毛遮眼，警示后宫之人不该看的别看、不该听的别听。
- **乾清宫**：皇帝平时睡觉的地方，据说有27张龙床以防刺客。牌匾「正大光明」后藏立储诏书，皇帝写两份诏书，驾崩后对比验证是否被动过手脚。门口有铜鹤铜龟及社稷江山金殿——紫禁城里最小的宫殿，提醒皇帝把江山社稷放在第一位。
- **交泰殿**：殿内放有25块传国玉玺。
- **坤宁宫**：皇后住所，明朝所有皇后都住于此。东北角文创店有5枚免费印章。
- **储秀宫**：慈禧居住20多年的地方，现为慈禧五十大寿时期原状陈列，慈禧因儿子在此出生而偏爱此处。旁边文创店有3枚免费印章。
- **翊坤宫与永寿宫**：永寿宫西边为东西六宫中唯一被称为殿的太极殿。
- **慈宁宫与寿康宫**：慈宁宫为康熙给奶奶孝庄皇太后修建的养老院，寿康宫为甄嬛（原文如此）居住地。
- **冰窖书吧**：内有3枚免费印章，印章造型有批折子的感觉。
- **断虹桥**：桥上有形态各异的石狮子，最有名的是「武当狮」（原文如此）。
- **武英殿**：后改为陶瓷馆，目前关闭状态，只能在门口观看。
- **文华殿**：与武英殿对应文东武西格局，主讲人去时未开放，据说现有一个展览。
- **箭亭**：清朝皇帝及子孙练习骑马射箭的地方，旁边商店可购买文创雪糕。
- **钟表馆**：展示那个年代的钟表造型。
- **珍宝馆**：即宁寿全宫，是乾隆给自己修建的养老院，乾隆退休后未放权仍照常上朝。皇极殿据说是1:1复刻乾清宫，宁寿宫对标坤宁宫。馆内虽称馆但不是单独展厅，院子周围屋子均可参观，游客众多，尤其凤冠展区拥挤。门口为我国现存三座古代九龙壁之一，左边数第三条白龙下方有一块木头，据说是当年烧制琉璃时弄坏一块，工匠为保命用木头刷白漆以假乱真。
- **养性殿与乐寿堂**：养性殿后有乐寿堂，是故宫里唯一能进去参观的皇家寝室，内有二龙仙楼设计。
- **珍妃井**：当年慈禧把珍妃丢进去的地方，现上头放的为井口石，珍妃并非从那个小眼进去。珍宝馆出口右手边商店有3枚免费印章。
- **东筒子夹道**：长长的夹道，拍照非常出片。
- **延禧宫与景仁宫**：延禧宫为网红打卡地，景仁宫为甄嬛被封熹妃时所住，珍妃也住过。
- **御花园**：内有钦安殿，供奉真武大帝，与北边景山酷似闭目盘坐人像的造型相呼应。
- **神武门**：故宫北门，出门左手边有两个盖章点——角楼咖啡2枚免费印章、故宫文创2枚免费印章。

# 互动与体验
- **盖章体验**：保和殿东北角汉字馆有4枚免费印章，可现场购买《紫禁城100》并盖章，工作人员现场操作，主讲人形容「盖了帽了」，并调侃乾隆喜欢盖章；故宫不止一处可买《紫禁城100》，每家店印章不同，购买后不能去其他店铺盖章，需有所取舍，据称汉字馆印章数量最多，盖完可选择邮寄到家或自行携带。
- **盖章体验**：坤宁宫东北角文创店有5枚免费印章，主讲人提醒别错过。
- **盖章体验**：储秀宫边文创店有3枚免费印章。
- **盖章体验**：冰窖书吧有3枚免费印章，主讲人表示盖章时有「批折子的感觉」，并称来之前看过网友分享，认为印章造型好看，在此购买了冰溪图。
- **盖章体验**：珍宝馆出口商店有3枚免费印章，主讲人提醒喜欢收集印章的别漏掉。
- **盖章体验**：神武门出门左手边角楼咖啡有2枚免费印章，故宫文创也有2枚免费印章。
- **拍照互动**：太和门门口铜狮子是故宫六对铜狮中最大的一对，不少人想合影，主讲人建议打消念头，因狮子脚踩寰宇象征权力，站在底下大爪子会盖在头上，单独拍张照即可。
- **拍照互动**：乾清宫门口摆放铜鹤与铜龟，不少人对着拍照，主讲人提示旁边还有两个精致小房子，即社稷江山金殿，是紫禁城里最小的宫殿。
- **打卡互动**：慈宁宫旁是寿康宫，主讲人提醒喜欢看《甄嬛传》的游客别忘了到此打卡。
- **打卡互动**：断虹桥是网红打卡地，桥上有形态各异的石狮子，最有名的是「武当狮」，主讲人邀请游客找一找它在哪。
- **打卡互动**：东筒子夹道是很多小姐姐喜欢来的拍照地点，主讲人称拍照非常出片。
- **打卡互动**：延禧宫是网红打卡地，旁边是景仁宫，当年甄嬛被封熹妃时居住，珍妃也住过。
- **文创体验**：箭亭旁商店可买到文创雪糕，主讲人提问雪糕造型是谁，欢迎在评论区分享。
- **参观体验**：珍宝馆虽名为馆但不是单独展厅，院子周围屋子都可进入参观，宝贝每样都令人惊叹；但游客太多，尤其看凤冠需「没点技术还真挤不进去」。
- **参观体验**：乐寿堂是故宫里唯一能进去参观的皇家寝室，内有二层仙楼设计，主讲人提示瞬间想到恭王府和珅的卧室。
- **参观体验**：珍妃井现上方放的是井口石，珍妃并非从那个小眼进去的。
- **参观体验**：武英殿现改为陶瓷馆，目前处于关闭状态，只能在门口看看；文华殿主讲人去时未开，据说现有一个展览，感兴趣可去看。
- **个人感受**：钟表馆的钟表造型令主讲人「开了眼」，感叹故宫宝贝不止这些。

# 收获与建议
## 历史知识与文化认知

- **午门功能**：明朝皇帝在此杖打犯错大臣，清朝皇帝在此颁发第二年历书（颁朔之礼）；午门为“明三暗五”结构，中间正门仅供皇帝行走，皇后大婚时可进一次，殿试前三名（状元、榜眼、探花）可出一次，旁门走皇亲国戚和文武百官。
- **太和门与太和殿**：太和门是明朝御门听政（上朝）的地方；太和殿是举行盛大典礼的场所（皇帝登基、皇后册封），并非上朝之地，文武百官在太和殿广场向皇帝行礼，站位为“文东武西”。
- **中和殿与保和殿**：中和殿是盛大典礼时皇帝的休息室；保和殿从乾隆五十四年开始作为殿试考场。
- **乾清宫与立储制度**：乾清宫是皇帝寝宫，内有27张龙床（据说是为防止刺客找到皇帝位置）；“正大光明”牌匾后藏立储诏书，皇帝写两份诏书，驾崩后对比验证是否被动过手脚。
- **坤宁宫与交泰殿**：坤宁宫为皇后住所，明朝所有皇后都住于此；交泰殿内放有25块传国玉玺。
- **储秀宫与慈禧**：慈禧在此居住20多年，其子在此出生；现为慈禧五十大寿时期的原状陈列。
- **慈宁宫与寿康宫**：慈宁宫是康熙为奶奶孝庄皇太后修建的养老院；寿康宫为甄嬛（历史人物）居住地。
- **珍宝馆与宁寿全宫**：珍宝馆实为宁寿全宫，是乾隆给自己修建的养老院，乾隆退休后未放权、每天照常上朝办公；皇极殿据说是1:1复刻乾清宫，宁寿宫对标坤宁宫。
- **乐寿堂与珍妃井**：乐寿堂是故宫里唯一能进去参观的皇家寝室，有二龙仙楼设计；珍妃井为当年慈禧把珍妃丢进去的地方，井口石为后放，珍妃并非从那个小眼进去。
- **九龙壁细节**：珍宝馆门口九龙壁为我国现存三座古代九龙壁之一，左边数第三条白龙下方有一块木头，据说是当年烧制琉璃砖瓦时弄坏一块，工匠为保命用木头刷白漆以假乱真。
- **断虹桥与武当狮**：断虹桥上有形态各异的石狮子，最有名的是“武当狮”。
- **箭亭与钟表馆**：箭亭是清朝皇帝及子孙练习骑马射箭的地方；钟表馆展示清代钟表造型。
- **御花园与钦安殿**：御花园内钦安殿供奉真武大帝；紫禁城靠山景山从天上看酷似闭目盘坐的人像，有人说该造型就是真武大帝。
- **其他建筑功能**：弘义阁是皇帝银库（内库），体仁阁是缎库；乾清门东边九卿直房是等级高的大臣等待召见之处，西边为军机处；乾清门门口狮子耳朵耷拉、眉毛遮眼，意在警示后宫之人“不该看的别看，不该听的别听”；社稷江山金殿是紫禁城里最小的宫殿，设于此提醒皇帝把江山社稷（百姓吃饭、民生问题）放在第一位。

## 游览建议与路线

- **拍照建议**：太和门门口铜狮子是故宫六对铜狮中最大的一对，建议单独拍照即可，不要站在狮子底下合影，因为大爪子会盖在头上。
- **第一条路线（全天）**：走完视频内提到的所有景点，适合打算在故宫待一整天的游客；建议早起排队，进门后沿中轴线往后走，可错开大批旅游团人群，一天约走3万步，游览中注意适当休息和补充水分。
- **第二条路线（半天）**：进门沿中轴线往后走，看完坤宁宫后去看景仁宫和延禧宫，接着逛钟表馆和珍宝馆，出来直奔御花园，从神武门出，约半天时间逛完。
- **第三条路线（约2小时）**：进门沿中轴线往后走，看完坤宁宫后去储秀宫，出来去御花园，从神武门出，最省力，预计2小时左右逛完。
- **延禧宫与景仁宫**：延禧宫为网红打卡地；景仁宫是当年甄嬛被封为熹妃时所住，珍妃也住过此地。
- **东筒子夹道**：拍照非常出片，很多游客喜欢来此打卡。
- **陶瓷馆状态**：武英殿改为陶瓷馆，目前处于关闭状态，只能在门口看看；文华殿据称有展览，可前往参观。

## 盖章与文创

- **盖章点汇总**：故宫内共有七个免费盖章位置——保和殿东北角汉字馆4枚、坤宁宫东北角文创店5枚、储秀宫边文创店3枚、冰窖书吧3枚、珍宝馆出口商店3枚、神武门出门左手边角楼咖啡2枚、故宫文创2枚。
- **紫禁城100购买规则**：故宫不止一处可购买紫禁城100，每家店印章不同；购买后不能去其他店铺盖章，需有所取舍；汉字馆印章数量据说是最多的，盖完后可选择邮寄到家或自行带走。
- **冰窖书吧体验**：印章造型好，盖章时有“批折子”的感觉；主讲人因已购买紫禁城100，在此购买了冰溪图。
- **文创雪糕**：箭亭旁边商店可购买文创雪糕。
