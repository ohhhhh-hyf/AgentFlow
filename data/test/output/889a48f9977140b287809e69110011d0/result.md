# 发布会概况
王毅在慕尼黑安全会议发表讲话并答问，借用今年慕安会报告主题「走向多极化」，指出联合国会员国从成立时51个增至193个，多极化既是历史必然也正在成为现实，中国给出的答案是推动平等有序的世界多极化，并就此提出四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。王毅表示中国必将是多极体系中的确定性因素，将坚定做变革世界中的建设性力量；中方始终认为欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手，今年是中欧建交50周年，中方愿同欧方用好这一契机深化战略沟通和互利合作。答问环节王毅就联合国与国际秩序规则、乌克兰问题、中美关系分别作出回应，强调中国是现行国际秩序受益者，主张通过对话政治解决乌克兰危机，对美政策保持连续性和稳定性、按相互尊重、和平共处、合作共赢三原则构建稳定健康可持续双边关系。

# 核心信息
王毅在慕尼黑安全会议提出四点看法。一是倡导平等相待，坚持权利平等、机会平等、规则平等，主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权，称这不会导致西方缺失而将促进世界正和。二是尊重国际法治，称联合国宪章宗旨和原则是国际关系根本遵循和建设多极世界的重要基石，批评有些国家迷信实力至上、打开丛林法则潘多拉盒子，强调国家不论大小强弱都是国际法治利益攸关方，大国要带头讲诚信讲法治、摒弃言行不一和零和博弈；中国加入几乎所有普遍性政府间国际组织和**600多项**国际公约，不搞例外主义、不搞合则用不合则弃；强调在遵守国际法上不能搞双重标准，尊重各国主权和领土完整就应支持中国实现完全统一。三是践行多边主义，称没有国家能独善其身、搞本国优先只会造成各方多数，联合国是践行多边主义、推进全球治理的核心平台，应固本强基而非拆梁毁柱、共担责任而非唯利是图、团结应对而非阵营对抗；中国承担超过**20%**的联合国会费，履行`巴黎协定`，建成世界最大清洁发电体系，提出并落实`全球发展倡议`、`全球安全倡议`、`全球文明倡议`。四是坚持开放共赢，称发展是破解各种难题的钥匙，保护主义不是出路、滥加关税没有赢家、脱钩断链断的是机遇、小院高墙封的是自己，应以普惠包容的经济全球化支撑平等有序的世界多极化；去年中国GDP增长**5%**，对世界经济增长贡献率接近**30%**，愿推动高质量共建`一带一路`同欧盟`全球门户`战略相互对接。
