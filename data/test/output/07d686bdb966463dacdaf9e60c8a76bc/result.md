# 讲座概况
本次分享会由发言人1主讲，围绕朝鲜半岛从分裂到朝鲜战争爆发、停战及今日朝韩格局展开。1945年二战结束、日本投降后，美苏军队分别进入朝鲜南北，以北纬38度为基准形成三八线；1949年新中国建立后宣布废除列强在华租界与特权，涉及苏联在东北的中长铁路及大连旅顺利益，苏联遂鼓动朝鲜进攻韩国，希望以仁川或釜山类似城市替代旅顺大连地位并继续在亚洲发挥影响力。1950年6月北朝鲜军队率先越过三八线向南进攻，朝鲜战争爆发，各方称谓不同：朝鲜称祖国统一解放战争，中国称抗美援朝，韩国称625事件，美国及西方国家称朝鲜战争或韩战，台湾地区称韩战。战争进程方面，朝鲜人民军从三八线打到洛东江环形防御圈（今大邱到釜山一带）；1950年9月15日美军仁川登陆成功，麦克阿瑟任联合国军总司令，另有十六个国家共同出兵；中国决定以志愿军形式出兵，1950年10月19日跨过鸭绿江，10月25日与韩国军队第一次交火，11月5日第一次战役结束，此后进行第二次战役（长津湖战役）、第三次战役越过三八线占领汉城（今首尔）、仁川、水源一带，扩展至三七线（北纬37度）；第五次战役为最后一次大规模战役，1953年7月27日双方正式达成停战协定，延续至今，朝韩名义上停战，未实现真正和平。问答环节延伸讨论了朝鲜战争影响、朝韩旅游与朝鲜现状、朝鲜半岛文明与历史沿革、南北割裂的历史渊源、美国对朝鲜的态度、朝韩统一畅想、中俄朝关系与图们江出海口、韩国军队在朝鲜战争中的作用、中国选择抗美援朝而非收复台湾的原因等议题。

# 核心观点与论证
论点一：朝鲜半岛分裂与三八线由来。1945年二战结束、日本投降后，美苏军队分别进入朝鲜南北，以北纬38度为基准形成三八线；1949年新中国建立后宣布废除列强在华租界与特权，涉及苏联在东北的中长铁路及大连旅顺利益，苏联鼓动朝鲜进攻韩国，希望以仁川或釜山类似城市替代旅顺大连地位并继续在亚洲发挥影响力。

论点二：朝鲜战争爆发与各方称谓。1950年6月北朝鲜军队率先越过三八线向南进攻，朝鲜战争爆发；朝鲜称祖国统一解放战争，中国称抗美援朝，韩国称625事件，美国及西方国家称朝鲜战争或韩战，台湾地区称韩战。

论点三：战争进程与主要战役。朝鲜人民军从三八线打到洛东江环形防御圈（今大邱到釜山一带）；1950年9月15日美军仁川登陆成功，分割包围并逐次歼灭朝鲜人民军，收复三八线以南韩国领土；麦克阿瑟任联合国军总司令，美军以联合国军身份参战，另有十六个国家共同出兵；美军越过三八线招致中国强烈不满。中国决定以志愿军形式出兵，1950年10月19日跨过鸭绿江，10月25日与韩国军队第一次交火，11月5日第一次战役结束；此后进行第二次战役（长津湖战役）、第三次战役越过三八线占领汉城（今首尔）、仁川、水源一带，扩展至三七线（北纬37度）；后期美军反攻，双方鏖战于三七线和三八线之间；第五次战役为最后一次大规模战役，结束后双方在三八线基础上互有攻防，形成今日朝韩边境。西部中朝方面向南占领开城、延安半岛和望京半岛一带；东部美军向北占领今韩国襄阳地区及金刚山地区。1953年7月27日双方正式达成停战协定，延续至今，朝韩名义上停战，未实现真正和平。

论点四：朝鲜战争的影响与评价。从中国角度奠定强国地位，美国再不敢小瞧中国；1967年越南战争时期中国警告美国不得越过北纬17度线，美国未敢越过；美国称此战为被遗忘的战争，联合国军最后一任司令官马克·克拉克承认是美国历史上第一次未取得胜利情况下签署停战协议的司令官；伤害最深的是朝鲜和韩国，一脉相承的血肉同胞分裂成两个国家，三八线悲剧延续至今。

论点五：南北割裂的历史渊源。美苏都希望在朝鲜半岛建立缓冲区；美国在三八线以南单独建立韩国以保护日本免遭苏联及共产主义势力影响，苏联在朝鲜北部建立卫星附属国，对苏联马首是瞻；最初设想不同占领区受降后像奥地利那样普选建立统一民选政府，但美苏关系急转直下，所扶植领导人各有心思，因意识形态不同最终建立两个国家，这也是朝鲜战争爆发的缘由。

论点六：美国对朝鲜的态度。美国惧怕朝鲜背后的中国和俄罗斯；朝鲜战争时朝鲜快被美国完全占领，中国出动志愿军帮朝鲜把美国打回去，苏联提供空军掩护和武器后勤支持，中苏联手把美国打回三八线以南；美国忌惮这一因素，没有主动进攻朝鲜，也没有再次挑起朝鲜半岛武装冲突；金家担心江山被颠覆，不敢贸然发动战争。

论点七：朝韩统一畅想。若当时美国未下场救援韩国，今日朝鲜可能是苏联卫星国附属，用来牵制中国并威胁美国在亚洲尤其日本的不稳定定时炸弹；现在若朝韩统一，大概率是韩国兼并朝鲜，因经济影响和综合实力；北方有充足优质兵源及核武器和导弹等尖端武器，统一后对整个东北亚是一颗不稳定定时炸弹；类比越南统一后宣布继承法国在中南半岛所有地盘和疆域，统一第二年进攻柬埔寨和泰国，导致1979年中国对越南自卫反击战，朝鲜半岛统一后局势更加不可控。

论点八：中俄朝关系与图们江出海口。中俄朝关系各怀鬼胎；中国与朝鲜、俄罗斯的问题主要是图们江出海口问题，至今拖着没有着落；图们江是俄罗斯和朝鲜的界江，是日本海出海口，在中朝俄边境，国际水域航道可通行，但俄罗斯和朝鲜建了一座小桥，大船无法通过；俄罗斯和朝鲜都不希望中国过分强大，不想过多依附中国，把图们江出海口封死，都不想把出海口让给中国。

论点九：韩国军队在朝鲜战争中的作用。韩国军队一开始瞎指挥，差点被朝鲜团灭；6月25日朝鲜战争爆发，7月10日以后朝鲜南部地面战斗主要是美军和朝鲜人民军进行，韩军负责冲人头；1952年之后美国把韩国重新整军训练备战，韩军才形成基本战斗力；此前韩军对美军类似猪队友，接连被中朝军队打败，志愿军跟美军占不到便宜时都从韩国军队战线突击，美军每次兵败都是韩国军队战线崩溃引起；第五次战役中志愿军从朝鲜半岛东部形成反包围突击，打崩韩国军队前线，美国把韩国第三军团全部撤销；1952年前韩军战斗力不敢恭维，1952年后不可小视；韩军军官主体是二战时期日本扶植的伪军和傀儡部队骨干，士兵类似国民党抓壮丁强征的农村青年；韩军从成军至今贯彻二战昭和日军武士道精神管理体制，老兵欺负新兵、军队霸凌事件蔓延至今，是旧日军部队的延伸。

论点十：中国选择抗美援朝而非收复台湾的原因。台湾和大陆之间海峡距离约100公里，中共刚建国没有相应海军实力；1950年朝鲜战争爆发，美国参众两院普遍认为这是共产主义世界对自由世界的全面进攻，把台湾和韩国共同纳入美国亚太保护圈，美军陆军出兵朝鲜半岛，海军第七舰队进驻台湾，防止解放军解放台湾和国民党反攻大陆；解放军建军时没有海军实力，无法进行解放台湾战斗；美国后期越过三八线向朝鲜及中朝边境进发，触动中国敏感神经，唇亡齿寒深入人心，即便不愿与美国爆发全面战争也不得不进行，台湾问题已让中国被动，朝鲜半岛要争取战略主动，解放军陆军很强，海上没办法战斗就只能在陆地上战斗；长津湖和上甘岭接连让美军惨败，是美国人挥之不去的梦魇。

# 金句总结
「朝鲜半岛对于中国的意义来说，就是一个唇亡齿寒的一个状态。」——背景：主讲人解释中国在美军越过三八线后决定以志愿军形式出兵的原因。

「美国再也不敢小瞧我们了。」——背景：主讲人评价朝鲜战争从中国角度奠定了强国地位，并提及1967年越南战争时期中国警告美国不得越过北纬17度线。

「他是美国历史上第一次在未取得胜利的情况下签署停战协议的司令官。」——背景：主讲人引述联合国军最后一任司令官马克·克拉克的承认，说明美国称此战为被遗忘的战争。

「伤害最深的其实还是朝鲜和韩国。毕竟大家都是就是一脉相承嘛，都是血肉同胞，却分裂成了两个国家，并且这样的三八线的悲剧延续至今。」——背景：主讲人总结朝鲜战争对朝韩双方的影响。

「各怀鬼胎。」——背景：主讲人评价当前中国、俄罗斯和朝鲜之间的关系，并提及图们江出海口问题至今拖着没有着落。

「他就是一支充满着昭和军国主义时期那种思想余孽的，就是旧日军部队的一种延伸。」——背景：主讲人评价韩国军队从成军至今贯彻二战昭和日军武士道精神管理体制，老兵欺负新兵、军队霸凌事件蔓延至今。
