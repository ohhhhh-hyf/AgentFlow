# 庭审概况
本案系国家开发银行（上诉人）与云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司（被上诉人）金融借款合同纠纷二审案件，由最高人民法院组成合议庭公开开庭审理。庭审围绕三个争议焦点展开：抵押权与融资租赁所有权冲突、罚息复利计算、违约金连带给付。各方就融资租赁登记性质、查询义务范围、设备唯一性等展开辩论，合议庭未当庭作出结论，最终经调解达成协议，确认国开行对93项设备有抵押权、招银租赁对6项设备有所有权，债权总额6474.4513万元。

# 举证与法庭调查
## 举证与质证
1. **国开行提交第五组证据第一项**：2018年9月融资租赁查询证书，证明其已尽查询义务。招银租赁质证认为该查询证书不符合要求，依据2014年93号文《中国人民银行关于融资租赁登记系统规定》，国开行在抵押时点未进行相应查询。
2. **国开行提交证据四**：东源煤电公司、曲靖电力公司对设备权属的出资证明，证明已尽审慎义务。东源公司质证认为该材料仅为贷后审查材料，不符合客观事实。
3. **招银租赁一审提交证据**：回租设备清单（证据7页），载明设备名称和生产厂家，但未载明设备型号。国开行质证认为无法据此判断设备是否同一。
4. **招银租赁一审提交2013年和2015年审计报告**（证据82页、95页），载明曲靖电力公司注册资本4亿元且已实缴。国开行质证认为该报告已载明设备出资事项。
5. **国开行2018年核查表**（证据108页），证明曲靖电力公司名下无融资租赁登记。招银租赁质证认为该核查表不符合要求。

## 证人、鉴定与其他来源陈述
- **评估报告**：明确曲靖电力公司拥有的在建工程价值5.7亿元，机械设备价值5.1亿元。国开行代理人主张该报告已确认资产存在。
- **审计报告**：招银租赁一审提交的2013年、2015年审计报告载明曲靖电力公司注册资本4亿元且已实缴。
- **上海中院一审判决**：仅限东源公司对设备的返还义务，未确认设备所有权归招银租赁所有。国开行主张该判决与本案抵押权审理不冲突。

## 法官询问
- **审判员询问国开行**：贷款前审查是否内部规定必须查询融资租赁系统，未查到结果是否需保留单子作为风控材料。国开行代理人回答：按央行规定需查询，但未保留筛查记录，因未查到结果。
- **审判员询问国开行**：查询曲靖电力公司登记信息未查到融资租赁结果，以此免责的逻辑。国开行代理人回答：查询是手段之一，系统无记载，至今仍无结果，证明无过失。
- **审判员询问招银租赁**：融资租赁登记系统中设备唯一标识码是否必填项。招银租赁代理人回答：不是必填项，因设备无唯一标识码。
- **审判员询问国开行和招银租赁**：央行融资租赁登记查询方式能否保证查询到结果。国开行代理人回答：只能按单位查询；招银租赁代理人回答：可按公司名称或设备查询，但设备查询涉及种类物区分问题。
- **审判员询问国开行和招银租赁**：查询通知规定银行办理抵押前需查询，违反规范是否导致最高人民法院认定不构成善意。国开行代理人回答：查询是基本义务，已尽审慎义务；招银租赁代理人回答：未查询即违反行业规范，应认定不构成善意。
- **审判员询问**：动产融资租赁因属性问题产生所有权与占有分离，融资租赁司法解释第九条如何适用。国开行代理人回答：查询范围和主体按司法解释规定；招银租赁代理人回答：应依谁主张谁举证原则，综合考量各方义务和证据优势。

## 争议焦点与辩论
1. **争议焦点一：抵押权与融资租赁所有权冲突**
   - **国开行主张**：抵押审查仅限于抵押人曲靖电力公司，已尽审慎义务，构成善意取得；融资租赁登记是行业强制性规范，非法定登记；查询曲靖电力公司名下无融资租赁登记。
   - **东源公司主张**：2015年12月2日邮件已告知设备融资租赁情况，邮件中抵押设备名称完全相同且用红色标注，国开行应尽注意义务。
   - **招银租赁主张**：2012年已取得设备所有权，国开行2015年抵押登记在后，未查询融资租赁系统，不构成善意；东源煤电出资行为系无权处分。
2. **争议焦点二：罚息、复息计算**
   - **国开行主张**：利息计算至2017年12月20日，罚息自2018年6月13日起算，复利自2018年3月21日起算；利息2179万5727.08元，罚息4105万0579.57元，复利191.8206万元。
   - **东源公司主张**：贷款提前到期应给合理期限，罚息不应计收复利，依据《人民币利率管理规定》第21条及最高人民法院2015、2016年判例。
3. **争议焦点三：违约金连带给付**
   - **国开行主张**：依据借款合同第24条第三项主张千分之一违约金，东源煤电未配合办理账户管理及柜台签约构成违约。
   - **东源公司主张**：国开行未举证东源煤电违反柜台协议，且未发限期纠正通知，主张违约金不符合合同约定。
   - **招银租赁表示**：非合同当事人，尊重合议庭审查结果。

# 庭审结果
1. **争议焦点归纳**：
   - 抵押权与融资租赁所有权冲突：国开行主张已尽审慎义务构成善意取得，招银租赁主张2012年已取得所有权且国开行未查询系统不构成善意。
   - 罚息、复息计算：国开行主张罚息自2018年6月13日起算、复利按合同约定计算，东源公司主张罚息不应作为复利基数。
   - 违约金连带给付：国开行主张依合同约定支付千分之一违约金，东源公司主张未举证违约事实。
2. **调解结果**：
   - 确认国开行对东源公司债权扣除破产清偿本金后，利息、罚息、复利共计6474.4513万元。
   - 确认招银租赁对涉案六项设备享有所有权，对应债权1377.4137万元。
   - 确认国开行对93项设备有抵押权，招银租赁对6项设备有所有权。
   - 国开行和招银租赁对案涉全部发电设备整体盘活处置，变现款各50%，费用各担50%。
   - 若司法变现不能，国开行和招银租赁放弃设备权益，由东源曲靖电力自主生产经营。
   - 各方对一审判决第二项、第四项无争议，按判项确认。
   - 一审诉讼费按一审判决执行，二审诉讼费由二审法院确定。
   - 各方就本案涉及问题不再存在任何争议。
