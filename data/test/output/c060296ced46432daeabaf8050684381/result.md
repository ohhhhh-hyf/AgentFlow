# 讲座概况
本次讲座由基金经理肖楠主讲，面向机构投资者汇报其过去一年的研究布局、投资框架反思与认知升级。肖楠首先指出投资者关心的“What happen next”类问题用处有限，因为知识与信息之间存在巨大鸿沟；随后明确反对市场上流行的“抱团”与“均值回归”观点，认为收益率呈幂律分布，投资核心在于寻找长线超级大牛股。他介绍了在互联网、财富管理、新消费、高端制造四个方向的研究布局，并分享了五点投资框架反思，包括对商业模式分类的反思、从商增角度理解商业模式、对企业家定价的思考、深度价值可能长期无效（打问号）以及小企业的X factor。最后，肖楠回答了投资者关于投资逻辑、行业观点、增长曲线、企业家精神等提问。

# 核心观点与论证
讲座围绕三个部分展开：研究布局、研究成果与投资框架反思。

**一、反对抱团与均值回归**
肖楠明确反对市场上两个流行观点。关于“抱团”，他认为该定义不本质，基金经理之间是竞争关系，主观上不可能抱团；同一公司买同一板块也不叫抱团，研究员推荐股票获广泛认可后大家买入是正常现象。关于“均值回归”，他认为这是“特别不本质的局部正确”，90%时间正确但10%错误代价惨重，并以某商学院老师在海螺水泥上做波段、最终两年错过五六倍涨幅为例说明。他强调收益率是幂律分布而非正态分布，美国股市200年价值增量由4%公司贡献，投资核心是找到长线超级大牛股。

**二、过去一年研究布局**
肖楠介绍四个重点方向：互联网（全球只有中美能产生巨大公司，已迭代三代企业）、财富管理（行业空间巨大，人均收入中位数提升将带来巨额剩余财富）、新消费（新公司从CEO到组织架构完全不同于传统企业）、高端制造（中国在多个细分领域占据主导地位，未来空间可见）。

**三、投资框架反思与认知升级**
肖楠分享五点反思：1. 对商业模式分类的反思，认为没有一劳永逸的坐地收钱生意，长期看所有企业都会死去；2. 从商增角度理解商业模式更本质，企业成长过程中商增过快会导致失败；3. 对企业家定价的思考，认为无法定价但需考虑长期变量，如中国和平稳定高速发展30多年这一隐藏的巨大变量；4. 深度价值可能长期无效（打问号），深度价值只是结果，原因不变则结果最好也只是不输；5. 小企业的X factor，驱动企业增长且不被线性描述的因子，经典模型无法定价但长期重要，超额认知来源于此。

# 金句总结
1. “知识和信息之间是有着巨大的鸿沟的。”——肖楠以此说明投资者关心的“What happen next”问题用处有限，因为知识无法直接传递。
2. “务实还是务虚，其实没有高下之分的。做好的都是大师，做不好都是东施效颦。”——肖楠在对比巴菲特与索罗斯两个投资流派时强调理念无好坏。
3. “均值回归这个事情，90%的时间都正确，那10%的错误依然让你代价惨重。”——肖楠反对均值回归观点，强调其局部正确性。
4. “收益率是幂律分布的，不是正态分布的。”——肖楠以此论证投资核心是寻找长线超级大牛股。
5. “我们一定要对市场保持谦卑。”——肖楠在讨论长期变量时提醒投资者保持谦虚。
6. “驱动企业增长且不被线性描述的因子，我们即使是没有办法去有效定价，我们也一定要承认它的存在。”——肖楠在介绍X factor时强调其重要性。

# Q&A 环节
问：您刚刚有讲到是在对于终局结果的重视的过程中，也更加去关注格局演进的过程中阶段性的特征，中期投资机会，请问您能对这一点再详细描述一下吗？
答：这个想法最早来自于我们过去错过了一些特别大的机会，我们判断这些行业的终局可能不大行，但明明判断对了，却在两三年的时间里深深错过了十几倍的涨幅。复盘发现，这些企业虽然某一代产品被追上，但做出了第二增长曲线，且壁垒更深。所以我们开始承认终局可能没那么强，但依然能做出好的投资。

问：您在年报中也讲到过，坚定持有优秀乃至伟大的公司。请问您对于优秀乃至伟大公司的判断标准，是否有具体的财务指标？
答：伟大公司在财务指标里看不出来。我举两个企业的例子，它们都在自己领域把成本做到行业最低，但A公司每年有高额研发支出，技术迭代快，且从董事长到技术骨干都有强烈的产业报国情绪；B公司不怎么做研发，靠精益求精的管理做到成本最低。A公司这种有产业报国基因、从跟着学到超越对手的企业堪称伟大。

问：我们是全市场基金，能否介绍一下这个产品的投资逻辑？对于消费以外的行业的选股，主要是基于什么逻辑？
答：我们很难分消费内消费外，选股逻辑都是一样的，都是以前讲过的“不可能三角”、企业三阶段、三种商业模式等。消费行业只许买消费，所以只能在消费行业里选，两者选股逻辑完全一样。

问：您是怎么看待血制品行业的竞争壁垒呢？
答：血制品行业我们初步研究过，觉得壁垒不是特别强，不是我们想要的那种强壁垒，这个就不展开了。

问：农林牧渔行业有所提升，请问您对这个行业的观点？
答：农林牧渔行业的提升是因为牧原股份那一只股票，不是我先看好农林牧渔行业再去选牧原，就是牧原股份的比例提高了。

问：您能够再具体讲一下生意模式里边商增和商减的这个分析吗？
答：用直白的理论讲，企业从小到大，部门越来越多，传达效率变低，内部腐败出现，企业要设部门巡视检查，又多了部门，人员要加工资提级别。有些生意收入10亿和100亿时机构没多多少，有些企业不需要设那么多副总裁就能做成。有些企业被商增拖死，比如互联网大厂一家效率高、一家山头林立。建议读党史，看组织如何保持活力。

问：伟大的企业的增长曲线，您能否再具体讲一下？
答：有些企业每年看是线性增长，但拉长10年看与竞争对手拉开极大差距。比如疫情时只有顺丰能送，一下子甩开竞争对手；家电领域美的做渠道扁平化，疫情一来占有率超过格力。这些企业平时直线发展，但在特殊时刻拐上去，就像突然下雨时发现有人带了伞。

问：财富管理行业能否具体展开，讲一下投资逻辑和投资机会？
答：财富管理行业话题特别大，且分层，顶级富豪、中产阶级、中低收入者的财富管理方式不同，商业模式也不同。我们最早研究保险时发现，不同保险公司业务员单均保费差距巨大，背后是结构设置、激励机制、文化的差异。财富分布超级不均匀，头部公司可能拿走行业增量的绝大部分，这种偏激分布可能诞生特别大的企业。

问：第二第三增长曲线需要卓越的企业家精神，请问您在观察这个指标方面有什么心得和把握？
答：第一，评判这个因素要特别小心谨慎，不要乱归因，把所有能归因到数据里的客观指标的因素都归因完，再谨慎评价虚的因素。第二，不要轻易给这些因素定价，绝对不要说因为企业家在所以公司值多少。我们一致同意它不可被定价。这些虚的因素在所有客观归因穷尽后再考虑，且只能在有限范围内做两两比较，不要跨行业比较。
