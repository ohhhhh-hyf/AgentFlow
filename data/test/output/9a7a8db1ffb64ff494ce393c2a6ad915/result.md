# 课程概况
本讲为初中物理光学复习课，系统复习光的直线传播、光速、光的反射定律、镜面反射与漫反射、平面镜成像及球面镜应用。课程先介绍光源（自然光源如太阳、萤火虫，人造光源如电灯）与光线（物理模型），强调光在均匀介质中沿直线传播，并列举三点一线、激光准直、小孔成像、日食月食、影子形成等实例；光速在真空中为3×10^8米/秒，空气中略慢，水中为真空中的3/4，玻璃中为2/3。随后讲解光的反射定律：三线共面、分居两侧、反射角等于入射角，法线为辅助线且垂直镜面，垂直入射时入射角为0度；作图步骤为先画法线，再根据反射角等于入射角画光线。镜面反射发生在光滑表面，反射光线平行，可能造成反光问题；漫反射发生在凹凸不平表面，反射光线射向各个方向，生活中大多数反射为漫反射，如黑板、电影银幕，两者均遵守反射定律。平面镜成像原理为光的反射，成正立、等大的虚像；实验用玻璃板代替平面镜以确定像的位置，用刻度尺比较像与物到镜面的距离，用两段相同蜡烛比较像与物大小；玻璃板有厚度会导致两个像，玻璃板不垂直会导致测量误差。球面镜中，凸面镜对光起发散作用，成缩小虚像，用于汽车后视镜、丁字路口镜；凹面镜对光起会聚作用，用于手电筒、太阳灶、耳鼻喉科检查；玻璃幕墙凹面可能造成光污染，烧死树木或引燃电线。

# 核心知识点梳理
**一、光的直线传播**
- **光源**：自身能够发光的物体。按来源分为自然光源（如太阳、萤火虫）和人造光源（如火把、蜡烛、煤油灯、电灯）。
- **光线**：用带箭头的直线表示光的传播路径，是**物理模型**，并非真实存在。
- **光在均匀介质中沿直线传播**：实例包括三点一线（步枪瞄准）、激光准直、小孔成像、日食月食、影子形成。
- **小孔成像**：成倒立的实像，放大或缩小取决于物距与像距，与孔的形状无关。
- **日食与月食**：日食时月球在太阳和地球之间，月食时地球在太阳和月球之间；日食分日全食、日偏食、日环食，月食分月全食、月偏食。
- **光速**：真空中为 `3×10^8` 米/秒（约每秒30万公里，一秒钟绕地球赤道7圈半），空气中略慢，水中为真空中的3/4，玻璃中为2/3。

**二、光的反射定律**
- **三线共面**：反射光线、入射光线和法线在同一平面内。
- **分居两侧**：反射光线和入射光线分居法线两侧。
- **反射角等于入射角**。
- **法线**：过入射点垂直于镜面的辅助线，用虚线表示，是入射角与反射角的角平分线。
- **垂直入射**时入射角为0度，反射角也为0度。
- **作图步骤**：先画法线，再根据反射角等于入射角画反射（或入射）光线，保留法线痕迹。

**三、镜面反射与漫反射**
- **镜面反射**：发生在光滑表面（如平面镜、平静水面），反射光线平行，可能造成反光问题。
- **漫反射**：发生在凹凸不平表面，反射光线射向各个方向，生活中大多数反射为漫反射（如黑板、电影银幕）。
- 两者均遵守光的反射定律。

**四、平面镜成像**
- **原理**：光的反射。
- **特点**：正立、等大、虚像。
- **实验**：用玻璃板代替平面镜便于确定像的位置；用刻度尺比较像与物到镜面的距离；用两段相同蜡烛比较像与物大小。
- **误差原因**：玻璃板有厚度导致两个像；玻璃板与水平面不垂直导致测量误差。

**五、球面镜**
- **凸面镜**：对光起发散作用，成正立、缩小的虚像，用于汽车后视镜、丁字路口镜。
- **凹面镜**：对光起会聚作用，用于手电筒、太阳灶、耳鼻喉科检查。
- ⭐ **难点**：玻璃幕墙凹面可能造成光污染，烧死树木或引燃电线。

# 课堂互动与答疑
问 → 答：学生问萤火虫是否算光源，教师答算，属于自然光源。
问 → 答：学生问光在空气中传播速度是否等于真空中，教师答空气中略慢，但常近似为 `3×10^8` 米/秒。
问 → 答：学生问为什么引入法线，教师答为后续学习折射做准备。
问 → 答：学生问光垂直射到镜面上入射角多少度，教师答0度，不是90度。
> 教师提醒：光线是物理模型，不是真实存在的；一开灯不会有很多箭飞来。
> 教师提醒：作图时先画法线，保留作图痕迹，箭头方向要正确。

# 课后任务与学习建议
教师未布置书面作业，但强调复习重点：光的直线传播实例（三点一线、激光准直、小孔成像、日食月食、影子）、光的反射定律（三线共面、分居两侧、反射角等于入射角）、镜面反射与漫反射的区别、平面镜成像特点（正立、等大、虚像）及实验注意事项（玻璃板有厚度、不垂直导致误差）、球面镜的应用（凸面镜发散、凹面镜会聚）。建议学生在家用激光笔、纸杯、蜡烛等做小孔成像和平面镜成像实验，加深理解。
