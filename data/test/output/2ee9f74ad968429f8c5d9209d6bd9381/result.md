# 报告概况
《政府工作报告》由国务院总理代表国务院向全国人民代表大会报告，报告期间为2023年工作回顾与2024年工作部署。报告指出，2023年面对异常复杂的国际环境和艰巨繁重的改革发展稳定任务，全年经济社会发展主要目标任务圆满完成，国内生产总值超过126万亿元，增长5.2%，城镇新增就业1244万人，居民人均可支配收入增长6.1%。报告同时分析了面临的困难和挑战，提出2024年坚持稳中求进工作总基调，统筹高质量发展和高水平安全，巩固和增强经济回升向好态势，以中国式现代化全面推进强国建设、民族复兴伟业。整体基调务实进取，既肯定成绩，也直面问题，强调政策聚焦发力、工作加倍努力。

# 核心政策
2024年主要预期目标：**国内生产总值增长5%左右**，**城镇新增就业1120万人**，**城镇调查失业率5.5%左右**，**居民消费价格涨幅3%左右**，**居民收入增长和经济增长同步**，**国际收支保持基本平衡**，**粮食产量1.3万亿斤以上**，**单位国内生产总值能耗降低2.5%左右**，生态环境质量持续改善。宏观政策取向：积极的财政政策适度加力、提质增效，**赤字率按3%安排**，**地方政府专项债券3.9万亿元**，**发行超长期特别国债10000亿元**，专项用于国家重大战略实施和重点领域安全能力建设；稳健的货币政策灵活适度、精准有效，保持流动性合理充裕，促进社会综合融资成本稳中有降。核心政策包括：大力推进现代化产业体系建设，加快发展新质生产力；深入实施科教兴国战略；着力扩大国内需求；坚定不移深化改革；扩大高水平对外开放；更好统筹发展和安全；坚持不懈抓好三农工作；推动城乡融合和区域协调发展；加强生态文明建设；切实保障和改善民生。

# 重点工作
**经济领域**：实施制造业重点产业链高质量发展行动，推动传统产业高端化、智能化、绿色化转型，促进中小企业专精特新发展；巩固扩大智能网联、新能源汽车等产业领先优势，制定未来产业发展规划；深入推进数字经济创新发展，开展`人工智能+`行动，实施制造业数字化转型行动。着力扩大国内需求，培育壮大新型消费，实施数字消费、绿色消费、健康消费促进政策，鼓励和推动消费品以旧换新；积极扩大有效投资，重点支持科技创新、新型基础设施、节能减排降碳等领域，加快实施十四五规划重大工程项目。

**科教领域**：制定实施教育强国建设规划纲要，开展基础教育扩优提质行动，大力提高职业教育质量；充分发挥新型举国体制优势，强化基础研究系统布局，推进关键核心技术协同攻关，强化企业科技创新主体地位；实施更加积极、更加开放、更加有效的人才政策，加大对青年科技人才支持力度。

**改革与开放领域**：深入实施国有企业改革深化提升行动，全面落实促进民营经济发展壮大的意见及配套举措，实施降低物流成本行动，健全防范化解拖欠企业账款长效机制；加快全国统一大市场建设，专项治理地方保护、市场分割、招商引资不当竞争等突出问题。扩大高水平对外开放，推动外贸稳规模优结构，全面取消制造业领域外资准入限制措施，放宽电信、医疗等服务业市场准入；推动高质量共建`一带一路`走深走实，抓好八项行动落实落地。

**安全与三农领域**：更好统筹发展和安全，优化房地产政策，加快构建房地产发展新模式，加大保障性住房建设和供给；统筹好地方债务风险化解和稳定发展，进一步落实一揽子化债方案；全方位夯实粮食安全根基，严守耕地红线，提高高标准农田建设投资补助水平；启动第二轮土地承包到期后再延长30年整省试点，深入实施乡村建设行动。

**生态领域**：深入践行绿水青山就是金山银山的理念，协同推进降碳、减污、扩绿、增长；深入实施空气质量持续改善行动计划，统筹水资源、水环境、水生态治理；积极稳妥推进碳达峰碳中和，扎实开展碳达峰十大行动，加快建设新型能源体系。

**民生领域**：多措并举稳就业促增收，预计今年高校毕业生超过1170万人，强化促进青年就业政策；提高医疗卫生服务能力，**居民医保人均财政补助标准提高30元**，深化公立医院改革，引导优质医疗资源下沉基层；加强社会保障，**城乡居民基础养老金月最低标准提高20元**，继续提高退休人员基本养老金；丰富人民群众精神文化生活，创新实施文化惠民工程。
