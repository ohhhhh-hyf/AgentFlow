# 沟通概况
班主任林瑞在372班家长会上，面向全体家长介绍了班级基本情况、教师团队、班级存在问题及解决思路、后续计划与措施，并给出家庭教育建议。班级共60人，男生25人、女生35人；教师团队多为老教师和优秀教师，班主任林瑞任教地理学科。会议还包含家长代表张宇波分享家庭教育经验、成立家长委员会（至少三人，自愿报名，已有家长自愿参加），以及保险购买、电子学生证办理、资助政策说明等事项。整体基调为加强家校协同，共同促进学生成长。

# 沟通内容
## 学习表现

- **亮点**：班级整体时间观念和执行能力较强，班风班貌纪律良好，教室地面干净、卫生状况好。
- **亮点**：学生遇到问题会积极向老师请教，班主任林瑞表示学生上课时会主动提问。
- **亮点**：学生关注老师、会主动向老师汇报情况，尊师意识较好。
- **需关注**：少数学生思考能力较差，尤其在自习课上，老师在场时表现安静，老师不在时纪律混乱。
- **需关注**：个别学生书写较差，班主任已与相关家长沟通，建议家长为孩子购买字帖练习书写。
- **需关注**：自习课效率较低，班主任计划加强班委培训，并给予学生10分钟讨论时间，允许不懂的学生离开座位向老师请教。

## 行为表现

- **亮点**：班级整体班风纪律良好，卫生状况佳。
- **需关注**：少数学生周末沉迷玩手机游戏，导致返校后精神疲惫、懒散，约有两三个学生存在手机依赖问题。
- **需关注**：发现少数男生有网瘾，有学生周末向游戏充值，金额达400元。
- **需关注**：有学生在周六晚上外出过生日，喝酒后回校一身酒气，还抽烟、玩手机。
- **需关注**：存在早恋现象，班主任建议家长关注孩子的QQ、抖音、快手等社交账号，留意是否有异常动态。
- **需关注**：有学生带镜子到校，约10人左右，班主任已要求全部收掉。
- **需关注**：有学生抽屉里发现小说，班主任建议家长管控孩子阅读内容。

## 社交与心理表现

- **需关注**：学生处于初中阶段，生理和心理持续变化，是人生中不稳定的时期，需要家长和老师共同引导。
- **需关注**：班主任提醒家长关注学生心理健康，发现异常应及时进行心理辅导。
- **需关注**：班主任在班级调查中发现，只有少数学生知道父母的生日，反映出部分学生对家庭关怀意识不足，班主任已就此进行感恩教育。

# 家长反馈
- **家长代表分享**：张宇波（家长代表）分享家庭教育经验，强调关注孩子身体健康和心理健康，教育孩子先做人、避免不良风气，家长要有平常心、尊重孩子、多倾听多交流，并配合学校制度与老师合作。
- **家委会成立**：班主任提议成立家长委员会，至少需要三人，自愿报名，已有家长自愿参加。
- **保险购买**：班主任建议家长为孩子购买保险，约310多元，可自行购买，最后会统计购买情况。
- **电子学生证**：班主任说明电子学生证套餐78元（移动套餐），方便联系，能办的就办。
- **资助政策**：班主任说明高中补助打在医保卡上、初中打在卡上，提醒家长注意补助使用，避免学生乱花。
- **费用管理**：班主任强调不在微信群收取任何费用，由学生交给生活委员，提醒家长防范诈骗。
- **手机管理**：班主任要求家长配合管理手机，统一上交存放，家长可不定时打电话检查，并提醒家长处理多余手机。
- **安全教育**：班主任提醒家长关注交通安全（未满16周岁骑电动车危险）、防诈骗、防溺水、防校园欺凌。
- **心理健康**：班主任建议家长关注学生心理健康，发现异常及时进行心理辅导。
- **家庭教育建议**：班主任建议家长避免过分关注、放任不管、期望过高等误区，创造和睦家庭气氛，多鼓励少批评。

# 共识与配合事项
## 费用与收费

- [ ] **家长**：确认水费险收费标准为每两周2元/人，若实际用水超出预算再另行说明
- [ ] **家长**：确认书费预交11000元尚未结算，待最终核算后多退少补
- [ ] **家长**：未购买书箱的同学，班主任将退还相应费用
- [ ] **家长**：少数同学存在约100元左右的无效费用（约70元），班主任后续会逐项公布明细
- [ ] **家长**：班主任不会在微信群内收取任何费用，所有费用由学生直接交给生活委员，请勿相信群内转账要求
- [ ] **家长**：注意防范冒充班主任头像进行收费的诈骗行为，涉及转账务必电话核实

## 保险

- [ ] **家长**：建议为学生购买保险，费用约310多元，可自行选择购买渠道（学校、保险公司、线上平台均可）
- [ ] **家长**：购买后配合班主任统计是否已购买，确保每名学生都有保障

## 电子学生证

- [ ] **家长**：电子学生证套餐为78元/月（移动套餐），方便学生请假时联系家长
- [ ] **家长**：目前班级仅有两个可用坐席，第三个坐席将于9月20几号到期，到期后需办理新号码
- [ ] **班主任**：将把新号码发到家长群，请家长重新登记补充
- [ ] **家长**：能办理电子学生证的尽量办理，方便家校联系；无法办理的请说明情况

## 资助政策

- [ ] **家长**：关注家长群内发布的资助政策文件，高中阶段所有补助将打在学生医保卡上（与初中打在卡上不同）
- [ ] **家长**：每次补助到账后与孩子确认金额及用途，防止学生将补助用于购买手机、过生日、喝酒等非学习消费
- [ ] **家长**：需要申请补助的学生，学校会协助办理相关手续

## 手机管理

- [ ] **家长**：配合学校手机管理制度，学生手机统一上交存放，每个手机箱贴好学生姓名
- [ ] **家长**：家中多余的手机（如家长名下办理的副卡手机）请处理掉或收回，避免学生藏匿使用
- [ ] **家长**：周一到周五不定时拨打学生电话，若电话能打通但无人接听，说明学生可能未按时上交手机
- [ ] **家长**：检查学生手机内容，关注是否存在网瘾、观看不健康内容、早恋等情况
- [ ] **家长**：关注学生QQ、抖音、快手等社交账号，留意是否被屏蔽、是否有多个账号、是否发布不当内容
- [ ] **家长**：发现学生有网瘾倾向及时干预，避免沉迷游戏

## 住校纪律

- [ ] **家长**：提醒住校学生遵守宿舍纪律，周六住校同样须遵守作息要求（2:10回寝室休息）
- [ ] **家长**：提醒学生不得在宿舍内吸烟、喝酒，外出过生日须提前报备

## 安全事项

- [ ] **家长**：提醒学生注意交通安全，未满16周岁不得骑电动车，尤其禁止载人（载2-3人非常危险）；如确需骑行须单人骑行
- [ ] **家长**：提醒学生注意运动安全、饮食安全
- [ ] **家长**：提醒学生防范诈骗、防溺水，不得私自下河游泳
- [ ] **家长**：关注防校园欺凌，学生遇到问题第一时间联系班主任处理
- [ ] **班主任**：学生遇到矛盾或欺凌事件，第一时间介入处理（举例：曾有一名学生11点反映矛盾，班主任12点即约谈至凌晨2点）

## 学习与行为管理

- [ ] **家长**：查看学生手册，书写较差的学生请购买字帖练习（文具店有售）
- [ ] **班主任**：加强班委培训，提升自习课管理效率；自习课给予学生10分钟讨论时间，不懂的问题可离开座位请教
- [ ] **班主任**：继续每天加强思想教育工作
- [ ] **班主任**：制定详细班规，严格请假制度，该扣分扣分、该写检讨写检讨、该罚站罚站
- [ ] **班主任**：定期与家长沟通学生表现，及时反馈问题
- [ ] **家长**：关注学生心理健康，发现异常及时进行心理辅导
- [ ] **家长**：提醒学生合理安排饮食、注意补充营养
- [ ] **家长**：鼓励学生不懂就问，主动向老师请教问题
- [ ] **家长**：正确看待成绩，不与其他人盲目比较，帮助学生分析进步与下滑原因
- [ ] **家长**：避免教育误区——不过分关注、不放任不管、不期望过高、不给过多零花钱
- [ ] **家长**：控制生活费额度，建议每周不超过150元（早餐3-4元、午餐8元、晚餐8元，约21-24元/天）
- [ ] **家长**：多鼓励少批评，给孩子制定容易达到的小目标，激发潜能
- [ ] **家长**：创造和睦、祥和、稳定的家庭气氛，不在孩子面前长时间玩手机
- [ ] **家长**：不在家里聚众打麻将、点外卖，给孩子安静学习环境
- [ ] **家长**：多抽时间了解孩子在校表现，关注孩子心理动态
