# 发布会概况
王毅在慕尼黑安全会议上发表演讲并回答主持人提问，阐述中国推动平等有序世界多极化的主张。他指出世界走向多极化是历史必然，中国将坚定做变革世界中的建设性力量，是多极体系中的确定性因素。演讲提出四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。在问答环节，王毅回应了关于国际秩序、乌克兰危机和中美关系等问题，强调中国维护以联合国为核心的国际体系，主张通过对话政治解决争端，并重申中美关系应遵循相互尊重、和平共处、合作共赢三原则。

# 核心信息
王毅在慕尼黑安全会议上发表演讲，指出世界走向多极化是历史必然，80年前联合国成立时只有51个会员国，到今天有193个国家。中国主张推动平等有序的世界多极化，提出四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。中国加入了几乎所有普遍性的政府间国际组织和600多项国际公约，承担超过20%的联合国会费，建成世界上最大的清洁发电体系。去年中国GDP增长5%，对世界经济增长的贡献率接近30%。今年是中欧建交50周年。

# 官方表态
关于国际秩序，王毅表示中国是现行国际秩序的受益者，主张推动秩序向更加公正合理方向发展，强调维护以联合国为核心的国际体系和以联合国宪章宗旨和原则为基础的国际关系基本准则，不搞双重标准。关于乌克兰危机，王毅指出中国从2022年2月25日起就提出对话协商解决，习近平主席提出四点主张，中国持续推进劝和促谈，乐见一切致力于和平的努力，包括美俄达成的共识，认为所有当事方和利益攸关方应适时参与和谈。关于中美关系，王毅表示中国对美政策保持连续性和稳定性，遵循相互尊重、和平共处、合作共赢三原则，愿意按照三原则同美方构建稳定健康可持续的双边关系，希望美方相向而行；如果美方打压遏制，中国将奉陪到底。
