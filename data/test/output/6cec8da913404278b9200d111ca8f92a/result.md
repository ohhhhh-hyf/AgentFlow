# 项目概况
援外玉米面加工厂项目中期验收会议召开，验收组于18号19号提前介入前期摸排，20号召开首次会议，检查分内业与外业，按建筑工程、安装工程、机电设备专业方向开展。截止今天，卢萨卡点除带料加工调试以外的所有验收工作已完成，蒙泽点全部验收工作已完成，并利用带料调试厂家在场资源顺带完成流程试生产；姆皮卡点内业资料已提前拿到卢萨卡点，现场验收工作尚未开展。内业方面基本评价为满足项目有关标准和规范要求；外业方面建筑、安装、机电设备总体满足规范和标准要求，工艺设备运行正常，产能符合设计指标；财务方面完全符合财务处理有关规范和标准。验收组提出人员履约和合同履约、内业资料整理、现场实体整改及不可预见费使用等问题，合作局领导要求尽快补充资料并与验收组沟通对接，重视蒙泽厂区混凝土路面开裂整改，做好成品保护，并强调去姆皮卡点的交通安全与疫情防控。

# 进度追踪
项目整体健康度良好，卢萨卡点除带料加工调试外验收工作已完成，蒙泽点全部验收工作已完成，姆皮卡点现场验收待开展。

- 内业检查：管理组技术组基本能按项目合同组建执行团队并按流程程序开展工作，受疫情及项目特殊情况影响主要人员基本能保证在前方岗位，项目执行团队编制了施工组织计划、管理计划、实施细则及各项专项预案，涵盖工程质量安全环境职业健康及合同管理实验检测等方面，验收组通过资料查阅、现场抽检、问询交流了解管理流程和资料收集整理情况，目前基本评价为满足项目有关标准和规范要求。
- 外业检查：建筑部分对卢萨卡和蒙泽厂区进行检测，过程性隐蔽工程通过查阅文件、可检测范围按规范和标准抽检，主材包括预制构件、年广场地砖从卢萨卡有质量管控体系的供货单位集中预制采购并从200多公里以外运至现场，钢结构材料从国内定制发货，施工工艺吊装精确度到外观质量满足规范和标准要求；设备部分执行单位与中粮西安设计院及相关厂家签订专项供货合同，参照中国标准专门定制生产三套成套设备，厂家高峰期派十几名工作人员到现场指导安装，验收组对工艺设备逐台复核并投料试运行，工艺设备运行正常，工艺流程满足生产要求，产能符合设计指标，机电设备安装达到国家质量检验有关标准。
- 财务方面：财务验收专家查阅资料并与相关人员沟通，本项目从账户设置、资金往来、银行开户等过程完全符合财务处理有关规范和标准。
- 人员履约和合同履约：个别同志进出场时间及护照需施工部和管理组进一步完善，个别岗位人员有申请更换流程，人员统计数量尤其是技术组对厂家服务人员可能未计算进去，个别特种人员证件有效期延期或更新未及时到位。
- 内业资料整理：质检资料、流程性文件、过程性检查文件、程序性管理文件和整改文件基本都有，但在分类整理及少量质检和管理机构验收签字的规范性上需进一步规范完善，资料分散，有一个点因太远又集中过来。
- 现场实体整改：存在局部损伤、装饰装修位置检查、卫生打扫、雨季前厂区及办公区排水排查等事项，某厂区非主要通道范围内混凝土路面有少量开裂，监控管线因设备启动震动接头处有脱落，卢萨卡点加工提升桶往上位置雨水可能倒灌，卢萨卡点廊墙最端头横向只有三个竖条。
- 不可预见费使用：检查中看到本项目有动用不可预见费的情况，有关依据证据和数据需进一步完善和收集整理清楚。
