# 讨论议题与背景
本次会议围绕日本国家概况、对日本的印象与了解展开自由讨论，由发言人1主持并引导，发言人2参与发言。发言人1提出日本在国人印象中较为复杂：历史原因导致中日曾发生战争与悲剧，但今天日本在中国外部投资中占很大比重，中日也是主要贸易伙伴；上学、上班人群喜欢去日本旅游，日本服务业和购物体验在各国中首屈一指。发言人2提到读研时上过讲日本文化的课，读《四世同堂》后觉得民族仇恨还是应该有一点影响。讨论涉及日本文化的来源与历史分期、天皇制度与君主立宪、旅游购物与中古店、日本民族性格与岛国环境等话题。

# 发言要点
发言人1主张日本文化没有原创，属外来接收后本土化改进，经历三次转折：古代大化改新（向中国、朝鲜半岛学习，形成和服、制茶、漆器等传统）、近代明治维新（对标清朝、向欧美列强学习，学英国和德国法度利器）、二战后和平宪法转型（美国制定和平宪法，社会结构大规模调整，向美国看齐）；并谈到古代日本君臣关系与中国差别大，天皇对各地封建君主而言更像吉祥物，被当神灵供奉以精神层面控制百姓，1945年二战结束后美军统帅麦克阿瑟进驻日本，公开要求天皇在媒体和众人面前露面，让平民知道天皇是真人而非神灵，推动社会转型；现今天皇如君主立宪制下英国、西班牙那样的象征性存在，不能参与政治和国家事务，政治由国会和内阁选出首相执政，美国把日本改造成英美海洋法系国家结构，天皇没有实权，靠政府养着，存在感不如英国国王。发言人1还谈到旅游购物：长崎、东京、大阪、秋叶原等城市，秋叶原可买数码宝贝、铁甲小宝等原装手办以及美妆、护肤品、玩具；日本奢侈品便宜，有Vintage中古店，广场协议后日本经济急剧恶化、泡沫经济崩溃，上班族失业后把原先买的高档大衣、西装、皮具、皮鞋等通过二手回收寄卖，催生中古二手店产业，上海也有很多这类店，能买到LV、Burberry、古奇等上个世纪知名大牌，男性款式相对少；其本人喜欢去日本爬山、爬富士山、看古城、逛博物馆，如镰仓、京都、名古屋，喜欢镰仓夏天舒服的气候。发言人2提到日本传统文化如漆艺、茶艺以及现代文化艺术，并提到听过一种评论：日本是岛国，气候非常不稳定，发展农业可能遇海啸导致收成没了，所以民族性格比较容易极端。双方分歧点在于：发言人1追问日本文化具体指哪一个历史阶段，发言人2未明确；发言人1认为日本民众现在对天皇没有崇拜，发言人2则追问是否还有崇拜，未达成一致。

# 共识形成
小组未形成明确统一意见或解决方案，讨论中形成的共同认识包括：日本在国人印象中较为复杂，中日既有历史战争与悲剧，也是主要贸易伙伴；日本文化属外来接收后本土化改进，经历大化改新、明治维新、二战后和平宪法转型三次转折；现今天皇为君主立宪制下的象征性存在，无实权；日本有Vintage中古店产业，上海也有这类店。
