# 庭审概况
本案为上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司之间的金融借款合同纠纷二审。上诉人国家开发银行不服云南省高级人民法院云民初88号民事判决，向本院提起上诉。本院依法组成合议庭，依据《中华人民共和国民事诉讼法》第134条第一款、第169条的规定公开开庭审理。庭审围绕抵押权与融资租赁所有权冲突、罚息复利计算、违约金给付三个争议焦点展开辩论，合议庭休庭评议后提出调解方案，各方均无异议并签字确认，法院当庭确认调解协议并出具调解书。

# 举证与法庭调查
**证据与质证意见**
- **国开行提交证据**：2018年9月对曲靖电力公司的融资租赁查询证书，招银租赁认为该查询证书不符合要求，依据2014年93号文《中国人民银行关于融资租赁登记系统规定》，国开行在抵押时点未进行相应查询。
- **国开行提交证据**：工商部门出资证明及证据四冶合成58亿，显示东源煤电公司、曲靖电力公司对设备权属的确认，国开行主张已尽审慎审查义务。
- **招银租赁提交证据**：一审提交的回租设备清单（证据7页），仅载明设备名称和生产厂家，未提及设备型号；2013年和2015年审计报告（证据82页、95页）载明曲靖电力公司注册资本4亿元且已实缴。
- **东源方提交证据**：2015年12月2日邮件及融资情况统计表，显示两家公司抵押设备名称完全相同，抵押设备部分用红色标注，主张已引起国开行注意义务。
- **国开行质证意见**：2015年12月2日邮件正文及附表均无融资租赁情形记载，该邮件为常规贷后审查材料，统计表中招银租赁栏记载融资额度及不动产抵押类型，无法得出已告知的结论。
- **招银租赁质证意见**：东源煤电2012年即取得租赁设备所有权，国开行2015年办理抵押登记时未查询融资租赁登记系统，不构成善意取得。

**法官询问要点**
- 合议庭询问各方对中国人民银行征信中心融资租赁登记性质及登记行为法律后果的理解。
- 合议庭询问国开行和招银租赁：央行融资租赁登记系统的查询方式能否保证查询到登记结果。
- 合议庭询问国开行：贷款前审查中内部规定是否要求必须查询融资租赁登记系统，未查到结果是否需将查询单作为风控材料。
- 合议庭询问招银租赁：融资租赁登记系统中设备唯一标识码是否为必填项。
- 合议庭询问国开行和招银租赁：查询通知规定在金融行业办理抵押前查询，违反该规范是否导致最高人民法院相关司法解释的适用。
- 合议庭询问各方：因不同登记机构产生登记瑕疵的看法及建议。

**双方辩论的争议焦点**
- **争议焦点一：抵押权与融资租赁所有权冲突**。国开行主张已尽审慎审查义务，构成善意取得抵押权；招银租赁认为国开行未查询融资租赁登记系统，不构成善意。
- **争议焦点二：罚息、复息计算**。国开行主张利息计算至2017年12月20日，罚息自2018年6月13日起算，复利按合同约定；东源方认为宣布贷款提前到期应给合理期限，罚息不应作为复利基数。
- **争议焦点三：违约金给付**。国开行主张东源煤电违约应支付千分之一违约金；东源方认为国开行未举证违约且未发纠正通知。

# 庭审结果
本案争议焦点为：一、国开行对案涉设备是否享有抵押权，是否构成善意取得；二、一审判决对案涉借款罚息、复息的计算是否正确；三、东源煤电、东源煤业是否应当连带给付违约金。

经合议庭休庭评议，提出调解方案，各方均无异议并签字确认。调解方案主要内容：确定国开行对东源公司债权扣除破产清偿本金后，利息、罚息、复利合计6474.4513万元；招银租赁对涉案六项设备享有所有权，对应债权1377.4137万元；国开行对93项设备有抵押权；招银租赁和国开行对案涉全部发电设备整体盘活处置，变现款双方各50%；变现款不足清偿时，招银租赁债权按破产重整计划预留方案实现；司法变现不能时，双方放弃设备权益，由东源曲靖电力自主生产经营。一审判决第二项、第四项无争议，按判项确认；一审诉讼费按一审判决执行，二审诉讼费由本院依法确定。法院当庭确认调解协议，并依据《中华人民共和国民事诉讼法》第97条出具调解书。
