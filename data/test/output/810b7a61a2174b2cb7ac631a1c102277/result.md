# 项目概况
本次会议为原占比二玉米面加工厂项目中期验收会议，验收组于18号19号提前介入前期摸排，20号召开首次会议，分内业检查和外业检查，按建筑工程、安装工程、机电设备专业方向开展。截止今天已完成卢萨卡点除弹料加工调试以外的所有验收工作，蒙泽点已完成全部验收工作，姆皮卡点现场验收工作尚未开展；因带料调试厂家工作人员在现场，验收组与技术组顺带把整个流程试生产、外方人员操作、产品生产过程过了一道。内业方面，管理组技术组基本能够按照项目合同从开工到过程中组建项目执行团队并按流程程序开展工作，受疫情及项目特殊情况影响主要人员基本能保证在前方岗位，验收组查阅内业资料、现场抽检及问询交流，基本评价为满足项目有关标准和规范要求，但分类整理及少量质检和管理机构验收签字的规范性还需进一步规范和完善。外业方面，建筑部分原材料除国内采购出口建筑材料外，主要主材包括预制构件、年广场地砖从卢萨卡大规模成建制有质量管控体系的供货单位集中预制采购、从200多公里以外拉过去，内在品质通过查验资料、外在表观通过现场抽检和检测达到很好标准，因资料完整整理结果没出来今天不下最后结论；安装部分以钢结构为主，所有材料从国内定制发货到现场，设备由技术组执行单位与国内中粮西安设计院及相关厂家签订专项供货合同、参照中国标准按输出产品分三类标准专门定制编制并生产三套成套设备，验收组对工艺设备逐台复核并投料试运行，工艺设备运行正常、工艺流程满足生产要求、产能符合设计指标，机电设备安装正确运行正常、达到国家质量检验有关标准。财务验收专家对本项目财务资料进行查阅并与相关人员沟通，本项目财务从账户设置、资金往来、银行开户等过程完全符合财务处理有关规范和标准；不可预见费方面，检查中看到本项目有动用不可预见费的情况，专家组已与施工单位沟通，有关依据证据和数据还需进一步完善和收集整理清楚，后续会利用时间做专门对接。

# 进度追踪
各模块进展如下：

- **卢萨卡点验收**：已完成除弹料加工调试以外的所有验收工作。
- **蒙泽点验收**：已完成全部验收工作，并利用带料调试厂家在场资源顺带完成整个流程试生产、外方人员操作及产品生产过程。
- **姆皮卡点验收**：现场验收工作尚未开展，内业资料已提前拿到卢萨卡点。
- **内业资料**：管理组技术组基本按项目合同组建执行团队并按流程程序开展工作，编制施工组织计划、管理计划、实施细则及各项专项预案，验收组查阅资料、现场抽检及问询交流，基本评价为满足项目有关标准和规范要求；但分类整理及少量质检和管理机构验收签字的规范性还需进一步规范和完善。
- **建筑部分**：原材料除国内采购出口建筑材料外，主要主材包括预制构件、年广场地砖从卢萨卡大规模成建制有质量管控体系的供货单位集中预制采购、从200多公里以外拉过去，内在品质通过查验资料、外在表观通过现场抽检和检测达到很好标准；因资料完整整理结果没出来，今天不下最后结论。
- **安装部分**：钢结构所有材料从国内定制发货到现场，施工工艺吊装精确度到现场查看外观质量满足规范和标准要求；设备由技术组执行单位与国内中粮西安设计院及相关厂家签订专项供货合同、参照中国标准按输出产品分三类标准专门定制编制并生产三套成套设备，厂家高峰期派十几名工作人员到现场指导安装，目前厂家团队、技术组和管理组驻厂专家成员在蒙泽点继续培训和交底。
- **机电设备**：验收组对工艺设备逐台复核并投料试运行，工艺设备运行正常、工艺流程满足生产要求、产能符合设计指标，机电设备安装正确运行正常、达到国家质量检验有关标准。
- **财务**：财务验收专家查阅本项目财务资料并与相关人员沟通，本项目财务从账户设置、资金往来、银行开户等过程完全符合财务处理有关规范和标准。
- **不可预见费**：检查中看到本项目有动用不可预见费的情况，专家组已与施工单位沟通，有关依据证据和数据还需进一步完善和收集整理清楚，后续会利用时间做专门对接。

# 风险预警
整体健康度：🟡低风险。主要风险与瓶颈如下：

- 人员履约方面，个别同志进出场时间以及护照还需施工部和管理组进一步完善，个别岗位人员因各种原因有申请更换流程，个别特种人员证件有效期可能因出国后国内延期或更新未及时到位。
- 人员统计数量尤其是技术组对厂家服务人员可能没有计算进去，投标和合同文件对数量有要求。
- 内业资料分类整理以及少量质检和管理机构验收签字的规范性还需进一步规范和完善，竣工文件全部集中到卢萨卡点过程中有一个点因太远还在分散。
- 某厂区非主要通道范围内混凝土路面有少量开裂现象，可能与基础碾压和混凝土扬升过程有关，若移交外方投入使用后再出现大面积开裂，对外影响不太好。

- 卢萨卡点加工提升桶往上位置，赞比亚雨量大风大，雨水可能倒灌。

# 后续计划
下一周期核心交付物与关键时间节点如下：

- **在末次会之前、最迟在出报告之前完成混凝土路面开裂整改**，由管理组和总包单位共同研究会同制定科学合理的整改方案，分析原因并结合赞比亚当地气候特点，整改完成后由验收组进行复核，在报告中形成闭环。
- **在验收完成第一时间将三个厂区资料全部汇总于卢萨卡**，包括竣工图进行分类汇总、分类组卷及编码，由技术组按验收组专家要求及援外项目执行手册管理办法规定执行。
- **在形成验收报告之前完善个别同志进出场时间以及护照资料**，达到闭合条件，由管理组和技术组负责。
- **与国内人力资源对接完善个别特种人员证件有效期延期或更新问题**，由执行单位负责。
- **全面检查监控管线接头脱落问题**，保证有效性和安全性，由施工组负责。
- **检查卢萨卡点加工提升桶往上位置雨水倒灌问题**，考虑增加覆盖面积或通过技术措施解决。
- **建议卢萨卡点廊墙最端头中间加两个竖条**，为巡检和维护人员提供安全保障。
- **交给外方之前继续做好成品保护**，破损地方及时修补。
- 会后及时安排接下来的工作情况，通过适当渠道向后方的领导汇报整个工作进展情况。

*依赖前提：姆皮卡点现场验收工作尚未开展，需在会后安排并注意雨季路况与交通安全；不可预见费有关依据证据和数据需进一步完善，后续专门对接。*
