# 沟通背景与目的
本次直播为杭州医学院医学技术专业硕士点招生宣讲，由检验医学院、生物工程学院党委书记、副院长宋宝峰副教授主讲，面向考生及家长介绍学位点基本情况、学科优势、研究方向、师资队伍、培养与就业、2026年招考计划及复试安排，并解答考生关于就业前景、初试科目、跨专业报考等问题。学位点于2024年获批，由5个学院共同承担培养工作，聚焦检验技术、医学影像技术、康复治疗、智能医学工程四个方向，2025年录取64人。学科建设方面，2023年获批省一流学科B类，近五年获国家级基金项目19项、纵向科研经费1300万、横向合作课题经费2200多万。师资方面，专任教师90人，高级职称53人，博士55人，硕导69人。2026年计划招生34人（以教育部正式下达为准），初试科目为思想政治理论、英语加一门按方向设置的专业课，复试初试占60%、复试占40%。宣讲明确允许非本专业考生跨专业报考，就业面涵盖医院、疾控中心、医药企业、医疗器械公司、保险公司、药监局、卫健委、海关、高校、研究所等。

# 达成共识
**达成的共识**：
- **允许非本专业考生跨专业报考医学技术专业硕士点**，宋宝峰明确表示「允许本科的就是非该专业的，就是比方说啊在从事检验的，你包括我们这个检验这个方向是可以的，可以跨专业自主报考的啊，这个大家放心」。
- **2026年计划招生34人，但以教育部正式下达人数为准**，宋宝峰强调「这个招生人数啊仅供这个参考啊，我们要以教育部的2026年这个正式下达的这个人数为准」。
- **复试成绩占比为初试60%、复试40%**，复试内容为英语能力测试20%、专业能力测试40%、综合能力测试40%。
- **就业前景被看好**，宋宝峰表示「大家不用不用太过担心哈和这个焦虑哈，我们是非常有信心的哈，大家一定有一个美好的这个前程」。
- **学校重视学科竞赛**，宋宝峰表示「以赛促学，以赛促教，以赛促改，来提高我们整个的这个教学质量，人才培养水平」。
