# 参观概况
本次参观为故宫博物院游览，讲解围绕午门、太和殿、中和殿、保和殿、乾清宫、坤宁宫、储秀宫、珍宝馆等主要景点展开，涵盖历史功能、建筑细节与相关典故，并推荐三条游览路线及七个免费盖章点。全程以中轴线为主，结合东西两侧宫殿与文创点，形成完整动线。讲解提示陶瓷馆（武英殿）关闭、文华殿有展览（未确认开放），并建议早到以错开人流。

# 核心看点与讲解
午门：明朝杖打犯错大臣，清朝行颁朔之礼；门洞明三暗五，中间正门仅供皇帝、大婚皇后及殿试前三名（状元、榜眼、探花）通行，旁门走皇亲国戚与文武百官。太和门广场：五座金水桥，中间桥供皇帝，两侧桥分属皇亲国戚与文武百官；太和门为明朝御门听政处，门口铜狮为故宫六对铜狮中最大一对，脚踩寰宇象征权力。太和殿：金銮殿，举行登基、皇后册封等大典，文武百官在广场行三呼万岁礼，站位为文东武西；西侧弘义阁为皇帝银库，东侧体仁阁为缎库。中和殿：大典前皇帝休息室。保和殿：自乾隆五十四年起为殿试考场，东北角汉字馆有4枚免费印章，可购《紫禁城100》现场盖章，各店印章不同且不能跨店盖。乾清门：过门即后宫，皇帝在此上早朝；东侧九卿直房为高等级大臣等待召见处，西侧为军机处；门口铜狮耷耳遮眉，警示后宫不该看别看、不该听别听。乾清宫：皇帝寝宫，内有27张龙床防刺客；牌匾“正大光明”后藏立储诏书，皇帝写两份对比以防篡改；门口有铜鹤铜龟及紫禁城最小宫殿“社稷江山金殿”，提醒皇帝以民生为本。交泰殿：存放25块传国玉玺。坤宁宫：皇后居所，明朝皇后均住此，东北角文创店有5枚免费印章。储秀宫：慈禧住20余年，现为慈禧五十大寿原状陈列，因儿子在此出生而偏爱，旁有文创店3枚免费印章。翊坤宫、永寿宫、太极殿（东西六宫唯一称殿者）。慈宁宫：康熙为孝庄皇太后修建的养老院；寿康宫为甄嬛（熹贵妃）居所。冰窖书吧：3枚免费印章，印章造型有批折子感。断虹桥：石狮形态各异，最有名为“捂裆狮”。武英殿：原为陶瓷馆，目前关闭。文华殿：东侧，与武英殿对应文东武西，去时未开，据说有展览。箭亭：清朝皇帝及子孙练习骑马射箭处，旁商店有文创雪糕。钟表馆：展示各式钟表。珍宝馆：门口有我国现存三座古代九龙壁之一，左数第三条白龙下方为木头修补（烧制损坏后以木刷漆以假乱真）；珍宝馆实为宁寿全宫，乾隆养老院，退休后仍照常上朝；皇极殿1:1复刻乾清宫，宁寿宫对标坤宁宫，养性殿后为乐寿堂（故宫唯一可入内参观的皇家寝室，有二龙戏珠设计），再后为珍妃井（井口石非珍妃坠入处）；出口商店有3枚免费印章。东筒子夹道：拍照出片。延禧宫：网红打卡地；景仁宫为甄嬛封熹妃时所居，珍妃亦住过。御花园：钦安殿供奉真武大帝，与景山形似闭目盘坐人像相呼应。神武门：故宫北门，出宫后左手边角楼咖啡与故宫文创各有2枚免费印章。

# 互动与体验
讲解中穿插互动提问，如询问文创雪糕形象、御花园与和珅后花园偏好等，并邀请观众在评论区分享。个人感受包括：珍宝馆游客众多，尤其看凤冠需挤入；冰窖书吧印章造型有批折子感；东筒子夹道拍照出片；一天走3万步，提醒适当休息补水。

# 收获与建议
收获包括：了解午门明三暗五、太和殿典礼功能、文东武西站位、乾清宫立储诏书、社稷江山金殿寓意、九龙壁木头修补典故、珍宝馆为乾隆养老院等知识。建议：早到排队进门后沿中轴线先逛，错开旅游团；三条路线按时间选择——全天路线（约3万步）、半天路线（中轴线+景仁宫、延禧宫、钟表馆、珍宝馆、御花园）、2小时省力路线（中轴线+储秀宫、御花园）；盖章爱好者可收集七个免费盖章点（汉字馆4枚、坤宁宫文创店5枚、储秀宫文创店3枚、冰窖书吧3枚、珍宝馆出口商店3枚、角楼咖啡2枚、故宫文创2枚），注意各店印章不同且不能跨店盖。
