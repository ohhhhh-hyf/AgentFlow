# 就诊概况
48岁男性患者张学恒，因上腹心窝处烧灼样疼痛反复发作4年、近3个月加重，于消化专科门诊就诊。疼痛与进食冷硬、辛辣食物及工作紧张劳累相关，近4年出现两次黑便（一年前及三个月前），均住院确诊大便出血，住院两三天后转黄；近两个月呕吐数次，吐出黄水样酸物，为早中餐食物，吐后舒适。既往有甲肝史（16岁，已愈）、磺胺药过敏史；家族中婶婶（无血缘关系）患胃癌。医生初步考虑消化道出血可能，建议留大便检查并预约后天胃镜，将向上级张医生汇报后商定治疗方案。

# 诊断与检查结果
本次门诊未进行胃镜及大便检查，医生根据病史初步判断存在消化道出血可能，需进一步检查明确。患者近4年两次黑便（一年前及三个月前）均经住院检查确诊大便出血，住院两三天后转黄；近3个月大便黄色正常，小便正常。既往16岁患甲肝，在三医院住院一个月，出院及后续体检肝功能均正常；对磺胺药过敏（左手红疹，持续半个月）。

# 治疗方案与医嘱
患者近期服用“大叔”（可能为药物名）效果渐差，从最初一天两次每次一颗增至每天四五次仍效果不佳；后加用奥美拉唑（国产，武汉药厂）和阿莫西林，以及单位医务室自配胃炎合剂，均初服有效，停药后复发。医生建议留大便检查以排查出血，并预约后天胃镜；关于手术问题，医生表示待检查资料全面后再判断，若药物可控则不需手术。生活注意事项：建议戒烟、少饮酒，因工作紧张、常加班熬夜可能加重病情，需注意休息。重点禁忌：**磺胺药过敏，用药需避免磺胺类药物**。
