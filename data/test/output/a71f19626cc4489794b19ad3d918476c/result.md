# 消化专科病史采集与诊疗安排

## 就诊概况
48岁男性患者张学恒，在成都轻工研究所从事科研工作，因上腹反复疼痛4年、近3个月持续发作，于消化专科初诊。疼痛位于心窝处，呈烧灼感，进食冷硬食物或工作紧张时诱发，白天为主，无夜间痛醒；近一年内两次黑便（一年前及三个月前），每次持续约一个月，均经医院检查诊断为大便出血并住院治疗；近两个月呕吐数次，吐出酸味黄水样物，为早午餐食物，晚间腹胀时呕吐后缓解。近期服用奥美拉唑（武汉药厂产）和阿莫西林，效果不佳，自行加量至每日4-5次。近三个月无黑便，大便黄色正常，小便正常，体重无明显下降。初步考虑上消化道疾病可能，需进一步检查明确，已预约后天胃镜并留大便标本。

## 病史与背景
1. **现病史**：上腹反复疼痛4年，每年春季多发，近3个月持续发作；疼痛位于心窝处，呈烧灼感，进食冷硬食物或工作紧张时诱发，白天为主，无夜间痛醒，可忍受；近三个月有完全不痛时（暖和、工作轻松时）。
2. **黑便史**：一年前及三个月前各出现一次黑便，每次持续约一个月，每日最多两次，大便形状基本正常；两次均经医院检查诊断为大便出血，分别住院约10天和2-3天，住院后大便转正常。
3. **呕吐史**：近两个月呕吐数次，吐出酸味黄水样物，为早午餐食物，晚间腹胀时呕吐后缓解；无隔夜食物吐出，无红色或黑色物。
4. **既往史**：16岁时患甲肝，在三医院住院一个月，出院及后续体检肝功能均正常；小时候因扁桃体炎在成都市儿童医院就诊，服用磺胺药后左手起红疹，持续半个月，确诊磺胺药过敏；双眼近视400度，偶尔口腔溃疡；无手术史。
5. **个人史**：吸烟史，以前每天一包，现限制在10支以内；偶尔饮酒，平时不喝；在成都轻工研究所从事科研工作，工作紧张，经常加班熬夜；已接种乙肝疫苗（上海产，三针）。
6. **家族史**：父亲76岁有低血压，母亲75岁有冠心病，弟弟身体健康；婶婶（无血缘关系）患胃癌，患者担心自己是否也患此病。

## 诊断与检查结果
1. **初步诊断**：考虑上消化道疾病可能（如消化性溃疡等），需进一步检查明确，尚未确诊。
2. **检查安排**：已预约后天胃镜，并需留大便标本检查有无出血。
3. **医生说明**：严医生解释婶婶患胃癌与患者无血缘关系，不必过度担心遗传风险；甲肝为急性病，不会慢性迁延，肝功能已恢复。
4. **患者顾虑**：患者担心是否需手术，因工作繁忙及可能出国进修，希望尽早安排；严医生表示待检查资料全面后再判断，药物控制可能避免手术。

## 治疗方案与医嘱
1. **检查安排**：留大便标本检查有无出血；胃镜预约在后天进行（因患者爱人可请假陪同）。
2. **用药**：近期服用奥美拉唑（武汉药厂产）和阿莫西林，效果不佳，自行加量至每日4-5次；另服用医务室自配胃炎合剂，效果不稳定，停药后症状反复。
3. **生活方式**：建议戒烟（现限制在10支以内），尽量少喝酒，注意休息，避免加班熬夜。
4. **复诊安排**：严医生将总结病情后向上级张医生汇报，再商定下一步处理意见。
