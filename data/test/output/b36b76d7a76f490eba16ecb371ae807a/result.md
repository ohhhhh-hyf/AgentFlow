# 沟通概况
本次家长会由372班班主任林瑞主持，围绕班级基本情况、存在问题与解决思路、费用收取、保险与电子学生证办理、家长委员会成立等议题展开，并与家长沟通家校协同事项。班级共60人，男生25人、女生35人，学生处于生理心理变化期，班风班貌良好，但少数同学存在周末玩手机、懒散、自习课效率低等问题。班主任提出手机放入手机箱、家长周一到周五可打电话检查手机是否上交等管理措施，并强调费用由学生交给生活委员、不在微信群收取，提醒家长和学生注意反诈。家长代表张宇波分享家庭教育经验，强调关注孩子身心健康、先做人后成才、平常心对待孩子。会议还明确成立家长委员会（至少三人、自愿报名），并沟通保险约310元可自行购买、电子学生证套餐78元等事项。

# 沟通内容
**亮点**：班级班风班貌良好，纪律与卫生表现好；学生时间观念和执行力较强；多数学生书写良好；学生遇到问题会主动向老师请教。

**需关注之处**：个别学生书写需练字，建议家长买字帖；自习课效率低，老师不在时纪律松散；少数同学周末玩手机、懒散；发现学生带镜子、看小说、玩手机，要求全部收掉；少数男生有网瘾，充游戏费用400元；有学生看直播、不健康内容；存在谈恋爱现象，建议家长关注QQ、抖音、快手等社交账号。

# 家长反馈
家长代表张宇波（372班语文老师）分享家庭教育经验，强调关注孩子身体健康和心理健康，先做人后成才，平常心对待孩子，尊重孩子，多倾听多交流，配合学校制度。她提到自己对孩子说：“无论怎样，你都是爸爸妈妈心里最优秀的儿子。”并建议家长给孩子自由空间，不轻易下消极评价。
