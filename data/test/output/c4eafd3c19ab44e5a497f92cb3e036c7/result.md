# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司（东源煤电）、云南东源曲靖电力有限公司（曲靖电力）、招银金融租赁有限公司（招银租赁）金融借款合同纠纷上诉案，由最高人民法院二审公开开庭审理。合议庭由审判长李少平及审判员魏文超、黄年、王海峰、葛洪涛组成，法官助理张瑞。各方当事人对出庭人员身份均无异议，东源煤电、东源煤业、曲靖电力合并发表意见。庭审围绕三个争议焦点展开：国开行抵押权是否构成善意取得、一审判决对罚息复利计算及起算日期是否认定错误、东源煤电及东源煤业是否应连带给付违约金。合议庭休庭评议后提出调解方案，各方均无异议，合议庭予以确认，庭后出具调解书。

# 举证与法庭调查
**证据与质证意见**
- **东源方邮件证据**：东源方主张2015年12月2日邮件中融资情况统计表载明招银租赁抵押物为恩洪电厂设备资产、抵押手续已登记，国开行抵押物为恩洪电厂设备在建工程、正在办理，且设备名称完全一致、用红色标注，国开行应尽注意义务；国开行反驳称邮件系贷后审查材料，统计表并列描述不能得出已告知的结论，且2015年12月2日邮件与12月22日签订抵押合同时间吻合，贷后审查报表应在次年年初提供。
- **国开行融资租赁查询证书**：国开行提交2018年9月对曲靖电力公司的融资租赁查询证书，主张已尽查询义务；招银租赁质证称该证书不符合要求，依据2014年93号中国人民银行规定，国开行应提供2015年12月抵押时点的查询结果。
- **招银租赁回租设备清单**：招银租赁一审提交回租设备清单（证据第7页），仅载明设备名称和生产厂家，未载明型号，出厂日期为2012年3月1日；国开行质证称现场调查核实抵押设备铭牌生产日期均在2013年以后（部分2013年11月、12月，部分2014年3月），看不出是同一设备。
- **权属证明材料**：国开行提交证据第54页、58页，显示东源煤电、曲靖电力对设备权属的证明材料和股东会决议，证明设备所有权属曲靖电力；国开行据此主张已尽审慎义务，融资租赁登记核查义务仅限于曲靖电力公司。
- **融资租赁登记核查表**：国开行提交证据第108页核查表，显示曲靖电力公司名下无融资租赁登记信息，主张已按法律法规和行业规范履行义务，构成善意取得。
- **审计报告**：招银租赁一审提交2013年和2015年审计报告（证据第82页、95页），载明曲靖电力公司注册资本4亿元且已实缴；国开行据此主张招银租赁知道或应当知道设备出资情况。

**法官询问要点**
- **融资租赁登记性质**：审判长询问各方如何理解中国人民银行征信中心融资租赁登记的性质及法律后果；国开行认为系行业强制性规范，目的是防范金融风险；招银租赁认为系权利公示，具有对抗效力，但不影响所有权设立转移；东源方认为系行业指导性规范，不当然产生物权后果。
- **查询方式**：审判员王海峰询问融资租赁登记系统有几种查询方式；国开行称仅能按查询单位查询；招银租赁称可按公司名称或设备查询，但设备查询涉及种类物区分问题。
- **设备识别码登记**：审判员询问案涉5套设备识别码是否登记清楚；招银租赁称设备系种类物，无唯一识别码，当时未登记；审判员追问设备安装后发电机上是否有唯一标识码，招银租赁称铭牌上只有型号和参数，上海电气出厂的同型号设备铭牌相同。
- **内部风控规定**：审判员询问国开行贷款前审查是否有内部规定要求必须查询融资租赁系统并保留未查询到结果的单子；国开行称按央行规定查询，因无记录未保留筛查记录，内部无此规定。
- **查询义务程度**：审判员询问违反查询规范多大程度导致融资租赁司法解释第9条第2款后果，是基本查询义务还是全面审慎义务；国开行主张基本义务，招银租赁主张严格义务，未查询即不构成善意。
- **其他途径知晓**：审判员询问若银行通过其他途径知晓抵押物属融资租赁物，是否相当于已了解风控情况；国开行称基本义务必须履行，招银租赁称仍须通过央行系统查询，因其他途径无法证明。
- **举证责任分担**：审判员询问融资租赁司法解释第9条第2款举证责任如何分担；国开行主张按谁主张谁举证原则，招银租赁主张第1、2、4项由出租人举证，第3项由第三人（国开行）举证。
- **登记信息冲突**：审判长询问各方如何看待不同登记机构产生的登记信息冲突及建议；国开行认为系系统信息不完整、条块化分割问题，招银租赁建议从立法、行业协会、技术层面改进。

**双方辩论的争议焦点**
- **告知义务是否履行**：东源方主张2015年12月2日邮件已告知设备抵押情况，国开行应尽注意义务；国开行主张邮件系贷后审查材料，统计表并列描述不能得出已告知结论，且招银租赁栏记载的抵押类型为不动产抵押，与融资租赁是两个法律概念。
- **审查义务范围**：国开行主张其审查义务仅限于抵押人曲靖电力公司，不能扩大到关联企业；招银租赁主张东源煤电系借款人兼抵押人全资控股母公司，国开行应调查东源煤电的权属完整性。
- **设备所有权归属**：招银租赁主张2012年设备交付时即取得所有权，东源煤电出资行为系无权处分；国开行主张设备系通用设备无唯一标识码，已对抵押人系统查询无记录，且权属证明显示所有权属曲靖电力。
- **是否构成善意取得**：国开行主张已尽审慎义务，构成善意取得；招银租赁主张国开行未在抵押时点查询，不构成善意。
- **上海中院判决影响**：国开行主张上海中院判决仅限返还义务，未确认所有权归属，与本案抵押权审理不冲突；招银租赁未直接回应。

# 庭审结果
**争议焦点归纳**
- **争议焦点一**：国开行抵押权是否构成善意取得。国开行主张已尽审查义务，抵押设备为通用设备无唯一标识码，且已查询融资租赁登记系统无记录，构成善意取得；东源方主张国开行未尽注意义务，因邮件中已用红色标注设备名称一致；招银租赁主张国开行未在抵押时点查询，不构成善意。
- **争议焦点二**：一审判决对案涉借款罚息复利计算及起算日期是否认定错误。国开行主张利息自2017年12月21日计算至2018年6月12日，罚息自2018年6月13日起算，复利自2018年3月21日起算；东源方主张国开行宣布贷款提前到期未给合理期限，且罚息不应作为复利基数。
- **争议焦点三**：东源煤电、东源煤业是否应连带给付违约金。国开行主张依据借款合同第24条第3项，被上诉人违约应支付千分之一违约金，且未配合办理账户管理及柜台前移手续；东源方主张国开行未举证证明违约行为，且未按合同约定发出限期纠正函。

**庭审结果**
- **调解方案**：合议庭休庭评议后提出调解方案，各方当事人均无异议，合议庭予以确认，庭后出具调解书。
- **债权确认**：国开行对东源煤电债权扣除破产清偿本金后，利息、罚息、复利合计6474.4513万元；招银租赁对涉案6项设备享有所有权，对应债权数额1377.4137万元；国开行对93项设备有抵押权，招银租赁对6项设备有所有权。
- **设备处置**：招银租赁和国开行对案涉全部发电设备整体盘活处置，变现价款双方各得50%，费用各担50%；调解书生效后20日内，国开行向一审法院提出执行申请，启动司法处置程序。
- **后续安排**：若破产管理人不将招银租赁债权纳入预留方案，由东源煤电按有担保清偿方案清偿；若司法变现不能，国开行和招银租赁放弃案涉设备权益，由东源曲靖电力自主生产经营；案涉设备管理费用由东源曲靖电力承担，东源曲靖电力无条件配合司法处置。
- **费用承担**：一审判决第2项、第4项无争议，按判项内容确认；一审诉讼费用中招银租赁诉请部分由二审法院计算后由国开行承担，二审诉讼费用由国开行和东源煤电各承担50%。
- **未决事项**：协议签订后各方就本案问题不再存在任何争议。
