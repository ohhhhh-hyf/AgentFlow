# 就诊概况
48岁男性患者张学恒，在成都轻工研究所从事科研工作，因上腹反复疼痛4年、近3个月加重，于消化专科初诊。患者主诉心窝部烧灼样疼痛，进食冷硬食物或工作紧张时诱发，近一年内两次出现黑便（分别于一年前和三个月前，每次持续约一个月，每日最多两次，均住院治疗后大便转黄），近两个月呕吐数次，呕吐物为酸味黄水样物，含未消化食物，夜间腹胀时呕吐。近期自行服用奥美拉唑、阿莫西林及医务室胃炎合剂，效果不佳。医生初步考虑上消化道疾病可能，需进一步检查明确诊断，已安排留大便检查及胃镜检查。

# 病史与背景
- **现病史**：上腹疼痛4年，每年春季多发，近3个月反复发作；疼痛位于心窝部，呈烧灼感，进食冷硬食物或工作紧张时诱发，可忍受，无夜间痛醒；近三个月大便为黄色，小便正常。
- **黑便史**：一年前和三个月前各出现一次黑便，每次持续约一个月，每日最多两次，大便呈黑色、像马路上的柏油，形状基本正常；两次均住院治疗，住院后大便转黄，住院时间分别为10天和两三天。
- **呕吐史**：近两个月呕吐数次，呕吐物为酸味黄水样物，含早晨和中午吃的食物，晚上感觉腹胀时呕吐，吐后舒服，无隔夜食物吐出，呕吐物无红色或黑色。
- **既往史**：16岁时患甲肝，在三医院住院一个月，出院时肝功能正常，之后体检肝功均正常；小时候因扁桃体炎在成都市儿童医院就诊，服用磺胺药后左手出现红疹，持续半个月，确诊磺胺药过敏。
- **预防接种**：按计划进行，近两年所里统一接种乙肝疫苗，上海产，共三针，无不良反应。
- **系统回顾**：偶有头痛头昏，与休息有关，未就医；双眼近视400度，平时不戴眼镜；偶有口腔溃疡，用贴片治疗；无咳嗽咳痰、无心慌心累；偶有腹泻，与进食不洁食物有关，急性自愈；无关节肌肉疼痛。
- **个人史**：出生并长期生活在成都，在成都轻工研究所从事科研工作，工作紧张，经常加班熬夜；吸烟史，以前每天一包，现限制在10支以内，计划逐步戒烟；偶尔饮酒，平时不喝；每天泡茶两次；26岁结婚，爱人及孩子身体健康。
- **家族史**：父亲76岁，有低血压（90/60mmHg）；母亲75岁，有冠心病，药物控制良好；有一个弟弟，身体健康；婶婶（叔叔的爱人）患胃癌，患者担心自己患病。

# 诊断与检查结果
医生初步考虑患者为上消化道疾病，需进一步检查明确诊断，未确诊。患者有两次黑便史，可能存在消化道出血，需留大便检查明确有无出血。患者有婶婶胃癌家族史，虽无血缘关系，但患者有胃癌担忧，医生解释婶婶与患者无血缘关系，无需过度担心。患者担心是否需要手术，医生表示待检查资料全面后再判断，若药物能控制病情则无需手术。

# 治疗方案与医嘱
- **检查安排**：留大便检查，以明确有无出血；胃镜预约在后天进行，患者爱人可陪同，胃镜活检后由张大夫查房时讨论结果。
- **用药**：患者近期自行服用奥美拉唑、阿莫西林及医务室胃炎合剂，效果不佳，医生未开具新药，待检查结果明确后决定治疗方案。
- **生活方式与饮食**：医生建议患者尽量少抽烟或不抽烟，少喝酒，因吸烟饮酒可能加重胃部疾病；注意休息，避免熬夜。
