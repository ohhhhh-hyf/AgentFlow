# 知识主题与概述
本视频围绕Stack Exchange上关于调和级数∑1/n收敛性的经典问题展开，皮卡以评论者身份逐一点评网友的证明方法。他首先从高中数学的前n项和定义出发，解释级数收敛与发散的标准：若所有部分和Sn小于某个固定上界a则收敛，若部分和能超过任意给定的数则发散。随后他介绍了两种主要证明流派：第一种通过分组估计，每组和大于1/2，从而证明部分和无上界；第二种通过证明H_n > log(n+1)来证明发散，因为log无上界。皮卡还补充了柯西凝聚判别法、积分估计和Stolz定理等工具，并批评某些证明是事后凑出来的、故弄玄虚，妨碍理解。整体逻辑框架是从基础定义出发，逐步剖析不同证明思路的优劣，最终强调自然、可理解的证明方法。

# 核心概念
## 调和级数
- 调和级数指∑1/n = 1 + 1/2 + 1/3 + …，其部分和记为H_n（英文为harmonic，调和之意），是微积分中的经典问题，属于清朝初年（康熙治鳌拜时期）提出的微积分范畴。
- 收敛与发散的定义：对正向级数，若所有部分和Sn都小于某个固定实数a（如100或1000万），则收敛；若部分和能超过任意给定的数，则发散。

## 分组估计证明
- 第一个网友的证明：将项分组，如1单独一组，1/2+1/3一组，1/4+1/5+1/6+1/7一组，每组和都大于1/2，因此任意多组相加无上界，故发散。
- 皮卡指出，这种分组求和思路与高斯小时候计算1+2+3+…+100的方法类似，都是发现具有良好性质的组（如和恒定或满足估计），从而简化求和问题。

## 柯西凝聚判别法
- 柯西凝聚判别法的证明过程与分组估计完全一样，适用于非负不增序列，通过分组取上界或下界来估计部分和。
- 应用该方法，∑1/n的收敛发散性等价于∑2^k·(1/2^k) = ∑1，即无穷个1相加，显然发散，从而简化了对增长缓慢序列的判断。

## 积分估计流派
- 该流派用积分曲线面积近似H_n：因为H_n的每一项高为1/n、底为1，矩形面积始终大于下方曲边梯形面积，故H_n > ∫₁ⁿ⁺¹ (1/x)dx = log(n+1)，而log无上界，所以发散。

## 差分流派（Stolz定理）
- 该流派试图证明H_n与log n同增长级别，通过Stolz定理（中文称Stolz定理，数学竞赛和考研常用）求差分极限：分子差分H_{n+1}-H_n = 1/(n+1)，分母差分log(n+1)-log n = log(1+1/n)，两者极限均为1，故H_n/log n → 1。
- 皮卡认为此方法不自然，因为需要事先知道H_n与log n同阶，属于先射箭后画靶。

# 核心结论
核心结论：调和级数∑1/n是发散的，这是微积分中的经典结论，可通过分组估计、柯西凝聚判别法、积分估计或Stolz定理等多种方法证明。易混淆点：收敛与发散的定义需明确上界a是固定的，且对所有n成立；部分和H_n与log n的关系是H_n > log(n+1)，但H_n本身无上界。待澄清问题：皮卡批评某些证明（如差分流派）是事后凑出来的，不自然，认为它们故弄玄虚、妨碍理解，但未给出更自然的替代证明。易错点：**不要误以为调和级数收敛**，因为虽然项趋于0，但部分和无上界；**不要混淆log与ln**，皮卡指出log是美国的写法，ln是欧洲传苏联再传中国的写法，两者本质相同。
