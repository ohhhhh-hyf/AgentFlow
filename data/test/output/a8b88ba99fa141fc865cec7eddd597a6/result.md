# 知识主题与概述
本笔记围绕调和级数收敛性的证明方法展开，源自皮卡在Stack Exchange上对网友回答的评论。皮卡首先介绍了级数收敛与发散的定义，随后评述了分组求和、柯西凝聚判别法、积分估计、对数差分等证明思路，并指出这些方法背后的本质联系。他批评了某些证明的故弄玄虚，认为其本质是简单的分组或积分估计，却故意写成复杂形式，妨碍理解；同时指出部分证明（如对数差分、Stolz定理）有“先射箭后画靶”之嫌，不够自然。皮卡计划根据本期视频的反响决定是否继续该系列。

# 核心概念
**级数收敛与发散的定义**
- 对于正向级数，若所有部分和 `sn` 都小于某个固定实数 `a`，则级数收敛；若部分和大于某个无界递增的 `bn`，则级数发散。

**分组求和法**
- 将调和级数分组，每组和均大于 `1/2`，从而证明其发散。
- 皮卡指出，该思路与**柯西凝聚判别法**的证明过程完全一致，即通过分组估计部分和。

**柯西凝聚判别法**
- 对于非负不增序列，其收敛性与凝聚后的序列 `2^k * a_{2^k}` 相同。
- 应用于调和级数时，等价于判断 `Σ 1` 的收敛性，显然发散。

**积分估计法**
- 利用积分曲线面积近似部分和，证明 `hn > log(n+1)`，因 `log` 无上界，故调和级数发散。

**对数差分法**
- 通过 `e^{1/k} > 1 + 1/k` 放缩，连乘积化简为 `n+1`，证明发散。
- 皮卡认为此法与积分估计本质相同，但形式复杂，有“装逼”之嫌。

**Stolz定理法**
- 利用 `hn / log n` 的差分极限为 `1`，证明二者同阶，从而发散。
- 皮卡批评此法不自然，属于“先射箭后画靶”。

# 核心结论
**核心结论**：调和级数发散，可通过分组求和、柯西凝聚判别法、积分估计、对数差分、Stolz定理等多种方法证明，这些方法本质相通。

**易混淆点**：
- **收敛与发散的定义**：需明确部分和是否有上界。
- **柯西凝聚判别法**与分组求和法的证明思路完全一致。
- **对数差分法**与积分估计法本质相同，只是形式不同。

**待澄清问题**：皮卡未明确说明柯西凝聚判别法的完整证明细节，仅指出其与分组求和法相同；也未深入展开“dialectic分解”思路。
