# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷一案，因不服云南省高级人民法院云民初88号民事判决，向本院提起上诉。本院依法组成合议庭，依据《中华人民共和国民事诉讼法》第一百三十四条第一款、第一百六十九条的规定公开开庭审理。庭审围绕抵押权与融资租赁所有权冲突、罚息复利计算、违约金三个争议焦点展开法庭调查与辩论。合议庭休庭评议后提出调解方案，各方当事人均无异议并签署调解协议，本院予以确认并出具调解书。

# 举证与法庭调查
一、举证与质证情况。国开行提交证据包括：2015年12月2日邮件及附表、工商部门出资证明、设备权属证明、人民银行征信中心查询结果、2018年核查表（证据108页）等，用以证明已尽审查义务、构成善意取得抵押权。招银租赁提交证据包括：回租设备清单（证据7页）、2013年和2015年审计报告（证据82页、95页）等，用以证明其2012年已取得设备所有权、国开行未查询融资租赁登记系统不构成善意。东源公司提交2015年12月2日邮件及截屏，主张已履行告知义务。质证中，国开行认为邮件及统计表不能证明告知义务已履行，统计表中招银租赁抵押类型记载为不动产抵押，与融资租赁概念不同；招银租赁认为国开行2018年9月查询证书不符合2014年93号文要求，且抵押时点未进行查询；东源公司认为邮件发送时间（2015年12月2日）与抵押合同签订时间（2015年12月20日）吻合，且抵押设备名称以红色标注，国开行应尽注意义务。二、法庭询问要点。合议庭询问各方对中国人民银行征信中心融资租赁登记性质及法律后果的理解；询问国开行贷款前审查是否内部规定必须查询融资租赁系统并保留未查询结果单证；询问招银租赁融资租赁登记系统中设备唯一标识码是否必填项；询问国开行与招银租赁查询方式能否保证查询到登记结果；询问各方对因不同登记机构产生登记瑕疵的意见。三、双方辩论焦点。关于抵押权与所有权冲突，国开行主张已按人民银行规定查询曲靖电力公司名下融资租赁登记信息，未发现登记，且设备为通用设备无唯一标识，已尽合理审慎义务，构成善意取得；招银租赁主张国开行未在抵押时点查询融资租赁登记系统，不构成善意，且东源煤电出资行为系无权处分；东源公司主张已通过邮件履行告知义务。关于罚息复利计算，国开行主张罚息自2018年6月13日起算，复利按合同第六条第四款约定计算；东源公司主张罚息不应计收复利，且宣布贷款提前到期应给合理期限。关于违约金，国开行主张依合同第24条第三项约定，东源煤电未配合办理账户管理及柜台签约手续构成违约，应支付千分之一违约金；东源公司主张国开行未举证违约行为，且未履行限期纠正程序。

# 庭审结果
本案争议焦点为：一、国开行对案涉设备是否享有抵押权及是否构成善意取得；二、一审判决对案涉借款罚息、复息的计算是否正确；三、东源煤电、东源煤业是否应连带给付违约金。经合议庭评议并征求各方意见，提出调解方案：确定国开行对93项设备有抵押权，招银租赁对6项设备有所有权；招银租赁和国开行对案涉全部发电设备整体盘活处置，并从变现款中实现各自债权，变现价格双方各50%，实现费用双方各担50%；若司法变现不能，双方放弃对案涉设备权益，由东源曲靖电力自主生产经营；各方对一审判决第二项、第四项无争议，按判项内容在调解书中确认；一审诉讼费中国开行诉请部分按一审判决执行，招银租赁诉请部分由二审法院按规定确定，二审诉讼费由本院依法确定。各方对调解方案均无异议，签署调解协议，本院出具调解书。
