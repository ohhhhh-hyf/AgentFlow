# 产品概况
海尔洗衣机创新发布会正式推出洗干集成新物种叠黛H2，专为中国家庭客阳一体空间设计。针对中国80%用户将洗烘套装在阳台叠放使用带来的屏幕过高、开门方向相反、水盒太高太沉等痛点，叠黛H2以一体集成机身解决叠放震动隐患，高度降至167厘米，可嵌入60厘米标准橱柜，同向开门，无水盒设计。产品搭载智慧大脑中枢神经式智能网络、灵犀洗烘联动、原创双擎热泵技术、3D透视烘干、精华洗2.0及空净过滤系统，旨在让用户告别晾晒、享受整洁有序的新阳台生活方式。发布会公布两款定价：10kg 3D透视烘干款12998元，10kg净净双擎热泵款10998元。

# 市场定位与目标用户
叠黛H2的目标人群包括向往整洁有序新阳台的中国家庭，尤其适合年轻人、养宠家庭及有宝宝的家庭。典型使用场景为客阳一体空间，用户在此休闲娱乐、健身、社交，悬挂晾衣既不美观又占空间。与欧洲家庭洗烘套装并排摆放不同，中国80%用户将洗烘套装在阳台叠放，存在操作不便。叠黛H2以一体集成机身、同向开门、无水盒设计解决叠放痛点，超薄机身嵌入60厘米标准橱柜，全平不突出，让阳台更美观整洁。差异化竞争力在于灵犀洗烘联动实现数据共享、洗涤结束前上桶提前15分钟预热，以及3D透视烘干、空净过滤系统等创新技术，相比洗烘套装的貌合神离，实现上下桶默契配合。

# 核心卖点与技术参数
叠黛H2按功能维度划分如下：

**一体集成设计**：专为客阳一体空间设计，一体集成机身解决洗烘套叠放带来的震动等安全隐患，高度167厘米，超薄机身嵌入60厘米标准橱柜，全平不突出，同向开门，无水盒设计。

**智慧互联**：智慧大脑中枢神经式智能网络，灵犀洗烘联动实现数据共享，洗涤结束前上桶提前15分钟主动预热，缩短烘干时长。

**烘干技术**：原创双擎热泵技术，大件烘干不缠绕；首次引入行业领先黑科技3D透视烘干，羽绒服、水洗被可一次烘透，免去二次晾晒。

**洗涤技术**：升级精华洗2.0，激活洗衣液39分钟洗净一周衣物；新鲜净水漂洗减少洗衣液残留，对残留泡沫敏感人群友好。

**健康守护**：空净过滤系统去除衣物线屑和毛絮，洗衣无残留、干衣无毛絮，适合养宠家庭和有宝宝的家庭。

**静音体验**：搭载三台变频电机，洗涤、甩干、烘干全过程噪音低。
