# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司（东源煤电）、云南东源曲靖电力有限公司（东源曲靖电力）、招银金融租赁有限公司（招银租赁）金融借款合同纠纷一案，国开行不服云南省高级人民法院2018云民初88号民事判决，向最高人民法院提起上诉。本案由审判员李少平担任审判长，与审判员魏文超、黄年、王海峰、葛洪涛组成合议庭，法官助理张瑞，依法公开开庭审理。庭审围绕三个争议焦点展开：动产抵押与融资租赁登记冲突及善意取得、罚息复利计算及起算日期、违约金连带给付。经合议庭调解，各方当事人自愿达成调解协议并签字确认，合议庭将依法出具调解书。

# 举证与法庭调查
**证据与质证意见**
- 国开行提交2018年9月对曲靖电力公司的融资租赁查询证书，拟证明已履行查询义务；招银租赁质证认为该查询证书不符合要求，国开行应在抵押时点（2015年12月）查询人行征信中心。
- 国开行提交证据第54页、58页，东源煤电公司、曲靖电力公司对案涉设备的权属证明材料及股东会决议，拟证明设备所有权属曲靖电力公司；招银租赁未对该组证据提出实质异议。
- 国开行提交证据第108页融资租赁登记信息核查表，拟证明已对曲靖电力公司名下融资租赁登记进行核查；招银租赁认为核查范围应扩大至东源煤电。
- 招银租赁提交一审证据第7页回租设备清单，载明设备名称、生产厂家，未载明设备型号，出厂日期为2012年3月1日；国开行质证认为该清单与现场调查核实的设备铭牌生产日期（2013年11月、12月、2014年3月）不符，不能证明系同一设备。
- 招银租赁提交一审证据第82页、95页2013年、2015年审计报告，载明曲靖电力公司注册资本4亿元且已实缴；国开行质证认为该报告已对设备出资事项进行载明。
- 东源方提交2015年12月2日邮件及附件《东源公司融资情况统计表》，拟证明已告知国开行抵押设备与招银租赁设备存在重合；国开行质证认为该邮件系贷后审查材料，统计表中招银租赁栏记载抵押类型为不动产抵押，与本案融资租赁系不同法律概念，不能证明已履行告知义务。

**法官询问要点**
- 合议庭询问各方对中国人民银行征信中心融资租赁登记性质及法律后果的理解。国开行认为系行业强制性规范，旨在防范金融风险；东源方认为系行业指导性规范，不产生物权后果；招银租赁认为非法定物权登记，但具对抗效力。
- 合议庭询问融资租赁登记系统的查询方式。国开行称仅能按单位查询；招银租赁称可按公司名称或设备情况查询，案涉5套设备因无唯一识别码未登记。
- 合议庭询问国开行贷款前风控资料中是否有内部规定要求必须查询融资租赁系统并留存未查询到结果的记录。国开行确认无此规定，因未查询到结果故未保留记录。
- 合议庭询问融资租赁登记系统中设备唯一标识码是否必填项。招银租赁称非必填项，案涉设备无唯一识别码，登记时无法填写。
- 合议庭询问各方对违反查询规范导致《融资租赁司法解释》第9条第2款法律后果的理解，即查询义务是基本义务还是全面审慎义务。国开行认为是基本义务；招银租赁认为是严格义务。
- 合议庭询问若银行通过其他途径知晓抵押物为融资租赁物，是否仍需查询登记系统。国开行认为查询系基本义务，仍需查询；招银租赁认为仍需通过央行系统查询，以确定标准衡量善意。
- 合议庭询问各方对《融资租赁司法解释》第9条第2款举证责任分担的理解。国开行认为按谁主张谁举证原则；招银租赁认为第1、2、4项由出租人举证，第3项由第三人（国开行）举证。
- 合议庭询问各方对因不同登记机构产生登记信息冲突的看法及建议。国开行认为系系统信息不完整、条块化分割所致；东源方认为系统整合或衔接有必要；招银租赁建议从立法统一、发挥行业协会作用、技术实现信息互通三方面着手。

**双方辩论的争议焦点**
- 争议焦点一：动产抵押与融资租赁登记冲突及善意取得。国开行主张已按央行规定查询融资租赁系统，未发现曲靖电力公司设备有融资租赁登记，设备为通用设备无唯一识别码，审查义务仅限于抵押人曲靖电力公司，构成善意取得；招银租赁认为国开行未在抵押时点查询，东源煤电与曲靖电力为100%控股关系，应扩大审查范围；东源方指出2015年12月2日邮件中融资情况统计表已用红色标注抵押设备名称与招银租赁一致，国开行应尽注意义务。
- 争议焦点二：罚息复利计算及起算日期。国开行主张利息计算至2017年12月20日，罚息自2018年6月13日起算至2019年2月19日，复利自2018年3月21日起算；东源方认为合同约定限期偿还，国开行当天发函要求立即偿还无合同依据，且罚息不应作为复利基数，复利再计复利无依据。
- 争议焦点三：违约金连带给付。国开行主张东源煤电、东源煤业违反借款合同第24条第3项，应支付千分之一违约金，且未配合账户管理及柜台前移；东源方认为国开行未举证证明违约行为，且未按合同约定先限期纠正，故无权主张违约金。

# 庭审结果
本案争议焦点归纳为三项：一是动产抵押与融资租赁登记冲突及善意取得问题；二是罚息复利计算及起算日期问题；三是违约金连带给付问题。经合议庭调解，各方当事人自愿达成调解协议并签字确认，合议庭将依法出具调解书。调解方案主要内容：国开行对东源煤电的债权扣除破产中已清偿本金外，利息、罚息、复利合计6474.4513万元；招银租赁对涉案6项设备享有所有权，对应债权数额1377.4137万元；国开行对93项设备有抵押权；案涉全部发电设备整体盘活处置，变现价款双方各得50%，实现费用各担50%；调解书生效后20日内由国开行向一审法院提出执行申请；若司法变现不能，双方放弃设备权益，由东源曲靖电力自主生产经营；案涉设备管理费用由东源曲靖电力承担；一审诉讼费中国开行诉请部分按一审判决执行，招银租赁诉请部分由国开行承担，二审诉讼费由国开行和东源煤电各承担50%。各方对调解方案均无异议，未决事项已通过调解方案一并解决。
