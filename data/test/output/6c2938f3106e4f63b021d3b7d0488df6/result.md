# 发布会概况
王毅在慕尼黑安全会议上发表主旨演讲并回答主持人提问，阐述中国对多极世界的立场主张。王毅指出世界正走向多极化，中国主张推动平等有序的世界多极化，提出四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。他强调中国将坚定做变革世界中的建设性力量，并引用数据说明中国加入几乎所有普遍性政府间国际组织和600多项国际公约，承担超过20%的联合国会费，去年GDP增长5%，对世界经济增长贡献率接近30%。整体基调坚定务实，既展现中国维护国际秩序的负责任态度，也明确回应外界关切。

# 核心信息
- **多极化主张**：王毅指出80年前联合国成立时只有51个会员国，今天是193个国家，世界走向多极化是历史必然；中国主张推动**平等有序的世界多极化**，坚持权利平等、机会平等、规则平等。
- **国际法治**：中国加入了几乎所有普遍性的政府间国际组织和**600多项国际公约**，从不搞例外主义，更不搞合则用、不合则弃。
- **多边主义**：中国承担超过**20%的联合国会费**，切实履行《巴黎协定》，建成世界上最大的清洁发电体系。
- **全球倡议**：中国提出并落实全球发展倡议、全球安全倡议、全球文明倡议，为完善全球治理提供公共产品。
- **开放共赢**：去年中国GDP增长**5%**，对世界经济增长贡献率接近**30%**；中国愿推动高质量共建“一带一路”，同欧盟“全球门户”战略相互对接。
- **中欧关系**：今年是中欧建交**50周年**，中方愿同欧方深化战略沟通和互利合作。

# 官方表态
- **多极化秩序**：王毅表示“多极化的世界既是历史的必然，也正在成为现实”，中国必将是多极体系中的确定性因素，将坚定做变革世界中的建设性力量。
- **平等相待**：王毅强调“坚持权利平等、机会平等、规则平等，应当成为建设多极世界的基本原则”，呼吁提升发展中国家在国际体系中的代表性和发言权。
- **国际法治**：王毅指出“联合国宪章宗旨和原则是处于国际关系的根本遵循，也是建设多极世界的重要基石”，反对在遵守国际法上搞双重标准。
- **多边主义**：王毅表示“联合国是践行多边主义、推进全球治理的核心平台”，对于这座大厦应该固本强基，而不是拆梁毁柱。
- **开放共赢**：王毅认为“保护主义不是出路，滥加关税没有赢家”，应当坚持开放合作，以普惠包容的经济全球化来支撑平等有序的世界多极化。
- **中欧关系**：王毅表示“中方始终认为欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手”。

# Q&A环节
**问**：主持人周琦提问，中国是否仍相信联合国和联合国宪章，是否推动联合国改革？
**答**：王毅回应称，中国是现行国际秩序的受益者，要推动秩序朝着更加公正合理的方向发展；应共同维护以联合国为核心的国际体系，共同遵守以联合国宪章宗旨和原则为基础的国际关系基本准则，这是最大的公约数。

**问**：主持人提及俄罗斯入侵乌克兰，询问中国是否可减少购买俄罗斯油气或停止双用物品以施压俄罗斯？
**答**：王毅回应称，中国同俄罗斯建立了结盟不对抗、不针对第三方的睦邻友好关系，从俄罗斯购买油气是正常国与国交往，没有哪个国家能提供如此巨量的油气满足中国民众需求；中国主张一切争端和冲突都应通过对话寻求政治解决，2022年2月25日中方即提出对话协商解决，习近平主席提出4点主张：各国主权领土完整应得到尊重、联合国宪章应得到遵守、各国合理安全关切应得到重视、一切致力于和平的努力都应得到支持；中国派特使去各国斡旋，同巴西等南方国家发起“和平之友”，乐见美国同俄罗斯达成的共识，欧洲有必要在解决危机根源性因素中发挥重要作用。

**问**：主持人请王毅预告中美关系将如何发展？
**答**：王毅表示，中国对美政策保持连续性和稳定性，不会轻易翻烙饼；对美政策就是习近平主席提出的三原则：相互尊重、和平共处、合作共赢；中方愿意按照三原则同美方构建稳定健康可持续的双边关系，希望美方相向而行；如果美方仍对中国打压遏制，中方别无选择，必将奉陪到底，坚决回击美方的单边和霸凌行径。
