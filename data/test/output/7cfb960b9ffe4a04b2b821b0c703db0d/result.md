# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷一案，国家开发银行不服云南省高级人民法院（2018）云民初88号民事判决，向本院提起上诉。本院依法组成合议庭，由审判员李少平担任审判长，与审判员魏文超、黄年、王海峰、葛洪涛组成合议庭，法官助理张瑞，于2019年公开开庭审理。庭审围绕三个争议焦点展开：国开行抵押权是否构成善意取得、罚息复利计算及起算日期、违约金承担。经合议庭组织调解，各方当事人自愿达成调解协议，法院予以确认并出具调解书。

# 原告诉称与被告辩称
各方当事人对调解方案均无异议，同意签署调解协议。确定国开行对东源煤电的债权扣除破产中已清偿本金外，利息、罚息、复利合计6474.4513万元。确定招银租赁对涉案6项设备享有所有权，国开行对93项设备有抵押权。招银租赁和国开行对案涉全部发电设备整体盘活处置，变现价款双方各得50%，实现费用各担50%。本案调解书生效后20日内，由国开行向一审法院提出执行申请，启动司法处置程序。若司法变现不能，国开行和招银租赁权益通过前述方法实现后均放弃对案涉设备权益，由东源曲靖电力自主生产经营。案涉设备上的管理费用由东源曲靖电力承担，东源曲靖电力无条件配合司法处置。一审诉讼费用中对于国开行诉请部分按一审判决执行，对于招银租赁诉请部分由二审法院按规定计算后由国开行承担。二审诉讼费用由法院依法确定后，由国开行和东源煤电各承担50%。本协议签订后，各方之间就本案涉及的问题不再存在任何争议。

# 举证与法庭调查
本案系国家开发银行与东源煤电、东源煤业、曲靖电力、招银租赁金融借款合同纠纷二审，围绕三个争议焦点展开：国开行抵押权是否善意取得、罚息复利计算、违约金承担。经调解，各方达成一致，确认债权数额及设备处置方案。国开行主张已按央行规定查询融资租赁登记系统，未发现曲靖电力公司设备有融资租赁登记，且设备为通用设备无唯一标识码，审查义务仅限于抵押人曲靖电力公司，构成善意取得。东源煤电反驳称2015年12月2日邮件已告知设备情况，且用红色标注，国开行应尽注意义务。招银租赁认为国开行未在抵押时点查询，不构成善意，且东源煤电出资行为系无权处分。合议庭询问融资租赁登记性质、查询方式、举证责任等，各方意见不一。国开行主张利息计算至2018年6月12日，罚息自2018年6月13日起算，复利自2018年3月21日起算，并给出具体金额。东源煤电认为国开行宣布贷款提前到期未给合理期限，且罚息不应计收复利，复利不应再计复利。招银租赁表示非合同当事人，尊重合议庭审查。国开行主张东源煤电、东源煤业违约，应支付违约金，依据合同第24条第3项。东源煤电反驳称国开行未举证证明违约，且未按合同约定先行限期纠正。招银租赁表示非合同当事人，尊重合议庭审查。

# 庭审结果
本案经调解，各方当事人自愿达成调解协议，法院予以确认并出具调解书。调解方案主要内容：确定国开行对东源煤电的债权扣除破产中已清偿本金外，利息、罚息、复利合计6474.4513万元；确定招银租赁对涉案6项设备享有所有权，国开行对93项设备有抵押权；招银租赁和国开行对案涉全部发电设备整体盘活处置，变现价款双方各得50%，实现费用各担50%；本案调解书生效后20日内，由国开行向一审法院提出执行申请，启动司法处置程序；若司法变现不能，国开行和招银租赁权益通过前述方法实现后均放弃对案涉设备权益，由东源曲靖电力自主生产经营；案涉设备上的管理费用由东源曲靖电力承担，东源曲靖电力无条件配合司法处置；一审诉讼费用中对于国开行诉请部分按一审判决执行，对于招银租赁诉请部分由二审法院按规定计算后由国开行承担；二审诉讼费用由法院依法确定后，由国开行和东源煤电各承担50%；本协议签订后，各方之间就本案涉及的问题不再存在任何争议。
