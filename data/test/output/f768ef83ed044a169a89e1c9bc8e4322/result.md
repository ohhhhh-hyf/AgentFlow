# 发布会概况
本次中金宏观策略争论周会由中金公司策略组主办，围绕大美丽法案、关税、港股流动性、光伏反内卷、人形机器人、游戏板块六大主题展开分析。策略组刘刚凯文提出基于信用周期而非宏大叙事的分析框架，认为去美元化担忧过度，美股创新高、纳斯达克从底部反弹35%。大美丽法案提高债务上限5万亿美元、延长减税新增支出3.4万亿、取消899条款，财政赤字率维持5-6%，三季度流动性抽水约1万亿美元，波动提供再配置机会。关税大概率是谈判技巧，市场静观其变，有效税率10-12%，通胀压力可控。港股流动性三季度不如二季度，建议在合适位置布局长期正确板块。光伏反内卷政策强化，硅料整合最迫切；人形机器人三季度关注华为云生态、本土企业技术闭环、特斯拉延期硬件替代三大主线；游戏板块调整后有望戴维斯双击。整体基调偏积极，强调结构性行情下提前埋伏长期正确板块。

# 核心信息
- **大美丽法案**：提高债务上限**5万亿美元**，延长2017年减税法案新增支出**3.4万亿**（每年3400亿），取消`899条款`，财政赤字率维持**5-6%**，关税收入可弥补支出。
- **美股表现**：纳斯达克从底部反弹**35%**，屡创历史新高；信用周期框架下，四季度美元可能小幅走强，美股可能反弹跑赢。
- **三季度流动性**：大美丽法案带来约**1万亿美元**抽水效应，美债利率可能上行但幅度不及2023年（当时从3.8%升至5%），期限溢价处于**2013年以来高点**。
- **关税**：四点信息——一定会做、需维持一定税率、不能太高、市场逐渐脱敏；原7月9日达成时间拖后，大部分税率较4月2日对等关税回落；有效税率测算**10-12%**，极端**18%**；年底通胀**3.3-3.4%**；关注8月12日中美谈判及越南转口限制**40%**。
- **港股流动性**：三季度不如二季度，原因包括美元流动性供给、港币未完全回来（7.84-7.85）、IPO融资多；市场点位在**23000-24000**区间。
- **光伏反内卷**：全球新增光伏装机从2020年**130GW**增至2024年**530GW**（CAGR 42%），2025-26年需求增速回落至**10%**左右；2023年产能从600GW增至1000GW，电池产能是需求**1.5倍**、硅片组件**2倍**、硅料**2.5倍**；2022年以来产业链价格下跌**70-90%**；硅料现金成本**38元/公斤**（颗粒硅28元、尾部45元）；光伏玻璃第二轮产能出清，7月降产**30%**，需出清**2万吨**；多晶硅期货价格反弹至**40元/公斤**，硅片涨**10%**、电池涨**2分**、组件涨**10%**。
- **人形机器人**：二季度A股机器人板块跌**9%**，跑输机械**12个百分点**，特斯拉供应商标签股回调**30-40%**；华为6月底发布`CloudRobot`具身智能平台和`盘古世界模型`；智元机器人拟收购上市，宇树科技年收入突破**10亿**，两家中标中国移动**1.2亿**采购订单；国内至少**100家**以上本体厂商；特斯拉Optimus存在电机过热、灵巧手负载不足、续航问题。
- **游戏板块**：6月版号单月发放**158个**（国产147个、进口11个），**2018年以来单月最高**；今年1-5月游戏市场规模同比增长**17%**，手游增长**20%**；吉比特仗剑传说首月流水**2亿多**，巨人网络超自然行动组6月流水**过亿**（年化乐观**20亿**，利润提升**50%以上**）；TTM PE **30倍**左右，2025年静态PE **20倍**左右。

# 官方表态
- **去美元化观点**：刘刚凯文表示「我们并不是完全的认同去美元化这个观点的」，认为市场存在两个误区——「把美元弱当成去美元化」「把美元弱和美股弱直接划等号」，美元弱在大部分时间对美股有利。
- **信用周期框架**：刘刚凯文提出「我们是实际上基于信用周期来做这个分析的」，美国像烧篝火「只要不给他泼冷水，稍微的它就会慢慢的缓过劲儿」，中国像煮水「你要不断的持续的添柴，只要添柴的这个速度变慢，这个水温是会慢慢的降下来的」。
- **大美丽法案影响**：刘刚凯文认为「中长期的影响反而从信用周期上是有利的」，三季度流动性抽水「能确定是他一定要发这个债」，但「你如果担心现在的估值比较高，我可以等一等，我不用去赌这个事儿」。
- **关税判断**：刘刚凯文表示「他一定要做」「需要维持一定的税率」「也不能太高」「市场逐渐脱敏」，认为威胁高税率「有可能是一个谈判技巧」。
- **港股流动性**：刘刚凯文指出「美元美债利率它并不是绝对主导港股市场的唯一的变量，很多时候你自己的基本面强，完全可以盖过它的影响」，流动性「相比5月份二季度之后一定是变紧的」。
- **光伏反内卷**：刘佳妮表示「我们也比较期待政府的干预，也认为是有一定的这个必要性的」，认为「价格的恶性竞争有望告一段落」「夯实了它的一个底部」。
- **人形机器人**：郭文秀提出三季度三大主线——华为云生态开放、本土企业技术闭环、特斯拉延期带来的硬件替代窗口，认为「三重周期共振的时候，其实是孕育着比较不错的一个投资机会的」。
- **游戏板块**：张雪琴表示「我们的态度旗帜鲜明是后者（回调一下更健康可以上车）」，认为「在消费政策和新品周期三重利好下面，游戏行业有望在调整后再次实现戴维斯双击」。

# Q&A环节
**问**：市场担心去美元化导致股债汇三杀，但美股反而创新高，如何理解？
**答**：刘刚凯文指出纳斯达克从底部反弹35%，市场存在两个误区——把美元弱当成去美元化、把美元弱和美股弱直接划等号。美元弱在大部分时间对美股有利，因为海外收入占比高，可形成金融条件宽松。应基于信用周期而非宏大叙事分析，下半年美国形成低基数可能环比改善，中国从924之后建立高基数，边际上可能此消彼长。

**问**：大美丽法案对财政赤字和债务的影响如何？
**答**：刘刚凯文解释大美丽法案三大块——提高债务上限5万亿美元、延长减税（新增支出3.4万亿，年3400亿）、取消899条款。关税收入每年3000-4000亿可弥补支出，财政赤字率基本维持在5-6%，不会大幅增加。短期看，三季度有约1万亿美元抽水效应，但需求端强可对冲，美债利率上行幅度可能不及2023年。

**问**：关税是否还会升级？对通胀影响多大？
**答**：刘刚凯文总结四点信息——一定会做、需维持一定税率（现在豁免10%的水平）、不能太高、市场逐渐脱敏。新变化是时间拖后（原7月9日）、大部分税率较4月2日回落、加拿大墨西哥欧盟因贸易占比高需谈妥。有效税率测算10-12%，极端18%，年底通胀3.3-3.4%，不大幅改变通胀路径。

**问**：港股流动性是否会收紧？对市场影响如何？
**答**：刘刚凯文指出港股流动性三季度不如二季度，原因包括美元流动性供给、港币未完全回来（7.84-7.85）、IPO融资多。但美元美债利率不是绝对主导变量，基本面强可盖过影响。市场点位在23000-24000区间，建议低迷时积极介入、亢奋时适度锁定利润。

**问**：光伏反内卷政策对行业影响如何？哪些环节最受益？
**答**：刘佳妮介绍反内卷政策级别提升——6月29日人民日报发声、7月1日中财委会议、7月3日工信部座谈会。硅料环节最易整合（供需比超200%、现金成本38元/公斤、颗粒硅28元、尾部45元），光伏玻璃第二轮产能出清（降产30%、需出清2万吨）。多晶硅期货价格反弹至40元/公斤，硅片涨10%、电池涨2分、组件涨10%，组件能否跟涨待观望招标情况。

**问**：人形机器人三季度有哪些催化剂？
**答**：郭文秀提出三大主线——华为云生态开放（盘古世界模型、CloudRobot平台）、本土企业技术闭环（智元机器人拟收购上市、宇树科技年收入破10亿、两家中标中国移动1.2亿采购订单）、特斯拉延期带来的硬件替代窗口（电机过热、灵巧手负载不足、续航问题）。建议关注三类信号：华为云生态接入厂商新增、头部企业出货量跨越年化500台或1000台、电机硬件优化。

**问**：游戏板块调整是否结束？估值是否合理？
**答**：张雪琴认为调整是回调一下更健康可以上车。TTM PE 30倍左右，2025年静态PE 20倍左右，低于2023年AI行情下的45倍。政策端友好（6月版号发放158个创新高），今年1-5月游戏市场规模同比增长17%，手游增长20%。中型厂商新品成为核心催化，但新品利润有滞后性，明年兑现，建议关注新品市场表现和下载榜排名。
