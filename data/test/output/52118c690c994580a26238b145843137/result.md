# 发言要点
发言人1作为主要发起者，回忆初中走读时每周一下午4点放学后聚集游戏厅、网吧，流行穿越火线CF、反恐精英online、使命召唤、战地、魔兽等，高中因高考压力不敢逃课，主要追星并搞乐队，玩架子鼓、电吉他、贝斯，追求朋克金属音乐；其称穿越火线抄袭，自己曾在贴吧和QQ空间写文章骂穿越火线被封禁，后成为CS铁杆粉，喜欢僵尸模式，并介绍求生之路第二部有东洋刀、电锯、砍刀砍丧尸，很暴力，后来有年龄限制，未成年人不能注册Steam账号，需18岁以上，还称求生之路精准预测美国政府在灾难中的表现，2020年新冠疫情后游戏重新火起来。发言人2称18岁前没逃过课，上大学后逃过一次；称看郭敬明小说挺难受、挺扭曲，并提到《梦里花落知多少》，还提到《意林》《读者》《故事会》并称意林讲得特别好；提到穿越火线、地下城与勇士、魔兽争霸，称欧美玩家爱玩打僵尸游戏，称植物大战僵尸有特别变态的版本，后期满屏子弹，电脑都卡，称使命召唤这游戏太男性了。发言人3认为逃课是正常现象，称小时候经常玩塔防游戏，现在还在玩植物大战僵尸和Kindle rush。发言人4称上大学就不算逃课，称班里特别流行看柯南，提到摩尔庄园、赛尔号，提到仙剑三最火且有电视剧。发言人5提到特别喜欢郭敬明的小说，提到当时还有一些杂志，提到萌化三国，提到仙剑四、仙辕剑、古剑四，质疑当时游戏没有年龄限制、内容暴力，小孩能否玩。发言人6提到生活杂志、柯南、老夫子、仙剑、Steam图标、僵尸题材，称艺术源于生活。观点交锋点包括：逃课是否正常及上大学后是否算逃课；郭敬明小说是否令人难受扭曲；穿越火线是否抄袭及游戏暴力与年龄限制；求生之路与生化危机、惊变48小时的影视游戏先后关系；变形金刚先有玩具还是电影；英雄联盟与DOTA的鄙视链及王者荣耀处于鄙视链最低端。

# 共识形成
小组未形成正式决议或统一意见，讨论以自由分享与回忆为主。形成的共同认知包括：**逃课在初中高中阶段被视为正常现象，但上大学后逃课一般不算**；**郭敬明小说、柯南、老夫子、意林读者故事会等是当时流行的阅读内容**；**穿越火线、CS、求生之路、仙剑、魔兽、摩尔庄园、赛尔号、植物大战僵尸等是当时流行的游戏**；**求生之路第二部因暴力内容后来设有年龄限制，未成年人不能注册Steam账号，需18岁以上**；**生化危机先有游戏后有电影，求生之路是在惊变48小时、生化危机基础上先有电影后有游戏**；**变形金刚先有玩具，后有MV和电影**；**英雄联盟与DOTA存在鄙视链，王者荣耀处于鄙视链最低端**。
