# 发布会概况
王毅在慕尼黑安全会议上发表演讲，阐述中国对多极世界的立场。王毅引用今年慕安会报告主题“走向多极化”，指出联合国会员国从51个增至193个，提出推动平等有序的世界多极化，并表达四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。中国承担超过20%联合国会费，建成世界最大清洁发电体系，提出全球发展倡议、全球安全倡议、全球文明倡议；去年GDP增长5%，对世界经济增长贡献率接近30%。王毅还回应了关于国际秩序、乌克兰危机、中美关系等提问，强调中国是现行国际秩序的受益者，将推动秩序朝更加公正合理方向发展。整体基调坚定、务实，展现中国作为多极体系中确定性因素和建设性力量的定位。

# 核心信息
- 王毅引用今年慕安会报告主题“走向多极化”，指出联合国成立时只有51个会员国，到今天有193个国家。
- 提出推动**平等有序的世界多极化**，这是习近平主席提出的重大主张。
- 表达四点看法：**倡导平等相待**、**尊重国际法治**、**践行多边主义**、**坚持开放共赢**。
- 中国承担**超过20%的联合国会费**，切实履行`巴黎协定`，建成**世界上最大的清洁发电体系**。
- 提出并落实`全球发展倡议`、`全球安全倡议`、`全球文明倡议`，为完善全球治理提供公共产品。
- 去年中国GDP增长**5%**，对世界经济增长贡献率接近**30%**。
- 中国加入**几乎所有普遍性的政府间国际组织**和**600多项国际公约**。
- 中国愿推动高质量共建`一带一路`，与欧盟`全球门户`战略相互对接。
- 今年是**中欧建交50周年**。

# 官方表态
- **多极化立场**：中国应当推动平等有序的世界多极化，这是习近平主席提出的重大主张，也是我们对多极世界真诚的期许。中国必将是多极体系中的确定性因素，将坚定做变革世界中的建设性力量。
- **平等相待**：坚持权利平等、机会平等、规则平等，应当成为建设多极世界的基本原则。中国主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权。
- **国际法治**：联合国宪章宗旨和原则是国际关系的根本遵循，也是建设多极世界的重要基石。多极格局不能是无序的状态。大国要带头讲诚信、讲法治，坚决摒弃言行不一、零和博弈。中国从不搞例外主义，更不搞合则用、不合则弃。
- **多边主义**：联合国是践行多边主义、推进全球治理的核心平台。对于这座大厦，我们应该固本强基，而不是拆梁毁柱。中国坚持真正的多边主义，倡导共商共建共享的全球治理观。
- **开放共赢**：发展是破解各种难题的钥匙，多极世界应该是各国共同发展的世界。保护主义不是出路，滥加关税没有赢家。脱钩断链断的是机遇，小院高墙封的是自己。
- **欧洲定位**：中方始终认为欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手。
- **人类命运共同体**：习近平主席提出共同构建人类命运共同体的重大理念，希望各国超越历史文化、社会制度、意识形态的不同，以同舟共济的精神共同呵护好人类可以居住的星球。

# Q&A环节
**问**：您提到国际秩序，现在有很多对联合国宪章的质疑，包括俄罗斯入侵乌克兰、美国总统威胁使用武力入侵格陵兰和巴拿马、巴勒斯坦人流离失所，贵国也被指控违反海洋法和世界人权宣言。您即将前往纽约参加安理会，您是否仍然相信联合国和联合国宪章？联合国改革在您的优先事项中排多高？
**答**：说到秩序，这几年总有人说中国要改变秩序、另起炉灶，但现在真正挑战秩序、毁约退群的国家出现了。中国是在现行国际秩序中发展起来的，是受益者，我们要按照大多数国家的愿望推动秩序朝更加公正合理的方向发展。谈到规则，我们起码应该有一个共同认知，就是共同维护以联合国为核心的国际体系，共同遵守以联合国宪章宗旨和原则为基础的国际关系基本准则，这是最大的公约数。只要大家都认同这一点，双重标准就不会出现。

**问**：自2022年以来，慕安会一直讨论俄罗斯入侵乌克兰。您在入侵前几天曾说“任何国家的主权、独立和领土完整都应得到尊重和维护，乌克兰也不例外”。现在俄罗斯已成为中国加油站（有军队的加油站），您对乌克兰有很大影响力。在压力加大、战争可能结束的情况下，您能否从您这边切断俄罗斯向中国供应天然气的可能性、降低价格或停止一些军民两用物资，以加大对俄罗斯的压力？
**答**：中国同俄罗斯是两大邻国，有着漫长的边界，建立了不结盟、不对抗、不针对第三方的睦邻友好关系，进而建立了全面战略伙伴关系。如果中国不从俄罗斯买油气，哪个国家能提供如此巨量的油气来满足中国民众的需求？那是不可能的，也是不保险的，因为常有国家把经贸问题政治化，当做打压中国的工具。但中国在地区热点问题上有自己的立场，历来主张一切争端和冲突都应通过对话寻求政治解决。从2022年2月25日危机爆发第二天起，中方就提出对话协商解决。习近平主席提出四点主张：各国主权领土完整应得到尊重、联合国宪章应得到遵守、各国合理安全关切应得到重视、一切致力于和平的努力应得到支持。中国派特使去各国斡旋，同巴西等南方国家发起和平之友。任何冲突的终点都是谈判桌，中方乐见一切致力于和平的努力，包括美俄达成的共识。所有当事方和利益攸关方都应适时参与和谈进程，欧洲更有必要发挥重要作用，共同探讨欧洲的长治久安。

**问**：时间快到了，能否简单预告一下您认为美中关系将如何发展？
**答**：中国的对美政策保持连续性和稳定性，不会轻易翻烙饼，这体现大国的战略定力和国际信誉。对美政策就是习近平主席提出的三原则：相互尊重、和平共处、合作共赢。中美制度不一样，是各自人民做出的选择，想改造或颠覆对方不切实际。正确态度是相互尊重，这是中美交往的前提；和平共处理所当然，中美两个大国总不能冲突起来，那将殃及整个世界；合作共赢是国际社会的期待，全球性挑战需要中美携手应对。中方已准备好，愿意按三原则同美方构建稳定健康可持续的双边关系。希望美方相向而行，但如果美方仍要打压遏制，中方别无选择，必将奉陪到底，坚决维护中国的主权、国家尊严和正当发展权利，坚决回击美方的单边霸凌行径。
