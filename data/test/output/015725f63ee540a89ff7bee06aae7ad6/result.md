# 就诊概况
患者于23年9月因腹痛一晚上确诊结肠癌，行结肠癌切除手术及8期化疗，复查发现肝转移，从老家到北京做PET-CT。去年9月行肝消融及乳腺结节切除，当时已有腹膜转移，切肠时可能切得不干净；术后行紫杉化疗，仅第一次有效，后续因肝功能不行停用靶向，至3月底复查发现肝、肺、腹膜又有转移。本次就诊为家属代述病史并咨询后续治疗，医生建议以全身系统治疗（化疗、靶向、免疫）为主，介入不是当前主要问题，并建议做第二次结肠确认基因检测，把之前切片拿过去再做一遍。

# 诊断与检查结果
医生指出患者为结肠癌术后多发转移，累及肝、肺、腹膜及肠壁。PET-CT显示肝、肺、腹膜有转移；肠镜显示没事但PET显示有问题，今天说可能是肠镜做得不好。4月份做的检查。医生强调现在化疗是否有效并不清楚，基因检测推荐或不推荐都需参考；免疫细胞状态很重要，数量不足需创造。

# 治疗方案与医嘱
治疗计划以全身系统治疗为主，包括化疗、靶向、免疫，需选靶向、选免疫；靶向和免疫治疗与原来化疗机制不同、可能协同。建议做第二次结肠确认基因检测，把之前切片拿过去再做一遍，第一次、第二次、第三次切片可对比，从对讲中找可用信息。生活注意事项：让患者把状态调整好，提升免疫力靠自己，大夫和手术有限；要做免疫评估，但方案由家属定。**若涨幅到10公分则要命，需先系统治疗**。
