# 发布会概况
本次中金宏观策略周会由策略组刘刚凯文主持，围绕大美丽法案、关税、港股流动性、光伏反内卷、人形机器人及游戏板块等热点展开，向投资者汇报宏观策略与行业最新观点。刘刚凯文分析大美丽法案三大块内容，认为信用周期改善，对美股美债不悲观，三季度有流动性波折但波动提供再配置机会；关税大概率是谈判技巧，市场静观其变；港股流动性三季度边际收紧，但基本面强可盖过影响。行业方面，刘佳妮、郭文秀、张雪琴分别就光伏反内卷、人形机器人、游戏板块给出投资观点，整体基调偏积极，强调在结构性行情中于合适位置布局长期正确板块。

# 核心信息
大美丽法案三大块：提高债务上限5万亿美元；延长2017年减税法案，新增支出3.4万亿美元，每年额外支出3400亿美元，同时减少新能源补贴等支出1.4万亿美元；取消899条款。刘刚凯文测算财政赤字率维持5-6%，关税收入可弥补支出，三季度美债供给压力约1万亿美元，可能推升利率但幅度或不及2023年。关税方面，有效税率10-12%，极端情况18%，通胀年底3.3-3.4%，关注8月1日、8月12日中美谈判及转口限制。港股流动性方面，港币弱至7.85，三季度流动性边际收紧。光伏行业产能过剩严重，硅料供需比超200%，硅片组件约2倍，电池1.5倍，价格下跌70-90%；反内卷政策升级，6月底至7月初高层多次发声，多晶硅期货价格反弹至40元/公斤。人形机器人二季度板块回调9%，跑输机械12个百分点。游戏板块6月版号单月发放158个（国产147个、进口11个），创2018年以来单月最高，1-5月市场规模同比增长17%，手游增长20%。

# 官方表态
刘刚凯文对大美丽法案表态：提高债务上限至少使违约风险消失，可提振部分增长；延长减税并非新增减税，而是避免今年底大幅加税；取消899条款避免影响美元体系根基。对关税表态：关税一定会做，需维持一定税率（约10-12%有效税率）以收上3000-4000亿美元收入，不能太高以免通胀受不了，市场逐渐脱敏，威胁提高税率可能是谈判技巧。对港股流动性表态：美元美债利率并非绝对主导港股市场的唯一变量，自身基本面强可盖过影响，但三季度流动性边际收紧。刘佳妮对光伏反内卷表态：反内卷力度和政策级别进一步提升，价格恶性竞争有望告一段落，行业底部夯实。郭文秀对人形机器人表态：三季度是迷茫期到商业兑现的过渡阶段，关注三类信号。张雪琴对游戏板块表态：在消费、政策和新品周期三重利好下，游戏行业有望在调整后再次实现戴维斯双击。

# Q&A环节
问：大美丽法案对美股、美债、美元流动性及港股流动性有何影响？答：刘刚凯文分析法案三大块，认为信用周期改善，财政赤字率维持5-6%，三季度美债供给压力约1万亿美元，可能推升利率但幅度或不及2023年，美股美债波动提供再配置机会，四季度美元可能小幅走强，对港股流动性边际偏负面但基本面强可盖过。问：关税升级为何市场反应冷静？答：刘刚凯文总结四点：关税一定会做、需维持一定税率、不能太高、市场逐渐脱敏；新变化为时间拖后、大部分税率较4月2日回落，有效税率10-12%，极端18%，通胀压力可控，市场静观其变。问：光伏反内卷政策对行业有何影响？答：刘佳妮介绍反内卷政策升级，高层多次发声，硅料环节最易整合，光伏玻璃第二轮产能出清，多晶硅期货价格反弹至40元/公斤，现货上涨，组件价格跟涨意愿但下游接受度待观察。问：人形机器人三季度有哪些催化剂？答：郭文秀提出三条主线：华为云生态开放、本土企业技术闭环、特斯拉延期带来的硬件替代窗口，关注物流场景、电机过热、轻量化等方向。问：游戏板块调整后是否还有机会？答：张雪琴认为政策友好、版号发放创新高，中型厂商新品成为核心催化，估值TTM PE约30倍，2025年静态PE约20倍，新品利润有滞后性，明年兑现，调整后有望戴维斯双击。
