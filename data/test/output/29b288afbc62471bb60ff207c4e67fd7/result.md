# 就诊概况
48岁男性患者张学恒，因上腹心窝处反复烧灼样疼痛4年、近3个月加重，就诊于消化专科。疼痛与进食冷硬食物、工作紧张劳累相关，刺激性食物可诱发，近3个月存在完全不痛时段；曾于一年前和三个月前两次出现黑便，均住院确诊为大便出血，住院两三天后大便转黄；近两个月呕吐数次，吐出黄水样酸味物，无呕血。既往有甲肝史（16岁，已愈）、磺胺药过敏史，家族中婶婶（无血缘关系）患胃癌。医生初步考虑消化道出血及胃部病变可能，建议留大便检查并预约后天胃镜，待向上级张医生汇报后商定治疗方案。

# 诊断与检查结果
本次就诊未进行胃镜及大便检查，医生根据病史初步判断需排查消化道出血及恶性病变可能。患者曾于一年前和三个月前两次黑便，住院检查均确诊为大便出血，住院两三天后大便转黄；近三个月无黑便，大便黄色正常。既往16岁患甲肝，在三医院住院一个月，出院时肝功能正常，此后体检肝功均正常；对磺胺药过敏（左手起红疹，持续半个月）。医生建议留大便样本检查出血，并预约后天行胃镜及活检。

# 治疗方案与医嘱
患者近期自行服药情况：最初服用某药（可能为“达喜”类）有效，后效果变差并加量至每日4-5次仍不佳；后加用国产奥美拉唑（武汉药厂）和阿莫西林，以及单位医务室自配胃炎合剂，效果短暂，停药后复发。医生建议戒烟、少饮酒，注意休息，避免劳累熬夜。**重点禁忌：磺胺药过敏，禁用磺胺类药物**。
