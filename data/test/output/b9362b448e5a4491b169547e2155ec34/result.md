# 复盘目标与结果概况
本次复盘会为公司年终总结会，预期目标为公布年度经营数据、发放年终奖与奖项、进行部门评价与展望。实际结果：年终奖总额226,000元，个人数额不一一公布；全年实打实支出390万元，利润率约24%或27%，成本控制较差；最高到手工资约20万元（两三人），平均到手工资1万多元；2023年公司总量提升、员工到手收入提升，但成本上升、结余缩水，尚有百来万未收回。老板自评对员工关心关注不够、管理不够雷厉风行，成本控制问题明年开会再议。会议逐一点评员工并颁发奖项，各部门总结展望，最后抽奖结束。

# 亮点事项
超出预期的成果包括：短视频账号粉丝大幅增长，视频号从719人增至8万，小红书从2000+增至6.4万，抖音从2000+增至5.7万，B站从3.1万增至7.6万，且账号变现课程评分约7.5分（满分10分），直播平均在线5000人以上；商务部门实打实项目约300万元；员工整体表现高于预期，如刘腾宇、张扬、宋俊逸等获高度评价。促成成功的关键动作：郭东辉在6月20日说服潘老师到外面拍摄，成为涨粉转折点，其坚持与破釜沉舟的决心是关键；老板认真准备评价与奖项，注重仪式感；员工主动解决问题、跨部门协作顺畅。最具复用价值的经验：**坚持与破釜沉舟的决心**，以及**以数据支撑决策、主动学习对标**（如郭东辉每晚刷直播间学习）。

# 不足事项
未达预期的环节：成本控制非常差，利润率低，全年支出390万元，结余缩水，有百来万未收回；加班多，人员不足，老板判断失误；外援成本高，内部人员参与拍摄不足；账号变现与直播重点项目尚未完成。现象 → 根因：成本控制差 → 老板对员工关心关注不够、管理不够雷厉风行，出现问题未及时解决；加班多 → 人员不足，老板未及时招合适人数；外援成本高 → 内部人员技术水平或参与度不足。关键根因：**老板管理不够雷厉风行、对员工关心不够**，以及**人员配置不足**。

# 改进计划
后续改进计划：明年开会讨论成本控制问题；明年再议年终奖额度；短视频部门期待账号开始变现，老板将投入更大精力；执行部门期待老板更多组织协调、减少侵占休息时间；商务部门老板将给予更多支持和帮助；鼓励员工参与拍摄，提升自身市场价值；老板反思对员工支持、管理、关心不够，明年改进。责任人：老板（成本控制、组织协调、支持商务）、郭东辉（短视频变现）、林海腾（后期安排）。时间：明年。
