# 发布会概况
王毅在慕尼黑安全会议上发表演讲并接受主持人周琦提问。会议围绕“走向多极化”主题展开，王毅提出推动平等有序的世界多极化，并阐述四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。王毅指出，80年前联合国成立时只有51个会员国，如今已有193个国家，多极化是历史必然；中国主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权。

在回应主持人周琦关于国际秩序与规则的提问时，王毅表示中国是现行国际秩序的受益者，主张推动秩序朝着更加公正合理的方向发展，并强调应共同维护以联合国为核心的国际体系，遵守以联合国宪章宗旨和原则为基础的国际关系基本准则。王毅指出，在遵守国际法上不能搞双重标准，要尊重各国主权和领土完整，就应该支持中国实现完全统一。

关于乌克兰危机，王毅表示中国同俄罗斯建立了结盟不对抗、不针对第三方的睦邻友好关系，并反问如果中国不从俄罗斯买油气，哪个国家能提供如此巨量的油气满足中国民众需求。王毅介绍，自2022年2月25日起中方就提出对话协商解决乌克兰危机，习近平主席提出4点主张，中国派特使斡旋，同巴西等南方国家发起和平之友；中方乐见一切致力于和平的努力，包括美国同俄罗斯达成的共识，并认为所有当事方包括利益攸关方都应适时参与和谈进程。

关于中美关系，王毅表示中国的对美政策保持连续性和稳定性，不会轻易翻烙饼，并阐述对美政策三原则：相互尊重、和平共处、合作共赢。王毅指出，如果美方不愿意相向而行，仍对中国打压遏制，中国必将奉陪到底；中方愿意按照三原则同美方构建稳定健康可持续的双边关系，并引用“天行健，君子以自强不息”“他强任他强，清风拂山岗”等古话表达立场。

# 核心信息
- **多极化现实**：80年前联合国成立时仅51个会员国，至今已达193个国家；多极化既是历史必然，也正在成为现实（依据：慕安会报告主题「走向多极化」）。
- **中国多极化主张**：提出推动**平等有序的世界多极化**，系习近平主席提出的重大主张；中国将作为多极体系中的确定性因素，坚定做变革世界中的建设性力量。
- **四点看法之一·平等相待**：坚持权利平等、机会平等、规则平等，作为建设多极世界的基本原则；主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权。
- **四点看法之二·尊重国际法治**：联合国宪章宗旨和原则是国际关系的根本遵循、建设多极世界的重要基石；中国加入几乎所有普遍性政府间国际组织及**600多项国际公约**，从不搞例外主义、不搞合则用不合则弃。
- **四点看法之三·践行多边主义**：坚持真正的多边主义，倡导共商共建共享的全球治理观；坚定维护联合国权威和地位，承担**超过20%的联合国会费**；切实履行《巴黎协定》，建成世界上最大的清洁发电体系。
- **四点看法之四·坚持开放共赢**：坚持开放合作，以普惠包容的经济全球化支撑平等有序的世界多极化；反对保护主义、滥加关税、脱钩断链、小院高墙。
- **中国发展数据**：去年中国GDP增长**5%**，对世界经济增长贡献率接近**30%**，担当全球经济增长重要引擎，向世界释放超大规模市场红利。
- **一带一路对接**：中国愿推动高质量共建「一带一路」，同欧盟「全球门户」战略相互对接。
- **中欧关系节点**：今年是中欧建交**50周年**，中方愿同欧方深化战略沟通和互利合作。
- **国际秩序立场**：中国是现行国际秩序的受益者，将按大多数国家愿望推动秩序朝更加公正合理方向发展；应共同维护以联合国为核心的国际体系，遵守以联合国宪章宗旨和原则为基础的国际关系基本准则。
- **国际法治原则**：在遵守国际法上不能搞双重标准；尊重各国主权和领土完整，就应该支持中国实现完全统一。
- **中俄关系定位**：中国同俄罗斯建立结盟不对抗、不针对第三方的睦邻友好关系，进而建立全面战略伙伴关系；两国交往属正常国与国交往。
- **中俄油气贸易**：中国从俄罗斯购买油气系满足民众需求；若中国不从俄罗斯购买，没有其他国家能提供如此巨量油气，且需防范经贸问题政治化、被用作打压中国的工具。
- **乌克兰危机时间线**：自危机爆发第2天（**2022年2月25日**）起，中方即提出对话协商解决。
- **乌克兰问题四点主张**：习近平主席提出4点主张——各国主权领土完整应得到尊重、联合国宪章应得到遵守、各国合理安全关切应得到重视、一切致力于和平的努力应得到支持。
- **劝和促谈行动**：中国派特使赴各国斡旋，同巴西等南方国家发起「和平之友」；中方乐见一切致力于和平的努力，包括美国同俄罗斯达成的共识。
- **和谈参与范围**：所有当事方包括利益攸关方应适时参与和谈进程；战事发生在欧洲大地，欧洲有必要发挥重要作用，共同探讨均衡、有效、可持续的欧洲安全框架。
- **对美政策三原则**：对美政策保持连续性和稳定性，不会轻易翻烙饼；遵循习近平主席提出的相互尊重、和平共处、合作共赢三原则。
- **中美关系应对**：中方愿按三原则同美方构建稳定健康可持续的双边关系；若美方仍对中国打压遏制，中国必将奉陪到底，坚决回击美方单边霸凌行径。

# Q&A环节
**1. 周琦**：您提到国际秩序，但当前我们看到俄罗斯入侵乌克兰、美国总统威胁使用武力入侵格陵兰和巴拿马、巴勒斯坦人流离失所，中国也被指责违反海洋法和《世界人权宣言》。您即将前往纽约参加安理会会议，您是否仍然相信联合国和《联合国宪章》？是否将推动联合国改革？

**王毅**：我不愿意回答周琦先生的提问，你的提问涉及秩序和规则两个关键词。真正要挑战秩序、毁约退群的国家已经出现，而中国是在现行国际秩序中发展起来的，是受益者，要推动秩序朝着更加公正合理的方向发展。我们应共同维护以联合国为核心的国际体系，遵守以联合国宪章宗旨和原则为基础的国际关系基本准则，这是最大的公约数。只要认同这一点，双重标准就没有存在空间。习近平主席提出全球发展倡议、全球安全倡议、全球文明倡议和构建人类命运共同体理念，希望各国超越历史文化社会制度意识形态的不同，共同建设好命运与共的地球村。

**2. 周琦**：2022年慕安会前几天您曾表示任何国家的主权、独立和领土完整都应得到尊重，乌克兰也不例外。如今俄罗斯已成为中国的一个"加油站"，中国对乌克兰有很大影响力。您是否可能减少从俄罗斯购买天然气、降低价格或停止输送军民两用物资，以施压俄罗斯结束战争？

**王毅**：中国同俄罗斯是两大邻国，建立了结盟不对抗、不针对第三方的睦邻友好关系。如果中国不从俄罗斯买油气，哪个国家能提供如此巨量的油气满足中国民众需求？那是不可能的，也是不保险的，因为常有国家把经贸问题政治化，当做打压中国的工具。中国在乌克兰问题上的立场是主张一切争端和冲突通过对话寻求政治解决。从2022年2月25日起，中方就提出对话协商解决。习近平主席提出4点主张：各国主权领土完整应该得到尊重，联合国宪章应该得到遵守，各国合理安全关切应该得到重视，一切致力于和平的努力都应该得到支持。我们派特使去各国斡旋，同巴西等南方国家发起和平之友。中方乐见一切致力于和平的努力，包括美国同俄罗斯达成的共识。所有当事方包括利益攸关方都应适时参与和谈进程，欧洲更有必要为此发挥重要作用。

**3. 周琦**：时间有限，请您简要展望中美关系将如何发展。

**王毅**：中国的对美政策保持连续性和稳定性，不会轻易翻烙饼。对美政策就是习近平主席提出的三原则：相互尊重、和平共处、合作共赢。中美制度不同是各自人民做出的选择，想改造或颠覆对方不切实际。中方愿意按照三原则同美方构建稳定健康可持续的双边关系。如果美方不愿意相向而行，仍对中国打压遏制，我们别无选择，必将奉陪到底，坚决维护中国的主权、国家尊严和正当发展权利，坚决回击美方的单边和霸凌行径。中国有句古话：天行健，君子以自强不息；他强任他强，清风拂山岗。我们对中美关系的未来充满信心，中美共同努力的方向就是相互尊重、和平共处、合作共赢。
