# 讲座概况
本次研讨会围绕1979年至1989年苏联入侵阿富汗战争（苏阿战争）展开讲解与问答。主讲人（发言人1）指出，阿富汗位于亚洲中部，东接中国，北邻塔吉克斯坦，南接巴基斯坦，西邻伊朗，被称为亚洲的中间走廊地带和兵家必争之地，国土纵深90%为高原山地，易守难攻，被称为帝国坟场。20世纪50年代阿富汗同时与苏联和西方国家保持友好交往，实行君主立宪制，精英与知识界奉行亲英与亲苏两头政策，文化上向英国靠拢，国家建设和工业向苏联看齐，基辛格评价阿明用苏联的火柴点美国的香烟。讲解梳理了苏联出兵过程：因阿明对苏联干涉内政不满并过度导向美国，苏联高层政治局决定在阿富汗彻底导向美国之前以兵变和武力介入；1979年12月24日平安夜，苏联趁阿富汗高层及军队被先前释放的麻痹信号所迷惑，以阿富汗请求救援为说法，从东部、中部、西部（塔吉克斯坦及土库曼斯坦方向）分路推进，一晚控制喀布尔政府高层，处决阿明一家，扶植代理人卡尔迈勒上台，将阿富汗纳入自己阵营。问答环节讨论了阿富汗难以征服的原因与各方援助，最终苏联于1989年撤军。

# 核心观点与论证
**论点一：阿富汗的地理战略位置决定其兵家必争。** 论据：阿富汗位于亚洲中部，东接中国，北邻塔吉克斯坦，南接巴基斯坦，西邻伊朗，被称为亚洲的中间走廊地带；国土纵深90%为高原山地，易难攻，被称为帝国坟场。发言人1据此判断：**谁控制了阿富汗，谁就控制住了亚洲的咽喉**。

**论点二：阿富汗战前奉行两头外交与混合制度。** 论据：20世纪50年代阿富汗同时与苏联和西方国家保持友好交往，实行君主立宪制，精英与知识界奉行亲英与亲苏两头政策；文化上向英国靠拢（议会制度、君主立宪制度、大学现代科学），国家建设和工业向苏联看齐。基辛格评价阿明用苏联的火柴点美国的香烟。

**论点三：苏联出兵源于对阿富汗倒向美国的战略担忧。** 论据：阿明对苏联日益干涉其国家内政不满，并过度导向美国，使苏联领导阶层大为火光；苏联高层政治局决定在阿富汗彻底导向美国之前，以兵变和武力介入。1979年12月24日平安夜，苏联趁阿富汗高层及军队被先前释放的麻痹信号所迷惑，以阿富汗请求救援为说法，从东部、中部、西部（塔吉克斯坦及土库曼斯坦方向）分路推进，一晚控制喀布尔政府高层，处决阿明一家，扶植代理人卡尔迈勒上台，将阿富汗纳入苏联阵营。

**论点四：冷战思维与苏联错判共同导致战略失误。** 发言人3以冷战思维分析：阿富汗被苏联视为苏联大家庭一员，根据勃列日涅夫逻辑不允许任何成员外出，如同之前出兵捷克；阿富汗是特殊战略要地，加上苏联错判，导致大的战略性失误。发言人1补充：同时期冷战处于苏攻美守，苏联咄咄逼人进行意识形态扩张和军事霸权恐吓。

**论点五：圣战者概念与宗教动员。** 发言人1解释：圣战者指狂烈激进的伊斯兰圣战思想，从上到下宗教式洗脑，使阿富汗圣战者具备像二战日本军国主义荼毒下日本军民那样不顾一切、抱着同归于尽思想进行圣战。

**论点六：阿富汗难以征服源于地形与部落制度。** 论据：阿富汗90%为高原山地，是天然游击战地区；除喀布尔和坎大哈等主要城市外，大部分乡村实行部落长老制，各自为政，政府无控制力，导致列强及城市政府无法对广大高原山地形成有力控制。

**论点七：各方援助与游击战消耗拖垮苏联。** 论据：众多阿拉伯国家、中国、西方盟国共同不满并援助阿富汗；阿富汗和穆斯林国家出动兵源，中国和西方盟国出动武器与情报资源支持抵抗组织，进行长达十年游击战争。中国教阿富汗圣战抵抗者兵法如地道战、地雷战，提供五六式冲锋枪和五六式半自动步枪（与AK47同型号），稀释已饱和的军工业；美国援助毒刺防空火箭筒，有效压制苏联雌鹿武装直升机。苏联重装部队在高原山地无法形成有效战斗力，基层官兵厌战，士气一落千丈，最终于1989年撤军。

# 金句总结
「谁控制了阿富汗，谁就控制住了亚洲的咽喉。」——发言人1在回答阿富汗为何被反复争夺时提出，点明其亚洲中间走廊地带的战略价值。

「他是用的苏联的火柴在点的美国的香烟。」——发言人1引述基辛格对阿富汗总统阿明的评价，说明阿富汗同时向苏联与美国两边要好处、充当墙头草的处境。

「根据这个勃列日涅夫的这个逻辑来说，是不允许任何一个成员外出的。」——发言人3以冷战思维解释苏联出兵逻辑，将阿富汗视为苏联大家庭一员，类比此前出兵捷克。

「阿富汗圣战者具备像二战时期日本军国主义荼毒之下的日本军民的那样一样，不顾一切的就是抱着一种同归于尽的思想进行一种圣战的方式。」——发言人1解释圣战者含义时，以二战日本军民作类比，说明其宗教式洗脑与同归于尽的思想状态。

「苏联的军事实力看似庞大，但实际上它的武器发挥不了任何的作用。」——发言人1总结苏联在阿富汗高原山地作战中重装部队失效、基层官兵厌战、士气一落千丈的困境。

# Q&A 环节
问（发言人2）：阿富汗到底有啥好呀？为啥都想打它？
答（发言人1）：地理位置的原因，因为谁控制了阿富汗，谁就控制住了亚洲的咽喉。

问（发言人2）：是不是阿富汗有石油啊？
答（发言人1）：它这个国家相对来说是个贫油国，但它周边的国家都是富油国，比如说是西边的伊朗，北边的土库曼斯坦和塔吉克斯坦。

问（发言人3）：之前看那个阿富汗那边把那个部队叫什么圣战者，这个是什么意思？
答（发言人1）：就是狂烈的激进的伊斯兰圣战思想，以及从上到下那种宗教式那种洗脑，然后导致了其阿富汗圣战者具备像二战时期日本军国主义荼毒之下的日本军民的那样一样，不顾一切的就是抱着一种同归于尽的思想进行一种圣战的方式。

问（发言人3）：这次苏阿战争之前，已经有三次这个英阿战争，这个阿富汗这个被称为叫做帝国坟场，这个可以简单说一下为什么这个阿富汗这个位置这么难打？虽然它的国土面积没有那么大，然后经济实力又没有那么好。
答（发言人1）：因为这个国家百分之九十都是处于高原山地地带，就是一个天然的游击战地区。它除了以喀布尔和坎大哈那几个主要城市为首的城市地区以外，剩下大部分百分之九十的地区都是乡村部落长老制的那种制度。你到乡村就是政府没有任何的控制力，都是由部落的长老，也就是咱们以前国内宗族的，像什么族长、村长这样的一个形式，然后控制的该部落，然后各个村落与部落各自为政，然后导致了任何一个列强以及阿富汗的城市政府对于广大的阿富汗高原山地地区无法形成一个有力的控制。

问（发言人3）：只提供军火，但是没有派人？
答（发言人1）：专家派的主要就教一些兵法、地道战、地雷战这一块的。
