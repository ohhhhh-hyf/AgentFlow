# 就诊概况
48岁男性患者张春和，在成都轻工研究所从事科研工作，因上腹烧灼痛4年、近3个月加重，于消化内科就诊。严医生接诊，初步判断需排查消化道出血及胃部病变，建议留大便做潜血检查并预约胃镜。

# 病史与背景
- **现病史**：上腹烧灼痛4年，每年春季多发，近3个月加重；疼痛位于心窝处，与进食冷、硬、辛辣食物及工作紧张劳累相关，与油腻食物关系不大；近3个月白天发作，无夜间痛醒，疼痛可忍受，有完全不痛的时候。
- **黑便史**：近4年出现两次黑便，一次在一年前，一次在三个月前，每次持续约一个月，大便干、形状正常，每日最多两次；两次均住院两三天后大便转黄。
- **伴随症状**：最近两个月出现反酸呕吐，呕吐物为酸水，含当日或隔日食物，呕吐后舒适。
- **既往史**：16岁时患甲肝，在三医院住院一个月，出院及此后体检肝功能均正常；小学时因扁桃体炎在儿童医院就诊。
- **过敏史**：小学时因扁桃体炎服用磺胺药后左手起红疹，持续半个月，医生诊断为药物过敏，此后禁用磺胺药。
- **家族史**：父亲76岁有低血压，母亲75岁有冠心病（服药控制良好），弟弟身体健康，婶婶（叔叔的爱人）患胃癌。
- **个人史**：在成都轻工研究所从事科研工作，工作紧张，经常加班熬夜；吸烟史，以前每日一包，现限制在10支以内，计划逐步戒烟；偶尔饮酒，平时不喝；每日喝两杯淡茶。
- **近期用药**：近期服用斯达舒，初有效后效果不佳，剂量从每日两次每次一颗增至每日四五次；另服用奥美拉唑（武汉产）、阿莫西林及单位医务室自配胃炎合剂，停药后症状反复。
