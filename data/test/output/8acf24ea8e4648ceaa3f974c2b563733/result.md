# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷一案，国家开发银行不服云南省高级人民法院（2018）云民初88号民事判决，向本院提起上诉。本院依法组成合议庭，依据《中华人民共和国民事诉讼法》第一百三十四条第一款、第一百六十九条的规定公开开庭审理。庭审核对各方当事人出庭人员身份后，围绕三个争议焦点进行审理：国开行是否尽到审查义务并善意取得抵押权、一审判决对案涉借款罚息复息的计算及起算日期是否认定错误、东源煤电及东源煤业是否应当连带给付违约金。各方充分发表辩论意见后，合议庭休庭评议并提出调解方案，各方均无异议，同意签署调解协议，本院将依法出具调解书。

# 举证与法庭调查
## 举证与质证

1. **融资租赁登记查询证书（招银租赁质证）**：招银租赁认为国开行提交的查询证书不符合要求，依据2014年93号中国人民银行关于融资租赁登记系统的规定，国开行应当在抵押时点（2015年12月）进行融资租赁登记查询，而非提供2018年9月的查询结果。
  - 证明目的：国开行主张其已按央行规定查询融资租赁登记系统，未发现登记记录，构成善意取得抵押权。
  - 对方质证意见：招银租赁认为查询时点错误，应以抵押操作时点（2015年12月）查询人行征信中心的结果为准，无论以设备名义还是电力公司名义查询；未在抵押时点查询则不构成善意。

2. **2015年12月2日邮件中的融资情况统计表（东源方举证）**：东源方提请法庭注意该邮件显示招银租赁抵押物已登记，国开行应尽注意义务。
  - 证明目的：东源方主张国开行对东源煤电的审查义务应当具备，因其借款人与抵押人构成100%全资控股关系。
  - 对方质证意见：国开行主张其审查义务仅限于抵押人曲靖电力公司，不能扩大到东源煤电公司。

3. **案涉5套设备登记情况（招银租赁陈述）**：案涉5套设备为通用设备，无唯一识别码，招银租赁未在登记系统中登记识别码。
  - 证明目的：说明融资租赁登记系统查询存在客观困难，设备无唯一识别码导致登记和查询难以对应。
  - 对方质证意见：国开行主张融资租赁登记为行业性规范，非法定物权登记；招银租赁认为查询是银行业严格义务，未查询则不构成善意。

4. **举证责任分配（招银租赁主张）**：招银租赁认为司法解释第9条第1、2、4项由出租人举证，第3项由第三人（国开行）举证。
  - 证明目的：明确各方在善意取得抵押权争议中的举证责任归属。
  - 对方质证意见：国开行未就此提出反驳意见。

## 争议焦点与辩论

1. **争议焦点一：国开行是否尽到审查义务、是否构成善意取得抵押权**
  - 国开行主张：其审查义务仅限于抵押人曲靖电力公司，不能扩大到东源煤电公司；已按央行规定查询融资租赁登记系统，未发现登记记录，构成善意取得。
  - 东源方反驳：2015年12月2日邮件中融资情况统计表已显示招银租赁抵押物已登记，国开行应尽注意义务；东源煤电具有双重身份，既是抵押人的全资控股母公司，又是贷款案件的借款人，国开行对东源煤电的审查义务应当具备。
  - 招银租赁反驳：国开行应在抵押时点（2015年12月）查询融资租赁登记系统，而非提供2018年9月的查询证书；案涉5套设备为通用设备无唯一识别码，招银租赁未在登记系统中登记识别码；融资租赁登记查询是银行业严格义务，未查询则不构成善意。
  - 举证责任：招银租赁认为司法解释第9条第1、2、4项由出租人举证，第3项由第三人（国开行）举证。

2. **争议焦点二：一审判决对案涉借款罚息、复息的计算及起算日期是否认定错误**
  - 国开行主张：本案中东源煤电利息支付时间截止到2017年12月20日，利息应从2017年12月21日计算到2018年6月12日，利息合计21,795,727.68元；罚息自2018年6月13日计算到东源煤电、东源煤业向人民法院申请破产受理之日即2019年2月19日，罚息为41,050,579.57元；复利自2018年3月21日计算到2019年2月19日，复利为1,918,206.23元。
  - 东源方反驳：国开行主张2018年6月13日以后宣布贷款提前到期按罚息计算不符合双方合同约定。借款合同第24条第2款第2项明确约定，国开行宣布贷款提前到期时应给东源公司发通知并要求限期偿还，限期偿还和立刻偿还是完全不同的两个概念；本案国开行当天发通知就要求借款人当天全额偿还，未给合理时间，且本案本金将近8.37亿元，金额较大。
  - 东源方关于复利计算的反驳：依据《人民币利率管理规定》第21条，对贷款期内不能按期支付的利息按合同利率按季计收复利，贷款利息后改按罚息利率计收复利，该规定仅针对贷款期内不能按期支付的利息，而非贷款逾期以后不能按期支付的罚息；合同第6条第4款约定贷款人对借款人不能按期支付的利息计收复利，其中对不能按期支付的逾期借款或挪用借款的利息表述的也是利息，均未提到罚息。
  - 国开行反驳：合同第6条第4款明确约定对逾期借款利息按罚息利率计收复利，有合同依据。

3. **争议焦点三：东源煤电、东源煤业是否应当连带给付违约金**
  - 国开行主张：借款合同第24条第3项明确约定被上诉人发生违约时应承担的违约责任，属双方意思自治，对双方均具有法律约束力；被上诉人出现违约事项时，理应向上诉人支付千分之一的违约金。
  - 东源方反驳：第一，国开行没有举证证明东源煤电存在违反柜台前移和账户管理的违约行为，在一审庭审、二审庭前会议及本次庭审中始终未向人民法院举证，举证不能的后果应由其自行承担；第二，按照合同约定，国开行必须对东源煤电的行为进行限期纠正，如不予纠正才有权主张违约金，但国开行自提起诉讼之日始终未向东源煤电发出过任何纠正行为的书面函件或进行过任何告知。
  - 招银租赁意见：招银租赁不是该解释时的参与方，尊重合议庭的审查结果。

# 庭审结果
1. **调解协议达成**：经本院组织调解，各方当事人自愿达成调解协议，不违反法律规定，本院予以确认，并将在庭后根据《中华人民共和国民事诉讼法》第97条的规定出具调解书。各方诉讼代理人已依次在调解协议正式文本上签字。

2. **债权数额确认**：国开行对东源煤电的债权，扣除破产重整程序中已清偿的本金外，利息、罚息、复利合计6474.4513万元。
  - 利息：2017年12月21日至2018年6月12日期间，合计2179.5727万元
  - 罚息：2018年6月13日至2019年2月19日期间，合计4105.0579万元
  - 复利：2018年3月21日至2019年2月19日期间，合计191.8206万元

3. **设备权属确认**：在东源煤电、东源煤业破产重整程序中，已确定招银租赁对涉案6项设备享有所有权，对应债权数额1377.4137万元；确定国开行对93项设备享有抵押权。

4. **设备整体处置安排**：招银租赁和国开行对案涉全部发电设备整体盘活处置，并从变现款中实现各自债权。
  - 变现价款双方各得50%，实现费用双方各担50%
  - 调解书生效后20日内，由国开行向一审法院提出执行申请，启动司法处置程序
  - 国开行、招银租赁未实现的债权，待执行法院出具终本裁定后，按照破产重整计划中的预留方案实现债权
  - 若破产管理人对招银租赁的债权不予纳入预留方案，由东源煤电按照此前招银租赁在东源煤电破产重整程序中有担保清偿方案予以清偿

5. **司法变现不能的兜底安排**：若司法变现不能，国开行和招银租赁的权益通过前述方法实现后，均放弃对案涉设备的权益，由东源曲靖电力自主生产经营。

6. **设备管理费用与配合义务**：案涉设备上的管理费用由东源曲靖电力承担，东源曲靖电力无条件配合司法处置。

7. **一审判决确认事项**：各方对一审判决第2项、第4项无争议，按照其判项内容在调解书中确认。

8. **诉讼费用分担**：
  - 一审诉讼费用中，对于国开行诉请部分按照一审判决执行
  - 对于招银租赁诉请部分的诉讼费用，由二审法院按照规定，根据争议财产对应的债权数额计算后，由国开行承担
  - 二审诉讼费用由法院依法确定后，由国开行和东源煤电各承担50%

9. **争议终结**：本协议签订后，各方之间就本案涉及的问题不再存在任何争议。

10. **程序安排**：合议庭休庭对争议问题进行评议，并请各方当事人协商调解方案；恢复开庭后宣读调解方案并征求各方意见，各方均无异议或修改意见；庭审结束，告知阅看庭审笔录并签名，如有遗漏和差错可以申请补正，随后闭庭。
