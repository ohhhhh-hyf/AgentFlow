# 访谈概述
余华在访谈中回顾了其文学创作生涯，将创作历程分为三个阶段：1.0阶段强调逼自己坐下来写，让屁股和椅子建立友谊；2.0阶段受卡夫卡启发，后受福克纳影响，采用视觉描写表现心理；3.0阶段后写作畅通无阻。他曾以托尔斯泰和陀思妥耶夫斯基为目标，但自知距离不可逾越。访谈覆盖文学创作阶段与理念、作品与时代的关系、写作状态与时间浪费、对批评的态度、网络热度与自我调节、中年危机与人生感悟、文学理想与未来计划等议题。余华最核心的观点包括：最好的写作状态在40多岁到50多岁，但那段时光被浪费，只出了两部作品；他认为这一代作家被马尔克斯误导，想在一本书里写一个世纪的故事，但没必要；他决定先写一个喜剧，改变读者对他的悲观印象，不再追求高度，转而追求宽度。访谈锚点包括《兄弟》（1996年开始创作）、《第七天》及三亚。看点在于余华亲述少年时在杭州湾被海流带走的经历，以及他直言莫言在莎士比亚故居发誓成为剧作家是「瞎扯」，并透露互联网上关于他的话有一半不是他说的。

# 访谈详细记录
## 文学创作阶段与理念

1. **余华将文学创作分为1.0、2.0、3.0三个阶段**：1.0阶段强调逼自己坐下来写，让屁股和椅子建立友谊；2.0阶段受卡夫卡启发，但遇到心理表现障碍；3.0阶段后写作畅通无阻，认为《活着》等作品已不是难题。
2. **余华曾以托尔斯泰和陀思妥耶夫斯基为目标**，当时觉得可能朝着他们去，现在知道距离不可逾越，但这种野心和幻想支撑他一篇篇写下来，同时对自己的写作不满意。
3. **2.0阶段受福克纳启发**：福克纳写一个穷白人把富白人杀了后的内心状态，采用让心脏停止跳动、让眼睛睁开的方式，心理描写没有心理，是视觉描写，通过视觉精确表达杀人后的状态。
4. **余华认为精神病人说话逻辑清晰**：他去过精神病医院，精神病人跟你说话逻辑是清晰的，一点都不混乱，只是空间方向不同，但逻辑完全是我们的逻辑。
5. **3.0版本以后就没再升级**：因为写作已经很成熟，比如写一个没有文化的农民讲述自己的故事，必须用最朴素的语言，不能用华丽语言，因为那不是他的成本，3.0版本已经是大海了。

## 作品与时代的关系

1. **《兄弟》创作始于1996年**，因当时中国社会变化复杂而写；2003年和2004年重新拿回来写时，发现很庆幸1996年没有写完，因为从2004年再看，96年时候的变化不算什么，那才是真正大的变化。
2. **余华认为作家需要与时代相遇**，中国始终处于一个很大变化的时代，作家需要足够的激情；《兄弟》是对中国一段时期内全景式的描写。
3. **《十八岁》一天写完**：余华提到写《十八岁》时一天就写完了，6000字，对于他这种写字比较慢的人已经是奇迹，说明写作顺利时状态很好。

## 写作状态与时间浪费

1. **余华认为最好的写作状态在40多岁到50多岁**，即《兄弟》到《第七天》期间，但那段时间被玩掉了，只出了两部作品，现在非常可惜。
2. **2006年开始写一部长篇小说**，实践跨度与《兄弟》相同，但从个人角度出发，想用接近陀思妥耶夫斯基的激烈方式去写；现在身体状态可能还能维持这种激烈，但那个时代的感觉没了，很难找回来。
3. **余华估计自己还能好好写作的时间约十年左右**，他来到三亚的工作很简单：写作、读书听音乐、锻炼。
4. **余华计划开学时与学生见面**，处理学校事务后回三亚继续写作，安安静静把感觉找回来。

## 对批评的态度

1. **《兄弟》出版时余华期待赞扬**，结果一片骂声，弄得他有点糊涂；他还努力想把骂声引过来，接受了很多采访去解释作品，但到《第七天》出来时只接受了一个采访，什么都不做了，让他们去骂吧。
2. **余华认为有些批评没有道理**：比如批评宋凡平这个人物写得太完美，但宋凡平不是贯穿全书的李光头和宋刚，只是特殊年代阶段性出现的人物，只能写他在这个阶段的表现，这种批评没有道理。
3. **余华认为有些批评有提醒作用**：比如有人说《第七天》里社会底层人未必都那么善良，这句话说得很好；在死无葬身之地相遇时必须把善良表现出来，否则没有力量，但写他们在现实生活中是朋友同事会勾心斗角，这种提醒会在以后写小人物的作品中考虑进去。
4. **余华应对批评的方式**：第一，不要去看就行了；第二，有些批评要重视，有些批评没有道理；他已经习惯了，因为骂人的人也累。

## 网络热度与自我调节

1. **余华曾停一年活动**，任何活动、采访都不做，处于冷静期；但后来发现自媒体时代不是这样，会把几十年前的事情都翻出来，以前说过的话都翻出来。
2. **余华认为互联网上关于他的话有一半不是他说的**：比如「想要命好的」「精神内耗，心里的戏太多」都不是他说的。
3. **余华不担心热度消散**：因为他的工作不是说话的，是写作，不说话其实也挺好；可能今天因为说了一句话突然被关注，又说错了一句引发愤怒，过了十年以后又众人喜欢了。
4. **余华建议面对负面消息时选择屏蔽**：发生的事情我们无法选择什么让它发生，但可以选择什么让自己知道、什么让自己不知道；如果网上负面消息太多，这段时间就不看，屏蔽掉，我们有这个权利和能力选择。

## 中年危机与人生感悟

1. **余华34岁时在年终总结中感到虚无**：一个成年人每到年底都会发现一种虚无，一年到头来，本来对生活充满信心的人变成一个面试者，这就是一个成年人的不安。
2. **余华认为中年危机是所有人都遇到的**：现实世界每天都是重复的，没有那么多新的东西，只有写作能够得到一些新的东西，虚构的世界带来一些新的东西。
3. **余华建议通过选择知道什么来调节**：如果那段时间感觉特别不舒服，网上负面消息太多就不看，屏蔽掉，可以选择积极的。

## 文学理想与未来计划

1. **余华认为这一代作家被马尔克斯误导**：整整一代中国作家都想在一本书里写一个世纪的故事，但没必要；伟大的托尔斯泰、狄更斯、莎士比亚、巴尔扎克、福楼拜、司汤达、契诃夫都没有这样写，马尔克斯开创了一个先例，但没有能力在不到30万字的小说里写出一个世界。
2. **余华不再追求高度，转而追求宽度**：写作能够走到的高度已经是现在的高度，允许自己下滑一下但不要下滑太多；年纪大了不会像年轻时充满野心，知道自己的能力在哪里、长处在哪里、还有多少潜力。
3. **余华决定先写一个喜剧**：这次回来选择了一篇篇喜剧，因为悲剧写得太重了，作品几乎都是悲剧；想把悲伤留给虚构，把欢乐留给现实，改变读者对他的悲观印象。
4. **余华谈及与莫言、苏童去莎士比亚故居**：莫言在雕塑前说要成为剧作家是瞎扯，他在那挑选帽子，后来帽子钱还是余华付的，买了三顶一模一样的深蓝色帽子，上面有莎士比亚的名字；在伦敦和牛津天天戴着那顶帽子，但莎士比亚没有给予任何灵感。

# 关键引语与金句
> “坐下来让屁股和椅子建立友谊，这是很重要的，这是年轻时候最重要。”

- 背景：谈到文学创作1.0阶段时，余华强调逼自己坐下来写作的重要性。

> “当时我觉得我将可能我的目标是对着那个托尔斯泰和陀思妥耶夫斯基去的，现在我知道我离他们的距离是不可逾越的。”

- 背景：回应年轻时对写作的野心与幻想，坦言如今自知与大师的差距。

> “我已经把那个40多岁到50岁最好的一段时间浪费掉了，就出了两部。”

- 背景：谈及2006年开始写的一部长篇小说感觉已远去、难以找回时，余华痛惜自己浪费了最好的写作年华。

> “在互联网上，起码我看到的我看到的啊，关于我这说的话，有一半不是我说的。”

- 背景：谈到网络走红后自媒体翻出旧事，余华指出网上流传的许多话并非他本人所说。

> “发生的事情我们是无法去选择什么让它发生，什么让它不发生，但是我们可以选择什么让自己去知道，什么让自己去不知道。”

- 背景：回应年轻人面对巨大不安与焦虑如何排解时，余华分享自我调节的方法。

> “把悲伤留给虚构，把欢乐留给现实。”

- 背景：谈到自己作品几乎都是悲剧时，余华总结自己的创作态度。

> “我们整整一代中国作家都想在一本书里边写那个一个世纪的故事，但是其实没有必要。”

- 背景：谈及文学理想时，余华认为这一代作家被马尔克斯误导。

> “假如那个历史的长河里边有一个主题的话，这个主题就是。一个一个世界，一个一个的人。”

- 背景：回应希望以什么样的姿态留在历史长河中时，余华给出的回答。
