# 报告概况
《政府工作报告》由国务院总理代表国务院向全国人民代表大会报告，报告期间为2023年工作回顾与2024年工作部署。报告核心主题是坚持稳中求进工作总基调，完整、准确、全面贯彻新发展理念，着力推动高质量发展，统筹扩大内需和深化供给侧结构性改革，统筹新型城镇化和乡村全面振兴，统筹高质量发展和高水平安全，以中国式现代化全面推进强国建设、民族复兴伟业。整体基调积极进取，既肯定2023年成绩来之不易，又直面外部环境复杂性上升、经济恢复基础不稳固、有效需求不足、社会预期偏弱等困难挑战，强调要巩固和增强经济回升向好态势，持续推动经济实现质的有效提升和量的合理增长。

# 核心政策
2024年主要预期目标：**国内生产总值增长5%左右**，**城镇新增就业1120万人**，**城镇调查失业率5.5%左右**，**居民消费价格涨幅3%左右**，**居民收入增长和经济增长同步**，**国际收支保持基本平衡**，**粮食产量1.3万亿斤以上**，**单位国内生产总值能耗降低2.5%左右**，生态环境质量持续改善。宏观政策取向：积极的财政政策适度加力、提质增效，**赤字率按3%安排**，**一般公共预算支出规模28.5万亿元**，**地方政府专项债券3.9万亿元**，**发行超长期特别国债10000亿元**，专项用于国家重大战略实施和重点领域安全能力建设；稳健的货币政策灵活适度、精准有效，保持流动性合理充裕，促进社会综合融资成本稳中有降，增强资本市场内在稳定性，保持人民币汇率在合理均衡水平上基本稳定。核心政策包括：大力推进现代化产业体系建设，加快发展新质生产力；深入实施科教兴国战略；着力扩大国内需求；坚定不移深化改革；扩大高水平对外开放；更好统筹发展和安全；坚持不懈抓好三农工作；推动城乡融合和区域协调发展；加强生态文明建设；切实保障和改善民生。

# 重点工作
**一、现代化产业体系建设**：实施制造业重点产业链高质量发展行动，推动传统产业高端化、智能化、绿色化转型，促进中小企业专精特新发展；巩固扩大智能网联、新能源汽车等产业领先优势，制定未来产业发展规划；深入推进数字经济创新发展，开展`人工智能+`行动，实施制造业数字化转型行动。**二、科教兴国战略**：制定实施教育强国建设规划纲要，开展基础教育扩优提质行动，加快建设中国特色世界一流的大学和优势学科；强化基础研究系统布局，推进关键核心技术协同攻关，强化企业科技创新主体地位；实施更加积极、更加开放、更加有效的人才政策，加大对青年科技人才支持力度。**三、扩大国内需求**：培育壮大新型消费，实施数字消费、绿色消费、健康消费促进政策，鼓励和推动消费品以旧换新；发挥政府投资带动放大效应，重点支持科技创新、新型基础设施、节能减排降碳等领域，着力稳定扩大民间投资。**四、深化改革**：深入实施国有企业改革深化提升行动，全面落实促进民营经济发展壮大的意见及配套举措，实施降低物流成本行动，健全防范化解拖欠企业账款长效机制；加快全国统一大市场建设，专项治理地方保护、市场分割、招商引资不当竞争等突出问题；谋划新一轮财税体制改革。**五、扩大高水平对外开放**：推动外贸稳规模优结构，促进跨境电商等新业态健康发展，拓展中间品贸易、绿色贸易等新增长点；**全面取消制造业领域外资准入限制措施**，放宽电信、医疗等服务业市场准入；推动高质量共建`一带一路`走深走实，抓好八项行动落实落地。**六、统筹发展和安全**：优化房地产政策，促进房地产市场平稳健康发展，加快构建房地产发展新模式，加大保障性住房建设和供给；统筹好地方债务风险化解和稳定发展，进一步落实一揽子化债方案；稳妥推进中小金融机构风险处置；全方位夯实粮食安全根基，强化能源资源安全保障。**七、三农工作**：学习运用`千村示范、万村整治`工程经验，稳定粮食播种面积，严守耕地红线，提高高标准农田建设投资补助水平；毫不放松巩固拓展脱贫攻坚成果，确保不发生规模性返贫；**启动第二轮土地承包到期后再延长30年整省试点**。**八、城乡融合和区域协调发展**：把加快农业转移人口市民化摆在突出位置，深化户籍制度改革，推动未落户常住人口平等享受城镇基本公共服务；深入实施西部大开发、东北全面振兴、中部地区加快崛起、东部地区加快推进现代化等战略，支持京津冀、长三角、粤港澳大湾区等地区发挥高质量发展动力源作用。**九、生态文明建设**：深入实施空气质量持续改善行动计划，统筹水资源、水环境、水生态治理，组织打好`三北`工程三大标志性战役；大力发展绿色低碳经济，推进产业结构、能源结构、交通运输结构绿色转型；积极稳妥推进碳达峰碳中和，扎实开展`碳达峰十大行动`。**十、保障和改善民生**：突出就业优先导向，强化促进青年就业政策，预计今年高校毕业生超过1170万人；**居民医保人均财政补助标准提高30元**，深化公立医院改革，引导优质医疗资源下沉基层；**城乡居民基础养老金月最低标准提高20元**，继续提高退休人员基本养老金；健全生育支持政策，减轻家庭生育养育教育负担；维护国家安全和社会稳定，坚决遏制重特大事故发生。
