# 电子科学与工程学院招生宣讲直播

## 沟通背景与目的
本次沟通为电子科技大学电子科学与工程学院面向考生及家长举办的招生宣讲直播，由主持人串联，学院领导段院、柳教授、张教授、李天明教授及在读博士研究生田雨桐依次参与分享。沟通旨在系统介绍学院历史沿革、师资科研平台及电子信息材料与元器件、电磁场与微波技术、电路与系统、物理电子学等主要学科方向，并辅以学生视角的择校建议，以吸引优秀生源报考。整体基调为全面展示学院实力与培养成果，内容覆盖完整、数据详实，达到了宣传推介的目的；直播中未形成明确决策，后续夏令营具体安排待定。

## 核心信息与数据
### 学院历史与整体情况
1. **历史沿革**：1956年建校之初成立无线电系、电真空器件系、无线电零件系，经1979年、1992年、2001年、2018年四次院系调整成立电子科学与工程学院（示范性微电子学院），2023年响应国家号召成立电子科学与工程学院与集成电路学院。
2. **学科设置**：电子科学与技术为一级学科，属国家重点一级学科，下设电磁场与微波技术、电路与系统、微电子学与固体电子学、物理电子学、电磁信息功能材料与机构5个二级学科方向，另有电磁场与微波军用关键材料、电子元器件等3个国防特色学科。
3. **党建荣誉**：学院党委入选教育部首批全国党建工作标杆院系，学院荣获全国教育系统先进集体。
4. **人才培养规模**：本科生现有1545人，招生专业为工科试验班（电子工程类），含电子科学与技术（国家特色专业、国家级一流本科专业建设点）与电磁场与无线技术两个专业方向；硕士和博士研究生1975人，招生专业含学术学位博士/硕士电子科学与技术、硕士材料科学与工程，专业学位博士/硕士电子信息、硕士材料工程。
5. **师资构成**：现有教师302人，其中教研系列139人、科研系列95人、教学系列14人、实验系列21人，教师总数269人，机关33人；高层次人才含两院院士2人、领军人才19人、青年人才28人、其他类型人才12人、后备61人。
6. **团队荣誉**：拥有两个全国高校黄大年式教师团队（第1个、第2个为电磁辐射与散射教师团队），2022年获批4个国家自然科学基金创新群体。
7. **科研经费与成果**：近5年科研经费到账稳定在3–4亿元之间，以纵向项目为主、横向项目为辅；牵头获国家科技奖励11项，发表高水平学术论文2000余篇，申请专利1600余件、授权1300余件。
8. **科研团队与平台**：共20个科研团队，年度经费过千万元的团队15个、过亿元团队1个；拥有国家电磁辐射控制材料工程技术研究中心、微波电子器件国家级重点实验室两个国家级平台，4个国际合作平台、7个省部级科研平台。
9. **国际交流**：共建国际姊妹院系两个（香港大学电机工程电子系、香港城市大学电子工程系），主办高水平国际会议13场，学生长短期交流项目20多个。

### 电子信息材料与元器件方向
1. **方向定位**：主要涉及电子材料与电子器件，在IT领域以物质基础与先导推动电路系统与电子装备研发，概括为「一代材料催生一代器件，服务一代整机」；以电子在物质中的输运特性（含电磁声光热力、化学生物特性）及外部作用为基础，设计研究和生产电子器件，以材料为基础、器件为核心、应用为目标导向。
2. **产业背景**：中国是电子产品生产大国但尚非强国，2021年中国集成电路电子产品进口额度已达2.8万亿元，约为原油进口量的1.7倍。
3. **邓龙江院士团队**：研究人员19人（正高13人、副高15人），开展结构和器件研究，近年发表包括Nature在内的论文300余篇，承担国家省部级及国际合作等研究课题130余项，年均到账经费3000多万元，授权发明专利100余项，获国家科技进步或技术发明二等奖共计3项。
4. **张怀武教授团队**：研究人员17人（正高15人、副高2人），重点开展LTCC材料及集成技术、微波毫米波晶圆及器件、自旋电子与磁量子器件传感器芯片等研究，承担国家重点研发计划、自然基金重点重大科学仪器项目、国际合作等项目100余项，发表SCI论文400余篇，年均到账经费2000余万元，获科技进步二等奖共计3项。
5. **依托平台**：国家电磁辐射控制材料工程技术研究中心，历史可追溯至1990年校级材料与技术研究中心，经2008年、2013年两次升级形成国家级平台，主要开展多频谱涂层、电磁材料与结构、智能材料与结构研究。
6. **毕业生代表**：河北美泰电子科技公司副总，率先带领团队采用MEMS工艺研制出SIW环形器隔离器，突破卡脖子器件核心技术，实现高性能非互易器件产业化。

### 电磁场与微波技术、电路与系统方向
1. **电磁场与微波技术**：包含微波毫米波电路、电波传播与电磁兼容、计算电磁学与工程电子学、天线理论与技术4个细分方向，涵盖射频微波整套系统的全部研发方向。
2. **电路与系统**：包含非线性电路与复杂电子系统、射频微波电路与系统、集成电路与系统3个专业方向；1981年开始招收研究生和博士研究生，1988年成立首批博士后流动站。
3. **学科平台与师资**：学科包含教育部国际合作联合实验室、国家高等学校学科创新引智基地，拥有国家级人才4人、新世纪人才2人、教授10人、副教授22人。
4. **太赫兹雷达成像**：樊勇教授团队成功研制0.22THz、0.34THz、0.42THz雷达成像系统，实验平台分辨率小于1厘米。
5. **太赫兹通信应用**：樊勇教授团队在太赫兹通信技术方面取得突破，成果于2023年成都大运会田径项目中成功示范应用。
6. **电磁波与物质互作用**：李恩教授团队面向5G通信、高性能系统、生物医学、新能源等方向提供应用需求与研究成果，在生物医学电磁学及成像方向发表大量高水平论文，并有20余项国家发明专利。
7. **高速车地通信**：樊勇教授、王成教授团队及李廷军教授团队从事高速磁浮交通38GHz车地通信系统研制，可实现安全可靠实时宽带通信，确保列车安全运行。

### 物理电子学方向
1. **学科定义**：物理电子学是物理学与电子科学技术的交叉学科，物理学研究物质能量的本质与性质，电子科学与技术研究电子在不同介质中的运动规律及与物质的相互作用。
2. **发展历程**：起源于1956年建校时的电子控器件专业，经近70年发展，纵向延伸至仿真设计、人工智能应用，横向拓展至太赫兹技术、医学交叉等方向。
3. **科研平台与经费**：拥有3个四川省工程中心或重点实验室，每年到校科研经费接近2亿元，为学院最多；学校为国际最大真空器件研究中心。
4. **科研团队**：物理电子学方向共有9个团队，2023年成功举办行业顶级会议。

### 学生视角
1. **择校理由**：博士生田雨桐分享选择电子学院的8个理由，包括成都作为四川省会、国家中心城市、新一线城市、国家历史文化名城、古蜀文明发祥地、中国十大古都之一的城市优势，学校电子信息学科群实力，学院电子科学与技术学科第四轮学科评估A+等。
2. **择校建议**：建议研究生新生先选团队再选导师，利用文献检索网站了解导师情况，提前沟通交流。

## 达成共识
1. **学院整体情况介绍口径**：段院在直播中确认，电子科学与工程学院自1956年建校初的无线电系等起步，经四次院系调整，于2023年响应国家号召成立电子科学与工程学院与集成电路学院；学院拥有国家重点一级学科电子科学与技术，下设5个二级学科方向及3个国防特色学科。该口径作为学院对外招生宣讲的统一表述，已完整呈现给考生及家长。

2. **电子信息材料与元器件方向定位**：柳教授明确该方向以“一代材料催生一代器件，服务一代整机”为概括，以材料为基础、器件为核心、应用为目标导向；同时指出中国是电子产品生产大国但尚非强国，2021年集成电路进口额达2.8万亿元、约为原油进口量的1.7倍，先进电子材料属“卡脖子”问题。该方向依托国家电磁辐射控制材料工程技术研究中心等两个国家级平台开展科研与人才培养。

3. **电磁场与微波技术、电路与系统方向覆盖范围**：张教授确认两个专业方向共同组建射频电子系统的全方位专业覆盖——电磁场与微波技术涵盖微波毫米波电路、电波传播与电磁兼容、计算电磁学与工程电子学、天线理论与技术4个细分方向；电路与系统涵盖非线性电路与复杂电子系统、射频微波电路与系统、集成电路与系统3个方向。学科历史可追溯至1956年，由林卫干先生和谢楚芳先生创建，所属一级学科入选双一流A类。

4. **物理电子学学科定位与优势**：李天明教授确认物理电子学是物理学与电子科学技术的交叉学科，学校该方向起源于1956年建校时的电子控器件专业，经近70年发展，纵向延伸至仿真设计、人工智能应用，横向拓展至太赫兹技术、医学交叉等；团队共9个，科研经费接近2亿元/年，为学院最多，并称学校为国际最大真空器件研究中心。

5. **学生择校与专业选择建议**：博士生田雨桐从学生视角分享选择电子学院的8个理由，包括成都的产业优势、学校电子信息学科群、学院电子科学与技术学科第四轮评估A+等；并建议研究生新生**先选团队再选导师**，利用文献检索网站了解导师情况，提前沟通交流。该建议作为在读学生的经验分享，已向考生及家长明确传达。
