# 项目概况
本次会议为原占比二玉米面加工厂项目中期验收会议，由验收组代表王总主持并汇报，合作局领导金昌柱、公司国内领导林总及管理组、技术组相关人员参会。验收组于18号、19号提前介入项目摸排，20号召开首次会议，目前已完成卢萨卡点（除带料加工调试外）和蒙蒙泽点的全部验收工作，姆皮卡点内业资料已提前拿到卢萨卡点。验收工作分内业检查和外业检查，专业方向涵盖建筑工程、安装工程和机电设备。

内业方面，项目执行团队基本能保证主要人员在岗，编制了施工组织计划、管理计划、实施细则和专项预案，内业资料基本满足项目有关标准和规范要求，竣工文件基本达到组卷和成册要求，但资料分散，需汇总到卢萨卡分类成册，且存在分类整理和签字规范性需完善的问题。外业方面，建筑部分主要建材从国内采购或从卢萨卡集中预制采购，内在品质和外观达到较好标准；安装部分钢结构材料从国内定制发货，施工工艺和外观质量满足规范要求；设备部分参照中国标准定制，由中粮西安设计院及厂家供货，蒙蒙泽点设备投料试运行正常，产能经打表计算符合设计指标。财务方面，账户设置、资金往来、银行开户等过程完全符合财务处理规范和标准，中基公司在此项目是第一个也是唯一一个项目，没有挪用资金的情况。

验收组提出整改要求：人员履约方面，个别人员进出场时间、护照及证件有效期需完善，人员统计需包含厂家服务人员；内业资料需按规范分类整理，签字规范性需完善，资料需汇总到卢萨卡分类成册；现场实体方面，局部装饰装修损伤需检查修补，厂区排水需清理排查，混凝土路面开裂需处理，监控管线接头脱落需检查，提升通道需考虑防雨水倒灌，廊桥竖条需加密。管理组田组长表示会后与技术组细化问题并制定方案处理，技术组龚总汇报人员统计和护照收集已开展，内业资料将严格按要求汇总，现场实体将编制方案逐一整改。合作局领导金昌柱要求相关方尽快补充资料，与验收组做好沟通，避免遗留未决事项；

要求管理组和总包单位共同分析蒙蒙泽厂区混凝土路面开裂原因，制定科学合理的整改方案，最迟在出报告前完成整改，验收组需复核；要求做好成品保护，及时修补破损。公司领导林总要求按照商务部经商局指示完成验收任务，按合同规章制度仔细验收，并提醒注意交通安全，姆皮卡路况不好，且赞比亚雨季已到。验收组补充说明不可预见费使用情况，本项目有动用不可预见费的情况，有关依据证据和数据必须做到充分无误，后续将专门对接完善资料。

# 后续计划
- **资料汇总**：执行单位会后将三个厂区的资料全部汇总至卢萨卡，包括竣工图，进行分类汇总、分类组卷及编码。
- **路面开裂整改**：管理组和总包单位共同分析蒙蒙泽厂区混凝土路面开裂原因，制定科学合理的整改方案，最迟在出报告前完成整改，验收组需复核。
- **现场整改**：对监控管线接头脱落进行全面检查，保证有效性和安全性；对提升通道雨水倒灌问题考虑技术措施解决；对廊桥竖条加密，增加安全保障；对局部装饰装修损伤进行检查修补，并打扫卫生；对厂区排水系统进行最后清理和排查；对混凝土路面裂纹重新清理，用防水材料全部封闭。
- **人员履约**：完善人员统计、护照和证件有效期等资料，人员统计需包含厂家服务人员。
- **不可预见费**：验收组继续跟踪和完善不可预见费使用资料，确保依据证据和数据充分无误，后续专门对接。
- **姆皮卡点验收**：会后及时安排剩余工作，注意交通安全和疫情防控。
