# 就诊概况
患者为女性，年龄、职业未提及。2023年9月因腹痛确诊结肠癌并切除，术后行8期化疗；复查发现肝转移，行肝消融及乳腺结节切除，但腹膜转移可能切除不干净。后续化疗因肝功能不佳停用部分药物，停药3个月。2024年3月底复查发现肝、肺、腹膜转移，4月份PET-CT显示广泛转移，肠镜未见异常但PET显示有转移。本次就诊核心主诉为结肠癌术后转移，讨论后续全身治疗方案。

# 病史与背景
- **现病史**：2023年9月因腹痛（疼了一晚上）确诊结肠癌，行结肠癌切除手术，术后行8期化疗；复查发现肝转移，行肝消融及乳腺结节切除，但腹膜转移可能切除不干净；后续化疗因肝功能不佳停用部分药物，停药3个月；2024年3月底复查发现肝、肺、腹膜转移；4月份PET-CT显示广泛转移，肠镜未见异常但PET显示有转移。
- **既往史**：患者多年来肠胃较弱，吃海鲜易上吐下泻。
- **手术史**：结肠癌切除手术、肝消融、乳腺结节切除。
- **近期用药**：化疗药物（具体药名未提及），因肝功能不佳停用部分药物。

# 诊断与检查结果
- **诊断结论**：结肠癌术后转移，累及肝、肺、腹膜。
- **检查结果**：4月份PET-CT显示广泛转移；肠镜显示无异常，但PET显示有转移，医生认为可能是肠镜做得不好。
- **基因检测**：建议进行基因检测（包括M2D等），可通过组织、血液、尿液、唾液进行。
- **免疫评估**：建议进行免疫评估，了解免疫细胞状态。

# 治疗方案与医嘱
- **检查安排**：建议进行基因检测（包括M2D等），可在肿瘤医院进行；建议进行免疫评估。
- **治疗建议**：当前主要问题是全身系统治疗（化疗、靶向、免疫可联合使用），而非局部介入；若肿瘤增大至10公分或危及生命，才需考虑局部处理。
- **用药说明**：因肝功能不佳，化疗药物停用部分，停药3个月。
- **生活方式**：建议患者调整状态，提升免疫力。
