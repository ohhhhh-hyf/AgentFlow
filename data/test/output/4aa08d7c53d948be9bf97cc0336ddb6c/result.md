# 参观概况
本次参观为故宫博物院游览，讲解围绕故宫主要景点展开，系统介绍了午门、太和殿、乾清宫、珍宝馆等处的历史背景与参观要点，并梳理了七个免费盖章点及三条游览路线。整体过程从午门检票进入，沿中轴线依次参观太和门、太和殿、中和殿、保和殿、乾清门、乾清宫、交泰殿、坤宁宫，再向西至储秀宫、翊坤宫、永寿宫、太极殿、慈宁宫、寿康宫，经断虹桥、武英殿、文华殿、箭亭，后至钟表馆、珍宝馆，最后经东筒子夹道、延禧宫、景仁宫到达御花园，从神武门结束。

# 核心看点与讲解
午门：三个门洞，进门后变五个，即明三暗五；中间正门仅供皇帝通行，皇帝大婚时皇后可进一次，殿试前三名（状元、榜眼、探花）可出一次，旁边两门走皇亲国戚和文武百官。太和门广场：有五座金水桥，皇帝走中间，皇亲国戚走挨着中间的两座桥，文武百官走最边上；太和门为明朝皇帝御门听政（上朝）之处，门口铜狮子为故宫六对铜狮中最大的一对，脚踩寰宇象征权力。太和殿：举行盛大典礼之处（如皇帝登基、皇后册封），非上朝处；文武百官在太和殿广场向皇帝喊“吾皇万岁万岁万万岁”，站位为文东武西；西边红衣阁是皇帝银库，东边体仁阁是缎库。中和殿：举行盛大典礼时皇帝的休息室。保和殿：自乾隆五十四年起为殿试考场；东北角汉字馆有4枚免费印章，可购买《紫禁城100》现场盖章，各店印章不同，购买后不能去其他店盖章，汉字馆印章数量最多。乾清门：过此门即后宫（皇帝和妃嫔生活区域）；东边九卿直房为等级高的大臣等待召见处，西边为军机处；门口铜狮耳朵耷拉、眉毛遮眼，警示后宫之人不该看的别看、不该听的别听。乾清宫：皇帝平时睡觉处，有27张龙床，据说是为防止刺客找到皇帝位置；牌匾“正大光明”后藏立储诏书，皇帝写两份诏书，驾崩后对比，若名字不同则说明被动手脚；门口有铜鹤与铜龟，旁边有社稷江山金殿，为紫禁城最小宫殿，提醒皇帝把江山社稷放在第一位。交泰殿：存放25块传国玉玺。坤宁宫：皇后居所，明朝所有皇后都住此；东北角文创店有5枚免费印章。储秀宫：慈禧住了20多年，现为慈禧五十大寿时期原状陈列，其子在此出生；旁边文创店有3枚免费印章。翊坤宫、永寿宫：位于储秀宫以南；永寿宫西边为太极殿，是东西六宫中唯一被称为殿的。慈宁宫：康熙为奶奶孝庄皇太后修建的养老院；旁边寿康宫为甄嬛居住处。冰窖书吧：有3枚免费印章，印章造型好，盖章有批折子的感觉。断虹桥：网红打卡地，桥上有形态各异的石狮子，最有名的为“武当狮”。武英殿：后改为陶瓷馆，目前关闭，只能在门口看；位于西边，对应文东武西。文华殿：位于东边，参观时未开，据说现有一个展览。箭亭：清朝皇帝及子孙练习骑马射箭处；旁边商店可买文创雪糕。钟表馆：展示那个年代的钟表造型。珍宝馆：门口有我国现存三座古代九龙壁之一，左边数第三条白色龙下边有一块木头，据说是当年烧制琉璃砖瓦时弄坏一块，工匠为保命找木头刷白漆以假乱真；珍宝馆并非单独展厅，院子周围屋子都可参观，游客很多，尤其看凤冠的；此处为宁寿全宫，是乾隆给自己修建的养老院，乾隆退休后未放权，每天照常上朝办公；皇极殿据说是1:1复刻乾清宫，宁寿宫对标坤宁宫，养性殿后为乐寿堂，是故宫里唯一能进去参观的皇家寝室，内有二龙戏珠（原文为“二龙仙楼”）设计，让人想到恭王府和珅的卧室；珍妃井为当年慈禧把珍妃丢进去之处，井口石非珍妃进入处；出口右手边商店有3枚免费印章。东筒子夹道：拍照非常出片。延禧宫：网红打卡地；旁边景仁宫为甄嬛被封熹妃时所住，珍妃也住过。御花园：有钦安殿，供奉真武大帝；紫禁城靠山景山从天上看酷似闭目盘坐人像，有人说造型就是真武大帝。神武门：故宫北门，出门左手边角楼咖啡有2枚免费印章，故宫文创有2枚免费印章。

# 互动与体验
参观中有多处盖章互动：保和殿东北角汉字馆有4枚免费印章，可购买《紫禁城100》现场盖章，各店印章不同，购买后不能去其他店盖章，汉字馆印章数量最多；坤宁宫东北角文创店有5枚免费印章；储秀宫文创店有3枚免费印章；冰窖书吧有3枚免费印章，盖章时有批折子的感觉；珍宝馆出口商店有3枚免费印章；神武门出门左手边角楼咖啡有2枚免费印章，故宫文创有2枚免费印章。共七个免费盖章点。个人感受：珍宝馆里宝贝很惊艳，但游客太多，尤其看凤冠的挤不进去；东筒子夹道拍照非常出片；文创雪糕可在箭亭旁商店购买。

# 收获与建议
参观收获包括：午门为明三暗五结构，中间正门仅供皇帝、皇后大婚及殿试前三名通行；太和殿为举行盛大典礼之处，非上朝场所，文武百官按文东武西站位；乾清宫有27张龙床，牌匾后藏立储诏书；交泰殿存25块传国玉玺；坤宁宫为皇后居所，储秀宫为慈禧居所，慈宁宫为孝庄太后养老院，寿康宫为甄嬛居所；珍宝馆为宁寿全宫，皇极殿1:1复刻乾清宫，乐寿堂为唯一可进入的皇家寝室；珍妃井井口石非珍妃进入处。建议：游览路线共三条，第一条走完所有景点，适合全天，建议早起排队，进门后沿中轴线往后走，可错开旅游团，一天走3万步；第二条中轴线至坤宁宫，看景仁宫、延禧宫，逛钟表馆、珍宝馆，御花园，神武门出，约半天；第三条中轴线至坤宁宫，去储秀宫，御花园，神武门出，约2小时，最省力。
