# 课程概况
本次课程为电气工程基础导论，是电气工程专业入门课。课程旨在解决两个问题：掌握电力系统发电、输电、配电、用电四个典型环节的构成、工作原理及整体关系；掌握电力系统分析、设计、运行、管理的基础理论、技术与计算方法。前修课程要求电路理论和电机学知识，特别是变压器和同步电机；后续课程包括电力系统分析、电力系统继电保护、电力系统自动化和高电压技术。第一章涉及电力系统基本概念，包括电力系统、电力网、动力系统、变电站等，要求理解电力系统特点及要求、掌握电能质量指标国家标准、了解接地方式。课程还梳理了电力发展简史，从直流输电到交流输电主导，再到直流在联网中重新受关注，并介绍了电力系统的形成过程与定义。

# 核心知识点梳理
**课程目标**：掌握电力系统四个典型环节（发电、输电、配电、用电）的构成、工作原理及整体关系；掌握电力系统分析、设计、运行、管理的基础理论、技术与计算方法。

**第一章学习内容**：
- 基本概念：`电力系统`、`电力网`、`动力系统`、`变电站`
- 理解电力系统的特点及由此引起的设计、运行基础理论
- 理解对电力系统提出的要求（涉及运行、设计、维护）
- 掌握电能质量指标及国家标准规定范围
- 了解电力系统常用接地方式，特别是工作接地（中性点接地方式）的不同特点

**三个难点** ⭐：
1. 由电力系统特点引出的基本原理，如电能不能大量储存决定有功功率和无功功率的动态平衡
2. 电力系统额定电压的规定（繁杂，需理清规律）
3. 各种中性点接地方式的特点（影响后续章节学习）

**学习方法**：注意概念的内涵和外延；从电力系统特点和要求出发，从最基础原理推导，不记结论；寻找额定电压规定之间的基本规律；比较不同中性点接地方式的特点。

**电力发展简史**：
- 直流输电早期试验：1874年俄国彼得堡4.5公里直流线路（传输功率4.5千瓦）；1882年法国德普勒57公里试验线路（首端电压343伏、末端850伏、输送功率200瓦、损耗78%）；1883年14公里试验（输送功率1.1千瓦、损耗55%）；1882年英国发明直流三线制系统（外线与中线间110伏、两外线间220伏）
- 直流输电受限：电压等级低时损耗大、电压降落快，制造大容量高压直流发电机困难
- 交流输电发展：1876年俄国发明单相变压器；1883年特斯拉制造感应电机；1885年匈牙利设计多台变压器并联运行；1886年威斯汀豪斯在美国麻省进行1.2千米30千伏交流输电示范；1886年俄国发明三相交流电、三相异步电动机
- 交直流电力战争：爱迪生与凯尔文主张直流（效率高、认为交流危险），威斯汀豪斯与特斯拉主张交流（易升压降压、减少损失）；标志性事件为法国到德国的交流输电线路（三相发电机、升压变压器、法兰克福两座降压变电站，供展览会照明和100马力三相异步电动机）
- 交流输电技术进展：1898年发明针式绝缘子（美国33千伏）；1906年悬式绝缘子（110千伏）；1912年发现电晕临界电压与导线直径成比例（铝线应用，美国154千伏）；1923年均压阀技术（220千伏）；1936年美国287千伏；1952年瑞典380千伏（首次采用分裂导线）；1956年苏联400千伏双回线路；1965年加拿大735千伏；1969年美国765千伏；1985年苏联1150千伏特高压（后降压至500千伏运行）
- 中国交流输电：1941年220千伏投运；1972年330千伏；1981年500千伏；2009年1000千伏交流特高压投运
- 直流输电重新受关注：1954年瑞典本土与哥特兰岛世界首个工业海底电缆工程（100千伏、96公里、汞弧阀）；1970年扩建50千伏1万千瓦晶闸管换流阀试验工程；1972年加拿大世界首个晶闸管换流阀背靠背直流工程；中国首个直流输电工程为舟山群岛与浙江定海电网连接；1989年葛上直流（葛洲坝电厂到上海，±500千伏）；2024年6月云广直流±800千伏特高压直流工程投运

**三相交流输电优势**：
1. 易于产生旋转磁场，三相电动机易做驱动
2. 瞬时功率恒定，不随时间变化
3. 输电线路导线量（金属消耗量）最少

三相三线制传输效率最高、金属消耗量最小，因此广泛应用；除室内配电等小功率供电采用单相交流外，其他场合基本采用三相交流；国内高压、超高压、特高压输电均采用三相交流，仅在联网时采用直流。

**电力系统的形成**：从单机向负荷供电（可靠性差）→ 并联发电机提高可靠性 → 输电线路电阻电抗导致电压和功率损耗 → 升压传输（加变压器）→ 形成电力系统雏形。

**电力系统定义**：发电机、变压器、输电线路和用电设备构成的整体，完成电能生产、输送、分配、消耗四个职能。

**电力网**：变压器和输电线路构成的网络，即电力系统去除发电机和用电设备的部分。

**动力系统**：电力系统加上发电厂动力部分（如火电厂的锅炉、汽机、煤炭输送处理系统；水电厂的水轮机、水坝、水库）。

**电网分类**：
- 地方电力网：向固定地方供电，电压等级110千伏及以下（早期35千伏及以下），供电半径20~50公里
- 区域电力网：电压等级110、220千伏及少量500千伏，供电半径超过50公里，联系较多发电厂和负荷中心
- 超高压远距离输送网络：电压等级500千伏或1000千伏（东北有330千伏），将发电厂电能送到负荷中心，构成跨省跨地区大型电力系统，如山西晋东南到湖北荆门的特高压线路（跨三省，连接华北和华中电网）

**变电站分类**：
- 按电压等级：以最高电压等级命名，如10千伏变电站（华工变电站）、220千伏变电站（关山变电站）、500千伏变电站（凤凰山变电站）
- 按功率流向：升压变电站（发电厂内，功率从低压侧流向高压侧）、降压变电站（大部分功率从高压侧流向低压侧）

# 课后任务与学习建议
教师推荐三本书供学生课后阅读（具体书名未提及），并建议作为电气专业学生应了解电力发展的基本发展史。教师强调第一章是重点内容，需掌握基本概念、电力系统特点及要求、电能质量指标、接地方式等；三个难点（电力系统特点引出的基本原理、额定电压规定、中性点接地方式）需重点学习。学习方法：注意概念内涵外延、从原理推导、寻找额定电压规律、比较接地方式特点。对电路理论和电机学知识有欠缺的同学，应补充相关内容，特别是变压器和同步电机知识。
