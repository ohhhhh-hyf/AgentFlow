# 发布会概况
王毅在慕尼黑安全会议上发表演讲并回答提问，阐述中国推动平等有序的世界多极化的主张，指出世界正走向多极化，中国必将是多极体系中的确定性因素，坚定做变革世界中的建设性力量。王毅提出4点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。关于乌克兰危机，王毅表示中方从危机爆发第2天起就提出对话协商解决，坚持劝和促谈，乐见一切和平努力。关于中美关系，王毅表示中方已准备好按照相互尊重、和平共处、合作共赢三原则同美方构建稳定健康可持续的双边关系，希望美方相向而行。整体基调坚定、务实，强调中国维护国际法治、践行多边主义、坚持开放共赢。

# 核心信息
- 王毅指出，世界更加变乱交织，慕安会报告主题为走向多极化；**80年前**联合国成立时只有**51个**会员国，今天有**193个**国家。
- 中国主张推动平等有序的世界多极化，这是习近平主席提出的重大主张；中国必将是多极体系中的确定性因素，坚定做变革世界中的建设性力量。
- 王毅提出4点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢；坚持权利平等、机会平等、规则平等应成为建设多极世界的基本原则。
- 中国加入了几乎所有普遍性的政府间国际组织和**600多项**国际公约，从不搞例外主义，更不搞合则用、不合则弃。
- 中国承担超过**20%**的联合国会费，切实履行`巴黎协定`，建成了世界上最大的清洁发电体系；提出并落实全球发展倡议、全球安全倡议、全球文明倡议。
- 去年中国GDP增长**5%**，对世界经济增长贡献率接近**30%**，担当全球经济增长的重要引擎；中国愿推动高质量共建`一带一路`，同欧盟`全球门户`战略相互对接。
- 今年是中欧建交**50周年**，中方愿同欧方深化战略沟通和互利合作。

# 官方表态
- **倡导平等相待**：王毅指出，列强争霸曾给人类带来灾难，两次世界大战殷鉴不远，不平等的秩序注定土崩瓦解；坚持权利平等、机会平等、规则平等应成为建设多极世界的基本原则。
- **尊重国际法治**：王毅强调，联合国宪章宗旨和原则是国际关系的根本遵循，也是建设多极世界的重要基石；多极格局不能是无序状态，大国要带头讲诚信、讲法治，坚决摒弃言行不一、零和博弈。
- **践行多边主义**：王毅表示，面对全球性挑战没有哪一个国家能够独善其身，搞本国优先只会造成各方的多输；联合国是践行多边主义、推进全球治理的核心平台，对于这座大厦应该固本强基，而不是拆梁毁柱。
- **坚持开放共赢**：王毅指出，发展是破解各种难题的钥匙，多极世界应该是各国共同发展的世界；保护主义不是出路，滥加关税没有赢家，脱钩断链断的是机遇，小院高墙封的是自己。
- **对国际秩序的表态**：王毅表示，中国是在现行国际秩序中发展起来的，是受益者，要推动秩序朝着更加公正合理的方向发展；应共同维护以联合国为核心的国际体系，遵守以联合国宪章宗旨和原则为基础的国际关系基本准则。
- **对欧洲的表态**：王毅表示，中方始终认为欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手；今年是中欧建交50周年，中方愿同欧方用好这一契机，深化战略沟通和互利合作。

# Q&A环节
**问**：周琦先生提问，您提到国际秩序，但有人质疑联合国宪章，包括俄罗斯入侵乌克兰、美国总统威胁使用武力等；您是否继续相信联合国和联合国宪章？是否推动联合国改革？
**答**：王毅表示，真正要挑战秩序、毁约退群的国家出现了，而中国是在现行国际秩序中发展起来的，是受益者，要推动秩序朝更加公正合理方向发展；应共同维护以联合国为核心的国际体系，遵守以联合国宪章宗旨和原则为基础的国际关系基本准则，这是最大的公约数，只要认同这一点，双重标准就不会出现。

**问**：周琦先生提问，您曾表示乌克兰的主权、独立和领土完整应得到尊重，现在俄罗斯已成为中国的加油站，您是否可能减少从俄罗斯购买油气、降低价格或停止双用途货物，以施压俄罗斯结束战争？
**答**：王毅表示，中国同俄罗斯是两大邻国，建立了结盟不对抗、不针对第三方的睦邻友好关系，交往是正常的国与国交往；如果中国不从俄罗斯买油气，没有哪个国家能提供如此巨量的油气满足中国民众需求，因为有的国家常把经贸问题政治化，当做打压中国的工具。中国主张一切争端和冲突都应通过对话寻求政治解决，从2022年2月25日危机爆发第2天起就提出对话协商解决；习近平主席提出4点主张：各国主权领土完整应得到尊重、联合国宪章应得到遵守、各国合理安全关切应得到重视、一切致力于和平的努力都应得到支持。中国派特使斡旋，同巴西等南方国家发起和平之友；中方乐见一切和平努力，包括美国同俄罗斯达成的共识，所有当事方包括利益攸关方应适时参与和谈进程，欧洲应发挥重要作用。

**问**：周琦先生提问，您如何看待中美关系未来发展？
**答**：王毅表示，中国对美政策保持连续性和稳定性，不会轻易翻烙饼；对美政策是习近平主席提出的三原则：相互尊重、和平共处、合作共赢。中方已准备好按照三原则同美方构建稳定健康可持续的双边关系，希望美方相向而行；如果美方仍要打压遏制中国，中方必将奉陪到底，坚决维护主权、国家尊严和正当发展权利，坚决回击美方的单边霸凌行径。
