# 复盘目标与结果概况
本次复盘会为2023年度总结与年终奖颁发会议，由老板主持，围绕年度经营数据、年终奖发放标准、部门与个人评价、颁奖及抽奖等环节展开。预期目标为总结全年发展状况、公布年终奖并激励员工。实际结果方面，公司全年总量提升，年终奖总额226,000元，成本支出390万元，利润率约24%或27%；最高到手工资（含年终奖）约20万，仅两三人，平均到手工资1万余元；干满一年员工从去年四五人增至12人。老板承认成本控制差是最大问题，根源在于管理上关心关注不够、不够雷厉风行，公司亏损100万元。会议对短视频、执行、商务三个部门逐一评价，对每位员工进行肯定并提出更高期待，颁发最佳新人、最佳进步、后期独挡一面、最佳员工、特别贡献五项奖项，最后以抽奖结束。

# 结果与关键成果
## 交付与里程碑

- **账号运营成果**：郭东辉负责的短视频账号在2023年实现多平台显著增长，视频号粉丝从3月1日的719人增至8万，小红书从2000+增至6.4万，抖音从2000+增至5.7万，B站从3.1万增至7.6万；涨粉转折点始于6月20日第一条外出拍摄的对话视频。
- **账号变现进度**：账号变现达到7.5分（满分10分），其中1分是期待空间；重点项目（变现）尚未完成，但已具备变现条件。
- **直播项目**：视频号直播4-5场，平均在线人数5000+，前100人平均在线时长50分钟以上；因暂无课程，尚未进行变现。
- **商务部门业绩**：商务部门实打实项目约300万元左右，基本达到预期；若计入入围项目则更多。

## 数据与指标

- **年终奖总额**：2023年年终奖转账总额为226,000元。
- **成本支出**：全年实打实支出390万元，包括人员工资、外援配音、字幕、租机器。
- **利润率**：约为24%或27%，老板评价为"非常不可观"。
- **员工收入**：最高工资（含年终奖）两三人达到20万以上；平均到手工资1万多元。
- **人工支出变化**：2023年平均人工支出相对提高，平时工资提高约25万；年终奖比去年多1312万多。
- **人员留存**：干满一年的员工从去年四五人增至今年12人。
- **公司盈亏**：公司总量提升，但结余到账往下跑，还有百来万没收回来；老板表示每个人会比去年少拿约10万，公司亏损100万。

## 制度与流程

- **年终奖发放标准**：入职两三个月或半年以内发红包，去年600-800元，今年约1000元；干满一年以一个月基本工资为基准，表现好会更高；超过一年主要考虑当年表现，不再过多考虑年限。
- **高额预算机制**：干得久且满意的员工有高预算，实际拿到两三万，预算可到大几万，但需给老板理由。
- **个人数额不公布**：年终奖个人数额不一一公布，以发到手为准。
- **奖项评选机制**：共6人5项奖，评选有竞争性，2选1或3选1；未获奖不代表能力不行，但证明不突出。
- **仪式感建设**：今年首次认真对待颁奖仪式，定制皮质证书（40元一本含设计费），另有洗手包（价值七八十元）等配套。

# 亮点事项
- **账号运营突破**：郭东辉负责的短视频账号在2023年实现大幅涨粉，视频号粉丝从700人增至8万，小红书从2000+增至6.4万，抖音从2000+增至5.7万，B站从3.1万增至7.6万，涨粉转折点始于6月20日第一条外出拍摄的对话视频；账号变现评分达7.5分（满分10分），直播在视频号播出4-5场，平均在线人数5000+。成功原因：郭东辉在潘老师多次提出放弃（累计10次提醒）的情况下坚持项目，并以破釜沉舟的决心说服潘老师尝试外出拍摄，同时外部公司挖角带来的压力也促成了这一转变。
- **员工评价与激励**：老板对每位员工逐一进行肯定性评价，并颁发5项奖项（最佳新人奖2人、最佳进步奖、后期独挡一面奖、最佳员工奖、特别贡献奖），评选过程经老板与政委认真讨论，奖项有竞争性（2选1或3选1）；老板表示2023年最有价值的事是招入张扬，其职业态度与工作能力基本达到期待。
- **仪式感建设**：今年首次认真对待颁奖仪式，定制皮质证书（40元/本，含设计费，老板亲自核对字体），并设置红包、洗手包（价值七八十元）等配套奖品；该举措源于去年李海腾及员工建议公司欠缺仪式感，老板今年予以落实。
- **后期团队整体进步**：林海腾指出今年后期整体强度比去年大、种类更多，但人员分级模糊化、效率整体接近，制作能力提升，高强度加班下仍能保证质量，体现职业操守；老板在年终奖中考虑加班补贴（约一两千元）。
- **商务部门成果**：商务部门实打实项目约300万元，基本达到预期；老板表示明年将给予更多支持与帮助。
- **员工主动性与跨部门协作**：郭东辉在多个平台运营中主动学习（每晚8-9点刷英语老师直播间研究内容与互动），并承担课程上架、开店等无经验工作；其「破壳」经验（找准一个点突破困境）被老板认可为员工给予老板信心的案例。

# 不足事项
- **成本控制差**：老板指出公司成本控制非常差是最大问题，2023年实打实花出去的钱（含人员工资、外援配音、字幕、租机器）达390万元，利润率仅约24%或27%，非常不可观；若今年没有增量、成本控制又是今年状况，就不会开这个会。根因被老板明确归为**老板的问题**——对业务关心或关注不够、不够雷厉风行，出现问题没有及时解决。
- **公司亏损与老板收入下降**：公司亏损100万元，老板表示每个人会比去年少拿约10万元左右；公司结余到账往下跑，还有百来万没收回来，实际到账是稍微缩水的。根因与成本控制差同源，老板承认管理上给予的支持、管理或关心不够，明年会反思这个问题。
- **账号尚未变现**：短视频账号虽在多个平台实现大幅涨粉（视频号从700涨至8万、小红书从2000+涨至6.4万、抖音从2000+涨至5.7万、B站从3.1万涨至7.6万），但**账号变现重点项目没有完成**，课程变现程度按满分10分计仅达7.5分，其中0.5分还是期待空间；直播虽已开4-5场、平均在线5000人以上，但因没有课程，尚不能进行变现。老板对短视频部门的明年期待即希望账号能开始变现。
- **人员不足导致加班严重**：老板承认加班是老板的锅，**本质上是没有及时招更合适或更合适人数的人员**——商务给活是连续信号，但业务有断续，给老板造成不需要招这么多人的错觉，同时平时积累的人脉资源又不确定，因此没有及时招合适人数，人员不够是加班最直观的因素，属老板判断失误。林海腾也反馈今年后半年基本都在加班，很少正常休息，劳累程度确实特别累。
- **外援成本高且内部人员无法替代**：钱德峰指出有一段时间请了很多天外援，但有些事公司自己人内部就可以搞定（如上午谁有空去按个机位、让机器不关机即可），这样的人公司都凑不出来；把拍摄这一截给外援与找拍摄外援两边价格差很多。老板回应拍摄性价比相对高，但确实没有安排开，期待明年大家都能参与拍摄，至少能应付得了。
- **拍摄人员被侵占时间多**：老板评价钱德峰时指出，从个人时间占用上来说，公司对其侵占是比较大的，后半年拍摄非常密集，甚至两个月连轴转、没有一天休息，回到公司很晚又要再开车去很远的地方。根因与人员不足、外援替代不足相关，老板期待明年尽可能少侵占大家休息时间。
- **商务部门支持不足**：老板评价张启时指出，商务这边其他人可能有些质疑，老板作为老板给商务的支持比较少，张启几乎没有什么项目，老板只是帮着聊了聊或帮着打理；老板承认明年会考虑给商务更多支持和帮助。
- **员工自我评价未达预期**：张启（发言者11）自述2023年对自己预期感觉没达到，可能是效率、时间方面的原因，另外项目上对同事的沟通和对甲方的沟通做得不太好，明年继续改进。
- **个别员工沟通吃力**：张文倩自述在法院项目上虽然做完了，但跟同学沟通上比较吃力，因为对方总是在踢皮球，不知道标准到底该怎么做；老板评价欧阳小元时也指出其沟通能力可能需要再爬坡会好一点。
- **拍摄参与意愿不足**：钱德峰反馈喊人参与拍摄时，很多人以没空、很忙、不想去为借口推脱；老板强调如果领导问到不能直接说没空，这是非常不职业的，起码应解释手头上忙的东西或勉为其难安排一下。

# 改进计划
- **针对成本控制差、利润率不可观（约24%或27%）**：老板表示成本控制是公司最大问题，明年开会时再讨论具体改进方案。
- **针对老板管理问题（关心关注不够、不够雷厉风行、问题未及时解决）**：老板承认这是成本问题的根源，明年会反思并改进管理方式，给予员工更多关心与关注。
- **针对账号尚未变现**：老板期待短视频账号明年开始变现，作为老板会投入更大精力，给予足够重视。
- **针对执行部门加班多、休息时间被侵占**：老板期待明年能更多进行组织协调，提高效率，尽可能少侵占大家休息时间；同时承认加班根源是人员不足，本质上是老板没有及时招合适或足够人数的人员，属于判断失误。
- **针对外援成本高、内部人员无法替代**：员工钱德峰建议公司内部人员可尝试参与简单拍摄（如按个机位、保证机器不关机），以降低外援成本并提升收入；老板回应称期待大家都能参与拍摄，明年会往这个方向推进，希望每个人都能参与。
- **针对商务部门支持不足**：老板表示张启（商务）几乎没有什么项目，老板给予的支持较少，后面会考虑给予更多支持和帮助。
- **针对拍摄人员被安排时直接说「没空」的不职业现象**：老板强调如果领导问到，应至少解释手头忙的事务或勉为其难安排，不能直接说没空。
- **针对后期人员加班补贴**：老板表示在年终奖基础上，会考虑对加班给予一两千元的补贴。
- **针对公司微信公众号未更新**：员工建议公司微信公众号可以更新，老板未明确回应。
