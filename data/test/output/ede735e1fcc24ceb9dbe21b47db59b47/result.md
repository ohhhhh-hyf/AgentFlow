# 发布会概况
2025年慕尼黑安全会议期间，中共中央政治局委员、外交部长王毅发表演讲并接受主持人提问，阐述中国对世界多极化的立场。王毅指出世界走向多极化是历史必然，中国主张推动平等有序的世界多极化，并提出四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。他强调中国是现行国际秩序的受益者和维护者，愿提供公共产品，并回应了关于国际秩序、乌克兰危机和中美关系等热点问题。整体基调坚定务实，展现中国作为多极体系中确定性因素和建设性力量的定位。

# 核心信息
王毅在慕尼黑安全会议上发表演讲，核心信息包括：世界走向多极化是历史必然，中国主张推动平等有序的世界多极化，并提出四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。关键数据：联合国成立时51个会员国，至今193个国家；中国承担超过**20%**的联合国会费；去年中国GDP增长**5%**，对世界经济增长贡献率接近**30%**；中国加入几乎所有普遍性政府间国际组织和**600多项**国际公约；中国建成世界上最大的清洁发电体系。王毅强调中国是现行国际秩序的受益者和维护者，愿提供公共产品，包括全球发展倡议、全球安全倡议、全球文明倡议。

# 官方表态
关于国际秩序与规则：王毅回应称中国是现行国际秩序的受益者，主张维护以联合国为核心的国际体系，遵守联合国宪章宗旨和原则，反对双重标准，推动秩序朝着更加公正合理的方向发展。关于乌克兰危机：王毅表示中国从俄罗斯购买油气是正常贸易，满足民众需求，不可能不买；中国主张通过对话政治解决，提出四点主张，派特使斡旋，发起和平之友，乐见一切致力于和平的努力。关于中美关系：王毅表示中国对美政策保持连续性和稳定性，遵循相互尊重、和平共处、合作共赢三原则，愿构建稳定健康可持续的双边关系，但若美方打压遏制，中方将奉陪到底。
