# 全文摘要
会议围绕生活中约定俗成规则（结婚、买房、工作）的合理性展开讨论，并延伸至理想工作形态、AI与机器人承担苦活累活、机器人拥有思想意识后的风险与反抗，以及相关影视作品和数码宝贝剧情，最后简短提及语音分离标注测试。会议未形成正式决策，整体为开放式脑暴讨论。核心分歧在于：发言人1认为买房、结婚等规则在经济好时可行、经济不好时不可行，工作可能合理但应干自己想做的；发言人2认为规则取决于遇到什么样的人，不能太绝对；发言人3认为必须工作合理，并主张让AI做苦活累活而非创作艺术。关于机器人思想意识，发言人2担忧其可能不受控制、罢工、反向控制人类，后果灾难性；发言人5认为机器人只需接受命令执行命令，不必有思想；发言人3认为智能和思想可能无法分开。

# 要点梳理
## 约定俗成规则的合理性
- **规则质疑**：发言人1提出买房、结婚等约定俗成规则不合理，经济好时可以，经济不好时不可以。
- **相对观点**：发言人2认为取决于遇到什么样的人，不能太绝对。
- **工作合理**：发言人3认为必须工作合理。
- **进修不定**：发言人2认为工作之后还要进修学习，说不准。
- **工作必要**：发言人1认为人不工作世界无法运转，工作可能合理，但应干自己想做的，不要与钱太挂钩。

## 理想工作形态
- **兴趣导向**：发言人1认为理想工作每天起来想干啥就干啥，参考自己兴趣干活。
- **不干活更好**：发言人4提出有没有可能不干活更好。
- **宠物博主**：发言人3举例宠物博主工作好，发宠物视频剪视频赚钱。
- **游戏高手**：发言人2提到游戏高手。
- **脏活累活**：发言人1指出总有脏活累活没人承担。

## AI与机器人承担苦活累活
- **AI分工**：发言人3认为应让AI做苦活累活，而不是创作艺术。
- **蔡明小品**：发言人2提到蔡明小品中机器人脑袋被敲后逆其道而行，煮了牛皮制品。
- **生产享受**：发言人1认为机器人负责生产、人负责享受挺好，但规则能否实现不确定。
- **控制风险**：发言人2担心AI普及后机器人有自己思维，若人类控制得当则好，否则可能革命。
- **阶级顾虑**：发言人1认为上层人不想让平民过太好，存在阶级。

## 机器人思想意识的风险
- **未来应用**：发言人5提到扫地机器人，未来可能有能打扫做饭的机器人。
- **反抗担忧**：发言人2提出机器人有思想意识后可能不受控制、罢工、反向控制人类，如终结者剧情。
- **电影结局**：发言人3提到斯皮尔伯格的人工智能电影结局。
- **执行命令**：发言人5认为机器人只需接受命令执行命令，不必有思想。
- **智能思想**：发言人3认为智能和思想可能无法分开。
- **思想影响**：发言人5担心思想带来不好影响，如执行指令时打人。
- **灾难后果**：发言人2认为机器人可能成为犯罪代理人、职业杀手、超级战士，罢工反抗后果灾难性。
- **军事应用**：发言人2提到军队单兵装甲外骨骼、智能枪械等半机械人状态。
- **排雷应用**：发言人3提到排雷机械狗和机械车已在使用。

## 影视作品中的机器人思想
- **游戏角色**：发言人2提到重返德军总部的超级战士。
- **数码宝贝**：发言人2提到数码宝贝中守卫兽和机械装甲兽升级为安多路兽，有独立思想意识。
- **作品归属**：发言人4询问数码宝贝第一部守卫兽和安多路兽是哪一部，发言人2说明第一部和第二部都有。
- **机械邪龙兽**：发言人2说明第二部最终boss机械邪龙兽是精密机械超级计算机形成生命体。
- **人脸识别**：发言人2提到安徒路兽在九几年就有人脸识别思想，第二部第七集被黑色魔轮控制后通过人脸识别判断人，主角嘉儿通过记忆唤醒。
