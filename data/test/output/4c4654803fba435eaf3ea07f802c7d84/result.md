# 发布会概况
王毅在慕尼黑安全会议上发表演讲并回答提问，阐述中国推动平等有序的世界多极化的主张，指出世界正走向多极化，联合国会员国从51个增至193个。中国将坚定做变革世界中的建设性力量，是多极体系中的确定性因素。演讲提出四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。王毅还回应了国际秩序、乌克兰危机、中美关系等提问，强调中国是现行国际秩序的受益者，主张通过对话政治解决争端，对美政策保持连续性和稳定性。整体基调坚定务实，展现中国作为负责任大国的国际担当。

# 核心信息
- **多极化趋势**：联合国会员国从**51个**增至**193个**，世界正走向多极化，中国主张推动平等有序的世界多极化，这是习近平主席提出的重大主张。
- **四点看法**：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢，作为建设多极世界的基本原则。
- **国际法治**：中国加入几乎所有普遍性政府间国际组织和**600多项**国际公约，从不搞例外主义，也不搞合则用、不合则弃。
- **联合国会费**：中国承担超过**20%**的联合国会费，坚定维护联合国的权威和地位。
- **清洁发电**：中国切实履行《巴黎协定》，建成世界上最大的清洁发电体系。
- **经济增长**：去年中国GDP增长**5%**，对世界经济增长贡献率接近**30%**，担当全球经济增长的重要引擎。
- **一带一路**：中国愿推动高质量共建“一带一路”，与欧盟“全球门户”战略相互对接。
- **全球倡议**：提出并落实全球发展倡议、全球安全倡议、全球文明倡议，为完善全球治理提供公共产品。

# 官方表态
- **多极化主张**：中国应当推动平等有序的世界多极化，这是习近平主席提出的又一个重大主张，也是我们对多极世界真诚的期许。
- **平等相待**：坚持权利平等、机会平等、规则平等，应当成为建设多极世界的基本原则；中国主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权。
- **国际法治**：联合国宪章宗旨和原则是处理国际关系的根本遵循，也是建设多极世界的重要基石；国家不论大小强弱，都是国际法治的利益攸关方。
- **多边主义**：联合国是践行多边主义、推进全球治理的核心平台，已经为各国遮风挡雨80年；未来的多极世界更加需要联合国，对于这座大厦，我们应该固本强基，而不是拆梁毁柱。
- **开放共赢**：发展是破解各种难题的钥匙，多极世界应该是各国共同发展的世界；保护主义不是出路，滥加关税没有赢家，脱钩断链断的是机遇，小院高墙封的是自己。
- **中欧关系**：中方始终认为欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手；今年是中欧建交50周年，中方愿同欧方深化战略沟通和互利合作。
- **人类命运共同体**：习近平主席提出共同构建人类命运共同体的重大理念，希望各国超越历史文化、社会制度、意识形态的不同，以同舟共济的精神共同呵护好这个唯一人类可以居住的星球。
- **对美政策**：中国的对美政策保持连续性和稳定性，不会轻易翻烙饼；对美政策就是习近平主席提出的三原则：相互尊重、和平共处、合作共赢。

# Q&A环节
**问**：主持人霍伊斯根提问，中国是否继续相信联合国和联合国宪章，是否推动联合国改革，联合国宪章在中国议程中的优先级有多高？
**答**：
- 中国是现行国际秩序的受益者，要推动这个秩序朝着更加公正合理的方向发展。
- 应共同维护以联合国为核心的国际体系，遵守以联合国宪章宗旨和原则为基础的国际关系基本准则，这是最大的公约数。
- 只要大家都认同这一点，双重标准就不会出现，没有它存在的空间。

**问**：主持人引用王毅此前关于尊重乌克兰主权和领土完整的表态，称俄罗斯已成为“中国的加油站”，询问中国是否可减少购买俄罗斯油气、降低价格或停止双用途货物以施压俄罗斯结束战争。
**答**：
- 中国同俄罗斯是两大邻国，建立了结盟不对抗、不针对第三方的睦邻友好关系，进而建立全面战略伙伴关系。
- 如果中国不从俄罗斯买油气，没有哪个国家能够提供如此巨量的油气来满足中国民众的需求，那是不可能的，也是不保险的。
- 中国主张一切争端和冲突都应通过对话寻求政治解决，武力和制裁不可能真正和彻底地解决问题。
- 从2022年2月25日起，中方就提出对话协商解决；习近平主席提出4点主张：各国主权领土完整应得到尊重、联合国宪章应得到遵守、各国合理安全关切应得到重视、一切致力于和平的努力都应得到支持。
- 中国派特使去各国斡旋，同巴西等南方国家发起“和平之友”。
- 中方乐见一切致力于和平的努力，包括美国同俄罗斯达成的共识；所有当事方和利益攸关方都应适时参与和谈，欧洲应发挥重要作用，共同探讨欧洲的长治久安和均衡有效可持续的安全框架。

**问**：主持人请王毅预告中美关系将如何发展。
**答**：
- 中国的对美政策保持连续性和稳定性，不会轻易翻烙饼，体现大国的战略定力和国际信誉。
- 对美政策是习近平主席提出的三原则：相互尊重、和平共处、合作共赢。
- 中方已准备好按三原则同美方构建稳定健康可持续的双边关系，希望美方相向而行。
- 如果美方仍要对中国打压和遏制，中国将奉陪到底，坚决维护国家主权、尊严和正当发展权利，坚决回击美方的单边和霸凌行径。
- 引用古语“天行健，君子以自强不息”“他强任他强，清风拂山岗；他横任他横，明月照大江”，表达对中美关系未来的信心。
