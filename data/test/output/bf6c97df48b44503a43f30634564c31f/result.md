# 访谈概述
本次对话由窦文涛主持，嘉宾为马先生（马未都）与《明朝那些事》作者当年明月，从刚播完的日本历史剧《大奥》切入，讨论日本文化精神与中日文化差异，并延伸至明朝历史与历史研究方法。马先生指出《大奥》前两部大致对应中国晚清到清初时段，后一部在明治维新之前，是一部有跨越性的历史剧；当年明月被该剧吸引的是日本人严谨的精神，称剧中每个演员都非常认真、有专业精神，第一集片头将军出场时所有人呈45度鞠躬、场面与色彩华丽，一看就不一样。所谓大奥即后宫，日本话中奥指很深的地方，即屋子最里处。讨论延伸至日本文化的极端精神、忠诚文化与终身雇佣制，以及明朝历史的跌宕起伏、朱元璋、正德皇帝、天启皇帝等人物与明朝灭亡原因，最后落到历史研究方法与经验教训。

# 访谈详细记录
一、日本历史剧《大奥》
- 该剧前两部大致对应中国晚清到清初时段，后一部在明治维新之前，是一部有跨越性的历史剧。
- 吸引当年明月的是日本人严谨的精神：回头看《三国演义》会看到很多群众演员笑，但看日本剧看不到笑的，每一个人都非常认真、特别有专业精神，都像大腕在演。
- 当年明月称第一集片头就把他震了：将军出场时所有人呈45度鞠躬，场面之华丽、色彩，一看就不一样。
- 马先生称大奥即普通话说的后宫，日本话的奥指很深的地方，即屋子最里处，如深奥、藏奥；翻译成后宫中国人一听就懂。
- 马先生称一个幕府将军是男人，跟1000个女人生活在大奥里，这1000个女人全是伺候这一个男人的。

二、日本文化精神与中日文化差异
- 当年明月称日本天皇一直是摆设，实际掌管权力的是幕府将军；德川家康开创德川幕府后，日本所有权力掌握在一个人手上。他举史实：德川家掌握政权后，天皇想举办活动但没钱，找将军要钱，将军不给，最后活动没办；后来还有为表示对幕府抗议而退位的。
- 当年明月称从《大奥》可以看出日本文化从头到尾没有变，其精神是极端精神，特点是把所有事情做到尽头。
- 马先生称日本战后用30年时间成为世界第二经济强国，是必然不是偶然，靠全民族的极端精神；日本是世界上强国里唯一没有资源的国家，是以绝对量而非人均量计。
- 当年明月称中国文化精神是中庸：讲究不是对也不是错、不是黑也不是白、不是真理也不是谬误，是太极，是一条最适合的路，叫融合；日本精神恰恰相反，坚持一个原则，如炮手忘记所有事情只记得把这一炮开出去，就达到最高境界。
- 马先生称日本是忠诚文化的典型国家，文化差异导致很多民族观念性冲突；他多次去过日本，在日本没有感受到很难过的时候，也没有谁对他非礼。
- 马先生称日本人的跳槽率是最高的，每一次跳槽都是社会资源的浪费；当年明月称西方经济学不能理解日本，经济学原理讲终身雇佣制会导致效率极低，但日本终身雇佣了效率还是特别高。
- 马先生称日本社会对聪明人、偷奸耍滑者抵制强烈，这种人没有生存环境；他举例日本做绳子做到全日本第一的人，长达几年不赚钱，从批发到送货一分钱不赚，把市场铺平后拿两张单子各加2%，全国东西4%就是不得了的数。
- 当年明月称慢慢来才是最快的方法，所有人按自己的角度做自己的事最节省成本，不会互相作用力抵消，形成合力就非常可怕。
- 马先生举例日本豆腐厂规定当天做当天卖，夜里11:45所有人做好不动手坐着看表，到12点整所有人赶紧开车，到4点多干完开始上市；当年明月称这叫一丝不苟。
- 当年明月称日本没有资源、什么都没有，还经常火山地震，人对世界有极强求生欲望，或对世界悲观、必须努力求生存，所以学会融入团体、按固定规则做事才能生存。
- 关于是否愿意做日本人：马先生称每个人在自己文化环境里愿意做，你做不成，你的文化不允许这种现象生存；当年明月称很不愿意，因为很多时候像盲从。
- 当年明月称日本人有寻死的那种潜在欲望，看樱花不看发芽、只看落那一天；因常年在岛国、生态环境恶劣，对死亡不是藐视而是有点向往或不惧怕，并称二战日军在中国有暴行是一种藐视生命。马先生认为日本民族不是藐视生命，而是重视，是翻着的。

三、明朝历史与《明朝那些事》
- 当年明月称写明史是因为明史他最熟，明史资料最多；历史界研究有两个难点，第一是先秦，第二是明清。明清没法说，因为一个说法可能有七个不同，一个事件可能有七个不同说法，像罗生门。
- 马先生称明朝本身260多年的过程跌宕起伏，几次都要死没死，土木之变、夺门之变等各种之变特别多，皇上被瓦剌军抓起来、把弟弟扶起来这类事完全构成现代版电视剧。
- 当年明月称推崇朱元璋，因为他太不容易：一个乞丐，历史上由最底层的人坐在皇位上独此一个，刘邦好歹是个村长；朱元璋要过饭，知道每一层的猫腻，所以疑心重；他从一起干到最后推翻元朝当上皇帝，定下明朝规章制度，基本上没有太大改动。
- 马先生认为人的因素最大，改变时势一定是出现一个人，是英雄史观。
- 当年明月以《亮剑》李云龙为例，称会打仗的人不用看兵书，是在战场上死死生生多少年积累经验。
- 关于朱元璋参加起义：当年明月称历史最重要的是明白它是发生过的，这事是真的，不是好玩；他掉脑袋的，非常有风险。马先生称站在历史原点前后都看不见，必须撤出来才能看见。
- 马先生称明朝有仁宣盛世，现在不怎么提因为时间太短；晚明尽管史书说政治黑暗、皇帝不上朝，但老百姓生活很好，有文徵明、《金瓶梅》，市民生活特别轻松，想去哪去哪，连皇册都不用了，江浙一带兴起工商业，给人当雇工活得很滋润，三言二拍这类市民小说出现说明有能养活自己的资本。
- 当年明月称李自成那时闹起义，是因为陕西那一带发生了大规模灾荒。
- 马先生称明末工艺品变得非常精细，有点像日本工艺，日本派了大量工匠跟中国交流；吴门画派如文征明、唐寅都是那个时期的，生活不好画不出小桥流水、风雨归舟图那种充满欣赏感觉的画；到八大山人朱耷时画翻白眼，是对社会愤愤不平。
- 当年明月称从历史中得到的唯一教训就是我们从来没有从历史中得到过教训；历史记载下来是照片，实际生活是录像，不知道那一幕之前和之后是什么，不能套用经验教训。
- 当年明月称明代什么都有：宦官专政魏忠贤、文官专政张居正、皇帝专政朱元璋，皇帝出去了还能回来、回来了还能做皇帝。
- 关于晚明：当年明月称吴三桂跟满清合作入关，除陈圆圆外还有个原因，他认为崇祯死了，当时说法是入关为崇祯皇帝复仇；崇祯皇帝可以不死，早点跑应该不跑。
- 当年明月称1644年明朝灭亡那年，有史料记载北京老瘟疫叫疙瘩瘟，今天看就是天花，很可能；他曾跟老师交流说明朝亡得蹊跷，什么坏事都赶上了。
- 马先生称中国历史王朝300年都是大限，一逼近300年自己就没了，和人到八九十岁大限快到了一样；严格讲超过300年大限的只有宋朝，南北宋接上，退让了大半个国土保证延续300年，汉朝中间隔断14年是彻底空的，唐明清都没有。
- 当年明月称今天数世界上公司超过279年的没有几家，明朝摊子几千万人。

四、明代审美与家具
- 马先生称中国在宋明这两个朝代是典型的汉人政权、文人政权，文人欣赏的审美比较高，对美的判断不是表象的；满族是异族，进来后对美的判断都是表象的。
- 马先生称今天凡是那种非常外在、直观能看到的都卖得非常贵，但100年前晚清到民国初年，值钱的一定是素雅的。
- 马先生称天启皇帝爱当木匠，干完活拆大盆去卖，卖完回来打听卖得怎么样，听说卖得很好就成就感特大；这从侧面反映当时社会的一种时尚，明式家具现在在国际上地位那么高绝不是偶然，所有偶然中一定有个必然因素。
- 当年明月称明代皇帝本身确实没什么事干，明神宗几十年不上朝，但不出去。
- 关于正德皇帝：当年明月称帮他翻案，明朝皇帝一般后人不会说自己朝代皇帝多差，正德被写得特别差是因为接班的是嘉靖，嘉靖不是他儿子而是堂兄弟，拐了个弯，不能把他写得太好；明武宗实录是嘉靖指派杨廷和等人编的，有偏颇，嘉靖上台搞大礼仪事件，为把父亲追封为皇帝折腾了很多人。
- 当年明月称正德皇帝绝不是史料所写的那么蠢，他从江南回来没有进京城，在通州先停了半年，先派人打探京城里有没有人想搞埋伏、搞圈套，非常有城府。
- 马先生称正德皇帝有定论说明朝最荒淫，清朝最荒淫的是咸丰，咸丰还留了个种，正德不留种，这事很奇怪；他对后宫女人没兴趣，因为那些女人被训练过、禁忌多、太保守，而民女不知他是谁，乔装改扮出去就不一样。
- 当年明月称正德皇帝据说去过江南，但没有具体史料能够证实，史官不能记皇上出去嫖娼。
- 当年明月称明武宗要去江南，不让去，跪金水桥前门全部跪着抗议，后来气坏了到锦衣卫去打，打死了十几个。
- 马先生称明朝有些史官把冒死跟皇帝说难听的话、让皇帝砍头当成时尚，为的是青史留名；他称这种文化的力量超出我们想象。
- 当年明月称正德到扬州要东西，说没有、有也不给，他就说回去，还让人准备酒席，说吃不了，把酒席折合银两带回去，打秋风。

五、历史研究方法与经验教训
- 当年明月称历史最重要的是明白它是发生过的，这事是真的；很多人看历史觉得故事好玩，但旁观者觉得好玩，当事人是掉脑袋的。
- 当年明月称从历史中得到的唯一教训就是我们从来没有从历史中得到过教训；历史记载下来是照片，实际生活是录像，不知道前因后果，不能套用经验教训。
- 当年明月称不能以现代人的聪明去评判古人，你不比前人聪明，甚至可能比前人笨，那种情况出现时你也得这么办。
- 马先生称站在历史原点前后都看不见，必须撤出来才能看见，但谁都不能站这么高俯视历史。
