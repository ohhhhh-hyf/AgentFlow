# 就诊概况
48岁男性患者张学恒，因上腹心窝处反复烧灼样疼痛4年、近3个月加重，就诊于消化专科门诊，由严医生接诊。患者疼痛与进食冷硬食物、工作紧张劳累相关，刺激性食物可诱发，曾两次出现黑便，近两个月有呕吐。初步考虑消化系统疾病，需排查消化道出血及恶性病变可能。医生建议留取大便标本检查，并预约后天行胃镜检查，待检查结果全面后向上级张医生汇报，再商定治疗方案。

# 诊断与检查结果
本次门诊未进行新的检查，医生通过详细病史采集作出初步判断。患者上腹疼痛呈烧灼样，与进食冷硬食物、工作紧张劳累相关，刺激性食物可诱发，近3个月存在完全不痛时段；曾于一年前和三个月前两次出现黑便，均住院检查确诊为大便出血，住院两三天后大便转黄；近两个月呕吐数次，吐出黄水样酸味物，为当日早午餐食物，吐后舒适，无呕血。近三个月无黑便，大便黄色正常，小便正常。既往16岁患甲肝，在三医院住院一个月，出院时肝功能正常，此后体检肝功均正常；对磺胺药过敏。家族中婶婶（叔叔的爱人）患胃癌，但医生解释无血缘关系。

# 治疗方案与医嘱
患者近期自行服药情况：最初服用某药（可能为“达喜”类）有效，后效果变差，加量至每日4-5次仍不佳；近期加用奥美拉唑（国产，武汉药厂）和阿莫西林，以及单位医务室自配胃炎合剂，效果短暂，停药后复发。医生建议患者戒烟、少饮酒，因工作紧张、经常熬夜可能影响病情，需注意休息。具体用药方案待检查结果明确后由上级张医生确定。
