# 锵锵三人行：从《大奥》到明史的文化对谈

## 访谈概述
本期《锵锵三人行》由主持人发言者1与嘉宾发言者2（《明朝那些事儿》作者）、发言者3、发言者4围绕日剧《大奥》与明史展开文化对谈。上半场从《大奥》切入，讨论日本文化中的极端精神、忠诚文化与中日文化差异；下半场转向《明朝那些事儿》与明史，探讨明史魅力、朱元璋评价、明朝兴亡经验教训及明式家具审美，最后以历史认知的局限性作结。受访者核心观点：其一，日本文化精神是极端精神，所有事情做到尽头，与中国的中庸文化形成鲜明对比；其二，明史资料最多但一个事件可能有7个不同说法，如同罗生门；其三，历史是照片、生活是录像，不能简单套用历史经验。访谈看点在于发言者2提出正德皇帝被写坏是因明武宗实录由嘉靖指派杨廷和等人编纂、存在偏颇，以及发言者3指出日本战后用30年成为世界第二经济强国（绝对量）是唯一没有资源的强国。

## 访谈详细记录
### 日剧《大奥》与日本文化

1. **《大奥》历史背景**：发言者3指出该剧三部曲中前两部对应中国晚明到清初时段，第三部在明治维新之前；发言者2补充这是有跨越性的历史剧。发言者1认为剧中日本礼仪令人欣赏，如和服小碎步、尊贵人物到来时两旁伏地行礼。
2. **大奥含义**：发言者3解释大奥即普通话的「后宫」，日语「奥」指屋子最深处，如「堂奥」「深奥」保留此痕迹；发言者2补充另一层意思是一般人不准进去。
3. **幕府与天皇关系**：发言者2讲述德川家康开创德川幕府后权力掌握在幕府将军手中，天皇是摆设；曾有一段天皇想办活动没钱，找将军要钱被拒，最后活动没办，天皇为抗议还退位。发言者1对比明朝皇帝为抗议大臣不上朝，发言者2指出不同在于明朝大臣仍听皇帝的，而日本天皇没有权力。
4. **日本极端精神**：发言者2认为《大奥》体现日本人「所有事情要做到尽头」的极端精神；发言者3补充战后日本用30年成为世界第二经济强国（绝对量），是唯一没有资源的强国，这不是偶然而是全民族极端精神的必然。
5. **豆腐厂案例**：发言者3讲述参观日本最底层豆腐厂，规定当天做当天卖，夜里11:45所有人坐好不动看着表，12点整同时站起来开始干活，到四点多干完上市，没人闲聊胡侃。
6. **岛国生存环境与民族性格**：发言者2分析日本是无资源岛国、多火山地震，跑都没地方跑，人本身有极强求生欲望，对世界悲观，必须融入团体按固定规则做事才能生存；发言者3认为日本投机取巧的人没有生存环境，社会文化鄙视使其无法生存。
7. **忠诚文化**：发言者3指出日本是忠诚文化的典型国度，靠具体事例而非说教体现；《大奥》中阿福25岁入宫当奶妈、65岁去世，40年无论做什么事不出于私心，所有人最终都认为他是楷模。
8. **中日文化对比**：发言者2以马先生家具店一块硬木刻云彩为例，称中国讲究中庸、融合，是「最适合的路」；日本精神恰相反，坚持一个原则做到极致，如炮手开炮忘记一切只记得把炮开出去即达最高境界。
9. **终身雇佣制**：发言者2指出日本跳槽率最低，西方经济学家不理解终身雇佣制缺乏竞争为何效率不降反高；发言者3认为每次跳槽都是社会资源浪费。
10. **日本人对死亡的态度**：发言者2认为日本人有寻死的潜在欲望，看樱花只看落的那天，对死亡不惧怕甚至有点向往，二战暴行是藐视生命的行为；发言者3不同意，认为日本民族不是藐视生命而是重视死亡，经济危机时很多身家万贯的人剖腹自杀。

### 《明朝那些事儿》与明史魅力

1. **《明朝那些事儿》热销**：发言者3指出该书发行量在排行榜第一，各报文学类都是第一；发言者1评价「写得好、写得放松」，发言者3认为过去写书的人都拘着，怕哪块不合适，其实广大读者了解历史大概是怎么回事就行了。
2. **为何写明朝**：发言者2解释别人问为何不写中国24史，他诚实回答「明史是我最熟」，因为明史资料最多；先秦没史料，史记就一两篇，孙武事迹都是编的；明清史料堆得比山还高，但一个事件可能有7个不同说法，如同黑泽明电影《罗生门》。
3. **明朝历史跌宕起伏**：发言者3指出明朝260多年过程本身跌宕起伏，几次要死没死，如土木堡之变、夺门之变，皇上被瓦剌军抓了，哥几个把弟弟扶起来，构成现代版电视剧才有的离奇情节。
4. **推崇朱元璋**：发言者2认为朱元璋从乞丐当上皇帝是历史上独一份，刘邦好歹是亭长；他定下明朝规章制度，基本没有太大改动，是了不起的人才。发言者3补充朱元璋要过饭，知道每一层的猫腻所以疑心重，但全知道的人太少见了。
5. **英雄史观**：发言者3认为人的因素最大，改变时势一定是出现一个人；发言者2以《亮剑》李云龙为例，没上过军事院校能打仗，是战场上积累经验的天赋。
6. **朱元璋起义的逼上梁山**：发言者1提到书中写朱元璋好友汤和让他参加起义军，他在庙里犹豫怕被杀头，后因信差送信被人听到告发，没办法才去起义；发言者2强调历史最重要的是弄明白这事是真的，旁观者觉得好玩，但当年那是造反，是要掉脑袋的风险。

### 明朝兴亡与经验教训

1. **明朝的兴盛时期**：发言者3提到仁宣盛世，以及晚明时期尽管史书说政治黑暗、皇帝不上朝，但老百姓生活很好；发言者2补充明末很多真相被掩盖，市民生活特别轻松舒服，想去哪去哪，皇册都不用了，江浙一带兴起工商业，给人当雇工活得很滋润。
2. **娱乐产品与生活富足**：发言者2指出三言二拍这类通俗小说出现是娱乐产品，说明有养活自己的资本；发言者3举例明末瓷器工艺彻底改观、变得精细，日本派大量工匠来交流学习，文征明、唐寅、董其昌都是那个时期的人，生活不好画不出小桥流水，八大山人明末画的都是翻白眼。
3. **李自成起义原因**：发言者2指出李自成闹起义是因为陕西一带发生大规模灾荒。
4. **历史经验教训**：发言者2引用名言「我们从历史中得到的唯一教训就是我们从来没有从历史中得到过教训」，解释历史事件发生时有背景，你不比前人聪明甚至可能比前人笨，那种情况出现时你也得那么办；比喻史书记载下来的是照片，古人的生活是录像，你不知道那一幕之前和之后是什么，所以千万不能套用经验。
5. **明朝灭亡的蹊跷**：发言者2讲述吴三桂与满清合作入关，除陈圆圆外还因崇祯皇帝死了，当时说法是入关为崇祯复仇；1644年李自成军打到京城无人抵抗，因北京闹瘟疫叫疙瘩瘟（即天花）；他与老师王佩奇先生交流，认为明朝亡得真蹊跷，什么坏事衰事都赶上了。
6. **王朝三百年大限**：发言者3指出中国历史王朝300年是大限，逼近300年就完了，跨过300年的只有宋朝（南北宋接上，退让大半个国土延续319年），汉朝中间隔断14年，唐朝明朝清朝都没跨过；发言者2比喻公司成立200多年够本了，明朝做公司摊子几千万人。

### 明朝皇帝与明式家具

1. **明清审美差异**：发言者3解释宋明是典型汉人政权、文人政权，审美素雅不表象；满族是异族，对美的判断都是表象的，大红大紫；今天凡是外在美直观能看到的都卖得贵，但晚清到民国初年收藏中素雅的东西才值钱。
2. **明武宗正德**：发言者2讲述正德皇帝要去江南，大臣全跪金水桥前抗议，他气坏了到锦衣卫打死了十几人还是不让去；到扬州要东西，政府说没有，他不生气说那就回去，还让人准备酒席，吃不了折合成银两带回去。发言者3认为正德是明朝皇帝中最特殊的行为、最鬼怪的个性，过去评价太低，说他荒淫，豹房是他弄的。
3. **正德被写坏的缘由**：发言者2指出接正德班的是嘉靖，不是他亲生儿子而是堂兄弟，所以不能把他写得太好；明武宗实录是嘉靖指派杨廷和等人编的，有偏颇；嘉靖上台搞大礼仪事件，为给自己父亲（王爷）争名分追封皇帝，死了很多人。
4. **正德的城府**：发言者2举例正德从江南回来没进京城，在通州先停半天，派人打探京城里有没有人搞埋伏圈套，说明此人绝不是史料所写的那么蠢。
5. **天启皇帝当木匠**：发言者3讲述天启皇帝干完活差大臣去卖，回来还打听卖得怎么样，卖得很好成就感特大；这从侧面反映当时社会时尚，家具在每个人心目中地位高，明式家具在国际上地位高绝不是偶然。
6. **正德生育问题**：发言者3指出正德是明朝最荒淫的皇帝，没少找女人但不留种，没有生育能力；发言者4补充没有正宗的传下来，到嘉靖这就拐弯了。发言者3分析正德对宫廷外女人有兴趣、宫廷内没兴趣，因宫廷女人禁忌太多太保守；发言者4补充民女不知他是谁，所以不一样。发言者2指出正德去过民间没有具体史料证实，史官没法记「皇上今天出去嫖娼」。
