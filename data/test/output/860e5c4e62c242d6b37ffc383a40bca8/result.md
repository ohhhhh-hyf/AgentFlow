# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷二审案，由最高人民法院组成合议庭公开开庭审理。庭审围绕动产抵押权与融资租赁所有权冲突、罚息复利计算、违约金连带责任三个争议焦点展开调查与辩论，各方充分发表意见后，合议庭在查明事实、分清是非的基础上提出调解方案，各方无异议并签署调解协议，法院出具调解书。

# 举证与法庭调查
## 举证与质证
- **国开行提交证据**：2018年6月13日向东源煤电、东源煤业发送的偿还贷款本金函件，证明其已宣布贷款提前到期，罚息应自2018年6月13日起算。东源公司质证认为，该函件未给合理期限，不符合合同约定。
- **国开行提交证据**：2018年9月融资租赁查询证书（第五组证据第一项），证明其已尽查询义务。招银租赁质证认为，该查询证书不符合2014年93号文规定，国开行在抵押时点未进行相应查询。
- **国开行提交证据**：工商部门出资证明、四冶合成58亿材料、人民银行出具的相关情况，证明其对设备所有权已尽审慎审查义务。招银租赁质证认为，工商登记公示的是出资行为而非动产所有权，东源煤电出资行为系无权处分。
- **国开行提交证据**：2018年对曲靖电力公司名下融资租赁情况的核查表（证据108页），证明核查时无融资租赁登记。招银租赁质证认为，该核查表不符合要求。
- **招银租赁提交证据**：回租设备清单（一审证据7页），载明设备名称、生产厂家，但未载明型号。国开行质证认为，该清单无法证明设备唯一性，且铭牌生产日期均在2013年以后，与清单提示的2012年3月1日不符。
- **招银租赁提交证据**：2013年、2015年审计报告（证据82页、95页），载明曲靖电力公司注册资本4亿元且已实缴。国开行质证认为，该报告已载明设备出资事项，招银租赁应当知道设备出资情况。
- **东源公司提交证据**：2015年12月2日邮件及融资情况统计表，证明其已告知国开行设备抵押情况。国开行质证认为，邮件正文及附表均未提及融资租赁情形，统计表中招银租赁一栏记载的抵押类型为不动产抵押，与融资租赁概念不同，无法得出已告知的结论。

## 证人、鉴定与其他来源陈述
- **评估报告**：评估报告明确曲靖电力公司拥有的在建工程价值5.7亿元，机械设备价值5.1亿元。国开行代理人引用该报告主张设备资产存在。
- **审计报告**：招银租赁一审提交的2013年、2015年审计报告（证据82页、95页）载明曲靖电力公司注册资本4亿元且已实缴。

## 法官询问
- **审判员询问**：央行融资租赁登记查询方式能否保证查询到登记结果？国开行代理人答：目前只能通过查询单位名称方式查询；招银租赁代理人答：可通过公司名称或设备情况两种方式查询，但设备查询涉及种类物区分问题。
- **审判员询问**：国开行贷款前审查中，内部是否有规定必须查询融资租赁登记，未查到需将未查到单子作为风控材料？国开行代理人答：办理动产抵押时需筛查系统，但因无查询结果，未保留筛查记录。
- **审判员询问**：国开行认为查询了电力公司登记信息，未查到设备融资租赁登记结果，以此免责的逻辑？国开行代理人答：作为金融机构按央行规定查询融资租赁系统，因设备为通用设备无法逐一查询，且查询曲靖电力公司无融资租赁记录，至今仍无记录，故无过失。
- **审判员询问**：融资租赁登记系统中设备唯一标识码是否必填项？招银租赁代理人答：不是必填项，因设备不像汽车有发动机号，无法唯一标识。
- **审判员询问**：查询通知规定银行业办理抵押前需查询，违反规范会导致什么后果？国开行代理人答：这是基本查询义务，根据最高法融资租赁司法解释第九条第三款，金融机构取得善意权利应查询融资租赁情况。
- **审判员询问**：若通过其他渠道知道抵押设备存在租赁，是否仍需查询？招银租赁代理人答：仍需通过央行系统查询，因其他方式无法证明，只有央行系统是确定标准。
- **审判员询问**：如何看待因不同登记机构产生登记瑕疵？国开行代理人答：人民银行融资租赁登记系统与动产抵押登记系统相互隔离、信息不流畅，导致多重抵押风险；招银租赁代理人答：规范不统一、登记机构不统一导致信息不对称，应从立法层面统一要求。

## 争议焦点与辩论
- **争议焦点一：动产抵押权与融资租赁所有权冲突**
  - **国开行主张**：其抵押登记针对曲靖电力公司设备，与招银租赁设备不同；已尽审慎审查义务，构成善意取得；融资租赁登记属行业强制规范，非法定登记。
  - **招银租赁主张**：国开行未在抵押时查询融资租赁登记，不构成善意；东源煤电出资行为系无权处分；招银租赁2012年即取得设备所有权。
  - **东源公司主张**：2015年12月2日邮件已告知设备抵押情况，国开行作为专业金融机构应尽注意义务。
  - **国开行主张**：利息计算至2017年12月20日，罚息自2018年6月13日起算，复利按合同第六条第四款约定计算。
  - **东源公司主张**：罚息不应作为复利计算基数，依据人民币利率管理规定第21条及最高法判例；提前到期通知未给合理期限，不符合合同约定。
  - **国开行主张**：依据合同第24条第三项，东源煤电违约应支付千分之一违约金；东源煤电未按合同第13条、第14条配合办理账户管理及柜台签约手续，构成违约。
  - **东源公司主张**：国开行未举证东源煤电违反柜台协议；未发出限期纠正通知，不符合合同约定。

# 庭审结果
- **争议焦点一**：动产抵押权与融资租赁所有权冲突。国开行主张其抵押登记针对曲靖电力公司设备，与招银租赁设备不同，且已尽审慎义务，构成善意取得；招银租赁认为国开行未在抵押时查询融资租赁登记，不构成善意。
- **争议焦点二**：罚息、复息计算。国开行主张利息计算至2017年12月20日，罚息自2018年6月13日起算，复利按合同约定计算；东源公司认为罚息不应作为复利计算基数，且提前到期通知未给合理期限。
- **争议焦点三**：违约金连带责任。国开行主张东源煤电违约应支付千分之一违约金；东源公司认为国开行未举证违约事实，且未发出限期纠正通知。
- **调解结果**：经本院主持调解，各方当事人自愿达成调解协议，法院予以确认并出具调解书。
  - 确认国开行对93项设备有抵押权，招银租赁对6项设备有所有权。
  - 国开行债权扣除破产中已清偿本金后，利息、罚息、复利合计6474.4513万元。
  - 招银租赁对6项设备享有所有权，对应债权1377.4137万元。
  - 设备整体盘活处置，变现款双方各50%，费用各担50%。
  - 若变现不足，招银租赁债权按破产重整计划预留方案实现。
  - 各方对一审判决第二项、第四项无争议。
  - 一审诉讼费中国开行诉请部分按一审判决执行，招银租赁诉请部分由二审法院按规定确定，二审诉讼费由本院依法确定。
