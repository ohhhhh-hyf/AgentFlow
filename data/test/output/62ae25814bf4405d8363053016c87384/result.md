# 访谈概述
本次访谈围绕作家余华的写作历程、创作状态与面对批评和网络关注的心态展开。余华将自学游泳分为1.0家门口池塘、2.0江河、3.0大海，对应文学创作三个阶段：第一阶段逼自己坐下来写，让屁股和椅子建立友谊；第二阶段受卡夫卡启发，写内心动荡不安的人物；第三阶段受威廉·福克纳启发，用视觉描写替代心理描写，如《狂人日记》中赵家的狗看人一眼。3.0之后没再升级，他认为《活着》可能是4.0版但已不是难题，3.0版本已经是大海，够了。他自述最好的写作状态在40多岁到50多岁，即《兄弟》到《第七天》期间，但那段最好时间被浪费，只出了两部作品；2006年开始写的一部长篇小说，现在身体状态可能还能维持激烈，但那个时代的感觉没了，80、90年代的感觉在远去，很难找回来，他估计能好好写作的时间可能只剩十年左右。他回应《第七天》出来时有教授说他变得仁慈了，说自己活着也蛮仁慈，作品几乎都是悲剧，这次回来选择写一篇喜剧，想先把一个喜剧写完，改变读者对他悲观的印象。面对批评，他形成的方式是：第一不要去看，第二有些批评要重视；他在互联网火起来后有一年停了一年，任何活动、采访都不做，称为一年冷静期，但自媒体时代会把几十年前的事情和以前说过的话翻出来，互联网上关于他的话有一半不是他说的。被问及希望以什么姿态留在历史长河，他回答“遗忘的姿态”，假如历史长河里有主题，主题就是一个世界、一个一个人。

# 访谈详细记录
一、自学游泳与文学创作的三阶段
- 余华将自学游泳分为1.0家门口池塘、2.0江河、3.0大海，对应文学创作三个阶段。
- 第一阶段：逼着自己坐下来写，“让屁股和椅子建立友谊”，这是年轻时候最重要的；如果离开写字桌躺到床上幻想作品多牛逼，可能就不会去写它。
- 第二阶段：受卡夫卡启发，写内心动荡不安的人物；写一个人物内心平静没有意思，内心动荡不安的话写1万个字。
- 第三阶段：受威廉·福克纳启发，福克纳写一个穷白人把一个富白人杀了之后的内心状态，采用“让心脏停止跳动，让眼睛睁开”，心理描写没有心理，是视觉描写；如《狂人日记》中赵家的狗看人一眼，就知道这个人精神状态。余华去过精神病医院，认为精神病人说话逻辑是清晰的，只是方向不同。
- 3.0版本之后没再升级，他认为《活着》可能是4.0版，但对他来说已不是难题，写作已经很成熟；写一个没什么文化的农民讲述自己的故事，要用最朴素的语言。他认为3.0版本已经是大海，够了。

二、写作状态与身体、感觉的流失
- 余华认为最好的写作状态在40多岁到50多岁，即《兄弟》到《第七天》期间，但那段最好时间被浪费，只出了两部作品。
- 2006年开始写的一部长篇小说，时间跨度与《兄弟》一样，从个人角度出发，想用接近陀思妥耶夫斯基的激烈方式写；现在身体状态可能还能维持这种激烈，但那个时代的感觉没了，80、90年代的感觉在远去，很难找回来。
- 他估计能好好写作的时间可能只剩十年左右。
- 他提到《十八岁出门远行》一天就写完，有6000字，对写字较慢的他来说是奇迹。

三、《兄弟》的创作与时代变化
- 《兄弟》1996年动笔，当时中国社会变化复杂；2003、2004年重新拿回来写时，庆幸1996年没写完，因为从2004年看，1996年的变化不算什么，那才是真正大的变化。

四、作品出版间隔与下一步计划
- 从《在细雨中呼喊》到《兄弟》隔了十年，《兄弟》到《第七天》隔了八年，《第七天》到《文城》又隔了八年。
- 余华希望快一点，已把这边整理完，开学时要去和学生们见一下，学校还有一些事情要处理，完了以后回三亚继续往前，安安静静把感觉找回来。
- 被问下一步长篇是否在2029年，余华未明确确认。

五、童年看海与人生感受
- 余华童年第一次看到大海，感受到人生是宽广的。
- 小时候每年夏天在海盐游泳，有一次进入海流，不能挣扎只能跟着海流走，一直漂到40里外才爬上来，赤脚沿海边走回来，天快亮了。海流把他带回海岸线，没有带到太平洋。
- 在三亚看到童年星空，发现月光是金色的，不是银色的。

六、《第七天》的仁慈与悲剧/喜剧转向
- 有教授说《第七天》出来时余华变得仁慈了。余华回应自己活着也蛮仁慈，作品几乎都是悲剧，这次回来选择写一篇喜剧，想先把一个喜剧写完，改变读者对他悲观的印象。
- 已确认：余华决定先完成一部喜剧作品。

七、追求宽度而非高度
- 余华表示对高度已经不追求了，现在追求宽度。认为作为作家，写作能走到的高度已经是现在的高度，允许自己下滑一下但不要下滑太多。
- 年纪大了，知道自己的能力、长处和还有多少潜力，不再像年轻时充满野心。

八、文学理想与马尔克斯的影响
- 余华认为这一代中国作家很大程度上被马尔克斯误导，都想在一本书里写一个世纪的故事，但其实没有必要。
- 托尔斯泰、狄更斯、莎士比亚、巴尔扎克、福楼拜、司汤达、契诃夫等都没有这样做。马尔克斯写拉丁美洲最混乱的世界所以能写出来，别人不一定写得出来。
- 余华现在知道自己要什么，就是把所处的时代通过更多方式表现出来。

九、莫言与莎士比亚故居之行
- 余华说莫言小说对话精彩，想写话剧，20多年前就开始写话剧，但写了没拿出来。
- 余华、苏童、莫言三人一起去莎士比亚故居，莫言在雕塑前发誓要成为剧作家，余华认为那是瞎扯，莫言当时在挑帽子，帽子钱还是余华付的，三人买了三顶一模一样的深蓝色帽子，上面有莎士比亚名字，后来找不着了。

十、面对批评与网络时代的心态
- 《兄弟》出版时余华以为会是一片赞扬，结果一片骂声，他接受很多采访努力解释。
- 《第七天》出来时只接收一个采访，告诉朋友们做好思想准备，果然一片骂声。《文城》出来时骂声还有但少一点。
- 余华找到对待批评的方式：第一不要去看，第二有些批评要重视。批评宋凡平写得太完美没有道理，因为宋凡平不是贯穿全书的人物；但批评《第七天》中社会底层人未必都善良，这句话很好，以后写小人物会考虑进去。
- 已确认：余华形成对待批评的方式，有道理的批评会在以后作品中考虑。

十一、网络热度与一年冷静期
- 余华在互联网火起来后有一年停了一年，任何活动、采访都不做，称为一年冷静期。
- 按过去经验一年后就在媒体上消失，但自媒体时代不是这样，几十年前的事情都被翻出来，以前说过的话也被翻出来。
- 互联网上关于他的话有一半不是他说的，比如“精神内耗”“想要命好”等都不是他说的。
- 他不担心喜欢会消散，因为他的工作是写作，不是靠说话。

十二、中年危机与自我调节
- 余华34岁时在年终总结中说成年人每到年底都会发现一种虚无，对生活充满信心的人变成面试者。
- 当时感觉生活每天在呼吸，人口增加、孩子来了，空间没有变得宽敞。只有写作能得到新的东西，虚构世界带来新东西，现实世界每天都是。
- 面对年轻人巨大的不安和焦虑，余华认为只有自我调节：发生的事情无法选择让它发生或不发生，但可以选择让自己知道什么、不知道什么，负面消息太多就屏蔽掉，选择积极的。

十三、希望以遗忘的姿态留在历史长河
- 被问及希望以什么姿态留在历史长河，余华回答“遗忘的姿态”，就是一个遗忘的人。
- 那些能够勉强被微风吹进耳朵的人，也是勉强吹进来的。假如历史长河里有主题，主题就是一个世界、一个一个人。
