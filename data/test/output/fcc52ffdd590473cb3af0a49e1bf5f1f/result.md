# 知识主题与概述
本笔记围绕调和级数收敛与发散这一经典问题展开，核心议题是评论 Stack Exchange（简称 MSE）上网友对该问题的回答与证明尝试。UP主皮卡以新系列试水之作的形式，从高中数学角度解释序列 `an=1/n`、前 n 项和、收敛（所有 `sn` 小于固定上界 a）与发散（`sn` 大于无界 `bn`）的定义，并依次评论了分组求和证明、柯西凝聚判别法、hn 大于 log(n+1) 的证明以及 hn 与 log n 同增长级别的证明。主要观点包括：分组求和与柯西凝聚判别法本质相同，高斯求和体现了发现恒定模式 group 后求和问题变为数 group 个数的思路；部分网友证明故弄玄虚、先射箭后画靶，本质与后续方法是一回事。整体逻辑框架是从基础定义出发，逐层剖析网友证明思路，并给出 UP主的主观评论与拓展联想。

# 核心概念
**调和级数**：指 `1+1/2+1/3+…+1/n` 的部分和，记为 `hn`，英文称 harmonic。

**收敛与发散**：对序列 `an=1/n`，前 n 项和 `sn`。若所有 `sn` 都小于某个固定实数 a，则收敛；若 `sn` 大于某个无界的 `bn`，则发散。

**分组求和证明**：将 `1/2+1/3`、`1/4` 至 `1/7`、`1/8` 至 `1/15` 等分组，每组和大于 `1/2`，任意多组 `1/2` 相加无上界，故发散。

**柯西凝聚判别法**：对非负不增序列，其收敛发散性等价于 `2^k·(1/2^k)` 即每项为 1 的级数，和等于 1，故发散；可推广到任意非负不增序列。UP主提及 `dialectic 分解` 文章。

**高斯求和联想**：高斯算 `1+2+…+100`，用 `1+100`、`2+99` 等每组 `101`，只需数有多少个 `101`；说明发现恒定或简单模式的 group 后，求和问题变为数 group 个数。

**hn 大于 log(n+1) 的证明**：`log` 即 `ln`，无上界故 `hn` 无上界、发散。流派包括积分收敛流派（用积分曲线面积近似 `hn` 并放缩，矩形面积大于曲边梯形，积分得 `log x`）和差分流派。网友方法两边取对数，利用 `e^(a+b)=e^a·e^b` 化为连乘积，再用 `e^(1/k)>1+1/k` 放缩，连乘积相消得 `n+1`。

**hn 与 log n 同增长级别及 Stolz 定理**：企图证明 `hn` 与 `log n` 同增长级别，因 `log n` 无上界故 `hn` 无上界、发散。UP主认为超纲且不自然，是先射箭后画靶，因为事先知道 `hn` 满足小于 `log n+1`、大于 `log n` 的不等式；若知道结果可用 `Stolz 定理`，对 `hn/log n` 做差分，分子差分 `1/(n+1)`、分母差分 `log(1+1/n)`，极限为 1。

# 核心结论
**核心结论**：调和级数是发散的。分组求和、柯西凝聚判别法、hn 大于 log(n+1)、hn 与 log n 同增长级别等证明均指向发散。

**易混淆点**：分组求和中每组和大于 `1/2`，但需注意组数无界；柯西凝聚判别法证明过程与分组求和完全一样；网友两边取对数的方法本质与差分方法是一回事，只是写成妨碍理解却显得 magic 的形式。
