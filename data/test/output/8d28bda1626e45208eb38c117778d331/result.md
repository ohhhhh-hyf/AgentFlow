# 课程概况
本讲为初中物理光学复习课，系统复习光的直线传播、光速、光的反射定律、镜面反射与漫反射、平面镜成像及球面镜应用。光源分为自然光源（太阳、萤火虫）与人造光源（电灯等），光线是带箭头的直线，为物理模型；光在均匀介质中沿直线传播，实例包括三点一线、激光准直、小孔成像、日食月食、影子形成。光速在真空中为3×10^8米/秒，空气中略慢，水中为真空中的3/4，玻璃中为2/3。光的反射定律为三线共面、分居两侧、反射角等于入射角，法线为辅助线且垂直镜面，垂直入射时入射角为0度；作图步骤为先画法线，再按反射角等于入射角画光线。镜面反射发生在光滑表面，反射光线平行，可能造成反光问题；漫反射发生在凹凸不平表面，反射光线射向各个方向，生活中大多数反射为漫反射，如黑板、电影银幕，两者均遵守反射定律。平面镜成像原理是光的反射，成正立、等大的虚像；实验用玻璃板代替平面镜以确定像的位置，用刻度尺比较像与物到镜面的距离，用两段相同蜡烛比较大小；玻璃板有厚度会导致两个像，玻璃板不垂直会导致测量误差。凸面镜对光起发散作用，成缩小虚像，用于汽车后视镜、丁字路口镜；凹面镜对光起会聚作用，用于手电筒、太阳灶、耳鼻喉科检查；玻璃幕墙凹面可能造成光污染，烧死树木或引燃电线。

# 核心知识点梳理
**光源**：自身能够发光的物体，分为自然光源（太阳、萤火虫）与人造光源（电灯等）。**光线**：带箭头的直线，是物理模型，非真实存在。**光在均匀介质中沿直线传播**：实例包括三点一线、激光准直、小孔成像、日食月食、影子形成。小孔成像成倒立实像，放大缩小不一定，与孔形状无关。日食时月球在中间，月食时地球在中间。**光速**：真空中为3×10^8米/秒（每秒绕地球赤道7圈半），空气中略慢，水中为真空中的3/4，玻璃中为2/3。**光的反射定律**：三线共面、分居两侧、反射角等于入射角；法线为辅助线，垂直镜面，垂直入射时入射角为0度。作图步骤：先画法线，再按反射角等于入射角画光线。**镜面反射与漫反射**：镜面反射发生在光滑表面，反射光线平行；漫反射发生在凹凸不平表面，反射光线射向各个方向，两者均遵守反射定律。**平面镜成像**：成正立、等大的虚像，原理是光的反射；实验用玻璃板代替平面镜，用刻度尺比较距离，用两段相同蜡烛比较大小。**球面镜**：凸面镜发散，成缩小虚像，用于汽车后视镜、丁字路口镜；凹面镜会聚，用于手电筒、太阳灶、耳鼻喉科检查。⭐难点：日食月食的区域划分（日全食、日偏食、日环食；月全食、月偏食）。易混点：*小孔成像成倒立实像，平面镜成像成正立虚像*。

# 课堂互动与答疑
问：萤火虫算不算光源？答：算，它自身能发光。问：光线是真实存在的吗？答：不是，是物理模型。问：为什么光在均匀介质中沿直线传播，但穿过大气层会偏折？答：因为大气层不均匀，光发生偏折，所以太阳看起来像越出地平线，星星会眨眼睛。问：为什么小孔成像的像与孔形状无关？答：因为光沿直线传播，像的形状由物体决定。问：为什么平面镜成像实验中用玻璃板代替平面镜？答：因为玻璃板透明，便于确定像的位置。问：为什么玻璃板有厚度会看到两个像？答：因为玻璃板两个面都能发生反射成像。问：为什么垂直入射时入射角是0度而不是90度？答：因为入射角是入射光线与法线的夹角，垂直入射时夹角为0度。> 教师提醒：光在均匀介质中沿直线传播，这句话要写全。

# 课后任务与学习建议
完成讲义练习第1至第6题（光的直线传播部分）、第7至第17题（光的反射定律、镜面反射与漫反射）、第18至第24题（平面镜成像、球面镜）。复习重点：光的直线传播实例、光的反射定律、平面镜成像特点及实验、镜面反射与漫反射的区别。建议：可在家用激光笔、硬纸壳、平面镜等做反射实验，用纸杯、针、蜡烛做小孔成像实验，用玻璃板、蜡烛做平面镜成像实验。
