# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷二审案件。合议庭由审判长及审判员组成，公开开庭审理。庭审围绕抵押权与融资租赁所有权冲突、罚息复利计算、违约金连带给付三个争议焦点展开法庭调查与辩论，各方分歧较大。休庭评议后，合议庭提出调解方案，各方均无异议并签字确认，法院当庭确认调解协议并出具调解书。

# 举证与法庭调查
## 举证与质证
- **国开行提交**：2018年9月对曲靖电力公司的融资租赁查询证书，证明其已尽查询义务。招银租赁质证认为该查询证书不符合要求，依据2014年93号文，国开行在抵押时点未查询人行征信中心。
- **国开行提交**：工商部门出资证明及权属证明（证据四，涉及58亿），证明抵押设备所有权属曲靖电力公司。招银租赁质证认为工商登记公示的是出资行为而非动产所有权，东源煤电出资系无权处分。
- **国开行提交**：2018年对曲靖电力公司融资租赁信息的核查表（证据108页），证明其名下无融资租赁登记。招银租赁质证认为该核查表系诉讼中制作，不能证明抵押时点已查询。
- **招银租赁提交**：回租设备清单（一审证据7页），载明设备名称、生产厂家，但无型号。国开行质证认为无法据此识别设备唯一性，且清单提示2012年3月1日，而抵押设备铭牌生产日期均在2013年以后，不能证明同一设备。
- **招银租赁提交**：2013年和2015年审计报告（证据82页、95页），载明曲靖电力公司注册资本4亿元且已实缴。国开行质证认为该报告已载明设备出资事项，招银租赁应当知道设备出资情况。
- **东源公司提交**：2015年12月2日邮件及融资情况统计表，证明已告知国开行设备存在融资租赁。国开行质证认为邮件正文及附表均无融资租赁文字，统计表招银租赁栏记载的抵押类型为不动产抵押，与融资租赁概念不同，不能证明履行告知义务。

## 法官询问
- **审判员询问**：各方如何理解中国人民银行征信中心融资租赁登记的性质及法律后果？国开行代理人认为系行业强制性规范，目的是防范动产可移动性、不明确性带来的金融风险；招银租赁代理人认为系行业指导性规范，不产生物权后果；东源公司代理人认为不当然产生物权后果。
- **审判员询问**：央行融资租赁登记系统的查询方式能否保证查询到登记结果？国开行代理人称目前只能按单位名称查询；招银租赁代理人称可通过公司名称或设备情况查询，但设备查询涉及种类物区分问题。
- **审判员询问**：国开行贷款前审查是否有内部规定必须查询融资租赁系统，未查到结果是否需保留单据作为风控材料？国开行代理人称无此规定，因未查到结果故未保留单据。
- **审判员询问**：融资租赁登记系统中设备唯一标识码是否必填项？招银租赁代理人称不是必填项，本案设备无发动机号等唯一标识，仅登记型号和参数。
- **审判员询问**：查询通知规定银行办理抵押前应查询，违反该规范会导致何种法律后果？国开行代理人称系基本查询义务，依据融资租赁司法解释第九条第三款，未查询不能取得善意权利；招银租赁代理人称系对银行业的严格要求，未查询即违反行业规范。
- **审判员询问**：若通过其他渠道获知设备存在租赁，是否仍需通过央行系统查询？招银租赁代理人称仍需查询，因央行规定出台背景是实务中大量纠纷，只有通过确定标准才能衡量善意。
- **审判员询问**：各方如何看待因不同登记机构产生登记瑕疵的问题？国开行代理人称动产抵押登记与融资租赁登记系统相互隔离，信息不流畅，可能导致多重抵押风险；东源公司代理人称系统整合有必要，但非专业机构无法提供建议；招银租赁代理人称应从立法层面统一规范，发挥行业协会作用，技术上可实现登记平台统一。

## 争议焦点与辩论
- **争议焦点一：抵押权与融资租赁所有权冲突**。国开行主张其已对抵押人曲靖电力公司履行查询义务，未发现融资租赁登记，构成善意取得；东源公司认为国开行作为专业金融机构，发现抵押设备名称与融资租赁设备一致时未尽注意义务；招银租赁认为国开行未在抵押时查询人行征信中心，不构成善意。
- **争议焦点二：罚息、复息计算**。国开行主张利息计算至2017年12月20日，罚息自2018年6月13日起算，复利自2018年3月21日起算；东源公司认为合同约定限期偿还，不应立即到期，且罚息不应计收复利。
- **争议焦点三：违约金连带给付**。国开行主张按合同第24条第三项，东源煤电未配合办理账户管理及柜台业务，构成违约，应支付千分之一违约金；东源公司认为国开行未举证违约行为，且未发出限期纠正通知，违约金请求不符合合同约定。

# 庭审结果
本案三个争议焦点均未当庭认定，合议庭休庭评议后提出调解方案，各方均无异议并签字确认，法院当庭确认调解协议并出具调解书。调解方案主要内容：国开行对东源公司债权扣除破产清偿本金后，利息、罚息、复利合计6474.4513万元；招银租赁对涉案六项设备享有所有权，对应债权1377.4137万元；国开行对93项设备有抵押权，招银租赁对六项设备有所有权；双方对案涉全部发电设备整体盘活处置，变现款双方各50%；变现款不足清偿时，招银租赁未实现债权按破产重整计划预留方案清偿；若司法变现不能，双方放弃设备权益，由东源曲靖电力自主生产经营；一审判决第二项、第四项无争议，按判项确认；一审诉讼费按一审判决执行，二审诉讼费由本院依法确定。
