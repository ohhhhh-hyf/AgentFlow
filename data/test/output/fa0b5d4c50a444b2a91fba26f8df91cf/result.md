# 就诊概况
患者张学恒，男，48岁，因上腹反复疼痛4年、近期加重3个月就诊于消化专科门诊。主诉心窝处烧灼样疼痛，与进食冷硬辛辣食物及工作紧张劳累相关，白天发作，夜间无痛醒；近4年每年春天发作较多。曾于一年前及三个月前出现两次黑便，最近两个月有呕吐。初步判断需进一步检查明确诊断，已安排大便检查与胃镜。

# 诊断与检查结果
本次门诊未进行辅助检查，医生根据病史采集作出初步判断：上腹疼痛位于心窝处，呈烧灼感，持续三个月，反反复复，近4年每年春天发作较多；与进食冷、硬、辛辣食物及工作紧张劳累相关，与油腻食物关系不大；白天发作，夜间无痛醒。患者曾于一年前及三个月前出现两次黑便，每次持续约一个月，住院治疗后好转；最近两个月出现呕吐，吐出黄水样酸物及当日所食食物。既往有甲肝病史（16岁时，已愈）、磺胺药过敏史。医生建议行大便检查以明确有无出血，并预约胃镜检查。

# 治疗方案与医嘱
- **检查安排**：患者需留大便做检查，以明确有无出血；胃镜预约在后天进行，因患者爱人可请假陪同，医生同意并说明后天也是胃镜时间，活检后正好张大夫查房。
- **生活方式**：建议戒烟限酒，因抽烟、喝酒对胃部疾病有不良影响；注意避免工作紧张、劳累、加班熬夜，因可能加重病情。
- **复诊与陪同**：胃镜当天需有爱人陪同，检查后由医生向上级张医生汇报病情，再商定下一步处理意见。
