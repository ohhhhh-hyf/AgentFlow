# 访谈概况
本次访谈走访了农村老人、村干部与民政局干部、城市社区社工等对象，目的是了解农村养老制度与城市社区养老经验，探讨解决乡村养老问题的启示。核心议题包括留守老人与独居现状、农村养老政策与困境、城市社区志愿者制度与养老服务中心、社工制度困境。据2021社区居家养老现状与未来趋势报告，65.5%的老人子女长期不在身边、无奈独居，仅26.8%与子女同住；农村方面2021年公安数据为73万多、占比约17.8%，预计老龄化程度会越来越严重。受访者普遍反映独居老人存在无人照料、无人慰藉、就医困难等问题，农村空巢老人面临无亲人陪伴、经济困难、子女不在身边、生病住院麻烦、娱乐方式少等困境，城市社区则以志愿者一对一帮扶和养老服务中心应对，但社工制度面临需求大而供给不足、资金有限、专业人才欠缺的困境。整体反馈基调为如实陈述现状与困难，并呼吁政府、子女、社区及专业养老服务机构共同关怀。

# 核心反馈
**独居老人无人照料、无人慰藉、就医困难**：据2021社区居家养老现状与未来趋势报告，65.5%的老人子女长期不在身边、无奈独居，仅26.8%与子女同住，独居老人不同程度存在无人平护照料、无人慰藉、就医困难等问题，甚至可能独自一人在家中发生意外。典型场景包括：黑龙江绥滨一位独居老奶奶报警称有人敲门，民警上门调查后老奶奶承认因一个人在家太寂寞、想找个人聊聊天才报了警；上海一名67岁独居老人在家中去世，直到多日之后家中满出刺鼻气味才被邻居发现；杭州一小区一名67岁独居老人不幸在家中去世，数天之后才被发现。

**农村空巢老人经济困难、子女不在身边、生病住院麻烦、娱乐方式少**：村干部与民政局干部反映，空巢老人可能面临的问题第一是没有很多亲人来陪伴，第二是经济比较困难，这个地方经济不太发达，生病、锻炼等都受影响，子女不在身边一旦生病住院就比较麻烦，娱乐方式少，只能坐在一起聊聊天、打打牌。有受访者说：> 现在80%都是都提醒这个在外面做做这些事的，年轻人都卖出去了。

**农村养老公共设施运营经费后续没有支持**：干部介绍，之前其实也探索过在一些农村建养老公共设施，提供日托、休闲娱乐、沟通交友的平台，但不是那种一次性的投入，地方财政都很困难，这种运营经费后续就没有支持的。

**城市小区留守老人社交机会更少、易孤独抑郁**：相比之下，城市小区中的留守老人们与外界社交的机会更少，更容易产生孤独、抑郁等情绪。社工谈到曾帮助一位存在心理问题的老人，其与邻里关系处理不和谐、半夜摔门，社区派志愿者上门但老人出现抗拒，觉得周围的人都是陌生的、没有关心他的人，内心可能有一点仇恨式的；经日复一日关心照料后，现在与邻里关系还算好了，能够理解一些、也可以接受一些意见，之前是不接受任何人的建议的，他今天都打来电话说寂寞空虚、得不到人关注。

**社工制度需求大而供给不足、资金有限、专业人才欠缺**：社工姐姐认为，目前社工制度的困境主要在于社会需求量大而供给不足，由于政府和社区资金有限，难以承担长期的专业社工服务费用，人民的需求得不到满足，大量社工迫于生计选择转行，这同时也阻碍着社工行业的长期发展。每个街道和乡镇派了两名社工驻点，主要围绕老人、小孩这一类去服务，但说实在话也很难能够走下来；社工行业工资都比较低，会影响就业率，基本上很多同学没做多久就垮了，可能不超过一年。服务需要花钱购买，不一定能够今年服务了、明年又能服务，要看领导能不能争取到这样的项目，一年的服务成效并不是那么的明显；资金拨不下来了，项目也结束了，但服务成效不一定就达到了。整个湖南省有这么大，这个街道也要花十来万块钱，省里还是拨了钱的，但很多社工并不是专业的、学社工专业出来的，在专业上其实还是很欠缺的。

# 关键洞察与建议
核心洞察：农村与城市留守老人问题均突出，农村空巢老人受经济困难、子女不在身边、娱乐方式少等多重因素叠加影响，城市小区留守老人社交机会更少、更易孤独抑郁；农村养老公共设施建设存在只考虑建设、不考虑后续持续运营经费的问题；社工制度面临社会需求量大而供给不足、资金有限、专业人才欠缺、服务成效不易显现的困境。受访者提出的建议与偏好：一是请专业施工人进行陪伴；二是尽量倡导在外务工的子女多跟他们联系；三是丰富他们的文化生活，能够有更多的娱乐方式；四是希望老年协会能够专项执行、专门建养老设施，有一个固定的场地，定期可以有一些施工人员或宣传，如板报宣传或健康知识讲座，并要给一个持续运营的经费，不管考虑建设还要考虑后续的持续运营，才能更好地发挥作用。城市社区方面的做法与倾向：志愿者制度实行一对一帮扶，通过定期表彰、志愿者积分兑换、雷锋超市兑换礼品让志愿者长期坚持；今年做小手拉大手，从儿童青少年着手拉动家长加入；周四准备开展送春联活动，邀请书法老师写对联让孩子上门送给老人；去年中秋节开展做月饼活动，还做过百家宴，让大家感觉社区就是一个大家庭；2023年的目标是家长他们自己来组织，社区作为一个协助者。受访者还表示，解决养老问题绝非易事，不仅需要政府的关心和重视，也离不开子女、社区乃至更专业的养老服务机构的耐心陪伴与关怀。
