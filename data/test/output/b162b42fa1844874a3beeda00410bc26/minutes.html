初中光学复习课：直线传播与反射

课程概况

本节课为初中光学复习课，主讲人系统梳理了几何光学的基础知识，涵盖光的直线传播、光的反射定律、镜面反射与漫反射、平面镜成像及球面镜应用。课程以讲义例题为载体，结合生活实例与实验演示，帮助学生巩固核心概念与作图方法。在光的直线传播部分，主讲人讲解了光源（自然光源与人造光源）、光线（物理模型）及光在均匀介质中沿直线传播的规律，列举三点一线、激光准直、小孔成像、日食月食、影子形成等实例。光速方面，真空中光速为3×10^8米/秒，空气中略慢，水中约为真空的3/4，玻璃中约为2/3；激光从地球到月球表面用时1.25秒，距离为3.75×10^8米。在光的反射部分，主讲人详细讲解了反射定律（三线共面、分居两侧、反射角等于入射角），并通过例题说明入射角与反射角的计算，强调作图时先画法线。镜面反射与漫反射均遵守反射定律，生活中大多数反射为漫反射，如黑板、银幕；雨后夜晚判断水潭位置是典型应用。平面镜成像方面，成等大、正立的虚像，像与物到镜面距离相等、连线与镜面垂直；实验用玻璃板代替平面镜便于确定像的位置，刻度尺比较距离，两段相同蜡烛比较大小；误差来源包括玻璃板与水平面不垂直及玻璃板有厚度。球面镜部分，凸面镜发散光线（用于汽车后视镜、丁字路口镜），凹面镜会聚光线（用于手电筒、太阳灶、耳鼻喉科检查镜），并讨论了玻璃幕墙凹面会聚光线造成的光污染问题。

核心知识点梳理

光的直线传播

  1. 光源：定义是自身能够发光的物体；按来源分为自然光源（如太阳）和人造光源（如火把、蜡烛、煤油灯、电灯）；萤火虫自身发光，属于自然光源。
  2. 光线：用一条带箭头的直线表示，是物理模型，并非真实存在；按形状可分为平行光源（如从无限远处来的太阳光）和点光源（如从远处看的蜡烛）。
  3. 光沿直线传播：光在均匀介质中沿直线传播；实验验证方法包括玻璃罩内用激光笔照射烟雾、直吸管与弯折吸管对比激光通过情况；大气层不均匀会使光线发生偏折，如太阳越出地平线、星星眨眼睛。
  4. 实例：三点一线（步枪瞄准、队列排齐、木工看尺子是否平直）、激光准直、小孔成像、日食月食、影子形成（如唐朝皮影戏）。
  5. 小孔成像：成倒立实像，放大缩小不一定，与孔形状无关；生活中树荫下的光斑是太阳透过树叶缝隙形成的小孔成像，因太阳距地球远大于树叶缝隙到地面距离，得到的是缩小的像；自制实验可用纸杯底部扎针孔、前方蒙塑料布，观察蜡烛火苗倒立像。
  6. 日食与月食：日食时太阳、月球、地球在同一直线，月球在中间，1号区域为日全食、2/3号区域为日偏食、4号区域为日环食；月食时地球在中间，月球完全在地球阴影内为月全食，部分在1号区域、部分在2/3号区域才出现月偏食。
  7. 光速：真空中光速为 3×10^8 米/秒（3×10^5 千米/秒），一秒钟绕地球赤道7圈半；空气中略慢（约 2.99×10^8 米/秒），水中约为真空中的3/4，玻璃中约为2/3；光在透明介质中传播，海水太阳光最多到达约200米深度。
  8. 计算题：激光从地球射到月球表面用时1.25秒，距离 s=V×T=3×10^8×1.25=3.75×10^8 米；发生雷电时先看到闪电后听到雷声，因为光速比声速快（声速15℃时为340米/秒）。

光的反射定律

  1. 基本概念：入射光线AO、入射点O、反射光线OB；法线是垂直于镜面的辅助线，画虚线，是入射光线与反射光线夹角的角平分线；入射角是入射光线与法线的夹角，反射角是反射光线与法线的夹角。
  2. 反射定律内容：反射光线、入射光线和法线在同一平面内（三线共面）；反射光线和入射光线分居法线两侧；反射角等于入射角。
  3. 易错点：光垂直射到镜面上时，入射角和反射角都是0度（不是90度）；反射光线与平面镜夹角40度时，入射角为50度（与法线夹角）。
  4. 作图步骤：先画法线（虚线，画两三段即可），再根据反射角等于入射角画入射或反射光线，最后补全箭头；可用刻度尺在法线两侧找对称点的方法确定光线位置。
  5. 例题结论：入射光线与镜面夹角增大时，入射角减小、反射角也减小，传播速度不变；入射光线与法线夹角60度时反射角60度；反射光线与入射光线夹角80度时反射角40度。

镜面反射与漫反射

  1. 镜面反射：平行光射到光滑表面（如平面镜、平静水面、光滑金属表面），反射光平行；人眼在反射光方向能看到，不在则看不到，如商场玻璃隔断易使人撞上。
  2. 漫反射：平行光射到凹凸不平的表面，把每个小面看作小平面镜，反射光线向各个方向；生活中大多数反射是漫反射，如黑板、电影院白色银幕、投影幕布、人本身。
  3. 共同点：镜面反射和漫反射都遵守光的反射定律。
  4. 雨后夜晚判断水潭：迎着月光走，地面上发亮处是水潭（镜面反射）；背着月光走，暗处是水潭；实验验证：白纸上放小镜子，手电筒垂直照射，斜着看镜子是黑的、白纸是亮的。
  5. 光路可逆：小明能看到小刚在平面镜中的像，则小刚也一定能看到小明在平面镜中的像。

平面镜成像

  1. 成像原理：光的反射，成的是虚像；实际光线没有到达像的位置，光屏不能接收到像。
  2. 成像特点：成正立、等大的虚像；像与物到镜面距离相等；像与物的连线与镜面垂直。
  3. 实验要点：用玻璃板代替平面镜是为了便于确定像的位置；刻度尺用于比较像与物到镜面的距离；两段完全相同的蜡烛用于比较像与物的大小；光屏可用毛玻璃、白塑料片或白墙充当。
  4. 实验误差原因：玻璃板与水平面不垂直（或与事先画好的镜面位置不重合）；玻璃板有厚度，两个面发生反射成像，会看到同一个蜡烛的两个像。
  5. 应用计算：视力表距镜子3.5米，像距镜子也是3.5米，人距镜子1.5米即可看到5米处的虚像；视力表距镜子3米时，人距镜子2米；人站在平面镜前1米处，人与像距离2米；人远离平面镜时，像的大小不变。
  6. 易混点：人在河边看到岸边树在水中的倒影属于光的反射（平静水面充当平面镜），但文学上称“倒影”，与平面镜成正立等大虚像并不矛盾；人在河边看到河水深度比实际浅是光的折射。

球面镜及其应用

  1. 凸面镜：对光线起发散作用；成正立、缩小的虚像；用于汽车后视镜、丁字路口拐弯处的镜子；司机看后视镜感觉车离得远，是视觉差异。
  2. 凹面镜：对光线起会聚作用，平行光反射后交于焦点F；用于手电筒电珠（小灯泡在焦点处）、汽车前大灯、探照灯、耳鼻喉科检查镜（中间镂空便于观察）、西藏藏民使用的太阳灶。
  3. 作图原则：以直代曲，把曲面看作许多小平面镜；阿基米德曾组织妇女用梳妆镜围成凹面烧毁敌人帆船。
  4. 光污染问题：玻璃幕墙做成凹面会聚光线，可能烧死树木（学校枣树被烧死）、引燃电线造成自燃；凹面还会反射声音，使楼间噪音增大。

课堂互动与答疑

Q1. 光源分类与光线模型

  • 学生：萤火虫算光源吗？光线是真实存在的吗？
教师：萤火虫自身发光，算自然光源。光线是人为引入的物理模型，用带箭头的直线表示，并非真实存在，只是为了方便描述光传播路径而设。

Q2. 光沿直线传播的适用条件

  • 学生：为什么太阳刚露出地平线就能看到，而不是在直线上才能看到？
教师：光沿直线传播的前提是均匀介质。地球大气层越往外越稀薄、不均匀，会使光线发生偏折，所以太阳实际位置还在地平线以下时就能看到；宇航员在月球上看太阳则必须沿直线。

Q3. 小孔成像的像的性质

  • 学生：小孔成像成的像一定是倒立的吗？放大缩小怎么判断？
教师：小孔成像一定成倒立的实像，因为光线实际到达光屏；放大或缩小取决于物距与像距的相对大小，不一定。像的形状与孔的形状无关，如树荫下的圆形光斑就是太阳经树叶缝隙小孔成像得到的缩小实像。

Q4. 月偏食的形成条件

  • 学生：月偏食是不是和日偏食一样，月球处在2、3号区域？
教师：不是。月球远小于地球，可以完全钻入地球阴影（1号区域）形成月全食；若月球只有部分进入1号区域、部分仍在2或3号区域，才出现月偏食。处在2、3号区域时月球只是略暗，不叫月食。

Q5. 光速在不同介质中的差异

  • 学生：光速在不同介质中一样吗？具体是多少？
教师：不一样。真空中光速为3×10⁸米/秒（约每秒30万公里，一秒钟绕地球赤道7圈半）；空气中略慢，约为2.99×10⁸米/秒；水中约为真空的3/4；玻璃中约为真空的2/3。计算时地球到月球间按真空处理。

Q6. 垂直入射时入射角与反射角

  • 学生：光垂直射到镜面上，入射角和反射角是多少度？
教师：都是0度。入射角是入射光线与法线的夹角，垂直入射时光线与法线重合，夹角为0度，反射角也等于0度，不能答成90度。

Q7. 反射作图的方法与步骤

  • 学生：画反射光线时，怎么确定入射光线的位置？需要用量角器量吗？
教师：不需要量角器。先画法线（虚线，垂直于镜面，留作图痕迹），再根据反射角等于入射角，利用等腰三角形对称性：在反射光线上取一点，量出到法线的距离，在法线另一侧对称位置取等距点，连接入射点即得入射光线，最后补全箭头。

Q8. 镜面反射与漫反射的区别

  • 学生：镜面反射和漫反射都遵守反射定律吗？生活中哪种更多？
教师：两种反射都遵守光的反射定律。镜面反射是平行光射到光滑表面后反射光仍平行；漫反射是表面凹凸不平，把每个小面看作小平面镜，反射光射向各个方向。生活中大多数反射是漫反射，如黑板、银幕、人的皮肤。

Q9. 雨后夜晚判断水潭位置

  • 学生：雨后夜晚，迎着月光走和背着月光走，亮处和暗处哪个是水潭？
教师：迎着月光走，亮处是水潭——水面发生镜面反射，反射光进入人眼；背着月光走，暗处是水潭——反射光射向另一侧，人眼接收不到。可用手电筒照白纸上的小镜子验证：垂直照射时斜看，镜子是黑的，白纸是亮的。

Q10. 平面镜成像实验用玻璃板的原因

  • 学生：研究平面镜成像为什么用玻璃板而不用镜子？
教师：玻璃板既能反射成像，又能透过它看到后面的蜡烛，便于移动未点燃的蜡烛去确定像的位置；用镜子则无法看到后面，无法确定像的位置。

Q11. 平面镜成像实验误差来源

  • 学生：实验中像与物到玻璃板距离不相等，可能是什么原因？
教师：一是玻璃板与水平面不垂直（或与事先画好的镜面位置不重合），导致像的位置偏移；二是玻璃板有厚度，前后两个面都会反射成像，若玻璃板较厚，肉眼可看到两个像，造成测量误差。

Q12. 平面镜成虚像的判断

  • 学生：为什么光屏上接收不到平面镜成的像？
教师：平面镜成的是虚像，反射光线的反向延长线会聚而成，实际光线并未到达像的位置，所以光屏接收不到。若将手放到后面蜡烛处不会被烫伤，就是这个道理。

Q13. 水中倒影与平面镜成像的关系

  • 学生：平面镜成的是正立等大的虚像，为什么水中的倒影是倒立的？
教师：平静的水面充当平面镜，镜面是水平放置的。岸边的树相对于水平镜面成的是正立等大的虚像，只是从人的观察角度看像是倒过来的，文学上称“倒影”，本质上仍是平面镜成像规律。

Q14. 凸面镜与凹面镜对光线的作用

  • 学生：凸面镜和凹面镜对光线各起什么作用？分别用在哪些地方？
教师：凸面镜对光线起发散作用，成缩小正立的虚像，用于汽车后视镜、丁字路口拐弯镜；凹面镜对光线起会聚作用，把平行光会聚到焦点，用于手电筒、汽车前大灯、太阳灶、耳鼻喉科检查镜。

课后任务与学习建议

  • [ ] 讲义第1–5题：光的直线传播相关练习，涵盖三点一线、影子形成、月全食等实例判断；第4题选C（光在均匀介质中沿直线传播），第5题多选选BCD（平面镜反射不属于直线传播），第6题选ABC（D项漏掉“均匀介质”条件）。
  • [ ] 激光测距计算题：一束激光从地球射到月球表面用时1.25秒，按s=vt计算，v取3×10⁸米/秒，距离为3.75×10⁸米。
  • [ ] 雷电现象判断题：先看到闪电后听到雷声，原因是光速比声速快（声速15℃时为340米/秒）。
  • [ ] 讲义第7–9题：光的反射定律探究实验与计算；第9题反射光线与平面镜夹角40°，入射角为50°，选A。
  • [ ] 讲义第8题作图：画出入射光线或反射光线，步骤为先画法线（虚线，留作图痕迹），再根据反射角等于入射角确定另一条光线，最后补全箭头。
  • [ ] 讲义第10–12题：反射定律应用；第10题选C（入射光线与镜面夹角增大，入射角减小，反射角也减小，传播速度不变），第11题入射角60°则反射角60°，第12题反射光线与入射光线夹角80°则反射角40°。
  • [ ] 讲义第13题：雨后夜晚判断水潭位置——迎着月光走，亮处是水潭（镜面反射）；背着月光走，暗处是水潭。
  • [ ] 讲义第14题：光路可逆性判断，选B（小明能看到小刚在平面镜中的像，则小刚也一定能看到小明在镜中的像）；A错在垂直入射时反射角应为0°，C错在漫反射也遵守反射定律，D错在不同介质中光速不同。
  • [ ] 讲义第15–17题：镜面反射与漫反射判断；电影院白色银幕产生漫反射（第15题选B），黑板反光看不清粉笔字是镜面反射，电影银幕粗糙是为了发生漫反射。
  • [ ] 讲义第18题：判断光的反射现象，选D（人在河边看到岸边树的倒影，平静水面充当平面镜）；A、B为直线传播，C为光的折射。
  • [ ] 讲义第19–20题：平面镜成像实验；玻璃板代替平面镜便于确定像的位置，刻度尺用于比较像与物到镜面距离，两段相同蜡烛用于比较像与物大小；光屏不能接收到虚像；物体靠近玻璃板时像的大小不变。
  • [ ] 讲义第19题后两条：实验误差原因——玻璃板与水平面不垂直，或玻璃板有厚度（两个面发生反射成像，造成两个像）。
  • [ ] 讲义第21–22题：视力表测视力；第21题视力表距镜3.5米，人距镜1.5米即可看到5米处虚像；第22题视力表距镜3米，人距镜2米，选B。
  • [ ] 讲义第23–24题：人站在平面镜前1米处，人与像距离2米；人远离平面镜时，像的大小不变（选C）。

复习重点

  • [ ] 光源：自身能够发光的物体，分为自然光源（太阳、萤火虫）和人造光源（火把、蜡烛、煤油灯、电灯）。
  • [ ] 光线：用带箭头的直线表示，是物理模型，并非真实存在。
  • [ ] 光在均匀介质中沿直线传播：适用条件为同一种均匀介质；实例包括三点一线、激光准直、小孔成像、日食月食、影子形成。
  • [ ] 小孔成像：成倒立实像（光线实际到达），放大缩小不一定，与孔形状无关；生活中树荫下的光斑是太阳经树叶缝隙形成的小孔成像，为缩小的实像。
  • [ ] 日食与月食：日食时太阳、月球、地球在同一直线，月球在中间，分日全食（1号区域）、日偏食（2、3号区域）、日环食（4号区域）；月食时地球在中间，月球完全进入地球阴影为月全食，部分进入为月偏食。
  • [ ] 光速：真空中为3×10⁸米/秒（每秒30万公里，一秒钟绕地球赤道7圈半）；空气中略慢（约2.99×10⁸米/秒）；水中约为真空的3/4；玻璃中约为2/3。
  • [ ] 光的反射定律：反射光线、入射光线和法线在同一平面内（共面）；反射光线和入射光线分居法线两侧；反射角等于入射角；光垂直射到镜面时入射角和反射角均为0°。
  • [ ] 镜面反射与漫反射：镜面反射是平行光射到光滑表面反射光仍平行；漫反射是平行光射到凹凸不平表面反射光向各个方向；两者都遵守光的反射定律；生活中大多数反射是漫反射（黑板、银幕、白纸）。
  • [ ] 光路可逆：在反射现象中，光路是可逆的。
  • [ ] 平面镜成像：成等大、正立的虚像；像与物到镜面距离相等，连线与镜面垂直；原理是光的反射。
  • [ ] 凸面镜与凹面镜：凸面镜对光线起发散作用，成正立缩小的虚像（汽车后视镜、丁字路口镜）；凹面镜对光线起会聚作用（手电筒、太阳灶、耳鼻喉科检查镜）。

学习建议

  • [ ] 自制小孔成像实验：用纸杯或易拉罐，底部用针扎一个小孔（不要用钉子杵大孔），前面用塑料布蒙住，点燃蜡烛放在小孔前方，可在塑料布上看到倒立的火苗像；体会像与孔形状无关。
  • [ ] 自制光的直线传播实验：用激光笔对准直吸管照射，吸管弯曲后墙上光点消失，证明光不会自行拐弯。
  • [ ] 自制反射定律实验：用硬纸壳（中间用透明胶带粘合可前后转动）、小平面镜和激光笔，在纸壳上画好刻度，即可在家研究反射定律。
  • [ ] 自制镜面反射与漫反射对比实验：白纸上放一面小镜子，用手电筒垂直照射，斜着看时镜子是黑的、周围白纸是亮的——镜子发生镜面反射（光线原路返回），白纸发生漫反射。
  • [ ] 自制平面镜成像实验：用透明玻璃板立在白纸上，前方点燃蜡烛，后方移动未点燃蜡烛至看似被点燃的位置，记录两蜡烛位置，可验证像与物到镜面距离相等、连线与镜面垂直；也可用两枚跳棋子代替蜡烛。
  • [ ] 购买激光笔：两元店或十元店即可买到，激光笔光线强度大、线直，便于观察，可用于直线传播、反射等实验。
  • [ ] 保护眼睛：主讲人提醒，长时间判卷、看屏幕、写字姿势不良都会导致视力下降；教室因投影和防反光整天拉窗帘，学生缺乏户外光照，近视率偏高；建议注意用眼卫生。
