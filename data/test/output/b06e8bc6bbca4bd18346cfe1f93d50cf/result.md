# 研讨背景与议题
本次圆桌由主持人（多模态大模型与具身智能融合方向）主持，参与讨论的包括于洋老师的博士生雄辉（强化学习）、卢策吾老师的博士生薛寒（数据收集与柔性物体操作）、于洋老师的博士生志龙（具身模型与世界模型）以及赵浩、王岳等老师。研讨围绕具身智能的模型形态、硬件期待、世界模型定义、模仿与强化学习路线及数据scaling五个议题展开。核心痛点在于：具身智能究竟收敛为统一端到端模型还是分层形态、硬件如何支撑真机evaluation的scale up、世界模型是否需要3D inductive bias、模仿学习与强化学习如何取舍，以及真机数据与仿真数据如何配比。

# 核心观点
模型形态议题：主持人提出大脑大模型、小脑大模型、端到端模型等形态，并以派灵收集6000多小时数据训出端到端模型为例，询问是统一模型还是前段固定加Action refiner；王岳认为大模型直通底层会消除硬件迭代可能性，至少应分上下层，大脑不变、小脑适应肢体；发言者6认为当前大模型不是终极形态，世界模型可能更接近人脑水平，但也不是最终形态。硬件形态议题：发言者3从机械与传感器角度反问具身身体会收敛成人形还是非人形，并提到机械智能、软手抓取；薛寒提出硬件需寿命和可靠性高，因真机evaluation中机器人撞几次就坏、难以scale up，现有工业机械臂并非为此设计，需要柔顺硬件结构；主持人认为具身是软硬件协同优化范式，以松龄二代和凝胶夹爪为例，认为协同进化；发言者6认为人形机器人和特种机器人将来都会存在，特斯拉花一半精力做22自由度灵巧手。世界模型议题：主持人介绍赵浩从computer vision角度评价世界模型，涉及是否需重构所有pixel和3D，并提到4D world model投稿；志龙从强化学习角度认为世界模型第一要素是可交互，回溯到Dyna Q和杨乐坤的表征与转移，当前世界模型物理规律欠缺明显；赵浩认为CV界追求重建物理世界动态，可作为RL世界模型的工具，但三维计算机视觉技术栈长，RL博士生难完全学习，并讨论inductive bias随数据规模变化；王岳以游戏跳楼例子认为世界模型可能做不到统一，policy可能是一个；发言者9提出不同物理结构可能有统一表征，讨论condition与M个模型复杂度。策略学习路线议题：主持人提出强化学习与模仿学习两大流派，派零团队收集上千小时近万小时数据后仍看到模仿学习瓶颈，语言模型有RLHF和o1思维链、MCTS；发言者10介绍公司采用模型强化加机理融合，监督学习动作空间大、数据分布不足，强化学习强依赖仿真环境、sim-to-real迁移难，需限定决策空间和任务分层；发言者9认为复杂任务应先模仿后强化，单独模仿或单独强化都不行；王岳认为pid有反馈就可作为reward，强化必然走得成；发言者11认为IL和RL没有本质冲突，只是想要一个latent状态。数据采集与scaling议题：主持人请杨立新和薛寒分享真机数据收集经验，赵浩和主持人代表仿真生成数据流派；杨立新强调视角控制和标定重要，open X等数据集相机视角不固定，且缺少物体运动信息，其团队采集刚体和关节体；薛寒all in真机采集，认为柔性体仿真需先进图形学技术如IPC、算力要求高、人才少，真机数据是更低成本方案，终极形态可能是脑机接口或可穿戴设备无感采集，互联网视频与机器人所需数据差异大；主持人提到ego4d数据清洗三个月，仿真数据加少量真机数据可显著提升成功率；赵浩认为真实还是仿真看成本，提出2025年应推广大规模利用无标注真实数据，国产仿真系统是产业问题。

# 达成共识与解决方案
研讨未形成正式决议，但各方在以下认知上趋于一致：**具身智能是软硬件协同优化的范式**，硬件需具备高寿命、高可靠性与柔顺结构以支撑真机evaluation的scale up；**模型形态至少应分上下层**，大脑保持稳定、小脑适应肢体与硬件变化，而非单一端到端直通底层；**世界模型与强化学习的关系上**，CV界重建物理世界动态的成果可作为RL世界模型的工具，但RL更关注可交互性与策略学习；**策略学习路线上**，复杂任务宜先模仿后强化，单独模仿或单独强化均难以覆盖，混合多种方式是目前较实际的解；**数据路线上**，真机数据与仿真数据并非相斥，仿真数据加少量真机数据可显著提升成功率，真实还是仿真应case by case看成本。

# 未决分歧与后续探索
未决分歧包括：具身智能最终会收敛成统一端到端模型，还是前段固定加Action refiner的分层形态；具身的身体会收敛成人形机器人还是非人形形态；世界模型是否需要3D inductive bias，还是由数据规模决定；世界模型最终是一个还是多个，policy是否可能统一；模仿学习和强化学习最终路线是单独一种还是混合；未来是否强依赖英伟达生态，还是会有国产仿真产品支持。后续探索方向包括：赵浩提出2025年应推广大规模利用无标注真实数据；薛寒提出可穿戴式设备或脑机接口作为无感采集的终极形态；主持人提出仿真数据与少量真机数据结合的训练方法；国产仿真系统作为产业问题需business by business讨论。
