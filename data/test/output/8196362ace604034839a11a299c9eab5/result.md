# 庭审概况
本案系上诉人国家开发银行不服云南省高级人民法院（2018）云民初88号民事判决，向最高人民法院提起上诉的金融借款合同纠纷二审案件，被上诉人为云南东源电力股份有限公司、云南东源曲靖电力有限公司及招银金融租赁有限公司。合议庭由审判长李少平与审判员魏文超、黄年、王海峰、葛洪涛组成，法官助理张瑞。庭审核对各方出庭人员身份后，围绕三个争议焦点展开法庭调查与辩论：国开行对案涉设备是否享有抵押权（善意取得）、一审判决对案涉借款罚息复息的计算及起算日期是否认定错误、东源煤电及东源煤业是否应连带给付违约金。合议庭多次到案发地调查走访并召开庭前会议，休庭评议后提出调解方案，各方均无异议，诉讼代理人依次在调解协议正式文本上签字，合议庭予以确认，庭后出具调解书。

# 原告诉称与被告辩称
上诉人国家开发银行上诉请求：撤销一审判决相关判项，改判其对案涉设备享有抵押权，并支持其利息、罚息、复利及违约金主张。事实与理由：国开行已按央行规定对抵押人曲靖电力公司进行融资租赁登记查询且无记录，设备为无唯一标识码的通用设备，核查义务仅限于抵押人，已尽审慎义务构成善意取得；东源煤电利息支付截止2017年12月20日，2018年6月13日发函要求当日归还，罚息应自该日起算，复利按合同第6条约定计算；依借款合同第24条第3项，东源煤电未配合办理账户管理及柜台前移手续构成违约，应支付千分之一违约金。被上诉人东源煤电、东源煤业、曲靖电力共同答辩：2015年12月2日邮件中两家公司抵押设备名称完全相同且以红色标注，国开行应尽注意义务；合同约定限期偿还而非立即偿还，且复利不应以罚息为基数；国开行未举证证明违约事实，且依约应先限期纠正。被上诉人招银租赁答辩：国开行未在抵押时点（2015年12月）查询人行征信中心，且东源煤电系借款人及抵押人全资控股母公司，国开行对其有审查义务，不构成善意。

# 举证与法庭调查
**证据与质证意见**
- 国开行提交2015年12月2日东源煤电发送的邮件及《东源公司融资情况统计表》，主张表中招银租赁抵押物为恩洪电厂设备资产且已登记，国开行抵押物为恩洪电厂设备在建工程正在办理，两者设备完全不同，不能得出已告知的结论；东源方反驳称该邮件系抵押合同签订（2015年12月22日）前发出，两家公司抵押设备名称完全相同且以红色标注，国开行应尽注意义务。
- 国开行提交证据54页、58页权属证明及股东会决议，主张显示所有权属曲靖电力公司，已尽审慎义务；招银租赁主张东源煤电出资行为系无权处分，招银租赁2012年已取得设备所有权。
- 招银租赁提交证据第7页回租设备清单，主张载明设备名称、生产厂家；国开行反驳称清单无型号，出厂日期2012年3月1日，而现场调查铭牌生产日期均在2013年以后，看不出同一设备。
- 招银租赁提交证据82页、95页审计报告，主张载明曲靖电力公司注册资本4个亿且实缴；国开行据此主张招银租赁应知道设备出资情况。
- 国开行提交2018年9月融资租赁查询证书，主张已尽查询义务；招银租赁反驳称该证书不符合2014年93号文规定，国开行应提供2015年12月抵押时点的查询结果。
- 东源方提交融资情况统计表及邮件截屏，主张两家公司抵押设备名称完全相同且用红色标注；国开行反驳称统计表中招银租赁抵押类型为不动产抵押，与融资租赁是两个法律概念。

**法官询问要点**
- 合议庭询问各方如何理解人行征信中心融资租赁登记的性质及法律后果：国开行认为系行业内强制性规范，目的是防范金融风险；东源方认为系行业指导性规范，非强制性，不当然产生物权后果；招银租赁认为系权利公示，可能产生对抗效力，但不影响所有权设立转移等法定效果。
- 合议庭询问央行融资租赁登记系统的查询方式：国开行称目前只能使用一种查询方式（查询单位）；招银租赁称可通过公司名称或设备查询，设备查询涉及种类物区分问题。
- 合议庭询问案涉5套设备登记时识别码是否登记清楚：东源方称设备交付时系种类物，无唯一识别码，未登记。
- 合议庭询问国开行贷款前审查内部是否有规定必须查询融资租赁系统、未查到也要保留记录：国开行称按央行规定必须查询，但未查到记录，未保留筛查记录，内部无此规定。
- 合议庭询问融资租赁登记系统设备唯一标识码是否必填项：招银租赁称不是必填项，案涉设备无唯一识别码，无法填写；发电机铭牌只有型号和参数，15万伏发电机只要是上海电气出厂，铭牌都一样。
- 合议庭询问违反查询规范多大程度导致司法解释第9条第2款法律后果、是基本查询义务还是全面审慎义务：国开行认为是基本查询义务，针对抵押人，审慎调查义务已完成；招银租赁认为是严格义务，银行未查询即不构成善意，本案中恩洪矿区发电厂只有两台设备，综合信息能确定5台设备唯一性，已足够引起国开行注意。
- 合议庭询问若银行通过其他途径了解到动产属融资租赁物，是否相当于已掌握风控情况：国开行称基本义务必须做，查询动作完成即可得出结论；东源方称金融机构接受抵押物前需确权查询，若通过其他渠道知道可能存在租赁，仍应查询；招银租赁称通过其他方式获知后仍应通过央行系统查询，因为其他方式无法证明，只有确定标准才能衡量善意。
- 合议庭询问融资租赁司法解释第9条第2款举证责任如何分担：国开行称按谁主张谁举证原则，争议焦点是查询范围和主体；招银租赁称第9条列举1、2、4项由出租人举证，第3项由第三人（国开行）证明办理抵押时查询了央行系统，国开行应扩展调查东源煤电，查询购买合同购买发票。
- 合议庭询问不同登记机构产生的登记信息冲突有何意见和建议：国开行称人行融资租赁系统和工商动产抵押登记信息不统一导致矛盾，是系统问题，建议系统整合；东源方称系统整合或衔接有必要，但提不出成熟建议；招银租赁建议从立法层面统一要求、发挥行业协会作用形成行业惯例、从操作和技术层面实现信息互通，企业主体也应主动登记。

**双方辩论的争议焦点**
- 争议焦点一：国开行对案涉设备是否享有抵押权（善意取得）。国开行主张已按央行规定对抵押人曲靖电力公司进行融资租赁登记查询且无记录，设备为无唯一标识码的通用设备，核查义务仅限于抵押人，已尽审慎义务构成善意取得；东源方反驳称2015年12月2日邮件中两家公司抵押设备名称完全相同且以红色标注，国开行应尽注意义务；招银租赁主张国开行未在抵押时点（2015年12月）查询人行征信中心，且东源煤电系借款人及抵押人全资控股母公司，国开行对其有审查义务，不构成善意。
- 争议焦点二：一审判决对案涉借款罚息复息的计算及起算日期是否认定错误。国开行主张利息自2017年12月21日计算至2018年6月12日合计21,795,727.68元，罚息自2018年6月13日计算至2019年2月19日（破产受理日）合计41,050,579.57元，复利自2018年3月21日计算至2019年2月19日合计1,918,206.23元；东源方反驳称合同约定限期偿还而非立即偿还，且复利不应以罚息为基数，合同第6条第4款仅表述为利息未提罚息，并援引最高法2015年、2016年判例。
- 争议焦点三：东源煤电、东源煤业是否应连带给付违约金。国开行主张依借款合同第24条第3项，东源煤电未配合办理账户管理及柜台前移手续构成违约，应支付千分之一违约金；东源方反驳称国开行未举证证明违约事实，且依约应先限期纠正，国开行从未发出书面函件。

# 庭审结果
本案争议焦点为：一、国开行对案涉设备是否享有抵押权（善意取得）；二、一审判决对案涉借款罚息复息的计算及起算日期是否认定错误；三、东源煤电、东源煤业是否应连带给付违约金。合议庭休庭评议后提出调解方案，各方均无异议，自愿达成调解协议，合议庭予以确认，庭后出具调解书。调解方案主要内容：国开行对东源煤电债权扣除破产已清偿本金外，利息、罚息、复利三项共计6474.4513万元；确定招银租赁对涉案6项设备享有所有权（对应债权1377.4137万元）、国开行对93项设备有抵押权，双方对案涉全部发电设备整体盘活处置，调解书生效后20日内由国开行向一审法院提出执行申请启动司法处置，变现价款双方各得50%、费用各担50%；未实现债权待执行法院出具体本裁定后按破产重整计划预留方案实现，若破产管理人不予纳入预留方案由东源煤电按有担保清偿方案清偿，若司法变现不能双方放弃权益由东源曲靖电力自主生产经营；案涉设备管理费用由东源曲靖电力承担并无条件配合司法处置；各方对一审判决第2项、第4项无争议按判项确认；一审诉讼费用中国开行诉请部分按一审判决执行、招银租赁诉请部分由国开行承担，二审诉讼费用由国开行和东源煤电各承担50%；协议签订后各方就本案问题不再存在任何争议。
