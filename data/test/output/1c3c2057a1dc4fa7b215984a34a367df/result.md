# 就诊概况
48岁男性患者张春和，因近4年反复上腹烧灼痛、近3个月加重，于消化内科就诊，接诊医生为严医生。患者主诉心窝处烧灼感，与进食冷硬刺激性食物及工作紧张劳累相关，每年春季多发，白天发作、无夜间痛醒；近一年内出现两次黑便，近两个月出现呕吐。初步判断需进一步检查以明确诊断。

# 病史与背景
- **现病史**：上腹烧灼痛反复发作4年，近3个月加重，疼痛位于心窝处，与进食冷硬刺激性食物及工作紧张劳累相关，每年春季多发，白天发作、无夜间痛醒，近3个月有完全不痛的时候。
- **伴随症状**：近一年内出现两次黑便（一次在一年前，一次在三个月前），第一次持续约一个月并住院约10天，第二次住院两三天后好转，黑便每日最多两次、干便、形状基本正常；近两个月出现呕吐，吐出酸水样物及当日或隔日食物，吐后舒适。
- **既往史**：16岁时患甲肝，在三医院住院一个月，出院时肝功能正常，此后体检肝功均正常；小时候因扁桃体炎在儿童医院就诊，服用磺胺药后左手起红疹持续半个月，医生诊断为药物过敏。
- **过敏史**：磺胺药过敏（服用后左手起红疹，持续半个月）。
- **家族史**：父亲76岁有低血压，母亲75岁有冠心病且药物控制良好，有一个弟弟身体健康；一个婶婶（叔叔的爱人）患胃癌，患者担心自己是否也会得胃癌。
- **个人史**：出生于成都并一直在成都生活，未去过传染病疫区；在成都轻工研究所从事科研工作，工作紧张，经常加班熬夜；吸烟史为以前一天一包，现限制在10支以内并考虑戒烟；偶尔饮酒，平时不喝；每天喝两泡淡茶；26岁结婚，有一小孩，爱人及孩子身体健康；家庭居住条件良好，三口人住两房一厅，父母及岳父母均单独居住。
