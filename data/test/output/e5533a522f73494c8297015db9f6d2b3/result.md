# 核心观点
**具身智能大模型形态与硬件期待**
- 发言者2介绍团队：自己代表多模态大模型与具身智能融合方向，雄辉（于洋老师博士生）擅长强化学习，薛寒（卢策武老师博士生）擅长数据收集与柔性物体操作，志龙（于洋老师博士生）擅长具身模型世界模型。
- 发言者3从机械角度提问具身形态收敛方向，提及机械智能、软手等。
- 发言者4提出硬件需寿命长、可靠性高，现有工业机械臂不适合大规模真机评估。
- 发言者2认为具身是软硬件协同优化，提及松龄产品两代差异、凝胶夹爪优势。
- 发言者5认为大模型不应从上到下统一，应分层，大脑不变，小脑适应肢体。
- 发言者6认为人形机器人和特种机器人都会存在，提及马斯克公司花一半精力做22自由度灵巧手。
- 发言者7从产业角度分析具身智能融资规模，预测未来3-4波变革。

**世界模型讨论**
- 发言者2提出世界模型是否需重构pixel、3D，以及action的离散/连续问题。
- 发言者8从强化学习角度解释世界模型概念，强调可交互性，提及dyna Q、Smith Huber、杨乐坤等，认为当前世界模型物理规律欠缺。
- 发言者7认为CV界世界模型可作为RL工具，但技术栈深，RL领域不关注三维表征，讨论inductive bias，提及unison、朱松纯、imagenet等，认为数据量决定inductive bias需求。
- 发言者5举例刺客信条，认为世界模型可能无法统一，但policy可能统一。
- 发言者9提出反对意见，认为强化学习世界模型是任务导向，CV世界模型可能不必要，讨论统一表征与condition。

**强化学习与模仿学习路线**
- 发言者2提出强化学习与模仿学习两大流派，提及派零团队观察到模仿学习瓶颈，语言模型有RLHF环节。
- 发言者10介绍公司采用模型强化加机理融合，监督学习数据分布不足，强化学习依赖仿真环境，建议任务分层。
- 发言者9同意混合方式，认为复杂任务应先模仿后强化，单独模仿或强化都不行。
- 发言者5强调反馈作为reward，认为强化学习可行。
- 发言者11认为模仿学习和强化学习不冲突，可先获取运动先验。

**数据采集与仿真**
- 发言者2引出数据采集话题，提及open embodiment X、joy等数据集质量问题。
- 发言者11分享数据采集经验，强调视角和标定重要性，记录物体运动。
- 发言者4主张reward采集路线，认为仿真技术对柔性体模拟不足，可穿戴设备是scale方案，互联网视频数据与机器人数据差异大。
- 发言者2提及ego4d数据清洗耗时三个月，仿真数据与真实数据结合可提升成功率，提及国产仿真系统问题。
- 发言者7认为真实数据与仿真数据选择看成本，提出2025年主题是推广无标注数据。

# 达成共识与解决方案
**具身智能是软硬件协同优化的范式**（发言者2），硬件寿命与可靠性是规模化真机评估的前提（发言者4），凝胶夹爪等硬件改进可提升触觉反馈与稳定性（发言者2）。**大模型形态应分层**，大脑不变、小脑适应肢体（发言者5），人形机器人与特种机器人将并存（发言者6）。**世界模型在强化学习领域强调可交互性**，当前物理规律理解欠缺（发言者8），CV界世界模型可作为RL工具（发言者7），数据量决定inductive bias需求（发言者7）。**策略学习宜采用混合方式**，复杂任务先模仿后强化（发言者9），监督学习数据分布不足、强化学习依赖仿真环境，任务分层可提升性能（发言者10），模仿学习与强化学习不冲突，可先获取运动先验（发言者11）。**数据采集需控制视角与标定**，记录物体运动（发言者11），仿真数据与少量真机数据结合可显著提升成功率（发言者2），真实数据与仿真数据选择看成本（发言者7），2025年应推广无标注数据（发言者7）。
