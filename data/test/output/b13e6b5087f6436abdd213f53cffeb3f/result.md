# 访谈概述
本次对话由窦文涛主持，嘉宾为马先生与《明朝那些事》作者当年明月，从刚播完的日本电视剧《大奥》谈起，认为它是《大长今》之后最有影响的外国剧，三部剧时间跨度约相当于中国晚明到清初，另有一部在明治维新之前。对话认为日本文化核心是极端精神与忠诚文化，凡事做到尽头、发自内心，与中国讲中庸、讲融合的文化差异极大，并举例战后日本用30年成为世界第二经济强国、跳槽率最低、终身雇佣制、豆腐厂按点开工、做绳子的人几年不赚钱铺市场等。关于生死观，对话提到日本人重视死亡而非单纯藐视生命，剖腹自杀、看樱花只看落的那一天，被认为源于岛国生存条件恶劣。关于明史，当年明月表示写明朝是因为明史资料最多、自己最熟，但明清史料说法不一如罗生门，明朝本身跌宕起伏，朱元璋从乞丐到皇帝被推崇为人才，历史经验教训难以套用。对话还提到正德皇帝被写坏、豹房实为动物园、晚明江南市民生活富足、明末灾荒与瘟疫导致李自成起义和明朝灭亡，以及中国王朝约300年大限。

# 访谈详细记录
一、《大奥》与日本文化
- 发言者3认为《大奥》是大长今以后可能最有影响的外国电视剧，拍得非常好。
- 发言者3介绍该剧三部，前两部大概相当于中国晚明到清初，发言者2补充后来还有一部在明治维新之前，是一部有跨越性的历史剧。
- 发言者2表示吸引他的是严谨的精神，看日本剧看不到群众演员笑场。
- 发言者3称听人说这是大长今以后最重要的外国剧，第1集片头将军出场时所有人呈45度开始鞠躬，依次鞠躬，场面之华丽包括色彩，一看就不一样。
- 发言者3介绍大奥就是普通话说的后宫，日本话的奥指很深的地方，屋子最里处叫奥，一般人不准进去。
- 发言者2说明日本天皇一直是摆设，实际掌管权力的是幕府将军，德川家康开创德川幕府后日本所有权力掌握在一个人手上。
- 发言者2称从实际上看幕府将军对天皇一点都不崇拜，天皇没钱办活动找将军要钱，将军不给，活动没办，后来还有为表示对幕府抗议而退位的。
- 发言者2认为日本文化从头到尾没有变，核心是极端精神，所有事情要做到尽头。
- 发言者3称日本是发自内心的，战后1945年以后用30年成为世界第二经济强国，是必然不是偶然，是唯一没有资源的国家。
- 发言者2认为中国文化精神是中庸，讲究融合，是一条最适合的路；日本精神恰相反，坚持一个原则。
- 发言者3称日本是忠诚文化的典型国度，坚韧不拔，做到极致。
- 发言者1提到有极端批评说日本人的忠诚叫家奴、奴。
- 发言者3称日本跳槽率最低，每一次跳槽都是社会资源的浪费。
- 发言者2称西方经济学家一直不能理解日本终身雇佣制，认为缺乏竞争会导致效率极低下，但日本终身雇佣了人家还是积极性特别高。
- 发言者3举例去日本参观最底层工厂，豆腐规定当天做当天卖，夜里11:45所有人坐好看着表，12点整所有人站起来开始工作，四点多钟干完，然后上市，今天的豆腐今天卖。
- 发言者2认为日本是岛国，没有资源，经常火山地震，人对世界有极强求生欲望，必须融入团体按固定规则做事才能生存。
- 发言者3称日本投机取巧的人没有生存环境，社会文化的鄙视非常难过，所以不能生存。
- 发言者3举例日本做绳子做到全日本第一的人，长达几年不赚钱，从批发处进货一分钱不赚送给客户，等把市场铺平后，拿单子跟两边各加2%，全国4%就是不得了的一个数。
- 发言者2称慢慢走或者不偷奸耍滑，是一条更快到达成功的道路。
- 发言者3称在这种文化中你愿意也做不成，你的文化不允许这种现象生存；强调忠诚最终一定要落到一个好处，所以这个民族才团结。
- 发言者2称很不愿意做日本人，因为很多时候像盲从，而且他们有一种寻死的潜在欲望。

二、日本生死观与忠诚
- 发言者2称日本人看樱花不看发芽的时候，只看落那一天，由于常年以来生活在岛国上，生存条件太恶劣，对死亡不是藐视，是有点向往或者说不惧怕。
- 发言者2称二战时日军到中国有那么多暴行，是一种藐视生命的行为。
- 发言者3认为日本民族不是藐视生命，是重视死亡，是翻着的；剖腹自杀不是藐视生命，是重视死亡；经济危机时日本很多身家万贯的人剖腹自杀。
- 发言者1提到有极端批评说日本人的忠诚叫家奴、奴。
- 发言者3称我们不能再用另外一个标准去评判它。

三、明朝历史与明史研究
- 发言者2表示写明朝是因为明史最熟，明史资料最多；历史界研究有两个难点，第一是先秦春秋，没史料，史记就那么一两篇，都是编的；第二是明清，明实录几千万字，明代史官的记录，明通鉴、明史纪事本末、明会典、纲目三编这些书堆得比山还高，但一个说法可能有7个不同，一个事件可能有7个不同说法，就好像罗生门。
- 发言者3称明朝本身260多年的过程跌宕起伏，几次都要死没死了，土木堡之变、夺门之变各种之变特别多，皇上已经被瓦剌军抓起来了，哥几个一攒吧说那不算，又把弟弟扶起来了，完全构成一个现代版的电视剧。
- 发言者1提到当年明月对朱元璋好像很推崇。
- 发言者3称一个乞丐坐到最上面独此一份，刘邦好歹是个村长亭长。
- 发言者2称推崇朱元璋因为他太不容易了，从一乞丐一直到最后推翻元朝当上了皇帝，定了多少规章制度，明朝的规章制度由他定下来，基本上没有什么太大的改动。
- 发言者3认为人的因素最大，改变时势一定是出现一个人。
- 发言者2称朱元璋天分相当高，举例李云龙没上过军事院校能打仗，会打仗的人打仗，不用看兵书，天赋。
- 发言者1提到朱元璋的选择有点逼上梁山的性质，好友汤和让他去参加起义军，他在庙里犹豫，怕被杀头，后来因为信差送信被人告发，没办法只能去起义。
- 发言者2称历史最重要的是你一定要弄明白它是发生过的，当年那是造反，于他而言是非常有风险的事儿。
- 发言者3称历史你回过头看谁都是一个聪明人，你站在一个历史的原点的时候，你前后都看不见，你必须撤出来，你才能看见他。
- 发言者3称明朝有仁宣盛世，晚明时尽管史书上一再说政治如何黑暗、皇帝如何不上朝，但老百姓生活很好。
- 发言者4提到金瓶梅写的西门庆是一个阶层。
- 发言者2称明末那段时间很多真相是被掩盖的，市民生活特别轻松舒服，想去哪去哪，连皇册都不用了，到处走，去给人打工；当年江浙一带兴起了工商业，给人当雇工活得很滋润；三言二拍这种娱乐产品的出现说明有能够养活自己的资本；后来李自成闹起义是因为陕西那一带发生了大规模的灾荒。
- 发言者3称从当时器皿可以看到人的生活乐趣，明末工艺变得非常精细，有点像日本的工艺，日本派了大量工匠跟中国交流。
- 发言者2称看到的史料穿什么都有，至少江南那一带确实非常富足。
- 发言者3称文征明、唐寅、董其昌都是那个时期的人。
- 发言者3称一到朱搭的时候，八大山人明末了，画的都是翻白眼，前面无文化派的人画的都是小桥流水。
- 发言者2称历史经验教训说多少次了，我们从历史中得到的唯一教训就是我们从来没有从历史中得到过教训。
- 发言者2称历史那个事儿发生的时候是有背景的，你不比前人聪明，甚至可能比前人笨，当那种情况出现的时候，你也得那么办。
- 发言者2称史书上记载下来是照片，而实际上古人的生活都是录像，你不知道为那一幕之前跟之后是什么，不知道当时为什么要做这个选择，所以千万不能套用，套用那一定要倒霉。
- 发言者2称明代这个朝代很有趣，什么事都有，宦官专政魏忠贤、刘瑾，文官专政张居正，皇帝专政朱元璋、朱棣，谁都可能当老大，而且什么都能发生，皇帝出去了还能回来了，还能做皇帝。
- 发言者2称晚明时期吴三桂跟满清合作要入关，陈圆圆是一个原因，还有一个原因是他认为崇祯死了，当时说法是我们入关是为崇祯皇帝复仇，吴三桂很忠诚于崇祯皇帝。
- 发言者2称1644年明朝灭亡那一年，李自成军打到京城没有人抵抗，因为有些史料记载1644年明朝首都北京闹瘟疫，叫疙瘩瘟，今天看疙瘩瘟就是天花。
- 发言者3称中国的历史王朝300年都是大限，一逼近300年的时候你自己就没就完了。
- 发言者3称中国历史上如果严格讲跨过300年大限的只有宋朝，南北宋接上以后，退让了大半个国土，保证了它延续了319年；汉朝中间隔断14年是彻底空的；唐朝明朝清朝都没跨过这个界限。
- 发言者2称今天数世界上公司超过276人的有几家呢，没有几家，明朝做公司多大摊子几千万人。

四、明朝皇帝与晚明社会
- 发言者1提到一种观点说明朝和清朝在美这方面，故宫金碧辉煌大红大紫是满族人的趣味，真正明朝不是这样。
- 发言者3称宋明两个朝代是典型的汉人政权，汉人是文人政权，对美的判断不是表象的；满族是异族，对美的判断都是表象的；今天凡是那种非常外在美直观能看到美的都卖得非常贵，但在100年前晚清到民国初年的收藏，这种东西都不值钱，一定是素雅的。
- 发言者2称明朝皇帝是九五至尊，但皇上说要去一趟江南，大臣说不行就不行，明武宗正德皇帝要去，不让去，全跪金水桥前面，后来气坏了到锦衣卫去打，打死了十几个，还是不让去。
- 发言者1提到明朝有些史官就是要跟皇帝说点难听的，让你砍我的头，这样我青史留名，冒死就为了个名。
- 发言者3称这就是文化的力量，文化的力量是一个超出我们想象的力量。
- 发言者2称明武宗正德后来打服了一批人，非要去不去不行，到扬州说我要什么东西，政府说没有东西没有了，有也不给，皇帝不生气，说那我就回去，还让人准备酒席，然后说吃不了，你们把酒席折合成银两，我带回去。
- 发言者3称正德皇帝是明朝整个皇帝中最特殊、最鬼怪的一个个性，过去对他的评价非常低，说他荒淫，豹房是他弄的。
- 发言者1提到一个爱当木匠的皇帝，发言者3称那是天启，直接干活，干完活差大臣去卖，回来还打听卖得怎么样，卖得很好，他成就感特大。
- 发言者3称这从侧面反映了当时社会的一种时尚，当时家具在每个人心目中地位高，明式家具现在在国际上那么高的地位绝对不是偶然的。
- 发言者2称明代皇帝本身确实也没什么事干，明神宗几十年不上朝，但他不出去。
- 发言者2称但凡是明朝的皇帝，后人不会说前朝自己朝代的皇帝多差，正德特别差是因为接他班的是嘉靖，嘉靖不是他的儿子，是他堂兄弟，所以不能够把他写得太好。
- 发言者2称正德皇帝被说特别荒淫，豹房其实就是玩的地方，里边养了豹子，有动物园，女人肯定是有的，但在后宫也是女人，不影响其他什么问题。
- 发言者3称正德皇帝是有定论的说明朝最荒淫的皇帝，清朝最荒淫的是咸丰，咸丰还留了个种，正德不留种，没少找女人但没有生育能力。
- 发言者3称正德皇帝对宫廷以外的女人都有兴趣，宫廷内的女人确实没兴趣，因为宫廷内的女人被训练过，禁忌太多，太保守。
- 发言者2称据说正德去过，但没有具体的史料能够确实，史料没法记。
- 发言者2称正德从江南回来，没有进京城，在通州先停了半天，先派人打探，这是史料记载的，先停在这儿，你们先给我把情况看清楚了，京城里有没有人想搞埋伏搞圈套，非常有城府。
- 发言者2称明武宗实录是嘉靖时候编的，具体说就是嘉靖指派杨廷和这些人编的，这些人一般都有某些程度的偏颇，因为嘉靖上台先搞了个大礼仪事件，为这事死了很多人，为给自己父亲争个名分，他父亲是王爷，他要把他追封为皇帝。
- 发言者1称很多人研究历史就有傲慢与偏见，没有设身处地，老觉得自己聪明，判断他昏庸无能。
