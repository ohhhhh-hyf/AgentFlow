# 就诊概况
本次门诊由消化专科医生严医生接诊48岁男性患者张学恒，患者为成都轻工研究所科研人员。就诊围绕上腹反复疼痛4年、近3月加重的主诉展开，疼痛位于心窝处，有烧灼感，进食冷、硬、刺激性食物或工作紧张时发作，近3个月出现两次黑便及呕吐。初步判断需进一步检查以明确有无消化道出血及胃部病变。

# 病史与背景
- **现病史**：上腹疼痛4年，每年春季多发，近3个月反复发作；疼痛位于心窝处，有烧灼感，吃冷、硬、刺激性食物或工作紧张时发作，可忍受，白天为主，夜间无痛醒。
- **黑便史**：一年前及三个月前各出现一次黑便，持续约一个月，均住院治疗后大便转黄，住院时间约10天及两三天。
- **呕吐**：最近两个月呕吐数次，吐出黄水样酸味物，晚上腹胀想吐，吐后缓解，无隔夜食物及红色或黑色内容物。
- **既往史**：16岁时患甲肝，在三医院住院一个月，出院时肝功能正常，之后体检肝功均正常；小时候因扁桃体炎在成都市儿童医院就诊。
- **过敏史**：磺胺药过敏，小时候服用磺胺药后左手起红疹，持续半个月，医生告知不能吃磺胺药。
- **家族史**：父亲76岁，有低血压（90/60）；母亲75岁，有冠心病，服药控制良好；有一个弟弟，身体健康；一个婶婶患胃癌。
- **个人史**：吸烟，以前一天一包，现限制在10支以内；偶尔饮酒，平时不喝；每天泡两次茶；工作紧张，经常加班熬夜。
- **近期用药**：自行服用奥美拉唑（武汉药厂生产）、阿莫西林及所里医务室配制的胃炎合剂，效果逐渐变差，奥美拉唑用量从最初一天两次、每次一颗增至每天四五次。

# 诊断与检查结果
本次就诊未进行相关检查，医生建议留大便检查以明确有无出血，并预约胃镜检查。既往检查结果：16岁患甲肝时在三医院住院，出院时肝功能正常；近期未做过针对腹痛的检查。

# 治疗方案与医嘱
- **检查安排**：留取大便标本送检，以明确有无消化道出血；预约后天进行胃镜检查，因患者爱人后天可请假陪同。
- **生活方式**：建议戒烟、少喝酒，因吸烟饮酒可能加重胃部疾病；注意避免工作紧张、劳累和熬夜，这些因素可能诱发或加重病情。
- **复诊与沟通**：医生将总结病情后向上一级医生张医生汇报，再与患者商量下一步处理意见。
- **手术问题**：需等检查资料全面后再判断是否需要手术，若药物能控制病情则不需手术。
