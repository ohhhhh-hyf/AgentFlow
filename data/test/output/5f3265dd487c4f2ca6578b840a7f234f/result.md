# 就诊概况
48岁男性患者张春和，因上腹心窝处烧灼感疼痛反复发作4年、近3个月持续不适，就诊于消化内科。疼痛与进食冷、硬、刺激性食物及工作紧张劳累相关，白天发作，无夜间痛醒；近3个月发作期间曾两次出现黑便，最近两个月出现反酸、呕吐。初步判断需进一步检查以明确诊断，已安排留大便查潜血及胃镜检查。

# 诊断与检查结果
本次就诊尚未得出明确诊断结论，未进行相关检查。医生初步判断需进一步检查以明确诊断，已安排留大便查潜血（因曾两次黑便）及胃镜检查。既往史：16岁患甲肝，在三医院住院一个月，出院时肝功能正常，此后体检肝功均正常；对磺胺药过敏（小时候因扁桃体炎服用后左手起红疹，持续半个月）。

# 治疗方案与医嘱
治疗计划：待检查资料全面后，由上级张医生（指导教授）汇报后商定处理意见；若药物能控制病情则不需手术，如需手术再商量。生活注意事项：建议戒烟、尽量少喝酒，因吸烟和饮酒对胃肠道疾病有影响；注意休息，避免过度劳累和熬夜。重点禁忌：**磺胺药过敏，禁用磺胺类药物**。
