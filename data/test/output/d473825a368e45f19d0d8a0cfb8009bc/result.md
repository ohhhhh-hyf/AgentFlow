# 参观概况
本次参观为故宫博物院游览攻略讲解，由导游（发言人1）以视频形式系统介绍故宫主要景点、历史典故、免费盖章点及游览路线。讲解覆盖午门、太和门、太和殿、中和殿、保和殿、乾清门、乾清宫、交泰殿、坤宁宫、储秀宫、翊坤宫、永寿宫、太极殿、慈宁宫、寿康宫、断虹桥、武英殿、文华殿、箭亭、钟表馆、珍宝馆、珍妃井、东筒子夹道、延禧宫、景仁宫、御花园、神武门等约27处景点，全程约12分钟，以中轴线为主干、穿插东西两侧支线，形成完整游览动线。

讲解核心围绕建筑规制与历史功能展开，如午门“明三暗五”门洞规制、太和殿盛大典礼功能、保和殿殿试考场沿革等，并穿插皇帝立储、慈禧居住等历史典故。导游同时汇总**七个免费盖章点**（合计22枚免费印章）、**三条游览路线**（分别约2小时、半天、全天）及紫禁城100购买与盖章规则，供游客按时间与体力自行选择。

# 核心看点与讲解
- **午门**：排队检票处，明朝皇帝在此杖打犯错大臣，清朝皇帝在此颁发次年历书（颁朔之礼）。门洞呈“明三暗五”规制——正面看三个门洞，进门后变五个；中间正门仅供皇帝行走，皇后大婚时可进一次，殿试前三名（状元、榜眼、探花）可出一次，两侧门洞走皇亲国戚和文武百官。
- **太和门广场**：眼前有五座金水桥，皇帝走中间桥，黄金国器走挨着中间的两座桥，文武百官走最边上。太和门是明朝皇帝御门听政（上朝）的地方，门口铜狮子为故宫六对铜狮中最大的一对，脚踩寰宇象征权力，建议单独拍照即可，不宜站在其下合影。
- **太和殿**：即金銮殿，但并非上朝场所，而是举行盛大典礼之地，如皇帝登基、皇后册封，文武百官在太和殿广场朝拜。百官站位遵循“文东武西”——文官站东边，武官站西边；西边红衣阁是皇帝银库，东边体仁阁是缎库。
- **中和殿**：举行盛大典礼时皇帝的休息室，文武百官站好后皇帝再前往太和殿。
- **保和殿**：自乾隆五十四年起为科举考试殿试考场。东北角有汉字馆，内有4枚免费印章，可购买《紫禁城100》并现场盖章；故宫多处可购此书，但每家店印章不同，从汉字馆购买后不能去其他店铺盖章，汉字馆印章数量据称最多，盖完可邮寄到家或自行带走。
- **乾清门**：过此门即后宫（皇帝与妃嫔生活区域）。东边九卿直房是等级高的大臣等待皇帝召见之处，西边为军机处。门口铜狮耳朵耷拉、眉毛遮眼，意在警示后宫之人“不该看的别看，不该听的别听”。
- **乾清宫**：皇帝平时睡觉之处，内有27张龙床，据说是为防止刺客找到皇帝位置。牌匾“正大光明”后藏皇帝立储秘密——皇帝写两份立储诏书，一份藏于牌匾后，驾崩后两份对比，名字不一致即说明诏书被动过手脚。门口有铜鹤铜龟及紫禁城最小宫殿“社稷江山金殿”，提醒皇帝将江山社稷、百姓民生放在首位。
- **交泰殿**：内放25块传国玉玺。
- **坤宁宫**：住皇后的宫殿，明朝所有皇后都住于此。东北角文创店有5枚免费印章。
- **储秀宫**：慈禧住了20多年的地方，现为慈禧五十大寿时期原状陈列，慈禧喜欢此处因其子在此出生。旁边文创店有3枚免费印章。
- **翊坤宫、永寿宫、太极殿**：翊坤宫和永寿宫为东西六宫建筑，永寿宫西边是东西六宫中唯一被称为“殿”的太极殿。
- **慈宁宫、寿康宫**：慈宁宫是康熙为奶奶孝庄皇太后修建的养老院，旁边寿康宫为甄嬛（《甄嬛传》人物）居住地。
- **冰窖书吧**：有3枚免费印章，印章造型好，盖章时有批折子的感觉。
- **断虹桥**：网红打卡地，桥上石狮子形态各异，最有名的是“捂裆狮”。
- **武英殿**：后改为陶瓷馆，目前关闭状态，只能在门口观看。
- **文华殿**：与武英殿对应“文东武西”，导游去时未开，据说现有一个展览。
- **箭亭**：清朝皇帝及子孙练习骑马射箭之处，旁边商店可买文创雪糕。
- **钟表馆**：展示古代钟表造型，令人开眼界。
- **珍宝馆**：强烈建议参观，实为宁寿全宫，是乾隆给自己修建的养老院，乾隆退休后未放权仍照常上朝。馆前有我国现存三座古代九龙壁之一，左边数第三条白龙下方有一块木头——据传当年烧制琉璃砖瓦时弄坏一块，工匠为保命用木头刷白漆以假乱真。馆内并非单独展厅，院子周围屋子都值得参观，凤冠展品游客极多。皇极殿据称1:1复刻乾清宫，宁寿宫对标坤宁宫，养性殿后为乐寿堂——故宫内唯一能进去参观的皇家寝室，有二龙戏珠设计，让人联想到恭王府和珅卧室。
- **珍妃井**：慈禧当年把珍妃丢进去之处，现井口石非珍妃进入的原口。
- **东筒子夹道**：长长的夹道，拍照非常出片。
- **延禧宫、景仁宫**：延禧宫为网红打卡地，景仁宫是甄嬛被封熹妃时所住，珍妃也住过。
- **御花园**：内有钦安殿，供奉真武大帝；紫禁城靠山景山从天上看酷似闭目盘坐人像，有人说该造型就是真武大帝。
- **神武门**：故宫北门，游览终点。出门左手边有两个盖章点——角楼咖啡（2枚免费印章）和故宫文创（2枚免费印章）。

# 互动与体验
- **盖章互动**：导游全程标注了**七个免费盖章点**，并提示喜欢盖章的游客可截图保存位置。各点印章数量分别为：保和殿东北角汉字馆4枚、坤宁宫东北角文创店5枚、储秀宫边文创店3枚、冰窖书吧3枚、珍宝馆出口右手边商店3枚、神武门出门左手边角楼咖啡2枚、神武门出门左手边故宫文创2枚。
  - **汉字馆盖章**：位于保和殿东北角，有4枚免费印章，可购买《紫禁城100》由工作人员现场盖章。导游评价“这感觉真是盖了帽了”，并调侃“怪不得乾隆那么喜欢盖章”。
  - **购买限制**：故宫内多处可购买《紫禁城100》，但每家店印章不同，从汉字馆购买后不能去其他店铺盖章，导游提醒“注定得有所取舍”，并称汉字馆印章数量最多。
  - **冰窖书吧盖章**：位于慈宁宫、寿康宫南侧，有3枚免费印章。导游称印章造型好，盖章时有“批折子的感觉”，并在此购买了冰溪图。
  - **珍宝馆出口商店盖章**：从珍宝馆出口出来后右手边往里走有商店，有3枚免费印章，导游提醒别漏掉。
- **文创雪糕体验**：箭亭旁商店可购买文创雪糕，导游以提问方式互动：“有谁知道他是谁吗？欢迎在评论区分享一波。”
- **拍照打卡点**：导游多次提示适合拍照的位置，包括太和门铜狮子（建议单独拍张照即可，不宜站在其下方合影）、东筒子夹道（“拍照非常出片”，受小姐姐们喜爱）、断虹桥（可寻找形态各异的石狮子中著名的“武当狮”）。
- **珍宝馆参观体验**：导游强烈建议参观珍宝馆，称“每一样都能让您忍不住说出平时常用的感叹词”，但提醒游客众多，尤其是看凤冠的“没点技术还真挤不进去”。
- **乐寿堂体验**：位于珍宝馆区域内，是故宫里**唯一能进去参观的皇家寝室**，可见二层仙楼设计，导游提示可联想到恭王府和珅的卧室。
- **个人游览数据**：导游按第一条路线走完全程，一天走了**3万步**，并提醒游客游览过程中“别忘了适当休息和补充水分”。

# 收获与建议
- **择时与排队**：建议早来排队，一进门就沿中轴线往里冲，可错开大批旅游团人群；导游本人一天走了3万步，游览中需注意适当休息和补充水分。
- **路线选择**：共三条路线可选——第一条走完视频内所有景点，适合打算在故宫待一整天的游客；第二条沿中轴线看坤宁宫后去景仁宫、延禧宫，再逛钟表馆和珍宝馆，出御花园从神武门出，约半天时间；第三条沿中轴线看坤宁宫后去储秀宫，出御花园从神武门出，约2小时，最省力。
- **盖章点汇总**：共七个免费盖章位置——保和殿东北角汉字馆4枚、坤宁宫东北角文创店5枚、储秀宫边文创店3枚、冰窖书吧3枚、珍宝馆出口右手边商店3枚、神武门出门左手边角楼咖啡2枚、神武门出门左手边故宫文创2枚。
- **紫禁城100购买提示**：故宫里不止一处可购买紫禁城100，每家店印章不同；从汉字馆购买后不能去其他店铺盖章，需有所取舍；汉字馆印章数量据说是最多的，盖完可选择邮寄到家或自行携带。
- **拍照建议**：太和门门口铜狮子是故宫六对铜狮中最大的一对，但建议单独给狮子拍照即可，不要站在狮子底下合影，因大爪子正好盖在头顶上。
- **珍宝馆参观提示**：珍宝馆并非单独展厅，院子周围屋子都值得进去看；游客非常多，尤其是看凤冠的区域，需有技术才能挤进去。
- **陶瓷馆状态**：武英殿已改为陶瓷馆，但目前处于关闭状态，只能在门口看看。
- **文华殿展览**：导游去时文华殿未开放，据说现在有一个展览，感兴趣可前往观看。
- **文创雪糕**：箭亭旁边商店可购买文创雪糕，导游未指明雪糕造型对应人物，欢迎在评论区分享。
- **断虹桥打卡**：断虹桥是网红打卡地，桥上石狮子形态各异，最有名的是武当狮，可自行寻找位置。
- **东筒子夹道**：从珍宝馆出口出来后的长夹道，拍照非常出片，是很多游客喜欢来的地方。
- **延禧宫与景仁宫**：延禧宫为网红打卡地，景仁宫是当年甄嬛被封为熹妃时居住的地方，珍妃也住过。
- **寿康宫打卡**：寿康宫是甄嬛居住的地方，喜欢看《甄嬛传》的游客可到此打卡。
- **珍妃井说明**：珍妃井上现放的叫井口石，珍妃并非从那个小眼进去的。
