# 电子科技大学电子科学与工程学院研究生招生宣讲会纪要

## 沟通背景

本次直播为电子科技大学电子科学与工程学院研究生招生宣讲会，由学院领导段院、柳教授、张教授、李天明教授及在读博士田雨桐面向考生和家长，系统介绍学院历史沿革、学科布局、师资科研、人才培养及招生政策。会议依次展开学院整体情况、电子信息材料与元器件、电磁场与微波技术与电路与系统、物理电子学等方向介绍，并由在读博士从学生视角分享择校经验。整体沟通基调为权威推介与务实答疑并重，全局成果定调为：全面呈现学院作为电子科学与技术一级学科国家重点学科建设单位在科研平台、师资力量与人才培养上的综合实力，明确招生专业与咨询渠道，并回应夏令营安排等考生关切。会议最后公布招生咨询QQ群及抽奖口令，完成互动收尾。

## 核心信息

### 1. 学院整体情况

- **历史沿革**：1956年建校时成立无线电系、电真空器件系、无线电零件系，经1979、1992、2001、2018年四次院系调整成立电子科学与工程学院，2023年成立电子科学与工程学院与集成电路学院。
- **学科设置**：电子科学与技术为一级学科国家重点学科，下设电磁场与微波技术、电路与系统、微电子学与固体电子学、物理电子学、电磁信息功能材料与机构5个二级学科方向，另有3个国防特色学科。
- **学生规模**：本科生现有1545人，招生专业为工科试验班（电子工程类），含电子科学与技术（国家特色专业、国家级一流本科专业建设点）和电磁场与无线技术两个专业方向；研究生现有硕士和博士研究生1975人，招生专业包括学术学位博士/硕士电子科学与技术、硕士材料科学与工程，专业学位博士/硕士电子信息、材料工程。
- **师资队伍**：现有教师302人，其中教研系139人、科研系95人、教学系14人、实验系21人，教师总数269人，机关33人；含两院院士2人、领军人才19人、青年人才28人、其他类型人才12人、后备61人。
- **科研实力**：近5年科研经费到账稳定在3~4亿元，以纵向项目为主；牵头获国家科技奖励11项，发表高水平论文2000余篇，申请专利1600余件、授权1300余件；共有20个科研团队，年度经费过千万元的团队15个，其中过亿元团队1个。
- **平台建设**：拥有国家电子辐射控制材料工程技术研究中心、微波电子器件国家级重点实验室两个国家级平台，4个国际合作平台，7个省部级科研平台；共建国际姊妹院系2个（香港大学电机工程电子系、香港城市大学电子工程系），主办高水平国际会议13场，学生长短期交流项目20多个。
- **荣誉资质**：学院党委入选教育部首批全国党建工作标杆院系，荣获全国教育系统先进集体；拥有两个全国高校黄大年式教师团队，2022年获批4个国家自然科学基金创新群体。

### 2. 电子信息材料与元器件方向

- **国家需求背景**：2021年中国集成电路电子产品进口额度达2.8万亿元，约为原油进口量的1.7倍；先进电子材料、元器件、电路系统等电子产品是我国最紧迫的卡脖子问题之一，应用于6G通讯、量子技术、智慧城市、光电技术、新能源、智能电子等领域，市场规模达万亿美元量级。
- **研究团队**：含国家级人才10余人，主要有两个团队——邓龙江院士领导的电磁辐射控制材料与技术团队（研究人员19人，正高13人、副高15人，近年发表含Nature在内论文300余篇，承担国家省部级及国际合作课题130余项，年均到账经费3000多万元，授权发明专利100余项，获国家科技进步奖或技术发明奖二等奖共3项）；张怀武教授领导的磁电薄膜与微型器件团队（研究人员17人，正高15人、副高2人，承担国家重点研发计划、自然基金重点重大科学仪器项目等100余项，获科技进步二等奖3项，发表SCI论文400余篇，年均到账经费2000余万元）。
- **科研平台**：依托国家电磁辐射控制材料工程技术研究中心（历史可追溯至1990年校级材料与技术研究中心，2008年、2013年两次升级）和电磁薄膜与集成器件全国重点实验室（2006年依托新型传感器、功率半导体技术、电子信息材料三个部级重点实验室筹建）两个国家级平台。
- **条件与成果**：科研面积2万余平米，其中超精尖3000平，建设两条国家重大任务试验生产线，拥有大型设备或系统500余台套；材料制备设备约50余台套，微纳加工设备30台套，微观表征设备10余台套，性能测试设备50余台套；已获国家技术发明等奖项共计7项。
- **毕业生去向**：包括英特尔、中芯国际、华为、德州仪器等企业及高校科研院所。
- **学生成果**：在读学生杨伟豪以第一作者在Nature Electronics、Nature Communications各发表一篇论文；5G滤波器芯片学生团队获挑战杯创新创业大赛四川省金奖；黄飞获2018年四川省优秀毕业生并获斯坦福大学博士全额奖学金；李凤霞读博期间发表论文16篇（一作6篇）；严巍获2020年华为光产线优秀合作项目奖、2021届王大珩光学奖，博士毕业后以优秀青年学者身份加入苏州大学；万位现任河北美泰电子科技公司副总，带领团队采用MEMS工艺研制出SIW环形器隔离器，突破卡脖子器件核心技术。

### 3. 电磁场与微波技术、电路与系统方向

- **学科方向**：电磁场与微波技术包含微波毫米波电路、电波传播与电磁兼容、计算电磁学与工程电子学、天线理论与技术4个细分方向；电路与系统包含非线性电路与复杂电子系统、射频微波电路与系统、集成电路与系统3个方向。
- **历史沿革**：电磁场与微波技术学科始于1956年建校时期，由林卫干先生和谢楚芳先生创建，形成电磁场与无线技术国家特色专业和电波传播与天线国防紧缺特色专业，所属一级学科电子科学与技术入选双一流A类学科。
- **团队构成**：电磁场与微波技术有6个团队——电磁辐射与散射、毫米波技术与系统应用、微波毫米波集成电路与系统、电磁兼容技术、微波测试与成像技术、无线技术与集成系统。
- **学科平台**：含国家自然基金委创新群体、国家高等学校学科创新引智基地、国家工程技术研究中心、国家级重点实验室，拥有中国高校最先进的微波暗室群体及微波毫米波太赫兹仿真测试平台。
- **代表性成果**：杨世文教授团队研究四维天线阵列技术，成果应用于中电14所某大型机载相控阵雷达，在强耦合超宽带相控阵方面取得进展；樊勇教授团队研究毫米波平面集成天线，应用于毫米波通信雷达系统，研制出0.22THz、0.34THz、0.42THz雷达成像系统，分辨率小于1厘米，太赫兹通信成果在2023年成都大运会田径项目示范应用；李恩教授团队在微波毫米波测量技术方面有60多年技术积累，突破众多技术封锁，在生物医学电磁学及成像方向发表大量高水平论文，有20余项国家发明专利；杨世文教授团队在电磁测井仪器方面获国家科技进步二等奖一项，成果在中海油推广应用；延波教授团队在微波毫米波太赫兹芯片、固态合成功率源、天线阵列、扩电网络等方面取得成果，获国家科技重大专项及军科委支持，研制出三毫米导引头前端、毫米波引信前端、8毫米宽带收发前端；计算电磁学相关算法被评为20世纪十大算法之一。
- **电路与系统学科**：1981年开始招收研究生，1988年成立首批博士后流动站，含教育部国际合作联合实验室、国家高等学校学科创新引智基地，拥有国家级人才4人、新世纪人才2人、教授10人、副教授22人；樊勇教授和李廷军教授团队研制高速磁浮交通38GHz车地通信系统；樊勇教授和张静团队研究毫米波通信雷达CMOS芯片；康凯教授团队在毫米波CMOS芯片方向取得成果，包括超宽带模块级芯片及5G通信和雷达系统。
- **人才培养与就业**：连续三年获全国大学生集成电路创新创业大赛奖项，获华为优秀合作项目奖、研究生优秀导学团队提名奖，学生获互联网+、国际HPV等奖项；就业领域包括华为、中兴等领军企业及各大研究所、高校，毕业生海外留学也有突破。

### 4. 物理电子学方向

- **学科定义**：物理电子学是物理学与电子科学与技术的交叉学科，典型应用包括微波电子学（微波电真空器件）、光电子学（光电器件）。
- **发展历程**：起源于1956年建校时在前苏联专家帮助下成立的电子器件专业，1979年在刘成刚院士带领下成立高能电子学研究所，2001年成立物理电子学，2018年成立电子科学与工程学院。
- **研究方向**：纵向发展包括上游仿真设计（拥有自主知识产权商用软件MMST和切皮克）和下游系统应用（毫米波雷达、无线输能系统、微波能干燥系统等），并引入人工智能到器件设计；横向发展包括频段向毫米波、太赫兹扩展，以及与医学交叉（太赫兹成像用于医学诊断）。
- **平台与规模**：拥有3个四川省工程中心或重点实验室，每年到校科研经费接近2亿元，为学院最多；是国际世界上最大的真空器件研究中心；2023年成功举办行业顶级会议；共有9个团队。
- **学生出口**：约1/3硕博连读、1/3去企业、1/3去研究所或其他（公务员等）；个人每年约2个硕士毕业、1个博士毕业。

### 5. 在读博士择校经验分享

- **城市优势**：成都为四川省会、国家中心城市、新一线城市、国家历史文化名城，电子信息产业发达，英特尔、华为、京东方等巨头汇聚。
- **学校与学科实力**：电子科技大学拥有电子信息博物馆，记录我国第一台晶体管收音机的诞生，构建了最完整的电子信息学科群；电子科学与技术学科在第4轮学科评估中获A+，稳居全国第一；学院拥有四大学科和19个科研团队。
- **团队情况**：田雨桐所在毫米波技术与系统应用团队在樊勇老师带领下，围绕微波毫米波理论与技术、天线理论与技术、元器件与电路、通信技术与系统、雷达成像技术与系统五大方向开展研究；团队硕博毕业生实现100%就业率，就业单位包括民营企业、大型央国企和头部科研院所。
- **奖助体系**：包括国家奖学金、学业奖学金、专项奖学金、新生奖学金、校园地国家助学贷款和生源地助学贷款等。
- **择校建议**：根据研究方向先选团队再选导师，可通过IEEE Xplore和中国知网等检索导师论文和指导研究生情况。

## 各方诉求

- **学院领导（段院）**：核心诉求为全面展示学院历史沿革、学科设置、师资队伍、科研经费与平台等整体实力，吸引优秀生源报考；关键关切为回应考生对夏令营时间安排的疑问，明确具体时间待定、相关信息将通过QQ群发布。
- **柳教授**：核心诉求为介绍电子信息材料与元器件方向的内涵、国家需求、研究团队、平台条件与毕业生去向，突出该方向在解决卡脖子问题中的重要性；关键关切为向考生传递该方向的国家战略价值与科研平台优势。
- **张教授**：核心诉求为介绍电磁场与微波技术和电路与系统两个学科方向的研究内容、历史沿革、团队构成、科研成果与人才培养情况；关键关切为展示学科历史积淀与前沿成果，明确就业领域与深造前景。
- **李天明教授**：核心诉求为介绍物理电子学的学科定义、学校发展历程、研究拓展方向、科研平台与团队情况，并说明学生出口；关键关切为传递该方向科研经费充足、平台规模国际领先的优势。
- **田雨桐博士**：核心诉求为从学生视角分享选择电子科技大学的8个理由，包括城市、学校、专业、团队、奖助体系等，并给出择校择导师建议；关键关切为以亲身经历帮助考生建立对学院学习生活与发展的直观认知。
- **主持人**：核心诉求为组织串场引导，推进招生咨询与直播互动环节；关键关切为落实夏令营时间答疑、公布招生咨询QQ群及抽奖口令，并引导中奖同学私信后台留下联系方式和收货地址。
