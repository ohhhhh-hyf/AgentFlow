具身智能圆桌论坛：技术路线与数据策略探讨

研讨背景与议题

本次圆桌论坛围绕具身智能领域的关键技术路线与数据策略展开，与会嘉宾与博士生就具身智能的形态与硬件期待、世界模型的定义与构建、强化学习与模仿学习的路线选择、数据采集与仿真数据应用四个议题进行了深入交流与观点碰撞。研讨旨在汇聚学术界与产业界不同方向的研究视角，探讨具身智能发展中的核心问题与可行路径，未形成明确决策。

  1. 具身智能的形态与硬件期待：探讨具身智能最终收敛形态（人形机器人或特种机器人），以及现有硬件对具身智能实验的适配性问题。
  2. 世界模型的定义与构建：讨论强化学习领域与计算机视觉领域对世界模型的不同理解，以及三维表征与归纳偏置在世界模型中的作用。
  3. 强化学习与模仿学习的路线选择：探讨监督学习、强化学习与模仿学习在具身智能任务中的适用边界与组合方式。
  4. 数据采集与仿真数据应用：讨论遥操作、可穿戴设备、仿真数据等多种数据获取方式的优劣，以及数据质量对模型训练的影响。

核心观点

具身智能的形态与硬件期待

  1. 形态收敛之问：发言者3提出具身智能最终形态是像人形机器人还是如《星际穿越》中可变形的大方块，并引机械领域「机械智能」概念，指出软手可通过强摩擦与顺应性在较大误差下仍抓得牢（发言者3）。
  2. 硬件寿命与可靠性要求：训练VLA需大规模真机评估，模型预测撞桌几次即损坏，难以可靠scale up；现有工业机械臂并非为此设计，需个人柔顺硬件结构支撑规模化评估（发言者4）。
  3. 软硬件协同进化：具身智能是软硬件协同优化范式，松灵产品第二代在遥操与策略部署上优于第一代；加凝胶的夹爪可反馈触觉且抓取更稳、摩擦力更好（发言者2）。
  4. 反对完全端到端：若大模型从最上直通最下，会消除硬件迭代可能性——新硬件（尤其软体机器人）出现时大模型可能需完全重新训练；至少应分两层，小脑应自适应肢体变化，如人手断了大脑仍能指挥另一只手完成泡咖啡（发言者5）。
  5. 人形与特种并存：特种机器人在工业生产制造中大量存在，人形机器人和特种机器人将来都会存在（发言者6）。

世界模型的定义与构建

  1. 强化学习视角的可交互性：世界模型概念可追溯至1990-91年强化学习之父Sutton的Dyna-Q文章，本质是黑盒，输出下一时刻观测，核心是可交互（发言者8）。
  2. CV视角的三维表征与归纳偏置：CV界追求重建物理世界，可作为RL世界模型的工具；但当前三维表征（voxel、光照纹理材质）在RL领域不受关注，如Dreamer等论文不带三维归纳偏置（发言者7）。
  3. 数据规模决定归纳偏置需求：数据多则归纳偏置少，数据少则需更多归纳偏置（发言者7）。
  4. 世界模型可能无法统一：因存在歧义问题，世界模型可能无法统一，而policy可能统一（发言者5）。
  5. 反对CV世界模型用于强化任务：CV世界模型对强化任务不必要，强化世界模型应针对任务本身（发言者9）。

强化学习与模仿学习的路线选择

  1. 业界实践：模型强化加机理融合：公司采用模型强化加机理融合方式；监督学习动作空间大、数据分布远不足以覆盖高维动作，纯强化学习强依赖仿真环境、难以做到sim-to-real迁移，需将决策规模与任务设定限制好（发言者10）。
  2. 复杂任务应先模仿后强化：看历史发展规律，复杂问题都是先模仿后强化，单独模仿或强化都不行；底层如PID在多数场景已能解好，没必要从零重新替代（发言者9）。
  3. 反馈可作为奖励：PID系统必有反馈，可作为强化学习的reward（发言者5）。
  4. 模仿与强化不冲突：两者只是获取运动先验的不同方式——有现成数据可从模仿学习角度做，没有数据可先用DeepMind的算法获取再以行为克隆形式实现（发言者11）。

数据采集与仿真数据应用

  1. 数据质量关键在视角与标定：Open X等数据集视角不固定，影响数据质量；随着技术进步数据质量会越来越高（发言者11）。
  2. reward采集路线：本人all in reward采集路线，现实世界是最好的仿真器；终极形态可能是脑机接口或机电方式，无感采集多模态数据（触觉、力觉、视觉、听觉内生），现阶段可穿戴设备是较能scale的方案（发言者4）。
  3. 互联网视频数据不适用：专门研究过发现，人们在互联网发布的内容与机器人所需数据差异很大（发言者4）。
  4. 仿真加少量真机数据可提升成功率：300条仿真数据加20条真机数据可显著提升成功率（发言者2）。
  5. 推广无标注数据利用：2025年应推广无标注数据利用，如segment anything（发言者7）。

达成共识与解决方案

未形成统一结论。本场研讨围绕具身智能的形态与硬件、世界模型定义、学习路线选择、数据采集四个议题展开，各方观点存在明显分歧，未达成正式决议。以下为各议题的倾向性认识与主流意见：

具身智能形态与硬件

  1. 软硬件协同优化：发言者2提出具身智能应是软硬件协同优化的范式，以松灵产品两代迭代为例，第二代在遥操与策略部署上明显优于第一代；夹爪加凝胶后可反馈触觉、增加摩擦力，体现协同进化价值。
  2. 硬件可靠性需求：发言者4强调具身智能实验对硬件寿命与可靠性的高要求——训练VLA需大规模真机评估，模型预测失误易导致撞桌损坏，现有工业机械臂并非为此设计，需个人柔顺的硬件结构以支撑规模化评估。
  3. 模型分层而非全端到端：发言者5主张大模型不应从上至下完全端到端，至少应分两个层面——以人手受伤为例，大脑仍能正常工作，说明小脑部分应自适应肢体变化，而非整体重训。
  4. 形态多元并存：发言者6认为人形机器人与特种机器人将来都会存在，特种机器人在工业生产制造中大量存在，不应只聚焦人形。

世界模型定义与构建

  1. 可交互性是核心要素：发言者8指出强化学习领域的世界模型概念可追溯至1990–91年Sutton的Dyna-Q文章，其定义为黑盒模型、输出下一时刻观测，本质是可交互概念；2018年Schmidhuber与LeCun的定义则包含表征与转移两个组件。
  2. 三维表征与归纳偏置的分歧：发言者7认为CV界追求重建物理世界，可作为RL世界模型的工具，但当前三维表征（voxel、光照纹理材质）在RL领域不受关注；发言者9持反对意见，认为CV世界模型对强化任务不必要，强化世界模型应针对任务本身。
  3. 数据规模决定偏置需求：发言者7提出数据规模决定inductive bias需求——数据多则偏置少，数据少则需更多先验约束。

强化学习与模仿学习路线

  1. 混合路线优于单一方法：发言者10从产业部署经验出发，认为当前阶段监督学习数据分布不足以覆盖高维动作空间，纯强化学习强依赖仿真环境、难以实现sim-to-real迁移，公司实际采用模型强化加机理融合方式；发言者9表示同意，并补充复杂问题最终都是先模仿后强化，底层PID等传统方法能解决的无需从零替代。
  2. 模仿与强化不冲突：发言者11认为两者只是获取运动先验的不同方式——有现成数据可从模仿学习入手，没有则可用DeepMind-style强化学习先获取数据再以BC形式建模，本质无冲突。

数据采集与仿真应用

  1. 现实世界是最好的仿真器：发言者4主张reward采集是低成本方案，现实世界数据优于仿真；终极采集形态可能是脑机接口或可穿戴设备，实现无感、多模态（触觉、力觉、视觉、听觉）内生采集。
  2. 仿真数据加少量真机数据可显著提升成功率：发言者2提到约300条仿真数据加20条真机数据即可显著提升成功率。
  3. 数据质量关键在视角与标定：发言者11强调视角和标定对数据质量的重要性，Open X等数据集视角不固定，影响训练效果。

解决方案

  1. 硬件适配：面向具身智能实验设计具备柔顺结构、高寿命、高可靠性的硬件本体，替代现有工业机械臂，支撑规模化真机评估（提出方：发言者4）。
  2. 模型分层架构：采用分层而非全端到端架构，小脑层自适应肢体变化，避免硬件迭代导致大模型完全重训（提出方：发言者5）。
  3. 混合学习路线：采用模型强化加机理融合方式，底层保留传统方法（PID、MPC等），上层结合监督学习与强化学习，弥补数据不足与仿真迁移缺陷（提出方：发言者10，发言者9认同）。
  4. 数据采集方案：现阶段采用可穿戴设备在人类操作过程中采集多模态数据，远期探索脑机接口等无感采集形态（提出方：发言者4）。
  5. 仿真与真机数据结合：以仿真数据为主、辅以少量真机数据微调，可显著提升任务成功率（提出方：发言者2）。

未决分歧与后续探索

  • 具身智能最终形态：发言者3提出具身智能收敛形态问题，类比星际穿越中可变形的方块机器人；发言者6认为人形机器人和特种机器人将来都会存在，各有用武之地；发言者5以断手后大脑仍能指挥新构型为例，主张模型不应绑定特定硬件形态。双方未达成一致，需进一步探讨不同形态的适用场景与硬件-模型解耦方案。
  • 世界模型是否需要三维归纳偏置：发言者7认为CV界追求重建物理世界，可作为RL世界模型的工具，但当前三维表征在RL领域不受关注，并主张数据规模决定inductive bias需求——数据多则bias少；发言者9持反对意见，认为CV世界模型对强化任务不必要，强化世界模型应针对任务本身，而非追求物理重建。双方围绕Dreamer等论文是否带三维偏置展开交锋，分歧未解。
  • 强化学习与模仿学习的最终路线：发言者10从产业实践出发，主张现阶段采用模型强化加机理融合方式，因监督学习数据分布不足以覆盖高维动作空间，纯强化学习又强依赖仿真环境、迁移困难；发言者9认为复杂任务应先模仿后强化，单独模仿或强化都不行；发言者11认为两者不冲突，只是获取运动先验的不同方式——有现成数据可从模仿学习入手，没有则可用强化学习先生成数据。最终路线未形成共识。
  • 数据采集方式优劣：发言者4主张reward采集是低成本方案，现实世界是最好的仿真器，终极形态可能是脑机接口或可穿戴设备；发言者2提到仿真数据加少量真机数据可显著提升成功率（如300条仿真数据加20条真机数据）；发言者7提出2025年应推广无标注数据利用（如segment anything）。遥操、可穿戴、仿真等路线的优劣仍在讨论中。
