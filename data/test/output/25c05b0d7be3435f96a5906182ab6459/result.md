# 庭审概况
本案系国家开发银行不服云南省高级人民法院2018云民初88号民事判决提起的上诉，案由为金融借款合同纠纷，被上诉人为云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司。本院依法组成合议庭公开开庭审理，由审判员李少平担任审判长，与审判员魏文超、黄年、王海峰、葛洪涛组成合议庭，法官助理张瑞。经核对，各方出庭人员身份均符合法律规定，东源煤电、东源煤业、曲靖电力三方合并发表意见。庭审围绕三个争议焦点调查辩论：一是抵押权与融资租赁所有权冲突及善意取得；二是罚息复利计算及起算日期；三是东源煤电东源煤业是否应连带给付违约金。合议庭休庭评议后提出调解方案，各方当事人均无异议，自愿达成调解协议，法院予以确认，庭后根据民事诉讼法第97条出具调解书。

# 举证与法庭调查
一、举证与质证。国开行提交2018年9月对曲靖电力公司的融资租赁查询证书、证据第54页和第58页东源煤电公司曲靖电力公司对设备权属的证明材料和股东会决议、证据第108页核查表等，主张已按央行规定查询融资租赁系统、对设备所有权尽到审慎义务。东源方提交2015年12月2日邮件及东源公司融资情况统计表，主张邮件中招银租赁一栏载明抵押物为恩洪电厂设备资产、抵押手续已登记，且设备名称与国开行抵押设备完全一致并用红色标注。招银租赁提交回租设备清单（证据第7页）、2013年和2015年审计报告（证据第82页、第95页），主张回租设备清单仅载明设备名称和生产厂家、未载明型号，出厂日期为2012年3月1日，而国开行现场核实的抵押设备铭牌生产日期均在2013年以后。

二、法官询问要点。合议庭询问：各方如何理解中国人民银行征信中心融资租赁登记的性质及法律后果；央行融资租赁登记系统有几种查询方式、能否保证查询到登记结果；国开行内部有无规定要求查询未果也须留存记录；融资租赁登记系统中设备唯一标识码是否为必填项；违反查询通知在多大程度上导致融资租赁司法解释第9条第2款的法律后果；第9条第2款举证责任如何分担；不同登记机构产生的登记信息冲突如何处理。

三、双方辩论的争议焦点。焦点一：国开行主张其抵押权完整无瑕疵、已尽基本查询义务、构成善意取得；东源方主张邮件已引起国开行注意义务；招银租赁主张国开行未在抵押时点查询融资租赁登记、不构成善意，东源煤电出资系无权处分。焦点二：国开行主张利息2179.572768万元、罚息4105.057957万元、复利191.820623万元；东源方主张2018年6月13日宣布贷款提前到期未给合理期限、罚息不应作为复利计算基数、复利再计算复利无合同依据。焦点三：国开行主张按借款合同第24条第3项支付千分之一违约金；东源方主张国开行未举证证明违反柜台前移和账户管理、且未先行限期纠正。

# 庭审结果
本案争议焦点为三项：一是抵押权与融资租赁所有权冲突及善意取得；二是一审判决对罚息复息计算及起算日期是否认定错误；三是东源煤电东源煤业是否应连带给付违约金。合议庭休庭评议后提出调解方案：国开行对东源煤电债权扣除破产已清偿本金外，利息2017年12月21日至2018年6月12日合计2179.5727万元、罚息2018年6月13日至2019年2月19日合计4105.0579万元、复利2018年3月21日至2019年2月19日合计191.8206万元，三项共计6474.4513万元；确认招银租赁对涉案6项设备享有所有权、对应债权1377.4137万元，确认国开行对93项设备有抵押权，双方对案涉全部发电设备整体盘活处置，调解书生效后20日内由国开行向一审法院提出执行申请启动司法处置，变现价款及费用双方各担50%；未实现债权按破产重整计划预留方案实现；东源曲靖电力承担管理费用并无条件配合司法处置；一审判决第2项第4项按判项确认；一审诉讼费用国开行诉请部分按一审判决执行、招银租赁诉请部分由国开行承担，二审诉讼费用由国开行和东源煤电各承担50%；协议签订后各方就本案问题不再存在争议。各方当事人对调解方案均无异议，自愿达成调解协议，法院予以确认，庭后根据民事诉讼法第97条出具调解书。合议庭指出，本案涉及的生产设备等动产抵押权与融资租赁物所有权冲突是司法实践中的普遍性难题，金融风险防控还有较大空间，根本原因在于国家还未建立统一的动产登记制度，现有动产融资租赁登记系统和动产抵押登记系统尚缺乏有效衔接，将根据最高人民法院关于加强司法建议工作的意见向有关部门提出司法建议。
