# 发布会概况
本次中金宏观策略周会由策略组刘刚凯文主持，围绕大美丽法案、关税更新、港股流动性、光伏反内卷、人形机器人及游戏板块等热点展开分析。会议指出大美丽法案三大块内容对信用周期有利，财政赤字率维持5-6%，三季度有流动性抽水效应，对美股美债不悲观；关税大概率要做，有效税率维持10-12%，市场逐渐脱敏；港股三季度流动性边际偏紧，但基本面强可盖过影响。光伏行业供需失衡，反内卷政策升级，硅料市场触底企稳；人形机器人三季度围绕三条主线展开；游戏板块政策友好、新品周期亮眼，调整后有望戴维斯双击。整体基调为在结构性行情中寻找机会，建议在合适位置布局长期正确板块。

# 核心信息
大美丽法案三大块：提高债务上限5万亿美元；延长2017年减税法案，新增支出3.4万亿美元（每年3400亿），同时减少新能源补贴等支出1.4万亿美元；取消899条款。财政赤字率维持5-6%，关税收入每年3000-4000亿可弥补支出。三季度流动性抽水效应约1万亿美元，美债利率可能上行但幅度或不及2023年（当时从3.8%升至5%）。关税有效税率当前10-12%，极端情况18%，大部分税率较4月2日对等关税水平回落，加拿大、墨西哥、欧盟单拎出，其他地区占比小。关注8月1日、8月12日中美谈判及转口限制。光伏行业：全球新增装机从2020年130GW升至2024年530GW，未来两年增速回落至10%左右；产能过剩，电池产能为需求1.5倍、硅片组件2倍、硅料2.5倍；2022年以来产业链价格下跌70-90%；多晶硅期货价格触及40元/公斤，硅片报价涨10%，电池涨2分钱。人形机器人：二季度A股板块跌约9%，跑输机械设备12个百分点；华为发布盘古世界模型和CloudRobot平台；智元机器人拟收购上市，宇树科技年收入突破10亿元，两家中标中国移动近1.2亿元采购订单。游戏板块：6月版号单月发放158个（国产147个、进口11个），为2018年以来单月最高；1-5月游戏市场规模同比增长17%，手游同比增长20%；TTM PE约30倍，2025年静态PE约20倍。

# 官方表态
刘刚凯文对大美丽法案表态：债务上限提高使违约风险消失，可提振增长；延长减税并非新增减税，而是避免大幅加税；取消899条款避免影响美元体系根基。对关税表态：关税大概率要做，需维持一定税率收钱，不能太高否则通胀受不了，市场逐渐脱敏，威胁高税率可能是谈判技巧。对港股流动性表态：三季度美元流动性供给压力，港币弱，金管局可能收紧，流动性不如二季度，但基本面强可盖过影响。刘佳妮对光伏反内卷表态：期待政府干预，认为有必要；价格恶性竞争有望告一段落，行业底部夯实。郭文秀对人形机器人表态：三季度是迷茫期到商业兑现的过渡阶段，关注三类信号。张雪琴对游戏板块表态：在消费、政策、新品周期三重利好下，游戏行业有望在调整后再次实现戴维斯双击。

# Q&A环节
问：大美丽法案对美股美债和美元流动性有何影响？答：刘刚凯文指出，法案三大块对信用周期有利，财政赤字率维持5-6%，三季度有流动性抽水效应，美债利率可能上行但幅度或不及2023年，对美股美债不悲观，波动提供再配置机会。问：关税升级市场为何反应冷静？答：关税大概率要做，有效税率维持10-12%，过高通胀受不了，市场逐渐脱敏，威胁高税率可能是谈判技巧。问：港股流动性三季度如何？答：美元流动性供给压力，港币弱，金管局可能收紧，流动性不如二季度，但基本面强可盖过影响。问：光伏反内卷政策进展如何？答：刘佳妮指出，政策级别提升，硅料环节最易整合，光伏玻璃第二轮产能出清，多晶硅期货价格反弹，硅料市场触底企稳。问：人形机器人三季度有哪些催化剂？答：郭文秀指出，围绕华为云生态、本土企业技术闭环、特斯拉延期硬件替代三条主线，关注物流场景、电机硬件优化等。问：游戏板块调整后是否可上车？答：张雪琴认为，政策友好、版号发放创新高、新品周期亮眼，估值TTM PE 30倍、2025年静态PE 20倍，调整后有望戴维斯双击。
