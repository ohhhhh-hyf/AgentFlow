# 知识主题与概述
GitHub 是一个面向所有人的大型开源资源库，既包含名校公开课、大厂面试题、开源大模型、AI 学习资料等实用内容，也收录表情包合集、职场黑名单等趣味资源。本期视频由工作室老李主讲，围绕 GitHub 的实用项目发现与使用技巧展开，内容覆盖三块：一是介绍工作性价比评估、表情包博物馆、健康指南、一键证件照、健身教练、教材资源、AI 视频生成、声音克隆、AI 学习资源库等热门项目；二是针对国内访问困难，讲解 Watt Toolkit 加速、镜像站、VPN 三种解决方案并比较优劣；三是讲解注册、页面汉化、搜索优化及项目主页各功能模块（star、watch、fork、About、release、readme 等）的使用方法。整体逻辑从「找什么」到「怎么访问」再到「怎么用」，层层递进，并穿插老李的个人使用体验与评价。

# 核心概念
## GitHub资源库定位
- **GitHub**不只是代码托管平台，而是每个人都可以用的**巨大宝藏资源库**，几乎想找的资源、教程、工具都能在上面找到
- 正经资源包括：麻省理工、斯坦福等名校公开课，字节、阿里、腾讯等大厂面试题和面试经验，Google、阿里等大公司最新的开源大模型，用AI搞副业赚钱的教程，AI学习资料等
- 不正经资源包括：国内这些年缺网火爆的表情包大合集、火到150岁养生指南、国内996最严重的大厂黑名单等

## 工作性价比评估项目
- 项目功能：输入年薪、工作地区、年假、通勤时长、学历、工作年限、领导同事情况等因素，综合评估后给出**工作性价比分数和评级**
- 老李测试之前程序员工作，评估结果为「性价比还不错，优质牛马」

## 表情包博物馆
- 收集国内过去这些年全网爆火的表情包大合集，包括甄嬛传、罗翔、特朗普、马保国等主题
- 用途：斗图时可把对方「按在地上摩擦」

## 健康活到150岁指南
- 分享经过科学论证的健康知识，如**间歇性进食**对身体有好处，会促进胆汁代谢、炎症自愈
- 吃天然发酵类食品可以改善肠道菌群生态

## 一键做证件照项目
- 上传一张大头照，即可一键抠图换背景，生成不同标准的证件照和各种规格的打印模板

## 丐版健身教练项目
- 选择要练习的肌肉群（如腹肌），项目提供用身体自重练习的参考动画，跟着做即可
- 适合请不起真人教练的用户

## 教材资源项目
- 收集国内所有小学、初中、高中及一部分大学的PDF教材，全部免费使用

## 全自动视频生成项目
- 项目名称为`Morning Printer Turbo`，近期超火

## 声音克隆模型ChatBox TTS
- 属于**零样本语音克隆**，特点是情感控制非常到位，克隆的声音像真人说话一样
- 使用方法：打开项目网页，上传一段自己的音频，合成一段英文台词即可试听效果

## AI学习资源库
- 涵盖大语言模型、`RAG`、`AI Agents`、`MSI`等最新AI技术
- 作者把所有教程内容整理成一份**500多页的PDF文档**，内含大量示意图帮助理解

## Awesome AI Apps项目
- 收录大模型最新的Agent应用，如医学影像数据分析Agent、AI投资Agent、竞争对手情报分析Agent等
- 适合跟进AI应用落地最新案例或寻找创业点子

## 解决GitHub访问问题
- **方法一**：使用`Watt Toolkit`加速软件——进入网站选择适合电脑的版本下载安装，打开后找到网络加速，勾选GitHub加速即可流畅访问
- **方法二**：使用GitHub镜像站，如`gh-proxy`——浏览器直接打开即可访问，默认是镜像的项目地址，搜索GitHub其他项目也没问题；但镜像站速度和稳定性较差
- **方法三**：使用魔法（VPN）——老李个人最推荐的方法
- 镜像站地址整理在文档中，需三连关注免费领取

## GitHub注册与汉化
- 注册GitHub很简单，用国内QQ邮箱就可以
- 解决全英文页面：给浏览器安装翻译插件，谷歌浏览器推荐`Google Translate`或`沉浸式翻译`，安装后可直接把网页翻译成中文
- 安装插件方法：点开浏览器三个点→拓展程序→管理拓展程序→搜索插件名安装
- 动手能力强的还可以安装汉化插件

## GitHub搜索方法
- GitHub原生搜索按关键词**精准匹配**，对国人不太好用——如搜`screen record`和`screen recording`按星标排序，结果不一样
- 推荐用AI搜索：在ChatGPT里用中文说「在GitHub上帮我找好用的录屏软件」，它会搜齐热门工具并总结成表格
- 找热门项目还可通过左侧`Explore`中的`Trending`，查看全站当天、本周、本月最热门项目
- 也可让ChatGPT帮忙找`GitHub daily`，及时分享最新最热门的项目

## GitHub项目页面构成
- 一个项目本质上就是一个文件夹，项目名字下面是子文件夹或文件
- `star`相当于对项目进行收藏和点赞，star越多说明项目越受欢迎，代表项目的「江湖地位」
- `watch`是关注项目，`fork`是复制项目到自己的账号
- 右边`About`是项目简介，一句话介绍项目是干啥的
- `release`是软件的安装包，点开可看到最新版本并下载安装
- `readme`文件是项目的说明书，默认在项目最下面展开显示，可了解项目用途、安装使用方法，是了解一个项目必看的内容
- 每个文件最近的`commit`日期可理解为最近更新时间，若更新日期是好几年前，大概率是没人维护的僵尸项目

## 易混点与适用边界
- **Watt Toolkit vs 镜像站**：Watt Toolkit更流畅，镜像站速度和稳定性更差；Watt Toolkit需下载安装并勾选GitHub加速，镜像站浏览器直接打开即可用。
- **GitHub原生搜索 vs AI搜索**：原生搜索按关键词精准匹配，搜「screen record」和「screen recording」结果不同；AI搜索（如ChatGPT）输入中文即可搜齐热门项目并总结成表格，解决英文不好、搜得不够准确全面的问题。
- **star、watch、fork的区别**：star是收藏点赞，watch是关注项目，fork是复制项目到自己的账号。
- **readme的定位**：是项目说明书，内容默认在项目最下面展开显示，用于了解项目干什么、怎么安装使用，是了解一个项目必看的东西。
