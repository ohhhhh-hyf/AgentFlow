# 就诊概况
本次门诊由消化专科严医生接诊48岁男性患者张学恒，患者为成都轻工研究所科研人员。就诊形式为初诊，患者因上腹心窝部反复烧灼样疼痛4年、每年春季多发、近3个月持续而来，疼痛进食冷硬或刺激性食物、工作紧张劳累时诱发，可忍受，无夜间痛醒，暖和轻松时无痛；一年前及三个月前各出现一次黑便，每次持续约一个月，每日最多两次，两次均住院检查诊断为大便出血，住院两三天后大便转黄；近两个月呕吐数次，吐出酸味黄水样物，含当日食物，夜间腹胀时呕吐后缓解。患者近期服用国产奥美拉唑（武汉药厂）和阿莫西林，自述增加剂量至每日四五次仍效果不佳。初步考虑上消化道疾病可能，需进一步检查明确，已安排留取大便标本及后天胃镜检查。

# 病史与背景
- **现病史**：上腹心窝部烧灼样疼痛反复发作4年，每年春季多发，近3个月持续；进食冷硬、辛辣等刺激性食物或工作紧张劳累时诱发，暖和、轻松时无痛，疼痛可忍受，无夜间痛醒。
- **黑便史**：一年前及三个月前各出现一次黑便，每次持续约一个月，每日最多两次，大便颜色改变但形状基本正常；两次均住院检查诊断为大便出血，住院两三天后大便转黄。
- **呕吐**：近两个月呕吐数次，吐出酸味黄水样物，含当日早、中餐食物，夜间腹胀时呕吐后缓解，无隔夜食物及红色、黑色呕吐物。
- **既往史**：16岁时患甲肝，在三医院住院一个月，出院时肝功能正常，此后体检肝功均正常；小时候因扁桃体炎在成都市儿童医院就诊，服用磺胺药后左手出现红疹，持续半个月，确诊磺胺过敏。
- **个人史**：吸烟史，既往每天一包，现限制在10支以内，计划逐步戒烟；偶尔饮酒，平时不喝；每天泡茶两次；双眼近视400度，偶有口腔溃疡。
- **家族史**：父亲76岁有低血压，母亲75岁有冠心病，弟弟身体健康；婶婶（叔叔的爱人）患胃癌，患者担心与此相关，严医生解释无血缘关系，不必过度担心。

# 诊断与检查结果
本次就诊尚未确诊，初步考虑上消化道疾病可能，需进一步检查明确。患者一年前及三个月前两次黑便均经大便检查诊断为大便出血，住院两三天后大便转黄；近三个月无黑便，大便黄色正常，小便正常，体重无明显下降。医生对家族史中婶婶患胃癌的情况进行解释，指出婶婶为叔叔的爱人，与患者无血缘关系，不必过度担心。患者担心是否需手术及出国进修安排，严医生表示待检查资料全面后再判断，若能药物控制则无需手术。

# 治疗方案与医嘱
- **检查安排**：患者需留取大便标本进行出血相关检查；胃镜预约在后天进行，因患者爱人可请假陪同，胃镜活检后恰逢张大夫查房，便于进一步诊疗。
- **生活方式与饮食**：建议戒烟限酒，因吸烟饮酒可能加重胃部疾病；注意避免进食冷、硬、辛辣等刺激性食物。
- **复诊安排**：严医生将总结病情后向上一级张医生（指导教授）汇报，再与患者讨论下一步治疗方案。
