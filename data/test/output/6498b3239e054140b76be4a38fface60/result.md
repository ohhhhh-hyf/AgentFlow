# 《电气工程基础》第一章导学与电力发展史讲解

## 课程概况

本次课程为《电气工程基础》第一章导学与电力发展史讲解。课程教学目的明确为两点：掌握电力系统发电、输电、配电、用电四个典型环节的构成、工作原理及其与电力系统整体的关系；掌握电力系统在分析、设计、运行、管理方面的基础理论、基本技术与基本计算方法。前修课程要求为电路理论、电机学，特别是变压器和同步电机知识；后续重要课程包括电力系统分析、电力系统机电保护、电力系统自动化、高电压技术。第一章为全书概念最多、最重要的章节，要求掌握电力系统、电力网、动力系统、变电站等基本概念，理解电力系统特点及其对设计运行的影响，掌握电能质量指标及国家标准规定范围，了解常用接地方式特别是中心点接地方式。三个学习难点为：电能不能大量储存决定的有功无功动态平衡问题、额定电压规定的繁杂性、中心点接地方式对后续章节的影响。课程主体梳理了从直流输电到交流输电、再到现代交直流混合输电的电力发展演进脉络，并系统讲解了三相交流输电优势、电力系统形成过程、电网分类与变电站分类方法。

## 核心知识点

### 1. 课程教学目标与学习要求

- **课程教学目的**：掌握电力系统发电、输电、配电、用电四个典型环节的构成、工作原理及与电力系统整体的关系；掌握电力系统在分析、设计、运行、管理方面的基础理论、基本技术与基本计算方法。
- **前修课程要求**：电路理论、电机学，特别是变压器和同步电机的相关知识。
- **后续课程衔接**：电力系统分析、电力系统机电保护、电力系统自动化、高电压技术。
- **第一章学习要求**：掌握电力系统、电力网、动力系统、变电站等基本概念；理解电力系统的特点及其对设计运行的影响；掌握电能质量指标及国家标准规定的范围；了解电力系统常用接地方式，特别是中心点接地方式。
- **三个学习难点**：电能不能大量储存决定的有功无功动态平衡问题；额定电压规定的繁杂性；中心点接地方式对后续章节的影响。
- **学习方法建议**：从基本概念内涵与外延入手，从电力系统特点与要求出发进行原理推导，寻找额定电压规定规律，比较不同中心点接地方式特点。

### 2. 电力发展简史：直流输电阶段

- **早期直流输电试验**：福泰勒使用2000米导线连接瓦斯发电机，拖动直流发电机、电动机和水泵，证明直流远距离输电可行。
- **1874年**：俄国工程师在彼得堡建成4.5公里直流输电线路，传输功率4.5千瓦。
- **1882年**：法国德普勒架设首条57公里直流试验线路，首端电压343伏、末端850伏，输送功率200瓦，损耗78%。
- **1883年**：德普勒从法国南部进行14公里输电试验，输送功率1.1千瓦，损耗55%。
- **1882年10月**：英国科学家发明直流输电三线制系统，外线与中线电压110伏，外线间电压220伏。
- **直流输电技术限制**：电压等级低时损耗大、电压降落快，制造大容量高压直流发电机困难。
- **19世纪末**：法国方剑串联多台直流发电机，将75千瓦电力输送75千米。
- **20世纪初期**：瑞典科学家在串联直流发电机上安装短路器，实现不停电切换，此后20多年建成15条直流输电线路。
- **1906年**：投运法国慕尼黑水电厂到里昂线路，180公里、57千伏、4700千瓦；1927年改建为260公里、125千伏、19000千瓦，接入两座水电站。

### 3. 交流输电的兴起与交直流之争

- **关键发明**：1876年俄国科学家发明单相变压器（主要用于照明）；1883年美国特斯拉制造感应电机；1885年匈牙利科学家设计多台变压器并联运行方式。
- **直流电阵营**：爱迪生与凯尔文主张推行直流电，理由是直流电效率高、交流电有危险性（曾购买威斯汀豪斯交流发电机用于死刑实验）。
- **交流电阵营**：威斯汀豪斯和特斯拉主张交流电，理由是交流电易用变压器升压降压、减少电能损失，交流发电机制造业发展为交流输电做了准备。
- **1886年**：威斯汀豪斯在美国麻省进行1.2千米30千伏交流输电示范；在意大利建成17英里、2千伏高压输电线路。
- **1886年**：俄国科学家发明三相交流电、三相交流输电和三相异步电动机。
- **第一条交流输电线路**：法国到德国的交流输电线路，采用三相发电机和升压变压器，在法兰克福建两座降压变电站，一座供展览会照明，另一座供100马力三相异步电动机。

### 4. 交流输电电压等级演进与直流输电复兴

- **电压等级演进**：1898年发明真实绝缘子，美国加利福尼亚输电电压提高到33千伏；1906年发明悬式绝缘子，建成110千伏高压输电；1912年发现电晕临界电压与导线直径成比例，铝线和钢芯铝绞线开始应用，美国建成154千伏线路；1923年均压阀技术应用，建成220千伏输电线路；1936年美国287千伏线路投运；1952年瑞典建成380千伏线路，首次采用分裂导线；1956年苏联400千伏双回线路投入运行；1965年加拿大建成735千伏输电系统；1969年美国765千伏线路并入电网；1985年苏联特高压1150千伏线路投运，后降压至500千伏运行。
- **中国交流输电发展**：224千伏线路1941年投运，330千伏1972年投运，500千伏1981年投运，1000千伏2009年投运（交流特高压首次）。
- **直流输电复兴背景**：交流大电网稳定问题突出，直流输电在联网中的优势重新显现。
- **直流输电复兴工程**：1954年瑞典本土与哥特兰岛建成世界第一个工业用海底电缆直流工程，电压100千伏、96公里，采用汞弧阀；1970年扩建50千伏、1万千瓦晶闸管换流阀试验工程；1972年世界第一个晶闸管换流阀背靠背直流工程在加拿大投运。
- **中国直流输电工程**：第一个为舟山群岛与浙江定海电网连接；第二个为1989年葛上直流（葛洲坝电厂到上海），±500千伏；今年6月投运云广直流±800千伏特高压直流工程。

### 5. 三相交流输电的优势与电力系统形成

- **三相交流系统三大优点**：易于产生旋转磁场，三相电动机易驱动；瞬时功率恒定；输电线路导线（金属）消耗量最少。
- **三相三线制优越性**：传输效率最高，金属消耗量在同等功率和功率因数下最小。
- **电力系统形成过程**：从单机向附近负荷供电，到多机互联提高可靠性，再通过升压输电扩大供电范围。
- **升压输电必要性**：输电线路参数（电阻、电抗）导致电压损耗和功率损耗，限制输电距离；升压可减小电流从而降低损耗。
- **电力系统定义**：发电机、变压器、输电线路和用电设备构成的整体，完成电能生产、输送、分配、消耗四个职能。
- **电力网定义**：电力系统中去除发电机和用电设备的部分，即变压器和输电线路构成的网络。
- **动力系统定义**：电力系统加上发电厂动力部分（火电锅炉汽机、水电水轮机水坝等）。

### 6. 电网分类与变电站分类

- **地方电力网**：电压等级110千伏及以下（早期35千伏及以下），供电半径20~50公里。
- **区域电力网**：电压等级110、220千伏及少量500千伏，供电半径超过50公里，联系较多发电厂和负荷中心。
- **超高压远距离输送网络**：电压等级500千伏或1000千伏（东北有330千伏），任务是将发电厂电能远距离送到负荷中心，构成跨省跨地区大型电力系统。
- **分类实例**：武汉电网属于地方电力网；华中电网属于区域电网；葛上直流、三峡到上海输电线路属于超高压远距离输电网络。
- **变电站按最高电压等级分类**：华工变电站10千伏，关山变电站220千伏，凤凰山变电站500千伏。
- **变电站按主要功率流向分类**：降压变电站（大部分功率从高压侧流向低压侧）、升压变电站（大部分功率从低压侧流向高压侧）。

## 问答记录

- **直流输电为何被交流输电取代**：直流输电电压等级低时损耗大、电压降落快，且制造大容量高压直流发电机困难；交流电易用变压器升压降压，可在电压提高状态下减少电能损失。
- **为何最终采用三相交流输电**：三相交流系统易于产生旋转磁场使电动机易驱动、瞬时功率恒定、输电线路导线消耗量最少；三相三线制传输效率最高，金属消耗量在同等功率和功率因数下最小。
- **为何需要升压输电**：输电线路的电阻和电抗导致电压损耗和功率损耗，限制输电距离；升压可减小电流从而降低损耗，扩大供电范围。
- **电力系统、电力网、动力系统三者区别**：电力系统是发电机、变压器、输电线路和用电设备构成的整体，完成电能生产、输送、分配、消耗四个职能；电力网是电力系统中去除发电机和用电设备的部分，即变压器和输电线路构成的网络；动力系统是电力系统加上发电厂动力部分（火电锅炉汽机、水电水轮机水坝等）。
