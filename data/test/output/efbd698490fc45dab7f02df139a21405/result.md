# 讲座概况
本次讲座由基金经理肖楠主讲，面向机构投资者，汇报其过去一年的研究布局、投资框架反思与认知升级，并回答投资者提问。肖楠首先指出投资者关心的“What happen next”问题因知识鸿沟而用处不大，并基于自身研究框架将问题分为重要不重要、可研究及难以研究四类，强调关心标的基本面变化、投资逻辑更新、认知深入和投资框架修正。他明确反对市场上“抱团”和“均值回归”两个流行观点，认为收益率是幂律分布，投资核心是找到长线超级大牛股。肖楠介绍过去一年在互联网、财富管理、新消费和高端制造四个方向的研究布局，并分享五点投资框架反思，包括商业模式分类不完备、从商增角度理解商业模式更本质、长期变量影响收益率、深度价值可能长期无效（打问号）、小企业的X factor。最后，他回答了投资者关于终局判断、伟大公司标准、全市场基金选股逻辑、血制品行业、农林牧渔行业、商增商减分析、增长曲线、财富管理行业及企业家精神等问题。

# 核心观点与论证
讲座按逻辑结构分为四部分。第一部分，肖楠提出知识与信息的鸿沟，指出投资者关心的“What happen next”问题用处不大，因为知识更新导致观点变化，而信息滞后。他基于自身研究框架，将问题分为重要不重要、可研究及难以研究四类，强调关心标的基本面变化、投资逻辑更新、认知深入和投资框架修正。第二部分，他明确反对“抱团”和“均值回归”两个流行观点。对于抱团，他认为定义不本质，基金经理之间是竞争关系，主观上不可能抱团；同一公司买同一板块是研究员推荐被认可的结果。对于均值回归，他认为这是局部正确，长期看收益率是幂律分布，美国股市200年增量由4%公司贡献，投资核心是找到长线超级大牛股。第三部分，他介绍过去一年在互联网、财富管理、新消费和高端制造四个方向的研究布局。互联网产业是富矿，中国美国能诞生巨大公司；财富管理行业空间巨大；新消费公司从CEO到组织架构完全不同于传统企业；高端制造中国占据主导地位，未来空间可见。第四部分，他分享五点投资框架反思：商业模式分类不完备，没有一劳永逸的坐地收钱生意；从商增角度理解商业模式更本质；长期变量如国运、文化背景影响收益率，需保持谦卑；深度价值可能长期无效（打问号）；小企业的X factor驱动企业增长且不被线性描述，无法定价但必须承认存在。

# 金句总结
1. “知识和信息之间是有着巨大的鸿沟的。”——肖楠以此说明投资者关心的“What happen next”问题用处不大，因为知识更新导致观点变化，而信息滞后。
2. “务实还是务虚，其实没有高下之分的。做好的都是大师，做不好都是东施效颦。”——肖楠以此说明投资理念没有好坏，关键在于执行。
3. “均值回归这个事情，90%的时间都正确，那10%的错误依然让你代价惨重。”——肖楠以此反对均值回归观点，强调长期看收益率是幂律分布。
4. “我们一定要对市场保持谦卑，就是有的时候我们可能在做投资的时候要考虑这个变量的时候，所以一定程度上要保持一定的谦虚。”——肖楠以此强调长期变量如国运、文化背景对收益率的影响。
5. “驱动企业增长且不被线性描述的因子，我们即使是没有办法去有效定价，我们也一定要承认它的存在。”——肖楠以此强调X factor的重要性。

# Q&A 环节
问：您刚刚有讲到是在对于终局结果的重视的过程中，也更加去关注格局演进的过程中阶段性的特征，中期投资机会，请问您能对这一点再详细描述一下吗？
答：这个想法最早是来自于我们过去错过了一些特别大的机会，导致我们非常懊恼。我们之所以错过，是因为我们判断这些行业的终局可能不大行，而最打脸的事情是我们明明也判断对了，但就是在两三年的时间里深深错过了十几倍的涨幅。复盘回来看，我们当时其实完全可以在考虑到终局可能没有那么好的前提下，依然做出漂亮投资来。这一类的企业有一些重要特征是我们当时忽略的，比如某一代产品领先后来被追上，但企业做出了第二增长曲线，且壁垒更深更厚。所以我们后来渐渐开始去对一些终局可能没有那么强的企业，依然做出好的投资。
