# 发布会概况
王毅在慕尼黑安全会议上发表主旨演讲，围绕“走向多极化”主题阐述中国推动平等有序世界多极化的主张。演讲借今年慕安会报告主题切入，指出80年前联合国成立时只有51个会员国，如今已有193个国家，多极化是历史必然。王毅提出四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。中国主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权；中国是现行国际秩序的受益者，主张共同维护以联合国为核心的国际体系，遵守以联合国宪章宗旨和原则为基础的国际关系基本准则。演讲后，王毅就国际秩序、乌克兰危机、中美关系等议题回答主持人提问。

# 核心信息
- **多极化背景数据**：80年前联合国成立时仅有51个会员国，如今已有193个国家；慕尼黑安全会议报告主题为“走向多极化”，多极化既是历史必然也正在成为现实。
- **中国多极化主张**：中国主张推动**平等有序的世界多极化**，这是习近平主席提出的重大主张；中国必将是多极体系中的确定性因素，坚定做变革世界中的建设性力量。
- **四点看法之一——倡导平等相待**：坚持权利平等、机会平等、规则平等，应成为建设多极世界的基本原则；中国主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权。
- **四点看法之二——尊重国际法治**：联合国宪章宗旨和原则是国际关系的根本遵循，也是建设多极世界的重要基石；多极格局不能是无序状态，大国要带头讲诚信、讲法治，摒弃言行不一和零和博弈。
- **四点看法之三——践行多边主义**：联合国是践行多边主义、推进全球治理的核心平台，已为各国遮风挡雨80年；未来多极世界更加需要联合国，应固本强基而非拆梁毁柱。
- **四点看法之四——坚持开放共赢**：发展是破解各种难题的钥匙，多极世界应是各国共同发展的世界；保护主义不是出路，滥加关税没有赢家，脱钩断链断的是机遇，小院高墙封的是自己。
- **中国参与国际组织数据**：中国加入了几乎所有普遍性的政府间国际组织和**600多项国际公约**；从不搞例外主义，更不搞合则用、不合则弃。
- **中国承担联合国会费**：中国坚定维护联合国的权威和地位，承担超过**20%的联合国会费**。
- **中国履行气候承诺**：中国切实履行`巴黎协定`，建成了世界上最大的清洁发电体系。
- **中国全球治理倡议**：中国提出并落实`全球发展倡议`、`全球安全倡议`、`全球文明倡议`，为完善全球治理提供公共产品。
- **中国经济数据**：去年中国GDP增长**5%**，对世界经济增长的贡献率接近**30%**；中国向世界释放超大规模的市场红利。
- **一带一路与欧盟对接**：中国愿推动高质量共建`一带一路`，同欧盟的`全球门户`战略相互对接，赋能彼此也赋能世界。
- **中欧建交50周年**：今年是中欧建交50周年，中方愿同欧方用好这一契机，深化战略沟通和互利合作。
- **中俄关系定位**：中国同俄罗斯建立了**结盟不对抗、不针对第三方**的睦邻友好关系，进而增进战略互信，建立全面战略伙伴关系。
- **中俄油气贸易立场**：中国从俄罗斯购买油气属正常国与国之间的交往；王毅反问“如果中国不从俄罗斯买，哪个国家能够提供如此巨量的油气来满足中国民众的需求”，并指出有的国家常把经贸问题政治化、当作打压中国的工具。
- **乌克兰危机中方时间表**：从危机爆发第2天（**2022年2月25日**）起，中方就提出对话协商解决。
- **乌克兰问题四点主张**：习近平主席提出的4点主张——各国主权领土完整应得到尊重、联合国宪章应得到遵守、各国合理安全关切应得到重视、一切致力于和平的努力都应得到支持。
- **劝和促谈行动**：中国派特使赴各国斡旋，同巴西等南方国家发起`和平之友`；中方乐见一切致力于和平的努力，包括美国同俄罗斯达成的共识。
- **和谈参与方范围**：所有当事方包括利益攸关方，都应适时参与到和谈进程当中；战事发生在欧洲大地上，欧洲更有必要为此发挥重要作用，共同探讨欧洲的长治久安，找到均衡、有效、可持续的欧洲安全框架。
- **中美关系政策基调**：中国对美政策保持连续性和稳定性，不会轻易翻烙饼；对美政策三原则为**相互尊重、和平共处、合作共赢**。
- **中美关系应对预案**：中方已准备好按三原则同美方构建稳定、健康、可持续的双边关系；若美方仍对中国打压遏制，中方将奉陪到底，坚决维护中国的主权、国家尊严和正当发展权利，坚决回击美方的单边和霸凌行径。

# 官方表态
**官方表态**（中国·王毅，慕尼黑安全会议主旨演讲）

**关于世界多极化**
- **主张**：世界正走向多极化，中国应当推动**平等有序的世界多极化**，这是习近平主席提出的重大主张，也是中国对多极世界的真诚期许。
- **针对**：多极化是否会带来动荡失序、冲突对抗是否意味着大国主导弱肉强食的疑问。
- **承诺**：中国必将是多极体系中的确定性因素，将坚定做变革世界中的建设性力量。
- **倡导平等相待**：坚持权利平等、机会平等、规则平等，应当成为建设多极世界的基本原则。
- **针对**：列强争霸曾给人类带来灾难，两次世界大战殷鉴不远，殖民体系、中心外围体系等不平等秩序注定土崩瓦解。
- **主张**：中国主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权。
- **边界**：这不会导致西方的缺失，而将促进世界的正和；每一个国家的声音都应该得到倾听，每一个国家都可以在多极格局中找到自身的位置、发挥自己的作用。

**关于国际法治**
- **主张**：联合国宪章宗旨和原则是处理国际关系的根本遵循，也是建设多极世界的重要基石；多极格局不能是无序的状态。
- **针对**：当今世界乱象频出，一个重要原因是有些国家迷信实力至上，打开了丛林法则的潘多拉盒子。
- **要求**：大国要带头讲诚信、讲法治，坚决摒弃言行不一、零和博弈；在遵守国际法上不能搞双重标准。
- **承诺**：中国坚定维护国际法治权威，积极履行国际责任和义务，从不搞例外主义，更不搞合则用、不合则弃。
- **条件**：要尊重各国的主权和领土完整，就应该支持中国实现完全统一。

**关于多边主义**
- **主张**：面对层出不穷的全球性挑战，没有哪一个国家能够独善其身；联合国是践行多边主义、推进全球治理的核心平台。
- **要求**：对于联合国这座大厦应该固本强基，而不是拆梁毁柱；对于治理全球难题应当共担责任，而不是唯利是图；对于共同挑战应该团结应对，而不是阵营对抗。
- **承诺**：中国坚持真正的多边主义，倡导共商共建共享的全球治理观，坚定维护联合国的权威和地位。

**关于开放共赢**
- **主张**：发展是破解各种难题的钥匙，多极世界应该是各国共同发展的世界；应当坚持开放合作，以普惠包容的经济全球化来支撑平等有序的世界多极化。
- **针对**：保护主义不是出路，滥加关税没有赢家，脱钩断链断的是机遇，小院高墙封的是自己。
- **承诺**：中国坚定同各国共享发展机遇，愿推动高质量共建“一带一路”，同欧盟的“全球门户”战略相互对接，赋能彼此也赋能世界。
- **关于欧洲**：中方始终认为欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手；今年是中欧建交50周年，中方愿意同欧方用好这一契机，深化战略沟通和互利合作。

# Q&A环节
**1. 主持人**：您提到国际秩序，我注意到当前有很多对联合国宪章和国际秩序的质疑——俄罗斯入侵乌克兰、美国总统威胁对格陵兰和巴拿马使用武力、巴勒斯坦人流离失所，中国也被指控违反海洋法和世界人权宣言。您即将前往纽约参加安理会会议，您是否仍然相信联合国和联合国宪章？联合国改革在您的议程中优先级有多高？

**王毅**：您的提问涉及两个关键词：秩序和规则。关于秩序，这几年总有人说中国要改变秩序、另起炉灶，但现在说这种话的人可能不多了，因为真正挑战秩序、毁约退群的国家出现了，欧洲朋友们可能每天都在感受到寒意。中国是在现行国际秩序中发展起来的，是受益者，我们要做的是按照大多数国家的愿望推动秩序朝更加公正合理的方向发展。关于规则，我们起码应有共同认知：共同维护以联合国为核心的国际体系，共同遵守以联合国宪章宗旨和原则为基础的国际关系基本准则，这是最大的公约数。只要认同这一点，双重标准就没有存在空间。中国意识到承担的国际责任和义务，愿意提供更多公共产品，习近平主席提出全球发展倡议、全球安全倡议、全球文明倡议，希望国际社会携手解决发展赤字、安全赤字和治理赤字。习主席还提出构建人类命运共同体的重大理念，希望各国超越历史文化、社会制度、意识形态差异，同舟共济建设好地球村，这已得到越来越多国家的理解认同和支持。

**2. 主持人**：自2022年以来，慕尼黑安全会议一直关注俄罗斯入侵乌克兰。就在入侵前几天，您曾表示任何国家的主权和领土完整都应得到尊重和维护，乌克兰也不例外。如今俄罗斯已成为中国的一个加油站——我补充一句，是带军队的加油站，这意味着您对乌克兰有很大影响力。现在压力越来越大，您是否可能从您这边采取措施，比如减少俄罗斯向中国供应天然气的可能性、降低价格，或停止部分军民两用物资，以加大对俄罗斯的压力，促使其结束战争？

**王毅**：中国同俄罗斯是两大邻国，有着漫长边界，两国关系经历过曲折后吸取教训，建立了结盟不对抗、不针对第三方的睦邻友好关系，进而增进战略互信，建立全面战略伙伴关系。中俄交往是正常的国与国交往。关于中国可否不从俄罗斯买油气，我想问：如果中国不从俄罗斯买，哪个国家能提供如此巨量的油气满足中国民众需求？那是不可能的，也是不保险的，因为常有国家把经贸问题政治化、当作打压中国的工具，我们不会允许，要为人民负责。中国在地区热点问题上有自己的立场，历来主张一切争端和冲突应通过对话寻求政治解决，武力和制裁不可能真正彻底解决问题，乌克兰问题上同样如此。从危机爆发第二天即2022年2月25日起，中方就提出对话协商解决。习近平主席提出的4点主张是中国立场最权威的阐释：各国主权领土完整应得到尊重，联合国宪章应得到遵守，各国合理安全关切应得到重视，一切致力于和平的努力都应得到支持。我们以此推进劝和促谈，哪怕有一点希望就做出百倍努力，派特使去各国斡旋，同巴西等南方国家发起和平之友。这些立场是公正客观、理性务实的，体现国际社会最大共识。任何冲突的终点都是谈判桌，中方乐见一切和平努力，包括美国同俄罗斯达成的共识，同时认为所有当事方和利益攸关方都应适时参与和谈。战事发生在欧洲大地，欧洲更有必要发挥重要作用，共同解决危机根源性因素，探讨欧洲长治久安，找到均衡、有效、可持续的欧洲安全框架。

**3. 主持人**：时间快到了，能否请您简要预告中美关系将如何发展？

**王毅**：中国的对美政策保持连续性和稳定性，不会轻易翻烙饼，这体现大国战略定力和国际信誉。对美政策就是习近平主席提出的三原则：相互尊重、和平共处、合作共赢。中美制度确实不一样，这是各自人民做出的选择，想改造或颠覆对方是不切实际的，正确态度是相互尊重，这是中美交往的前提。和平共处理所当然，中美两个大国总不能冲突起来，那将殃及整个世界，所以要开展对话、加强交往、增进了解、建立信任。合作共赢是因为国际社会期待中美合作，全球性挑战也需要中美携手应对，这也是两个大国应承担的国际责任。中方已准备好按三原则同美方构建稳定、健康、可持续的双边关系，找到两个大国在这个星球上的正确相处之道。我们希望美方相向而行，但如果美方仍要打压遏制，我们也别无选择，必将奉陪到底，坚决维护中国的主权、国家尊严和正当发展权利，坚决回击美方的单边霸凌行径。中国这样做也是为了维护国际公平正义和国际关系基本准则。中国人从来不信邪、不怕鬼，新中国就是在战胜各种艰难险阻中发展壮大起来的。我们对世界前途充满信心，对中美关系未来也充满信心，中美只有一个共同努力方向，就是相互尊重、和平共处、合作共赢，这也是国际社会最大的期待。
