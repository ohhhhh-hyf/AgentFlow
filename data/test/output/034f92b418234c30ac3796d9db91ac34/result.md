# 访谈概述
本次访谈围绕作家余华的写作历程、创作状态与文学理想展开，由主持人提问、余华作答。余华将自学游泳分为1.0家门口池塘、2.0江河、3.0大海，对应文学创作三个阶段：第一阶段逼自己坐下来写，第二阶段受卡夫卡启发遇到心理描写障碍，第三阶段受威廉·福克纳启发用视觉描写表现人物内心，3.0之后没再升级，认为已是大海。他谈到作家需要运气，最好的写作状态在40多岁到50多岁即《兄弟》到《第七天》期间，但被浪费掉了，只出了两部作品；《兄弟》1996年开始写，2003、2004年重新拿回来写，庆幸1996年没写完。他谈到对待批评的方式、网络热度与自媒体时代关于他的话有一半不是他说的，以及中年危机与自我调节。他表示对高度已经不追求，现在追求宽度，被问希望以什么姿态留在历史长河时回答：遗忘的姿态，一个遗忘的人。

# 访谈详细记录
**一、自学游泳与文学创作的三段式**
- 余华将自学游泳分为1.0家门口池塘、2.0江河、3.0大海，对应文学创作三个阶段。
- 第一阶段：逼着自己坐下来写，“让屁股和椅子建立友谊”，这是年轻时候最重要的；如果躺在床上幻想作品多牛逼，可能就不会去写了。
- 第二阶段：八月出的《远行》是2.0版本，卡夫卡给他最大启发；越写越难，遇到心理描写障碍——写人物内心平静没有意思，内心动荡不安则写一万字。
- 第三阶段：遇到威廉·福克纳，看他写穷白人把富白人杀了之后的内心状态，方式是“让心脏停止跳动，让眼睛睁开”，心理描写没有心理，是视觉描写；如《狂人日记》中“赵家的狗，我看了我一眼”，一下就知道这个人精神状态。余华去过精神病医院，认为精神病人说话逻辑是清晰的，只是方向不同。
- 3.0版本之后没再升级，余华认为已经够了，已经是大海；《活着》也许可算4.0版，但对他来说已不是难题，写一个没什么文化的农民讲述自己的故事，要用最朴素的语言。

**二、写作状态与运气**
- 余华认为作家需要一点运气，什么时候写什么作品很重要，对的就会写得很顺；《18岁出门远行》一天写完，6000字，对写字较慢的他来说是奇迹。
- 最好的写作状态在40多岁到50多岁，即《兄弟》到《第七天》期间，但那段时间“玩掉了”，他非常可惜。
- 2006年开始写的一部长篇小说，时间跨度跟《兄弟》一样，但从个人角度而非时代角度出发，想用接近陀思妥耶夫斯基的激烈方式写；现在身体状态可能还能维持这种激烈，但那个时代的感觉没了，80年代、90年代的感觉在远去，很难找回来。

**三、《兄弟》的创作与时代变化**
- 《兄弟》1996年开始写，2003年、2004年尤其是2004年重新拿回来写，庆幸1996年没写完；从2004年再看，1996年的变化不算什么，那才是真正大的变化。
- 余华认为中国始终处于很大变化中。

**四、作品出版间隔与下一步计划**
- 从《在细雨中呼喊》到《兄弟》隔了十年，《兄弟》到《第七天》隔了八年，《第七天》到《文城》又隔了八年；主持人问下一步是不是2029年。
- 余华希望快一点，已把这边整理完，开学时要去和学生们见一下，学校还有一些事情要处理，完了以后回三亚继续往前，安安静静把感觉找回来。
- 在三亚的工作很简单：写作、读书听音乐、锻炼。

**五、童年看海与人生感受**
- 余华童年第一次看到大海，感受到人生是宽广的；小时候每年夏天在海盐游泳，有一次进入海流，知道不能挣扎只能跟着海流走，一直到了40里外才爬上来，赤脚沿着海边走回来，天快亮了。
- 当时非常紧张，以为要死在海里，后来放心，因为了解杭州湾海流只会把他带回海岸线，不会带到太平洋；最后海流把他带到海盐边上平湖乍浦那个地方。
- 在三亚看到童年星空，发现月光是金色的，不是银色的；小时候在海水里仰躺看天空，看到天空光亮变化，远处星星点点，觉得海浪带他回家了。

**六、《第七天》的仁慈与批评**
- 有教授说《第七天》出来时余华变得仁慈了；余华认为自己活着也蛮仁慈，作品几乎都是悲剧，这次想先写完一篇喜剧，改变读者印象。
- 对待批评的方式：第一不要去看，第二有些批评要重视。
- 有人批评宋凡平写得太完美，余华认为宋凡平不是贯穿全书的人物，只是特殊年代出现的阶段性人物，这种批评没有道理。
- 有人说《第七天》中社会底层人未必都那么善良，余华认为这句话很好，以后写小人物会考虑进去；写他们在现实生活中是朋友同事但会勾心斗角，身份要把握住，不能写得太邪恶。

**七、文学理想与高度宽度**
- 余华表示对高度已经不追求，现在追求宽度；认为写作能走到的高度已经是现在的高度，允许自己下滑一下但不要下滑太多，年纪大了知道自己的能力、长处和还有多少潜力。
- 认为我们这一代作家在很大程度上被马尔克斯误导，都想在一本书里写一个世纪的故事，但没有能力在不到30万字的小说里写出一个世界。
- 谈到莫言写话剧是因为对话精彩，想表达得更牛逼；余华认为莫言在莎士比亚故居发誓是瞎扯，当时只是挑帽子，帽子钱还是余华付的，三顶一模一样的黑蓝色帽子后来找不着了。

**八、网络热度与批评应对**
- 《兄弟》出版时余华以为是一片赞扬，结果一片骂声，接受很多采访努力解释；《第七天》出来时只接收一个采访，告诉星期天朋友们做好思想准备，果然一片骂声；《文城》出来时骂声少一点。
- 经历网络高热度后，曾停了一年冷静期，不做任何活动、采访；但自媒体时代会把几十年前的事情翻出来，互联网上关于余华说的话有一半不是他说的，如“精神内耗”“想要命好”都不是他说的。
- 余华不担心喜欢消散，因为他的工作不是说话，是写作。

**九、中年危机与自我调节**
- 余华34岁时在年终总结说成年人每到年底会发现一种虚无，生活每天在呼吸，人口增加，空间没变宽敞，只有写作能得到新东西。
- 面对年轻人不安焦虑，认为只有自我调节：可以选择让自己知道什么、不知道什么，负面消息太多就屏蔽掉，选择积极的。

**十、希望留在历史长河中的姿态**
- 余华回答：遗忘的姿态，一个遗忘的人；那些能勉强被微风吹进耳朵的人，也是勉强吹进来的。
- 假如历史长河里有主题，主题就是一个世界，一个一个人。
