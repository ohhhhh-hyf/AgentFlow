# 景城苑小区物业招标答疑与评标会

## 全文摘要
景城苑小区召开物业招标答疑与评标会，业主代表与两家竞标物业公司（富家物业、资平物业）围绕小区改造计划、停车与安管、承接查验交接、包干制经验及公益服务、楼层杂物与晾晒治理等议题展开问答。富家物业承诺一年内完成改造，提出增设人行门禁、升级道闸、增设隔离墩、建设外围停车场、增设电动车停车场等措施；资平物业提出“洗理静音、疏金活选、疑难杂症、有效提升”四步举措，承诺进场一个月内完成环境绿化集中整改、半年内完成设备设施排查、八个月内保证项目有效运作。评标委员会打分（去掉一个最高分和最低分，全程保密、暂停网络直播、录像不公开）后，深圳市资平物业发展有限公司以第一名中标候选人身份中标；其余名次为长沙富佳物业72.91分、湖南恒居恒基居业物业60.73分、重庆新东源物业54.48分。

## 分段速览
### 00:00:10-00:09:36 富家物业答疑
业主代表就改造计划、停车管理、承接查验、安管问题及管理经验等五个方面提问，富家物业逐一回应。改造方面，预计一年内完成标书所列12大改造点；停车乱象将先分析原因，再通过增设停车位、保安劝阻等方式解决；交接工作提前两周入场摸底、提前一周培训人员，不顺利时先私下沟通，再请业委会或街道协调，必要时采取强制措施；安管方面提出增设人行门禁、升级道闸系统、增设隔离墩、建设外围停车场及电动车停车场等五项措施；管理上强调用心倾听、如实记录、马上处理、及时反馈。

### 00:10:00-00:19:44 资平物业公司介绍与改造方案
资平物业代表介绍公司情况：成立于2004年，总部在深圳，全国367个项目，其中127个业委会项目，为中国物业管理协会副会长单位及全国百强企业。针对景城苑项目提出四步举措：进场一个月内集中资源完成环境绿化清扫（洗理静音）；调动集团设备公司工程师全面排查设备设施（疏金活选）；涉及重大改造经业委会授权或业主大会招投标（疑难杂症）；导入公司管理标准与经验（有效提升）。团队编制16人，承诺薪酬福利高于周边同类项目，一线人员直招不外包，并导入顾客管理系统及社区文化活动。

### 00:19:52-00:22:45 资平物业回应改造与时间问题
业主代表询问中标后从哪些方面改造及预计时间。资平物业回应：主要存在安全管控、设备设施维护、环境、社区氛围四方面问题。进场一个月内集中整改环境绿化、楼道杂物及卫生；利用集团工程师资源全面排查设备设施，投资款内快速整改，需动用维修资金的启动业主大会授权；针对业主和业委会关注问题优先整改。承诺一年内保证小区达到有序状态。

### 00:22:50-00:25:55 包干制经验与公益服务
业主询问资平物业在包干制方面的经验及公益服务。资平物业介绍：在长沙有11个项目，其中10个为包干制、1个酬金制。包干制下强调财务透明、保障业主知情权，加强与业委会和业主互动，团队直招并选拔优秀管理干部。公益服务方面，提供居家上门服务（员工免费、材料费业主自付或自购）、家政服务及24小时业主护送服务，在长沙均有开展。

### 00:26:01-00:28:42 承接查验与交接安排
资平物业回应承接查验问题：前期与社区街道派出所沟通，与现有物业及业委会明确设备设施、债务债权；按专业线分组查验，调动集团工程师协助，避免遗留问题；承接查验期间在16人团队基础上增派150%人员，确保交接和查验准确。

### 00:28:42-00:31:23 安管与停车问题解决方案
资平物业回应监控门禁失效及停车混乱问题：关键岗位（门岗、门勤岗、车务）由老员工担任，对外来人员车辆登记核实后放行；收集业主车辆信息，制定停车管理方案（含禁区停放、动线规划），升级道闸识别外来与业主车辆；通过设备公司技术手段加强关键部位监控。

### 00:31:23-00:34:44 楼层杂物与晾晒问题处理
业主询问如何在不激发矛盾前提下解决楼层顶层堆放杂物和乱搭乱晒。资平物业提出：宣传引导，通过上门宣传、海报普及法律知识，让业主认识风险与法律责任；联合社区及应急管理部门采取行动；与业主充分沟通，给予处理时限；设置临时堆放区供业主限期存放；针对晾晒需求设置集中晾晒区，可提供免费上门晾晒增值服务。强调以疏导为主、避免强制。

### 00:35:00-00:35:33 评标与结果公布
评标委员会打分，规则为去掉一个最高分和最低分，打分环节全程保密、暂停网络直播、录像材料不予公开。最终公布结果：第一名中标候选人为深圳市资平物业发展有限公司，第二名长沙富佳物业管理有限公司72.91分，第三名湖南恒居恒基居业物业管理有限公司60.73分，第四名重庆新东源物业管理有限公司54.48分。招标活动圆满结束。

## 要点梳理
### 改造计划与时间
1. 富家物业回应业主关于中标后改造计划与时间的提问：具体改造项目已在标书第117页详细说明，预计改造时间在**一年内**完成。
2. 资平物业针对景城苑项目提出四步举措：**洗理静音**（进场第一个月调动湖南战队其他项目人员资源，对环境绿化、杂物进行全面清扫，保证感官上干净整洁有序）、**疏金活选**（调动集团设备公司水电、给排水、电梯、消防工程师，对小区所有设备设施全面排查诊断，在投资范围内集中改造）、**疑难杂症**（涉及消防、渗水等重大事项，全面检查后提供意见，经业委会授权或召开业主大会进行招投标）、**有效提升**（将总部管理标准与前沿管理经验延续至本项目）。
3. 资平物业承诺时间节点：进场一个月内完成环境绿化集中整改；半年内完成设备设施排查；**八个月以内**保证项目有效运作；一年以内保证小区达到有序状态。
4. 资平物业团队编制为**16人**，承诺薪酬福利高于同类及周边项目，所有一线人员**直招不外包**（基于长沙经验教训，外包对现场服务品质影响大）。

### 停车与安管问题
1. 业主反映小区存在监控门禁失效导致人员车辆随意进出、停车管理混乱问题，两家公司分别提出整改方案。
2. 富家物业提出五项措施：①大门口增设人行门禁系统（支持手机微信、刷卡、密码进出）；②升级大堂道闸系统，业主车辆信息统一录入管理，临时车辆由安保人员登记放行、入座时询问；③地面增设隔离墩，禁止公共场所停车，保障消防通道与人行通道畅通；④建设外围停车场并安装停车管理系统，规范机动车停放；⑤增设电动车停车场（考察发现电动车乱停乱放与停车位不足有严重关系）。
3. 富家物业针对车辆乱停问题提出先分析原因（停车场地不够、停车位置太远或业主不自觉），再针对性制定方案：停车位不够则增加停车位；业主不自觉则派保安、客服人员现场说服、劝阻、纠正。
4. 资平物业提出：①关键岗位（门岗、门勤岗、车务）由老员工担任，保证对外来人员车辆进行管控、登记、核实后放行；②收集小区业主车辆信息，制定整体停车管理方案（含禁区停放、动线规划），形成小区停车制度与公约；③升级道闸识别外来人员与业主亲戚来访；④通过自有设备公司与平台在技术层面解决监控问题，对停车关键岗位与关键部位监控进行技术管控。

### 承接查验与交接
1. 业主询问中标后如何落实与原物业的承接查验工作及交接不畅的应对措施。
2. 富家物业回应：公司以接手二手小区为主，有丰富交接经验。具体安排：①交接前**提前两周**项目负责人入场摸底，摸清小区现场情况；②**提前一周**所有服务人员安排到位并培训，了解公司制度与操作流程。
3. 富家物业交接分两种情况应对：顺利交接按流程进行；不顺利时先与原物业私下沟通了解诉求，公司间能解决则直接解决；不能解决则拜托业委会或街道社区领导组织现场协调会；仍不能解决时，在获得业委会、业主大会及街道社区许可下采取强制措施。
4. 资平物业回应：①前期与社区街道、派出所沟通，与现有物业及业委会明确设备设施、债务债权等事项；②按专业线分不同专业组，调动集团工程师资源协助项目查出问题，避免物业与物业之间形成对立局面；③承接查验期间在现有16人团队基础上**增派150%人员**，有成熟的承接查验小组与标准。

### 包干制经验与公益服务
1. 业主询问资平物业在包干制方面的经验及中标后计划提供的公益性、福利性拓展服务。
2. 资平物业介绍：在湖南有11个项目（长沙11个），其中**10个为包干制、1个为酬金制**。
3. 资平物业强调包干制下同样保证：①财务透明，包干制每季度将物业管理费、停车费等财务对全体业主公示；②管理透明，电梯、消防、外包等事项让业主代表参与管理；③团队直招，所有一线人员及管理干部在集团内选拔，30%来自现有团队、60%左右来自现有物业优秀员工及重新招聘。
4. 资平物业列举公益服务：长沙所有项目居家上门服务员工免费、材料费业主自付或代购；家政服务；24小时业主护送服务，有偿与无偿业务均有开展。

### 楼层杂物与晾晒问题
1. 业主提出小区楼层顶层存在堆放杂物、乱搭乱晒问题，询问如何在不激发矛盾前提下有效解决。
2. 资平物业提出以**疏导而非强制**为原则：①宣传引导，通过上门宣传、小区海报、法律知识宣传，让业主明白楼层堆放杂物存在风险且需承担法律责任；②联合社区、应急管理部门采取行动；③提前与业主沟通，告知危害并给出处理杂物的时间段；④与业主沟通设置闲置区域作为临时堆放点，贴纸条注明可临时存放但需限期解决。
3. 资平物业针对晾晒问题：湖南阴雨天气多，业主有晾晒需求，可在小区寻找位置设置**集中晾晒区**；部分项目可提供免费增值服务——太阳大时物业工作人员上门取被子晾晒，早上拉出、晚上收回。
4. 资平物业总结：物业管理既要人性化也要有管理手段，强制会激发矛盾，疏导让业主明白道理后问题更易解决。

### 评标结果
1. 评标规则：评标委员会打分，**去掉一个最高分和最低分**；打分环节全程保密，暂停会场网络直播，录像材料不予公开；评委、监督员及必要会务人员以外人员退场。
2. 评标结果：第一名中标候选人为**深圳市资平物业发展有限公司**；第二名长沙富佳物业管理有限公司**72.91分**；第三名湖南恒居恒基居业物业管理有限公司**60.73分**；第四名重庆新东源新东源物业管理有限公司**54.48分**。
3. 主持人宣布深圳市资平物业发展有限公司中标，招标活动圆满结束。

### 结论与决定
1. 深圳市资平物业发展有限公司经评标委员会打分（去掉最高分和最低分）确定为第一名中标候选人，中标景城苑小区物业项目。
2. 评标打分规则为去掉一个最高分和最低分，打分环节全程保密，暂停网络直播，录像材料不予公开。
