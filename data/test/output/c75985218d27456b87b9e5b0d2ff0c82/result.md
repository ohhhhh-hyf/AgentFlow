# 庭审概况
本案系上诉人国家开发银行与被上诉人云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司金融借款合同纠纷二审案件，由最高人民法院依法组成合议庭公开开庭审理。庭审围绕三个争议焦点展开：一是抵押权与融资租赁所有权冲突问题，二是罚息、复利计算问题，三是违约金连带责任问题。各方充分发表意见后，合议庭休庭评议并提出调解方案，各方均无异议，同意签署调解协议。

# 举证与法庭调查
## 举证与质证
- **国开行提交证据**：2018年9月对曲靖电力公司的融资租赁查询证书，证明其已尽审查义务；招银租赁质证认为该查询证书不符合要求，依据2014年93号文《中国人民银行关于融资租赁登记系统规定》，国开行在抵押时点未进行相应查询。
- **国开行提交证据**：工商部门出资证明及权属证明（证据四冶合成58亿），证明已对设备所有权尽到合理审慎义务；招银租赁质证认为工商登记公示的是出资行为而非动产所有权，东源煤电出资行为系无权处分。
- **招银租赁提交证据**：回租设备清单（一审证据7页），载明设备名称、生产厂家，但未载明型号；国开行质证认为该清单无法识别设备唯一性，且铭牌生产日期均在2013年以后，与清单提示的2012年3月1日不符。
- **招银租赁提交证据**：2013年和2015年审计报告（证据82页、95页），载明曲靖电力公司注册资本4亿元且已实缴；国开行质证认为该报告已载明设备出资事项，招银租赁应当知道设备出资情况。
- **国开行提交证据**：2018年核查表（证据108页），证明曲靖电力公司名下无融资租赁登记；招银租赁质证认为该核查表系诉讼中截图，不能证明抵押时点已查询。

## 法官询问
- **审判员询问**：中国人民银行征信中心融资租赁登记的性质及法律后果？国开行代理人认为系行业强制规范，招银租赁代理人认为系行业指导性规范，东源公司代理人认为不当然产生物权后果。
- **审判员询问**：融资租赁登记系统查询方式能否保证查询到登记结果？国开行代理人称只能按单位名称查询；招银租赁代理人称可按公司名称或设备查询，但设备查询涉及种类物区分问题。
- **审判员询问**：国开行贷款前审查是否有内部规定要求必须查询融资租赁登记，未查到需将查询单作为风控材料？国开行代理人称无此规定，因未查到结果故未保留查询单。
- **审判员询问**：融资租赁登记系统中设备唯一标识码是否必填项？招银租赁代理人称非必填项，本案设备无唯一标识码，故未登记。
- **审判员询问**：查询通知规定银行办理抵押前应查询，违反该规范是否导致最高人民法院相关司法解释的适用？国开行代理人认为系基本查询义务，已对抵押人完成审慎调查；招银租赁代理人认为银行未查询即违反行业规范，应承担不利后果。
- **审判员询问**：若通过其他渠道获知设备存在租赁，是否仍需通过央行系统查询？招银租赁代理人认为仍需查询，因央行规定出台背景即实务中大量纠纷，其他方式无法证明善意。
- **审判员询问**：不同登记机构产生登记瑕疵时，各方有何意见和建议？国开行代理人认为系系统信息不完整、体系相互隔离所致；东源公司代理人称非专业机构，无具体建议；招银租赁代理人建议从立法层面统一规范，发挥行业协会作用，并推动登记平台统一。

## 争议焦点与辩论
### 争议焦点一：抵押权与融资租赁所有权冲突
- **国开行主张**：其审查义务仅限于抵押人曲靖电力公司，已尽合理审慎义务，2018年核查时曲靖电力公司名下无融资租赁登记，构成善意取得。
- **招银租赁主张**：国开行未在抵押时查询融资租赁登记，不构成善意取得；其2012年已取得设备所有权，国开行2015年抵押登记在后。
- **东源公司主张**：其2015年12月2日发送的邮件已用红色标注抵押设备与招银租赁设备名称一致，国开行作为专业金融机构应尽注意义务。
- **国开行反驳**：邮件系贷后审查材料，非针对抵押物的告知；统计表中招银租赁栏记载的抵押类型为不动产抵押，与融资租赁不同，无法得出已告知的结论。

### 争议焦点二：罚息、复利计算
- **国开行主张**：利息计算至2018年6月12日合计2179万5727.08元，罚息自2018年6月13日至2019年2月19日合计4105万零579.57元，复利自2018年3月21日至2019年2月19日合计191.8206万元。
- **东源公司主张**：罚息不应作为复利计算基数，依据《人民币利率管理规定》第21条；国开行宣布贷款提前到期未给合理期限，不符合合同约定。
- **国开行反驳**：合同第六条第四款明确约定罚息计收复利，且东源煤电未上诉，一审已支持罚息复利部分。

### 争议焦点三：违约金连带责任
- **国开行主张**：依据借款合同第24条第三项，东源煤电应支付千分之一违约金；东源煤电未按合同第13条、第14条配合办理账户管理及柜台签约手续，构成违约。
- **东源公司主张**：国开行未举证东源煤电违反柜台协议，且未发出限期纠正通知，主张违约金不符合合同约定。

# 庭审结果
本案经合议庭评议，各方当事人对调解方案均无异议，同意签署调解协议。调解方案主要内容：国开行对东源公司债权扣除已清偿本金后，利息、罚息、复利合计6474.4513万元；招银租赁对涉案六项设备享有所有权，对应债权数额1377.4137万元；国开行对93项设备有抵押权，招银租赁对六项设备有所有权；双方同意整体盘活处置设备，变现款各50%，费用各担50%；若变现不足，招银租赁未实现债权按破产重整计划预留方案实现；各方对一审判决第二项、第四项无争议。合议庭将根据《中华人民共和国民事诉讼法》第97条规定出具调解书。
