# 研讨背景与议题
本次圆桌论坛围绕具身智能领域的关键技术问题展开，参与人员包括穆老师、王岳、薛寒、志龙、赵浩、杨立新、静波等老师与博士生，以及业界嘉宾。核心探讨的技术痛点包括：具身智能大模型是否应端到端、硬件形态的收敛方向、世界模型的定义与构建、强化学习与模仿学习的路线选择，以及数据采集与仿真的优劣。各方观点碰撞激烈，未形成统一结论。

# 核心观点
关于大模型与硬件协同：王岳认为大模型不应从上到下完全贯通，硬件变化会导致重新训练，应分层；薛寒提出硬件需高寿命、高可靠性以支持大规模真机评估；穆老师强调软硬件协同优化。关于世界模型：赵浩从CV角度强调3D、物理规律、可交互，志龙从RL角度认为可交互是首要、物理规律欠缺，王岳提出世界模型可能无法统一、存在歧义问题，policy可能统一，薛寒认为CV世界模型对强化任务不必要。关于强化学习与模仿学习：业界嘉宾介绍模型强化加机理融合，薛寒认为复杂任务应先模仿后强化，王岳认为PID反馈可作为reward，静波认为两者不冲突、可获取运动先验。关于数据采集与仿真：杨立新强调视角和标定对数据质量的影响，薛寒认为真机数据是低成本方案、可穿戴设备是终极形态，穆老师认为仿真数据可弥补真机数据不足，赵浩提出加入无标注真实数据。

# 达成共识与解决方案
**软硬件协同优化是具身智能发展的关键范式**，硬件寿命与可靠性需支持大规模真机评估。**世界模型在CV与RL领域关注点不同**，CV强调3D、物理规律、可交互，RL强调可交互与策略学习。**复杂任务应先模仿后强化**，单独模仿或强化均不可行。**数据采集应结合真机与仿真数据**，仿真数据可弥补真机数据不足，真机数据是低成本方案，可穿戴设备是终极形态。**2025年应推广无标注真实数据的使用**。

# 未决分歧与后续探索
未决分歧包括：具身智能大模型是否应端到端；世界模型是否需要3D inductive bias；强化学习与模仿学习最终路线如何；仿真数据与真实数据比例如何。后续探索方向包括：验证世界模型统一性与歧义问题，探索可穿戴设备采集数据方案，研究国产仿真系统替代英伟达生态的可能性。
