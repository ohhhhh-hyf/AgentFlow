# 就诊概况
48岁男性患者张学恒，在成都轻工研究所从事科研工作，因上腹反复疼痛4年、近3个月加重，伴两次黑便及近期呕吐，于消化专科门诊就诊。接诊医生为严医生。初步判断需进一步检查以明确病因，排除消化道出血及胃癌可能。

# 病史与背景
- **现病史**：上腹疼痛4年，每年春季多发，近3个月反复发作；疼痛位于心窝部，呈烧灼感，进食冷硬或刺激性食物及工作紧张时诱发；近4年出现两次黑便，分别于1年前和3个月前，均住院治疗后大便转黄；近两个月呕吐数次，呕吐物为酸味黄水样物，含未消化食物，夜间腹胀时呕吐后缓解；近3个月大便为黄色，小便正常，无夜间痛醒，体重无明显下降。
- **既往史**：16岁时患甲肝，在三医院住院一个月，出院及后续体检肝功能均正常；无手术史；预防接种按计划进行，近两年所里统一接种上海产乙肝疫苗三针，无不良反应。
- **过敏史**：小时候因扁桃体炎在成都市儿童医院就诊，服用磺胺药后左手出现红疹，持续半个月，确诊磺胺药过敏。
- **家族史**：父亲76岁有低血压，母亲75岁有冠心病（药物控制良好），弟弟身体健康；婶婶（叔叔的爱人）有胃癌病史。
- **个人史**：成都人，在成都轻工研究所从事科研工作，工作紧张，经常加班熬夜；有吸烟史（以前每天一包，现限制在10支以内，计划逐步戒烟）；偶尔饮酒，平时不喝；已婚，26岁结婚，有一子，爱人及孩子身体健康。
- **近期用药**：近期服用奥美拉唑（武汉药厂产）、阿莫西林及医务室胃炎合剂，效果不佳。

# 诊断与检查结果
医生未给出明确诊断结论，建议进一步检查。患者有两次黑便史，需排除消化道出血；有胃癌家族史（婶婶），需排除胃癌可能。

# 治疗方案与医嘱
- **检查安排**：建议患者留大便检查，以明确有无出血；胃镜预约在后天进行，患者爱人可陪同。
- **生活方式**：建议戒烟、少喝酒，因吸烟饮酒可能加重胃部疾病；注意避免熬夜。
- **复诊与陪同**：胃镜预约在后天，患者爱人可陪同；医生将总结病情后向张医生（上级教授）汇报，再讨论下一步处理意见。
