# 发布会概况
王毅在慕尼黑安全会议上围绕多极化世界走向阐述中方立场，提出平等相待、尊重国际法治、践行多边主义、坚持开放共赢四点主张，并回答乌克兰问题与中美关系提问。王毅表示，多极化是历史必然并正在成为现实，中国主张推动平等有序的世界多极化，中国必将是多极体系中的确定性因素，坚定做变革世界中的建设性力量。他强调联合国宪章宗旨和原则是国际关系根本遵循，遵守国际法不能搞双重标准，应支持中国实现完全统一。他称联合国是践行多边主义、推进全球治理的核心平台，应固本强基而非拆梁毁柱。他提出保护主义不是出路，滥加关税没有赢家，脱钩断链断的是机遇，小院高墙封的是自己。在乌克兰问题上，他表示中方主张一切争端和冲突都应通过对话寻求政治解决，乐见一切致力于和平的努力，包括美俄达成的共识。在中美关系上，他表示中国对美政策保持连续性和稳定性，愿按相互尊重、和平共处、合作共赢三原则同美方构建稳定健康可持续的双边关系。

# 核心信息
王毅在慕尼黑安全会议上提出四点主张：一是倡导平等相待，坚持权利平等、机会平等、规则平等，主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权；二是尊重国际法治，强调联合国宪章宗旨和原则是国际关系根本遵循，国家不论大小强弱都是国际法治利益攸关方，大国要带头讲诚信讲法治，摒弃言行不一、零和博弈，遵守国际法不能搞双重标准，应支持中国实现完全统一；三是践行多边主义，称联合国是践行多边主义、推进全球治理的核心平台，应固本强基而非拆梁毁柱，中国承担超过**20%**的联合国会费，履行`巴黎协定`，建成世界上最大的清洁发电体系，提出并落实全球发展倡议、全球安全倡议、全球文明倡议；四是坚持开放共赢，指出保护主义不是出路，滥加关税没有赢家，脱钩断链断的是机遇，小院高墙封的是自己，去年中国GDP增长**5%**，对世界经济增长的贡献率接近**30%**，愿推动高质量共建`一带一路`同欧盟`全球门户`战略相互对接。王毅表示，欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手，今年是中欧建交**50周年**，中方愿同欧方用好这一契机深化战略沟通和互利合作。

# 官方表态
关于多极化：王毅表示，多极化的世界既是历史的必然，也正在成为现实；中国给出的答案是应当推动平等有序的世界多极化，这是习近平主席提出的又一个重大主张；中国必将是多极体系中的确定性因素，将坚定做变革世界中的建设性力量。
关于国际法治：王毅表示，联合国宪章宗旨和原则是处于国际关系的根本遵循，也是建设多极世界的重要基石；国家不论大小强弱，都是国际法治的利益攸关方；大国要带头讲诚信，讲法治，坚决摒弃言行不一、零和博弈；在遵守国际法上不能搞双重标准，要尊重各国的主权和领土完整，就应该支持中国实现完全统一。
关于多边主义：王毅表示，联合国是践行多边主义、推进全球治理的核心平台，已经为各国遮风挡雨80年；对于这座大厦，我们应该固本强基，而不是拆梁毁柱；中国坚持真正的多边主义，倡导共商共建共享的全球治理观，坚定维护联合国的权威和地位。
关于开放共赢：王毅表示，保护主义不是出路，滥加关税没有赢家；脱钩断链断的是机遇，小院高墙封的是自己；应当坚持开放合作，以普惠包容的经济全球化来支撑平等有序的世界多极化。
关于乌克兰问题：王毅表示，中国同俄罗斯是两大邻国，有着漫长的边界，两国建立了不结盟、不对抗、不针对第三方的睦邻友好关系，进而建立全面战略伙伴关系；中国同俄罗斯之间的交往是正常的国与国之间的交往；中方历来主张一切争端和冲突都应该通过对话寻求政治解决，因为武力和制裁不可能真正和彻底的解决问题；习近平主席提出的4点主张是中国立场的最权威的阐释；任何冲突的终点都是谈判桌；中方乐见一切致力于和平的努力，包括这两天美国同俄罗斯达成的共识；所有当事方包括利益攸关方，都应该适时的参与到这个和谈的进程当中；这场战事发生在欧洲大地上，欧洲更有必要为此发挥重要的作用。
关于中美关系：王毅表示，中国的对美政策保持着连续性和稳定性，我们不会轻易的翻烙饼；我们的对美政策就是习近平主席提出的三原则，相互尊重，和平共处，合作共赢；如果想改造或者颠覆对方的话，那是不切实际的；中美两个大国总不能冲突起来吧，因为那将殃及整个世界；中方已经准备好了，我们愿意按照三原则同美方构建稳定健康可持续的双边关系；如果美方仍然还要对中国打压和遏制，那我们也别无选择，我们必将奉陪到底。

# Q&A环节
问（发言者2）：你提到国际秩序，也提到需要尊重联合国宪章，我们已看到俄罗斯入侵乌克兰，也看到美国总统威胁对格陵兰和巴拿马使用武力、巴勒斯坦人流离失所，你的国家也被指控违反海洋法或世界人权宣言。你正前往纽约联合国安理会，你是否继续相信联合国？是否相信联合国宪章？是否会推动联合国及宪章改革？这一优先度有多高？
→ 答（王毅）：说到秩序，这几年总有人说中国要改变秩序、另起炉灶，但现在再说这种话的人可能不会太多了，因为真正要挑战秩序、毁约退群的国家出现了；中国是在现行国际秩序中发展起来的，是这个秩序的受益者，我们要做的就是按照大多数国家的愿望，推动这个秩序朝着更加公正合理的方向去发展。谈到规则，我们需要共同来维护以联合国为核心的国际体系，共同遵守以联合国宪章宗旨和原则为基础的国际关系的基本准则，这应该是我们的最大公约数；只要大家都认同这一点，有些人所说的双重标准就不会出现了。中国愿意向世界提供更多的公共产品，习近平主席提出全球发展倡议、全球安全倡议、全球文明倡议，希望国际社会携起手来共同解决好发展赤字、安全赤字、治理赤字；习主席还提出共同构建人类命运共同体，希望各国超越历史文化社会制度意识形态的不同，以同舟共济的精神共同呵护好这个唯一人类可以居住的星球。

问（发言者2）：自2022年以来慕安会的一个话题是俄罗斯入侵乌克兰，你在俄罗斯入侵前几天曾说过主权、独立和领土完整应得到尊重和保障，乌克兰也不例外；今天俄罗斯已成为中国的加油站，中国对乌克兰有很大影响力，你是否看到现在有更多压力，你方可以做一些事情，比如削减俄罗斯向你国供应天然气的可能性或降低价格，或停止部分两用物资，以对俄施压结束战争？
→ 答（王毅）：中国同俄罗斯是两大邻国，有着漫长的边界，两国关系过去经历过一番曲折，之后双方吸取教训，建立了不结盟、不对抗、不针对第三方的睦邻友好关系，进而增进战略互信，建立全面战略伙伴关系；中国同俄罗斯之间的交往是正常的国与国之间的交往。如果中国不从俄罗斯买油气，哪个国家能够提供如此巨量的油气来满足中国民众的需求呢？那是不可能的，也是不保险的。中国在对待地区热点问题上是有我们的立场的，历来主张一切争端和冲突都应该通过对话寻求政治解决，乌克兰问题上同样如此。从这场危机爆发的第2天开始，就是2022年2月25号，中方就提出了对话协商解决；习近平主席提出的4点主张是中国立场的最权威的阐释，那就是各国的主权领土完整应该得到尊重，联合国的宪章应该得到遵守，各国的合理安全关切应该得到重视，一切致力于和平的努力都应该得到支持。我们派出的特使去各国斡旋，同巴西等南方国家发起了和平之友。任何冲突的终点都是谈判桌，中方乐见一切致力于和平的努力，包括这两天美国同俄罗斯达成的共识；所有当事方包括利益攸关方，都应该适时的参与到这个和谈的进程当中；这场战事发生在欧洲大地上，欧洲更有必要为此发挥重要的作用。

问（发言者2）：请简要预告一下你如何看待中美关系的发展？
→ 答（王毅）：中国的对美政策保持着连续性和稳定性，我们不会轻易的翻烙饼，这体现了作为大国的战略定力和国际信誉；我们的对美政策就是习近平主席提出的三原则，相互尊重，和平共处，合作共赢。中国和美国制度确实不一样，这是我们各自人民做出的选择，如果想改造或者颠覆对方的话，那是不切实际的，正确的态度就是相互尊重，这是中美交往的一个前提。和平共处更是理所当然，中美两个大国总不能冲突起来吧，因为那将殃及整个世界，所以还是要开展对话，加强交往，增进了解，建立信任。合作共赢，这是因为国际社会期待中美开展合作，全球性的挑战也需要中美携手来应对，这也是中美两个大国应当承担的国际责任。中方已经准备好了，我们愿意按照三原则同美方构建稳定健康可持续的双边关系，找到两个大国在这个星球上的正确相处之道；我们当然希望美方能够相向而行，但是如果美方不愿意，如果美方仍然还要对中国打压和遏制，那我们也别无选择，我们必将奉陪到底，必将坚定的维护中国的主权、中国的国家的尊严和我们的正当发展权利，必将坚决的回击美方的单边和霸凌的这种行径。
