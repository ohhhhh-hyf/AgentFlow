# 课程概况
本次课程为历史小论文写作指导课，围绕观点明确、论证条理、材料运用等展开。教师通过例题讲解自命题、观点提示、图表信息等题型，强调审题、读材料、列事实、升华观点，并分析学生答案。课程核心是让学生掌握小论文写作的基本方法与解题步骤，提升观点提炼与论证能力。

# 核心知识点梳理
## 小论文写作基本要求
- **观点明确**：观点必须亮出来，不能只是简单陈述或罗列名词，需形成自己的判断。
- **论证条理**：论证一般写两到三条，不宜过多或过少，需支撑论点。
- **内容结构**：先打开背景学术报告，再加入自己的观点，最后进行论述或升华。
- **逻辑清晰**：可用序号或直接列出，但逻辑要清晰，如按时间脉络（700时期、明清时期）或国内外、内外等分类。

## 自命题类题型解题步骤
- **审题**：先阅读题目，注意要求（如用世界史知识、范围限定）及小红帽要求，审题要慢。
- **读材料**：认真读材料，抓主要信息，细看材料间关系。
- **列事实**：先写题目，再罗列与材料相关的事实，避免直接写在答题卡上。
- **论述升华**：最后进行论述和升华，不能简单重复观点。

## 观点提示类题型
- **选择观点**：先看观点，选择核心观点，明确表达自己的判断（正确或错误）。
- **表述角度**：不能照抄材料，需用自己的角度表述。
- **总结升华**：最后总结观点并进行升华。

## 图表信息类题型
- **提取信息**：快速查看图表关键信息（题头、横向纵向），注意信息间关系变化。
- **分析论证**：提取有效信息进行分析，如中国历代领导等级变化可结合儒家思想等。
- **官方答案示例**：梁启超观点、唐朝国力强盛但民德问题等。

# 课堂互动与答疑
**问**：武汉长江大桥这道题，你的思路是什么？
**答**：学生分析材料，提到新中国成立、改革开放等背景，强调写作需体现重大国家利益，背景部分可写对内改革、对外开放，按时间顺序先内后外。
**延伸思考**：写作时需结合时代背景，体现国家利益。

**问**：1940年材料评析，你选择哪个观点？
**答**：学生选择第二条，论证中华文化优越性，如丝绸之路、四大发明对欧洲贡献等。
**延伸思考**：需结合抗战时期背景分析写作目的。

**问**：图表信息类题目，如何提取信息？
**答**：需快速查看图表关键信息（题头、横向纵向），注意信息间关系变化，提取有效信息进行分析。
**延伸思考**：可结合儒家思想等分析中国历代领导等级变化。

# 课后任务与学习建议
**任务**：完成小论文写作练习，注意观点明确、论证两三条、逻辑清晰、最后升华。
**建议**：审题要慢，注意要求；读材料抓主要信息；先写题目再列事实；结合时代背景分析；不能照抄材料，需用自己的角度表述。
