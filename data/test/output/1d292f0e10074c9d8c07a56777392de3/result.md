# 锵锵三人行：从《大奥》看日本文化，再谈明史兴衰

## 访谈概述
本期《锵锵三人行》由主持人（发言人1）与嘉宾当年明月（发言人3）、另一位嘉宾（发言人2）围绕日本历史剧《大奥》与明朝历史展开对话。节目先讨论《大奥》所反映的日本江户时代（约相当于中国晚清至清初，后一部在明治维新前），指出“大奥”即后宫，“奥”在日语中指很深的地方。嘉宾们认为该剧体现了日本文化的严谨与极端精神，并由此延伸到日本战后用30年成为世界第二经济强国（绝对量，且是唯一没有资源的强国）、终身雇佣制下仍保持高效率、豆腐厂当天做当天卖且夜里12点整准时开工等事例，对比中国的中庸精神与日本的坚持原则、忠诚文化。随后话题转向明朝历史。当年明月解释自己写《明朝那些事儿》是因为明史资料最多，但一个事件可能有七个不同说法，研究难度大；明朝260多年过程跌宕起伏，如土堡之变、夺门之变等离奇事件构成现代版电视剧。他推崇朱元璋，认为其是历史上唯一由最底层（乞丐）当上皇帝的人，刘邦好歹是村长，且朱元璋定下明朝规章制度基本无大改动。关于明朝兴亡，嘉宾认为明末江南市民生活轻松、工商业兴起，出现三言二拍等娱乐产品，吴门画派如文征明、唐寅的作品体现生活乐趣；但历史最大教训是“从来没有从历史中得到过教训”，且中国历史上超过300年大限的只有宋朝，且退让了大半个国土。节目还讨论了明朝皇帝与审美：正德皇帝被评价为明朝最荒淫，但可能被嘉靖时期编史者写坏，其从江南回来在通州停半年先派人打探京城情况，很有城府；天启皇帝爱当木匠，干完活拆大盆去卖，反映当时社会对家具的重视，明式家具在国际上地位高。嘉宾指出宋明是汉人政权、文人审美高，满族趣味偏表象，故宫大红大紫是满族趣味。

## 访谈详细记录
### 日本历史剧《大奥》与日本文化

- **访谈员**：这部刚播完、引起很大反响的《大奥》，你们俩都看了？
- **受访嘉宾**：对，我也这么认为，确实是一部拍得非常好看的剧。

1. **《大奥》的时代背景**：嘉宾指出该剧共三部，前两部约相当于中国晚清到清初时段，后一部在明治维新之前，是一部有跨越性的历史剧。
2. **“大奥”释义**：嘉宾解释“大奥”即普通话所说的后宫，日语中“奥”指很深的地方，即屋子最里处，如“深奥”一词仍保留此痕迹。
3. **观感与日本人的严谨精神**：嘉宾认为该剧吸引他的是其中体现的严谨精神——看日本历史剧看不到群众演员笑，每个人都特别认真、有专业精神；第一集片头将军出场时所有人呈45度鞠躬、场面华丽，一看就不一样。
4. **日本文化的极端精神**：嘉宾认为从《大奥》可看出日本文化从头到尾没有变，其特点是“所有的事情要做到尽头”，这是一种极端精神；战后1945年日本用30年成为世界第二经济强国（绝对量而非人均量），且是世界上强国里唯一没有资源的国家，这不是偶然而是必然。
5. **中日文化差异**：嘉宾对比指出中国的文化精神是中庸，日本文化则强调坚持一个原则；日本是忠诚文化的典型国家，但也有人批评这种忠诚是“家奴”式的。
6. **日本社会的效率与一丝不苟**：嘉宾举例参观日本最底层豆腐厂——日本规定豆腐当天做当天卖，夜里11:45所有人坐等看表，12点整一到立刻开工，4点多干完上市，期间无人闲聊，体现一丝不苟；嘉宾还提到日本跳槽率最高，每次跳槽都是社会资源浪费，但另一嘉宾补充日本实行终身雇佣制。

### 明朝历史与明史研究

- **访谈员**：为什么很多人对明史感兴趣？你写《明朝那些事儿》的缘由是什么？
- **受访嘉宾**：因为明史资料最多，但一个事件可能有七个不同说法，研究起来很难。

1. **写明史的缘由**：嘉宾当年明月表示自己写《明朝那些事儿》是因为明史资料最多，但一个事件可能有七个不同说法，研究难度大。
2. **对朱元璋的推崇**：嘉宾认为朱元璋是历史上唯一由最底层（乞丐）当上皇帝的人，刘邦好歹是村长；朱元璋定下明朝规章制度，基本无大改动。
3. **明朝的离奇事件**：嘉宾指出明朝经历土堡之变、夺门之变等离奇事件，构成现代版电视剧；明朝260多年过程跌宕起伏。
4. **明末市民生活与工商业**：嘉宾提到明末江南市民生活轻松，工商业兴起，出现三言二拍等娱乐产品；吴门画派如文征明、唐寅的作品体现生活乐趣。
5. **历史教训**：嘉宾引用名言“我们从历史中得到的唯一教训就是我们从来没有从历史中得到过教训”，认为历史中有很玄的东西——人们总觉得以往的人该怎么办，都是聪明的、错误的。
6. **明朝兴亡经验**：嘉宾指出中国历史上超过300年大限的只有宋朝，且退让了大半个国土；明朝的兴亡经验值得深思。

### 明朝皇帝与审美

- **访谈员**：正德皇帝为什么被说成特别荒淫？
- **受访嘉宾**：他被评价为明朝最荒淫的皇帝，但可能被嘉靖时期编史者写坏了。

1. **正德皇帝的荒淫评价**：嘉宾指出正德皇帝被定为明朝最荒淫的皇帝，清朝最荒淫的是咸丰；正德没少找女人但不留种，没有正宗传下来，到嘉靖是拐弯。
2. **正德皇帝的城府**：嘉宾举例正德从江南回来没进京城，在通州先停半年，派人打探京城里有没有人想搞埋伏或圈套，说明他很有城府；嘉宾认为这个人绝不是史料所写的那么蠢。
3. **史书编纂的偏颇**：嘉宾指出明武宗实录是嘉靖时期指派杨廷和等人编的，因嘉靖上台搞大礼仪事件、追封自己父亲为皇帝，编史者有一定偏颇，把正德写坏了；嘉宾认为历史非常玄幻，有些事你看到以为这么回事，实际上不是。
4. **天启皇帝与明式家具**：嘉宾提到天启皇帝爱当木匠，干完活拆大盆去卖，反映当时社会对家具的重视；明式家具在国际上地位高，皇帝下大力气做，体现其影响之深。
5. **宋明审美与满族趣味**：嘉宾指出宋明是汉人政权、文人审美高，满族趣味偏表象，故宫大红大紫是满族趣味；主持人认同研究历史不能有傲慢与偏见，要设身处地。
