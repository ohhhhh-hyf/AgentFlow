# 课程概况
本讲为初中物理光学复习课，系统复习光的直线传播、光速、光的反射定律、镜面反射与漫反射、平面镜成像及球面镜应用。课程先介绍光源（自然光源如太阳、萤火虫，人造光源如电灯）与光线（物理模型），强调光在均匀介质中沿直线传播，并列举三点一线、激光准直、小孔成像、日食月食、影子形成等实例；光速在真空中为3×10^8米/秒，空气中略慢，水中为真空中的3/4，玻璃中为2/3。随后讲解光的反射定律：三线共面、分居两侧、反射角等于入射角，法线为辅助线且垂直镜面，垂直入射时入射角为0度；作图步骤为先画法线，再根据反射角等于入射角画光线。镜面反射发生在光滑表面，反射光线平行，可能造成反光问题；漫反射发生在凹凸不平表面，反射光线射向各个方向，生活中大多数反射为漫反射，如黑板、电影银幕，两者均遵守反射定律。平面镜成像原理为光的反射，成正立、等大的虚像；实验用玻璃板代替平面镜以确定像的位置，用刻度尺比较像与物到镜面的距离，用两段相同蜡烛比较像与物大小；玻璃板有厚度会导致两个像，玻璃板不垂直会导致测量误差。球面镜中，凸面镜对光起发散作用，成缩小虚像，用于汽车后视镜、丁字路口镜；凹面镜对光起会聚作用，用于手电筒、太阳灶、耳鼻喉科检查；玻璃幕墙凹面可能造成光污染，烧死树木或引燃电线。

# 核心知识点梳理
**光的直线传播**：光源是自身能够发光的物体，分为自然光源（太阳、萤火虫）和人造光源（火把、蜡烛、煤油灯、电灯）；光线是带有箭头的直线，是物理模型，并非真实存在。光在均匀介质中沿直线传播，实例包括三点一线、激光准直、小孔成像、日食月食、影子形成。小孔成像成倒立实像，放大缩小不一定，与孔形状无关；日食时月球在中间，月食时地球在中间。光速：真空中为3×10^8米/秒（每秒绕地球赤道7圈半），空气中略慢，水中为真空中的3/4，玻璃中为2/3。

**光的反射定律**：反射光线、入射光线和法线在同一平面内（共面），反射光线和入射光线分居法线两侧，反射角等于入射角。法线是垂直于镜面的辅助线，画虚线。垂直入射时入射角为0度。作图步骤：先画法线，再根据反射角等于入射角画光线，保留作图痕迹。易混点：*入射角是入射光线与法线的夹角，不是与镜面的夹角*。

**镜面反射与漫反射**：镜面反射发生在光滑表面，反射光线平行，可能造成反光问题（如黑板反光）；漫反射发生在凹凸不平表面，反射光线射向各个方向，生活中大多数反射为漫反射（如黑板、电影银幕、人眼看到物体）。两者均遵守光的反射定律。

**平面镜成像**：原理是光的反射，成正立、等大的虚像。实验用玻璃板代替平面镜便于确定像的位置，用刻度尺比较像与物到镜面的距离，用两段相同蜡烛比较像与物大小。玻璃板有厚度会导致两个像，玻璃板不垂直会导致测量误差。光路可逆。

**球面镜**：凸面镜对光起发散作用，成正立、缩小的虚像，用于汽车后视镜、丁字路口镜；凹面镜对光起会聚作用，用于手电筒、太阳灶、耳鼻喉科检查。玻璃幕墙凹面可能造成光污染，烧死树木或引燃电线。

# 课堂互动与答疑
问：光垂直射到镜面上，入射角和反射角是多少？
答：都是0度，因为入射角是入射光线与法线的夹角，垂直入射时夹角为0度。

问：为什么研究反射要引入法线？
答：法线是辅助线，垂直镜面，为后续学习折射做准备。

问：平面镜成像实验中，为什么用玻璃板代替平面镜？
答：玻璃板既能反射成像，又能透过光，便于移动后面的蜡烛确定像的位置。

问：为什么玻璃板会看到两个像？
答：玻璃板有厚度，两个面都能发生反射成像。

问：为什么平面镜成的是虚像？
答：因为实际光线没有到达像的位置，是反射光线的反向延长线会聚而成。

> 教师提醒：光在均匀介质中沿直线传播，这句话要写全。

# 课后任务与学习建议
课堂练习：完成讲义第1~5题（光的直线传播）、第7~17题（光的反射）、第18~24题（平面镜成像）。教师强调复习重点：光的反射定律（三线共面、分居两侧、反射角等于入射角）、平面镜成像特点（正立、等大、虚像）、镜面反射与漫反射的区别。学习建议：可在家用激光笔、硬纸壳、平面镜等器材自主完成反射定律和平面镜成像实验；注意作图时先画法线，保留作图痕迹。
