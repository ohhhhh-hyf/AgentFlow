# 发布会概况
王毅在慕尼黑安全会议上借用今年慕安会报告主题「走向多极化」作答，指出联合国会员国从成立时51个增至今天193个，多极化既是历史必然也正在成为现实，中国给出的答案是推动平等有序的世界多极化，并称中国必将是多极体系中的确定性因素、坚定做变革世界中的建设性力量。他随后阐述四点看法：一是倡导平等相待，坚持权利平等、机会平等、规则平等，主张大小国家一律平等、提升发展中国家在国际体系中的代表性和发言权；二是尊重国际法治，称联合国宪章宗旨和原则是国际关系根本遵循和建设多极世界的重要基石，批评有些国家迷信实力至上、打开丛林法则潘多拉盒子；三是践行多边主义，称没有国家能独善其身、搞本国优先只会造成各方多数，联合国是核心平台应固本强基而非拆梁毁柱；四是坚持开放共赢，称保护主义不是出路、滥加关税没有赢家、脱钩断链断的是机遇、小院高墙封的是自己。在中欧关系上，他表示欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手，今年是中欧建交50周年，中方愿同欧方用好这一契机深化战略沟通和互利合作。在答问环节，他回应了联合国与国际秩序规则、乌克兰问题、中美关系等提问，强调中国是现行国际秩序受益者、主张通过对话政治解决乌克兰危机、对美政策保持连续性和稳定性。

# 核心信息
王毅指出，联合国成立时只有51个会员国，到今天共193个国家。中国主张推动平等有序的世界多极化，坚持权利平等、机会平等、规则平等，大小国家一律平等，提升发展中国家在国际体系中的代表性和发言权。中国加入几乎所有普遍性政府间国际组织和**600多项**国际公约，不搞例外主义，不搞合则用、不合则弃。中国承担着**超过20%**的联合国会费，切实履行`巴黎协定`，建成世界上最大的清洁发电体系，并提出并落实全球发展倡议、全球安全倡议、全球文明倡议。去年中国GDP增长**5%**，对世界经济增长的贡献率**接近30%**。中国愿推动高质量共建`一带一路`，同欧盟`门户`全球门户的战略相互对接。今年是中欧建交**50周年**，中方愿同欧方用好这一契机，深化战略沟通和互利合作。

# 官方表态
关于国际秩序与规则，王毅表示，中国是在现行国际秩序中发展起来的，是这个秩序的受益者，要做的就是按照大多数国家的愿望，推动这个秩序朝着更加公正合理的方向去发展；需要共同维护以联合国为核心的国际体系，共同遵守以联合国宪章宗旨和原则为基础的国际关系的基本准则，这应该是最大的公约数。关于乌克兰问题，王毅表示，中国同俄罗斯是两大邻国，有着漫长的边界，两国建立了不结盟、不对抗、不针对第三方的睦邻友好关系，进而建立了全面战略伙伴关系；中国同俄罗斯之间的交往是正常的国与国之间的交往。他反问：> 如果中国不从俄罗斯买，哪个国家能够提供如此巨量的油气来满足中国民众的需求呢？那是不可能的，也是不保险的。他强调，中国历来主张一切争端和冲突都应该通过对话寻求政治解决，乌克兰问题上同样如此，从这场危机爆发的第2天开始，就是2022年2月25号，中方就提出了对话协商解决；习近平主席提出的4点主张是中国立场的最权威的阐释，那就是各国的主权领土完整应该得到尊重，联合国的宪章应该得到遵守，各国的合理安全关切应该得到重视，一切致力于和平的努力都应该得到支持。中方派出的特使去各国斡旋，同巴西等南方国家发起了和平之友；中方乐见一切致力于和平的努力，包括这两天美国同俄罗斯达成的共识；所有当事方包括利益攸关方，都应该适时参与到这个和谈的进程当中，欧洲更有必要为此发挥重要的作用。关于中美关系，王毅表示，中国的对美政策保持着连续性和稳定性，不会轻易的翻烙饼；对美政策就是习近平主席提出的三原则，相互尊重，和平共处，合作共赢；中方已经准备好了，愿意按照三原则同美方构建稳定健康可持续的双边关系，找到两个大国在这个星球上的正确相处之道；如果美方仍然还要对中国打压和遏制，那我们也别无选择，我们必将奉陪到底，必将坚定的维护中国的主权、国家的尊严和我们的正当发展权利，必将坚决的回击美方的单边和霸凌的这种行径。
