# 访谈概况
本次访谈围绕农村留守老人养老问题展开，访谈对象包括农村留守老人、村政府和民政局干部、城市社区养老社工。访谈目的是了解留守老人养老现状与困境，并寻求解决之道。整体反馈基调为：留守老人面临无人照料、就医困难、经济困难等突出问题，农村养老政策保障水平有限，城市社区志愿者制度与社工服务提供了有益经验，但社工行业面临供给不足、资金短缺、专业欠缺等困境。

# 核心反馈
## 农村留守老人
- **独居现状**：根据2021社区居家养老现状与未来趋势报告，**65.5%** 的老人子女长期不在身边，无奈独居，仅 **26.8%** 的老人与子女同住。
- **生活困境**：独居老人存在无人平护照料、无人慰藉、就医困难等问题，甚至可能独自在家发生意外。
- **典型案例**：黑龙江绥滨一位独居老奶奶因寂寞报警，承认“因为自己一个人在家太寂寞，所以想找个人聊聊天”；上海、杭州各有一名 **67岁** 独居老人去世多日后才被发现。
- **经济压力**：农村老人反映子女外出打工，经济压力大，老人适应能力降低，城市对农村老人存在无形歧视。
- **就医障碍**：一位视障老人说出了自己在就医上遇到的障碍。

## 村政府和民政局干部
- **五保户供养**：五保户分为集中供养和分散供养，分散供养五保户每月发 **475元** 生活费，另有护理补贴；集中供养则将生活护理补贴直接发给敬老院护理人员。
- **低保标准**：残疾人一二级纳入最低生活保障，有 **160、270、380** 三个标准，根据家庭状况制定。
- **养老金水平**：农村老年人每月养老金 **118元**，可能提高，但农村养老金与工人养老金待遇不完全相同。
- **养老问题**：农村养老面临经济困难、子女不在身边、娱乐方式少等问题；之前探索过农村养老公共设施，但地方财政困难，运营经费后续无支持。
- **现有做法**：村支两委和志愿者每月开展党员组织会，下午搞活动、清洁卫生，到孤寡老人、留守老人家里走访。

## 城市社区养老社工
- **志愿者制度**：社区建立志愿者制度，一对一帮扶，志愿者定期看望老人，提供帮助；志愿者积分兑换，年底可到雷锋超市兑换礼品。
- **活动开展**：今年周四准备开展送春联活动，邀请书法老师写对联，孩子们上门送对联；去年中秋节开展做月饼活动，还做过百家宴。
- **未来目标**：2023年目标是家长自己组织活动，社区作为协助者。
- **养老服务中心**：每个社区成立养老服务中心，提供理疗、按摩、老年大学、心理咨询等服务。
- **心理帮扶案例**：社工帮助过一位心理问题老人，通过日复一日关心照料，老人心理问题逐渐好转，与邻里关系改善。
- **社工困境**：社工制度困境在于社会需求量大而供给不足，政府和社区资金有限，难以承担长期专业社工服务费用，大量社工迫于生计转行。

# 关键洞察与建议
**现状洞察**：根据2021社区居家养老现状与未来趋势报告，**65.5%** 的老人子女长期不在身边，独居老人基数庞大，且存在无人照料、就医困难等问题，说明农村留守老人养老问题具有普遍性和紧迫性。
**政策局限**：农村养老金每月 **118元**，分散供养五保户每月 **475元**，保障水平有限；农村养老公共设施因地方财政困难，运营经费后续无支持，说明一次性投入难以持续。
**社工困境**：社工工资低，很多同学做不超过一年就离职；服务领域多，专注力不集中，项目不一定每年都有，说明社工行业供给不足、专业欠缺，影响服务成效。
**改善建议**：建议请专业施工人进行陪伴，倡导在外务工的子女多与老人联系，丰富老人的文化生活，增加娱乐方式；希望老年协会专项执行，专门建养老设施，有固定场地，定期开展宣传、健康知识讲座，并考虑持续运营经费。
**社区经验**：城市社区通过志愿者一对一帮扶、积分兑换、小手拉大手等活动，让老人融入社区，说明社区参与和代际互动有助于缓解老人孤独感。
