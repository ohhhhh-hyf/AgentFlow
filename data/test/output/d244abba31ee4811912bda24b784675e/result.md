# 讲座概况
本次汇报由基金经理肖楠面向投资者进行，主题为过去一段时间的研究布局、研究认知成果以及投资理念与框架的反思与更新。肖楠首先明确反对市场上流行的抱团与均值回归两个观点，随后汇报过去一年研究资源投入互联网、财富管理、新消费、高端制造四个方向，并分享围绕四大领域的重要认知，最后用五点反思梳理对投资框架的更新：对商业模式的反思、对终局判断的反思、对长期隐性变量的反思、深度价值可能长期无效（打问号，未得结论）、小企业X factor。汇报后进入客户提问交流环节，肖楠就终局判断与格局演进、伟大公司判断标准、全市场基金选股逻辑、血制品行业壁垒、农林牧渔行业提升、商增商减分析、伟大企业增长曲线、财富管理行业、企业家精神观察心得等问题逐一作答。

# 核心观点与论证
**论点一：反对抱团与均值回归两种流行观点。** 肖楠认为抱团定义不本质，基金经理之间是竞争关系，主观上不具备抱团意愿，同一公司研究员推荐被广泛认可买入也不叫抱团，且抱团只是截面数据忽略了时间维度；均值回归是特别不本质的局部正确，90%时间正确但10%错误代价惨重，举例某商学院老师在海螺水泥上做波段十年赚两三倍，2016至2017年卖出后该股约两年涨五六倍再未买回，并指出收益率是幂律分布而非正态分布，美国股市200年价值增量由4%的公司贡献。

**论点二：四大研究布局方向。** 过去一年研究资源投入互联网、财富管理、新消费、高端制造四个方向。互联网：全球仅中美能做成巨大产业，中国十几年迭代出流量、运营管理、算法三代企业，港股通开通后可投；财富管理：中国进入小康，人均收入中位数前移带来巨额剩余财富待专业机构管理，行业空间远超想象；新消费：富裕年代诞生的消费公司从CEO理念、组织架构到生产方式与匮乏年代企业完全不同；高端制造：中国几乎是唯一拥有全产业链的国家，很多细分领域已占据主导地位，欧美日企业份额已是中国企业碗里的肉。

**论点三：研究认知成果。** 新消费领域看起来产品差不多的公司收入利润差距巨大，企业眼中产品差异在三年五年十年维度被放大；传统消费龙头赚钱龙二龙三也赚钱，新消费同一行业一家赚很多钱另一家完全不挣钱；从`商增`角度理解企业商业模式，商增过快导致企业走向失败，成长企业靠什么吸收熵增是关键。

**论点四：投资框架五点反思。** 一是对商业模式，世界上没有一劳永逸坐地收钱的生意、极端稀缺，单一维度出发可能错失机会，商增角度理解商业模式更本质，企业家精神是否值得定价存疑并与张坤争论过；二是对终局判断，因终局判断不清晰或悲观而放弃中期十倍机会，需在坚持终局判断基础上争取研究格局演进阶段性特征；三是对长期隐性变量，为什么日本德国没有出巴菲特索罗斯，中国基金经理放到日本韩国不一定有好收益率，国运等长期变量解释相当部分收益率来源，并研究奢侈品和白酒文化强势案例；四是深度价值可能长期无效（打问号，未得结论），深度价值只是结果，去年投的深度价值标的result非常差；五是小企业X factor，经典`DCF`/`DDM`都是线性假设，企业发展是曲线，曲率因素无法定价但长期起作用，超额认知来自这些方面。

# 金句总结
「知识和信息之间是有着巨大的鸿沟的。」——背景：肖楠在开场说明投资者关心的What happen next类问题对提问者用处不大，看好某板块对本人是knowledge，对他人只是一条信息。

「务实还是务虚，其实没有高下之分的。做好的都是大师，做不好都是东施效颦。」——背景：肖楠以巴菲特代表的极端务实派与索罗斯代表的极端务虚派说明基金经理理念处于两个极端中间，强调理念没有好坏。

「均值回归这个事情，90%的时间都正确，那10%的错误依然让你代价惨重。」——背景：肖楠反对均值回归观点，以海螺水泥波段操作案例说明。

「收益率是幂律分布的，不是正态分布的。」——背景：肖楠论证均值回归不本质，指出美国股市200年价值增量由4%的公司贡献。

「长期看所有的企业都要死去，就是我们不能够抱着就是抱定说我我们要买一个千秋万代的这种企业。」——背景：肖楠反思对商业模式的理解，指出没有一劳永逸坐地收钱的生意。

「我们一定要把底线的风险搞好。我们一致同意的就是这个东西它不可被定价，它不能被定价。」——背景：肖楠回答企业家精神观察心得，强调不乱归因、不轻易定价。

# Q&A 环节
问：您刚刚讲到在对于终局结果的重视的过程中，也更加去关注格局演进的过程中阶段性的特征、中期投资机会，请问您能对这一点再详细描述一下吗？
→ 答：肖楠表示不太好说具体标的，这个想法最早来自过去错过了一些特别大的机会，之所以错过是因为判断这些行业终局可能不大行，但明明判断对了却在两三年时间里深深错过了十几倍的涨幅。复盘看当时完全可以在既考虑终局可能没那么好的前提下依然做出漂亮投资。这类企业的重要特征是做出了第二增长曲线，且第二增长曲线的壁垒比第一增长曲线还要深、还要厚。后来在一些投资中，对终局可能没那么强的标的，依然能够做出好的投资，希望未来不要再去错过类似机会。

问：您在年报中也讲到过，坚定持有优秀乃至伟大的公司。请问您能否对优秀乃至伟大的公司的判断标准，有一些具体的财务指标？
→ 答：肖楠称伟大公司是在财务指标里面看不出来的。举例A、B两家同属一个大行业但不同细分子行业的国企，投资逻辑非常像，都在自己领域把成本做到行业最低，市场份额稳固且不断提高。区别在于B公司没有太多研发、靠精益求精的管理做到成本极低；A公司每年有高额研发支出，关键技术指标以非常强速度迭代，还有很多特别前沿的研发项目，这些方向上的技术目前掌握在德国人、日本人手里。A公司在发展初期被德国人、日本人坑过，从董事长到总经理到技术骨干都有强烈的产业报国、技术报国理想，从跟着日本人学、跟着德国人学，到越做越强、超越对手，再到对手跑过来跟他们学、开始做全产业链布局，这种企业堪称伟大的企业。

问：我们是全市场基金，能否介绍一下这个产品的投资逻辑呢？对于消费以外的行业的选股，主要是基于什么逻辑呢？
→ 答：肖楠称很难分消费内消费外，选股逻辑都是一样的，都是不可能三角、企业三阶段、三种商业模式这一类的，消费行业只许买消费所以只能在消费行业里面选，两者选股逻辑完全一样。

问：您是怎么看待血制品行业的竞争壁垒呢？
→ 答：肖楠称血制品行业初初研究过，觉得壁垒不是特别的强，不是想要的那种强壁垒，研究不是特别多，相比之下买了另外一些强壁垒的公司，还有一些基金经理买了血制品行业，可以请教他们。

问：农林牧渔行业是有所提升，请问您对这个行业的观点能够给我们讲一下吗？
→ 答：肖楠称这行业太大了，农林牧渔行业的提升是因为牧原股份那一只股票，不是因为先看好农林牧渔行业再去选了牧原股份，就是牧原股份的比例提高了。

问：您能够再具体讲一下生意模式里边商增和商减的这个分析吗？
→ 答：肖楠用直白例子说明：企业从小到大，部门越来越多，中层干部一大堆，上面要分领导、还有副总裁，传达效率变低、效率开始变差，内部腐败开始出现，企业为解决供应商利益关联问题又要设置巡视检查部门，部门人员要加工资、提级别，多部门老总今年提哪个明年提哪个；企业要扩张，往下游或上游多做业务，又要多一个副总裁、多个部门。有些生意模式收入10个亿跟100个亿时没多多少机构、没多几个部门，有些企业是商增把自己拖死的。行业里剩两家大厂，一家效率特别高，另一家山头林立、互相推诿、腐败丛生，差别在于做得不好的公司从一开始就没考虑好企业大了以后商增怎么处理效率问题和人员问题。建议读一读党史，看组织如何保持活力，很多政府或企业确实是处理商增的高手。

问：您讲到伟大的企业的增长曲线，您能否对于这个曲线的情况再具体跟大家讲一下呢？
→ 答：肖楠称每年看企业今年增长20、明年15、后年17.5都是线性的，站10年周期看企业跟竞争对手之间拉开极大差距。举例快递行业疫情时只有顺丰能送，一下子把竞争对手甩出一大截；家电领域过去格力一直是老大，美的做渠道扁平化、T加三一直没看到成果，疫情来了美的占有率一下子超过格力。当企业在埋头做一些事情、还没体现到报表时，我们往往忽略其未来可能产生的重大影响。这些伟大的企业都是在一些特别特殊的时候拐上去的，就像平时走在路上大家都走得好好的，突然来一场雨，发现有一个人带伞了，别人都淋成了落汤鸡。

问：您刚刚有讲到财富管理行业，能否对这个行业具体展开，讲一下投资逻辑和投资机会呢？
→ 答：肖楠称财富管理行业话题特别大且分层，顶级富豪、普通中产阶级、中低收入人员的财富管理都有不同的公司和商业模式。最早关注这个行业是研究保险时发现，某些保险公司一个保险员一单能签七八千的首次保费，有些公司平均一个业务员大概三千多、有些两千多，差距巨大，背后是结构设置、机构设置、激励机制、文化等差异。发基金时也发现同样渠道经理，有的问的问题超级专业，有的永远问下半年是涨是跌、明年是牛市还是熊市。财富管理行业最大的逻辑在于财富分布超级不均匀，头部公司一口气拿掉行业增量的绝大部分，有些公司拿掉70%、80%，剩下的第二名只能拿到剩下的20%的80%，这种特别偏激、密分布特别偏激的行业里有可能诞生特别大的企业。因监管和法律规则原因有些标的不能投，未来合同设置更清晰时可能会在投资上有所体现。

问：您刚刚讲到曲线的方面，第二第三增长曲线需要卓越的企业家精神，企业家精神应该是投资中比较艺术的部分，请问您在观察这个指标的方面会有什么心得和把握呢？
→ 答：肖楠称第一个心得是评判这个因素时要特别小心谨慎，不要乱归因，不要因为一个企业成功就说企业家特别厉害，就像不要因为一个基金经理过去业绩很好就说他特别厉害，一定要把所有能够被归因到数据里的客观指标因素全部归因完，再特别谨慎地评价比较虚的因素。第二个心得是不要轻易给这些因素定价，绝对不要说因为这个企业家在所以公司就能值多少多少。始终强调的是避免错误的归因，避免因为对企业家的认可去犯投资上的错误，一定要把底线的风险搞好。这些因素不可被定价，只能在有限范围内做两两比较，比如两个公司做同样生意、同样产品，可以比较两个企业家的水平高低、理念先后，仅此而已，不要跨行业、跨业务、跨产品去比较，一定要非常谨慎地使用所谓企业家精神、伟大企业这些说法。
