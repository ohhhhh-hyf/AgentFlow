# 庭审概况
本案系国家开发银行（上诉人）与云南东源电力股份有限公司、云南东源曲靖电力有限公司、招银金融租赁有限公司（被上诉人）金融借款合同纠纷二审，国开行不服云南省高级人民法院2018云民初88号民事判决向本院提起上诉。合议庭由审判员李少平担任审判长，与审判员魏文超、黄年、王海峰、葛洪涛组成，法官助理张瑞。经核对，各方出庭人员身份均符合法律规定，东源煤电、东源煤业、曲靖电力三方委托共同诉讼代理人合并发表意见，各方确认已收到诉讼文书及开庭传票。庭审围绕三个争议焦点调查辩论：抵押权与融资租赁所有权冲突及善意取得、罚息复利计算及起算日期、东源煤电东源煤业是否应连带给付违约金。合议庭提出调解方案，各方均无异议，诉讼代理人依次在调解协议正式文本上签字，法院予以确认并庭后出具调解书。

# 举证与法庭调查
**一、举证与质证**

国开行提交2018年9月对曲靖电力公司的融资租赁查询证书、证据第54页和第58页东源煤电公司曲靖电力公司对设备权属的证明材料和股东会决议、证据第108页核查表；招银租赁提交2015年12月2日邮件及东源公司融资情况统计表、回租设备清单（证据第7页）、2013年和2015年审计报告（证据第82页、第95页）。

**二、法官询问要点**

合议庭就中国人民银行征信中心融资租赁登记的性质及法律后果、融资租赁登记系统查询方式、案涉5套设备是否登记唯一识别码、国开行贷款前风控是否要求保留查询记录、融资租赁司法解释第9条第2款举证责任分担、不同登记机构信息冲突如何处理等问题进行询问。

**三、双方辩论的争议焦点**

1. 抵押权与融资租赁所有权冲突及善意取得：国开行主张已按央行规定查询融资租赁系统且无记录、设备为通用设备无唯一标识码、构成善意取得；招银租赁主张国开行未在抵押时点查询、不构成善意、东源煤电出资系无权处分、其2012年已取得设备所有权。
2. 罚息复利计算及起算日期：国开行主张利息自2017年12月21日至2018年6月12日合计2179.5727万元、罚息自2018年6月13日至2019年2月19日合计4105.0579万元、复利自2018年3月21日至2019年2月19日合计191.8206万元；东源方主张2018年6月13日宣布提前到期未给合理期限、罚息不应作为复利计算基数、复利再计算复利无合同依据。
3. 东源煤电东源煤业是否应连带给付违约金：国开行主张按借款合同第24条第3项支付千分之一违约金、东源方未配合办理账户管理及柜台前移手续；东源方主张国开行未举证证明违约行为且未按合同约定先行限期纠正。

# 庭审结果
合议庭归纳三个争议焦点：一是抵押权与融资租赁所有权冲突及善意取得；二是罚息复利计算及起算日期；三是东源煤电东源煤业是否应连带给付违约金。合议庭提出调解方案：国开行对东源煤电债权利息罚息复利共计6474.4513万元；确认招银租赁对涉案6项设备享有所有权、对应债权数额1377.4137万元，确认国开行对93项设备有抵押权；案涉全部发电设备整体盘活处置，调解书生效后20日内由国开行向一审法院提出执行申请启动司法处置程序，变现价款双方各得50%、实现费用双方各担50%；未实现债权按破产重整计划预留方案实现；案涉设备管理费用由东源曲靖电力承担并无条件配合司法处置；各方对一审判决第2项第4项无争议按其判项内容在调解书中确认；一审诉讼费用中国开行诉请部分按一审判决执行、招银租赁诉请部分诉讼费用由国开行承担，二审诉讼费用由国开行和东源煤电各承担50%；本协议签订后各方就本案涉及问题不再存在任何争议。各方对调解方案均无异议，诉讼代理人依次在调解协议正式文本上签字，法院予以确认并庭后出具调解书。
