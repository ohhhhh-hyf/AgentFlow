# 讨论议题与背景
本次会议为一场围绕“18岁以前的深刻印象和记忆”的分享讨论，由发言人1发起，共6位成员（发言人1至发言人6）参与。讨论由发言人1提出逃课、网吧游戏、追星、音乐会等话题作为由头，成员们依次分享了各自青春期的经历与偏好。议题范围涵盖：18岁前的青春记忆分享（逃课、追星、乐队、漫画、小说、杂志）、流行电脑游戏讨论、第一人称射击游戏与暴力内容讨论、游戏与电影关系讨论、塔防游戏与使命召唤讨论。整体以分享观点为主，未形成统一结论，讨论氛围轻松发散。关键锚点包括：**CS1.5/1.6**、**求生之路第二部**、**Steam账号18岁年龄限制**。讨论推进方式为漫谈式，由发言人1引导话题，成员们围绕游戏、漫画、小说等主题自由发散，逐块展开。

# 发言要点
## 18岁前的青春记忆分享

- **发言人1**：初中走读，每周一下午四点放学后大家聚集在游戏厅、网吧，流行穿越火线CF、反恐精英online、使命召唤、战地、魔兽等游戏；高中因高考压力不敢逃课，转而追星、搞乐队，追求朋克金属主题音乐。
- **发言人2**：十八岁前没逃过课，大学后才逃过一次；觉得郭敬明的小说看着难受、扭曲；喜欢看漫画；初中玩魔兽争霸（非魔兽世界）；认为王者荣耀在游戏鄙视链最底端。
- **发言人3**：逃课是正常现象；经常玩塔防游戏，如植物大战僵尸、Kindle rush，现在也还在玩。
- **发言人4**：上大学后逃课不算；当时班里流行看柯南；提到电脑游戏摩尔庄园、赛尔号；玩过CS1.5和1.6；提到植物大战僵尸融合版。
- **发言人5**：特别喜欢郭敬明的小说；提到萌化三国；玩过仙剑四；质疑穿越火线等游戏没有年龄限制、内容暴力，认为同龄人里没怎么玩过这个。
- **发言人6**：提到Steam图标是个人头上面有个阀门；喜欢僵尸题材；表哥每年过年给放恐怖片。

## 流行电脑游戏讨论

- **发言人1**：询问大家流行的电脑游戏，提到劲舞团，尤其问女生角度；初中时流行CS online，高中时单机最流行求生之路，联机局域玩。
- **发言人4**：提到摩尔庄园、赛尔号。
- **发言人2**：提到穿越火线、地下城与勇士；初中玩魔兽争霸，不是魔兽世界。
- **发言人5**：玩过仙剑四，还玩过仙辕剑或古剑四，记不清具体是哪个。
- **发言人2**：认为英雄联盟和DOTA有鄙视链，王者荣耀在鄙视链最底端。

## 第一人称射击游戏与暴力内容讨论

- **发言人1**：玩过CS1.5和1.6；因在贴吧和QQ空间写文章骂穿越火线抄袭，被穿越火线平台封禁，后成为CS反恐精英铁杆热衷粉，最喜欢僵尸模式；学校舞蹈队说他跳舞姿势像舞体僵尸。
- **发言人2**：觉得穿越火线现在看起来像像素游戏。
- **发言人5**：质疑穿越火线等游戏没有年龄限制、内容暴力，认为同龄人里没怎么玩过这个。
- **发言人1**：解释求生之路第二部血腥暴力，能用东洋刀、电锯、砍刀砍丧尸群，能把脑袋和四肢砍飞、血喷一脸，因此有年龄限制，未成年人不能注册Steam账号，需18岁以上。
- **发言人1**：认为求生之路制作团队精准预测美国政府面对大灾难的表现，2020年新冠疫情爆发后美国政府表现与游戏预测一样，疫情后全世界重新玩起这个游戏。
- **发言人1**：描述求生之路剧情：美国政府一开始对病毒传播默不作声，导致国家失控，军队强力介入以暴力清理方式处理，结果军队也被感染失控，主角团不相信政府承诺、自己拿起枪自救，最后去荒岛开辟新住处。
- **发言人2**：提到欧美玩家爱玩打僵尸游戏，模式一上线欧洲玩家就疯狂在线，整个欧洲年轻人都在打僵尸。
- **发言人1**：提到生化危机也是病毒泄露、政府反应迟钝不作为导致失控，生化三直接用核武器把整个城市夷平。
- **发言人2**：觉得生化危机恐怖，不敢玩。
- **发言人5**：提到过年时跟表姐表弟一群人看恐怖片，大家都跑了。
- **发言人1**：提到惊变48小时、死亡鬼屋、生化危机等作品，求生之路是这些作品的综合；在求生之路里最怕坦克，最烦smoke和jacking——smoke会用长舌头捆人，jacking会骑在肩膀上让人控制不了主界面。
- **发言人2**：认为一切恐惧源于火力不足。

## 游戏与电影关系讨论

- **发言人2**：询问游戏和电影哪个先出，举例生化危机。
- **发言人1**：回答生化危机是先有游戏后有电影；求生之路是在惊变48小时、生化危机基础上，先有电影后有的游戏。
- **发言人4**：提问变形金刚先有的啥。
- **发言人1**：认为变形金刚先有玩具，后有MV和电影，提到绿日（green day）乐队出了介绍变形金刚的MV。
- **发言人2**：提到变形金刚玩具能扭吧扭吧变成车。
- **发言人1**：觉得变形金刚有点抄袭日本题材，电影有点翻拍盗版的感觉。

## 塔防游戏与使命召唤讨论

- **发言人3**：经常玩塔防游戏，如植物大战僵尸、Kindle rush，现在也还在玩。
- **发言人4**：提到植物大战僵尸融合版。
- **发言人2**：提到植物大战僵尸有特别变态的版，后期满屏全是子弹，电脑都卡扛不住。
- **发言人2**：觉得使命召唤这游戏太男性了。
- **发言人1**：介绍使命召唤黑色行动是冷战时期美国和苏联结合真实历史进行明争暗斗、非官方台面上的军事秘密行动；现代战争第一部贴合车臣战争、伊拉克战争、海湾战争，但后来美国挑衅俄罗斯、俄罗斯反杀到美国本土、吊打北约，结合当前俄罗斯在乌克兰的表现，有点高估俄罗斯了。

# 共识形成
- **一致意见**：与会者普遍认同18岁前的青春记忆以游戏、漫画、小说、杂志等娱乐活动为主，且**逃课、去网吧打游戏是当时常见的集体行为**。发言人3认为逃课是正常现象，发言人4补充上大学后不算逃课，发言人2表示自己18岁前未逃过课、大学后才逃过一次。
- **倾向性认识**：在游戏讨论中，多数成员认可**穿越火线、CS、求生之路、魔兽争霸、仙剑系列**等为当时流行游戏；发言人2认为王者荣耀处于游戏鄙视链最底端，发言人5提及英雄联盟、DOTA与王者荣耀之间存在鄙视链，未形成统一排序。
- **主要分歧点**：发言人1与发言人2、发言人5在游戏暴力与年龄限制问题上看法不一致——发言人1认为求生之路第二部血腥暴力、需18岁以上才能注册Steam账号，且其剧情精准预测了美国政府疫情表现；发言人5质疑此类暴力游戏无年龄限制、同龄人很少玩；发言人2觉得生化危机恐怖不敢玩。此外，发言人1认为变形金刚抄袭日本题材、电影有翻拍盗版感，发言人2仅提及玩具能变形，未就此展开争论。
