# 18岁前青春记忆分享会

## 讨论议题与背景
本次会议为一场关于18岁前青春记忆的分享讨论，由主持人发起，共6位发言人参与，围绕逃课、网吧游戏、追星、漫画、单机与网游等话题展开漫谈式分享。讨论由主持人提出「18岁以前有没有什么特别深刻的印象和记忆」开场，各发言人依次分享个人经历：发言人1初中走读时每周一下午4点放学后常去游戏厅、网吧玩穿越火线（CF）、反恐精英online（CS online）等游戏，高中因高考压力不敢逃课转而追星、搞乐队；发言人2表示大学才逃过一次课；发言人5喜欢郭敬明的小说；多人提到流行漫画如柯南、老夫子、萌化三国等。随后话题自然流转至电脑游戏（摩尔庄园、赛尔号、仙剑系列、魔兽争霸等）、第一人称射击游戏与暴力内容（求生之路、生化危机）、游戏与电影关系（变形金刚）、塔防游戏（植物大战僵尸）及使命召唤等议题。整体以分享观点为主，未形成统一结论，讨论按话题逐块推进，由主持人引导过渡，各发言人自由插话补充。

## 发言要点
### 18岁前的青春记忆分享
1. **主持人（发言人1）**：初中走读，每周一下午4点放学后常去游戏厅、网吧，流行玩穿越火线（CF）、反恐精英online（CS online）及动视、易电、暴雪旗下游戏如使命召唤、战地、魔兽；高中因高考压力不敢逃课，转而追星、搞乐队，偏好朋克金属音乐。
2. **发言人2**：大学才逃过一次课，18岁前未逃课；喜欢看漫画，初中玩魔兽争霸（单机），区分魔兽争霸与魔兽世界（网游）。
3. **发言人5**：喜欢郭敬明的小说；玩过仙剑四，也玩过仙剑系列或古剑系列；质疑游戏暴力内容无年龄限制，认为同龄人很少玩此类游戏。
4. **发言人4**：提到摩尔庄园、赛尔号；认为仙剑三最火且有电视剧；讨论英雄联盟、DOTA、王者荣耀存在鄙视链，王者荣耀被认为最低端。
5. **发言人3**：喜欢塔防游戏，如植物大战僵尸、Kindle rush。

### 电脑游戏与单机游戏讨论
1. **发言人1**：询问大家流行的电脑游戏，提及劲舞团；初中流行CS online，高中（2010年）流行求生之路（单机联机局域玩）。
2. **发言人4**：提到摩尔庄园、赛尔号；认为仙剑三最火且有电视剧。
3. **发言人2**：提到穿越火线、地下城与勇士；初中玩魔兽争霸，区分魔兽争霸（单机）与魔兽世界（网游）；认为王者荣耀在鄙视链最低端。
4. **发言人5**：玩过仙剑四，也玩过仙剑系列或古剑系列；讨论英雄联盟、DOTA、王者荣耀存在鄙视链。
5. **发言人1**：指出求生之路第二部血腥暴力，可砍飞丧尸脑袋四肢、血喷一脸，导致Steam要求18岁以上才能注册。

### 第一人称射击游戏与暴力内容讨论
1. **发言人1**：因在贴吧和QQ空间写文章骂穿越火线被平台封禁，后成为CS反恐精英铁杆粉丝，喜欢僵尸模式；曾被说跳舞姿势像舞体僵尸。
2. **发言人5**：质疑游戏暴力内容无年龄限制，认为同龄人很少玩此类游戏。
3. **发言人1**：指出求生之路第二部血腥暴力，可砍飞丧尸脑袋四肢、血喷一脸，导致Steam要求18岁以上才能注册；认为制作团队精准预测美国政府在大灾难中的表现，2020年新冠疫情后游戏重新火爆。
4. **发言人2**：提到生化危机游戏恐怖，不敢玩；认为欧美玩家爱玩打僵尸游戏，模式一上线欧洲年轻人疯狂在线。

### 求生之路游戏剧情与角色讨论
1. **发言人1**：讲述求生之路剧情：美国政府默不作声导致病毒失控，军队暴力清理但被感染，主角团自救；最怕坦克，最烦smoke（长舌头捆人）和jacking（骑肩膀控制）。
2. **发言人6**：提到最后生还者游戏很火。
3. **发言人2**：提到生化危机游戏恐怖，不敢玩；认为一切恐惧源于火力不足。

### 游戏与电影关系及变形金刚讨论
1. **发言人1**：指出生化危机先有游戏后有电影；求生之路在惊变48小时、生化危机基础上先有电影后有游戏。
2. **发言人4**：提问变形金刚先有玩具还是电影。
3. **发言人1**：认为变形金刚先有玩具，后有MV和电影（绿日乐队出过MV介绍变形金刚）。

### 塔防游戏与使命召唤讨论
1. **发言人3**：喜欢塔防游戏，如植物大战僵尸、Kindle rush。
2. **发言人2**：提到植物大战僵尸有变态版，后期满屏子弹导致电脑卡；认为使命召唤游戏太男性化。
3. **发言人1**：指出黑色行动基于冷战时期美苏真实历史，现代战争虚构较多，认为高估俄罗斯。

## 共识形成
1. **【达成共识】青春记忆分享以游戏与流行文化为主线**：全体成员围绕18岁前的逃课、网吧游戏、追星、漫画等话题展开分享，一致认可穿越火线（CF）、反恐精英online（CS online）、求生之路、生化危机、仙剑系列、魔兽争霸等游戏及柯南、老夫子等漫画是共同的时代记忆；**求生之路第二部因血腥暴力导致Steam要求18岁以上才能注册**，这一年龄限制口径得到多人确认。

2. **【核心分歧/待定取舍】游戏暴力内容与年龄限制的争议**：发言人5质疑求生之路等游戏暴力内容无年龄限制，认为同龄人很少玩这类游戏；发言人1则主张求生之路第二部确实血腥暴力（可砍飞丧尸脑袋四肢、血喷一脸），因此Steam要求18岁以上才能注册，并认为该游戏制作团队精准预测了美国政府在大灾难中的表现，2020年新冠疫情后游戏重新火爆。此外，在游戏鄙视链上，发言人2认为英雄联盟与DOTA存在鄙视链，王者荣耀处于最低端，发言人5对此提出疑问但未展开定论。
