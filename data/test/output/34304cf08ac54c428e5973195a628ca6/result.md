# 就诊概况
48岁男性患者张学恒，职业为科研工作，在成都轻工研究所工作，因上腹反复疼痛4年、近3个月持续发作来消化专科门诊初诊。疼痛位于心窝处，有烧灼感，进食冷硬或刺激性食物、工作紧张时诱发，白天为主，夜间无痛醒；一年前与三个月前各出现一次黑便，每次持续约一个月，每日最多两次，大便形状基本正常，两次均住院检查诊断为大便出血，住院两三天后大便转黄；近两个月呕吐数次，吐出酸味黄水样物，为早午餐食物，晚上腹胀时呕吐后缓解。患者近期服用奥美拉唑（武汉药厂产）和阿莫西林，效果不佳，自述每日服药4-5次。初步判断需进一步检查，考虑上消化道出血可能，需通过大便检查及胃镜明确，并待向上级张医生汇报后商定治疗方案。

# 病史与背景
1. **现病史**：上腹反复疼痛4年，每年春季多发，近3个月持续发作；疼痛位于心窝处，有烧灼感，进食冷硬或刺激性食物、工作紧张时诱发，白天为主，夜间无痛醒，疼痛可忍受。
2. **黑便史**：一年前和三个月前各出现一次黑便，每次持续约一个月，每日最多两次，大便形状基本正常；两次均住院检查诊断为大便出血，住院两三天后大便转黄。
3. **呕吐史**：近两个月呕吐数次，吐出酸味黄水样物，为早午餐食物，晚上腹胀时呕吐后缓解。
4. **既往史**：16岁时患甲肝，在三医院住院一个月，出院后肝功能正常；小时候因扁桃体炎在成都市儿童医院就诊，服用磺胺药后左手起红疹，持续半个月，确诊磺胺药过敏。
5. **个人史**：吸烟史，以前每天一包，现限制在10支以内；偶尔饮酒，平时不喝；双眼近视400度，偶尔口腔溃疡。
6. **家族史**：父亲76岁有低血压，母亲75岁有冠心病，弟弟身体健康；婶婶（无血缘关系）患胃癌，患者担心自己是否也患此病。

# 诊断与检查结果
1. **初步印象**：考虑上消化道出血可能，需通过大便检查及胃镜进一步明确。
2. **检查安排**：需留大便标本检查有无出血；预约后天做胃镜，因患者爱人可请假陪同，胃镜活检后恰逢张大夫查房，便于进一步讨论。
3. **医生说明**：严医生解释婶婶（无血缘关系）患胃癌与患者无血缘关系，不必过早担心；关于手术问题，需等检查资料更全面后再判断，若药物能控制病情则无需手术。
4. **患者顾虑**：患者担心自己是否患胃癌，因婶婶有胃癌病史；担心是否需要手术，因工作繁忙且所里领导安排出国进修，希望尽早安排。
