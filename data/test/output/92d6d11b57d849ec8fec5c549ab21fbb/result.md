# 结肠癌术后多发转移患者后续治疗方案讨论

## 就诊概况
患者为结肠癌术后患者，本次为家属代述复诊咨询。核心主诉：结肠癌术后出现肝转移、腹膜转移，化疗后肝功能不佳停药3个月，3月底复查发现肝、肺、腹膜新发转移，4月CT示肝上及背部各有一块病灶；上个月肠镜未见异常，但PET-CT显示有转移，考虑肠镜可能做得不好。本次就诊要解决的问题：除化疗和靶向治疗外是否有更有效手段，是否需要再做肝消融等局部治疗，以及是否需做二次基因检测和免疫评估。医生初步判断当前主要问题是全身系统治疗，局部介入暂不考虑，需做二次基因检测以寻找靶向和免疫治疗依据。

## 病史与背景
1. **确诊与手术**：患者确诊结肠癌后做了切除手术，术后做了8期化疗。
2. **转移与局部治疗**：复查发现肝转移，去年9月做了肝消融和乳腺结节切除；切肠时可能切得不干净，存在腹膜转移。
3. **化疗与停药**：消融和切除后做了紫杉醇化疗，但第一次后因肝功能不行停用靶向药，停药3个月。
4. **近期复查**：3月底复查发现肝、肺、腹膜又有转移；4月份CT显示肝上有一块，背上也有一块。
5. **肠镜与PET-CT**：上个月肠镜显示没事，但派特CT显示有转移，可能肠镜做得不好。
6. **既往肠胃情况**：患者多年来吃东西易中毒，比如吃海鲜就爱上吐下泻，家属一直觉得他肠胃比较弱。

## 诊断与检查结果
1. **诊断结论**：结肠癌术后肝转移、腹膜转移，化疗后肝功能不佳停药3个月，3月底复查发现肝、肺、腹膜新发转移。
2. **检查结果**：4月份CT显示肝上有一块，背上也有一块；上个月肠镜显示没事，但派特CT显示有转移，可能肠镜做得不好。
3. **医生说明**：医生认为当前主要问题是全身系统治疗，局部介入不是主要问题；如果病灶涨幅到10公分、危及生命才需处理，现在病灶小，要先系统治疗。
4. **家属疑问与顾虑**：家属询问除了化疗和靶向还有没有更有效手段，是否需要再做肝消融等局部治疗；家属表示患者尚不知晓扩散情况，不想做太多检查。

## 治疗方案与医嘱
1. **检查安排**：建议做二次基因检测，可在肿瘤医院进行，约涉及3个学科；建议做免疫评估，但方案由家属定。
2. **治疗方案**：当前以全身系统治疗为主，包括化疗、靶向、免疫，可联合使用；医生解释靶向联合免疫可能协同增效（1+1大于2）。
3. **生活方式与饮食**：医生建议家属让患者调整好身体状态，为后续系统治疗做准备。
4. **用药说明**：医生提及四联康，用于肚子不好时服用，但患者未关注。

### 预警信号
1. **肝功能不佳**：化疗后肝功能不行，导致停药3个月，可能影响治疗效果。

### 需要观察的变化
1. **病灶变化**：需观察肝、肺、腹膜转移灶变化，若病灶涨幅到10公分、危及生命才需处理。
