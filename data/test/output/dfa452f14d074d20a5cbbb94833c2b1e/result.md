# 访谈概况
本次访谈围绕农村留守老人养老问题展开，受访对象包括农村独居老人、村政府和民政局干部、城市社区养老社工等。访谈目的是了解农村养老现状、政策实施情况、存在困境及城市社区养老经验，以探索解决路径。整体反馈基调为：农村留守老人面临无人照料、无人慰藉、就医困难等突出问题，养老政策覆盖有限、运营经费不足，城市社区志愿者制度和社工服务提供了有益借鉴，但社工行业存在供给不足、资金短缺、专业欠缺等困境。

# 核心反馈
**农村留守老人核心痛点**：据2021年报告数据，65.5%的老人子女长期不在身边，26.8%与子女同住；独居老人存在无人照料、无人慰藉、就医困难等问题，甚至发生意外。典型案例：黑龙江绥滨独居老人因寂寞报警；杭州67岁独居老人去世多日才被发现。

**农村养老政策现状**：五保户分集中供养和分散供养，分散供养每月475元生活费加护理补贴；残疾人按等级纳入低保，标准为160、270、380元；农村养老金每月118元，与工人养老金待遇不同。村支两委和志愿者定期上门服务，每月党员组织会后开展活动。

**对现有解决方案的不满**：干部指出农村养老存在经济困难、子女不在身边、娱乐方式少等问题；之前探索建设的养老公共设施因运营经费无后续支持而难以为继。

**城市社区经验**：建立志愿者制度，一对一帮扶，志愿者积分兑换礼品，发掘中年志愿者，开展小手拉大手活动、送春联、做月饼、百家宴等；社区养老服务中心提供理疗、按摩、老年大学、心理咨询等服务。社工帮助心理问题老人案例：一位老人因心理问题与邻里关系不和谐，经社工日复一日关心照料后逐渐好转。

**社工制度困境**：社工分为社区社工（小区出资）和街道社工（政府出资）；存在社会需求量大而供给不足、政府和社区资金有限、社工工资低、转行率高、专业欠缺、项目资金不稳定、服务成效不明显等问题。

# 关键洞察与建议
核心洞察：农村留守老人养老问题突出，经济困难、子女不在身边、娱乐方式少是主要困境；养老公共设施建设需考虑后续持续运营经费；城市社区志愿者制度和社工服务为农村养老提供借鉴。建议：请专业施工人陪伴、倡导在外务工子女多联系、丰富文化生活、老年协会专项建养老设施并保障持续运营经费；城市社区可发掘中年志愿者、开展小手拉大手活动、组织送春联等社区活动增强老人归属感；社工行业需提高工资待遇、增强专业性、保障项目资金稳定，以提升服务成效。
