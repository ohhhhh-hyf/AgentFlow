# 发布会概况
2025年2月，中共中央政治局委员、外交部长王毅在慕尼黑安全会议上发表演讲并回答提问，阐述中国对多极世界的立场。王毅引用今年慕安会报告主题“走向多极化”，指出联合国成立时仅有51个会员国，如今已有193个国家，提出推动平等有序的世界多极化，这是习近平主席提出的主张。他围绕这一主张表达四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。中国承担超过20%的联合国会费，建成世界最大清洁发电体系，提出全球发展倡议、全球安全倡议、全球文明倡议。去年中国GDP增长5%，对世界经济增长贡献率接近30%。在问答环节，王毅回应了关于国际秩序、乌克兰危机、中美关系等提问，重申中国维护以联合国为核心的国际体系、通过对话政治解决争端、按三原则处理中美关系等立场。整体基调坚定务实，强调中国是多极体系中的确定性因素和变革世界中的建设性力量。

# 核心信息
王毅在慕尼黑安全会议上发表演讲，核心信息包括：联合国成立时仅有51个会员国，如今已有193个国家；中国承担超过**20%**的联合国会费；建成世界上最大的清洁发电体系；提出并落实`全球发展倡议`、`全球安全倡议`、`全球文明倡议`；去年中国GDP增长**5%**，对世界经济增长贡献率接近**30%**；中国加入几乎所有普遍性政府间国际组织和**600多项**国际公约；今年是中欧建交**50周年**。王毅提出推动平等有序的世界多极化，这是习近平主席提出的主张，并就此表达四点看法：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。中国愿推动高质量共建`一带一路`，同欧盟的`全球门户`战略相互对接。

# 官方表态
王毅在演讲中主动阐述中国对多极世界的立场，按主题分组如下：

**关于多极化**：王毅表示，多极化的世界既是历史的必然，也正在成为现实。中国给出的答案是推动平等有序的世界多极化，这是习近平主席提出的重大主张。中国必将是多极体系中的确定性因素，将坚定做变革世界中的建设性力量。

**关于平等相待**：王毅指出，列强争霸曾给人类带来灾难，两次世界大战殷鉴不远，不平等的秩序注定土崩瓦解。坚持权利平等、机会平等、规则平等，应当成为建设多极世界的基本原则。中国主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权。

**关于国际法治**：王毅强调，联合国宪章宗旨和原则是国际关系的根本遵循，也是建设多极世界的重要基石。多极格局不能是无序的状态，如果没有了规矩，昨天在餐桌上明天就可能在菜单里。大国要带头讲诚信、讲法治，坚决摒弃言行不一、零和博弈。中国坚定维护国际法治权威，积极履行国际责任和义务，从不搞例外主义，更不搞合则用、不合则弃。

**关于多边主义**：王毅表示，联合国是践行多边主义、推进全球治理的核心平台，已经为各国遮风挡雨80年。未来的多极世界更加需要联合国，对于这座大厦，我们应该固本强基，而不是拆梁毁柱。中国坚持真正的多边主义，倡导共商共建共享的全球治理观。

**关于开放共赢**：王毅指出，发展是破解各种难题的钥匙，多极世界应该是各国共同发展的世界。保护主义不是出路，滥加关税没有赢家。脱钩断链断的是机遇，小院高墙封的是自己。应当坚持开放合作，以普惠包容的经济全球化来支撑平等有序的世界多极化。

**关于中欧关系**：王毅表示，中方始终认为欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手。今年是中欧建交50周年，中方愿意同欧方用好这一契机，深化战略沟通和互利合作。

# Q&A环节
**问**：主持人提问，您提到国际秩序，现在很多人质疑联合国宪章，包括俄罗斯入侵乌克兰、美国总统威胁使用武力入侵格陵兰和巴拿马、驱逐巴勒斯坦人，贵国也被指控违反海洋法和世界人权宣言。您即将前往纽约参加安理会会议，您是否仍然相信联合国和联合国宪章？是否致力于改革联合国？
**答**：王毅表示，关于秩序，这几年总有人说中国要改变秩序、另起炉灶，但现在真正挑战秩序、毁约退群的国家出现了，欧洲的朋友可能每天都在感受到阵阵袭来的寒意。中国是在现行国际秩序中发展起来的，是受益者，要做的就是按照大多数国家的愿望，推动秩序朝更加公正合理的方向发展。关于规则，大家起码应该有一个共同认知，就是维护以联合国为核心的国际体系，遵守以联合国宪章宗旨和原则为基础的国际关系基本准则，这是最大的公约数。只要认同这一点，双重标准就没有存在的空间。习近平主席提出全球发展倡议、全球安全倡议、全球文明倡议，希望国际社会携手解决发展赤字、安全赤字、治理赤字，共同构建人类命运共同体。

**问**：主持人提问，2022年慕安会前几天您曾表示任何国家的主权、独立和领土完整都应得到尊重和维护，乌克兰也不例外。现在俄罗斯已成为中国的一个加油站，您是否可能利用影响力，减少从俄罗斯购买天然气、降低价格或停止进口军民两用物资，以加大对俄罗斯的压力，结束战争？
**答**：王毅表示，中国同俄罗斯是两大邻国，有着漫长的边界，两国建立了不结盟、不对抗、不针对第三方的睦邻友好关系，进而建立了全面战略伙伴关系。如果中国不从俄罗斯买油气，哪个国家能提供如此巨量的油气来满足中国民众的需求？那是不可能的，也是不保险的，因为有的国家常把经贸问题政治化，当作打压中国的工具。中国在地区热点问题上有自己的立场，历来主张一切争端和冲突都应通过对话寻求政治解决，武力和制裁不可能真正彻底解决问题。从2022年2月25日危机爆发第二天起，中方就提出对话协商解决。习近平主席提出4点主张：各国主权领土完整应得到尊重、联合国宪章应得到遵守、各国合理安全关切应得到重视、一切致力于和平的努力应得到支持。中国以此推进劝和促谈，派特使去各国斡旋，同巴西等南方国家发起和平之友。任何冲突的终点都是谈判桌，中方乐见一切致力于和平的努力，包括美俄达成的共识，同时认为所有当事方和利益攸关方都应适时参与和谈进程。这场战事发生在欧洲大地上，欧洲更有必要发挥重要作用，共同探讨欧洲的长治久安，找到均衡、有效、可持续的欧洲安全框架。

**问**：主持人提问，能否简要预告一下您认为美中关系将如何发展？
**答**：王毅表示，中国的对美政策保持连续性和稳定性，不会轻易翻烙饼，这体现大国的战略定力和国际信誉。对美政策就是习近平主席提出的三原则：相互尊重、和平共处、合作共赢。中美制度不同是各自人民的选择，想改造或颠覆对方不切实际，正确态度是相互尊重，这是中美交往的前提；和平共处理所当然，中美两个大国总不能冲突起来，那将殃及整个世界；合作共赢是国际社会的期待，全球性挑战需要中美携手应对。中方已准备好按三原则同美方构建稳定健康可持续的双边关系，希望美方相向而行。如果美方仍要打压遏制，中国别无选择，必将奉陪到底，坚决维护主权、国家尊严和正当发展权利，坚决回击美方的单边霸凌行径。中国有句古话：天行健，君子以自强不息。还有话说：他强任他强，清风拂山岗；他横任他横，明月照大江。总之，我们对世界前途和中美关系的未来都充满信心。
