## 要点梳理
### 文化自信与中华民族现代文明建设

1. 习近平总书记提出“两个结合”，强调“我们五千年的文明，我们要尊重，也要弘扬，把它里边精华的东西和我们现在所坚持的马克思主义立场、观点、方法结合起来，这就是中国特色社会主义”，指出把马克思主义基本原理同中国具体实际、同中华优秀传统文化相结合是必由之路。
2. 2023年6月，习近平总书记主持召开文化传承发展座谈会，系统论述中华文明的五个突出特性，进一步阐述“两个结合”尤其是“第二个结合”的重大意义。
3. 2023年10月，全国宣传思想文化工作会议在京召开，首次提出习近平文化思想。
4. 习近平总书记考察孔子故里、岳麓书院、三苏祠、武夷山朱熹园等地，强调从中华优秀传统文化中汲取治国理政理念和思维、以时代精神激活其生命力。
5. 《深化文化体制改革实施方案》是中央全面深化改革领导小组审议通过的第一个专项小组改革方案；《关于实施中华优秀传统文化传承发展工程的意见》首次以中央文件形式对文化传承发展进行部署。
6. 文化领域供给侧结构性改革深入推进，文化旅游深度融合、非遗保护传承制度日益完善、公共文化服务体系不断健全；深入实施中华文明探源工程，高标准推进国家文化公园建设，中国共产党历史展览馆、国家版本馆等文化地标落成，《复兴文库》、“中国历代绘画大系”出版。
7. 我国成为图书、电视剧、动漫等领域生产大国，数字文化产业成为激发消费潜力“新引擎”，电影市场规模屡创新高；深化国有文艺院团改革，树立以人民为中心的创作导向。

### 赵乐际访问俄罗斯并出席中俄议会合作委员会第九次会议

1. 应俄罗斯联邦会议国家杜马主席沃洛金和联邦委员会主席马特维延科邀请，全国人大常委会委员长赵乐际于7月9日至13日对俄罗斯进行正式友好访问，在圣彼得堡会见总统普京，在莫斯科与马特维延科、沃洛金分别举行会谈，并出席中俄议会合作委员会第九次会议。
2. 今年是中俄建交75周年，赵乐际表示中国全国人大愿同俄罗斯联邦会议一道，从立法机构层面落实两国元首重要共识，为巩固政治互信、深化务实合作、增进人民友谊作贡献。
3. 普京表示俄中立法机构始终保持高水平合作，加强俄中议会合作委员会工作有利于两国交流经验、互学互鉴，促进立法、地方等各领域合作。
4. 与马特维延科、沃洛金会谈时，赵乐际提出两国立法机构要立足职能职责，用好中俄议会合作委员会、双边友好小组等机制和平台，深化多层级、多领域、多渠道交流合作，互学互鉴立法经验，为务实合作提供法治保障。
5. 马特维延科表示发展对华关系得到俄社会广泛认同和支持；沃洛金表示俄国家杜马不同党派在发展对华关系上高度一致，俄坚定恪守一个中国原则，反对任何外部势力干涉中国内政。
6. 7月10日，赵乐际出席中俄议会合作委员会第九次会议并致辞，提出密切战略协作、交流治国理政经验、发挥立法机构职能作用、传承弘扬传统友谊、加强多边协作团结壮大“全球南方”力量等五点建议。
7. 访问期间，赵乐际在莫斯科向俄无名烈士墓敬献花圈。

### 夏粮产量创历史新高

1. 今年我国夏粮产量达2996亿斤，比2023年增加72.5亿斤，再创历史新高，克服多重自然灾害影响。
2. 夏粮单产每亩达到375.2公斤，其中小麦单产达399.1公斤，比2023年增加10公斤，单产恢复性增长是产量增加的主要原因。
3. 全国已建成高标准农田10亿多亩；农业农村部启动小麦单产提升三年行动；中央财政首次提前下拨16亿元小麦“一喷三防”资金。
4. 小麦质量为近年来最好水平，主产区一、二等小麦占比普遍较高，夏粮首战告捷为全年粮食丰收奠定基础。

### 6月份国家铁路货运指标增长

1. 6月份国家铁路发送货物3.32亿吨，完成货运周转量2665亿吨公里，同比分别增长6.1%、5.3%，创历史同期新高；我国铁路货运量、货运周转量等指标稳居世界首位。
2. 分品类看，化肥农药运量增幅最大，同比增长26.2%；煤炭日均装车量，集装箱、商品汽车、冷链货物发送量等均创历史同期新高。
3. 连接内陆物流节点城市的多式联运快车已覆盖各省会城市，连接港口和内陆腹地城市的铁海快线班列已覆盖全国主要港口。
4. 6月份中欧班列累计开行1719列，发送货物18万标箱，同比分别增长15%、11%。

### 上半年快递业发展提速

1. 今年上半年我国快递业务量超800亿件，截至6月30日已达800亿件。
2. 快递企业已运行国际航线40余条，面向东南亚开通陆运专线，运行美西海运航线，多地启用、升级跨境仓，农村寄递网络覆盖范围逐渐扩大。
3. 每天超1亿件快递包裹在农村地区流动，5—6月生鲜商品进入销售旺季、电商促销拉动线上消费，快递日均业务量近5亿件。
4. 快递业不断丰富服务场景，拓展服务领域，实现与制造业的融合发展。

### 油气管网建设提速

1. 预计全年新增油气管网里程超4000公里，“全国一张网”不断完善。
2. 西气东输四线已完成吐鲁番至中卫段主体管道工程建设，今年投产后年输气能力将提升150亿立方米；川气东送二线、虎林到长春天然气管道等工程加速推进。
3. 我国主干油气管网约10万公里，输气能力从2020年2230亿立方米增加到3290亿立方米，增幅达48%，天然气“全国一张网”日供气能力超10亿立方米。
4. 到2025年，将初步形成东北、西北、西南以及海上四大油气战略通道，建成“五纵五横”的天然气干线管网。

### 渝川皖等地应对降雨天气

1. 7月13日8时至14日8时，重庆九龙坡、江北等28个区县出现暴雨，其中沙坪坝、江津等13个区县大暴雨，当地组织工作人员连夜抢险排涝。
2. 四川暴雨造成内江部分地区出现内涝、滑坡等险情，消防救援人员紧急出动转移被困群众。
3. 强降雨导致安徽多条河流水位上涨，滁州市全椒县工作人员加强巡堤，及时处置堤防渗漏和管涌等情况。
4. 水利部针对“七下八上”防汛关键期逐流域安排防御；长江1号、2号洪水正在演进，三峡水库15日将迎来洪峰流量45000立方米每秒量级的洪水过程，水利部联合调度嘉陵江亭子口水库等上游干支流水库群，减小三峡水库入库洪峰流量。
