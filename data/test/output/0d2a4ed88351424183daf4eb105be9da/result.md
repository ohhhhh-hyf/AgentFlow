# 就诊概况
患者为结肠癌术后患者，2023年9月因结肠癌行切除手术，术后完成8期化疗，后出现肝转移，去年9月行肝消融和乳腺结节切除，因肝功能不佳停用部分化疗药，3月底复查发现肝、肺、腹膜转移。患者主诉为肚子疼，疼了一晚上，既往有吃海鲜后上吐下泻史。初步诊断为结肠癌术后多发转移（肝、肺、腹膜）。医生建议优先进行全身系统治疗（化疗、靶向、免疫），而非局部介入，并建议进行基因检测和免疫评估以指导后续治疗。

# 诊断与检查结果
诊断结论：结肠癌术后多发转移，累及肝脏、肺、腹膜。关键检查结果：PET-CT显示肝转移、肺转移、腹膜转移；肠镜显示未见异常，但PET-CT显示有转移，医生认为可能肠镜做得不好；基因检测提示存在基因突变，但具体类型未明确。异常指标：肝功能不佳，导致停用部分化疗药。
