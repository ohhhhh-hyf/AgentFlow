# 复盘目标与结果概况
本次复盘会为2023年度总结暨年终奖颁发年会，预期目标是总结公司年度发展状况、公布年终奖并评价员工。实际结果：年终奖总额226,000元，个人数额不一一公布；成本控制较差，实打实支出390万元（含人员工资、外援配音字幕租机器），利润率约24%或27%；最高工资两三人含年终奖到手20万元，平均工资到手1万多元；2023年人工支出相对提高25万元左右，年终奖比去年多13万元左右；干满一年12人；公司总量提升，但结余到账往下跑，有百来万没收回来；老板比去年少拿10万元左右，承担风险亏100万元。会议主要内容包括年度数据报告、年终奖发放标准说明、逐人评价员工、颁发5项奖项及抽奖。

# 亮点事项
- **短视频账号数据增长显著**：视频号粉丝从700涨到8万，小红书从2000+到6.4万，抖音从2000+到5.7万，B站从3.1万到7.6万，关键转折点是6月20日第一条外出拍摄视频，成功原因是郭东辉破釜沉舟说服潘老师外出拍摄，并坚持不放弃。
- **账号变现课程拍到7.5分（满分10）**，直播视频号4-5场，平均在线5000人+，为后续变现打下基础。
- **刘腾宇评价最高**，职业性、专业性、纪律性好，年终奖因此拉一档；老板称其“干的活倒来倒去倒不到他头上”，沟通专业，迟到几乎没有。
- **张扬作为公司邀请人才**，基本达到期待，老板称“2023年干到最有价值的一件事就把他招进来”。
- **宋俊逸编导效率高**，第一次安排宁波两分钟宣传片稿子即获认可，“行家一出手便知有没有”。
- **市井为后期技术标杆**，最好没有之一，能胜任课程、微电影、MV、快剪等各类后期。

# 不足事项
- **成本控制非常差**：实打实支出390万元（含人员工资、外援配音字幕租机器），利润率仅24%或27%，老板承认“最大的癌症的问题，根源的问题就是老板的问题”，对关心关注不够、不够雷厉风行、问题未及时解决。
- **公司结余到账往下跑**：有百来万没收回来，老板比去年少拿10万元左右，承担风险亏100万元。
- **短视频重点项目未完成**：账号变现课程拍到7.5分（满分10），重点项目未完成；直播虽平均在线5000人+，但尚无课程可变现。
- **加班严重**：后半年基本都在加班，很少正常休息，根因是老板未及时招合适人数的人员，属于判断失误。
- **拍摄外援成本高**：钱德峰指出请外援价格与内部拍摄差很多，但公司内部凑不出人去按机位。
- **后期与前期奖金不平衡**：老板承认后期比前期少一截，是唯一愿意解释的奖金侧重。
