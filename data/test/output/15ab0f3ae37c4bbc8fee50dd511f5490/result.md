# 发布会概况
王毅在慕尼黑安全会议上发表讲话，围绕多极化世界走向阐述中方立场，提出四点主张：倡导平等相待、尊重国际法治、践行多边主义、坚持开放共赢。王毅表示中国必将是多极体系中的确定性因素，将坚定做变革世界中的建设性力量。他称欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手，今年是中欧建交50周年，中方愿同欧方深化战略沟通和互利合作。在答问环节，王毅就联合国作用、乌克兰问题、中美关系等作出回应，强调中国对美政策保持连续性和稳定性，遵循相互尊重、和平共处、合作共赢三原则。

# 核心信息
王毅提出四点主张：一是倡导平等相待，坚持权利平等、机会平等、规则平等，主张大小国家一律平等，呼吁提升发展中国家在国际体系中的代表性和发言权；二是尊重国际法治，强调联合国宪章宗旨和原则是国际关系根本遵循，中国加入了几乎所有普遍性的政府间国际组织和**600多项**国际公约，从不搞例外主义；三是践行多边主义，称联合国是推进全球治理的核心平台，中国承担着超过**20%**的联合国会费，切实履行巴黎协定，建成了世界上最大的清洁发电体系，提出并落实全球发展倡议、全球安全倡议、全球文明倡议；四是坚持开放共赢，称保护主义不是出路，滥加关税没有赢家，脱钩断链断的是机遇，小院高墙封的是自己，去年中国GDP增长**5%**，对世界经济增长的贡献率接近**30%**，愿推动高质量共建一带一路同欧盟的门户全球门户战略相互对接。王毅表示今年是中欧建交50周年，中方愿同欧方用好这一契机深化战略沟通和互利合作。

# 官方表态
关于多极化，王毅表示多极化的世界既是历史的必然，也正在成为现实，中国给出的答案是应当推动平等有序的世界多极化，这是习近平主席提出的重大主张。关于国际法治，王毅称国家不论大小强弱都是国际法治的利益攸关方，多极格局不能是无序的状态，大国要带头讲诚信、讲法治，坚决摒弃言行不一、零和博弈，并强调在遵守国际法上不能搞双重标准，要尊重各国的主权和领土完整，就应该支持中国实现完全统一。关于多边主义，王毅称联合国已经为各国遮风挡雨80年，对于这座大厦应该固本强基，而不是拆梁毁柱。关于开放共赢，王毅称发展是破解各种难题的钥匙，多极世界应该是各国共同发展的世界。关于中欧关系，王毅称中方始终认为欧洲是多极世界的重要一极，中欧双方是伙伴而不是对手。关于乌克兰问题，王毅称中国同俄罗斯之间的交往是正常的国与国之间的交往，反问如果中国不从俄罗斯买油气，哪个国家能够提供如此巨量的油气来满足中国民众的需求，表示中方历来主张一切争端和冲突都应该通过对话寻求政治解决，习近平主席提出的4点主张是中国立场的最权威的阐释，任何冲突的终点都是谈判桌，中方乐见一切致力于和平的努力，包括这两天美国同俄罗斯达成的共识，认为所有当事方包括利益攸关方都应该适时参与到和谈进程当中，欧洲更有必要为此发挥重要作用。关于中美关系，王毅称中国的对美政策保持着连续性和稳定性，不会轻易翻烙饼，对美政策就是习近平主席提出的三原则：相互尊重、和平共处、合作共赢，中方已经准备好了，愿意按照三原则同美方构建稳定健康可持续的双边关系，如果美方仍然还要对中国打压和遏制，那我们也别无选择，我们必将奉陪到底。

# Q&A环节
问：中国是否继续相信联合国及联合国宪章，是否会推动联合国及宪章改革，优先级多高？ → 答：王毅表示，说到秩序，这几年总有人说中国要改变秩序、另起炉灶，但现在再说这种话的人可能不会太多了，因为真正要挑战秩序、毁约退群的国家出现了；中国是在现行国际秩序中发展起来的，是这个秩序的受益者，要做的就是按照大多数国家的愿望，推动这个秩序朝着更加公正合理的方向去发展。谈到规则，王毅认为起码应该有一个共同认知，那就是需要共同来维护以联合国为核心的国际体系，共同遵守以联合国宪章宗旨和原则为基础的国际关系基本准则，这应该是最大的公约数。

问：中国是否可减少从俄罗斯购买油气或停止部分两用物资以对俄施压结束战争？ → 答：王毅表示，中国同俄罗斯是两大邻国，有着漫长的边界，两国关系过去经历过一番曲折，之后双方吸取教训，建立了结盟不对抗、不针对第三方的睦邻友好关系，进而增进了战略互信，建立了全面战略伙伴关系；中国同俄罗斯之间的交往是正常的国与国之间的交往。王毅反问，如果中国不从俄罗斯买，哪个国家能够提供如此巨量的油气来满足中国民众的需求呢？那是不可能的，也是不保险的。王毅表示中国在对待地区热点问题上是有立场的，历来主张一切争端和冲突都应该通过对话寻求政治解决，乌克兰问题上同样如此，从这场危机爆发的第2天开始，就是2022年2月25号，中方就提出了对话协商解决，习近平主席提出的4点主张是中国立场的最权威的阐释，中方以此为遵循不断推进劝和促谈，派出的特使去各国斡旋，同巴西等南方国家发起了和平之友。

问：中美关系将如何发展？ → 答：王毅表示，中国的对美政策保持着连续性和稳定性，不会轻易翻烙饼，这体现了作为大国的战略定力和国际信誉；对美政策就是习近平主席提出的三原则，相互尊重、和平共处、合作共赢。中国和美国制度确实不一样，这是各自人民做出的选择，如果想改造或者颠覆对方的话，那是不切实际的，正确的态度就是相互尊重。中美两个大国总不能冲突起来，因为那将殃及整个世界，所以还是要开展对话、加强交往、增进了解、建立信任。合作共赢是因为国际社会期待中美开展合作，全球性的挑战也需要中美携手来应对。中方已经准备好了，愿意按照三原则同美方构建稳定健康可持续的双边关系，找到两个大国在这个星球上的正确相处之道，当然希望美方能够相向而行；但如果美方不愿意，如果美方仍然还要对中国打压和遏制，那我们也别无选择，我们必将奉陪到底，必将坚定维护中国的主权、国家的尊严和正当发展权利，必将坚决回击美方的单边和霸凌行径。
