# 内容总结
- 会议围绕定价、月度追踪、流程审批等工作总结上半年问题，并制定下半年工作目标与改进举措。
- 上半年项目总数由50个增至57个，其中消费销售23个、租赁27个，8月广州、珠海增加7个；
- 流程审批2477条，同比增长46%，超时7条占比0.3%，同比下降0.38%。
- 会议指出定价依据性不足、风险意识缺乏、项目区划思路缺乏、难点项目破局能力欠缺、市场跟进预见性不足、客户审核标准降低但个别项目风险意识需加强等问题。
- 下半年需加强定价依据性、价格逻辑推导、去库存风险意识、实时追踪思维，完善退租台账，加强客户审核风险把控。
- 定价组新人分别汇报下半年工作目标与举措，领导点评强调务实、避免务虚、多思考工作意义。
- 会议确认多项改进方向，包括加强人员横向对比、日常了解项目情况、重点关注履约风险等。
# 主要议题
## 上半年工作总结与问题分析
### 问题与事实
- 上半年项目总数57个，其中消费销售23个、租赁27个，8月广州、珠海增加7个。
- 流程审批2477条，同比增长46%，超时7条占比0.3%，同比下降0.38%。
- 定价依据性不足，价格输出有时根据经验判断，有时只对标竞品，未充分对比分析项目价值区位、圈层等因素。
- 对项目区划思路缺乏关注，更多关注价格本身，对项目打法、人员组织安排和城市策略缺乏了解，可能造成价格与区划不匹配。
- 风险意识不足，定价过程中对项目面临风险了解不多，对同城其他项目缺乏系统关注。###[【风险意识不足，对项目面临问题和同城项目缺乏系统了解】](https://example.com/annotation)
- 难点项目破局能力欠缺，如佛山石山、江门鹤山、广州租赁、北京北边租赁等项目，对核心问题判断不准，不能有效出具政策方案和调整建议。
- 对项目敏感度和预见性不足，如对北京租赁市场跑得少，市场掌握欠缺。
- 月度追踪节奏不够紧凑，项目定价后追踪不及时，可能导致政策给出但未达去化预期。
- 客户审核标准降低，个别项目考虑去化而质量把控不足，风险意识需加强。###[【客户审核标准降低，个别项目风险意识需加强】](https://example.com/annotation)
### 讨论观点
- 有建议指出，定价工作抓重点能力需提升，信息大而全但结构弱，重点突出和关键信息抓取偏弱。
- 有建议指出，好的经验和工具（如流程超时控制、退租台账）应及时分享，提升部门效率。
- 有发言提出，工作做久了会有疲态，工作积极性不足，需改进。
### 建议与方案
- 定价方面，到一个城市不能为了定价而定价，要充分了解城市问题风险和解决思路，加强人员盘点。###[【到一个城市呢不能为了定价而定价。 **用户批注** 这不废话】](https://example.com/annotation)
- 加强价格逻辑推导，与金额部门探讨学习，理清价格与区划关系，加强定价后评估。###[【下半年需加强价格逻辑推导和定价后评估】](https://example.com/annotation)
- 月度追踪方面，加强思想转变，树立去库存风险意识，加强敏感度和感知度。
- 加强人员横向对比和评估，包括本月与上月数据对比。
- 加强实时追踪思维，日常在客户审核、价格申请、退租催售等环节了解项目情况，节省月度时间。###[【就日常的话就是在日常的客户审核价格申请，包括退去催催售等环节呢，就是把这个项目的日常情况呢了解清楚 **用户批注** 我信你还是信秦始皇？】](https://example.com/annotation)
- 流程方面，继续完善退租台账，加快退租整理速度和审批效率。
- 客户审核方面，重点关注履约风险，动态把握项目区划和客户动态，坚持底线。###[【个别重点的或者是亮点项目或者是有罚的项目比较多的这种项目呢，还是重点关注这个履约风险 **用户批注** 弃车保帅】](https://example.com/annotation)

- 状态：方向明确。

## 定价组新人工作汇报与点评
### 问题与事实
- 相关发言汇报：流程审批效率低、时间长；
- 对内审项目情况不完全清楚，较难给出成熟客观的审批建议；
- 对未实际去过的项目没有具体概念；
- 对项目竞品价格和库存数据准确性难以把控；
- 定价方面尚无完整定价经历，对目标城市、项目本体和竞品情况不熟悉。
- 相关发言汇报：工作效率偏低，拿到工作盲目开始，缺乏思考；
- 对项目掌握度低，数据不敏感，不能及时给出合理判断；
- 时间管理欠缺，工作偏滞后。
- 相关发言汇报：计划下半年完成5个项目周边竞品实地调研，输出调研汇总表不少于5张，完成项目定价不少于5个，8月完成广州南湾项目模拟定价；
- 计划年底前完成84个项目调研。
### 讨论观点
- 有建议指出，新人要多思考工作目的和效果，不要停留在表面，要改变思维模式和工作习惯。
- 有建议指出，时间节点把控要精准，原则上按节点完成。
- 有建议指出，新人应多提问、会提问，理解数据背后的意义，梳理整体工作流程和脉络。
- 有建议指出，新人之间可每隔两三天碰一下，分享新学内容和问题，共同成长。
- 有建议指出，要有空杯心态，忘记原来做过招商。
- 领导点评强调，汇报要务实，不要务虚，说一是一，避免大而空的概念。
### 建议与方案
- 相关发言提出：流程分类处理，紧急重要流程优先审批；
- 内审表格每月更新，作为审批字典；
- 利用地图标记项目位置，通过卫星图了解周边；
- 多向项目同事、总监、经理、顾问沟通；
- 出差时实地调研在售项目；
- 仔细研读竞品表格，多源询问保证信息准确；
- 通过三表数据、视频、互联网了解城市；
- 通过项目定位报告了解项目本体；
- 完成佛山大沥项目定价，全流程经历一遍。
- 相关发言提出：提升数据敏感度，通过库存、任务完成情况判断项目问题；
- 多方面收集竞品信息；
- 了解项目人员组织、区划、科属情况；
- 理解菱形定价，了解房源信息、成交情况、政策；
- 提高数据收集能力。
- 相关发言提出：手写定价、课审、SOP等文件；
- 抓住广州南湾项目模拟定价，与建国哥背靠背对比复盘；
- 完成9个城市24个年终自有项目调研，访谈不少于50次，竞品调研不少于60次；
- 12月独立对接月度内审、输出定价报告并汇报。
