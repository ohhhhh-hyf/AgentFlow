# 项目概况
本次会议为援外玉米面加工厂项目中期验收会议，验收组于18号、19号提前介入前期摸排，20号召开首次会议，分内业检查和外业检查，按建筑工程、安装工程、机电设备专业方向开展。截止今天已完成卢萨卡点除弹料加工调试以外的所有验收工作，蒙泽点已完成全部验收工作，姆皮卡点现场验收工作尚未开展；因带料调试厂家工作人员在现场，顺带把整个流程试生产、外方人员操作、产品生产过程过了一道。内业方面，管理组技术组基本能按项目合同从开工到过程中组建项目执行团队并按流程程序开展工作，受疫情及项目特殊情况影响主要人员基本能保证在前方岗位，验收组查阅内业资料、现场抽检及问询交流，基本评价为满足项目有关标准和规范要求，但分类整理及少量质检和管理机构验收签字的规范性还需进一步规范和完善。外业方面，建筑部分原材料除国内采购出口建筑材料外，主要主材包括预制构件、年广场地砖从卢萨卡大规模成建制有质量管控体系的供货单位集中预制采购、从200多公里以外拉过去，整个项目内在品质通过查验资料、外在表观通过现场抽检和检测达到很好标准，由于资料完整整理结果没出来今天不下最后结论；安装部分以钢结构为主，钢结构所有材料从国内定制发货到现场，设备由技术组执行单位与国内中粮西安设计院及相关厂家签订专项供货合同、参照中国标准、按输出产品分三类标准专门定制编制并生产三套成套设备，厂家高峰期派十几名工作人员到现场指导安装，验收组对工艺设备逐台复核并进行投料试运行，工艺设备运行正常、工艺流程满足生产要求、产能符合设计指标，机电设备安装达到国家质量检验有关标准。财务验收专家查阅财务资料并与相关人员沟通，本项目财务从账户设置、资金往来、银行开户等过程完全符合财务处理有关规范和标准。会议提出人员履约和合同履约、内业资料、现场实体三方面整改要求，合作局领导建议资料方面尽快补充并与验收组做好沟通对接、争取不出现遗留未决事项，蒙泽厂区混凝土路面开裂问题由管理组和总包单位共同研究会同制定科学合理整改方案、争取在末次会之前最迟出报告之前完成整改并形成闭环，交给外方之前要继续做好成品保护；林总要求按商务部指示把验收任务圆满完成、注意姆皮卡雨季交通安全。王总补充不可预见费使用问题后续专门对接。

# 风险预警
本次会议识别的主要风险与瓶颈如下：混凝土路面开裂，可能移交外方投入使用后很快再出现开裂，对外影响不太好，等级中，责任人为管理组和总包单位，应对计划为分析原因、结合赞比亚当地气候特点制定切实可行整改方案、共同研究会同制定科学合理整改方案；混凝土路面开裂可能只是很小一部分，其他部位隐患表象还没反映出来，一旦移交外方再出现大面积开裂可能不太好，等级中，责任人为管理组和总包单位，应对计划为分析成因并采取解决措施避免以后再出现；监控管线接头处因设备启动震动有脱落，可能引起机械故障，等级中，责任人为施工组，应对计划为全面检查保证有效性和安全性；卢萨卡点加工提升桶往上位置，赞比亚雨量大风大，雨水可能倒灌，等级中，责任人为施工方，应对计划为检查并考虑增加覆盖面积或通过技术措施解决；卢萨卡点廊墙最端头横向只有三个竖条，巡检和维护人员安全保障不足，等级低，责任人为施工方，应对计划为中间再加两个竖条；工程实体完工挺长时间，带料调试一直没法进行导致验收推后，成品保护可能有疏忽，等级中，责任人为管理组和总包单位，应对计划为交给外方之前继续做好成品保护、有破损地方及时修补；姆皮卡路况不好，赞比亚雨季大雨季，验收组下去交通安全风险，等级高，责任人为验收组，应对计划为下去时注意交通安全；疫情风险，需注意新冠防控，等级中，责任人为验收组，应对计划为注意新冠防控。整体健康度：🟡低风险。

# 后续计划
下一周期核心交付物包括：完成姆皮卡点现场验收工作；管理组和技术组在会后形成验收报告之前完善个别同志进出场时间以及护照资料、把资料整理闭合；执行单位跟国内人力资源做对接、完善个别特种人员证件有效期延期或更新问题；执行单位按项目执行有关标准和规范及国家有关规范及时把资料汇总到卢萨卡、分类成册、按竣工文件归档要求及时组卷；施工组全面检查监控管线接头处脱落问题；施工方处理混凝土路面裂纹时重新清理、用防水材料全部封管；检查卢萨卡点加工提升桶往上位置雨水倒灌问题并考虑增加覆盖面积或通过技术措施解决；卢萨卡点廊墙最端头中间再加两个竖条；管理组和总包单位共同研究会同制定科学合理的混凝土路面开裂整改方案；交给外方之前继续做好成品保护、有破损地方及时修补。验收标准为满足项目有关标准和规范要求、竣工文件达到基本组卷和成册要求、整改在报告里形成闭环并经验收组复核。关键时间节点：争取在末次会之前、最迟出报告之前完成混凝土路面开裂整改，出报告之前完成整改后验收组还要复核；不可预见费使用的有关依据证据和数据在末次汇报时再进行沟通。依赖前提：混凝土路面开裂原因需现场各方分析明确；不可预见费使用依据证据和数据需进一步完善和收集整理清楚；人员统计数量尤其是技术组对包括厂家服务人员是否计入需完善；个别特种人员证件有效期延期或更新是否及时到位需与国内人力资源对接确认。
