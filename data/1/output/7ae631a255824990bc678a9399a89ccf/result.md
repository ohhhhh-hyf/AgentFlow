### 球谐函数  （核心 · ★★★★★）
- 考法预判：可能以计算题形式考查球谐函数的归一化条件，要求写出归一化系数并验证归一化。也可能在量子力学角动量问题中要求写出具体的球谐函数表达式。
- 必须先会：
  - 球谐函数Y_lm(θ,φ)满足归一化条件：∫Θ_lm(θ) sinθ dθ = 1（对θ积分，φ部分已归一化）。
  - 归一化系数N_lm由归一化条件确定，具体形式为N_lm = sqrt((2l+1)/(4π) * (l-m)!/(l+m)!)（连带勒让德归一化）。
  - 球谐函数Y_lm(θ,φ) = N_lm P_l^m(cosθ) e^{imφ}，其中P_l^m为连带勒让德函数。
  - l取非负整数（0,1,2,...），m取整数且满足 -l ≤ m ≤ l。
  - 球谐函数是角动量算符L²和L_z的共同本征函数，本征值分别为l(l+1)ℏ²和mℏ。
- 知识点讲解：球谐函数是量子力学中描述角向波函数的标准函数，由极角θ和方位角φ决定。其归一化条件要求对全空间积分等于1，具体为∫Θ_lm(θ) sinθ dθ = 1，其中sinθ来自球坐标体积元。归一化系数N_lm通过该条件确定，通常与连带勒让德函数的正交归一性相关。适用边界：l必须为非负整数，m为整数且绝对值不超过l，否则球谐函数无定义。考试中可能要求写出归一化系数或验证归一化，也可能在氢原子波函数中直接使用。
- 方法步骤：
  1. 默写球谐函数标准形式：Y_lm(θ,φ) = N_lm P_l^m(cosθ) e^{imφ}。
  2. 检查l和m的取值是否满足l≥0且|m|≤l。
  3. 写出归一化条件∫|Y_lm|² sinθ dθ dφ = 1，并分离θ和φ积分。
  4. 利用连带勒让德函数的正交性计算θ积分，确定归一化系数N_lm。
  5. 代入具体l,m值，写出归一化的球谐函数。
  6. 回代验证归一化条件是否满足。
- 易错提醒：
  - 忘记体积元中的sinθ因子，导致归一化积分错误。
  - 混淆m的正负号，e^{imφ}中m带符号，不能随意取绝对值。
  - l和m取值超出范围（如|m|>l）时球谐函数为零，不能直接套公式。

### 梯度算子  （核心 · ★★★★★）
- 考法预判：可能以计算题形式考查在正交曲线坐标系中写出线元并求梯度，或给定线元求拉梅系数。也可能在电磁学或量子力学中要求用梯度算子表示物理量。
- 必须先会：
  - 正交曲线坐标系中线元平方为(ds)² = h1² dq1² + h2² dq2² + h3² dq3²，其中h_i = √g_ii为拉梅系数。

  - 常见坐标系：直角坐标h_i=1；柱坐标h_ρ=1, h_φ=ρ, h_z=1；球坐标h_r=1, h_θ=r, h_φ=r sinθ。

- 方法步骤：
  1. 识别坐标系类型（直角、柱、球等），写出坐标变换关系。
  2. 计算拉梅系数h_i = |∂r/∂q_i|，或从线元表达式直接读出。
  3. 写出梯度公式：∇f = Σ (1/h_i)(∂f/∂q_i) e_i。
  4. 代入具体函数f，计算各分量偏导数。
  5. 整理成矢量形式，检查单位是否正确。

### 双原子分子转动能量  （核心 · ★★★★★）
- 考法预判：可能以计算题形式考查双原子分子转动惯量的计算，或要求写出转动动能表达式并求能级。也可能在统计物理中考查转动配分函数。
- 必须先会：
  - 双原子分子总转动惯量I_总 = m1 r1² + m2 r2² = μ r²，其中μ = m1 m2 / (m1+m2)为约化质量，r = r1 + r2。
  - 转动动能T = 1/2 m1 r1² (θ'² + sin²θ φ'²) + 1/2 m2 r2² (θ'² + sin²θ φ'²) = 1/2 I_总 (θ'² + sin²θ φ'²)。
  - 量子化后转动能级E_J = ℏ² J(J+1) / (2I)，J=0,1,2,...。
  - 转动惯量I = μ r²，其中r为两原子核间距。
- 知识点讲解：双原子分子可视为刚性转子，总转动惯量等于两原子绕质心转动惯量之和，即I_总 = m1 r1² + m2 r2²，其中r1和r2是各原子到质心的距离，满足m1 r1 = m2 r2，因此可化为约化质量形式I = μ r²。转动动能表达式T = 1/2 I (θ'² + sin²θ φ'²)与单质点转子形式相同，只是用总转动惯量代替mr²。适用边界：刚性转子假设，即r固定。考试中可能要求计算转动惯量或能级。笔记缺项：应补充约化质量的推导以及转动能级在光谱中的应用。
- 方法步骤：
  1. 确定两原子质量m1, m2和核间距r。
  2. 计算约化质量μ = m1 m2 / (m1+m2)。
  3. 计算转动惯量I = μ r²。
  4. 写出转动动能T = 1/2 I (θ'² + sin²θ φ'²)。

- 易错提醒：
  - 忘记约化质量公式，直接用m1+m2计算。
  - 混淆r1和r2与核间距r的关系，r1+r2=r。
  - 在量子化能级中忘记J从0开始。

### 量子态中的 μ 空间  （重点 · ★★★★☆）

- 必须先会：

### Aψ_a=aψ_a  （重点 · ★★★★☆）
- 考法预判：可能以概念题或判断题形式考查共同本征函数的存在条件，例如给出两个算符 A 和 B，判断它们是否有共同本征函数。也可能要求说明当 [A,B]≠0 时，A 的本征函数是否一定是 B 的本征函数。
- 必须先会：
  - 若两个算符 A 和 B 有共同本征函数 ψ，则 Aψ_a=aψ_a 且 Bψ_b=bψ_b 同时成立。
  - 共同本征函数存在的条件是 [A,B]=0，即 A 和 B 对易。
  - 若 [A,B]≠0，则 A 的本征函数 ψ_a 一般不是 B 的本征函数。
  - 共同本征函数要求 ψ 同时满足两个本征方程，且对应的本征值分别为 a 和 b。
- 知识点讲解：在量子力学中，若两个算符 A 和 B 存在共同本征函数 ψ，则 ψ 必须同时满足 Aψ_a=aψ_a 和 Bψ_b=bψ_b。共同本征函数存在的充要条件是 [A,B]=0，即两个算符对易。如果 [A,B]≠0，则一般不存在共同本征函数，此时 A 的本征函数 ψ_a 通常不是 B 的本征函数。
- 方法步骤：
  1. 判断题目是否涉及两个算符的共同本征函数。
  2. 计算对易子 [A,B]。
  3. 若 [A,B]=0，则存在共同本征函数，可尝试构造同时满足两个本征方程的函数。
  4. 若 [A,B]≠0，则不存在共同本征函数，说明 A 的本征函数不是 B 的本征函数。
  5. 验证结果：将候选函数代入两个本征方程，确认是否同时成立。
- 易错提醒：
  - 误认为只要 A 和 B 各自有本征函数就一定有共同本征函数，忽略对易条件。
  - 当 [A,B]≠0 时，仍试图寻找共同本征函数，导致错误。
