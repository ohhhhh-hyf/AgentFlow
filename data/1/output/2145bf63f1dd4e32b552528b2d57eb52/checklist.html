核心★★★★★ Definition 1 (电磁场中带电粒子的哈密顿量)

考法预判. 可能以选择题或填空题考查正则动量与机械动量的区别，以及哈密顿量的具体形式。也可能要求写出电磁场中带电粒子的哈密顿量并说明各项物理意义。 [1]

必须先会.

  • 洛伦兹力：F = qE + qv × B
  • 矢势 A 与标势 φ 描述电磁场，E = -∇φ - ∂A/∂t，B = ∇ × A
  • 正则动量 P = mv + qA，区别于机械动量 mv
  • 哈密顿量 H = (P - qA)²/(2m) + qφ
  • 哈密顿量中动能项用正则动量表示，势能项为 qφ

知识点讲解. 电磁场中带电粒子的哈密顿量是量子力学处理带电粒子在电磁场中运动的基础。其标准形式为 H = (P - qA)²/(2m) + qφ，其中 P 是正则动量，A 是矢势，φ 是标势。正则动量 P = mv + qA，与机械动量 mv 不同，它包含了电磁场的贡献。适用边界：非相对论情形，且电磁场为经典场。考试中常要求写出哈密顿量，并区分正则动量与机械动量。注意矢势 A 的规范变换不影响物理结果，但哈密顿量形式会变。笔记缺项：可能缺少对规范不变性的讨论，以及如何从拉格朗日量导出哈密顿量。 [1]

方法步骤. [1]

  1. 默写哈密顿量标准形式 H = (P - qA)²/(2m) + qφ
  2. 检查适用条件：非相对论、经典电磁场
  3. 代入具体电磁场（如均匀磁场）的矢势和标势
  4. 区分正则动量 P 与机械动量 mv，注意 P = mv + qA
  5. 回代检查：验证哈密顿量是否给出正确的运动方程

易错提醒. [1]

  • 混淆正则动量与机械动量，导致哈密顿量写错
  • 忘记矢势 A 的规范变换不影响物理，但哈密顿量形式会变
  • 在相对论情形下误用非相对论哈密顿量

核心★★★★★ Definition 2 (哈密顿量)

考法预判. 可能要求从拉格朗日量出发推导哈密顿量，或直接写出电磁场中带电粒子的哈密顿量。也可能考查正则动量的定义。 [1]

必须先会.

  • 拉格朗日量 L = T - V，其中 T 为动能，V 为势能
  • 正则动量 P = ∂L/∂q̇
  • 哈密顿量 H = Σ P q̇ - L
  • 电磁场中 H = (P - qA)²/(2m) + qφ
  • 正则动量 P = mv + qA

知识点讲解. 哈密顿量是经典力学和量子力学中的核心概念，通过勒让德变换从拉格朗日量得到。对于电磁场中的带电粒子，拉格朗日量包含矢势和标势，导致正则动量 P = mv + qA，与机械动量不同。哈密顿量 H = (P - qA)²/(2m) + qφ 是量子力学中薛定谔方程的基础。适用边界：非相对论、经典电磁场。考试中常要求推导或默写哈密顿量，并理解正则动量的物理意义。笔记缺项：可能缺少从拉格朗日量到哈密顿量的完整推导步骤，以及正则动量与机械动量的对比。 [1]

方法步骤. [1]

  1. 写出拉格朗日量 L = T - V，注意电磁场中 V 包含 qφ - qv·A
  2. 计算正则动量 P = ∂L/∂q̇，得到 P = mv + qA
  3. 通过勒让德变换 H = P·v - L 推导哈密顿量
  4. 化简得到 H = (P - qA)²/(2m) + qφ
  5. 检查适用条件：非相对论、经典电磁场

易错提醒.

  • 拉格朗日量中势能项写错，漏掉 -qv·A
  • 正则动量计算错误，混淆偏导数
  • 勒让德变换时忘记减去 L

核心★★★★★ Definition 4 (经典力学中一个组态的微观数)

考法预判. 可能考查相格的概念、微观态数的计算，或要求说明 h^r 的意义。

必须先会.

  • 相格是相空间中最小体积单元，大小为 h^r，其中 r 为自由度
  • 微观态数等于相空间体积除以相格体积
  • δp_i δq_i = h_0，h_0 为普朗克常数
  • 经典力学中一个组态的微观数由相格决定
  • 相格大小 h^r 是量子化条件的体现

知识点讲解. 经典力学中，一个组态的微观数由相空间中的相格决定。相格是相空间中最小体积单元，大小为 h^r，其中 r 为自由度，h 为普朗克常数。微观态数等于相空间体积除以相格体积。适用边界：经典统计力学，但引入量子化条件。考试中常要求计算微观态数，或说明相格的意义。笔记缺项：可能缺少相格与量子态对应关系的详细讨论。经典力学中一个组态的微观数是目录里已有的知识点，类型是concept。先把必须会的条目钉死：相格、h^r、微观态数、最小格子、微观状态数、相格 h^r。 [1][2]

方法步骤.

  1. 确定系统的自由度 r
  2. 计算相格体积 h^r
  3. 计算相空间总体积
  4. 微观态数 = 相空间体积 / 相格体积
  5. 检查单位是否一致

易错提醒.

  • 忘记相格大小是 h^r 而不是 h
  • 自由度 r 计算错误
  • 混淆相空间体积与相格体积

  • 完备性条件：∑ |ψ_n><ψ_n| = 1（单位算符）。

  1. 确认哈密顿算符 H 的本征方程 H ψ_n = E_n ψ_n。

  3. 将任意波函数 ψ 展开为 ∑ c_n ψ_n。
  4. 利用正交归一性计算系数 c_n = ∫ ψ_n* ψ dτ。
  5. 验证展开式是否满足薛定谔方程。

易错提醒.

  • 混淆完备性与封闭性，两者本质相同但表述不同。

  • 定理成立条件：矢量场 a 在体积 V 内及其边界 S 上连续且具有一阶连续偏导数。
  • 物理意义：闭合曲面上的通量等于体积内散度的体积分，即源的总强度。

知识点讲解. 散度定理（高斯定理）建立了闭合曲面积分与体积分之间的联系：∮_S a·dS = ∫_V ∇·a dV。它表明矢量场穿过闭合曲面的通量等于该曲面所围体积内散度的积分。适用条件是矢量场在体积内连续可微，否则定理不成立。在物理中，常用于将通量计算转化为散度积分，或反之。考试中可能要求利用定理简化积分计算，或证明给定矢量场的通量等于某体积分。 [1]

  3. 应用定理：将曲面积分转化为体积分（或反之），写出 ∇·a 的表达式。
  4. 计算积分：对散度进行体积分，或对通量进行曲面积分。

  • 忽略外法向方向，导致符号错误。
  • 场在体积内有奇点时直接套用定理，未做处理。

  • 总转动惯量 I_总 = μ r²，其中 r 为两原子间距离。

重点★★★★☆ Theorem 24 (μ空间分割（宏观）)

考法预判. 可能考查 μ 空间的分割方法，以及代表点与运动状态的对应关系。注意宏观上 μ 空间被划分为小体元 Δμ_j。 [1][2]

必须先会.

  • μ 空间是描述单个粒子运动状态的相空间，坐标轴为广义坐标和广义动量。
  • 宏观上，μ 空间被划分为许多小体元 Δμ_j。
  • 每个小体元对应一组可能的运动状态。
  • 代表点表示粒子的具体运动状态，位于 μ 空间中的某一点。
  • 统计物理中，通过划分 μ 空间来计数微观状态数。

知识点讲解. μ 空间是单个粒子的相空间，由广义坐标和广义动量张成。在宏观统计中，将 μ 空间划分为许多小体元 Δμ_j，每个体元代表一组相近的运动状态。粒子的运动状态由代表点表示，位于 μ 空间中的某一点。通过统计各体元中的代表点数，可以计算微观状态数。考试中可能要求理解分割方法或计算体元大小。注意 μ 空间是 2f 维（f 为自由度）。 [1]

方法步骤. [1][3]

  1. 确定 μ 空间的维度：2f（f 为自由度）。
  2. 将 μ 空间划分为小体元 Δμ_j，体元大小可相等或不相等。
  3. 每个体元对应一组运动状态，代表点表示具体状态。
  4. 统计各体元中的代表点数，用于计算状态数。
  5. 检查体元划分是否覆盖整个空间。

易错提醒. [1]

  • 混淆 μ 空间与 Γ 空间（Γ 空间是 N 粒子相空间）。
  • 忘记 μ 空间维度是 2f。
  • 认为代表点只能位于体元中心，实际可在体元内任意位置。
