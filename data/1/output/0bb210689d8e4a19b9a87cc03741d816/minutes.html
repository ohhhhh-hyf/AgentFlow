全文摘要

本次例会由申家坤主持，参会人员包括武思华、范炳杰、盛晋珲、徐玥、姜彪、郭慧敏、李梦甜、李家豪、张宇翔、鄢书畅等团队成员，围绕ASR模型优化、数据标注、端到端demo搭建及资源规划等模块展开同步与讨论。待办问题已修复，包括端侧未显示和大模型返回多引号问题；网页demo已集成会议摘要接口，后续将集成非实时转写；平板端到端demo依赖多个团队提供链路包，已联系相关团队，预计明天先给一个包测试。ASR模型优化方面，郭慧敏加入噪声数据训练后，初步测试bad case改善，说话人指标提升约1个点，ASR指标仍在评测中；申家坤通过多组对比实验发现，基于之前模型继续训练会出现幻觉和领域词WER差，基于原始模型训练则相对均衡。数据标注方面，法本标注即将完成，文德240h数据本周可审查完，LP约230h本周可用；内部WeLink标注进度提升61h，但仍有400min未审查。资源规划方面，现网会议流量峰值约800个会议同时在线，与纪要数据6000-7000量级不符，需进一步核对；模型当前支持6路并发，10路并发需12卡，徐玥建议先借资源部署测试，效果认可后再申请。

引擎性能与断网保护

  1. 断网保护机制已实现（范炳杰）：当用户超过20秒未发送音频即判定为断网，释放通道资源。
    • 背景：断网时引擎需发送结束标识，通道会占着准备释放，超过六通道后新连接会被断开。
    • 已做功能性能压测及断网场景测试。

端到端Demo与链路打通

    • 推理性能尚未优化，主要瓶颈在almony模块加速，单请求音频处理需1点几秒，若提速一倍并发可提升至10路。

ASR模型优化与评测

  1. 噪声数据训练改善bad case（郭慧敏）：将带noise标签数据加入训练，初步测试范炳杰反馈的bad case基本无静音出字、噪声出字现象。
    • 键盘声导致出字幻觉、媒体音不关导致出字问题仍存在，远近如一功能尚未实测，仅测了之前bad case。
    • 说话人指标提升约1个点（与demo版本对比），ASR指标仍在评测中[待确认: 时限]。
  2. 多组对比实验结论（申家坤）：基于之前模型继续训练会出现幻觉和领域词WER差，基于原始模型训练相对均衡；单独使用ASR reward调优时领域词WER差约0%点几。
  3. 术语转写效果差问题（徐玥）：计划用术语挖掘工具爬取特定领域数据，先搞AI、华为、政府、金融、法律、数学等几个领域，产出后供大家验证。
    • 现有测试集领域关键词涵盖车、金融、美妆等，后补录政府相关、华为、AI专业术语三个领域。

结论与决定

  1. 待办拨测报错问题修复：确认已修复，根因为待办返回空时校验 result code 取不到值导致报错（武思华）。端侧未显示问题待对方确认版本修复时间，武思华负责跟进；回流测试由文涛负责，需先让华山侧添加数据表以便查询，武思华与丁俊已确认文件上传下载结果无误。
    • 依据：待办返回空时，任务 result 为 list，无 result code 可取，校验时取不到值即报错。
    • 要求：武思华跟进华山侧加数据表，并确认端侧版本修复时间。
  2. 网页 demo 集成会议摘要与非实时转写功能：选定先以业飞提供的会议摘要接口（仅 get 一个）打通一条路，后续再按类似方式补齐其他接口（范炳杰、申家坤）。网页 demo 已加页面，录完后可点击生成会议摘要，后续将接入书畅侧非实时转写结果，便于调试体验与演示。
    • 依据：业飞已提供生产专用接口，本地已验证 python 接口可调通。
    • 要求：先通一条链路，再观察中间环节确定 demo 接入方式。
  3. 模型并发与资源规划：原则同意先通过其他项目借资源部署测试版本，待效果获产品认可后再正式申请资源（徐玥、会议共识）。当前模型支持 6 路并发，10 路并发需 12 卡（约 1:1 卡并发比，含部署与 FA 各 1 卡）；推理加速主要瓶颈在 almony 模块，单请求约 1.2 秒，若提速一倍并发可提升至 10 路。
    • 依据：现网会议流量峰值约 800 个会议同时在线，但纪要侧数据为 6000–7000，量级不符，需进一步核对口径后再定资源规模。
    • 要求：范炳杰找数据提供方拆分设备与报表口径，确认现网流量真实数值。
  4. 麦克风与内录双信号异常修复：明确本周更新版本修复，当前两路同时打开会出现信号异常，只能开单路麦克风（范炳杰、盛晋珲）。
    • 依据：现网电脑版本双录信号问题尚未接入，两路同开会异常。
    • 要求：本周内更新版本刷掉该问题。
  5. ASR 模型噪声数据训练方案：采纳将带 noise 标签数据重新加入训练，初步测试此前 bad case 基本消除，说话人指标提升约 1 个点，ASR 指标仍在评测中（郭慧敏、会议共识）。远近如一功能对出字干扰问题暂不纠结，若后续干扰大可在笔记等场景加开关按钮控制。
    • 依据：早期模型曾加入 noise 标签数据，后调 ASR 效果时未再纳入；本次训练重新加入后 bad case 归类测试基本无此现象。
    • 要求：郭慧敏完成 ASR 指标评测并输出结果。
