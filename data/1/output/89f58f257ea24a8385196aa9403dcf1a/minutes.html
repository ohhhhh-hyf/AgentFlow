全文摘要

小艺慧记项目进展会由申家坤牵头过 Java 侧问题，武思华、方思邈、范炳杰、李梦甜、盛晋珲、徐玥、邬昱圣、张宇翔、郭慧敏、姜彪、李家豪、郭镨岳、鄢书畅等参与，覆盖 Java 侧版本节奏与需求范围、端侧锻炼与后台保存、tob 数统计与重复标点、回流权限与流失格式对齐、微服务测试与打点、长文本性能与竞品对比、标题与字幕摘要及 agent 需求、接口 demo 与微服务统一接口改造、录音机控件与 910c 机器验证、问题单与中测版本、引擎并发与流量统计、外部 ASR 转写评估、模型量化与并发探索、端到端 demo 与控件链路、930 节点与引擎优化目标、强基性 4.0 接口横向对比、多模态 SDK 与云服务分发、转测范围与指标定义、ASR 模型效果与 GRPO 改动、数据标注进度、实时与非实时 ASR 方案、专业词汇与关键词提取流程、小模型保底方案与人力安排等板块。关键结论：本周转政策、下周转线、再下一周商品；930 前引擎至少做到单卡四路、效果至少持平 4.0；长文本场景拿竞品去测并再问推理优化方式；微服务统一接口改成根据此部署的 bid 地调，先调千问码调通流程；910c 机器这周下周初验证是模型问题还是机器问题；问题单找武思华核一下、中测时带上中测版本。关键数字锚点：长文本实测 60000 多字还行、8~9 万字不行，邮里面手头跟最大的都到 40 多秒；长基线 4.0 优化一个半月达到单卡 10 并发；慧敏和家坤九月份每人只能算 0.2 甚至 0.3 的人力。
