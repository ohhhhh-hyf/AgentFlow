### 第一个重要极限  （核心 · ★★★★★）
- 考法预判：必考大题，每届必出。常考变形如 sin 3x / x 或 sin 5x / sin 3x，需凑形；第二个重要极限常考 (1+2/x)^{3x} 型，凑"一加无穷小、指数取倒数"结构。注意替换只能在乘除中使用，加减法不能乱换，如 tan x - sin x 比 x^3 必须先提公因子。
- 必须先会：
  - 第一个重要极限：lim_{x→0} sin x / x = 1。
  - 第二个重要极限：lim_{n→∞} (1 + 1/n)^n = e，或 lim_{x→∞} (1 + 1/x)^x = e。
  - 凑形方法：对 sin(ax)/x，乘除凑成 a * sin(ax)/(ax)，极限为 a。
  - 对 (1 + a/x)^{bx} 型，凑成 [(1 + a/x)^{x/a}]^{ab}，极限为 e^{ab}。
  - 等价替换只能在乘除中使用，加减法中不能直接替换。
- 知识点讲解：两个重要极限是极限计算的基础工具。第一个重要极限 lim_{x→0} sin x / x = 1 本质是 0/0 型，通过凑形将 sin(ax)/x 化为 a * sin(ax)/(ax)，从而利用极限为 1。第二个重要极限 lim_{n→∞} (1+1/n)^n = e 是 1^∞ 型，需凑成"一加无穷小、指数取倒数"的结构，例如 (1+2/x)^{3x} 可化为 [(1+2/x)^{x/2}]^6，极限为 e^6。老师强调替换只能在乘除中使用，加减法不能乱换，典型反例是 tan x - sin x 比 x^3，直接替换会错，必须先提公因子 tan x(1 - cos x)，再分别替换。本次考试必考，需熟练掌握凑形和替换规则。
- 方法步骤：
  1. 识别题型：极限式中含 sin 或 (1+1/n)^n 结构，判断为重要极限。
  2. 对 sin 型：将分子分母凑成 sin(ax)/(ax) 形式，提取系数。
  3. 对 (1+1/n)^n 型：凑成 (1 + a/x)^{bx}，令 t = x/a，化为 [(1+1/t)^t]^{ab}。
  4. 计算极限：利用重要极限结果，得出 e 的幂次或系数。
  5. 检查：确认替换只在乘除中进行，加减法未直接替换。
- 易错提醒：
  - 加减法中不能直接使用等价替换，如 tan x - sin x 不能分别替换为 x - x = 0。
  - 凑形时注意系数，如 sin 3x / x 的极限是 3，不是 1。
  - 第二个重要极限的指数要取倒数，如 (1+2/x)^{3x} 的指数是 3x，需凑成 x/2 的倒数。
- 溯源
  - 老师原话：第一个重要极限就是那个 sin x 比 x，当 x 趋近于零的时候极限等于一。
  - 老师原话：考的时候一般不会直接给你 sin x 比 x，而是给你变形，比如 sin 3x 比 x，或者 sin 5x 比 sin 3x 这种，大家要会凑形。
  - 知识库：limit_doc_03_两个重要极限与等价替换.docx — lim(x→0) sin x/x = 1,几何证明思路,变形全集:sin kx/kx、tan x/x 等。
  - 知识库：limit_doc_03_两个重要极限与等价替换.docx — lim(1+1/x)^x=e,凑形三步法,复利背景。
  - 笔记：第一个重要极限 lim(x→0) sin x / x = 1 几何证明:扇形面积夹逼 x 必须用弧度

### 等价无穷小的来源  （核心 · ★★★★★）
- 考法预判：必考大题，常与极限计算结合。需背熟九个常用等价无穷小，并掌握替换规则：只能在乘除中使用，加减法不能乱换。典型陷阱题如 tan x - sin x 比 x^3，需先提公因子。
- 必须先会：
  - 常用等价无穷小（x→0）：sin x ~ x，tan x ~ x，1 - cos x ~ x^2/2，ln(1+x) ~ x，e^x - 1 ~ x。
  - 等价替换只能在乘除中使用，加减法中不能直接替换。
  - 替换的严谨依据是泰勒展开，等价无穷小是泰勒一阶近似。
  - 陷阱题：tan x - sin x 不能直接替换为 x - x = 0，需先提公因子 tan x(1 - cos x)。
- 知识点讲解：等价无穷小替换是求极限的常用方法，其来源是泰勒展开的一阶近似。当 x→0 时，sin x、tan x、ln(1+x)、e^x - 1 等都与 x 等价，1 - cos x 与 x^2/2 等价。替换规则是只能在乘除中使用，加减法中不能乱换，因为加减法中的替换可能忽略高阶项导致错误。老师强调的陷阱题 tan x - sin x 比 x^3，直接替换会得到 0，但正确做法是先提公因子 tan x(1 - cos x)，再替换为 x * (x^2/2) = x^3/2，极限为 1/2。本次考试必考，需背熟常用等价无穷小并掌握替换规则。笔记缺项：可补充更多等价无穷小的推导和组合使用。
- 方法步骤：
  1. 识别题型：极限式中含 sin、tan、ln、e^x 等，判断为等价无穷小替换。
  2. 检查替换位置：确认替换只在乘除中进行，加减法需先变形。
  3. 若加减法中有可提公因子，先提取公因子，再替换。
  4. 替换后化简，计算极限。
  5. 检查结果是否合理，避免出现 0/0 未处理的情况。
- 易错提醒：
  - 加减法中直接替换，如 tan x - sin x 替换为 x - x = 0。
  - 忽略高阶项，如 1 - cos x 替换为 x^2/2 而非 x。
  - 替换后未化简，导致极限计算错误。
- 溯源
  - 老师原话：第二个必考的是等价无穷小替换求极限。
  - 知识库：limit_ppt_03_无穷小与无穷大.pptx — 无穷小 以零为极限的函数 零是唯一可作无穷小的常数 有限个无穷小之和仍无穷小
  - 知识库：limit_ppt_07_等价无穷小.pptx — 常用等价无穷小 sin x ~ x;tan x ~ x 1−cos x ~ x2/2 ln(1+x) ~ x;e^x−1 ~ x (1+x)^a−1 ~ ax
  - 笔记：如果函数 f(x) 在自变量的某一变化过程中以零为极限,就称 f(x) 是该过程中的无穷小。例如 x→0 时 x、sin x、1 − cos x 都是无穷小;x→∞ 时 1/x …

### 间断点分类  （核心 · ★★★★★）
- 考法预判：必考大题，几乎年年有。常给分段函数，判断分段点处是第几类间断点，可去还是跳跃。判断流程：先看左右极限，都存在是第一类，相等是可去、不相等是跳跃；有一个不存在是第二类。
- 必须先会：
  - 第一类间断点：左右极限都存在。若相等则为可去间断点，若不相等则为跳跃间断点。
  - 第二类间断点：左右极限至少有一个不存在。
  - 判断流程：先求左右极限，再比较。
  - 可去间断点可通过补充定义使函数连续。
- 知识点讲解：间断点分类是函数连续性的重要应用。第一类间断点指左右极限都存在，其中相等时为可去间断点（可通过补充定义使函数连续），不相等时为跳跃间断点。第二类间断点指左右极限至少有一个不存在，如无穷间断点、振荡间断点。判断流程：先求左右极限，都存在则为第一类，再比较是否相等；若有一个不存在则为第二类。老师强调分段函数判断间断点几乎年年考，需熟练掌握。笔记缺项：可补充典型例子，如 y = sin(1/x) 在 x=0 处为第二类振荡间断点。
- 方法步骤：
  1. 确定间断点：找函数无定义或分段点。
  2. 求左极限和右极限。
  3. 若左右极限都存在：比较是否相等，相等为可去，不相等为跳跃。
  4. 若左右极限至少一个不存在：为第二类间断点。
  5. 下结论并说明类型。
- 易错提醒：
  - 忘记求左右极限，直接判断。
  - 将可去间断点误判为跳跃，或反之。
  - 忽略分段点处的定义。
- 溯源
  - 老师原话：第四个必考的是间断点的分类。
  - 知识库：limit_doc_04_连续性与间断点专题.docx — 第一类(可去/跳跃)与第二类(无穷/振荡)的判断流程与典型例子。
  - 知识库：limit_ppt_09_间断点分类.pptx — 第二类间断点 左右极限至少一个不存在 无穷间断:1/x 在 0 振荡间断:sin(1/x)

- 必须先会：
  - 连续三条件：函数在 x0 有定义、极限存在、极限值等于函数值。
  - 左连续：lim_{x→x0^-} f(x) = f(x0)；右连续：lim_{x→x0^+} f(x) = f(x0)。
  - 初等函数在其定义域内连续。
  - 连续函数的和、差、积、商（分母不为零）仍连续。

### 闭区间上连续函数的三大定理  （重点 · ★★★★☆）
- 考法预判：重点内容，考到概率大。零点定理是证明题必考类型，常考证明方程在区间内有根。需掌握构造函数、找端点异号、下结论的流程，证明唯一需加单调性。
- 必须先会：
  - 零点定理：若 f(x) 在 [a,b] 上连续，且 f(a) * f(b) < 0，则存在 c ∈ (a,b) 使 f(c) = 0。
  - 介值定理：连续函数在闭区间上可取到介于端点值之间的任何值。
  - 最值定理：连续函数在闭区间上有最大值和最小值。
  - 证明方程有根：构造函数，找端点异号，用零点定理。
- 知识点讲解：闭区间上连续函数的三大定理包括最值定理、介值定理和零点定理。零点定理是证明方程有根的重要工具，其条件是函数在闭区间上连续且端点函数值异号。证明流程：先构造函数，再找两个端点函数值异号，直接下结论。若要证明唯一，需再加单调性。老师强调零点定理证明题每年必考，需掌握书写规范。笔记缺项：可补充介值定理的应用。闭区间上连续函数的三大定理是目录里已有的知识点，类型是theorem。先把必须会的条目钉死：最值定理、介值定理、零点定理、闭区间性质。老师这次点到的是：零点定理，复习时按这些条目展开，不要另开新点。做题时先判断本题是不是在用它，再按方法步骤走，最后回代检查适用条件。
- 方法步骤：
  1. 构造函数：将方程 f(x)=0 转化为函数 f(x)。
  2. 找区间 [a,b]，计算 f(a) 和 f(b)。
  3. 验证 f(a) * f(b) < 0。
  4. 由零点定理，存在 c ∈ (a,b) 使 f(c)=0。
  5. 若需证明唯一，再证明函数单调。
- 易错提醒：
  - 忘记验证函数在闭区间上连续。
  - 端点函数值异号条件不满足。
  - 证明唯一时未说明单调性。
- 溯源
  - 老师原话：重点二是连续性的概念和闭区间上连续函数的性质，特别是零点定理。
  - 老师原话：证明方程在某个区间内有根，就用零点定理，先构造函数，再找两个端点函数值异号，直接下结论。
  - 老师原话：证明题就是零点定理和单调有界。
  - 知识库：limit_ppt_08_函数连续性.pptx — 连续函数运算 四则运算保持连续 复合保持连续 反函数保持连续
  - 笔记：零点定理应用 证明方程有根 构造连续函数 找端点异号
  - 笔记：闭区间连续函数性质 最值定理:必有最大最小值 有界性:必有界 介值定理:取中间值 零点定理:异号必有根

### 无穷大的定义  （重点 · ★★★★☆）
- 考法预判：重点内容，考到概率大。常考概念辨析，特别是"无界"和"无穷大"的区别，选择题出现过 x sin x 的反例。需掌握无穷大的定义及与无界的区别。
- 必须先会：
  - 无穷大：当 x→x0 时，|f(x)| 无限增大，即对任意 M>0，存在 δ，使 0<|x-x0|<δ 时 |f(x)|>M。
  - 无界：函数在定义域上无上界或无下界，但不一定是无穷大。
  - 反例：f(x) = x sin x 在 x→∞ 时无界但不是无穷大，因为存在子列使函数值为 0。
  - 无穷大与无界的区别：无穷大要求所有点都趋于无穷，无界只要求存在点趋于无穷。
- 知识点讲解：无穷大是函数在某个过程中绝对值无限增大的概念，而无界是函数在定义域上无上界或无下界。两者区别在于：无穷大要求当 x 趋近于某点时，函数值对所有点都趋于无穷；而无界只要求存在点使函数值趋于无穷。典型反例是 f(x) = x sin x，当 x→∞ 时，取 x = nπ 时函数值为 0，取 x = π/2 + 2nπ 时函数值趋于无穷，因此无界但不是无穷大。老师强调这个反例在选择题中出现过，需牢记。笔记缺项：可补充无穷大的比较。
- 方法步骤：
  1. 用自己的话复述无穷大的定义的定义或结论，并写出一条限制条件
  2. 对照老师点到的判断流程逐步核验：无穷大
  3. 用一个正例确认能用，再用一个反例钉住边界
  4. 若要写证明，按「构造 → 验证条件 → 下结论」的顺序落笔
- 易错提醒：
  - 将无界误认为无穷大。
  - 忽略无穷大要求所有点都趋于无穷。
- 溯源
  - 老师原话：重点三是无穷小与无穷大的概念辨析，特别是"无界"和"无穷大"的区别，那个 x 乘 sin x 的反例要记住，这个在选择题里出现过。
  - 知识库：limit_ppt_03_无穷小与无穷大.pptx — 无穷大 |f(x)| 无限增大 记 lim f = ∞ 正无穷大与负无穷大
