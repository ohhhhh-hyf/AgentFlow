核心★★★★★ Definition 1 (电磁场中带电粒子的哈密顿量)

考法预判. 可能以计算题形式考查电磁场中带电粒子的哈密顿量，要求写出矢势和标势下的哈密顿量表达式，并区分正则动量与机械动量。也可能结合具体规范（如库仑规范）进行变形。 [1]

必须先会.

  • 电磁场中带电粒子的哈密顿量：H = (1/2m)(p - qA)^2 + qφ，其中 p 为正则动量，A 为矢势，φ 为标势。
  • 正则动量 p = m v + qA，机械动量 m v = p - qA。
  • 洛伦兹力 F = q(E + v × B)，其中 E = -∇φ - ∂A/∂t，B = ∇ × A。
  • 哈密顿量形式：H = (p - qA)^2/(2m) + qφ，注意 p 是正则动量而非机械动量。

知识点讲解. 电磁场中带电粒子的哈密顿量是量子力学与经典力学衔接的重要公式。其标准形式为 H = (p - qA)^2/(2m) + qφ，其中 p 是正则动量，与机械动量 m v 相差 qA。适用边界：非相对论情形，且电磁场由矢势 A 和标势 φ 描述。考试中常要求写出哈密顿量，并注意正则动量与机械动量的区别，尤其在规范变换下哈密顿量形式会变化。笔记缺项：应补充规范不变性的讨论，以及不同规范（如库仑规范、洛伦兹规范）下的具体形式。 [1]

方法步骤. [1]

  1. 识别题目是否涉及电磁场中的带电粒子，确认需要写出哈密顿量。
  2. 写出正则动量 p = m v + qA，并确认机械动量 m v = p - qA。
  3. 代入哈密顿量公式 H = (p - qA)^2/(2m) + qφ。
  4. 检查是否满足非相对论条件，并确认矢势和标势的定义。
  5. 若涉及规范变换，验证哈密顿量形式是否相应变化。

易错提醒. [1]

  • 混淆正则动量与机械动量，导致哈密顿量写错。
  • 忽略标势 φ 的贡献，只写动能项。
  • 在非相对论条件下误用相对论哈密顿量。

核心★★★★★ Definition 2 (哈密顿量)

考法预判. 可能以推导题或计算题形式考查哈密顿量的构造，要求从拉格朗日量出发求正则动量并写出哈密顿量。也可能结合具体系统（如谐振子）进行变形。 [1]

必须先会.

  • 哈密顿量 H = Σ p_i q̇_i - L，其中 p_i = ∂L/∂q̇_i 为正则动量。
  • 正则动量 p_i = ∂L/∂q̇_i。
  • 哈密顿量表达式：H = T + V（动能加势能），但需用正则动量表示。
  • 拉格朗日量 L = T - V。

知识点讲解. 哈密顿量是经典力学中描述系统总能量的函数，通常表示为 H = Σ p_i q̇_i - L。其构造步骤：先写出拉格朗日量 L = T - V，再求正则动量 p_i = ∂L/∂q̇_i，最后通过勒让德变换得到哈密顿量。适用边界：适用于完整约束、保守力系统。考试中常要求从拉格朗日量推导哈密顿量，或直接给出哈密顿量求运动方程。笔记缺项：应补充哈密顿量与拉格朗日量的关系，以及循环坐标的处理。哈密顿量是目录里已有的知识点，类型是formula。先把必须会的条目钉死：拉格朗日量、正则动量、哈密顿量表达式、动能与势能。 [1]

方法步骤. [1]

  1. 默写哈密顿量的标准形式和成立条件
  2. 检查变量是否满足公式前提
  3. 先凑成标准形再代入，不要直接套裸公式
  4. 代入后回代检查有没有改变原问题

易错提醒. [1]

  • 忘记用正则动量表示哈密顿量，直接写 T+V。
  • 混淆广义速度与正则动量。
  • 忽略约束条件，导致哈密顿量不完整。

核心★★★★★ Definition 3 (角向方程)

考法预判. 可能以计算题形式考查角向方程的解，要求写出球谐函数并判断本征值。也可能结合氢原子问题，要求写出角向方程并求解。 [1][2][3]

必须先会.

  • 角向方程：L² Y_lm = l(l+1)ħ² Y_lm，其中 L² 为轨道角动量平方算符。
  • 球谐函数 Y_lm(θ,φ) 是角向方程的解，满足正交归一化条件。
  • 球坐标表示：L² = -ħ² [1/sinθ ∂/∂θ (sinθ ∂/∂θ) + 1/sin²θ ∂²/∂φ²]。
  • 本征值问题：l = 0,1,2,...，m = -l,...,l。

知识点讲解. 角向方程是量子力学中描述粒子角动量本征态的方程，其解为球谐函数 Y_lm(θ,φ)。方程形式为 L² Y_lm = l(l+1)ħ² Y_lm，其中 L² 是轨道角动量平方算符，在球坐标下表示为 -ħ² [1/sinθ ∂/∂θ (sinθ ∂/∂θ) + 1/sin²θ ∂²/∂φ²]。适用边界：适用于中心势场问题，如氢原子。考试中常要求写出角向方程并求解本征值，或直接给出球谐函数。笔记缺项：应补充球谐函数的递推关系和正交归一化条件。 [1][2][3]

方法步骤. [1][2][3]

  1. 识别问题是否涉及角向方程，确认使用球坐标。
  2. 写出角向方程 L² Y_lm = l(l+1)ħ² Y_lm。
  3. 代入 L² 的球坐标表示。
  4. 求解本征值 l 和 m，并写出对应的球谐函数。
  5. 验证正交归一化条件。

易错提醒. [1][2][3]

  • 混淆角向方程与径向方程。
  • 忘记球谐函数的归一化条件。
  • 错误使用 L² 的表达式，忽略 θ 和 φ 的偏导项。

核心★★★★★ Definition 4 (经典力学中一个组态的微观数)

考法预判. 可能以概念题或计算题形式考查经典力学中一个组态的微观数，要求计算相格大小和微观态数。也可能结合统计物理基本假设进行变形。 [1][2]

必须先会.

  • 相格：在相空间中划分的最小体积单元，大小为 h^r，其中 r 为自由度。
  • 微观态数：一个组态对应的微观状态数等于相空间体积除以相格大小。

  • 将度规矩阵误写为常数矩阵。

重点★★★★☆ Theorem 19 (散度定理)

考法预判. 可能以计算题或证明题形式考查，要求利用散度定理将矢量场的面积分转化为体积分，或反之。注意定理的适用条件（矢量场连续可微、闭合曲面）以及方向约定（外法向）。 [1]

必须先会.

  • 散度定理（高斯定理）：∮_S F·dS = ∫_V (∇·F) dV，其中 S 是闭合曲面，V 是 S 包围的体积，dS 方向为外法向。
  • 通量：Φ = ∮_S F·dS，表示矢量场穿过闭合曲面的净流量。
  • 散度：∇·F = ∂Fx/∂x + ∂Fy/∂y + ∂Fz/∂z，表示场在某点的源强度。
  • 定理成立条件：矢量场 F 在体积 V 内及边界 S 上连续且具有一阶连续偏导数。
  • 物理意义：闭合曲面上的通量等于体积内散度的体积分，即源的总强度。

知识点讲解. 散度定理（高斯定理）建立了矢量场穿过闭合曲面的通量与该场在曲面所围体积内散度的体积分之间的联系，公式为 ∮_S F·dS = ∫_V (∇·F) dV。适用条件是矢量场在体积 V 内及边界 S 上连续且一阶偏导数连续。考试中常见题型包括：给定矢量场计算闭合曲面的通量（直接积分或转化为体积分）、利用定理简化计算、或证明某些恒等式。 [1]

方法步骤. [1]

  1. 判断题目是否涉及闭合曲面上的面积分或体积分中的散度，若是则考虑使用散度定理。
  2. 写出矢量场 F 的分量，计算散度 ∇·F。
  3. 确定体积 V 和边界曲面 S，注意 S 必须闭合且方向为外法向。
  4. 将面积分 ∮_S F·dS 转化为体积分 ∫_V (∇·F) dV，或反之。
  5. 计算体积分或面积分，注意积分区域的对称性可简化计算。
  6. 检查结果是否符合物理意义，如通量是否与源强度一致。

易错提醒.

  • 忘记曲面必须是闭合的，对开放曲面直接使用定理导致错误。
  • dS 方向取错（内法向）导致符号错误。
  • 矢量场在体积内存在奇点（如点电荷）时，定理不直接适用，需挖去奇点处理。

重点★★★★☆ Theorem 20 (旋度)

考法预判. 可能考查旋度的计算、斯托克斯定理的应用，或判断矢量场是否为无旋场。注意旋度的物理意义（环量密度）以及斯托克斯定理中曲面方向与环路方向的右手定则。

  • 斯托克斯定理中曲面方向与路径方向不满足右手定则，导致符号错误。
  • 对非闭合路径直接使用斯托克斯定理，需补线或调整。

  • 相空间轨迹的椭圆面积与能量成正比，是经典统计中相空间体积的基础。

知识点讲解. 线性谐振子是经典力学中重要的模型，受弹性力 F = -kx 作用，运动方程为 m d²x/dt² = -kx，解得 x(t) = A cos(ωt + φ)，其中 ω = √(k/m)。 [1][2]

  5. 计算椭圆面积 A = π * x_max * p_max = 2πE/ω。
  6. 检查单位与物理意义。

  • 混淆圆频率 ω 与频率 f，ω = 2πf。
  • 椭圆面积计算时半轴取错，导致面积公式错误。
  • 忘记相空间轨迹是椭圆，误认为圆。

方法步骤. [1][2][3]

  2. 写出转动能量公式 E = L²/(2I)。
  3. 确定转动惯量 I，对于双原子分子 I = μr²，其中 μ 为约化质量，r 为键长。
  4. 若给定角动量或角速度，计算能量。
  5. 分析角坐标 (θ, φ) 的变化范围。
  6. 检查是否满足刚性条件。

  • 将刚性转子误认为有振动自由度，导致能量表达式错误。
  • 转动惯量计算错误，忘记使用约化质量。
  • 混淆角动量 L 与角速度 ω 的关系。

重点★★★★☆ Theorem 23 (双原子分子转动的约化质量与能量)

考法预判. 可能考查双原子分子转动惯量的计算、约化质量的定义以及转动能量公式的应用。注意约化质量 μ = m1m2/(m1+m2)，转动惯量 I = μr²。 [1][2]

必须先会.

  • 约化质量 μ = m1m2/(m1+m2)，用于将两体问题化为单体问题。
  • 转动惯量 I = μr²，其中 r 为两原子间距离。
  • 转动能量 E = L²/(2I) = (1/2)Iω²。
  • 角动量 L = Iω。
  • 对于刚性转子，能量只与角动量有关，与角坐标无关。

知识点讲解. 双原子分子转动时，可等效为质量为约化质量 μ 的质点绕固定点转动，μ = m1m2/(m1+m2)。转动惯量 I = μr²，其中 r 为键长。转动能量 E = L²/(2I) = (1/2)Iω²。考试中可能要求计算约化质量、转动惯量或转动能量。注意约化质量小于任一原子质量，且当 m1 = m2 时 μ = m/2。 [1][2]

方法步骤. [1][2]

  1. 识别题目涉及双原子分子转动，写出约化质量公式 μ = m1m2/(m1+m2)。
  2. 计算约化质量 μ。
  3. 计算转动惯量 I = μr²，其中 r 为键长。
  4. 写出转动能量公式 E = L²/(2I) 或 E = (1/2)Iω²。
  5. 代入已知量计算能量或角动量。
  6. 检查单位与物理合理性。

易错提醒. [1][2]

  • 约化质量计算错误，忘记分母是质量和。
  • 转动惯量公式中 r 取错，应为两原子间距离。
  • 混淆角动量 L 与角速度 ω。

重点★★★★☆ Theorem 24 (μ空间分割（宏观）)

考法预判. 可能考查 μ 空间的概念、宏观体元划分以及代表点的意义。注意 μ 空间是单个粒子的相空间，宏观体元划分用于统计计数。 [2]

必须先会.

  • μ 空间是单个粒子的相空间，由位置坐标和动量坐标构成，维度为 2s（s 为自由度）。
  • 宏观体元划分：将 μ 空间划分为若干小体元 Δω，每个体元足够小，但包含大量微观状态。
  • 代表点：每个粒子的状态在 μ 空间中用一个点表示，称为代表点。
  • 宏观体元划分用于统计物理中计算微观状态数，体元大小影响状态数。
  • 在经典统计中，体元 Δω 的大小与普朗克常数 h 有关，通常取 Δω = h^s。

知识点讲解. μ 空间是描述单个粒子状态的相空间，由广义坐标和广义动量构成。对于 s 个自由度的粒子，μ 空间是 2s 维的。在宏观统计中，将 μ 空间划分为若干小体元 Δω，每个体元足够小，使得宏观物理量在其中近似不变，但又包含大量微观状态。每个粒子的状态用代表点表示，代表点在 μ 空间中的分布反映了系统的统计性质。 [1][2]

方法步骤. [2][3]

  1. 明确 μ 空间的定义：单个粒子的相空间，坐标轴为广义坐标和广义动量。
  2. 确定粒子的自由度 s，μ 空间维度为 2s。
  3. 将 μ 空间划分为小体元 Δω，体元大小通常取 h^s。
  4. 将每个粒子的状态用代表点表示，统计各体元内的代表点数。
  5. 利用体元内代表点数计算微观状态数或分布函数。
  6. 检查体元划分是否满足宏观小、微观大的条件。

易错提醒.

  • 混淆 μ 空间与 Γ 空间（多粒子相空间）。
  • 体元大小取错，未考虑普朗克常数。
  • 忘记代表点表示单个粒子状态，而非系统状态。
