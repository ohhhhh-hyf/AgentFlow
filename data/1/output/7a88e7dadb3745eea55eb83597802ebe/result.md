### 不确定度关系的严格证明  （核心 · ★★★★★）

- 必须先会：
  - 不确定度关系：ΔA·ΔB ≥ |⟨[A,B]⟩|/2。
  - 其中 ΔA 和 ΔB 为标准差，[A,B] 为对易子。

- 方法步骤：
  1. 定义标准差 ΔA = sqrt(⟨(A-⟨A⟩)²⟩)。
  2. 构造态 |f⟩ = (A-⟨A⟩)|ψ⟩，|g⟩ = (B-⟨B⟩)|ψ⟩。

### 厄米算符属于不同本征值的本征态必然正交  （核心 · ★★★★★）
- 考法预判：可能以证明题或简答题形式出现，要求证明厄米算符属于不同本征值的本征态正交。也可能结合具体算符（如动量、角动量）判断其本征态是否正交。
- 必须先会：
  - 厄米算符的定义：⟨ψ|Aφ⟩ = ⟨Aψ|φ⟩。
  - 设 A|ψ_m⟩ = a_m|ψ_m⟩，A|ψ_n⟩ = a_n|ψ_n⟩，且 a_m ≠ a_n。
  - 由 ⟨ψ_m|A|ψ_n⟩ = a_n⟨ψ_m|ψ_n⟩ = a_m⟨ψ_m|ψ_n⟩，得 (a_m - a_n)⟨ψ_m|ψ_n⟩ = 0。
  - 因为 a_m ≠ a_n，所以 ⟨ψ_m|ψ_n⟩ = 0，即正交。
  - 若本征值简并，简并子空间内的本征态不一定正交，但可通过正交化方法构造正交基。
- 知识点讲解：厄米算符对应可观测量，其本征态的正交性是量子力学的重要性质。证明思路：利用厄米性 ⟨ψ_m|A|ψ_n⟩ = ⟨Aψ_m|ψ_n⟩，代入本征方程，得到 (a_m - a_n)⟨ψ_m|ψ_n⟩ = 0。由于本征值不同，内积必为零。注意：若本征值相同（简并），则本征态不一定正交，但可以通过施密特正交化构造正交归一基。考试中可能要求写出完整证明，或判断给定算符本征态是否正交。笔记缺项：简并情形下的正交化处理。
- 方法步骤：
  1. 写出厄米算符的定义式 ⟨ψ|Aφ⟩ = ⟨Aψ|φ⟩。
  2. 设两个本征态 |ψ_m⟩、|ψ_n⟩ 对应本征值 a_m、a_n。
  3. 计算 ⟨ψ_m|A|ψ_n⟩，分别用 A 作用右矢和左矢得到两个表达式。
  4. 利用厄米性使两个表达式相等，得到 (a_m - a_n)⟨ψ_m|ψ_n⟩ = 0。
  5. 由 a_m ≠ a_n 推出 ⟨ψ_m|ψ_n⟩ = 0，即正交。

### 厄米算符本征值的实数性  （重点 · ★★★★☆）
- 考法预判：可能以证明题形式出现，要求证明厄米算符的本征值为实数。也可能结合具体算符判断本征值是否实数。
- 必须先会：

  - 设 A|ψ⟩ = λ|ψ⟩，则 ⟨ψ|A|ψ⟩ = λ⟨ψ|ψ⟩。
  - 由厄米性，⟨ψ|A|ψ⟩ = ⟨Aψ|ψ⟩ = λ*⟨ψ|ψ⟩。
  - 因此 λ = λ*，即 λ 为实数。
  - 本征值实数性保证可观测量取实数值。
- 知识点讲解：厄米算符对应可观测量，其本征值必须是实数。证明：设 A|ψ⟩ = λ|ψ⟩，则 ⟨ψ|A|ψ⟩ = λ⟨ψ|ψ⟩。利用厄米性，⟨ψ|A|ψ⟩ = ⟨Aψ|ψ⟩ = λ*⟨ψ|ψ⟩。由于 ⟨ψ|ψ⟩ > 0，所以 λ = λ*，即 λ 为实数。考试中可能要求写出证明过程，或判断算符是否为厄米算符。笔记缺项：厄米算符的判定方法。
- 方法步骤：
  1. 写出厄米算符定义 ⟨ψ|Aφ⟩ = ⟨Aψ|φ⟩。
  2. 设本征方程 A|ψ⟩ = λ|ψ⟩。
  3. 计算 ⟨ψ|A|ψ⟩，分别用两种方式表示。
  4. 利用厄米性使两式相等，得到 λ = λ*。
  5. 得出结论：本征值为实数。
- 易错提醒：
  - 忘记利用厄米性，直接认为 ⟨ψ|A|ψ⟩ 是实数。

- 考法预判：可能考查利用对易关系求平均值，要求计算l_x或l_y在|lm⟩态中的平均值，或证明某个平均值为零。
- 必须先会：
  - 对易关系：[l_x, l_y] = iħl_z，循环对称。
  - 在|lm⟩态中，l_z平均值为mħ。
  - l_x和l_y的平均值在|lm⟩态中为零：⟨l_x⟩=⟨l_y⟩=0。
  - 利用对易关系可推导平均值关系，如⟨l_x²⟩=⟨l_y²⟩=ħ²[l(l+1)-m²]/2。
  - 平均值公式：⟨A⟩=⟨ψ|A|ψ⟩。
- 知识点讲解：利用对易关系可以简化平均值计算。在|lm⟩态中，l_z有确定值mħ，但l_x和l_y没有确定值，其平均值为零。这是因为l_x和l_y不改变m，但|lm⟩是l_z的本征态，l_x和l_y的期望为零。考试中可能要求计算l_x或l_y的平均值，或利用对易关系推导关系式。注意对易关系的循环性。
- 方法步骤：
  1. 写出对易关系[l_x, l_y]=iħl_z。
  2. 利用升降算符l_±=l_x±il_y，将l_x和l_y表示为l_±的组合。
  3. 计算⟨lm|l_±|lm⟩，由于l_±改变m，结果为0。
  4. 因此⟨l_x⟩=⟨l_y⟩=0。
  5. 若求平方平均值，利用l_±作用结果。
- 易错提醒：
  - 忘记l_x和l_y的平均值为零，误以为有确定值。
  - 对易关系符号错误，导致推导错误。
  - 升降算符作用结果不熟悉，导致计算错误。
- 溯源
  - 笔记：**例1.** 求 $l_x$ 和 $l_y$ 在 $|lm\rangle$ 下的平均值。 已知 $l_z |lm\rangle = m\hbar |lm\rangle$,…
  - 笔记：由 $l^2 = l_x^2 + l_y^2 + l_z^2$,且 $l_x^2 = l^2 - l_z^2 - l_y^2$,…

### 共同本征函数  （重点 · ★★★★☆）
- 考法预判：可能考查共同本征函数的条件，要求判断两个算符是否具有共同本征函数，或说明对易条件。
- 必须先会：
  - 两个算符A和B具有共同本征函数集的充要条件是[A,B]=0。
  - 若[A,B]=0，则存在一组共同本征函数，使得A和B同时对角化。
  - 若[A,B]≠0，则不存在共同本征函数集，但可能有部分共同本征态。
  - 例如，l²和l_z对易，有共同本征函数Y_l^m。
  - l_x和l_y不对易，没有共同本征函数集。
- 知识点讲解：共同本征函数的存在性与对易关系密切相关。若两个算符对易，则它们有共同本征函数集，可以同时确定两个物理量。若不对易，则不能同时确定，满足不确定关系。考试中可能要求判断两个算符是否对易，或说明共同本征函数的存在条件。注意对易是充分必要条件。共同本征函数是目录里已有的知识点，类型是concept。先把必须会的条目钉死：对易条件、共同本征态、非对易情形。
- 方法步骤：
  1. 计算两个算符的对易子[A,B]。
  2. 若[A,B]=0，则存在共同本征函数集。
  3. 若[A,B]≠0，则不存在共同本征函数集。
  4. 若存在，写出共同本征函数并验证。
  5. 若不存在，说明不确定关系。
- 易错提醒：
  - 混淆对易与不对易的条件，导致判断错误。
  - 忘记对易是共同本征函数存在的充要条件。
  - 对具体算符，如l_x和l_y，误以为有共同本征函数。
- 溯源

### 厄米算符的证明  （重点 · ★★★★☆）
- 考法预判：可能以证明题形式考查厄米算符的定义式⟨φ|A|φ⟩=⟨φ|A†|φ⟩，要求从内积的实性出发证明。也可能给出具体算符（如动量算符），要求判断其是否为厄米算符，并写出转置、共轭算符的定义。
- 必须先会：
  - 转置算符定义：⟨φ|A^T|ψ⟩ = ⟨ψ*|A|φ*⟩（或 ⟨φ|A^T|ψ⟩ = ⟨ψ|A|φ⟩*，具体形式需按教材约定）。
  - 共轭算符定义：⟨φ|A*|ψ⟩ = ⟨φ*|A|ψ*⟩。
  - 厄米算符定义：A† = A，即 ⟨φ|A|ψ⟩ = ⟨Aφ|ψ⟩，等价于 ⟨φ|A|φ⟩ 为实数。
  - 厄米算符的实性证明：⟨φ|A|φ⟩ = ⟨φ|A†|φ⟩ = ⟨φ|A|φ⟩*，故 ⟨φ|A|φ⟩ 等于其共轭，必为实数。
  - 厄米算符的本征值为实数，属于不同本征值的本征矢正交。
- 知识点讲解：厄米算符是量子力学中表示力学量的算符，其定义是 A† = A，即算符的厄米共轭等于自身。厄米共轭算符 A† 由转置和复共轭复合而成：先取转置，再取复共轭。转置算符的定义涉及内积的交换，共轭算符则对波函数取复共轭。
- 方法步骤：
  1. 判断题型：若要求证明厄米性，则从定义 A† = A 出发；若要求证明实性，则利用 ⟨φ|A|φ⟩ = ⟨φ|A†|φ⟩。
  2. 写出厄米共轭的定义：A† = (A^T)*，并明确转置和共轭算符的作用规则。
  3. 对给定算符，计算 ⟨φ|A|ψ⟩ 与 ⟨Aφ|ψ⟩，比较两者是否相等。
  4. 若相等，则 A 为厄米算符；若不相等，则不是。
  5. 证明实性时，令 |ψ⟩ = |φ⟩，利用 ⟨φ|A|φ⟩ = ⟨φ|A†|φ⟩ = ⟨φ|A|φ⟩*，得出 ⟨φ|A|φ⟩ 为实数。
  6. 回代检查：确认每一步内积的次序和复共轭处理正确。
- 易错提醒：
  - 混淆转置算符和共轭算符的定义，导致厄米共轭计算错误。
  - 忘记厄米算符定义中内积的次序：⟨φ|A|ψ⟩ = ⟨Aφ|ψ⟩，而不是 ⟨φ|A|ψ⟩ = ⟨ψ|A|φ⟩。
  - 在证明实性时，错误地认为 ⟨φ|A|φ⟩ 自动为实数，而忽略了需要利用 A† = A 的条件。
- 溯源

### 表象间的转化  （重点 · ★★★★☆）
- 考法预判：可能以计算题形式考查：给定两个表象的基矢变换关系，求态矢量在另一表象中的系数列向量。也可能要求写出变换矩阵的具体形式，并利用变换矩阵进行表象间的转换。
- 必须先会：
  - 基矢变换：设 {|n⟩} 和 {|α⟩} 为两组基，变换关系为 |α⟩ = Σ_n U_nα |n⟩，其中 U_nα = ⟨n|α⟩。
  - 系数列向量变换：若态 |ψ⟩ 在 {|n⟩} 表象中系数为 c_n = ⟨n|ψ⟩，在 {|α⟩} 表象中系数为 d_α = ⟨α|ψ⟩，则 d_α = Σ_n U†_αn c_n，即 d = U† c。
  - 变换矩阵 U 是幺正矩阵：U†U = I，U† = U^{-1}。
  - 变换矩阵的矩阵元：U_αn = ⟨α|n⟩，U†_nα = ⟨n|α⟩。
  - 表象变换保持内积和概率守恒。
- 知识点讲解：表象间的转化是量子力学中在不同基底下描述同一态矢量的方法。给定两组基 {|n⟩} 和 {|α⟩}，它们之间的变换由变换矩阵 U 联系，矩阵元 U_αn = ⟨α|n⟩。态矢量 |ψ⟩ 在两组基下的系数列向量分别为 c（在 {|n⟩} 下）和 d（在 {|α⟩} 下），它们通过 d = U† c 相互转换。
- 方法步骤：
  1. 识别题型：若要求系数变换，则明确新旧表象的基矢和态矢量。
  2. 写出变换矩阵 U：矩阵元 U_αn = ⟨α|n⟩，注意行指标为新基，列指标为旧基。
  3. 若已知旧系数列向量 c，则新系数 d = U† c，其中 U† 的矩阵元为 (U†)_nα = ⟨n|α⟩。
  4. 若已知新系数 d，则旧系数 c = U d。
  5. 检查幺正性：验证 U†U = I，确保变换正确。
  6. 回代：将得到的系数代回态矢量表达式，验证与原态一致。
- 易错提醒：
  - 混淆变换矩阵 U 和 U† 的使用方向，导致系数变换错误。
  - 忘记变换矩阵是幺正矩阵，错误地使用 U^{-1} 而不利用 U† = U^{-1}。
  - 在构造变换矩阵时，行和列指标颠倒，导致矩阵元写错。
