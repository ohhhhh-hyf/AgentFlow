核心★★★★★ 角向方程

考法预判. 可能以填空题或简答题形式考查角向方程的具体形式，要求写出含 sinθ 微分项的方程，或说明分离变量法中角向部分的处理。也可能结合球谐函数考查边界条件。 [1][2][3]

必须先会.

  • 角向方程由分离变量法从球坐标薛定谔方程得到，形式为：1/sinθ * d/dθ(sinθ * dΘ/dθ) + [l(l+1) - m²/sin²θ]Θ = 0。
  • 方程中 sinθ 微分项源于球坐标拉普拉斯算符的角向部分。
  • m 为磁量子数，l 为角量子数，满足 l ≥ |m|。
  • 角向方程的解为连带勒让德函数 P_l^m(cosθ)，与 φ 部分结合构成球谐函数。
  • 分离变量时，φ 部分给出 e^{imφ}，要求 m 为整数以保证单值性。

知识点讲解. 角向方程是球坐标下薛定谔方程分离变量后得到的关于极角 θ 的常微分方程。其标准形式为 1/sinθ * d/dθ(sinθ * dΘ/dθ) + [l(l+1) - m²/sin²θ]Θ = 0，其中 sinθ 微分项来自拉普拉斯算符的角向部分。适用边界：仅适用于球对称势场，且要求波函数在 θ=0 和 θ=π 处有限，这导致 l 和 m 取整数。考试中可能要求写出方程或判断解的合法性。笔记缺项：应补充连带勒让德函数的递推关系及正交性，以及球谐函数的归一化条件。 [1][2][3]

方法步骤. [1][2][3]

  1. 默写角向方程的标准形式和成立条件
  2. 检查变量是否满足公式前提
  3. 先凑成标准形再代入，不要直接套裸公式
  4. 代入后回代检查有没有改变原问题

易错提醒. [1][2][3]

  • 忘记 sinθ 微分项，导致方程形式错误。
  • 忽略 m 必须为整数，导致解不满足单值性。
  • 混淆角向方程与径向方程，注意角向只含 θ 和 φ。

核心★★★★★ 径向方程与角向方程

考法预判. 可能以简答题或推导题形式考查分离变量法 ψ=RΘΦ 的步骤，要求写出径向方程和角向方程的具体形式，并说明各部分的物理意义。 [1][2][3]

必须先会.

  • 球坐标下波函数可分离为 ψ(r,θ,φ) = R(r)Θ(θ)Φ(φ)。
  • 分离变量后得到三个常微分方程：径向方程、角向方程（θ部分）、φ方程。
  • 径向方程形式：1/r² * d/dr(r² dR/dr) + [2μ/ℏ²(E - V(r)) - l(l+1)/r²]R = 0。
  • 角向方程（θ部分）与 φ 方程结合得到球谐函数 Y_l^m(θ,φ)。
  • φ 方程解为 e^{imφ}，m 为整数。

知识点讲解. 分离变量法将球坐标薛定谔方程分解为径向和角向部分。设 ψ=RΘΦ，代入后除以 ψ 并乘以 r²sin²θ，可分离出 φ 方程、θ 方程和径向方程。径向方程含势能 V(r) 和离心势能项 l(l+1)/r²，角向方程与 l、m 相关。适用边界：仅适用于势能只依赖 r 的中心力场。考试中可能要求写出分离后的方程或解释各项来源。笔记缺项：应补充径向方程在氢原子中的具体解（如拉盖尔多项式）以及归一化条件。 [1][2][3]

方法步骤. [1][2][3]

  1. 写出球坐标薛定谔方程，设 ψ=RΘΦ。
  2. 代入并分离变量，分别得到 φ、θ、r 的方程。
  3. 写出径向方程和角向方程的标准形式。
  4. 根据边界条件确定量子数 l、m 的取值范围。
  5. 写出解的形式并检查是否满足归一化。

易错提醒. [1][2][3]

  • 分离变量时漏掉 r²sinθ 因子，导致方程错误。
  • 混淆径向方程和角向方程中的量子数。
  • 忘记离心势能项 l(l+1)/r²。

方法步骤. [1][2][3]

  1. 写出厄米算符的定义式 ⟨ψ|Aφ⟩ = ⟨Aψ|φ⟩。
  2. 设两个本征态 |ψ_m⟩、|ψ_n⟩ 对应本征值 a_m、a_n。
  3. 计算 ⟨ψ_m|A|ψ_n⟩，分别用 A 作用右矢和左矢得到两个表达式。
  4. 利用厄米性使两个表达式相等，得到 (a_m - a_n)⟨ψ_m|ψ_n⟩ = 0。
  5. 由 a_m ≠ a_n 推出 ⟨ψ_m|ψ_n⟩ = 0，即正交。
  6. 若本征值简并，说明需正交化处理。

  • 证明中未说明 a_m - a_n ≠ 0 的原因。

方法步骤. [1][2]

  1. 确认算符 A 的本征态 {|ψ_k⟩} 是否完备（通常由厄米性保证）。
  2. 写出完备性关系 Σ_k |ψ_k⟩⟨ψ_k| = I。
  3. 若需展开态 |ψ⟩，计算系数 c_k = ⟨ψ_k|ψ⟩。
  4. 利用投影算符 P_k = |ψ_k⟩⟨ψ_k| 表示展开式 |ψ⟩ = Σ_k P_k |ψ⟩。
  5. 在计算矩阵元时，插入单位算符 I = Σ_k |ψ_k⟩⟨ψ_k| 以简化。
  6. 检查展开系数是否满足归一化 Σ_k |c_k|^2 = 1。

  • 混淆投影算符 P_k 与概率 |c_k|^2。
  • 在连续谱情形误用求和形式，应使用积分。

考法预判. 可能以证明题形式考查厄米算符的定义式⟨φ|A|φ⟩=⟨φ|A†|φ⟩，要求从内积的实性出发证明。也可能给出具体算符（如动量算符），要求判断其是否为厄米算符，并写出转置、共轭算符的定义。 [1]

必须先会.

  • 转置算符定义：⟨φ|A^T|ψ⟩ = ⟨ψ*|A|φ*⟩（或 ⟨φ|A^T|ψ⟩ = ⟨ψ|A|φ⟩*，具体形式需按教材约定）。
  • 共轭算符定义：⟨φ|A*|ψ⟩ = ⟨φ*|A|ψ*⟩。
  • 厄米算符定义：A† = A，即 ⟨φ|A|ψ⟩ = ⟨Aφ|ψ⟩，等价于 ⟨φ|A|φ⟩ 为实数。
  • 厄米算符的实性证明：⟨φ|A|φ⟩ = ⟨φ|A†|φ⟩ = ⟨φ|A|φ⟩*，故 ⟨φ|A|φ⟩ 等于其共轭，必为实数。
  • 厄米算符的本征值为实数，属于不同本征值的本征矢正交。

知识点讲解. 厄米算符是量子力学中表示力学量的算符，其定义是 A† = A，即算符的厄米共轭等于自身。厄米共轭算符 A† 由转置和复共轭复合而成：先取转置，再取复共轭。转置算符的定义涉及内积的交换，共轭算符则对波函数取复共轭。 [1]

方法步骤. [1]

  1. 判断题型：若要求证明厄米性，则从定义 A† = A 出发；若要求证明实性，则利用 ⟨φ|A|φ⟩ = ⟨φ|A†|φ⟩。
  2. 写出厄米共轭的定义：A† = (A^T)*，并明确转置和共轭算符的作用规则。
  3. 对给定算符，计算 ⟨φ|A|ψ⟩ 与 ⟨Aφ|ψ⟩，比较两者是否相等。
  4. 若相等，则 A 为厄米算符；若不相等，则不是。
  5. 证明实性时，令 |ψ⟩ = |φ⟩，利用 ⟨φ|A|φ⟩ = ⟨φ|A†|φ⟩ = ⟨φ|A|φ⟩*，得出 ⟨φ|A|φ⟩ 为实数。
  6. 回代检查：确认每一步内积的次序和复共轭处理正确。

易错提醒. [1]

  • 混淆转置算符和共轭算符的定义，导致厄米共轭计算错误。
  • 忘记厄米算符定义中内积的次序：⟨φ|A|ψ⟩ = ⟨Aφ|ψ⟩，而不是 ⟨φ|A|ψ⟩ = ⟨ψ|A|φ⟩。
  • 在证明实性时，错误地认为 ⟨φ|A|φ⟩ 自动为实数，而忽略了需要利用 A† = A 的条件。

重点★★★★☆ 表象间的转化

考法预判. 可能以计算题形式考查：给定两个表象的基矢变换关系，求态矢量在另一表象中的系数列向量。也可能要求写出变换矩阵的具体形式，并利用变换矩阵进行表象间的转换。 [1][2][3]

必须先会.

  • 基矢变换：设 {|n⟩} 和 {|α⟩} 为两组基，变换关系为 |α⟩ = Σ_n U_nα |n⟩，其中 U_nα = ⟨n|α⟩。
  • 系数列向量变换：若态 |ψ⟩ 在 {|n⟩} 表象中系数为 c_n = ⟨n|ψ⟩，在 {|α⟩} 表象中系数为 d_α = ⟨α|ψ⟩，则 d_α = Σ_n U†_αn c_n，即 d = U† c。
  • 变换矩阵 U 是幺正矩阵：U†U = I，U† = U^{-1}。
  • 变换矩阵的矩阵元：U_αn = ⟨α|n⟩，U†_nα = ⟨n|α⟩。
  • 表象变换保持内积和概率守恒。

知识点讲解. 表象间的转化是量子力学中在不同基底下描述同一态矢量的方法。给定两组基 {|n⟩} 和 {|α⟩}，它们之间的变换由变换矩阵 U 联系，矩阵元 U_αn = ⟨α|n⟩。态矢量 |ψ⟩ 在两组基下的系数列向量分别为 c（在 {|n⟩} 下）和 d（在 {|α⟩} 下），它们通过 d = U† c 相互转换。 [1][2][3]

方法步骤. [1]

  1. 识别题型：若要求系数变换，则明确新旧表象的基矢和态矢量。
  2. 写出变换矩阵 U：矩阵元 U_αn = ⟨α|n⟩，注意行指标为新基，列指标为旧基。
  3. 若已知旧系数列向量 c，则新系数 d = U† c，其中 U† 的矩阵元为 (U†)_nα = ⟨n|α⟩。
  4. 若已知新系数 d，则旧系数 c = U d。
  5. 检查幺正性：验证 U†U = I，确保变换正确。
  6. 回代：将得到的系数代回态矢量表达式，验证与原态一致。

易错提醒. [1][3]

  • 混淆变换矩阵 U 和 U† 的使用方向，导致系数变换错误。
  • 忘记变换矩阵是幺正矩阵，错误地使用 U^{-1} 而不利用 U† = U^{-1}。
  • 在构造变换矩阵时，行和列指标颠倒，导致矩阵元写错。
