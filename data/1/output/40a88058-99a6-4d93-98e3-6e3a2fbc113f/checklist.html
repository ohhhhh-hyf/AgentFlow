核心★★★★★ 氢原子

必须先会

  • 氢原子能级公式：E_n = -μ e^4 / (2 (4πε_0)^2 ħ^2 n^2) = -13.6 eV / n^2（约化质量μ近似为电子质量）
  • 波函数 ψ_{nlm}(r,θ,φ) = R_{nl}(r) Y_{lm}(θ,φ)，其中R_{nl}为径向函数，Y_{lm}为球谐函数
  • 量子数：主量子数n=1,2,...；角量子数l=0,1,...,n-1；磁量子数m=-l,...,l
  • 能级简并度：对给定n，简并度为 n^2（不考虑自旋）
  • 电流分布与磁矩：电子轨道运动产生磁矩，磁矩与角动量关系 μ = -e/(2μ) L

知识点讲解 氢原子是量子力学中少数可精确求解的系统，其能级公式和波函数是理解原子结构的基础。能级公式由库仑势和薛定谔方程解得，约化质量μ在考虑核运动时需修正。波函数分离为径向和角向部分，径向函数含拉盖尔多项式，角向为球谐函数。量子数n,l,m分别决定能量、角动量大小和角动量z分量。简并度n^2源于不同l,m组合对应相同能量。电流分布与磁矩联系了量子力学与电磁学，是后续塞曼效应等的基础。考试可能要求写出能级公式、说明量子数取值范围、计算简并度，或分析波函数对称性。注意区分氢原子与类氢离子的能级公式差异。

方法步骤

  1. 识别题目要求：是求能级、写波函数、还是分析量子数/简并度
  2. 若求能级，写出氢原子能级公式 E_n = -13.6 eV / n^2，注意约化质量修正
  3. 若写波函数，写出 ψ_{nlm} = R_{nl} Y_{lm}，并说明各量子数取值范围
  4. 若求简并度，对给定n，统计l从0到n-1，每个l有2l+1个m，求和得n^2
  5. 若涉及磁矩，用 μ = -e/(2μ) L 计算，注意方向与角动量相反
  6. 检查量子数是否满足 l ≤ n-1，|m| ≤ l

易错提醒

  • 忘记约化质量修正，直接用电子质量导致能级数值偏差
  • 混淆主量子数n与角量子数l的取值上限，l最大为n-1
  • 简并度计算时遗漏m的取值，或错误认为简并度为2n^2（那是考虑自旋后）

知识点讲解 厄米算符对应可观测力学量，其本征值实数性保证了测量结果为实数。证明本征值实数性时，利用 ⟨a|A|a⟩ = a⟨a|a⟩，同时由厄米性 ⟨a|A|a⟩ = ⟨A a|a⟩ = a*⟨a|a⟩，因⟨a|a⟩>0，故a=a*。正交性证明类似，对两个不同本征值a,b，有 (a-b)⟨a|b⟩=0，因a≠b，故内积为零。完备性使得任意量子态可分解为本征态叠加，是态叠加原理的数学基础。考试可能要求证明实数性或正交性，或利用完备性展开态并计算概率。注意简并情形下本征态不一定自动正交，需正交化处理。

方法步骤

  1. 确认算符为厄米：检查 A† = A 或 ⟨ψ|A|φ⟩ = ⟨Aψ|φ⟩
  2. 证明本征值实数性：写出本征方程，取内积，利用厄米性比较
  3. 证明正交性：对两个本征态，利用本征方程和厄米性，推导 (a-b)⟨a|b⟩=0
  4. 若简并，对同一本征值的多个本征态，用施密特正交化构造正交基
  5. 利用完备性展开任意态，计算展开系数 c_n = ⟨a_n|ψ⟩
  6. 验证展开系数满足归一化 Σ|c_n|^2 = 1

易错提醒

  • 忘记厄米算符定义中内积的顺序，导致证明错误
  • 在简并情形下直接认为所有本征态正交，实际需正交化
  • 完备性展开时忘记归一化条件，导致概率计算错误
