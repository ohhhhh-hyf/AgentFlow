核心★★★★★ Definition 1 (典型空间中的度规)

考法预判. 可能以选择题或简答题形式考查正交曲线坐标系中线元与度规张量的对应关系，或给定具体坐标系（如球坐标、柱坐标）写出 ds² 和 g_ii。也可能要求判断某表达式是否为正确的线元。

必须先会.

  • 线元 ds² = Σ g_ii (dx^i)²，其中 g_ii 为度规张量的对角分量。
  • 正交曲线坐标系中度规张量是对角的，非对角元为零。
  • 球坐标：ds² = dr² + r² dθ² + r² sin²θ dφ²，g_rr=1, g_θθ=r², g_φφ=r² sin²θ。
  • 柱坐标：ds² = dρ² + ρ² dφ² + dz²，g_ρρ=1, g_φφ=ρ², g_zz=1。
  • 度规张量 g_ii 是坐标的函数，可能随位置变化。

知识点讲解. 度规张量 g_ii 描述空间中两点间距离的度量，在正交曲线坐标系中，线元 ds² 等于各坐标微分的平方乘以对应的度规分量之和。例如球坐标中，径向度规为 1，角向度规随 r 和 θ 变化。适用边界是正交曲线坐标系，此时度规为对角矩阵；若坐标系非正交，则需考虑交叉项。本次考试可能要求根据给定坐标系写出线元或度规分量，或判断坐标变换后的表达式。笔记中应补充常见坐标系的度规分量表，并注意度规分量是坐标的函数，不能当作常数。

方法步骤. [1][2]

  1. 用自己的话复述典型空间中的度规的定义或结论，并写出一条限制条件
  2. 按「先看条件再下结论」的流程逐步核验
  3. 用一个正例确认能用，再用一个反例钉住边界
  4. 若要写证明，按「构造 → 验证条件 → 下结论」的顺序落笔

易错提醒.

  • 容易混淆球坐标中 θ 与 φ 的度规分量，注意 g_φφ = r² sin²θ 而非 r²。
  • 忘记度规分量是坐标的函数，在积分或微分时不能当作常数处理。

核心★★★★★ Definition 2 (散度定理)

考法预判. 可能以计算题形式考查通过散度定理将体积分转化为面积分，或反之。也可能要求判断散度定理的适用条件，或结合具体矢量场计算通量。 [1][2]

必须先会.

  • 散度定理：∫_V (∇·F) dV = ∮_S F·dS，其中 S 是体积 V 的闭合曲面。
  • 散度 ∇·F 表示矢量场的源强度，通量表示穿过曲面的总量。
  • 定理要求矢量场在体积 V 内具有连续的一阶偏导数。
  • 常用于简化计算：将难以计算的体积分转化为面积分，或反之。

知识点讲解. 散度定理建立了体积分与面积分之间的联系，核心公式为 ∫_V (∇·F) dV = ∮_S F·dS。它适用于闭合曲面围成的体积，且矢量场在区域内光滑。物理上，散度代表单位体积的源强度，通量代表穿过曲面的总流量。考试中可能要求利用该定理将体积分化为面积分，或计算某矢量场的通量。注意曲面必须闭合，且方向取外法向。笔记中应补充常见矢量场的散度计算，并注意边界条件。散度定理是目录里已有的知识点，类型是theorem。先把必须会的条目钉死：通量与散度的关系、体积分与面积分。 [1][2]

方法步骤. [1][2]

  1. 判断题目要求的是体积分还是面积分，确定是否使用散度定理。
  2. 计算矢量场 F 的散度 ∇·F。
  3. 将体积分 ∫_V (∇·F) dV 转化为闭合曲面 S 上的面积分 ∮_S F·dS。
  4. 根据曲面形状选择坐标系，计算面积分。
  5. 检查曲面是否闭合，方向是否取外法向。

易错提醒. [1][2]

  • 忘记曲面必须闭合，若曲面不闭合则不能直接应用散度定理。
  • 面积分方向取反会导致符号错误，注意外法向约定。

核心★★★★★ Definition 3 (旋度)

考法预判. 可能以计算题或概念题考查旋度的定义、环量与面积分的关系，或给定矢量场计算旋度。也可能要求判断某矢量场是否为无旋场。

必须先会.

  • 旋度 ∇×F 是矢量，描述矢量场的旋转程度。
  • 环量 ∮_C F·dl 与旋度面积分的关系：∮_C F·dl = ∫_S (∇×F)·dS（斯托克斯定理）。
  • 若 ∇×F = 0，则矢量场为无旋场（保守场）。
  • 旋度在直角坐标系中的表达式为 ∇×F = (∂F_z/∂y - ∂F_y/∂z, ∂F_x/∂z - ∂F_z/∂x, ∂F_y/∂x - ∂F_x/∂y)。

知识点讲解. 旋度是矢量场在某点的旋转强度，其大小和方向由 ∇×F 给出。斯托克斯定理将环量（线积分）与旋度的面积分联系起来，适用于光滑曲面。若旋度为零，则场无旋，环量恒为零。考试中可能要求计算给定矢量场的旋度，或利用斯托克斯定理简化环量计算。注意曲面方向与曲线方向需满足右手定则。笔记中应补充旋度在柱坐标和球坐标中的表达式，并注意计算时的偏导顺序。旋度是目录里已有的知识点，类型是theorem。先把必须会的条目钉死：旋度定义、环量与面积分。做题时先判断本题是不是在用它，再按方法步骤走，最后回代检查适用条件。 [1]

方法步骤.

  1. 确定矢量场 F 的分量表达式。
  2. 根据坐标系选择旋度公式（直角坐标、柱坐标或球坐标）。
  3. 计算各分量偏导，得到 ∇×F。
  4. 若需计算环量，利用斯托克斯定理转化为面积分。
  5. 检查曲面方向与曲线方向是否满足右手定则。

易错提醒.

  • 混淆旋度与散度，注意旋度是矢量，散度是标量。
  • 在非直角坐标系中直接套用直角坐标公式导致错误，需使用对应坐标系的旋度表达式。

核心★★★★★ Definition 4 (μ空间分割（宏观）)

考法预判. 可能以概念题或简答题考查 μ 空间分割的意义，或给定分割方式计算小体元 Δμ_j 的数目。也可能结合宏观分布考查代表点的分布。 [1][2][3]

必须先会.

  • μ 空间是单个粒子的相空间，由位置和动量坐标构成。
  • 将 μ 空间分割成许多小体元 Δμ_j，每个体元对应一个相格。

重点★★★★★ Theorem 12 (厄米算符属于不同本征值的本征态必然正交)

考法预判. 厄米算符不同本征值的本征态正交性常以证明题出现，要求写出证明过程。可能结合具体算符（如动量、角动量）验证正交性，或利用正交性简化计算。 [1][2][3]

必须先会.

  • 证明关键：利用 ⟨a|A|b⟩ = a⟨a|b⟩ = b⟨a|b⟩，因 a ≠ b 得 ⟨a|b⟩ = 0。

  • 正交性保证本征态可作为正交基，但需归一化。

知识点讲解. 厄米算符属于不同本征值的本征态必然正交，这是量子力学中态矢正交性的基础。证明思路：设 A|a⟩ = a|a⟩，A|b⟩ = b|b⟩，且 a ≠ b。利用厄米性，⟨a|A|b⟩ = a⟨a|b⟩ = b⟨a|b⟩，因此 (a - b)⟨a|b⟩ = 0，因 a ≠ b，故 ⟨a|b⟩ = 0。适用边界：该定理仅适用于厄米算符，且本征值不同。 [1][2][3]

  1. 设 A 为厄米算符，本征态 |a⟩ 和 |b⟩ 对应本征值 a 和 b，且 a ≠ b。
  2. 写出 ⟨a|A|b⟩ 的两种表达式：a⟨a|b⟩ 和 b⟨a|b⟩。
  3. 利用厄米性 ⟨a|A|b⟩ = ⟨A a|b⟩ = a⟨a|b⟩，与 b⟨a|b⟩ 相等。
  4. 由 (a - b)⟨a|b⟩ = 0，因 a ≠ b，得 ⟨a|b⟩ = 0。
  5. 结论：不同本征值的本征态正交。

  • 混淆正交性与归一化，正交不一定归一。

重点★★★★☆ Theorem 25 (本征态的封闭性)

考法预判. 可能以概念题考查封闭性条件 ∑|k><k| = 1，或要求利用其展开态矢。 [1]

必须先会.

  • 封闭性条件：∑|k><k| = 1（单位算符）。
  • 任意态矢 |ψ> 可展开为 |ψ> = ∑|k><k|ψ>。
  • 基矢满足正交归一性 <k|k'> = δ_kk'。
  • 封闭性条件用于在表象之间转换。

知识点讲解. 本征态的封闭性条件表明，一组完备基矢的投影算符之和等于单位算符：∑|k><k| = 1。这意味着任意态矢都可以用这组基矢展开：|ψ> = ∑|k><k|ψ>。封闭性条件是量子力学中表象变换的基础。考试中可能要求利用封闭性条件展开态矢，或证明某个算符的矩阵表示。注意基矢必须完备且正交归一。 [1][2][3]

方法步骤. [1][2][3]

  1. 用自己的话复述本征态的封闭性的定义或结论，并写出一条限制条件
  2. 按「先看条件再下结论」的流程逐步核验
  3. 用一个正例确认能用，再用一个反例钉住边界
  4. 若要写证明，按「构造 → 验证条件 → 下结论」的顺序落笔

易错提醒. [1][3]

  • 忘记封闭性条件要求完备基。
  • 混淆投影算符与单位算符。
