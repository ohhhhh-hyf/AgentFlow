核心★★★★★ Definition 1 (哈密顿量)

考法预判. 可能以概念题或简答题形式考查哈密顿量的定义及其在量子力学中的地位，也可能结合具体系统（如氢原子）写出哈密顿量表达式。注意区分哈密顿量与能量算符的关系。 [1][2]

必须先会.

  • 哈密顿量是系统的总能量算符，在量子力学中通常表示为动能算符与势能算符之和：H = T + V。
  • 对于单粒子系统，哈密顿量可写为 H = -ħ²/(2m)∇² + V(r)。
  • 哈密顿量的本征值对应系统的能量本征值，本征方程 Hψ = Eψ 是定态薛定谔方程。
  • 哈密顿量是厄米算符，其本征值为实数，本征态构成完备正交基。

知识点讲解. 哈密顿量是量子力学中描述系统总能量的算符，由动能部分和势能部分组成。对于单粒子，动能算符为 -ħ²/(2m)∇²，势能算符为 V(r)。哈密顿量的本征值给出系统可能的能量值，本征函数描述定态。哈密顿量是厄米算符，因此本征值为实数，本征态具有正交完备性。在考试中，可能要求写出特定系统的哈密顿量，或利用哈密顿量求解定态薛定谔方程。注意哈密顿量在不同表象中的表示可能不同，但物理内容不变。笔记中应补充哈密顿量在坐标表象和动量表象中的具体形式。 [1][2]

方法步骤. [1][2]

  1. 识别系统类型（单粒子、多粒子、是否含势场）。
  2. 写出动能算符的一般形式：T = -ħ²/(2m)∇²（多粒子时求和）。
  3. 根据物理情境写出势能算符 V(r)。
  4. 将动能与势能相加得到哈密顿量 H = T + V。
  5. 若要求本征值，则求解定态薛定谔方程 Hψ = Eψ。

易错提醒. [1][2]

  • 不要忘记动能算符中的拉普拉斯算符作用于波函数，注意符号和系数。
  • 哈密顿量是算符，不是数值，不能直接与能量数值混淆。

核心★★★★★ Definition 2 (概率密度角度分布与径向分布)

考法预判. 可能以概念题或计算题形式考查概率密度的角度分布和径向分布，要求区分两者并写出表达式。也可能结合氢原子波函数分析电子云分布。 [1]

必须先会.

  • 概率密度角度分布描述电子在空间各方向出现的概率，由球谐函数 Y_lm(θ,φ) 的模方决定。
  • 径向分布函数 D(r) = r²R(r)² 描述电子在半径 r 处球壳内出现的概率。
  • 角度分布与径向分布共同决定电子在空间的总概率密度 |ψ|² = |R(r)Y_lm(θ,φ)|²。
  • s 轨道角度分布为球形对称，p 轨道呈哑铃形，d 轨道形状更复杂。

知识点讲解. 概率密度角度分布和径向分布是描述电子在原子中空间分布的两个方面。角度分布由球谐函数决定，反映电子在不同方向出现的概率，与量子数 l 和 m 有关；径向分布由径向波函数决定，反映电子在不同半径处出现的概率，与量子数 n 和 l 有关。两者相乘得到总概率密度。在考试中，可能要求画出或识别不同轨道的角度分布图，或计算径向分布函数的极值。注意径向分布函数包含 r² 因子，因为球壳体积随半径增大。笔记中应补充常见轨道的角度分布形状和径向分布节点数。 [1]

方法步骤. [1]

  1. 确定量子数 n, l, m。
  2. 写出径向波函数 R(r) 和球谐函数 Y_lm(θ,φ)。
  3. 角度分布为 |Y_lm(θ,φ)|²，径向分布为 r²|R(r)|²。
  4. 分析角度分布的方向性（如 s 球形、p 哑铃形）。
  5. 分析径向分布的节点和峰值位置。

易错提醒. [1]

  • 不要忘记径向分布函数中的 r² 因子。
  • 角度分布与径向分布不能混淆，前者只与角度有关，后者只与半径有关。

核心★★★★★ Definition 5 (厄米算符本征态的正交性与完备性)

考法预判. 可能以证明题或概念题形式考查厄米算符本征态的正交性和完备性，要求证明不同本征值的本征态正交，或利用完备性展开波函数。 [1][2][3]

必须先会.

  • 厄米算符属于不同本征值的本征态必然正交：若 Aψ₁=a₁ψ₁, Aψ₂=a₂ψ₂ 且 a₁≠a₂，则 ⟨ψ₁|ψ₂⟩=0。
  • 厄米算符的本征态构成完备集，任意波函数可按本征态展开：ψ = Σcₙφₙ。
  • 展开系数 cₙ = ⟨φₙ|ψ⟩。
  • 完备性也称为封闭性，即 Σ|φₙ⟩⟨φₙ| = I。

知识点讲解. 厄米算符本征态的正交性和完备性是量子力学的重要定理。正交性指不同本征值的本征态内积为零，这保证了本征态可以作为正交基。完备性指本征态张成整个希尔伯特空间，任意波函数都可以展开为本征态的线性组合。这两个性质使得厄米算符的本征态构成一组正交完备基，用于表示量子态和计算期望值。在考试中，可能要求证明正交性，或利用完备性进行展开。注意简并本征态不一定自动正交，但可以通过施密特正交化处理。笔记中应补充完备性在态矢量表示中的应用。 [1][2][3]

方法步骤. [1][2][3]

  1. 设厄米算符 A 的两个本征态 |ψ₁⟩, |ψ₂⟩ 对应本征值 a₁, a₂。
  2. 利用厄米性：⟨ψ₁|A|ψ₂⟩ = ⟨ψ₂|A|ψ₁⟩*。
  3. 代入本征方程，得到 (a₁-a₂)⟨ψ₁|ψ₂⟩=0。
  4. 若 a₁≠a₂，则 ⟨ψ₁|ψ₂⟩=0，证明正交。
  5. 对于完备性，写出展开式 ψ = Σcₙφₙ，并计算系数 cₙ = ⟨φₙ|ψ⟩。

易错提醒. [1][2][3]

  • 正交性只对不同本征值的本征态成立，简并本征态不一定正交。
  • 完备性展开时，系数计算不要忘记内积的共轭。

核心★★★★★ Definition 6 (厄米算符本征值的实数性)

考法预判. 可能以证明题或概念题形式考查厄米算符本征值为实数的证明，也可能结合具体算符（如哈密顿量）判断其本征值性质。 [1]

必须先会.

  • 该定理是量子力学中物理量可观测性的基础。

知识点讲解. 厄米算符本征值的实数性是量子力学的基本定理。由于物理量对应的算符是厄米算符，其本征值代表可能的测量结果，必须是实数。证明基于厄米算符的定义：⟨ψ|A|ψ⟩ = ⟨ψ|A|ψ⟩*。将本征方程代入，得到 a⟨ψ|ψ⟩ = a*⟨ψ|ψ⟩，由于 ⟨ψ|ψ⟩>0，故 a=a*。在考试中，可能要求写出证明过程，或判断某个算符是否为厄米算符。注意厄米算符的定义在不同文献中可能有差异，但本征值实数性不变。笔记中应补充厄米算符的判定方法。 [1]

方法步骤. [1]

  2. 写出本征方程 A|ψ⟩=a|ψ⟩。
  3. 计算 ⟨ψ|A|ψ⟩，利用厄米性 ⟨ψ|A|ψ⟩ = ⟨ψ|A|ψ⟩*。
  4. 代入本征方程，得到 a⟨ψ|ψ⟩ = a*⟨ψ|ψ⟩。
  5. 由于 ⟨ψ|ψ⟩≠0，得出 a=a*，即 a 为实数。

易错提醒. [1]

  • 证明中不要忘记 ⟨ψ|ψ⟩ 是正实数。
  • 厄米算符的定义要正确，注意内积的共轭。

重点★★★★☆ Theorem 18 (散度定理)

考法预判. 可能以计算题或概念题形式考查散度定理，要求应用散度定理计算通量或体积分。

必须先会.

  • 散度定理：∮_S F·dS = ∫_V ∇·F dV，其中 S 是闭合曲面，V 是包围的体积。
  • 散度定理将曲面积分转化为体积分。
  • 散度 ∇·F 表示向量场的源强度。
  • 应用条件：向量场 F 在 V 内连续可微。

知识点讲解. 散度定理（高斯定理）是向量分析中的重要定理，它建立了闭合曲面上向量场的通量与曲面内部散度的体积分之间的联系。数学表达式为 ∮_S F·dS = ∫_V ∇·F dV。该定理在电磁学中用于计算电通量，在流体力学中用于质量守恒。在考试中，可能要求利用散度定理简化计算，或证明该定理。注意应用时需满足向量场在体积内连续可微的条件。笔记中应补充散度定理的物理意义。散度定理是目录里已有的知识点，类型是theorem。先把必须会的条目钉死：散度定理、散度向量场在闭合曲面的通量等于向量场的散度在曲面包围区域的体积分。做题时先判断本题是不是在用它，再按方法步骤走，最后回代检查适用条件。 [1]

方法步骤. [1]

  1. 识别问题中的闭合曲面 S 和向量场 F。
  2. 计算散度 ∇·F。
  3. 确定体积 V 及其边界 S。
  4. 应用散度定理将曲面积分转化为体积分。
  5. 计算体积分得到结果。

易错提醒.

  • 曲面必须是闭合的。
  • 向量场需在体积内连续可微。

重点★★★★☆ Theorem 19 (旋度)

考法预判. 可能以计算题形式考查旋度的定义和计算，要求计算向量场的旋度。

必须先会.

  • 旋度 ∇×F 是向量场 F 的旋转强度，结果为向量。
  • 在直角坐标中，∇×F = (∂F_z/∂y - ∂F_y/∂z, ∂F_x/∂z - ∂F_z/∂x, ∂F_y/∂x - ∂F_x/∂y)。
  • 旋度为零的场称为无旋场，可表示为标量场的梯度。
  • 旋度在流体力学和电磁学中有重要应用。

知识点讲解. 旋度是向量分析中的算子，描述向量场的旋转特性。它作用于向量场得到另一个向量场，表示局部旋转的角速度。在直角坐标中，旋度由偏导数的组合给出。旋度为零的场是无旋场，可以表示为标量场的梯度。在物理中，旋度用于描述流体的涡旋和电磁场。在考试中，可能要求计算给定向量场的旋度。注意旋度是向量，不是标量。笔记中应补充旋度在球坐标和柱坐标中的表达式。旋度是目录里已有的知识点，类型是concept。先把必须会的条目钉死：旋度定义、旋度计算。做题时先判断本题是不是在用它，再按方法步骤走，最后回代检查适用条件。 [1]

方法步骤.

  1. 写出向量场 F = (F_x, F_y, F_z)。
  2. 计算各偏导数。
  3. 代入旋度公式 ∇×F。
  4. 整理得到旋度向量。
  5. 若旋度为零，则场无旋。

易错提醒.

  • 旋度是向量，注意分量顺序。
  • 不要忘记偏导数的正确计算。
