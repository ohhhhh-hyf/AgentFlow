# [讨论议题与背景]
[一段话概括讨论主题、成员构成与核心探讨问题（一段写完，约 250–400 字）：① 成员构成（人数、身份或编号照原文）② **为什么现在讨论**（由头或前情，原文有才写）③ 议题范围（议题名逐条列出）④ **整体倾向或是否有结论**（分享型写明「以分享观点为主，未形成统一结论」）⑤ 原文有的关键数字、时间或专名选 1–3 个作锚点 ⑥ 讨论怎么推进（逐块推进还是漫谈发散）；一致与分歧明细归 [共识形成]、发言明细归 [发言要点]；不留空]

# [发言要点]
[两种组织方式按原文实际选一种，不硬套：① **成员发言集中**时按成员分节——每位成员一行 `## 成员称呼`（有姓名写姓名；无姓名按原文编号或角色，全篇一个称呼），其下 `- ` 一条一行写主张与论据；② **议题分散/漫谈型**按议题分节——每个议题一行 `## 议题名`，其下 `- **成员称呼**：主张与依据`；**交锋写实：谁主张什么、谁反对、理由是什么，同一议题下多条交锋各占一条**（只有同一次发言的碎片才合并）；每条 30–100 字、一条一件事；**原文的具体数字、次数、案例、时间落进对应条目**]

# [共识形成]
[写清两侧（约 150–300 字）：① 一致意见或产出（关键产出**加粗**）② **没有统一意见时写本场的倾向性认识与主要分歧点**——谁与谁不一致、分歧在哪（不只写「无」）③ 关键数字或结论口径照原文]

# [待探讨问题与后续]
[先写需进一步探讨、核实、未定论的问题（原文的疑问、分歧、被搁置的话题），一条一个，用「未确认：…」「待核实：…」「未定论：…」句式起头；原文有分工或后续约定（谁去查什么、下次聊什么）就接着写，**没有就不写这一段、不编造分工**；两者都没有则写「未提及」]
