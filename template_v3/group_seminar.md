# [讨论议题与背景]
[一段话概括讨论主题、成员构成及核心探讨问题（列出谈到的议题范围）；以分享观点为主、未形成统一结论的场次要写明（如「以分享观点为主，未形成统一结论」），不留空]

# [发言要点]
[两种组织方式，按原文实际选一种，不要硬套：① **成员发言集中**时按成员分节——每位成员一行 `## 成员称呼`（有姓名写姓名；无姓名按原文编号或角色，全文统一），其下 `- ` 一条一行写他的主张与论据；② **议题分散/漫谈型**时按议题分节——每个议题一行 `## 议题名`，其下 `- **成员称呼**：主张与依据`。观点交锋处写明「谁反对谁、分歧在哪」；同一议题的碎片合并成一条，每条 30–100 字、一条一件事，信息多就拆条或加缩进子条 `  - `]

# [共识形成]
[有统一意见或产出就写；**没有统一意见时写本场达成的倾向性认识与主要分歧点**（不要只写「无」）；关键产出**加粗**]

# [待探讨问题与后续]
[先写需进一步探讨、核实、未定论的问题：原文里的疑问、未达成一致的分歧、被搁置的话题，一条一个，用「未确认：…」「待核实：…」「未定论：…」这类句式起头；原文若有分工或后续约定（谁去查什么、下次聊什么、会后做什么）就接着写，**没有就不写这一段，不要编造分工**；确实两者都没有则写「未提及」（不写说明句）]
