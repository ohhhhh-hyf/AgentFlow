# [沟通背景与目的]
[一段话概括参与方、沟通主题与目的、整体结果或基调（一段写完，约 250–400 字）：① 参与方（机构/身份照原文）② 为什么沟通、要解决什么 ③ 整体结果或基调（原文没有明确结果就写「未提及」）；**本栏不出现成串的统计数字与专名清单**——人数、经费、奖项、平台名、学科名都归 [核心信息与数据]；**写完数一下：出现 3 个以上数字就是串栏**，删掉数字与专名、只留参与方、目的、结果三项；**超 400 字不合格**：只能删数字、专名与介绍性事实]

# [核心信息与数据]
[承载一方宣贯的事实要点：按主题分组（每组一行 `## 主题名`，**主题名后加括号标注发言的姓名＋职称/机构**（能确定发言人才标，只给编号或识别不到时不标、不写编号、不猜人；**讲话里提到的团队负责人、专家、校友不是发言人、不标**）；**组内超过 6 条再拆一组，同一发言人的内容归同组**），其下 `- **要点**：一条一行`（**每条 30–100 字，条内不再标注人名**），数字、年份、比例、专名、政策名照原文写全；**一条一个事实，不要把同类事实并排塞进一条**；**条数由原文决定**，**不要压成长段、也不要只挑几条**；诉求与回应归 [各方立场与诉求]；没有就写「未提及」]

# [各方立场与诉求]
[只写**听众诉求与宣讲方回应**：谁提出或关注什么、对方如何回应、分歧在哪；按参与方写（`- **参与方**：诉求或回应`，一条一行，不写成整段、不合并成「双方一致认为」）；**谁介绍了哪块归 [核心信息与数据] 的分组标注**，事实与数字清单也归那栏；原文没有就写「未提及」]

# [达成共识]
[只写已明确达成或确认的结论、口径与承诺（关键承诺**加粗**，原话用 `> ` 逐字引、整栏最多 3–5 句）；**待定、计划、尚未确定的一律归 [待协调事项与后续]**，已在其它栏写过的不复述；原文没有明确共识就写「未提及」（有讨论无结论时写「未达成明确共识」）]

# [待协调事项与后续]
[**分两组写，有内容才写**：① `## 待协调事项`——未定、待确认、需对接的事，`- **事项**：对接人/负责人/预计时间`（缺的项不写、不逐项标「待定」）；② `## 后续安排与参与方式`——联系方式、群号、链接、重要时间节点、报名渠道等读者接下来要做什么（照原文写全）；两组都没有就写「未提及」]
