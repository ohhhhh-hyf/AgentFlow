# [争议焦点]
[按**议题**归纳双方真正的分歧（不按环节复述交锋）：每条一个焦点 `- **焦点**：争的是什么；正方：…；反方：…`（一方没有对应主张就只写有的那侧）；**3–5 条，原文出现的焦点都要有**，**看完通篇回头归纳**，不与 [核心论点] 逐字重复；**只归纳立场与依据，不做输赢或"谁更有道理"的判断**（原文明示占优才写、写在 [结辩与评委点评]）；没有观点对立就写「未提及」]

# [环节交锋]
[按原文实际出现的环节分组（环节名取原文说法）：每个环节一行 `## 环节名`，其下 `- ` 一条一个争议点（先写一方进攻、紧接写对方回应，写清谁攻谁守），**每个环节 2–5 个交锋点**；原文没有环节线索就按交锋顺序分条、不硬分组；**没有区分说话人时按立场归入正方/反方，判不准写「一方」**；**每个交锋点尽量带 1 句原文引用**（`> ` 逐字不改写，归不到人只引原话）]

# [结辩与评委点评]
[**分三条写**：`- **正方结辩**：…`、`- **反方结辩**：…`、`- **评委点评**：…`（原文没有的不写）；每条写清核心升华点与关键判断（数字、名次照原文），**每条 60–150 字**；**原文明示获胜方时才标注**，未明示不写]
