# [就诊概况]
[一段话交代本次就诊全貌（一段写完，约 200–350 字）：① 患者基本信息（姓名、性别、年龄、职业照原文）② 就诊科室、时间与形式（初诊/复诊/家属代述，原文有才写）③ **核心主诉照原文写全**（症状、部位、性质、时长、诱因、伴随症状）④ 关键背景一两句（既往、过敏、近期用药）⑤ 初步判断与本次要解决的问题（未确诊照原文写「考虑…，需…进一步明确」）；病史与用药细节归 [病史与背景]/[治疗方案与医嘱]；整栏都没有内容才写「未明确」]

# [病史与背景]
[客观记录与本次就诊相关的背景（约 250–450 字）：**按原文实际出现的内容立条**（一条一个事实 `- **项别**：内容`）——原文说到哪几项就写哪几项，**不要为凑清单把没有的项写成「未提及」**；**症状与病史的描述本身就是核心事实**，照原文写全（部位、性质、时长、诱因、发作与缓解、伴随症状、既往发作与处理），**不得当「过程铺陈」压缩成一句**；**过敏史（药物/食物）、禁忌类信息原文出现必须逐项写入**；整栏都没有内容才写「未明确」]

# [诊断与检查结果]
[记录原文给出的诊断结论或初步印象（**尚未确诊照原文写「考虑…，需…进一步明确」，不把推测写成确诊**）、关键检查/检验结果及解读、医生对结果的说明（约 150–300 字）；**只有医生或原文认定异常、偏高、偏低或需关注的指标才加粗**，不按常识或参考范围自行认定异常；未被原文定性的按普通文本记录；整栏都没有内容才写「未明确」]

# [治疗方案与医嘱]
[医嘱清单（约 200–400 字）：**按原文实际给出的类别立条**，**有哪几类写哪几类、没有的类别不立条**，**每条都是 `- ` 分点行**（`- **类别**：内容`，同类下多条用缩进子条）；药品明细**只写进下表**（**原文出现过的药名一行一药**，缺格写 `—`，没有任何药品信息时整表只写一行「未提及」），正文不重复药品名称与用法用量；需解释的用药说明（为何换药/停药）写进对应条目；重点禁忌与高风险提醒加粗；整栏都没有内容才写「未明确」]

# [病情说明与沟通]
[只写**医生怎么说的、患者或家属怎么决定的**（约 150–300 字，`- **要点**：一条一行）：医生对病情与方案的解释（含通俗说明）、方案选择与理由（为什么这样治、什么情况下才考虑某种处理）、预期与需要观察的变化、提醒与安慰；患者或家属的疑问、顾虑与决定（同意/暂缓/自行决定）；**病史归 [病史与背景]、检查与诊断事实归 [诊断与检查结果]、用药与安排归 [治疗方案与医嘱]，本栏只写说明与沟通本身**；原文没有就写「未明确」]

# [复诊与预警信号]
[**原文给了复诊或随访安排才写复诊时间**（复查项目与时间照原文）；需立即就医的预警症状用 ⚠️ 标注、**逐项写入**；需要观察的变化（监测什么、什么情况要提前联系）也写进本栏（约 80–200 字）；都没有就写「未明确」]
