# [问答概况]
[用一段话概括问答场合的基本信息，包括时间、地点、发言人身份、参与媒体或机构、讨论的核心议题]

# [核心提问与回应]
[**一条问答独立成段**，按原文提问顺序排列：双方都能对应到人时用**称呼**开头——有姓名写姓名，否则写角色（记者/发言人…，照原文；同一人在全篇只用同一个称呼）：`记者：…` 换行 `发言人：…`，称呼不加粗；两方都对应不上人时才写成「**问**：…」换行「**答**：…」；**开头已经是称呼，内容里不要再写「记者提问」「发言人回应」这类重复说明**；回应写完整要点、不改变原意，答话要点多时用 `- ` 分点写清；内容相似的问题合并成一条]

# [媒体关注焦点]
[写媒体重复追问或重点追问的问题（追问顺序、重复次数按原文）+ 官方回应的要点；不做传播效果或社会影响的推断]

# [信息澄清与表态]
[提炼发言人对热点、争议或敏感问题的澄清说明与关键表态，重点内容**加粗**突出；与「核心提问与回应」重复的内容不在这里重写]
