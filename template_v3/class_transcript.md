# [核心知识点梳理]
[按教学逻辑分层：每个一级知识点一行 `## 名称`；其下**必须** `- ` 一条一行（`- **小类**：内容`；**不得写成连续段落**）——案例、数字、时间线（如「用了 X 年」）、奖项名、人名、原话都要落进对应条目；**每个知识点优先用 3–4 条覆盖定义/公式、方法步骤、易错点等代表性内容；关键事实超过 4 项时继续逐条保留，不得为满足条数而删除**；重点用**加粗**、难点用 ⭐ 标注，术语/公式/命令用 `具体内容` 标注，易混点用 *具体内容* 提醒；同类信息可以归组，但不要合并成一条长句]

# [课堂互动与答疑]
[**按互动环节分组总结**（每组一行 `## 组名`，组名取原文说法、原文有环节名就带上），其下 `- ` 一条一个互动点（每条 30–100 字）：写清**谁做了什么、问了什么、教师如何回应**，**一条一个点、不写成对话记录**（不逐轮照抄问答）；**教师的关键点评、提问与引导照原文逐字引用**——成句的用 `> ` 单独一行并在行首写明出处，短句可写在条目内用引号；**学生发言按点概括**（同类合并，典型回答可举 1–2 例），不逐条罗列；**只收对理解有增量的互动**：提问与追问、澄清/纠正/限定、举例与讨论、教师的点评与引导；**复述已讲内容、管理性对话、寒暄不收**；**整栏引用不超过 5 句**；原文没有互动就写「未提及」]
