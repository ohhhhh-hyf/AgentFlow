# [发布会概况]
[一段话概括发布会主题、发布单位与整体基调（最多 3 段、每段不超过 300 字）：① **时间地点与主办/参与**（发布时间、地点、主办与发布单位、发言人身份、到会媒体，照原文；没有的不编）② 围绕哪几块（列出板块名）③ 一句话定性或结论；逐项信息与数据照原文写进 [核心信息]、官方立场归 [官方表态]，本栏不复述]

# [核心信息]
[提炼官方发布的关键事实、核心数据及政策举措：**一条一件事、一条一行 `- **要点**：内容`**；**原文有的都要列、一条不落**——数字、时间表、适用范围与对象、执行方式；同一指标的多组取值（基线与现状、目标与完成）写成一条对照，不要只留一侧；每条交代**依据**（文件、政策或规划名）、**口径与范围**（同比/环比/基数、适用对象与时限）、**时间表**（发布时间与生效/执行时间分开写）——原文没有的不编；**数字与结论必须与原文对得上，不换算、不估算、不自行加总，不用「据悉/有关方面」模糊来源**；**本栏不逐条写人名**（不写「某某表示/强调」这类前缀）；第三方或非官方来源的信息才在条内标出来源；**数据与政策举措进本栏，立场与主张归 [官方表态]，同一事实不要两栏都写**；关键数据加粗，文件名、政策名、日期、机构名用 `具体内容` 标注]

# [官方表态]
[只写发言人**主动**表态（政策宣示类；与提问一一对应的回应归「Q&A环节」，[核心信息] 写过的政策举措不在这里重写——**同一内容不要两栏都写**）：**按主题分组逐条还原；一次表态含多个承诺或条件时分别列条**（不要压成一句）；**发言人身份在栏首交代一次**（首句或小标题写明 机构＋姓名；**多位发言人时每组开头写明**），**条目不逐条写人名、不写「某某强调/指出」这类前缀**；**挖到四层**：主张（含呼吁与要求）、针对什么、条件与前提、承诺或边界（不做什么）；**照原文保留限定语与程度**（力争/有望/原则上/除…外不得省成确定表述），引用的政策、法律、会议名称照原文写全；**`>` 只引原文连续原话、逐字照抄**（概括句或拼接句不算引语；长引语改为照原文措辞的要点）；记者/嘉宾/机构等**第三方表态另起条目标来源**，不与官方口径混写]

# [Q&A环节]
[**一条问答独立成段，一问一答＝一条记录**，按提问顺序**逐条编号**：`**1. 记者（人民日报 张宇）**：…` 换行 `**答**：…`，条与条之间空一行；提问方写「媒体名＋姓名/记者」（原文任何位置出现过姓名就必须用，**不得用「主持人」「发言人」顶替已知姓名**）；**同一场只有一位发布人时回应方统一写「答」**，多位发言人写姓名；**两方都对应不上人时才写成**「**问**：…」「**答**：…」；**每轮称呼都加粗**；**开头已是称呼，不要再写「主持人提问」这类重复说明**；答话超过约 400 字也**单段**连着写（一问一答各一段，不分段、不分点）；原文没有正式问答就写「未提及」（不要硬凑问答）]
