# [发布会概况]
[一段话概括发布会主题、发布单位与整体基调（一段写完，约 300–400 字）：① 时间地点与主办/参与（发布方、发言人身份、到会媒体照原文，没有的不编）② 围绕哪几块（有板块列板块名、单一讲话列分点主张名）③ 一句话定性或结论 ④ 原文有的关键数字锚点 1–3 个 ⑤ 问答涉及的议题与后续安排；明细、立场、问答分别归 [核心信息]/[官方表态]/[Q&A环节]]

# [核心信息]
[提炼官方发布的事实、数据与举措：**按发布板块分组**（`## 组名` 照原文），**一条一个主题**（同一文件或板块的多项合并成一条）；覆盖度以板块为单位保证：每项文件、每组数据都要有落点，数字、时间表、适用范围与对象、执行方式不落项；每条交代依据、口径与范围与时间表（**发布与生效分开写**）；多组取值写成一条对照；不换算、不估算、不自行加总，不用「据悉/有关方面」，与原文对得上、原文没有的不编；本栏不逐条写人名（不写「某某表示/强调」前缀）；立场与主张归 [官方表态]；关键数据加粗、政策名用 `具体内容` 标注]

# [官方表态]
[只写发言人**主动**表态（**整栏约 400–800 字**；同一内容不两栏都写，回应归 [Q&A环节]）：按 机构/职务＋议题 分组（每组一行 `## 机构或职务｜议题`，单一发言人只写议题），每组最多 3–4 条、每条 40–120 字，多个承诺或条件分别列条；**不写身份行**（身份见 [发布会概况]，多人时由每组标题的机构或职务承担）、不写会议背景导语，不逐条写人名、不写「某某强调/指出」前缀；挖到四层：主张、针对什么、条件与前提、承诺或边界；照原文保留限定语（力争/有望/原则上 不得省），政策与会议名照原文写全；`>` 只引连续原话、逐字照抄；第三方表态另起条目标来源]

# [Q&A环节]
[**一问一答＝一条记录、逐条编号**：`**1. 记者（人民日报 张宇）**：…` 换行 `**陈立**：…`，条间空一行；提问方写「媒体名＋姓名/记者」，回应方能确定姓名就写姓名（同一称呼，确实没有才写「答」）；**开头已是称呼就不再写「记者提问」这类重复说明**；**称呼里机构只能跟在人名/媒体名后**；两方都对应不上人时才写「**问**：…」「**答**：…」；**每轮称呼加粗**；**答话超约 400 字压到 400 字以内**（删例子与铺垫，保留结论、数字、条件与时限），仍**单段**连着写；没有正式问答就写「未提及」]
