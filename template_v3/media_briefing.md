# [发布会概况]
[一段话概括发布会主题、发布单位与整体基调（最多 3 段、每段不超过 300 字）：① 谁主办/谁参与 ② 围绕哪几块（列出板块名）③ 一句话定性或结论；逐项信息与数据照原文写进 [核心信息]、官方立场归 [官方表态]，本栏不复述]

# [核心信息]
[提炼官方发布的关键事实、核心数据及政策举措：**一条一件事、一条一行 `- **要点**：内容`**；每条交代**发布主体**（谁/什么场合）、**依据**（文件、政策或规划名）、**口径与范围**（同比/环比/基数、适用对象与时限）、**时间表**——原文没有的不编；**数字与结论必须与原文对得上，不用「据悉/有关方面」模糊来源**；关键数据加粗，文件名、政策名、日期、机构名用 `具体内容` 标注]

# [官方表态]
[只写发言人**主动**表态（政策宣示类；与提问一一对应的回应归「Q&A环节」，同一内容不要两栏都写）：按主题分组逐条还原，**每条写清是谁说的**（首次写 机构+职务+姓名，其后统一简称）；**挖到四层**：主张、针对什么、条件与前提、承诺或边界；**`>` 只引原文连续原话、逐字照抄**（概括句或拼接句不算引语；长引语改为照原文措辞的要点）；记者/嘉宾/机构等**第三方表态另起条目标来源**，不与官方口径混写]

# [Q&A环节]
[**一条问答独立成段**，按提问顺序：**能确定是谁就用姓名**——原文任何位置出现过该人姓名就必须用（首次「媒体/机构＋姓名」，其后姓名；提问方写「媒体名＋记者」或姓名；**不得用「主持人」「发言人」顶替已知姓名**）；原文确实没有姓名才用角色（记者/主持人/嘉宾），**两方都对应不上人时才写成**「**问**：…」「**答**：…」；同一人同一称呼、**每轮称呼都加粗**；**开头已是称呼，不要再写「主持人提问」这类重复说明**；答话超过约 400 字必须分点；原文没有正式问答就写「未提及」（不要硬凑问答）]
