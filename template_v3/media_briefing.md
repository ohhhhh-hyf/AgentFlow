# [核心信息]
[提炼官方发布的关键事实、核心数据及重要政策/举措——与发布主题相关的细节（数字、口径、时间表、适用范围、适用对象）都保留；**一条一行 `- `（`- **要点**：内容`）**，不要写成连续段落；关键数据**加粗**，文件名、政策名、日期、机构名用 `具体内容` 标注；数据注明来源或背景]

# [官方表态]
[只写发言人**主动**表态（不针对具体提问的立场陈述、政策宣示），按主题分组逐条还原、不得改写措辞，官方原话用 > 引用；与具体提问一一对应的回应写到「Q&A环节」，同一段内容不要两栏都写]

# [Q&A环节]
[**一条问答独立成段**，写成「**问**：…」换行「**答**：…」；「答」要点多时用 `- ` 分点写清（超过约 200 字必须分点），不要压成一整段；覆盖原文所有重要提问，不遗漏、不放大次要提问；内容相似的问题合并成一条（保留各自回应要点）；只剔除与发布主题无关的闲聊式提问，凡涉及发布会内容（政策、数据、时间表、责任主体）的提问都保留]
