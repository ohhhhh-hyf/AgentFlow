# 对话记录

<!-- requirement
忠实记录对话双方的核心交流内容、情感表达及共识/分歧，聚焦沟通本质与信息传递，双方立场须如实还原；不得曲解对话意图，关键信息点不得丢（同类可归并）。以分享、闲聊、漫谈为主的对话，先把"谁说了什么、说到什么程度"落住，不强行提炼决策与行动

# [对话概况]
[一段话概括（一段写完，约 250–400 字）：① 参与方与场合关系（有姓名写姓名，没有姓名只写原文明示的角色或关系，不补关系、不推断）② **为什么聊起、话题走向**（谁起的头、怎么转到下一块）③ 主要话题逐条列出 ④ **倾向与差异**：多数人怎么看、谁与谁不同、为什么（分享漫谈型写明「以分享为主，未形成明确结论」）⑤ 原文有的数字或具体事例选 1–3 个作锚点；**明细归 [交流内容]、原话归 [关键原话]**；不留空]

# [交流内容]
[按话题分条：每条写成 `- **话题**：谁提出、主张什么、对方如何回应、有无定论`（每条 30–100 字）；同一次发言的碎片合并成一条，**同一话题下每位发言人各占一条缩进子条，不要把多人塞进同一条**；**原文的具体细节（数字、次数、例子、时间、地点、约定）都落进对应条目，不只写主张**；本栏不夹引用——原话统一放 [关键原话]]

# [关键原话]
[逐字摘录最能代表各方立场、信息量最大的原话，**最多 8 句，有几句写几句**（不硬凑）；**格式固定：金句行 `> “……”`（加引号、不改字不合并）、其下一行 `- 背景：……`**——背景一句话即可：聊到哪个话题、谁对谁说的、针对什么事（原文没线索就写 `- 背景：未提及`，不编）；**同一个意思原文有原话就用原话**，不改转述；没有可摘的原话就写「未提及」]

# [共识与分歧]
[写**由事实得出的判断**（约 150–300 字）：① 一致的是什么、为什么都认同 ② 不一致在哪、**分歧的性质**（必要 vs 安心、审美或习惯差异）③ 分享漫谈型没有明确共识或分歧时，写**本场的倾向与依据**，不要写「未提及」、也不硬凑结论；**不复述各人分别说什么（明细归 [交流内容]）**；关键共识**加粗**，仍待确认的判断用 *具体内容* 标注]

# [延伸话题与后续]
[先写被提起但没聊完、或明确说"下次再聊"的话题（一条一个，照原文说法，不自拟话题名）；原文有承诺、约定或后续行动（谁去做什么、什么时候）就接着写，**没有就不写这一段、不要编造**；两者都没有则写「未提及」]
