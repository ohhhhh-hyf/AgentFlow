# 对话记录

<!-- requirement
忠实记录对话双方的核心交流内容、情感表达及共识/分歧，聚焦沟通本质与信息传递，双方立场须如实还原；不得曲解对话意图，关键信息点不得丢（同类可归并）。以分享、闲聊、漫谈为主的对话，先把"谁说了什么、说到什么程度"落住，不强行提炼决策与行动
-->

# [对话概况]
[一段话概括对话双方、对话主题、场景及整体脉络（谈了哪几个话题、以什么为主）；本场没有结论也要写明（如「以分享为主，未形成明确结论」），不留空]

# [交流内容]
[按话题分条：每条写成 `- **话题**：谁提出/主张什么/对方如何回应/有无定论`；同一话题的碎片合并成一条，不一句一条；关键原话用 > 引用（逐字，2–4 条）；人名、地点、物品名、约定事项、数字用 `具体内容` 标注；每条 30–100 字，信息多就拆成多条或加缩进子条 `  - `]

# [共识与分歧]
[分别写共识与分歧；**闲聊/漫谈型对话没有明确共识或分歧时，写本场的主要观点差异、偏好差异或各自关注点**（如「各人习惯不同：…」），不要写「未提及」，也不要硬凑结论；关键共识可用 **加粗**，敏感或仍待确认的判断可用 *具体内容* 标注]

# [延伸话题与后续]
[先写本场被提起但没聊完、或明确说"下次/改天再聊"的话题（一条一个，照原文说法，如「延伸：民谣吉他与留胡子的设想」）；原文若有承诺、约定或后续行动（谁去做什么、什么时候、约在哪里）就接着写，**没有就不写这一段，不要编造**；确实两者都没有则写「未提及」（不写说明句）]
