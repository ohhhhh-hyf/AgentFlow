# [访谈概述]
[一段话概括采访主题、受访者身份与内容概述（一段写完，约 250–400 字）：① 受访者身份与背景（职业/机构/代表作照原文）② 采访主题与目的 ③ 访谈主线与话题（议题名逐条列出）④ **最核心的观点与结论 1–3 条**（**每条一句话点题，可带原文的关键数字或事例作依据**）⑤ 原文有的关键数字、时间或专名选 1–3 个作锚点 ⑥ **访谈看点**（受访者强调的独家经历或自陈与流俗不同之处——**以原话为限，不做外部比较**）；**不展开受访者的论据与细节（归 [访谈详细记录]）**；没有的写「未提及」]

# [访谈详细记录]
[两级结构：每个议题一行 `## 议题名`，其下一条一行记录受访者的观点与事实陈述（每议题 2–5 条，按支撑力取舍）（数字、时间、地点、人名照原文）；**一个议题下有多个观点或事实就各自成条，不要压成一条；同一个观点讲到的细节、例子、时间线也落进该条**（每条 30–120 字，讲不完就分条或加缩进子条 `  - `）；受访者陈述的事实与他个人的看法、推测分开写，看法标明「受访者认为」；不要自建表格]

# [关键引语与金句]
[逐字摘录受访者原话中最能代表其立场、信息量最大的句子，**最多 8 句，有几句写几句**（不硬凑；**金句行用 `>` 引用并加引号**（`> “……”`）、逐字不改字、不合并）；**每条金句下一行背景，格式固定：金句行 `> “……”`、背景行 `- 背景：……`**——背景一句话即可，这句话在什么情形下说的：回应什么问题/谈到什么话题、针对谁或什么事（原文没线索就写 `- 背景：未提及`，不编）]
