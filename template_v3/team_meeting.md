# [例会概况]
[一段话概括本次例会（一段写完，约 250–400 字）：① 参会成员或部门（姓名优先，没人名写部门/角色、人数照原文）② **为什么开**（阶段或由头，原文有才写）③ 主线议题——议题名逐条列出，**每块一句话交代谈到什么程度：已定/待定/仅同步** ④ **整体态势**（哪些顺利、哪些卡住或延期）⑤ 结论与下一步方向（没有就写「以同步为主，未形成明确结论」）⑥ 原文有的关键数字或时间节点选 1–3 个作锚点；**本栏只到「议题级主线 + 态势」**，任务级进展与分工归 [工作进展]、跨人依赖归 [协作需求]]

# [工作进展]
[**按成员或模块分组**（每组一行 `## 成员/模块名`，每组 2–5 条，不要把栏名再当小标题），**每条写成 `- **任务名**：进展；下一步…；时间节点…`**（约 500–900 字）：四要素（谁、做了什么、到什么程度、下一步）齐全，**不写状态半句碎片**（同一次修改的连续动作合并成一条，一个任务讲不完用缩进子条）；状态（✅已完成 / 🔄进行中 / ⛔阻塞）在任务名后标一次；**本栏只写"已做了什么、到什么程度"**——会上定下的分工、责任人与时限归 [决定与待办]]

# [决定与待办]
[只写会上**定下来的事**（约 150–350 字，`- **事项**：一条一行`）：拍板或达成一致的决定（带口径与依据）、行动项（谁、何时前、做什么）、承诺与任务分配；同一次决定的多个动作合并成一条；**责任人与时限照原文，原文没给就只写事**；已写进 [工作进展] 或 [协作需求] 的不重复；没有拍板或分工就写「未提及」（只讨论未定的归 [待确认与风险]）]

# [协作需求]
[列出成员间提出的协作请求与跨人依赖（约 150–300 字），写清提出方、配合方与时限；已在 [工作进展] 写过的进展不复述；原文提到的跨人依赖一条不落，同一任务沿用 [工作进展] 的名称]

# [待确认与风险]
[只写**未决与异常**（约 100–250 字，`- **事项**：一条一行`）：尚未议定或需再确认的事项、不同意见与分歧、明确的阻塞与延期、需请示或等外部条件的事——写清卡在哪、在等什么、影响什么；**只写原文出现的未决与风险，不替团队预判**（只是"讨论过"不算风险）；**不写「原文未提及…」这类说明句**；没有就写「未提及」]
