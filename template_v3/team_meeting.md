# [例会概况]
[一段话交代例会构成与主线：参会成员/部门（照原文）、本次例会的主线议题（把议题名列出来）、形成的总体结论或下一步方向；**不展开各任务进展与分工（那是 [工作进展] / [协作需求] 的事）**；约 120–250 字]

# [工作进展]
[按成员或任务维度分级呈现（二级标题 `##` 写成员或模块，下方用 `- ` 列任务要点），**每条写成 `- **任务名**：进展；下一步…；时间节点…`**——四要素（谁、做了什么、做到什么程度、下一步）齐全，信息少的条目也要写清进展内容，**不要只写状态或半句碎片、不要一句一条**（同一次修改的几个小动作合并成一条）；状态用 ✅已完成 / 🔄进行中 / ⛔阻塞 标注在任务名后一次即可，关键阻塞、延期节点或高风险事项用 **具体内容** 强调，任务名、版本号、工单号用 `具体内容` 标注]

# [协作需求]
[列出成员间提出的协作请求、跨人/跨组依赖项及需要支持的事项，写清提出方与配合方；同一任务沿用[工作进展]里的名称，不要换称]
