# [讲座概况]
[一段话交代讲座信息与骨架（约 250–400 字）：① 主讲人及机构/头衔、主题、形式或场合（原文有才写）② **为什么讲这个、面向谁** ③ 围绕哪几个板块（板块名/领域名照原文列）④ **讲座的核心主张或最有分量的 2–3 个判断**（不逐条复述论点）⑤ **1–3 个关键数字、案例或专名作锚点**（不展开细节）⑥ **对听众的意义或适用对象**；**论证过程与论据清单归 [核心观点与论证]**；原文没有的项（如主讲人姓名）一次性写「未提及」]

# [核心观点与论证]
[按讲座的逻辑层次：每个论点一行 `## 论点`，其下用 `- ` 一条一行列支撑论据、案例与数据（论点和论据对应清楚，不泛泛而谈）；**一个论点下原文有多条论据、案例或数据就各占一条，不要压成一条；原文提到的数字、年份、人名、地名、事例与过程都要落进对应条目**（每条 30–120 字，讲不完就分条或加缩进子条 `  - `）；核心概念、模型、方法用 `具体内容` 标注，有行业影响力的判断用 **加粗** 强调；多个子论点分别列出，不复述]

# [金句总结]
[摘录主讲人讲座中的核心金句与深刻见解，**3–8 句**为限（一条一行，用 `> ` 引用、逐字不改字）；金句多时优先选信息量最大、最能代表主讲人立场的；每条可跟一句背景或关联论点说明（原文有才写），避免脱离上下文的孤立引用]

# [Q&A 环节]
[**一条问答独立成段**，按提问顺序：能对应到人就用**称呼**开头（姓名优先，其次角色；同一人同一称呼）：`**听众**：…` 换行 `**主讲人**：…`，**每轮称呼都加粗**；两方都对应不上人时才写成「**问**：…」「**答**：…」；**开头已是称呼，不要再写「听众提问」这类重复说明**；答话超过约 400 字也**单段**连着写（一问一答各一段，不分段、不分点）；原文没有正式问答就写「未提及」（不要硬凑问答）]
