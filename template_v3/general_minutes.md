# [全文摘要]
[一段话概括：先写这段文本是什么、围绕什么展开，再写核心结论或最终决定（没有结论就写整体判断，如「以分享为主，未形成明确结论」）；**每段不超过 400 字、最多 3 段**，信息多就拆段；只写概览，具体事项留给下方要点]

# [要点梳理]
[按原文自身的板块边界分组（议题切换、时间分段、原文小标题）；每组先写一行 `## 板块名`（短语，不加编号），再用 `- ` 一条一行列出具体事项（数字、时间、责任人、结论照原文）；摘要已概括的不重复；组数与条数只由原文决定，不要硬拆或硬凑]

# [分段速览]
[按原文自身的推进顺序逐段整理（时间点、章节或板块切换即分段）：每段先写一行 `## 时间段或板块名`（照原文说法，如 `00:14-00:50 会议概述`），其下 `- ` 一条一行写该段要点，数字、时间、责任人、结论照原文；与[要点梳理]的组织维度必须不同——这里按原文推进顺序走，不要换成主题重新分组、也不要照抄[要点梳理]的分组名；原文没有明确时间或分段线索时按自然段落推进；本栏允许与其它栏呈现同一事实（按时间维度再现不算重复）]
