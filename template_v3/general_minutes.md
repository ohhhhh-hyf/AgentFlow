# [全文摘要]
[一段话（最多 3 段、每段不超过 400 字）交代这四样，缺一不可：① 这是什么场合、谁参与或主办（人数、机构、身份照原文）；② 围绕什么、覆盖哪几个板块（把板块名列出来）；③ 关键结论 / 最终决定 / 结果口径（没有结论就写明「以分享为主，未形成明确结论」）；④ **关键数字进摘要**：人数、金额、比例、时限、项数等原文出现的关键数字，至少带 1–3 个最关键的（摘要里没有任何关键数字＝不合格）；不展开论据与逐项细节（那些归[要点梳理]/[分段速览]），但「参与主体 + 结论 + 关键数字」必须进摘要]

# [要点梳理]
[分两层写：① 先按原文自身的板块边界分组（议题切换、时间分段、原文小标题）——每组一行 `## 板块名`（短语，不加编号），其下 `- ` 一条一行列具体事实（数字、时间、责任人、结论照原文）；② 末尾固定三组（**有内容才写该组，没有就不出现**）：`## 结论与决定`——本场拍板/表决/达成的结论（逐条，带口径与依据）；`## 行动项与分工`——谁在何时前做什么（原文有责任人与时限才写，不编造）；`## 待确认与风险`——未达成一致的分歧、待确认事项、明确风险与阻塞（原文有则写）；同一事实在摘要里以「结论+关键数字」出现、在本栏以「分项事实」展开——这是「骨架 vs 明细」的分工，不算重复；组数与条数只由原文决定，不要硬拆或硬凑]

# [分段速览]
[按原文自身的推进顺序逐段整理（时间点、章节或板块切换即分段）：每段先写一行 `## 时间段或板块名`（照原文说法，有时间戳的用时间起头，不要自拟），其下 `- ` 一条一行写该段要点，数字、时间、责任人、结论照原文；与[要点梳理]的组织维度必须不同——这里按原文推进顺序走，不要换成主题重新分组、也不要照抄[要点梳理]的分组名；原文没有明确时间或分段线索时按自然段落推进；本栏允许与其它栏呈现同一事实（按时间维度再现不算重复）]
