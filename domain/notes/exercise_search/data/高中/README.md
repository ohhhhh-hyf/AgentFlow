# 高中题库全量统计（/bank/ 完整接口版）

> 实测数据（2026-08）。**所有 id 均可直接用于 `/bank/v1/question` 取题**：
> - 课本 `textbook_id` → 取题 `book_id` 参数
> - 章节 `textbook_catalog_id` → 取题 `section` 参数
> - 知识点 `id` → 取题 `keypoint` 参数；题型 `id` → 取题 `type` 参数

|---|---|---|---|---|---|---|

## 文件说明

| 文件 | 内容 |
|---|---|
| 01_科目与课本.md | 高中科目 + 每科全部版本/课本（textbook_id 即 book_id） |
| 02_知识点.md | 每科完整知识点树（id 传 keypoint） |
| 03_题型与考试类型.md | 每科题型 + 高中考试类型 25 条 |
| 04_章节.md | 每科每课本完整章节树（textbook_catalog_id 传 section） |

> ⚠️ 说明：高中综合、高中科学无课本版本；高中通用技术有课本和章节但题库无题（取题返回 0）；部分课本的第一个 catalog 节点是"致同学们/序言"类前言章节，通常也无题，请用正式章节取题。
