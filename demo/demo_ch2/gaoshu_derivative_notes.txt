高等数学·第二章 导数与微分·学习笔记（期末完整版）

本笔记系统覆盖导数一章全部核心内容：导数的概念（变化率、定义、几何意义、可导与连续）、求导法则（四则运算、复合函数、隐函数、参数方程、对数求导法）、高阶导数、微分（定义、运算法则、近似计算），以及综合例题与易错点。每一节都按"概念定义 → 直观理解 → 性质定理 → 计算方法 → 例题详解 → 易错提醒"的顺序展开，力求自学可懂、复习可用。

一、导数的概念

1.1 变化率与导数的定义

先看一个直观问题：物体自由落体，位移 s = (1/2)gt²，如何描述它在某一时刻 t₀ 的"瞬时速度"？从 t₀ 到 t₀ + Δt 这段时间的平均速度是 Δs/Δt = (s(t₀+Δt) − s(t₀))/Δt，这刻画的是"一段时间内的平均快慢"。要得到 t₀ 时刻的瞬时速度，就让 Δt 无限变小，看平均速度趋于哪个数——这个"趋于的极限"就是瞬时速度。把它推广到一般函数，就得到导数的定义。

定义：设函数 y = f(x) 在点 x₀ 的某邻域内有定义。如果极限
lim(Δx→0) (f(x₀+Δx) − f(x₀)) / Δx
存在，则称此极限为 f(x) 在 x₀ 处的导数，记作 f'(x₀)，或 y'|_(x=x₀)，或 dy/dx|_(x=x₀)。此时称 f(x) 在 x₀ 处可导。分母 Δx 也可以写成 x − x₀，等价形式是
f'(x₀) = lim(x→x₀) (f(x) − f(x₀)) / (x − x₀)。

直观理解：平均变化率是割线斜率（两个点连线的斜率），导数就是当两点无限靠近时割线斜率的极限，即切线的斜率。换句话说，导数刻画的是"函数在一点处变化的快慢与方向"——正导数说明函数在该点附近递增，负导数说明递减，导数的绝对值越大，变化越剧烈。

左导数与右导数：若只让 Δx 从左侧趋于 0（Δx < 0），得到左导数 f'₋(x₀)；只从右侧趋于 0 得到右导数 f'₊(x₀)。函数在 x₀ 处可导当且仅当左右导数都存在且相等。这个充要条件在判断分段函数分段点可导性时是必经之路。

导函数：若 f(x) 在区间 I 上每一点都可导，则导数 f'(x) 是 I 上的一个函数，称为导函数。求 f'(x₀) 可以先求导函数再代值，即 f'(x₀) = f'(x)|_(x=x₀)。

例1 用定义求 f(x) = x² 在 x = 2 处的导数。解：f'(2) = lim(Δx→0) ((2+Δx)² − 4)/Δx = lim(Δx→0) (4 + 4Δx + Δx² − 4)/Δx = lim(Δx→0) (4 + Δx) = 4。

例2 用定义求 f(x) = sin x 的导函数。解：f'(x) = lim(h→0) (sin(x+h) − sin x)/h = lim(h→0) 2cos(x + h/2)sin(h/2)/h = cos x（用到了 sin(x+h) − sin x = 2cos(x+h/2)sin(h/2) 与重要极限 lim sin t / t = 1）。

例3 讨论 f(x) = |x| 在 x = 0 处的可导性。解：f'₋(0) = lim(Δx→0⁻) (−Δx)/Δx = −1，f'₊(0) = lim(Δx→0⁺) Δx/Δx = 1，左右导数不等，故 f(x) 在 x = 0 处不可导。这正对应 y = |x| 的图像在原点处有一个"尖点"，尖点处没有切线。

易错提醒：用定义求导时，Δx 是整体变量，不要出现 "lim(Δx→0) (f(x₀+Δx) − f(x₀))/Δx 中分子里只放一个 Δx→0" 的错误写法；分子必须是 f(x₀+Δx) − f(x₀)，Δx 在分子分母中要保持一致。

1.2 导数的几何意义

几何意义：f'(x₀) 就是曲线 y = f(x) 在点 (x₀, f(x₀)) 处切线的斜率。因此过该点的切线方程为
y − f(x₀) = f'(x₀)(x − x₀)；
法线（与切线垂直）方程为
y − f(x₀) = −1/f'(x₀) · (x − x₀)（当 f'(x₀) ≠ 0 时）。

例 求曲线 y = x³ 在点 (1, 1) 处的切线与法线方程。解：y' = 3x²，f'(1) = 3。切线：y − 1 = 3(x − 1)，即 y = 3x − 2；法线：y − 1 = −(1/3)(x − 1)，即 y = −x/3 + 4/3。

易错提醒：先确认点是否在曲线上。若点在曲线上才直接用切点公式；若题目给的是"过某点的切线"（点不一定在曲线上），需要设切点再解方程。

1.3 可导与连续的关系

定理：可导必连续。证明：Δy = (Δy/Δx)·Δx，两边取极限得 lim(Δx→0) Δy = f'(x₀)·0 = 0，即 Δx→0 时 Δy→0，这正是连续的定义。

注意逆命题不成立：连续不一定可导。经典反例是 y = |x| 在 x = 0 处连续（lim |x| = 0 = |0|）但不可导（上一节已证）；另一个例子是 y = x^(1/3) 在 x = 0 处连续，但该点切线竖直（斜率无穷大），导数不存在。

结论要牢记：可导 ⇒ 连续，连续 ⇏ 可导。在判断题里"可导必连续"为真，"连续必可导"为假。

1.4 基本初等函数的导数公式

这些公式是求导的"乘法表"，必须背熟：
（1）(C)' = 0（C 为常数）；
（2）(xⁿ)' = nxⁿ⁻¹（n 为实数），例如 (x³)' = 3x²，(1/x)' = (x⁻¹)' = −x⁻² = −1/x²， (√x)' = (x^(1/2))' = 1/(2√x)；
（3）(sin x)' = cos x， (cos x)' = −sin x， (tan x)' = sec²x， (cot x)' = −csc²x， (sec x)' = sec x·tan x， (csc x)' = −csc x·cot x；
（4）(arcsin x)' = 1/√(1−x²)， (arccos x)' = −1/√(1−x²)， (arctan x)' = 1/(1+x²)， (arccot x)' = −1/(1+x²)；
（5）(aˣ)' = aˣ·ln a（a > 0 且 a ≠ 1），特别地 (eˣ)' = eˣ；
（6）(log_a x)' = 1/(x·ln a)，特别地 (ln x)' = 1/x。

例 求 y = x³ − 2x² + 5x − 1 的导数。解：y' = 3x² − 4x + 5（逐项用幂函数公式与常数公式）。

易错提醒：(aˣ)' 与 (xᵃ)' 不要混淆——底数是常数指数是变量用指数公式（乘 ln a），底数是变量指数是常数用幂公式。另外 (ln|x|)' = 1/x 对 x ≠ 0 成立，不要漏掉绝对值。

二、求导法则

2.1 四则运算法则

设 u = u(x)，v = v(x) 都可导，则：
（1）(u ± v)' = u' ± v'；
（2）(u·v)' = u'·v + u·v'（乘积的导数 = 前导后不导 + 前不导后导）；
（3）(u/v)' = (u'·v − u·v')/v²（v ≠ 0，分子是"上导下不导减上不导下导"）。

这三个法则把"求导"从单个函数推广到函数的加减乘除组合。

例1 求 y = x²·sin x 的导数。解：y' = (x²)'·sin x + x²·(sin x)' = 2x·sin x + x²·cos x。

例2 求 y = tan x 的导数。解：tan x = sin x/cos x，y' = ((sin x)'·cos x − sin x·(cos x)')/cos²x = (cos²x + sin²x)/cos²x = 1/cos²x = sec²x，与公式表一致。

例3 求 y = eˣ/x 的导数。解：y' = ((eˣ)'·x − eˣ·(x)')/x² = (x·eˣ − eˣ)/x² = eˣ(x − 1)/x²。

易错提醒：乘积法则的符号是"加"，商法则的分子是"减"，方向不能写反（u'v − uv' 不是 uv' − u'v）。先判断结构再选法则：见到乘积用乘积法则，见到分式用商法则，能化简的先化简（如 x²/x = x 直接求导更快）。

2.2 复合函数求导（链式法则）

设 y = f(u)，u = g(x) 均可导，则复合函数 y = f(g(x)) 的导数为
dy/dx = dy/du · du/dx = f'(g(x)) · g'(x)。
口诀：外层求导（把内层整体当自变量），再乘内层导数。复合几层就乘几层。

例1 求 y = sin(2x) 的导数。解：外层 sin 导 cos，内层 2x 导 2，y' = cos(2x)·2 = 2cos(2x)。

例2 求 y = e^(x²) 的导数。解：y' = e^(x²)·(x²)' = 2x·e^(x²)。

例3 求 y = ln(1 + x²) 的导数。解：y' = 1/(1+x²)·(1+x²)' = 2x/(1+x²)。

例4 求 y = √(1 + tan x) 的导数。解：y' = 1/(2√(1+tan x))·sec²x（三层复合：开方、1+tan、tan）。

易错提醒：链式法则最常见的错误是"漏乘内层导数"——求完外层就停。检查方法：看复合了几层，就应当乘几个因子。例如 y = sin²(3x)，先看成 u²（u = sin(3x)）再 u = sin v（v = 3x），y' = 2sin(3x)·cos(3x)·3。

2.3 隐函数求导

如果方程 F(x, y) = 0 能确定 y 是 x 的函数 y = y(x)，但不好（或不必）显式解出 y，就称 y 是 x 的隐函数。求导方法：方程两边同时对 x 求导，把 y 看作 x 的函数（出现 y 的地方就出现 y'），然后解出 y'。

例1 由 x² + y² = 1 求 y'。解：两边对 x 求导：2x + 2y·y' = 0，解得 y' = −x/y（y ≠ 0）。这与显式解 y = √(1−x²) 求导的结果 y' = −x/√(1−x²) 一致。

例2 由 eʸ + xy = e 求 y' 在 x = 0 处的值。解：两边求导：eʸ·y' + y + x·y' = 0，得 y' = −y/(eʸ + x)。x = 0 时由原方程 eʸ = e 得 y = 1，故 y'(0) = −1/(e + 0) = −1/e。

易错提醒：对含 y 的项求导后**必须乘 y'**，这是隐函数求导的得分点也是失分点。求导后若表达式里还含 y，允许保留（不必消掉），代点求值时先用原方程把 y 算出来。

2.4 参数方程求导

若曲线由参数方程 x = φ(t)，y = ψ(t) 给出（φ、ψ 可导且 φ'(t) ≠ 0），则
dy/dx = ψ'(t)/φ'(t)。
推导：dy/dx = (dy/dt)/(dx/dt)。若再求二阶导，d²y/dx² = d(dy/dx)/dx = [d(dy/dx)/dt] / [dx/dt]。

例 求摆线 x = t − sin t，y = 1 − cos t 在 t = π/2 处的切线斜率。解：dx/dt = 1 − cos t，dy/dt = sin t，dy/dx = sin t/(1 − cos t)。t = π/2 时斜率为 1/(1 − 0) = 1。

易错提醒：dy/dx 与 dy/dt 是两个不同概念，前者是"对 x 求导"，后者是"对参数 t 求导"，不能混用。求二阶导时，dy/dx 的结果还要再对 t 求导，最后再除以 dx/dt，不能直接对 dy/dx 的结果再求一次"对 x 的导"（因为还没有 x 的表达式）。

2.5 对数求导法

适用情形：幂指函数（底数和指数都含变量，如 xˣ）以及多个因子连乘连除的式子。方法：先取对数 ln y = ln f(x)，再用隐函数求导法求 y'，最后两边乘 y 得 y' = y·(ln y)'。

例1 求 y = xˣ 的导数（x > 0）。解：ln y = x·ln x，两边求导：y'/y = ln x + 1，故 y' = xˣ·(ln x + 1)。

例2 求 y = √((x−1)(x−2)/((x−3)(x−4))) 的导数。解：ln y = (1/2)[ln(x−1) + ln(x−2) − ln(x−3) − ln(x−4)]，求导得 y'/y = (1/2)[1/(x−1) + 1/(x−2) − 1/(x−3) − 1/(x−4)]，再乘 y 即得。

易错提醒：取对数时注意定义域（真数大于零）；幂指函数不能用幂公式或指数公式直接套（底数和指数都在变），必须对数求导法。

三、高阶导数

3.1 高阶导数的定义与计算

若 f'(x) 可导，则其导数称为二阶导数，记 f''(x) 或 d²y/dx²；依此类推，n 阶导数记 f^(n)(x) 或 dⁿy/dxⁿ。二阶导数的几何意义是曲线的凹凸相关量，物理意义是加速度。

常见函数的高阶导数：
（1）(eˣ)^(n) = eˣ；
（2）(sin x)^(n) = sin(x + nπ/2)，(cos x)^(n) = cos(x + nπ/2)；
（3）(ln(1+x))^(n) = (−1)^(n−1)·(n−1)!/(1+x)ⁿ；
（4）(1/(1+x))^(n) = (−1)ⁿ·n!/(1+x)^(n+1)；
（5）幂函数 x^m 的 n 阶导，n > m 时为 0。

莱布尼茨公式：若 u、v 都有 n 阶导数，则
(uv)^(n) = Σ_(k=0..n) C(n,k)·u^(n−k)·v^(k)，
形式与二项式展开一致。它把"乘积的高阶导"化为"各因子高阶导的组合"，适合 u、v 中有一个是低次多项式的情形。

例 求 y = x²·eˣ 的 20 阶导数。解：取 u = eˣ（任意阶导都是 eˣ），v = x²（三阶及以上为 0），由莱布尼茨公式
y^(20) = C(20,0)·eˣ·(x²)^(0) + C(20,1)·eˣ·(x²)' + C(20,2)·eˣ·(x²)''
= eˣ·x² + 20·eˣ·2x + 190·eˣ·2
= eˣ(x² + 40x + 380)。

易错提醒：莱布尼茨公式中组合数 C(n,k) 不要漏；注意 (x²)' = 2x、(x²)'' = 2、(x²)''' = 0，逐阶算清楚再套公式。

四、微分

4.1 微分的定义与几何意义

定义：设 y = f(x) 在点 x₀ 的某邻域内有定义，Δx 是自变量的增量。若增量 Δy = f(x₀+Δx) − f(x₀) 可表示为
Δy = A·Δx + o(Δx)，
其中 A 是与 Δx 无关的常数，则称 f(x) 在 x₀ 处可微，A·Δx 称为微分，记 dy = A·Δx。

定理（可微与可导等价）：f(x) 在 x₀ 处可微当且仅当可导，且此时 A = f'(x₀)。即 dy = f'(x₀)·Δx。通常把 Δx 记作 dx，于是 dy = f'(x) dx。

几何意义：dy 是曲线在切点处切线的纵坐标增量（沿切线走 Δx 上升的高度），而 Δy 是曲线本身的纵坐标增量。当 Δx 很小时，dy 与 Δy 之差是比 Δx 更高阶的无穷小，故用 dy 近似 Δy。

例 求 y = x² 在 x = 1，Δx = 0.1 处的微分。解：dy = f'(1)·Δx = 2×0.1 = 0.2；而真实增量 Δy = (1.1)² − 1 = 0.21，两者相差 0.01，很小。

4.2 微分运算法则与微分形式不变性

微分运算法则（由导数法则直接推出）：
（1）d(u ± v) = du ± dv；
（2）d(uv) = v·du + u·dv；
（3）d(u/v) = (v·du − u·dv)/v²；
（4）复合函数：d[f(g(x))] = f'(g(x))·g'(x)dx。

一阶微分形式不变性：设 y = f(u)，无论 u 是自变量还是中间变量（u = g(x)），都有 dy = f'(u) du。也就是说"外层导数乘以内层微分"的写法对中间变量同样成立。这个性质让微分在换元、近似计算时非常灵活。

例 求 y = sin(2x + 1) 的微分。解：dy = cos(2x+1)·d(2x+1) = cos(2x+1)·2dx = 2cos(2x+1) dx，与链式法则结果一致。

4.3 微分的近似计算

由 Δy ≈ dy，得近似公式
f(x₀ + Δx) ≈ f(x₀) + f'(x₀)·Δx。
常用近似（x → 0 时）：√(1+x) ≈ 1 + x/2；eˣ ≈ 1 + x；ln(1+x) ≈ x；sin x ≈ x；(1+x)ⁿ ≈ 1 + nx。

例1 求 √9.1 的近似值。解：取 f(x) = √x，x₀ = 9，Δx = 0.1。f'(x) = 1/(2√x)，f'(9) = 1/6。√9.1 ≈ 3 + (1/6)×0.1 = 3.0167（精确值约 3.0166，误差极小）。

例2 求 e^0.02 的近似值。解：取 f(x) = eˣ，x₀ = 0，Δx = 0.02，f'(0) = 1。e^0.02 ≈ 1 + 0.02 = 1.02。

易错提醒：近似公式中的 Δx 要足够小才准；先确定"基准点" x₀（方便计算函数值和导数值的点），再写 Δx = 目标 − x₀。

五、综合例题与易错点

5.1 综合例题

例1 求 y = (x²+1)·ln x 的导数。解：乘积法则 y' = 2x·ln x + (x²+1)/x。

例2 求 y = e^(sin x) 的导数。解：链式法则 y' = e^(sin x)·cos x。

例3 由方程 x³ + y³ = 6xy 求 dy/dx。解：3x² + 3y²·y' = 6y + 6x·y'，整理得 y'(3y² − 6x) = 6y − 3x²，故 y' = (2y − x²)/(y² − 2x)。

例4 求摆线 x = a(t − sin t)，y = a(1 − cos t) 在 t = π 处的切线方程。解：dx/dt = a(1 − cos t)，dy/dt = a sin t，dy/dx = sin t/(1 − cos t) = cot(t/2)。t = π 时斜率为 cot(π/2) = 0，点为 (aπ, 2a)，切线 y = 2a（水平切线）。

例5 求 y = x²·e^(−x) 的凹凸区间与拐点。解：y' = e^(−x)(2x − x²)，y'' = e^(−x)(x² − 4x + 2)。令 y'' = 0 得 x = 2 ± √2。x < 2−√2 时 y'' > 0（凹），2−√2 < x < 2+√2 时 y'' < 0（凸），x > 2+√2 时 y'' > 0（凹），x = 2±√2 为拐点。

例6 求函数 f(x) = x³ − 3x 在 [0, 2] 上的最值。解：f'(x) = 3x² − 3 = 3(x−1)(x+1)，驻点 x = 1（在区间内）。f(0) = 0，f(1) = −2，f(2) = 2，故最小值 −2，最大值 2。

5.2 易错点清单

① 复合函数漏乘内层导数——这是所有求导错误里最高频的，务必逐层检查；
② 商法则分子符号写反——(u/v)' 分子是 u'v − uv'，先写"上导下不导"；
③ 隐函数求导漏 y'——对含 y 的项求导后必须补乘 y'；
④ 参数方程 dy/dx 与 dy/dt 混淆——前者才是切线斜率；
⑤ 可导必连续，连续不一定可导——y = |x| 在 0 处是经典反例；
⑥ 微分 dy 与增量 Δy 不是一回事——dy 是切线增量，Δy 是曲线增量，二者差一个高阶无穷小；
⑦ 幂指函数 xˣ 不能直接套幂公式或指数公式——必须对数求导法；
⑧ 高阶导用莱布尼茨公式时别漏组合数。

5.3 常用公式表

导数： (C)' = 0；(xⁿ)' = nxⁿ⁻¹；(sin x)' = cos x；(cos x)' = −sin x；(tan x)' = sec²x；(eˣ)' = eˣ；(aˣ)' = aˣ ln a；(ln x)' = 1/x；(arcsin x)' = 1/√(1−x²)；(arctan x)' = 1/(1+x²)。
法则： (u±v)' = u'±v'；(uv)' = u'v + uv'；(u/v)' = (u'v − uv')/v²；复合 dy/dx = f'(g(x))·g'(x)。
微分： dy = f'(x) dx；一阶微分形式不变性 dy = f'(u) du。
高阶： 莱布尼茨 (uv)^(n) = Σ C(n,k) u^(n−k) v^(k)。
