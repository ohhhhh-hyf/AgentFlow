高等数学期末划重点（最后一课课堂录音整理）

同学们，最后这节课我把期末考试的范围和重点跟大家交代清楚，大家对照自己的笔记好好复习。

先说说整体结构。咱们第一章极限是考试的重中之重，占到大约三成左右的分数，而且后面的导数、积分都要用它，所以这一章必须吃透。其他章节虽然也有分，但极限要是没学好，后面全是空中楼阁。

一、必考内容（一定出大题，务必掌握）

第一个必考的是两个重要极限，这个每届必出，而且是拉开分差的地方。第一个重要极限就是那个 sin x 比 x，当 x 趋近于零的时候极限等于一。考的时候一般不会直接给你 sin x 比 x，而是给你变形，比如 sin 3x 比 x，或者 sin 5x 比 sin 3x 这种，大家要会凑形。第二个重要极限是那个一加 n 分之一的 n 次方趋近于 e，这个也必考，要会凑"一加无穷小、指数取倒数"这个结构，比如一加 x 分之二的三 x 次方这种，答案都是 e 的多少次方。

第二个必考的是等价无穷小替换求极限。这一块我给九个常用的等价无穷小，大家必须背下来：sin x 等价于 x，tan x 等价于 x，一减 cos x 等价于二分之 x 平方，ln 一加 x 等价于 x，e 的 x 次方减一等价于 x，这些一定要滚瓜烂熟。注意我强调过的，替换只能在乘除里面用，加减法里面不能乱换，那个 tan x 减 sin x 比 x 三次方的题，很多同学直接换就错了，一定要先提公因子。

第三个必考的是极限计算的一般方法，0 比 0 型、无穷比无穷型都会出计算题。0 比 0 型的套路是约因子、有理化、等价替换；无穷比无穷型就是抓大头，分子分母同除以最高次项。这个没什么技巧，就是多练。

第四个必考的是间断点的分类。给你一个分段函数，让你判断在分段点处是第几类间断点，是可去还是跳跃，这种题几乎年年有。大家记住判断流程：先看左右极限，都存在就是第一类，相等是可去、不相等是跳跃；有一个不存在就是第二类。

二、重点内容（考到的概率很大）

重点一个是夹逼准则和单调有界准则，这个一般出在数列极限的题里。夹逼要注意放缩，两边极限要一致；单调有界要按三步走，先证有界再证单调最后设极限解方程。递推数列的题会用到，比如那个 x 一等于根号二，x 加一等于根号下二加 x 的题，大家一定要会。

重点二是连续性的概念和闭区间上连续函数的性质，特别是零点定理。证明方程在某个区间内有根，就用零点定理，先构造函数，再找两个端点函数值异号，直接下结论。如果要证唯一，再加一步单调性。这个证明题是每年必考的一个类型，大家一定要掌握书写规范。

重点三是无穷小与无穷大的概念辨析，特别是"无界"和"无穷大"的区别，那个 x 乘 sin x 的反例要记住，这个在选择题里出现过。

三、了解内容（有印象即可）

数列极限和函数极限的定义证明，就是那个 ε 语言和 ε-δ 语言，大家了解书写规范就行，一般不会让你现场证一个大题，但概念要清楚。海涅定理了解一下它的思想。连续函数的运算性质了解即可。

四、考法提示与复习建议

计算题一般五到六道，全是极限；选择填空里会有概念辨析，比如收敛和有界的关系、等价替换的适用范围；证明题就是零点定理和单调有界。大家复习的时候，把我说的必考四块每块做十道题，重点两块每块做五道，基本就稳了。错题一定要整理，考前把错题本过一遍，比盲目刷题效果好得多。

还有两天时间，大家把两个重要极限和九个等价无穷小默写一遍，保证拿分。好，就这些，下课。
