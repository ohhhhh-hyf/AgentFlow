二、知识点

核心★★★★★ 氢原子

考法预判 可能考查氢原子能级公式的应用，如计算能级差、跃迁波长；也可能给出波函数要求识别量子数或判断归一化。需掌握量子数的物理意义和取值规则。

必须先会

  • 氢原子能级公式：E_n = -13.6 eV / n^2，n=1,2,3,...
  • 波函数 ψ_nlm(r,θ,φ) = R_nl(r) Y_lm(θ,φ)，其中 n 为主量子数，l 为角量子数，m 为磁量子数。
  • 量子数取值：n=1,2,...；l=0,1,...,n-1；m=-l,-l+1,...,l。
  • 能级简并度：n^2（不考虑自旋）。
  • 波函数归一化条件：∫|ψ|^2 dV = 1。

知识点讲解 氢原子是量子力学中少数可精确求解的系统，其能级公式 E_n = -13.6 eV / n^2 是核心，适用于库仑势。波函数由三个量子数 (n,l,m) 标记，分别决定能量、角动量大小和角动量 z 分量。考试中可能要求根据能级公式计算跃迁光子能量，或根据波函数形式判断量子数。注意能级简并度 n^2 是忽略自旋的结果，若考虑自旋则简并度加倍。笔记中缺少波函数的具体形式，建议补充 R_nl 和 Y_lm 的表达式。

方法步骤

  1. 识别题目是否涉及氢原子能级或波函数。
  2. 若求能级，直接代入 E_n = -13.6 eV / n^2。
  3. 若求跃迁，计算 ΔE = E_final - E_initial，再求波长 λ = hc/ΔE。
  4. 若给波函数，确定 n,l,m 并检查取值是否合法。
  5. 若求概率密度，计算 |ψ|^2 并积分。

易错提醒

  • 注意能级公式只适用于氢原子（单电子），不适用于多电子原子。
  • 量子数 l 不能超过 n-1，m 不能超过 |l|。
  • 计算跃迁时注意单位换算（eV 与 J）。

重点★★★★☆ 宏观态与微观态

考法预判 可能考查宏观态与微观态的定义及区分，或通过具体例子（如气体分子分布）说明宏观态对应的微观态数。需理解量子态与相空间体积的对应关系。

必须先会

  • 宏观态由宏观参量（如温度、压强、体积）确定，微观态由每个粒子的量子态确定。
  • 一个宏观态对应大量微观态，微观态数称为热力学概率。
  • 量子态与相空间体积元 h^3 对应，每个量子态占据相空间体积 h^3。
  • μ 空间是单个粒子的相空间，ΔM 的分割举例：将 μ 空间划分为若干小体积元 Δω_i，每个体积元对应一个量子态。

知识点讲解 宏观态与微观态是统计物理的基础概念。宏观态由少数宏观参量描述，微观态则具体到每个粒子的状态。例如，一个容器中的气体，宏观态由 P,V,T 确定，微观态则是每个分子的位置和动量。量子力学中，微观态对应量子态，每个量子态在相空间中占据体积 h^3。考试可能要求判断某个描述是宏观态还是微观态，或计算给定宏观态下的微观态数。注意宏观态与微观态是一对多的关系。

方法步骤

  1. 判断题目描述的是宏观参量还是微观状态。
  2. 若为宏观态，列出其宏观参量。
  3. 若为微观态，确定每个粒子的量子数或位置动量。
  4. 若求微观态数，计算相空间体积除以 h^3。

易错提醒

  • 不要混淆宏观态与微观态，宏观态是统计平均的结果。
  • 量子态与相空间体积的对应关系仅在经典极限下成立。

重点★★★★☆ 角动量的对易式

考法预判 可能考查角动量分量之间的对易关系，如 [L_x, L_y] = iħL_z，或角动量平方与分量的对易。也可能要求利用对易关系推导本征值。

必须先会

  • 角动量分量对易关系：[L_x, L_y] = iħL_z，[L_y, L_z] = iħL_x，[L_z, L_x] = iħL_y。
  • 角动量平方与分量对易：[L^2, L_i] = 0，i=x,y,z。
  • 与坐标的对易关系：[L_i, x_j] = iħ ε_ijk x_k。
  • 与动量的对易关系：[L_i, p_j] = iħ ε_ijk p_k。
  • 常用对易恒等式：[A, BC] = B[A,C] + [A,B]C。

知识点讲解 角动量对易式是量子力学角动量理论的核心。分量之间不对易，导致不能同时确定所有分量；但 L^2 与每个分量对易，因此可以同时确定 L^2 和一个分量（通常取 L_z）。考试可能要求记忆对易关系，或利用它们推导不确定关系。注意对易关系中的 ε_ijk 是列维-奇维塔符号。笔记中缺少与坐标、动量对易的具体形式，建议补充。

方法步骤

  1. 识别题目是否涉及角动量对易。
  2. 若求对易关系，直接套用标准公式。
  3. 若求本征值，利用 [L^2, L_z]=0 选择共同本征态。
  4. 若求不确定关系，利用对易关系计算 ΔL_x ΔL_y ≥ ħ/2 |<L_z>|。

易错提醒

  • 注意对易关系的符号和因子 iħ。
  • 不要忘记 [L^2, L_i]=0，这是共同本征态的基础。

重点★★★★☆ 宏观分布、组态、微观态

考法预判 可能考查宏观分布、组态、微观态的概念，或计算经典力学中一个组态的微观数。需理解 μ 空间分割与宏观分布的关系。

必须先会

  • 宏观分布：将 μ 空间分割为若干小区域，每个区域内的粒子数 N_i 构成宏观分布。
  • 宏观态由宏观分布确定，组态（配容）是具体的粒子分配方式。
  • 经典力学中一个组态的微观数：W = N! / ∏ N_i!。
  • 一个分布的微观分布数：考虑粒子全同性，W = ∏ (ω_i^{N_i} / N_i!)，其中 ω_i 是第 i 个区域的量子态数。

知识点讲解 宏观分布、组态、微观态是统计物理中描述多粒子系统的重要概念。宏观分布是粗粒化的描述，组态是具体的分配，微观态则是更精细的量子态。经典力学中，一个组态的微观数由排列组合给出。考试可能要求计算给定分布下的微观态数，或理解这些概念的区别。注意全同粒子的处理：经典粒子可区分，量子粒子不可区分。

方法步骤

  1. 确定系统是经典还是量子。
  2. 若经典，计算组态数 W = N! / ∏ N_i!。
  3. 若量子，计算微观分布数 W = ∏ (ω_i^{N_i} / N_i!)。
  4. 注意粒子是否全同。

易错提醒

  • 经典与量子微观态数公式不同，不要混淆。
  • 注意 N_i 是第 i 个区域的粒子数，ω_i 是量子态数。

重点★★★★☆ 一维半无限深方势阱

考法预判 可能考查一维半无限深方势阱的束缚态条件、波函数连续条件，以及能级量子化。可能要求写出波函数或计算能级。

必须先会

  • 束缚态条件：能量 E < V0（势阱深度），波函数在无穷远处趋于零。
  • 波函数连续条件：在势阱边界处波函数及其导数连续（若势函数有限）。
  • 能级量子化：由边界条件得到量子化条件，如 k a = nπ 等。
  • 半无限深势阱：一侧为无限高势垒，另一侧为有限势垒，波函数在无限高侧为零。

知识点讲解 一维半无限深方势阱是量子力学中的典型模型，用于理解束缚态和量子化。势阱一侧无限高，波函数在该侧为零；另一侧有限高，波函数可渗透到势垒中。束缚态条件要求能量低于势垒高度，波函数在无穷远处衰减。考试可能要求求解波函数和能级，注意边界条件的应用。笔记中缺少具体求解步骤，建议补充。

方法步骤

  1. 写出分区薛定谔方程。
  2. 在势阱内解为平面波，势垒区为指数衰减。
  3. 应用边界条件：波函数连续，导数连续（若势函数有限）。
  4. 在无限高侧，波函数为零。
  5. 由边界条件得到量子化条件，解出能级。

易错提醒

  • 注意无限高侧波函数必须为零，不能有渗透。
  • 导数连续条件仅在势函数有限时成立，若势函数无限则不适用。

考法预判 可能考查一维谐振子的能量本征值、本征函数，或利用升降算符求解。可能要求计算跃迁矩阵元。

必须先会

  • 能量本征值：E_n = ħω(n + 1/2)，n=0,1,2,...
  • 本征函数：ψ_n(x) = N_n H_n(ξ) e^{-ξ^2/2}，其中 ξ = √(mω/ħ) x，H_n 为厄米多项式。
  • 升降算符：a†|n> = √(n+1)|n+1>，a|n> = √n|n-1>。
  • 基态波函数：ψ_0(x) = (mω/πħ)^{1/4} e^{-mωx^2/(2ħ)}。

知识点讲解 一维谐振子是量子力学中重要的可解模型，能级等间距，基态能量不为零。升降算符方法简洁，可用于计算矩阵元和激发态。考试可能要求写出能级公式，或利用升降算符计算 <n|x|m>。注意本征函数中的厄米多项式，以及归一化常数。笔记中缺少升降算符的具体应用，建议补充。

方法步骤

  1. 识别题目是否涉及谐振子。
  2. 若求能级，直接使用 E_n = ħω(n+1/2)。
  3. 若求波函数，写出 ψ_n 并归一化。
  4. 若求矩阵元，利用升降算符表示 x 和 p。
  5. 计算 <n|x|m> 时，将 x 用 a 和 a† 表示。

易错提醒

  • 注意基态能量不为零，为 ħω/2。
  • 升降算符作用时注意系数 √n 和 √(n+1)。
