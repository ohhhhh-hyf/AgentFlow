## 目标

同步侧四类接口里，**三类**从 `/api/v1/{domain}/{task}/...` 收敛到 `/api/agent/v1`，`domain` / `task` 改由请求体传；**预览接口按你的要求不动**。旧路径直接删除（404）。

### 改动后的对外路由面

| 形态 | 改动前 | 改动后 |
|---|---|---|
| 同步 POST | `POST /api/v1/{domain}/{task}` | `POST /api/agent/v1` |
| 流式 POST | `POST /api/v1/{domain}/{task}/stream` | `POST /api/agent/v1/stream` |
| 下载 GET | `GET /api/v1/{domain}/{task}/file/{request_id}/{file_name}` | `GET /api/agent/v1/file/{request_id}/{file_name}` |
| 预览 GET | `GET /api/v1/{domain}/{task}/preview?request_id=&user_id=` | **不变** |

异步 `/api/v1/tasks` 四件套、`/api/v1/health`、`/data` 静态挂载、`/docs` 一律不动。

两个 POST 的请求体变成 `{domain, task, time, texts, docs, extra}` —— 与异步提交接口同形（异步本来就是 `TaskRequest + domain + task`）。下载接口不再需要域和任务名：产物目录 `data/{user_id}/output/{request_id}/` 由 `request_id` 唯一确定，`file_name` 取响应 `data.file_name`，这两个参数本来就够定位。

## 代码改动

**1. `app/schemas.py`** — 新增 `DomainTaskRequest(TaskRequest)`，加 `domain: str` / `task: str` 两个必填字段。这是域+任务名请求体的唯一定义处。

**2. `app/tasklines.py`** — 新增 `resolve_line(domain, task) -> (域, 线名)` 与异常 `TaskLineNotFound(status, message)`，把白名单校验收成一份。当前异步接口的 `_validate_domain_task`（`routes/tasks.py:63-74`）和新的同步接口需要同一套规则（域不存在 400、域内无此线 404、其他域有这个线时给"域不支持"提示），目前这段逻辑只写在异步侧。

**3. `app/routes/agent.py`（新建）** — 统一路由器 `APIRouter(prefix="/api/agent/v1", tags=["agent"])`，三个端点：
- `POST ""` → 校验 domain/task → `run_task(domain, line, req, ...)` → `TaskResponse`（保留 `response_model`）
- `POST "/stream"` → 同样校验 → `stream_task(...)` → NDJSON
- `GET "/file/{request_id}/{file_name}"` → 下载
- 请求头沿用现有约定：`X-Request-Id` 可选（缺省自动生成）、`X-User-Id` 必填；`ApiError` 由 `main.py` 的全局处理器转成 `{code, request_id, message}`，与现在一致。

**4. `app/routes/_file_endpoints.py`** — `download_endpoint(task)` 工厂去掉 `task` 参数（它只用来给函数命名，占位没用），改成一个普通 handler；`preview_endpoint(task)` 原样保留。

**5. `app/routes/_registry.py`** — 从"每条线注册四类路由"缩成"按声明注册预览路由"（只保留 `files=True` 的线），`_headers()` 辅助函数移到 `agent.py`。文件与 `register_domain` 入口名保留，避免动 `meeting.py` / `notes.py` 的调用方式。

**6. `app/routes/meeting.py` / `notes.py`** — 只改 docstring（前缀不变，现在只服务预览端点）。

**7. `app/routes/tasks.py`** — `AsyncTaskRequest` 改为继承 `schemas.DomainTaskRequest`（保持类名，OpenAPI 名称不变，异步行为零变化）；`_validate_domain_task` 改成 `resolve_line` 的薄包装，重新抛出 `AsyncApiError`，状态码与消息逐字不变。

**8. `app/main.py`** — `include_router(agent.router)`；`routes/tasks.py:171` 文档里提到 `/api/v1/health` 仍然正确，不用改。

**9. `app/tasks.py` 不动** —— 路由层解析出线名后照旧调 `run_task(domain, line, ...)` / `stream_task(...)`，`_prepare` / `_validate` / 产物落盘全部复用。

### 一处行为收紧（顺带修好）

同步接口原来的任务名校验是**全局**的（`tasks.py:352` 用 `all_lines()` 的并集），所以 `POST /api/v1/notes/minutes` 能通过校验、然后在域装配里以更深层的错误失败。新实现按域校验（与异步接口一致）：`notes` + `minutes` 现在干净地返回 404「notes 不支持任务线：minutes」。这是修正，不是回归，我会在 api.md 里写明。
